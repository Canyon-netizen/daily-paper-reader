# Iteration 2: Infrastructure Design

## Overview

This document specifies infrastructure solutions for DPR iteration 2, addressing five critical gaps identified in iteration 1:
1. Static IDs require code changes
2. No cross-module search
3. No export functionality
4. No templates
5. Build-time type generation

**Constraints**: Astro static-first, build-time only. Must match existing patterns, not break existing modules.

---

## 1. Build-Time Auto-Discovery

### Problem
Adding a new markdown to `docs/ideas/*.md` doesn't auto-create a route. `getStaticPaths` is hardcoded in each `[id].astro`.

### Solution: Vite Plugin + Generated Paths Module

Create a Vite plugin that scans `docs/{module}/*.md` at build time and generates a paths registry.

**File**: `astro-src/scripts/generate-paths.mjs`

```javascript
// astro-src/scripts/generate-paths.mjs
// Scans docs/{module}/*.md and generates a TypeScript paths registry

import fs from 'fs';
import path from 'path';
import matter from 'gray-matter';

const DOCS_DIR = path.resolve('docs');
const OUTPUT_FILE = 'astro-src/lib/paths.generated.ts';
const MODULES = ['ideas', 'experiments', 'writing', 'roadmap'];

function extractIdFromFrontmatter(content) {
  const { data } = matter(content);
  // Try explicit id field, then derive from title, then use filename
  return data.id || (data.title ? data.title.toLowerCase().replace(/[^a-z0-9]+/g, '-').replace(/^-|-$/g, '') : null);
}

function scanModule(moduleName) {
  const moduleDir = path.join(DOCS_DIR, moduleName);
  if (!fs.existsSync(moduleDir)) return [];

  const files = fs.readdirSync(moduleDir).filter(f => f.endsWith('.md'));
  return files.map(filename => {
    const id = filename.replace('.md', '');
    const filepath = path.join(moduleDir, filename);
    const content = fs.readFileSync(filepath, 'utf-8');
    const explicitId = extractIdFromFrontmatter(content);
    return explicitId || id;
  });
}

const paths = MODULES.reduce((acc, mod) => {
  acc[mod] = scanModule(mod);
  return acc;
}, {});

const output = `// AUTO-GENERATED — Do not edit manually
// Generated by scripts/generate-paths.mjs

${Object.entries(paths).map(([mod, ids]) =>
  `export const ${mod}Paths = ${JSON.stringify(ids, null, 2)} as const;`
).join('\n')}

export type ModuleName = ${MODULES.map(m => `'${m}'`).join(' | ')};

export const allModulePaths: Record<ModuleName, readonly string[]> = {
  ${MODULES.map(m => `${m}: ${m}Paths`).join(',\n  ')}
};
`;

fs.writeFileSync(OUTPUT_FILE, output);
console.log(`Generated paths to ${OUTPUT_FILE}`);
```

**Integration**: Add to `package.json` scripts:

```json
{
  "scripts": {
    "prebuild": "node astro-src/scripts/generate-paths.mjs",
    "dev": "node astro-src/scripts/generate-paths.mjs && astro dev"
  }
}
```

**Usage in `[id].astro`**:

```astro
---
import { ideasPaths } from '../../lib/paths.generated';

export async function getStaticPaths() {
  return ideasPaths.map((id) => ({ params: { id } }));
}
```

### Pattern for New Modules

To add a new module (e.g., `notes/`):

1. Add to `MODULES` array in `generate-paths.mjs`
2. Create `docs/notes/*.md` files
3. Use `import { allModulePaths } from '../../lib/paths.generated'` in the page

## 2. Cross-Module Search

### Problem
No unified search across ideas + experiments + writings + papers + library.

### Solution: Unified Search API + Client

**File**: `astro-src/lib/search/unified.ts`

```typescript
import { searchPapers } from '../search';
import { getIdeas } from '../ideas';
import { getExperiments } from '../experiments';
import { getWritings } from '../writing';

export interface UnifiedSearchResult {
  module: 'paper' | 'idea' | 'experiment' | 'writing' | 'library';
  id: string;
  title: string;
  excerpt: string;
  score: number;
}

export interface UnifiedSearchOptions {
  query: string;
  modules?: Array<'paper' | 'idea' | 'experiment' | 'writing' | 'library'>;
  topK?: number;
}

export async function unifiedSearch(opts: UnifiedSearchOptions): Promise<UnifiedSearchResult[]> {
  const { query, modules = ['paper', 'idea', 'experiment', 'writing', 'library'], topK = 50 } = opts;
  const results: UnifiedSearchResult[] = [];

  // Parallel search across requested modules
  const searches: Promise<void>[] = [];

  if (modules.includes('paper')) {
    searches.push(
      searchPapers(query, { topK }).then(r => {
        results.push(...r.hits.map(h => ({
          module: 'paper' as const,
          id: h.id,
          title: h.id, // Would fetch full title from corpus
          excerpt: '',
          score: h.score,
        })));
      })
    );
  }

  if (modules.includes('idea')) {
    const ideas = getIdeas();
    const q = query.toLowerCase();
    ideas.filter(i =>
      i.title.toLowerCase().includes(q) ||
      i.description.toLowerCase().includes(q)
    ).forEach(i => results.push({
      module: 'idea',
      id: i.id,
      title: i.title,
      excerpt: i.description.slice(0, 150),
      score: 1.0, // Simple binary match for now
    }));
  }

  if (modules.includes('experiment')) {
    const experiments = getExperiments();
    const q = query.toLowerCase();
    experiments.filter(e =>
      e.title.toLowerCase().includes(q) ||
      e.hypothesis.toLowerCase().includes(q)
    ).forEach(e => results.push({
      module: 'experiment',
      id: e.id,
      title: e.title,
      excerpt: e.hypothesis.slice(0, 150),
      score: 1.0,
    }));
  }

  if (modules.includes('writing')) {
    const writings = getWritings();
    const q = query.toLowerCase();
    writings.filter(w =>
      w.title.toLowerCase().includes(q) ||
      w.content?.toLowerCase().includes(q)
    ).forEach(w => results.push({
      module: 'writing',
      id: w.id,
      title: w.title,
      excerpt: w.content?.slice(0, 150) || '',
      score: 1.0,
    }));
  }

  await Promise.all(searches);

  // Sort by score and limit
  return results
    .sort((a, b) => b.score - a.score)
    .slice(0, topK);
}
```

## 3. Export Functionality

### Problem
Writings can't be exported as PDF/Markdown.

### Solution: Client-Side Export with Libraries

**File**: `astro-src/lib/export/index.ts`

```typescript
import type { Writing } from '../writing/types';

/**
 * Export a writing as Markdown file
 */
export function exportAsMarkdown(writing: Writing): void {
  const frontmatter = [
    '---',
    `title: ${writing.title}`,
    `created: ${new Date(writing.createdAt).toISOString()}`,
    `updated: ${new Date(writing.updatedAt).toISOString()}`,
    writing.tags?.length ? `tags: [${writing.tags.join(', ')}]` : null,
    '---',
    '',
  ].filter(Boolean).join('\n');

  const content = `${frontmatter}\n\n${writing.content || ''}`;

  downloadFile(content, `${writing.id}.md`, 'text/markdown');
}

/**
 * Export a writing as PDF (client-side via browser print)
 */
export function exportAsPDF(writing: Writing, titleElement: HTMLElement, contentElement: HTMLElement): void {
  const printWindow = window.open('', '_blank');
  if (!printWindow) return;

  printWindow.document.write(`
    <!DOCTYPE html>
    <html>
    <head>
      <title>${writing.title}</title>
      <style>
        body { font-family: system-ui, sans-serif; max-width: 800px; margin: 0 auto; padding: 40px; }
        h1 { font-size: 24px; }
        .meta { color: #666; font-size: 14px; }
        .content { line-height: 1.6; }
        @media print { body { padding: 0; } }
      </style>
    </head>
    <body>
      <h1>${writing.title}</h1>
      <div class="meta">创建于 ${new Date(writing.createdAt).toLocaleDateString()}</div>
      <div class="content">${contentElement.innerHTML}</div>
    </body>
    </html>
  `);

  printWindow.document.close();
  printWindow.focus();
  setTimeout(() => {
    printWindow.print();
    printWindow.close();
  }, 250);
}

function downloadFile(content: string, filename: string, mimeType: string): void {
  const blob = new Blob([content], { type: mimeType });
  const url = URL.createObjectURL(blob);
  const a = document.createElement('a');
  a.href = url;
  a.download = filename;
  a.click();
  URL.revokeObjectURL(url);
}
```

## 5. Build-Time Type Generation

### Problem
Frontmatter types aren't auto-generated from sample docs.

### Solution: Type Generation Script

**File**: `astro-src/scripts/generate-types.mjs`

```javascript
// astro-src/scripts/generate-types.mjs
// Scans sample docs and generates TypeScript interfaces

import fs from 'fs';
import path from 'path';
import matter from 'gray-matter';

const DOCS_DIR = path.resolve('docs');
const OUTPUT_DIR = 'astro-src/lib';
const MODULES = ['ideas', 'experiments', 'writing', 'roadmap'];

function extractFrontmatterFields(moduleName) {
  const moduleDir = path.join(DOCS_DIR, moduleName);
  if (!fs.existsSync(moduleDir)) return new Set();

  const files = fs.readdirSync(moduleDir).filter(f => f.endsWith('.md'));
  const allFields = new Set<string>();

  files.slice(0, 5).forEach(filename => { // Sample first 5 files
    const content = fs.readFileSync(path.join(moduleDir, filename), 'utf-8');
    const { data } = matter(content);
    Object.keys(data).forEach(k => allFields.add(k));
  });

  return allFields;
}

function tsTypeFromValue(value) {
  if (value === null || value === undefined) return 'string';
  if (typeof value === 'boolean') return 'boolean';
  if (typeof value === 'number') return 'number';
  if (Array.isArray(value)) return 'string[]';
  if (typeof value === 'object') return 'Record<string, any>';
  return 'string';
}

function generateTypeScript(moduleName, fields) {
  const interfaceName = moduleName.slice(0, -1).charAt(0).toUpperCase() +
                        moduleName.slice(1).replace(/s$/, ''); // idea -> Idea

  const lines = [
    `// AUTO-GENERATED — Do not edit manually`,
    `// Generated by scripts/generate-types.mjs`,
    ``,
    `export interface ${interfaceName} {`,
  ];

  const requiredFields = ['title', 'id', 'status'];
  const optionalFields = [...fields].filter(f => !requiredFields.includes(f));

  requiredFields.forEach(f => {
    lines.push(`  ${f}: ${tsTypeFromValue('')};`);
  });

  optionalFields.forEach(f => {
    lines.push(`  ${f}?: ${tsTypeFromValue('')};`);
  });

  lines.push('}');
  lines.push('');
  lines.push(`export type ${interfaceName}Status = 'draft' | 'active' | 'completed' | 'archived';`);

  return lines.join('\n');
}

MODULES.forEach(mod => {
  const fields = extractFrontmatterFields(mod);
  if (fields.size === 0) return;

  const output = generateTypeScript(mod, fields);
  const outputPath = path.join(OUTPUT_DIR, `${mod}/types.generated.ts`);

  // Ensure directory exists
  const dir = path.dirname(outputPath);
  if (!fs.existsSync(dir)) fs.mkdirSync(dir, { recursive: true });

  fs.writeFileSync(outputPath, output);
  console.log(`Generated types to ${outputPath}`);
});
```

**Integration**: Add to build chain:

```json
{
  "scripts": {
    "prebuild": "node astro-src/scripts/generate-paths.mjs && node astro-src/scripts/generate-types.mjs"
  }
}
```


## Summary: Pattern for Future Modules

To add a new module (e.g., `notes/`):

| Step | Action | Files |
|------|--------|-------|
| 1 | Create docs content | `docs/notes/*.md` |
| 2 | Add to generate-paths.mjs | `MODULES = [..., 'notes']` |
| 3 | Add to generate-types.mjs | `MODULES = [..., 'notes']` |
| 4 | Create types file | `astro-src/lib/notes/types.ts` |
| 5 | Create storage/operations | `astro-src/lib/notes/index.ts` |
| 6 | Create pages | `astro-src/pages/notes/index.astro`, `[id].astro` |
| 7 | Use generated paths | `import { notesPaths } from '../lib/paths.generated'` |
| 8 | Add to search | Update `unifiedSearch` to include 'notes' |

---

## Implementation Order

1. **Phase 1**: Build-time auto-discovery (paths generation)
2. **Phase 2**: Type generation script
3. **Phase 3**: Unified search page + API
4. **Phase 4**: Export functionality for writings
5. **Phase 5**: Template system

Each phase is independent and doesn't break existing functionality.
