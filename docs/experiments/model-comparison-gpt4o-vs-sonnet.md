# Model Comparison: GPT-4o vs Claude Sonnet 3.5 on Code Reasoning

## Experiment ID

`model-comparison-gpt4o-vs-sonnet`

## Hypothesis

Claude Sonnet 3.5 outperforms GPT-4o on complex code reasoning tasks requiring multi-step reasoning.

## Method

Run both models on 500 LeetCode hard problems. Measure pass rate, time to solution, and explanation quality.

## Variables

- **Model** (independent): GPT-4o vs Claude Sonnet 3.5
- **Pass Rate** (dependent): Percentage of problems solved correctly
- **Explanation Quality** (dependent): Human-rated clarity and correctness

## Expected Results

Claude Sonnet 3.5 achieves 15% higher pass rate on dynamic programming problems.

## Actual Results

Claude Sonnet 3.5: 62% pass rate vs GPT-4o: 51%. DP tasks show 18% gap.
