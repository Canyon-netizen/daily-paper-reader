## 摘要
求解航空航天领域中的多智能体最优控制问题，例如追逃问题和空间对抗作战，可被建模为非凸微分博弈，但目前用于求解此类问题的算法非常有限。本文引入了广义纳什均衡问题（GNEP）的一种松弛形式，以排除动力学中的智能体间控制耦合，该形式在许多多智能体系统中具有代表性。本文的主要贡献是提出了一种用于求解广泛类型微分博弈的算法，命名为 FALCON：开环纳什均衡的快速增广拉格朗日凸化方法。在方法上，采用序列凸规划（SCP）构造可处理的凸子博弈，然后通过包含势博弈重构的标准凸规划方法进行求解。本文证明了在温和假设下，FALCON 对非凸微分博弈具有收敛到开环纳什均衡的全局收敛性保证，并通过合作型与竞争型微分博弈的数值实验进行了验证。

## Abstract
Solving multi-agent optimal control problems in aerospace such as pursuit-evasion and contested space operations can be modeled as non-convex differential games for which, there are limited algorithms. In this work, a relaxation of generalized Nash Equilibrium problems (GNEPs) to exclude inter-agent control coupling in dynamics, which is representative of many multi-agent systems is introduced. The main contribution is an algorithm for solving a broad class of differential games named FALCON: Fast Augmented Lagrangian Convexification for Open-loop Nash equilibria is presented. Methodologically, sequential convex programming (SCP) is utilized to create tractable convex sub-games which can then be solved via standard convex programming methods involving a potential game reformulation. FALCON is demonstrated to have global convergence guarantees to an open-loop Nash equilibrium for non-convex differential games under mild assumptions. This is numerically shown through both cooperative and competitive differential games.

## 2. 方法论

### 2.1 问题形式化：部分解耦广义纳什均衡（PDGNEP）

考虑 $N$ 个智能体，每个智能体的动力学只依赖自身状态与控制（**部分解耦松弛**），耦合只通过共享目标与约束体现：

$$
\dot{x}_i(t) = f(x_i(t), u_i(t)),\quad x_i \in \mathbb{R}^n,\; u_i \in \mathbb{R}^m,\quad f(\cdot) \in C^2
$$

求解问题：

$$
\min_{X_i, \Upsilon_i}\; J_i(X, \Upsilon),\quad \forall i \in [N]
\quad \text{s.t.}\; D_i(X_i, \Upsilon_i) = 0,\; C(X, \Upsilon) \le 0.
$$

**温和假设**：动力学二阶可微且有界、$C^2$ 光滑；目标与约束的梯度、Hessian 在可行域上**一致有界**（常数 $G_{\max}, H_{\max}$）。

### 2.2 关键技术细节

**(a) 连续时间约束处理**：引入外部惩罚函数

$$
q_c^i(z) = [z]_+^3 \in C^2(\mathbb{R})
$$

以及增广状态 $\tilde{x}_i = [x_i^\top,\; y_i]^\top$，其中 $y_i$ 累积约束违反；通过 $y_i(t_{k+1}) - y_i(t_k) \le \varepsilon$ 实现**离散节点间的连续时间可行性保证**，并得到点违反上界 $C_\rho \le \delta_\rho(\varepsilon) = (4\varepsilon\omega_\rho)^{1/3}$。

**(b) 增广拉格朗日重构**：采用**上镜图（epigraph）形式**将非凸目标吸收到约束中：

$$
\min_{z_i, \tau_i}\; \tau_i,\quad \text{s.t.}\; J_i(z_i, z_{-i}) \le \tau_i.
$$

定义增广惩罚项

$$
P_i = (\lambda_i)^\top D_i + \tfrac{\omega}{2}\|D_i\|^2 + \mu^\top [C]_+ + \tfrac{\omega}{2}\|[C]_+\|^2,
$$

并构造每个智能体的增广拉格朗日 $L_i(z, \tau_i, \lambda_i, \mu, \omega) = \tau_i + P_i$，按标准对偶更新

$$
\lambda_i^{k+1} = \lambda_i^k + \omega^k D_i(z^{*k}),\quad \mu^{k+1} = [\mu^k + \omega^k C(z^{*k})]_+,\quad \omega^{k+1} = \beta\omega^k,\; \beta>1.
$$

**(c) 局部凸化子博弈（Problem 3）**：对非线性约束进行一阶线性化（虚拟控制 $\xi_i$ 与虚拟缓冲 $\zeta$ 处理"人为不可行性"），并加入信赖域 $\|z_i - \bar{z}_i\|_\infty \le r_i$ 抑制"人为无界性"。所构造的目标势函数为

$$
\Phi_k = \sum_{i=1}^{N}\left[\tau_i + (\lambda_i^k)^\top \xi_i + \tfrac{\omega^k}{2}\|\xi_i\|^2 + \tfrac{\eta}{2}\|z_i - \bar{z}_i^k\|^2\right] + (\mu^k)^\top \zeta + \tfrac{\omega^k}{2}\|\zeta\|^2.
$$

由 $\eta$ 与 $\omega^k$ 项保证势函数 **$\min(\eta,\omega^k)$-强凸**，子博弈为**二阶锥规划（SOCP）**，可用 Clarabel 等内点法高效求解；其解等价于凸化博弈的**变分纳什均衡（v-GNE）**。

### 2.3 算法流程（FALCON）

主循环包含 5 个核心步骤：

1. **逐次线性化**：在当前参考轨迹处对约束做一阶展开；
2. **步接受判据**：计算联合势函数接受比
$$
\rho_k = \frac{\sum_i \Delta Q_i^k}{\sum_i \Delta L_i^k},\quad \rho_k \ge \rho_0 \text{ 接受},
$$
其中 $\Delta Q_i^k, \Delta L_i^k$ 分别为真实与凸化近似的代价下降；
3. **乘子更新**：仅当 $\max_i |\Delta Q_i^k| < \delta_k$（$\delta_k \to 0$）时执行对偶更新；
4. **信赖域更新**：按 $\rho_k$ 相对阈值 $\rho_1, \rho_2$ 收缩/扩张半径；
5. **收敛判定**：
$$
\max_i |\Delta Q_i^k| \le \varepsilon_{\text{opt}}\;\land\; \chi^k \le \varepsilon_{\text{feas}}.
$$

### 2.4 收敛性结果

- **全局收敛（Theorem IV.8）**：在二阶充分条件与 $C^2$ 光滑性下，算法从任意满足假设的初值出发，**全局收敛**到原非凸 PDGNEP 的一个**可行变分纳什均衡**，并保持**连续时间点违反上界** $C_\rho \le \delta_\rho(\varepsilon)$；
- **收敛速率（Theorem IV.10）**：在更严格的乘子更新判据 $\max_i |\Delta Q_i^k| \le \min\{\delta_k, \eta_{\text{rate}}\chi^k\}$ 下：
  - 若惩罚权重有界 $\omega_k \le \omega_{\max}$，乘子序列 **Q-线性收敛**；
  - 若 $\omega_k \to \infty$，则 **Q-超线性收敛**；
- **关键中间结论**：子博弈强凸性（Lemma IV.1）、解唯一性（IV.2）、与 v-GNE 等价性（IV.3）、有限步接受（IV.5）、冻结乘子下极限点为平稳点（IV.6）。

## 6. 主要结论与发现

1. **FALCON 在温和假设下全局收敛**到非凸微分博弈的开环变分纳什均衡，且**保证连续时间可行性**（节点间约束违反有上界 $\delta_\rho(\varepsilon)\to 0$）；
2. **在乘子更新子序列上具有 Q-线性或 Q-超线性收敛速率**，具体取决于惩罚权重是否发散；
3. **数值性能显著优于基线**（F1 Austin 场景）：
   - **收敛率**：DG-SQP 为 72%，FALCON 为 **100%**；
   - **耗时**：DG-SQP 单次收敛约 $50.02 \pm 19.27\,\text{s}$，FALCON 仅 $0.87 \pm 0.40\,\text{s}$（**约 57× 加速**）；
   - **迭代数**：DG-SQP $422.8 \pm 138.0$，FALCON $85.9 \pm 43.8$；
   - **ALGAMES** 在该场景未能达到相同的收敛标准；
4. **合作型场景中涌现合理行为**：走廊问题中智能体自发形成单列编队穿越瓶颈；
5. **异构博弈可解**：航天器 Lady-Bandit-Guard 场景中 Guard 能有效阻止 Bandit 接近 Lady（在大多数初值下），展示了方法在三类角色混合博弈中的适用性。

## 7. 优点

- **理论保障强**：从单智能体 SCvx* 严格扩展到多智能体博弈，给出全局收敛 + 收敛速率的完整证明链（Lemma IV.1–IV.10 + Theorem IV.8, IV.10），**非凸 + 约束 + 多智能体三层困难同时处理**，是较少见的；
- **方法组合巧妙**：将"序列凸化（SCvx*） + 增广拉格朗日博弈（ALGAMES） + 势博弈重构（v-GNE）+ SOCP 内点法（Clarabel）"有机融合，发挥各自长处；
- **连续时间可行性**：通过三次惩罚函数 + 增广状态显式处理节点间约束违反，对安全关键场景意义重大；
- **算法通用**：单智能体时退化为 SCvx*，多智能体时统一为 v-GNE 求解，**代码可复用性高**（DifferentialGames.jl）；
- **数值加速显著**：相比 DG-SQP 约一个数量级以上加速，且**收敛鲁棒性更高**；
- **代码与生态开放**：作者公开了 Julia 软件包 [38]，便于复现。
