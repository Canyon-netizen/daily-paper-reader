## 摘要
现代生成模型越来越多地使用模型自身生成的信号进行训练，这既创造了自我改进的机会，也带来了模型坍缩的风险。我们研究修正流（RF）的最优自蒸馏（SD）：给定一个次优的教师速度场，用真实RF速度与教师速度混合数据训练出的学生模型能否被严格证明优于教师？对于在固定插值对上施加岭正则化的线性RF，我们证明了一个精确的仿射路径恒等式，推导出最优混合系数的闭式表达，并证明当教师风险沿正则化路径非平稳时，累积速度风险将严格改善。最优系数遵循一条符号规则：正向混合用于修正欠正则化的教师，而负向混合用于修正过正则化的教师。我们还提出了一种一次性广义交叉验证（GCV）和验证调优流程，避免了对混合权重进行网格搜索和重复拟合。将该定理与RF的Wasserstein收敛界相结合，我们证明最优自蒸馏改善了控制连续时间与有限步生成误差的速度估计项。在高斯模型、高斯混合以及图像数据上的实验表明，最优自蒸馏在速度风险、模式恢复和有限步生成方面均优于教师模型和纯蒸馏。

## Abstract
Modern generative models are increasingly trained using model-generated signals, creating both opportunities for self-improvement and risks of collapse. We study optimal self-distillation (SD) for rectified flow (RF): given a suboptimal teacher velocity field, can a student trained on a mixture of true RF velocities and teacher velocities provably improve the teacher? For linear RF with ridge regularization on fixed interpolation pairs, we prove an exact affine path identity, derive the optimal mixing coefficient in closed form, and show strict improvement in integrated velocity risk whenever the teacher risk is nonstationary along the regularization path. The optimal coefficient obeys a sign rule: positive mixing corrects under-regularized teachers, while negative mixing corrects over-regularized teachers. We also give one-shot generalized cross-validation (GCV) and validation tuning procedure that avoids grid search over mixing weights and repeated refitting. Combining this theorem with RF Wasserstein convergence bounds, we show that optimal self-distillation improves the velocity estimation terms controlling continuous-time and finite-step generation error. Experiments with Gaussian models, Gaussian mixtures, and image data show that optimal self-distillation improves velocity risk, mode recovery, and finite-step generation relative to both the teacher and pure distillation.

## 2. 方法论

### 2.1 整体框架

采用**线性探测（linear probing）**策略：固定时间-条件特征映射 $\phi(t,x)$，仅训练轻量线性头 $W$。给定训练三元组 $\{(X_{0,i}, X_{1,i}, T_i)\}_{i=1}^N$，定义：
$$X_{T_i,i} = (1-T_i)X_{0,i} + T_i X_{1,i},\quad u_i = X_{1,i} - X_{0,i},\quad \phi_i = \phi(T_i, X_{T_i,i})$$

- **教师模型**（带岭正则化）：
$$\hat{W}_\lambda = \arg\min_W \frac{1}{N}\|U - \Phi W\|_F^2 + \lambda \|W\|_F^2 = \left(\frac{\Phi^\top \Phi}{N} + \lambda I_m\right)^{-1}\frac{\Phi^\top U}{N}$$

- **纯蒸馏**：用 $\hat{U}_\lambda = \Phi\hat{W}_\lambda$ 作为目标重新训练。

- **自蒸馏混合目标**（$\xi \in \mathbb{R}$）：
$$U^{(\xi)} = (1-\xi)U + \xi \hat{U}_\lambda$$

### 2.2 关键理论结果

**命题 1（仿射路径恒等式）**：对任意 $\lambda>0$ 和 $\xi\in\mathbb{R}$，自蒸馏学生满足
$$\hat{W}_{\mathrm{sd},\lambda,\xi} = (1-\xi)\hat{W}_\lambda + \xi\hat{W}_{\mathrm{pd},\lambda}$$

**定理 2（最优自蒸馏）**：记 $C(\lambda) = \mathbb{E}\bigl[\langle u-v_\lambda, u-v_{\mathrm{pd},\lambda}\rangle\,|\,D_N\bigr]$，$D(\lambda) = \mathbb{E}\bigl[\|v_\lambda - v_{\mathrm{pd},\lambda}\|^2\,|\,D_N\bigr] \geq 0$，则
$$R_{\mathrm{sd}}(\lambda,\xi) = R(\lambda) - 2\xi\{R(\lambda) - C(\lambda)\} + \xi^2 D(\lambda)$$

最优混合系数及对应风险为：
$$\xi^\star(\lambda) = \frac{R(\lambda) - C(\lambda)}{D(\lambda)},\quad R^\star_{\mathrm{sd}}(\lambda) = R(\lambda) - \frac{[R(\lambda)-C(\lambda)]^2}{D(\lambda)}$$

进一步，在 $R(\lambda)$ 关于 $\lambda$ 可微时：
$$\xi^\star(\lambda) = -\frac{\lambda R'(\lambda)}{2D(\lambda)}$$

**核心符号规则**：当 $R'(\lambda) \neq 0$ 时，$R^\star_{\mathrm{sd}}(\lambda) < R(\lambda)$（严格改进），且
$$\mathrm{sign}(\xi^\star(\lambda)) = -\mathrm{sign}(R'(\lambda))$$

即**正向混合**修正欠正则化教师，**负向混合**修正过正则化教师。

### 2.3 一次性调优方法

通过 GCV 或验证集估计 $R, R_{\mathrm{pd}}, C$，得到免网格搜索的 GCV 估计：
$$\hat{\xi}_{\mathrm{GCV}} = \frac{\hat{R} - \hat{C}}{\hat{R} + \hat{R}_{\mathrm{pd}} - 2\hat{C}}$$

对非线性/神经网络模型，在仿射族 $v_\xi(t,x) = v(t,x) + \xi\{v_{\mathrm{pd}}(t,x) - v(t,x)\}$ 上做一维验证搜索，无需重新训练学生模型。

### 2.4 算法流程（Algorithm 1）

1. 采样 RF 三元组并构造 $X_{T_i,i}, u_i$；
2. 在真实速度上训练教师 $v$；
3. 形成教师速度 $\hat{u}_i = v(T_i, X_{T_i,i})$，训练纯蒸馏模型 $v_{\mathrm{pd}}$；
4. 通过 GCV 或验证估计 $\hat{\xi}$；
5. 使用 $v_{\hat\xi}$，或在混合目标 $(1-\hat\xi)u_i + \hat\xi \hat{u}_i$ 上训练一个学生。

| 各向异性高斯 + 时序 Legendre 基 | 时间切片速度风险 | 同上 |
| 非线性 4 分量高斯混合（MoG） | 模式恢复、Sliced $W_2^2$、MMD、协方差误差 | 同上 |
| 手写数字 / Fashion-MNIST（受控缩放） | RF 风险、Feature-FD、Inception-FID、条件准确率 | 同上 |
| CIFAR-10（U-Net 神经 RF，$32\times32$） | RF 风险、FID、KID（NFE=32） | 教师、纯蒸馏、SD 裁剪至 $[0,1]$、最优 SD、计算量匹配的 fine-tune 基线 |
| 多种 2D 目标（MoG-4 / Checkerboard / Moons / Spiral） | 时间相关 vs 均匀混合消融 | 均匀、TD-affine、TD-refit、约束混合、纯蒸馏 |

**Benchmark**：理论分析中的"Oracle"（即真实测试 RF 风险下的最优 $\xi^\star$），以及若干下游生成度量（Sliced $W_2^2$、MMD、FID、KID、Feature-FD）。

## 6. 主要结论与发现

1. **仿射路径结构**：自蒸馏学生严格位于"教师"与"纯蒸馏"之间的仿射直线上（Proposition 1）；
2. **严格改进定理**：当教师风险沿岭正则化路径非平稳（$R'(\lambda)\neq 0$）时，最优自蒸馏严格降低累积 RF 风险（Theorem 2）；
3. **符号规则**：$R'(\lambda)>0$（欠正则化）$\Rightarrow \xi^\star>0$；$R'(\lambda)<0$（过正则化）$\Rightarrow \xi^\star<0$；将 $\xi$ 约束在 $[0,1]$ 会丢失后一种关键修正；
4. **Wasserstein 生成上界**：最优 SD 同时改善连续时间（Proposition 3）与有限步 Euler（Theorem 4）Wasserstein 上界中的速度估计项；
5. **GCV 一次性调优**：在 Gaussian / 各向异性 / MoG 等设置中，GCV 与 Oracle 的混合系数与风险几乎重合；
6. **实验表现**：
   - MoG（$\lambda\approx 7.5$）：教师风险 $2.077$，纯蒸馏恶化至 $2.639$，Oracle SD 降至 $0.265$，GCV-SD 降至 $0.273$；Sliced $W_2^2$ 由 $\approx 1.02$ 降至 $0.093$；
   - Fashion-MNIST 受控缩放（$\hat\xi=-2.83$）：RF 风险 $0.828\to 0.210$，Feature-FD $818.5\to 8.8$，条件准确率 $0.107\to 0.895$；
   - CIFAR-10（$a=0.75$，$\hat\xi=-1.225$，NFE=32）：RF 风险 $0.2435\to 0.1803$，FID $284.26\to 30.08$，KID $0.3215\to 0.0186$；
   - $\lambda\approx 31.6$ 的 Gaussian RF：教师风险 $\approx 1.67$，Oracle SD $\approx 1.14$，One-shot SD $\approx 1.22$。

## 7. 优点

- **理论结果严格**：对带岭正则化的线性 RF，给出闭式最优 $\xi^\star$、严格改进保证与符号规则；
- **计算高效**：通过一次性 GCV 或验证调优，免去对 $\xi$ 的网格搜索与重复 refit；
- **桥接两条研究线**：将岭回归中的最优自蒸馏理论（Dang et al.）成功迁移到流匹配 / RF 速度场场景；
- **实验层次完整**：从玩具 Gaussian 到神经网络 U-Net，从受控缩放到天然教师，从速度风险到多维度生成度量；
- **重要的方法学警示**：揭示了在 $[0,1]$ 约束下做传统"凸"蒸馏会**错过过正则化教师所需的负混合修正**，这是对常规蒸馏观念的有益纠正；
- **与 RF 收敛界有机结合**：将速度风险的改进落实到 Wasserstein 生成上界（包括 Euler 离散化情形）的具体收紧量。

## 8. 不足与局限

- **线性假设**：严格定理仅适用于带岭正则化的线性 RF；神经网络场景下的仿射族 (19) 是**经验性推广**，缺乏对应的端到端非线性保证——论文已明确指出"严格改进定理对线性 RF 才精确，神经网络扩展仍是开放问题"；
- **固定插值**：与递归 Reflow 不同，本文不改变端点配对或插值协变量，**未直接覆盖** Reflow 实践中的"递归端点替换"情形；
- **正则化水平依赖**：定理仅说明对**给定 $\lambda$ 的教师**可沿其岭路径改进，并不声称教师被全局最优正则化；
- **生成指标并非普涨**：理论保证的是速度估计项的下降，但下游指标（FID/MMD 等）依赖于 Lipschitz 常数、直线性、ODE 稳定性与离散化，论文也明确"这并不必然意味着每个下游度量在任意误设下都严格改进"；
- **资源不透明**：未提供 GPU/TPU 型号、训练时长、能耗等算力信息，可复现性细节有限；
- **图像实验为受控压力测试**：手写数字 / Fashion-MNIST 通过显式缩放构造"过正则化教师"，对天然训练教师的提升较为温和（Table S2），实际部署场景下的有效性仍需更多样化验证；
- **部分细微场景负混合未必改进下游**：在 Moons/Spiral 等 2D 目标上，TD-refit 在某些指标上劣于均匀混合，说明端到端的扩展理论尚未成熟。
