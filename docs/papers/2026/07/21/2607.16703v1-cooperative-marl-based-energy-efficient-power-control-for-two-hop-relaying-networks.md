## 摘要
本文研究了协作通信网络中的协作博弈问题，其中每个中继自主决策，并以最大化能效为共同优化目标。我们考虑了无法获得瞬时信道状态信息（CSI）而只能获取部分可观测的过时CSI的非理想情况。为求解该博弈问题，我们定义了一种基于延迟奖励的状态-动作价值函数，并提出了一种多智能体深度Q网络学习框架。随后，我们通过分析证明：基于瞬时CSI的博弈论方法所获得的效用可作为所提方法效用的上界。仿真结果表明，所提方法显著优于其潜在的替代方案，且与最优解的差距仅为约5.2%。

## Abstract
In this paper, we study a cooperative game in the cooperative communication network, where each relay makes decisions autonomously and aims to achieve the same optimization objective of maximizing energy efficiency. We consider the non-ideal situation where instantaneous channel state information (CSI) is difficult to obtain and only partially observable outdated CSI is available. To solve this game problem, we define a delayed reward-based state-action value function and propose a multi-agent deep Q network learning framework. Then, we prove analytically that utilities obtained by game-theoretic approaches with the instantaneous CSI serve as upper bounds for those of the proposed method. Simulation results reveal that our approach considerably outperforms its potential alternatives and is only about 5.2% away from the optimal solution.

## 1. 核心问题与研究动机

- **研究场景**：双跳无线协作中继网络，包含一个源节点 $S$、一个目的节点 $D$ 和 $K$ 个采用放大转发（AF）协议的中继 $R_k$；源与目的之间的直连链路被遮挡，必须依赖中继协作通信。
- **优化目标**：最大化系统的能量效率，即端到端信道容量与全网总发射功率之比：
$$EE(P_1, P_2, \dots, P_K) = \frac{I}{P_s + \sum_{k=1}^{K} P_k}$$
其中 $I=\tfrac{1}{2}\log_2(1+\gamma)$，$\gamma$ 为目的端合并后的输出 SNR。
- **关键难点（非理想条件）**：在快速时变信道下，瞬时全局 CSI 难以获取，每个中继只能获得与自身关联的**部分过时 CSI**（$h_{sk}(t-1)$、$h_{kd}(t-1)$）。传统博弈论/凸优化方法依赖中心控制器与全局瞬时信息，无法直接适用；同时，多智能体强化学习在"过时信息 + 部分观测"下如何设计与收敛仍是开放问题。
- **研究动机**：在分布式、非理想环境下，让每个中继自主决策发射功率 $P_k$，以协作方式逼近（瞬时 CSI 条件下的）博弈论最优解。

## 2. 方法论

### 2.1 协作博弈建模
- **博弈要素**：
  - 玩家：中继集合 $\{R_k\}_{k=1}^{K}$，同时行动；
  - 效用函数：所有玩家共享同一个能效函数 $EE(\cdot)$，体现"协作"特性；
  - 策略空间：离散功率等级 $\{0, 1, 2, \dots, L\}\cdot \frac{P_{k,\max}}{L}$，故构成有限静态博弈。
- 由 Nash 定理保证**混合策略纳什均衡**存在，但该均衡需在确定性环境（全局瞬时 CSI）下求得。

### 2.2 信道时变模型
采用一阶高斯马尔可夫块衰落自回归模型刻画相邻时隙的时序相关：
$$h_{ij}(t) = \rho\, h_{ij}(t-1) + \sqrt{1-\rho^2}\,\zeta(t),\quad \zeta(t)\sim \mathcal{CN}(0, \sigma_j^2)$$
其中 $\rho$ 为归一化信道相关系数。仿真中取 $\rho=0.1$，体现信道快速变化、过时信息失真严重的非理想场景。

### 2.3 MDP 与系统变量设计
- **状态（部分观测）**：$S_t^k = [h_{sk}(t-1), h_{kd}(t-1), P_s]$，无中继间信息交换；
- **动作**：$A_t^k = a_k(t) \in \{0, 1, 2, \dots, L\}$，对应 $L+1$ 个离散功率档；
- **奖励（延迟奖励，关键贡献）**：$r_t^k = EE(\mathbf{a}_t; s_t, p)$，由当前联合动作 $\mathbf{a}_t$ 与**下一时隙**全局状态 $s_{t+1}$ 共同决定，因而只能在 $t+1$ 时刻被观测到。

### 2.4 延迟奖励状态-动作值函数 $\tilde Q$
针对上述延迟奖励，重新定义 $\tilde Q$ 函数：
$$\tilde Q(s_t, a_t;\theta) = \mathbb{E}\!\left[r_t(s_{t+1}, a_t) + \gamma \max_{a_{t+1}} \tilde Q(s_{t+1}, a_{t+1};\theta)\right]$$
- TD 误差：
$$TD(t) = r_t + \gamma \max_{a_{t+1}} \tilde Q(s_{t+1}, a_{t+1};\theta^-) - \tilde Q(s_t, a_t;\theta)$$
- 损失函数：
$$L(\theta) = \mathbb{E}_{e_t^k\sim B_k}\!\left[(TD^k(t))^2\right]$$
采用非中心化 RMSProp 优化评估网络参数 $\theta$，并以目标网络 $\theta^-$ 周期性更新。
- 经验回放：每个智能体 $k$ 维护独立缓冲 $B_k$，训练时按 mini-batch 采样。

### 2.5 算法流程（Algorithm 1 概述）
1. 初始化每个智能体的评估网络 $\theta_k$ 与目标网络 $\theta_k^-=\theta_k$；
2. 每 episode 重置信道环境；
3. 每时隙各 agent 依 $\varepsilon$-Greedy 选择功率档并执行；
4. 环境在下一时隙反馈延迟奖励 $r_t^k$；
5. 存储 $e_t^k = \{s_t^k, a_t^k, r_t^k, s_{t+1}^k\}$ 至 $B_k$；
6. 采样 batch 并最小化 $L(\theta)$ 更新 $\theta_k$；每 $C$ 步同步 $\theta_k^-$；
7. 重复至 $u_{\max}^{epi}$ 个 episode。

### 2.6 上界性能分析
- 在已知全局瞬时 CSI 时，博弈论方法可得最优联合动作 $\mathbf{a}_t^* = \pi_G^*(s_{t+1})$，对应效用 $EE^*$；
- 证明：
$$EE^*(\mathbf{P}^*) \ge \mathbb{E}_{s_{t+1}}\!\left[r_t(s_{t+1}, \tilde{\mathbf{a}}_t)\right] + \gamma \mathbb{E}_{s_{t+1}}\!\left[\max_{a_{t+1}} \tilde Q(s_{t+1}, a_{t+1};\theta)\right]$$
进而得到：
$$\tilde Q(s_t, \tilde{\mathbf{a}}_t;\theta) \le \mathbb{E}_{s_{t+1}}\!\left[Q_G(s_t, \mathbf{a}_t^*)\right]$$
即**瞬时 CSI 下的博弈论效用是 MARL 方案的上界**，且对长期和单步决策均成立。

### 2.7 复杂度
单 agent 网络含 $M$ 层全连接层、$N_m$ 个神经元，决策时间复杂度为 $O\!\left(\sum_{m=1}^{M-1} N_m N_{m+1}\right)$，整体训练复杂度为 $O\!\left(u_{\max}^{epi}\, t_{\max}\, \sum_{m=1}^{M-1} N_m N_{m+1}\right)$。

  - 实验**仅基于单一网络拓扑/参数设置**（$K=5$, $\rho=0.1$, 固定噪声方差等），未给出多组随机种子下误差棒、不同 $\rho$、不同 $K$、不同 $P_s$ 下的敏感性分析；
  - 未做消融实验（如去除延迟奖励定义、去除经验回放、改变 DQN 结构等），难以单独归因"延迟奖励定义"与"多智能体分布式"两者的贡献；
  - 缺少对信道相关性 $\rho$、噪声功率、源功率、中继数等关键参数的扫参，鲁棒性论证偏弱；
  - 与 SADQN 的对比缺少联合动作空间维度的复杂度/可扩展性量化。
- 综合来看，实验**针对核心论点（分布式 MARL 优于集中式/非学习方法且接近上界）较为直观有效**，但在覆盖广度和统计严谨性上仍有改进空间。

## 6. 主要结论与发现

- **性能差距**：以 $L+1=5$ 为例，Optimal ≈ 0.823 bit/J/Hz，所提方案 ≈ 0.781 bit/J/Hz，**仅约 5.2% 的次优性**，在非理想环境下表现接近博弈论上界。
- **超越基准**：所提方案优于 GOIBS（约 0.761 bit/J/Hz，低 2.6%）、POIBS（约 0.409 bit/J/Hz，远低）和 SADQN（在 $L$ 较大时性能反降）；SADQN 收敛慢（≈ 60 episode）且波动大，所提方案约 40 episode 收敛且更稳定。
- **可扩展性**：所提分布式方案将联合动作空间 $(L+1)^K$ 分解为 $K$ 个独立的 $(L+1)$ 空间，避免"维度爆炸"，因此 $L$ 增大时仍能持续提升性能，而 SADQN 反而下降。
- **理论保证**：从 $\tilde Q$ 函数层面证明瞬时 CSI 下的博弈论效用为 MARL 效用的上界，对长期多步与单步决策均成立。

## 7. 优点

- **问题建模贴合实际**：明确考虑"无瞬时全局 CSI、仅有部分过时 CSI"这一非理想场景，比多数仍假设完美 CSI 的 MARL 通信工作更具工程价值。
- **延迟奖励定义有新意**：将"奖励在 $t+1$ 才能被观测到"显式纳入 $\tilde Q$ 函数推导，使算法设计与物理通信机制一致。
- **去中心化避免维度灾难**：每个中继仅处理自身 $L+1$ 维动作空间，显著优于集中式 SADQN 的 $(L+1)^K$ 维空间。
- **理论分析完备**：给出博弈论上界与 MARL 性能之间的严格不等式，连接了经典博弈论与多智能体强化学习。
- **算法实现简洁**：仅采用全连接 DQN + 经验回放 + 目标网络 + RMSProp，工程上易复现。

## 8. 不足与局限

- **算力与代码信息缺失**：未公开 GPU 型号、训练时长、超参搜索过程，也未提供开源代码链接，难以独立复现与验证。
- **实验覆盖有限**：
  - 仅在单一拓扑（$K=5$）与单一信道相关性 $\rho=0.1$ 下测试，缺乏对 $\rho$、$K$、$P_s$、噪声方差等的敏感性分析；
  - 每组仅 5 次随机试验，未给出标准差或置信区间；
  - 没有消融实验，难以拆解"延迟奖励"、"分布式结构"、"经验回放"各自贡献。
- **基准选择偏向性**：
  - GOIBS 在 $\rho=0.1$ 下表现已较差（2.6% 差距），但作者未在更大 $\rho$（即过时 CSI 更可用）下对比，可能存在基准偏弱的风险；
  - SADQN 在大 $L$ 下性能下降，但其"维度灾难"并未与其它动作空间压缩方法（如参数共享、actor-critic、分层 RL）做进一步对比。
- **应用限制**：
  - 仅考虑 AF 中继与单天线场景，未推广到多天线、毫米波、D2D、IRS 等更复杂拓扑；
  - 离散功率等级 $L$ 的选择对性能影响大，但论文未给出连续功率动作下的扩展讨论；
  - 假设中继间无信息交换，但实际系统中至少存在信令交互，未来可考虑有限通信下的部分去中心化方案。
- **稳定性与收敛**：虽然图 1 显示 40 episode 收敛，但未给出长期运行（数千 episode）的稳定性、策略振荡或灾难性遗忘分析。
