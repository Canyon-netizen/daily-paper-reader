## TL;DR

在策略自蒸馏（OPSD）本是大语言模型对齐与增强的重要范式，却在复杂推理任务上出现了悖论性退化。研究者系统诊断发现，根源在于教师梯度在学生高熵决策分叉处激进压制了认知性推理标记，导致「思维坍缩」。为此，论文提出自适应双视角 OPSD（AD-OPSD），通过非对称逐点分歧门控将高风险标记锚定到冻结基模型的参考先验，在保留纠错能力的同时维持原生推理能力。在多个数学基准上，该方法相较标准 OPSD 最高提升 +4.1% 绝对准确率。

## 研究背景与动机

大语言模型的后训练阶段，[[自蒸馏]]已成为一种高效的能力增强手段。与传统的离线蒸馏不同，OPSD 在真实答案条件下由教师模型实时生成在线目标分布，让学生模型同时学习来自教师的监督信号和来自环境的奖励反馈。这种范式在通用对齐任务上表现出色，但当研究者们试图将其迁移到复杂推理场景时，却发现了一个令人困惑的现象：模型不仅没有进步，反而出现了性能退化。

这种现象在数学推理任务上尤为明显。研究者以 Qwen3-1.7B 为例，观察到一个清晰的因果链条：基线模型的认知标记密度（每千个生成标记中认知性标记的数量，即 ET per 1k）为 10.3，下游准确率为 38.1%；经过标准 OPSD 微调后，认知标记密度骤降至 7.9，准确率也跟着跌落到 33.9%。模型似乎「忘记」了如何进行深度思考。

已有的研究虽然零散地记录了 OPSD 会抑制「认知性言语化」和高熵决策分叉的现象，但缺乏系统性的诊断分析——究竟在什么位置、为什么会发生这种抑制？更没有提出能够同时保留 OPSD 纠错能力的解决方案。研究者将这种优化病态正式命名为「思维坍缩」，并以此为切入点展开了系统性研究。

## 方法

解决任何优化病态的第一步，是精确诊断其根源。研究者采用了三重递进的证据链来定位思维坍缩的源头。

第一重是[[梯度掩码]]诊断。研究者按学生模型的 token 级条件熵 $H(y_i \mid y_{<i})$ 将 token 空间划分为高熵和低熵两个区域，在反向传播时对高熵位置屏蔽梯度。结果发现，仅屏蔽 top-50% 高熵 token 的梯度就足以将思维密度从 7.9 拉回 10.7（甚至超过了基线模型的 10.3）；而如果反过来只在低熵位置蒸馏，思维密度依然会坍缩到 7.6。进一步的细化实验表明，关键的坍缩压力集中在 top-20% 的最高熵 token 上。这意味着教师梯度对推理过程的干预具有高度局部性，集中爆发在模型「最需要思考」的分叉点上。

第二重是微观 token 级目标差异分析。在训练起点（step 0）的 3.9M token 语料上，研究者追踪学生模型中认知标记（ET）的分布与教师目标的冲突。他们发现认知标记天然集中于高熵区域：top-10% 高熵区域包含了 34.0% 的认知标记，top-50% 高熵区域更是容纳了 95.3% 的认知标记。问题在于这些位置上，学生模型的认知标记与教师模型的非认知目标之间存在严重的 top-1 不一致——在 top-10% 高熵区间内，66.3% 的「学生认知标记→教师非认知标记」不一致事件集中分布。这意味着从训练一开始，教师梯度就在持续向学生的高质量推理路径施加负向压制。

第三重是逐点分歧映射。研究者定义了逐点 KL 贡献作为实时风险指标：

$$C_i = P_\theta(y_i \mid \cdot) \cdot \left(\log P_\theta(y_i \mid \cdot) - \log P_t(y_i \mid \cdot)\right)$$

这个指标衡量的是当学生模型在某个 token 上的概率高于教师时，梯度反向传播会产生的抑制强度。分析表明，在 $P_\theta > P_t$ 的活跃抑制区和高熵 token 的交集内，$C_i$ 最高的 10% 区间中认知标记的局部密度达到 7.9%，而最低区间仅有 3.5%。这验证了 $C_i$ 作为抑制风险代理信号的有效性。

基于上述诊断，研究者提出了 Adaptive Dual-Perspective OPSD（AD-OPSD）。核心思想是在局部高熵沙盒内，使用非对称逐点分歧门控将高抑制风险 token 的目标从纯教师分布重新插值到冻结基模型与教师的混合分布。具体的双视角目标分布定义为：

$$\pi_i^*(v) = U_i \cdot \pi_{\text{base}}(v \mid y_{<i}, X) + (1 - U_i) \cdot \pi_t(v \mid y_{<i}, X, GT)$$

其中 $U_i$ 是「教师不可靠指数」，由以下门控机制自适应生成（仅在 $\log P_\theta > \log P_t$ 时激活）：

$$U_i = \sigma\left(\frac{P_\theta(y_i \mid \cdot)\big(\log P_\theta(y_i \mid \cdot) - \log P_t(y_i \mid \cdot)\big)}{\tau}\right)$$

这个设计包含两个关键要素：第一是空间沙盒定位，仅在 top-$p\%$（默认 20%）学生高熵 token 上施加门控，沙盒外保持 $U_j = 0$ 以完整保留教师纠错信号；第二是非对称激活条件，只有当学生概率高于教师（即存在潜在抑制风险）时才向基模型方向插值，否则门控自动关闭。最终的损失函数在沙盒内外分别使用不同的 KL 散度目标：

$$\mathcal{L}_{\text{AD-OPSD}}(\theta) = \sum_{y_i \in \mathcal{V}_{\text{High-H}}} D_{\text{KL}}\!\big(\pi_i^*(\cdot)\,\|\,\pi_\theta(\cdot \mid y_{<i}, X)\big) + \sum_{y_j \notin \mathcal{V}_{\text{High-H}}} D_{\text{KL}}\!\big(\pi_t(\cdot)\,\|\,\pi_\theta(\cdot \mid y_{<j}, X)\big)$$

## 实验与结果

实验在多个数学推理基准上展开，包括 MATH500、AIME 2024、AIME 2025 和 HMMT 2025，覆盖了不同难度级别的竞赛数学题目。模型方面使用了 Qwen3-1.7B、Qwen3-4B 以及 DeepSeek-R1-Distill-Qwen-1.5B，全部采用 LoRA 高效微调。

主实验结果清晰地验证了方法的有效性。在 Qwen3-4B 上，AD-OPSD 达到 70.2% 平均准确率，相较标准 OPSD 的 67.0% 提升了 3.2 个百分点；在更小的 Qwen3-1.7B 上，提升幅度更为显著，从 47.7% 增至 51.8%（+4.1%），在最具挑战性的 AIME 2025 子集上更是取得了 +6.7% 的绝对增益。思维密度追踪数据进一步建立了性能与推理行为之间的关联：AD-OPSD 在恢复思维密度的同时并未牺牲推理准确性。

泛化性实验采用了不同的后训练范式配置（NT/NT 模式，即非思考模式训练）。在这种更具挑战性的设置下，AD-OPSD 在思考模式和传统推理模式下均带来了稳定提升，分别达到 +4.9% 和 +1.5%。消融实验进一步表明，沙盒比例 $p\%$ 呈现钟形曲线，20%–30% 为最优区间；门控函数的连续性（sigmoid pointwise）显著优于离散形式（tanh pointwise 或 global entropy）；随着最大生成长度增加收益趋于收敛，这与直觉相符——生成长度越长，教师分布越接近基模型分布，优化冲突自然缓解。

## 讨论与可借鉴点

这项工作的核心贡献在于揭示了 OPSD 在复杂推理场景失效的深层机制：教师模型虽然擅长纠错，但在模型的「思考分叉点」上过于激进地否定了学生的原生推理路径，导致后者逐渐丧失自主探索能力。这不是简单的过拟合问题，而是一种系统性的优化偏差——监督信号在空间上的分布与认知任务对自由度的需求之间存在结构性冲突。

AD-OPSD 的设计思路值得借鉴：它没有简单地切断梯度或降低学习率，而是通过双视角目标分布将基模型作为「锚点」，在局部高风险区域引入参考先验来平衡教师信号的压制效应。这种解耦控制——沙盒内外分别处理、高风险 token 自适应调节——比二元梯度掩码更能兼顾纠错与探索之间的张力。

研究的局限同样值得注意。全部实验基于 LoRA 高效微调和小规模模型（最大 4B 参数），全参数微调下的表现和统计显著性尚未验证。此外，冻结基模型作为参考先验虽然简洁，但基模型本身的推理能力也会影响最终的锚定效果。在更大规模模型和更复杂推理任务（如代码生成、多跳问答）上的泛化性，是后续研究的重要方向。

## Abstract
On-Policy Self-Distillation (OPSD) has emerged as a crucial paradigm for enhancing and aligning Large Language Models (LLMs). However, in complex reasoning tasks, OPSD paradoxically degrades downstream performance. In this paper, we systematically investigate this pathology and identify a severe optimization trap we define as \textbf{Thinking Collapse} -- a sharp decline in the model's native intermediate reasoning behavior, measured by epistemic-token density (ET per 1k). Through entropy-based gradient masking and token-level target analysis, we show that this collapse is triggered by aggressive teacher gradients at high-student-entropy decision forks, where student epistemic tokens are frequently suppressed into teacher non-epistemic targets and are highly concentrated in high pointwise student-teacher divergence regions. To resolve this optimization pathology, we propose \textbf{Adaptive Dual-Perspective OPSD (AD-OPSD)}, a robust control framework that dynamically moderates the self-distillation objective. AD-OPSD selectively anchors high-suppression-risk sandboxed tokens to a reference prior derived from the frozen base model via an asymmetrical pointwise divergence gate, preserving native thinking capacity while retaining OPSD's error-correcting power. Extensive experiments across competitive mathematical benchmarks show that AD-OPSD improves over standard OPSD by up to \textbf{+4.1\%} absolute average accuracy across diverse model scales and datasets. Further analysis demonstrates that AD-OPSD mitigates thinking collapse and generalizes robustly to different post-training paradigms.

## 二、方法论：AD-OPSD

### 2.1 诊断阶段：三重证据链定位坍缩源头

1. **基于熵的梯度掩码诊断**：在反向传播时按学生熵 $H(y_i \mid y_{<i})$ 动态划分 token 空间。结论：
   - **Top-50% 高熵掩码**（屏蔽高熵位置梯度）→ 思维密度恢复至 10.7（超过 Base 的 10.3）；
   - **Bottom-50% 掩码**（仅在低熵位置蒸馏）→ 思维密度继续坍缩至 7.6；
   - **核心 20%**：仅屏蔽 Top-20% 学生高熵 token 的梯度即可将思维密度从 7.9 拉回 9.8，表明坍缩压力高度集中在**最高熵决策分叉**。

2. **微观 token 级目标差异分析**（训练起点 step 0）：在 3.9M token 语料中：
   - 学生 ET 高度集中于高熵区域：Top-10% 高熵区域包含 **34.0%** 的 ET，Top-50% 包含 **95.3%**；
   - 出现严重的"**Student-ET → Teacher-Non-ET**" top-1 目标不一致：Top-10% 高熵区间内分布了 66.3% 的 ET-to-Non-ET 不一致事件，造成 step-0 即开始的对学生认知 token 的负梯度压制。

3. **逐点分歧映射**：定义逐点 KL 贡献 $C_i$ 作为实时风险指标：
$$C_i = P_s(y_i \mid y_{<i}) \cdot (\log P_s(y_i \mid y_{<i}) - \log P_t(y_i \mid y_{<i}))$$
   在活跃抑制区 $P_s > P_t$、Top-20% 高熵沙盒内，ET 在 $C_i$ 最高的 10% 区间局部密度达 **7.9%**，而最低区间仅 3.5%，验证 $C_i$ 是稳健的抑制风险代理信号。

### 2.2 解法：AD-OPSD（Adaptive Dual-Perspective OPSD）

- **核心思想**：在**局部高熵沙盒**内，使用**非对称逐点分歧门控**将高抑制风险 token 的目标从纯教师分布重新插值到（冻结的）基模型 $\pi_{\text{base}}$ 与教师 $\pi_t$ 的混合分布，保留原生探索路径的同时不丧失事实纠错。

- **双视角目标分布**：
$$\pi_i^*(v) = U_i \cdot \pi_{\text{base}}(v \mid y_{<i}, X) + (1 - U_i) \cdot \pi_t(v \mid y_{<i}, X, GT)$$
  其中 $U_i \in [0,1]$ 为"教师不可靠指数"。

- **自适应门控机制**（两阶段）：
  1. **空间沙盒定位**：仅在 Top-$p\%$ 学生高熵 token（默认 $p=20\%$）上施加门控；沙盒外设 $U_j = 0$，保留完整教师纠错信号。
  2. **逐点分歧门控**（仅在 $\log P_\theta > \log P_t$ 时激活）：
$$U_i = \sigma\!\left(\frac{P_\theta(y_i \mid \cdot)\big(\log P_\theta(y_i \mid \cdot) - \log P_t(y_i \mid \cdot)\big)}{\tau}\right)$$
  其中 $\sigma$ 为 sigmoid，温度 $\tau = 1.0$，并对 $P_\theta$ 采用 stop-gradient 处理。该机制确保当学生概率高于教师（即潜在抑制风险）时，才向 $\pi_{\text{base}}$ 方向插值；否则门控自动关闭。

- **静态变体 SD-OPSD**：在活跃抑制区直接设 $U_i = \alpha = 0.5$ 作为对照。

- **最终损失函数**：
$$\mathcal{L}_{\text{AD-OPSD}}(\theta) = \sum_{y_i \in \mathcal{V}_{\text{High-H}}} D_{\text{KL}}\!\big(\pi_i^*(\cdot)\,\|\,\pi_\theta(\cdot \mid y_{<i}, X)\big) + \sum_{y_j \notin \mathcal{V}_{\text{High-H}}} D_{\text{KL}}\!\big(\pi_t(\cdot)\,\|\,\pi_\theta(\cdot \mid y_{<j}, X)\big)$$

## 六、主要结论与发现

- **诊断结论**：思维坍缩的根源是教师在**学生高熵决策分叉**（具体为 Top-20% 高熵 token）施加的**激进监督信号**；这些位置正是学生 ET（认知性标记）最集中、且与教师目标存在系统性 top-1 差异的所在地。

- **方法效果**：AD-OPSD 在 Qwen3-4B 上达 70.2% 平均（vs OPSD 67.0%），Qwen3-1.7B 上达 51.8%（vs OPSD 47.7%）；在 AIME25 上对 Qwen3-1.7B 的提升达 +6.7% 绝对值。

  - 在 NT/NT 配置下，AD-OPSD 仍带来显著收益（NonThinking 模式 +1.5%，Thinking 模式 +4.9%）；
  - $L_{\max}$ 越长，收益越收敛（因随生成长度增长，$\pi_t \to \pi_{\text{base}}$，冲突自然消失）；

- **机理结论**：单纯二元梯度掩码陷入"思维保留 vs 纠错保留"的优化死锁，必须采用**连续的、token 自适应的、非对称**门控才能兼顾。
