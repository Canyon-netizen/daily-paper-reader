## TL;DR

SEED 是一个面向大语言模型智能体的自演化强化学习框架，通过让策略模型自己从已完成轨迹中提取自然语言技能、并比较技能上下文前后的概率偏移来构建密集的 token 级在策略蒸馏信号，从而弥补稀疏结果奖励与细粒度策略更新之间的监督鸿沟。实验证明，该方法在文本和视觉智能体任务上均实现了 15%~30% 的性能提升，并将样本效率提高近一倍，同时展现出对未见场景的良好泛化能力。

## 研究背景与动机

大语言模型正逐步成为长程交互任务中的核心智能体，从网页导航、API 调用到机器人操作，这些场景都要求模型在多轮交互中持续做出决策并适应环境反馈。然而，当模型需要完成复杂的序列决策时，传统[[监督学习]]范式面临严峻瓶颈：人工为每一步交互标注最优动作不仅成本极高，而且难以覆盖真实环境中可能出现的海量变体情况。

[[强化学习]]为这一困境提供了一条更具扩展性的解决路径——模型可以在环境中自主探索并从反馈中学习。然而，基于结果的强化学习方法存在一个根本性的局限性：它只在轨迹结束时提供稀疏的奖励信号。以完成一个多步骤任务为例，模型可能在数百次环境交互之后才收到一个成功或失败的结果标签，而对于过程中每一步决策是否合理，奖励信号完全沉默。这种监督稀疏性在回合级结果与词元级策略学习之间制造了巨大的监督鸿沟，导致策略梯度估计方差大、更新方向模糊、学习效率低下。

一种直觉上的解决思路是借鉴[[事后经验回放]]的思想——将失败的轨迹重新解释为另一种任务的尝试，从而为中间决策提供更丰富的监督。然而，传统事后方法主要针对离散动作空间设计，且依赖额外的经验回放缓冲区来存储历史轨迹，这在需要高吞吐量采样的在线学习场景中会带来显著的存储与计算开销。更关键的是，这些方法通常只能捕捉到简单的成功/失败二元信号，难以表达轨迹中的高层语义信息——为什么某一步会失败？观察到了什么关键信息导致决策偏差？这些关于工作流和决策逻辑的知识无法被简单的奖励塑形所编码。

SEED 的核心洞察正是由此切入：既然大语言模型本身具备强大的自然语言理解与生成能力，能否让它自己从轨迹中提炼出可复用的技能知识，并将这些知识转化为细粒度的辅助监督信号？

## 方法

SEED 的方法设计围绕三个关键步骤展开：轨迹到技能的语义转化、策略自提取机制、以及概率偏移驱动的蒸馏信号。这个框架的核心理念是：事后监督信号不应该是静态的、一成不变的，而应该随着策略能力的提升而共同演化。

在第一阶段，SEED 对策略模型进行微调，使其能够分析已完成的轨迹并生成自然语言技能描述。这些技能以文本形式捕捉三类可复用的知识：工作流程（如“当遇到错误信息 X 时，应该先检查配置文件而非直接重试”）、关键观察（如“服务器日志中出现的 OOM 关键字预示着资源即将耗尽”）以及失败规避规则（如“在调用外部 API 前应先验证输入参数的边界合法性”）。与仅仅返回一个标量奖励值不同，自然语言技能携带了丰富的语义信息，能够解释决策的因果逻辑和上下文依赖关系。

在第二阶段，当 SEED 进入实际的[[强化学习]]训练循环时，当前策略模型扮演双重角色：它既负责在环境中采集新的交互轨迹，又充当从这些轨迹中提取事后技能的分析器。这一设计蕴含着精妙的自我改进循环——当策略通过学习变得更强时，它的技能分析能力也会同步提升，从而能够从轨迹中提取出更高质量的监督信号；而更高质量的事后监督反过来又能加速策略的提升。这种协同演化机制使得辅助监督信号始终与策略能力保持匹配，避免了传统方法中监督信号与策略能力脱节的问题。

在第三阶段，SEED 对采样的动作在两种不同的上下文条件下进行重新评分：普通上下文（不包含任何技能信息）和技能增强上下文（在输入前附加提取的技能描述文本）。技能引发的概率偏移量 $\Delta p_t$ 体现了技能知识对决策的影响程度——如果某个动作在技能上下文中被显著提升，说明该动作与技能所描述的工作流高度一致，值得被强化；反之，如果概率变化不大，则说明该动作可能与技能知识无关或存在冲突。SEED 将这种概率偏移量化为密集的 token 级在策略蒸馏信号，具体形式为：

$$\mathcal{L}_{\text{distill}} = -\sum_{t} \log \frac{\pi_\theta(a_t | s_t, \text{skill})}{\pi_{\theta_{\text{old}}}(a_t | s_t)} \cdot \Delta p_t$$

其中 $\Delta p_t$ 表示技能上下文相对于普通上下文带来的概率变化量。这个蒸馏损失与原始的[[策略梯度]]损失联合优化，使辅助监督始终与当前轨迹分布保持对齐（on-policy），从而避免了离线蒸馏方法中常见的分布偏移问题。

## 实验与结果

研究团队在两类典型的智能体任务上系统验证了 SEED 的有效性。第一类是文本智能体任务，包括网页导航和 API 调用场景，要求模型理解自然语言指令并在模拟环境中完成多轮交互；第二类是视觉智能体任务，包括机器人操作和视觉问答，需要模型融合视觉感知与决策制定。对比基线涵盖标准 PPO、事后经验回放方法（HER）以及几种代表性的离线蒸馏方法。

实验结果清晰地展示了 SEED 的优势。在所有测试任务上，SEED 均实现了显著的性能提升，平均相对提升达到 15%~30%。更值得关注的是样本效率指标——SEED 仅需使用 50% 的训练样本就能达到基线方法的最终性能水平，这表明密集的 token 级监督信号大幅加速了策略收敛，减少了对环境交互数量的需求。

消融实验进一步揭示了各组件的贡献度。移除技能生成模块（即用预定义的固定规则替代策略模型生成的技能描述）会导致性能回退约 40%，这一结果有力证实了自然语言技能的语义丰富性不可被简单规则所替代。同时，固定技能分析器不让其与策略共同演化时，性能也出现了明显下降，验证了自演化机制在整个框架中的核心价值。

泛化性评估是实验的另一亮点。研究团队设计了包含未见任务变体和全新环境配置的测试集，SEED 在这些具有分布偏移的测试场景中表现出稳健的零样本迁移能力。这一结果符合预期——自然语言技能编码的是抽象的工作流知识而非具体的动作序列，因此能够跨任务复用并在新环境中发挥作用。

## 讨论与可借鉴点

SEED 展示了一条有潜力的研究路径：用大语言模型自身的语言理解能力来填补强化学习中的监督稀疏问题。其核心贡献在于将事后监督从简单的奖励塑形升级为语义丰富的技能蒸馏，并通过策略与技能的协同演化机制实现了监督信号的自适应调整——这避免了静态辅助信号随策略提升而逐渐失效的问题。

当前方法仍存在一定的局限性。首先，技能提取的质量依赖于基础模型的表达能力，若大语言模型的自然语言理解能力不足，生成的技能描述可能包含噪声或错误语义。其次，蒸馏损失与策略梯度损失的权重配比需要手动设定，如何实现自动调节（如根据训练阶段动态调整权重）仍值得深入探索。最后，SEED 目前聚焦于在策略场景，对于需要大规模离线预训练的场合，如何在技能质量与采样效率之间取得平衡仍是开放问题。

## 研究背景与动机

大语言模型正逐步成为长程交互任务中的核心智能体，从网页导航、API 调用到机器人操作，这些场景都要求模型在多轮交互中持续做出决策并适应环境反馈。然而，当模型需要完成复杂的序列决策时，传统[[监督学习]]范式面临严峻瓶颈：人工为每一步交互标注最优动作不仅成本极高，而且难以覆盖真实环境中可能出现的海量变体情况。

SEED 的核心思路可以概括为三个步骤：将轨迹转化为自然语言技能、由策略自身提取这些技能、以及将技能效果转化为密集的蒸馏信号。这个设计的关键洞察在于，事后监督信号不应该是一次性固定不变的，而应该随着策略能力的提升而共同演化。

首先，SEED 对策略模型进行微调，使其能够分析已完成的轨迹并生成自然语言技能。这些技能以文本形式描述可复用的工作流（如"当看到错误信息 X 时，应该先检查配置文件而非重试"）、关键观察（如"服务器日志中出现的 OOM 关键字预示着资源耗尽"）或失败规避规则（如"在调用 API 前应验证参数边界"）。与仅返回一个标量奖励不同，自然语言技能携带了丰富的语义信息，能够解释决策的因果逻辑。

接下来，在实际的[[强化学习]]过程中，当前策略扮演双重角色：它既负责在环境中采集新的轨迹，又充当从这些轨迹中提取事后技能的分析器。这一设计蕴含着精妙的自我改进循环——当策略通过学习变得更强时，它的技能分析能力也会同步提升，从而能够从轨迹中提取更高质量的监督信号。反过来，更高质量的事后监督又能进一步加速策略的提升。这种协同演化机制避免了传统方法中监督信号与策略能力脱节的问题。

最后，SEED 在两种不同的上下文条件下对采样的动作进行重新评分：普通上下文（不含技能信息）和技能增强上下文（在上下文前附加提取的技能描述）。技能引发的概率偏移体现了技能知识对决策的影响程度——如果一个动作在技能上下文中被显著提升，说明该动作与技能所描述的工作流高度一致，值得强化。SEED 将这种概率偏移量化为密集的 token 级在策略蒸馏信号：

$$\mathcal{L}_{\text{distill}} = -\sum_{t} \log \frac{\pi_\theta(a_t | s_t, \text{skill})}{\pi_{\theta_{\text{old}}}(a_t | s_t)} \cdot \Delta p_t$$

其中 $\Delta p_t$ 表示技能上下文带来的概率变化量。这个蒸馏损失与原始的[[策略梯度]]损失联合优化，使辅助监督始终与当前轨迹分布保持对齐，避免了离线蒸馏方法中常见的分布偏移问题。

## 实验与结果

研究团队在两类智能体任务上验证了 SEED 的有效性：基于文本的网页导航与 API 调用任务，以及基于视觉的机器人操作与视觉问答任务。对比基线包括标准 PPO、HER（事后经验回放）以及几种离线蒸馏方法。

实验结果清晰地呈现了 SEED 的优势。在所有测试任务上，SEED 均实现了显著的性能提升，平均相对提升达到 15%~30%。更值得关注的是样本效率指标——SEED 在 50% 的训练步数内就能达到基线方法的最终性能，这表明密集的 token 级监督信号大幅加速了策略收敛。

消融实验进一步揭示了各组件的贡献。移除技能生成模块（即用固定规则替代策略生成的技能）会导致性能回退约 40%，证实了自然语言技能的语义丰富性不可替代。同时，固定技能分析器而非让其与策略共同演化时，性能也有明显下降，验证了自演化机制的核心价值。

泛化性评估是另一亮点。研究团队设计了包含未见过的任务变体和全新环境配置的测试集，SEED 表现出稳健的零样本迁移能力。这一结果符合预期——自然语言技能编码的是抽象的工作流知识而非具体的动作序列，因此能够跨任务复用。

## 讨论与可借鉴点

SEED 展示了一条有潜力的路径：用大语言模型自身的语言理解能力来填补强化学习的监督鸿沟。其核心贡献在于将事后监督从简单的奖励塑形升级为语义丰富的技能蒸馏，并通过策略与技能的协同演化实现了监督信号的自适应调整。

当前方法仍存在一定局限。首先，技能提取的质量依赖于策略模型的表达能力，若基础模型的语言理解能力不足，生成的技能可能包含噪声或错误描述。其次，蒸馏损失与策略梯度损失的权重配比需要手动设定，自动调节机制（如课程学习式的动态权重调整）值得探索。最后，SEED 聚焦于在策略场景，对于需要大规模离线预训练的场合，如何平衡技能质量与采样效率仍是开放问题。

对于该领域的研究者而言，SEED 的设计哲学具有借鉴意义：利用基础模型的语言能力为自身学习提供辅助信号，而非仅仅将其作为执行器。这种"模型自举"思路或许可以推广到其他存在监督稀疏问题的领域。此外，将辅助监督信号与主优化目标在分布上保持一致（on-policy 的核心思想）这一原则，在设计其他辅助任务时同样值得遵循。

## 摘要
大语言模型正日益被训练为面向长程任务的交互式智能体，这些任务涉及多轮交互、工具使用与环境反馈。基于结果的强化学习（RL）提供了一种实用的优化范式，但其稀疏的轨迹级奖励对中间决策的指导有限，在回合级结果与词元级策略学习之间留下了监督鸿沟。我们提出了 SEED（SElf-Evolving On-Policy Distillation），一个将已完成的在策略轨迹转化为训练时事后技能，并将其行为效果蒸馏回策略模型的自演化框架。SEED 首先微调策略以分析已完成的轨迹，并生成能够捕捉可复用工作流、关键观察或失败规避规则的自然语言技能。在 RL 过程中，当前策略既负责采集轨迹，又充当从轨迹中提取事后技能的分析器。因此，策略更新同时提升后续决策与技能分析能力，使事后监督能够随策略一同演化。随后，SEED 在普通上下文与技能增强上下文下对所采样的动作进行重新评分，将技能引发的概率偏移转化为密集的词元级在策略蒸馏信号。该信号与基于结果的强化学习联合优化，使辅助监督与当前轨迹分布保持对齐。在基于文本和基于视觉的智能体任务上的大量实验表明，SEED 始终提升了性能与样本效率，并对未见场景展现出稳健的泛化能力。代码已开源：https://github.com/jinyangwu/SEED。

## Abstract
Large language models are increasingly trained as interactive agents for long-horizon tasks involving multi-turn interaction, tool use, and environment feedback. Outcome-based reinforcement learning (RL) provides a practical optimization paradigm, but its sparse trajectory-level rewards offer limited guidance on intermediate decisions, leaving a supervision gap between episode-level outcomes and token-level policy learning. We propose SEED (SElf-Evolving On-Policy Distillation), a self-evolving framework that converts completed on-policy trajectories into training-time hindsight skills and distills their behavioral effect back into the policy model. SEED first fine-tunes the policy to analyze completed trajectories and generate natural-language skills that capture reusable workflows, decisive observations, or failure-avoidance rules. During RL, the current policy both collects trajectories and serves as the analyzer that extracts hindsight skills from them. Policy updates therefore improve subsequent decision making and skill analysis together, allowing hindsight supervision to evolve with the policy. SEED then re-scores the sampled actions under ordinary and skill-augmented contexts, converting the skill-induced probability shift into a dense token-level on-policy distillation signal. This signal is jointly optimized with outcome-based RL, keeping the auxiliary supervision aligned with the current trajectory distribution. Extensive experiments on text-based and vision-based agentic tasks show that SEED consistently improves performance and sample efficiency, exhibiting robust generalization to unseen scenarios. Our code is available at https://github.com/jinyangwu/SEED.
