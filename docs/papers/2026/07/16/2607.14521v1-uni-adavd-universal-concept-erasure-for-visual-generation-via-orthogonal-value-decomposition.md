## 摘要
视觉生成模型不可避免地从未经筛选的预训练数据中吸收不良概念，因此概念擦除对于安全部署至关重要。然而，现有的擦除方法往往针对特定架构，并且在擦除目标概念的同时难以保留非目标内容和生成先验。本文提出 Uni-AdaVD，一种用于视觉生成的通用推理时概念擦除框架。Uni-AdaVD 将多模态注意力的值空间作为统一的干预空间，并引入编码器感知的目标表征构建方法，以在异构文本编码器之间定位目标语义。该方法进一步将正交值分解与自适应擦除偏移相结合，在不更新原始模型权重的条件下抑制目标语义方向。我们在 U-Net、DiT 以及自回归图像生成器，以及文生视频模型上进行了大量实验，结果表明该方法在单概念和多概念擦除任务上均表现出色，同时能够保留非目标先验。上述结果表明，Uni-AdaVD 为现代视觉生成模型提供了一种高效且适应性强的安全机制。代码已开源：https://github.com/QifanZhou/Uni-AdaVD。

## Abstract
Visual generative models inevitably absorb undesirable concepts from uncurated pretraining data, making concept erasure essential for safe deployment. Existing erasure methods, however, are often architecture-specific and struggle to remove target concepts while preserving non-target content and generative priors. We present Uni-AdaVD, a universal inference-time concept erasure framework for visual generation. Uni-AdaVD treats the value space of multimodal attention as a unified intervention space and introduces encoder-aware target representation construction to localize target semantics across heterogeneous text encoders. It further combines orthogonal value decomposition with an adaptive erasing shift to suppress target semantic directions without updating the original model weights. Extensive experiments on U-Net-, DiT-, and autoregressive image generators, as well as text-to-video models, demonstrate strong performance on single- and multi-concept erasure while preserving non-target priors. These results suggest that Uni-AdaVD provides an efficient and adaptable safety mechanism for modern visual generative models. Our code is available at https://github.com/QifanZhou/Uni-AdaVD.

视觉生成模型（如 Stable Diffusion 类 U-Net、DiT、自回归图像模型及文生视频模型）在未经严格筛选的大规模图文对上预训练，不可避免地吸收了 NSFW、名人肖像、版权风格等不良概念，给安全部署带来风险。

现有的概念擦除（Concept Erasure）方法存在两大共性局限：

- **架构耦合**：多数方法针对扩散模型 U-Net 设计（例如在 cross-attention 上做干预或微调），难以迁移到 DiT、自回归或视频生成架构；
- **副作用明显**：在抑制目标概念的同时，往往损害对非目标内容、风格及整体生成先验（图像质量、多样性）的保留能力。

因此，论文目标是提出一种**架构无关、推理时可用、不更新模型权重**的通用擦除框架。

## 2. 方法论

### 2.1 核心思想

Uni-AdaVD 提出将**多模态注意力中的 Value 空间**作为统一的干预空间——无论模型是 U-Net、DiT、自回归还是文生视频，其堆叠的注意力层（self-/cross-/joint-attention）都共享 $\text{Attention}(Q,K,V)$ 这一基本结构，因此 Value 空间提供了"跨架构的公分母"。

在此基础上：
1. 用**编码器感知的目标表征**统一不同文本编码器（CLIP、CLIP-L/14、T5-XXL 等）下"目标概念"的语义方向；
2. 用**正交 Value 分解**定位并构造擦除方向；
3. 用**自适应擦除位移**在推理过程中对 Value 进行位移，从而抑制目标语义、保留非目标先验。

### 2.2 关键技术细节

**(a) 多模态 Value 拼接。** 对输入的图像/视频 token $I \in \mathbb{R}^{L_I \times d}$ 与文本 token $T \in \mathbb{R}^{L_T \times d}$，将 Q/K/V 沿 token 维拼接：

$$
Q = [Q_I;\, Q_T], \quad K = [K_I;\, K_T], \quad V = [V_I;\, V_T]
$$

注意力输出为

$$
\text{Attention}(Q,K,V) = \text{softmax}\!\left(\frac{QK^\top}{\sqrt{d_k}}\right)V
$$

**(b) 编码器感知的目标表征。** 对目标概念的文本 embedding $c_t = [c_{t,1}, c_{t,2}, \dots, c_{t,L}]^\top$，取其 Value 投影并归一化得到

$$
\hat{v}^i \in \mathbb{R}^{d_v}, \quad \forall i \in \{1,\dots,L\}
$$

通过在所有可用的 Value 子空间上求均值，统一 CLIP、T5 等异构文本编码器下的语义方向。

**(c) 正交 Value 分解与擦除位移。** 将与目标方向对齐的分量从 Value 中减去：

$$
v^i \leftarrow v^i - (\hat{v}^i)^\top v^i \,\hat{v}^i
$$

其闭式投影表达为

$$
v^i_{\perp} = v^i - \frac{(\hat{v}^i)^\top v^i}{(\hat{v}^i)^\top \hat{v}^i}\,\hat{v}^i
$$

聚合多个 token 的位移量：

$$
c_a = \sum_{i=t_s}^{t_{\text{EOT}}} c_{t,i}
$$

**(d) 自适应层选择。** 为避免对每层无差别干预，引入二值掩码

$$
\delta_\ell(\hat{v}^i, v^i) = 
\begin{cases}
1, & \cos(\hat{v}^i, v^i) \ge \epsilon \\
0, & \text{otherwise}
\end{cases}
$$

$$
R = v^i - \delta_\ell(\hat{v}^i, v^i)\,(\hat{v}^i)^\top v^i
$$

即仅在当前层 Value 与目标方向余弦相似度高于阈值 $\epsilon$（如 0.5）时才执行擦除，最大化对非目标先验的保留。

### 2.3 算法流程

1. 输入：目标概念文本、待干预模型、生成 prompt；
2. 计算目标概念在 Value 空间下的方向 $\hat{v}^i$；
3. 推理时，对每一层 cross/joint-attention 计算余弦相似度判断是否触发擦除；
4. 若触发，则按正交分解公式对 Value 进行位移；
5. 输出图像/视频，期间**不修改任何模型权重**。

## 3. 实验设计

### 3.1 数据集与场景

- **图像擦除**：Stable Diffusion v1.4（U-Net）、Stable Diffusion 3 / FLUX（DiT）、LlamaGen（自回归图像）；
- **视频擦除**：CogVideoX / AnimateDiff 等文生视频模型；
- **擦除目标**：包含名人身份、NSFW、版权角色、风格等多类不良概念；
- **评估基准**：与主流概念擦除 benchmark（如 I2P、UnlearnDiff、CEBench 等）以及多种概念类别对齐。

### 3.2 对比方法

- 训练时方法：ESD、Concept Ablation（CA）、MACE、SALUN、UCE 等；
- 推理时方法：包括基于 cross-attention 操控的 Saliency-based 方法、负向 prompt 引导、Safe Latent Diffusion（SLD）等。

### 3.3 评估指标

- **擦除效果**：生成图像中目标概念的检出率 / 分类器分数（如 NudeNet、CelebA 分类器）、CLIP 相似度；
- **生成质量**：FID、CLIP Score、人脸/物体识别分数；
- **先验保留**：非目标 prompt 下的图像质量与多样性退化幅度。

## 5. 实验数量与充分性

- **跨架构验证**：覆盖 4 类主流架构（U-Net、DiT、自回归、文生视频），是已有概念擦除论文中覆盖最广的之一；
- **单概念 vs 多概念**：分别报告单概念与多概念同时擦除的结果；
- **消融实验**：包括是否启用"编码器感知目标表征"、"自适应层选择 $\delta_\ell$"、"正交分解 vs 简单减法"等组件的消融；
- **先验保留**：通过大量中性/非目标 prompt 的生成质量对比验证副作用程度；
- **超参分析**：$\epsilon$（相似度阈值）等关键超参的敏感性曲线。

总体而言实验较为充分，但**缺少对对抗鲁棒性（如 adversarial prompt bypass、AdvUnlearn 类型攻击）、对长尾/复合概念的覆盖，以及人评主观质量**的系统评估，公平性受限于未在统一算力、统一采样设置下与所有最新方法逐一对比。

## 6. 主要结论与发现

1. Value 空间可作为概念擦除的**统一干预域**，跨架构迁移性显著优于传统 cross-attention 操控；
2. **编码器感知的目标表征**有效解决了 CLIP、T5 等不同文本编码器下"目标语义"对齐不一致的问题；
3. **正交分解 + 自适应位移**能够在抑制目标方向的同时，最大限度保留与目标方向近似正交的非目标内容；
4. 在 U-Net、DiT、自回归、文生视频四类模型上，单/多概念擦除均取得 SOTA 或可比 SOTA 效果，且 FID/CLIP Score 等先验保留指标退化最小；
5. 由于完全推理时执行、零权重更新，可作为"即插即用"的安全模块部署。

---

## 7. 优点

- **架构无关**：是首批将概念擦除统一到 DiT 与自回归图像/视频生成器上的工作；
- **零权重更新**：推理时干预，无需昂贵重训，便于版本回滚与合规审计；
- **机制清晰**：基于正交分解的数学推导简洁，组件解耦（编码器感知、正交、自适应），便于复用；
- **副作用小**：自适应层选择显著降低了对生成先验的破坏；
- **多概念友好**：聚合位移量 $c_a = \sum_i c_{t,i}$ 天然支持多概念同时擦除。

---

## 8. 不足与局限

- **算力与复现性披露不全**：未公开 GPU 型号、批量大小、单次实验时长；
- **对抗鲁棒性未知**：未在 adversarial prompt、inpainting 重建、参数微调绕过等攻击下评估其鲁棒性；
- **联合分布偏移风险**：对 Value 做正交投影可能隐式破坏与文本条件无关的视觉细节，对长 prompt 或复合 prompt 影响尚需更多评测；
- **视频与自回归模型评估偏少**：相比 U-Net，DiT/自回归/视频上的定量指标与可视化对比仍较薄弱；
- **阈值 $\epsilon$ 与层选择策略的敏感性**：依赖于手工设定的相似度阈值，缺乏自适应学习机制；
- **伦理与双用风险**：作为擦除工具本身可被反向用于"定向植入/规避检测"，论文未充分讨论防御面；
- **公平性**：未明确说明是否在相同推理步数、相同 CFG scale、相同种子下与所有 baseline 一一对齐，可能存在评估偏差。
