## 摘要
强化学习（RL）主要作为一种用于优化控制任务的计算方法而为人所知，但越来越多地被用于解释生物行为。尽管强化学习成功捕捉到了生物学的关键方面，但仍存在一个主要缺口：智能体之间的行为变异性。稳定的个体差异天然地渗透于生物群体之中，然而强化学习模型通常只呈现单一最优个体或群体平均水平。要弥合这一缺口，需要超越当前的做法，转而采用生物学上合理的机制来生成行为多样性。本文综述了来自强化学习各子领域的方法，并勾勒出弥合生物学与仿真之间差距的潜在前进路径。

## Abstract
Reinforcement learning (RL) is primarily known as a computational method for optimizing control tasks, but it is increasingly used to explain biological behavior. While RL successfully captures key aspects of biology, a major gap remains: between-agent behavioral variability. Consistent individual differences naturally permeate biological populations, yet RL models typically present only the single best individual or the population average. Addressing this gap requires moving beyond current practices to generate behavioral diversity using biologically plausible mechanisms. Here, we examine approaches from various subfields of RL and outline potential paths forward to close the gap between biology and simulation.

## 1. 核心问题与整体含义

### 研究背景
- **RL 的双重身份**：强化学习（RL）既是一种用于优化控制任务的工程方法，也越来越多地被行为生态学借用来从"经验驱动、机制化"的角度解释生物行为。
- **关键缺口**：当前 RL 应用主要面向工程控制，追求**单一最优策略**，常将高学习变异性视为需要平均掉的"噪声"。但真实生物种群中**稳定的个体间行为差异**（性格/行为异质性）并非"噪声"，而是具有进化与生态后果的核心特征。
- **核心矛盾**：RL 模型通常只报告"最佳个体"或"群体平均"，掩盖了学习过程中涌现的行为分布；而 ML 社区又倾向用"自上而下"的奖励（如好奇心、多样性奖励）显式优化多样性，这与生物学机制脱节。

### 研究目标
提出一个研究纲领，将 RL 定位为**理解生物行为机制**的框架，而非单纯的拟合/优化工具；并以**行为异质性**为典型案例，从**自下而上**的角度讨论如何让个体差异自然涌现。

## 2. 方法论：核心思想与三个维度

论文并非提出具体算法，而是提出一个**研究路线图**，沿三个相互补充、非排他的维度展开：

### 维度一：扩展决策空间（第 2 节）
1. **探索与涌现行为**
   - 随机动作选择可导致训练轨迹发散，但能否产生范围广泛且稳定的个体差异存疑。
   - 内生动机方法（基于新颖性、多样性、熵的奖励）以及基于不确定性最小化的探索，提示**仅靠外部奖励驱动的优化可能不足以解释稳定个体差异**。
   - 关键观点：行为多样性也可**通过 agent–environment 互动自然涌现**，反映发育动力学与环境的相互作用。

2. **多目标行为**
   - 生物行为常映射于**权衡**（如速度-准确性、合作-竞争、社会意识）。
   - 多目标问题存在 **Pareto 前沿**（即在多个目标上均最优的策略集合 $\mathcal{P} = \{ \pi \mid \nexists \pi' \text{ s.t. } \pi' \succ \pi \}$，意味着无法在改善某一目标的同时不牺牲其他目标）。
   - 实现方式：多个并行模型或单一条件模型；神经科学证据表明不同任务可投射到**正交流形**，对应大脑不同脑区。
   - 能量/参数预算限制可作为**迫使模块化与权衡的生物学合理机制**。

3. **价值的分布表征（Distributional RL）**
   - 标量价值压缩了潜在收益分布的信息（均值相同但方差不同的选项会被等同处理）。
   - 分布式 RL 保留完整收益分布 $Z(s,a)$，涵盖不确定性、风险与时延。
   - 个体可在分布的不同侧做出选择（乐观/悲观），并对特定奖励序列敏感，从而支持路径依赖的个性。

### 维度二：学习动态塑造时间维度上的行为（第 3 节）
1. **路径依赖与偏差**
   - "热炉效应"等早期经历可引发自我强化反馈循环，将行为推向某个**吸引子**（即动力学系统中的局部稳定状态）。
   - 即使没有显式奖惩，偏差也可形成（如 Tabula Rasa agent 涌现的内群体偏好）。
   - 动力学视角：偏差相当于"落入先前选择的吸引盆"。

2. **多时间尺度学习（元学习）**
   - 生物学学习跨越个体/进化、短/长时、快/慢决策等多个嵌套尺度。
   - 元学习用嵌套时序循环建模：内层循环（快）跨任务时间步优化奖励；外层循环（慢）跨任务片段调整、不直接接收奖励。
   - 有助解开环境背景、发育历史、目标导向 vs 习惯系统等不同贡献。

3. **开放式过程**
   - 传统 RL 限定固定状态/动作空间，限制行为多样性。
   - 开放演化方法允许**动态状态空间与组合灵活性**；通过不断"重述表征"或维护"模型库"应对不可预测环境。
   - 通过 **chunking**（将动作序列组合为可选技能）非线性扩展行为空间。

### 维度三：将行为嵌入种群而非仅个体（第 4 节）
1. **基于种群的算法**
   - 进化/遗传算法沿中性变异维度探索，逃出局部最优，可能更接近自然系统的"近最优性"。
   - 作者团队近期研究表明：从简单优化出发，群体算法可自然涌现行为多样性；如**视觉分辨率**作为内在感知约束可调节策略变异。

2. **多智能体环境（MARL）**
   - MARL 引入非平稳动力学，违反马尔可夫性。
   - 集中训练/参数共享会**限制行为个体性**。
   - 图神经网络等可实现完全去中心化学习与涌现通信，但**显式优化多样性**与生物学合理机制仍存张力。

3. **社会结构的影响**
   - 交互拓扑（空间、时序、网络多层结构）可驱动行为多样性。
   - 局部连接主导的网络、非对称多层交互、奖励网络位置本身均可塑造异质性。
   - 论文还将视野延伸到人类制度：共享媒介（如经济）可催生多样化社会生态位；政治制度同样塑造多样性/一致性。

## 6. 主要结论与发现

1. **RL 当前用于生物学存在结构性局限**：对单一最优策略和平均化的偏好，与生物行为多样性的核心地位不符。
2. **应从"自上而下显式优化多样性"转向"自下而上自然涌现"**：让个体差异源于生物学合理机制，而非新奇性/多样性奖励的直接最大化。
3. **三条互补路径**可同时推进：扩展决策空间、纳入时序动态、嵌入种群/社会。
4. **机制间相互纠缠**：各维度并非独立，而是耦合的"学习—环境系统"的不同侧面，可单独或联合应用。
5. **Anna Karenina 原理的类比**：每个非最优行为策略可能以独特方式失败；稳定行为差异可能源于偶然发散被时间放大并强化为持久吸引子。
6. **呼吁跨界反馈**：建模与实证应形成迭代回路——RL 不只是拟合工具，更是揭示行为起源的机制框架。
