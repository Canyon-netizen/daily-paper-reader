## 摘要
可验证奖励强化学习（RLVR）已显著提升了大语言模型在数学推理和代码生成等任务上的推理能力。然而，大多数 RLVR 方法对整个轨迹赋予单一标量结果奖励，导致监督信号稀疏，难以进行细粒度的逐词元信用分配。在策略蒸馏（OPD）通过从更强的教师模型蒸馏逐词元分布提供了更密集的监督，但需要额外的教师模型，并且通常假设师生之间共享词表。在策略自蒸馏（OPSD）通过将同一模型以特权信息作为条件来构建教师策略，从而消除了对外部教师的依赖。然而，直接匹配教师分布可能导致信息泄露和优化不稳定。RLSD 通过仅使用教师信号来调节更新幅度，避免了直接匹配，但在采样推理失败时无法提供明确的修正方向。为了应对这一权衡，我们提出了 $\mathrm{H}^{2}\mathrm{SD}$，一种混合事后自蒸馏框架，它根据轨迹的正确性以不同方式使用教师。对于成功的轨迹，教师接收已被确认为正确的学生回复以及一个重新表述指令，其在原始回复词元上的概率用于调节更新幅度，而不改变由奖励所确定的方向。对于失败的轨迹，我们让教师以包含关键推理步骤和已验证答案的参考提示作为条件，并最小化学生到教师的反向 KL 散度。在多个具有挑战性的推理基准上的实验表明，H$^2$SD 在保持优化稳定和生成效率良好的同时，始终优于代表性的 RLVR、OPSD 和 RLSD 基线方法。

## Abstract
Reinforcement learning with verifiable rewards (RLVR) has substantially improved the reasoning capabilities of large language models on tasks such as mathematical reasoning and code generation. However, most RLVR methods assign a scalar outcome reward to an entire trajectory, resulting in sparse supervision and limited token-level credit assignment. On-policy distillation (OPD) provides denser supervision by distilling token-level distributions from a stronger teacher model, but requires an additional teacher and typically assumes a shared vocabulary. On-policy self-distillation (OPSD) removes this dependency by conditioning the same model on privileged information to construct a teacher policy. However, directly matching the teacher distribution may cause information leakage and unstable optimization. RLSD avoids direct matching by using the teacher signal only to modulate update magnitudes, but it cannot provide an explicit correction direction when the sampled reasoning fails. To address this tradeoff, we introduce $\mathrm{H}^{2}\mathrm{SD}$, a hybrid hindsight self distillation framework that uses the teacher differently according to trajectory correctness. For successful trajectories, the teacher receives the student response confirmed as correct together with a rephrasing instruction, and its probabilities on the original response tokens are used to modulate update magnitudes without changing the direction determined by the reward. For failed trajectories, we condition the teacher on a reference hint containing key reasoning steps and a verified answer, and minimize the reverse KL divergence from the student to the teacher. Experiments on multiple challenging reasoning benchmarks show that H$^2$SD consistently outperforms representative RLVR, OPSD, and RLSD baselines while maintaining stable optimization and favorable generation efficiency.

## 1. 核心问题与整体含义（研究动机与背景）

- **RLVR 的监督稀疏瓶颈**：以 GRPO 为代表的可验证奖励强化学习（RLVR）虽然显著提升了大语言模型（LLM）在数学推理和代码生成上的能力，但通常仅对整条轨迹赋予一个标量结果奖励，导致**逐 token 信用分配不足**，难以识别推理中具体哪一步导致成功或失败。
- **OPD 的依赖性强**：在策略蒸馏（OPD）通过引入更强教师模型提供逐 token 分布监督，缓解稀疏性问题，但需额外教师并通常要求师生**共享词表**，限制了实际可用范围。
- **OPSD 的信息泄露与不稳定**：在策略自蒸馏（OPSD）使用同一模型并以特权信息（如真实答案）作为条件构建教师策略，消除了对外部教师的依赖。但**直接匹配教师分布**会让特权信息在每个 token 上泄露给学生，并带来优化不稳定。
- **RLSD 缺乏修正方向**：RLSD 改为只利用教师信号**调节更新幅度**，缓解了泄露与不稳定，但当学生采样到错误推理时，仅靠幅度调节无法提供"应当走向哪里"的显式修正方向。
- **核心权衡**：在"分布级显式修正"与"幅度级稳定信用分配"之间存在张力，而最佳监督策略**取决于学生轨迹是否正确**——这就是 H²SD 要解决的根本问题。

## 2. 方法论：核心思想、关键技术细节与公式

### 2.1 整体框架（核心思想）

H²SD（Hybrid Hindsight Self-Distillation，混合事后自蒸馏）是一种**正确性感知的混合自蒸馏框架**，根据学生轨迹正确性**差异化使用教师信号**：

- **成功轨迹**（已通过验证器）→ **幅度级调制**（沿用 RLSD，不改变奖励方向）
- **失败轨迹** → **反向 KL 蒸馏**（利用 hint 条件下的教师分布提供方向性修正）

### 2.2 Hint 设计（特权信息生成）

- 直接答案级特权信息过于粗糙，无法揭示具体推理错误。
- 引入**外部更强的 LLM（Kimi-K2.6）作为 hint 生成器**，针对每个问题 $x$ 生成自然语言提示 $h$：
$$h = \mathcal{H}(x)$$
- 该 hint 包含**关键中间推理步骤**与**由验证器确认的最终答案**。
- 关键设计：Kimi-K2.6 **不直接作为教师**，也不要求与学生共享词表；实际教师分布仍由当前模型 $\pi_\theta$ 在 hint 条件下产生：
$$\pi_T(\cdot \mid x, h, y_{<t}) = \pi_\theta(\cdot \mid x, h, y_{<t})$$
$$\pi_S(\cdot \mid x, y_{<t}) = \pi_\theta(\cdot \mid x, y_{<t})$$

### 2.3 成功轨迹的处理：幅度级调制 + 改写

- 教师接收**已被验证为正确的学生回复** + **"重新表述该回复"的指令**。
- 教师在原始回复 token 上的概率用于计算 RLSD 风格的**幅度权重**：
$$\Delta_t = \mathrm{sg}(\log P_T(y_t) - \log P_S(y_t))$$
$$w_t = \exp(\mathrm{sign}(\hat{A})\cdot \Delta_t) = \left(\frac{P_T(y_t)}{P_S(y_t)}\right)^{\mathrm{sign}(\hat{A})}$$
- Token 级优势为：
$$\hat{A}_t = \hat{A}\big[(1-\lambda) + \lambda\,\mathrm{clip}(w_t, 1-\epsilon_w, 1+\epsilon_w)\big]$$
- **作用**：保持奖励决定的优化方向，只在轨迹内细化逐 token 信用分配，避免直接匹配教师分布。

### 2.4 失败轨迹的处理：反向 KL 蒸馏

- 负奖励只能惩罚已采样动作，但**不指明应倾向哪个替代 token**。
- 使用 hint 条件下的教师分布提供方向性修正，最小化**学生到教师的反向 KL**：
$$\mathcal{L}_{\mathrm{RKL}} = \frac{1}{T}\sum_{t=1}^{T} D_{\mathrm{KL}}\!\left(p^{S}_{t,\theta}\,\big\|\, \mathrm{sg}[p^{T,h}_{t,\theta}]\right)$$
其中 $p^{S}_{t,\theta} = \pi_\theta(\cdot\mid x, y_{<t})$，$p^{T,h}_{t,\theta} = \pi_\theta(\cdot\mid x, h, y_{<t})$，$\mathrm{sg}[\cdot]$ 为 stop-gradient。

### 2.5 总目标

设轨迹正确性指示器 $m = \mathbb{1}[R(x, y) = 1]$，则整体目标为：
$$\mathcal{L}_{\mathrm{H^2SD}} = \mathbb{E}_{x,y}\big[\,m\,\mathcal{L}_{\mathrm{RLSD}} + \gamma\,(1-m)\,\mathcal{L}_{\mathrm{RKL}}\,\big]$$
其中 $\gamma$ 控制对失败轨迹的修正蒸馏强度，$\mathcal{L}_{\mathrm{RLSD}}$ 为使用改写提示的 RLSD 损失形式。

### 2.6 实现要点

- 采用 **VERL + SGLang** 实现。
- 为缓解长链推理下全词表蒸馏的巨大显存开销，对 OPSD 采用**Top-100 token 精确概率 + 尾部桶合并**的近似。
- 所有方法共享同一 hint 来源（Kimi-K2.6 生成），保证比较公平。

- **基准任务**：3 类（共 9 个具体规模，含分布外尺寸）。

## 6. 主要结论与发现

- **主结果**：H²SD 在 Sudoku、Calcudoku、Arrow Maze 上整体最优（综合平均 50.49% vs 第二名 RLSD 24.85%），尤其在 Sudoku 上提升显著（6×6：76.50% vs 第二 OPSD 35.25%）。
- **泛化性**：在训练分布外的 Arrow Maze-8×8 / 10×10 上仍稳定领先。
- **生成效率**：H²SD 以**最短的平均生成长度**取得最高 pass@1（图 3），说明改进并非来自更长推理链，而是更有效的学习信号利用。
- **路由必要**：若将成功/失败路由对调（Reversed Routing），策略熵迅速崩塌至接近 0，性能低于 Base LLM；证明**正确性条件路由不可或缺**。
- **Hint 质量决定上限**：含过程级推理信息的 hint 显著优于仅含最终答案或程序化反馈的特权信号；hint 在三个基准上一致最优。
- **改写的位置依赖**：改写指令对 Magnitude Only 提升最大（+23.75/+32.00 pp），对 H²SD 也有正向作用（+8.00/+5.75 pp），但**对 Reverse-KL Only 反向有害**（-2.50/-3.50 pp）——说明改写应与幅度调制而非分布匹配搭配。
- **对比 SRPO**：H²SD 同样按正确性路由，但因对失败轨迹提供方向性修正并对成功轨迹提供 token 级信用细化，一致优于 SRPO。

## 7. 优点（方法与实验设计亮点）

- **问题诊断清晰**：准确识别 OPSD（信息泄露+不稳定）与 RLSD（无法修正失败）之间的张力，并将"按轨迹正确性切换策略"作为解决思路。
- **混合目标设计简洁**：仅用一个指示器 $m$ 在 $\mathcal{L}_{\mathrm{RLSD}}$ 与 $\mathcal{L}_{\mathrm{RKL}}$ 间切换，便于复现与扩展。
- **解耦 hint 生成与教师**：Kimi-K2.6 只生成 hint，不直接当教师，规避了 OPD 对词表一致性的硬约束。
- **改写指令的小改动大收益**：在成功轨迹上以 RLSD 框架加一个改写提示，就实现"路径保留 + token 级细化"，改动极小却显著提升性能。
- **实验对照组严谨**：通过共享 hint（OPSD / RLSD+hint / H²SD）剥离"信息内容 vs 信息利用方式"的混淆，并从熵演化角度提供训练动态层面的解释。
- **生成效率优势**：提升来自更密集、更精准的信用分配，而非依赖更长推理链。

## 8. 不足与局限

- **任务范围偏窄**：基准仅限三类逻辑谜题，未覆盖数学竞赛（如 AIME、MATH）、代码生成（HumanEval/MBPP）等 RLVR 主战场，泛化性结论需进一步验证。
- **依赖外部强模型生成 hint**：Kimi-K2.6 的能力上限决定 hint 质量，引入了**提示工程依赖**与额外离线成本。
- **计算开销未充分量化**：Top-100 近似虽缓解显存，但长链推理下教师前向仍是主要开销；训练时长、单次实验成本未披露，难以评估实际部署可行性。
- **超参数敏感性**：损失权重 $\gamma$、RLSD 中的 $\lambda$、改写提示模板等关键超参数的影响未做系统扫描。
- **统计显著性不足**：未见多次随机种子运行的均值±方差，结论的稳健性存疑。
- **改写策略的通用性**：Calcudoku 等"多解"任务下，改写可能与学生已选路径不一致；论文承认但未给出自适应解法。
- **可能的应用限制**：当任务不存在可验证器或高质量 hint 生成器时（如开放式写作、对话），框架难以直接迁移。
- **Reversed Routing 现象虽指出，但熵崩塌的根因（奖励信号与分布目标的对抗）缺乏更细致的理论解释**。
