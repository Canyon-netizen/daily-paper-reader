## TL;DR

这篇论文提出了一个名为 RLAW 的智能体工作流架构，将 [[POMDP]] 路由机制与内部自校正奖励模型相结合，让大语言模型在执行动作前先"自我批判"决策轨迹。实验在 ALFWorld 和 WebShop 两个基准上，相比主流的 [[ReAct 框架]] 取得了 24.5% 的绝对成功率提升，幻觉率降低超过一半。该工作证明了在 LLM 智能体中引入强化学习的价值函数逼近与策略优化思想，能够有效缓解长程规划中的错误累积问题。

## 研究背景与动机

大语言模型在开放域问答等单轮任务上已经展现出令人印象深刻的能力，但当我们要求它像人类一样在真实环境中执行多步骤任务时，问题就变得棘手起来。想象一个场景：让 LLM 控制一个机械臂去厨房拿杯子——它需要在部分可观测的环境中导航、识别物体、判断动作的物理可行性，并在长达十几步的序列中保持目标一致性。这种长程规划能力恰恰是当前 LLM 的短板。

传统 LLM 智能体的核心缺陷可以归结为三点。首先是**级联幻觉问题**：LLM 基于最大似然估计进行自回归生成，一旦在某一步做出了错误假设（比如认为杯子在柜子里），这个错误会像滚雪球一样污染后续整个推理链，最终导致任务完全失败。其次是**奖励归因困难**：缺乏显式的优化目标意味着智能体只能被动遵循预训练阶段形成的文本分布，无法主动选择那些更可能达成目标的动作。第三是**感知-动作闭环缺失**：零样本或少样本的提示范式本质上是开环的，智能体无法根据环境反馈动态调整策略，容易陷入死循环或重复调用工具。

论文的切入点在于：能否将 LLM 智能体的规划问题纳入一个严格的数学框架——[[POMDP]]——并借助强化学习的思想来弥补上述缺陷？POMDP 的核心洞察是：在真实环境中，智能体永远无法直接观测到环境的真实状态，只能依赖不完全的观测来推断当前所处状态，并通过选择动作最大化期望累积奖励。这种形式化恰好契合了 LLM 智能体面临的现实挑战。

## 方法

RLAW 的设计围绕一个简洁而强大的循环：**生成（Generation）→ 批判（Critique）→ 执行（Execution）**。整个框架建立在 [[POMDP]] 的七元组形式化之上，将真实状态空间 $\mathcal{S}$、动作空间 $\mathcal{A}$、状态转移函数 $\mathcal{T}$、奖励函数 $\mathcal{R}$、观测空间 $\Omega$、观测发射概率 $O$ 和折扣因子 $\gamma$ 作为建模基础。最优策略 $\pi^*$ 的目标被定义为最大化期望累积折扣回报：

$$\pi^{*} = \arg\max_{\pi}\;\mathbb{E}_{\pi}\left[\sum_{t=0}^{\infty}\gamma^{t} r_{t+1}\right]$$

由于底层状态不可观测，智能体需要维护一个**信念状态** $b_t$，通过贝叶斯规则融合历史观测来近似推断当前状态。作者采用了图结构记忆 $M_t$ 来高效表示这种信念状态——节点代表关键实体和关系，边编码它们之间的依赖关系。图的更新通过 [[图注意力网络]] 实现，节点特征的聚合采用注意力加权：

$$h_i^{(l+1)} = \sigma\!\left(\sum_{j\in\mathcal{N}(i)} \alpha_{i,j}\, W^{(l)} h_j^{(l)}\right)$$

在 Actor 生成阶段，策略网络 $\pi_\theta$（冻结的 LLaMA-3-8B）接收拼接了目标、历史轨迹 $H_t$ 和序列化图记忆的提示，然后采样出候选动作 $(z_t, a_t)$。这里的 $z_t$ 是中间推理结果，$a_t$ 是最终执行的动作。

Critique 模块是整个架构的创新所在。它扮演"内部奖励模型"的角色，在动作真正执行之前评估其质量。Critic $f_\phi$ 以 JSON 格式输出逻辑检查结果、安全检查结果、0 到 1 的评分以及自然语言诊断。当评分低于阈值 $\tau = 0.70$ 时，候选动作被否决，Critic 的反馈被追加到 Actor 的上下文中，强制其重新生成。为了防止无限循环，系统设置了每步最多三次重生的限制。

Critic 的优化目标采用因果交叉熵损失函数：

$$L(\phi) = -\sum_{i=1}^{L} \log P_\phi(y_i \mid y_{<i}, x)$$

最终的整体优化目标融合了来自环境的稀疏奖励 $R_{\text{env}}$ 和来自 Critic 的内部奖励 $R_{\text{critique}}$：

$$J(\pi_\theta) = \mathbb{E}_{\tau\sim\pi_\theta}\!\left[\sum_{t=0}^{H} \gamma^{t}\big(R_{\text{env}}(s_t, a_t) + \lambda\, R_{\text{critique}}(o_t, a_t)\big)\right]$$

策略更新部分借鉴了 [[PPO]] 的截断目标函数来稳定训练：

$$L^{\text{CLIP}}(\theta) = \hat{\mathbb{E}}_t\!\left[\min\big(r_t(\theta)\hat{A}_t,\; \text{clip}(r_t(\theta), 1-\epsilon, 1+\epsilon)\hat{A}_t\big)\right]$$

优势估计 $\hat{A}_t$ 由价值函数基线给出，确保策略更新方向更加可靠。

## 实验与结果

实验在两个标准基准上进行。**ALFWorld** 是一个基于 TextWorld 的具身仿真环境，模拟多房间家居场景中的物体操作任务，包含拾取放置、清洁归位、加热冷却等六类任务，平均最优轨迹长度约 12.8 步。**WebShop** 则是一个在线购物网站的模拟环境，包含超过一百万件商品和上万条人类购物轨迹，用于测试智能体在网页导航中的搜索与决策能力。

主实验结果显示，RLAW 在 ALFWorld 上达到 **78.6%** 的任务成功率，相比 ReAct 的 54.1% 和基线 LLM 的 22.4% 有显著提升；WebShop 上的成功率从 ReAct 的 42.3% 提升至 65.8%。这对应着论文报告的 **24.5% 绝对提升**。不仅如此，成功轨迹的平均步数也有明显下降——ALFWorld 从 12.1 步降至 9.4 步，WebShop 从 10.5 步降至 8.2 步，说明 Critic 模块不仅提高了成功率，还让智能体的行为更加高效。

最引人注目的发现是幻觉率的下降。在 ALFWorld 上，ReAct 的幻觉率为 28.5%，即超过四分之一的轨迹包含物理上或逻辑上不可行的动作；RLAW 将这一数字压制到 12.4%。这直接验证了"提议-批判-执行"工作流的有效性——Critic 模块在早期就拦截了不合理的动作，避免了后续的错误传播。

消融实验进一步拆解了各组件的贡献。移除 Critic 模块后成功率下降约 15 个百分点，移除图记忆后下降约 8 个百分点，两者同时缺失时效果最差。有趣的是，Critic 模块的拒绝率在不同任务类型中差异很大——在需要精确物体识别的任务中拒绝率高达 40%，在简单导航任务中则不足 10%，这说明 Critic 学会了根据任务难度自适应地调整审查力度。

## 讨论与可借鉴点

RLAW 的核心贡献在于证明了强化学习的理论框架可以有效地移植到 LLM 智能体的设计中来。通过将 Critic 模块建模为内部奖励模型，系统获得了在执行前"预判"动作质量的能力，这与人类在做重要决策前进行深思熟虑的认知模式高度一致。图结构记忆则为长期依赖关系的建模提供了高效的表示，使智能体能够在复杂任务中保持上下文一致性。

## 2. 方法论

### 2.1 核心思想

RLAW 由三个串联阶段构成：**Generation（Actor）→ Critique（Internal Reward Model）→ Execution**。其形式化基础是 POMDP 7 元组：

$$\langle \mathcal{S}, \mathcal{A}, \mathcal{T}, \mathcal{R}, \Omega, O, \gamma \rangle$$

其中 $\mathcal{S}$ 为真实状态空间，$\mathcal{A}$ 为离散动作空间，$\mathcal{T}: \mathcal{S}\times\mathcal{A}\to\Delta(\mathcal{S})$ 为状态转移函数，$\mathcal{R}: \mathcal{S}\times\mathcal{A}\to\mathbb{R}$ 为奖励函数，$\Omega$ 为观测空间，$O:\mathcal{S}\to\Delta(\Omega)$ 为观测发射概率，$\gamma\in[0,1)$ 为折扣因子。

最优策略 $\pi^*$ 必须最大化期望累积折扣回报：

$$\pi^{*} = \arg\max_{\pi}\;\mathbb{E}_{\pi}\left[\sum_{t=0}^{\infty}\gamma^{t} r_{t+1}\right]$$

由于底层状态不可观测，智能体依赖信念状态 $b_t$，并通过贝叶斯规则更新：

$$b_{t+1}(s') = \eta\, O(o_{t+1}\mid s')\sum_{s\in\mathcal{S}} T(s'\mid s, a_{t})\, b_{t}(s)$$

由于精确信念状态不可解析，作者将 $b_t$ 近似为观测历史 $o_{\le t}$ 与**图结构记忆** $M_t$ 的组合：

$$M_t = f_{\text{update}}(M_{t-1}, o_t, a_{t-1})$$

### 2.2 关键技术细节

**（1）Actor 生成阶段**：以冻结的 LLaMA-3-8B（4-bit NF4 量化）作为策略 $\pi_\theta$，提示构造为：

$$\text{Prompt}_{\text{Actor}} = \text{Concat}(\text{Goal}, H_t, \text{Serialize}(M_t))$$

$$(z_t, a_t) \sim \pi_\theta(z, a \mid \text{Prompt}_{\text{Actor}})$$

其中 $H_t = (o_1, a_1, o_2, a_2, \ldots, o_t)$ 为完整历史。$M_t$ 由 Graph Attention Network（GAT）维护，节点特征按如下规则更新：

$$h_i^{(l+1)} = \sigma\!\left(\sum_{j\in\mathcal{N}(i)} \alpha_{i,j}\, W^{(l)} h_j^{(l)}\right)$$

$$\alpha_{i,j} = \frac{\exp\!\big(\text{LeakyReLU}(a^{T}[Wh_i \,\|\, Wh_j])\big)}{\sum_{k\in\mathcal{N}(i)} \exp\!\big(\text{LeakyReLU}(a^{T}[Wh_i \,\|\, Wh_k])\big)}$$

Transformer 内部使用标准缩放点积注意力：

$$\text{Attention}(Q, K, V) = \text{softmax}\!\left(\frac{QK^{T}}{\sqrt{d_k}}\right)V$$

**（2）Critique 内部奖励机制**：定义内部奖励函数 $R_{\text{critique}}(o_t, z_t, a_t)$，由轻量级 Critic 模型 $f_\phi$ 输出连续评分：

$$R_{\text{critique}} = \sigma\!\big(f_\phi(o_t, z_t, a_t)\big)$$

Critic 以 JSON 格式输出逻辑检查、安全检查、0–1 评分与自然语言诊断。优化目标是因果交叉熵：

$$L(\phi) = -\sum_{i=1}^{L} \log P_\phi(y_i \mid y_{<i}, x)$$

若 $R_{\text{critique}} < \tau$（$\tau = 0.70$），候选动作被否决，Critic 的反馈追加到 Actor 上下文，强制 Actor 重新生成；每步最多 3 次重生。

**（3）执行阶段**：通过 Critic 的动作进入环境，得到稀疏环境奖励 $R_{\text{env}}$ 与新观测。整体优化目标为环境奖励与内部奖励的加权和：

$$J(\pi_\theta) = \mathbb{E}_{\tau\sim\pi_\theta}\!\left[\sum_{t=0}^{H} \gamma^{t}\big(R_{\text{env}}(s_t, a_t) + \lambda\, R_{\text{critique}}(o_t, a_t)\big)\right]$$

其中 $\lambda = 0.5$，$\gamma = 0.95$，最大步数 $H = 50$。

策略侧借鉴 PPO 的截断目标进行对齐：

$$L^{\text{CLIP}}(\theta) = \hat{\mathbb{E}}_t\!\left[\min\big(r_t(\theta)\hat{A}_t,\; \text{clip}(r_t(\theta), 1-\epsilon, 1+\epsilon)\hat{A}_t\big)\right]$$

其中 $r_t(\theta) = \pi_\theta(a_t\mid s_t) / \pi_{\theta_{\text{old}}}(a_t\mid s_t)$，优势估计由价值基线给出：

$$\hat{A}_t = R_t + \gamma V_\phi(s_{t+1}) - V_\phi(s_t)$$

### 2.3 算法流程

每步执行：① 融合观测 $o_t$ 与图记忆 $M_t$ 生成 Prompt；② Actor 采样 $(z_t, a_t)$；③ Critic 计算 $R_{\text{critique}}$；④ 若低于阈值则重生（≤ 3 次），否则执行；⑤ 接收环境奖励 $R_{\text{env}}$ 与新观测；⑥ 更新 $M_t$ 与历史。

## 8. 不足与局限

- **推理延迟代价明显**：单步 2.15 s（ReAct 仅 1.20 s），VRAM 9.4 GB、功耗 210 W，约为基线 1.8×，**不适合实时控制**（高速无人机、毫秒级机器人等）。
- **上下文窗口受限**：4,096 token 截断下，当 $H>100$ 步时出现"Lost in the Middle"现象，导致早期约束被遗忘、POMDP 假设失效。
- **Critic 自身可靠性问题**：若 Critic 欠训练或自身产生幻觉，可能误拒有效动作或误放无效动作，引发无限重生循环；论文承认 Critic 阈值缺乏自适应机制。
- **缺乏置信区间与统计检验**：500 episode 的对比未给出误差棒、p 值或多次随机种子，结论的统计稳健性有待验证。
- **基线覆盖不足**：未与 Reflexion、ToT/GoT、AutoGPT 等同样定位为"自校正/搜索型"的方法直接对比，难以判断 RLAW 相对同类方法的真正优势。
- **自建多模态平台透明度低**：第三个实验平台细节未充分披露，可能影响结果普适性。
- **奖励工程依赖**：$\lambda=0.5$、$\tau=0.70$ 等超参通过网格搜索得到，未分析其对不同任务难度与领域迁移的敏感性。
- **价值函数估计细节缺失**：仅提及"以 Bellman 方程为基础"但未展示 Critic 训练中具体的 TD 目标、回报计算与是否使用 GAE 等关键实现细节。
- **未在更开放的真实场景验证**：ALFWorld 与 WebShop 仍为受控仿真，向工业机器人、智能客服、数据库修改等高风险场景的迁移性未经验证。
