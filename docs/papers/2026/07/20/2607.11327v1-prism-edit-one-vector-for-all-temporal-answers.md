## 摘要
模型编辑使大语言模型(LLMs)无需重新训练即可保持最新，但时序事实暴露了当前主流"定位-编辑"范式的局限性：更新并非总是替换。当一个事实发生变化时，新答案应成为当前答案，而旧答案在历史时间上下文中可能仍然正确。基于这一洞察，我们使用因果追踪表明，LLMs已通过两阶段内部计算支持这种区分：早期MLP层检索与时间无关的主语表征，后续层用时间上下文对其进行调制以产生时间正确的答案。受此发现启发，我们提出了PRISM Edit，它在多个时间上下文中优化单个多义表征，并利用模型固有的调制路径将其路由至时间正确的预测，无需任何架构修改。我们在TimeConflict——一个我们新提出的时序编辑基准——以及经过时序增强的CounterFact上进行评估。PRISM Edit平均比最佳基线提升+23.3的时间一致性(TC)和+33.7的当前相对时间得分(CRS)，同时速度提升超过2倍。代码和数据已公开于 https://github.com/AnonymousStudy972/PRISM-Edit。

## Abstract
Model editing keeps large language models (LLMs) up to date without retraining, but temporal facts expose a limitation of the prevailing locate-and-edit paradigm: an update is not always a replacement. When a fact changes, the new answer should become current while the old answer may remain correct in historical time contexts. Building on this insight, we use causal tracing to show that LLMs already support this distinction via a two-stage internal computation: early MLP layers retrieve a time-agnostic subject representation, and later layers modulate it with temporal context to yield the time-correct answer. Motivated by this finding, we introduce PRISM Edit, which optimizes a single polysemous representation across temporal contexts and leverages the model's inherent modulation pathway to route it to temporally correct predictions, without any architectural modification. We evaluate on TimeConflict, a new temporal editing benchmark we introduce, and on temporally augmented CounterFact. PRISM Edit improves over the best baseline by +23.3 Temporal Consistency (TC) and +33.7 Current Relative-time Score (CRS) on average while being more than 2x faster. Code and data are publicly available at https://github.com/AnonymousStudy972/PRISM-Edit.

## 一、核心问题与研究背景

- **核心问题**：现有大语言模型知识编辑主要遵循"定位—编辑"(locate-and-edit)范式，将事实更新视为对旧答案的**整体替换**。然而**时序事实**（temporal facts）具有多义性：新答案应成为当前正确答案，而旧答案在历史时间语境下仍然成立，因此编辑不应是简单替换。
- **关键挑战**：传统编辑范式无法在同一主语—关系对 $(s,r)$ 下同时保留"当前答案"与"历史答案"，导致编辑后历史回忆（historical recall）崩塌。
- **已有方案的不足**：
  - METO（Yin et al., 2024）将时序拆分为多次独立编辑，忽略了模型内在的时间处理机制；
  - SPIKE（Zhao et al., 2026）按时间标记稀疏注入参数，需要额外存储与路由开销；
  - 外部记忆类方法（GRACE、WISE）避开参数修改但引入辅助模块与检索开销。
- **本文立场**：先理解模型内部如何解析时间歧义，再设计与该机制**协同**而非对抗的编辑方法。

## 二、方法论：PRISM Edit

### 2.1 核心思想
借助**因果追踪（causal tracing）**对 $(s,r,o,t)$ 四元组进行分析，发现 LLM 内部对时序知识采用**两阶段级联机制**：

1. **早期 MLP 层（L4–L8）在主语末 token 处检索时间无关的主体表征**——IE 峰值在 L4 MLP（IE=0.549）；
2. **时间信息虽更早到达（约 L10–15 注意力层），但其调制作用发生在上层（约 L20+）**，通过后层注意力对同一主体信号做时间调制得到时序正确答案。

由此得到**核心结论**：现有 locate-and-edit 方法所编辑的位置（主语末 MLP）在该层输入 $k_{\text{new}}$ 与 $k_{\text{old}}$ 几乎相同，因此任何线性更新 $\Delta W$ 都满足：
$$\|\Delta W k_{\text{new}} - \Delta W k_{\text{old}}\| \leq \|\Delta W\| \cdot \|k_{\text{new}} - k_{\text{old}}\| \approx 0$$

这意味着编辑层**几何上无法区分时间**——这是表示空间的根本限制，而非优化器的失败。

### 2.2 时序多义性（Temporal Polysemy）
PRISM Edit 形式化"时序多义"概念：一个写入值应支持多个上下文条件下的不同读出：
$$v^* \xrightarrow{c_{t_1}} o_1, \quad v^* \xrightarrow{c_{t_2}} o_2, \ldots$$
这模仿了语言学中的一词多义——模型上层注意力路径已有此路由能力，PRISM Edit 只需优化 $v^*$ 使该路径正确路由即可，无需显式路由器。

### 2.3 联合优化目标
对同一 $(s,r)$ 对、$N$ 个时间上下文 $\{t_i, o_i\}_{i=1}^N$，求解：
$$\delta^* = \arg\min_{\delta} \sum_{i=1}^{N} \lambda_i L_i(\delta) + \Omega(\delta), \quad v^* = v_0 + \delta^*$$

其中：
$$L_i(\delta) = -\log P_{G_{v_0+\delta}}\left[o_i \,\big|\, p_i(s,r,t_i)\right]$$

最常见的"当前—历史"二状态情形实例化为：
$$\delta^* = \arg\min_{\delta}\; L_{\text{new}} + \lambda_{\text{old}} L_{\text{old}} + L_{\text{bare}} + \Omega(\delta)$$

$L_{\text{bare}}$ 约束**无时间标记的提示**默认输出新答案，$\Omega(\delta)$ 为局部性约束与范数正则。

### 2.4 算法流程（Algorithm 1）
1. 对每条编辑 $e_b$，构造多时间上下文数据集 $D_b$；
2. 取出目标层 $\ell^*$ 的初始隐藏态 $v_{0,b}$；
3. 通过上述联合优化求解 $\delta_b^*$，得到多义向量 $v_b^* = v_{0,b} + \delta_b^*$；
4. 使用类似 AlphaEdit 的**零空间约束最小二乘**在编辑层 $L$ 上求解权重更新 $\Delta W_{\ell_w}$：
$$\Delta W_{\ell_w} = R_{\ell_w} K_{\ell_w}^\top P_{\ell_w} M_{\ell_w}^{-1}$$
其中 $M_{\ell_w} = P_{\ell_w}(C_{\ell_w} + K_{\ell_w} K_{\ell_w}^\top) + \eta I$。

## 六、主要结论与发现

1. **机制发现**：LLM 内部对时序事实采用"早层 MLP 检索主体 → 后期注意力调制时间"的**两阶段级联机制**，这是首个对 $(s,r,o,t)$ 四元组的因果追踪研究。
2. **几何局限**：传统编辑层无法区分新旧时间（$\|k_{\text{new}} - k_{\text{old}}\| \approx 0$），因此 METO 等多编辑方案在该层失效是必然的。
3. **性能领先**：PRISM Edit 在三个数据集、两个模型上**所有指标均第一**；平均较最强基线提升 **+23.3 TC** 与 **+33.7 CRS**。
4. **速度优势**：平均编辑时间 5.44 s/record（Llama-3），较 AlphaEdit 快 **2.8×**、较 METO 快 **5.2×**。
5. **机制可视化**：PCA 轨迹显示编辑后模型在约 L20 处出现表征分叉（bifurcation），与机制假设一致。
6. **通用原则**："对齐编辑与模型内在计算"比"施加外部结构"更有效——为其他上下文条件编辑任务提供方法论启示。
