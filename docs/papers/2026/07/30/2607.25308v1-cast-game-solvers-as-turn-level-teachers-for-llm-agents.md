## 摘要
训练大语言模型（LLMs）在长视野游戏中行动是迈向通用决策的有前景的一步，然而基于可验证奖励的强化学习（RLVR）依赖于稀疏的最终奖励，几乎无法揭示哪些决策决定了成功。更密集的过程信号可以提供这种缺失的轮次级归因，但现有来源难以同时保持低成本和准确性。我们观察到游戏求解器状态值的变化揭示了某个动作是否将状态向成功推进。基于这一洞察，我们提出了CAST（Credit Assignment from Solver Teachers，来自求解器教师的信用分配），它将这些价值变化转化为求解器优势，并作为轮次级信号注入RLVR中。我们进一步证明，在软最优求解器假设下，最大化求解器优势等价于从求解器进行在策略蒸馏，只需标量值而非教师logits。在推箱子（Sokoban）、扫雷（Minesweeper）和Rush Hour游戏中，CAST在领域内和未见难度评估下，在每一款游戏上都优于所有训练基线，并在ALFWorld和WebShop上取得了最高的平均零样本性能。我们的代码可在 https://github.com/Wloner0809/CAST 获取。

## Abstract
Training large language models (LLMs) to act in long-horizon games is a promising step toward generalist decision-making, yet reinforcement learning with verifiable rewards (RLVR) relies on sparse final rewards that reveal little about which decisions determine success. Denser process signals could supply this missing turn-level credit, but existing sources are hard to keep both cheap and accurate. We observe that changes in a game solver's state value reveal whether an action advances the state toward success. Building on this insight, we propose CAST (Credit Assignment from Solver Teachers), which converts these value changes into solver advantages and injects them into RLVR as turn-level signals. We further show that, under a soft-optimal solver assumption, maximizing the solver advantage is equivalent to on-policy distillation from the solver, requiring only scalar values rather than teacher logits. Across Sokoban, Minesweeper, and Rush Hour, CAST outperforms all trained baselines on every game under both in-domain and unseen-difficulty evaluation and achieves the highest average zero-shot performance on ALFWorld and WebShop. Our code is available at https://github.com/Wloner0809/CAST.

## 1. 核心问题与研究动机

- **长程博弈中的稀疏奖励困境**：在 Sokoban、Minesweeper 等经典博弈中训练 LLM 智能体时，RLVR 仅依赖 0/1 终局奖励（公式 $R(\tau) = r_T = \mathbb{1}\{s_T \in \mathcal{S}_{\text{solved}}\}$），但长轨迹中早期决策的影响往往延迟显现，导致无法判断"哪一步真正决定胜负"，形成**过程级信用分配**的瓶颈。
- **现有过程信号的代价与可靠性矛盾**：已有方法（如搜索式过程标注 GiGPO、过程奖励模型 PRM、Tree-search 推理等）在计算成本、监督获取、信号可靠性三者间难以兼得，且往往依赖昂贵 rollout 或额外训练的 verifier。
- **核心洞察**：论文观察到博弈**求解器**（A*、反向 BFS、约束求解等）天然能为任意状态 $s$ 提供**成本剩余** $N(s)$（即从该状态获胜最少还需多少步），其变化 $N(s_t) - N(s_{t+1})$ 即可精确刻画"该动作是否推进了走向胜利"。这把稀疏终局奖励转成了廉价、稠密且准确的轮次级信号。
- **与 SFT 监督的本质差异**：在求解器专家轨迹上做 SFT 仅暴露 LLM 于"专家访问过的状态"，一旦 LLM 在交互中偏离就失去指导；因此需要在**自策略（on-policy）**下让求解器为 LLM 实际访问的状态打分。

### 2.1 求解器优势（Solver Advantage）的构造

- 将博弈建模为有限步 MDP $\mathcal{M}=(\mathcal{S},\mathcal{A},P,r,H)$，对最短路博弈定义势函数 $\Phi(s)=-N(s)$，从而 $V^{\pi_{\text{Solver}}}(s)=-N(s)$。
- 对单步动作定义：
  $$Q^{\pi_{\text{Solver}}}(s_t,a_t) = -1 + \mathbb{E}_{s_{t+1}}\!\left[V^{\pi_{\text{Solver}}}(s_{t+1})\right]$$
  $$A^{\pi_{\text{Solver}}}(s_t,a_t) = Q^{\pi_{\text{Solver}}}(s_t,a_t) - V^{\pi_{\text{Solver}}}(s_t) = -1 + N(s_t) - \mathbb{E}_{s_{t+1}}[N(s_{t+1})]$$
- 由于最优动作下 $A^{\pi_{\text{Solver}}}=0$（不便作为正信号），通过 **+1 平移**得到"位移型"求解器优势：
  $$\tilde{A}^{\pi_{\text{Solver}}}(s_t,a_t) = N(s_t) - \mathbb{E}_{s_{t+1}}[N(s_{t+1})]$$
  其中最优动作得 $+1$，原地踏步得 $0$，陷入死局惩罚为 $-N(s_t)$。

### 2.2 两步轻量化信号塑形（Signal Shaping）

- **asinh 压缩**：解决重尾分布（绝大多数动作 $|A|=0,\pm1$，死局惩罚却可达数十）：
  $$g(x)=\operatorname{asinh}(x)=\ln\!\left(x+\sqrt{x^{2}+1}\right)$$
  小信号近似线性，保留分辨率；大信号仅对数增长，缓解极端值主导。
- **批量级 RMS 归一化**：消除跨游戏、跨难度的尺度差异，但**不减去均值**，以保留"零 = 无进展"的语义：
  $$h(x)=\frac{g(x)}{\operatorname{RMS}_B(g)+\epsilon},\quad \operatorname{RMS}_B(g)=\sqrt{\frac{1}{|B|}\sum_{(i,t)\in B} g\!\left(\tilde{A}^{\pi_{\text{Solver}}}_{i,t}\right)^{2}}$$

### 2.3 与 GRPO 的融合

- 在 GRPO 的轨迹级 outcome 优势上**叠加**塑形后的求解器优势，逐 token 广播：
  $$\hat{A}_{i,t} = \hat{A}^{\text{outcome}}_i + \alpha\cdot h\!\left(\tilde{A}^{\pi_{\text{Solver}}}_{i,t}\right)$$
- 替换 GRPO 裁剪目标 $\mathcal{J}_{\text{GRPO}}(\theta)$ 中的 $\hat{A}_i$，使终局奖励继续锚定全局信号，求解器信号逐回合精修。

### 2.4 核心定理（Theorem 2.1：隐式目标等价性）

- **假设**：求解器为软最优策略（Ziebart/Haarnoja 等的最大熵形式），即
  $$\pi_{\text{Solver}}(a\mid s)\propto \exp\!\left(Q^{\pi_{\text{Solver}}}(s,a)/\tau\right)$$
  且 $|A^{\pi_{\text{Solver}}}|\lesssim 1$，GRPO 提供无偏任务梯度，PPO 式冻结访问分布。
- **结论**：上述训练规则的策略梯度更新方向等价于优化
  $$J_{\text{ours}}(\theta)=\underbrace{\mathbb{E}_{s_0\sim\mu}\!\left[V^{\pi_\theta}_{\text{task}}(s_0)\right]}_{\text{任务回报}} \;-\; \beta\,\underbrace{\mathbb{E}_{s\sim d_{\pi_\theta}}\!\left[H\!\left(\pi_\theta(\cdot\mid s),\,\pi_{\text{Solver}}(\cdot\mid s)\right)\right]}_{\text{交叉熵蒸馏}}$$
  $$\beta=\frac{\alpha\,\tau}{\sqrt{2}\,\big(\operatorname{RMS}_B(g)+\epsilon\big)}$$
- **关键性质**：
  1. **Logit-free OPD**：传统 LLM 蒸馏需要教师完整 token 分布，而 $A^{\pi_{\text{Solver}}}=\tau\log\pi_{\text{Solver}}$ 意味着**单个标量即编码教师偏好**，无需 logits。
  2. **学生可超越教师**：每状态最优策略有闭式解
     $$\pi^{*}(a\mid s)\propto \pi_{\text{Solver}}(a\mid s)\,\exp\!\left(\tfrac{1}{\beta}A^{\pi_\theta}_{\text{task}}(s,a)\right)$$
     当 $\beta\to\infty$ 时退化为教师，$\beta$ 有限时任务优势可指数级"倾斜"先验，使学生超越教师。
  3. 利用 Performance Difference Lemma 可证明次优性上界为 $O(H\epsilon_\pi)$（线性于 $H$），优于行为克隆的 $O(H^{2}\epsilon_\pi)$。

## 3. 实验设计

### 3.1 数据集与基准

- **训练域**：三款程序生成的经典博弈——
  - **Sokoban**（长期规划）：ID 为 $6\times 6$+2 箱，Unseen 为 $7\times 7$+3 箱。
  - **Minesweeper**（部分可观测推理）：ID 为 $6\times 6$+7 雷，Unseen 为 $7\times 7$+10 雷，含固定的"首点揭示"消除开局盲猜。
  - **Rush Hour**（约束组合搜索）：ID 为 $6\times 6$+7 车，Unseen 为 $6\times 6$+9 车。
  - 每档难度各 200 个保留测试实例，按 board hash 去重保不与训练集重叠。
- **零样本 OOD 域**：不微调直接在 **ALFWorld**（具身家务，6 类任务、30 turn 上限）与 **WebShop**（在线购物 500 测试指令、30 turn 上限）评估。
- **评估指标**：每实例 4 条独立 rollout 的 Avg@4 成功率；Sokoban/Minesweeper ID 30 turn、Unseen 40 turn；Rush Hour 20 turn；最大响应 16384 token。

### 3.2 基线对比

- **训练基线**（共享 Qwen3-4B-Instruct-2507 骨干、相同终局奖励）：
  - **GRPO**（outcome-only）、**GSPO**、**DAPO**（CAST 的 backbone，关闭求解器信号后即 DAPO）。
  - **GiGPO**（Feng et al., 2026，process-level RL 基线）。
- **无训练参考**：基模型 + ReAct prompt；以及 Gemini-2.5-Flash/Pro、Claude-Sonnet-4.5/4.6、Claude-Opus-4.5/4.6 等闭源模型同 prompt 设置。

### 3.3 实现要点

- 三博弈共享同一 ReAct 多回合接口，但状态编码与动作空间各异（详见 Appendix C.2 系统提示）。
- 求解器实现：
  - Sokoban：A* + 最小代价 box-to-target 启发式。
  - Minesweeper：约束推理 + 全局雷概率的精确推断。
  - Rush Hour：多源反向 BFS 预计算可达状态精确最短路表（超大态空间回退 IDA*）。
- 主实验在 DAPO 骨架上接入求解器优势，$\alpha=0.1$，batch size 16，每 prompt 8 rollout，最大响应 16384 token。

## 4. 资源与算力

## 6. 主要结论与发现

- **In-domain & Unseen-difficulty**：在 Sokoban、Minesweeper、Rush Hour 三款游戏上，CAST 在两种难度设置下的 Avg@4 **均取得所有训练方法中的最佳**（ID 平均 62.1 / Unseen 平均 28.4，对比 DAPO 44.7 / 18.7；Minesweeper ID 相对最强训练基线 +14.9）。
- **样本效率**：达到 DAPO 峰值验证性能所需的步数缩减为 1.7–2.0×（Sokoban 200→120、Minesweeper 400→200、Rush Hour 240→140）。
- **零样本 OOD 迁移**：
  - ALFWorld 域平均 **37.9**（次优 DAPO 30.4），WebShop **22.7**（次优 GSPO 17.9），总体 Overall **30.3**。
  - WebShop 案例：基模型在 walnut 颜色约束下直接购买错误商品；CAST 先识别"无 walnut→拒绝购买→再次搜索→在颜色页选中 walnut 后再购买"，体现求解器信号训练出的"约束检查 + 错误恢复"行为。
- **组件贡献**：$\alpha=0.1$ 为最优权衡（太小稀释信号，太大挤压稀疏终局目标）；asinh 与 RMS 缺一不可——去掉 asinh 收敛最慢且最低，去掉 RMS 训练后期噪声大。
- **可行性**：精确求解器只占总训练步 73 ppm；用 DQN 值网络替代精确求解器后仍接近精确版性能，并明显优于其他训练基线，**支持该方法可迁移到无精确求解器的标准 RL 场景**。

## 7. 方法与实验设计的优点

- **理论与工程紧密结合**：Theorem 2.1 在 4 条可检验假设下把"标量优势"严格等价于"交叉熵蒸馏"，并给出 $\beta$ 的精确表达式与闭式最优策略、可超越教师的机制，性能上界 $O(H\epsilon_\pi)$ 的证明也较完整。
- **信号廉价又稠密**：利用现成博弈求解器即可在每环境步 $8.4\%$ 时间内得到轮次级监督；与 PRM/搜索式过程信号相比，几乎无额外训练成本。
- **细节处理扎实**：asinh 保符号、RMS 不去均值、shifted advantage 把死局惩罚可计算化（$-N(s_t)$）、detach 死局状态为有限惩罚，以及 PPO 式 frozen-visitation surrogate 的明确假设。
- **泛化证据多维**：同时展示 ID、Unseen-difficulty、跨域零样本，且 WebShop 案例将"行为变化"具体化，增强说服力。
- **可扩展性强**：附录展示 DQN 替代精确求解器的等价效果，证明方法不依赖人工硬编码求解器，可推广到经典 RL/Deep RL 场景。

## 8. 不足与局限

- **依赖高质量求解器**：核心信号来自精确或近精确求解器，对没有现成求解器的复杂任务（如开放式对话、跨域具身任务）难以直接复用；DQN 替代只在 Rush Hour 验证，覆盖单一。
- **Minesweeper 上的弱项**：Unseen-difficulty 上仅 11.0，与 DAPO（7.3）相比领先但绝对值低，提示部分可观测 + 概率性局面下求解器信号仍不够强。
- **超参与算力披露不足**：$\alpha$ 默认 $0.1$ 但其最优性只在 Sokoban 上做了扫描；其余游戏未给出 $\alpha$ 调优；GPU 型号/数量、训练总时长、总浮点算力等**未明确披露**。
- **OOD 评估可能受动作空间差异影响**：ALFWorld/WebShop 与博弈共享多回合 ReAct 接口但动作空间差异较大，文中未做更细粒度的"动作结构相似性"分析；零样本收益的来源究竟是"求解器诱导的规划能力"还是"多回合 RL 本身"难以彻底剥离。

- **单模型规模**：仅报告 Qwen3-4B-Instruct-2507 上的结果，未在更大骨干（如 7B/13B）或其他模型族上验证，规模扩展性未知。
- **闭源模型评估协议不完全对齐**：开源用 T=0.6、闭源用 T=1.0，且 prompt 可能略有差异，可能放大或缩小对比差距；同时闭源模型未给出多 run 误差带。
- **过程信号噪声未被深入讨论**：求解器返回的最短路代价假设博弈环境完全可建模，但实际 MDP 转移若存在不可建模噪声（如环境随机化、奖励漂移），$N(s)$ 可能失真，论文未做对应鲁棒性实验。
