## 摘要
构建能够对玩家动作做出连贯响应的交互式世界，长期以来一直是计算机图形学、游戏和人工智能共同追求的目标。近期涌现的视频生成模型提供了一条由数据驱动的实现路径，通过以用户动作为条件来预测未来的观察画面，并日益被视为潜在的下一代游戏引擎。然而，要实现真正可交互的游戏世界，需要具备以下特性：交互结果能够在不断演化的游戏条件下遵循规则、所产生的后果能够在长时跨度上持续存在、以及生成循环能够以实时方式运行。传统游戏引擎通过一个循环的动作–状态–观察回路来实现这些特性：在该回路中，玩家动作依据预定义规则更新一个显式的游戏状态，然后从该状态渲染出观察画面。本文将这一回路作为组织视角，从四个维度审视交互式游戏世界建模：玩家动作控制、游戏状态动力学、状态–观察的持续性，以及实时交互式生成。在每个维度上，我们从交互式游戏世界所需的能力出发，将现有方法归入若干具有代表性的方法家族，并讨论每个家族的优势与权衡。作为对上述分析的补充，我们还针对《黑神话：悟空》构建了一个可扩展的数据引擎，采集了超过 90 小时的游玩数据，其中包含与画面帧对齐的玩家动作、真实游戏状态以及视觉观察画面，并附有结构化与语义化标注，可作为面向状态感知的游戏世界建模的资源。我们希望本文能够清晰呈现该领域当前的研究现状，并推动交互式游戏世界的进一步发展。

## Abstract
Building interactive worlds that respond coherently to player actions has long been a shared goal of computer graphics, games, and artificial intelligence. Recent video generative models provide a data-driven route toward this goal by predicting future observations conditioned on user actions, and are increasingly regarded as potential next-generation game engines. Realizing a genuinely interactive game world, however, requires interaction outcomes that follow rules over evolving game conditions, consequences that persist over long horizons, and a generation loop that operates in real time. Conventional game engines realize these properties through a recurrent action-state-observation loop, in which player actions update an explicit game state according to predefined rules and observations are rendered from the resulting state. Taking this loop as an organizing lens, this paper examines interactive game world modeling along four dimensions: player action control, game state dynamics, state-observation persistence, and real-time interactive generation. For each dimension, we start from the capabilities required by an interactive game world, group existing approaches into representative families, and discuss the strengths and trade-offs of each family. Complementing this analysis, we present a scalable data engine for Black Myth: Wukong that collects over 90 hours of gameplay with frame-aligned player actions, ground-truth game states, and visual observations, together with structured and semantic annotations, as a resource for state-aware game world modeling. We hope this paper offers a clear picture of where the field stands and fosters progress toward interactive game worlds.

## 一、核心问题与研究动机

- **研究背景**：构建能对玩家动作做出连贯响应的交互式世界，是计算机图形学、游戏与 AI 的共同长期目标。近年来，以 Sora、Wan、HunyuanVideo 等为代表的视频生成模型展示了"由数据驱动学习世界规律"的可能性，并被广泛视为下一代游戏引擎的候选方案。
- **关键差距**：现有视频生成模型虽然在视觉表现上日趋逼真，但要成为真正的"游戏引擎"，仍需满足三项核心要求——
  1. 交互结果需在不断演化的游戏条件下遵循规则（如攻击判定受 stamina、cooldown、boss 阶段等状态约束）；
  2. 交互后果需在长时跨度上保持一致（如离屏后 boss 进入二阶段、伤害值不可恢复）；
  3. 生成循环需以实时速率运行。
- **核心论点**：传统游戏引擎通过 **动作–状态–观察（action–state–observation）循环** 实现上述特性——玩家动作依据预定义规则更新一个**显式的游戏状态**，再从该状态渲染出观察画面。现有交互式世界模型多将状态隐式地"纠缠"在像素中，缺失对显式状态的建模能力，导致规则一致性、长时持久性与实时可控性难以兼得。

## 二、方法论：核心思想与框架

### 2.1 整体框架：四维度组织视角

论文**并非提出单一新模型**，而是提出一个**统一的分析框架**，将交互式游戏世界建模沿四个关键维度组织：

| 维度 | 对应循环环节 | 核心问题 |
|------|------------|---------|
| ① 玩家动作控制（Player Action Control） | Action | 玩家意图如何在驱动生成前被表征？ |
| ② 游戏状态动力学（Game State Dynamics） | State | 状态以何种形式存在与演化？ |
| ③ 状态–观察的持久性（State-Observation Persistence） | State→Observation | 长时跨度下生成结果如何与状态保持一致？ |
| ④ 实时交互式生成（Real-Time Interactive Generation） | Loop Latency | 如何在交互速率内完成输入到画面的闭环？ |

### 2.2 每个维度的方法家族分类

**① 玩家动作控制**
- 几何轨迹族（Camera-controlled）：以相机位姿/光线作为条件信号（MotionCtrl、CameraCtrl、CamCo、CamI2V），或将相机几何作为架构先验（CamAsRelPE、Unified Camera PE）；精确但远离自然玩家输入。
- 运动信号族（Motor signals）：设备定义的动作（Oasis、Matrix-Game 系列、SCOPE、Hunyuan-GameCraft）或自学的 latent action（Genie、Playable Video、Olaf-World 等）；忠于玩家原生操作，但难以表达组合语义。
- 语义事件族（Semantic events）：以自然语言表达意图（GameGen-X、Yume-1.5、Pandora、PAN、Promptable Game Models、Incantation、ReactiveGWM、ActWorld）；表达力强，但随粒度增加计算成本上升。

**② 游戏状态动力学**
- 状态纠缠于观察：Open-Sora、Wan、LTX-2、GameNGen、DIAMOND、WHAM、Oasis、Matrix-Game——无独立状态，世界规则隐式地由像素相关性学习。
- 状态为学习潜变量：GameGAN、Dreamer 系列（用于 RL 与规划）、NavWM、StateSpaceDiffuser 等——无需标注、可扩展，但不可解释、且对非视觉因果变化（如根据 HP 决定击杀 vs 击伤）不可靠。
- 状态为显式描述：LLM 作为文本世界模拟器、WildWorld 的逐帧状态标注、EgoCS-400K、AnimeGamer 的逐步属性预测——可读可验证，但需大规模状态标注数据，与生成回路的整合仍待探索。

**③ 状态–观察的持久性**
- 记忆为存储的观察（Memory as stored observations）：
  - 时序索引：渐进压缩、嵌入化摘要、递归自回归扩散（RAD）、可学习检索（MemLearner、Mixture of Contexts）等；
  - 空间索引：FOV 重叠检索、相机位姿–时间戳索引（WorldMem、WorldPack）、压缩注意力缓存（RELIC）、surfel 锚定（VMem）；
  - 局限：环境动态变化时，历史拷贝无法代表当前真值（如建筑物被技能摧毁后，回访时可能复原）。
- 记忆为对当前的估计（Memory as estimates of the present）：
  - ActWorld 保留事件过渡帧、Hybrid Memory 跟踪离屏动态主体、流等变模型传播未观察区域、PERSIST 在潜 3D 状态上演化并生成引导帧、AnimeGamer 预测显式状态；
  - 局限：高频交互下的小幅变化会累积成显著偏差，可靠的逐步更新决策缺乏原则性依据。

**④ 实时交互式生成**
- 降低生成延迟（缩短"输入→画面"时间）：
  - 步数缩减蒸馏：CausVid、Causal Forcing++、Diagonal Distillation、Astrolabe 等；
  - 流式生成：Rolling Forcing、HiAR、Streaming-aware 蒸馏、Self-Resampling 等；
  - 系统级优化：minWM、InSpatio、硬件–算法协同设计（SGGE）；
  - 共同局限：只缩短从输入到画面路径，未涉及"效果应在何时出现"。
- 降低条件延迟（让条件随播放实时切换）：
  - Yume-1.5 切换文本控制的世界事件、MagicWorld 在键盘导航下演化场景、DreamX-World 调节可组合事件指令；
  - 局限：触发结果的时机仍由生成先验决定，缺乏与游戏规则/动画定义时刻的对齐机制。

### 2.3 关键设计洞见（贯穿全文的"方法论"结论）

- **控制延迟 vs. 结果延迟的辨析**：响应感（control latency）需最小化以保证"game feel"，但结果时机（consequence latency）需遵循规则的起手–有效–收招（startup–active–recovery）节律；二者不能混为一谈。
- **"从像素到状态"的转向**：现有方法的盲点（规则性、持久性、节律性）共同指向"游戏状态显式化"这一未解的枢纽。
