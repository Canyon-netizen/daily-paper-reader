## 摘要
我们研究 $N$ 人非合作随机微分博弈的连续时间强化学习问题。每个参与者采用熵正则化的探索策略；在给定其他参与者行动的条件下，最优响应为 Gibbs 分布，而纳什均衡要求这 $N$ 个条件分布联合相容。我们证明，自然的均衡概念——同时最大化 Hamiltonian——与该相容性等价，并建立了以最优 $q$-函数上可计算的交叉偏导准则表示的充要条件。对于解耦博弈和对称博弈，纳什均衡无条件存在。当相容性不成立时，坐标路径积分的构造给出一个近似相关均衡，并具有显式的二次 KL 散度界，该界在探索权重 $γ\to\infty$ 时局部一致地趋于零。$N$ 人博弈的 $q$-函数框架推广了文献 [21] 的单智能体 $q$-学习理论，其弱鞅刻画为无模型的同策略和离策略算法提供了理论依据。该框架可推广至遍历（无限时间）情形，并保持相同的局部一致渐近收敛率 $O_R(1/γ)$。

## Abstract
We study continuous-time reinforcement learning for $N$-player noncooperative stochastic differential games. Each player adopts an entropy-regularized exploratory policy; given the others' actions, the optimal response is a Gibbs distribution, and a Nash equilibrium requires these $N$ conditional distributions to be jointly compatible. We prove that the natural equilibrium concept -- simultaneous Hamiltonian maximization -- is equivalent to this compatibility, and establish a necessary and sufficient condition expressed as a computable cross-partial criterion on the optimal $q$-functions. Nash equilibria exist unconditionally for decoupled and symmetric games. When compatibility fails, a coordinate path integral construction yields an approximate correlated equilibrium with explicit quadratic KL-divergence bounds that vanish locally uniformly as the exploration weight $γ\to\infty$. A $q$-function framework for the $N$-player game extends the single-agent $q$-learning theory of [21], with weak martingale characterizations motivating model-free on-policy and off-policy algorithms. The framework extends to the ergodic (infinite-horizon) setting with the same locally uniform $O_R(1/γ)$ asymptotic rates.

$$dX_t^i = \tilde{b}^i(t, X_t, \pi_t)dt + \tilde{\sigma}^i(t, X_t, \pi_t)dW_t^i$$
其中均值化系数为：
$$\tilde{b}^i(t, x, \pi) := \int_{U^N} b^i(t, x, u)\pi(u;t,x)du, \quad \tilde{\sigma}^i(t, x, \pi) := \sqrt{\int_{U^N} [\sigma^i(t,x,u)]^2 \pi(u;t,x)du}$$

玩家 $i$ 的性能函数引入**Shannon 熵正则化** $-\gamma_i \log \pi_i$（$\gamma_i>0$ 为探索权重）：
$$\tilde{J}^i(t,x;\pi) := \mathbb{E}\left[\int_t^T e^{-\beta_i(s-t)}\int_U [f^i(s,X_s,u^i) - \gamma_i\log\pi_i(u^i;s,X_s)]\pi_i(u^i;s,X_s)du^i ds + e^{-\beta_i(T-t)}g^i(X_T)\right]$$

### 2.2 条件最优策略与 Gibbs 分布

**HJB 方程**（条件于其他玩家动作 $u^{-i}$）：
$$0 = \partial_t \tilde{V}^i(t,x;u^{-i}) - \beta_i\tilde{V}^i(t,x;u^{-i}) + \sup_{\pi_i \in \mathcal{P}(U)} \int_U [H^i - \gamma_i \log\pi_i]\pi_i du_i$$
其中 Hamiltonian 为：
$$H^i(t,x,u^i,u^{-i},p,A) := \sum_{k=1}^N \left[b_k(t,x,u)p_k + \frac{1}{2}\sigma_k(t,x,u)^2 A_{k,k}\right] + f^i(t,x,u^i)$$

**条件最优策略**为 Gibbs 分布：
$$\pi_i^*(u^i; t,x,u^{-i}) \propto \exp\left\{\frac{1}{\gamma_i} H^i(t,x,u^i,u^{-i},\partial_x \tilde{V}^i, \partial_x^2 \tilde{V}^i)\right\}$$

### 2.3 兼容性条件（核心）

**定义**：纳什均衡存在的充要条件是 N 个条件最优策略 $\pi_1^*, \ldots, \pi_N^*$ 存在一个联合密度 $\psi \in \mathcal{P}(U^N)$ 使得：
$$\pi_i^*(u^i; t,x,u^{-i}) = \frac{\psi(u)}{\int_U \psi(u)du^i}, \quad \forall i=1,\ldots,N$$

**三大等价条件**（Theorem 13）：
- **(1)** 兼容联合密度存在；
- **(2)** $\phi$-因子化：存在正函数 $\phi_i(u^{-i})$ 使得 $\pi_i^*(u^i;u^{-i})\cdot\phi_i(u^{-i}) = \pi_j^*(u^j;u^{-j})\cdot\phi_j(u^{-j})$；
- **(3)** **交叉偏导准则**（可计算）：
$$\frac{1}{\gamma_i}\frac{\partial^2 q_i^*}{\partial u_j \partial u_i}(t,x,u) = \frac{1}{\gamma_j}\frac{\partial^2 q_j^*}{\partial u_i \partial u_j}(t,x,u), \quad \forall i \neq j$$

其中 $q_i^*$ 为最优 q-函数，定义为 $q_i^* = \partial_t \tilde{V}^i + H^i - \beta_i \tilde{V}^i$。

**关键等价定理**：Theorem 12 证明**自然均衡**（同时最大化所有 Hamiltonian，定义 9）与**兼容性**（条件最优策略的联合相容性，定义 10）严格等价。

### 2.4 交叉偏导的分解（Proposition 17）

$$\frac{\partial^2 q_i^*}{\partial u_j \partial u_i} = \underbrace{\sum_{k=1}^N \left[\frac{\partial^2 b_k}{\partial u_j \partial u_i}(\nabla_x \tilde{V}^i)_k + \left(\frac{\partial\sigma_k}{\partial u_i}\frac{\partial\sigma_k}{\partial u_j} + \sigma_k \frac{\partial^2 \sigma_k}{\partial u_j \partial u_i}\right)(D_x^2 \tilde{V}^i)_{k,k}\right]}_{\text{直接效应（direct effect）}} + \underbrace{\sum_{k=1}^N \left[\frac{\partial b_k}{\partial u_i}\frac{\partial(\nabla_x \tilde{V}^i)_k}{\partial u_j} + \sigma_k\frac{\partial\sigma_k}{\partial u_i}\frac{\partial(D_x^2 \tilde{V}^i)_{k,k}}{\partial u_j}\right]}_{\text{间接效应（indirect effect）}}$$

### 2.5 大 γ 渐近分析（Proposition 21）

策略收敛到均匀分布的速率（局部一致）：
$$\sup_{(t,x,u)\in[0,T]\times B_R \times U^N} \left|\pi_i^*(u^i|u^{-i};t,x) - \frac{1}{|U|}\right| = O_R\left(\frac{1}{\gamma_i}\right)$$

兼容性间隙消失的速率：
$$\max_{i\neq j} \sup_{(t,x,u)\in[0,T]\times B_R \times U^N} \left|\frac{1}{\gamma_i}\frac{\partial^2 q_i^*}{\partial u_j \partial u_i} - \frac{1}{\gamma_j}\frac{\partial^2 q_j^*}{\partial u_i \partial u_j}\right| = O_R\left(\frac{1}{\gamma}\right)$$

### 2.6 近似相关均衡（Theorem 24）

当兼容性失败时，通过**坐标路径积分**构造联合密度 $\hat{\psi}(u;t,x) \propto e^{\Phi(u)}$，其中：
$$\Phi(u) := \sum_{k=1}^N \int_0^{u_k} a_k(u_1,\ldots,u_{k-1},v_k,0,\ldots,0)dv_k, \quad a_k(u) := \frac{1}{\gamma_k}\frac{\partial q_k^*}{\partial u_k}(t,x,u)$$

**KL 散度界**（$\delta := 2(N-1)\epsilon|U|^2 \leq 1$）：
$$D_{KL}(\hat{\pi}_i(\cdot|u^{-i};t,x) \| \pi_i^*(\cdot|u^{-i};t,x)) \leq 16(N-1)^2\epsilon^2|U|^4$$

值函数次优性界（Corollary 25）：
$$0 \leq \tilde{V}^i(t,x;u^{-i}) - \tilde{V}^i_{\hat{\pi}}(t,x;u^{-i}) \leq \frac{1-e^{-\beta_i(T-t)}}{\beta_i}\epsilon_i^{CE}$$

### 2.7 q-Learning 算法（Section 7）

**三种算法**：
- **Algorithm 1**：On-Policy 策略评估（同策略）；
- **Algorithm 2**：q-Learning 整体迭代（策略评估 + 策略改进）；
- **Algorithm 3**：**Off-Policy** 直接学习 $q_i^*$（使用与玩家策略无关的行为策略 $\pi_b$，如 $\mathcal{N}(0, \sigma_b^2 I)$）。

**训练目标**：最小化时序差分（TD）残差的平方 $L(\theta,\phi) = \mathbb{E}[(\delta_s)^2]$。

**关键理论支撑**：
- **Theorem 34**（q-函数的弱鞅刻画）：$\hat{q}_i = q_i(\cdot;\pi)$ 当且仅当过程 $M_s$ 为鞅，其中 $M_s$ 包含 $e^{-\beta_i s}\tilde{J}^i + \int e^{-\beta_i r}[f^i - \hat{q}_i]dr$。
- **Theorem 37**（最优 q-函数的弱鞅刻画）：$\hat{q}_i^* = q_i^*$ 当且仅当归一化约束 $\int_U e^{\hat{q}_i^*/\gamma_i}du_i = 1$ 成立且 $M_s$ 对任意 $\pi\in\Pi$ 为鞅。
- **Theorem 33**（策略改进定理）：$I_i(\pi)$ 改进策略严格优于 $\pi$，且 $I_i(\pi)=\pi$ 当且仅当 $\pi = \pi_i^*$。

### 2.8 遍历性（无限时域）扩展（Section 5）

时间齐次系数下，HJB 方程变为椭圆型：
$$\beta_i V^i(x;u^{-i}) = G^i(\nabla_x V^i, D_x^2 V^i; u^{-i}, \gamma_i)$$

所有有限时域结论（兼容性条件、KL 界、q-learning 框架）平行推广到遍历情形，保持同样的局部一致 $O_R(1/\gamma)$ 渐近速率。

## 3. 实验设计

### 3.1 场景：两人遍历性线性二次（LQ）随机微分博弈

**状态动力学**（一维）：
$$dX_t = (AX_t + B_1 a_{1,t} + B_2 a_{2,t})dt + \sigma dW_t$$

**目标函数**（无限时域熵正则化折扣奖励）：
$$V^i(\pi_1,\pi_2) = \mathbb{E}\left[\int_0^\infty e^{-\rho t}\left[-Q_i X_t^2 - R_i a_{i,t}^2 - \gamma_i \log\pi_i(a_{i,t}|X_t)\right]dt\right]$$

**参数设置**（刻意设计为**异质**情形，使对手耦合参数在两位玩家之间数值上可区分）：

| 参数 | 值 | 角色 |
|---|---|---|
| $A$ | $-1.0$ | 均值回复 |
| $B_1, B_2$ | $2.0, 0.5$ | 玩家 1 控制力是玩家 2 的 4 倍 |
| $Q_1, Q_2$ | $1.0, 2.0$ | 异质状态惩罚 |
| $R_1, R_2$ | $1.0, 0.5$ | 异质控制成本 |
| $\sigma$ | $0.3$ | 扩散系数 |
| $\rho$ | $0.1$ | 折扣率 |
| $\Delta t$ | $0.02$ | 离散化步长 |

### 3.2 q-函数参数化

$$q^i(x, a^i, a^{-i}) = -\frac{e^{-\psi_3^i}}{2}(a^i - \psi_1^i x - \psi_2^i)^2 + \eta_1^i a^{-i}x + \eta_2^i a^{-i}$$

其中 $\psi_1^i$（反馈增益）、$\psi_3^i$（对数精度）刻画自身动作依赖；$\eta_1^i$、$\eta_2^i$ 刻画**对手动作耦合**。

### 3.3 基线与方法对比

- **未对比传统 MARL 方法**（如 MADDPG、QMIX 等），原因在于这些方法基于离散时间且缺乏连续时间理论基础，与本文的连续时间理论框架不直接可比；
- **真值基线**：通过求解耦合代数 Riccati 方程获得纳什均衡精确解 $P_1=0.2746, P_2=0.4426, K_1=-0.5493, K_2=-0.4426$；
- 在该 LQ 设置下兼容性条件**自动满足**（$\partial^2 H^i/\partial u^i \partial u^j = 0$ 对 $i\neq j$），故实验中无需检验兼容性间隙。

### 3.4 学习设置

- **算法**：Off-Policy q-Learning（Algorithm 3）；
- **行为策略**：$\pi_b = \mathcal{N}(0,1)$（与玩家策略无关）；
- **训练步数**：$3 \times 10^6$ 步；
- **学习率**：$\alpha_\psi$ 从 $7\times 10^{-4}$ 退火到 $1\times 10^{-4}$（2×10⁶ 步时切换）；$\alpha_\eta$ 类似调度（$4\times 10^{-4} \to 1\times 10^{-4}$）；
- **优化器**：SGD。

## 6. 论文主要贡献与创新点

1. **首次系统建立连续时间 N 人一般和 SDGs 的探索式 RL 理论**：覆盖有限 N、异质玩家、探索式随机策略，是 MFG 与两人零和博弈情形的本质推广；
2. **兼容性条件的完整刻画**：通过交叉偏导准则给出**可计算的纳什均衡存在性判据**（Theorem 13），并证明自然均衡与兼容性的严格等价（Theorem 12）；
3. **大 γ 渐近理论**：证明 Gibbs 策略收敛到均匀分布、兼容性间隙以 $O_R(1/\gamma)$ 消失的局部一致速率，为近似均衡提供渐近保证；
4. **近似相关均衡构造**：通过坐标路径积分在兼容性失效时构造联合密度，并给出 KL 散度与值函数次优性的显式界；
5. **q-Learning 三算法体系**：含 on-policy 评估、整体迭代、off-policy 三种算法，配合**最优 q-函数的弱鞅刻画**（Theorem 37），实现真正的无模型学习；
6. **有限时域与遍历情形的统一处理**：所有结论在两类时域下平行成立，理论框架完整。

## 7. 局限性

- **理论假设较强**：依赖系数全局 Lipschitz、状态空间 $\mathbb{R}^d$、策略空间为密度类 $\mathcal{P}(U)$ 等标准假设，限制了对实际复杂系统的直接应用；
- **状态约束处理**：Theorem 23 要求 $K_t \subseteq [0,T]\times \mathbb{R}^d$、$U$ 紧致，部分实际场景可能不满足；
- **可计算性受限**：交叉偏导准则虽可判定兼容性，但实际计算 $q_i^*$ 的二阶交叉偏导在维度灾难下仍困难；
- **数值验证单薄**：仅一组 LQ 实验，缺少复杂场景、对比实验、消融研究；
- **算法可扩展性**：Algorithm 3 的 off-policy 收敛性分析未在论文中给出完整证明（仅依赖鞅刻画，未给出深度参数化下的有限样本收敛速率）。

## 8. 总体评价

本文是**连续时间多智能体强化学习理论**的重要进展，针对 N 人一般和随机微分博弈提出了**完整的探索式均衡分析框架**。理论部分**结构清晰、结论深刻**——特别是兼容性条件的交叉偏导刻画与近似相关均衡的 KL 界，均具有独立的理论价值。算法部分给出**统一的三套 q-learning 算法**并通过最优 q-函数的鞅刻画提供了理论支撑。然而，**实验验证较为单薄**，仅在 LQ 设定下做了单组 off-policy 验证，未展示兼容性失效、遍历 vs 有限时域对比、非线性场景等关键实证。整体而言，本文**理论贡献 > 实验贡献**，适合作为连续时间 MARL 的理论基础工作，对后续在非 LQ 场景下的实证研究具有重要指导意义。

**适用读者**：连续时间控制与随机博弈、MARL 理论、探索-利用机制研究方向的学者与研究生。**推荐引用场景**：连续时间 MARL 的均衡存在性条件、q-learning 在随机微分博弈中的扩展、熵正则化均衡的近似构造等相关研究的基线文献。
