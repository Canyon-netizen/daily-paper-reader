安全基于模型的强化学习（RL）通常将控制理论分析与机器人强化学习相结合，使机器人能够在安全地探索（部分）未知系统动力学的同时，推导出兼顾任务效率的控制动作。控制性能与安全保障通常依赖于部分建模的标称系统动力学的先验知识，以及用于补偿残余模型不确定性的数据驱动模型。然而，现有方法往往忽视了残余模型不确定性的结构（例如，控制仿射分量），这可能导致基于安全学习控制器下的机器人行为过于保守或安全保证失效。本文提出了一种安全强化学习框架，利用控制屏障函数（CBF）学习控制仿射动力学并获得可认证的数据驱动安全策略。具体而言，我们首先采用控制仿射随机傅里叶特征（ARFF）将机器人动力学建模为控制仿射形式，该方法在计算效率上能够随数据集规模进行扩展，并能减少基于模型的强化学习中潜在的模型偏差。随后，采用一种基于自适应一致性预测（ACP）的无模型高效不确定性量化方法，对由学习得到的控制仿射动力学所引入的安全约束不确定性进行量化。这使得数据驱动的安全保障能够与基于 CBF 的原理化、高效控制器综合相兼容。在倒立摆和三维四旋翼平台上的仿真结果验证了所提框架的有效性。

## Abstract
Safe model-based reinforcement learning (RL) often bridges control-theoretic analysis and RL for robots to safely explore (partially) unknown system dynamics while deriving control actions for task efficiency. The control performance and safety assurance typically rely on prior knowledge of partially modeled nominal system dynamics and the data-driven models that compensate for residual model uncertainties. However, existing methods often overlook the structure of residual model uncertainties (e.g., components affine in control), which could lead to overly conservative robot behaviors or invalid safety guarantees under the safe learning-based controllers. This paper proposes a safe reinforcement learning framework that learns control-affine dynamics with a certifiable data-driven safe policy using control barrier functions (CBF). Specifically, we first use Control-Affine Random Fourier Features (ARFF) to model robot dynamics in a control-affine form, which offers computational efficiency that scales with dataset size and reduces potential model bias for model-based reinforcement learning. Then, a model-free, efficient uncertainty quantification method using adaptive conformal prediction (ACP) is applied to quantify the uncertainty in the safety constraint arising from the learned control-affine dynamics. This allows for data-driven safety assurance amenable to principled and efficient controller synthesis with CBF. Simulation results on the cartpole and the 3D quadrotor platforms demonstrate the effectiveness of the proposed framework.

## 1. 核心问题与研究动机

- **研究背景**：安全基于模型的强化学习（Safe MBRL）旨在让机器人在部分未知的系统动力学下，既能安全探索又能保证任务效率。然而，其性能与安全性依赖于两部分：(1) 部分已知的标称动力学（由物理定律推导），(2) 数据驱动学习的残差不确定性模型。
- **现有方法的不足**：
  - 已有方法（如 GP-free 或标准 RFF）在建模残差不确定性 $d(x_k, u_k)$ 时**忽略其控制仿射结构**，即默认 $d(x_k, u_k) \approx \tilde{f}(x_k)$，忽略了控制输入 $u_k$ 对残差的影响；
  - 这种忽略会导致：① 模型偏差较大进而影响控制性能；② CBF 优化问题需要将优化变量传播进非线性数据驱动模型而难以高效求解；
  - RFF 近似 GP 还会**低估预测方差**，导致不确定性感知的安全约束过于乐观，无法保证安全。
- **本文核心问题**：如何在保留残差动力学控制仿射结构的前提下，高效学习并提供可认证的安全保证？

## 2. 方法论

### 2.1 整体框架

- 提出 **SafeCARL**（Safe Control-Affine RL）框架：每个学习回合分为两步：
  1. 用 ARFF 拟合残差动力学 → 用 Thompson Sampling 采样的动力学经 MPPI 产生参考控制输入；
  2. 用 CBF 进行安全过滤得到最终安全控制量。

### 2.2 关键技术 1：控制仿射随机傅里叶特征（ARFF）

- 将残差动力学建模为线性仿射形式：
$$d(x_k, u_k) = \omega^\top \phi(x_k, u_k)$$
- 特征 $\phi(x_k, u_k)$ 设计为：
$$\phi(x_k, u_k) = \left[\varphi_1(x_k), \cdots, \varphi_{m+1}(x_k)\right] \begin{bmatrix} u_k \\ 1 \end{bmatrix}$$
- 其中 $\varphi_i(x_k) = \sqrt{2/P}\left[\sin(\theta_{i,1}^\top x_k), \cos(\theta_{i,1}^\top x_k), \ldots\right]^\top$，$\theta_{i,j}$ 独立同分布于高斯分布。
- **训练**：通过岭回归求解：
$$\omega_t = \left(\Sigma_0 + \sum_{i=1}^{t-1}\sum_{k=1}^K \phi(x_k^i, u_k^i)\phi(x_k^i, u_k^i)^\top\right)^{-1} \sum_{i=1}^{t-1}\sum_{k=1}^K \phi(x_k^i, u_k^i) d_\epsilon(x_k^i, u_k^i)$$
- **优势**：解析解，不随数据集规模而显著增加计算成本；显式分离控制输入，使后续 CBF 优化保持凸性。

### 2.3 关键技术 2：自适应一致性预测（ACP）不确定性量化

- 定义安全屏障证书预测值 $G(x_k, u_k) = h(\hat{f}(x_k) + \hat{g}(x_k)u_k + d(x_k, u_k)) - (1-\gamma)h(x_k)$，真实值 $G^*(x_k, u_k)$。
- 利用 ACP 构造置信区间：
$$P\left(-S^{(r)} + G(x_k, u_k) \leq G^*(x_k, u_k) \leq S^{(r)} + G(x_k, u_k)\right) \geq 1 - \alpha$$
- 通过对误差 $S_k = |G^*(x_k, u_k) - G(x_k, u_k)|$ 计算分位数 $S^{(r)}$，其中 $r = \lceil (K+1)(1-\alpha_c) \rceil$。
- **定理 1**：将机会约束 $P(G^*(x_k, u_k) \geq 0) \geq 1-\alpha$ 等价转化为确定性的不确定性感知安全约束：
$$-S^{(r)} + G(x_k, u_k) \geq 0$$
- 利用 ACP 递推更新 $\alpha_{k+1} = \alpha_k + \delta(\alpha_c - e_k)$，保证在线可用的、模型无关的可靠不确定性区间。

### 2.4 关键技术 3：基于 CBF 的安全控制综合

- 优化问题：
$$u_k^t = \arg\min_{u_k^t} \|u_k^t - u_k^{ref}\|^2$$
$$\text{s.t. } h(x_k^{t+1}) - h(x_k^t) \geq -\gamma h(x_k^t) + S^{(r)}, \quad u_k \in [u_{min}, u_{max}]$$
- 其中 $x_k^{t+1} = \hat{f}(x_k^t) + \hat{g}(x_k^t)u_k^t + \omega_t^\top \Phi(x_k^t)\left[(u_k^t)^\top, 1\right]^\top$。
- **关键优势**：由于控制输入 $u_k$ 在残差项中保持线性，约束保持线性，**整个优化为凸优化**，可用 CVXPY 直接求解。

### 2.5 探索策略

- 引入 Thompson Sampling 在动力学参数空间采样 $\tilde{\omega}_t \sim \mathcal{N}(\omega_t, \Sigma_{\omega_t}^{-1})$，以平衡探索与利用。
