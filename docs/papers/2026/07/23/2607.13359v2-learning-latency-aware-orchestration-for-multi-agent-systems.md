## TL;DR

多智能体系统通过让多个 LLM 驱动的智能体协同工作来提升推理能力，但多步执行和重复调用也带来了高昂的推理时延。本文提出 LAMaS 框架，从训练和推理两个层面解决时延问题：训练时学习时延感知的执行图结构，推理时通过轻量控制器动态剔除冗余交互。实验表明，该方法在四个基准上实现超过 50% 的端到端时延降低，同时保持甚至提升了任务准确率。

## 研究背景与动机

多智能体系统（Multi-Agent System）已成为当前 LLM 应用的重要范式。这类系统通过结构化的工作流协调多个智能体，每个智能体专注于特定子任务，最终通过协作完成复杂推理。然而，这种协作模式付出的代价是显著的推理时延——每个智能体都需要独立调用 LLM，多步执行链路叠加起来，端到端延迟往往难以接受。

现有研究已经注意到多智能体系统的高成本问题，并提出了多种编排优化方法。这些方法通常从任务性能或推理成本的角度入手，例如压缩智能体数量、优化调用顺序或降低单次调用 token 消耗。但一个关键洞察被忽视了：**端到端时延并非由所有交互的平均耗时决定，而是由关键执行路径（critical path）决定的**。在一条执行链路中，如果某个智能体处于关键路径上，它的延迟会直接传导至最终结果；相反，脱离关键路径的优化——比如削减一个本来就“等待中”的智能体的调用——对端到端时延毫无贡献。因此，单纯降低总体成本并不能可靠地缩短实际延迟。

更棘手的是，时延优化与准确率之间存在张力。在传统的信用分配（credit assignment）机制下，模型可能错误地将贡献度归因到非关键路径的操作上，导致学习到的执行图在削减延迟时恰好删除了重要的推理步骤。这构成了一个两难困境：不优化时延则系统太慢，朴素优化则可能牺牲准确率。

## 方法

LAMaS 的核心思路是将时延优化显式地融入多智能体系统的学习过程，而非事后补救。这一框架在两个时间维度上分别发挥作用：**训练时**学习一个结构上“延迟友好”的执行图，**推理时**则通过运行时控制器动态补充结构性学习的不足。

### 训练阶段：关键路径感知的执行图学习

在训练阶段，LAMaS 的目标是构建一个时延感知的执行图（execution graph）。与传统方法不同，这里的关键创新在于**关键路径感知的信用分配**机制。传统信用分配往往将贡献度均摊或基于最终损失反向传播，但 LAMaS 明确建模每个智能体操作对端到端延迟的影响。

具体而言，LAMaS 引入了一个约束优化问题：在保证任务性能不低于某个阈值的前提下，最小化期望的端到端延迟。形式化地，可以写作：

$$\min_{G} \mathbb{E}[T(G)] \quad \text{s.t.} \quad \mathbb{E}[P(G)] \geq \theta$$

其中 $G$ 是执行图结构，$T(G)$ 表示该图对应的端到端时延，$P(G)$ 表示任务性能指标，$\theta$ 是预设的性能下界。这个约束确保了优化不会以牺牲准确率为代价。

关键路径感知体现在信用分配过程中。LAMaS 分析执行图中每条路径的延迟贡献，对于处于关键路径上的操作给予更高的“保留权重”，而对非关键路径上的冗余交互则施加更大的优化压力。通过这种方式学习到的执行图，在结构层面就已经倾向于跳过或简化非关键的交互步骤。

### 推理阶段：轻量控制器的动态冗余消除

训练阶段确定的执行图是静态的，它无法利用推理时的具体输入特征和中间状态。为此，LAMaS 在推理阶段引入了一个**轻量级控制器**，对图的执行过程进行动态调整。

这个控制器的作用是实时评估当前执行状态下是否还存在冗余的智能体交互。当某些未来交互在给定当前上下文的情况下已经可以预判为非必要或可简化时，控制器会提前介入，跳过或合并这些交互。由于控制器本身是轻量级的——可能是一个小型模型或基于规则的模块——它的引入开销远小于它所消除的延迟。

这种“训练时学习结构 + 推理时动态调整”的双层设计弥补了各自的不足：结构学习保证了基本的延迟优化方向，动态控制则捕捉了输入相关的个性化优化机会。

## 实验与结果

研究团队在四个基准上评估了 LAMaS 的效果，这些基准涵盖了不同复杂度和任务类型的多智能体场景。对比基线包括当前主流的基于学习的编排方法。

实验结果显示，LAMaS 在所有基准上均取得了所评估基线中最低的推理时延。具体而言，端到端延迟相比最优基线降低超过 50%，这一提升幅度在实际应用中具有显著意义。关键的是，这种时延优势并未以准确率为代价——LAMaS 在多数基准上保持了竞争力甚至更优的准确率，验证了其约束优化设计的有效性。

消融实验进一步揭示了两个组件的贡献。移除训练阶段的关键路径感知学习会导致延迟回升，说明静态图结构本身已经编码了重要的优化信息。移除推理阶段的动态控制器也会使性能下降，尤其是在输入变化较大、静态图难以覆盖所有情况的场景下。这两项消融共同印证了双层设计互补价值的假设。

## 讨论与可借鉴点

LAMaS 的模块化设计是其另一个亮点。框架的核心组件——关键路径分析器、约束优化器、轻量控制器——与具体智能体的实现是松耦合的。实验表明，将 LAMaS 迁移到其他多智能体系统只需极少的适配工作，却能持续带来时延下降。这意味着该方法具有良好的泛化能力，可以作为多智能体系统优化的通用基础架构。

当然，当前工作也存在局限。首先，关键路径的准确识别依赖于对各智能体执行时间的可靠估计，这在 LLM 推理中具有方差（不同输入、不同负载下调用时间差异较大）。其次，轻量控制器的设计空间尚有探索余地——更复杂的控制器可能带来更大优化幅度，但也引入了更多开销和部署复杂度。最后，约束优化中的性能下界 $\theta$ 需要人工设定，如何自适应地调整这一阈值是未来值得研究的问题。

从更宏观的角度看，LAMaS 揭示了 [[多智能体系统]] 编排优化中一个被低估的维度——时延与成本并非等价优化目标。这一洞察对于未来设计高效多智能体应用具有重要启发意义。

## 摘要
多智能体系统（MAS）通过结构化的工作流协同多个由 LLM 驱动的智能体，由此获得更强的推理能力，但也因多步执行和重复的模型调用而承担高昂的推理时延。现有的编排方法主要优化任务性能和推理成本，对时延的关注明显不足。在多智能体系统中，端到端时延由关键执行路径决定，因此仅降低总体成本并不能可靠地缩短时延。此外，在保持准确性的同时优化时延并非易事：朴素的时延优化可能会错误地分配算子级的贡献度，从而损害任务准确率。为弥补这一空白，我们提出了时延感知多智能体系统（LAMaS），一个面向基于学习的多智能体系统的时延感知编排框架。LAMaS 在两个层面上应对这一挑战：在训练时，它通过带有关键路径感知贡献度分配的约束优化来学习时延感知执行图；在推理时，由于训练时确定的图无法利用运行时证据，它通过一个轻量级控制器对图的构建加以补充，该控制器能够在执行展开过程中自适应地剔除冗余的未来智能体交互。在四个基准上的实验表明，LAMaS 在所评估的基于学习的多智能体系统基线中取得了最低的时延，端到端时延降低超过 50%，同时保持具有竞争力或更优的准确率。LAMaS 还具有模块化特性，仅需极少改动即可迁移到其他多智能体系统，并持续带来时延下降。

## Abstract
Multi-agent systems (MAS) coordinate multiple LLM-powered agents through structured workflows, gaining reasoning power but incurring high inference latency from multi-step execution and repeated model invocations. Existing orchestration methods primarily optimize task performance and inference cost, leaving latency largely unaddressed. In MAS, end-to-end latency is governed by the critical execution path, so reducing total cost alone does not reliably reduce latency. Moreover, optimizing latency while preserving accuracy remains non-trivial: naive latency optimization can misassign operator-level credit and degrade task accuracy. To address this gap, we propose Latency-Aware Multi-agent System (LAMaS), a latency-aware orchestration framework for learning-based multi-agent systems. LAMaS addresses this challenge at two levels: at training time, it learns latency-aware execution graphs through constrained optimization with critical-path-aware credit assignment; at inference time, since a graph committed at training time cannot exploit runtime evidence, it complements graph construction with a lightweight controller that adaptively eliminates redundant future agent interactions as execution unfolds. Experiments on four benchmarks show that LAMaS achieves the best latency among evaluated learning-based MAS baselines, reducing end-to-end latency by over 50\% while maintaining competitive or better accuracy. LAMaS is also modular and transfers to other MAS with minimal changes, consistently yielding latency reductions.
