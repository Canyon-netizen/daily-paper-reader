## TL;DR

H²SD 针对 RLVR 训练中轨迹级标量奖励缺乏 token 级指导的问题，创新性地提出根据轨迹正确性分而治之的蒸馏策略：成功的轨迹用重述指令构造教师上下文，仅做幅度精修；失败的轨迹则引入验证器确认的参考提示，通过反向 KL 散度进行纠正性蒸馏。实验在 Sudoku、Calcudoku 和 Arrow Maze 等推理基准上取得最优综合性能，且训练稳定、精度-效率权衡出色。

## 研究背景与动机

带可验证奖励的强化学习（RLVR）近年来成为提升大语言模型推理能力的主流范式。无论是 GRPO 还是其他变体，其核心都是让模型在可验证的任务上生成响应，再根据最终结果给出标量奖励。这种轨迹级的监督信号虽然训练稳定，但存在一个根本性的局限：对于一条包含成百上千个 token 的推理链，模型只能知道最终对还是错，却无法得知链条中哪些推理步骤是关键、哪些是冗余甚至是错误的。这就好比老师只告诉学生这次考试得了多少分，却不给任何答题过程的反馈。

为了缓解这个问题，社区陆续提出了多种自蒸馏方法。其基本思路是让同一个模型既当学生又当教师：教师模型额外接收到一些特权信息（如标准答案、参考解法），然后对学生生成的 token 进行 token 级监督。根据教师信号的使用方式，这些方法大致可以分为两派。一派是直接做分布匹配，即让学生 token 的概率分布向教师分布靠拢，这最容易想到，但特权信息泄漏可能导致学生直接"抄答案"，训练变得不稳定。另一派是只调节更新幅度，不做分布匹配，教师信号仅决定每个 token 的梯度大小，这避免了分布偏移，但本质上仍然沿用和成功轨迹相同的策略，无法对失败轨迹提供方向性的纠正。

作者敏锐地捕捉到了一个被忽视却至关重要的现象：成功轨迹和失败轨迹的"本质"是不同的。一条成功的响应已经包含了学生自己生成的有效推理路径，这条路径本身就是可靠的——它的问题不在于方向错了，而在于可能不够精炼或某些 token 的置信度分配不够准确。一条失败的响应则完全不同：它要么走错了方向，要么在某个关键节点卡住了，需要的是来自外部的纠正性参考。因此，用同一套策略处理这两种轨迹，本质上是一种错配。

## 方法

基于上述观察，H²SD 的核心设计非常直接：根据轨迹是否正确，联合调整教师上下文的内容和更新策略的形态，形成一种"混合路由"机制。

对于成功轨迹，H²SD 采用幅度调制策略。教师模型的输入是学生已验证正确的响应加上一个重述指令："Rephrase the correct response concisely and accurately." 教师对这个重述版本给出概率打分，而学生则用教师打分与自身打分的对数比值来调制 token 的梯度权重。具体而言，令 $\Delta_t = \text{sg}(\log P^S(y_t) - \log P^T_{\text{rephrase}}(y_t))$ 表示教师与学生在 token $t$ 上的置信度差异，权重 $w_t = \exp(\text{sign}(A) \cdot \Delta_t)$ 将这个差异转换为梯度缩放因子，最终的有效优势 $\hat{A}_t$ 在原始优势 $A$ 的基础上乘以一个截断后的权重。这个设计的精妙之处在于：它完全不改变奖励的方向——模型仍然在强化那些最终导向正确答案的响应——但通过重述指令，教师帮模型识别出了响应中真正关键的推理步骤，将冗余内容的权重压低，从而细化 token 级的信用分配。重述指令的作用可以理解为一种"蒸馏压缩"：教师在复述过程中会自动省略可有可无的过渡性表达，学生因此学会用更少的 token 表达同样正确的推理。

对于失败轨迹，H²SD 切换到反向 KL 蒸馏策略。这里的关键组件是一个由更强大的外部模型（实验中使用了 Kimi-K2.6）生成的参考提示 $h = \mathcal{H}(x)$，它包含关键中间推理步骤和经验证器确认的最终答案。学生模型以这个提示为教师条件，尝试让自己的 token 分布反向匹配教师的分布。形式化地，损失函数为 $\mathcal{L}_{\text{RKL}} = \frac{1}{T}\sum_{t=1}^{T} D_{\text{KL}}(p^S_{t,\theta} \| \text{sg}[p^{T,h}_{t,\theta}])$。选择反向 KL 而非前向 KL 是经过仔细考虑的：反向 KL 具有"mode-seeking"特性，它会让学生向教师分布的主要模式靠拢，而不会试图覆盖教师分布中概率很低的区域。这避免了在失败轨迹上引入过多探索性噪声，让学生专注于学习那些被验证器确认的正确推理片段。

最终，H²SD 的总体目标函数可以写为：

$$\mathcal{L}_{\text{H}^2\text{SD}} = \mathbb{E}_{x,y}\big[m\cdot\mathcal{L}_{\text{RLSD}} + \gamma(1-m)\cdot\mathcal{L}_{\text{RKL}}\big]$$

其中 $m = \mathbb{1}[R(x,y)=1]$ 是轨迹正确性的指示函数，$\gamma$ 是控制失败轨迹上纠正蒸馏强度的超参数。这不是一个简单的加权组合，而是一个根据结果动态路由的混合策略——轨迹正确性决定了教师上下文是什么，也决定了学生应该如何向教师学习。

## 实验与结果

实验在三个逻辑推理基准上进行：Sudoku（数独）、Calcudoku（肯肯数独）和 Arrow Maze（箭头迷宫），涵盖从 6×6 到 10×10 的多种网格尺寸。所有训练基于 Qwen3-30B-A3B-Instruct-2507 模型，在 VERL 框架下使用 FSDP 全参数训练。

主实验对比了八种方法：基座模型、GRPO、SDPO、RLSD、RLSD+hint、OPSD、SRPO 和 H²SD。结果显示，H²SD 在所有七个基准配置上的总体均值为 50.49%，显著优于次优方法 RLSD 的 24.85%。尤其引人注目的是在 Sudoku-6×6 上，H²SD 达到 76.50%，而排名第二的 OPSD 仅为 35.25%，提升幅度超过 40 个百分点。

消融实验提供了几个关键洞察。首先是路由策略的必要性：实验设置了四种路由变体——仅幅度调制、仅反向 KL、反向路由（即成功用反向 KL、失败用幅度调制）以及 H²SD 的正确路由。反向路由在所有基准上导致训练崩溃，策略熵迅速降至零，说明将两种策略颠倒过来不仅无效甚至有害。其次是重述指令的作用：消融表明重述指令仅在幅度调制策略下带来提升，在反向 KL 策略下反而会导致熵坍缩，这是因为反向 KL 本身已经对分布进行了强约束，加上重述的压缩效应后约束过强。最后是提示类型的对比：过程级的丰富信息（如参考提示和兄弟解）显著优于答案级的简单信息（如仅含最终答案），说明失败轨迹需要的是完整的推理线索而非孤立的正确答案。

精度-效率权衡的实验尤其值得关注。H²SD 在所有四个基准上都位于或接近 Pareto 前沿，表明它不仅能达到最高精度，还能以更少的生成 token 代价实现这些精度——正确响应更短意味着模型学会了更直接地推理，错误响应也显著缩短说明失败后的无谓探索被有效抑制了。

## 讨论与可借鉴点

H²SD 最有启发性的贡献在于它的问题重构：不是去寻找一个更好的通用蒸馏策略，而是承认成功与失败轨迹本质不同，需要分而治之。这种"结果条件路由"的思路值得借鉴到其他训练场景中。

局限性方面，H²SD 对外部强模型和验证器的依赖是其推广的瓶颈——如果某个领域没有可靠的验证器或足够强的外部模型，提示的离线生成这一步就无法完成。此外，实验仅覆盖逻辑推理谜题，数学证明、代码生成等具有更长推理链的任务是否适用尚待验证。单一基座模型也限制了结论的泛化性，小规模模型在冷启动阶段成功率过低可能导致路由机制失效。方法层面，H²SD 在成功轨迹上仅做幅度精修而不做方向引导，这意味着它难以纠正那些"碰巧成功但推理路径不严谨"的响应，这一空白或许可以与搜索增强策略结合来填补。

从工程实践角度看，H²SD 的提示离线生成策略是一个实用的设计：特权信息在训练阶段提供但不影响推理阶段的计算成本，推理时模型仍然只看到问题本身。重述指令与幅度调制的协同效应则提示我们，适当的"数据增强"——即使是语义等价的内容变换——可以在不引入额外推理开销的情况下显著提升信用分配的质量。

## 摘要
带可验证奖励的强化学习（RLVR）为语言模型推理提供了可靠的结果监督，但标量轨迹奖励只能提供有限的 token 级指导。现有自蒸馏方法引入了一个特权教师，但通常给它分配固定的角色：直接分布匹配可能会破坏成功行为，而仅基于幅度的调制在失败后几乎无法提供纠正性指导。我们观察到成功与失败的轨迹需要不同形式的后视监督。成功的响应已经包含由学生生成的有效推理路径，因此可以充当特权上下文，而非被外部推理所取代；而失败的响应则需要纠正性的参考信息。我们提出混合后视自蒸馏（$\mathrm{H}^{2}\mathrm{SD}$），它根据轨迹正确性联合调整教师上下文与更新策略。对于成功轨迹，我们根据已验证的响应与改述指令构建教师上下文，并仅使用教师重新评估原始响应 token。这强调关键推理而非冗余内容，在不改变奖励方向的前提下细化基于幅度的信用分配。对于失败轨迹，由验证器确认的参考提示通过反向 KL 蒸馏提供纠正性指导。控制性消融实验表明，性能增益依赖于按结果条件进行的路由以及改述指令。在具有挑战性的推理基准上的实验表明，H$^2$SD 在代表性的 RLVR 与自蒸馏基线中取得了最强的整体性能，并具有稳定的优化过程和良好的精度-效率权衡。

## Abstract
Reinforcement learning with verifiable rewards (RLVR) provides reliable outcome supervision for language model reasoning, but a scalar trajectory reward offers limited token-level guidance. Existing self-distillation methods add a privileged teacher but typically assign it a fixed role: direct distribution matching may destabilize successful behavior, while magnitude-only modulation offers little corrective guidance after failure. We observe that successful and failed trajectories require different forms of hindsight supervision. A successful response already contains a valid student-generated reasoning path and can therefore serve as privileged context rather than being replaced by an external rationale. A failed response, however, requires corrective reference information. We introduce Hybrid Hindsight Self-Distillation ($\mathrm{H}^{2}\mathrm{SD}$), which jointly adapts teacher context and update strategy to trajectory correctness. For successful trajectories, we construct the teacher context from the verified response and a rephrasing instruction, and use the teacher only to re-evaluate the original response tokens. This emphasizes essential deductions over redundant content and refines magnitude-based credit assignment without changing the reward direction. For failed trajectories, a verifier-confirmed reference hint provides corrective guidance through reverse-KL distillation. Controlled ablations show that the gains depend on outcome-conditioned routing and the rephrasing instruction. Experiments on challenging reasoning benchmarks show that H$^2$SD achieves the strongest overall performance among representative RLVR and self-distillation baselines, with stable optimization and a favorable accuracy-efficiency trade-off.

## 2. 方法论：H²SD 混合后视自蒸馏

### 2.1 核心思想
按轨迹正确性联合调整**教师上下文**与**更新策略**，形成"混合路由"机制：
- **成功轨迹** $\Rightarrow$ 用重述指令构造教师上下文，仅用于幅度调制（类似 RLSD）；
- **失败轨迹** $\Rightarrow$ 用验证器确认的参考提示构造教师上下文，进行反向 KL 蒸馏（类似 OPSD）。

### 2.2 关键组件

#### 2.2.1 提示生成（Hints）
使用一个更强的外部 LLM（实验中为 Kimi-K2.6）离线生成参考提示 $h$：

$$h = \mathcal{H}(x)$$

提示包含**关键中间推理步骤**与**经验证器确认的最终答案**，仅作为训练时的特权上下文，不参与策略优化或推理。

#### 2.2.2 学生/教师分布定义
对每个 token 位置 $t$，定义：

$$p^S_{t,\theta}(\cdot) = \pi_\theta(\cdot \mid x, y_{<t})$$

$$p^{T,h}_{t,\theta}(\cdot) = \pi_\theta(\cdot \mid x, h, y_{<t})$$

#### 2.2.3 成功轨迹的幅度调制（类似 RLSD）
教师接收**学生原始已验证响应** + **重述指令**（"Rephrase the correct response"），其对原始响应 token 的概率用于幅度调制：

$$\Delta_t = \text{sg}\big(\log P^S(y_t) - \log P^T_{\text{rephrase}}(y_t)\big)$$

$$w_t = \exp\big(\text{sign}(A)\cdot \Delta_t\big)$$

$$\hat{A}_t = A\big[(1-\lambda) + \lambda \cdot \text{clip}(w_t, 1-\epsilon_w, 1+\epsilon_w)\big]$$

这在**不改变奖励方向**的前提下细化 token 级信用分配。

#### 2.2.4 失败轨迹的反向 KL 蒸馏
教师以参考提示 $h$ 为条件，学生向教师分布反向对齐：

$$\mathcal{L}_{\text{RKL}} = \frac{1}{T}\sum_{t=1}^{T} D_{\text{KL}}\big(p^S_{t,\theta}\,\big\|\, \text{sg}[p^{T,h}_{t,\theta}]\big)$$

反向 KL 的"mode-seeking"特性避免学生被强制覆盖过广。

#### 2.2.5 总体目标函数
设 $m = \mathbb{1}[R(x,y)=1]$ 表示轨迹正确性：

$$\mathcal{L}_{\text{H}^2\text{SD}} = \mathbb{E}_{x,y}\big[m\cdot\mathcal{L}_{\text{RLSD}} + \gamma(1-m)\cdot\mathcal{L}_{\text{RKL}}\big]$$

其中 $\gamma$ 控制失败轨迹上纠正蒸馏的强度。

## 3. 实验设计

### 3.1 模型与基准
- **基座模型**：Qwen3-30B-A3B-Instruct-2507（30B 级 MoE 指令模型）
- **三个逻辑推理基准**：
  - **Sudoku**：6×6、8×8 网格（行/列/子块约束）
  - **Calcudoku**：5×5、6×6（区域算术约束 + cage 条件）
  - **Arrow Maze**：6×6、7×7、8×8、9×9、10×10（射线长度匹配约束，覆盖网格）
- 所有方法在 **VERL + SGLang** 框架下实现，全参数 FSDP 训练。

### 3.2 对比方法
| 方法 | 类别 |
|------|------|
| **Base LLM** | 无训练基线 |
| **GRPO** | RLVR 基线 |
| **SDPO** | 自蒸馏（兄弟响应作为反馈 + GJSD） |
| **RLSD** | 自蒸馏（幅度调制） |
| **RLSD+hint** | RLSD + 外部提示（隔离提示价值 vs. 使用方式） |
| **OPSD** | 自蒸馏（前向 KL 匹配教师） |
| **SRPO** | 按正确性路由：成功→GRPO，失败→熵加权 SDPO |
| **H²SD** | 本文方法 |

### 3.3 实现要点
- **提示生成**：Kimi-K2.6，温度 0.1，最大长度 65536 tokens，每题最多 5 次尝试，仅保留验证器接受的提示。
- **蒸馏加速**：为缓解长链路推理下的全词表蒸馏显存开销，保留学生 top-100 token 精确概率，其余合并为尾部桶。
- **SDPO/SRPO** 采用广义 Jensen-Shannon 散度（$\alpha=0.5$）。

## 6. 主要结论与发现

1. **H²SD 综合性能最优**：在 Sudoku、Calcudoku、Arrow Maze 上总体均值 50.49%，远超次优 RLSD（24.85%）；Sudoku-6×6 上 76.50% vs. 次优 OPSD 35.25%，提升幅度极大。
2. **按结果条件路由至关重要**：成功轨迹应保持奖励方向并精修信用；失败轨迹应获得方向性纠正。反向路由（混淆两者）会迅速导致熵崩溃与训练失败。
3. **过程级特权信息是关键**：提示中包含推理过程（兄弟解、Kimi 提示）显著优于仅含答案或程序反馈的特权信息。
4. **重述指令与幅度调制协同**：重述去除冗余步骤而不改变正确路径，在幅度调制下保留探索能力；在反向 KL 下则会过度约束。
5. **精度-效率权衡更优**：H²SD 以最少生成 token 取得最高精度，正确响应更短、错误响应也显著缩短，避免冗长探索。
6. **泛化性**：在 Arrow Maze 未见过的 8×8、10×10 上仍保持最优，体现学到的推理能力可迁移。

## 7. 优点

- **方法论清晰且有原则性**：以"成功/失败轨迹本质不同"这一观察为出发点，路由设计自然且可解释。
- **消融设计严谨**：通过共享相同提示 + 多种提示类型对比，干净地分离了"特权信息"与"使用策略"的贡献。
- **稳定训练**：熵曲线证据表明 H²SD 不会过早坍缩，兼具稳定性与纠错能力。
- **多维度评估**：同时报告精度、生成成本、泛化能力、熵动态、路由策略敏感性，覆盖面广。
- **实用性强**：成功轨迹的幅度调制成本低，提示离线生成，不增加在线训练开销。
- **可推广性强**：提示设计、路由机制、幅度调制均与具体任务解耦，理论上可迁移至其他可验证推理任务。

## 8. 不足与局限

1. **依赖外部强模型与验证器**：需要 Kimi-K2.6 这类足够强的外部 LLM 生成验证器接受的提示；若无可用验证器或强模型，应用受限。
2. **单基座模型**：实验仅在 Qwen3-30B-A3B-Instruct-2507 上完成，作者承认小模型在冷启动场景下成功率过低、方法对比不稳定；缺乏多规模泛化证据。
3. **任务类型单一**：仅限逻辑推理谜题（Sudoku/Calcudoku/Arrow Maze），未涉及数学、代码、开放域问答或 agentic 任务；作者也指出这是未来方向。
4. **过滤效应**：仅保留能生成有效提示的训练题，可能减少训练数据覆盖。
5. **方法对比未涵盖基线多样化**：缺少与 GSPO、DAPO 等近期 RLVR 改进方法、以及 SRPO 之外的最新 self-distill 方法（如 OPCD、GATES、SD-Zero 等）的直接对比；OPSD 使用前向 KL，理论上若与反向 KL OPSD 对比可能更公平。
6. **算力报告不完整**：未明确报告总训练时长、收敛步数或单步耗时，仅给出 rollout step 数。
7. **重述提示工程复杂**：附录中重述 system prompt 极长且包含严格约束，提示工程负担较重；未讨论不同任务间提示模板的可复用性。
8. **未能完全解释为何 SRPO 同样路由却效果差**：作者指出 H²SD 比 SRPO 更优，但未深入分析 SRPO 内部失败模式（如熵加权 SDPO 在长链路上的退化）。
