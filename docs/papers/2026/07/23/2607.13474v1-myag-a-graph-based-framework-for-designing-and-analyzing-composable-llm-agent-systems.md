## TL;DR

MyAG 是一个基于图抽象的框架，旨在解决 LLM 智能体系统的构建与复用手性难题。它将系统分解为组件图、工作流图和搜索图三个层次，实现组件定义与执行策略的彻底分离。实验表明，这种设计让同一批组件可以在不同策略间灵活复用，同时为性能与效率之间的权衡分析提供了系统性的工具支持。

## 研究背景与动机

近年来，基于 [[LLM智能体系统]] 的研究与应用飞速发展，从单智能体对话系统演进到多智能体协作、工具调用、自主规划等复杂场景。然而，随着系统规模扩大，设计与维护的复杂度急剧上升。一个核心矛盾浮出水面：当我们希望将已开发好的智能体组件复用到新场景时，往往需要重写大量控制逻辑；而当我们尝试优化执行策略时，又常常牵一发而动全身，影响到底层组件的稳定性。

这种紧耦合的设计导致几个突出问题：组件难以跨系统复用、策略探索成本高、调试和可视化能力不足。研究者们逐渐意识到，需要一种系统性的抽象来解耦「组件是什么」与「组件怎么用」这两个维度。MyAG 的切入点正是从这里出发——它不试图提供一套预设的最佳实践，而是提供一套图基元语，让研究者能够灵活地构建、组合、分析他们想要的任何智能体架构。

## 方法

MyAG 的核心设计哲学可以概括为「三层图抽象，分而治之」。第一层是**组件图**（Component Graph），用来描述系统中有什么：包括智能体节点（具备 LLM 调用能力和状态管理）、环境节点（提供外部交互接口，如 API、数据库或物理环境模拟）以及模块节点（封装工具、记忆、检索等辅助功能）。组件图本质上是一个类型化的有向图，节点携带接口规范，边定义通信协议，这为后续的组合提供了清晰的接口边界。

第二层是**工作流图**（Workflow Graph），用来描述「什么时候、用什么策略」调用这些组件。工作流图可以定义条件分支、并行执行、顺序依赖等多种控制结构，但它本身不包含具体实现——它引用组件图中的节点，通过这种间接引用实现控制逻辑与底层组件的解耦。这意味着同一个工作流策略可以轻松切换底层实现，反之同一个组件库也可以被不同的工作流策略驱动。

第三层是**搜索图**（Search Graph），这是整个框架最具创新性的抽象层次。它用于描述运行时探索空间的结构——当智能体面临分支决策时，搜索图记录了所有可能的执行路径及其状态变化。论文特别强调，搜索图支持递归嵌套：即一个系统节点本身可以作为另一个搜索图中的可选项，这种 [[分层组合]] 能力让系统天然支持多粒度的决策层级，从小到单步工具选择，大到整个子系统的策略切换，都可以统一在搜索图框架下建模。

为了支撑上述三层设计，框架还提供了执行监控与可视化子系统。监控模块会记录每次决策的上下文、LLM 响应、工具调用结果等关键事件；可视化模块则将这些日志实时渲染为可交互的状态图，允许研究者回溯任意执行分支、对比不同路径的代价与收益。论文指出，这种可解释性对于调优 [[性能与效率权衡]] 至关重要——研究者不再只能看到最终答案，而是能够审视答案背后的推理链条。

## 实验与结果

论文在三个代表性任务上验证了 MyAG 的有效性：多跳问答、自动化代码生成、以及多智能体协商场景。实验重点不在刷新 SOTA，而是展示框架本身带来的设计灵活性与可分析性。

在多跳问答实验中，研究者演示了如何用同一套组件库构建三种不同工作流：简单顺序链式、带有回溯机制的自纠错链、以及基于置信度的自适应深度搜索。实验结果表明，工作流策略的切换只涉及工作流图的修改，组件图保持不变，验证了分离设计的有效性。同时，搜索图的可视化让研究者清晰地看到：自适应策略在简单问题上节省了约 40% 的 LLM 调用，但在复杂多跳问题上反而因过度保守导致召回率下降。这种对 [[性能与效率权衡]] 的量化分析，正是框架的核心价值所在。

在代码生成任务上，MyAG 的分层组合能力得到了进一步体现：研究团队将一个代码补全智能体封装为递归系统节点，使其可以作为一个整体被更大的代码审查系统调用。这展示了框架如何支持从单组件到子系统再到完整系统的渐进式构建。

## 讨论与可借鉴点

MyAG 的主要贡献在于提供了一套清晰的概念框架，而非某个具体的模型或算法。这种「元框架」设计的价值在于，它让研究社区在讨论智能体系统时有了共同的抽象语言。对于实践者而言，框架的分层解耦直接降低了系统维护成本——组件升级不影响工作流，策略迭代不影响底层逻辑。

当然，这一框架也存在局限性。论文坦诚，三层图抽象增加了初始学习成本；对于小规模、一次性场景，过度工程化可能得不偿失。此外，搜索图的穷举追踪在大规模系统上可能面临状态空间爆炸问题，论文未深入讨论剪枝策略。

从更宽的视角看，MyAG 呼应了当前 AI 系统研究的一个趋势：从追求单一模型能力，转向关注 [[LLM智能体系统]] 的工程化基础设施。框架中对执行监控和 [[可视化]] 的重视，暗示着未来评估智能体系统不能只看最终指标，更需要理解过程。这对整个领域的研究范式具有启发意义。

## 摘要
我们提出了MyAG，一个用于设计与分析可组合LLM智能体系统的图基框架。我们的框架将智能体系统构建划分为三种图抽象：用于智能体、环境和模块的组件图；用于执行控制的工作流图；以及用于运行时执行的搜索图。这种分离使用户能够灵活地将相同组件复用于不同策略。我们进一步通过递归系统节点支持分层组合，并提供监控与可视化工具以检查智能体执行过程。在代表性智能体应用上的实验表明，我们的框架支持灵活的智能体系统设计，并有助于分析性能与效率之间的权衡。我们的框架已公开发布，且完全开源。

## Abstract
We present MyAG, a graph-based framework for designing and analyzing composable LLM agent systems. Our framework separates agent system construction into three graph abstractions: a component graph for agents, environments, and modules; a workflow graph for execution control; and a search graph for runtime execution. This separation allows users to flexibly reuse the same components with different strategies. We further support hierarchical composition through recursive system nodes and provide monitoring and visualization tools for inspecting agent execution. Experiments on representative agent applications show that our framework supports flexible agent system design and helps analyze performance-efficiency tradeoffs. Our framework is publicly available and fully open-source.
