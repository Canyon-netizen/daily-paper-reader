## 摘要
扩散大语言模型（dLLMs）通过对掩码序列进行迭代去噪来生成文本，提供了一种并行替代自回归模型的方案，但通过后训练激发其强大的推理能力仍然困难重重：监督微调属于离策略方法，存在暴露偏差问题；强化学习仅提供稀疏的序列级奖励，且在缺乏可处理序列似然的情况下难以应用。在策略自蒸馏（OPSD）作为一种有前景的替代方案，利用同一模型同时充当学生和教师，提供密集的、词元级的、在策略的监督信号，但其效果取决于是否能为教师赋予特权信息（PI）——通常是推理时无法获得的实例特定真值参考——因此学生最终蒸馏的只是一个不含特权信息的弱共识策略，对扩散大语言模型的推理能力提升有限。我们提出 dOPSD，该方法直接从学生自身的去噪轨迹中推导教师的特权信息，利用同一轨迹中更靠后、去噪程度更高的步骤来评估被掩码位置，而非依赖外部标签，从而使教师的优势源自模型自身的解码过程；在 Dream 和 LLaDA 上的实验表明，dOPSD 提升了两者在域内数学推理和域外代码生成任务上的表现，优于监督方法和在策略基线方法。

## Abstract
Diffusion large language models (dLLMs) generate text by iteratively denoising a masked sequence, offering a parallel alternative to autoregressive models, but eliciting strong reasoning through post-training remains difficult: supervised fine-tuning is off-policy and suffers from exposure bias, while reinforcement learning gives only sparse, sequence-level rewards and is hard to apply without tractable sequence likelihoods. On-policy self-distillation (OPSD) offers a promising alternative, using one model as both student and teacher to provide dense, token-level, on-policy supervision, but its effectiveness hinges on giving the teacher privileged information (PI) - typically an instance-specific ground-truth reference unavailable at inference - so the student ends up distilling a weak PI-free consensus policy that yields little improvement on dLLM reasoning. We introduce dOPSD, which instead derives the teacher's privilege directly from the student's own denoising trajectory, evaluating masked positions using later, more-decoded steps of that same trajectory rather than an external label, so the teacher's advantage emerges from the model's own decoding process; on Dream and LLaDA, dOPSD improves both in-domain math reasoning and out-of-domain code generation, outperforming supervised and on-policy baselines.

## 1. 核心问题与研究动机

扩散大语言模型（dLLM，如 Dream、LLaDA）通过迭代去噪生成文本，具备并行解码与双向上下文优势，但其**后训练激发推理能力**仍面临三大困境：

- **监督微调（SFT）**：离策略，存在暴露偏差（exposure bias），即学生被训练在自身不会产生的上下文前缀上。
- **可验证奖励的强化学习（RLVR/GRPO）**：仅提供稀疏的序列级奖励；dLLM 缺乏可处理的序列似然，使策略优化难以直接适配。
- **已有在策略自蒸馏（OPSD）**：要求教师获得推理时不可见的**特权信息（Privileged Information, PI）**，通常为实例特定的参考答案。当 PI 为实例特定时，由于学生推理时无法访问 PI，学生最终蒸馏的是一个对 PI 边际化后的**弱共识策略**，对推理改进有限。

本文核心问题是：**能否构造一种无需外部标签、密集、词元级、在策略的监督信号**，专为扩散解码设计。

## 2. 方法论

### 2.1 OPSD 失败的两个根因（分析）

作者在第 3.2 节给出形式化论证：

**(a) PI-free 坍缩**：当学生无法在推理时看到 PI $y^\star$，最小化期望散度将驱动学生收敛到：

$$p_S^\star(y|x) = \frac{\exp\{\mathbb{E}_{y^\star\sim D(\cdot|x)} \log p_T(y|x,y^\star)\}}{\sum_{y'}\exp\{\mathbb{E}_{y^\star\sim D(\cdot|x)} \log p_T(y'|x,y^\star)\}}$$

即对所有 PI 条件教师的归一化几何均值。当 $y^\star$ 为实例特定时（如逐题参考解答），不同 $y^\star$ 诱导互不兼容的教师，平均后坍缩为弱共识。

**(b) 离解码路径**：直接把自回归 OPSD 移植到 dLLM 时，需对完整 rollout 做随机掩码。但 dLLM 推理时按置信度顺序解码，作者实验表明：10% 随机掩码中 ~90% 落在本该已被提交的"容易"词元上，监督点严重偏离模型自身解码路径。

### 2.2 dOPSD 核心思想

dOPSD **完全从学生自身的去噪轨迹** 中同时获取学生状态、教师特权与噪声，三者同源，无需外部真值。

dLLM 解码过程可写成轨迹：
$$s_0 \to s_1 \to \cdots \to s_K = \hat{y}, \qquad M_0 \supseteq M_1 \supseteq \cdots \supseteq M_K = \varnothing$$

- **学生状态**：从仍处于高掩码率（$|M_{k'}|/L > \tau$）的解码步骤中均匀采样 $k$，学生按真实推理路径在 $s_k$ 的掩码位置 $M_k$ 上预测。
- **教师特权**：对位置 $i \in M_k$，收集其后续仍被掩码的步骤集 $T_i = \{t: k < t \le K, i \in M_t\}$，将同一模型在更靠后、已更充分解码的状态 $s_t$ 上的预测取平均作为教师目标：

$$\bar{p}_i = \frac{1}{|T_i|}\sum_{t\in T_i} \pi_\theta(\cdot|x, s_t)_i$$

若 $T_i = \varnothing$（下一即刻被解码），则退化为终点教师 $\pi_\theta(\cdot|x, \hat{y})_i$。

- **损失函数**：使用带停止梯度的广义 Jensen–Shannon 散度（默认 $\beta\to 0$，即前向 KL，质量覆盖型）：

$$\ell(x,\hat{y}) = \frac{1}{|M_k|}\sum_{i\in M_k} \mathrm{JSD}_\beta\!\left(\mathrm{sg}[\bar{p}_i],\ \pi_\theta(\cdot|x,s_k)_i\right)$$

- **Rollout 验证**：仅当 $\hat{y}$ 与标准最终答案一致时才计入损失，过滤自信错误：

$$L_{dOPSD}(\theta) = \mathbb{E}_x\,\mathbb{E}_{\hat{y}\sim\pi_\theta(\cdot|x)}\!\left[\mathbb{1}[\hat{y}\text{ correct}]\cdot \ell(x,\hat{y})\right]$$

- **架构兼容**：仅做掩码预测前向，无需架构改动；额外代价是每个不同未来步骤一次教师前向。

### 2.3 与原 OPSD 的对比

| 维度 | OPSD | dOPSD |
|---|---|---|
| 教师特权来源 | 外部参考答案 $y^\star$ | 学生自身轨迹的后续状态 $s_{t>k}$ |
| 噪声来源 | rollout 上的随机掩码 | 真实解码步骤 $s_k$ |
| 适用模型 | 自回归 LLM | 扩散 LLM |
| 是否需要参考 CoT | 是 | 否（无需 CoT；最终答案仅用于可选验证） |

## 3. 实验设计

### 3.1 训练数据
- **MixChain-Z-PRM12K**：约 12K 道竞赛数学题（沿 MATH/PRM800K 谱系），含可校验最终答案与多条不同粒度的 CoT 解答。仅使用答案字段做 rollout 验证，CoT 仅供 SFT/OPSD(full) 基线使用。

### 3.2 评测基准
- **域内数学推理**：GSM8K（1,319 题，Acc@1）、MATH500（500 题，Acc@1）。
- **域外代码生成**（仅数学训练后的零样本迁移）：HumanEval（164，pass@1）、MBPP（500，pass@1）。

### 3.3 基线方法
1. **Base**：未调优的 Dream-7B-Instruct / LLaDA-8B-Instruct。
2. **SFT**：对参考解答做监督微调（离策略）。
3. **GRPO**：可验证最终答案奖励的分组相对策略优化（适配扩散解码）。
4. **OPSD (answer-only)**：教师仅以最终答案为 PI。
5. **OPSD (full-solution)**：教师以完整参考解答为 PI。

### 3.4 训练设置
- 模型：Dream-7B-Instruct（7B）、LLaDA-8B-Instruct（8B）。
- 全部方法均叠加 LoRA（rank 32，α=32，覆盖 q/k/v/o/gate/up/down_proj）。
- 优化器 AdamW，峰值学习率 $2\times 10^{-5}$，3 个 epoch，取最佳检查点。
- dOPSD 掩码阈值默认 $\tau = 0.5$。

### 3.5 推理设置
- Dream：温度 0.1 + top-p 0.9 + 置信度重掩码；HumanEval 启用熵阈值并行解码（阈值 0.5）。
- LLaDA：温度 0（贪心），block-based 半自回归去噪，block 长按任务调整。
- 扩散步数 = 生成词元数；单样本解码，无 best-of-n / 自一致性。

## 6. 主要结论与发现

- **唯一全面改进基线的方法**：在 Dream 与 LLaDA 上，dOPSD 是**唯一在四个基准上全部提升基线模型**的后训练方法；SFT、GRPO、OPSD(answer-only) 与基线持平或略降，OPSD(full-solution) 严重坍缩（Dream GSM8K 81.41→67.25；LLaDA 71.23→57.86）。
- **域内数学**：Dream GSM8K +1.63、MATH500 +3.23；LLaDA GSM8K +1.64、MATH500 +4.76。
- **域外代码（仅数学训练后零样本迁移）**：Dream HumanEval +4.17、MBPP +1.06；LLaDA HumanEval +3.51、MBPP +1.09——**缓解了监督与 PI-conditioned 基线的灾难性遗忘**。
- **失败模式归因**：
  - OPSD 的 PI 必须为**共享、可重用**的规则（如系统提示），不能为实例特定参考答案；
  - 越丰富的 PI 越让教师互不兼容，OPSD(full) < OPSD(answer-only) 在所有基准稳定成立。
- **设计要素的有效性**：
  - 前向 KL（mass-covering）优于反向 KL（mode-seeking）。
  - 教师 horizon 越长越好；聚合整个剩余轨迹最佳。
  - $\tau = 0.5$ 最优，过小（学习信号稀疏）或过大（教师目标不可靠）均劣化。
  - 即使**不做 rollout 验证**，仅靠轨迹特权仍可超过基线；验证仅带来额外小幅增益——意味着方法本身不依赖参考答案。

## 7. 方法与实验亮点

- **洞察独到**：发现 dLLM 的去噪轨迹本身即天然蕴含"前瞻特权"——同一模型在更靠后、更充分解码的状态上对相同掩码位置的预测，构成一种**无标签、自生成、on-policy** 的教师信号，这是自回归模型所没有的结构性优势。
- **理论 + 实验双重论证 PI-free 坍缩**：不仅给出几何均值公式，还在 dLLM 上以 Figure 2c 直接观察到"PI 越丰富 → 教师越互不兼容 → 学生越差"的因果链。
- **架构透明**：仅修改监督点选择，不改模型架构，仅引入额外的"教师前向"，易集成到标准 dLLM 训练管线。
- **可控的消融维度**：散度方向、教师 horizon、掩码阈值、是否验证，四个轴向均有系统消融，便于复现与迁移。
- **质性证据充分**：附录 C 给出三例完整生成对比，明确展示各基线典型错误（×24 虚构换算、丢失符号、生成空回答），让读者直观感受到 dOPSD 的推理稳健性。
- **无标签潜力**：无需参考 CoT、甚至无需参考答案（不验证版）也能获益，对难以获得高质量 CoT 的真实场景具有实用价值。

- **backbone 与任务覆盖窄**：仅 2 个 dLLM（Dream-7B、LLaDA-8B），未验证更小/更大规模、其它 dLLM（如 SEDD、MDLM 等纯离散扩散模型）的可迁移性。
- **域外评测单一**：仅 HumanEval/MBPP 两个代码基准，未涉及更广泛推理、常识或多语言任务。
- **未与最新 dLLM-RL 直接比较**：d1、IGPO 等近期专门为扩散 LLM 设计的 RL 方法未被纳入基线，难以判断 dOPSD 与专门 RL 方法的相对位次。
- **Rollout 验证仍需参考答案**：虽然论文证明无验证也能获益，但最佳结果依赖最终答案；这一假设在很多真实数据（如开放式对话、CoT 不可校验的任务）中不成立。
- **额外前向开销**：教师需要遍历每个未来步骤一次，虽"无架构改动"，但对长序列、K 较大场景的训练时长与显存开销增加未被定量分析。
- **理论分析深度有限**：PI-free 坍缩的论证主要是几何均值公式 + 实验观测，缺乏对 dLLM 训练动力学的更严格收敛性或泛化界分析。
- **失败模式集中于简单算术**：附录 C 的例子偏向单位换算、符号处理等浅层错误，未展示在需要多步规划或复杂符号操作时的差异。
