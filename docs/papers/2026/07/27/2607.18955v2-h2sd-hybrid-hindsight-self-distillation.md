## 摘要
基于可验证奖励的强化学习（RLVR）为语言模型推理提供了可靠的结果监督，但标量轨迹奖励在 token 级别的指导有限。现有的自蒸馏方法引入了一个特权教师模型，但通常赋予其固定角色：直接分布匹配可能破坏成功行为，而仅基于幅度的调制在失败后几乎不提供纠错性指导。我们观察到，成功轨迹与失败轨迹需要不同形式的后视监督。成功的响应本身已包含由学生模型生成的有效推理路径，因此可以充当特权上下文，而无需被外部推理过程所替代；而失败的响应则需要纠错性的参考信息。我们提出了混合后视自蒸馏（H$^2$SD），它根据轨迹的正确性联合调整教师上下文与更新策略。对于成功轨迹，我们依据已验证的响应与一条改写指令构建教师上下文，并仅使用教师模型对原始响应 token 进行重新评估。这突出了关键推导而弱化了冗余内容，并在不改变奖励方向的前提下细化了基于幅度的信用分配。对于失败轨迹，由验证器确认的参考提示通过反向 KL 蒸馏提供纠错性指导。受控消融实验表明，性能增益依赖于按结果条件路由的机制与改写指令。在具有挑战性的推理基准上的实验表明，H$^2$SD 在代表性的 RLVR 与自蒸馏基线方法中取得了最强的整体性能，并具有稳定的优化过程以及良好的精度-效率权衡。

## Abstract
Reinforcement learning with verifiable rewards (RLVR) provides reliable outcome supervision for language model reasoning, but a scalar trajectory reward offers limited token-level guidance. Existing self-distillation methods add a privileged teacher but typically assign it a fixed role: direct distribution matching may destabilize successful behavior, while magnitude-only modulation offers little corrective guidance after failure. We observe that successful and failed trajectories require different forms of hindsight supervision. A successful response already contains a valid student-generated reasoning path and can therefore serve as privileged context rather than being replaced by an external rationale. A failed response, however, requires corrective reference information. We introduce Hybrid Hindsight Self-Distillation ($\mathrm{H}^{2}\mathrm{SD}$), which jointly adapts teacher context and update strategy to trajectory correctness. For successful trajectories, we construct the teacher context from the verified response and a rephrasing instruction, and use the teacher only to re-evaluate the original response tokens. This emphasizes essential deductions over redundant content and refines magnitude-based credit assignment without changing the reward direction. For failed trajectories, a verifier-confirmed reference hint provides corrective guidance through reverse-KL distillation. Controlled ablations show that the gains depend on outcome-conditioned routing and the rephrasing instruction. Experiments on challenging reasoning benchmarks show that H$^2$SD achieves the strongest overall performance among representative RLVR and self-distillation baselines, with stable optimization and a favorable accuracy-efficiency trade-off.

# H²SD：混合后视自蒸馏 — 论文总结

## 一、核心问题与研究动机

- **背景**：基于可验证奖励的强化学习（RLVR，如 GRPO）已成为增强大语言模型推理能力的主流范式，但其奖励信号仅为轨迹级别的标量，无法提供 token 级的细粒度指导，导致信用分配（credit assignment）粗粒度。
- **现有方案的不足**：
  - **On-Policy Self-Distillation (OPSD)**：令教师分支接收特权信息（如解题提示），通过 token 级分布匹配提供密集监督；但直接匹配教师分布可能引入特权信息泄露并破坏学生已有正确行为。
  - **RLSD**：仅使用教师信号重新调制 token 级别的更新幅度，缓解了信息泄露但缺乏对错误轨迹的方向性纠错。
  - **SRPO**：对成功/失败样本做简单路由，但未细致分配不同更新策略。
- **核心洞察**：成功轨迹与失败轨迹需要**不同形式的后视监督**：
  - 成功响应本身已包含有效推理路径，应作为特权上下文保留，而非被外部答案替代；
  - 失败响应需要纠错性的参考信息来引导分布修正。
- 本文据此提出 **H²SD (Hybrid Hindsight Self-Distillation)**：联合按结果条件调整教师上下文与更新策略。

## 二、方法论

### 2.1 提示生成（Hint Design）

- 使用更强的外部语言模型（如 Kimi-K2.6）离线为每个问题 $x$ 生成自然语言提示 $h$，包含关键中间推导步骤与验证器确认的最终答案：
$$h = \mathcal{H}(x)$$
- 强模型仅提供自然语言提示，不作为教师，亦无需与学生共享词表；实际教师分布仍由当前模型 $\pi_\theta$ 在提示条件下产生。

### 2.2 混合自蒸馏目标

- **成功轨迹**（$m = \mathbb{1}[R(x,y)=1]$）：教师上下文由"已验证的响应 + 改写指令"组成，概率仅用于 RLSD 的幅度调制 $\mathcal{L}_{\text{RLSD}}$，保留奖励方向不变。
- **失败轨迹**（$m=0$）：教师由提示条件化，对学生施加**反向 KL 蒸馏**：
$$\mathcal{L}_{\text{RKL}} = \frac{1}{T}\sum_{t=1}^{T} D_{\text{KL}}\!\left(p^{S}_{t,\theta}\,\|\,\text{sg}[p^{T,h}_{t,\theta}]\right)$$
  其中 $p^{S}_{t,\theta} = \pi_\theta(\cdot\mid x, y_{<t})$，$p^{T,h}_{t,\theta} = \pi_\theta(\cdot\mid x, h, y_{<t})$，$\text{sg}[\cdot]$ 表示停止梯度。

- **总目标**：
$$\mathcal{L}_{\text{H}^2\text{SD}} = \mathbb{E}_{x,y}\!\left[\,m\cdot\mathcal{L}_{\text{RLSD}} + \gamma(1-m)\cdot\mathcal{L}_{\text{RKL}}\,\right]$$

### 2.3 RLSD 幅度调制回顾

- 对于 token $t$，教师相对学生的对数概率差为：
$$\Delta_t = \text{sg}\!\left(\log P^T(y_t) - \log P^S(y_t)\right)$$
- Token 级别优势为：
$$\hat{A}_t = A\left[(1-\lambda) + \lambda\cdot\text{clip}(w_t, 1-\epsilon_w, 1+\epsilon_w)\right],\quad w_t = \left(\frac{P^T(y_t)}{P^S(y_t)}\right)^{\!\text{sign}(A)}$$

### 2.4 关键设计要点

- **改写指令**：仅在成功轨迹上使用，使教师重新评估学生原始 token，强调关键推导、去除冗余与试探性检查。
- **Top-$K$ 蒸馏**：为缓解长链推理的全词表蒸馏开销，保留学生前 100 个 token 的精确概率，其余合并为尾桶。
- **提示过滤**：仅保留验证器确认通过的提示。

## 六、主要结论与发现

1. **H²SD 取得最佳综合性能**：在四个基准 10 个配置上有 9 项排名第一，整体平均 **50.49%**，远超次优 RLSD（24.85%）和 GRPO（24.68%）。
2. **按结果条件路由至关重要**：Reversed Routing（反向交换成功/失败分配）性能低于 Base LLM，且熵迅速崩溃至零，说明单纯组合两种更新目标不足以带来提升，**正确性条件路由才是核心**。
3. **特权上下文质量对失败轨迹纠错影响显著**：仅有最终答案或程序化反馈收益有限，含有过程级信息的提示（Hint）效果最佳；同批正确 sibling solution 表现其次（Sudoku-6×6 达 61.75%）。
4. **改写指令（Rephrase）与更新策略之间存在交互**：
   - 与 Magnitude Only 结合时，改写大幅提升性能（Sudoku-6×6 提升 23.75 个百分点）；
   - 与 Reverse-KL Only 结合时，改写反而降低性能并导致熵锐减；
   - H²SD 通过在成功轨迹上使用改写+幅度调制、保留失败轨迹上的反向 KL，成功兼顾二者优势。
5. **精度-效率权衡更优**：H²SD 在获得最高 pass@1 的同时生成长度最短，正确响应与失败响应长度均较短，主要源于更高的成功率与更直接的纠错信号。

## 七、优点与亮点

- **问题切入精准**：明确指出成功/失败轨迹的异质性需求，并通过对 RLSD 与 OPSD 局限的对比清晰建立动机；
- **方法简洁而有效**：仅在前向阶段为教师装配差异化 prompt 与损失函数，无需额外网络或分支；
- **消融系统充分**：路由、上下文、改写三轮消融配合熵曲线，从稳定性与探索性角度交叉印证；
- **效率意识强**：Top-$K$ 蒸馏与生成效率分析显示方法并非通过生成长度堆出性能；
- **教学设计友好**：附录提供了精确的提示模板、改写提示与超参表，便于复现。

## 八、不足与局限

- **依赖外部强模型**：H²SD 依赖 Kimi-K2.6 离线生成且验证通过的提示；当目标问题无可用强模型或验证器时，将产生 preprocessing 瓶颈并降低训练数据覆盖率；
- **单一模型规模**：仅在 Qwen3-30B-A3B-Instruct-2507 上验证；作者承认小模型初始成功率过低导致训练不稳定，但仍未给出小规模结果，因此**对能力下限的鲁棒性未知**；
- **基准覆盖窄**：Sudoku、Calcudoku、Arrow Maze 均为自包含的逻辑谜题，**缺乏数学竞赛、代码生成、问答等更具生态意义的推理任务**；
- **超参公平性存疑**：各基线学习率不一致，可能放大 H²SD 的相对优势；
- **训练时长与收敛步数未披露**：影响对实际计算成本的评估；
- **逆向 KL 的 mode-seeking 风险被部分缓解但未根除**：在失败轨迹分支仍使用反向 KL，作者通过路由缓解，未给出与前向 KL、JSD、α-JSD 等替代散度的对比；
- **提示质量对最终性能影响未做敏感性分析**：例如对不同强模型或不同改写策略的鲁棒性未系统化讨论。
