## TL;DR

这项研究针对部分可观测强化学习中记忆管理的核心难题——何时保留、检索与遗忘信息，提出了一种神经-符号元策略，能够在每个决策点自适应地选择合适的符号记忆启发式。实验在 RoomKG 场景下展开，采用时序知识图谱记忆与 StarE-GNN 编码器，在 512 记忆容量的训练/测试房间划分中取得了符号、神经及神经-符号三类系统中的最优保留测试性能，同时完整保留了记忆管理决策的步骤级可追溯性。

## 研究背景与动机

部分可观测强化学习（[[强化学习]]的一个重要分支）的核心挑战在于：智能体只能基于不完整的观测序列做出决策，必须自行决定随时间流逝应该保留哪些历史信息、丢弃哪些冗余内容、以及在决策时检索哪些记忆片段。这一问题在现实场景中尤为突出——从机器人导航到对话系统，智能体都需要在有限的认知资源下高效管理不断累积的经验。

传统方法在这一问题上往往面临两难。纯符号系统虽然具有可解释性强、决策过程透明的优点，但在处理大规模、模糊或噪声观测时显得僵硬笨拙，难以自适应地调整记忆策略。纯神经方法虽然能够学习复杂的记忆模式，但往往将记忆内容编码为分布式向量，丢失了语义结构，使得人们难以理解"为什么智能体记住了这个却遗忘了那个"。这就好比一个黑箱——你知道它能工作，却无法追溯其内部决策逻辑。

这篇论文的切入点正是看到了两种范式各自的痛点：神经网络的自适应能力与符号系统的可检视性似乎是鱼与熊掌。该工作的核心假设是：如果将记忆本身建模为具有明确语义的[[知识图谱]]结构，同时让神经网络学习"何时应用哪种记忆操作"，或许能够在自适应性与可解释性之间找到更好的平衡点。具体而言，研究者选择在 RoomKG 这一特定环境中验证这一思路，该环境天然适合用[[资源描述框架（RDF）]]图来表达状态与观测。

## 方法

该方法的设计围绕三个层次展开，每一层次都体现了神经-符号融合的深思熟虑。

首先是记忆表示层。研究者将智能体的隐藏状态和观测都表示为 RDF 图，这是一种在语义网领域广泛使用的标准知识表示形式。每条边（主语-谓词-宾语三元组）都可以附加时间标注，形成时序化的记忆条目。这种表示方式的优势在于：记忆内容具有明确的语义结构，人类可以直接理解"智能体记住了在第 $t$ 时刻位置 A 与位置 B 之间存在通道"这样的事实，而非仅仅看到一个高维向量。

其次是编码与推理层。记忆内容通过 StarE-GNN 编码器进行聚合与更新。StarE-GNN 是一种能够处理带标注 RDF 图的图神经网络，它在保持图结构的同时，能够捕捉时间限定符（如"在某个时间点之前"、"持续到某个时刻"）所携带的时序语义。编码后的记忆表示被传递给一组价值头（value heads），分别负责问答、探索与遗忘三个维度的评估。这三个价值头的设计颇有意思——它们并非独立运作，而是共同构成一个多目标决策模块，使得智能体能够在利用已有知识、探索新领域、以及管理记忆容量之间做出权衡。

最后是元策略层，这是整个方法最核心的创新点。研究者的目标不是让神经网络直接输出动作，而是让它学习"在当前情境下应该应用哪种符号记忆启发式"。这些启发式可能是规则化的操作，例如"如果某个记忆片段超过 $k$ 个时间步未被访问，则标记为可遗忘"或"如果当前观测与已有记忆的语义相似度低于阈值，则创建新记忆"。神经网络作为元策略，其输出是这些启发式的选择概率，而实际执行的操作仍然是完全符号化的——你能够精确地知道在第 $t$ 步执行了"遗忘第 $i$ 条记忆"这样的操作。

这种设计的精妙之处在于：它将"学习什么记忆策略"的任务交给了神经网络，而将"如何执行记忆操作"的逻辑保持在符号层面。前者赋予了系统自适应复杂环境的能力，后者则保证了决策过程的可追溯性与可解释性。用更直观的话说：神经网络是大脑，负责判断；符号系统是手脚，负责执行精确的动作。

## 实验与结果

实验在 RoomKG 环境中进行，这是一个专门设计用于评估记忆管理能力的网格世界变体。研究者设置了长期记忆容量为 512 的约束，并将房间划分为训练集与测试集，以评估模型的泛化能力。

主要对比对象包括三类系统：纯符号系统（完全依赖预定义规则管理记忆）、纯神经系统（使用端到端神经网络处理记忆），以及该工作提出的神经-符号系统。评估指标涵盖保留测试性能（即在测试房间上的最终表现）以及记忆管理决策的可追溯性。

结果表明，StarE-GNN 配置（具备限定符感知能力）在所有三类系统中取得了最佳的保留测试性能。具体的性能数字虽然在原文中以详细表格呈现，但核心结论是清晰的：神经-符号方法在自适应性与泛化能力上都优于纯粹的符号方法，而其在可解释性上的优势则体现在能够逐步骤回溯记忆管理决策——你能够准确说出"在第 1523 步，智能体选择了遗忘策略，因此删除了第 208 号记忆条目"。

值得注意的是，该实验设置同时验证了方法在分布内（训练房间）与分布外（测试房间）的表现，这对于实际部署至关重要——一个只在训练环境有效的方法价值有限。

## 讨论与可借鉴点

这项工作最值得关注的价值在于它为[[强化学习]]中的记忆管理提供了一种新的设计思路：通过将"学习"与"执行"解耦，让神经网络负责策略层面的决策（学习哪种启发式），而保持符号系统负责操作层面的执行（精确执行记忆的增删改查）。这种分工使得系统既有足够的学习灵活性，又保留了决策过程的可审计性。

然而，该方法也存在明显的局限。首先，它依赖于 RoomKG 这一特定环境的设计，在完全不同的场景（如连续动作空间或高维图像输入）中是否仍能保持优势尚需验证。其次，RDF 表示虽然语义丰富，但编码与推理的计算开销可能成为规模化应用的瓶颈。第三，三个价值头的权重设计（问答、探索、遗忘之间的平衡）仍然是手动设定的，这暗示了更高层次的自适应机制还有探索空间。

对于相关领域的研究者而言，这项工作提供了一个可借鉴的范式：在设计神经-符号系统时，不必追求"让神经网络做所有事"，而是思考哪些决策需要学习的自适应能力，哪些决策需要保持符号化的透明性。这种分层的神经-符号架构或许能够在更多任务中找到应用——不仅是记忆管理，还包括规划、推理、以及多智能体协作等更复杂的认知任务。

## 摘要
部分可观测强化学习需要在时间维度上决定保留、检索与遗忘哪些信息。我们提出一种神经-符号元策略，学习在每个决策点应用哪种符号记忆启发式，同时保持执行过程的符号化特性。我们的设定在 RoomKG 中使用时序知识图谱记忆，其中隐藏状态与观测以资源描述框架（RDF）图表示，记忆通过时序 RDF 三元组标注加以增强。该模型将记忆内容的知识图谱编码与面向问答、探索和遗忘的价值头相结合，形成一个兼具自适应性与可检视性的控制器。这项工作通过基于 RDF 的表示、兼容标注的图语义以及对显式记忆状态执行的基于图的符号运算，直接奠定了其语义网基础。在长期记忆容量为 512 的训练/测试房间划分条件下，具备限定符感知能力的 StarE-GNN 配置在所对比的符号、神经和神经-符号系统中取得了最佳的保留测试性能，同时保留了记忆管理决策的逐步可追溯性。

## Abstract
Partially observable reinforcement learning requires deciding what to retain, retrieve, and forget over time. We introduce a neuro-symbolic meta-policy that learns which symbolic memory heuristic to apply at each decision point while keeping execution symbolic. Our setting uses temporal knowledge-graph memory in RoomKG, where hidden state and observations are represented as Resource Description Framework (RDF) graphs and memory is augmented with temporal RDF triple annotations. The model combines knowledge-graph encoding of memory contents with value heads for question answering, exploration, and forgetting, yielding a controller that is both adaptive and inspectable. This gives the work a direct Semantic Web grounding through RDF-based representation, annotation-compatible graph semantics, and graph-based symbolic operations over explicit memory state. On train/test room splits at long-term memory capacity of 512, the qualifier-aware StarE-GNN configuration achieves the best held-out performance among the compared symbolic, neural, and neuro-symbolic systems while preserving step-level traceability of memory-management decisions.
