## 摘要
带可验证奖励的强化学习（RLVR）为语言模型推理提供了可靠的结果监督，但标量轨迹奖励对 token 级别的指导有限。现有的自蒸馏方法增加了一个特权教师，但通常为其分配固定的角色：直接分布匹配可能会破坏成功的行为，而仅调节幅值的方式在失败后几乎不提供纠正性指导。我们观察到，成功轨迹和失败轨迹需要不同形式的事后监督。成功的响应本身已包含由学生模型生成的有效推理路径，因此可以作为特权上下文，而无需被外部推理所替代；而失败的响应则需要纠正性的参考信息。我们提出了混合事后自蒸馏（H$^2$SD），它根据轨迹的正确性联合调整教师上下文与更新策略。对于成功轨迹，我们从已验证的响应和一条改写指令构建教师上下文，并仅使用教师重新评估原始响应 token。由此得到的概率在不改变由奖励所决定方向的前提下，细化了 token 级的信用分配。对于失败轨迹，已验证的参考提示通过反向 KL 蒸馏提供纠正性指导。在具有挑战性的推理基准上的实验表明，H$^2$SD 在代表性的 RLVR 与自蒸馏基线中取得了最强的综合性能，并具有稳定的优化过程以及有利的精度-效率权衡。

## Abstract
Reinforcement learning with verifiable rewards (RLVR) provides reliable outcome supervision for language model reasoning, but a scalar trajectory reward offers limited token-level guidance. Existing self-distillation methods add a privileged teacher but typically assign it a fixed role: direct distribution matching may destabilize successful behavior, while magnitude-only modulation offers little corrective guidance after failure. We observe that successful and failed trajectories require different forms of hindsight supervision. A successful response already contains a valid student-generated reasoning path and can therefore serve as privileged context rather than being replaced by an external rationale. A failed response, however, requires corrective reference information. We introduce Hybrid Hindsight Self-Distillation ($\mathrm{H}^{2}\mathrm{SD}$), which jointly adapts teacher context and update strategy to trajectory correctness. For successful trajectories, we construct the teacher context from the verified response and a rephrasing instruction, and use the teacher only to re-evaluate the original response tokens. The resulting probabilities refine token credit assignment without changing the direction determined by the reward. For failed trajectories, a verified reference hint provides corrective guidance through reverse-KL distillation. Experiments on challenging reasoning benchmarks show that H$^2$SD achieves the strongest overall performance among representative RLVR and self-distillation baselines, with stable optimization and a favorable accuracy-efficiency trade-off.

# H$^2$SD：混合事后自蒸馏 — 论文总结

## 1. 核心问题与研究动机

RLVR（带可验证奖励的强化学习）通过 GRPO 等算法为 LLM 推理提供可靠的结果监督，但**标量轨迹级奖励**只能告诉模型"整条轨迹对/错"，无法提供 token 级的细粒度指引，造成信用分配（credit assignment）瓶颈。

为缓解该问题，已有两条路线：

- **On-Policy Distillation (OPD)**：引入更强的教师模型提供 token 级 logits 监督，但要求教师与学生共享词表，且强教师不易获得。
- **On-Policy Self-Distillation (OPSD)**：用同一模型同时充当师生，并给教师附加"特权信息"（如真实答案、已验证响应等），但直接做分布匹配易导致**特权信息泄漏**与训练不稳定。
- **RLSD**：改用教师信号仅调制 token 级更新幅度（magnitude modulation），缓解了泄漏，但**失去对失败轨迹的方向性纠错能力**。
- **SRPO**：对成功轨迹走 GRPO、失败轨迹走自蒸馏，但纠错信号较弱。

本文观察到的关键问题：成功与失败轨迹所需的监督形式**本质不同**——成功轨迹已有学生生成的合法路径，只需细粒度信用调整；失败轨迹需要**方向性的纠正参考**。

## 2. 方法论

### 2.1 核心思想

**H$^2$SD（Hybrid Hindsight Self-Distillation）**：依据轨迹正确性 $m = \mathbb{1}[R(x,y)=1]$ 联合选择教师上下文与更新策略：

$$\mathcal{L}_{\mathrm{H}^2\mathrm{SD}} = \mathbb{E}_{x,y}\Big[m\cdot \mathcal{L}_{\mathrm{RLSD}} + \gamma(1-m)\cdot \mathcal{L}_{\mathrm{RKL}}\Big]$$

### 2.2 关键技术细节

- **提示（Hint）生成**：用外部更强模型 Kimi-K2.6 离线为每个问题生成自然语言提示 $h=\mathcal{H}(x)$，包含关键中间推理步骤和经验证的最终答案。教师 = 同一个学生模型，但条件在 $h$ 上：
$$p^{T,h}_{t,\theta}(\cdot) = \pi_\theta(\cdot\mid x, h, y_{<t}),\quad p^S_{t,\theta}(\cdot)=\pi_\theta(\cdot\mid x, y_{<t})$$

- **成功轨迹（$m=1$）**：
  - 教师输入：已验证的学生响应 + "改写指令"。
  - 教师**不生成新回答**，仅 teacher-forcing 对原始 token 重打分，得到幅度权重 $w_t$：
$$w_t = \left(\frac{P^T(y_t)}{P^S(y_t)}\right)^{\mathrm{sign}(A)}$$
  - token 级优势：
$$\hat{A}_t = A\cdot\big[(1-\lambda)+\lambda\cdot\mathrm{clip}(w_t, 1-\epsilon_w, 1+\epsilon_w)\big]$$
  - 保留 GRPO 的截断目标方向，**仅细化 token 级信用**。

- **失败轨迹（$m=0$）**：
  - 教师条件在离线提示 $h$ 上，对学生做**反向 KL 蒸馏**：
$$\mathcal{L}_{\mathrm{RKL}} = \frac{1}{T}\sum_{t=1}^T D_{\mathrm{KL}}\!\Big(p^S_{t,\theta}\,\big\|\,\mathrm{sg}[p^{T,h}_{t,\theta}]\Big)$$
  - 提供方向性纠错信号。

### 2.3 算法流程概述

1. 学生采样 $G$ 条轨迹，得奖励与正确性标记 $m$。
2. 对 $m=1$ 轨迹：构造"改写+已验证响应"的教师上下文，用 RLSD 幅度调制更新。
3. 对 $m=0$ 轨迹：构造"提示 $h$"的教师上下文，用反向 KL 蒸馏更新。
4. 加权求和得总损失。
