## 摘要
异步强化学习（RL）通过将 rollout 生成与策略优化重叠来加速大语言模型（LLM）的后训练，但由此产生的陈旧离策略数据会使优化变得不稳定，并最终导致策略崩溃。现有方法通常仅依据重要性比率的大小来保留或丢弃 token，在所有 token 位置上一致地应用相同的阈值。在本工作中，我们揭示了重要性比率的自然尺度随 token 熵系统性地变化。在异步动态下，这种熵-比率缩放关系会导致两种不同的现象：在低熵情况下，固有的训练-推理差异被急剧放大成显著的采样噪声；在高熵情况下，飞行中的权重更新自然地引发显著且合理的探索性偏离。因此，仅基于幅度的修正会无意中接纳被放大的噪声，同时严格屏蔽掉由飞行中更新所触发的必要探索。为解决这一问题，我们提出了熵缩放信任域（ESTR），它通过每个 token 的局部熵来缩放其离策略偏差，无需额外的前向传播或显式的版本切换检测。在长视野智能体任务和数学推理基准测试中，ESTR 一致地优于现有异步方法，并实现了最佳的训练-推理一致性。与同步 GRPO 相比，ESTR 在达到相近准确率的同时，将训练速度提升了 2.6 倍。

## Abstract
Asynchronous reinforcement learning (RL) accelerates large language model (LLM) post-training by overlapping rollout generation with policy optimization, but the resulting stale, off-policy data can destabilize optimization and ultimately cause policy collapse. Existing methods typically retain or discard tokens based solely on the magnitude of their importance ratios, applying the same threshold uniformly across token positions. In this work, we reveal that the natural scale of the importance ratio varies systematically with token entropy. Under asynchronous dynamics, this entropy-ratio scaling dictates two distinct phenomena: at low entropy, the inherent train-inference discrepancy is drastically amplified into substantial sampling noise; at high entropy, in-flight weight updates naturally induce pronounced, legitimate exploratory deviations. Consequently, magnitude-only correction inadvertently admits the amplified noise while strictly masking out the essential exploration triggered by in-flight updates. To address this, we propose the Entropy-Scaled Trust Region (ESTR), which scales each token's off-policy deviation by its local entropy, requiring no auxiliary forward passes or explicit version-switch detection. Across long-horizon agentic tasks and mathematical reasoning benchmarks, ESTR consistently outperforms existing asynchronous methods and achieves the best train-inference consistency. Compared with synchronous GRPO, ESTR attains comparable accuracy while improving training speed by $2.6\times$.

# 论文总结：ESTR（熵缩放信任域）

## 1. 核心问题与研究背景

- **研究场景**：异步强化学习（Asynchronous RL）已成为大规模 LLM 后训练的主流范式。它通过将 rollout 生成与策略优化并行运行，显著提高吞吐量，但同时也引入了严重的 **off-policy 陈旧性（staleness）**问题：用于训练的 rollout 是由滞后甚至快速发散的行为策略（behavior policy）生成的。
- **核心矛盾**：长程多轮 rollout 中，一条轨迹可能跨越多个权重版本，导致 *intra-trajectory version switching*（轨迹内版本切换）与 *inter-trajectory lag*（轨迹间滞后）。在高 GIP（梯度-推理失配）情况下，训练容易陷入 **不可逆的策略崩溃**。
- **现有方法的局限**：主流稳定化方案（如 IcePop、KPop 等）均属于"基于幅值"的过滤——它们仅以重要性比 $|\delta_t|$ 的大小为标准，对所有 token 统一施加固定阈值。这隐含两个有缺陷的假设：
  - 单凭 $|\delta_t|$ 的绝对幅值即可判断 token 的"可信度"；
  - 单条轨迹可视为由单一、明确的行为策略生成。
- **本文发现**：重要性比的"自然尺度"与 **token 熵 $H_t$** 系统性耦合，满足 $E[\delta_t^2] \propto H_t$（理论推导见附录 A）。这导致异步 RL 中出现两种反向现象：
  - **低熵处**：分母近零放大训练-推理微小差距，产生被严重放大的 *采样噪声*（不是策略漂移）；
  - **高熵处**：in-flight 权重更新自然引发的大 $|\delta_t|$ 实际为 *真实探索*，应被保留。
- 固定阈值无法区分这两种现象，导致"接纳噪声、扼杀探索"的系统性偏差。

## 2. 方法论：熵缩放信任域（ESTR）

### 2.1 核心思想

将"信任域边界"从 *全局固定阈值* 改造为 **依赖 token 局部熵** 的动态边界：

$$|\delta_t| \leq \sqrt{\tau\,(H_t + \epsilon)}$$

其中 $\tau$ 控制总预算，$\epsilon$ 为防止 $H_t \approx 0$ 的常数项。

### 2.2 关键技术细节

- **重要性比定义**：
$$\delta_t \triangleq \log \frac{\pi_\theta(y_t \mid s_t)}{\mu_t(y_t \mid s_t)}, \quad H_t \triangleq -\sum_{w \in V} \mu_t(w \mid s_t) \log \mu_t(w \mid s_t)$$

- **熵-比值缩放定律**（Proposition 2）：在 logit 扰动模型 $\pi_\theta(w) = \frac{e^{z_w + \eta_w}}{\sum_v e^{z_v + \eta_v}}$ 下，一阶展开得到
$$E[\delta_t^2] = \sigma_t^2 \sum_{w \in V} \rho_w (1 - \rho_w) \approx \sigma_t^2 H_t$$
即 off-policy 偏离的二阶矩与局部熵线性相关。

- **二阶信任域推导**：由 KL 散度的 Taylor 展开
$$D_{\mathrm{KL}}(\mu_t \| \pi_\theta) \approx \frac{1}{2} E_{v \sim \mu_t}\!\left[\delta_t(v)^2\right]$$
传统固定预算 $\delta_t^2 \leq c$ 假设数据为同方差（homoscedastic），与上述 *异方差*（heteroscedastic）性质矛盾。

- **熵标准化预算**：定义标准化偏离
$$z_t \triangleq \frac{\delta_t}{\sqrt{\nu_t}}, \quad \nu_t \triangleq H_t + \epsilon, \quad z_t^2 \leq \tau$$
在开关点（switch point），尽管 $\delta_t$ 与 $H_t$ 同步飙升，$z_t$ 仍近似保持 $\sigma_t$ 的尺度，**与熵无关**（Proposition 3）。

- **ESTR 保留掩码**：
$$M_{i,t} = \mathbf{1}\!\left[S_{i,t} \leq \tau\right], \quad S_t \triangleq \frac{\delta_t^2}{H_t + \epsilon}$$

- **严格广义性**（Proposition 4）：若强制 $H_t + \epsilon \equiv C$，则规则退化为固定阈值 $|\delta_t| \leq \sqrt{\tau C}$。ESTR 的边界在低熵处严格更紧（消除放大噪声），在高熵处严格更宽（保留探索），二者仅在交叉点 $H^\star = C - \epsilon$ 处重合。

- **完整目标函数**（结合 PPO 风格 clip）：
$$L_{\mathrm{ESTR}}(\theta) = -\mathbb{E}\!\left[\frac{1}{\sum_i |o_i|} \sum_{i,t} M_{i,t} \cdot \min\!\left(r_{i,t} A_{i,t},\ \mathrm{clip}(r_{i,t},1-\epsilon_{\mathrm{low}},1+\epsilon_{\mathrm{high}}) A_{i,t}\right)\right]$$

其中 clip 控制受信任 token 的步长，$M_{i,t}$ 则直接丢弃违反熵缩放边界的 token（hard mask，stop-gradient），梯度形式为
$$\nabla_\theta L_{\mathrm{ESTR}} = -\mathbb{E}\!\left[\frac{1}{P} \sum_{i,t} M_{i,t}\, C_{i,t}\, r_{i,t} A_{i,t}\, \nabla_\theta \log \pi_\theta(o_{i,t}|s_{i,t})\right]$$

- **实施优势**：$H_t$ 直接读自推理侧 logit，**无需任何额外前向传播**，也无需显式探测版本切换点。

- **训练 token 数**：最长响应长度 32768，prompt 长度 4096，最大轮数 100（BrowseComp-Plus）

> 注：原文未给出每个任务的 *绝对训练小时数*，仅给出 per-step 时间与吞吐量。

## 5. 实验数量与充分性

- **任务覆盖**：3 类任务（长程 agentic / 多轮工具调用 / 单轮数学推理），2 个不同规模模型（MoE 30B-A3B、dense 7B），跨域且异质。
- **基线对照**：4 个基线（sync / async / IcePop / KPop），其中 3 个异步方法形成公平对比（同一 off-policy 数据集、同一 keep mask 接口）。
- **鲁棒性测试**：
  - Intra-trajectory staleness 扫描（4 个值）
  - Inter-trajectory staleness 扫描（5 个值）
  - 超参 $\tau$ 扫描（3 个值 × 2 个任务）
  - 全局 batch size 扫描（4 个值）
- **诊断与可视化**：mask 演化图（训练 step 0–800 的联合分布演化）、IS 比值标准差、masked fraction、log-perplexity、wall-clock 时间等 6+ 条曲线。
- **超参搜索**：默认 $\tau$ 与 batch size 对结果影响在 1 个百分点以内，表明方法对阈值不敏感。
- **消融**：通过理论 Proposition 4 严格证明 ESTR 是固定阈值的严格广义化，构成一种"结构化消融"。
- **公平性**：所有方法共享同一 rollout 池、同一 logprob、同一 PPO clip 设置；同步与异步在 *相同总硬件预算* 下比较。

总体而言，实验较为充分，覆盖了精度、稳定性、效率、鲁棒性多个维度，且对比设置公平。

## 6. 主要结论与发现

- **精度层面**：
  - BrowseComp-Plus：**37.34 avg@1**，超过最强异步基线 KPop (34.94) 与 IcePop (32.53)，逼近同步 GRPO (38.55)
  - Multi-turn GSM8K：**95.69**，几乎匹配同步 GRPO (96.07)；基线崩溃至 60–71
  - AIME 2024–2026：**avg@4 = 17.04**（vs 同步 17.54），**pass@4 = 28.38**，**超过**同步 GRPO (27.68)
- **稳定性层面**：
  - 在 GSM8K 上，IcePop/KPop 在几百步内 *不可逆崩溃*；ESTR 全程稳定
  - 在 DAPO-Math 上，原生异步 GRPO 早期即崩塌，IcePop/KPop 平台化，ESTR 持续上升
  - ESTR 维持最低且最稳定的 *rollout–target KL*，且策略熵稳步上升（健康探索）
- **效率层面**：在 *相同硬件* 下训练速度 **2.6×**，单步时间缩短 62%，且 *几乎不增加任何 overhead*（每 token 仅一次熵读取）
- **掩码行为**：ESTR 的 masked fraction $\rho_{\mathrm{mask}}$ 比固定阈值基线 **低约一个数量级**，却仍保持最低的 IS 比值标准差——证明它精准丢弃噪声 token 而非探索 token
- **健壮性**：在 $\Delta_{\mathrm{intra}}\in\{1,5,7,9\}$、$\Delta_{\mathrm{inter}}\in\{1,5,15,20,30\}$ 的所有扫描下都不崩溃，奖励随 staleness 单调优雅下降
- **理论意义**：确立了"off-policy 偏离应按 token 局部熵标准化"的统一原则

## 7. 方法与实验设计的亮点

- **理论驱动**：从 logit 扰动模型一阶展开严格推导出 $E[\delta_t^2] \approx \sigma_t^2 H_t$，揭示 token 熵与重要性比之间的内禀耦合，而非经验观察
- **二阶 KL 一致性**：将信任域约束直接联系到 $\frac{1}{2}E[\delta_t^2]$（KL 二阶近似），与 PPO/TRPO 的数学框架一致
- **Switch-point 不变性**（Proposition 3）：标准化后的偏离在 in-flight 版本切换点保持尺度稳定，使方法天然吸收 staleness
- **严格广义性**（Proposition 4）：固定阈值是 ESTR 在 *单一交叉点* 处的特例，提供了优雅的"前向兼容"关系
- **零额外开销**：熵值可由推理 logit 直接读取，无需额外前向传播，也无需显式探测版本切换点
- **Stop-gradient 掩码**：与 PPO clip 各司其职（clip 约束步长，mask 移除违反信任域的 token），工程实现简洁
- **mask 自适应**：随训练进行 $\rho_{\mathrm{mask}}$ 自动调节（0.1% → 4.8%），无需手工 schedule
- **充分诊断**：mask 在 $(H_t,|\delta_t|)$ 平面上的演化图直观展示方法的运作机制

## 8. 不足与局限

- **模型覆盖有限**：仅在 Qwen3-30B-A3B 与 Qwen2.5-7B 上验证，未涵盖 dense 更大规模（如 70B+）、其它架构（Llama、DeepSeek 等）以及更多模态
- **token 熵估计依赖推理端 logit**：若 rollout 与训练侧的 logit 计算精度不一致（如不同 attention 实现、量化），熵标准化可能引入偏差；论文未深入讨论该鲁棒性
- **超长 horizon 的累积误差**：作者明确指出"未来工作将探索更长 horizon 与极端异步场景"，暗示当前结果尚未覆盖超长程 agentic 任务
- **$\tau$ 的迁移性**：BrowseComp-Plus 默认 $\tau=0.7$、DAPO-Math/GSM8K 默认 $\tau=1.6$，任务间需要重新调参；附录敏感性表显示影响不大但非零
- **缺乏对极小 batch / 极小 rollout 场景的测试**：batch size ≥ 32 起步，对极小 batch 的稳定性未验证
- **理论假设简化**：logit 扰动模型为 *一阶近似*，未考察

二阶及高阶扰动项对结论的影响

- **奖励模型/法官依赖**：BrowseComp-Plus 依赖 LLM judge，存在评测噪声与潜在偏置；论文未做多次种子或多模型 judge 的稳定性验证
- **缺乏对失败模式的具体分析**：未深入剖析 ESTR 在何种极端情况（如全部 token 同时高熵或全部低熵）下可能失效
- **理论结果与实践之间存在"一阶近似"鸿沟**：Proposition 2 仅为一阶展开，实际训练中 logit 扰动幅度可能更大，缺乏有限样本/有限扰动的误差界
- **未与 RLHF 通用管线整合测试**：本文聚焦 RL 后训练中的 GRPO 范式，对 actor-critic、PPO with value model、online DPO 等场景的迁移性未验证

## 9. 总体评价

**ESTR** 提出了一种理论驱动的、面向异步 RL 的"熵缩放信任域"机制。其核心贡献在于：

1. **揭示了一个被长期忽视的内禀耦合**——token 熵与重要性比方差之间的 $E[\delta_t^2] \propto H_t$ 关系——并由此诊断出固定阈值方法在异步 RL 中的"反直觉偏差"（接纳噪声、扼杀探索）。
2. **给出了形式简洁、可解释性强的修正**——仅用一个标准化分数 $S_t = \delta_t^2 / (H_t + \epsilon)$ 取代固定阈值，且严格包含固定阈值作为特例，具有优雅的理论兼容性。
3. **在工程层面几乎"零额外开销"**——熵值直接从推理 logit 读取，无须额外前向、无须探测版本切换点，使其极易集成到现有异步 RL 框架（如 verl、AsyncRLHF）。
4. **实验覆盖与稳定性论证充分**——跨三类异质任务、两个模型规模、多个 staleness 扫描、超参敏感度与硬件公平对比下，均展示出"逼近同步 GRPO 精度 + 2.6× 训练加速 + 鲁棒抗崩溃"的综合优势。

本文的主要价值在于将异步 RL 的稳定性问题从"经验调参"提升到"理论指导的统计修正"，并以最小工程代价落地。其局限（模型族覆盖不足、超长 horizon 未验证、对 rollout/训练侧 logit 一致性的依赖）为后续工作留下了明确的方向。

**适用场景推荐**：ESTR 特别适合以下情形——长 horizon 多轮 agentic 任务、大规模 MoE 模型 RL 后训练、严格延迟容忍但硬件紧缺的工业级 RL 系统。对于推理与训练使用不同 attention kernel 或量化精度的部署，建议在使用前做一轮 logit 分布一致性检验。
