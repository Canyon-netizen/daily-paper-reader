## 摘要
我们研究了一个去中心化强化学习问题，其中多个智能体与同一马尔可夫决策过程（MDP）进行交互。智能体可以通过网络交换信息，以协同学习最优状态-动作值函数。针对该问题，我们提出了一种新颖的基于轮次的分布式 Q 学习算法，称为 VRDQ，在每个轮次内，智能体局部估计贝尔曼最优算子，并使用基于一致性的协议扩散信息。对于静态网络和时变网络，我们均建立了 VRDQ 的高概率有限时间收敛率，其因协作而获得了线性加速。关键的是，我们证明样本复杂度上的此类加速仅需 $\tilde{O}(1)$ 的通信成本，大幅优于现有工作中的通信开销。

## Abstract
We investigate a decentralized reinforcement learning problem involving multiple agents that interact with the same Markov Decision Process (MDP). The agents can exchange information over a network to collectively learn the optimal state-action value function. For this setting, we introduce a novel epoch-based distributed $Q$-learning algorithm called VRDQ, where within each epoch, agents locally estimate the Bellman optimality operator and diffuse information using a consensus-based protocol. For both static and time-varying networks, we establish high-probability finite-time convergence rates for VRDQ that enjoy linear speedups from collaboration. Crucially, we prove that such speedups in sample-complexity require only $\tilde{O}(1)$ communication, substantially improving upon the communication costs in prior work.

## 1. 核心问题与研究动机

- 关键问题：
  - **(i) 样本效率**：通过协作，每个智能体能否从单智能体的 $\tilde{O}(1/\sqrt{T})$ 加速到 $\tilde{O}(1/\sqrt{NT})$？

论文指出已有去中心化 Q 学习工作（如 QD-learning [Kar et al., 2013]、分布式 TD(0)/Q-learning [Doan et al., 2019; Heredia et al., 2020]）存在两大不足：
1. 最终误差界中**未显式体现协作带来的统计加速**；
2. 通信成本随时间步数**线性增长**（$O(T)$），导致提高精度必然伴随高额通信开销，限制了实际部署。

本文的目标正是**同时获得近最优的样本复杂度协作加速 $\tilde{O}(1/\sqrt{NT})$，并把通信开销降至 $\tilde{O}(1)$**（即关于 $N$、$T$ 仅 poly-log 增长），且覆盖静态与时变网络。

## 2. 方法论

### 2.1 核心思想

提出 **VRDQ（Variance-Reduced Diffused Q-Learning）**，核心由两个并行模块组成：

- **模块一：局部算子估计（Variance Reduction）**：每个智能体在一个 epoch 内用 $H$ 个样本聚合估计 Bellman 最优算子的低方差版本，而非每步都用单样本高方差估计；
- **模块二：共识扩散（Diffusion）**：在 epoch 的前 $L$ 步并行运行平均一致性协议，扩散上一 epoch 产生的更新方向 $T_{i,k-1}Q_{i,k}$。

由于估计阶段耗时远长于扩散阶段，两者**并行执行**（详见图 1），从而将统计误差与网络诱导误差解耦。

### 2.2 关键公式

**Q 函数真值所满足的 Bellman 最优算子不动点**：
$$T^* f(s,a) := R(s,a) + \gamma \sum_{s' \in \mathcal{S}} P(s'|s,a) \max_{a' \in \mathcal{A}} f(s', a'), \quad \forall f \in \mathbb{R}^{\mathcal{S}\times\mathcal{A}}.$$

**传统单样本噪声算子**（每步更新，方差高）：
$$T_t f(s,a) = R(s,a) + \gamma \max_{a' \in \mathcal{A}} f(s_t(s,a), a').$$

**VRDQ 的低方差经验算子**（每 epoch 一次，使用 $H$ 个样本聚合估计转移核）：
$$P_{i,k}(s'|s,a) = \frac{1}{H}\sum_{u=0}^{H-1} \mathbf{1}^{i,k,u}_{s,a}(s'),$$
$$T_{i,k} f(s,a) := R_{i,k}(s,a) + \gamma \sum_{s' \in \mathcal{S}} P_{i,k}(s'|s,a) \max_{a' \in \mathcal{A}} f(s', a').$$

**扩散协议**（仅在 epoch 内前 $L$ 步执行）：
$$d^{(\ell+1)}_{i,k}(s,a) = \sum_{j \in \mathcal{N}_i} (W)_{ij}\, d^{(\ell)}_{j,k}(s,a), \quad \ell = 0,\dots,L-1,$$
初始值 $d^{(0)}_{i,k} = T_{i,k-1}Q_{i,k}$（按惯例 $T_{i,-1}f = 0$），并且
$$d^{(L)}_{i,k}(s,a) = [W^L]_{i,\cdot}\, d^{(0)}_{k}(s,a).$$

**Q 表更新**（每 epoch 末一次）：
$$Q_{i,k+1} = (1-\alpha) Q_{i,k} + \alpha\, d^{(L)}_{i,k}.$$

### 2.3 超参数选择（Theorem 1）

算法 1 中的步长 $\alpha$、epoch 数 $K$、扩散步数 $L$ 选为：
$$\alpha = \frac{\log(NT)}{(1-\gamma)K}, \qquad K = \lceil c_1 \log(NT)/(1-\gamma)\rceil, \qquad L = \left\lceil \frac{\log\!\left(c_2 N^{3/2}\sqrt{T}\sqrt{p_{1-\gamma}}\right)}{\log(1/\rho)}\right\rceil,$$
其中 $\rho \in (0,1)$ 是双随机矩阵 $W$ 的谱收缩常数（见 Fact 1）。

### 2.4 时变网络扩展（Theorem 2）

对满足标准 Assumption 1 的双随机时变矩阵序列 $\{W(t)\}$，仅需将扩散过程替换为 $W(kH+\ell)$ 驱动，且每个 epoch 扩散 $\bar{L}B$ 步：
$$d^{(\ell+1)}_{i,k}(s,a) = \sum_{j \in \mathcal{N}_i(kH+\ell)} (W)_{ij}(kH+\ell)\, d^{(\ell)}_{j,k}(s,a).$$
$\bar{L}$ 的取值与 $L$ 类似，只是把 $\rho$ 替换为 $\omega = \sup_{t \ge B-1} \|W_B(t) - \tfrac{1}{N}\mathbf{1}\mathbf{1}^\top\|_2$。

## 6. 主要结论与发现

**Theorem 1（静态网络）**：在 Theorem 1 给定的参数选取下，VRDQ 以至少 $1-\delta$ 的概率满足：
$$e_{i,K} \leq \frac{e_{i,0}}{NT} + O\!\left(\frac{\bar{R}\sqrt{\log(NT)\,\log(2SAT/\delta)}}{(1-\gamma)^{2.5}\sqrt{NT}}\right).$$

这给出三个核心发现：

1. **近最优的协作加速**：$\tilde{O}(1/\sqrt{NT})$，与单智能体 $\tilde{O}(1/\sqrt{T})$ 相比获得关于 $N$ 的线性加速，达到集中式/联邦式方法的最佳统计效率（在 $(1-\gamma)$ 多项式因子内）。
2. **通信成本对数化**：总通信量 $KL = O(\log^2(NT))$，相对已有工作 $O(T)$ 的通信成本是数量级提升。
3. **网络拓扑仅影响"热身"阶段**：稳态收敛率与拓扑无关，但 $\rho$ 决定了所需的最小扩散步数 $L$，进而要求 $T$ 不小于某下界。

**Theorem 2（时变网络）**：在 Assumption 1 下 VRDQ 保持完全相同的 $\tilde{O}(1/\sqrt{NT})$ 收敛界，且通信开销仍为 poly-log（$K\bar{L}B$ 关于 $T$ 为对数量级），其中 $B$ 与 $T$ 无关（但可能与 $N$ 相关）。
