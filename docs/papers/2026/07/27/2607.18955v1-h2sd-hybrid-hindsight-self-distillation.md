## TL;DR

H²SD（Hybrid Hindsight Self-Distillation）提出了一种针对大语言模型强化学习可验证奖励方法的混合自蒸馏框架。其核心思路是根据轨迹的正确性采取不同的教师利用策略：对成功轨迹使用教师概率进行幅度调制以细化信用分配，对失败轨迹通过反向 KL 散度提供明确的修正方向。在 Sudoku、Calcudoku 和 Arrow Maze 三个逻辑推理基准上，H²SD 取得了最高 76.50% 的准确率，相较最优基线提升约 49 个百分点，同时保持了更优的生成效率。

## 研究背景与动机

大语言模型在数学推理和代码生成等任务上的突破，很大程度上得益于基于可验证奖励的强化学习方法（RLVR）。这类方法以 GRPO 为代表，通过奖励信号指导模型生成符合要求的答案。然而，当前的 RLVR 框架面临一个根本性的局限：将单一的标量奖励分配给整条推理轨迹。这种粗粒度的监督方式导致 token 级的信用分配严重不足——模型无法精确判断推理链中的哪些中间步骤真正推动了成功，哪些步骤只是搭了顺风车。

为了缓解监督稀疏的问题，研究者先后提出了几种改进思路。在策略蒸馏（OPD）通过引入更强的教师模型，在 token 级别提供分布监督，让模型学习教师对每个位置的概率分布。但这种方法依赖额外的教师模型，且通常要求师生共享词表，工程代价较高。在策略自蒸馏（OPSD）则尝试让同一模型扮演师生角色，通过给教师输入特权信息（如正确答案是"9"）来构建教师策略，学生则基于原始问题条件化生成响应。然而，直接匹配教师分布会引发特权信息泄露——模型可能学到"当答案是9时，下一个token应该是..."这样的捷径，而非真正理解推理过程，导致训练不稳定。

随后出现的 RLSD 方法试图规避分布匹配带来的风险。它不再强迫学生直接模仿教师分布，而是用教师的概率信号来调节 token 级的更新幅度，保留奖励确定的梯度方向。这种设计在成功轨迹上效果不错，但在采样到失败轨迹时，问题变得棘手：仅调节幅度不足以提供明确的修正方向，模型只知道"这个地方要少更新一点"，却不知道"正确的答案应该是什么样的"。

这三种方法的困境揭示了一个关键洞察：**成功轨迹与失败轨迹对监督的需求本质上是不同的**。成功轨迹已经有了可靠的奖励方向，需要的是细化信用分配、精准调整置信度；失败轨迹则迫切需要知道正确的推理路径应该是什么样子的。这构成了 H²SD 设计的出发点。

## 方法

H²SD 的核心创新在于**结果条件路由**（Outcome-Conditioned Routing）：根据轨迹的正确性，以不同的方式利用教师模型。

对于成功轨迹，H²SD 采用类似 RLSD 的幅度调制策略。这里的关键设计在于教师 prompt 的构造：教师不仅看到原始的学生响应（已被验证器确认为正确），还额外接收一条改述指令，要求其"在不改变逻辑的前提下，用另一种表述重新表达"。教师在原始响应 token 上的概率分布被用来计算调制权重：

$$w_t = \exp\left(\mathrm{sign}(A) \cdot \Delta_t\right) = \left(\frac{P_T(y_t)}{P_S(y_t)}\right)^{\mathrm{sign}(A)}$$

其中 $\Delta_t$ 是教师与学生 log 概率之差的 stop-gradient 项。这个权重作用于 token 级的优势估计，使得高置信度的 token 获得更大的更新幅度，低置信度的 token 被抑制。重要的是，调制只改变幅度，不改变由奖励确定的梯度方向——这避免了直接分布匹配可能带来的信息泄露问题。改述指令的引入则进一步解耦了"正确答案"与"具体措辞"，让模型更关注推理过程的稳健性。

对于失败轨迹，H²SD 转而最小化反向 KL 散度。这里的教师被条件化在一个参考提示上，该提示由更强的语言模型生成，包含**关键中间推理步骤**和**验证器确认的最终答案**。形式上，教师分布为 $\pi_T(\cdot \mid x, h, y_{<t})$，其中 $h$ 是包含过程信息的提示。学生分布则为 $\pi_S(\cdot \mid x, y_{<t})$。通过最小化从学生到教师的反向 KL：

$$\mathcal{L}_{\mathrm{RKL}} = \frac{1}{T}\sum_{t=1}^{T} D_{\mathrm{KL}}\!\left(p^S_{t,\theta}\,\big\|\,\mathrm{sg}[p^{T,h}_{t,\theta}]\right)$$

反向 KL 的特性使得学生被拉向教师分布的"峰值"区域，而非覆盖整个分布的"平均"区域。这对于提供明确的修正方向至关重要——模型会学到"在这种情况下，正确答案最可能的下一个 token 是什么"，而非"在所有可能性中加权平均的结果是什么"。

最终的混合目标函数将两种策略统一起来：

$$\mathcal{L}_{\mathrm{H^2SD}} = \mathbb{E}_{x,y}\left[\,m\,\mathcal{L}_{\mathrm{RLSD}} + \gamma(1-m)\,\mathcal{L}_{\mathrm{RKL}}\,\right]$$

其中 $m$ 是轨迹正确性的指示函数，$\gamma$ 控制失败轨迹上修正蒸馏的强度。这种设计在保持优化稳定性的同时，为两种轨迹提供了互补的监督信号。

## 实验与结果

实验在三个逻辑推理基准上进行：Sudoku（数独）、Calcudoku（算数数独）和 Arrow Maze（箭头迷宫），每个基准包含多个尺寸变体以测试模型在不同难度下的泛化能力。基座模型为 Qwen3-30B-A3B-Instruct-2507，提示生成器调用 Kimi-K2.6。

## 摘要
基于可验证奖励的强化学习（RLVR）已显著提升了大语言模型在数学推理和代码生成等任务上的推理能力。然而，大多数 RLVR 方法将标量结果奖励分配给整个轨迹，导致监督稀疏且 token 级别的信用分配有限。在策略蒸馏（OPD）通过从更强的教师模型蒸馏 token 级别的分布来提供更密集的监督，但需要额外的教师模型，并且通常假设共享词表。在策略自蒸馏（OPSD）通过在特权信息上对同一模型进行条件化来构建教师策略，从而消除了这种依赖关系。然而，直接匹配教师分布可能导致信息泄露和优化不稳定。RLSD 通过仅使用教师信号来调节更新幅度，避免了直接匹配，但它在采样推理失败时无法提供明确的修正方向。为了解决这种权衡，我们引入了 $\mathrm{H}^{2}\mathrm{SD}$，一种混合事后自蒸馏框架，它根据轨迹正确性以不同方式使用教师。对于成功的轨迹，教师接收被确认为正确的学生响应以及一个改述指令，其在原始响应 token 上的概率被用于调节更新幅度，而不改变由奖励确定的方向。对于失败的轨迹，我们在包含关键推理步骤和已验证答案的参考提示上对教师进行条件化，并最小化从学生到教师的逆 KL 散度。在多个具有挑战性的推理基准上的实验表明，H$^2$SD 在保持稳定优化和有利的生成效率的同时，始终优于代表性的 RLVR、OPSD 和 RLSD 基线方法。

## Abstract
Reinforcement learning with verifiable rewards (RLVR) has substantially improved the reasoning capabilities of large language models on tasks such as mathematical reasoning and code generation. However, most RLVR methods assign a scalar outcome reward to an entire trajectory, resulting in sparse supervision and limited token-level credit assignment. On-policy distillation (OPD) provides denser supervision by distilling token-level distributions from a stronger teacher model, but requires an additional teacher and typically assumes a shared vocabulary. On-policy self-distillation (OPSD) removes this dependency by conditioning the same model on privileged information to construct a teacher policy. However, directly matching the teacher distribution may cause information leakage and unstable optimization. RLSD avoids direct matching by using the teacher signal only to modulate update magnitudes, but it cannot provide an explicit correction direction when the sampled reasoning fails. To address this tradeoff, we introduce $\mathrm{H}^{2}\mathrm{SD}$, a hybrid hindsight self distillation framework that uses the teacher differently according to trajectory correctness. For successful trajectories, the teacher receives the student response confirmed as correct together with a rephrasing instruction, and its probabilities on the original response tokens are used to modulate update magnitudes without changing the direction determined by the reward. For failed trajectories, we condition the teacher on a reference hint containing key reasoning steps and a verified answer, and minimize the reverse KL divergence from the student to the teacher. Experiments on multiple challenging reasoning benchmarks show that H$^2$SD consistently outperforms representative RLVR, OPSD, and RLSD baselines while maintaining stable optimization and favorable generation efficiency.

## 2. 方法论：H²SD 混合事后自蒸馏

### 2.1 提示生成（Hint Design）
使用更强的语言模型（Kimi-K2.6）作为提示生成器 $\mathcal{H}$，对每个问题 $x$ 生成自然语言提示 $h$，包含**关键中间推理步骤**与**验证器确认的最终答案**：

$$h = \mathcal{H}(x)$$

该提示仅训练时可见，由当前学生模型自身条件化生成教师分布：

$$\pi_T(\cdot \mid x, h, y_{<t}) = \pi_\theta(\cdot \mid x, h, y_{<t})$$

### 2.2 混合蒸馏策略

**结果条件路由（Outcome-Conditioned Routing）**：

- **成功轨迹** ($m = \mathbb{1}[R(x,y)=1]$)：教师接收"被验证正确的学生响应 + 改述指令"，其对原响应 token 的概率用于**RLSD 式幅度调制**（不改变奖励确定的方向）。
- **失败轨迹** ($1-m$)：教师在参考提示 $h$ 上条件化，**最小化反向 KL 散度**（Reverse KL）以提供显式修正方向。

### 2.3 关键公式

**RLSD 幅度调制权重**：

$$w_t = \exp\left(\mathrm{sign}(A) \cdot \Delta_t\right) = \left(\frac{P_T(y_t)}{P_S(y_t)}\right)^{\mathrm{sign}(A)}$$

其中 $\Delta_t = \mathrm{sg}\!\left(\log P_T(y_t) - \log P_S(y_t)\right)$，$\mathrm{sg}(\cdot)$ 为 stop-gradient。

**token 级优势**：

$$\hat{A}_t = A\left[(1-\lambda) + \lambda \,\mathrm{clip}(w_t,\, 1-\epsilon_w,\, 1+\epsilon_w)\right]$$

**失败轨迹的反向 KL 目标**：

$$\mathcal{L}_{\mathrm{RKL}} = \frac{1}{T}\sum_{t=1}^{T} D_{\mathrm{KL}}\!\left(p^S_{t,\theta}\,\big\|\,\mathrm{sg}[p^{T,h}_{t,\theta}]\right)$$

其中 $p^S_{t,\theta} = \pi_\theta(\cdot \mid x, y_{<t})$，$p^{T,h}_{t,\theta} = \pi_\theta(\cdot \mid x, h, y_{<t})$。

**H²SD 总体目标**：

$$\mathcal{L}_{\mathrm{H^2SD}} = \mathbb{E}_{x,y}\left[\,m\,\mathcal{L}_{\mathrm{RLSD}} + \gamma(1-m)\,\mathcal{L}_{\mathrm{RKL}}\,\right]$$

其中 $\gamma$ 控制失败轨迹上修正蒸馏的强度。

### 2.4 算法流程
1. 学生策略 $\pi_\theta$ 对问题 $x$ 采样 $G$ 条轨迹；
2. 对每条轨迹：计算奖励 $R$，确定正确性 $m$；
3. **若成功**：教师输入"原响应 + 改述指令"，按 RLSD 计算幅度调制权重；
4. **若失败**：教师输入"问题 + 提示 $h$"，计算反向 KL；
5. 用混合损失更新 $\theta$。
