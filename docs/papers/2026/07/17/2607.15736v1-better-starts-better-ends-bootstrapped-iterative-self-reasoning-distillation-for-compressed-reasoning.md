## TL;DR

大推理模型生成的长思维链中包含大量冗余推导和无效验证，现有在策略自蒸馏方法受制于初始化瓶颈——从冗长的基模型出发时，KL 损失实际上落在充满噪声的前缀上，简洁教师只能在局部打补丁。BIRD 提出先通过提示切换 SFT 预热模型的 rollout 分布，再从改善后的前缀出发执行逆向 KL 蒸馏。在 Qwen3-8B 上，这种两阶段策略将 MATH-500 准确率从 86.2% 提升至 92.0%，同时将平均响应长度从 3099 token 压缩至 1115 token，首次实现了准确率提升与长度压缩的同步发生。

## 研究背景与动机

大推理模型通常依赖长链思维（CoT）轨迹来逐步推导答案，这种方式确实带来了显著的能力提升，但代价是推理成本急剧膨胀。深入观察这些长轨迹会发现一个被低估的现象：其中相当一部分计算被浪费在重复的自我验证、绕了一圈又回到原点的推导、以及对最终答案毫无贡献的迂回探索。更耐人寻味的是，当研究者尝试压缩这些思维链时，往往会得到一个反直觉的发现——缩短后的模型不仅没有变笨，有时甚至比原始模型表现更好。这强烈暗示原始长 CoT 中存在大量"表演思考"而非"真正思考"的成分。

这一观察催生了推理压缩研究的蓬勃发展。免训练方法通过在推理时加入简洁指令或早停机制来控制生成长度，但效果高度依赖模型本身的遵循能力。基于强化学习的方法引入长度惩罚奖励，能系统性地平衡准确率与效率，但需要精心设计奖励函数和训练流程。这些方法要么缺乏训练信号的指导，要么需要借助外部力量。

在策略自蒸馏（OPSD）代表了一条更优雅的路线：让模型自身充当教师，在简洁性指令下生成动态参考。具体来说，学生模型采样一条轨迹，然后一个携带简洁指令的教师版本在相同前缀上提供更简洁的下一 token 预测，损失函数是学生分布与教师分布之间的逆向 KL 散度。理论上这形成了闭环自改进：更简洁的教师引导学生缩短推理，学生变短后又生成新的简洁前缀。

然而论文揭示了一个此前被忽视的瓶颈——**前缀支持问题**。逆向 KL 散度只在学生已经访问过的前缀上计算监督信号，这是一个"前缀局部"的匹配目标。当从冗长的基模型开始训练时，学生会探索大量噪声、冗余甚至已经偏离正确轨道的前缀。此时简洁教师虽然存在，但被查询时所处的上下文已经充满杂质。教师只能在局部提供下一 token 的修正，无法从根本上扭转学生继续沿着错误方向探索的倾向。这就像给一个习惯性绕远路的人指路，每次只能告诉他"下一步怎么走"，但这个人还是会继续选择绕远路，因为他的整体策略已经偏向冗长。

## 方法

理解 BIRD 的设计需要先明确推理压缩的形式化框架。将推理压缩表述为分布匹配问题：学习一个学生策略 $\pi_\theta$，使其匹配某个目标分布 $\pi_{\text{target}}$。不同方法的差异既在于如何构造目标分布，也在于监督信号实际施加在序列的哪些位置上。

序列生成遵循标准的自回归分解，每个 token 的概率取决于之前的所有 token。在策略自蒸馏的目标函数可以写作：

$$\mathcal{L}(\theta) = \mathbb{E}_{x \sim D,\, y \sim \pi_{\theta}(\cdot \mid x)} \left[ \sum_{t} D_{KL}\left(q_{t} \,\|\, p_{t}\right) \right]$$

其中 $q_t = \pi_{\theta}(\cdot \mid x, y_{<t})$ 是学生在当前位置的分布，而 $p_t = \pi_{\bar{\theta}}(\cdot \mid x, c, y_{<t})$ 是教师分布，它携带了简洁指令 $c$（如"请简洁回答"），被查询时同样处于学生的当前前缀。停止梯度操作确保教师参数不因梯度回传而更新，通常采用周期性地从学生参数同步的策略。

问题在于这个目标函数的监督范围受限于学生 rollouts 的前缀支持。如果学生的前缀分布本身偏向冗长、噪声和偏轨，那么即使教师再简洁，匹配也是在错误的基础上进行的。这解释了为什么直接对大推理模型应用在策略自蒸馏往往只能获得有限的改进——蒸馏的效率被初始化拖累了。

BIRD 的核心洞察是：**与其让教师去适应脏乱的前缀分布，不如先改善前缀分布本身**。这催生了两阶段的设计。

第一阶段被称为静态自举（Prompt-Switch SFT）。给定训练题目集 $D$，对每个样本 $x$，让基模型在简洁指令 $c$ 下采样一条轨迹。这里引入一个关键过滤条件：只有当模型生成的答案与真实答案匹配时才保留这条轨迹。这一步筛掉了那些虽然简洁但答案错误的轨迹，确保进入后续训练的数据质量。

$$D_{\text{filtered}} = \{(x, y) \mid \text{answer}(y) = GT(x)\}$$

接下来是最关键的设计：**提示切换**。轨迹本身是在 $x + c$（原始问题加简洁指令）的条件下生成的，但在训练时只使用原始问题 $x$ 作为提示，不包含简洁指令。这意味着模型学习的是：面对普通数学题时，自动采用简洁的推理风格，而非在指令驱动下才变得简洁。这一步将"指令诱导的简洁性"内化为模型的默认行为，避免简洁成为推理时的临时工件。论文采用轻量级的微调配置：仅 1 个 epoch、每个样本 1 条轨迹、最大长度 2048 token、LoRA 高效适配。这种轻量化设计确保第一阶段不会过度拟合特定轨迹，同时足以将简洁推理的偏好注入模型。

第二阶段是动态精炼（Warm-Start OPSD）。从第一阶段得到的预热模型 $\pi_{\theta_{\text{SFT}}}$ 出发，执行标准的逆向 KL 在策略自蒸馏。教师是学生参数的停止梯度副本，按周期从学生同步。教师在生成时同样携带简洁指令，但这次面临的前缀分布已经大大改善——更短、更直接、更少噪声。教师能够在更干净、信息量更丰富的上下文上提供监督，KL 损失不再浪费在冗余和偏轨区域。第二阶段的关键改进是**初始化**：不再从冗长的基模型出发，而是从一个已经"习惯"简洁推理的模型起步。这相当于给模型换了一个更好的起点，后续的蒸馏优化在这个起点上能够更高效地收敛。

## 实验与结果

论文在 Qwen3 系列的 1.7B、4B、8B 三个规模上验证 BIRD，评测基准包括 MATH-500、AIME 2024 和 AIME 2025。基线方法包括原始模型（Base）、仅推理时加简洁指令（Concise）、以及论文自行复现的冷启动 OPSD 方法 CRISP。

主结果呈现了清晰的层级关系。在 Qwen3-8B 上，BIRD 将 MATH-500 准确率从 86.2% 提升至 92.0%，同时将平均响应长度从 3099 token 压缩至 1115 token，准确率提升和长度压缩同时发生，这是最理想的结果形态。在更具挑战性的 AIME 2024 上，准确率从 38.33% 升至 58.33%，长度从 6230 压缩至 4067，提升幅度依然显著。论文还测试了跨模型家族的迁移能力：在 DeepSeek-R1-Distill-Llama-8B 上，BIRD 依然取得了 +8.0 个百分点的准确率提升和 33% 的长度缩减，说明两阶段策略不依赖特定模型架构。

论文引入了一个综合指标 **Token Efficiency (TE)**，定义为 $TE = \frac{Accuracy}{\ln(Length)}$，用对数长度作为分母来刻画"长度缩短的边际收益递减"效应。在这个指标下，BIRD 在 9 个模型-基准组合中有 8 个取得最高值，仅在 Qwen3-1.7B / AIME 2025 上略低于 CRISP。值得关注的是，1.7B 这样的小规模模型收益有限，准确率甚至有小幅下降，表明小模型在简洁指令下生成正确答案的可靠性不足，Stage 1 的效果受限于模型容量。

消融实验揭示了各组件的贡献。SFT-only（仅第一阶段）在准确率上与 Base 相当但长度大幅缩短，说明提示切换 SFT 本身就能实现有意义的压缩。CRISP（冷启动 OPSD）能够进一步压缩长度，但准确率提升有限。BIRD 则是两者结合后的最优结果。阶段顺序的消融更有意思：如果将两个阶段颠倒过来——先做 OPSD 再做 SFT——长度虽然能进一步压缩，但准确率显著下降（Qwen3-4B / AIME 2025 从 40.83% 跌至 28.33%），说明后置的 SFT 会覆盖在线学习到的策略。

训练动力学曲线直观地展示了初始化改善的效果。BIRD 的初始 Token Efficiency 就已经达到了 CRISP 训练全程的峰值水平，25 步之后就超过了 CRISP 的最佳表现。这意味着 Stage 1 的预热让模型"赢在起跑线上"，后续的 OPSD 不需要从头学习简洁推理，只需在已有基础上精炼。

## 讨论与可借鉴点

BIRD 最重要的理论贡献是揭示了**前缀支持在蒸馏中的关键作用**。此前的研究通常关注如何构造更好的教师、选择更优的蒸馏目标函数，但 BIRD 指出，问题不仅在于教师"说什么"，更在于教师"被问什么"。即使拥有完美的简洁教师，如果它总是被查询于噪声和偏轨的前缀上，蒸馏依然低效。这个视角将推理压缩从"如何让模型变短"扩展到"如何让模型在更短的上下文中学习"。

两阶段设计体现了"先改善数据分布再训练"的工程哲学。第一阶段的提示切换 SFT 不需要任何外部教师或奖励信号，只依赖模型自身的生成能力和简单的答案过滤。这使其成为一个即插即用的组件，可以与各种后续蒸馏策略组合。这种"自举"思想——利用模型自身的生成能力来改善后续训练的起点——值得在其他长文本生成压缩任务中借鉴。

然而，论文的实验范围集中于数学推理这一单一领域。大推理模型同样广泛应用于代码生成、逻辑推理、多模态推理等场景，这些领域的长链思维是否同样存在可压缩的冗余、BIRD 的两阶段策略能否迁移，还有待验证。此外，论文在超参披露上略显不足——KL 损失截断到前 1024 token、SFT 截断到 2048 token、LoRA 秩等关键超参的选择依据和敏感性分析未被详细讨论，这为后续复现和调优留下了一定空间。

对于实践者而言，BIRD 的一个重要启示是**初始化质量对在线学习方法的决定性影响**。当模型的初始 rollout 分布不理想时，即使采用理论上正确的优化目标，也难以取得好的结果。在这种情况下，与其直接在目标分布上训练，不如先花少量资源改善模型自身的生成分布，再进行目标驱动的训练。这种"预热-精炼"的范式或许可以推广到其他需要模型探索自身分布的场景中。

## 摘要
大型推理模型通常通过长思维链（CoT）轨迹来求解问题，但其中相当一部分计算被耗费在冗余推导、反复的自我验证以及无法改善最终答案的迂回过程上。现有的在策略自蒸馏方法通过让学生模型在自身 rollout 采样得到的前缀上匹配其自身的简洁版本来降低这一成本。我们证明该目标存在初始化瓶颈：由于监督仅施加于已访问的前缀，从一个冗长的基模型开始训练时，KL 损失落在的上下文往往充满噪声、冗余或已经偏离正轨。在这些区域，简洁的教师只能提供局部修正，而学生仍会继续探索高效推理者本应避免的轨迹。本文提出 BIRD（Bootstrapped Iterative Self-Reasoning Distillation，自举迭代自推理蒸馏），一种在在策略训练之前先改善 rollout 分布的两阶段自推理蒸馏方法。BIRD 首先在简洁性指令下从基模型采样简洁解，仅保留答案正确的轨迹，并执行轻量级的提示切换 SFT 步骤。这些轨迹在简洁性指令下生成，但学习时使用原始任务提示，从而将指令诱导的简洁性转化为默认的推理行为。从这个预热模型出发，BIRD 进而以简洁的自教师在策略反向 KL 蒸馏施加于更干净、信息量更丰富的前缀之上。在 Qwen3 系列模型上，BIRD 在 MATH-500 与 AIME 基准上取得了优于提示方法和冷启动在策略蒸馏的精度–效率权衡。在 Qwen3-8B 上，它将 MATH-500 精度从 86.2% 提升至 92.0%，同时将平均响应长度从 3,099 个 token 缩减至 1,115 个 token。这些结果凸显了前缀支持在高效推理蒸馏中的核心地位。

## Abstract
Large reasoning models often solve problems through long chain-of-thought (CoT) traces, yet much of this computation is spent on redundant derivations, repeated self-verification, and detours that do not improve the final answer. Existing on-policy self-distillation methods reduce this cost by matching a student model to a concise copy of itself on prefixes sampled from the student's own rollouts. We show that this objective has an initialization bottleneck. Since supervision is applied only to visited prefixes, training from a verbose base model places the KL loss on contexts that are often noisy, redundant, or already off track. In such regions, a concise teacher can provide only local corrections, while the student continues to explore trajectories that an efficient reasoner should avoid. In this paper, we propose BIRD(Bootstrapped Iterative Self-Reasoning Distillation), a two-stage self-reasoning distillation method that improves the rollout distribution before on-policy training. BIRD first samples concise solutions from the base model under a brevity instruction, keeps only answer-correct traces, and performs a lightweight prompt-switch SFT step. The traces are generated with the brevity instruction but learned under the original task prompt, turning instruction-induced conciseness into a default reasoning behavior. Starting from this warm model, BIRD then applies on-policy reverse-KL distillation with a concise self-teacher, now on cleaner and more informative prefixes. Across Qwen3 series models, BIRD achieves a stronger accuracy-efficiency trade-off than prompting and cold-start on-policy distillation on MATH-500 and AIME benchmarks. On Qwen3-8B, it improves MATH-500 accuracy from 86.2% to 92.0% while reducing the average response length from 3,099 to 1,115 tokens. These results highlight prefix support as a central factor in efficient reasoning distillation.

## 1. 核心问题与研究背景

大型推理模型（LRM）通过长链思维（CoT）求解问题时，往往包含大量**冗余推导、重复自我验证与无效迂回**，导致推理成本高昂但对最终答案贡献有限。推理压缩（Reasoning Compression）旨在缩短思维链同时保持（或提升）准确率。

现有方法大致分为四类：
- **免训练方法**：通过简洁提示、早停或自纠错控制生成长度；
- **基于强化学习的方法**：引入长度惩罚奖励；
- **基于监督微调（SFT）的方法**：在外部模型生成的压缩轨迹上微调；
- **在策略自蒸馏（On-Policy Self-Distillation, OPSD）**：让模型本身在简洁性指令下充当动态教师进行反向 KL 蒸馏。

**核心发现（冷启动前缀支持瓶颈）**：OPSD 的损失只在学生已采样的前缀上计算，属于"前缀局部（prefix-local）"目标。当从冗长的基模型出发训练时，学生会访问大量噪声、冗余、已偏轨的前缀；此时简洁教师只能在已污染的上下文上提供**局部**下一 token 修正，无法把学生拉回高效推理轨道。因此，**OPSD 的有效性不仅取决于教师分布本身，更取决于教师被查询时所处的前缀支持（prefix support）**。

## 2. 方法论

### 2.1 形式化视角

将推理压缩统一写为分布匹配问题：

$$\min_{\theta} D\left(\pi_{\theta}, \pi_{\text{target}}\right)$$

其中 $\pi_{\theta}$ 为学生策略，$\pi_{\text{target}}$ 为目标分布。方法的差异既体现在如何构造 $\pi_{\text{target}}$，也体现在**匹配损失实际施加在哪些位置上**。

序列生成遵循自回归分解：

$$\pi_{\theta}(y \mid x) = \prod_{t=1}^{T} \pi_{\theta}(y_{t} \mid x, y_{<t})$$

OPSD 的目标函数为：

$$\mathcal{L}(\theta) = \mathbb{E}_{x \sim D,\, y \sim \pi_{\theta}(\cdot \mid x)} \left[ \sum_{t} D_{KL}\left(q_{t} \,\|\, p_{t}\right) \right]$$

其中 $q_t = \pi_{\theta}(\cdot \mid x, y_{<t})$ 为学生分布，$p_t = \pi_{\bar{\theta}}(\cdot \mid x, c, y_{<t})$ 为携带简洁指令 $c$ 的教师分布，$\bar{\theta}$ 为学生参数的停止梯度副本。

### 2.2 BIRD 两阶段框架

**Stage 1 —— 静态自举（Prompt-Switch SFT）**

对每个训练题 $x$，令基模型在简洁指令 $c$ 下采样一条轨迹 $y$，仅当答案匹配时保留：

$$D_{\text{filtered}} = \{(x, y) \mid \text{answer}(y) = GT(x)\}$$

然后进行**提示切换 SFT**：轨迹在 $x+c$ 下生成，但训练时使用原始提示 $x$。该步骤将"指令诱导的简洁性"内化为**默认推理行为**，避免其沦为推理时工件。SFT 仅 1 个 epoch、每题 1 条轨迹、2048 token 截断，使用 LoRA。

**Stage 2 —— 动态精炼（Warm-Start OPSD）**

从 $\pi_{\theta_{SFT}}$ 出发执行标准反向 KL 自蒸馏，教师为周期性刷新的停止梯度学生副本，KL 仅在 rollout 前 1024 个 token 上计算。关键区别在于**初始化**：教师被查询时所处的支持已偏向更短、更直接、更在轨的前缀。

   - **Qwen3-8B / AIME 2024**：准确率从 38.33% → **58.33%**，长度从 6230 → **4067**；
   - **DeepSeek-R1-Distill-Llama-8B / MATH-500**：准确率 +8.0 pp，长度 -33%。
4. **提示切换 SFT 将指令性简洁性转化为默认行为**：单独推理时加简洁指令已优于基线，但 BIRD 通过内化取得进一步大幅压缩。
5. **阶段顺序至关重要**：OPSD → SFT 顺序虽能进一步压缩，但会覆盖在线学习到的策略，导致准确率显著下降（Qwen3-4B / AIME 2025：40.83% → 28.33%）。
6. **训练动力学上**：BIRD 的初始 TE 已达到 CRISP 训练全程的峰值，仅 25 步即超过 CRISP 最佳值。

## 7. 论文亮点

- **新视角**：首次明确指出 OPSD 存在"前缀支持瓶颈"，将关注点从"如何构造简洁教师"扩展到"在哪些前缀上查询教师"。
- **简洁工程方案**：仅需"采样→过滤→提示切换 SFT→标准 OPSD"四个步骤，无需外部教师或奖励工程，可即插即用。

- **指标设计合理**：TE = Accuracy / ln(Length) 同时反映压缩的边际收益衰减。
- **消融完整**：阶段必要性、阶段顺序、训练动力学、定性轨迹分析齐备，论证充分。

## 8. 不足与局限

1. **任务域局限**：实验仅覆盖数学推理（MATH-500、AIME、训练集 DAPO-Math），未验证代码、常识、多模态等场景；超长链思维（如 o1 类任务）的适用性未知。
2. **训练分布局限**：训练数据仅来自 DAPO-Math-17k-dedup，对训练分布外的题目效果未检验。
3. **超参与可复现性**：SFT 截断长度（2048）、KL 截断长度（1024）、LoRA 秩、温度、刷教师间隔 $M$ 等关键超参的搜索范围与敏感性未系统报告；随机种子、统计显著性未给出。
4. **算力与成本透明度不足**：未披露单次实验训练时长、累计 GPU 小时、碳成本等。
5. **极小模型收益有限**：在 Qwen3-1.7B 上 TE 提升主要由压缩驱动，伴随小幅准确率下降，表明小模型执行指令的可靠性有限，Stage 1 质量受规模制约。
6. **真实部署评估缺失**：未涉及延迟、吞吐量、显存峰值等系统级指标；最长 8192 token 截断可能掩盖极端案例表现。
7. **理论分析有限**：论文以经验论证为主，未给出关于"前缀支持→匹配效率"的严格理论刻画（例如收敛上界或 KL 最小化性质）。
8. **公平比较的边界**：与 CRISP 均为重实现而非原作者代码，可能引入实现偏差；与最新 RL 长度惩罚方法（如 L1、Leash、DiPO）的直接对比也较为有限。
