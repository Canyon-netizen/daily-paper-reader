## 摘要
操作受约束的动力系统要求控制器在高效求解复杂任务的同时，保证递归可行性与安全约束。为应对这些相互冲突的需求，我们提出了可行动作最优控制（Feasible Action for Optimal Control, FAOC），一种融合强化学习（RL）与最优控制（OC）的新型控制框架。其核心贡献是一种计算高效的、基于优化的映射算法，该算法将强化学习智能体的动作从一个静态的抽象集合，转换为最优控制问题（OCP）依赖于状态的可行参数集合，从而严格保证动力系统约束的满足。因此，FAOC 有效地将最优控制的可预测安全性与强化学习的灵活性结合起来。与已有工作相比，强化学习智能体的抽象动作空间无需依赖专家或启发式设计，最优控制问题的构建也不会因强化学习无法保证可行性而受到影响。我们将该方法应用于机器人乒乓球的实时运动规划，该任务涵盖了上述各项挑战。通过仿真实验，我们证明 FAOC 在样本效率和闭环性能两方面均优于当前最先进的方法。

## Abstract
Operating constrained dynamical systems requires controllers to efficiently solve complex tasks while enforcing recursive feasibility and safety constraints. To address these competing requirements, we present Feasible Action for Optimal Control (FAOC), a novel control framework integrating Reinforcement Learning (RL) and Optimal Control (OC). The key contribution is a computationally efficient, optimization-based mapping algorithm that transforms the RL agent's action from a static abstract set into a state-dependent feasible parameter set of the Optimal Control Problem (OCP), guaranteeing strict satisfaction of the dynamical system's constraints. Thus, FAOC effectively combines the predictable safety of OC with the flexibility of RL. In contrast to prior work, the abstract action space of the RL agent does not require expert or heuristic design, and the OCP formulation is not compromised by the inability of RL to guarantee feasibility. We apply our approach to real-time motion planning for robot table tennis, which encapsulates these challenges. Via simulated experiments, we show that FAOC outperforms state-of-the-art baselines in both sample efficiency and closed-loop performance.

## 1. 核心问题与研究动机

在受约束动态系统（如机器人）的控制中，需要同时满足两类相互冲突的目标：

- **任务层面**：高效求解复杂、长视野的决策任务，需要灵活的探索能力。
- **安全层面**：必须严格保证状态/输入/输出约束的递归可行性，确保物理安全。

**两类方法的互补性与不足**：

- **纯强化学习（RL）**：具备强大的非凸、长视野、稀疏奖励任务求解能力，但**无法严格保证约束满足**，限制其在安全攸关场景的部署。
- **纯最优控制（OC）/MPC**：能够利用先验模型显式约束，但**对非凸/长视野问题易陷入局部不可行或计算不可行**，且对稀疏奖励信号不友好。

**现有融合方法的局限**：
- 现有"参数化 OCP + RL"方法常采用**静态、连续、与状态无关的动作空间**，但 OCP 的真实可行参数集合通常是**状态依赖、几何复杂**的。静态参数化会包含不可行动作、遗漏最优可行动作，迫使 RL 隐式学习可行性边界，导致样本效率低。
- 部分方法用松弛变量或代价惩罚来回避不可行性，无法严格保证可行性。
- 少数方法在动作空间设计上做了可达性约束（如 [30] 的一维映射、[31] 的超立方体映射），但分别受限于维度或原点必须在可行集内部的强假设。

**FAOC 的核心定位**：在不损害 OCP 严格可行性的前提下，让 RL 在一个静态、几何简洁的抽象动作空间内自由采样，并通过一个可逆的优化映射自动将其转换为状态相关的可行 OCP 参数。

## 2. 方法论

### 2.1 总体框架（4 步闭环）

1. RL 智能体（NN）从系统状态 $x$（及环境观测 $s_{\text{env}}$）输出参数 $(\mu, \Sigma)$，采样得到原始动作 $a$，经非线性有界映射 $b(\cdot)$（如 $\tanh$）映射到抽象动作 $\bar{a} \in \bar{A}$，其中 $\bar{A} \subset \mathbb{R}^n$ 为静态、紧、实心、凸的集合（典型取超立方体 $[-1,1]^n$）。
2. **映射算法 $\mathcal{M}$** 将 $\bar{a}$ 映射为 OCP 的参数 $p \in \mathcal{P}(x)$，其中 $\mathcal{P}(x)$ 是依赖于状态 $x$ 的可行参数集合。该映射保证 $p$ 严格可行，并尽可能覆盖全部可行区域。
3. $p$ 固定 OCP 中编码动作的向量，求解参数化 OCP 得到最优控制输入轨迹。
4. 输入作用于系统，得到下一状态 $x^+$，进入下一控制周期。

### 2.2 参数化 OCP 与可行参数集拓扑刻画

参数化 OCP 一般形式：

$$
\min_{z \in \mathcal{Z}} \; f(z, p, x) \quad \text{s.t.} \quad g(z, p, x) \le 0, \quad H_z z + H_p p + H_x x + h = 0.
$$

其中 $x$ 为初始状态，$z$ 为决策变量（含预测状态/输入轨迹），$p \in \mathbb{R}^n$ 为 RL 选择的参数。

**Lemma 1（拓扑性质）**：在 mild 几何条件下，状态依赖可行参数集 $\mathcal{P}(x)$ 是**紧、实心、凸**的。关键假设包括：$\mathcal{Z}$ 非空紧凸；$g$ 关于 $(z,p)$ 联合凸且连续；联合可行集 $\mathcal{S}(x)$ 在 $p$ 子空间无衰退方向；存在严格可行内点；$\text{rg}(H_p) \subseteq H_z^T$，其中 $T = \text{aff}\,\mathcal{Z} - \tilde{z}$。

**Corollary 1（线性 MPC + 终值约束）**：若阶段约束集 $\mathcal{Z}_k$、终值集 $\mathcal{X}_N$ 为紧、实心、凸，且 $C$ 行满秩，则 $\mathcal{P}(x)$ 紧、实心、凸。

### 2.3 核心算法：凸集间的可逆径向映射

基础框架（Algorithm 1）：给定紧、实心、凸集 $X$（基础）与 $Y$（目标），及各自内点 $x_c, y_c$，对每个 $x \in X$：

1. 计算方向 $d = x - x_c$，以及使射线抵达 $\text{bd}\,X$ 的边界缩放因子 $\alpha \ge 1$；
2. 应用方向变换 $d' = \phi(d)$；
3. 计算使 $y_c + \beta d' \in \text{bd}\,Y$ 的 $\beta > 0$；
4. 输出 $y = y_c + \beta\alpha \cdot d'$。

**Proposition 1（可逆性）**：若 $\phi$ 连续、可逆、正齐次，则该映射 $M: X \to Y$ 双射；逆映射通过交换 $(X, x_c, x) \leftrightarrow (Y, y_c, y)$ 与 $\phi \to \phi^{-1}$ 得到。

### 2.4 几何失真缓解

**问题**：若 $\phi(d) = d$（恒等变换），点会向目标集形状差异显著的方向过度聚集，导致样本浪费。

**2D 面积匹配变换**（Propositions 2、3）：
- 定义归一化面积函数 $a_X(\xi) = A_{X(\xi)} / A_X$，作为二维均匀分布在极角上的边缘 CDF。
- 变换 $\phi(d) = \|d\| \cdot [\cos \upsilon, \sin \upsilon]^\top$，其中 $\upsilon = a_Y^{-1}(a_X(\xi))$，$\xi = \arg(d)$。
- 性质：连续、可逆、正齐次；保证均匀采样 $X$ 经映射后边缘角度分布恰为 $a_Y$。
- 注：联合分布并不保证完全均匀；显式计算可由凸多边形顶点有序集合下的"有向三角剖分"完成，无需求三角函数。

**任意维线性变换**（Proposition 4）：$\phi(d) = \Phi d$，通过**仿射相关椭球代理集** $\tilde{X} = Q_{\tilde{X}} u + q_{\tilde{X}}$ 与 $\tilde{Y} = Q_{\tilde{Y}} v + q_{\tilde{Y}}$ 之间的仿射映射构造 $\Phi = Q_{\tilde{Y}} Q_{\tilde{X}}^{-1}$。在显式表示可用时，椭球代理可由最大体积内接椭球（MVIE，SDP）获得。

### 2.5 隐式定义目标集的实时映射（关键技术）

实践中 $\mathcal{P}(x)$ 通常仅由 OCP 约束隐式给出（$Y = EW + e$，$W \subset \mathbb{R}^{n_w}$ 为 OCP 决策变量集合，$n_w > n$，$E$ 行满秩；Assumption 2：$E(\text{aff}\,W) = \mathbb{R}^n$）。需在不知 $Y$ 显式几何的情况下求内点、变换矩阵与边界缩放因子。

- **Proposition 5**：$y_c = Ew_c + e$，$w_c \in \text{relint}\,W$，可直接由高维空间相对内点投影得到。
- **Proposition 6（顶点法内切球）**：通过将所有顶点的像拉回 $W$ 同时满足约束，最大化内切球半径 $\bar G B_P(r^*) + y_c$；$m$ 与 $n$ 线性增长，仅适合低维 $n$。
- **Proposition 7（lifting 法内切球，主流方法）**：令 $w(q) = L q + w_c$，匹配 $EL = rG$ 与对偶范数约束 $\|(L^\top a_j)\|_* + a_j^\top w_c \le b_j$，$r$ 的下界可由凸优化得到，规模与 $W$ 描述量同阶。
- **Proposition 8（隐式目标形状矩阵）**：在降维实心集 $V$ 上求椭球代理 $\tilde{V}$，提升得 $\tilde{W} = F\tilde{V} + w_p$，再正向映射至 $Y$；对 $R = EFQ_{\tilde{V}}$ 做 SVD，取 $\tilde{U}\tilde{\Sigma}$ 为可逆的 $Q_{\tilde{Y}}$。
- **Example 3（状态无关变换矩阵）**：对线性 MPC，将初始状态 $x$ 与控制序列 $u_{0:N-1}$ 联合升维构造实心集 $\mathcal{V}_a$，离线估计其椭球代理；在 $x$ 固定时通过零空间分解得到与状态无关的有效形状矩阵 $\tilde Q_{\tilde{V}} = Q_u K_\perp$（标量缩放因子 $r(x)$ 被径向边界搜索吸收），从而 $\Phi$ 完全状态无关。
- **边界缩放（式 (8)）**：通过升维凸优化直接求 $\beta$：
$$
\max_{\beta, w}\; \beta \quad \text{s.t.}\; Ew + e = y_c + \beta d',\; w \in W.
$$

整个映射在闭环中**无需显式构造 $\mathcal{P}(x)$ 的几何表示**，满足实时性。

## 3. 实验设计

### 3.1 任务场景：8 自由度移动机械臂机器人乒乓球实时运动规划
- **系统状态**：157 维（含球观测、关节状态、目标技能）。
- **RL 输出**：每关节 2 维（位置 + 速度），共 16 维航点。
- **控制频率**：RL 在 31.25 Hz 决策；底层 1 kHz 跟踪；规划 32 ms 内的轨迹（每关节 32 个 setpoint）。
- **OCP 结构**（Corollary 1 的实例）：将 32 ms 分成 $N = 4$ 段，每段 $T = 8$ ms，假设常加加速度（jerk），三段积分得到位置轨迹的 cubic spline；状态 $x_k \in \mathbb{R}^3$ 为 (位置, 速度, 加速度)，输入 $u_k \in \mathbb{R}$ 为 jerk。
- $A, B$ 为三重积分器的精确 ZOH 离散化；阶段约束 $\mathcal{Z}_k$ 包含位置/速度/加速度/jerk 限幅；终值约束 $x_N \in \mathcal{X}_\infty$（最大控制不变集 MCIS），参数 $p = C x_N$ 提取末段 (位置, 速度)；对 OCP 内部约束保守收紧以保证闭环 1 ms 采样不违反原始限幅（详见 [40]）。
- 求解器：DAQP（嵌入式双 active-set QP）；MCIS 用 Qhull 离线生成。

### 3.2 对比方法
- **FAOC（本文）**：基于 $1 \sim 8$ 节映射算法 + 终端**等式约束**（无代价调权）。
- **2Dsoft**：2D 静态动作空间 + 软终端代价（$w_s u_k^2 + \|p - Cx_N\|_{W_t}^2$），含未可达航点；使用 Clarabel（qpsolvers）。
- **1Dpos / 1Dvel / 1Dacc（来自 [30] klimits 库）**：仅一维航点。
- **参数选择**：5 个不同随机种子；评测回合数 1000/数据点。

### 3.3 RL 算法与对比协议
- **训练算法**：Soft Actor-Critic（SAC）+ BRONet 网络（baseline 实验）；SimBaV2（更强基线：分类分布 critic + 更大网络）；
- **指标**：回合成功率 (Fraction Balls Returned)、上旋 (Topspin)、回球速度 (Velocity)、下旋 (Backspin)、落点距离 (Goal Distance)；均以球在对方台面反弹时状态计算。
- **三轮实验**：
  1. Baseline（SAC + BRONet，31.25 Hz）；
  2. 算法/架构影响（SimBaV2，31.25 Hz）；
  3. 低 RL 频率影响（SimBaV2，7.8125 Hz，128 ms 段）。

### 3.4 评估方法
- 5 个随机种子 × 3 个实验；
- 每个指标配 5 个方法对比；
- 配对 Mann-Whitney U 检验比较每个基线 vs FAOC；报告 $p$ 值与显著性（$p<0.05$ 为显著）；
- 低于 50% 成功率的结果被剔除以降低估计方差；
- 排除 1Dacc 在 baseline 实验的部分种子（3/5 未学会回球）。

## 6. 主要结论与发现

1. **样本效率与最终性能**：在 31.25 Hz 与 7.8125 Hz 两种决策频率、SAC + SimBaV2 两种算法/架构下，FAOC 在成功率、上旋、回球速度三项指标上均显著（$p<0.05$）超越所有基线；下旋与落点距离上无显著差异。
2. **2D vs 1D**：2D 控制器（FAOC、2Dsoft）在所有场景下全面优于 1D 控制器，确认了动作空间维度（可控性）对性能的影响。
3. **状态依赖动作空间的价值**：2Dsoft 与 FAOC 同样具备 2D 可控性，但 FAOC 因航点严格可达，样本效率显著更高。
4. **低频鲁棒性**：将决策频率从 31.25 Hz 降至 7.8125 Hz 后，FAOC 性能几乎不变，而其他控制器显著退化；FAOC 在 128 ms 段下的"显著优势对子"由 8 个增至 13 个，说明 FAOC 对决策频率更不敏感，更适合延迟、计算受限系统。
5. **可用性边界**：应用实例虽然涉及机器人 8-DoF 与避障等**非凸**问题，但 OCP 层面的目标集仍是凸的（位置-速度航点），凸性是映射算法可用前提；非凸性由 RL 在抽象动作空间层面处理，并未违反理论假设。

- **缺少组件级消融**：未单独验证"面积匹配 vs 线性变换"、"原始 1D 映射（如 [30]）vs FAOC 的差异是否来自状态依赖性本身"、"Theorem 1 假设违反时的鲁棒性"等关键问题。
- **仿真唯一性**：所有定量结论来自机器人乒乓球仿真，缺少跨任务（无人机、自动驾驶、manipulation 等）外推验证；虽然作者提及"非凸由 RL 处理，映射仍作用在凸 OCP 上"，但**未

在跨任务上验证映射算法的鲁棒性是否依赖于 OCP 可行参数集的"紧、实心、凸"假设。

- **对不可行情形的处理**：虽然理论上假设 $\mathcal{P}(x)$ 非空，但实际中若可行集为空（如任务规格冲突、传感器失效），闭环系统将面临求解失败；论文未给出 fallback 策略或安全退化机制的讨论。
- **终值等式约束 vs 终端代价**：FAOC 在 OCP 中强制 $Cx_N = p$（等式约束），相比 2Dsoft 的软约束虽换来严格可行性，但若 $p$ 选得不切实际，可能使 OCP 求解失败；论文未分析这种最坏情形下的鲁棒性。
- **公平调参披露不全**：2Dsoft 的权重 $w_s, W_t$ 仅通过截图示例 $|w_s=0.0/0.1/1.0/10.0|$，未报告系统化的网格搜索过程；调优不足可能掩盖 2Dsoft 的真实潜力。
- **数据集来源混合未细分**：综合仿真 + 真实人类击球数据的混合比例与各自贡献未量化，导致对样本效率提升的解释（FAOC vs 基线）难以严格归因。
- **指标与任务质量度量偏窄**：上旋、回球速度、落点距离等均以对方台面反弹时刻的球状态计算，无法直接反映对手接球难度、回合长度、多回合稳定性等高层指标。
- **理论假设较重**：Lemma 1 要求 $g$ 联合凸、$\mathcal{S}(x)$ 在 $p$ 方向无衰退、$\text{rg}(H_p) \subseteq H_z^\top T$ 等；真实机器人系统中的摩擦、间隙、接触非凸等使这些假设在实践中可能近似成立但难以严格验证。
- **缺乏失败案例分析**：未展示任何 RL 智能体或 OCP 求解失败、约束违反、回球出界等异常情形的样本，安全性评估偏乐观。

## 9. 复现性与工程化评估

- **代码开源**：作者明确声明算法与 OCP 实现已在 GitHub 公开（链接见论文），这为社区复现与二次开发提供了基础。
- **OCP 求解器选择合理**：DAQP 是为嵌入式场景设计的双 active-set QP 求解器，与 1 kHz 底层控制、32 ms OCP 周期的实时性需求匹配良好；终端不变集 MCIS 用 Qhull 离线生成，符合工业实践。
- **依赖生态完整**：训练数据采集（含真实人类击球）、仿真环境（应继承自 Nature 论文 [1]）、OCP 求解器、RL 网络（BRONet / SimBaV2）均为可获取的开源组件，理论上有较高复现可行性。
- **复现风险点**：由于未披露 GPU 型号、训练时长、batch size、学习率、随机种子初始化细节、2Dsoft 调参表等，第三方复现仍需投入相当的工程时间进行参数搜索与平台移植（特别是嵌入式 DAQP 的交叉编译与硬件在环）。
- **工程化路径清晰**：状态无关变换矩阵（Example 3）使 $\Phi$ 离线计算，内点/边界缩放在线凸优化问题规模与 OCP 决策变量同阶，整体架构对实际部署友好。

## 10. 整体评价与启示

### 10.1 学术贡献定位

- **理论层面**：在"RL 抽象动作空间"与"OCP 状态依赖可行参数集"之间建立严格的双射桥梁，给出了紧、实心、凸集之间可逆径向映射的完整刻画，弥补了现有"参数化 OCP + RL"方法在动作空间设计上的理论空白。
- **算法层面**：从 2D 精确解（面积匹配）到任意维线性变换（椭球代理），再到隐式定义目标集的实时映射（提升 + 内切球 + 凸优化），构成了一个由易到难、可组合的工具箱。
- **应用层面**：在 8-DoF 乒乓球机器人这一非平凡、长视野、强约束的真实场景上验证了 FAOC 的可行性与优越性，且与 Nature 级机器人系统同源，证明了从理论到工程的闭环。

### 10.2 对未来工作的启示

1. **动作空间设计原则**：在"RL + OCP"融合框架中，应优先保证抽象动作空间与可行参数集之间的可逆映射，避免静态、几何不匹配的动作空间设计。
2. **凸分解思路**：将非凸性分解为"RL 层抽象动作空间处理非凸 + OCP 层在凸可行集上保证安全"，是处理复杂约束问题的有效范式。
3. **状态无关预计算**：利用径向边界搜索吸收标量缩放，使方向变换矩阵 $\Phi$ 可离线计算，是降低在线映射开销的关键工程技巧，可推广到其他实时控制场景。
4. **可逆映射的扩展价值**：可逆性使得专家演示、对称数据增强、离线 RL 等技术可直接作用于抽象动作空间，无需考虑 OCP 可行性的复杂几何。
5. **跨任务迁移**：FAOC 的算法框架理论上可推广到任何具有"凸参数化 OCP + 长视野稀疏奖励"特征的任务（如无人机轨迹规划、自动驾驶决策、机械臂操作），未来工作值得在更多领域验证。
