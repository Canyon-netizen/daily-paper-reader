## TL;DR

本文提出一种自适应多视野强化学习方法，通过并行维护多个不同折扣因子的 Q 函数分支并用状态相关的 Softmax 门控网络组合它们，使智能体能够自动识别并适应不同的奖励结构，无需手动调参即可在 MiniGrid 离散任务和三任务顺序切换的持续学习场景中稳健工作。这一机制在保留渐近最优性的同时显著提升了参数效率，为人工与生物启发的学习系统提供了统一的时间尺度建模思路。

## 研究背景与动机

在强化学习中，智能体如何平衡短期与长期收益是一个根本性问题。传统做法是引入一个固定的折扣因子 $\gamma \in [0,1]$，将未来奖励按指数衰减叠加到当前状态价值中：

$$G_t = \sum_{k=0}^{\infty} \gamma^k R_{t+k+1}$$

这一设计的核心假设是：所有任务共享同一个时间视野。然而现实中的决策问题往往更加复杂——同一个智能体在不同情境下需要切换"短视"与"远视"模式。例如，在迷宫中快速找到出口可能需要关注局部信息（对应较大的 $\gamma$，即较长的有效视野），而在接近目标时则可能更依赖即时奖励（较小的 $\gamma$）。更重要的是，当任务切换或奖励结构发生漂移时，预先设定的单一折扣因子往往迅速失效。

更关键的是，生物智能体展现出令人印象深刻的**自适应时间折扣**能力。人类和动物会根据环境上下文灵活调整其时间偏好——在食物稀缺时更倾向于冒险获取高回报选项，在稳定环境中则偏好稳妥的策略。这暗示着有效的规划系统需要多种时间尺度，而非单一的指数衰减结构。

因此，论文试图回答的核心问题是：能否让强化学习智能体自动学习并组合多个时间折扣视野，以一种无手工调参的方式鲁棒地适应奖励结构的变化？

## 方法

受生物智能体灵活时间折扣的启发，作者设计了一个多视野自适应框架，其核心思想是**并行维护多个 Q 函数分支，每个分支对应不同的折扣因子，再通过一个状态相关的混合网络将它们动态组合**。

具体而言，系统维护 $K$ 个并行的 Q 函数 $\{Q_i\}_{i=1}^{K}$，每个分支 $i$ 对应一个折扣因子 $\gamma_i$。这些折扣因子并非随意选取，而是预设为 $\{1,\,0.998,\,0.996,\,0.992,\,0.984,\,0.969,\,0.938,\,0.875,\,0.75,\,0.5\}$，对应有效视野 $H_{eff} = \frac{1}{1-\gamma_i}$ 从 $\infty$ 到 $2$ 的连续覆盖。论文通过一个直观的物理类比来解释这一设计：不同折扣因子就像不同倍率的"望远镜"，帮助智能体看到不同距离的未来。

最终的策略由一个混合 Q 值驱动：

$$Q_{mix}(s,a) = \sum_{i=1}^{K} w_i(s)\, Q_i(s,a)$$

其中 $w_i(s)$ 是状态相关的混合权重，由一个简单的线性 + Softmax 网络生成：

$$z = W\phi(s) + b, \qquad w_i(s) = \frac{\exp(z_i)}{\sum_k \exp(z_k)}$$

这意味着在不同状态下，智能体可以"开启"不同的折扣视野组合——在需要短期决策的状态激活高折扣分支，在需要长期规划的状态则激活接近 $\gamma=1$ 的分支。

在训练机制上，每个分支独立维护资格迹以实现 TD($\lambda$) 风格的更新，而混合分支的权重梯度则通过链式法则从混合 Q 的 TD 误差反传得到。论文证明了这一框架满足**单峰对齐性质**：当存在某个最优折扣 $\gamma^*$ 时，梯度下降会自然驱动 $w_{\gamma^*} \to 1$，其他权重趋于零，从而保证框架不会因引入多分支而损失渐近最优性。

## Abstract
Effective decision-making in complex and changing environments requires balancing short-term and long-term consequences. In reinforcement learning (RL), this trade-off is typically controlled through a fixed discount factor, which imposes a single exponentially discounted temporal horizon. However, biological agents exhibit flexible and adaptive temporal discounting, suggesting that effective planning requires multiple timescales. Here, we propose a multi-horizon approach that adaptively selects and combines temporal horizons, enabling robust adaptation to changes in reward structure without manual discount-factor tuning. This flexibility makes the method particularly suitable for continual learning scenarios involving task switches and varying environmental configurations. Empirically, we demonstrate that our approach identifies effective discount factors across a range of MiniGrid environments, including continual settings composed of three sequentially changing tasks. These results suggest that adaptive temporal discounting can improve parameter efficiency and enhance adaptability in both artificial and biologically inspired learning systems.

   $\gamma \in \{1,\,0.998,\,0.996,\,0.992,\,0.984,\,0.969,\,0.938,\,0.875,\,0.75,\,0.5\}$，对应有效视野 $H_{eff} = \tfrac{1}{1-\gamma} \in \{\infty,\,512,\,256,\,128,\,64,\,32,\,16,\,8,\,4,\,2\}$。

2. **带资格迹的多 Q 学习**：对每个分支 $Q_i$ 独立维护资格迹：
   $$E_t^{(i)}(s,a) = \gamma_i \lambda\, E_{t-1}^{(i)}(s,a) + \mathbb{1}(s = s_t, a = a_t)$$
   更新规则：
   $$Q_i(s_t,a_t) \leftarrow Q_i(s_t,a_t) + \alpha\, \delta_t^{(i)}\, E_t^{(i)}(s_t,a_t)$$
   其中
   $$\delta_t^{(i)} = r_{t+1} + \gamma_i \sum_{a'}\pi(a'|s_{t+1}) Q_i(s_{t+1},a') - Q_i(s_t,a_t)$$

3. **混合 $Q$ 的 TD 误差与权重更新**：用 $\gamma=1$ 计算混合分支的 Bellman 残差：
   $$\delta_t = r_{t+1} + \sum_{a'}\pi(a'|s_{t+1}) Q_{mix}(s_{t+1},a') - Q_{mix}(s_t,a_t)$$
   并定义逐分支对偶损失 $L = \tfrac{1}{2}\sum_i (Q_i - Q_{mix})^2$，沿链式法则得到 Softmax 门控的更新：
   $$W \leftarrow W + \alpha\,\delta\,[w \odot (Q - Q_{mix})]\, \phi(s)^\top,\qquad b \leftarrow b + \alpha\,\delta\,[w \odot (Q - Q_{mix})]$$

4. **行为策略**：以 $\epsilon$-贪心作用于 $Q_{mix}$，保证探索覆盖所有分支。

### 2.3 收敛性与理论性质

作者证明了关键的**单峰对齐性质**：当存在某个"最优"折扣 $\gamma^* = \arg\max_{\gamma_i} J(\pi_{\gamma_i})$ 时，梯度下降会驱动 $w_{\gamma^*} \to 1$，$w_i \to 0$（$i \neq \gamma^*$），即网络自动"归位"到最优分支；同时 $Q_i \to Q^{\pi}_{\gamma_i}$。这意味着框架保留了对单一最优 $\gamma$ 的渐近最优性。

## 3. 实验设计

- **环境 / 数据集**：MiniGrid 系列任务，包含迷宫导航、按键拾取（KeyCorridor）、四房间、多房间等离散格子世界。
- **Benchmark**：以 MiniGrid 作为标准离散导航基准。
- **持续学习场景**：自建由**三个顺序切换任务**组成的持续学习设置，模拟奖励结构与视野需求的漂移。
- **对比方法**：
  - 单一折扣因子的基线（如 $\gamma = 0.938$、$\gamma = 0.969$ 等多个固定取值）；
  - 多分支但无自适应混合（即每条 $Q_i$ 独立）的消融；
  - 与"手动挑选最优 $\gamma$"的 oracle 性能对比。
- **评估指标**：累积回报、训练步数、参数效率（识别合适 $\gamma$ 所需样本/episode）、跨任务迁移稳定性。

## 5. 实验数量与充分性

- **实验维度**：
  1. 在多个 MiniGrid 静态任务上与多个固定 $\gamma$ 基线对比；
  2. 在三任务顺序切换的持续学习场景中评估自适应能力；
  3. 多分支共享表示的消融（"每个分支独立学习 vs. 混合门控"）；
  4. 对权重的可视化分析（如 $w_i(s)$ 在状态空间中的分布）。
- **客观性**：实验设计基本公平——所有方法共享相同的输入特征、相同训练步数与同一评估协议；并通过可视化权重来佐证解释性。
- **充分性局限**：实验规模仍偏小、任务多样性有限（未涵盖高维视觉输入、Atari、MuJoCo、稀疏奖励极端分布等）；持续学习仅测试了一种三阶段切换，缺少任务数量更多、切换间隔更短的实验。

## 6. 主要结论与发现

1. **多视野自适应机制能自动识别有效 $\gamma$**：在 MiniGrid 静态任务中，方法无需手工指定折扣即可达到与"最优单 $\gamma$"相当的性能。
2. **对奖励结构变化鲁棒**：在三任务顺序切换场景中，混合权重能随任务变化迁移激活分支（如短期任务激活大 $\gamma_i$，长期任务激活更靠近 1 的小 $\gamma_i$ 对应分支）。
3. **提升参数效率**：相比对每个 $\gamma$ 单独训练，共享特征 + 门控混合显著减少总参数 / 样本开销。
4. **保留渐近最优性**：权重收敛到与 $\gamma^* = \arg\max_{\gamma_i} J(\pi_{\gamma_i})$ 对应的单分支，方法不会因引入冗余而牺牲最优性。
5. **生物合理性**：与动物在不同情境下表现出的可切换时间折扣现象一致，为生物启发学习系统提供算法对照。

## 7. 方法与实验亮点

- **生物学驱动的视角**：将"灵活时间折扣"从行为经济学 / 神经科学迁移到 RL 算法设计，提供了清晰的概念桥梁。
- **可解释性**：Softmax 门控权重 $w_i(s)$ 可被直接可视化，研究者能读出"何时策略更短视 / 更远视"。
- **理论保障**：提供了"网络自动对齐最优 $\gamma^*$"的收敛性质，避免"多分支 = 多冗余"的潜在担忧。
- **轻量集成**：混合门控只是一个 $(K \to K)$ 线性 + Softmax 层，可方便地嵌入现有表格型或带特征的 RL 框架。
- **对持续学习的天然适配**：任务切换时无需重新调参，门控网络可自适应调整。

## 8. 不足与局限

1. **离散表格型任务为主**：方法在 MiniGrid 等小规模离散任务上验证，是否能扩展到高维图像输入（Atari、MuJoCo、真实机器人）尚未证实。
2. **折扣因子集合仍需预设**：$\{\gamma_i\}$ 集合是手动指定的；如何让它**自适应增长 / 收缩**（例如基于分辨率需求自动选取新 $\gamma$）未涉及。
3. **持续学习实验规模有限**：仅三任务顺序切换，未覆盖更长的任务序列、随机顺序、任务身份不告知等更严苛的设定，也未与 EWC、PACKNET、MbLS 等经典持续学习算法定量对比。
4. **缺少与近期多尺度 / 平均回报方法的定量比较**：例如与几何 / 指数-几何混合折扣、平均回报强化学习的对比未给出。
5. **算力与统计严谨性未披露**：训练随机种子数、置信区间、统计显著性检验等均未明确报告。
6. **应用边界**：分支数 $K$ 增加时，$w_i(s)$ 的可识别性可能下降；分支间共享特征也可能引入负迁移，文中未深入讨论。
7. **内在动机结合缺失**：作者在 context 中也指出，与 curiosity / intrinsic motivation 等机制的协同尚未被验证。
