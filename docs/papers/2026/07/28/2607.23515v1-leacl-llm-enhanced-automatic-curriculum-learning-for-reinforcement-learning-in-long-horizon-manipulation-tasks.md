## 摘要
长视野操作任务由于奖励信号稀疏且视野跨度长，对强化学习构成了重大挑战。自动课程学习（ACL）被提出用于应对这些挑战，其方法是在一系列任务上由易到难地逐步训练智能体。然而，ACL 的成效在很大程度上依赖于任务相关的规范——例如定义良好的任务参数空间和难度度量——而这些规范通常需要人工设计，并且难以泛化到多样化的任务中。大语言模型（LLM）的最新进展提供了一条有前景的替代途径，它能够利用 LLM 在网络规模上积累的常识知识，将复杂任务分解为有意义的子任务。这种分解可以为高效学习长视野任务提供自然的课程结构。然而，现有基于 LLM 的方法通常依赖人工设计的密集奖励函数来学习每个子任务，这可能引入偏差，并且仍然需要大量的人工监督。在本文中，我们提出了大语言模型增强的自动课程学习（LEACL），一个融合 LLM 与 ACL 以克服上述局限性的框架。具体而言，LLM 既被用于将任务分解为子任务，也被用于为每个子任务生成任务相关的规范。这些规范随后被 ACL 算法用于仅依靠稀疏奖励信号来指导学习，从而消除了设计密集奖励的需求。我们在 LIBERO 基准上的五个长视野操作任务上对 LEACL 进行了评估。结果表明，LEACL 在成功率方面相比人工设计的密集奖励实现了更优的渐近性能。

## Abstract
Long-horizon manipulation tasks pose significant challenges for reinforcement learning due to sparse reward signals and long horizons. Automatic curriculum learning (ACL) has been proposed to tackle these challenges by progressively training agents on a sequence of tasks, from easier to more difficult. However, the success of ACL depends heavily on task-dependent specifications-such as well-defined task parameter spaces and difficulty measures-which are often manually crafted and difficult to generalize across diverse tasks. Recent advances in large language models (LLMs) offer a promising alternative by enabling the decomposition of complex tasks into meaningful subtasks using the LLMs' web-scale common-sense knowledge. This decomposition can provide a natural curriculum structure for efficient learning of long-horizon tasks. However, existing LLM-based methods typically rely on hand-designed dense reward functions to learn each subtask, which can introduce bias and still requires significant human supervision.   In this work, we propose LLM-enhanced automatic curriculum learning (LEACL), a framework that integrates LLMs and ACL to address these limitations. Specifically, LLMs are used to both decompose tasks into subtasks and to generate task-dependent specifications for each subtask. These specifications are then used by ACL algorithms to guide learning using only sparse reward signals, eliminating the need for dense reward design. We evaluate LEACL on five long-horizon manipulation tasks from the LIBERO benchmark. LEACL achieves better asymptotic performance in terms of the success rates compared to human-designed dense rewards.

## 2. 方法论

### 2.1 整体框架（LEACL）

LEACL 由三个顺序执行的阶段构成：

1. **LLM 任务分解**：将长视野任务分解为一系列语义明确的子任务，每个子任务用 PDDL（Planning Domain Definition Language）规范表示。
2. **LLM 元任务生成**：为每个子任务自动生成任务参数空间（task parameter space）和难度度量（difficulty measure）。
3. **自动课程学习（ACL）**：调用现成 ACL 算法，仅使用稀疏奖励训练 RL 智能体。

### 2.2 关键技术细节

**阶段一：LLM 任务分解**

- 采用**双层提示策略**（bi-level prompting）：
  - 高层 LLM：给定自然语言目标描述，生成 K 个子任务的自然语言描述序列。
  - 低层 LLM：将每个自然语言子任务转换为合法的 PDDL 规范。
- 引入**反思机制**（reflection）：语法验证 + 迭代修正以提高 PDDL 规范的可执行性。
- 形式化表示：每个子任务规范为 $\tau_i = \langle M, F, R, P_i, I_i, G_i \rangle \in \mathcal{T}$，其中 $P_i$ 为谓词集合、$I_i$ 为初始文字集合、$G_i$ 为目标文字合取集合。
- 假设：完整谓词词汇表（grammar）作为先验提供给 LLM（如 LIBERO+ 的全套谓词）。

**阶段二：LLM 元任务生成**

- **任务参数空间**：LLM 识别 $N_i$ 维参数向量 $c_i = (c_i^j)_{j=1}^{N_i}$，形成控制空间 $C_i$，并生成 Python 函数模板将 $C_i$ 映射到 PDDL 子集 $\mathcal{T}_i \subset \mathcal{T}$。例如，开抽屉子任务的控制变量可包括抽屉初始位置与目标开度。
- **难度度量**：LLM 生成 $D$ 个按难度排序的参数向量 $(c_i^1, \dots, c_i^D)$，满足当 $p > q$ 时 $c_i^p$ 比 $c_i^q$ 更难。

**阶段三：自动课程学习**

- 选用 **Active Domain Randomization (ADR)** 作为下游 ACL 算法（虽然 LEACL 设计为可即插即用，支持 ALP-GMM、COVAR-GMM、GOAL-GAN、PLR 等多种算法）。
- 基于 **TeachMyAgent** 框架实现。
- 优化目标为最大化后训练智能体在原始子任务 $M_i$ 上的成功率。

### 2.3 形式化表述

任务建模为有限视野目标增强 MDP：

$$\mathcal{M} = \langle \mathcal{S}, \mathcal{A}, T, \mu, R, \mathcal{S}_G \rangle$$

其中 $T: \mathcal{S} \times \mathcal{A} \to \mathcal{S}$ 为转移函数，奖励函数为：

$$R(s) = \begin{cases} 1, & s \in \mathcal{S}_G \\ 0, & \text{otherwise} \end{cases}$$

学习目标为最大化期望累积回报：

$$\max_{\pi} J(\pi) = \mathbb{E}_{a_t \sim \pi, \mu}\left[\sum_{t=1}^{H} R(s_t \in \mathcal{S}_G)\right]$$

子任务分解后获得子任务–PDDL 配对序列 $(\langle M_i, \tau_i \rangle)_{i=1}^{K}$。

## 8. 不足与局限

### 8.1 方法层面

- **谓词集先验依赖**：需要预先给定领域谓词词汇表（grammar），如 LIBERO+ 提供的全套谓词。这是 LEACL 的核心局限——若谓词不完整，LLM 无法表达所需子目标。
- **LLM 错误传播**：任务分解或 PDDL 生成错误会直接影响课程质量，论文未报告 LLM 失败率与人工干预频率。
- **单 LLM、单 ACL 算法实验**：未对比不同 LLM（GPT-4、Claude 等）与不同 ACL 算法的组合效果。
- **幻觉风险**：LLM 可能在 PDDL 中生成语义上无效但语法合法的子目标，导致无效课程。

### 8.2 实验层面

- **任务规模有限**：仅 5 个 LIBERO+ 任务，未覆盖更广泛的机器人操作场景。
- **缺少消融**：未对提示设计、ACL 算法选择、谓词参数化深度等进行系统消融。
- **算力披露缺失**：GPU 型号/数量、训练时长、LLM 调用成本等未明确报告，影响可复现性评估。
- **统计检验不足**：未报告跨方法的统计显著性检验（如配对 t-test）。
- **种子数较少**：5 个种子在长视野任务成功率评估中方差可能仍较大，部分任务置信区间较宽（如 LEAGUE 在 Task 2 上 $71.0 \pm 37.4$）。

### 8.3 应用层面

- **仿真局限**：仅在 MuJoCo 仿真中评估，未涉及真实机器人迁移（sim-to-real）。
- **任务范围**：主要聚焦桌面操作（tabletop manipulation），对移动操作、双手机器人等场景未验证。
- **对象交互类型局限**：主要为抓取-放置与简单开/关类接触交互，更复杂的装配、柔性物体操作未涉及。
- **LLM 推理成本**：每次训练前需多次 LLM 查询生成课程（任务分解 + 元任务生成），虽强调"减少训练中查询"，但离线成本仍未量化。
