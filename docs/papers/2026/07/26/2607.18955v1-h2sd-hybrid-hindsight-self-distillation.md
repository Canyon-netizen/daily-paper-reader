## 摘要
带可验证奖励的强化学习 (RLVR) 显著提升了大型语言模型在数学推理和代码生成等任务上的推理能力。然而，大多数 RLVR 方法对整个轨迹赋予一个标量结果奖励，导致监督稀疏且词元级信用分配有限。在线策略蒸馏 (OPD) 通过从更强的教师模型蒸馏词元级分布来提供更密集的监督，但需要额外的教师模型，并且通常假设共享词表。在线策略自蒸馏 (OPSD) 通过将同一模型以特权信息为条件来构建教师策略，从而消除了对额外教师模型的依赖。然而，直接匹配教师分布可能导致信息泄露和优化不稳定。RLSD 通过仅使用教师信号来调节更新幅度，避免了直接匹配，但在采样推理失败时无法提供明确的修正方向。为了解决这一权衡，我们引入了 $\mathrm{H}^{2}\mathrm{SD}$，这是一种混合事后自蒸馏框架，它根据轨迹的正确性以不同方式使用教师。对于成功的轨迹，教师接收已确认为正确的学生回答以及一个改述指令，其在原始回答词元上的概率被用于调节更新幅度，而不改变由奖励所决定的方向。对于失败的轨迹，我们让教师以包含关键推理步骤和已验证答案的参考提示为条件，并最小化学生到教师的反向 KL 散度。在多个具有挑战性的推理基准上的实验表明，H$^2$SD 在保持优化稳定性和良好生成效率的同时，持续优于代表性的 RLVR、OPSD 和 RLSD 基线。

## Abstract
Reinforcement learning with verifiable rewards (RLVR) has substantially improved the reasoning capabilities of large language models on tasks such as mathematical reasoning and code generation. However, most RLVR methods assign a scalar outcome reward to an entire trajectory, resulting in sparse supervision and limited token-level credit assignment. On-policy distillation (OPD) provides denser supervision by distilling token-level distributions from a stronger teacher model, but requires an additional teacher and typically assumes a shared vocabulary. On-policy self-distillation (OPSD) removes this dependency by conditioning the same model on privileged information to construct a teacher policy. However, directly matching the teacher distribution may cause information leakage and unstable optimization. RLSD avoids direct matching by using the teacher signal only to modulate update magnitudes, but it cannot provide an explicit correction direction when the sampled reasoning fails. To address this tradeoff, we introduce $\mathrm{H}^{2}\mathrm{SD}$, a hybrid hindsight self distillation framework that uses the teacher differently according to trajectory correctness. For successful trajectories, the teacher receives the student response confirmed as correct together with a rephrasing instruction, and its probabilities on the original response tokens are used to modulate update magnitudes without changing the direction determined by the reward. For failed trajectories, we condition the teacher on a reference hint containing key reasoning steps and a verified answer, and minimize the reverse KL divergence from the student to the teacher. Experiments on multiple challenging reasoning benchmarks show that H$^2$SD consistently outperforms representative RLVR, OPSD, and RLSD baselines while maintaining stable optimization and favorable generation efficiency.

## 1. 核心问题与研究动机

**研究背景**：带可验证奖励的强化学习（RLVR，典型代表 GRPO）显著提升了 LLM 在数学推理、代码生成等任务上的能力，但存在两个固有缺陷：

- **奖励稀疏**：对整条轨迹仅赋予一个标量结果奖励，导致 token 级信用分配（credit assignment）信息不足，无法区分轨迹中哪些 token 真正促成成功或失败。
- **教师依赖**：在线策略蒸馏（OPD）通过更强教师模型的 token 级 logits 提供更密集的监督，但需要额外教师模型且通常要求师生共享词表，限制了其适用性。

**已有自蒸馏路线的权衡**：

- **OPSD**（在线策略自蒸馏）：用同一模型在特权信息（如真实答案）条件下充当教师，目标是 token 级分布匹配。但直接匹配教师分布可能引发**特权信息泄露**与**训练不稳定**。
- **RLSD**：回避直接分布匹配，仅用教师信号调节更新幅度（$\Delta_t$ 作为 token 权重），保持奖励决定的方向。然而当采样推理失败时，单纯的幅度调节**无法提供显式的纠错方向**。

**本文核心问题**：如何在不依赖外部更强教师模型的前提下，既保证优化稳定、避免信息泄露，又能为失败轨迹提供显式的分布级纠错信号？

## 2. 方法论：H²SD 混合事后自蒸馏

### 2.1 核心思想

按轨迹正确性**路由分配**监督策略：

- **成功轨迹**（$R(x,y)=1$）：奖励已提供可靠方向，使用 **幅度调制**（RLSD 风格）进行 token 级精细信用分配，不改变方向。
- **失败轨迹**（$R(x,y)=0$）：负奖励无法指明如何修正，使用 **反向 KL 蒸馏** 进行显式分布级纠错。

### 2.2 关键设计：提示（Hint）生成

使用一个更强的 LLM（Kimi-K2.6）作为提示生成器，为每个问题 $x$ 生成自然语言提示 $h$：

$$h = \mathcal{H}(x)$$

提示包含**关键中间推理步骤 + 验证器确认的最终答案**。提示仅训练时可用，推理时不可见，从而构造自教师。OPSD 与 H²SD 使用相同提示，以隔离"如何利用提示"这一变量的影响。

### 2.3 损失函数

**成功轨迹（幅度调制 + 改述）**：教师接收"已确认正确"的学生回答与改述指令（"Rephrase the correct response"），其在原始 token 上的概率计算 RLSD 式幅度权重：

$$w_t = \exp(\mathrm{sign}(\hat{A})\cdot \Delta_t) = \left(\frac{P^T(y_t)}{P^S(y_t)}\right)^{\mathrm{sign}(\hat{A})}$$

$$\hat{A}_t = \hat{A}\left[(1-\lambda) + \lambda\,\mathrm{clip}(w_t, 1-\epsilon_w, 1+\epsilon_w)\right]$$

**失败轨迹（反向 KL 纠错）**：以提示 $h$ 条件化教师，最小化学生到教师的反向 KL：

$$\mathcal{L}_{\mathrm{RKL}} = \frac{1}{T}\sum_{t=1}^{T} D_{\mathrm{KL}}\!\left(p^{S}_{t,\theta}\,\big\|\,\mathrm{sg}[p^{T,h}_{t,\theta}]\right)$$

其中 $p^S_{t,\theta} = \pi_\theta(\cdot|x, y_{<t})$，$p^{T,h}_{t,\theta} = \pi_\theta(\cdot|x, h, y_{<t})$，$\mathrm{sg}[\cdot]$ 表示停止梯度。

**总体目标**：

$$\mathcal{L}_{\mathrm{H^2SD}} = \mathbb{E}_{x,y}\!\left[m\,\mathcal{L}_{\mathrm{RLSD}} + \gamma(1-m)\,\mathcal{L}_{\mathrm{RKL}}\right]$$

其中 $m = \mathbf{1}[R(x,y)=1]$，$\gamma$ 控制失败轨迹上的纠错强度。

### 2.4 实现细节

- 为降低长链推理场景下全词表蒸馏的内存开销，仅保留学生 top-100 token 的精确概率，其余合并到一个尾桶（tail bucket）。
- 基于 VERL + SGLang 框架实现；OPSD 与 SRPO 的失败分支采用 $\alpha=0.5$ 的广义 Jensen–Shannon 散度。
- 训练使用 **4 节点 × 8 张 NVIDIA H200 140GB GPU**。

## 3. 实验设计

### 3.1 基础模型与提示生成器

- **基础模型**：Qwen3-30B-A3B-Instruct-2507（统一基模型，所有方法相同）。
- **提示生成器**：Kimi-K2.6（仅用于生成自然语言提示）。

### 3.2 基准任务（逻辑推理）

| 任务 | 规格 | 说明 |
|------|------|------|
| Sudoku | $6\times6$, $8\times8$ | 行/列/宫内数字不重复 |
| Calcudoku | $5\times5$, $6\times6$ | 区域算术约束 |
| Arrow Maze | $6\times6 \sim 10\times10$ | 射线长度匹配数字 |

### 3.3 对比基线

- **GRPO**：纯 RLVR 基线。
- **OPSD**：直接做 token 级分布匹配的自蒸馏。
- **RLSD**：仅做幅度调制的稳定自蒸馏。
- **RLSD+hint**：把 RLSD 的答案级特权信息替换为提示（控制变量）。
- **SDPO**：基于兄弟解（sibling solution）的自蒸馏。
- **SRPO**：路由成功→GRPO、失败→熵加权 SDPO 的样本路由方法。

### 3.4 评估指标

- pass@1 验证准确率（%）；
- 平均生成 token 数（效率）；
- Actor 熵（nats，衡量策略多样性与探索稳定性）。

## 6. 主要结论与发现

- **整体性能领先**：H²SD 在 Sudoku、Calcudoku、Arrow Maze 三个基准上取得最佳综合表现（Overall 平均 50.49%，远高于第二名 RLSD 的 24.85%）；在 Arrow Maze 所有尺寸上均排第一。
- **Sudoku 优势显著**：6×6 上从基座 24.50% 跃升至 **76.50%**，8×8 上从 14.00% 跃升至 **57.25%**。
- **泛化性**：在未训练规模（Arrow Maze-8×8、10×10）上仍取得最佳成绩，说明改进源自推理能力而非过拟合。
- **效率优势**：H²SD 以最少的平均生成 token 数取得最高 pass@1（Figure 3），说明改进并非依赖更长响应。
- **三种关键设计均必要**：
  1. 基于正确性的路由（Reversed Routing 会引发熵坍缩至 0，验证路由方向正确）；
  2. 过程级提示（Hint）优于单纯答案、程序化反馈和兄弟解；
  3. 成功轨迹上的改述对 Magnitude Only 与 H²SD 有显著增益（+23.75/+32.00 与 +8.00/+5.75 百分点），但对 Reverse-KL Only 反而有害。
- **稳定训练**：H²SD 在 actor 熵上保持稳定，而 Reverse-KL Only + 改述与 Reversed Routing 均出现熵骤降。

## 7. 优点与亮点

- **正视权衡、给出统一解**：清晰刻画了 OPSD（强纠错但易泄漏）↔ RLSD（稳定但弱纠错）之间的张力，并提出按轨迹正确性自适应的混合方案。
- **路由设计简洁而有效**：成功轨迹用幅度调制、失败轨迹用反向 KL，只需一个正确性掩码 $m$，实现简单。
- **改述机制细节考究**：让教师改述学生已正确的回答，避免与学生走不同推理路径而过度约束正确轨迹。
- **提示信号差异化消融**：系统比较 4 种特权上下文（程序化反馈、真实答案、兄弟解、提示），说明**过程级**信息对复杂推理更有效。
- **稳定性分析充分**：通过 actor 熵曲线揭示 Reversed Routing 与 Reverse-KL+改述的熵坍缩现象，反衬 H²SD 的稳健。
- **效率与效果兼顾**：在生成长度更短的情况下取得更高准确率，工程友好。
- **基线覆盖广**：与 GRPO、OPSD、RLSD、RLSD+hint、SDPO、SRPO 等代表性方法全方位对比。

## 8. 不足与局限

- **基准范围较窄**：仅在 Sudoku、Calcudoku、Arrow Maze 三类**逻辑/约束满足**任务上评估，缺乏数学（GSM8K、MATH）、代码（HumanEval、MBPP）、开放问答等更广泛推理基准上的验证。
- **单一基模型**：所有实验均基于 Qwen3-30B-A3B-Instruct-2507，未验证方法在不同规模（如 7B/70B）、不同家族（如 Llama、DeepSeek）模型上的可迁移性。
- **依赖外部强模型生成提示**：使用 Kimi-K2.6 生成 hint 引入额外成本与外部依赖；若替换为弱模型生成提示，性能可能下降（文中未给出此类消融）。
- **训练时长未披露**：算力与训练成本（wall-clock、训练步数、单步时间）信息不完整，难以评估实际部署成本。
- **失败轨迹纠错的过约束风险**：在反向 KL 下，若提示与学生合理但不同的推理路径存在分歧，可能压制多样性；表 4 已暗示 Reverse-KL Only + 改述在正确轨迹上表现下降。
- **奖励可验证性假设**：方法依赖规则化、可验证的成功/失败判定（$R(x,y)\in\{0,1\}$），难以直接迁移到奖励稀疏或主观性强的开放式生成任务。
- **top-100 概率近似的偏差**：为节省显存所做的概率截断可能引入系统性偏差，论文未给出该近似对最终性能影响程度的量化分析。
