## 摘要
多视角空间推理要求视觉-语言模型在图像间比较视觉证据、对齐物体对应关系，并在长视觉上下文中推断空间关系。在这种场景下，思维链推理往往变得越来越冗长，却并不能带来更高的准确率。可验证奖励的强化学习天然契合该任务，但标准 GRPO 奖励仅依赖于稀疏的结局级反馈，既无法提供关于推理轨迹何处出错的信号，也无法对其长度施加任何控制。我们提出了 LenGuard-GPC，一个同时解决上述两个问题的密集奖励框架。对于每一条采样轨迹，它比较在标准提示与引导提示下的逐词元预测分布，并以所得的词元求和 KL 散度作为密集奖励信号。由于该 KL 惩罚沿词元累积，否则会无论质量如何都偏向较短的回复，我们引入了一种分阶段长度奖励，将推理长度控制在合理范围内，同时避免简单地鼓励简短回复。在六个多视角空间推理基准上的实验表明，LenGuard-GPC 在提升准确率的同时降低了平均回复长度。

## Abstract
Multi-view spatial reasoning requires vision-language models to compare visual evidence across images, align object correspondences, and infer spatial relations over long visual contexts, a setting where chain-of-thought reasoning tends to grow verbose without becoming more accurate. Reinforcement learning with verifiable rewards is a natural fit for this task, but standard GRPO reward relies on sparse outcome-level feedback and gives no signal about where a reasoning trajectory goes wrong, nor any control over its length. We propose LenGuard-GPC, a dense reward framework that addresses both problems together. For each sampled trajectory, it compares the token-wise predictive distributions under a standard prompt and a guided prompt, and uses the resulting token-sum KL divergence as a dense reward signal. Since this KL penalty accumulates over tokens and would otherwise reward shorter responses regardless of their quality, we introduce a staged length bonus that keeps reasoning length within a controlled range without simply encouraging brevity. On six multi-view spatial reasoning benchmarks, LenGuard-GPC improves accuracy over vanilla GRPO while reducing average response length.

# LenGuard-GPC 论文总结

## 1. 核心问题与研究背景

**问题定义**：多视角空间推理（Multi-view Spatial Reasoning）要求视觉-语言模型（VLM）在同一场景的多个不同视角图像之间比对视觉证据、建立物体对应关系，并推断空间关系。这一任务超越了单图视觉问答的范式，模型必须显式解决"跨视角物体匹配"问题。

**关键挑战**：
- **长推理链不带来准确率提升**：模型倾向于对每张图进行冗长描述，推理轨迹越长，越容易积累未校正的错误，错误传播加剧，反而干扰了对关键跨视角证据的提取。
- **稀疏奖励缺乏过程级反馈**：标准 GRPO（Group Relative Policy Optimization）仅使用结局级（outcome-level）的对错奖励，无法定位推理轨迹中具体哪一步出错（例如视角错配、物体对应错误、空间关系推断错误等局部错误）。
- **长度控制难题**：单纯的奖励塑造容易引发两种退化行为——(a) 极短回答（short-answer collapse），即模型仅输出答案跳过推理；(b) 边界聚集（boundary-seeking），即模型将生成长度集中在奖励阶梯的最低边界上。

**研究意义**：现有 GRPO 训练在多模态长上下文任务中缺乏过程级引导与生成长度调控机制，亟需一种稠密且长度感知的奖励设计。

## 2. 方法论

### 2.1 核心思想

LenGuard-GPC 提出一种**长度守卫的引导提示一致性奖励框架**（Length-Guarding with Guided-Prompt Consistency），由两个核心组件构成：
1. **引导提示一致性奖励（Guided-Prompt Consistency Reward）**：在标准提示基础上引入一个含任务级指导句 $h$ 的"引导提示"，对同一采样轨迹计算两种条件下的逐词元 KL 散度，作为过程级稠密信号。
2. **分阶段长度奖励（Staged Length Bonus）**：分段式长度奖励机制，避免 KL 累积带来的偏短倾向与边界聚集。

### 2.2 关键技术细节

**引导提示构造**：
- 标准提示 $x = (\mathcal{I}, q)$，其中 $\mathcal{I} = \{I_1, \dots, I_m\}$ 为多视角图像，$q$ 为问题。
- 引导提示 $x_{gp} = (\mathcal{I}, q, h)$，其中 $h$ 是由 GPT-5.3-Chat 为每个训练实例生成的单句任务指导。
- 引导提示**仅用于训练时的奖励计算**，推理时不使用，引入零推理时开销。

**KL 散度稠密奖励**：对同一条采样轨迹 $y = (y_1, \dots, y_T)$，在标准提示和引导提示条件下分别计算逐词元预测分布：

$$p_t^{std} = \pi_\theta(\cdot \mid x, y_{<t}), \quad p_t^{gp} = \pi_\theta(\cdot \mid x_{gp}, y_{<t})$$

$$D_t = D_{KL}\!\left(p_t^{std} \,\|\, p_t^{gp}\right)$$

累积 KL 散度作为一致性度量：

$$S_{KL}(y) = \sum_{t=1}^{T} D_t, \quad r_{KL}(y) = -\lambda_{KL} \cdot S_{KL}(y)$$

**关键实现细节**：轨迹仅从标准提示 $x$ 自回归采样一次，引导提示下的分布通过 **teacher forcing** 在固定轨迹上并行计算 token 级预测，因此训练时间仅增加约 $1.6\times$，而非翻倍。

**分阶段长度奖励**：定义三个长度边界 $(l_1, l_2, l_3)$ 和两个奖励水平 $(r_1, r_2)$：

$$r_{len}(T) = \begin{cases} 0, & T < l_1 \\ r_1 + (r_2 - r_1)\cdot\dfrac{T - l_1}{l_2 - l_1}, & l_1 \le T \le l_2 \\ r_2, & l_2 < T \le l_3 \end{cases}$$

- $T < l_1$：无奖励，抑制过短回答；
- $l_1 \le T \le l_2$：线性递增，平衡充分性与紧凑性，避免边界聚集；
- $l_2 < T \le l_3$：恒定 $r_2$，不鼓励额外长度。

**GRPO 总奖励函数**：

$$r(y) = \lambda_{task}\,r_{task}(y) + \lambda_{KL}\,r_{KL}(y) + \lambda_{len}\,r_{len}(T)$$

其中 $r_{task} = \lambda_{acc}\,r_{acc} + \lambda_{format}\,r_{format}$。优势函数在组内归一化：

$$A_i = \frac{r_i - \mathrm{mean}(\{r_j\})}{\mathrm{std}(\{r_j\}) + \epsilon}$$

### 2.3 算法流程

```
输入：训练实例 (I, q, a)，策略 π_θ，组大小 G
1. 构造 x = (I, q) 与 x_gp = (I, q, h)
2. 从 π_θ(·|x) 采样 G 条轨迹 {y_i}
3. 对每条 y_i 计算 r_acc, r_format, r_KL, r_len
4. 组合为 r_i = r(y_i)
5. 组内归一化得到优势 {A_i}
6. 用标准 GRPO 目标更新 π_θ
```

## 6. 主要结论与发现

1. **准确率提升**：在 6 个基准上，LenGuard-GPC 取得 **57.3%** 平均准确率，比 vanilla GRPO（55.3%）提升 **+2.0** 个点，比基模型（51.4%）提升 **+5.9** 个点，并在开源模型中达到最优平均分。
2. **域内显著增益**：MMSI-Bench **+3.9**（32.2→36.1）、MindCube **+3.7**（44.7→48.4）、ViewSpatial **+2.5**（44.4→46.9）。
3. **域外不退化**：3DSR +0.7、BLINK +1.1、CV-Bench +0.3，证明未过拟合训练分布。
4. **跨视角位置推理提升最显著**：MMSI-Bench 子类别中 Cam–Obj **+13.9**、Cam–Reg **+12.0**、Obj–Reg **+7.1**、Obj–Obj **+5.3**，验证了稠密 KL 奖励在跨视角对齐上的针对性。
5. **效率改进**：MMSI 上平均 token 从 307.9 降至 261.9（**−14.9%**），ViewSpatial 上从 196.5 降至 121.6（**−38.1%**），实现"更短且更强"。
6. **组件必要性**：消融表明分阶段长度奖励单独贡献正向（33.5→36.1），格式奖励起到稳定器作用。
7. **通用性**：方法框架可推广至视频理解、多图比对、文档视觉推理、具身感知等长上下文多模态任务。

## 7. 优点

- **方法新颖性**：将"引导提示"作为参考条件来构造过程级奖励（受 Self On-Policy Distillation 启发，但用作 RL 奖励而非监督蒸馏损失），思路简洁而有效。
- **零推理开销**：引导提示仅训练时使用，推理时与基模型一致，部署友好。
- **可解释的过程级反馈**：token-sum KL 提供了细粒度的轨迹级信号，理论上可定位局部推理偏差。
- **长度控制双目标兼顾**：分段式奖励同时抑制过短回答与边界聚集，比平坦奖励更鲁棒。
- **效率-效果双赢**：在多数基准上同时实现准确率提升与 token 成本下降。
- **计算经济**：teacher forcing 复用采样轨迹，使额外开销控制在 $1.6\times$ 而非 $2\times$。
- **泛化验证完整**：域内 + 域外共 6 个基准，含细粒度子类别分析，论据充分。

---

## 8. 不足与局限

### 8.1 方法层面

- **引导质量依赖外部 LLM**：$h$ 由 GPT-5.3-Chat 生成，引入了对闭源模型的依赖与潜在的提示偏差（不同引导质量对奖励稳定性影响未分析）。
- **KL 分布对齐假设**：以"标准提示 vs 引导提示"分布差作为过程奖励，但 $h$ 仅为单句指导，是否充分反映正确的空间推理过程存疑。
- **长度奖励设计依赖调参**：分段边界 $(l_1, l_2, l_3)$ 与奖励水平 $(r_1, r_2)$ 需针对数据集手工设定，跨任务迁移性未验证。
- **token-sum KL 仍存在偏短倾向**：尽管通过分段奖励缓解，但 KL 项本身随长度累积的根本性质未被根本解决。

### 8.2 实验层面

- **算力与训练预算未披露**，影响可复现性；
- **缺乏多次种子运行的方差报告**，统计显著性不明确；
- **消融仅在 MMSI-Bench 单基准**，未在多基准上交叉验证组件贡献；
- **无超参数敏感性分析**（不同 $\lambda_{KL}$、不同长度边界的影响）；
- **缺乏与同类过程级 RL 方法的直接对比**（如 R1-VL 的 step-wise GRPO、Video-R1、Insight-V 等）；
- **引导提示生成策略的消融缺失**：未比较人工设计 vs LLM 生成 vs 不同 LLM 的影响。

### 8.3 应用层面

- **任务域集中于多视角空间推理**，对其他长上下文多模态任务（视频、文档、具身）的迁移仅作展望，未提供实证；
- **8B 规模基模型**，未验证方法在更大或更小模型上的可扩展性；
- **MMSI-Bench 细粒度分析显示**，属性外观（Appr.）和物体运动（Obj.）子类别反而下降（−7.6 和 −1.5），表明奖励信号对**局部属性/动态推理**的引导能力有限。
