## 摘要
运行受约束的动力系统要求控制器在高效求解复杂任务的同时满足递归可行性与安全性约束。为应对这些相互冲突的需求，我们提出了可行动作最优控制（FAOC），一个将强化学习（RL）与最优控制（OC）相融合的新型控制框架。其核心贡献在于一种计算高效的、基于优化的映射算法，该算法将强化学习智能体的动作从静态的抽象集合映射为状态依赖的最优控制问题（OCP）可行参数集合，从而保证严格满足动力系统的约束。因此，FAOC 有效地结合了最优控制的可预期安全性与强化学习的灵活性。与已有工作相比，强化学习智能体的抽象动作空间无需专家或启发式设计，最优控制问题的构建也不会因强化学习无法保证可行性而妥协。我们将该方法应用于机器人乒乓球实时运动规划任务中，该任务涵盖了上述所有挑战。通过仿真实验，我们表明 FAOC 在样本效率与闭环性能两方面均优于当前最先进的基线方法。

## Abstract
Operating constrained dynamical systems requires controllers to efficiently solve complex tasks while enforcing recursive feasibility and safety constraints. To address these competing requirements, we present Feasible Action for Optimal Control (FAOC), a novel control framework integrating Reinforcement Learning (RL) and Optimal Control (OC). The key contribution is a computationally efficient, optimization-based mapping algorithm that transforms the RL agent's action from a static abstract set into a state-dependent feasible parameter set of the Optimal Control Problem (OCP), guaranteeing strict satisfaction of the dynamical system's constraints. Thus, FAOC effectively combines the predictable safety of OC with the flexibility of RL. In contrast to prior work, the abstract action space of the RL agent does not require expert or heuristic design, and the OCP formulation is not compromised by the inability of RL to guarantee feasibility. We apply our approach to real-time motion planning for robot table tennis, which encapsulates these challenges. Via simulated experiments, we show that FAOC outperforms state-of-the-art baselines in both sample efficiency and closed-loop performance.

## 1. 核心问题与整体含义

**研究动机与背景**

- 受约束的动力学系统（如机器人）要求控制器在高效完成复杂任务的同时，严格保证**递归可行性**与**安全性约束**。

- 最优控制（OC）/模型预测控制（MPC）能显式建模动力学并严格执行约束，但难以处理非凸、长视野、稀疏奖励任务，且在大规模 OCP 下**计算可能不可实时**。

  1. **动作空间依赖专家/启发式设计**（如人为给定可行边界），导致"边界模糊"；
  2. **OCP 可行性依赖 RL 参数时，RL 必须隐式学习可行域**，严重影响学习效率与最终性能。
- 本文目标是设计一个映射算法，把 RL 的抽象动作 **bijectively** 映射到 OCP 的**状态依赖可行参数集**，从而兼具 OC 的安全性与 RL 的灵活性。

## 2. 方法论

### 2.1 整体框架（FAOC）

FAOC 由四步闭环构成（见图 1）：
1. **RL 智能体**基于状态 $x$ 输出多元高斯分布的参数 $(\mu, \Sigma)$，通过非线性有界函数 $b(\cdot)$（如 tanh）得到静态抽象动作 $\bar{a}\in\bar{A}\subset\mathbb{R}^n$；
2. **映射算法** $\mathcal{M}$ 把 $\bar{a}$ 映射为状态依赖的可行参数 $p\in\mathcal{P}(x)\subset\mathbb{R}^n$；
3. 将 $p$ 嵌入 OCP 的"动作编码参数"位置（如终端状态目标 $Cx_N=p$），求解 OCP；
4. 将最优控制输入以开环方式作用于系统，进入下一周期。

### 2.2 OCP 可行参数集的拓扑刻画（Lemma 1 & Corollary 1）

- 对通用参数化 OCP：
$$\min_{z\in Z}\,f(z,p,x) \quad \text{s.t.}\; g(z,p,x)\le 0,\; H_zz+H_pp+H_xx+h=0$$
- 在以下条件下 $\mathcal{P}(x)$ 是**紧、实心（solid）、凸**集：$Z$ 紧凸；$g$ 关于 $(z,p)$ 联合凸；联合可行集在 $p$ 方向无衰退方向；存在严格可行内部点；以及 $\text{range}(H_p)\subseteq H_z^T$。
- **推论**：对带终端约束 $Cx_N=p$ 的线性 MPC（$C$ 行满秩），$\mathcal{P}(x)$ 自动具备上述拓扑性质。

### 2.3 通用径向映射算法（Algorithm 1）

针对两个紧、实心、凸集 $\mathcal{X}$（基集）、$\mathcal{Y}$（目标集）：

$$
\text{若 } x=x_c:\; y=y_c;\quad \text{否则 } d=x-x_c,\; d'=\phi(d),\; y=y_c+\beta\alpha d'
$$

其中 $\alpha\ge 1$ 为 $x_c+\alpha d$ 到达 $\text{bd}\,\mathcal{X}$ 的比例，$\beta>0$ 为 $y_c+\beta d'$ 到达 $\text{bd}\,\mathcal{Y}$ 的比例；$\phi$ 为**正齐次、可逆、连续**的方向变换。

- **Proposition 1**：在上述条件下 $\mathcal{M}$ 严格可逆（无 action aliasing）。
- 当 $\mathcal{X},\mathcal{Y}$ 为多面体（$H$-表示）时，$\alpha,\beta$ 可由简单的 half-space ratio test 解析计算。

### 2.4 缓解几何畸变

- **2D 面积匹配变换（Propositions 2 & 3）**：定义归一化面积函数
$$a_X(\xi)=\frac{A_{X(\xi)}}{A_X},\quad \xi\in[0,2\pi]$$
方向变换 $\phi$ 用极角 $a_Y^{-1}(a_X(\xi))$ 替换，**严格保证边际角分布匹配**，但仅适用于 $n=2$。
- **任意维度线性变换（Proposition 4）**：用**椭球代理集** $\tilde{\mathcal{X}}=Q_{\tilde{X}}u+q_{\tilde{X}},\tilde{\mathcal{Y}}=Q_{\tilde{Y}}v+q_{\tilde{Y}}$，得到 $\Phi=Q_{\tilde{Y}}Q_{\tilde{X}}^{-1}$。对多面体可由 **MVIE（最大内切椭球）** 通过 SDP 高效求解。

### 2.5 隐式目标集的可实时计算

- 将目标集表示为更高维凸集的仿射像：$\mathcal{Y}=E\mathcal{W}+e$，$E\in\mathbb{R}^{n\times n_w}$。
- **内部点计算**：通过降低维度的 $\mathcal{V}=\{v\mid Fv+w_p\in\mathcal{W}\}$ 求 Chebyshev 中心；
  - **Proposition 6（顶点法）**：在低维可用；
  - **Proposition 7（lifting 法）**：对多面体 $\mathcal{W}$ 利用对偶范数约束，可应用于任意维度。
- **形状矩阵（Proposition 8 & Example 3）**：通过离线构造包含初始状态空间 $\mathcal{X}_0$ 的增广集 $\mathcal{V}_a$，可计算**状态无关**的 $\Phi$（避免了每次控制循环求解 SDP）。
- **边界比例 $\beta$**：在 $\mathcal{W}$ 上做一次凸优化（最大化 $\beta$，约束 $Ew+e=y_c+\beta d'$），无需显式几何表达。

### 2.6 整体实时映射

联合 Proposition 5/6/7（内部点）、Proposition 8（状态无关 $\Phi$）与 (8)（$\beta$ 求解），整套映射算法在实时控制循环中**无需显式几何表达**，保证可行性。

## 6. 主要结论与发现

- **FAOC 在所有三个实验中均显著优于基线**：回球率、上旋、回球速度显著领先，下旋与目标距离与最强基线无显著差异，但**没有基线在任何指标上显著优于 FAOC**；
- **2D 可控性优于 1D 系列**：维度更完整的 RL 输出带来更高最终性能与更低的种子方差；
- **可达性感知的动作空间优于无约束的动作空间**：FAOC 显著优于 2Dsoft，原因是 2Dsoft 探索了大量不可行航点，损害样本效率；
- **FAOC 对 RL 频率降低更鲁棒**：7.8125 Hz 下 FAOC 性能几乎不变，其余控制器性能下降明显，FAOC 的"轨迹段可控性 + 严格可达性"优势更突出；
- **算法与架构升级（SimBaV2）对所有方法均有益**，但 FAOC 的动作空间设计优势仍然存在。
