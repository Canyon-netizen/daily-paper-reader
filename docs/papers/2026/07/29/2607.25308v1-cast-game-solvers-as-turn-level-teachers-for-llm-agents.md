## TL;DR

CAST 是一种让大语言模型在长视野博弈中学会精准决策的新训练方法。它利用游戏自带的求解器来判断每一步是好是坏——如果动作让状态更接近胜利，求解器优势就为正；如果把局面推向死路，优势就为负。这个信号被压缩归一化后叠加到传统的结果奖励上，使模型在稀疏奖励之外获得了轮次级的精细监督。实验表明，CAST 在 Sokoban、Minesweeper、Rush Hour 三款游戏中全面超越所有训练基线，并实现了 ALFWorld 和 WebShop 上的最高零样本平均性能，同时求解器的计算开销几乎可以忽略不计（仅占训练时间的 0.0073%）。

## 研究背景与动机

训练 LLM 在需要多步规划的游戏中做决策，是通往通用决策智能体的一条有前景的路线。在这类任务中，玩家必须前瞻数十甚至上百步，任何一步失误都可能导致全局失败。然而，当前主流的 [[RLVR]]（基于可验证奖励的强化学习）方法——以 GRPO、DAPO 为代表——只依赖稀疏的 0/1 终端奖励：赢了有信号，输了没信号，但中间哪一步走得好、哪一步走得差，完全无从得知。这种 [[Credit assignment|信用分配]] 失效的问题，使得模型在长轨迹中很难学到"哪一步真正决定了成败"。

学术界已经意识到这个问题，并尝试引入更密集的过程监督信号。蒙特卡洛树搜索（MCTS）可以提供每步的价值估计，但计算代价极其昂贵，难以扩展到大规模训练。[[Process reward|过程奖励模型]]（PRM）通过额外训练一个神经网络来评分每一步，但训练数据标注成本高，且学到的价值函数未必准确。还有一些方法利用跨轨迹的分组对比，但它们依赖于相似状态在 batch 中反复出现，对于探索性极强的游戏场景并不适用。

CAST 的核心洞察来自于一个简单却深刻的观察：游戏本身往往配有领域专属的求解器。对于 Sokoban，可以用 A* 搜索计算当前状态距离目标还差多少步；对于 Minesweeper，约束求解器能精确算出还需要揭示多少格才能确保胜利；对于 Rush Hour，最优移动次数可以直接 BFS 得到。这个求解器返回的"成本到目标"数值，本质上就是一种状态价值函数——它天然地衡量了"当前局面有多好"。因此，如果某一步动作让这个数值变小了，就说明动作将状态向成功推进；反之则说明在帮倒忙。这正是 CAST 所依赖的轮次级监督信号：它不需要昂贵的树搜索，不需要额外的神经网络训练，只需要调用一个现成的求解器，几乎零成本，却能给出精确到每一步的"好与坏"判断。

## 方法

CAST 的方法论可以从三个层次来理解：如何定义信号、如何处理信号、如何将信号注入训练。

首先是信号的定义。给定当前状态 $s_t$ 和执行动作 $a_t$ 后的下一状态 $s_{t+1}$，求解器返回两个成本值 $N(s_t)$ 和 $N(s_{t+1})$，分别表示从两个状态到达目标的剩余最优步数。在最优策略下，每一步恰好减少 1，因此可以定义原始求解器优势为：

$$A^{\pi_{\text{Solver}}}(s_t, a_t) = -1 + N(s_t) - \mathbb{E}_{s_{t+1}}[N(s_{t+1})]$$

对于最优动作，$N(s_{t+1}) = N(s_t) - 1$，所以优势为 0。但 0 不利于作为正向信号来强化好动作，因此 CAST 引入了一个平移：

$$\tilde{A}^{\pi_{\text{Solver}}}(s_t, a_t) = N(s_t) - \mathbb{E}_{s_{t+1}}[N(s_{t+1})]$$

这样，最优推进动作得到 +1，无效动作得到 0，有害动作得到负值，而一旦进入死状态则惩罚封顶。

接下来是信号的处理。原始的优势值存在两个实际问题：其一是重尾分布——进入死状态的惩罚可能远大于正常推进的奖励；其二是跨游戏量纲不一致，Sokoban 的最优步数可能是几十步，而 Minesweeper 的数值范围完全不同。CAST 采用 asinh 压缩和 batch 级 RMS 归一化来解决这两个问题：

$$g(x) = \text{asinh}(x), \quad h(x) = \frac{g(x)}{\text{RMS}_{\mathcal{B}}(g) + \epsilon}$$

asinh 函数在小信号区域近似线性，能保留大多数 $\pm 1$ 步推进之间的可区分度；对于极端值则转为对数增长，从而压缩重尾。RMS 归一化不减去均值是有意为之——保留 0 作为"无推进"的语义基准，正负号本身即表示"好坏"。

最后是将信号注入训练。传统 GRPO 使用轨迹级结局优势 $\hat{A}^{\text{outcome}}_i$ 来更新策略，CAST 则将其扩展为：

$$\hat{A}_{i,t} = \hat{A}^{\text{outcome}}_i + \alpha\, h\!\left(\tilde{A}^{\pi_{\text{Solver}}}_{i,t}\right)$$

其中 $\alpha$ 控制求解器引导强度（默认 0.1）。这个式子实现了三层粒度的对齐：轨迹级（结局奖励）、轮次级（求解器优势）、token 级（策略梯度更新的实际粒度）。

论文进一步论证了一个重要的理论性质：在 soft-optimal 求解器假设下，最大化求解器优势等价于 [[On-policy distillation|在策略蒸馏]]——但不需要教师模型输出 logits，仅用一个标量值就能编码教师的动作偏好。直觉上，求解器优势在引导模型学习"哪些动作被教师偏爱"的同时，也允许模型在任务奖励的驱动下偏离教师、去发现教师未覆盖但同样优秀的动作——这是纯粹的 logit-free OPD 无法做到的。

## 实验与结果

CAST 的实验覆盖了三个核心游戏和两个零样本迁移基准，设计上充分考虑了域内（in-domain）和难度外推（unseen-difficulty）两种评估场景。

在域内评估中，三个游戏分别测试不同的认知挑战：Sokoban 要求长视野规划和不可逆动作中的精细决策；Minesweeper 涉及部分可观测状态下的贝叶斯推理；Rush Hour 则需要组合搜索找到最少步数解。结果显示，CAST 在所有三个游戏的域内评估中均取得最高的 Avg@4 成功率，相较于去掉求解器信号的 DAPO 基线，Sokoban 提升 5.7 个百分点，Minesweeper 提升 14.9 个百分点。更值得注意的是训练效率的改善：CAST 达到峰值性能所需的更新步数普遍减少 1.7× 到 2.0×，这意味着求解器优势信号不仅提升了最终表现，还加速了学习过程。

在未见难度评估中，模型面对的是训练时未曾见过的更大棋盘或更多物体。CAST 依然保持了优势地位，表明它学到的不只是记忆特定难度的解法，而是真正掌握了一种可迁移的规划能力。

零样本迁移是更严苛的考验：训练于游戏任务的模型直接应用于 ALFWorld（具身家务任务）和 WebShop（网页购物任务）。CAST 在这两个基准上都取得了训练方法的最高平均性能，ALFWorld 平均 37.9，WebShop 平均 22.7，整体 30.3 超过第二名 5.6 分。这个结果相当引人注目——游戏训练中习得的规划与回退策略，似乎在一定程度上泛化到了真实世界的任务结构中。

消融实验验证了方法各组件的必要性。$\alpha = 0.1$ 表现最佳，过小则求解器信号被结局奖励淹没，过大则干扰任务目标的学习。asinh 压缩和 RMS 归一化缺一不可：去掉 asinh 会导致极端惩罚主导梯度，去掉 RMS 则在后期训练中引入剧烈波动。论文还验证了方法对精确求解器的依赖程度：用 DQN 学到的值函数替代精确求解器后，CAST 的性能仅有轻微下降，但依然优于所有训练基线。这说明 CAST 对近似求解器的鲁棒性良好，在没有精确求解器的场景下也有实用价值。

## 讨论与可借鉴点

CAST 的核心贡献在于提供了一种廉价且精确的轮次级监督来源。游戏求解器在 LLM 的整个训练周期中只贡献了 0.0073% 的计算时间，却带来了全面的性能提升和训练加速。这种"以标量值替代教师 logits"的思路，避开了 logit distillation 的高内存开销和软标签对齐问题，同时在理论上被证明等价于在策略蒸馏——这为 [[Credit assignment|信用分配]] 问题提供了一个优雅的实践路径。

不过，CAST 的适用范围并非没有边界。它依赖于领域专属求解器的存在——对于那些没有高效精确求解器的任务（如开放式规划、多智能体协作），CAST 的信号来源就失效了。虽然 DQN 学习型值函数的实验表明近似求解器可以作为备选，但这又引入了额外的训练成本和泛化误差。另一个值得思考的方向是：求解器优势信号是否只在早期训练阶段发挥作用，在模型已经充分学会游戏规则后，是否会变得冗余甚至引入噪声？论文没有系统地分析这一动态过程。

对于更广泛的研究社区，CAST 的启示在于：与其一味追求更强的模型架构或更复杂的奖励机制，不如充分利用任务本身已经蕴含的结构信息。游戏求解器、形式化验证器、约束求解器——这些工具在各自的领域中积累了几十年的算法优化，在 LLM 时代重新审视它们作为"教师"的角色，或许能为 [[RLVR]] 的过程监督打开新的思路。

## 摘要
训练大语言模型（LLMs）在长视野博弈中行动是迈向通用决策的一步有前景的方向，然而基于可验证奖励的强化学习（RLVR）依赖于稀疏的最终奖励，几乎无法揭示哪些决策决定了成功。更密集的过程信号可以提供这种缺失的轮次级归因，但现有来源难以同时兼顾低成本与高精度。我们观察到，游戏求解器状态值的变化能够揭示一个动作是否将状态向成功推进。基于这一洞察，我们提出了CAST（Credit Assignment from Solver Teachers，即来自求解器教师的归因），它将这些价值变化转化为求解器优势，并将其作为轮次级信号注入RLVR中。我们进一步证明，在软最优求解器假设下，最大化求解器优势等价于从求解器进行的在策略蒸馏，仅需要标量值而非教师logits。在Sokoban、Minesweeper和Rush Hour上，无论域内评估还是未见难度评估，CAST在每款游戏上都优于所有训练基线，并在ALFWorld和WebShop上取得了最高的平均零样本性能。我们的代码已在 https://github.com/Wloner0809/CAST 开源。

## Abstract
Training large language models (LLMs) to act in long-horizon games is a promising step toward generalist decision-making, yet reinforcement learning with verifiable rewards (RLVR) relies on sparse final rewards that reveal little about which decisions determine success. Denser process signals could supply this missing turn-level credit, but existing sources are hard to keep both cheap and accurate. We observe that changes in a game solver's state value reveal whether an action advances the state toward success. Building on this insight, we propose CAST (Credit Assignment from Solver Teachers), which converts these value changes into solver advantages and injects them into RLVR as turn-level signals. We further show that, under a soft-optimal solver assumption, maximizing the solver advantage is equivalent to on-policy distillation from the solver, requiring only scalar values rather than teacher logits. Across Sokoban, Minesweeper, and Rush Hour, CAST outperforms all trained baselines on every game under both in-domain and unseen-difficulty evaluation and achieves the highest average zero-shot performance on ALFWorld and WebShop. Our code is available at https://github.com/Wloner0809/CAST.

## 2. 方法论：核心思想、关键技术细节与算法流程

### 2.1 核心思想

将求解器在LLM访问过的状态上查询得到的 **状态价值变化** $\Delta V = N(s_t) - N(s_{t+1})$ 转化为 **求解器优势（solver advantage）**，作为turn级过程信号叠加到GRPO的结局优势之上。在 **soft-optimal求解器假设** 下，该更新等价于 **logit-free的on-policy distillation（OPD）**。

### 2.2 关键技术细节

**(a) 求解器成本与价值定义**

- 对任意状态 $s$，求解器返回 **cost-to-go** $N(s)$（Sokoban/Rush Hour为最优动作数；Minesweeper为求解器完成剩余安全格所需揭示次数）。
- 定义势函数 $\Phi(s) = -N(s)$，则 $V^{\pi_{\text{Solver}}}(s) = -N(s)$。
- Q值与优势：

$$Q^{\pi_{\text{Solver}}}(s_t, a_t) = -1 + \mathbb{E}_{s_{t+1}}\left[V^{\pi_{\text{Solver}}}(s_{t+1})\right]$$

$$A^{\pi_{\text{Solver}}}(s_t, a_t) = -1 + N(s_t) - \mathbb{E}_{s_{t+1}}[N(s_{t+1})]$$

**(b) 平移使"推进"对应正奖励**

由于求解器最优动作恰好每步减少1，$A^{\pi_{\text{Solver}}}$ 在最优动作处为0，不利于作正信号。引入 **平移求解器优势**：

$$\tilde{A}^{\pi_{\text{Solver}}}(s_t, a_t) = A^{\pi_{\text{Solver}}}(s_t, a_t) + 1 = N(s_t) - \mathbb{E}_{s_{t+1}}[N(s_{t+1})]$$

含义：最优推进 $+1$，无效动作 $0$，有害动作取负；进入死状态时惩罚封顶为 $-N(s_t)$。

**(c) 信号整形：asinh压缩 + Batch级RMS归一化**

原始信号存在两个问题：**(1)** 重尾分布（死状态惩罚极大）；**(2)** 跨游戏量纲不一致。采用：

$$g(x) = \text{asinh}(x) = \ln\!\left(x + \sqrt{x^2+1}\right)$$

$$h(x) = \frac{g(x)}{\text{RMS}_{\mathcal{B}}(g) + \epsilon},\quad \text{RMS}_{\mathcal{B}}(g) = \sqrt{\frac{1}{|\mathcal{B}|}\sum_{(i,t)\in\mathcal{B}} g\!\left(\tilde{A}^{\pi_{\text{Solver}}}(s_{i,t}, a_{i,t})\right)^2}$$

- asinh在小信号区近似线性，保留大多数 $\pm 1$ 步推进的可区分度；对极端值仅对数增长，压缩重尾。
- 不减去均值是有意为之：保留 $0$ 作为"无推进"语义，正负符号即"好坏"。

**(d) 与GRPO结合**

把轨迹级结局优势与turn级求解器信号相加后broadcast到token级：

$$\hat{A}_{i,t} = \hat{A}^{\text{outcome}}_i + \alpha\, h\!\left(\tilde{A}^{\pi_{\text{Solver}}}_{i,t}\right)$$

其中 $\alpha$ 控制求解器引导强度（默认 $\alpha=0.1$），替换GRPO目标中的 $\hat{A}^{\text{outcome}}_i$，实现三层粒度对齐：轨迹级（结局）+ turn级（求解器）+ token级（优化粒度）。

**(e) 理论：与logit-free OPD等价**

**定理2.1（CAST的隐式目标）**：在soft-optimal求解器（$\pi_{\text{Solver}}(a|s) \propto \exp(Q^{\pi_{\text{Solver}}}(s,a)/\tau)$）、小信号假设、GRPO无偏估计、固定访问分布近似下，式(8)的策略梯度更新方向等于如下目标的梯度：

$$J_{\text{ours}}(\theta) = \mathbb{E}_{s_0\sim\mu}\!\left[V^{\pi_\theta}_{\text{task}}(s_0)\right] - \beta\,\mathbb{E}_{s\sim d_{\pi_\theta}}\!\left[H\!\left(\pi_\theta(\cdot|s),\, \pi_{\text{Solver}}(\cdot|s)\right)\right]$$

$$\beta = \frac{\alpha\,\tau}{\sqrt{2}\left(\text{RMS}_{\mathcal{B}}(g) + \epsilon\right)}$$

其中 $H(\pi_\theta, \pi_{\text{Solver}}) = -\mathbb{E}_{a\sim\pi_\theta}[\log\pi_{\text{Solver}}(a|s)]$ 是 **从学生到教师的交叉熵**。由此：

- **Logit-free OPD**：由引理 $A^{\pi_{\text{Solver}}} = \tau\log\pi_{\text{Solver}}$，单个标量即编码教师log偏好，无需logits。
- **闭式最优策略**：$\pi^*(a|s) \propto \pi_{\text{Solver}}(a|s)\,\exp\!\big(A^{\pi_\theta}_{\text{task}}(s,a)/\beta\big)$，即学生可偏离教师朝向任务更优动作（$\beta\to\infty$ 时退化为教师）。
- **附加结论**：通过 **Performance Difference Lemma** 给出 $\mathcal{O}(H\epsilon_\pi)$ 的次优性界（优于行为克隆的 $\mathcal{O}(H^2\epsilon_\pi)$）。
- **鲁棒扩展**（推论C.10）：去除小信号假设时，asinh压缩引入step-dependent的 $\beta_{\text{eff}}$，自动降低极端步的蒸馏强度。

**(f) 算法流程概览**

1. 用当前策略 $\pi_{\theta_{\text{old}}}$ 采样 $G$ 条轨迹，保留状态历史；
2. 对每个 $(s_{i,t}, a_{i,t})$，调用求解器得 $N(s_{i,t})$ 与 $N(s_{i,t+1})$；
3. 计算 $\tilde{A}^{\pi_{\text{Solver}}}$，经asinh+RMS归一化得 $h(\cdot)$；
4. 与结局优势 $\hat{A}^{\text{outcome}}_i$ 相加得 $\hat{A}_{i,t}$；
5. 以DAPO为backbone，按clipped surrogate目标更新 $\theta$。

  - 单条轨迹中LLM生成占 **99.9%**，求解器仅占轨迹的 **0.01%**；
  - 单个训练步（batch级）总耗时190.0s中，求解器仅贡献 **约73 ppm**（即0.0073%），开销可忽略。
- **底座模型**：Qwen3-4B-Instruct-2507（4B参数）。
- **推理引擎**：开源模型用SGLang本地部署，闭源用OpenAI兼容API。
- **训练规模**：batch size 16，每prompt 8 rollouts，max response 16384 token；总更新步数 Sokoban 200、Minesweeper 400、Rush Hour 300。
- **DQN求解器**：transformer编码器（$d_{\text{model}}=128$，8头3层，512维输出），3阶段训练约 $3\times 10^6$ 步基础RL + 150 epoch/阶段的潜势回归微调，训练板8000块。
- **未明确说明**：论文未披露GPU型号/数量、训练总时长（wall-clock）、集群规模等细节。

## 5. 实验数量与充分性

- **实验覆盖度**：
  - 3个训练游戏 × 2种评估设置（ID + Unseen）= **6组主结果**；
  - 3个源游戏 × 2个OOD基准 = **6组零样本迁移**；
  - 1组DQN替代求解器实验（Rush Hour）；
  - 2组消融（$\alpha$扫描4档 + asinh/RMS 3档）；
  - 6个闭源模型 + 1个底座 + 4个训练基线 = **11组对比对象**；
  - 训练曲线对比 + 求解器开销分解 + WebShop案例研究 = **多组可视化分析**。
- **统计严谨性**：3个独立随机种子，EMA平滑0.6并报告标准差带；Avg@4减少采样方差。
- **公平性**：
  - 所有训练方法共用同底座、同终端奖励、同rollout预算；
  - 闭源对比使用相同ReAct prompt与Avg@4协议；
  - DAPO vs CAST的对比直接剥离了求解器信号的贡献，干净可控。
- **不足**：单论文评估的游戏和基准数量仍属中等规模，未涵盖更多博弈或更长视野任务。

## 6. 主要结论与发现

- **全面领先**：CAST在 **3个训练游戏的ID和Unseen设置上均取得最佳Avg@4**，平均提升明显（Sokoban ID +5.7 over DAPO；Minesweeper ID +14.9 over最佳训练基线）。
- **训练效率**：相对DAPO达到峰值所需的步数，CAST加速 **1.7×–2.0×**（Sokoban 120 vs 200，Minesweeper 200 vs 400，Rush Hour 140 vs 240）。
- **零样本迁移**：ALFWorld平均37.9、WebShop平均22.7，均为训练方法最佳，整体30.3超过第二名5.6分。
- **WebShop案例**：相比底座盲目坚持错误商品，CAST-Sokoban智能体展示出"回退—重新搜索—精确选色—再购买"的规划行为。
- **消融结论**：$\alpha=0.1$ 最佳；asinh和RMS归一化缺一不可（去asinh影响最大，去RMS后期波动）。
- **实际可行性**：精确求解器开销仅73 ppm；DQN学习型值函数作近似求解器时，最终Avg@4仅略低于精确版且优于所有训练基线，表明方法对精确求解器依赖度低。
- **理论验证**：在soft-optimal假设下隐式目标即为任务回报 + 学生到教师交叉熵，并得到优于行为克隆的 $\mathcal{O}(H\epsilon_\pi)$ 次优性界。

## 7. 优点

- **方法论创新**：首次将游戏求解器状态值变化作为turn级教师信号，避免MCTS/PRM的高代价。
- **优雅的理论统一**：在soft-optimal假设下，证明"solver优势最大化 ≡ logit-free OPD"，自然导出闭式最优策略并提供 $\mathcal{O}(H\epsilon_\pi)$ 改进保证。
- **信号整形简单有效**：asinh + RMS仅两条轻量变换即稳定训练，消融明确。
- **理论-实践闭环**：推导给出的 $\beta = \alpha\tau/[\sqrt{2}(\text{RMS}+\epsilon)]$ 显式连接超参与温度、归一化尺度。
- **实证广度**：3个互补挑战类型的游戏 + 2个OOD基准，覆盖规划/部分观测/组合搜索。
- **实用导向**：精确求解器开销可忽略；DQN值网络可替代，扩展到无精确求解器的场景。
- **可解释性增强**：通过求解器差距可视化"动作好坏"，相比纯黑盒PRM更易诊断。

---

## 8. 不足与局限

- **求解器依赖**：方法核心依赖"可计算 $N(s)$"的领域求解器，对缺乏精确求解器的真实任务直接迁移困难；学习型值网络的版本虽有效但仍有性能损失。
- **soft-optimal假设的脆弱性**：当求解器偏离最优（如部分可观察博弈中扫雷需概率猜测），引理 $A^{\pi_{\text{Solver}}}=\tau\log\pi_{\text{Solver}}$ 不严格成立，蒸馏解释退化。
- **Minesweeper未见难度仍有较大提升空间**：ID 44.7 vs Unseen 11.0，说明难例上方法仍未充分解决。
- **小信号假设**：asinh线性化在 $A\approx 0$ 处有效，依赖 $|A^{\pi_{\text{Solver}}}|\lesssim 1$；虽然推论C.10放宽到step-dependent $\beta_{\text{eff}}$，但极端步仍依赖人工选择 $\alpha$。
- **实验规模受限**：
  - 仅3个游戏、1个底座（Qwen3-4B），未验证跨模型规模/族的效果；
  - 训练步数较少（Sokoban

200步），可能尚未收敛到稳定最优；
- **求解器依赖度测试**仅在Rush Hour上做了DQN替代，未在三个游戏上系统验证。

- **闭源比较的不对等**：闭源模型仅用通用ReAct prompt，未提示"思考更长"或加入ReAct+CoT/工具等针对性增强，不能完全代表其上限。

- **OOD泛化未做fine-tune实验**：仅评估"从游戏训练出的策略直接迁移到ALFWorld/WebShop"的零样本表现，缺少在现实基准上继续训练是否能保持优势的分析。

- **理论保证保守**：推导依赖固定访问分布近似 $d_{\pi_\theta} \approx d_{\pi_{\theta_{\text{old}}}}$ 与soft-optimal求解器假设；在策略显著漂移或求解器分布严重偏离soft-optimal时，OPD解释与次优性界会退化。

- **隐私/对抗视角缺失**：求解器调用是oracle式的，未讨论当求解器不可信、被注入错误代价时（如对抗环境或噪声$N(s)$）CAST的鲁棒性。

- **信号归一化的潜在副作用**：asinh虽压缩重尾但非线性变换引入step-dependent梯度尺度（已在推论C.10中体现），意味着同一个$\alpha$在不同游戏/不同训练阶段可能需要重新调节。

## 9. 综合评价与启示

**学术贡献**：
1. **方法层面**：提出"求解器状态值变化作为turn级教师信号"这一新范式，把"领域专属求解器"这一长期被忽视的资源变成LLM决策智能体的可重用监督源。
2. **理论层面**：在soft-optimal假设下将"求解器优势最大化"严格等价于logit-free的on-policy蒸馏，并给出闭式最优策略 $\pi^* \propto \pi_{\text{Solver}} \cdot \exp(A_{\text{task}}/\beta)$ 与优于BC的 $\mathcal{O}(H\epsilon_\pi)$ 次优性界——为"过程监督信号"提供了少有的紧致理论分析。
3. **工程层面**：asinh + RMS 归一化与73 ppm求解器开销证明了该方法的工程可行性，DQN学习型值函数替代实验则初步展示了对精确求解器的低依赖度。

**实践启示**：
- 对具备求解器的领域（棋类、逻辑谜题、形式化规划、组合优化问题），CAST提供了一个低成本即插即用的turn级监督方案，可作为RLVR之外的密集奖励补充。
- "求解器差距"天然具备 **可解释性** 和 **事后分析价值**——可视化每步推进/倒退可辅助诊断智能体的失败模式（论文Figure 4示例）。
- $\beta$ 的显式公式将超参与温度、归一化尺度绑定，便于跨任务迁移调参。

**未来方向**（论文提及与可推断）：
- **学习型近似求解器**：用DQN/世界模型/distilled solver替代精确求解器，进一步扩展到缺乏封闭解的领域（如具身导航、长篇写作决策）。
- **求解器的不确定性建模**：将$N(s)$ 替换为分布/$N(s)$的置信度估计，以处理soft-optimal假设失效的场景（如Minesweeper部分可观察下的概率猜测）。
- **跨任务solver池**：构建跨游戏的统一solver接口，使CAST能从Sokoban迁移到八数码、24点、推箱子变体等。
- **与PRM/MCTS的杂交**：在solver不可达的状态上fallback到MCTS或PRM，构建混合细粒度教师信号。
- **更长视野与策略漂移**：验证CAST在数千步级episodic tasks与显著分布漂移下的稳定性，检验OPD解释在$d_{\pi_\theta}\approx d_{\pi_{\theta_{\text{old}}}}$失效时的退化模式。

**整体定位**：CAST是LLM-based决策智能体训练中"过程监督信号"谱系中的新成员——比MCTS便宜、比PRM可靠、比GiGPO更细粒度。其理论-实践闭环与可忽略的求解器开销使其既具备学术研究价值，也具备向真实工业管道落地的潜力；但求解器依赖、soft-optimal假设和小信号假设三大前提仍是其规模化推广必须解决的核心挑战。
