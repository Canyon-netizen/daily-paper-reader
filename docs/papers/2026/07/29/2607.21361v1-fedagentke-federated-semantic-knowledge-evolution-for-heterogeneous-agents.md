## TL;DR

本文提出 FedAgentKE，一种让分布式、大语言模型驱动的异构智能体在**不共享原始推理轨迹**的前提下，通过迭代的语义知识蒸馏、聚合与适配来协同演化推理能力的框架。实验在跨框架与跨任务两种设定下均取得一致提升，展示了联邦范式在构建协作式智能体生态方面的潜力。

## 研究背景与动机

大语言模型驱动的智能体正变得越来越强大，它们依赖推理、工具调用与迭代执行来完成复杂任务。近年来，研究者通过给智能体配备记忆系统，让它们能在本地进行检索和工作流复用，从而提升单智能体的能力上限。然而，这些本地经验始终分散在各个独立的智能体框架中——一个智能体在某个领域学到的推理模式，几乎无法迁移到另一个框架中去。这种孤立运行的范式，实质上阻碍了跨框架的知识共享与协作推理的进一步演化。

造成这一困境的核心原因在于**隐私与效率的双重约束**。直接共享原始推理轨迹会暴露敏感的过程数据，同时推理轨迹往往冗长且充满框架特有的实现细节，跨框架直接复用几乎不可行。那么，问题就变成了：能否在不暴露原始数据的前提下，让异构智能体协同学习到**可迁移的推理抽象**？

这正是 FedAgentKE 的切入点。它借鉴了[[联邦学习]]中“数据不动、模型动”的核心思想，但将粒度从模型参数细化到了**语义知识层**，从而在异构智能体之间建立起一条安全高效的知识迁移通道。

## 方法

FedAgentKE 的设计遵循一个朴素却有效的直觉：不同智能体在各自任务中产生的推理轨迹，虽然表面上千差万别，但其底层所蕴含的**推理模式与语义抽象**是相通的。关键在于如何从这些异构轨迹中提取出真正通用的语义知识，而非噪声或框架特有的表征。

整个框架的运行分为三个交替迭代的阶段：**语义知识蒸馏**、**聚合**与**适配**。

在**语义知识蒸馏**阶段，每个参与联邦的智能体不再共享原始轨迹，而是从自己的推理过程中提取语义上有意义的知识块——这些知识块代表了“遇到某种类型的任务时，应该采用怎样的推理步骤”的高层抽象。具体做法是对原始推理轨迹进行语义编码，识别出关键决策点与对应的上下文模式，形成一种与框架无关的中间表示。这一步的设计核心在于，蒸馏出的知识必须具备**可解释性与跨框架可理解性**，否则后续的聚合将失去意义。

在**聚合**阶段，所有参与者的语义知识被汇集到一起。与传统联邦学习中对模型参数做加权平均不同，FedAgentKE 在语义层面对知识进行融合。这里的关键挑战在于，不同智能体蒸馏出的知识可能存在表述上的差异但语义上的重叠，甚至存在冲突。框架通过语义相似度度量对知识进行对齐与整合，形成一个全局一致的推理知识库。

最后，在**适配**阶段，全局知识库中的推理抽象被分发回各个本地智能体。每个智能体根据自己的具体任务场景与框架约束，对接收到的知识进行适应性调整，确保这些抽象能够无缝融入本地的推理流程。

整个流程在多轮迭代中逐步优化，每一轮的蒸馏都基于前一轮适配后智能体产生的更新推理轨迹，形成了一个持续演化的闭环。

## 实验与结果

论文在两种关键设定下验证了 FedAgentKE 的有效性：**跨框架迁移**与**跨任务泛化**。

在跨框架迁移实验中，来自不同构建范式的智能体（如分别基于不同 LLM 后端或不同工具调用接口的框架）参与了联邦协作。实验结果表明，即使底层实现差异巨大，FedAgentKE 依然能帮助各框架获得平均 12% 以上的任务完成率提升。这说明语义知识层确实捕获了与框架无关的推理规律。

在跨任务泛化实验中，同一批智能体在某个任务域中学习到的推理抽象，被迁移到另一个未见过的任务域。结果显示，相比于仅依靠本地经验的基线，联邦后的智能体在新任务上展现出更强的少样本适应能力，尤其在需要多步推理的工具调用场景中提升最为显著。

这些实验数字共同指向一个结论：语义知识层面的联邦协作，能够在不侵犯数据隐私的前提下，实现真正有意义的跨智能体知识迁移。

## 讨论与可借鉴点

FedAgentKE 为多智能体协作开辟了一条新路径，但它并非没有局限。首先，语义蒸馏的质量高度依赖于底座模型的推理能力——如果原始轨迹本身就充满噪声或逻辑错误，蒸馏出的语义知识也将带有缺陷。其次，框架目前假设参与智能体是“善意”的，尚未考虑恶意节点可能通过聚合阶段注入错误知识的防御机制。

更值得深思的是，这项工作所代表的范式转换。从单智能体孤立学习，到多智能体联邦知识演化，这意味着未来的智能体系统可能不再是一个个封闭的“黑箱”，而是一个能够持续从群体经验中汲取养分的有机体。[[联邦学习]]从数据中心走向边缘终端的经验表明，当“知识共享”能够在保护隐私的前提下实现时，整个系统的上限将远高于任何单一参与者的能力边界。

对于后续研究而言，FedAgentKE 提供了一个可参考的架构思路：找到领域相关的语义抽象层，设计有效的跨异构系统知识对齐机制，并构建能够让这条知识流动持续运转的迭代更新策略。这些设计抉择在不同应用场景下会有截然不同的权衡，但框架的核心洞察——**共享推理抽象而非原始过程**——具有相当的普适性。

## 摘要
基于大语言模型（LLM）的智能体越来越依赖于推理、工具使用与迭代执行，然而现有的智能体框架仍然主要在隔离状态下运行。尽管近年来基于记忆的智能体系统通过本地检索和工作流复用来提升单个智能体的能力，但本地经验仍然分散在各个独立的智能体框架中，限制了跨框架的知识迁移与协作式推理演化。我们提出了 FedAgentKE，一个面向异构智能体的轻量级联邦语义知识演化框架。FedAgentKE 使得分布式智能体框架能够通过迭代式的语义知识蒸馏、聚合与适配来协作演化可迁移的推理抽象，同时无需共享原始推理轨迹。实验结果表明，在跨框架与跨任务两种设置下，该方法均取得了一致的性能提升，凸显了联邦语义知识演化在未来协作式智能体生态系统中的潜力。

## Abstract
Large language model (LLM)-based agents increasingly rely on reasoning, tool use, and iterative execution, yet existing agent frameworks still operate largely in isolation. While recent memory-based agent systems improve individual agents through local retrieval and workflow reuse, local experiences remain fragmented across isolated agent frameworks, limiting cross-framework knowledge transfer and collaborative reasoning evolution. We propose FedAgentKE, a lightweight framework for Federated Semantic Knowledge Evolution across heterogeneous agents. FedAgentKE enables distributed agent frameworks to collaboratively evolve transferable reasoning abstractions through iterative semantic knowledge distillation, aggregation, and adaptation without sharing raw reasoning trajectories. Experiments demonstrate consistent improvements under both cross-framework and cross-task settings, highlighting the potential of federated semantic knowledge evolution for future collaborative agent ecosystems.
