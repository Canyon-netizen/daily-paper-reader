## 摘要
当具有社会价值的努力成本较高、可观测性较弱且主要惠及他人时，合作可能会失败。借鉴 Holmström 的团队道德风险模型，我们引入了对话道德风险博弈（Dialogue Moral Hazard Game），这是一种受控的文本博弈，将这种隐藏行动结构操作化用于语言智能体。在每一回合中，智能体可以保留即时局部奖励，或支付查询成本以揭示一个主要帮助另一智能体下游决策的隐藏安全事实。我们评估了七个开放权重的语言模型，并将行为分解为查询使用、已实现的信息传递、局部奖励保留、不安全选择、格式有效性以及团队成功。基础模型通常在没有团队成功的情况下保留局部奖励，或者进行查询但不传递能改变最终决策的信息。随后，我们使用监督微调、RLOO、序列式 SFT+RLOO 以及 GEPA 提示优化作为诊断性更新机制。它们的效果具有异质性：OLMo-7B 表现出最符合机制预期的权重层面改进，而 GEPA 有时在提升团队成功的同时减少甚至消除了高成本的查询。因此，优化可以在不恢复预期合作机制的情况下改变总体奖励，这促使我们在评估中报告机制层面的行为，而非仅报告团队成功。

## Abstract
Cooperation can fail when socially valuable effort is costly, weakly observable, and mainly benefits others. Drawing on Holmström's team moral-hazard model, we introduce the Dialogue Moral Hazard Game, a controlled textual game that operationalizes this hidden-action structure for language agents. In each episode, an agent can preserve an immediate local reward or pay a query cost to reveal a hidden safety fact that primarily helps another agent's downstream decision. We evaluate seven open-weight language models and decompose behavior into query use, realized information transfer, local-reward preservation, unsafe choice, format validity, and team success. Base models commonly preserve local reward without team success or query without communicating information that changes the final decision. We then use supervised fine-tuning, RLOO, sequential SFT+RLOO, and GEPA prompt optimization as diagnostic update mechanisms. Their effects are heterogeneous: OLMo-7B shows the clearest mechanism-consistent weight-level improvement, whereas GEPA sometimes improves team success while reducing or eliminating costly queries. Thus, optimization can shift aggregate reward without recovering the intended cooperative mechanism, motivating evaluations that report mechanism-level behavior rather than team success alone.

# 论文总结：多智能体语言模型中的道德风险

## 1. 核心问题与研究动机

- **核心问题**：当社会性有价值的努力具有**成本高、可观测性弱、且主要惠及他人**这三个特征时，合作往往失败。这一情景本质上是 Holmström (1982) 提出的**团队道德风险（moral hazard in teams）**问题：
  - 智能体 $i$ 选择私有努力水平 $e_i$，承担私有成本 $c_i(e_i)$，团队产出为 $Y(e_1,\ldots,e_n)$；
  - 努力具有社会价值 $\partial Y / \partial e_i > c'_i(e_i)$，但对个体无吸引力 $\alpha_i \partial Y / \partial e_i < c'_i(e_i)$；
  - 在二元动作博弈中，这一比较可表述为 $\Delta_i Y$ 与 $k$（查询成本）的离散边际比较。
- **研究动机**：现有大语言模型智能体评测多关注**聚合产出**（如团队成功率），但缺乏对**隐藏行动机制**的可控测试。语言智能体在多智能体部署中常需执行"检查、警告、升级、查询工具"等行为，这些行为消耗 token、延迟与算力，但收益主要流向其他智能体或整个系统。论文的核心问题是：*当前语言模型及后训练方法是否表现出道德风险式行为？优化是否真正恢复了预期合作机制？*

## 2. 方法论

### 2.1 核心思想：对话式道德风险博弈（Dialogue Moral Hazard Game）

- **博弈结构**：在有向环 $N=\{1,\ldots,n\}$（$\sigma(i)=(i \bmod n)+1$）上，智能体 $i$ 持有一个 case $i$，选项集 $A_i$，公开效用 $u_i$，隐藏不安全选项 $h_i$。目标最终动作为：
  $$a_i^* = \arg\max_{a \in A_i \setminus \{h_i\}} u_i(a), \qquad T = \prod_{i=1}^{n} \mathbb{1}[a_i = a_i^*]$$
- **三阶段流程**：
  1. **观测阶段**：每个智能体仅看到自己 case 的选项与可见效用，不知道自身 case 的不安全选项。
  2. **工作阶段**：智能体决定 $e_i \in \{0,1\}$——保留本地回答（$\text{ACTION LOCAL}\langle OPT \rangle$）或支付 $k$ 进行查询（$\text{ACTION QUERY}$），查询以私有方式揭示 $\sigma(i)$ case 的 $h_{\sigma(i)}$。
  3. **公示阶段**：查询者可发布匿名告示 "NOTE CASE $\langle ID \rangle$ UNSAFE $\langle OPT \rangle$"。
  4. **最终阶段**：智能体在阅读公示版后作出 $\text{FINAL}\langle OPT \rangle$。
- **奖励机制**：综合得分定义为
  $$R_{\text{game}} = w_L \frac{1}{n}\sum_i L_i + w_F \frac{1}{n}\sum_i F_i + w_T T - k \frac{1}{n}\sum_i Q_i$$
  主设置 $(w_L,w_F,w_T,k)=(0.35,0.15,0.50,0.10)$。该得分与 RLOO 训练奖励（解析性 + 推理结构 + 精确目标动作匹配）刻意分离，以避免循环论证。

### 2.2 四种诊断性更新机制

| 方法 | 类型 | 关键设置 |
|------|------|----------|
| **SFT** | LoRA 监督微调 | 演示教师覆盖 $(k, w_T, n, \text{匿名/署名})$；LoRA $r=16, \alpha=32, \text{dropout}=0.05$；22,680 训练/5,670 评估样本；2,000 步，lr $=2\times 10^{-4}$，bf16 |
| **RLOO** | REINFORCE+留一基线 | $K=5$ 采样，top-p=1.0；奖励分项 $(0.05, 0.10, 0.85)$；2,000 步，lr $=1\times 10^{-6}$，$\beta_{\text{KL}}=0.03$ |
| **SFT+RLOO** | 顺序组合 | 1,000 步 SFT + 1,000 步 RLOO |
| **GEPA** | 基于 DSPy 的提示优化 | 搜索自然语言提示 $q^*$，最大化验证集 $R_{\text{game}}$：$$q^* = \arg\max_{q \in Q} \frac{1}{|D_{\text{val}}|}\sum_{x \in D_{\text{val}}} R_{\text{game}}(x, y_q(x))$$ 64 训练/32 验证/64 测试集；6,000 次度量调用，minibatch=5 |

所有训练信号**理论盲化**：提示中不出现 "Holmström"、"moral hazard"、"team production" 等术语。

### 2.3 机制级分解指标

六个独立可观测维度：**查询率 (Query rate)**、**信息传递 (Information transfer)**、**局部奖励保留 (Local reward)**、**不安全选择 (Unsafe choice)**、**格式有效性 (Format validity)**、**团队成功 (Team success)**。该分解使得失败可定位至「未查询 / 查询未通报 / 收到未使用」三个独立环节。

## 6. 主要结论与发现

- **基座模型普遍欠供给成本性合作**：除 Qwen3-4B 外，多数模型团队成功率 $\approx 0$，虽保留较高局部奖励或偶尔查询（Gemma 4B 100% 格式有效但 0% 团队成功 → 排除纯格式失败假设）。
- **查询率 ≠ 有效合作**：OLMo-7B 查询率最高（76.9%）但信息传递仅 11.2%，团队成功 1.2%；Qwen3-4B 查询后信息传递 50.9%，团队成功 21.3%，二者形成对比。
- **干预效果高度异质**：
  - OLMo-7B 在 SFT / SFT+RLOO 下表现**机制一致**改进（团队成功 1.2 → 38.8 ± 13.1，查询率 76.9 → 96.1，信息传递 11.2 → 62.0）；
  - Qwen3-4B 在权重级 SFT 下反而退化（$\Delta = -20.1$ pp）；
  - 多数模型权重级干预效果很小或为零。
- **GEPA 提升团队成功但绕过机制**：Qwen3-4B 与 OLMo-7B 在 GEPA 下把查询率降至接近 0，却获得最高团队成功率增益。Qwen3-4B 学到一条"从可见效用推断安全性"的规则式捷径（极端高低效用视为不安全并排除），而非真正付出查询成本 → **聚合改善不等于合作机制恢复**。
- **不确定性诊断**：$\text{Best weight}-\text{Base}$ 团队成功变化 +6.3 [+0.3, +17.0] pp，4/7 模型正向；留一分析显示该结果**主要由 OLMo-7B 驱动**（剔除后 +1.1 [-0.1, +2.4]）。GEPA d$z$=0.91、未校正 $p$=0.031 但 BH $q$=0.391。
- **机制相关性**：跨聚合行——团队成功与信息传递 $r=0.96, \rho=0.76$，与查询率 $r=0.63$，与局部奖励 $r=-0.50$，与不安全选择 $r=-0.71$。

## 7. 优点与亮点

- **机制级分解评测**：将失败定位到「未查询 / 查询未通报 / 收到未使用」三个独立环节，避免了"团队成功率 = 合作能力"的简单化推断。
- **理论到操作的桥接**：清晰地把 Holmström 边际条件翻译为二元动作博弈的离散比较，避免了线性生产函数的隐含假设。
- **理论盲化提示设计**：训练信号与提示中均避免提及经济学术语，使评测结论不依赖模型对术语的先验识别。
- **多诊断并行**：权重级 SFT / RLOO / SFT+RLOO + 提示级 GEPA 并用，将"权重级 vs 推理级"的差别纳入视野。
- **统计严谨性**：非参数 bootstrap、配对符号翻转、BH 校正、留一模型检验、机制相关矩阵等齐备；明确区分探索性诊断与确认性检验。
- **机制欺骗的可解释性**：附录 D 公开 GEPA 学到的全部 7 个模型提示，使"绕过机制"的结论可复核（特别是 Qwen3-4B 的"安全从效用推断"启发式）。

## 8. 不足与局限

- **激励结构单一**：主评估固定 $k=0.10, n=2$、匿名告示；论文未做代价函数、群体规模、署名/匿名、通信协议的因果敏感性扫描。
- **样本规模受限**：仅 7 个 4B–9B 模型，7 模型配对的统计效力受限；前沿规模系统（OpenAI / Anthropic）因权重不可访问而未覆盖，作者明确指出其结论可能不外推至 frontier 规模。
- **训练数据黑箱**：开放权重模型的预训练/后训练细节不可知，影响对训练选择的归因。
- **结构化文本案例的抽象化**：剥离了真实部署中的延迟、API、信任、组织约束等，仅刻画"受控成本性努力"。
- **格式混淆未能因果隔离**：未执行 oracle-format repair 对照实验以彻底排除格式失败作为混淆源。

- **机制相关性是诊断性而非因果性**：跨聚合行的相关为一致性检查而非因果证明。
