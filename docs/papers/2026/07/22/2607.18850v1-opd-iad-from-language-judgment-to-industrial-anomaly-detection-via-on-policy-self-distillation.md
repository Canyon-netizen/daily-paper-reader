## 摘要
大型视觉-语言模型（LVLMs）最近在工业异常检测（IAD）方面展现出强大的潜力，能够提供图像级异常判断和可解释的缺陷推理。然而，目前基于LVLM的IAD方法仍然难以从生成的语言判断中产生精确的像素级异常图。我们的目标是实现精确的像素级定位，同时将语言作为引导而非让其主导视觉响应。具体而言，我们提出了textbf{OPD-IAD}，一个面向基于LVLM的IAD的、具有证据特权优势的密集在线自蒸馏框架。OPD-IAD将特权缺陷证据蒸馏到模型自身的在线判断轨迹上，使最终生成的判断能够在密集监督下学习，而不是仅被视为文本答案。由此产生的判断将作为密集异常感知的语义条件。为了将该条件转化为密集视觉证据，我们引入了textbf{语言引导视觉锚定}，它通过判断转发将图像和问题在最终判断条件下重新编码为语义锚点，并通过一个对比热图头将其与密集视觉特征进行对比，从而生成异常图。由此，语言判断提供了紧凑的语义引导，而密集视觉特征仍是像素级评分的基础，使得语言能够引导异常定位，而不会让语言质量直接决定像素级响应。大量实验表明，OPD-IAD在基于LVLM的IAD方法中取得了最佳的整体性能，在大多数图像级、像素级和问答（QA）指标上均处于领先地位。

## Abstract
Large vision-language models (LVLMs) have recently shown strong potential for industrial anomaly detection (IAD) by providing image-level anomaly judgments and interpretable defect reasoning. However, current LVLM-based IAD methods still struggle to produce precise pixel-level anomaly maps from generated language judgments. We aim to achieve precise pixel-level localization while using language as guidance rather than letting it dominate the visual response. Specifically, we propose \textbf{OPD-IAD}, an evidence-privileged dense on-policy self-distillation framework for LVLM-based IAD. OPD-IAD distills privileged defect evidence onto the model's own on-policy judgment trajectory, enabling the final generated judgment to be learned under dense supervision rather than treated only as a textual answer. The resulting judgment serves as a semantic condition for dense anomaly perception. To turn this condition into dense visual evidence, we introduce \textbf{Language-guided Visual Anchoring}, which uses a judgment reforward to re-encode the image and question under the final-judgment condition into semantic anchors and contrasts them with dense visual features through a contrastive heatmap head to generate anomaly maps. The language judgment therefore provides compact semantic guidance, while dense visual features remain the basis for pixel-level scoring, allowing language to guide anomaly localization without letting language quality directly dictate the pixel-level response. Extensive experiments show that OPD-IAD achieves the best overall performance among LVLM-based IAD methods, leading on most image-level, pixel-level, and QA metrics.

# OPD-IAD 论文总结

## 1. 核心问题与研究动机

工业异常检测（IAD）需要同时完成两类任务：
- **图像级判断**：识别产品是否异常，并给出可解释的文本推理；
- **像素级定位**：在图像上精确标出缺陷区域。

近年来，大视觉-语言模型（LVLM）已能够为工业图像输出异常判断和缺陷解释，但将其转化为**精确像素级异常图**仍是未解决的问题。现有方法存在两条有缺陷的路径：

- **解耦路径**：语言判断仅作为解释输出，不参与热图生成，导致文本与定位脱节；
- **紧耦合路径**：通过分割 token、掩码文本、推理 token 注意力等"语言侧接口"驱动定位，使像素响应过分依赖生成文本的正确性与稳定性，错误或不稳定的判断会直接误导热图。

论文的核心主张是：**语言判断应作为语义引导，而像素级响应必须基于密集视觉证据**。围绕这一原则，需要解决两个训练层面的挑战：
1. 监督必须作用于**模型自身在部署时产生的轨迹**（即 on-policy）；
2. 监督必须**密集、细粒度**，反映缺陷证据，而非仅奖励最终答案。

## 2. 方法论

### 2.1 整体框架：双分支 + 共享定位

模型（以 Qwen3-VL-8B 为骨干）针对部署输入 $(x_i^{img}, x_i^{text})$ 生成语言响应 $\hat{y}_i$，并提取其最终判断 $\hat{a}_i = \text{Trim}_{\text{ans}}(\hat{y}_i)$。该判断在 **判断转发（judgment reforward）** 中与图像、问题以及一组可学习的"异常 / 正常"基锚 $z_a, z_n$ 一起被重新编码，得到上下文相关的锚 $\tilde{z}_a, \tilde{z}_n$。对比热图头将密集视觉 patch 特征 $v_{ij}$ 与这两个锚进行对比打分，得到像素级异常图 $\hat{M}_i$。

### 2.2 证据特权的在线自蒸馏（OPSD）

- **学生分支**在部署上下文 $c_i^S = \text{Prompt}_S(x_i^{img}, x_i^{text})$ 下自采样响应 $\hat{y}_i \sim \pi_\theta(\cdot|c_i^S)$；
- **教师分支**使用同一模型的 EMA 副本，仅在训练时存在，并在特权上下文 $c_i^T = \text{Prompt}_T(x_i^{img}, x_i^{text}, r_i)$ 下对学生的每个前缀进行重打分。

教师权重由 EMA 维护：

$$\bar{\theta}^{(k)} = \mu\,\bar{\theta}^{(k-1)} + (1-\mu)\,\theta^{(k)},\quad \mu\in(0,1)$$

对学生每个位置 $t$ 的下一 token 分布做 token 级分布散度匹配：

$$\ell_{\text{OPSD}}^{(i)} = \sum_{t=1}^{|\hat{y}_i|} D\!\left(P_{S,t}\;\|\;\text{stopgrad}(P_{T,t})\right)$$

其中 $D$ 采用广义 Jensen–Shannon 散度，对应的混合分布为：

$$m_t^{\beta} = (1-\beta)P_{S,t} + \beta\,\text{stopgrad}(P_{T,t})$$

$$D_{\text{JSD}}^{\beta}\!\left(P_{S,t}\|\,\text{stopgrad}(P_{T,t})\right) = \beta\,\text{KL}\!\left(\text{stopgrad}(P_{T,t})\|m_t^{\beta}\right) + (1-\beta)\,\text{KL}\!\left(P_{S,t}\|m_t^{\beta}\right)$$

当 $\beta=0.5$ 时退化为对称 JSD。该设计同时实现"on-policy（监督学生实际采样轨迹）"和"密集 token 级（每步都学到缺陷证据）"。

### 2.3 语言引导的视觉锚定（LVA）

判断转发后取两个上下文锚的隐藏状态：

$$(\tilde{z}_a,\tilde{z}_n) = f_{\theta}^{\text{ref}}\!\left(x_i^{img}, x_i^{text}, \hat{a}_i; z_a, z_n\right),\quad \tilde{z}_a,\tilde{z}_n \in \mathbb{R}^d$$

对比热图头通过投影 + 归一化 + 余弦对比计算每个 patch 的异常 logit：

$$\bar{v}_{ij} = \frac{v_{ij}}{\|v_{ij}\|_2},\quad \bar{z}_a = \frac{g_a(\tilde{z}_a)}{\|g_a(\tilde{z}_a)\|_2},\quad \bar{z}_n = \frac{g_n(\tilde{z}_n)}{\|g_n(\tilde{z}_n)\|_2}$$

$$s_{ij} = \tau\!\left(\langle \bar{v}_{ij}, \bar{z}_a\rangle - \langle \bar{v}_{ij}, \bar{z}_n\rangle\right)$$

其中 $\tau$ 为可学习温度。上采样得到像素级异常图。语言仅提供**语义条件**，像素打分仍由视觉特征决定。

### 2.4 总训练目标

$$L = L_{\text{OPSD}} + \lambda_R L_{\text{reward}} + \lambda_H L_{\text{map}}$$

- **$L_{\text{OPSD}}$**：上述 token 级自蒸馏损失，学习部署时的判断；
- **$L_{\text{reward}} = R_{\text{fmt}}(\hat{y}_i) + R_{\text{ans}}(\hat{a}_i, a_i)$**：稀疏的结果级奖励，仅用于正则化答案格式与最终判断；
- **$L_{\text{map}}$**：图像级 BCE（取 top-1% logit 平均）+ 像素级 BCE/Focal/Dice 损失 + 锚分离约束 $L_{\text{con}}=\max(\langle\bar{z}_a,\bar{z}_n\rangle+m, 0)$。

## 6. 主要结论

- OPD-IAD 在 5 个零样本 IAD 基准上，多数**图像级、像素级、QA 指标**领先现有基于 LVLM 的 IAD 方法；
- **OPSD > SFT > GRPO（稀疏奖励）**：on-policy + 密集 token 级监督显著优于固定目标模仿；纯结果级 GRPO 虽在图像级略高，但像素定位全面退化；
- **最终判断是最强的部署型语义条件**：完整响应、学习型锚、不聚合最终判断、移除语言输出均损害定位；
- **GT 判断 > 默认判断 > 错误判断**，证明判断语义确实参与并影响视觉锚定，但即使判断错误，**热图仍能保持局部异常响应**，证实"语言引导而非主导"的设计目标达成。

## 7. 优点与亮点

1. **清晰的设计原则**：明确区分"语言引导"与"视觉主导"，避免像素响应被文本质量绑架；
2. **训练与定位的一致性**：用 OPSD 把"部署时自采样的判断"作为下游定位的语义条件，两阶段使用同一轨迹；
3. **双分支共享架构**：学生/教师共享 LVLM，仅上下文不同，工程实现简洁；
4. **判断干预实验**：直接替换最终判断观察定位变化，提供了因果性的解释力；
5. **跨数据集零样本**评测，比单域监督设置更具实用价值；
6. 论文叙述体系完整，问题 → 方法 → 实验 → 结论环环相扣。

## 8. 不足与局限

1. **算力门槛高**：8 × A100 + 30 epoch 全量微调 8B 模型，难以复现，且文中**未报告训练时长**；
2. **基线覆盖不全**：未与近期强 LVLM-IAD 方法（VMAD、AG-VAS、OmniAD、IAD-R1、AnomalyR1、Triad 等）做直接对比，部分指标缺失；
3. **未提供方差与统计显著性**：每数据集单次实验，无法判断优势是否稳定；
4. **超参鲁棒性研究不足**：$\mu$、$\beta$、$\lambda_R$、温度 $\tau$ 等关键超参未做敏感性分析；
5. **定性评估规模小**：仅 8 张可视化图像，缺乏对失败案例的系统分析；
6. **依赖训练期特权证据**：源域缺陷分析参考 $r_i$ 的构造方式与质量对结果影响未讨论，跨域迁移时若 $r_i$ 与目标分布差异大，效果可能下降；
7. **二值判断的精度上限**：QA/Acc. 在部分数据集（如 MVTec-AD 仅 71.42、SDD 仅 62.91）仍偏低，说明语言侧仍有改进空间；
8. **未与传统密集 IAD SOTA 对比**：与仅做视觉的强零样本/少样本方法（如 AnomalyCLIP、MUSC、VisualAD）的对比被回避，难以判断 LVLM 路线相对纯视觉路线的真实收益。
