## TL;DR

工业异常检测需要同时给出「图像级有没有问题」的语言判断和「像素级哪里有问题」的热图定位。现有大视觉语言模型擅长前者，但将语言判断转化为精确像素级异常图仍是难题——要么文本与定位脱节，要么语言质量直接绑架像素响应。 OPD-IAD 提出了证据特权的在线自蒸馏（OPSD）和语言引导的视觉锚定（LVA）两套机制，让语言判断作为语义条件引导密集视觉特征打分，而非替代视觉做像素级决策。实验在 5 个跨数据集零样本设定下，于图像级、像素级和问答三项指标上均取得了基于大视觉语言模型的工业异常检测最佳综合性能。

## 研究背景与动机

工业异常检测（IAD）的核心需求可以拆解为两个层次：**图像级判断**要求模型回答「这张产品图片有没有缺陷」，并给出可解释的文字推理；**像素级定位**则要求在图像上精确圈出异常区域，为后续的质检分拣提供依据。近年来大视觉语言模型的兴起为 IAD 带来了新的可能性——模型不仅能给出二值答案，还能输出缺陷类型的自然语言解释，这在工业场景的可解释性要求下极具价值。

然而，将语言判断「翻译」成像素级异常图这件事，现有方法走得并不顺畅。论文将现有路径归纳为两种有缺陷的做法：**解耦路径**下，语言判断仅作为人类可读的文本输出，与热图生成过程完全隔离——模型同时训练一个额外的分割头来独立完成定位，文本与定位之间没有信息流动，各干各的。**紧耦合路径**则走向另一个极端，通过引入分割 token、掩码文本token、推理token注意力等「语言侧接口」来驱动视觉定位，让像素级响应高度依赖生成文本的正确性与稳定性。一旦语言判断出错或不稳定，异常图就会跟着跑偏，语言质量直接决定了像素级结果的可用性。

论文的核心主张是：**语言判断应当作为语义引导，而像素级响应必须建立在密集视觉证据之上**。这句话包含了两层含义——语言不是可有可无的附加品，它确实参与引导了异常定位的过程；但语言也不能「越位」，像素打分的主角始终是视觉特征，语言只在语义层面提供条件信息。这条原则背后有两个训练层面的实际挑战：第一，监督必须作用于模型在部署时实际产生的判断轨迹（所谓 on-policy），而不是某个固定参考答案；第二，监督必须是密集且细粒度的，能够反映缺陷证据在 token 序列中的逐步显现，而不是仅仅在最后奖励一个正确或错误的最终答案。

## 方法

围绕上述原则，OPD-IAD 设计了一套「双分支共享定位」的框架，骨干模型选用 Qwen3-VL-8B-Instruct，训练时同时维护学生分支和教师分支，两者在视觉编码器和语言解码器上共享权重，仅输入的上下文不同。

### 在线自蒸馏：让判断在密集监督下学习

学生分支处理部署时的输入上下文 $c_i^S = \text{Prompt}_S(x_i^{img}, x_i^{text})$，自采样产生语言响应 $\hat{y}_i \sim \pi_\theta(\cdot|c_i^S)$，从中提取最终判断 $\hat{a}_i = \text{Trim}_{\text{ans}}(\hat{y}_i)$——这就是模型在部署时实际会给出的答案。教师分支则使用同一模型的 EMA 副本（记作 $\bar{\theta}$），仅在训练阶段存在，它在特权上下文 $c_i^T = \text{Prompt}_T(x_i^{img}, x_i^{text}, r_i)$ 下对学生采样的每个前缀 token 进行重打分。这里 $r_i$ 代表特权缺陷证据，可以是对应区域的像素级标注或缺陷类型的描述性分析，其作用是让教师在训练阶段获得学生无法直接观察到的细粒度缺陷信息。

教师权重通过 EMA 动态维护：

$$\bar{\theta}^{(k)} = \mu\,\bar{\theta}^{(k-1)} + (1-\mu)\,\theta^{(k)}$$

对学生每个位置 $t$ 的 token 级分布与教师的对应分布做散度匹配：

$$\ell_{\text{OPSD}}^{(i)} = \sum_{t=1}^{|\hat{y}_i|} D\!\left(P_{S,t}\;\|\;\text{stopgrad}(P_{T,t})\right)$$

论文选择广义 Jensen–Shannon 散度作为 $D$，对应的混合分布为：

$$m_t^{\beta} = (1-\beta)P_{S,t} + \beta\,\text{stopgrad}(P_{T,t})$$

$$D_{\text{JSD}}^{\beta}\!\left(P_{S,t}\|\,\text{stopgrad}(P_{T,t})\right) = \beta\,\text{KL}\!\left(\text{stopgrad}(P_{T,t})\|m_t^{\beta}\right) + (1-\beta)\,\text{KL}\!\left(P_{S,t}\|m_t^{\beta}\right)$$

当 $\beta=0.5$ 时退化为对称的经典 JSD。这套设计的精妙之处在于「双重 on-policy」——教师重打分的对象是学生实际采样出的完整轨迹，而不是某个固定标准答案；每一步 token 的分布都受到监督，而不仅仅是最终判断的结果被奖惩。换言之，缺陷证据的信息通过教师分布渗透到了判断生成的每一个 token 级决策中，使最终判断本身就在密集监督下学会了感知异常，而非仅仅学会了输出一个「正确」的字符串。

### 语言引导的视觉锚定：让判断条件落地为像素证据

拿到模型在部署上下文下产生的最终判断 $\hat{a}_i$ 之后，需要将其转化为像素级异常图的语义条件。直接的做法是用判断文本对视觉特征做交叉注意力，但这样容易让语言质量绑架视觉响应。 OPD-IAD 采取的策略是「判断转发」：将图像、原始问题以及学好的「异常 / 正常」基锚 $z_a, z_n$ 与最终判断 $\hat{a}_i$ 一起重新送入模型，得到上下文相关的锚点：

$$(\tilde{z}_a,\tilde{z}_n) = f_{\theta}^{\text{ref}}\!\left(x_i^{img}, x_i^{text}, \hat{a}_i; z_a, z_n\right),\quad \tilde{z}_a,\tilde{z}_n \in \mathbb{R}^d$$

基锚 $z_a, z_n$ 是可学习的向量，代表「什么是异常」和「什么是正常」的语义原型空间。通过判断转发，这两个原型在当前具体问题语境下被调适为 $\tilde{z}_a$ 和 $\tilde{z}_n$——它们编码了模型对这张图是否异常的整体判断所携带的语义信息。

接下来，对比热图头将密集视觉 patch 特征 $v_{ij}$ 与这两个锚进行对比打分：

$$\bar{v}_{ij} = \frac{v_{ij}}{\|v_{ij}\|_2},\quad \bar{z}_a = \frac{g_a(\tilde{z}_a)}{\|g_a(\tilde{z}_a)\|_2},\quad \bar{z}_n = \frac{g_n(\tilde{z}_n)}{\|g_n(\tilde{z}_n)\|_2}$$

$$s_{ij} = \tau\!\left(\langle \bar{v}_{ij}, \bar{z}_a\rangle - \langle \bar{v}_{ij}, \bar{z}_n\rangle\right)$$

其中 $\tau$ 为可学习温度参数。每个 patch 的异常 logit 是其与「异常锚」的余弦相似度减去其与「正常锚」的余弦相似度，本质上是在问：这个 patch 的视觉特征更像缺陷还是更像正常产品？最后通过上采样将 patch 级打分转化为像素级异常图 $\hat{M}_i$。

这个设计的核心逻辑是：语言判断提供了紧凑的语义条件，异常锚和正常锚的对比决定了「在语义空间中什么样的视觉特征代表异常」，但具体的像素级评分仍然由密集视觉特征与这两个锚的相似度差值决定。语言引导了定位的方向，但不直接决定每个像素的值——即使语言判断出错，视觉特征本身的异常模式仍然能够驱动热图响应。

### 总训练目标

完整的目标函数由三项组成：

$$L = L_{\text{OPSD}} + \lambda_R L_{\text{reward}} + \lambda_H L_{\text{map}}$$

- **$L_{\text{OPSD}}$**：前文介绍的 token 级自蒸馏损失，让模型在实际部署语境下生成的判断质量得到提升。
- **$L_{\text{reward}}$**：稀疏的结果级奖励，包括格式奖励 $R_{\text{fmt}}(\hat{y}_i)$（确保输出符合预期格式）和判断奖励 $R_{\text{ans}}(\hat{a}_i, a_i)$（奖励最终答案的正确性），仅用于正则化，不主导优化方向。
- **$L_{\text{map}}$**：密集定位损失，包含图像级 BCE（取 top-1% logit 平均的异常概率与真实标签的交叉熵）、像素级 BCE/Focal/Dice 损失组合，以及一个锚分离约束 $L_{\text{con}}=\max(\langle\bar{z}_a,\bar{z}_n\rangle+m, 0)$，防止异常锚和正常锚在语义空间里塌缩到一起。

整体而言，OPSD 让语言判断变好（密集监督下学会感知缺陷），LVA 让判断条件落地为像素证据（语义锚引导视觉对比），两者的产出通过 $L_{\text{map}}$ 联合优化，形成语言引导视觉、视觉支撑像素的闭环。

## 实验与结果

### 实验设置

### 核心结论

实验结果验证了论文的设计假设。在 MVTec-AD 和 VisA 两个主流基准上，OPD-IAD 在图像级 AUROC/AP/F1 和像素级 AUROC/AP/F1/AUPRO 上全面领先基线方法，尤其在像素级 F1 指标上的优势最为显著。以 VisA 为例，OPD-IAD 的像素级 F1 达到 59.26，较第二名提升明显，这一差距在工业质检场景中意味着大量额外的误检或漏检。

一个值得关注的对比来自训练范式消融：纯模仿学习（SFT）下像素定位尚可但图像级判断退化；仅用稀疏结果级奖励的强化学习（GRPO，单 rollout）在图像级略高但像素定位全面崩溃；只有 OPD-IAD 的 on-policy 密集 token 级监督同时保住了两项能力。这一结果直接证明了「密集监督每个 token 的判断生成」对最终定位质量的关键作用。

语言引导视觉锚定的消融实验则揭示了另一层洞察。当论文设计四种定位接口（纯文本注意力、分割 token、对比锚定、热图头）并对比三种判断干预（GT 判断、模型默认判断、错误注入判断）时，对比锚定 + 默认判断的组合在像素级指标上与使用 GT 判断的差距很小——这说明锚点机制成功地将语义条件转化为了对视觉特征的对比引导，而非简单地「复制」语言判断的正确性。关键的是，即使注入错误判断，对比锚定方案的热图仍然保留了局部异常响应，而分割 token 方案的定位则完全跟随错误判断崩溃。这一对比有力地支撑了论文「语言引导而非主导」的设计目标。

跨数据集的结果进一步表明，模型在 VisA 上训练后对钢材（SDD）、纹理（DTD-Synthetic）和织物（WFDD）的泛化能力同样可观，尤其在 SDD 和 DTD-Synthetic 上的像素级 AUROC 均超过 98%，说明语义锚所编码的异常概念具有一定的跨材质普适性。

## 讨论与可借鉴点

OPD-IAD 在方法论层面给出了一个清晰的设计原则：[[语义引导]]与[[密集视觉证据]]应当各司其职，前者提供方向性条件，后者提供像素级评分的根基。这条原则不仅适用于工业异常检测，任何需要在视觉语言模型中同时追求文本可解释性与密集空间预测的任务——如医学影像的病灶定位、遥感图像的变化检测——都可以借鉴这一思路：通过 on-policy 自蒸馏让语言判断本身变得更「懂」异常，再通过判断转发将语义条件锚化为视觉空间的对比向量，让两种模态的贡献解耦而非耦合。

从工程角度看，论文选择全量微调 Qwen3-VL-8B 的做法在当前算力背景下门槛不低——8 张 A100 训练 30 epoch 的成本对大多数研究团队而言难以承受。OPE-IAD 的设计本身并不必然依赖全量微调，LoRA 等参数高效微调方法在理论上同样可行，只是论文尚未探索。一个值得追问的问题是：当换用更小的骨干模型或参数高效微调策略时，OPSD 的 token 级密集监督是否仍然能带来同等幅度的提升？这一点在论文中被回避了，也是后续工作可以填补的空白。

局限方面，论文虽然在设计层面区分了「引导」与「主导」，但在超参层面仍有不少未充分验证的地方：EMA 衰减率 $\mu$、JSD 混合系数 $\beta$、奖励权重 $\lambda_R$ 等关键超参均只使用了一组配置，缺少灵敏度分析。此外，论文未与近期提出的其他强基线（如 VMAD、AG-VAS、OmniAD 等）做直接对比，也未纳入与纯视觉零样本方法（如 AnomalyCLIP）的对照，使得 LVLM 路线相对于成熟纯视觉路线的增量收益难以定量评估。问答准确率在部分数据集上仍偏低（SDD 仅 62.91），说明语言侧的缺陷理解能力仍有较大提升空间——这既是 OPD-IAD 的局限，也是整个基于大视觉语言模型的工业异常检测领域下一步需要攻克的方向。

## 摘要
大型视觉-语言模型（LVLMs）最近在工业异常检测（IAD）方面展现出强大的潜力，能够提供图像级异常判断和可解释的缺陷推理。然而，目前基于LVLM的IAD方法仍然难以从生成的语言判断中产生精确的像素级异常图。我们的目标是实现精确的像素级定位，同时将语言作为引导而非让其主导视觉响应。具体而言，我们提出了textbf{OPD-IAD}，一个面向基于LVLM的IAD的、具有证据特权优势的密集在线自蒸馏框架。OPD-IAD将特权缺陷证据蒸馏到模型自身的在线判断轨迹上，使最终生成的判断能够在密集监督下学习，而不是仅被视为文本答案。由此产生的判断将作为密集异常感知的语义条件。为了将该条件转化为密集视觉证据，我们引入了textbf{语言引导视觉锚定}，它通过判断转发将图像和问题在最终判断条件下重新编码为语义锚点，并通过一个对比热图头将其与密集视觉特征进行对比，从而生成异常图。由此，语言判断提供了紧凑的语义引导，而密集视觉特征仍是像素级评分的基础，使得语言能够引导异常定位，而不会让语言质量直接决定像素级响应。大量实验表明，OPD-IAD在基于LVLM的IAD方法中取得了最佳的整体性能，在大多数图像级、像素级和问答（QA）指标上均处于领先地位。

## Abstract
Large vision-language models (LVLMs) have recently shown strong potential for industrial anomaly detection (IAD) by providing image-level anomaly judgments and interpretable defect reasoning. However, current LVLM-based IAD methods still struggle to produce precise pixel-level anomaly maps from generated language judgments. We aim to achieve precise pixel-level localization while using language as guidance rather than letting it dominate the visual response. Specifically, we propose \textbf{OPD-IAD}, an evidence-privileged dense on-policy self-distillation framework for LVLM-based IAD. OPD-IAD distills privileged defect evidence onto the model's own on-policy judgment trajectory, enabling the final generated judgment to be learned under dense supervision rather than treated only as a textual answer. The resulting judgment serves as a semantic condition for dense anomaly perception. To turn this condition into dense visual evidence, we introduce \textbf{Language-guided Visual Anchoring}, which uses a judgment reforward to re-encode the image and question under the final-judgment condition into semantic anchors and contrasts them with dense visual features through a contrastive heatmap head to generate anomaly maps. The language judgment therefore provides compact semantic guidance, while dense visual features remain the basis for pixel-level scoring, allowing language to guide anomaly localization without letting language quality directly dictate the pixel-level response. Extensive experiments show that OPD-IAD achieves the best overall performance among LVLM-based IAD methods, leading on most image-level, pixel-level, and QA metrics.

# OPD-IAD 论文总结

## 1. 核心问题与研究动机

工业异常检测（IAD）需要同时完成两类任务：
- **图像级判断**：识别产品是否异常，并给出可解释的文本推理；
- **像素级定位**：在图像上精确标出缺陷区域。

近年来，大视觉-语言模型（LVLM）已能够为工业图像输出异常判断和缺陷解释，但将其转化为**精确像素级异常图**仍是未解决的问题。现有方法存在两条有缺陷的路径：

- **解耦路径**：语言判断仅作为解释输出，不参与热图生成，导致文本与定位脱节；
- **紧耦合路径**：通过分割 token、掩码文本、推理 token 注意力等"语言侧接口"驱动定位，使像素响应过分依赖生成文本的正确性与稳定性，错误或不稳定的判断会直接误导热图。

论文的核心主张是：**语言判断应作为语义引导，而像素级响应必须基于密集视觉证据**。围绕这一原则，需要解决两个训练层面的挑战：
1. 监督必须作用于**模型自身在部署时产生的轨迹**（即 on-policy）；
2. 监督必须**密集、细粒度**，反映缺陷证据，而非仅奖励最终答案。

## 2. 方法论

### 2.1 整体框架：双分支 + 共享定位

模型（以 Qwen3-VL-8B 为骨干）针对部署输入 $(x_i^{img}, x_i^{text})$ 生成语言响应 $\hat{y}_i$，并提取其最终判断 $\hat{a}_i = \text{Trim}_{\text{ans}}(\hat{y}_i)$。该判断在 **判断转发（judgment reforward）** 中与图像、问题以及一组可学习的"异常 / 正常"基锚 $z_a, z_n$ 一起被重新编码，得到上下文相关的锚 $\tilde{z}_a, \tilde{z}_n$。对比热图头将密集视觉 patch 特征 $v_{ij}$ 与这两个锚进行对比打分，得到像素级异常图 $\hat{M}_i$。

### 2.2 证据特权的在线自蒸馏（OPSD）

- **学生分支**在部署上下文 $c_i^S = \text{Prompt}_S(x_i^{img}, x_i^{text})$ 下自采样响应 $\hat{y}_i \sim \pi_\theta(\cdot|c_i^S)$；
- **教师分支**使用同一模型的 EMA 副本，仅在训练时存在，并在特权上下文 $c_i^T = \text{Prompt}_T(x_i^{img}, x_i^{text}, r_i)$ 下对学生的每个前缀进行重打分。

教师权重由 EMA 维护：

$$\bar{\theta}^{(k)} = \mu\,\bar{\theta}^{(k-1)} + (1-\mu)\,\theta^{(k)},\quad \mu\in(0,1)$$

对学生每个位置 $t$ 的下一 token 分布做 token 级分布散度匹配：

$$\ell_{\text{OPSD}}^{(i)} = \sum_{t=1}^{|\hat{y}_i|} D\!\left(P_{S,t}\;\|\;\text{stopgrad}(P_{T,t})\right)$$

其中 $D$ 采用广义 Jensen–Shannon 散度，对应的混合分布为：

$$m_t^{\beta} = (1-\beta)P_{S,t} + \beta\,\text{stopgrad}(P_{T,t})$$

$$D_{\text{JSD}}^{\beta}\!\left(P_{S,t}\|\,\text{stopgrad}(P_{T,t})\right) = \beta\,\text{KL}\!\left(\text{stopgrad}(P_{T,t})\|m_t^{\beta}\right) + (1-\beta)\,\text{KL}\!\left(P_{S,t}\|m_t^{\beta}\right)$$

当 $\beta=0.5$ 时退化为对称 JSD。该设计同时实现"on-policy（监督学生实际采样轨迹）"和"密集 token 级（每步都学到缺陷证据）"。

### 2.3 语言引导的视觉锚定（LVA）

判断转发后取两个上下文锚的隐藏状态：

$$(\tilde{z}_a,\tilde{z}_n) = f_{\theta}^{\text{ref}}\!\left(x_i^{img}, x_i^{text}, \hat{a}_i; z_a, z_n\right),\quad \tilde{z}_a,\tilde{z}_n \in \mathbb{R}^d$$

对比热图头通过投影 + 归一化 + 余弦对比计算每个 patch 的异常 logit：

$$\bar{v}_{ij} = \frac{v_{ij}}{\|v_{ij}\|_2},\quad \bar{z}_a = \frac{g_a(\tilde{z}_a)}{\|g_a(\tilde{z}_a)\|_2},\quad \bar{z}_n = \frac{g_n(\tilde{z}_n)}{\|g_n(\tilde{z}_n)\|_2}$$

$$s_{ij} = \tau\!\left(\langle \bar{v}_{ij}, \bar{z}_a\rangle - \langle \bar{v}_{ij}, \bar{z}_n\rangle\right)$$

其中 $\tau$ 为可学习温度。上采样得到像素级异常图。语言仅提供**语义条件**，像素打分仍由视觉特征决定。

### 2.4 总训练目标

$$L = L_{\text{OPSD}} + \lambda_R L_{\text{reward}} + \lambda_H L_{\text{map}}$$

- **$L_{\text{OPSD}}$**：上述 token 级自蒸馏损失，学习部署时的判断；
- **$L_{\text{reward}} = R_{\text{fmt}}(\hat{y}_i) + R_{\text{ans}}(\hat{a}_i, a_i)$**：稀疏的结果级奖励，仅用于正则化答案格式与最终判断；
- **$L_{\text{map}}$**：图像级 BCE（取 top-1% logit 平均）+ 像素级 BCE/Focal/Dice 损失 + 锚分离约束 $L_{\text{con}}=\max(\langle\bar{z}_a,\bar{z}_n\rangle+m, 0)$。
