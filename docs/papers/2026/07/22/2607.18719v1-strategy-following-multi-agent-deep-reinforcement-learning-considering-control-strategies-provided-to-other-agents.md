## TL;DR

这篇论文针对多智能体深度强化学习中人类难以高效控制协作结构的问题，提出了一种名为 sfDA7-X 的策略跟随方法。其核心思想是仅对部分关键智能体下达粗粒度指令（如"去某个区域"），未受指令的智能体则通过新设计的聚合目标通道（ADC）感知其他智能体的策略方向，自发补全被忽视的区域。实验在网格对象收集任务中验证了该方法的有效性：在有偏指令设置下，相比基线方法 sfDA6-IQN，对象收集数提升 8.00%，奖励提升 6.76%，且热力图可视化确认了智能体确实能实现互补覆盖而非重复进入同一区域。

## 研究背景与动机

基于深度强化学习的多智能体系统已在自动驾驶、实时战略游戏、无人机协作等场景展现出显著潜力。然而，训练完成的智能体在实际部署中仍面临两大长期挑战：一是懒智能体问题，即部分智能体发现不参与协作也能享受团队收益，从而逐渐丧失积极性；二是训练收敛的协作结构往往只是局部最优，难以与人类管理者的预期意图保持一致。

为解决可控性问题，已有研究尝试使用语言指令、程序化指令或条件策略等技术手段控制智能体行为。但这些方法存在一个共同缺陷：假设指令必须下达给全部智能体。在拥有数十乃至数百个智能体的真实系统中，对每个智能体逐一设计并下发指令既耗时耗力，也难以从全局视角优化协作结构。人类管理者真正期望的交互方式是：**仅告诉某些关键智能体"去做什么"，其余智能体能够自动理解整体目标并填补空缺**——这正是本文想要解决的核心问题。

## 方法

论文在已有的 sfDA6-X（策略跟随分布式注意力 actor 架构）基础上进行扩展，核心创新是引入**聚合目标通道（Aggregated Decision Channel, ADC）**。

在形式化层面，多智能体系统被建模为 Dec-POMDP：时间步 $t \in \mathbb{Z}^+$，智能体集合 $I = \{1, \dots, N\}$，每个智能体学习策略 $\pi_i$ 以最大化折扣累积回报 $R_i = \sum_{t=0}^{H} \gamma^{t} r_i(s, a)$。目标通道（DC）是一个 $G_X \times G_Y$ 的二值矩阵，标记"建议活动区域"——训练时仅当智能体在 DC 标记区域内收集对象时获得正奖励。人类管理者通过调整 DC 形状即可在测试时以粗粒度方式控制智能体的偏好区域。

ADC 的设计理念是：**让每个智能体不仅知道自己的指令，还能感知其他智能体被分配了什么指令**。具体而言，设 episode $e$ 下分配给"除智能体 $i$ 之外所有智能体"的 DC 集合为 $\mathcal{D}_{e,i}$，则智能体 $i$ 接收的 ADC 定义为：

$$M^{\text{ADC}}_i = \sum_{d \in \mathcal{D}_{e,i}} d$$

这意味着当其他智能体都偏向同一区域时，ADC 在该区域的值会更大，从而自然引导当前智能体前往"被忽视"的区域。论文假设在执行阶段智能体可以获取所有 DC，这是因为 DC 由人类管理者统一下发，集中可获取。

网络结构上，ADC 与原始 DC 一起输入条件模块的多头自注意力与 Transformer 编码器中，注意力机制帮助智能体权衡自身指令与其他智能体指令的相对重要性，生成综合性的显著性向量后传入 DRL head（如 IQN）输出 Q 值选择动作。ADC 的数学形式极为简洁——仅是对他人 DC 的求和，与智能体数量 $N$ 无关，具有良好的工程化部署前景和可扩展性。

## 实验与结果

实验在 $49 \times 25$ 的网格对象收集游戏环境中进行，4 个智能体，动作集为四向移动，环境始终维持 80 个可收集对象，episode 长度为 200 步。DC 仅配置两种类型：`entire`（全域）与 `half`（半域），用于模拟人类下达的不同偏好的区域指令。

训练阶段的结果显示，sfDA7-X 相比基线 sfDA6-IQN 在对象收集数上提升 3.80%，奖励提升 3.26%，且收敛速度基本相当，说明额外的 ADC 输入并未显著增加学习负担。

更具实际意义的是有偏 DC 执行阶段的对比。此时人类有意让部分智能体偏向特定区域，观察未受指令智能体能否自动补全剩余工作。结果表明 sfDA7-IQN 在对象收集数上提升 8.00%，奖励提升 6.76%。热力图可视化直观揭示了行为差异：sfDA6-IQN 中未被指令的智能体倾向于重复进入已被同伴偏好的区域，导致区域覆盖不均；而 sfDA7-IQN 的智能体能够主动识别并走向被忽视的区域，实现更合理的互补覆盖。无偏 DC 下的实验进一步验证了 ADC 的可解释性——当其他智能体集中在某区域时，ADC 值差异显著影响当前智能体的行为倾斜程度。

## 讨论与可借鉴点

论文的方法在概念上清晰优雅：ADC 机制引入了"互补感知"的归纳偏置，使智能体无需显式通信即可理解团队协作的全局态势。这一设计兼顾了人类可控性与智能体自主性——人类只需给出粗粒度指令，高频的"剩余调度"由智能体自适应完成。

然而实验设计存在明显不足：仅在单一网格环境、仅 $N=4$ 的设置下验证，缺乏与 QMIX、MAPPO 等标准多智能体基线的横向对比，也未进行消融实验来单独评估 ADC 的贡献。ADC 的有效性高度依赖"执行阶段可获取所有 DC"的假设——若在分布式场景中 DC 无法集中收集，则需要额外的通信开销。DC 类型仅限 entire/half 两种规则形状，更复杂的非凸区域或带障碍物的引导区域尚未探索。

对于该领域的研究者而言，ADC 的设计思路值得借鉴：让智能体感知"队友在做什么"而非直接传递动作信息，是一种轻量级的隐式协调机制。该思想可推广至需要层次化控制的多智能体场景，如多机器人仓库调度、异构无人机群协同等。后续工作应在 StarCraft 多智能体挑战、MuJoCo 等标准基准上验证，并探索 ADC 在更大规模智能体群中的可扩展性表现。

## 摘要
本研究提出了一种多智能体系统的学习方法，该方法允许智能体在学习后通过人类管理者的指令进行控制，并使未接受指令的智能体能够根据其他智能体的动作隐式地补充整体工作。基于深度学习的多智能体应用已展现出潜力；因此，为了实现广泛的社会应用，人类应能够使用简便的方法控制已训练的智能体，以应对环境和社会变化。即便没有上述变化，已学习到的协作通常也难以符合人类管理者的期望，因此更倾向于控制协作结构以匹配人类意图。一些研究致力于使用简单指令控制智能体行为。然而，它们假设指令会提供给所有智能体，这既耗时费力，在设计更优的协作机制时也不够清晰。理想情况下，特定智能体应接收关键动作指令，而其他智能体应自动完成剩余任务。所提方法扩展了先前关于多智能体深度强化学习可控性的研究，使未接受指令的智能体能够自适应地补充被忽视的任务和区域。实验结果表明，使用所提方法的智能体能够转换至另一种协作结构，并实现优于传统方法的性能。

## Abstract
This study proposes a learning method for multi-agent systems that allows agents to be controlled through human manager instructions after learning and enables uninstructed agents to implicitly complement the overall work based on the actions of other agents. Multi-agent applications using deep learning have shown potential; thus, to achieve extensive social applications, humans should be able to control learned agents using simple methods to respond to environmental and social changes. Even without such changes, learned coordination often does not match the expectations of human managers, making it preferable to control coordination structures to match human intentions. Some studies have aimed to control agent behavior using simple instructions. However, they assumed that instructions are provided to all agents, which is time-consuming and not evident when designing a better cooperation regime. Ideally, specific agents should receive key action instructions, while others should automatically complete the remaining tasks. The proposed method, which extends previous work on controllability in multi-agent deep reinforcement learning, enables uninstructed agents to adaptively complement overlooked tasks and areas. The experimental results show that agents using the proposed method can shift to another cooperative structure and achieve better performance than those using conventional methods.

## 二、方法论

### 2.1 整体框架：sfDA7-X

在已有的 **sfDA6-X**（strategy-following distributed attentional actor architecture after conditional attention）基础上扩展而来，核心新增 **聚合目标通道（Aggregated DC, ADC）**，使智能体在决策时能感知其他智能体被分配的策略方向。

### 2.2 预备形式化（Dec-POMDP）

- 时间步 $t \in \mathbb{Z}^+$，智能体集合 $I = \{1, \dots, N\}$。
- 元组 $\langle I, S, \{A_i\}, p_T, \{r_i\}, \{\Omega_i\}, O, H \rangle$。
- 状态转移 $p_T(s' \mid s, a)$，奖励 $r_i(s, a) \in \mathbb{R}$。
- 每个智能体学习策略 $\pi_i$ 以最大化折扣累积回报：
  $$R_i = \sum_{t=0}^{H} \gamma^{t} r_i(s, a),\quad 0 \le \gamma < 1$$

### 2.3 目标通道（DC）

- 一个 $G_X \times G_Y$ 二值矩阵（0/1），标记"建议活动区域"（beige 区域）。
- 训练时：仅当智能体在 DC 标记区域内收集对象时获得正奖励 $r_o$；其他区域收集无奖励。
- 通过调整 DC 形状即可在测试时以**粗粒度**控制智能体偏好的活动区域。

### 2.4 关键创新：聚合目标通道 ADC

设 episode $e$ 下分配给"除智能体 $i$ 之外所有智能体"的 DC 集合为 $\mathcal{D}_{e,i}$，则智能体 $i$ 接收的 ADC 定义为：

$$M^{\text{ADC}}_i = \sum_{d \in \mathcal{D}_{e,i}} d$$

- ADC 是**单一矩阵**，与智能体数量 $N$ 无关。
- 当其他智能体偏向同一区域时，ADC 在该区域的值更大，可引导当前智能体前往"被忽视"区域。
- 作者假设：**在执行阶段智能体可获得他人 DC**，理由是 DC 由人类管理者下发，集中可获取。

### 2.5 网络结构

sfDA7-X 在 sfDA6-X 基础上将 **DC + ADC** 同时输入到条件模块（CM）的多头自注意力 + Transformer 编码器中，生成显著性向量 $v_{\text{sal}}$，再传入 DRL head（本工作采用 **IQN**，即 implicit quantile network 作为 DRL head）：
$$Q = \text{DRLHead}\bigl(h^{0}_{L_L}\bigr)$$
