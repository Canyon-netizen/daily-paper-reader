## 摘要
异步强化学习通过解耦 rollout 生成与优化来提升吞吐量，但陈旧性是不可避免的副产物，它由策略滞后、引擎延迟以及混合专家路由共同加剧。从信赖域的视角看，这种失配至关重要：训练-推理差异在有限时间界中决定了近似误差，而 PPO 裁剪仅对外向的已采样更新进行门控，充当的是采样代理而非全策略约束。其结果是在陈旧 rollout 影响最深的异步机制下，高陈旧性更新仍处于弱控制状态。我们提出陈旧性自适应信赖域（SAT），它将去耦的采样对数比作为实用的陈旧性代理，借助基于陈旧性的核尺度在每个批次中识别高失配尾部，并仅对名义 PPO 区间中按符号选定的一端进行收缩。这在普通 token 上保留了基线行为，同时在新截获的外向区间上施加更为保守的更新。我们证明了相对 PPO 的局部区间包含性与逐点悲观性，展示了自适应规则如何在异质陈旧性下重塑更新几何。我们在基于 Qwen3-30B-A3B-Base、以 SGLang 作为推理引擎、以 Megatron 进行训练的解耦异步 RL 设置中对 SAT 进行评估。在该设置下，SAT-GSPO w/ R3 取得了所观察到的最佳 AIME24 avg@8，在 lag 1 时达到 35.83，在 lag 8 时达到 34.79，而 SAT-GSPO 在 lag 1 时达到 34.17。自适应裁剪与路由重放分别作为针对失配尾部与路由不一致性的互补稳定器。总体而言，将裁剪区间与陈旧性异质性对齐可有效稳定异步强化学习。

## Abstract
Asynchronous reinforcement learning improves throughput by decoupling rollout generation from optimization, but staleness is an inevitable byproduct compounded by policy lag, engine delays, and mixture-of-experts routing. From a trust-region perspective, this mismatch is critical: training-inference divergence governs approximation error in finite-horizon bounds, whereas PPO clipping only gates sampled outward updates, acting as a sampled surrogate rather than a full-policy constraint. As a result, high-staleness updates remain weakly controlled in the asynchronous regime where stale rollouts matter most.   We introduce the Staleness-Adaptive Trust Region (SAT), which uses the detached sampled log-ratio as a practical staleness proxy, identifies high-mismatch tails within each batch via staleness-based kernel scaling, and contracts only the sign-selected endpoint of the nominal PPO interval. This preserves baseline behavior on ordinary tokens while enforcing more conservative updates on newly intercepted outward bands. We prove local interval containment and pointwise pessimism relative to PPO, showing how the adaptive rule reshapes update geometry under heterogeneous staleness.   We evaluate SAT in a decoupled asynchronous RL setup built on Qwen3-30B-A3B-Base, using SGLang as the inference engine and Megatron for training. In this setting, SAT-GSPO w/ R3 achieves the best observed AIME24 avg@8, reaching 35.83 at lag 1 and 34.79 at lag 8, while SAT-GSPO reaches 34.17 at lag 1. Adaptive clipping and routing replay act as complementary stabilizers targeting mismatch tails and routing inconsistency, respectively. Overall, aligning clip intervals with staleness heterogeneity effectively stabilizes asynchronous RL.

# 论文总结：Stale but Stable：用于稳定异步强化学习的陈旧性自适应信赖域

## 1. 核心问题与研究动机

异步强化学习（Asynchronous RL）通过将 rollout 生成与优化解耦到独立 GPU 池并周期性广播权重来提升吞吐与 GPU 利用率，但其代价是引入了**陈旧性（staleness）**。该陈旧性并非由单一来源构成，而是由三类因素叠加而成：

- **策略更新滞后**：在权重广播窗口内进行的若干优化器步累积产生 $\Delta^{\pi}_{b,t} = \log \pi^{(j)} - \log \pi^{(\ell)}$；
- **实现失配**：即使权重一致，训练端与推理端的算子、精度与 MoE 路由仍产生差异 $\Delta^{\text{impl}}_{b,t} = \log \pi^{(\ell)} - \log \mu_{b,t}$；
- **MoE 路由不一致**：Top-K mask 的不连续性使小数值扰动即可激活不同专家集。

总失配分解为 $d_{b,t} = \log r_{b,t} = \Delta^{\pi}_{b,t} + \Delta^{\text{impl}}_{b,t}$，其分布在同一 rollout 窗口内高度异质且呈长尾。论文将此现象称为**陈旧性相关异步 RL 不稳定（Staleness-associated Asynchronous RL instability）**。

从信赖域（trust region）角度看，PPO 裁剪仅是对已采样 token 的外向更新进行门控，是**采样代理而非全策略约束**；固定半径在异质失配下同时过松（高陈旧尾部）与过紧（普通 token），尤其在高 lag（lag = 8）下会引发训练中后期评价指标崩塌（collapse）。

## 2. 方法论：SAT 的核心思想、关键公式与算法流程

### 2.1 设计原则

SAT 旨在**仅对当前 batch 中观察到的"高陈旧性尾部"按符号方向收缩 PPO 区间**，对普通 token 和 pull-back 更新保持原 PPO 行为，并可作为 drop-in 替换。

### 2.2 关键技术细节

**(1) 分离采样的 token 级陈旧性代理**：
$$d_{b,t} = \log r_{b,t}, \qquad d^{\text{sg}}_{b,t} \triangleq \text{sg}[d_{b,t}]$$
其中 sg 表示 stop-gradient，代理仅用于决定裁剪区间，不参与优化。

**(2) 基于陈旧性的核函数尺度（Staleness-based Kernel Scaling）**：
$$\hat{F}_{|d|}(x) = \frac{1}{|\mathcal{T}_{\text{act}}|}\sum_{(b,t)\in\mathcal{T}_{\text{act}}} \mathbf{1}\{|d_{b,t}| \le x\}, \quad q = \text{sg}\left[\inf\{x \ge 0: \hat{F}_{|d|}(x) \ge \alpha\}\right]$$
参考分位数 $q$ 由当前 batch 自校准，$\alpha = 0.90$。符号分离后通过 Hill 核映射：
$$\psi(u;q) = \frac{1}{1+(u/q)^2}, \quad u^{+}_{b,t}=[d^{\text{sg}}_{b,t}]_+,\quad u^{-}_{b,t}=[-d^{\text{sg}}_{b,t}]_+$$
满足 $\psi(0;q)=1$，$\psi(q;q)=1/2$，且 $\partial\psi/\partial u \le 0$。

**(3) 有效收缩因子（Effective Contraction Factors）**：
$$c_{\pm,b,t} = \begin{cases} \psi(u_{\pm,b,t};\, q), & q>0\ \text{且}\ |d^{\text{sg}}_{b,t}| > q \\ 1, & \text{otherwise}\end{cases}, \quad \tilde{\varepsilon}^{\text{low}}_{b,t} = \varepsilon_{\text{low}} c^{-}_{b,t},\quad \tilde{\varepsilon}^{\text{high}}_{b,t} = \varepsilon_{\text{high}} c^{+}_{b,t}$$

**(4) SAT 采样目标**：
$$\bar{r}^{\text{SAT}}_{b,t} = \text{clip}\left(r_{b,t},\, 1-\tilde{\varepsilon}^{\text{low}}_{b,t},\, 1+\tilde{\varepsilon}^{\text{high}}_{b,t}\right), \quad S^{\text{SAT}}_{b,t} = \min\!\left(r_{b,t}\hat{A}_{b,t},\ \bar{r}^{\text{SAT}}_{b,t}\hat{A}_{b,t}\right)$$

### 2.3 序列级扩展（GSPO）

GSPO 用长度归一化序列比 $\rho^{\text{seq}}_{b} = \exp\!\big(\tfrac{1}{T_b}\sum_t \log r^{\text{tok}}_{b,t}\big)$ 替换 token 比，量化经验分位数在序列级施加 SAT。

### 2.4 理论保证（命题 4.1：更新几何）

设 $I_{\text{PPO}}=[1-\varepsilon_{\text{low}},\,1+\varepsilon_{\text{high}}]$，$I^{\text{SAT}}_{b,t}=[1-\varepsilon_{\text{low}}c^-_{b,t},\,1+\varepsilon_{\text{high}}c^+_{b,t}]$，则：

- **(i) 区间包含**：$I^{\text{SAT}}_{b,t} \subseteq I_{\text{PPO}}$；门关闭时两区间重合，门开启时按符号选定的端点严格内移。
- **(ii) 逐点悲观性**：$S^{\text{SAT}}(r,\hat{A}) \le S_{\text{PPO}}(r,\hat{A})$。
- **(iii) 差异精确作用域**：仅在新截获的外向区间 $\{ \hat{A}>0,\ 1+\varepsilon_{\text{high}}c^+_{b,t}<r<1+\varepsilon_{\text{high}}\} \lor \{\hat{A}<0,\ 1-\varepsilon_{\text{low}}<r<1-\varepsilon_{\text{low}}c^-_{b,t}\}$ 上 SAT 梯度为零而 PPO 保留外向梯度 $\hat{A}$。

### 2.5 与信赖域界的联系

通过 Lemma 3.1（$D_{\text{TV}}(\mu\!\parallel\!\pi)[s]=\tfrac12 \mathbb{E}_{a\sim\mu}|r_s(a)-1|$）与 Proposition 3.2（理想全动作比包络控制 TV），SAT 论证：硬全动作比界本可控制有限时间界 (4) 的 TV 惩罚项，但 PPO 仅作用于采样动作；SAT 因此在采样代理层面对高陈旧尾部按需收缩。

- **轻量级 drop-in**：每 batch 仅增加一次分位数计算与少量逐元素 tensor 操作；禁用时与基础 PPO/GRPO/GSPO bit-identical。
- **符号感知自适应**：仅在使比值远离 1 的方向收缩，避免误伤 pull-back 更新。
- **方向感知统一框架**：在附录 E 中将 PPO、TRPO、DPPO、SPO、DRPO、TIS、IcePop、KPop、GSPO、SeqClip、R3 纳入同一非对称裁剪设计空间，定位明确。
- **解耦稳定器**：自适应裁剪针对失配尾部，R3 针对路由不一致，二者机制互补，避免一刀切。

## 8. 不足与局限

- **代理层控制**：SAT 收缩的是采样名义区间而非已学策略本身，未观测的词表动作仍不受约束；$|\log r|$ 不等价于 $D_{\text{TV}}$（缺少概率质量加权），亦不等于版本年龄。
- **混合失配混淆**：$d_{b,t}$ 同时混合策略滞后与实现失配，无法在两者间给出唯一可加性分解；论文将其作为诊断假设而非精确分解。
- **相对适应而非绝对适应**：参考分位数 $q$ 逐 batch 重算，因此方法响应的是相对失配尾部而非绝对标度，不能保证随 lag 增大单调收缩。
- **序列级语义的弱化**：GSPO 路径下 token 比可相互抵消，序列比不再对应 token-level $D_{\text{TV}}$ 解释。
- **经验范围有限**：单一种子、无置信区间、单一 backbone、单一基准（AIME24）、单任务（数学推理）；未在代码、对话、agentic 等异构任务上验证。
- **未报告关键训练元数据**：未给出 wall-clock 训练时长、rollout-to-train 吞吐比、token 总数等工程指标，外推成本受限。
- **崩溃标注主观**：collapse 判定基于日志窗口内是否恢复，缺乏自动判据。
