## 摘要
基于可验证奖励的强化学习 (RLVR) 已显著提升了大语言模型在数学推理和代码生成等任务上的推理能力。然而，大多数 RLVR 方法为整个轨迹分配一个标量的结果奖励，导致监督信号稀疏，且 token 级别的信用分配有限。同策略蒸馏 (OPD) 通过从更强的教师模型蒸馏 token 级别的分布来提供更密集的监督信号，但需要额外的教师模型，并且通常假设共享词表。同策略自蒸馏 (OPSD) 通过将同一模型在特权信息上进行条件化来构建教师策略，从而消除了对外部教师模型的依赖。然而，直接匹配教师分布可能导致信息泄露和优化不稳定。RLSD 通过仅使用教师信号来调节更新幅度，避免了直接匹配，但在采样推理失败时无法提供明确的修正方向。为了应对这一权衡，我们提出了 $\mathrm{H}^{2}\mathrm{SD}$，一种混合事后自蒸馏框架，它根据轨迹的正确性以不同方式使用教师模型。对于成功的轨迹，教师模型接收已确认正确的学生响应以及一个复述指令，其在原始响应 token 上的概率用于调节更新幅度，而不改变由奖励确定的方向。对于失败的轨迹，我们将教师模型以包含关键推理步骤和已验证答案的参考提示为条件，并最小化学生模型到教师模型的反向 KL 散度。在多个具有挑战性的推理基准上的实验表明，H$^2$SD 在保持优化稳定和良好生成效率的同时，始终优于代表性的 RLVR、OPSD 和 RLSD 基线方法。

## Abstract
Reinforcement learning with verifiable rewards (RLVR) has substantially improved the reasoning capabilities of large language models on tasks such as mathematical reasoning and code generation. However, most RLVR methods assign a scalar outcome reward to an entire trajectory, resulting in sparse supervision and limited token-level credit assignment. On-policy distillation (OPD) provides denser supervision by distilling token-level distributions from a stronger teacher model, but requires an additional teacher and typically assumes a shared vocabulary. On-policy self-distillation (OPSD) removes this dependency by conditioning the same model on privileged information to construct a teacher policy. However, directly matching the teacher distribution may cause information leakage and unstable optimization. RLSD avoids direct matching by using the teacher signal only to modulate update magnitudes, but it cannot provide an explicit correction direction when the sampled reasoning fails. To address this tradeoff, we introduce $\mathrm{H}^{2}\mathrm{SD}$, a hybrid hindsight self distillation framework that uses the teacher differently according to trajectory correctness. For successful trajectories, the teacher receives the student response confirmed as correct together with a rephrasing instruction, and its probabilities on the original response tokens are used to modulate update magnitudes without changing the direction determined by the reward. For failed trajectories, we condition the teacher on a reference hint containing key reasoning steps and a verified answer, and minimize the reverse KL divergence from the student to the teacher. Experiments on multiple challenging reasoning benchmarks show that H$^2$SD consistently outperforms representative RLVR, OPSD, and RLSD baselines while maintaining stable optimization and favorable generation efficiency.

## 一、核心问题与研究动机

RLVR（如 GRPO、DAPO、GSPO）已成为增强大语言模型推理能力的主流范式，但存在以下结构性瓶颈：

- **监督稀疏**：仅对整条轨迹赋予一个标量结果奖励，无法区分轨迹中哪些 token 对成功或失败负责，token 级信用分配能力有限。
- **OPD 的依赖**：在线策略蒸馏通过引入更强教师模型提供 token 级密集监督，但需要外部教师，且教师与学生通常必须共享词表，限制了适用性。
- **OPSD 的缺陷**：自蒸馏用同一模型在特权信息（如参考答案）上条件化充当教师，虽摆脱外部教师，但直接匹配特权条件分布容易导致**特权信息泄露**与训练不稳定。
- **RLSD 的不足**：仅以教师信号调节 token 级更新幅度，避免了信息泄露，但**无法为采样失败的推理提供显式修正方向**——它只调节对已有错误的惩罚强度，不告诉模型"应该往哪走"。

论文核心观察：在策略自蒸馏中，**分布级修正**与**稳定的 token 级信用分配**之间存在权衡，且最优策略**取决于轨迹是否正确**。

## 二、方法论：H²SD 框架

### 2.1 整体思路

按轨迹正确性进行**结果条件路由**（Outcome-Conditioned Routing）：
- **成功轨迹** → 奖励方向已可靠，使用 RLSD 式幅度调制做更细粒度的 token 级信用分配；
- **失败轨迹** → 采样路径不可靠，需要从特权条件教师拉出显式的修正方向。

### 2.2 提示（Hint）设计

使用更强的语言模型（Kimi-K2.6）为每个问题生成自然语言提示 $h$，包含**关键中间推理步骤与由验证器确认的最终答案**：

$$h = \mathcal{H}(x)$$

更强的模型仅作为提示生成器，不充当教师、不需要共享词表。实际教师分布仍由当前学生模型本身在提示条件下生成：

$$\pi^T(\cdot \mid x, h, y_{<t}) = \pi_\theta(\cdot \mid x, h, y_{<t}),\quad \pi^S(\cdot \mid x, y_{<t}) = \pi_\theta(\cdot \mid x, y_{<t})$$

### 2.3 失败轨迹：反向 KL 修正

对失败轨迹，将教师以参考提示 $h$ 为条件，最小化**从学生到教师的反向 KL 散度**：

$$\mathcal{L}_{\text{RKL}} = \frac{1}{T}\sum_{t=1}^{T} D_{\text{KL}}\!\left(p^S_{t,\theta} \,\Big\|\, \text{sg}[p^{T,h}_{t,\theta}]\right)$$

其中 $p^S_{t,\theta}=\pi_\theta(\cdot\mid x, y_{<t})$，$p^{T,h}_{t,\theta}=\pi_\theta(\cdot\mid x, h, y_{<t})$，教师分支使用 stop-gradient。

### 2.4 成功轨迹：幅度调制 + 复述指令

对成功轨迹，教师接收"已确认正确的学生响应 + 复述指令"，其在**原始响应 token** 上的概率用于计算幅度权重 $w_t$，保持 GRPO 原始方向，仅重新分配奖励/惩罚强度。复述指令的作用是去除冗余内容但保留有效推理路径。

### 2.5 总体目标

设 $m = \mathbb{1}[R(x,y)=1]$ 为正确性指示：

$$\mathcal{L}_{\text{H}^2\text{SD}} = \mathbb{E}_{x,y}\!\left[m\,\mathcal{L}_{\text{RLSD}} + \gamma(1-m)\,\mathcal{L}_{\text{RKL}}\right]$$

其中 $\gamma$ 控制失败轨迹上修正蒸馏的强度。

## 三、实验设计

### 3.1 模型与基准

- **基础模型**：Qwen3-30B-A3B-Instruct-2507
- **提示生成器**：Kimi-K2.6
- **三个逻辑推理基准**：
  - **Sudoku**：6×6 与 8×8 网格（每行/列/宫内数字不重复）；
  - **Calcudoku**：5×5 与 6×6，引入区域级算术约束；
  - **Arrow Maze**：6×6、7×7、8×8、9×9、10×10，需为每格分配方向箭头使射线长度匹配数值。

### 3.2 基线方法

- **GRPO**（标准 RLVR）
- **OPSD**（在线自蒸馏，分布匹配）
- **RLSD**（仅幅度调制的稳定自蒸馏）
- **RLSD+hint**（将 RLSD 的特权信息替换为本文使用的提示，控制变量）
- **SDPO**（自蒸馏策略优化）
- **SRPO**（成功走 GRPO、失败走自蒸馏的路由式方法）

### 3.3 实现细节

- 基于 **VERL + SGLang** 实现；
- 为缓解长链推理下全词表蒸馏的显存压力，**仅保留学生 top-100 token 的精确概率，其余合并为尾桶**；
- SDPO 与 SRPO 的蒸馏分支使用 $\alpha=0.5$ 的广义 Jensen–Shannon 散度。

## 六、主要结论与发现

1. **H²SD 在全部基准上达到最佳综合性能**：Sudoku 上提升尤为显著（6×6: 76.50% vs OPSD 35.25%；8×8: 57.25% vs OPSD 16.75%），且生成 token 数更少。
2. **结果条件路由是关键**：仅用任一单一策略（Magnitude Only 或 Reverse-KL Only）效果都明显低于 H²SD；将成功/失败分配**反转**会导致策略熵迅速坍缩到零，性能低于基础 LLM。
3. **特权信息质量决定上限**：在四个特权上下文中，仅含最终答案的"Ground truth"几乎无提升，而**包含过程级推理的提示**提升最大（Sudoku-6×6: 24.50→76.50%）。
4. **复述指令与更新方式强耦合**：复述显著提升 Magnitude Only（+23.75/+32.00pp）和 H²SD（+8.00/+5.75pp），但**降低** Reverse-KL Only（−2.50/−3.50pp），并使后者熵急剧下降。
5. **效率与精度同向**：H²SD 在 Sudoku-6×6 上同时实现最高 pass@1 与最低平均生成 token 数。

## 七、优点

- **方法论洞察清晰**：明确指出 OPSD 与 RLSD 之间的权衡，并提出"按正确性分而治之"的简洁解法，动机与设计一一对应。
- **控制变量严谨**：RLSD+hint 与 OPSD/H²SD 共享相同提示，使性能差异可归因于"如何使用"而非"信息本身"。
- **多维消融**：路由策略、特权信息、复述指令、熵动态、生成效率五个角度交叉验证，证据链完整。
- **实现考虑实际**：top-100 token 概率保留 + 尾桶合并的工程技巧降低了长链推理蒸馏的显存开销。
- **熵动态可视化**：通过 actor 熵曲线直观展示策略坍缩，避免仅靠最终准确率评判的片面性。

## 八、不足与局限

- **任务覆盖单一**：所有基准均为**确定性逻辑推理（数独、迷宫、算术方阵）**，缺乏对数学竞赛题、代码生成、开放问答等典型 RLVR 场景的验证，方法在更广泛推理任务上的迁移性未知。
- **强模型依赖提示生成**：虽然 H²SD 摆脱了教师模型的词表约束，但仍依赖 Kimi-K2.6 生成高质量提示；在无法获取更强模型的场景下（如闭源部署或特定领域），提示质量可能成为瓶颈。
- **未给出训练成本细节**：4×8 H200 的硬件配置已给出，但未报告训练步数、wall-clock 时间、奖励模型调用次数等关键成本指标。
- **超参数 $\gamma$ 与 $\lambda$ 的消融不足**：仅在主结果与少量消融中隐式使用，缺少对这两个核心超参数的敏感性分析。
- **失败轨迹的反向 KL 可能仍存泄露风险**：虽然比 OPSD 更温和，但学生分布仍直接被特权条件教师拉近，对特权信息的依赖程度未做定量评估。
- **SRPO 对比存在配置差异**：SRPO 走 entropy-weighted SDPO 分支，而 H²SD 走 reverse-KL 分支，两者在失败轨迹上的差异可能部分来自分支选择而非路由思想本身。
- **样本效率未深入分析**：仅报告最终准确率，未给出训练曲线或样本复杂度层面的对比，难以判断 H²SD 的优势是来自更快收敛还是更高上限。
