## TL;DR

H²SD 针对大语言模型推理训练中监督信号稀疏、token 级信用分配不足的问题，提出按轨迹正确性差异化使用教师信号的混合事后自蒸馏框架：成功轨迹用教师概率调控更新幅度保持方向稳定，失败轨迹以参考提示构造教师并用反向 KL 散度提供明确修正方向。实验在 Sudoku、Calcudoku、Arrow Maze 等逻辑推理基准上稳定超越 RLVR、OPSD、RLSD 等基线方法，为自蒸馏训练提供了更稳定高效的方案。

## 研究背景与动机

在可验证奖励强化学习（RLVR）范式下，模型通过整条推理轨迹的标量奖励学习解题策略。以 GRPO、DAPO、GSPO 为代表的这类方法已在数学推理和代码生成任务上展现出显著能力，但一个根本性的瓶颈始终制约着其训练效率：仅对完整轨迹赋予二元结果奖励，意味着模型无法区分轨迹中哪些 token 对最终成功或失败负责，这种 token 级信用分配不足的问题在高难度推理任务中尤为突出。

为了获得更密集的监督信号，学术界发展出两条技术路线。[[同策略蒸馏]]（OPD）通过引入更强的外部教师模型，直接蒸馏其 token 级概率分布来指导学生模型更新，显著提升了信号密度。然而这一方案存在明显局限：需要额外维护一个教师模型，且师生模型通常必须共享词表，增加了系统复杂度。更关键的是，在推理场景中我们往往并没有一个"永远更强"的教师可用。

同策略自蒸馏（OPSD）通过将同一模型在特权信息（如参考答案）上进行条件化来构建教师策略，从而摆脱了对外部教师的依赖。其核心思想是：模型在"看到答案"的条件下生成的分布，比在"不看到答案"的条件下生成的分布包含更多正确推理路径的信息，因此可以充当教师来引导学生学习。这一思路看似优雅，但论文敏锐地指出了其深层问题：直接匹配教师分布会导致**特权信息泄露**——学生模型可能被直接训练去复现特权条件下的 token，而非真正学会解题的推理能力，同时这种直接匹配还容易造成训练不稳定。

第三条路线以 RLSD 为代表，其设计哲学截然不同：完全避免匹配教师分布，仅用教师信号来调节 token 级的更新幅度。具体而言，模型仍然按照 REINFORCE 类方法由奖励确定更新方向，但每个 token 的更新幅度由教师概率重新加权。这样既保留了 reward 的方向信息，又实现了更细粒度的信用分配。然而这一方案在面对采样失败时显得力不从心：它只调节对已有错误的惩罚强度，却无法告诉模型"应该往哪个方向修正"。

论文的核心洞见正在于此：最优的自蒸馏策略**取决于轨迹是否正确**。当轨迹成功时，reward 方向已经可靠，此时需要的是更精细的幅度调制；当轨迹失败时，采样的推理路径不可信，模型需要从特权条件教师那里获得一个明确的修正方向。

## 方法

H²SD 的整体架构建立在**结果条件路由**（Outcome-Conditioned Routing）的设计原则上，即根据轨迹的正确性以不同方式使用教师模型。教师策略和[[学生策略]]均由当前训练的模型本身在不同的条件化方式下生成，这种自蒸馏设计完全消除了对外部教师的依赖。

在失败轨迹的处理上，H²SD 引入了一个关键组件：参考提示（reference hint）。该提示由一个更强的语言模型（论文使用 Kimi-K2.6）为每个问题独立生成，包含**关键中间推理步骤和经验证器确认的最终答案**。注意这里的设计精妙之处在于：更强的模型仅作为提示生成器，不充当教师也不需要与学生共享词表。实际的教师分布仍然由当前学生模型本身在提示条件下生成。

形式化地，设提示生成函数为 $h = \mathcal{H}(x)$，学生策略为 $\pi^S(\cdot \mid x, y_{<t}) = \pi_\theta(\cdot \mid x, y_{<t})$，教师策略为 $\pi^T(\cdot \mid x, h, y_{<t}) = \pi_\theta(\cdot \mid x, h, y_{<t})$。对于失败轨迹，H²SD 最小化从学生分布到教师分布的**反向 KL 散度**：

$$\mathcal{L}_{\text{RKL}} = \frac{1}{T}\sum_{t=1}^{T} D_{\text{KL}}\!\left(p^S_{t,\theta} \,\Big\|\, \text{sg}[p^{T,h}_{t,\theta}]\right)$$

其中 $p^S_{t,\theta} = \pi_\theta(\cdot \mid x, y_{<t})$，$p^{T,h}_{t,\theta} = \pi_\theta(\cdot \mid x, h, y_{<t})$，教师分支使用 stop-gradient。反向 KL 散度的特性是**均值寻找**（mean-seeking）而非模式寻找——它会使学生分布的均值趋近教师分布，这正好对应了"需要明确修正方向"的需求。

对于成功轨迹，处理方式则截然不同。H²SD 采用**幅度调制**策略，教师模型接收已确认正确的学生响应以及一个复述指令，其在原始响应 token 上的概率用于计算 token 级更新幅度权重，但**不改变由 reward 确定的更新方向**。复述指令的作用是引导教师分布去除冗余内容同时保留有效推理路径。这种设计保证了在成功轨迹上优化方向的可靠性，同时通过幅度调制实现更细粒度的信用分配。

最终的混合目标函数整合了两种策略。设 $m = \mathbb{1}[R(x,y)=1]$ 为轨迹正确性指示器：

$$\mathcal{L}_{\text{H}^2\text{SD}} = \mathbb{E}_{x,y}\!\left[m\,\mathcal{L}_{\text{RLSD}} + \gamma(1-m)\,\mathcal{L}_{\text{RKL}}\right]$$

其中 $\gamma$ 控制失败轨迹上修正蒸馏的强度。这一目标函数清晰地表达了"分而治之"的设计思想：成功轨迹走 RLSD 式的幅度调制分支，失败轨迹走反向 KL 修正分支。

从实现角度，H²SD 基于 VERL 框架与 SGLang 推理引擎构建。针对长链推理场景下全词表蒸馏的显存压力，论文采用了实用的工程技巧：仅保留学生模型 top-100 token 的精确概率，其余 token 概率合并为一个尾桶（bucket），在保证蒸馏效果的同时显著降低了计算开销。

## 实验与结果

论文在三个精心设计的逻辑推理基准上进行了系统实验。Sudoku 基准包含 6×6 和 8×8 两种规格，要求模型在每行、每列、每个宫格内填入不重复的数字，对应数独游戏的核心约束。Calcudoku 引入区域级算术约束，模型需同时满足数字不重复约束和区域求和约束，增加了推理的复杂程度。Arrow Maze 则要求为每个格子分配方向箭头，使从该格子出发的射线恰好经过指定数量的格子，这是一个更复杂的组合优化问题，实验涵盖 6×6 到 10×10 的多种规格。

实验以 Qwen3-30B-A3B-Instruct-2507 作为基础模型，对比了包括标准 GRPO（典型 RLVR 方法）、OPSD（在线自蒸馏、分布匹配）、RLSD（仅幅度调制）、RLSD+hint（将 RLSD 的特权信息替换为本文使用的提示，控制变量以隔离"提示内容"与"使用方式"的差异）、SDPO（自蒸馏策略优化）、SRPO（成功走 GRPO、失败走自蒸馏的路由式方法）在内的多个基线。

主实验结果呈现出压倒性的差异。在 9 个基准设置上，H²SD 的 Overall 平均性能达到 50.49%，远超第二名 RLSD 的 24.85%，提升幅度超过一倍。在最具挑战性的 Sudoku-8×8 上，H²SD 达到 57.25%，而 OPSD 仅有 16.75%，差距极为显著。更值得注意的是，H²SD 并非以牺牲效率换取准确率：在 Sudoku-6×6 上，它同时实现了最高的 pass@1 准确率和最低的平均生成 token 数。

路由策略的消融实验验证了核心设计决策的有效性。将成功轨迹与失败轨迹的策略**反转**（即成功轨迹用反向 KL、失败轨迹用幅度调制）会导致策略熵迅速坍缩到接近零，最终性能甚至低于基础 LLM 基线。仅使用单一策略（Magnitude Only 或 Reverse-KL Only）的性能也明显低于 H²SD 的混合方案。这些结果有力地证明了"按正确性分而治之"这一设计选择的必要性。

特权信息类型的消融揭示了提示质量的关键作用。仅包含最终答案的"Ground truth"条件几乎不带来任何提升，而包含过程级推理的提示则带来显著增益——在 Sudoku-6×6 上从 24.50% 提升至 76.50%。这一发现强调了在自蒸馏框架中，**提示的内容质量**直接决定了性能上限。

复述指令与更新方式之间存在强耦合效应。复述显著提升了幅度调制类策略的性能，但对反向 KL 类策略反而有害，这可能是因为复述改变了教师分布与学生分布之间的相对关系，使得均值寻找特性不再适合同步的更新幅度调整。

## 讨论与可借鉴点

H²SD 的核心贡献在于提供了一条清晰的问题解决路径：面对两种互补技术手段的权衡时，不要试图设计一个"万能"的单一策略，而是根据数据或轨迹的内在属性进行条件化路由。这一思想具有超越具体任务的普适性，可以推广到其他存在类似权衡的机器学习场景中。

从工程实现角度，论文强调的**控制变量严谨性**值得借鉴。通过引入 RLSD+hint 作为对照，论文有效地隔离了"提示内容"与"使用方式"两个变量，使得性能差异可以明确归因于方法论层面的创新而非信息质量的差异。这种精细的实验设计思路对于提升论文的可信度和可复现性至关重要。

然而，H²SD 的适用场景目前主要局限于**确定性逻辑推理任务**。所有实验基准（数独、算术方阵、箭头迷宫）都遵循明确的验证规则，且正确答案通常唯一。对于数学竞赛题、代码生成等具有更大解空间和更复杂验证流程的任务，H²SD 的有效性尚待验证。此外，失败轨迹的反向 KL 修正虽然比直接分布匹配更温和，但学生分布仍然被特权条件教师直接拉近，特权信息泄露的风险并未完全消除，只是以更隐蔽的形式存在。

从更宏观的视角看，H²SD 反映了大语言模型推理训练领域的一个趋势：随着模型能力的提升，纯粹的强化学习信号已不足以支撑高效训练，如何在保持优化稳定性的同时引入更丰富的监督信息，成为下一阶段研究的关键问题。H²SD 以优雅的方式回答了这一问题，但其对更强语言模型生成提示的依赖，也意味着在无法获取更强模型的闭源部署或特定领域场景中，该方法的适用性可能受限。

## 摘要
基于可验证奖励的强化学习 (RLVR) 已显著提升了大语言模型在数学推理和代码生成等任务上的推理能力。然而，大多数 RLVR 方法为整个轨迹分配一个标量的结果奖励，导致监督信号稀疏，且 token 级别的信用分配有限。同策略蒸馏 (OPD) 通过从更强的教师模型蒸馏 token 级别的分布来提供更密集的监督信号，但需要额外的教师模型，并且通常假设共享词表。同策略自蒸馏 (OPSD) 通过将同一模型在特权信息上进行条件化来构建教师策略，从而消除了对外部教师模型的依赖。然而，直接匹配教师分布可能导致信息泄露和优化不稳定。RLSD 通过仅使用教师信号来调节更新幅度，避免了直接匹配，但在采样推理失败时无法提供明确的修正方向。为了应对这一权衡，我们提出了 $\mathrm{H}^{2}\mathrm{SD}$，一种混合事后自蒸馏框架，它根据轨迹的正确性以不同方式使用教师模型。对于成功的轨迹，教师模型接收已确认正确的学生响应以及一个复述指令，其在原始响应 token 上的概率用于调节更新幅度，而不改变由奖励确定的方向。对于失败的轨迹，我们将教师模型以包含关键推理步骤和已验证答案的参考提示为条件，并最小化学生模型到教师模型的反向 KL 散度。在多个具有挑战性的推理基准上的实验表明，H$^2$SD 在保持优化稳定和良好生成效率的同时，始终优于代表性的 RLVR、OPSD 和 RLSD 基线方法。

## Abstract
Reinforcement learning with verifiable rewards (RLVR) has substantially improved the reasoning capabilities of large language models on tasks such as mathematical reasoning and code generation. However, most RLVR methods assign a scalar outcome reward to an entire trajectory, resulting in sparse supervision and limited token-level credit assignment. On-policy distillation (OPD) provides denser supervision by distilling token-level distributions from a stronger teacher model, but requires an additional teacher and typically assumes a shared vocabulary. On-policy self-distillation (OPSD) removes this dependency by conditioning the same model on privileged information to construct a teacher policy. However, directly matching the teacher distribution may cause information leakage and unstable optimization. RLSD avoids direct matching by using the teacher signal only to modulate update magnitudes, but it cannot provide an explicit correction direction when the sampled reasoning fails. To address this tradeoff, we introduce $\mathrm{H}^{2}\mathrm{SD}$, a hybrid hindsight self distillation framework that uses the teacher differently according to trajectory correctness. For successful trajectories, the teacher receives the student response confirmed as correct together with a rephrasing instruction, and its probabilities on the original response tokens are used to modulate update magnitudes without changing the direction determined by the reward. For failed trajectories, we condition the teacher on a reference hint containing key reasoning steps and a verified answer, and minimize the reverse KL divergence from the student to the teacher. Experiments on multiple challenging reasoning benchmarks show that H$^2$SD consistently outperforms representative RLVR, OPSD, and RLSD baselines while maintaining stable optimization and favorable generation efficiency.

## 一、核心问题与研究动机

RLVR（如 GRPO、DAPO、GSPO）已成为增强大语言模型推理能力的主流范式，但存在以下结构性瓶颈：

- **监督稀疏**：仅对整条轨迹赋予一个标量结果奖励，无法区分轨迹中哪些 token 对成功或失败负责，token 级信用分配能力有限。
- **OPD 的依赖**：在线策略蒸馏通过引入更强教师模型提供 token 级密集监督，但需要外部教师，且教师与学生通常必须共享词表，限制了适用性。
- **OPSD 的缺陷**：自蒸馏用同一模型在特权信息（如参考答案）上条件化充当教师，虽摆脱外部教师，但直接匹配特权条件分布容易导致**特权信息泄露**与训练不稳定。
- **RLSD 的不足**：仅以教师信号调节 token 级更新幅度，避免了信息泄露，但**无法为采样失败的推理提供显式修正方向**——它只调节对已有错误的惩罚强度，不告诉模型"应该往哪走"。

论文核心观察：在策略自蒸馏中，**分布级修正**与**稳定的 token 级信用分配**之间存在权衡，且最优策略**取决于轨迹是否正确**。

## 二、方法论：H²SD 框架

### 2.1 整体思路

按轨迹正确性进行**结果条件路由**（Outcome-Conditioned Routing）：
- **成功轨迹** → 奖励方向已可靠，使用 RLSD 式幅度调制做更细粒度的 token 级信用分配；
- **失败轨迹** → 采样路径不可靠，需要从特权条件教师拉出显式的修正方向。

### 2.2 提示（Hint）设计

使用更强的语言模型（Kimi-K2.6）为每个问题生成自然语言提示 $h$，包含**关键中间推理步骤与由验证器确认的最终答案**：

$$h = \mathcal{H}(x)$$

更强的模型仅作为提示生成器，不充当教师、不需要共享词表。实际教师分布仍由当前学生模型本身在提示条件下生成：

$$\pi^T(\cdot \mid x, h, y_{<t}) = \pi_\theta(\cdot \mid x, h, y_{<t}),\quad \pi^S(\cdot \mid x, y_{<t}) = \pi_\theta(\cdot \mid x, y_{<t})$$

### 2.3 失败轨迹：反向 KL 修正

对失败轨迹，将教师以参考提示 $h$ 为条件，最小化**从学生到教师的反向 KL 散度**：

$$\mathcal{L}_{\text{RKL}} = \frac{1}{T}\sum_{t=1}^{T} D_{\text{KL}}\!\left(p^S_{t,\theta} \,\Big\|\, \text{sg}[p^{T,h}_{t,\theta}]\right)$$

其中 $p^S_{t,\theta}=\pi_\theta(\cdot\mid x, y_{<t})$，$p^{T,h}_{t,\theta}=\pi_\theta(\cdot\mid x, h, y_{<t})$，教师分支使用 stop-gradient。

### 2.4 成功轨迹：幅度调制 + 复述指令

对成功轨迹，教师接收"已确认正确的学生响应 + 复述指令"，其在**原始响应 token** 上的概率用于计算幅度权重 $w_t$，保持 GRPO 原始方向，仅重新分配奖励/惩罚强度。复述指令的作用是去除冗余内容但保留有效推理路径。

### 2.5 总体目标

设 $m = \mathbb{1}[R(x,y)=1]$ 为正确性指示：

$$\mathcal{L}_{\text{H}^2\text{SD}} = \mathbb{E}_{x,y}\!\left[m\,\mathcal{L}_{\text{RLSD}} + \gamma(1-m)\,\mathcal{L}_{\text{RKL}}\right]$$

其中 $\gamma$ 控制失败轨迹上修正蒸馏的强度。
