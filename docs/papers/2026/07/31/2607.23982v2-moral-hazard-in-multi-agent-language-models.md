## 摘要
当具有社会价值的努力需要付出成本、难以被观察且主要惠及他人时，合作可能会失败。基于 Holmström 的团队道德风险模型，我们提出了对话式道德风险博弈（Dialogue Moral Hazard Game），这是一款受控的文本博弈，将这种隐藏行动结构操作化以适用于语言智能体。在每一轮中，智能体可以保留即时的本地奖励，或支付查询成本以揭示一个主要帮助另一智能体做出下游决策的隐藏安全事实。我们评估了七个开源权重语言模型和一个前沿 API 模型，将行为分解为查询使用、实现的信息传递、本地奖励保留、不安全选择、格式有效性以及团队成功。基础开源权重模型通常在未能实现团队成功的情况下保留本地奖励，或在未能传递能改变最终决策的信息的情况下进行查询。GPT-5.6 Sol 在主要设置下达到天花板行为，自主扫描对查询成本和团队奖励响应强烈。在一项包含 3,015 次决策、采用脚本化搭档的激励隔离实验中，其经验性查询阈值在九种查询成本下跟踪由 Holmström 推导的私人份额边界，平均绝对误差为 0.013。随后，我们使用监督微调、RLOO、顺序式 SFT+RLOO 以及 GEPA 提示优化作为诊断性更新机制（在覆盖范围内）。这些机制的效果各异：OLMo-7B 表现出最清晰的符合机制的权重级改善，而 GEPA 有时能在减少乃至消除高成本查询的同时提升团队成功。因此，优化可能改变总体奖励，却未必能恢复预期的合作机制，这促使我们采用能报告机制级行为而非仅报告团队成功的评估方法。

## Abstract
Cooperation can fail when socially valuable effort is costly, weakly observable, and mainly benefits others. Drawing on Holmström's team moral-hazard model, we introduce the Dialogue Moral Hazard Game, a controlled textual game that operationalizes this hidden-action structure for language agents. In each episode, an agent can preserve an immediate local reward or pay a query cost to reveal a hidden safety fact that primarily helps another agent's downstream decision. We evaluate seven open-weight language models and one frontier API model, decomposing behavior into query use, realized information transfer, local-reward preservation, unsafe choice, format validity, and team success. Base open-weight models commonly preserve local reward without team success or query without communicating information that changes the final decision. GPT-5.6 Sol reaches ceiling behavior in the primary setting, and autonomous sweeps respond strongly to query cost and team reward. In a 3,015-decision incentive-isolation experiment with scripted partners, its empirical query threshold tracks the Holmström-derived private-share boundary across nine query costs with mean absolute error 0.013. We then use supervised fine-tuning, RLOO, sequential SFT+RLOO, and GEPA prompt optimization as diagnostic update mechanisms where coverage permits. Their effects are heterogeneous: OLMo-7B shows the clearest mechanism-consistent weight-level improvement, whereas GEPA sometimes improves team success while reducing or eliminating costly queries. Thus, optimization can shift aggregate reward without recovering the intended cooperative mechanism, motivating evaluations that report mechanism-level behavior rather than team success alone.

- **关键矛盾**：从个体角度看，一项社会最优的努力可能因私人激励不足而被放弃，即 $\partial Y / \partial e_i > c_i'(e_i)$（社会值得做）但 $\alpha_i \partial Y / \partial e_i < c_i'(e_i)$（个体不愿做），其中 $\alpha_i$ 是该智能体在团队产出中所获份额。
- **现实意义**：检查他人工作、发出下游警告、调用工具查询等行为会消耗 token、延迟与算力，而收益主要归于系统或其他智能体；这种"成本自担、收益外溢"的结构在多智能体 LLM 部署中是核心安全问题。
- **理论定位**：与囚徒困境、公共品博弈、序贯社会困境等合作博弈互补，本论文专门分离"私有的信息获取努力"与"公有的信息使用"，用于操作化隐藏行动结构。

## 2. 方法论

### 2.1 对话式道德风险博弈（Dialogue Moral Hazard Game）

- **核心思想**：将隐藏行动结构离散化为二元博弈，智能体可选择"保留本地奖励"或"支付查询成本揭示另一智能体案例的隐藏不安全选项"。
- **博弈结构**：$n$ 个智能体按有向环排列，$\sigma(i) = (i \bmod n) + 1$；每个智能体拥有自己的案例 $i$，其中存在一个隐藏的不安全选项 $h_i \in A_i$，仅能由前驱 $\sigma^{-1}(i)$ 通过查询揭示。
- **博弈流程**（四阶段）：
  1. **观察阶段（observation）**：智能体看到自己的案例与收益契约。
  2. **工作阶段（work）**：选择 $e_i \in \{0, 1\}$，$e_i=1$ 支付成本 $k$ 揭示 $h_{\sigma(i)}$；$e_i=0$ 改为回答本地公开问题。
  3. **记录阶段（note）**：查询方可在公共板发布 `NOTE CASE <ID> UNSAFE <OPTION>`，可匿名或带出处。
  4. **最终阶段（final）**：每个智能体在观察公共板后为自己的案例选择最终动作。
- **奖励函数**：综合得分采用

$$R_{\text{game}} = w_L \cdot \frac{1}{n}\sum_{i=1}^n L_i + w_F \cdot \frac{1}{n}\sum_{i=1}^n F_i + w_T \cdot T - k \cdot \frac{1}{n}\sum_{i=1}^n Q_i$$

其中主设置权重 $(w_L, w_F, w_T, k) = (0.35, 0.15, 0.50, 0.10)$，$T = \prod_{i=1}^n \mathbb{1}[a_i = a_i^*]$ 为全员团队成功指标。
- **六维行为分解**：避免"查询频率"或"聚合成功率"被当作充分证据，论文单独报告：本地奖励保留、查询率、实现的信息传递、不安全选择、格式有效性、团队成功。

### 2.2 构造与理论有效性

- **自主激励扫描**：保持完整 query–warning–decision 链路，分别扫描查询成本 $k$、团队奖励 $w_T$、群体规模 $n$。理论预测查询成本阈值 $k^* = w_F + w_T - w_L = 0.30$，团队奖励阈值 $w_T^* = w_L + k - w_F = 0.30$。
- **私人份额激励隔离实验**：脚本化所有伙伴行为，将焦点智能体的私人收益写为

$$U_i = w_L L_i + w_F F_i + n\alpha_i w_T T - k Q_i$$

从而焦点决策的边际差简化为

$$m_i \equiv U_i(\text{QUERY}) - U_i(\text{LOCAL}) = n\alpha_i w_T - w_L - k$$

得到 Holmström 风格的私人无差异边界

$$\alpha^*(k) = \frac{w_L + k}{n\, w_T}$$

在 $n=2, w_L=0.35, w_T=0.50$ 下即 $\alpha^*(k) = 0.35 + k$。

### 2.3 四类诊断式更新机制

- **监督微调（SFT）**：脚本化教师演示，对查询成本、团队奖励、群体规模、出处是否匿名进行多样化，最小化

$$L_{\text{SFT}}(\phi) = -\mathbb{E}_{(x, y^*) \sim D_{\text{SFT}}}[\ell_\phi(y^* \mid x)]$$

- **RLOO（REINFORCE Leave-One-Out）**：REINFORCE 风格策略梯度，使用留一法基线，奖励包含结构化有效性 0.05、推理结构 0.10、目标动作精确匹配 0.85：

$$L_{\text{RLOO}}(\phi) = -\mathbb{E}_x\!\left[\frac{1}{K}\sum_{j=1}^K \hat{A}_j\, \ell_\phi(y_j \mid x)\right] + \beta\, \mathbb{E}_x[D_{\text{KL}}(p_\phi \| p_{\text{ref}})]$$

- **顺序式 SFT + RLOO**：以 SFT 适配器初始化，再进行 RLOO。
- **GEPA 提示优化**：通过 DSPy 搜索自然语言提示，最大化

$$q^* = \arg\max_{q \in Q}\, \frac{1}{|D_{\text{val}}|}\sum_{x \in D_{\text{val}}} R_{\text{game}}(x, y_q(x))$$

只接受标量分数与脱敏执行轨迹作为反馈。所有更新机制采用 LoRA 适配器：

$$W_\phi = W + \alpha \frac{B A}{r}$$

其中 $W$ 冻结，$A, B$ 为可训练低秩矩阵，训练信号对理论信息"blind"。

  - 团队奖励扫描 $w_T \in \{0.00, 0.20, 0.30, 0.40, 0.50, 0.80, 1.00\}$。
  - 群体规模扫描 $n \in \{2,3,\dots,9\}$。
- **激励隔离实验**：67 个 $(k, \alpha_i)$ 单元，9 个查询成本，每个 $k$ 下扫描 7–9 个 $\alpha_i$ 等级。
- **基线对照**：每个开源模型 3 个模型运行种子，GPT-5.6 Sol 3 个外部 API 采样复制。
- **统计诊断**：非参数 bootstrap 置信区间、配对符号翻转精确检验、配对标准化效应 $d_z$、Holm 与 Benjamini–Hochberg 多重校正、留一模型敏感性分析、1,000 次蒙特卡洛随机对照重采样。
- **充分性评价**：
  - 优势：实验设计具有理论预测 + 多角度扫描 + 统计多重校正的多层结构；并通过激励隔离实验直接将 LLM 行为与 Holmström 边界对照，平均绝对误差仅 0.013（最大 0.020）。
  - 局限：开源权重模型限于 4B–9B；GPT-5.6 Sol 仅有 1 个 GEPA 种子；群体规模扫描未观察到单调"大团队偷懒"现象；权重级与提示级更新机制可能存在未观察的提示敏感性。

## 6. 主要结论与发现

- **基线能力分化明显**：GPT-5.6 Sol 在主设置下达到 100% 查询率、100% 信息传递、100% 团队成功、0% 不安全选择，构成"可解性上限"。开源模型中 Qwen3-4B 表现最好（团队成功 21.3%），其余多数"保留本地奖励"或"查询但未传递有效信息"。
- **自主行为对激励敏感**：GPT-5.6 Sol 的查询率随 $k$ 上升（$k=0.15$ 时 98.9% → $k=0.40$ 时 4.4%）单调下降；随 $w_T$ 上升（$w_T=0.20$ 时 0% → $w_T=0.50$ 时 100%）单调上升；行为断点与理论预测一致。
- **激励隔离实验验证机制**：GPT-5.6 Sol 的经验查询阈值在 9 个 $k$ 下均跟踪 Holmström 边界，平均绝对误差 0.013；在边界下方几乎从不查询，边界上方总是查询，恰好无差异时为 68.9%。
- **权重级更新效应异质**：
  - OLMo-7B 出现最清晰的机制一致性改进：团队成功从 1.2% → 38.8%（SFT+RLOO），同时查询率 76.9% → 96.1%、信息传递 11.2% → 62.0%、不安全选择 62.0% → 22.0%。
  - RLOO 单独使用对所有模型几乎无影响（平均变化 0.0pp）。
  - Qwen3-4B 在 SFT 下反而退化（-20.1pp）。
  - 留一模型敏感性显示"最佳权重更新"效应主要由 OLMo-7B 驱动；移除后均值由 +6.3pp 降至 +1.1pp。
- **GEPA 可通过捷径提升聚合得分**：GEPA 平均带来 +9.4pp 团队成功（精确 $p=0.031$，但 BH 校正 $q=0.391$），但 OLMo-7B 和 Qwen3-4B 在团队成功提升的同时查询率显著下降；Qwen3-4B 的优化提示"从不查询，依靠公开效用启发式推断安全"，完全绕开了被测的合作机制。
- **核心方法论结论**：聚合奖励（团队成功）的提升不等同于"代价性合作机制"的恢复；评估应同时报告机制级行为。

## 7. 优点

- **理论-行为对齐**：将 Holmström 团队道德风险模型离散化为二元博弈，使私人-社会激励不等式可在不假设线性生产函数的条件下直接检验。
- **行为分解设计**：六维分解（查询、信息传递、本地奖励、不安全选择、格式有效性、团队成功）避免将频率与机制完成混淆。
- **两层级构造有效性论证**：
  - 自主激励扫描 + 理论断点预测；
  - 脚本化伙伴激励隔离实验，将 LLM 行为与 Holmström 边界直接对照（$k$ 与 $\alpha_i$ 的二维扫描、3015 次决策）。
- **多诊断更新机制**：同时检验权重级（SFT / RLOO / SFT+RLOO）与提示级（GEPA）优化，便于区分"机制恢复"与"奖励作弊"。
- **统计严谨性**：使用配对符号翻转精确检验、Bootstrap 置信区间、多重比较校正、留一模型敏感性分析，并对 GEPA "无查询捷径"提供了可读的优化后提示作为定性证据。
- **相关性诊断**：实现的信息传递与团队成功相关性最强（Pearson $r=0.96$），查询率次之（$r=0.63$），不安全选择与之负相关（$r=-0.71$），与隐藏行动机制一致。
- **透明性**：附录给出完整随机对照解析期望、Monte Carlo 验证、所有提示与超参数，并承诺公开代码与提示优化产物。

## 8. 不足与局限

- **覆盖范围有限**：
  - 仅评估 4B–9B 开源模型，未覆盖更大规模开源系统；
  - GPT-5.6 Sol 受 API 限制无法匹配 LoRA 更新，仅有 1 个 GEPA 种子，未参与配对权重级检验；
  - 群体规模扫描未能证实"大团队偷懒"的单调预测，仅证明协议在大 $n$ 下仍可执行。
- **奖励聚合局限**：所有-or-无团队奖励 $w_T=0.5$ 不提供查询或记录的边际信用，可能弱化对努力行为的精细区分。
- **机制恢复 ≠ 奖励提升的混淆**：论文承认 OLMo-7B 的明显改进依赖单一模型，Qwen

- **机制恢复 ≠ 奖励提升的混淆**（续）：OLMo-7B 的明显改进依赖单一模型，Qwen3-4B 在 SFT 下反而退化（−20.1pp），Qwen3.5-9B 在 RLOO 下退化（−7.2pp），说明权重级更新对不同基座能力的不均衡效应，且 SFT 训练分布的多样性可能在某些模型上覆盖了有效的自主推理路径。
- **学习信号盲性**：训练信号对理论信息"blind"，更新机制并未显式激励 $\alpha^*(k)$ 边界行为，因此它们究竟通过何种内部表征恢复合作仍是黑箱。
- **统计功效不均**：GPT-5.6 Sol 仅 1 个 GEPA 种子使其与开源模型的配对比较缺乏对称性；某些单元格的样本量在多重校正后不足以检测中小效应。
- **仅评估英文语境**：所有提示、案例、推理均以英文书写，未检验多语言或文化差异下合作规范的差异。
- **静态快照评估**：所有评估为单轮多智能体博弈，未覆盖真实部署中的迭代对话、记忆、工具调用、长程依赖等动态特性。
- **仅覆盖二元工作决策**：真实隐藏行动空间通常连续或高维，论文的 $\{0,1\}$ 离散化虽便于理论对照但限制了外部效度。

## 9. 启示与展望

- **对多智能体 LLM 部署安全的启示**：单智能体对齐评估不足以预测多智能体部署中的行为；必须在团队产出契约下重新评估成本—收益结构。
- **对合作机制设计的启示**：高风险多智能体 LLM 系统可能需要重新分配团队产出份额 $\alpha_i$、引入边际信用、提供透明公共板，使合作的私有激励与社会激励一致。
- **对评估协议的启示**：聚合指标（成功率、得分）可能掩盖代价性合作的失败；评估应同时报告机制级行为分解（查询、传递、警告）以检测"无机制成功"。
- **未来研究方向**：
  - 将博弈扩展到连续努力空间与多步隐藏行动；
  - 纳入记忆、工具调用、检索增强智能体下的隐藏行动建模；
  - 研究多语言与跨文化合作规范；
  - 探索更精细的边际信用分配机制（如 Shapley 值风格的产出份额）；
  - 设计"代价性合作基准测试"作为多智能体安全评估的标准组件。

## 10. 总体评价

本论文将 Holmström 团队道德风险模型创造性地离散化为多智能体 LLM 博弈，提供了迄今最为严格的"隐藏行动"可操作化定义。其核心贡献在于：(1) 通过 **自主激励扫描 + 脚本化激励隔离**两层构造有效性论证，将 LLM 行为与经济学理论的精确边界（$\alpha^*(k)$）直接对照；(2) 通过 **六维行为分解**，避免将聚合得分的提升误读为代价性合作的恢复；(3) 通过 **多诊断更新机制**（SFT/RLOO/SFT+RLOO/GEPA）系统比较权重级与提示级优化的效果差异，揭示了 GEPA 可通过"无查询捷径"提升聚合得分的方法论陷阱。

论文的实验设计在理论预测、多角度扫描、统计多重校正上具有较高严谨性，但在模型覆盖范围（4B–9B + 单一前沿 API）、奖励聚合粒度（全员 all-or-nothing）、学习信号盲性上仍有明显局限。整体而言，本工作既是 **多智能体 LLM 安全评估方法论** 的重要进展（提出"机制级评估"取代"聚合评估"的范式），也是 **对齐与博弈论交叉** 的可复用模板，对任何涉及代价性合作的多智能体系统设计具有直接参考价值。
