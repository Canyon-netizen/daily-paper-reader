## 摘要
大型视觉语言模型（VLMs）如今在交互式环境中充当智能体，要在多轮交互中实现成功，需要在轮次之间进行连贯的推理与决策。尽管在智能体环境中进行端到端训练能够提升这种多轮决策能力，但现有方法主要依赖于对拼接后的 token 轨迹进行 token 级优化，或采用轮内均匀信用分配的轮级优化。在本文中，我们为这两个层级的优化建立了理论公式，并推导出一种同时服务于两类目标的混合优势函数。此外，通过恰当选取折扣因子和学习目标，我们证明了统一的评论家模型能够同时估计轮级和 token 级的价值。由此，我们提出了 HyGAE——一种结合混合优势与统一评论家、联合优化 token 级与轮级目标的 actor-critic 框架。我们在五个多轮决策环境中对 HyGAE 进行了广泛评估，其平均成功率高达 91%，相对其他方法取得了 10% 的显著提升。此外，我们还进行了深入分析，表明混合优势与回报的精确解析形式对优化至关重要。项目主页：https://wx-zhang.github.io/hygae-web/。

## Abstract
Large Vision-Language Models (VLMs) now act as agents in interactive environments, where success requires coherent reasoning and decision-making across turns. Although end-to-end training in agentic environments can improve such multi-turn decision-making abilities, current methods mainly rely on either token-wise optimization over concatenated token trajectories or turn-wise optimization with uniform within-turn credit. In this work, we establish theoretical formulations for the two levels of optimization and derive a hybrid advantage that serves both objectives. Furthermore, with an appropriate choice of discount factor and learning target, we prove that a unified critic model can estimate values for both turn-wise and token-wise. As such, we propose HyGAE, an actor-critic framework that jointly optimizes token- and turn-level objectives with the hybrid advantage and unified critic. We conduct extensive evaluations of HyGAE across five multi-turn decision-making environments, where it achieves an average success rate of 91% and a significant improvement of 10% over other methods. Furthermore, we provide an in-depth analysis showing that the exact analytic form of the hybrid advantage and return is crucial for optimization. Project Page: https://wx-zhang.github.io/hygae-web/.

**研究动机**：大型视觉语言模型（VLM）正越来越多地被部署为交互式环境中的智能体，需要在多轮交互中保持连贯的推理与决策。然而，现有 VLM 普遍存在"短视"问题——它们往往仅基于最当前观察进行推理，忽略历史动作与反馈，导致重复输出无效动作、缺乏长程规划能力。

**核心矛盾**：现有 VLM 智能体的端到端强化学习训练主要遵循两种范式，二者各有局限：
- **Token 级优化**（如 Token-PPO）：将每个 token 视为独立动作，可提供细粒度的生成指导，但环境奖励的折扣在长文本生成中会被过度累积。
- **Turn 级优化**（如 Turn-PPO/RL4VLM）：将整个轮次视为一个宏观动作，便于利用轮级反馈，但丢弃了 turn 内的细粒度 token 信用分配信号，影响自回归生成的稳定性。

**整体含义**：本文试图弥合二者的割裂，从理论上揭示 token 级与 turn 级优化的内在联系，并提出统一的双层级优化框架。

## 2. 方法论

### 2.1 核心思想

HyGAE（**Hy**brid **G**eneralized **A**dvantage **E**stimation）框架包含三大核心组件：

1. **混合优势估计（Hybrid Advantage）**：将 turn 级优势与 token 级优势以线性组合方式融合，单一 surrogate 函数同时优化两个层级的目标。
2. **统一评论家（Unified Critic）**：通过特定折扣因子设置，使一个价值模型可同时估计 turn 级和 token 级价值，避免双 critic 的计算开销。
3. **精确的混合回报（Hybrid Return）**：通过将 turn 级回报广播至 turn 内每个 token 位置并叠加折扣奖励，构建稳定的价值学习目标。

### 2.2 理论框架

**Token 级与 Turn 级 POMDP 形式化**：

在 turn $t$，VLM 生成 token 序列 $\mathbf{a}_t = (a_t^1, a_t^2, \ldots, a_t^{I_t})$，token 级奖励定义为：

$$r_t^i = \begin{cases} r_t, & i = I_t \\ 0, & \text{otherwise} \end{cases}$$

**关键定理 1（梯度等价性）**：当 turn 级与 token 级折扣因子满足 $\gamma_t = \gamma^{I_t}$ 时，对任意 $\alpha \in [0,1]$：

$$\nabla J(\theta) = \nabla L_{\text{hybrid}}(\theta) = \nabla L_{\text{turn}}(\theta) = \nabla L_{\text{token}}(\theta)$$

这意味着混合优化方向与原目标梯度一致，理论上有保证。

**关键定理 2（价值一致性）**：在相同折扣条件下，turn 级价值与 token 级轨迹末位价值相等：

$$V^{\pi}(\tau_t) = V^{\pi}(\tau_{I_t}^{t})$$

因此无需为两个层级分别训练 critic。

### 2.3 混合优势与回报

**混合优势**：

$$\widehat{A}_t^i = \alpha \widehat{A}_t + (1-\alpha) \widehat{A}_t^i, \quad \alpha \in [0,1]$$

其中 $\widehat{A}_t$ 为 turn 级优势（GT 推算常量），$\widehat{A}_t^i$ 为 token 级优势。

**混合回报**（用于 Critic 学习）：

$$\widehat{G}_t^i = \alpha \widehat{G}_t^{i,(\text{turn})} + (1-\alpha) \widehat{G}_t^{i,(\text{token})}$$

Turn 级回报通过下式广播至 turn 内每个 token：

$$\widehat{G}_t^{i,(\text{turn})} = \widehat{A}_t + \sum_{k=i+1}^{I_t} \gamma^{k-i} r_k + \widehat{V}_{\psi}(\tau_t)$$

### 2.4 偏差-方差分析

**定理 3（偏差）**：turn 级估计偏差 ≤ token 级估计偏差（$b_{\text{turn}} \leq b_{\text{token}}$）。

**定理 4（方差）**：turn 级估计方差 > token 级估计方差（$v_{\text{turn}} > v_{\text{token}}$）。

这从理论上证明混合策略自然地平衡了偏差-方差权衡。

### 2.5 算法流程

算法采用 PPO 风格训练，policy 损失为：

$$\widehat{L}_{\text{hybrid}}(\theta) = \mathbb{E}\left[\sum_{t=0}^{T-1}\sum_{i=0}^{I_t-1} \min\left(\rho_t^i(\theta)\widehat{A}_t^i,\ \text{clip}(\rho_t^i(\theta), 1-\epsilon, 1+\epsilon)\widehat{A}_t^i\right)\right]$$

完整流程见 Algorithm 1（外部循环 → 轨迹收集 → turn/token 优势计算 → 价值学习目标构造 → PPO 更新）。
