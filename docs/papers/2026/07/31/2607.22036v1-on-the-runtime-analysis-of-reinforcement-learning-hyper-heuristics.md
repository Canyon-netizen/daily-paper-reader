tldr: 选择型超启发式算法通过从底层启发式中挑选算子来自动设计优化流程，但现有理论工作多采用简化的学习机制。研究分析了文献中的强化学习超启发式 RLHH，证明当参数设置合适时，配合 RLS_1 与 RLS_2 两个随机局部搜索算子，它在 LeadingOnes 函数上能达到与固定使用最优算子相同的期望运行时间。实验显示在实际问题规模下，其表现优于此前已知具有最优期望运行时间的广义随机梯度超启发式 GRG-HH。

## 摘要
选择超启发式算法（HHs）通过在优化过程的每个阶段从一组底层启发式算法中选择一个来应用，从而实现算法设计的自动化。近期已有若干重要结果严格证明了选择超启发式算法在标准基准函数上的性能。然而，这些超启发式算法所使用的学习机制相比真实应用中典型的机器学习技术已被大幅简化。本文分析了文献中的一种强化学习超启发式算法（RLHH）。此前唯一可获得的结果证明，在广泛的参数设定范围内，RLHH 未能学会针对标准 LeadingOnes 基准函数恰当地选择启发式算法。在本文中，我们严格证明：采用合适的参数值，并配备两个随机局部搜索算子 RLS_1 和 RLS_2 的 RLHH，能够以这两个算子在忽略低阶项意义下所能达到的最优期望运行时间优化 LeadingOnes 基准函数。实验表明，对于现实规模的测试问题，其速度优于此前已被证明同样在忽略低阶项意义下具有最优期望运行时间的广义随机梯度超启发式算法。

## Abstract
Selection Hyper-heuristics (HHs) automate algorithmic design by selecting from a set of low-level heuristics which one to apply at each stage of the optimisation process. Several impressive results have been recently rigorously proven regarding the performance of selection hyper-heuristics (HHs) for standard benchmark functions. However, the learning mechanisms employed by these HHs are considerably simplified compared to the machine learning techniques typically used in real world applications. In this paper we analyse a Reinforcement Learning Hyper-heuristic (RLHH) from the literature. The only previous result available proved that for a wide range of parameter settings, RLHH does not learn to select heuristics appropriately for the standard LeadingOnes benchmark function. In this paper, we rigorously prove that with appropriate parameter values RLHH equipped with two random local search operators, RLS_1 and RLS_2 optimises the LeadingOnes benchmark function in the best possible expected runtime achievable with the two operators up to lower order terms. Experiments show that for realistic problem sizes it is faster than the Generalised Random Gradient HH which was previously proven to also have optimal expected runtime up to lower order terms.

- **参数设计精细**：$\alpha = 1 + 1/\log n$ 与 $\beta = 1/n$ 的设置，使 RLS$_1$ 的期望权重漂移恰好处于"中性"附近，从而其他更优算子能够获得更大的权重增长，体现对 RLHH 动力学的深刻理解。
- **实验规模宏大**：问题规模达 $n = 9 \times 10^9$，并使用逆变换采样，使得对超大问题的实证成为可能。
- **清晰的两阶段结构**：将优化过程按 $i = n/2$ 划分为两个阶段，对应算子优势的相变，分析简洁明了。

## 8. 不足与局限

- **基准函数单一**：仅分析 LeadingOnes，未涉及 OneMax、Jump、Cliff、TwoRates 等其他标准基准，对 RLHH 的普适性论据有限。
- **算子集合受限**：仅使用 $\{RLS_1, RLS_2\}$ 两个 RLS 类算子；论文指出未来需扩展到更大的算子集合（如 GRG 中 $|H| = O(1)$）。
- **参数限制**：理论上 $\gamma < 1$ 才能严格保证 $w_1 = o(w_{\max})$；虽然实践中 $\gamma = 1.0$ 表现良好，但缺少对 $\gamma = 1.0$ 的严格证明。
- **学习机制单一**：仅分析加性权重更新与轮盘赌选择两种机制；其他文献中使用的**乘法更新**、**最大权重选择（max choice）**等机制未被覆盖。
- **实验仅 1 个函数**：与对比方法（GRG、MAHH 等已有多个基准上的完整分析）相比，RLHH 的实证广度不足。
- **可解释性局限**：权重动态的分析依赖多个复杂的辅助引理（Lemma 1–8），后续工作难以直接复用或扩展。
- **应用层面缺失**：虽然强化学习 HH 在现实中被广泛用于调度、路径规划等问题，但本文完全停留在理论分析与合成基准上，未触及任何实际应用场景。
