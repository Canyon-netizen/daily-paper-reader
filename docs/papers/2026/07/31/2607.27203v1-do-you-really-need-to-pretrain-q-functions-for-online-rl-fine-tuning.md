## 摘要
预训练后微调已成为学习高性能策略的主流方法。在基于价值的强化学习（RL）中，这自然引出一个问题：给定一个预训练策略，是否也应该在离线数据上预训练 Q 函数？传统观点认为应该如此，但最近的研究结果表明，使用随机初始化的 Q 函数进行在线强化学习也能产生高性能且可靠的策略，无需预训练 Q 函数。在本文中，我们系统地研究了当在预训练的基础策略之上进行微调时，预训练 Q 函数是否真的有所帮助。我们惊讶地发现，朴素的 Q 函数预训练相比随机初始化往往只能带来很小的收益。我们表明这源于一个根本性的不匹配：预训练期间学到的 Q 函数针对的是预训练策略的 Q 函数，而不是在线微调收敛到的 Q 函数，并且即使经过离线价值最大化，这个差距仍然存在。受此发现的启发，我们提出了通过策略集成进行初始化（Initialization via Policy Ensemble, IPE），这是一种简单的方法，它训练多个多样化的策略，并利用它们汇集的回放数据来引导在线强化学习中的 Q 函数学习。在一系列具有挑战性的连续控制基准测试中，IPE 在微调性能上相比朴素的 Q 函数预训练平均实现了 1.26 倍的提升。

## Abstract
Pre-training followed by fine-tuning has become the dominant recipe for learning performant policies, and in value-based reinforcement learning (RL) this raises a natural question: given a pretrained policy, should the Q-function be pretrained on offline data too? Conventional wisdom suggests it should, but recent results show that online RL with a randomly-initialized Q-function can result in highly performant and reliable policies without needing to pretrain the Q-function. In this paper, we systematically study whether pretraining the Q-function actually helps when fine-tuning on top of a pretrained base policy. We find, surprisingly, that naive Q-function pretraining often provides little benefit over random initialization. We show this stems from a fundamental mismatch: the Q-function learned during pretraining targets the pretrained policy's Q-function, not the Q-function that online fine-tuning converges to, and this gap persists even after offline value maximization. Motivated by this finding, we propose Initialization via Policy Ensemble (IPE), a simple method that trains multiple diverse policies and uses their pooled rollouts to bootstrap the Q-function learning in online RL. Across a suite of challenging continuous control benchmarks, IPE yields an average 1.26x improvement in fine-tuning performance over naive Q-function pre-training.

## 1. 核心问题与整体含义

- **研究背景**：预训练–微调已成为学习高性能策略的主流范式，广泛应用于大语言模型与机器人（如视觉-语言-动作 VLA 模型）。在基于价值的强化学习（RL）中，当已有预训练策略时，一个自然而关键的问题是：是否也应该在离线数据上预训练 Q 函数？
- **传统观点与最新证据的冲突**：传统离线到在线 RL 工作通常联合预训练策略与 Q 函数；但近期研究表明，仅以预训练策略 + 随机初始化的 Q 函数进行在线微调，也能取得高性能甚至更稳定的表现。
- **本文聚焦问题**：在仅给定一个固定预训练策略（不要求与离线 RL 算法联合训练）的前提下，系统性地考察 Q 函数预训练是否真正能提升在线 RL 微调的样本效率与最终性能，并解释为何朴素预训练常常无效。
- **核心动机**：揭露朴素 Q 函数预训练与在线 RL 收敛目标之间存在根本错位，并提出改进策略。

## 2. 方法论

### 2.1 问题形式化

- 环境建模为 MDP $\{\mathcal{S}, \mathcal{A}, \rho, r, \gamma, T\}$，目标是最大化折扣累积回报 $\mathbb{E}_\pi\left[\sum_{t=0}^{T}\gamma^t r(s_t, a_t)\right]$。
- 给定预训练基础策略 $\pi_{\text{base}}$（通过监督学习得到）和离线数据集 $\mathcal{D}_{\text{offline}}=\{(s,a,r,s')\}$，研究如何预训练 Q 函数 $Q_\phi$ 以提升在线微调表现。
- 使用 **EXPO** 作为离策略 RL 微调算法：维护基础流策略 $\pi_{\text{base}}$ 与轻量"编辑策略" $\pi_{\text{edit}}$，后者最大化：

$$L(\pi_{\text{edit}}) = -\mathbb{E}_{(s_t,a_t)\sim\mathcal{D},\,\hat{a}_t\sim\pi_{\text{edit}}}\left[Q_\phi(s_t, a_t+\hat{a}_t) - \alpha\log \pi_{\text{edit}}(\hat{a}_t\mid s_t, a_t)\right]$$

- 在线推理采用"即时最优动作"（On-the-Fly, OTF）策略，从 $N$ 个采样动作中选取 Q 值最大者：

$$\tilde{a}^* = \arg\max_{a\in\{a_i, \tilde{a}_i\}_{i=1}^N} Q_\phi(s, a)$$

### 2.2 关键诊断：Q 函数错位

- 引入 **偏好准确率（preference accuracy）**：衡量学习到的 Q 函数将 $\pi^*$ 动作排在 $\pi_{\text{base}}$ 动作之前的比例。
- 实验发现（即便 $\pi_{\text{base}}$ 训练至接近 100% 成功率）：

$$Q^{\pi_{\text{base}}} \neq Q^{\pi^*_{\text{RL}}}$$

即离线预训练的 Q 函数收敛到的目标 $Q^{\pi_{\text{base}}}$，与在线微调最终需要的 $Q^{\pi^*_{\text{RL}}}$ 不同。

- **三种离线价值最大化补救手段均无效**：
  1. 学习 EXPO 的编辑策略；
  2. 在 $\pi_{\text{base}}$ 上蒸馏一步最大化 Q 值的策略（Max Q + BC loss）；
  3. 直接对 $\pi_{\text{base}}$ 做动作梯度优化。
- 三者均无法拉近 $Q^{\pi_{\text{base}}}$ 与 $Q^{\pi^*_{\text{RL}}}$ 之间的距离，偏好准确率与最终性能均无提升。

### 2.3 IPE（Initialization via Policy Ensemble）算法

- **核心思想**：单一预训练策略产生的动作分布过于狭窄，导致 Q 函数退化为 $Q^{\pi_{\text{base}}}\approx V^{\pi_{\text{base}}}$。通过对同一行为分布训练 $N$ 个多样化策略，并汇集它们的环境回放，可以扩展 Q 函数对状态-动作空间的覆盖。
- **算法流程**（Algorithm 1）：
  1. 输入离线数据 $\mathcal{D}_{\text{offline}}$ 与基础策略 $\pi_{\text{base}}$；
  2. 训练 $N$ 个附加策略 $\{\pi_i\}_{i=1}^N$（监督学习，可使用相同或不同子集数据、不同随机种子）；
  3. 初始化回放缓冲区 $\mathcal{D}\leftarrow \emptyset$；
  4. 对每个策略 $\pi\in\{\pi_{\text{base}},\pi_1,\dots,\pi_N\}$ 进行环境回放，将转移 $(s,a,r,s')$ 加入缓冲区；
  5. 输出扩充后的缓冲区供在线 RL 使用。
- 当 $N=0$ 时退化为标准的在线 RL 预热阶段。

## 3. 实验设计

- **任务基准**：
  - **Robomimic**：lift-ph、can-mh、square-ph（7 自由度机械臂操作）；
  - **OGBench**：cube-double-singletask-task2-v0、scene-singletask-task2-v0、puzzle-4x6-singletask-task2-v0（含长视野组合推理）。
- **基础 RL 算法**：EXPO，并附加验证 **RLPD**（附录 A）。
- **对比基线**：
  1. 朴素 Q 函数预训练 + 在线微调；
  2. 随机初始化 Q 函数 + 在线微调；
  3. IPE（论文提出的方法）；
  4. 多种离线价值最大化变体作为补救（EXPO edit 策略、Max Q+BC、Q 动作梯度）。
- **训练配置**：update-to-data ratio（UTD）为 1（主实验），附录额外验证 UTD=20。
- **评估指标**：成功率随微调步数变化曲线；偏好准确率（preference accuracy）；Q 函数方差。
- **Q 函数训练目标**：标准 TD 学习

$$L(\phi) = \mathbb{E}_{(s_t,a_t,s_{t+1})\sim\mathcal{D}}\left[\left(r_t + \gamma Q_{\phi'}(s_{t+1},\tilde{a}^*_{t+1}) - Q_\phi(s_t,a_t)\right)^2\right]$$

## 6. 主要结论与发现

- **结论 1**：朴素 Q 函数预训练对在线 RL 微调几乎没有帮助，甚至在某些任务上损害性能；这与"预训练越多越好"的直觉相悖。
- **结论 2**：根源在于目标错位——预训练收敛到 $Q^{\pi_{\text{base}}}$，而在线微调需要 $Q^{\pi^*_{\text{RL}}}$，二者即使在 $\pi_{\text{base}}$ 近最优时仍不一致。
- **结论 3**：离线价值最大化（编辑策略蒸馏、Max Q+BC、动作梯度）无法缩小该错位，必须依赖在线交互。
- **结论 4**：单一策略的动作覆盖不足，导致 Q 函数坍缩为 $V^{\pi_{\text{base}}}$；通过 IPE 训练多个多样化策略并汇集回放，可显著提升 Q 函数对状态-动作空间的覆盖。
- **结论 5**：IPE 在六个连续控制任务上相对朴素 Q 函数预训练平均带来 **26%（即 1.26×）的性能提升**，并随 $N$ 增大而单调改善（$N=5$ 时最佳）。

## 7. 优点

- **问题新颖且具现实意义**：首次系统性地质疑在线 RL 微调中 Q 函数预训练的必要性，对当前 VLA 模型在线微调范式有直接指导意义。
- **诊断深入透彻**：从偏好准确率、Q 函数方差、动作多样性等多角度剖析失败原因，定位到"目标错位"这一根本机制。
- **方法简洁实用**：IPE 不需修改 RL 算法本身，仅在数据回放阶段引入多样化策略，工程成本低。
- **实验设计较为公平**：共享同一基础策略、同一 RL 算法，仅切换 Q 函数初始化方式，排除算法层面的混淆变量。
- **消融与扩展性研究完整**：包含 $N$ 数量、UTD 比、不同算法（EXPO、RLPD）下的验证。

## 8. 不足与局限

- **离线数据利用率不足**：IPE 需要额外对多个策略做环境回放，带来额外数据采集开销；论文明确承认这是局限并留作未来工作。
- **任务规模受限**：所有实验集中在"小规模"预训练策略，未在真正的 VLA 模型（如 π0.5、π*0.6）上验证，限制了结论在大模型场景下的可推广性。
- **算法覆盖不足**：仅考察离策略方法（EXPO、RLPD），未在 on-policy 方法（如 PPO）下验证其结论。
- **种子数较少**：每设定仅 3 个随机种子，统计显著性证据偏弱，且附录中部分实验（如 RLPD UTD=20）展示略显粗糙。
- **理论分析薄弱**：未提供关于"为何 $Q^{\pi_{\text{base}}}\neq Q^{\pi^*_{\text{RL}}}$"的形式化理论刻画（如收敛性、误差上界），主要依赖实证。
- **可解释性局限**：IPE 的成功被归因于"动作覆盖更广"，但未定量刻画"覆盖到何种程度足以桥接错位"，缺乏更精细的准则。
- **应用范围**：聚焦连续控制机械臂操作任务，对其他领域（如自动驾驶、游戏、推荐系统）的适用性未探讨。
