## Abstract
Training large language models (LLMs) to act in long-horizon games is a promising step toward generalist decision-making, yet reinforcement learning with verifiable rewards (RLVR) relies on sparse final rewards that reveal little about which decisions determine success. Denser process signals could supply this missing turn-level credit, but existing sources are hard to keep both cheap and accurate. We observe that changes in a game solver's state value reveal whether an action advances the state toward success. Building on this insight, we propose CAST (Credit Assignment from Solver Teachers), which converts these value changes into solver advantages and injects them into RLVR as turn-level signals. We further show that, under a soft-optimal solver assumption, maximizing the solver advantage is equivalent to on-policy distillation from the solver, requiring only scalar values rather than teacher logits. Across Sokoban, Minesweeper, and Rush Hour, CAST outperforms all trained baselines on every game under both in-domain and unseen-difficulty evaluation and achieves the highest average zero-shot performance on ALFWorld and WebShop. Our code is available at https://github.com/Wloner0809/CAST.

## 二、方法论

### 2.1 问题形式化

- 将博弈建模为有限视野 MDP：$M = (S, A, P, r, H)$
- 奖励稀疏且可验证：$r_t = 0\ (t < T),\ R(\tau) = r_T = \mathbb{1}\{s_T \in S_{\text{solved}}\}$

$$\hat{A}^{\text{outcome}}_i = \frac{R_i - \mu_R}{\sigma_R + \delta}$$
同一轨迹内所有回合共享同一信用，导致回合级信号缺失。

### 2.2 求解器作为回合级教师

- **求解器状态值**：定义 cost-to-go $N(s)$（Sokoban/Rush Hour 为最短动作数，扫雷为最少揭示数），令 $V^{\pi_{\text{Solver}}}(s) = -N(s)$
- **Q 与优势**：
$$Q^{\pi_{\text{Solver}}}(s_t, a_t) = -1 + \mathbb{E}_{s_{t+1}}\left[V^{\pi_{\text{Solver}}}(s_{t+1})\right]$$
$$A^{\pi_{\text{Solver}}}(s_t, a_t) = -1 + N(s_t) - \mathbb{E}_{s_{t+1}}\left[N(s_{t+1})\right]$$
- **偏移后的求解器优势**（使"推进一步"对应正值）：
$$\tilde{A}^{\pi_{\text{Solver}}}(s_t, a_t) = N(s_t) - \mathbb{E}_{s_{t+1}}\left[N(s_{t+1})\right]$$
最优动作为 $+1$，无效动作为 $0$，有害动作为负；进入死局时封顶为 $-N(s_t)$。

### 2.3 信号整形（稳定化）

- **asinh 压缩**：
$$g(x) = \text{asinh}(x) = \ln\left(x + \sqrt{x^2 + 1}\right)$$
在小信号区近线性、对极端值仅对数增长，保留正负号。
- **批次 RMS 归一化**：
$$h(x) = \frac{g(x)}{\text{RMS}_B(g) + \epsilon}$$
跨博弈去除量纲差异，**不减均值**（保留"零=无进展"的语义）。
- **与 GRPO 结合**：
$$\hat{A}_{i,t} = \hat{A}^{\text{outcome}}_i + \alpha\, h\left(\tilde{A}^{\pi_{\text{Solver}}}_{i,t}\right)$$
轨迹级优势锚定最终胜负，过程信号逐回合细化，二者广播到 token 级。

### 2.4 与 On-Policy Distillation（OPD）的等价性（定理 2.1）

- **核心恒等式**（推论 C.5）：
$$A^{\pi_{\text{Solver}}}(s, a) = \tau \log \pi_{\text{Solver}}(a|s)$$
即单个标量优势已包含教师的对数偏好，**无需教师 logits**。
- **隐式目标**：
$$J(\theta) = \mathbb{E}_{s_0 \sim \mu}\!\left[V^{\pi_\theta}_{\text{task}}(s_0)\right] - \beta\, \mathbb{E}_{s \sim d^{\pi_\theta}}\!\left[H(\pi_\theta(\cdot|s),\, \pi_{\text{Solver}}(\cdot|s))\right]$$
其中 $\beta = \dfrac{\alpha\tau}{\sqrt{2}\,(\text{RMS}_B(g) + \epsilon)}$。
- **封闭最优策略**（推论 C.8）：
$$\pi^*(a|s) \propto \pi_{\text{Solver}}(a|s) \exp\!\left(\frac{1}{\beta} A^{\pi_\theta}_{\text{task}}(s,a)\right)$$
当 $\beta \to \infty$ 时退化为求解器本身；有限 $\beta$ 下任务优势可"倾斜"先验，使**学生可超越教师**。
- **性能提升保证**（PDL + 内生奖励整形）：次优界为 $O(H\epsilon_\pi)$，优于行为克隆的 $O(H^2\epsilon_\pi)$。

### 2.5 流程概述

冻结策略模型 → 多回合 rollout → 每步查询博弈求解器得到 $N(s_t), N(s_{t+1})$ → 计算偏移优势并整形 → 注入 GRPO 优势进行 PPO 风格截断更新。

## 三、实验设计

### 3.1 训练环境（数据集）

- **Sokoban**：ID $6\times 6$ / 2 箱；Unseen $7\times 7$ / 3 箱；求解器为加权 A\*。
- **Minesweeper**：ID $6\times 6$ / 7 雷；Unseen $7\times 7$ / 10 雷；求解器为约束满足 + 组合地雷概率推断。
- **Rush Hour**：ID $6\times 6$ / 7 车；Unseen $6\times 6$ / 9 车；求解器为多源反向 BFS 预计算 + IDA\* 回退。

每个 split 含 200 个去重且经求解器可解性验证的测试实例。

### 3.2 OOD 零样本基准

- **ALFWorld**（具身家庭任务，6 类标准任务）
- **WebShop**（500 条测试指令，匹配率作为成功判定）

### 3.3 基线对比

- **闭源提示法参考**：Gemini-2.5-Flash/Pro、Claude Sonnet-4.5/4.6、Claude Opus-4.5/4.6，全部走 ReAct 框架。
- **训练基线（共享 Qwen3-4B-Instruct-2507 主干）**：
  - 结果监督类：GRPO、GSPO、DAPO
  - 过程监督类：GiGPO（组内分组策略优化）
- **评估指标**：Avg@4（每实例 4 次 rollout 取平均成功率），3 个独立随机种子报告均值。

### 3.4 主实验结果概览

- **训练博弈内**：CAST 在三个游戏的 ID 与 Unseen 难度上均**取得所有训练方法中的最高 Avg@4**。相对 DAPO 主干（去掉求解器信号后）平均提升 ID +17.4、Unseen +9.7。
- **训练效率**：达到 DAPO 峰值验证性能所需的步数在 Sokoban/Minesweeper/Rush Hour 上分别减少 $1.7\times$、$2.0\times$、$1.7\times$。
- **零样本 OOD 迁移**：ALFWorld 域平均 37.9（+5.8 vs 最佳基线），WebShop 22.7（+4.8），Overall 30.3（+5.6）；附 WebShop 案例研究展示恢复与约束检查能力。
- **消融**：求解器权重 $\alpha$ 在 $0.1$ 最佳；去除 asinh 显著拖累；去除 RMS 归一化训练末期出现下降。
- **可替代求解器**：在 Rush Hour 上用 DQN 值网络替代精确求解器，性能与精确版本相近，且无明显晚期崩溃。

## 六、主要结论

- 博弈求解器的状态价值增量可以转化为**稳定、廉价、稠密**的回合级信用，显著缓解 RLVR 在长视野博弈中的信用分配难题。
- 在软最优假设下，该信号**等价于求解器的 on-policy distillation**，但只需标量 $N(s)$ 而**无需教师 logits**。
- CAST 在 Sokoban、Minesweeper、Rush Hour 三个互补挑战上**全面超越所有训练基线**；在未见难度与零样本 OOD 任务（ALFWorld、WebShop）上均取得最佳平均表现，且训练步数减少 $1.7$–$2.0\times$。
- 即使没有精确求解器，**DQN 学习到的值网络**也能保留绝大部分收益，证明方法不依赖手工求解器。
- 整体论证：**可靠的状态评估**（无论来自精确算法还是学习网络）是从稀疏终局奖励通往回合级信用的实用路径。

## 七、优点与亮点

- **方法层面**：首次把博弈求解器作为回合级教师注入 RLVR；建立与 OPD 的等价定理，绕开了 LLM 蒸馏对教师 logits 的依赖；通过 asinh + RMS 给出干净的理论支撑的整形方案。
- **实现层面**：求解器开销几乎可忽略（73 ppm），无需额外训练过程奖励模型或大规模搜索。
- **实验层面**：覆盖结果/过程监督两类基线、3 个互补博弈、ID + Unseen 难度 + 2 个零样本 OOD 基准，并附带定性案例；随机种子、EMA 平滑、Avg@4 评估降低方差。
- **理论层面**：定理 2.1 + 推论 C.8/C.10 + PDL 证明给出 $O(H\epsilon_\pi)$ 的次优界，超越行为克隆的 $O(H^2\epsilon_\pi)$，并解释"学生可超越教师"。

## 八、不足与局限

- **资源披露不全**：未明确报告 GPU 型号与数量、训练总时长、总 FLOPs 或训练 token 数，难以横向评估算力成本。
- **博弈域有限**：仅 3 个有可计算求解器的博弈；现实开放环境（网页、机器人、对话）中并非总能获得 cost-to-go，求解器可用性成为方法推广的主要瓶颈（论文虽以 DQN 近似回应，但仅在 Rush Hour 上验证）。
- **理论假设较强**：软最优与小信号假设依赖求解器近乎最优；当 $A^{\pi_{\text{Solver}}}$ 偏离 ±1 时需引入步级 $\beta_{\text{eff}}$ 修正，实践中可能放大估计噪声。
- **评估协议的潜在偏差**：所有比较均共享 Qwen3-4B-Instruct-2507 主干 + DAPO 优化器，对闭源模型仅做 ReAct 提示对比，公平性来自控制变量但仍有"框架/提示模板"层面的不对称；Avg@4 仅报告最终 checkpoint，未给出训练全过程置信区间。
- **DQN 替代求解器的实验仅在 Rush Hour** 完成，未在另外两个博弈上验证近似值网络的通用性。
- **零样本 OOD 仍依赖文本协议对齐**：ALFWorld/WebShop 与游戏共享相同的 ReAct 循环与单步动作接口，迁移便利性部分来自环境结构相似，未涵盖与游戏差异更大的具身或多模态任务。
- **未讨论鲁棒性与安全**：求解器被攻击或出错的场景、对抗性环境下的信用可靠性问题未被考虑。
