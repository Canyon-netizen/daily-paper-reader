## TL;DR

H²SD 针对强化学习与可验证奖励（RLVR）中监督信号稀疏、token 级信用分配不足的问题，创新性地提出按轨迹正确性分叉处理：成功轨迹沿用奖励方向但用教师概率调制更新幅度，失败轨迹则借助包含推理步骤的参考提示构造教师并最小化反向 KL 散度。在 Sudoku、Calcudoku、Arrow Maze 等逻辑推理基准上，H²SD 以 50.49% 的平均准确率大幅超越 GRPO（24.68%）、OPSD（24.01%）和 RLSD（24.85%）等基线，同时保持了稳定的训练动态和较高的生成效率。

## 研究背景与动机

以 GRPO 为代表的 RLVR 方法近年来在数学推理和代码生成任务上取得了显著进展，其核心思想是将可验证的标量奖励（如答案是否正确）分配给整条推理轨迹。然而，这种粗粒度的奖励机制带来了一个根本性的瓶颈：监督信号极度稀疏。在一条完整的推理链中，模型只能得知"最终答案对/错"这一二值信息，却无法区分链路上哪些中间步骤真正推动了正确结果、哪些 token 是冗余甚至误导性的。这种 token 级[[信用分配]]能力受限的问题，严重制约了模型在长链推理任务中的学习效率。

研究者们意识到这一点后，自然地尝试引入更密集的监督信号。同策略蒸馏（OPD）通过让更强的教师模型提供逐 token 的概率分布来指导学生模型，在分布层面实现精细化纠错。但 OPD 依赖外部强教师模型，且通常要求师生共享词表，在实际部署中存在诸多限制。同策略自蒸馏（OPSD）转而利用同一模型在特权信息（如正确答案或环境反馈）条件下的输出作为教师，从而摆脱了对外部模型的依赖。然而，直接让学生分布匹配教师分布会导致信息泄露：特权信息可能被隐式编码到 logits 中，使得学生模型在训练时过度依赖这些信息，训练动态变得不稳定。

RLSD 则采取了更为保守的策略——完全放弃分布级匹配，仅将教师信号用于调节 token 级的更新幅度，保留由奖励决定的方向不变。这种做法有效规避了信息泄露问题，但代价是失去了对失败轨迹的方向性纠错能力：当模型采样到一条错误的推理时，RLSD 只能更重地惩罚已采样的错误分布，却无法告诉模型"正确的分布应该是什么样的"。

H²SD 的切入点是上述两种策略之间存在的根本张力：分布级纠错（OPSD）能够为失败轨迹提供明确的修正方向，但面临信息泄露与优化不稳定的风险；仅做幅度调制（RLSD）保证了训练稳定性，却在失败时缺乏纠错信号。论文的核心洞察是——这种权衡并非不可调和，成功轨迹与失败轨迹对教师信号的需求本就不同，完全可以对它们采用差异化的处理策略。

## 方法

H²SD 的整体框架可以用一个条件路由来概括：对于正确完成的轨迹，保留奖励赋予的优化方向，仅借助教师概率来精细化调整各 token 的更新幅度；对于推理失败的轨迹，则显式地引入方向性修正，通过最小化反向 KL 散度引导学生分布向教师分布靠拢。

这一设计的关键在于如何构造两类轨迹各自的教师策略。首先需要解决的是特权信息的获取问题。论文使用一个更强的外部模型（实验中使用 Kimi-K2.6）为每道题目生成自然语言参考提示 $h = \mathcal{H}(x)$，该提示包含关键中间推理步骤以及由验证器确认的最终答案。这个提示在训练时作为特权上下文条件使用，但仅作为教师构造的输入而非教师本身——这与直接用提示作为监督信号的做法有本质区别。

对于成功轨迹的处理体现了 H²SD 的精巧设计。教师模型接收两方面的输入：被验证为正确的学生响应本身，以及一条"复述这条正确响应"的指令。这里复述指令的作用至关重要：它诱导教师在保持语义一致性的前提下，对原始响应的 token 序列进行重新表述，从而产生略有差异但语义等价的概率分布。教师在原始响应各 token 上的概率 $P^T(y_t)$ 与学生概率 $P^S(y_t)$ 的对数差值被提取为幅度调制信号：
$$\Delta_t = \mathrm{sg}\!\left(\log P^T(y_t) - \log P^S(y_t)\right)$$
进而构造权重因子：
$$w_t = \left(\frac{P^T(y_t)}{P^S(y_t)}\right)^{\mathrm{sign}(A)}$$
最终的优势估计被调整为：
$$\hat{A}_t = A\!\left[(1-\lambda) + \lambda\, \mathrm{clip}(w_t,\, 1-\epsilon_w,\, 1+\epsilon_w)\right]$$
这个调整后的优势 $\hat{A}_t$ 替换了 GRPO 中原始的轨迹级优势 $A$，但方向仍由奖励决定，调制仅作用于幅度层面。教师概率高的 token 获得更大的优势强化，教师概率低的 token 则被相对削弱，从而在不改变整体优化方向的前提下实现了 token 级的差异化信用分配。

失败轨迹的处理则需要显式的方向性修正。这里的教师策略以参考提示 $h$ 为条件，由同一模型参数化：
$$p^T_{t,\theta}(\cdot) = \pi_\theta(\cdot \mid x, h, y_{<t})$$
参考提示中包含的关键推理步骤和验证答案使得教师分布能够指向一条通向正确答案的推理路径。H²SD 选择最小化从学生分布到教师分布的反向 KL 散度：
$$\mathcal{L}_{\mathrm{RKL}} = \frac{1}{T}\sum_{t=1}^{T} D_{\mathrm{KL}}\!\left(p^S_{t,\theta}\,\big\|\,\mathrm{sg}[p^{T,h}_{t,\theta}]\right)$$
选择反向 KL（而非正向 KL）是有意为之的：反向 KL 在优化时会选择学生分布的支撑集上概率最高的模式，这使得学生倾向于"全或无"地采纳教师提供的某条推理路径，而非在错误路径与正确路径之间做软混合。对于需要明确修正方向的失败轨迹，这种特性比正向 KL 的均值-seeking 行为更为合适。

综合两部分的监督信号，H²SD 的总目标函数为：
$$\mathcal{L}_{\mathrm{H^2SD}} = \mathbb{E}_{x,y}\!\left[m\,\mathcal{L}_{\mathrm{RLSD}} + \gamma(1-m)\,\mathcal{L}_{\mathrm{RKL}}\right]$$
其中 $m = \mathbb{1}[R(x,y)=1]$ 是轨迹正确性指标，$\gamma$ 控制失败轨迹上反向 KL 纠错的强度。整个框架完全基于自蒸馏实现，无需外部教师模型，且通过 top-100 token 精确概率加尾部桶的策略有效控制了全词表蒸馏的显存开销。

## 实验与结果

论文在一组具有挑战性的逻辑推理基准上验证了 H²SD 的有效性，包括数独（Sudoku）、肯肯数独（Calcudoku）和箭头迷宫（Arrow Maze）三类任务。这些任务的共同特点是验证器可以精确判定最终答案的正确性，但推理路径具有高度的组合复杂度，能够充分暴露 token 级信用分配的问题。

实验以 Qwen3-30B-A3B-Instruct-2507 作为基础模型（一种 MoE 架构），使用 32 张 NVIDIA H200 140GB GPU 进行训练。为确保对比的公平性，OPSD、RLSD+hint 和 H²SD 均使用由 Kimi-K2.6 生成的相同参考提示。

主实验结果呈现出压倒性的优势。在 Sudoku-6×6 任务上，H²SD 达到 76.50% 的 pass@1 准确率，而最佳基线 OPSD 仅为 35.25%，提升超过 40 个百分点。在包含更多尺寸变体的综合平均指标上，H²SD 的 50.49% 对比 GRPO 的 24.68%、OPSD 的 24.01%、RLSD 的 24.85%，优势始终保持在 20 个百分点以上。尤为值得注意的是，H²SD 在训练时从未见过的 Arrow Maze-8×8 和 10×10 尺寸上依然保持最佳表现，说明其具备较强的跨尺寸泛化能力。

消融实验揭示了几个重要结论。关于路由策略的设计，论文对比了三种变体：仅用幅度调制（去除反向 KL 分支）、仅用反向 KL（去除幅度调制分支）、以及反转路由（正确轨迹用反向 KL、失败轨迹用幅度调制）。结果显示完整的两路混合策略最优，而反转路由会导致 actor 熵快速崩溃至接近零，策略的探索能力完全丧失——这直接证明了"成功轨迹需要保持奖励方向、失败轨迹需要方向性修正"这一设计直觉的正确性。

关于特权信息类型的消融则表明，包含过程级推理步骤的 Hint 效果最好，优于仅含最终答案的 Ground Truth 和程序化反馈。这说明教师能够提供的不仅是"答案是什么"，更是"如何得出答案"的推理模式。

复述指令的分析则呈现出有趣的上下文依赖性：复述指令仅在幅度调制路径上稳定有效，与反向 KL 直接匹配结合时反而损害性能。这可能是因为反向 KL 已经通过提示条件隐式地引导了教师分布的表述方式，额外的复述指令反而引入了不必要的干扰。

在效率维度上，论文通过计算 pass@1 与生成 token 数的帕累托前沿表明，H²SD 以最少的生成 token 数取得了最高的推理准确率，实现了精度与效率的良好兼顾。

## 讨论与可借鉴点

H²SD 的一个重要贡献在于揭示了 RLVR 中"分布级纠错"与"token 级信用分配"并非不可兼得：通过按轨迹正确性进行差异化处理，可以同时获得稳定优化和方向性修正两种能力。这种分而治之的思路——对不同性质的数据采用不同的学习策略——在处理强化学习中的异质性监督信号时具有普遍的借鉴意义。参考提示的设计也提示我们，特权信息的价值不仅在于"给出正确答案"，更在于"展示通向答案的推理路径"。

然而，当前的方法仍存在若干局限。首先，任务验证集中于逻辑推理类任务（Sudoku、Calcudoku、Arrow Maze），尚未在数学竞赛、代码生成等 RLVR 的主流应用场景上验证，这些任务通常具有更长的推理链和更复杂的奖励结构。其次，方法依赖外部强模型生成参考提示，在仅有规则验证器、缺乏高质量推理示范的场景下，提示获取成本和质量可能成为隐性瓶颈。再次，$\gamma$ 和 $\lambda$ 等关键超参的敏感性分析缺失，限制了对方法稳定性的全面评估。最后，反向 KL 的"模式寻求"特性在多解问题（如存在多种等价格式解答的 Calcudoku）上的表现尚待进一步探索。

从更宏观的角度看，H²SD 指向了一个值得关注的研究方向：如何在大语言模型的强化学习训练中，动态地、细粒度地调配多种监督信号。随着模型规模的增大和推理任务的复杂化，单一的奖励机制愈发难以支撑高效学习，而如何设计机制来整合结果奖励、过程监督、教师引导等多种信号，将是下一阶段的重要课题。

## 摘要
带可验证奖励的强化学习（RLVR）已在数学推理和代码生成等任务上显著提升了大语言模型的推理能力。然而，大多数 RLVR 方法将标量结果奖励分配给整个轨迹，导致监督稀疏以及词元级信用分配受限。同策略蒸馏（OPD）通过从更强的教师模型蒸馏词元级分布来提供更密集的监督，但需要额外的教师模型并且通常假设共享词表。同策略自蒸馏（OPSD）通过将同一模型以特权信息为条件来构建教师策略，从而消除了这种依赖。然而，直接匹配教师分布可能导致信息泄露和优化不稳定。RLSD 通过仅使用教师信号来调节更新幅度以避免直接匹配，但当采样的推理失败时，它无法提供明确的修正方向。为解决这一权衡，我们引入了 $\mathrm{H}^{2}\mathrm{SD}$，这是一种混合事后自蒸馏框架，根据轨迹的正确性以不同方式使用教师。对于成功的轨迹，教师接收被确认为正确的学生响应以及一条复述指令，其在原始响应词元上的概率用于调节更新幅度，而不改变由奖励所决定的方向。对于失败的轨迹，我们以包含关键推理步骤和已验证答案的参考提示为条件来构造教师，并最小化学生到教师的反向 KL 散度。在多个具有挑战性的推理基准上的实验表明，H$^2$SD 在保持稳定优化和良好生成效率的同时，始终优于代表性的 RLVR、OPSD 和 RLSD 基线方法。

## Abstract
Reinforcement learning with verifiable rewards (RLVR) has substantially improved the reasoning capabilities of large language models on tasks such as mathematical reasoning and code generation. However, most RLVR methods assign a scalar outcome reward to an entire trajectory, resulting in sparse supervision and limited token-level credit assignment. On-policy distillation (OPD) provides denser supervision by distilling token-level distributions from a stronger teacher model, but requires an additional teacher and typically assumes a shared vocabulary. On-policy self-distillation (OPSD) removes this dependency by conditioning the same model on privileged information to construct a teacher policy. However, directly matching the teacher distribution may cause information leakage and unstable optimization. RLSD avoids direct matching by using the teacher signal only to modulate update magnitudes, but it cannot provide an explicit correction direction when the sampled reasoning fails. To address this tradeoff, we introduce $\mathrm{H}^{2}\mathrm{SD}$, a hybrid hindsight self distillation framework that uses the teacher differently according to trajectory correctness. For successful trajectories, the teacher receives the student response confirmed as correct together with a rephrasing instruction, and its probabilities on the original response tokens are used to modulate update magnitudes without changing the direction determined by the reward. For failed trajectories, we condition the teacher on a reference hint containing key reasoning steps and a verified answer, and minimize the reverse KL divergence from the student to the teacher. Experiments on multiple challenging reasoning benchmarks show that H$^2$SD consistently outperforms representative RLVR, OPSD, and RLSD baselines while maintaining stable optimization and favorable generation efficiency.

- **OPSD 的信息泄露与不稳定问题**：同策略自蒸馏（On-Policy Self-Distillation）让同一模型在特权信息（如正确答案、环境反馈）条件下充当教师，再对学生分布做直接匹配。但特权信息可能隐式编码在 logits 中，导致学生逐步依赖该信息，训练稳定性下降。
- **RLSD 的纠错能力不足问题**：自蒸馏 RLVR（RLSD）放弃直接匹配，仅将教师信号用于调节 token 级更新幅度（保留奖励方向不变），缓解了信息泄露，却无法为失败轨迹指明应朝何分布修正——仅是更重地惩罚已采样的错误。

## 2. 方法论

### 2.1 整体思路

H²SD（Hybrid Hindsight Self-Distillation）按轨迹正确性 $m = \mathbb{1}[R(x,y)=1]$ 路由到两种监督方式：
- **成功轨迹**：保留奖励方向，仅用教师信号细化 token 级信用分配（类似 RLSD 的幅度调制）。
- **失败轨迹**：需要方向性纠错，最小化学生到条件教师分布的反向 KL 散度。

### 2.2 关键设计

**提示（Hint）生成**：由更强模型（实验使用 Kimi-K2.6）为每道题 $x$ 生成自然语言提示 $h = \mathcal{H}(x)$，包含关键中间推理步骤与验证器确认的最终答案。该提示仅在训练时作为特权信息使用，且仅作为上下文条件而非作为教师本身。
$$h = \mathcal{H}(x), \quad \pi_T(\cdot \mid x, h, y_{<t}) = \pi_\theta(\cdot \mid x, h, y_{<t}), \quad \pi_S(\cdot \mid x, y_{<t}) = \pi_\theta(\cdot \mid x, y_{<t})$$

**成功路径：幅度调制 + 复述指令**。教师接收被验证正确的学生响应以及"Rephrase the correct response"指令，其在原始响应 token 上的概率 $P^T(y_t)$ 用于构造幅度权重：
$$\Delta_t = \mathrm{sg}\!\left(\log P^T(y_t) - \log P^S(y_t)\right), \quad w_t = \exp(\mathrm{sign}(A)\cdot \Delta_t) = \left(\frac{P^T(y_t)}{P^S(y_t)}\right)^{\mathrm{sign}(A)}$$
$$\hat{A}_t = A\!\left[(1-\lambda) + \lambda\, \mathrm{clip}(w_t,\, 1-\epsilon_w,\, 1+\epsilon_w)\right]$$
其中 $\hat{A}_t$ 替换 GRPO 中的轨迹级优势 $A$，保留奖励方向。

**失败路径：反向 KL 纠错**。使用条件教师 $p^T_{t,\theta}(\cdot) = \pi_\theta(\cdot \mid x, h, y_{<t})$ 给出方向性修正：
$$\mathcal{L}_{\mathrm{RKL}} = \frac{1}{T}\sum_{t=1}^{T} D_{\mathrm{KL}}\!\left(p^S_{t,\theta}\,\big\|\, \mathrm{sg}[p^{T,h}_{t,\theta}]\right)$$

**总目标**：
$$\mathcal{L}_{\mathrm{H^2SD}} = \mathbb{E}_{x,y}\!\left[m\,\mathcal{L}_{\mathrm{RLSD}} + \gamma(1-m)\,\mathcal{L}_{\mathrm{RKL}}\right]$$
其中 $\gamma$ 控制失败轨迹上纠错蒸馏的强度。

**实现细节**：为缓解长链推理上全词表蒸馏的显存开销，OPSD 与 H²SD 仅保留学生 top-100 token 的精确概率，其余合并为尾部桶。

- **方法简洁**：成功轨迹几乎不改变优化方向，仅做幅度调制；失败轨迹才引入 RKL，避免了 OPSD 的特权信息泄露与不稳定。
- **控制变量严谨**：OPSD、RLSD+hint、H²SD 共享相同 Hint，使对比聚焦于"如何利用特权信息"。
- **效率与精度兼顾**：Figure 3 显示 H²SD 以最少生成 token 数取得最高 pass@1。
- **充分消融**：路由、特权信息类型、复述指令、熵动力学均有专项实验支撑结论。

## 8. 不足与局限

- **任务域偏窄**：仅在 Sudoku/Calcudoku/Arrow Maze 等逻辑推理任务上验证，论文声称的"reasoning benchmarks"未覆盖数学竞赛、代码生成等更广泛的 RLVR 主流场景。
- **单一模型族**：仅以 Qwen3-30B-A3B-Instruct-2507 为学生、Kimi-K2.6 为提示生成器，未在其他架构（如稠密 LLM、不同规模 MoE）上验证，泛化结论需谨慎。
- **算力与训练成本未披露**：未报告 wall-clock 时间、训练步数、单次实验成本，限制可复现性评估。
- **特权信息的依赖**：方法效果依赖外部强模型生成提示；在无法获得此类提示的纯 RLVR 场景（仅有规则验证器）下，Hint 的获取成本与质量成为隐性瓶颈。
- **基线集合较小**：未与近期更多 RLSD 改进（如 CEPO、GATES、SRPO 的后续变体）做对比；OPSD/RLSD 在其原始任务上的较强结果未被充分复现以说明其在该基准上的潜力天花板。
- **稳定性分析有限**：熵崩溃证据基于 Sudoku 两个尺寸，未在其他任务上系统化验证；$\gamma$、$\lambda$ 等超参的敏感性未给出。
- **潜在失败模式**：含多解的任务（如 Calcudoku）下，外部提示与学生推理路径可能不一致，复述指令设计能否普适仍待验证。
