tldr: 强化学习可验证奖励（RLVR）方法在语言模型推理中只能提供轨迹级标量奖励，缺乏token级细粒度指导。现有自蒸馏方法为教师模型分配固定角色，难以同时适配成功与失败轨迹的不同需求。本文提出混合事后自蒸馏H²SD，根据轨迹正确性动态调整教师上下文与更新策略：成功轨迹用已验证回答构造教师上下文并重新评估原始token，失败轨迹借助验证器提示进行反向KL蒸馏校正。实验表明H²SD在多个推理基准上整体性能最优，优化稳定且精度与效率权衡良好，为RLVR框架下的token级信用分配提供了新思路。

## TL;DR

H²SD 针对强化学习可验证奖励中 token 级指导不足的问题，提出根据轨迹正确性动态切换教师角色——成功轨迹用改述后的教师重新评估原始 token 以优化幅度分配，失败轨迹则借助参考提示通过反向 KL 蒸馏提供纠错方向。在 Sudoku、Calcudoku、Arrow Maze 等逻辑推理基准上，H²SD 超越 GRPO、RLSD、OPSD 等代表性基线，综合准确率达 50.49%，且训练过程稳定、推理时无需教师。

## 研究背景与动机

在大语言模型训练中，[[RLVR]]（带可验证奖励的强化学习）框架以任务结果作为监督信号，为推理能力提升提供了可靠的结果导向优化。GRPO 等方法在此范式下表现优异，但它们只能输出轨迹级的标量奖励——换句话说，同一回答中所有 token 被平等对待，既无法区分关键推导步骤与冗余旁白，也无法为长链推理中的 token 级决策提供细粒度的信用分配。

为突破这一局限，研究者尝试引入自蒸馏机制：用同一模型充当教师与学生，通过特权信息构造教师的置信分布，进而对学生策略进行分布匹配。理想很丰满，现实却很骨感。直接让教师进行正向 KL 分布匹配可能摧毁已经成功的推理策略——毕竟成功轨迹已经包含一条学生自主生成的正确路径，用外部解释替换它反而画蛇添足。另一条思路是只调整损失幅度而不改变奖励方向（如 RLSD），这避免了策略崩塌，但问题在于：对于最终失败的轨迹，幅度调制几乎无法提供有意义的纠错指引。

论文的核心观察由此浮现：成功轨迹与失败轨迹对事后监督的需求本质不同。一条成功的响应已经验证了自身的正确性，它需要的是在已有路径基础上精细化信用分配——强化关键推导、抑制冗余内容。一条失败的响应则完全不同，它迫切需要方向性的纠错信号，引导模型走向正确答案。这两类需求恰好对应两种不同的蒸馏策略，问题的关键变为：如何设计一种机制，让模型根据轨迹正确性自适应地选择合适的监督形式？

## 方法

H²SD 的设计围绕一个核心问题展开：如何让教师模型在成功与失败轨迹上扮演不同角色？答案在于联合调整教师上下文与更新策略本身。

**成功轨迹的处理**采用"幅度重分配"思路。教师接收的上下文由三个部分构成：原始问题、学生已验证正确的完整响应、以及一条改述指令。这条改述指令是整个设计的关键细节——它要求教师在不改变答案内容的前提下改写整个推理过程，但必须原样保留 `<answer>` 块中的最终答案。教师随后仅对原始响应中的 token 进行概率再评估，计算每个位置的对数概率变化 $\Delta_t$，进而构造类似 RLSD 的 token 级权重。这一策略的精妙之处在于：奖励方向保持不变（因为最终答案正确），但通过教师对推理过程的重新评分，原本被埋没的关键步骤获得了更高的信用权重，冗余的中间步骤则被相对削弱。

**失败轨迹的处理**则引入反向 KL 蒸馏。当一条轨迹未能通过验证器时，教师接收的上下文变为问题加上由外部更强模型离线生成的参考提示。这里的提示经过验证器确认答案正确后才被保留，确保了参考信息的可靠性。教师与学生之间采用反向 KL 散度进行约束：

$$\mathcal{L}_{\mathrm{RKL}} = \frac{1}{T}\sum_{t=1}^{T} D_{\mathrm{KL}}\!\left(\, p^{S}_{t,\theta}\;\|\;\mathrm{sg}[p^{T,h}_{t,\theta}]\,\right)$$

其中 $p^{S}_{t,\theta}$ 是学生在当前上下文下的分布，$p^{T,h}_{t,\theta}$ 是教师在加入提示后的分布，$\mathrm{sg}[\cdot]$ 阻止梯度回传到教师网络。反向 KL 的特性在于它倾向于让学生分布覆盖教师分布的主要模式，这对失败轨迹的纠错尤为有利——学生的正确答案区域会被教师的高概率区域"覆盖"并强化，从而引导模型向正确答案收敛。

**总体目标**整合两条路径：

$$\mathcal{L}_{\mathrm{H^2SD}} = \mathbb{E}_{x,y}\!\left[\, m\,\mathcal{L}_{\mathrm{RLSD}} \;+\; \gamma\,(1-m)\,\mathcal{L}_{\mathrm{RKL}}\,\right]$$

其中 $m = \mathbb{1}[R(x,y)=1]$ 是轨迹正确性指示，$\gamma$ 平衡两类轨迹的权重。成功轨迹享受幅度调制的稳定性，失败轨迹获得反向 KL 的纠错能力，两者互补而非竞争。

在实现层面，H²SD 基于 VERL + SGLang 框架进行全参数训练，使用 FSDP 进行参数分片。为控制长链推理场景下的显存开销，对完整词表的蒸馏概率进行了截断近似——保留 top-100 token 的精确概率，其余 token 合并到尾部桶中。训练时采用梯度裁剪（$\ell_2 \le 1.0$）等常规稳定化手段。

## 实验与结果

实验在三个逻辑推理基准上进行：Sudoku（$6\times6$、$8\times8$ 网格）、Calcudoku（$5\times5$、$6\times6$ 网格）以及 Arrow Maze（$6\times6$ 到 $10\times10$ 多尺寸，含未训练尺寸用于泛化性测试）。基础模型统一使用 Qwen3-30B-A3B-Instruct-2507。

主实验结果清晰地展示了 H²SD 的优势。在综合均值上，H²SD 达到 50.49%，相比 GRPO（24.68%）、RLSD（24.85%）、OPSD（24.01%）、SRPO（24.01%）等基线均有大幅提升，尤其在 Sudoku 任务上优势显著（$6\times6$: 76.50%，$8\times8$: 57.25%）。更值得注意的是，H²SD 在未训练过的 Arrow Maze-8×8 和 10×10 尺寸上依然保持最优性能，显示出良好的跨尺寸泛化能力。

消融实验揭示了几个关键设计决策的有效性。首先是路由策略的核心性——当将两类轨迹的处理方式对调（成功用反向 KL、失败用幅度调制）时，性能骤降至 6.40%，且 actor 熵迅速坍缩至零，说明错误的路由策略不仅无效，甚至会完全破坏训练过程。其次是改述指令的独特作用：对幅度调制策略，提升幅度高达 23.75–32.00 个百分点；但对反向 KL 策略，引入改述反而损害性能（-2.50 ~ -3.50 个百分点）。这一结果揭示了一个有趣的规律：改述之所以有效，是因为它帮助教师在成功轨迹上识别关键 token，但如果教师本来就在进行方向性纠错（反向 KL），改述引入的扰动就会干扰纠错信号。

效率分析同样令人鼓舞。H²SD 在多个基准上以更少的生成 token 数达到了更高的 pass@1 准确率，证明了其不仅提升了模型输出的正确性，还优化了推理的简洁性——模型学会了"更快地想通正确答案"。

## 讨论与可借鉴点

H²SD 的核心贡献在于揭示了一个此前被忽视的事实：自蒸馏中的教师角色不能是静态的。成功轨迹与失败轨迹对监督信号的需求存在本质差异，强行统一处理会顾此失彼。这一洞察启发我们重新审视自蒸馏的设计范式——不仅要在模型层面区分教师与学生，还要在样本层面根据轨迹属性动态分配教师的职责。

几个设计细节值得借鉴。改述指令的引入是一个精巧的设计，它在保留学生已成功推理路径的前提下，让教师有机会重新评估每个 token 的重要性——既避免了特权信息泄漏，又实现了细粒度的信用分配。此外，将提示生成完全离线化（使用 Kimi-K2.6）且训练时不查询，使得推理时无需教师，这对部署友好。

然而局限性同样存在。H²SD 依赖外部更强模型生成离线提示，并要求存在可靠的验证器来确认提示的正确性——这在代码生成或开放域问答等缺乏确定性验证器的场景中可能难以适用。实验仅在单一模型规模（30B 参数）上验证，且未覆盖 MATH、AIME 等常见数学推理基准，其外部有效性有待进一步论证。此外，改述指令中包含任务相关的硬编码（如"`<answer>` 块原样保留"），跨任务迁移时需要重新设计 prompt。

总体而言，H²SD 为 [[RLVR]] 框架下的 token 级信用分配问题提供了一条可行路径，其"按结果条件路由 + 差异化蒸馏"的思路对后续研究具有参考价值——尤其是当训练样本包含异质性轨迹（如推理任务中同时存在成功与失败的演示）时，动态分配教师角色的思想或许能推广到更广泛的强化学习与自蒸馏场景中。

## 摘要
带可验证奖励的强化学习（RLVR）为语言模型推理提供了可靠的结果监督，但标量轨迹奖励所提供的 token 级别指导十分有限。现有的自蒸馏方法引入了一个具有特权信息的教师模型，但通常为其赋予固定的角色：直接进行分布匹配可能会破坏已成功的策略行为，而仅在幅度上进行调制则几乎无法在失败后提供有意义的纠错指引。我们观察到，成功与失败的轨迹各自需要不同形式的事后监督。成功的响应已经包含一条由学生模型生成的合理推理路径，因此更适合作为特权上下文，而无需被外部解释所替换；反之，失败的响应则需要具有纠错作用的参考信息。我们提出混合事后自蒸馏（H$^2$SD），根据轨迹的正确性联合调整教师上下文与更新策略。对于成功轨迹，我们依据已验证的响应和一条改述指令来构建教师上下文，并仅让教师对原始响应 token 进行再评估。该方法在保持奖励方向不变的前提下，强调关键推导、抑制冗余内容，从而改进基于幅度的信用分配。对于失败轨迹，则使用由验证器确认的参考提示，通过反向 KL 蒸馏提供纠错指导。受控消融实验表明，性能增益依赖于按结果条件进行的路由以及改述指令。多个具有挑战性的推理基准上的实验显示，H$^2$SD 在代表性的 RLVR 与自蒸馏基线中取得了最优的综合性能，并具有稳定的优化过程以及良好的精度-效率权衡。

## Abstract
Reinforcement learning with verifiable rewards (RLVR) provides reliable outcome supervision for language model reasoning, but a scalar trajectory reward offers limited token-level guidance. Existing self-distillation methods add a privileged teacher but typically assign it a fixed role: direct distribution matching may destabilize successful behavior, while magnitude-only modulation offers little corrective guidance after failure. We observe that successful and failed trajectories require different forms of hindsight supervision. A successful response already contains a valid student-generated reasoning path and can therefore serve as privileged context rather than being replaced by an external rationale. A failed response, however, requires corrective reference information. We introduce Hybrid Hindsight Self-Distillation ($\mathrm{H}^{2}\mathrm{SD}$), which jointly adapts teacher context and update strategy to trajectory correctness. For successful trajectories, we construct the teacher context from the verified response and a rephrasing instruction, and use the teacher only to re-evaluate the original response tokens. This emphasizes essential deductions over redundant content and refines magnitude-based credit assignment without changing the reward direction. For failed trajectories, a verifier-confirmed reference hint provides corrective guidance through reverse-KL distillation. Controlled ablations show that the gains depend on outcome-conditioned routing and the rephrasing instruction. Experiments on challenging reasoning benchmarks show that H$^2$SD achieves the strongest overall performance among representative RLVR and self-distillation baselines, with stable optimization and a favorable accuracy-efficiency trade-off.

## 二、方法论

### 2.1 教师构造（Hint Design）

使用更强的外部模型 Kimi-K2.6（仅离线生成，训练时不查询）针对每个问题 $x$ 生成自然语言提示 $h$：
$$h = \mathcal{H}(x)$$
提示需通过任务验证器确认答案正确后才被保留。OPSD 与 H²SD 使用相同的提示以保证公平对比。

### 2.2 混合自蒸馏（Hybrid Self-Distillation）

设 $m = \mathbb{1}[R(x,y)=1]$ 为轨迹正确性指示，H²SD 的总体目标为：
$$\mathcal{L}_{\mathrm{H^2SD}} = \mathbb{E}_{x,y}\!\left[\, m\,\mathcal{L}_{\mathrm{RLSD}} \;+\; \gamma\,(1-m)\,\mathcal{L}_{\mathrm{RKL}}\,\right]$$

#### （a）成功轨迹：幅度调制 + 改述
教师接收"问题 $x$ + 学生已验证正确的响应 + 改述指令"，仅对**原始响应 token**重评估，得到对数概率差 $\Delta_t$，进而构造 RLSD 形式的 token 级权重。该策略**保留奖励方向不变**，仅在幅度上重新分配，强化关键推导、抑制冗余步骤。

#### （b）失败轨迹：反向 KL 蒸馏
教师接收"问题 $x$ + 参考提示 $h$ + 响应前文"，学生到教师使用反向 KL：
$$\mathcal{L}_{\mathrm{RKL}} = \frac{1}{T}\sum_{t=1}^{T} D_{\mathrm{KL}}\!\left(\, p^{S}_{t,\theta}\;\|\;\mathrm{sg}[p^{T,h}_{t,\theta}]\,\right)$$
其中 $p^{S}_{t,\theta}=\pi_\theta(\cdot|x,y_{<t})$，$p^{T,h}_{t,\theta}=\pi_\theta(\cdot|x,h,y_{<t})$，$\mathrm{sg}[\cdot]$ 阻止梯度回流。该分支为失败轨迹提供**方向性纠错信号**。

### 2.3 算法流程概览
1. 旧策略 $\pi_{\theta_{\mathrm{old}}}$ 采样 $G$ 条轨迹；
2. 验证器给出标量奖励，并区分成功/失败；
3. 对成功轨迹：构造改述教师 → 计算幅度权重 $w_t$ → 采用 RLSD 更新；
4. 对失败轨迹：构造提示教师 → 反向 KL 蒸馏；
5. 梯度整合（含梯度裁剪 $\ell_2 \le 1.0$、top-100 蒸馏等）。

## 三、实验设计

### 3.1 模型与基准
- **基础模型**：Qwen3-30B-A3B-Instruct-2507
- **三个逻辑推理基准**：
  - **Sudoku**：$6\times6$、$8\times8$ 网格（行/列/宫约束）
  - **Calcudoku**：$5\times5$、$6\times6$ 区域算术约束
  - **Arrow Maze**：$6\times6 \sim 10\times10$ 多尺寸（**含未训练尺寸**用于泛化性测试）

### 3.2 对比方法
| 方法 | 类型 |
|---|---|
| Base LLM | 不训练基线 |
| GRPO | RLVR 基线 |
| SDPO | 兄弟正确响应反馈 + GJSD |
| RLSD | 答案级特权 + 幅度调制 |
| RLSD+hint | 同 H²SD 提示但仅幅度调制 |
| OPSD | 提示教师 + 正向 KL 分布匹配 |
| SRPO | 成功→GRPO，失败→自蒸馏（熵加权） |
| **H²SD** | **本文方法** |

### 3.3 实现细节
- 基于 **VERL + SGLang** 全参数训练（FSDP）。
- 为降低长链推理全词表蒸馏显存，**保留 top-100 token 的精确概率，其余合并到尾部桶**。
- SDPO 与 SRPO 的蒸馏分支使用 $\alpha=0.5$ 的广义 Jensen–Shannon 散度。
- 验证器由各任务规则化打分函数提供。

## 六、主要结论与发现

1. **整体性能最优**：H²SD 在 4 个基准的综合均值达到 **50.49%**，显著超过 GRPO（24.68%）、RLSD（24.85%）、OPSD（24.01%）、SRPO（24.01%）、RLSD+hint（24.72%），在 Sudoku 上尤为突出（$6\times6$: 76.50%，$8\times8$: 57.25%）。
2. **泛化能力**：在未训练的 Arrow Maze-8×8、-10×10 上仍获最优结果。
3. **路由策略至关重要**：反向路由（成功用 reverse-KL、失败用 magnitude）性能骤降至 6.40%，且 actor 熵迅速坍缩至零。
4. **特权上下文信息量越大越好**：纯答案或程序化反馈收益有限；富含过程信息的提示带来最大提升（Sibling: 61.75% / 48.50% / 19.60%；Hint: 76.50% / 57.25% / 24.20%）。
5. **改述的有效性依赖于更新形式**：对 Magnitude Only 提升 23.75/32.00 个百分点，对 H²SD 提升 8.00/5.75，但会**损害** Reverse-KL Only（-2.50/-3.50）。
6. **精度-效率权衡良好**：H²SD 在多个基准上以**更少的生成 token** 达到最高 pass@1。
7. **优化稳定**：熵曲线显示 H²SD 与 Magnitude Only 类似，保持探索性。

## 七、优点

1. **问题切分精准**：成功与失败轨迹监督需求差异的洞察为差异化蒸馏提供了理论依据。
2. **双重机制互补**：保留 RLSD 的稳定性 + 引入 reverse-KL 的纠错性，按结果条件路由。
3. **改述设计巧妙**：避免外部解释覆盖学生已成功路径，同时去除冗余内容；并通过指令级约束确保 `<answer>` 块字面一致（见附录 C.2）。
4. **公平性强**：OPSD 与 H²SD 使用**完全相同的离线提示**，将增益归因于"如何用提示"而非"提示本身"。
5. **诊断充分**：熵动态、长度分解、路由反例等多种分析共同支撑结论。
6. **训练-推理解耦**：提示生成离线完成，**推理时无需教师**。

---

## 八、不足与局限

1. **依赖外部强模型生成提示**：需 Kimi-K2.6 能解题并通过验证器；增加预处理成本；若没有可靠外部模型或确定性验证器则不可用。
2. **单模型规模评估**：仅在 Qwen3-30B-A3B-Instruct-2507 上验证；作者明确说明小模型在冷启动下初始成功率过低，难以稳定比较，**未跨规模验证**。
3. **未覆盖常见推理基准**：未在数学竞赛（如 AIME、MATH）或代码生成等通用 RLVR 任务上验证，**外部有效性**受限。
4. **数据覆盖损失**：若某题始终无法生成被验证器接受的提示，则该训练样本被丢弃，可能影响数据利用率。
5. **token 概率近似**：top-100 + 尾部桶的近似对长链推理质量的影响尚未量化。
6. **基线覆盖偏差风险**：未与最先进 OPD（如 GKD、Minillm 变体）的最新版本系统比较；SRPO、SDPO 的训练超参与原始实现略有差异。
7. **实验报告维度**：总训练时长、总 GPU-hour、收敛步数等**算力成本指标缺失**，难以评估实际性价比。
8. **改述模板耦合任务**：改述指令含"`<answer>` 块原样保留"等任务相关硬编码，**跨任务迁移需重新设计 prompt**。
