## TL;DR

这篇论文提出了一种让强化学习智能体自动选择最优时间折扣因子的方法——不再依赖人工调参，而是通过一个状态依赖的混合权重机制，从预定义的多组折扣因子中自适应地组合出适合当前情境的时间视野。在 MiniGrid 系列环境和三任务持续学习场景中，这种方法不仅能自动收敛到任务对应的最优折扣因子，还显著提升了参数效率和对任务切换的适应能力。

## 研究背景与动机

在强化学习中，折扣因子 $\gamma$ 是控制「眼前利益」与「长远收益」权衡的关键杠杆。标准形式下，智能体最大化的是折扣回报

$$G_t = \sum_{k=0}^{\infty} \gamma^k R_{t+k+1}, \quad \gamma \in [0,1)$$

单一固定的 $\gamma$ 隐含地决定了智能体的「有效时间视野」，其大小为 $H_{\text{eff}} = \frac{1}{1-\gamma}$：较小的 $\gamma$ 意味着只关心眼前几步的回报，较大的 $\gamma$ 则要求智能体能够看得更远。这个设计虽然简洁，却带来一个根本性的困境——现实任务中，奖励结构和任务目标往往随时间变化，同一个 $\gamma$ 很难在不同阶段都保持最优。

试想一个导航任务：初期需要快速探索、获得即时奖励，后期则需要规划一条穿越多个房间的长路径。显然，「短视」和「远视」在任务的不同阶段各有优势，而单一 $\gamma$ 必须在二者之间做trade-off，往往两者都无法兼顾。

生物智能给了我们一个重要启示。人类和动物并非用固定的时间折扣策略做决策，而是展现出灵活、自适应的多时间尺度特性——面对不同情境时，大脑可以自动调节「多快能看到回报」。这种灵活性暗示，有效的规划可能本身就要求同时维护多个时间尺度，而非依赖单一参数。

论文的核心问题由此而生：能否让 RL 智能体自动在多个时间折扣尺度之间切换，而无需人工干预？

## 方法

解决思路说起来并不复杂：预先定义一组 $K$ 个不同的折扣因子 $\Gamma = \{\gamma_1, \ldots, \gamma_K\}$，让每个 $\gamma$ 各自维护一套独立的 Q 函数，再通过一个可学习的混合权重将它们组合起来。关键在于，这个混合权重必须是「状态依赖」的——在不同状态下，智能体可以侧重不同的折扣尺度。

具体实现分为三个技术支柱。

**并行 Q 函数学习**。对每个折扣因子 $\gamma_i$，算法独立维护一个 Q 函数 $Q_i(s,a)$，采用带有资格迹的 Watkins Q($\lambda$) 更新。TD 误差定义为

$$\delta^{(i)}_t = r_{t+1} + \gamma_i \sum_{a'} \pi(a'|s_{t+1}) Q_i(s_{t+1}, a') - Q_i(s_t, a_t)$$

资格迹的引入让每个 $Q_i$ 能够兼顾更长历史信息的信用分配，$\lambda=0.8$ 是论文采用的默认值。更新公式为

$$Q_i(s_t,a_t) \leftarrow Q_i(s_t,a_t) + \alpha \delta^{(i)}_t E^{(i)}_t(s_t,a_t)$$

这样 $K$ 套 Q 函数并行运行，各自对应不同的时间视野——从极短视的 $H=2$（$\gamma=0.5$）到近乎无限远的 $H=512$（$\gamma=0.998$），覆盖了决策场景中可能遇到的全部时间尺度。

**状态依赖的混合权重**。这是方法的核心创新点。通过一个小型线性层，根据状态嵌入 $\phi(s)$ 生成 softmax 权重：

$$z = W\phi(s) + b, \quad w_i(s) = \frac{\exp(z_k)}{\sum_j \exp(z_j)}$$

最终用于决策的是这 $K$ 个 Q 函数的加权组合：

$$Q_{\text{mix}}(s,a) = \sum_{i=1}^{K} w_i(s)\, Q_i(s,a)$$

这意味着，在某个状态下，智能体可能更信任「短视」Q 函数提供的评估；在另一个需要规划远期目标的状态，同一个智能体会自动将权重转向「远视」Q 函数。权重 $w_i(s)$ 的学习完全由 TD 误差驱动，无需任何额外监督。

**混合 Q 的端到端更新**。整个系统以 $Q_{\text{mix}}$ 的 TD 误差作为损失函数：

$$\delta = y - Q_{\text{mix}}(s_t, a_t), \quad L = \tfrac{1}{2}\delta^2$$

通过链式法则，权重参数 $W$ 和 $b$ 的梯度具有简洁的形式：

$$\frac{\partial Q_{\text{mix}}}{\partial z_i} = w_i(Q_i - Q_{\text{mix}})$$

这保证了混合权重的调整方向是「让当前状态更信任那些对该状态估值更准的 Q 函数」。参数更新为

$$W \leftarrow W + \alpha \delta \big[\, w \odot (Q - Q_{\text{mix}}) \,\big] \phi(s)^\top$$

整个流程在概念上形成了一个优雅的闭环：各折扣尺度的 Q 函数并行探索，混合权重根据状态自动选择最可靠的尺度组合，TD 误差同时驱动两者收敛。

## 实验与结果

论文在 MiniGrid 环境中验证了方法的有效性。MiniGrid 是一个轻量级的 grid-world 平台，适合快速原型验证，任务包括导航、拾取目标物、避开障碍等。

最关键的发现出现在权重收敛行为上。在单任务环境中，状态依赖的混合权重 $w_i(s)$ 会自发地将大部分概率质量集中到该任务最优的 $\gamma_i$ 附近——这验证了「自动选 $\gamma$」这一核心假设是成立的，智能体不需要任何关于「哪个折扣因子最好」的先验知识，就能在学习中自动发现正确答案。

在参数效率方面，自适应多时间尺度方法相比固定 $\gamma$ 的 Q($\lambda$) 基线表现出了明显优势。达到相近目标性能时，自适应方法所需的环境交互步数更少。这说明「多尺度并行探索」并非冗余开销，而是通过让智能体在早期就能接触到不同时间尺度的反馈信号，实际上加速了学习过程。

最具挑战性的测试是三任务持续学习场景。三个任务依次切换，每个任务的最优折扣因子各不相同。实验结果显示，智能体在任务切换后能够无需人工干预地重新调整混合权重，将注意力从上一个任务对应的折扣尺度迁移到新任务所需的尺度。这一能力对持续学习场景意义重大——在实际应用中，任务边界往往是未知的，智能体必须能够在没有显式「任务切换信号」的情况下自主适应。

## 讨论与可借鉴点

论文的方法在概念上非常干净——不需要复杂的网络架构，不需要额外的元学习目标，只在经典 Q($\lambda$) 框架上增加了一个轻量级的 softmax 混合层。这种设计思路值得借鉴：与其从零设计一个复杂的新架构，不如在成熟方法上做「最小必要改动」，以解决核心痛点。

然而，实验的覆盖面还有限。MiniGrid 是低维的 grid-world 环境，能否泛化到高维的视觉输入或连续控制任务（如 Atari、MuJoCo）仍是未知数。论文采用线性函数逼近产生状态嵌入，对复杂观测的处理能力存疑。此外，混合权重的学习完全依赖 TD 误差的隐式监督，在奖励稀疏或延迟的场景中，这种监督信号本身可能就不够有效。

从理论角度看，论文缺乏对混合 Q-learning 收敛性的分析。并行维护 $K$ 套 Q 函数是否会引入额外的方差？多个时间尺度的资格迹之间是否存在相互干扰？这些问题没有得到充分讨论。

尽管如此，自适应时间折扣的核心思想为强化学习的持续学习和快速适应研究开辟了一个有价值的切入点。它与 [[元强化学习]] 中「让智能体学会学习」的目标高度契合，也与神经科学中多时间尺度表征的研究形成了跨学科呼应。如果能在更大规模、更多样化的环境中验证其有效性，这类方法有潜力成为构建真正灵活、适应性强的智能体的基础组件之一。

## Abstract
Effective decision-making in complex and changing environments requires balancing short-term and long-term consequences. In reinforcement learning (RL), this trade-off is typically controlled through a fixed discount factor, which imposes a single exponentially discounted temporal horizon. However, biological agents exhibit flexible and adaptive temporal discounting, suggesting that effective planning requires multiple timescales. Here, we propose a multi-horizon approach that adaptively selects and combines temporal horizons, enabling robust adaptation to changes in reward structure without manual discount-factor tuning. This flexibility makes the method particularly suitable for continual learning scenarios involving task switches and varying environmental configurations. Empirically, we demonstrate that our approach identifies effective discount factors across a range of MiniGrid environments, including continual settings composed of three sequentially changing tasks. These results suggest that adaptive temporal discounting can improve parameter efficiency and enhance adaptability in both artificial and biologically inspired learning systems.

$$G_t = \sum_{k=0}^{\infty} \gamma^k R_{t+k+1}, \quad \gamma \in [0,1)$$

固定单一 $\gamma$ 只能表达单一的指数衰减时间视野（effective horizon $H_{\text{eff}} = \frac{1}{1-\gamma}$），存在以下核心缺陷：

- **参数敏感**：任务奖励结构变化时，需反复手动调参；
- **任务切换能力弱**：在持续学习（continual learning）场景中，无法适应不同任务的最佳折扣尺度；
- **生物合理性不足**：人类与动物表现出**灵活、自适应**的多时间尺度折扣特性，单 $\gamma$ 无法模拟。

因此，论文的核心问题是：**如何让 RL 智能体无需手工调节 $\gamma$ 即可自动适配多种任务与奖励结构？**

## 2. 方法论

### 2.1 核心思想

预定义一组 K 个不同的折扣因子集合：
$$\Gamma = \{\gamma_1, \ldots, \gamma_K\}, \quad \gamma \in \{1, 0.998, 0.996, 0.992, 0.984, 0.969, 0.938, 0.875, 0.75, 0.5\}$$

对应的有效时间视野 $H_{\text{eff}} = \frac{1}{1-\gamma}$ 为 $\{\infty, 512, 256, 128, 64, 32, 16, 8, 4, 2\}$，覆盖从"极短视"到"无限远视"的完整谱系。

为每个 $\gamma_i$ 维护独立的 Q 函数 $Q_i(s,a) \approx Q^{\pi}_{\gamma_i}(s,a)$，并通过一个**可学习的、与状态相关的混合权重**自适应地组合它们。

### 2.2 关键技术细节

**（1）Q 函数的并行学习（Watkins Q(λ) with eligibility traces）**

对每个 $i$，使用资格迹机制（$\lambda = 0.8$）更新：

$$Q_i(s_t,a_t) \leftarrow Q_i(s_t,a_t) + \alpha \delta^{(i)}_t E^{(i)}_t(s_t,a_t)$$

其中：
- TD 误差：$\delta^{(i)}_t = r_{t+1} + \gamma_i \sum_{a'} \pi(a'|s_{t+1}) Q_i(s_{t+1}, a') - Q_i(s_t, a_t)$
- 资格迹：$E^{(i)}_t(s,a) = \gamma_i \lambda E^{(i)}_{t-1}(s,a) + \mathbf{1}(s=s_t, a=a_t)$

**（2）状态依赖的混合权重 $w_i(s)$**

通过一个小型线性层产生 softmax 权重：

$$z = W\phi(s) + b, \quad w_i(s) = \frac{\exp(z_k)}{\sum_j \exp(z_j)}$$

混合 Q 函数：
$$Q_{\text{mix}}(s,a) = \sum_{i=1}^{K} w_i(s)\, Q_i(s,a)$$

**（3）混合 Q 的 TD 更新与权重学习**

$$y = r_{t+1} + \sum_{a'} \pi(a'|s_{t+1})\, Q_{\text{mix}}(s_{t+1}, a')$$
$$\delta = y - Q_{\text{mix}}(s_t, a_t), \quad L = \tfrac{1}{2}\delta^2$$

通过链式法则得到梯度（利用 softmax 性质 $\partial w_k / \partial z_i = w_k(\delta_{ki} - w_i)$）：

$$\frac{\partial Q_{\text{mix}}}{\partial z_i} = w_i(Q_i - Q_{\text{mix}})$$

权重更新：
$$W \leftarrow W + \alpha \delta \big[\, w \odot (Q - Q_{\text{mix}}) \,\big] \phi(s)^\top$$
$$b \leftarrow b + \alpha \delta \big[\, w \odot (Q - Q_{\text{mix}}) \,\big]$$

其中 $\odot$ 表示逐元素乘积。

### 2.3 算法流程总结

1. 初始化 $K$ 个 Q 表（或网络）与权重参数 $W,b$；
2. 在环境中执行 $\epsilon$-greedy 策略（基于 $Q_{\text{mix}}$）；
3. 对每个 $i$ 用各自的 $\gamma_i$ 与资格迹更新 $Q_i$；
4. 用 $Q_{\text{mix}}$ 的 TD 误差梯度更新 $W,b$。
