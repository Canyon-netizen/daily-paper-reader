## Abstract
Modern generative models are increasingly trained using model-generated signals, creating both opportunities for self-improvement and risks of collapse. We study optimal self-distillation (SD) for rectified flow (RF): given a suboptimal teacher velocity field, can a student trained on a mixture of true RF velocities and teacher velocities provably improve the teacher? For linear RF with ridge regularization on fixed interpolation pairs, we prove an exact affine path identity, derive the optimal mixing coefficient in closed form, and show strict improvement in integrated velocity risk whenever the teacher risk is nonstationary along the regularization path. The optimal coefficient obeys a sign rule: positive mixing corrects under-regularized teachers, while negative mixing corrects over-regularized teachers. We also give one-shot generalized cross-validation (GCV) and validation tuning procedure that avoids grid search over mixing weights and repeated refitting. Combining this theorem with RF Wasserstein convergence bounds, we show that optimal self-distillation improves the velocity estimation terms controlling continuous-time and finite-step generation error. Experiments with Gaussian models, Gaussian mixtures, and image data show that optimal self-distillation improves velocity risk, mode recovery, and finite-step generation relative to both the teacher and pure distillation.

- **合成数据**：各向同性/各向异性高斯分布；二维四成分高斯混合（MoG-4）；棋盘、月牙、螺旋等二维流形。
- **图像数据**：手写数字、Fashion-MNIST、CIFAR-10（$32\times 32$）。

### 3.2 对比基线

| 方法 | 含义 |
|---|---|
| Teacher | 原始教师速度场 |
| Pure Distillation (PD) | 纯蒸馏（$\xi=1$） |
| SD clipped $[0,1]$ | 强制凸混合范围 |
| Optimal / Unconstrained SD | 无约束 $\xi \in \mathbb{R}$ |
| Oracle SD | 由测试风险选最优 $\xi$ |
| One-shot GCV/Validation SD | 一次性调参 |
| Time-dependent (TD) | 逐时刻 $\xi_t$ |
| Fine-tune（匹配算力） | 计算量匹配的微调基线 |

### 3.3 评价指标

- **风险类**：RF 回归风险（积分与逐时刻）；时间分辨验证风险。
- **分布类**：Sliced $W_2^2$、RBF MMD、模式质量 L1 误差、协方差 F 误差。
- **生成类**：Feature-FD、Inception-FID、KID、Conditional Accuracy/Confidence。
- **采样类**：不同 NFE（32、64）下的 Euler 采样。

## 6. 主要结论

1. **理论严格性**：在固定插值对的线性 RF + 岭正则化假设下，最优自蒸馏对**任何非平稳**教师严格改进 RF 速度风险。
2. **符号规则**：$\xi^{\star}$ 的符号与 $R'(\lambda)$ 相反——过正则化需要负向混合，欠正则化需要正向混合。
3. **一次性调参**：GCV / 验证集选出的 $\xi$ 接近 oracle，无需网格搜索。
4. **生成误差改善**：通过 Wasserstein 收敛界，最优 SD 改善连续时间和 Euler 离散生成上界中的速度误差项。
5. **纯蒸馏的反例**：纯蒸馏（$\xi=1$）会重复相同的压缩，在过正则化区域甚至**恶化**教师；将 $\xi$ 限制在 $[0,1]$ 会失去负向校正机会。
6. **神经扩展有效**：在 CIFAR-10 U-Net 上（$a=0.75$ 缩放教师），$\hat{\xi} = -1.225$，将 FID 从 284.26 降至 30.08，KID 从 0.3215 降至 0.0186。

## 7. 优点

- **理论完备性**：精确仿射路径 + 闭式最优解 + 严格改进定理，公式推导干净优雅。
- **跨界迁移**：将 Dang 等人（ridge regression 自蒸馏）的几何结构迁移到生成式 RF 速度匹配，给出新的分析样本。
- **符号规则的可解释性**：正/负 $\xi$ 对应欠/过正则化修正，有清晰的物理含义。
- **一次性调参**：GCV 估计避免了昂贵的网格搜索，并且无需求逆额外矩阵。
- **生成误差桥接**：通过 Bansal 等人的 RF Wasserstein 界，将速度风险改善转化为实际生成度量改善。
- **实证多样**：合成 + 图像 + 神经 U-Net 阶梯推进，覆盖度较平衡。
- **诚实陈述**：作者明确指出"有限步生成还依赖 Lipschitz、笔直性、ODE 稳定性、离散化等"，不夸大理论边界。

## 8. 不足与局限

- **线性假设**：严格改进定理仅对**线性 RF + 岭正则化**成立；非线性神经网络的对应保证仍是公开问题。
- **固定插值对**：与递归 Reflow 改变端点耦合的实践相反，与实际多轮训练场景有距离。
- **教师正则化局部性**：理论保证的是"对给定正则化水平的非平稳教师"局部修正，未声称全局最优教师。
- **类别偏置**：神经 CIFAR-10 实验构造了"刻意缩放"的失配教师（$a=0.75$），偏向于展示负向混合的修正能力；对未失配老师的增益较小（Table S2 中 Feature-FD 仅 9.88→9.38）。
- **算力报告缺失**：未披露 GPU 型号、训练时长等，实验难以复现。
- **下游指标无强保证**：定理仅控制速度风险，不直接保证 FID/KID 在所有设置下严格改进；部分实验（如 Spiral 时变混合）确实出现生成指标变差。
- **与主流基线对比少**：未与 DDIM 蒸馏、Progressive Distillation、Diffusion Self-Distillation 等近期方法直接比较。
- **应用域限制**：仅在视觉与二维密度上验证，未涉及文本、音频、视频等高维生成任务。
