## TL;DR

强化学习的评论器通常估计绝对状态价值，但控制只需要价值差异。本文提出相对价值学习（RV），通过反对称函数直接学习状态间的价值差，构造的成对Bellman算子被证明具有$\gamma$-收缩性，确保收敛到真实价值差。核心贡献包括适定的多步回报目标、无偏的策略梯度估计器R-GAE，以及轨迹排序初始化来控制方差。在49款Atari游戏中，RV嵌入PPO后取得了与标准PPO相当的性能，证明相对价值是绝对评论器的有效替代。

## 研究背景与动机

强化学习中的评论器（critic）传统上估计的是绝对状态价值函数$V^\pi(s)$，即在给定策略下从状态$s$开始的期望累计折扣奖励。这个绝对值衡量的是"这个状态本身有多好"。然而，当我们审视强化学习的控制目标时，会发现一个根本性的不对称：**决策行为——无论是贪心选择$\max_a Q^\pi(s,a)$还是计算优势函数$A^\pi(s,a)=Q^\pi(s,a)-V^\pi(s)$——本质上只依赖于状态或动作之间的相对差异**。

这种不对称性揭示了一个长期被忽视的"规范自由度"（gauge freedom）问题。对任意常数$c$，将价值函数平移为$V'(s)=V(s)+c$，同时将奖励塑形为$r'(s)=r(s)+(1-\gamma)c$，新的价值函数仍然满足Bellman方程，但更重要的是，所有动作偏好和优势函数保持完全不变。这意味着当我们只需要相对排序来做决策时，绝对标定是一个多余的自由度——它不仅没有提供决策所需的信息，还可能引入不必要的复杂性。

规范自由度在多个实际场景中造成具体困扰。在基于人类反馈的强化学习（RLHF）中，人类通常给出的是两两比较或偏好信号，而非绝对评分。在奖励塑形场景中，基线选择的变化会导致绝对价值飘移，但决策边界不应随之改变。在分布式强化学习中，不同worker的critic可能学到相差甚远的绝对值偏移，合并时需要额外校准。这些问题共同指向一个方向：**与其学习一个本质上不确定的绝对值，不如直接从价值差异出发。**

## 方法

基于上述洞察，作者提出相对价值学习（RV），其核心是学习一个反对称配对函数$\Delta_\theta(s_i, s_j)$来近似真实价值差$\Delta^\pi(s_i, s_j)=V^\pi(s_i)-V^\pi(s_j)$。这个函数必须满足$\Delta_\theta(s_i, s_j)=-\Delta_\theta(s_j, s_i)$和$\Delta_\theta(s,s)=0$这两个约束，它们由网络架构天然保证：使用孪生编码器提取状态特征，然后将两个特征的差通过一个无偏置的线性投影。

形式上，作者引入**成对Bellman恒等式**。假设从状态$s_i$和$s_j$分别独立采样下一个状态$s'_i$和$s'_j$，有：

$$\Delta^\pi(s_i, s_j) = r^\pi(s_i) - r^\pi(s_j) + \gamma\,\mathbb{E}_{s'_i, s'_j}\left[\Delta^\pi(s'_i, s'_j)\right]$$

这推广了标准的单状态Bellman方程到配对形式。基于此，作者定义**成对Bellman算子**$\mathcal{T}^\pi$。一个关键的理论结果是定理3.1：在有界函数空间中，成对Bellman算子是$\gamma$-收缩的，即

$$\|\mathcal{T}^\pi \Delta_1 - \mathcal{T}^\pi \Delta_2\|_\infty \leq \gamma \|\Delta_1 - \Delta_2\|_\infty$$

由Banach不动点定理，这保证了唯一不动点的存在性，且该不动点恰好等于真实价值差$\Delta^\pi$。这为整个框架奠定了理论基础。

有了收缩算子，接下来需要构造可学习的回报目标。作者详细推导了**1步目标**，处理了终局状态带来的技术挑战——当$s_i$或$s_j$为终局时，期望中的下一项需要根据四种终局组合（00、01、10、11）分别给出明确定义，避免分母为零的未定义情况。更一般地，**n步目标**为：

$$y^{(n)}_{ij} = \sum_{k=0}^{n-1}\gamma^k (r_{i+k} - r_{j+k}) + \gamma^n \Delta_\theta(s_{i+n}, s_{j+n})$$

通过指数加权混合多个n步目标，可以得到**$\lambda$-回报目标**。

策略梯度的核心是需要优势估计。作者提出了**R-GAE（相对广义优势估计）**。其构造颇为巧妙：首先定义一个"零锚定"的相对价值序列，以$\widetilde{V}_\theta(s_0)=0$开始，然后通过累积$\Delta_\theta$构建每个状态的相对价值：

$$\widetilde{V}_\theta(s_t) = \sum_{k=0}^{t-1}\Delta_\theta(s_{k+1}, s_k)$$

由此定义相对TD残差$\tilde{\delta}_t = r_t + \gamma \widetilde{V}_\theta(s_{t+1}) - \widetilde{V}_\theta(s_t)$，并类似标准GAE构造优势估计$\tilde{A}_t = \sum_{l=0}^{T-t}(\gamma\lambda)^l \tilde{\delta}_{t+l}$。

一个重要发现是引理3.2揭示的代数关系：$\tilde{A}_t = A_t + B_t$，其中$B_t$是一个轨迹常数项，与初始状态的真实价值相关。关键在于推论3.3：当将R-GAE优势代入[[策略梯度]]估计器时，$B_t$在给定历史轨迹下的条件期望为零，因此**策略梯度估计仍然无偏**。唯一的代价是方差会增加一个与$B_t^2$成正比的项。

为了控制这个方差项，作者提出**轨迹排序初始化**（Trajectory Ranking）。其思想是在batch中抽取多个轨迹的起始状态，构建价值差矩阵，用行均值减去batch最小值得到一个非负偏移估计。这个偏移量作为相对价值的"伪绝对参考点"，使得不同轨迹的价值估计对齐到相近的尺度，从而让$B_t$在期望意义上趋近于零。

最终的训练目标将PPO的策略损失与相对critic的回归损失以及熵正则化项相结合。值得注意的是配对采样的设计：33%的配对来自同一轨迹（提供短期差异信号），67%来自随机配对（提供跨轨迹的相对排序信号）。

## 实验与结果

实验在[[Atari]]基准的Arcade Learning Environment（ALE）上进行，涵盖49款游戏，使用标准的PPO预处理流程（84×84灰度图、4帧堆叠、frame skip等），训练40M帧。作者将PPO+RV与标准PPO以及直接优势估计（DAE）进行对比，后者是近期一个相关的基线方法。

在单游戏层面，PPO+RV在30/49（61%）款游戏中超越了标准PPO，在37/49（75%）款游戏中超越了DAE。聚合指标方面，作者使用了IQM（区间四分位数均值）、中位数和最优性差距等鲁棒统计量。结果显示，PPO+RV在所有聚合指标上全面优于DAE，与标准PPO相当或略有优势。特别值得注意的是，PPO+RV在某些游戏中展现出显著提升，而几乎没有出现灾难性的性能下降。

消融实验验证了轨迹排序初始化的有效性：相比简单的零初始化，带偏移的初始化在大多数游戏上表现更好，证实了控制$B_t$方差的理论预期。配对采样策略的消融则表明，同轨迹配对比例过高时会损害性能，可能是因为这种配对丢失了跨轨迹的相对排序信息。

## 讨论与可借鉴点

这项工作的核心贡献在于理论层面：它将"控制只看相对差异"这一直觉严格化，构造了一套自洽的算子理论和学习目标。从这个角度看，成对Bellman算子的$\gamma$-收缩性是一个漂亮的结果，它说明在[[价值函数学习]]中消除规范自由度并不会牺牲收敛保证。

然而，这项工作也面临若干局限。首先，轨迹常数$B_t$虽然在策略梯度无偏性上被"消除"，但其方差效应仍然存在，轨迹排序初始化只是部分缓解了这一问题——论文自己也承认没有给出完整解决方案。其次，相对critic的表达力受到反对称结构的约束，强制要求$\Delta_\theta(s,s)=0$可能限制了某些需要偏离这一约束的表示。

从实践角度，RV提供一个即插即用的critic替代方案：网络架构和超参数几乎不需要改变，就可以在标准PPO框架中尝试。在偏好学习或人类反馈强化学习场景中，由于人类天然给出的是相对偏好信号而非绝对评分，RV可能有更大的用武之地，但论文目前只在监督式Atari游戏上验证，连续控制或其他[[强化学习]]范式的表现仍是未知数。

对于研究者而言，这篇论文提供了一个值得借鉴的思路：**从决策需求反推学习目标**。当发现某个看似必要的设计（如绝对价值估计）实际上与最终目标（如动作选择）无关时，重新审视其必要性可能带来理论简化与实践改进的契机。

## 摘要
在强化学习中，评论器通常估计绝对状态价值 $V(s)$，评估某个特定情境在孤立状态下的好坏。然而，事实上只有价值差异才对控制具有意义。受此启发，我们提出了相对价值学习（RV），一个通过反对称函数 $Δ(s_i, s_j) = V(s_i) - V(s_j)$ 直接学习价值差异的框架。我们引入成对 Bellman 算子，并证明其为 $γ$-收缩算子，存在唯一不动点等于真实价值差异；推导了适定的 $1$ 步、$n$ 步及 $\lambda$-回报目标；并基于成对差异重构广义优势估计，得到无偏的策略梯度估计器（R-GAE）。除理论结果外，我们将 RV 与 PPO 相结合，在 Atari 基准测试（49 个 ALE 游戏）上取得了与标准 PPO 相当的竞争性能，表明相对价值估计是绝对评论器的有效替代方案。

## Abstract
In reinforcement learning, critics typically estimate absolute state values $V(s)$, estimating how good a particular situation is in isolation. However, it turns out that only differences in value are relevant for control. Motivated by this, we propose Relative Value Learning (RV), a framework that learns value differences directly via an antisymmetric function $Δ(s_i, s_j) = V(s_i) - V(s_j)$. We introduce a pairwise Bellman operator and prove it is a $γ$-contraction with a unique fixed point equal to the true value differences, derive well-posed $1$-step, $n$-step and $λ$-return targets and reconstruct generalized advantage estimation from pairwise differences to obtain an unbiased policy-gradient estimator (R-GAE). Beyond theoretical results, we integrate RV with PPO and achieve competitive performance on the Atari benchmark (49 ALE games) compared to standard PPO, indicating that relative value estimation is an effective alternative to absolute critics.

# 论文详细总结：Relative Value Learning（相对价值学习）

## 1. 核心问题与研究动机

- **量纲冗余问题**：在标准强化学习中，评论器（critic）通常估计**绝对状态价值** $V^{\pi}(s)$，但决策（如贪心动作选择 $\max_a Q^{\pi}(s,a)$ 或优势函数 $A^{\pi}(s,a)$）只依赖状态/动作间的**相对差异**。对任意常数 $c$ 平移 $V^{\pi}$ 后，所有动作偏好和优势都保持不变——这是一个固有的"规范自由度"（gauge freedom）。
- **绝对标定的副作用**：绝对值标定带来不必要的自由度，对奖励塑形（reward shaping）或基线变化敏感；在只给定两两比较/偏好反馈的人类反馈 RL 场景下，绝对标定的合理性更成问题。
- **研究视角的转变**：把"价值差异"放在首位，作为 critic 学习的基本对象，消除规范自由度并对齐决策本身的相对不变性。

## 2. 方法论

### 2.1 核心思想

学习一个**反对称配对差分函数**：
$$\Delta_\theta(s_i, s_j) = -\Delta_\theta(s_j, s_i),\quad \Delta_\theta(s,s)=0$$
近似真实价值差 $\Delta^{\pi}(s_i, s_j) := V^{\pi}(s_i) - V^{\pi}(s_j)$。

### 2.2 关键技术细节

- **成对 Bellman 恒等式（独立采样两个后继状态）**：
$$\Delta^{\pi}(s_i, s_j) = r^{\pi}(s_i) - r^{\pi}(s_j) + \gamma\,\mathbb{E}_{s'_i, s'_j}\!\left[\Delta^{\pi}(s'_i, s'_j)\right]$$

- **成对 Bellman 算子**（在反对称有界函数 Banach 空间 $\mathcal{F}$ 上）：
$$(\mathcal{T}^{\pi}\Delta)(s_i, s_j) := \Delta_{r^{\pi}}(s_i, s_j) + \gamma\,(\widehat{P}^{\pi}\Delta)(s_i, s_j)$$

- **定理 3.1（$\gamma$-收缩与唯一性）**：
$$\|\mathcal{T}^{\pi}\Delta_1 - \mathcal{T}^{\pi}\Delta_2\|_\infty \le \gamma\|\Delta_1 - \Delta_2\|_\infty$$
由 Banach 不动点定理，$\mathcal{T}^{\pi}$ 有唯一不动点 $\Delta^{\pi}$。

- **规范不变性**（Lemma B.1）：对 $V^{\pi}$ 加任意常数 $c$（配合 reward shaping $r' = r+(1-\gamma)c$），得到的 $V^{\pi'}$ 仍满足 Bellman 方程，且 $A^{\pi'} = A^{\pi}$、$\Delta^{\pi'} = \Delta^{\pi}$。

- **适定目标的推导**（应对终局状态让目标分母无法定义的难题）：

  **1-step 目标**：
$$y^{(1)}_{ij} := (r_i - r_j) + \gamma\,\delta_{ij}$$
其中按 $(d_i, d_j) \in \{0,1\}^2$ 四种终局组合给出 $\delta_{ij}$ 的具体形式（例如两者皆终局时 $\delta_{ij}=0$，单边终局时使用 $\Delta_\theta(s_i, s_{j+1}) - r_i$ 等）。

  **n-step 目标**：
$$y^{(n)}_{ij} = \sum_{k=0}^{n-1}\gamma^k (r_{i+k} - r_{j+k}) + \gamma^n \Delta_\theta(s_{i+n}, s_{j+n})$$
  **$\lambda$-回报目标**：以权重 $(1-\lambda)\lambda^{n-1}$ 混合多个 $n$-step 目标。

- **R-GAE（相对广义优势估计）**：

  通过"零锚定"构造相对值序列 $\widetilde{V}_\theta(s_0):=0,\ \widetilde{V}_\theta(s_t):=\sum_{k=0}^{t-1}\Delta_\theta(s_{k+1}, s_k)$，定义相对 TD 残差和优势：
$$\tilde{\delta}_t := r_t + \gamma \widetilde{V}_\theta(s_{t+1}) - \widetilde{V}_\theta(s_t),\quad \tilde{A}_t := \sum_{l=0}^{T-t}(\gamma\lambda)^l \tilde{\delta}_{t+l}$$

- **关键定理**（Lemma 3.2 / Corollary 3.3）：
$$\tilde{A}_t = A_t + B_t,\quad B_t = (1-\gamma)C\sum_{l=0}^{T-t}(\gamma\lambda)^l,\ \ C=V^{\pi}(s_0)$$
代入策略梯度后，由于 $B_t$ 在给定历史下的条件期望消失，$\nabla_\phi \tilde{J}(\phi) = \nabla_\phi J(\phi)$，即**仍然无偏**，但方差正比于 $C^2$（Lemma C.1）。

- **轨迹排序初始化（Trajectory Ranking, §4）**：为缓解 $B_t$ 对长 horizon 的方差放大，作者提出：跨多个 rollout 抽取其"开始状态"，构建 $N\times N$ 的 $\Delta_\theta$ 矩阵，用行均值减去 batch 内最小值得到非负偏移估计 $\bar{V}_\theta$：
$$\bar{V}_\theta(s) = \hat{V}_\theta(s_{\text{start}}) + \Delta_\theta(s, s_{\text{start}})$$
期望让 $\mathbb{E}_t[B_t] \approx 0$。

- **网络结构**：与 PPO 相同的 CNN 编码器 $f_{\text{enc}}$ 共享，相对 critic 用孪生差分头
$$\Delta_\theta(s_i, s_j) = \Phi\!\left(f_{\text{enc}}(s_i) - f_{\text{enc}}(s_j)\right)$$
其中 $\Phi$ 取为单一向量 $w^\top(\cdot)$（无偏置），**由构造保证反对称性和 $\Delta_\theta(s,s)=0$**。

- **训练目标**：
$$\mathcal{L}(\theta) = -\mathcal{L}_{\text{policy}}(\theta) + c_v\,\mathcal{L}_{\text{critic}}(\theta) + c_e\,\mathcal{L}_{\text{ent}}(\theta)$$
其中
$$\mathcal{L}_{\text{policy}}(\theta) = \mathbb{E}_t\left[\min\bigl(r_t(\theta)\tilde{A}_t,\ \text{clip}(r_t(\theta),1-\epsilon,1+\epsilon)\tilde{A}_t\bigr)\right]$$
$$\mathcal{L}_{\text{critic}}(\theta) = \mathbb{E}_{(i,j)\sim\mu}\!\left[\bigl(\Delta_\theta(s_i,s_j) - y^{(n)}_{ij}\bigr)^2\right]$$
对采样策略 $\mu$：33% 同轨迹、67% 随机配对（Appendix E 消融）。

## 6. 主要结论与发现

- **理论方面**：
  - 成对 Bellman 算子是 $\gamma$-收缩，有唯一不动点=真实价值差。
  - 1/n-step/$\lambda$ 回报目标在反对称差分函数空间内**适定可采样**。
  - **R-GAE 是标准 GAE 的相对版本**：$\tilde{A}_t = A_t + B_t$，其中 $B_t$ 是依赖零锚点的轨迹常数。
  - 替换 $\tilde{A}_t$ 进入策略梯度**仍保持无偏**（Corollary 3.3），只是方差多出 $\propto B_t^2$ 的噪声项。

- **实证方面**：
  - **PPO+RV 在 30/49 (61%) 游戏上超过 PPO**；37/49 (75%) 超过 DAE。
  - 聚合 IQM / Median / Optimality Gap 等指标全面优于 DAE，与 PPO 相当或略有优势（Figure 3）。
  - **轨迹排序初始化**消融显示，对多数游戏而言有偏估计优于零初始化（Figure 4）。
  - 配对采样对性能影响较小，但当 $p$（同轨迹概率）过大时性能有所下降（Table 4）。

## 8. 不足与局限

- **轨迹常数 $B_t$ 仍是方差源**：仅被部分缓解（per-trajectory 锚点替代 zero），长 horizon 或 $\gamma\lambda \to 1$ 时方差仍显著，论文并未给出完整解决方案。
- **critic 表达力受限**：强制反对称结构 + 单一向量投影（实际近似 linear head）可能在某些游戏上欠拟合，非线性反对称头的潜力未被充分挖掘。
- **配对训练的 $\mathcal{O}(B^2)$ 复杂度**：批大小 $B$ 上为二次复杂度，需要子采样才能实用，从而以方差换计算。
- **轨迹排序假设**：要求 batch 内各轨迹的后基线值在同一可比较尺度上；若不同 episode 的真实值差极大或排序信号本身被噪声主导，初始化可能退化为无效。
- **实验覆盖窄**：仅在 on-policy PPO + 离散动作 Atari 上验证；连续动作控制、off-policy 设置、偏好/HITL-RL 等论文宣称最适用的场景**没有实证支持**。
- **过度规范化风险**：理论上规范自由度对控制无意义，但在追求可解释性或下游使用（e.g., 折扣回报分解、终身价值迁移）时，绝对值的缺失可能成为阻碍。
- **Atari 噪声大**：10 颗种子在 Atari 上的标准差常常很大，单游戏胜负的统计显著性存疑，部分结论（如"60%+ 游戏胜 PPO"）应结合 IQM 等聚合指标解读。
