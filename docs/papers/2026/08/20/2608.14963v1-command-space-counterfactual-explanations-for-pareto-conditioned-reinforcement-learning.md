## 摘要
帕累托条件网络通过将单一策略以期望回报命令为条件，学习多种多目标强化学习行为。然而，从命令和状态到动作的局部映射仍然是不透明的。我们针对帕累托条件网络提出命令空间反事实解释：在黑盒设定下，给定固定状态、原始命令以及替代动作，我们搜索一个变化最小的期望回报命令，在该命令下同一训练好的策略会选择该替代动作。我们的贡献有三方面。首先，我们将帕累托条件网络的解释形式化为回报命令干预，使用仅回报的帕累托条件网络变体，以避免水平条件化带来的额外歧义。其次，我们将对抗性机器学习方法适配于强化学习的解释。第三，我们引入一种边界种子化的方向搜索方法，在命令-动作空间中优于纯局部优化，从而提出我们的方法 CF-ZOO。所得的解释具有可操作性，并以用户自身的偏好直观表达："如果你的权衡稍微偏向 X，智能体本会选择 Y。"

## Abstract
Pareto Conditioned Networks learn multiple multi-objective reinforcement learning behaviours by conditioning a single policy on a desired return command. However, the local mapping from command and state to action remains opaque. We propose command-space counterfactual explanations for PCNs: given a fixed state, original command, and foil action, we search, in a black-box setting, for a minimally changed desired-return command under which the same trained policy would choose the foil. Our contributions are threefold. First, we formulate PCN explanations as return-command interventions, using a return-only PCN variant that avoids the added ambiguity of horizon-conditioning. Second, we adapt adversarial machine learning methods to reinforcement-learning explanations. Third, we introduce a boundary-seeded directional search that improves over purely local optimization in the command-action landscape, resulting in our proposed approach CF-ZOO. The resulting explanations are actionable and intuitively expressed in the user's own preferences: "If your trade-off had shifted slightly towards X, the agent would have chosen Y."

## 1. 核心问题与研究背景

Pareto Conditioned Networks（PCN）通过将单一策略以期望回报向量 $\mathbf{R}^{des}_t$（甚至 horizon）为条件，学习一族 Pareto 最优的多目标强化学习（MORL）行为。然而，**命令-状态-动作的局部映射是一个神经黑盒**：尽管 desired-return 命令本身在目标空间中可解释，但给定状态下策略为何选择该动作并不透明。这一"可解释接口"缺口限制了 PCN 在决策支持场景中的应用。

论文观察到：现有 RL 反事实工作主要关注**视觉状态反事实**（Olson 2021、Huber 2023、Samadi 2024）、**可达性反事实**（RACCER）、**多样化反事实动作序列**（ACTER）以及**策略本身的反事实修改**，但**没有针对 PCN 独有的"用户输入偏好"接口**——即 desired-return 命令本身。论文因此提出一类新的反事实问题：固定状态与训练策略，最小幅度的命令扰动 $\delta\mathbf{R}$ 即可让同一策略选择不同的 foil 动作 $a_f$。这种解释以用户偏好自然语言呈现（"如果你的权衡稍微偏向 X，智能体会选择 Y"），因而是天然可操作的。

## 2. 方法论

### 2.1 Return-Only PCN 变体

原始 PCN 形式化为：
$$\pi_\theta(a_t \mid s_t, \mathbf{R}^{des}_t, h^{des}_t)$$

作者通过实证发现 horizon 输入在测试中并不提供稳定的时序控制，因此**移除 horizon 维度**，采用：
$$\pi_\theta(a_t \mid s_t, \mathbf{R}^{des}_t)$$

并通过偏好更短轨迹、对 reward-neutral 后缀进行剪枝等后处理保持性能。这简化了命令空间：反事实只需 $ \mathbf{R} \mapsto \mathbf{R} + \delta\mathbf{R}$，避免 $(R, h) \mapsto (R + \delta R, h + \delta h)$ 的双变量歧义。

### 2.2 命令空间反事实定义

给定状态 $s_t$、当前命令 $\mathbf{R}_t$、foil 动作 $a_f \neq a^\star$（贪心动作），寻找扰动 $\delta\mathbf{R}$ 使得：
$$a_f = \arg\max_{a \in \mathcal{A}(s_t)} \ell_a(s_t, \mathbf{R}_t + \delta\mathbf{R})$$

其中 $\ell_a$ 为 PCN 输出动作 $a$ 的对数概率。

### 2.3 优化目标

借鉴 Carlini–Wagner（C&W）有目标攻击与 ZOO 的边缘结构，定义目标 foil 边缘：
$$M_f(\mathbf{R}) = \ell_{a_f}(s_t, \mathbf{R}) - \max_{a \in \mathcal{A}(s_t),\, a \neq a_f} \ell_a(s_t, \mathbf{R})$$

并设 hinge 项 $H_f(\mathbf{R}) = \max\{\kappa - M_f(\mathbf{R}), 0\}$，$\kappa \geq 0$。最终黑盒目标：
$$L(\delta) = \|\delta\|_2^2 + c\, H_f(\Pi_C(\mathbf{R}_t + \delta))$$

其中 $c > 0$ 控制 flip 惩罚强度，$\Pi_C$ 将命令投影到可行盒 $\mathcal{C} = \{\mathbf{R} : \mathbf{R}_{\min} \leq \mathbf{R} \leq \mathbf{R}_{\max}\}$。

### 2.4 边界种子化方向搜索（Boundary-Seeded Directional Search）

**动机**：纯局部 C&W/ZOO 优化在命令-动作景观平坦或非凸、远离 foil 区域时容易陷入局部解。

**核心步骤**：
1. **方向启发**：利用训练时记录的 Pareto 前沿 $\mathcal{F} = \{\mathbf{R}^{front}_j\}_{j=1}^N$，计算剩余命令 $\tilde{\mathbf{R}}_j = \mathbf{R}^{front}_j - \mathbf{R}^{col}_t$，并选择 foil 边缘最大者 $\mathbf{R}_{j^\star}$，由此推断粗粒度方向符号 $\mathbf{d} = \tilde{\mathbf{R}}_{j^\star} - \mathbf{R}_t$。
2. **方向限制**：依据 $\mathbf{d}$ 各分量符号约束后续射线搜索的单调性。
3. **射线搜索**：从标准高斯 $\mathbf{v} \sim \mathcal{N}(0, I_d)$ 抽取单位方向 $\mathbf{u}$，沿射线
$$\mathbf{R}(\alpha; \mathbf{u}) = \mathbf{R}_t + \alpha D\mathbf{u},\quad \alpha \geq 0$$
   搜索，$D = \mathrm{diag}(\mathbf{R}_{\max} - \mathbf{R}_{\min})$ 为按维度尺度化矩阵。
4. **二分回溯**：若射线终点满足 $M_f(\mathbf{R}(\alpha; \mathbf{u})) \geq \kappa$，则用 16 步二分搜索将其回拉至距离原命令最近的可行 foil 点。
5. **失败回退**：若无射线成功，则退回原始 $\mathbf{R}_t$ 处的局部 ZOO。

### 2.5 ZOO-ADAM 局部精修

对每个坐标 $i$，采用中心差分估计：
$$\hat{\nabla}_i L(\delta) = \frac{L(\delta + h\mathbf{e}_i) - L(\delta - h\mathbf{e}_i)}{2h}$$

使用 $\beta_1=0.9$、$\beta_2=0.999$、$\eta=0.01$、$h=10^{-3}$ 的 ADAM 更新（即 ZOO-ADAM）。每次迭代需 3 次 PCN 查询（2 次有限差分 + 1 次更新验证）。

### 2.6 CF-ZOO 整体算法

$$\text{CF-ZOO} = \underbrace{\text{边界种子方向搜索}}_{\text{全局方向初始化}} \;\to\; \underbrace{\text{ZOO-ADAM 局部精修}}_{\text{黑盒精炼}}$$

## 6. 主要结论与发现

1. **CF-ZOO 显著优于白盒 C&W 基线**：在 797 个用例中达到 79.9% 成功率，而 WHITE-CW 仅 40.4%。这表明**局部初始化质量比梯度可访问性更重要**——白盒梯度在命令-动作景观中常陷入失败局部解。
2. **Boundary seeding 是关键**：除 Fruit-Tree 几乎所有环境都呈现大幅提升；压力测试中 75.8%（2422/3195）总体成功率。
3. **失败可被分解**：78.7% 成功、16.6% 网格不可行 foil（PCN 未学到该行为）、4.7% 搜索受限失败。在**已知可行的 foil**子集中，CF-ZOO 恢复率达 94.4%，剩余 5.6% 为高预算下仍难以定位的反事实。
4. **环境敏感度**：Collect-Two 与 Fruit-Tree 接近 100%；Minecart、Reward-Line 高成功率；DST 与 Resource-Gathering 较低，揭示这些环境中**状态或训练分布对 foil 行为的强约束**。
5. **解释具备稀疏性、可操作性**：成功反事实通常仅修改 1–2 个目标维度，且新命令 $R^{cf}$ 可直接由用户下发到同一训练好的策略。
