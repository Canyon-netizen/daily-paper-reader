## 摘要
在策略自蒸馏（OPSD）借助策略自身轨迹上的特权自教师，为语言智能体提供稠密的 token 级监督。现有方法主要依据教师信任度来分配这种监督，但信任度并不能揭示强调某个 token 是否契合当前策略目标。我们将这一现象称为信任-效用失配，并提出自蒸馏影响校准（ICSD）。对于每个受监督的 token，ICSD 度量其重要性加权的强化学习替代损失贡献对教师导向输出扰动的一阶响应。批量自适应校准将这一非平稳信号转换为有界分配权重，同时在每个动作回合内保留原始辅助损失总量。这些解耦的权重仅作用于蒸馏损失，无需额外的模型前向计算。在 ALFWorld、WebShop 和 Search-QA 任务上，覆盖 1.5B 至 7B 的两个模型族，ICSD 在组相对策略优化（GRPO）与组中组策略优化（GiGPO）下，相对仅基于信任度的分配方案均提升了所有匹配的综合指标。在 7B 模型上，ALFWorld 任务成功率可达 96.1%，WebShop 任务得分可达 93.1。冻结批次分析表明，ICSD 将分配至目标对立 token 的教师支持质量从 60.1% 降至 37.8%，并将与强化学习梯度的余弦兼容性提升 0.192。配套代码仓库见 https://github.com/lanqz7766/Influence-Calibration-for-On-Policy-Self-Distillation-in-Agentic-RL。

## Abstract
On-policy self-distillation (OPSD) gives language agents dense token-level supervision from a privileged self-teacher on the policy's own trajectories. Existing methods allocate this supervision mainly by teacher trust, but trust does not reveal whether emphasizing a token supports the current policy objective. We call this the trust-utility mismatch and introduce Influence Calibration for Self-Distillation (ICSD). For each supervised token, ICSD measures the first-order response of its importance-weighted RL surrogate contribution to a teacher-directed output perturbation. Batch-adaptive calibration converts this non-stationary signal into a bounded allocation weight while preserving the original auxiliary-loss mass within each action turn. These detached weights affect only the distillation loss and require no additional model pass. Across ALFWorld, WebShop, and Search-QA, ICSD improves all matched aggregate metrics over trust-only allocation under Group Relative Policy Optimization (GRPO) and Group-in-Group Policy Optimization (GiGPO), across two model families spanning 1.5B to 7B. At 7B, it reaches 96.1% ALFWorld success and a WebShop score of 93.1. Frozen-batch analyses show that ICSD reduces teacher-supported mass assigned to objective-opposed tokens from 60.1% to 37.8% and raises cosine compatibility with the RL gradient by 0.192. A companion repository is avail- able at https://github.com/lanqz7766/Influence-Calibration-for-On-Policy-Self-Distillation-in-Agentic-RL.

## 1. 核心问题与研究动机

**问题定义**：在策略自蒸馏（On-Policy Self-Distillation, OPSD）框架下，特权自教师在策略自身采样的轨迹上为每个 token 提供稠密监督。现有方法（如 SDAR、Skill-SD、SAGE-OPD 等）主要依据 **教师信任度（teacher trust）** 来分配蒸馏权重，例如通过教师-学生差距 $\Delta_t$、熵、不确定性或位置偏差等估计"该信号是否可信"。

**信任-效用失配（trust–utility mismatch）**：作者指出"信任"与"效用"是两个不同维度——

- 信任回答：教师信号是否**可信**？
- 效用回答：沿着该信号更新是否**契合当前 RL 目标**？

两个 token 即使获得相同的信任度权重 $g_t$，其一可能落在优势函数 $A_t$ 支持的动作回合（应强化），而另一个位于优势函数惩罚的回合（应抑制）。在冻结的 ALFWorld 批次上，仅靠信任度分配会把 **60.1%** 的教师支持质量放在目标对立的 token 上。

**研究意义**：在长视野智能体任务中，奖励仅在回合末尾稀疏到达，token 级密集监督的分配方式直接影响策略改进步伐。该问题在 GRPO/GiGPO 等 on-policy 优化算法与多轮工具调用场景中尤为关键。

## 2. 方法论：影响校准自蒸馏（ICSD）

### 2.1 总体设计

ICSD 不修改 RL 替代损失 $L_{RL}$，而是为已存在的 OPSD 辅助分支重新分配 token 权重 $c_t$，在不增加辅助损失总量（与 SDAR 完全相等）的前提下，将可信教师信号向"目标支持的"token 倾斜。

### 2.2 关键数学构件

**（a）特权蒸馏基线**

$$\hat{\ell}^{KD}_t(\theta) = \mathrm{sg}\!\left[\log\pi^+_\theta(a_t|x_t,z_t)\right] - \log\pi_\theta(a_t|x_t)$$

$$\Delta_t = \mathrm{sg}\!\left[\log\pi^+_\theta(a_t|x_t,z_t) - \log\pi_\theta(a_t|x_t)\right]$$

继承 SDAR 的信任权重 $g_t = G_{\text{trust}}(\Delta_t) \in [0,1]$。

**（b）教师方向的目标影响得分**

对采样 token 的对数概率做教师方向扰动：

$$\log\rho_t(\epsilon) = \log\rho_t + \epsilon\Delta_t,\quad \rho_t(\epsilon) = \rho_t e^{\epsilon\Delta_t}$$

其对 token 替代贡献 $J_t = \hat{A}_t \rho_t$ 的一阶 Taylor 系数为：

$$u_t := \left.\frac{d \hat{A}_t \rho_t(\epsilon)}{d\epsilon}\right|_{\epsilon=0} = \hat{A}_t \rho_t \Delta_t$$

Taylor 余项由 $\frac{1}{2}|\hat{A}_t|\rho_t\Delta_t^2 e^{|\epsilon\Delta_t|}$ 界定（见附录 A.1）。

**（c）批量自适应校准（Asymmetric Laplace CDF）**

$u_t$ 的尺度随优势、策略比与差距漂移且呈重尾。按动作回合索引将 token 分组 $G$，用中位数与单侧均值拟合位置 $\hat{\mu}_G$ 与两侧尺度 $\hat{b}^-_G,\hat{b}^+_G$（下界 $\varepsilon$）：

$$\Phi_G(u) = \begin{cases} \eta \exp\!\left(\dfrac{u-\hat{\mu}_G}{\hat{b}^-_G}\right), & u < \hat{\mu}_G \\[6pt] 1-(1-\eta)\exp\!\left(-\dfrac{u-\hat{\mu}_G}{\hat{b}^+_G}\right), & u \ge \hat{\mu}_G \end{cases}$$

令 $\tilde{m}_t = \Phi_G(u_t) \in (0,1)$，$\eta = 0.5$。

**（d）保守合成（Conservative Composition）**

当 $\hat{A}_t<0$ 且 $\Delta_t<0$ 时，扰动方向与辅助更新方向冲突，保留 $g_t$：

$$D=\{t:\hat{A}_t<0,\Delta_t<0\},\quad C=B\setminus D$$

**（e）动作回合质量匹配**

对每个动作回合 $q$，在 $C_q$ 上重标定系数，使回合内辅助质量严格守恒：

$$\alpha_q = \frac{\sum_{j\in C_q} g_j}{\sum_{j\in C_q} g_j \tilde{m}_j}$$

$$c_t = \begin{cases} g_t, & t\in D_q \\ \alpha_q\,g_t\tilde{m}_t, & t\in C_q \end{cases}$$

$$\sum_{t\in q} c_t = \sum_{t\in q} g_t \quad \forall q$$

**（f）命题 1（关键不变性）**：$\Phi_G$ 对 $u$ 上的正仿射变换 $u'_j = au_j+b\ (a>0)$ 不变，因而 $c_t$ 也保持不变，保证跨回合与训练阶段的可比性（完整证明见附录 A.2）。

### 2.3 算法流程（Algorithm A1）

输入：minibatch $B$（含动作回合分组）、蒸馏权重 $\lambda$、尺度下界 $\varepsilon$。

1. 滚动生成轨迹，计算 $\hat{A}_t, \rho_t$ 与学生 log 概率；
2. 评估 stop-gradient 特权分支 $\pi^+_\theta$，计算 $\Delta_t$ 与基线信任权重 $g_t$；
3. 计算解耦影响得分 $u_t = \hat{A}_t\rho_t\Delta_t$；
4. 在每个校准组 $G$ 上拟合 $(\hat{\mu}_G,\hat{b}^-_G,\hat{b}^+_G)$，得 $\tilde{m}_t = \Phi_G(u_t)$；样本不足时退回 minibatch 统计；
5. 形成 $D$ 与 $C$；
6. 对每个动作回合 $q$：若 $\sum_{j\in C_q}g_j\tilde{m}_j > \varepsilon$，按上式计算 $\alpha_q$ 与 $c_t$；否则退化到 $c_t = g_t$；
7. 解耦 $\{c_t\}$ 后做 actor 更新。

全程**不增加任何前向/反向传播**，仅 detached 算术运算。

## 3. 实验设计

### 3.1 数据集 / 任务

- **ALFWorld**（6 子任务：Pick/Look/Clean/Heat/Cool/Pick2）：文本交互式家庭任务，评估成功率。
- **WebShop**：在线购物网页交互，报告 Score 与 Accuracy。
- **Search-QA**（Search-R1 的 7 个子集）：NQ、TriviaQA、PopQA、HotpotQA、2WikiMultiQA、MuSiQue、Bamboogle。

### 3.2 模型与训练算法

- 模型族：**Qwen2.5-Instruct**（1.5B / 3B / 7B）+ **Qwen3**（1.7B / 4B）。
- 优化器：**GRPO** 与 **GiGPO**（$\gamma=0.95$）。
- 共享特权自教师与 SDAR SkillBank。

### 3.3 对比方法

- **基线**：Vanilla、Skill-Prompt*、OPSD、Skill-SD、Skill-GRPO、RLSD。
- **直接对照**：GRPO / GiGPO 各自 + SDAR / + ICSD（matched comparison）。
- **消融对照**（ALFWorld 1.5B + GiGPO）：Fisher magnitude、Sign-only、Influence-only。

### 3.4 协议

采用 SDAR 对齐协议：actor LR $=1\times10^{-6}$，ratio clip $0.2$，KL $0.01$（Search-QA $0.001$），$\lambda=0.01$，ICSD 训练步数 150（Search-QA 200）。

## 5. 实验数量与充分性

### 5.1 实验规模

- 主结果：4 个 Qwen2.5 模型（1.5B/3B/7B）+ 1 个 Qwen3 模型（1.7B）在 3 个 benchmark × 2 个优化器下作 matched comparison；
- 扩展对照：Vanilla / Skill-Prompt* / OPSD / Skill-GRPO(*) 等 4 类基线在 4 个模型上的汇总指标；
- Qwen3-4B 单独表格（ALFWorld × GiGPO）；
- 消融实验：6 个分配变体（GiGPO+SDAR、Fisher magnitude、Sign-only、Influence-only、ICSD、GiGPO）；
- 敏感性：$\eta_F$、$\lambda$、校准族（Laplace vs Gaussian）、影响信号类型 4 组；
- 机制分析：4 个 ALFWorld 冻结批次（544,427 tokens）的 TCM 与 16 个冻结批次的余弦兼容性分析；
- 学习曲线：GRPO / GiGPO 在 ALFWorld 与 WebShop 上的训练全过程。

总体实验**较为充分**，覆盖了多个模型族、两个优化器、三类任务，并在 token 级做了机制层面的可解释性验证。

### 5.2 公平性

- matched comparison：同模型、同数据、同特权自教师、同 SDAR 信任分配，仅替换为 ICSD；
- 公布基线复用 SDAR 论文报告值，其余来自作者训练日志；
- 配对 bootstrap（16 批次 × 95% CI）确保机制结论的统计稳健性；
- 剪裁暴露审计（$\le 0.128\%$ 被 clip 的 token）公开。

潜在偏差：
- ALFWorld 上 ICSD 优势最显著，Search-QA 上绝对增益较小（尤其在 1.5B 上）；
- 论文未报告多次随机种子的方差条棒，主结果表格是单次运行或 SDAR 报告值的对比。

## 6. 主要结论与发现

### 6.1 性能结果（表 1、表 2、表 3）

- **Qwen2.5-7B + GiGPO + ICSD**：ALFWorld 96.1%、Search-QA 49.1%、WebShop Score 93.1 / Acc 84.4，为全表最高；
- Qwen2.5-3B / 1.5B / Qwen3-1.7B 上 ICSD 均在 matched block 内全面优于 SDAR；
- **Qwen3-4B** ALFWorld Avg：SDAR 89.8 → ICSD 95.3（+5.5）；
- WebShop Accuracy 提升最显著：Qwen2.5-1.5B GRPO +11.7，GiGPO +7.0。

### 6.2 机制层面

- **TCM（trusted-conflict mass）**：在 4 个 ALFWorld 冻结批次上，SDAR 60.1% → ICSD 37.8%，下降 22.3 pp（95% CI [22.1, 22.6]）；
- **余弦兼容性 $\cos(\nabla L_{KD}, \nabla L_{RL})$**：16 个批次上平均提升 **+0.192**（95% CI [0.147, 0.240]），所有 16 个批次均为正向；置换对照仅 +0.020，证明提升源自 token 级匹配而非总质量；
- **符号区域再分配**：$\Delta_t>0,\hat{A}_t>0$ 增 +6.2 pp；$\Delta_t>0,\hat{A}_t<0$ 减 7.5 pp；$\Delta_t<0,\hat{A}_t>0$ 减 1.5 pp；双重负号区不变。

### 6.3 消融结论

- 单独 Fisher 幅度（无符号）91.4%，与 GiGPO 持平 → 幅度本身不够；
- 单独 Influence-only（无信任）93.0%；
- 符号二值（Sign-only）92.2%，与 SDAR 持平；
- 完整 ICSD（信任 × 连续有符号影响）93.8% → **三项缺一不可**。

## 7. 优点

- **机制清晰**：把"信任"与"效用"明确解耦，给出 teacher-directed 输出扰动下的一阶影响得分，理论上有 Taylor 余项界定；
- **轻量级**：无需任何额外前向/反向传播，仅 detached 算术 + CDF 拟合，端到端开销约 0.4%；
- **理论严谨**：附录给出 $\Phi_G$ 的单调性、仿射不变性、回合质量守恒与排序性的完整证明；
- **公平性强**：matched comparison 设计固定了模型、数据、教师、SDAR 信任分配，仅替换分配器；
- **可解释机制**：通过 TCM、余弦兼容性、四象限再分配三视角同时验证再分配方向；
- **跨族跨尺度泛化**：1.5B → 7B、Qwen2.5 / Qwen3、GRPO / GiGPO 一致提升；
- **超参数稳健**：CDF 分割 $\eta=0.5$、$\lambda=0.01$、Laplace 校准族均经敏感性扫描；
- **运行时审计公开**：clip 暴露比例、双 clip 上限、pooled ratio 分布等小但关键的工程细节均披露。

## 8. 不足与局限

- **训练算力披露不完整**：仅给 1.5B WebShop 4×H100 的开销，7B / 4B 模型规模下的 GPU 数与总训练时长未说明；
- **方差与显著性报告不足**：主结果缺少多次随机种子运行的均值±标准差，部分指标增益较小（特别是 Search-QA 在 1.5B 上的绝对提升在 1pp 以内）；
- **Search-QA 收益相对温和**：7 个子集上 ICSD 优势普遍小于 ALFWorld / WebShop，提示在短回合、单步决策任务中，影响校准的边际效用有限；
- **应用限制**：
  - 假设存在特权分支（额外上下文 $z_t$，如 trajectory-derived skill），在无特权信息的纯在线 RL 场景无法直接使用；
  - 校准组按动作回合索引聚合，需依赖回合边界信息，回合结构化程度低的任务可能受影响；
  - 校准依赖每回合至少 8 个有效 token 的经验阈值，否则退回全局统计；
- **未触及的参数空间影响**：附录 B 给出理想化自然梯度解释，但实际算法仅在输出坐标上扰动，理论上更精确的参数空间影响尚不可行（百万-十亿参数 agent 的 Hessian 求解代价过大）；
- **clip 暴露**：约 0.069% token 的 clipped surrogate 平坦区会让 $u_t$ 高估局部响应，虽影响微小（这些 token 仅获 0.103% 组合质量），但未被特殊处理；
- **稀疏奖励任务**：Search-QA 类任务奖励信号本就比 ALFWorld/WebShop 更稀疏，ICSD 对 token 级影响的判别可能因优势估计噪声增大而退化；
- **仍需特权分支**：ICSD 属于 OPSD 家族方法，无法脱离特权自教师使用，可能限制其在严格无监督场景下的部署。
