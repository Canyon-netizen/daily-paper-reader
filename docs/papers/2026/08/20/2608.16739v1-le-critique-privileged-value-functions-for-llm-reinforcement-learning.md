tldr: 大语言模型强化学习中，GRPO 等组相对方法依赖多 rollout 来降低梯度方差，但只能提供序列级信用分配，且易被慢样本拖慢训练。学习型价值函数理论上可提供 token 级优势，却因工程开销大而难以落地。本文提出 PVF（Privileged Value Functions）以无偏方式向策略目标注入任务相关的 token 级信号，并设计 TETHER 基线，根据价值函数精度自适应地在组相对与价值基线间插值。在多个推理任务上的实验表明，两策略均稳定优于标准价值基线，并达到或超越 GRPO 表现。

motivation: 组相对 RL 方法只能给序列级信用且吞吐受限，价值函数方法虽能提供 token 级优势却工程复杂，难以在 LLM RL 流水线中实际部署。
method: 提出 PVF 以无偏方式注入任务相关的 token 级信号，并设计 TETHER 基线依据价值函数精度自适应插值组相对与价值基线。
result: 在多个推理任务上，两策略均稳定优于标准价值基线，且性能达到或超越 mean-baseline GRPO。

## 摘要
大语言模型（LLM）的强化学习算法在很大程度上以其方差缩减策略来区分。GRPO 等组相对方法通过对每个提示采样多个 rollout 来降低梯度方差，但仅提供序列级别的信用分配。此外，训练还会被掉队 rollout 所阻塞，从而降低吞吐量并增加离策略程度。学习得到的价值函数理论上可以同时解决这两个问题，无需大组就能提供 token 级别的优势。然而，额外的工程基础设施挑战以及无评论员方法在实践中的成功，使得很难证明将价值函数纳入强化学习流程的合理性。我们提出两种互补策略来提升价值函数强化学习的性能：1）特权价值函数（PVF），提供了一种优雅的机制来注入额外的、与任务相关的 token 级信号，同时不使策略目标产生偏差；2）TETHER，一种基线方法，能够根据价值函数的准确性自适应地在组相对基线和价值基线之间进行插值。在多项推理任务上，这两种策略均一致地优于标准价值函数基线，并且与均值基线 GRPO 相当或超越之。

## Abstract
Reinforcement learning algorithms for Large Language Models (LLMs) are largely distinguished by their variance reduction strategy. Group-relative methods like GRPO reduce gradient variance by sampling multiple rollouts per prompt, but provide only sequence-level credit. Training is also blocked by straggler rollouts, reducing throughput and increasing off-policyness. Learned value functions theoretically address both problems, providing token-level advantages without requiring large groups. However, additional infrastructure engineering challenges combined with the practical success of critic-free methods have made it difficult to justify their inclusion in RL pipelines. We propose two complementary strategies to improve the performance of value function RL: 1) Privileged Value Functions (PVF) which provide an elegant mechanism to inject additional task-relevant token-level signal without biasing the policy objective; 2) TETHER, a baseline that adaptively interpolates between group-relative and value baselines depending on the value function accuracy. Across several reasoning tasks, both strategies consistently improve over the standard value function baseline, and are competitive with or outperform mean-baseline GRPO.

# Le Critique：用于大语言模型强化学习的特权价值函数

## 1. 核心问题与研究动机

大语言模型（LLM）的强化学习算法在方差缩减策略上呈现明显分化：

- **组相对方法（GRPO、RLOO）**：通过对同一提示采样多个 rollout，以组内回报均值/留一法（Leave-One-Out, LOO）均值估计基线，仅能提供**序列级（sequence-level）信用分配**，且训练必须等待组中最慢的样本（straggler）完成，导致吞吐量降低、离策略程度（off-policyness）增加。
- **学习型价值函数方法（PPO + GAE）**：理论上可同时解决上述问题，提供**token 级优势估计**且无需大组采样；但额外引入评论员的工程复杂度（独立的 GPU 分配、推理与训练异步等），加之无评论员方法在实践中表现出色，使得价值函数在 LLM RL 流水线中难以合理化。

论文的核心动机是：**重新审视价值函数在 LLM RL 中的潜力**，提出以更低风险的方式将价值函数重新引入现有 GRPO 基础设施，从而既保留 token 级信用分配，又能避免因评论员拟合不佳而导致的性能退化。

## 2. 方法论

### 2.1 特权价值函数（Privileged Value Functions, PVF）

**核心思想**：将训练中可获得但策略在推理时无法观察的信息（参考解答、verifier rubric、同组其他响应及其回报等），仅通过**评论员**而非策略来利用，从而在不改变策略优化目标的前提下改善价值估计。

**形式化定义**。设 $h_{i,t}=(x_i, y_{i,<t})$ 为策略状态，$z_{i,t}$ 为特权上下文，则特权价值函数定义为：

$$
V^{\pi}(h_{i,t}, z_{i,t}) := \mathbb{E}_{\tau_i \sim \pi}\!\left[R_i \mid h_{i,t}, z_{i,t}\right], \qquad \hat{A}^{\text{PVF}}_{i,t} = R_i - V_{\phi}(h_{i,t}, z_{i,t}).
$$

**无偏性条件（baseline admissibility）**：只要 $z_{i,t}$ 在给定 $h_{i,t}$ 下与 $y_{i,t}$ 条件独立，即

$$
z_{i,t} \perp\!\!\!\perp\; y_{i,t} \mid h_{i,t},
$$

则策略梯度保持无偏。例如：固定的参考答案是合法的特权信息；而轨迹 $i$ 自身的未来 token、已实现的回报或 verifier 反馈则不合法。

**信息论保证**：对于最优预测器，更丰富的条件信息严格不增加预测残差方差：

$$
\mathbb{E}\!\left[\big(R_i - \mathbb{E}[R_i \mid h_{i,t}, z_{i,t}]\big)^2\right] \;\le\; \mathbb{E}\!\left[\big(R_i - \mathbb{E}[R_i \mid h_{i,t}]\big)^2\right].
$$

### 2.2 TETHER：自适应组–值混合基线

**核心思想**：评论员在训练初期往往拟合不足，纯价值基线易失效；而组基线（LOO）虽稳健但缺乏 token 级信息。TETHER 在两者之间进行**线性插值**并**在线拟合**混合系数。

**形式化定义**。令 $V_{i,t} = V_{\phi}(h_{i,t})$ 为学习型 token 级价值，$\bar{b}^{\text{LOO}}_i$ 为 LOO 组基线，则

$$
\hat{b}^{\text{TETHER}}_{i,t} = (1-\rho)\,\bar{b}^{\text{LOO}}_i + \rho\, V_{i,t}, \qquad \hat{A}^{\text{TETHER}}_{i,t} = R_i - \hat{b}^{\text{TETHER}}_{i,t}.
$$

当 $\rho = 0$ 退化为 LOO 组基线，$\rho = 1$ 退化为 token 级价值基线，中间值实现平滑过渡。

**自适应系数拟合**：在每一批完成 $B_k$ 上，通过最小化 Monte Carlo 回报预测误差估计最优 $\hat{\rho}_k$：

$$
\hat{\rho}_k = \arg\min_{\rho \in [0,1]} \sum_{(i,t)\in B_k} \big(R_i - \hat{b}^{\text{TETHER}}_{i,t}(\rho)\big)^2,
$$

并以 EMA（衰减率 $d = 0.95$）平滑：$\rho_k = d\rho_{k-1} + (1-d)\hat{\rho}_k$。**关键约束**：$\rho_k$ 仅用于下一批 $B_{k+1}$，不用于本批优势计算，以保持无偏性。

**统计最优性证明**（附录 C）。设 $A_B = R - B$、$\Delta = V - B$，则 $A_\rho = A_B - \rho\Delta$，最小化 $\mathbb{E}[A_\rho^2]$ 得到最优

$$
\rho^{\star} = \text{clip}_{[0,1]}\!\left(\frac{\mathbb{E}[A_B \Delta]}{\mathbb{E}[\Delta^2]}\right),
$$

并且满足严格优于任一端点的保证：

$$
\mathbb{E}[(A_{\rho^{\star}})^2] \;\le\; \min\!\left\{\mathbb{E}[(R-B)^2],\,\mathbb{E}[(R-V)^2]\right\}.
$$

### 2.3 异步价值函数训练基础设施

为避免价值学习成为同步瓶颈，论文开源了 `prime-values` 系统（基于 PRIME-RL 构建）：

- **评估–训练分离**：值评估器（evaluator）与值训练器（trainer）使用独立模型副本，evaluator 持续提供服务、trainer 在后台执行优化器更新；
- **FIFO 回放缓冲**：已评估的轨迹入队，每个轨迹至多被复用 $N = 2$ 次；
- **价值预热（warmup）**：策略更新前仅运行 20 步价值训练作为校准。

## 7. 优点

- **方法论优雅**：PVF 通过「基线无偏性条件」清晰地界定哪些信息可注入评论员，既享受特权信息又保持原 RL 目标，是相对自蒸馏（self-distillation）更轻量的替代方案；
- **TETHER 的双重视角**：既可视为简单的 PVF（LOO 均值即一种免训练的特权评论员），又是连续插值的混合基线，理论上保证严格不差于任一端点；
- **异步基础设施开源**：`prime-values` 提供了可复用的 evaluate-before-train 异步价值训练栈，便于后续研究在更大规模上重做实验；
- **统计与实证双重支撑**：附录 C 给出最优 $\rho$ 的闭式推导与 $\le \min$ 端点的理论保证；
- **基线与超参严格匹配**：MEAN/VF/PVF/TETHER 在同一策略配置下比较，VF 与 PVF/TETHER 之间共享价值训练设置，使对比更具说服力。

## 8. 不足与局限

- **算力匹配不严谨**：MEAN 与价值基线之间未做精确算力对齐，价值基线额外占用专用值训练器 + 值评估器节点，存在「价值方法用更多资源」的潜在偏倚；
- **模型规模有限**：仅在 4B 模型、至多 32768 token 的中等 horizon 上验证；未触及长链路代理训练（如多步工具调用、网页交互）等价值函数方差缩减可能更显著的场景；
- **基础设施成本**：价值函数增加 GPU 显存/算力开销，作者建议未来工作研究 value function scaling laws，但本文未给出系统性的算力–性能权衡分析；
- **特权信息来源受限**：PVF 无法利用由完成响应本身产生的回顾性反馈（这是 self-distillation 的优势）；当无任何特权信息可用时，PVF 退化为普通 VF；
- **TETHER 的过拟合风险**：在有限批次上拟合的 $\rho$ 可能引入噪声，作者虽使用 EMA 与滞后更新缓解，但理论上不能保证每一步策略更新都满足群体最优性保证；
- **$\lambda$ 调节尚未系统化**：仅做了 $0.99988$ vs $1.0$ 的初步比较，$\lambda_{\text{GAE}}$ 与 $\lambda_{\text{target}}$ 的解耦调优、随评论员精度的自适应 $\lambda$ 调度等都留作未来工作；
- **种子数较少**：Reasoning Gym 仅 2 粒种子，置信区间较宽，部分提升的统计显著性有限；
- **任务覆盖偏向推理**：未涉及对话、代码生成、长篇写作等多样性更高的应用领域。
