基于可验证奖励的强化学习 (RLVR) 在训练大语言模型智能体方面十分有效。然而，终态奖励只能提供粗粒度的轨迹级监督，使得成功行为、反复出现的错误和偶然性选择纠缠在同一个结果信号中。现有的智能体自蒸馏方法通过自然语言技能来丰富稀疏的监督信号，但外部检索的或由更强模型从单条轨迹中提取的技能，可能与当前经验不匹配、超出当前策略的能力范围，或仍然局限于特定路径。我们提出了群体反思自蒸馏 (GRSD)，从策略自身已验证的 rollout 中提炼出能力对齐且区分结果的指导信号。对于每个 prompt，策略在一个同策略组中对每条已验证的轨迹进行反思，并通过一个 stop-gradient 快照对比来自成功与失败 rollout 的反思结果，从而构建群体级特权指导。在此指导下，自教师通过调节基于结果的优势来细化轮级信用分配，同时保持验证器所确定的学习方向。在多个智能体环境和模型规模上的实验表明，GRSD 一致地优于具有竞争力的基线方法，并能更有效地泛化到未见过的任务。

## Abstract
Reinforcement learning with verifiable rewards (RLVR) is effective for training large language model agents. However, terminal rewards provide only coarse trajectory-level supervision, leaving successful behaviors, recurring mistakes, and incidental choices entangled in the same outcome signal. Existing agentic self-distillation methods enrich sparse supervision with natural-language skills, but skills retrieved externally or extracted from a single trajectory by stronger models may mismatch current experience, exceed the policy's capability, or remain path-specific. We propose Group-Reflective Self-Distillation (GRSD), which derives capability-aligned and outcome-discriminative guidance from the policy's own verified rollouts. For each prompt, the policy reflects on each verified trajectory in an on-policy group, and a stop-gradient snapshot contrasts the resulting reflections from successful and failed rollouts to construct group-level privileged guidance. Conditioned on this guidance, a self-teacher refines turn-level credit assignment by modulating outcome-based advantages while preserving the verifier-determined learning direction. Experiments across multiple agentic environments and model scales demonstrate that GRSD consistently outperforms competitive baselines and generalizes more effectively to unseen tasks.

# 论文总结：GRSD——面向智能体强化学习的群体反思自蒸馏

## 1. 核心问题与研究动机

RLVR（基于可验证奖励的强化学习）是训练 LLM 智能体的主流范式，但存在以下核心局限：

- **稀疏终态监督**：终态奖励仅在轨迹结束提供 coarse-grained 的成功/失败信号，导致成功行为、反复错误与偶发选择全部纠缠在同一结果信号中。
- **现有自蒸馏方法的能力失配**：如 Skill-SD、SDAR 通过外部技能库检索技能，可能与当前 prompt/状态/轨迹不匹配；而由更强外部模型从单条轨迹中提取的"事后技能"，可能超出当前策略的能力边界。
- **单轨迹技能缺乏对比**：成功轨迹可能包含冗余绕路，失败轨迹仍可能包含有用行为，单条轨迹提取的技能容易捕获路径特异性细节，而非真正区分成败的行为模式。

由此引出两个核心挑战：① 如何从策略自身的同策略经验中提取能力对齐（capability-aligned）的指导；② 如何通过对比 rollout 识别成功关键行为与反复出现的失败模式。

## 2. 方法论

### 2.1 整体框架

GRSD 由两阶段构成：

- **Stage A：策略原生自反思（Policy-Native Self-Reflection）**：策略对自身每条已验证轨迹生成反思技能 $s_i$，保持能力对齐。
- **Stage B：群体级指导构建（Group-Level Guidance Construction）**：用 stop-gradient 快照对比成功/失败反思，合成 prompt 特定的 DO/AVOID 指导 $z_x$。
- **轮级自蒸馏（Turn-Level Self-Distillation）**：以 $z_x$ 为特权上下文，自教师调整轨迹级优势以实现轮级信用分配。

### 2.2 关键技术细节

**Stage A 反思生成**：
$$s_i \sim \pi_{\theta_{\text{old}}}(\cdot \mid x, \tau_i, b_i, p_{\text{ref}})$$

由固定外部判官 $J$ 对每个反思打分 $r^{\text{ref}}_i \in \{0,1,2,3\}$，归一化后得反思优势 $A^{\text{ref}}_i$。

**Stage B 群体指导合成**：
$$z_x \sim \pi_{\bar\theta}(\cdot \mid x, S^+_x, S^-_x, p_{\text{guide}}), \quad \bar\theta = \text{sg}(\theta_{\text{old}})$$

其中 $S^+_x = \{s_i \mid b_i = 1\}$、$S^-_x = \{s_i \mid b_i = 0\}$。Stage A 通过反思损失训练，Stage B 为 detached 不传梯度。

**轮级信用分配**：
- 学生上下文：$c^{\text{stu}}_{i,t} = C(x, H_{i,t})$
- 教师上下文：$c^{\text{tea}}_{i,t} = C(x, z_x, H_{i,t})$
- 教师–学生似然差：
$$\Delta_{i,t} = \frac{1}{L_{i,t}}\sum_{k=1}^{L_{i,t}} \left[\log \pi_{\bar\theta}(y_{i,t,k}\mid y_{i,t,<k}, c^{\text{tea}}_{i,t}) - \log \pi_{\bar\theta}(y_{i,t,k}\mid y_{i,t,<k}, c^{\text{stu}}_{i,t})\right]$$
- 方向对齐：$q_{i,t} = \text{sign}(A_i)\Delta_{i,t}$
- 归一化裁剪调制分数：
$$\hat{q}_{i,t} = \text{clip}\left(\frac{\exp(q_{i,t})-1}{D_x}, -\hat{G}, \hat{G}\right), \quad D_x = \frac{1}{|T_x|}\sum_{(j,t')\in T_x}|\exp(q_{j,t'})-1|+\epsilon_{\text{gap}}$$
- 轮级调制优势：
$$\hat{A}_{i,t} = A_i(1 + \lambda \hat{q}_{i,t} m_x)$$
其中混合结果掩码 $m_x = \mathbf{1}[|S^+_x|>0 \land |S^-_x|>0]$；约束 $\lambda\hat{G}<1$ 保证调制不改变 $A_i$ 的符号。

### 2.3 总目标函数

$$L(\theta) = L_{\text{task}}(\theta) + \alpha L_{\text{ref}}(\theta)$$

任务损失使用裁剪 GRPO 代理但将轨迹级优势替换为 $\hat{A}_{i,t}$；反思损失仅优化反思 token，由独立归一化的反思优势驱动。两部分监督互不相交 token 集合。

### 2.4 理论保证（附录）

- **命题 1（群体对比方差缩减）**：在条件独立表示模型下，跨多个成功/失败反思聚合能将条件均方误差由 $\text{tr}(\Sigma^1_x+\Sigma^0_x)$ 缩减至 $\text{tr}(\Sigma^1_x/n_+ + \Sigma^0_x/n_-)$。
- **命题 2（有界正调制）**：令 $\delta = \lambda\hat{G}<1$，则 $1-\delta \le w_{i,t} \le 1+\delta$，且 $\text{sign}(\hat{A}_{i,t}) = \text{sign}(A_i)$。
- **命题 3（正重加权等价）**：$\phi_\varepsilon(\rho, wA) = w\phi_\varepsilon(\rho, A)$，故 GRSD 代理恰为 GRPO 代理的逐项正重加权。

- **训练后期优势持续**：在 baseline 平台期之后仍持续上升，验证差距逐步拉大；教师–学生似然差距绝对值小于 Skill-SD/SDAR，提示更兼容的指导。

## 7. 优点

- **真正"自蒸馏"**：无需外部技能库、无需更强大的外部生成器，技能和指导完全由当前策略及其 stop-gradient 快照构造。
- **能力对齐**：反思由同一策略生成，避免了外部模型指导"超出能力边界"的问题。
- **结果区分性**：群体对比天然压制路径特异性，捕获成功–失败差异行为。
- **理论完备**：三命题分别给出群体聚合方差缩减、有界正调制、GRPO 重加权等价性，机制清晰。
- **无推理开销**：指导仅用于训练阶段信用调制，部署阶段零成本。
- **多规模泛化**：在 1.7B / 3B / 7B 三档模型上一致保持优势，且对 OOD 与 unseen 任务均有效。
- **公平严谨**：附录提供算法伪代码、prompt 模板、wall-clock 对比、消融、敏感性分析、训练动态、超参细节，可复现性高。

## 8. 不足与局限

- **环境覆盖有限**：仅在 3 个环境（具身 / 搜索 / 购物）验证，未涉及代码生成、数学推理、复杂多工具调用等更多领域。
- **依赖外部判官**：反射奖励由 DeepSeek-V4-Flash 给出，对算力与延迟有额外需求；判官质量直接影响 Stage A 训练效果，存在"评判依赖"风险。
- **理想化假设**：命题 1 的方差缩减结论依赖"条件独立表示"模型，自然语言反思的依赖关系可能削弱理论保证；附录明确指出该命题不构成无条件保证。
- **训练成本上升**：相对 GRPO 增加约 17% wall-clock，主要来自 Stage A 反思生成与 Stage B 合成；中等规模实验尚可承受，超大规模训练需权衡。
- **混合群体依赖**：仅当 prompt 组同时存在成功与失败 rollout 时才激活调制；冷启动早期或难度过高任务可能退化为 GRPO（附录 G.2 显示有效群体比例有限）。
- **事后条件偏差**：$\Delta_{i,t}$ 是基于完整轨迹的 hindsight 信号，理论分析明确指出"非因果估计"，存在解释性而非因果性的风险。
