## TL;DR

大语言模型在长视野博弈中做决策时，传统的强化学习只能等到游戏结束才知道胜负，导致模型学不会"哪一步走得好、哪一步走得差"。CAST 提出让游戏求解器充当"教师"，把每一步的价值变化转化为细粒度的训练信号。在推箱子、扫雷、华容道三类游戏中，这种方法比现有训练方式平均提升十几个百分点，甚至能在完全不同的家务任务和网购任务上实现零样本迁移。

## 研究背景与动机

让大语言模型学会在复杂环境中做长序列决策，是通往通用智能体的重要一步。当前主流做法是 [[RLVR]]（基于可验证奖励的强化学习）——游戏结束得到一个 0/1 胜负信号，据此更新模型。但这种信号稀疏到了近乎无用的程度：一场推箱子游戏可能要推几十步，任何一步失误都会导致全盘皆输，而模型只能得到"你输了"这三个字。模型根本不知道失败发生在第几步、哪一步该往左而不是往右，这就是所谓的[[信用分配]]难题。

已有研究试图用过程奖励模型或搜索树来提供中间信号，但要么需要额外训练一个奖励网络，要么计算成本极高，要么只在状态相似的轨迹之间有效。如何同时做到"廉价"与"准确"，始终是个悬而未决的问题。

CAST 的核心洞察来自一个朴素观察：游戏求解器（Solver）对任意可达状态都能计算"距离解有多远"。如果当前状态离解还差 5 步，下一步走对了变成差 4 步，说明这一步在往正确方向推进；如果走错了变成差 6 步甚至陷入死局，说明这一步在帮倒忙。状态值的变化 $\Delta V$ 因此天然携带了回合级的信用信息——而且完全来自游戏本身的确定性强度的求解器，不需要任何额外标注。

## 方法

CAST 的方法论分为三个层次来展开。

首先是**求解器优势的构造**。设 $N(s)$ 为状态 $s$ 距离最近解态的最少步数（cost-to-go），定义势函数 $\Phi(s) = -N(s)$。则某动作的优势为相邻状态势函数的差：

$$\tilde{A}^{\pi_S}(s_t, a_t) = N(s_t) - \mathbb{E}_{s_{t+1}}[N(s_{t+1})]$$

这个量的含义很直观：正值代表减少了到达目标的步数，负值代表增加了步数甚至导致无解。为了让"最优动作"映射为一致的正值，再做一个平移：

$$\bar{A}^{\pi_S}(s_t, a_t) = \tilde{A}^{\pi_S}(s_t, a_t) + 1$$

这样最优步得 +1，无进展得 0，有害步得负分。

其次是**信号整形**。直接使用原始优势值会遇到两个问题：一是不同游戏、同一游戏不同难度之间数值尺度差异巨大；二是死状态可能导致极端的负值让训练崩溃。CAST 采用两步变换：先用 asinh 函数压缩大数值、保留小信号的线性特性，再在每个 batch 内做 RMS 归一化（不减去均值以保留"零"的语义）。

最后是**与 GRPO 的结合**。原有的 [[GRPO]] 方法只能提供轨迹级的胜负优势，CAST 在其基础上加入加权的过程信号：

$$\hat{A}_{i,t} = \hat{A}_i^{\text{outcome}} + \alpha\, h\!\left(\bar{A}^{\pi_S}_{i,t}\right)$$

其中 $\alpha=0.1$ 控制求解器引导强度。最终的优势通过 token 级广播给 GRPO 的裁剪替代目标。

论文还给出了一个深刻的理论结果：**在软最优求解器假设下，最大化求解器优势等价于从求解器进行在策略蒸馏，但只需要标量而不需要教师的 logits**。这意味着 CAST 不仅是一种启发式技巧，而是有严格数学支撑的方法。标量 $\bar{A}^{\pi_S}$ 隐式编码了教师对最优动作的偏好梯度，无需访问教师的概率分布。

## 实验与结果

实验覆盖了三个性质迥异的游戏：推箱子要求长视野不可逆规划、扫雷涉及部分观测下的概率推理、华容道则是约束满足与组合搜索。

在域内难度（训练时见过的规模）评估中，CAST 的平均成功率达到 62.1%，比最强的训练基线 [[DAPO]]（44.7%）高出 17.4 个百分点。在未见难度（更大的棋盘、更多障碍物）上，CAST 的优势依然显著：28.4% 对比 18.7%，提升 9.7 点。更值得注意的是样本效率——CAST 在三个游戏上分别只需要 DAPO 所需步数的 50%~60% 就达到峰值性能，加速比达到 1.7 到 2 倍。

最引人注目的是零样本迁移能力。CAST 在 ALFWorld（具身家务任务）和 WebShop（网购任务）上的平均成功率达到 30.3%，比第二名高出 5.6 点。一个典型案例是：在推箱子训练中学会的"中途纠错"能力，迁移到了"在多个约束条件下筛选商品"的任务——模型先拒绝不符合材质要求的候选，再二次搜索找到 walnut 实木选项，最终完成购买。

消融实验进一步确认了每个组件的必要性：去掉 asinh 压缩或 RMS 归一化都会导致性能下降；$\alpha$ 的取值以 0.1 为最优，太小则求解器信号几乎不起作用，太大则"挤出"了原本的胜负信号。用学习型 DQN 值网络替代精确求解器后，华容道上的性能与精确版本接近，说明方法不依赖手工求解器的完美性。

## 讨论与可借鉴点

CAST 的成功揭示了一个重要规律：**博弈求解器不仅仅是个"裁判"（判断胜负），更是一个"教练"（告诉每一步的对错）**。这一思路的巧妙之处在于，它把游戏内部已有、过去却被忽视的确定性强度的求解器信号重新利用起来，无需额外训练、不需要标注数据、几乎不增加计算开销（论文报告求解器查询仅占训练步的 73 ppm）。

然而这项研究也存在局限。最核心的假设是"软最优求解器"——即求解器选择的动作至少接近最优策略。如果求解器的策略与最优差距较大，标量优势就无法准确反映真实偏好，蒸馏解释也会退化。论文用附录讨论了这一风险但未量化敏感性。此外，极端死状态产生的超大负值在 asinh 压缩后仍可能影响梯度，论文用 $\beta_{\text{eff}}$ 做了修正但极端情况仍需小心。

对后续研究的启发是多维度的。在方法层面，用学习型值网络替代手工求解器是一个自然延伸——论文已在华容道上验证了可行性，但在推箱子这类需要强规划能力的游戏中是否同样有效，尚待探索。在问题层面，"哪些领域天然存在可廉价获取的求解器"决定了 CAST 的适用范围——代码调试、形式化证明、数学证明验证等场景都可能受益于类似思路。在理论层面，"无 logits 的蒸馏"这一发现暗示，仅用标量反馈就能隐式传递策略偏好，这比传统的模仿学习更加轻量。

总体而言，CAST 代表了将领域知识注入强化学习训练的一条新路径。它不追求通用到可以在任何任务上开箱即用，而是在"有求解器"的游戏场景中做到了极致——同时兼顾了理论优雅性（显式推导与蒸馏等价性）和工程可行性（几乎可忽略的开销）。这种"在约束条件下追求极致"的思路，或许比盲目追求大一统方法更值得借鉴。

## 摘要
训练大语言模型（LLMs）在长视野游戏中执行动作是迈向通用决策的有希望的一步，然而基于可验证奖励的强化学习（RLVR）依赖于稀疏的最终奖励，这些奖励几乎无法揭示哪些决策决定了成功。更密集的过程信号本可以提供这种缺失的回合级信用分配，但现有来源难以同时兼顾低成本与高准确性。我们观察到，游戏求解器状态值的变化能够揭示某个动作是否将状态向成功方向推进。基于这一洞察，我们提出了CAST（Credit Assignment from Solver Teachers，即来自求解器教师的信用分配），它将这些价值变化转化为求解器优势，并将其作为回合级信号注入RLVR中。我们进一步证明，在软最优求解器假设下，最大化求解器优势等同于从求解器进行在策略蒸馏，仅需标量值而无需教师的logits。在推箱子（Sokoban）、扫雷（Minesweeper）和华容道（Rush Hour）上，CAST在域内与未见难度评估下均在每个游戏上优于所有训练基线，并在ALFWorld和WebShop上取得了最高的平均零样本性能。我们的代码已开源于 https://github.com/Wloner0809/CAST 。

## Abstract
Training large language models (LLMs) to act in long-horizon games is a promising step toward generalist decision-making, yet reinforcement learning with verifiable rewards (RLVR) relies on sparse final rewards that reveal little about which decisions determine success. Denser process signals could supply this missing turn-level credit, but existing sources are hard to keep both cheap and accurate. We observe that changes in a game solver's state value reveal whether an action advances the state toward success. Building on this insight, we propose CAST (Credit Assignment from Solver Teachers), which converts these value changes into solver advantages and injects them into RLVR as turn-level signals. We further show that, under a soft-optimal solver assumption, maximizing the solver advantage is equivalent to on-policy distillation from the solver, requiring only scalar values rather than teacher logits. Across Sokoban, Minesweeper, and Rush Hour, CAST outperforms all trained baselines on every game under both in-domain and unseen-difficulty evaluation and achieves the highest average zero-shot performance on ALFWorld and WebShop. Our code is available at https://github.com/Wloner0809/CAST.

## 2. 方法论

### 2.1 形式化（MDP 与 RLVR 基线）

将博弈建模为有限视野 MDP：

$$\mathcal{M} = (\mathcal{S}, \mathcal{A}, P, r, H),\quad r_t = 0\ (t<T),\quad R(\tau) = \mathbf{1}\{s_T \in \mathcal{S}_{\text{solved}}\}$$

GRPO 给出按组归一化的轨迹级优势：

$$\hat{A}_i^{\text{outcome}} = \frac{R_i - \mu_R}{\sigma_R + \delta},\quad \mu_R = \tfrac{1}{G}\sum_{j=1}^G R_j$$

其瓶颈在于轨迹级优势广播到每个 token，无法识别关键决策回合。

### 2.2 求解器优势的构造

定义求解器 cost-to-go $N(s)$（到达解态最少动作数），并设势函数 $\Phi(s) = -N(s)$，则求解器优势为：

$$\tilde{A}^{\pi_S}(s_t, a_t) = N(s_t) - \mathbb{E}_{s_{t+1}}[N(s_{t+1})]$$

为使"最优动作"映射为正值，作平移得到**平移后求解器优势**：

$$\bar{A}^{\pi_S}(s_t, a_t) = \tilde{A}^{\pi_S}(s_t, a_t) + 1$$

最优步得 $+1$，无效步得 $0$，有害步得负分；死状态以 $-N(s_t)$ 为下界。

### 2.3 信号整形

为应对重尾与跨任务尺度差异，两步轻量化变换：

- **asinh 压缩**：$g(x) = \text{asinh}(x) = \ln\!\left(x + \sqrt{x^2+1}\right)$，小信号近似线性、大信号对数压缩，且保留正负号。
- **批次级 RMS 归一化**：

$$h(x) = \frac{g(x)}{\mathrm{RMS}_B(g) + \epsilon},\quad \mathrm{RMS}_B(g) = \sqrt{\tfrac{1}{|B|}\sum_{(i,t)\in B} g(\bar{A}^{\pi_S})^2}$$

不减去均值是有意为之：保留 $0$ 作为"无进展"的语义。

### 2.4 与 GRPO 结合

$$\hat{A}_{i,t} = \hat{A}_i^{\text{outcome}} + \alpha\, h\!\left(\bar{A}^{\pi_S}_{i,t}\right)$$

其中 $\alpha=0.1$ 控制求解器引导强度；优势仍以 token 级广播给 GRPO 裁剪替代目标。

### 2.5 核心定理（无 Logit 的在策略蒸馏等价性）

**Theorem 2.1（隐式目标）**：在软最优求解器假设 $\pi_S(a|s) \propto \exp(Q^{\pi_S}(s,a)/\tau)$、小信号 $|A^{\pi_S}|\lesssim 1$、GRPO 一致性与冻结访问代理下：

$$J_{\text{ours}}(\theta) = \mathbb{E}_{s_0\sim\mu}\!\left[V^{\pi_\theta}_{\text{task}}(s_0)\right] - \beta\,\mathbb{E}_{s\sim d_{\pi_\theta}}\!\left[H(\pi_\theta(\cdot|s),\ \pi_S(\cdot|s))\right]$$

$$\beta = \frac{\alpha\tau}{\sqrt{2}(\mathrm{RMS}_B(g)+\epsilon)}$$

- **关键推论**：利用 $A^{\pi_S}(s,a) = \tau \log \pi_S(a|s)$ 与 asinh 在最优步邻域的一阶 Taylor 近似，标量 $\bar{A}^{\pi_S}$ 即编码了教师的对数偏好，**无需教师 logits**。
- **超越教师的可能**：封闭最优解 $\pi^*(a|s) \propto \pi_S(a|s)\exp(A^{\pi_\theta}_{\text{task}}(s,a)/\beta)$ —— 当 $\beta\to\infty$ 时 $\pi^*\to\pi_S$，有限 $\beta$ 下任务优势可"倾斜"教师分布，使学生超越求解器。
- **附加结论**：用性能差引理（PDL）与奖励塑形定理可证明次优性界为 $O(H\epsilon_\pi)$（优于行为克隆的 $O(H^2\epsilon_\pi)$）。

### 2.6 训练管线

- 基座：**Qwen3-4B-Instruct-2507**；骨架采用 DAPO（保留 token-mean 损失与 clip-higher）。
- 训练尺度：batch size 16，每提示 8 条 rollout，$\alpha=0.1$，训练步数 Sokoban 200、Minesweeper 400、Rush Hour 300。
- 求解器实现：推箱子用加权 $A^*$（含 box→target 最小指派启发式）；扫雷用约束推理 + 全局雷概率推理；华容道用反向 BFS 预计算最短路表。

- **理论一致**：在软最优求解器假设下，CAST 隐式目标等价于"任务回报 − $\beta\times$ 交叉熵蒸馏"，无需教师 logits；并存在学生超越教师的形式化机制。
- **实用性**：精确求解器训练开销几乎可忽略；用学习型 DQN 值网络替代后，Rush Hour 性能与精确求解器版本接近，证明方法不依赖手工求解器。

---

## 7. 优点

- **问题定位精准**：直击 RLVR 在长视野博弈中"轨迹级稀疏奖励 = 信用分配失败"这一根本痛点。
- **方法简洁优雅**：仅用标量 cost-to-go 差作为信号，借助 asinh + RMS 双重整形即可稳定训练，无须新增网络或额外标注。
- **理论深度高**：证明"无 Logit 的在策略蒸馏等价性"、给出闭式最优策略 $\pi^*\propto\pi_S\exp(A_{\text{task}}/\beta)$、并用 PDL 得到 $O(H\epsilon_\pi)$ 次优性界。
- **三类互补游戏验证**：长视野规划、部分观测、约束组合三种挑战覆盖全面，增强结论可信度。
- **零样本迁移亮点**：在完全不同的具身/网页任务上展现可迁移的规划与纠错能力。
- **消融与替代分析完备**：$\alpha$ 扫描、组件消融、近似求解器替代，结论互相印证。
- **开销实测透明**：给出三层粒度的墙钟分解，量化说明"73 ppm"的工程可行性。

## 8. 不足与局限

- **依赖软最优求解器假设**：定理 2.1 在此假设下成立；若实际求解器与最优策略偏差大，蒸馏解释会退化（附录 C.5.7 已讨论但未量化偏差敏感性）。
- **重尾与小信号近似**：asinh 的一阶 Taylor 在 $|A^{\pi_S}|\gg 1$ 处不再精确，虽有 Corollary C.10 用 $\beta_{\text{eff}}$ 修正，但极端死状态仍可能影响梯度稳定。
- **跨任务通用性受限**：当前结果依赖"可廉价获取精确求解器"的游戏；虽在 Rush Hour 上验证 DQN 近似可替代，但未在 Sokoban/Minesweeper 上验证学习型求解器，对无手工求解器场景的推广性证据有限。
- **算力与统计细节缺失**：未报告 GPU 型号/数量/总训练时长；闭源模型为单 run；每档评测仅 200 实例，对罕见失败模式统计力不足。
- **OOD 评测深度有限**：ALFWorld 与 WebShop 仅报 Avg@4 成功率，未做回合级行为分析或定性错误归因（除一例 WebShop 案例外）。
- **过程信号与任务奖励的耦合风险**：当 $\alpha$ 过大时，过程信号会"挤出"稀疏任务目标（图 4c 显示训练奖励晚塌），说明权重选择敏感；实际部署需逐游戏调 $\alpha$，缺乏自适应策略。
- **稀疏终局奖励的潜在副作用**：极难实例仍以失败为主（Minesweeper Unseen 仅 11.0），提示对"完全不可解"或"需要猜测"实例的信号噪声仍需进一步处理。
