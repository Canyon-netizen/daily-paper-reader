## 摘要
同策略自蒸馏（OPSD）通过使用以参考解为条件的模型特权视角，来监督仅观察问题的学生视角，从而提升推理能力。然而，教师所提供的 token 级目标可能依赖于推理时不可得的参考解特有信息。我们提出问题空间引导的 OPSD（PS-OPSD），用基于轨迹的引导替代完整解法，该引导刻画了初始状态、目标条件、约束以及选定的状态转移路径。学生 rollout 与 OPSD 目标保持不变。在三个数学推理基准以及 1.7B 至 8B 参数规模的模型上，PS-OPSD 在所比较方法中取得了最高的仅依据问题的聚合准确率。受控实验进一步表明，引导相关性与路径连贯性对性能提升均有贡献，凸显了特权信息的表示形式是 OPSD 中一个重要的设计选择。

## Abstract
On-policy self-distillation (OPSD) improves reasoning by using a privileged view of a model conditioned on reference solutions to supervise a student view that observes only the question. However, the teacher-provided token-level targets may depend on reference-specific information unavailable at inference time. We propose Problem-Space-Guided OPSD (PS-OPSD), which replaces the complete solution with trajectory-grounded guidance describing the initial state, goal conditions, constraints, and a selected state-transition path. The student rollout and OPSD objective remain unchanged. Across three mathematical reasoning benchmarks and model scales ranging from 1.7B to 8B, PS-OPSD achieves the highest aggregate question-only accuracy among the compared methods. Controlled experiments further indicate that guidance relevance and path coherence contribute to these gains, highlighting the representation of privileged information as an important design choice in OPSD.

# 论文总结：PS-OPSD——以问题空间引导替代完整解题轨迹的自蒸馏

## 1. 核心问题与研究动机

- **背景**：On-Policy Self-Distillation（OPSD）是一种面向推理模型的同策略自蒸馏方法：学生仅根据问题 $q$ 生成轨迹，**特权教师**（同一模型的有 LoRA 副本）则以完整参考答案 $r$ 为条件，对学生的每个前缀 $\hat{y}_{<t}$ 提供 token 级分布匹配监督。
- **关键矛盾（训练–部署接口不对称）**：训练时教师看到完整解 $r$，但部署时学生仅能见到 $q$。完整解法中混入了**参考解特有信息**（最终答案绑定、特定推理顺序、特定文字表达、特定算术过程），这些信息在仅看问题时不可恢复。
- **已有证据**：近期工作观察到 OPSD 训练后的模型会**显式援引不存在的参考答案/答案键/提示**（Yang et al., 2026），即出现"特权信息泄露"行为。
- **核心问题**：在 OPSD 框架中，**教师应当观察何种特权信息**才是可迁移的？即特权信息的**表征（representation）**先于蒸馏损失设计。

## 2. 方法论：Problem-Space-Guided OPSD（PS-OPSD）

### 2.1 形式化：经典问题空间

- 借鉴 Newell–Simon 的问题空间理论（及 STRIPS），将一道数学题概念化为：
$$P(q) = \langle S, s_0, O, G, C \rangle$$
其中 $S$ 为状态空间，$s_0$ 为初始状态，$O$ 为可用算子集，$G$ 为目标条件，$C$ 为约束（数学题扩展）。
- 该形式化**仅作概念模型**，PS-OPSD 并不显式枚举 $S$、$O$，而是从一条已验证的解轨迹 $r$ 中**抽取**实例化的部分。

### 2.2 核心表征：Problem-Space Guidance

- 对每个 $(q, r)$，离线抽取器序列化为：
$$g_{PS}(q, r) = \langle s_0, G, C, \pi \rangle$$
  其中 $\pi = (\tau_1, \dots, \tau_k)$ 为选定的状态转移路径。
- 每个转移记录：
$$\tau_i = (o_i, \text{pre}_i, \text{transform}_i, s_i)$$
  即 **算子 / 前置条件 / 状态变换 / 产生的状态**。
- 四类顶层字段：
  - **Initial State**：变量、实体、已知条件、关系；
  - **Goal Conditions**：目标与可验证的成功条件；
  - **Constraints**：不变量、定义域、有效性条件；
  - **Selected State-Transition Path**：按顺序的 $(\text{Operator}, \text{Preconditions}, \text{Transformation}, \text{Resulting State})$ 记录列表。
- **关键设计取舍**：放弃完整解的措辞、顺序、算术细节，仅保留**沿轨迹实例化的功能性结构**——受关系迁移理论（Gentner 1983, Gick & Holyoak 1983）启发，认为"结构关系"比"具体解题形态"更可重用。

### 2.3 训练与推理流程

- **离线一次性抽取**：使用 Qwen3.6-35B-A3B 作为抽取器，将每个 $(q, r)$ 转成 $g_{PS}$ 并缓存；抽取器在优化与推理时均不使用。
- **训练时特权教师上下文替换**：
$$p^{OPSD}_{T,t} = p_T(\cdot \mid q, r, \hat{y}_{<t}),\quad p^{PS}_{T,t} = p_T(\cdot \mid q, g_{PS}(q,r), \hat{y}_{<t}),\quad p_{\theta,t} = p_\theta(\cdot \mid q, \hat{y}_{<t})$$
  **学生 rollout 与 OPSD 优化目标保持不变**。
- **优化目标（截断 KL 形式）**：
  - 温度 $T$ 下的软化分布：$p^{(T)} = \text{softmax}(z_p/T)$，$q^{(T)} = \text{softmax}(z_q/T)$；
  - 逐词表坐标的 KL 贡献：$d_T(p, q; v) = p^{(T)}(v)\log \frac{p^{(T)}(v)}{q^{(T)}(v)}$；
  - 截断 KL：$D^e_{c,T}(p \| q) = \sum_{v \in V} \min\{d_T(p, q; v), c\}$；
  - 总损失：
$$L_{PS\text{-}OPSD} = \mathbb{E}_{(q,r) \sim D}\;\mathbb{E}_{\hat{y} \sim p_\theta(\cdot \mid q)}\!\left[\frac{1}{|\hat{y}|}\sum_{t} D^e_{c,T}\!\left(p^{PS}_{T,t} \,\|\, p_{\theta,t}\right)\right]$$
  词表求和取全词表，对每个坐标贡献先截断再对非 padding 位置求平均。
- **推理**：学生仅以问题 $q$ 为输入，无参考答案、引导、教师、抽取器。算法 1（Algorithm 1）给出了完整流程。
- **额外控制变量**（4B 主设定下）：
  - **Flattened PS**：去字段名、层级与步骤分隔符；
  - **Mismatched PS**：用同问题族、同难度、同长度的另一题的引导替换；
  - **Path-Corrupted PS**：保留每个 $\tau_i$ 的局部语义但打乱/不一致地重组，破坏全局路径连贯性。

  - 9 个 scale×benchmark 单元中 PS-OPSD 严格最高的有 6 个；其余差距很小（AIME25@1.7B -0.19，HMMT25@4B -0.37，AIME24@8B -0.65）。
- **代表性控制（Table 2，4B）**：
  - Flattened PS 63.61、Path-Corrupted PS 62.19、Mismatched PS 61.76——相对完整 PS-OPSD（64.32）均下降；
  - 表明**目标相关引导**（vs Mismatched，-2.56）与**全局路径连贯性**（vs Path-Corrupted，-2.13）均贡献明显；**显式字段结构**的边际增量较小但稳定（-0.71），且对 HMMT25 反而略有不利。
- **问题级行为（Table 3，4B，90 题）**：
  - 相对 Base：PS-OPSD +2.56（18 改善 / 7 退步）、AVSD +1.02、GRPO +0.62、OPSD -0.06、SFT -0.15；
  - PS-OPSD vs OPSD：+2.62（23 vs 9 / 58 持平）。
- **Base 难例覆盖（Table 4，4B）**：Hard Avg 1.69→4.35、Hard Pass 8.70%→13.04%、Retention 97.01%→98.51%、Net Expansion 0→+2。
- **显式 PI 泄露（Figure 4）**：训练集最终 checkpoint OPSD 3.0% vs PS-OPSD 0.5%；留出验证集 OPSD 2.2% vs PS-OPSD 0.4%——PS-OPSD 在分布外问题上也显著降低对不可见参考的显式援引。
- **正确路径 token 熵（Table 5）**：
  - 与 Base 相比，OPSD 与 PS-OPSD 都未让正确路径更尖锐；
  - PS-OPSD vs OPSD：1.7B 三项均下降；4B Avg 不变、pass@12 +1.11、熵 +0.0321 nats；8B Avg +0.68、pass@12 +4.44、熵 +0.0319 nats——4B/8B 的覆盖增益并不依赖更集中的预测分布。
- **总体结论**：特权信息的**信息量**并非越多越好；将其组织为**问题求解结构（问题空间引导）**是 OPSD 中一个被忽视的关键设计变量。

## 7. 优点

- **问题切分清晰**：把"特权信息如何表征"独立于"蒸馏损失如何设计"，先回答表征问题，再改造 OPSD。
- **方法改动最小、接口清晰**：仅替换教师上下文，学生 rollout 与 token 级目标保持不变；推理时无任何特权模块，便于部署。
- **理论支撑**：基于经典问题空间理论与关系迁移理论，抽取 $\langle s_0, G, C, \pi \rangle$ 具有明确语义，而非 ad-hoc 提示工程。
- **评测多维**：聚合准确率 + 检查点轨迹 + 问题级增益/退化 + 难例覆盖 + 显式 PI 泄露 + 正确路径熵，且同时报告训练集与留出验证集。
- **控制实验设计严谨**：通过 Flattened / Mismatched / Path-Corrupted 三类变体，将"相关性""字段结构""路径连贯性"三种因素解耦。
- **行为诊断有价值**：显式 PI-Invocation 率给出可观测的泄露指标，且在留出验证集上同样成立，支持"减少参考特异依赖"的解释。

## 8. 不足与局限

- **域与模型族单一**：仅在 Qwen3（1.7B/4B/8B）+ 竞赛数学上验证，未覆盖其他模型族（Llama、DeepSeek 等）与领域（代码、常识、形式证明等），泛化性未知。
- **离线抽取器的依赖与成本**：使用 Qwen3.6-35B-A3B 抽取引导带来额外预处理成本与失败模式风险（抽取错误可能引入新的偏差）；论文未对抽取失败做敏感性分析。
- **表征集约范围有限**：$\pi$ 仅基于**单条**已验证解轨迹实例化，未涵盖替代路径、可恢复错误与完整问题空间；若 $r$ 本身欠佳，引导可能系统性偏差。
- **评测样本量较小**：AIME24/25 与 HMMT25 每套约 30 题，标准差最高 $\pm 2.89$（PS-OPSD@1.7B AIME25），报告的"严格最高"单元数与微差结论对采样噪声较敏感。
- **消融仅在 4B 主设定**：三种 PS 控制变体的结论未在其他规模上重复，难以判定是否随规模系统性变化。
- **温度与截断阈值的可复现性不足**：精确 $T$、$c$ 与运行配置"绑定到每次运行的 manifest"，不同尺度/运行不同，限制外部复现。
- **诊断非因果**：显式 PI-Invocation 是**行为表征**而非因果识别（无法证明不援引即不依赖特权信息）；正确路径熵衡量的是**局部预测集中度**而非**语义策略多样性**。
- **缺少与近期修复类方法的对比**：未与 Purified OPSD（Shen et al., 2026）、AVSD 之外的多视图/纯化基线充分对比；AVSD 被定位为方法级基线而非表征对照。
- **结论的因果链路未闭合**："PI-Invocation 下降 ⇒ 对不可见参考依赖下降 ⇒ 泛化提升"之间尚需更直接的干预或反事实证据。
