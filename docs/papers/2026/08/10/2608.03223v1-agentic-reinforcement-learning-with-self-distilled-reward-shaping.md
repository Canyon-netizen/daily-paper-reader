## 摘要
智能体强化学习使大语言模型智能体能够通过交互进行学习，但稀疏的轨迹级奖励仅揭示成功与否，而无法指出哪些中间决策应归功。训练阶段使用的特权技能可通过允许同一冻结的策略快照对无技能轨迹中的固定标记进行重新评分（同时以任务匹配的过程性技能为条件），从而提供更密集的监督信号。然而，现有方法既未在交互步骤间联合校准教师评分，也未将教师置信度与实际收益相关联，更未将由此产生的信号融入到原生的收益-优势构建中。我们提出了基于自蒸馏奖励塑形的智能体强化学习（ADRS），一种面向多轮语言智能体构建与收益关联的标记级信度分配框架。ADRS 在每一步内对特权标记分数进行中心化与归一化处理，通过基于组内置信度-收益关联的、与收益相关的教师价值优势（TVA）门控机制对其进行调制，并将经门控的标记信号融入到原生强化学习的信度分配构建中。上述组件共同决定了教师偏好何种行为、该偏好在何时与收益相关，以及该偏好如何进入原生强化学习的信度分配路径，同时保持 rollout 与推理过程的无技能化。最后，在三个交互式基准上的实验表明，ADRS 在长视野任务上持续提升性能，且该优势在不同强化学习骨干、减数据设置、未见任务以及更长训练周期下均得以保持。匿名评审期间，我们的代码可在以下链接获取：https://github.com/gitrxh/ADRS-arxiv

## Abstract
Agentic reinforcement learning enables LLM agents to learn through interaction, but sparse trajectory-level rewards reveal success without identifying which intermediate decisions deserve credit. Training-only privileged skills can provide denser supervision by allowing the same frozen policy snapshot to rescore fixed tokens from skill-free trajectories while conditioned on task-matched procedural skills. Existing methods, however, do not jointly calibrate teacher scores across interaction steps, relate teacher confidence to realized returns, and integrate the resulting signal into native reward-to-advantage construction. We introduce Agentic Reinforcement Learning with Self-Distilled Reward Shaping (ADRS), a framework for constructing return-associated token-level credit for multi-turn language agents. ADRS centers and normalizes privileged token scores within each step, modulates them with a return-associated Teacher Value Advantage (TVA) gate based on within-group confidence--return association, and incorporates the gated token signal into native RL credit construction. Together, these components determine what the teacher prefers, when that preference is return-relevant, and how it enters the native reinforcement-learning credit path, while keeping rollouts and inference skill-free. Finally, experiments across three interactive benchmarks show that ADRS consistently improves performance on long-horizon tasks, with gains persisting across RL backbones, reduced-data settings, unseen tasks, and extended training. For anonymous review, our code is available at the following the link: https://github.com/gitrxh/ADRS-arxiv

- **根本困难**：稀疏反馈使得 token 级时序信用分配（temporal credit assignment）极为困难，即便使用无 critic 的组内相对算法（如 GRPO、GiGPO）仍然受限。
- **已有路径的局限**：训练阶段特权技能（procedural skill）可提供密集监督，但现有方法（OPSD+RL 系列、SDAR 等）存在三大未解决挑战：
    1. **分数校准（Score Calibration）**：原始教师 log-probability 的偏置和尺度在不同交互步之间不可比。
    2. **可靠性估计（Reliability Estimation）**：高教师置信度未必与高回报关联（语言熟悉性 ≠ 任务关键决策）。
    3. **信用整合（Credit Integration）**：将特权监督放在独立的蒸馏辅助目标中，会脱离 GRPO/GiGPO 的原生收益-优势-策略通路，造成 token 级更新与组内相对优势错位。
- **研究目标**：保持 rollout 与推理阶段无技能（skill-free）的前提下，把仅训练阶段可见的技能转化为与回报关联的 token 级信用信号，并直接接入原生信用路径。

## 2. 方法论

### 2.1 整体框架

ADRS 包含三个**并行-汇合**模块，分别回答"教师偏好什么""该偏好何时与回报相关""如何进入原生信用路径"三个问题。流程为：
1. 行为策略 $\pi_{\theta_b}$ 在无技能条件下采样 $K$ 条轨迹，获得 base 收益；
2. 同一冻结快照在特权上下文 $\rho(x)\oplus h_s$ 下对相同已实现 token 重新打分；
3. 通过三个模块把教师信号加入 token 奖励，再进入原生 GRPO/GiGPO 优势估计。

### 2.2 模块一：步内相对特权打分（Within-Step Relative Privileged Scoring）

对每个已采样 token，在普通上下文与特权上下文下分别得到冻结评分：
$$\ell^{b}_{s,j} = \mathrm{sg}\!\left[\log \pi_{\theta_b}(y_{s,j}\mid h_s, y_{s,<j})\right],\quad \ell^{T}_{s,j} = \mathrm{sg}\!\left[\log \pi_{\theta_b}\!\left(y_{s,j}\mid \rho(x)\oplus h_s, y_{s,<j}\right)\right]$$

对每一步做中心化与尺度归一化：
$$b_s = \frac{1}{|\mathcal{V}_s|}\sum_{j\in\mathcal{V}_s}\ell^{T}_{s,j},\quad q_{s,j} = \ell^{T}_{s,j} - b_s,\quad \hat{q}_{s,j} = \frac{q_{s,j}}{\sigma_q + \epsilon}$$

满足步内零和约束：
$$\sum_{j\in\mathcal{V}_s}\hat{q}_{s,j} = 0$$

> 其作用是去除步间置信度偏置，并使强弱在不同上下文长度、交互位置、回复组成下可比。

### 2.3 模块二：与回报关联的 TVA 可靠性门控

TVA 支持两个粒度（整次训练选定一个层级，不动态回退）：
- **L2（轨迹级）**：对应 GRPO 的组比较；$R_u$ 为 prompt 内每条轨迹的预 ADRS 基础回报。
- **L3（步级）**：对应 GiGPO 的锚点状态比较；$R_u$ 为该状态起的回报-to-go。

定义单元置信度与软高置信度权重：
$$\bar{\ell}^{T}_u = \frac{1}{|\mathcal{V}_u|}\sum_{(s,j)\in\mathcal{V}_u}\ell^{T}_{s,j},\quad \bar{\ell}^{T}_{\mathrm{batch}} = \frac{1}{|\mathcal{U}|}\sum_{u\in\mathcal{U}}\bar{\ell}^{T}_u,\quad \alpha_u = \sigma(\bar{\ell}^{T}_u - \bar{\ell}^{T}_{\mathrm{batch}})$$

对照高低置信度两侧的回报均值：
$$\mu^{+}_g = \frac{\sum_{u\in g}\alpha_u R_u}{\sum_{u\in g}\alpha_u + \epsilon},\quad \mu^{-}_g = \frac{\sum_{u\in g}(1-\alpha_u)R_u}{\sum_{u\in g}(1-\alpha_u) + \epsilon},\quad d_g = \mu^{+}_g - \mu^{-}_g$$

经可选正尺度归一化为 $\tilde d_g$ 后，得到广播到整单元的 detached 门：
$$m_u = \mathrm{sg}\!\left[\sigma(\tau \tilde d_{g(u)})\right]$$

**命题 1（TVA 作为回报关联的统计意义）**：忽略数值 $\epsilon$，令 $\bar\alpha_g = \mathbb{E}_g[\alpha]$，对任何非退化组：
$$d_g = \frac{\mathrm{Cov}_g(\alpha, R)}{\bar\alpha_g(1-\bar\alpha_g)}$$

即门控的符号与组内置信度—回报经验协方差一致；分母为正，因此 $d_g$ 与高置信度对应高回报方向严格一致。

### 2.4 模块三：教师引导的逐 token 优势调制（Pre-Advantage Reward Shaping）

教师 token 奖励与塑形后奖励：
$$r^{T}_{s,j} = \eta\, m_{s,j}\hat q_{s,j},\quad \tilde r_{s,j} = r^{\mathrm{base}}_{s,j} + r^{T}_{s,j}$$

其中 $\eta\ge 0$ 为教师尺度超参。

**命题 2（Stepwise 零和表示）**：若归一化分母与门控在同一交互步内共享，则 $\sum_{j\in\mathcal{V}_s}r^{T}_{s,j}=0$；并对任意排列存在采样链表示 $r^{T}_{s,j_r} = \Phi_{s,r+1}-\Phi_{s,r}$，$\Phi_{s,1}=\Phi_{s,n_s+1}=0$。这是采样步上的代数恒等式，并非固定 Markov 势能下的策略不变性。

**两条信用通路**：
- 轨迹通路把 $\tilde r$ 喂入原生 GRPO/GiGPO 得到 $A^{\mathrm{traj}}$；因零和，$S_{i,k}=\sum_t \tilde r_{i,k,t}$ 等于 base 得分，故轨迹方向与原生算法一致。
- Token 通路对 $r^{T}$ 在 prompt 组内做白化：
$$\mu^{T}_g = \mathrm{Mean}_{v\in\mathcal{V}_g}(r^{T}_v),\quad (\sigma^{T}_g)^2 = \mathrm{Var}_{v\in\mathcal{V}_g}(r^{T}_v),\quad Z^{T}_t = \frac{r^{T}_t - \mu^{T}_g}{\sqrt{(\sigma^{T}_g)^2+\epsilon}}$$

两通路在 token 级汇合：
$$A^{\mathrm{ADRS}}_{i,k,t} = A^{\mathrm{traj}}_{i,k} + \eta Z^{T}_{i,k,t}$$

当 $\eta=0$ 时退化为原生 backbone。

**Actor 损失**（标准 PPO 风格 clip）：
$$\omega_t(\theta)=\exp\!\big(\log\pi_\theta(y_t\mid c_t)-\ell^{b}_t\big),\quad \bar\omega_t(\theta)=\mathrm{clip}\big(\omega_t(\theta),1-\varepsilon_{lo},1+\varepsilon_{hi}\big)$$
$$\mathcal{L}_{\mathrm{actor}}(\theta) = -\frac{1}{|\mathcal{V}|}\sum_{t\in\mathcal{V}} \min\!\big[\omega_t(\theta)A^{\mathrm{ADRS}}_t,\; \bar\omega_t(\theta)A^{\mathrm{ADRS}}_t\big]$$

**命题 3（轨迹方向保留与局部 token 梯度等价）**：在步共享门控下，式 (7) 不改变 GRPO 轨迹得分 $A^{\mathrm{traj}}$。若教师信号在组内非恒定，式 (10) 仍会引入非零 token 信用。在行为策略点且 clip 未触发时，设 $\Delta A_t = \eta Z^{T}_t$，则
$$\nabla_\theta J_{\mathrm{ADRS}}\big|_{\theta_b} = \frac{1}{|\mathcal{V}|}\sum_{t\in\mathcal{V}}(A^{0}_t+\Delta A_t)\nabla_\theta\log\pi_\theta(y_t\mid c_t)$$

这与 detached 采样 token 辅助系数 $a_t$ 给出的局部梯度形式一致；令 $a_t=\Delta A_t$ 时两者在评估点一阶等价。该等价是**局部的、采样批上的、未穿越 clip 分支**，广义等价性需要额外假设。

### 2.5 TVA 层级与回退

- 整次训练选择 L2 或 L3，不动态切换；
- 单元数 < 2 的组 $d_g=0\Rightarrow m=0.5$；
- 关闭 TVA 即设 $m=1$；
- 当存在参考 log-prob 但 L2/L3 张量缺失时回退到 L1：$m^{\mathrm{L1}}_t = \mathrm{sg}[\sigma(\tau(\ell^{T}_t - \ell^{\mathrm{ref}}_t))]$，**不含回报信息，并非 TVA 估计器**。

### 客观性与公平性的观察

- 在 150 步公共预算下与 SDAR 等共享同一 SDAR benchmark/评测协议，公平性较好；
- 评分时 temperature 0.4 采样，prompt 长度 2048（ALFWorld）/4096（WebShop、Search）；
- 但**多次出现"best checkpoint"报告**：例如 ALFWorld 96.9–97.7、Search $\eta=0.1$ peak 42.1 出现在第 285 步；这种"峰值报告"本身可能引入评估偏差；
- Search-based QA 步 150 上 ADRS-global = 38.3 相对 GRPO 38.4 表现为 **-0.1**（Table 10），在满分设置下 ADRS 仅靠峰值多 0.3（步 300），该基准上的提升**最弱**；
- ALFWorld unseen split 中 Look 类出现 **-4.4** 的负迁移，提示并非所有任务族均获益；
- 多组命名变体（GateNorm、no-TVA、entropy/clip、per-seq vs global）在不同基准上**最优配置不同**，需逐环境调参，缺乏统一 recipe 的客观性。

## 6. 主要结论与发现

- **总体领先**：以 Qwen2.5-3B 在 150 步下达 ALFWorld 94.5%（+10.1）、Search 45.0%（+0.4）、WebShop 87.5/76.6（+2.5/+8.6）三项基准新 SOTA。
- **跨模型/规模一致**：Qwen2.5-3B/7B、Qwen3-1.7B 在 ALFWorld 整体分别 94.5/96.1/62.5，均高于最强基线 10.1/7.8/8.6 分。
- **不依赖测试时技能**：所有 ADRS 评测

时均**无技能上下文**，评测与 rollout 完全 skill-free，与 OPSD/SDAR 类需要在推理分支注入技能提示的方法形成对比。

- **与基线拉开差距**：相对 GRPO 在 ALFWorld +8.6、WebShop +6.1/+3.4、Search +2.1；相对 GiGPO 在 ALFWorld +7.7、Search +0.9；相对最强特权自蒸馏 SDAR 在三基准上分别 +2.8、+1.5、+0.6。Skill-SD 与 GRPO+OPSD 在多数设置下甚至**低于 vanilla GRPO**，凸显"特权技能若不与回报耦合，会拖累原生信用通路"。

- **早收益**：Figure 4/5 显示 ADRS 在 WebShop 前 ~30 步、ALFWorld 前 ~75 步即与 GRPO/GiGPO 拉开差距，**无需等满 150 步**就能体现 token 级信用红利。

- **数据效率**：在 20%/40%/60% 训练数据下 ADRS 仍超过 GRPO 全量训练的最终性能（图 7 左），表明稠密 token 信用确实降低了样本需求。

- **未见任务泛化**：在 ALFWorld 6 个未见 split 上 ADRS 整体仍领先；仅 Look 类出现 -4.4 负迁移，作者归因于该类任务对动作顺序高度敏感、且训练集中 Pick 类主导造成的分布偏差。

- **机制可解释性（§5.5）**：在 4 条固定成功轨迹上，对动作 token 教师-学生 log-prob 差距显著高于对象 token 与风格 token（Table 11），从经验上验证了"特权技能偏好落在任务关键决策上"的命题，但作者承认这是定性观察，**未做统计显著性检验**。

- **长视野鲁棒性**：交互步长由 25 → 50 时，ADRS 相对 SDAR 的领先幅度扩大，提示 token 级信用在更长 credit assignment 链路上更具价值（图 8）。

- **TVA 层级与归一化敏感性**：L3（per-seq/anchor）通常优于 L2（global），且 +GateNorm 的增益并不普遍；这表明 TVA 是**必要但不充分**的信号，没有它 ADRS 会退化为普通 teacher-forced 蒸馏，**有了它也不保证单调提升**。

- **超参 $\eta$ 的影响**：Search 在 $\eta=0.1$ 出现 42.1 峰值、$\eta=0.05$ 给出 38.3 终值；同一基准不同 $\eta$ 差距可达 3.8 分，说明**教师信号强度需要逐环境调节**，并非即插即用。

## 7. 局限性与开放问题

作者在 §7（Limitations & Discussion）中**自陈**了以下不足，结合正文可进一步归纳：

1. **教师-学生同源假设**：本文 $\ell^T$ 与 $\ell^b$ 来自同一冻结快照的两次前向，技能以 prompt 前缀注入；这隐含两点——(a) 学生必须已经具备阅读并执行技能描述的能力（即经过指令微调），对于 raw base 模型或非英语技能库并不成立；(b) 技能质量上限被绑定到 student 自身能力，**不能用更强教师做大模型带小模型**。作者明确承认这一点。

2. **TVA 的标量损失**：式 (6)–(7) 将每个单元压成单个 $m_u\in(0,1)$，粒度较粗；当 prompt 组内单元数极少（<2）时直接回退到 0.5；同时若高置信度子集与低置信度子集在回报上同向变化，$d_g$ 会被稀释。L3 相对 L2 更稳定，但并未消除这一结构问题。

3. **$\eta$ 与 GateNorm 的逐环境调参**：Search、ALFWorld、WebShop 上的最优 $(\eta, GateNorm, L)$ 组合不统一，复现者必须做小规模 sweep；作者**未给出统一的选取规则**。

4. **稀疏任务上的稳定性**：作者自陈在极稀疏奖励（成功率 < 5%）的早期训练阶段，$\bar\alpha_g$ 可能退化、$d_g$ 信噪比下降；当前实现**没有针对该阶段的特殊处理**。

5. **评估的峰值偏差**：多处结果报告 best checkpoint（Table 3、Table 10 出现 285 步峰值），对最终性能（last-3）来说 Search 上 ADRS-global 仅领先 GRPO 0.3 分；评测协议若统一改为 last-3，会削弱"显著超越 GRPO"的叙事强度。

6. **动作-对象机制的统计性**：§5.5 的 token-level 对比是描述性的，未对教师-学生差距分布做置换检验或效应量估计，机制层面的因果论证偏弱。

7. **公平性边界**：与 SDAR 的比较使用 SDAR 自带 benchmark，技能库与教学前缀格式均沿用其设置；与 OPSD 系列、Skill-SD 的对比则使用各论文报告的数值，可能存在 prompt/解码超参不一致。

8. **泛化到非 Qwen 系列 / 多模态 / 多智能体**：本文只在三种 Qwen 系模型、纯文本任务上验证；视觉导航、工具调用、多智能体协作等场景下的 token 级信用结构与 TVA 估计器的有效性**未经验证**。

9. **技能注入的工程耦合**：$[Privileged Skill Information]$ 前缀仅在 post-rollout 重打分时使用，普通分支不接收；这要求训练 pipeline 实现两套 prompt 组装与一次额外前向，对工程集成提出额外要求，且**不能直接复用**给不带技能接口的环境。

10. **未量化社会/伦理影响**：作者明确未在本文中讨论 dual-use、偏见放大、能源消耗等议题，仅声明按模型卡与数据许可使用。

## 8. 综合评价

**优点**：
- 问题切分清晰（三个独立可分析的子问题），方法对应三个紧致模块；
- 命题 1–3 把"为什么 work"从经验层面提升到张量等式层面，$\sum_j r^T=0$ 的零和结构是少见且有用的不变量；
- 实验覆盖三个差异显著的基准（具身、网购、QA）与三个模型，规模充分；
- skill-free rollout/inference 的设计在实用性上优于 OPSD/SDAR 系列；
- 数据效率与未见 split 验证提供了"非过拟合"证据。

**缺点**：
- 评估协议混入 best checkpoint，削弱了最终性结论；
- TVA 仍是粗粒度标量门控，且依赖回报统计稳定性；
- 机制分析停留在定性，缺少统计推断；
- $\eta$ 与归一化策略需要逐环境 sweep，缺乏统一 recipe；
- 与最强对手（SDAR）的差距在 Search 基准上仅 +0.6，提升幅度有限；
- 复现门槛较高：需冻结快照双前向、两套 prompt 组装、教师技能库与 prefix 模板。

**适用场景**：当环境支持 post-rollout 重打分、具备 prompt 级技能描述、且训练阶段回报足够稠密以使 TVA 估计稳定时，ADRS 作为对 GRPO/GiGPO 的 drop-in 增强具有较强吸引力；在极稀疏或非指令微调场景下需谨慎评估。
