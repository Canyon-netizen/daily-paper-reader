## 摘要
深度强化学习（RL）众所周知样本效率低下。其原因之一在于强化学习智能体通常从零开始初始化，迫使它们只能通过在线交互获取与任务相关的知识。现有方法通过预先收集的数据集、高保真模拟器或对相关任务的元学习来获得有信息量的初始化，但这些前提条件往往难以获取甚至完全不可用。在本文中，我们提出了用于价值网络初始化的程序化动力学先验（ProDVI），这是一个利用编码在大语言模型中的常识和领域知识来初始化强化学习智能体、且无需依赖上述资源的框架。具体而言，ProDVI 提示一个代码生成语言模型生成可执行的 Python 函数，这些函数对环境动力学进行粗粒度的假设编码。随后利用这些函数生成合成转移样本。基于这些转移样本，我们构建一个辅助的动力学预测目标，在 actor-critic 框架下对价值网络的状态-动作编码器进行预训练。所学习到的表示在在线强化学习开始之前便引入了具有动力学感知能力的归纳偏置。需要强调的是，生成的程序仅用于表示预训练，并不要求其能忠实地模拟目标环境。尽管生成的程序可能并不准确，但其所带来的初始化可以通过真实转移样本与奖励信号的在线学习加以修正。在 OpenAI Gym 和 DeepMind Control Suite 任务上的实验表明，ProDVI 能够有效提升无模型强化学习算法的样本效率。

## Abstract
Deep Reinforcement Learning (RL) is notoriously sample inefficient. One contributing factor is that RL agents are typically initialized from scratch, forcing them to acquire task-relevant knowledge through online interaction. Existing approaches obtain informative initializations through pre-collected datasets, high-fidelity simulators, or meta-learning over related tasks, but these prerequisites may be difficult to access or even unavailable. In this paper, we propose Programmatic Dynamics Priors for Value Network Initialization (ProDVI), a framework that leverages the commonsense and domain knowledge encoded in large language models to initialize RL agents without relying on these resources. Specifically, ProDVI prompts a code-generating language model to produce executable Python functions that encode coarse hypotheses about environment dynamics. These functions are then used to generate synthetic transitions. Based on these transitions, we construct an auxiliary dynamics prediction objective to pretrain the state-action encoder of the value network in an actor-critic framework. The learned representation provides dynamics-aware inductive biases before online RL begins. Importantly, the generated programs are used only for representation pretraining and are not required to faithfully simulate the target environment. While the generated programs may be inaccurate, their induced initialization can be corrected through online learning from real transitions and rewards. Experiments on OpenAI Gym and DeepMind Control Suite tasks show that ProDVI can effectively improve the sample efficiency of model-free RL algorithms.

  3. 如何将该先验蒸馏到智能体中？

## 2. 方法论

### 2.1 核心思想
ProDVI（Programmatic Dynamics Priors for Value Network Initialization）通过提示代码生成 LLM 产出可执行 Python 函数，对环境动力学进行粗粒度假设编码；然后用这些函数合成大量转移样本，通过辅助动力学预测任务预训练 actor-critic 框架中价值网络的状态-动作编码器，从而在在线 RL 开始前注入动力学感知的归纳偏置。

### 2.2 关键技术细节

#### （1）从 LLM 抽取先验知识
- **环境描述**：以 Python 类形式描述环境，包括 docstring（动作/观测空间的语义含义）和内部变量（如重力、机体质量等配置参数）。
- **动力学分析**：LLM 首先生成对环境动力学的**结构化文本分析**（分析动作如何影响观测，按步骤分解因果关系）。
- **代码生成**：基于分析，LLM 实现一个 `do_simulation(o, a) → o'` 函数，编码近似的动力学程序 $g_{\text{LLM}}$，但**不要求忠实模拟**真实环境。

#### （2）辅助动力学预测目标
ProDVI 的核心灵感来自 OFENet，在**归一化观测空间**中训练状态-动作编码器。给定转移样本 $(\tilde{o}_t, a_t, \tilde{o}_{t+1})$，辅助损失为：

$$z_t = f_\theta(\tilde{o}_t, a_t)$$

$$L_{\text{Aux}} = \|d_\phi(z_t) - \tilde{o}_{t+1}\|_2^2$$

其中 $f_\theta$ 为状态-动作编码器，$d_\phi$ 为解码器。归一化（通过 NormMethod）能避免不同维度的值域差异导致梯度失衡。

#### （3）合成样本生成
观测从多元高斯分布采样后裁剪到有限范围，动作从有效范围均匀采样：

$$o \sim \mathcal{N}(0, I), \quad \tilde{o} = \text{clip}(o, -O, O), \quad a \sim \mathcal{U}(a_{\min}, a_{\max})$$

合成下一观测：

$$\hat{o}_{t+1} = g_{\text{LLM}}(\tilde{o}_t, a_t)$$

合成转移样本按其自身均值 $\mu$、标准差 $\sigma$ 归一化后裁剪到 $(-O, O)$，得到 $\tilde{o}_{t+1}$。

#### （4）软重置以缓解可塑性损失
ProDVI 借鉴 "shrink-and-perturb" 策略：

$$\theta_{\text{init}} = \alpha \bar{\theta} + (1-\alpha)\theta_0$$

其中 $\bar{\theta}$ 为预训练参数，$\theta_0$ 为从原始初始化分布重新采样的参数，$\alpha \in (0,1)$ 控制保留比例。这可避免编码器对合成数据过拟合后无法适应真实环境转移。

### 2.3 算法流程（Algorithm 1）
1. 提示 LLM 基于环境描述生成文本动力学分析与可执行程序 $g_{\text{LLM}}$；
2. 生成 $N_{\text{syn}}$ 个合成转移样本；
3. 归一化合成下一观测；
4. 在合成数据上预训练编码器 $f_\theta$ 与解码器 $d_\phi$，最小化 $L_{\text{Aux}}$；
5. 通过软重置获得 $\theta_{\text{init}}$；
6. 使用 $\theta_{\text{init}}$ 初始化价值网络，运行在线 actor-critic RL。

### 2.4 方法特性
- **不依赖** 预收集轨迹、模拟器或元学习任务；
- **LLM 解耦**：生成程序后不再调用 LLM；
- **可跨任务复用**：相同动力学规则的任务共享先验；
- **不准确也可纠正**：在线 RL 通过真实转移与奖励修正初始化偏差。

## 3. 实验设计

### 3.1 基准与场景
- **OpenAI Gym (MuJoCo)**：5 个经典运动任务 — Ant-v5、HalfCheetah-v5、Hopper-v5、Humanoid-v5、Walker2d-v5（训练 1M 时间步）；
- **DeepMind Control Suite (DMControl)**：7 个高难度任务 — dog-{run, stand, trot, walk}、humanoid-{run, stand, walk}（训练 500k 时间步，动作重复 2 次）；
- **LLM**：GPT-5.5；Gym 中按任务生成先验，DMControl 中按域（domain）生成（因同一域任务共享动力学规则）。

### 3.2 对比方法
- **AnonMethod**：基于 TD3 的强无模型基线，结合 NormMethod 与观察预测辅助任务；
- **AnonMethod w/o Aux**：AnonMethod 去掉辅助观察预测任务的变体；
- **AnonMethod-SAC / AnonMethod-SAC w/o Aux**：基于 SAC 的对应版本；
- **Deep-TD3 / Deep-SAC**：加深加宽后的 TD3/SAC，用于归一化评分基准。

### 3.3 评估协议
- 每个方法/任务 5 个随机种子（$\{42, 99, 123, 520, 668\}$），每 5k 步在 10 个 episode 上评估；
- 报告 Mean 与 IQM（Interquartile Mean）；
- Gym 使用 Deep-TD3 归一化评分：

$$\text{Deep-TD3-Norm}(x) = \frac{x - \text{random score}}{\text{Deep-TD3 score} - \text{random score}}$$

### 3.4 默认超参数
- 合成转移数 $N_{\text{syn}} = 7\text{M}$，插值系数 $\alpha = 0.5$；
- 预训练 batch size 256，5 epochs，AdamW 优化器（lr = 3e-4，weight decay = 1e-4）；
- 其他沿用 AnonMethod/NormMethod 默认配置（详见附录表 4）。

## 6. 主要结论与发现

- **样本效率提升**：在 Gym 和 DMControl 上，+ProDVI 在 0.25M 步的低数据场景中提升尤为显著，且对 AnonMethod 和 AnonMethod w/o Aux 均稳定有效；
- **算法无关性**：相同的程序化动力学先验迁移到 SAC 骨架同样带来增益（特别在训练初期），说明先验不依赖于特定 actor-critic 算法；
- **增益来源并非准确模拟**：LLM 生成的程序在真实转移上预测误差很大（MSE/MAPE 极高），说明这些程序远非忠实模拟器；
- **增益来自有信息量的动力学信息**：以 ProDVI 初始化后的编码器作动力学预测器，在真实转移上训练损失低于从零训练，说明先验在隐藏单元中编码了有用的结构信息；
- **对 LLM 生成随机性稳健**：两次独立生成的先验（#2、#3）在 Gym 和 DMControl 上均带来一致提升；
- **软重置必要**：直接使用预训练参数初始化未必最佳，$\alpha = 0.5$ 在缓解可塑性损失的同时保留动力学偏置。

## 7. 优点

- **门槛低**：仅需环境描述（docstring + 配置参数）与一次 LLM 调用，无需任何数据集、模拟器或元训练任务，扩展了 RL 初始化的适用场景；
- **LLM 解耦**：避免在线 RL 循环中的重复 LLM 调用，节省推理成本；
- **跨任务复用**：相同动力学的不同任务可共享同一先验；
- **容错性好**：不要求生成程序忠实模拟，对不准确的先验具备在线修正能力；
- **机制可解释**：通过动力学预测器迁移实验直接验证了增益来自编码器表示而非预测准确性；
- **可迁移性强**：在 TD3 与 SAC 两种骨架上均验证有效；
- **稳健性强**：对 LLM 生成的随机性不敏感；
- **实验设计规范**：使用归一化评分、IQM、bootstrap 置信区间、五种子平均等标准协议。

## 8. 不足与局限

- **状态空间限制**：目前仅在低维 state-based 设置上验证，未扩展到高维视觉观测（pixel-based）；
- **依赖 LLM 能力**：生成程序的质量受 LLM 代码生成与物理推理能力限制；若 LLM 无法产生有意义的动力学分解，则 ProDVI 退化为普通随机初始化；
- **超参数依赖**：合成样本数（7M）与插值系数（$\alpha = 0.5$）的选择依赖于在 Gym 上的两阶段敏感性研究，DMControl 上未独立调优，存在跨域泛化风险；
- **未衡量计算开销**：合成 7M 样本并预训练编码器所需的额外时间/算力未在正文中明确报告，对实际部署的性价比尚不清楚；
- **生成样本不在分布内**：从高斯分布采样的 $(\tilde{o}_t, a_t)$ 可能不在真实观测-动作流形上，预训练数据分布与在线 RL 数据分布存在 mismatch；
- **跨任务复用假设**：在 DMControl 按"域"复用先验，依赖"同域任务共享动力学规则"的假设，对动力学差异显著的任务未必有效；
- **解释性归因有限**：仅通过动力学预测损失间接验证先验提供了有信息量的特征，但未深入揭示是哪些结构属性（如质量守恒、几何关系）带来了增益；
- **可比基线较少**：与专门为 LLM 生成世界模型设计的方法（如 Code World Models、WorldCoder、Eureka、GenSim、RoboGen）缺乏直接的 head-to-head 对比，主要与无模型 RL 基线比较；
- **样本数与步数规模偏小**：Gym 1M 步、DMControl 500k 步对于现代 RL benchmark 仍属较小规模，对长程复杂任务的扩展性未知。
