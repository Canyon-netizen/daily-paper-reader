## 摘要
同策略自蒸馏（OPSD）通过蒸馏来自冻结教师模型的指导信息来适配语言模型，其中教师模型的指导来自学生模型采样的轨迹。然而，其有效性高度取决于这些轨迹的质量。我们表明，当学生模型的轨迹展开偏离目标轨迹时，使教师模型以偏离目标的上下文前缀为条件，会显著削弱其与任务相关的监督。受控前缀损坏实验揭示了这一失效模式，我们将其称为轨迹条件化信号退化。为解决这一问题，我们提出一个统一的训练框架，将两种互补的监督路径分离。第一条路径保留基于轨迹展开的分布匹配，为学生模型实际访问的状态提供指导；第二条路径在规范的真实目标上下文上采用监督交叉熵，从而避免在错误的轨迹展开前缀上强制施加目标令牌所带来的不兼容性。我们利用令牌级轨迹展开—目标对齐来动态调整真实上下文锚点的强度：在冷启动阶段强化该锚点，并随着轨迹展开质量的提升而逐步放松。跨多个模型规模、两类任务以及通用推理基准的实验表明，与 OPSD 相比，所提方法能够提升任务习得能力，同时保持通用能力，从而获得更有利的经验性可塑性—稳定性权衡。这些发现表明，上下文质量是同策略自蒸馏中的核心瓶颈，并证明了将基于轨迹展开的指导与规范监督相分离的价值。

## Abstract
On-policy self-distillation (OPSD) adapts a language model by distilling guidance from a frozen teacher on trajectories sampled from the student. Its effectiveness, however, depends critically on the quality of those trajectories. We show that when student rollouts drift from target trajectories, conditioning the teacher on off-target prefixes substantially weakens its task-relevant supervision. Controlled prefix-corruption experiments expose this failure mode, which we term rollout-conditioned signal degradation. To address this problem, we propose a unified training framework that separates two complementary supervision pathways. The first retains rollout-conditioned distribution matching, providing guidance on states the student actually visits. The second applies supervised cross-entropy on canonical ground-truth contexts, avoiding the incompatibility of imposing target tokens on erroneous rollout prefixes. Token-level rollout-target alignment is used to adapt the strength of the canonical-context anchor, emphasizing it during cold start and relaxing it as rollout quality improves. Experiments across multiple model scales, two task families, and general-reasoning benchmarks show that the proposed approach improves task acquisition over OPSD while preserving general capabilities, resulting in a more favorable empirical plasticity-stability trade-off. These findings identify context quality as a central bottleneck in on-policy self-distillation and demonstrate the value of separating rollout-conditioned guidance from canonical supervision.

- **核心概念**：将上述现象命名为 **rollout-conditioned signal degradation（轨迹条件化信号退化）**，并提出 **context-validity principle（上下文有效性原则）**：每个监督目标都应在其语义有效的上下文下评估。

## 2. 方法论：Supervised Distillation Steering (SDS)

### 2.1 整体框架

SDS 将两条互补的监督路径**严格解耦**于不同的前缀上下文，共享同一组可训练参数 $\Delta\theta$：

1. **Rollout-conditioned 分支**：在学生生成前缀 $[x;\hat{y}]$ 上，将学生 $p_S(\cdot|x,\hat{y}_{<t})$ 与冻结特权教师 $p_T(\cdot|x^{PI},\hat{y}_{<t})$ 对齐（采用 generalized JSD）。
2. **Canonical-context anchoring 分支**：在 ground-truth 前缀 $[x;y^\*]$ 上独立进行 teacher-forcing 交叉熵计算。

### 2.2 关键公式

**OPSD 基线（Eq. 1）**：

$$L_{\text{OPSD}} = \frac{1}{|\hat{y}|}\sum_{t=1}^{|\hat{y}|} D\!\left(p_T(\cdot\mid x^{PI},\hat{y}_{<t})\;\|\;p_S(\cdot\mid x,\hat{y}_{<t})\right)$$

**Naive OPSD+CE 的目标–上下文失配（Eq. 4–5）**：

$$L_{\text{naive CE}} = -\frac{1}{|y^\*|}\sum_{t=1}^{|y^\*|}\log p_S(y^\*_t\mid x,\hat{y}_{<t})$$
$$L_{\text{naive OPSD+CE}} = L_{\text{OPSD}} + \lambda_{\text{CE}}\,L_{\text{naive CE}}$$

其中 $y^\*_t$ 在已发散的 $\hat{y}_{<t}$ 下未必是合法下一 token。

**SDS 的上下文分离锚定（Eq. 6）**：

$$L_{\text{anchor}} = -\frac{1}{|y^\*|}\sum_{t=1}^{|y^\*|}\log p_S(y^\*_t\mid x,y^\*_{<t})$$

**自适应锚定权重（Eq. 7）**：令 $\mathrm{sim}(\hat{y},y^\*)$ 为任意取值于 $[0,1]$ 的 token 级相似度（默认 token-level F1），则

$$w_{\text{anchor}} = 1 - \mathrm{sim}(\hat{y},y^\*)$$

$$L_{\text{SDS}} = \frac{1}{|\hat{y}|}\sum_{t=1}^{|\hat{y}|} D\!\left(p_T(\cdot\mid x^{PI},\hat{y}_{<t})\;\|\;p_S(\cdot\mid x,\hat{y}_{<t})\right) + \alpha\,w_{\text{anchor}}\,L_{\text{anchor}}$$

其中发散项采用 generalized JSD：

$$\mathrm{JSD}_\beta(p_T\|p_S) = \beta D_{\mathrm{KL}}(p_T\|m_\beta) + (1-\beta)D_{\mathrm{KL}}(p_S\|m_\beta),\quad m_\beta=\beta p_T+(1-\beta)p_S$$

### 2.3 算法流程要点

- 教师为冻结的 $\theta_0$（LoRA 禁用），学生为 $\theta_0+\Delta\theta$（LoRA 启用），实现白盒自蒸馏。
- 两条分支在**前向层面**完全分离：rollout 分支使用 $[x;\hat{y}]$，锚定分支使用 $[x;y^\*]$，二者梯度共同更新 $\Delta\theta$。
- 锚定权重 $w_{\text{anchor}}$ 由当前策略的 rollout 在线计算，形成**闭环负反馈**：rollout 与目标对齐越差，锚定越强；对齐改善后锚定放松但保持非零。
- 不依赖固定的训练阶段切换点或人工设定权重。

## 3. 实验设计

### 3.1 模型与数据集

- **模型**：Qwen3-1.7B / 4B / 8B（开源权重，可复现白盒自蒸馏）。
- **任务适配数据集**：
  - **ToolAlpaca（SDFT 处理版）**：多轮结构化工具调用，4,046 训练样本，68 测试题；
  - **SimpleMath**：四则小数运算 + 链式思维 + 4 位小数答案格式，2,500 训练 / 12,500 测试，取分层 1,000 题作为评估子集。
- **通用能力保留基准**（均非训练集）：AIME 2024（30 题）、MATH-500、ARC-Challenge。

### 3.2 对比方法

- **主要基线**：SFT（标准监督微调）、GRPO（基于二元结果奖励的组相对策略优化）、OPSD（同策略自蒸馏）、SDS（本文）。
- **消融对照**：
  - **Naive OPSD+CE**：上下文未分离的 CE 注入；
  - **Isolated SFT, w=1 / w=0.5**：保持上下文分离但固定锚定权重；
  - **SFT→OPSD**：人工两阶段切换；
  - **$\alpha$ 消融**：$\alpha\in\{0.1,0.2,0.5\}$。

### 3.3 评估指标

- ToolAlpaca：Pass@12、Turn Accuracy、Format Rate；
- SimpleMath：Overall Accuracy + 分运算（+/-/×/÷）准确率，贪心解码；
- AIME 2024 / MATH-500：Pass@8、Avg@8、MajVote@8，温度 1.0、top-p 0.95、max_tokens 38,912，$\mathrm{math\_verify}$ 评分；
- ARC-Challenge：准确率 + 格式率。

### 3.4 实现细节

- LoRA：rank=64，$\alpha_{\text{LoRA}}=128$，dropout=0.05，目标模块为 q/k/v/o/gate/up/down 投影；
- 优化器：AdamW，lr=$5\times10^{-5}$（SimpleMath）/ $1\times10^{-5}$（Tool-use），cosine 调度，bf16 + FlashAttention-2 + 梯度检查点；
- 框架：ms-swift 4.1.3 + vLLM 0.11.0（colocate 推理教师）；
- **每个方法 × 模型组合用 3 个随机种子（42/43/44）**，主表报告均值。

## 4. 资源与算力

- **GPU**：NVIDIA H20（143 GB 显存）。
- 文末附录列出各任务共用的 LoRA/优化器配置（Table 4–10），明确给出 SDS 相比 OPSD 每步多一次独立 student 前向（canonical-context CE 分支）。

## 6. 主要结论与发现

- **机制层面**：上下文质量是 on-policy 自蒸馏被忽视的核心瓶颈。同一 ground-truth 信号，在 canonical 前缀下有效、在发散前缀下反而损害训练（Naive OPSD+CE 在 SimpleMath 上仅 55.20%、AIME Avg@8 暴跌至 3.33%）。
- **方法层面**：将 rollout-conditioned 分布匹配与 canonical-context 监督在**前向层面分离**，并通过 token 级 $\mathrm{sim}(\hat{y},y^\*)$ 自适应调节锚定强度，可同时获得：
  - 较 OPSD 显著更好的任务获取（Qwen3-4B SimpleMath：$23.23\%\to 62.43\%$；Tools Pass@12：$62.75\%\to 72.06\%$）；
  - 较 SFT 显著更好的通用能力保留（AIME24 Avg@8：$38.33\%\to 67.98\%$；ARC-Challenge Acc：$66.13\%\to 87.75\%$）；
  - 在 plasticity–stability 平面上位于 SFT（强任务弱能力）与 OPSD（弱任务强能力）之间，构成更优的 Pareto 折中。
- **设计层面**：
  - 上下文分离 > 加权或调度（SFT→OPSD 仅 55.03%/35.42%）；
  - 自适应权重优于固定权重（无单一固定 $w$ 同时取得强任务与强能力）；
  - $\alpha=0.2$ 在 Qwen3-4B SimpleMath 上为最佳平衡点（$\alpha=0.1$ 偏保留、$\alpha=0.5$ 偏获取且任务精度不优于 0.2）。
- **度量层面**：连续分级距离（Token F1 / ROUGE-L F1 / Token Edit Distance）显著优于二值 Exact Match，尤其在乘除法上（EM 乘法仅 3.6% vs. 分级方法 25.2–29.6%）。

## 7. 优点与亮点

- **问题发现价值高**：用简洁的受控实验（prefix corruption + 真实 rollout 分箱）明确指出了 OPSD 长期被忽视的监督失效机制，诊断论证扎实。
- **设计原则清晰**：将 "**监督目标在何种上下文下评估**" 从工程细节提升为显式的 *context-validity principle*，并给出可操作的实现（context-separated forward）。
- **闭环自适应调度**：$w_{\text{anchor}}=1-\mathrm{sim}(\hat{y},y^\*)$ 完全由当前策略行为决定，无需人工切换点或预设 schedule，避免了 SFT→OPSD 流水线的不连续性。
- **实现轻量**：仅需一次额外 student 前向（30–40% 额外开销），无须单独的保留数据集、无须路由或冻结机制、无须 SFT 预热阶段。
- **实验证据链完整**：从 RQ1–RQ3 的诊断到主表、消融、跨尺度、度量敏感性、训练动力学，多角度交叉支撑结论。
- **可解释的 $\alpha$ 旋钮**：在 plasticity–stability 平面上提供可读的工程调控接口。

## 8. 不足与局限

- **模型族单一**：所有实验均限于 Qwen3 家族（1.7B/4B/8B），未在 Llama、DeepSeek 等其他开源模型或更大规模上验证，跨架构泛化性未知。
- **任务覆盖面有限**：仅 ToolAlpaca 与 SimpleMath 两类任务，且 SimpleMath 为受控算术任务，未覆盖开放对话、代码、长文档推理等更复杂的输出结构。
- **腐败代理的简化性**：受控随机 token 替换与真实学生错误（结构化、历史依赖）存在差距，作者自身亦承认 controlled corruption 不能完全复现自然 rollout 的错误模式。
- **算力信息不充分**：未给出总 GPU 时长、节点数或能耗；仅给出每步相对开销的定性估计。
- **依赖特权信号**：与所有 OPSD 方法一样，SDS 仍需要"已验证答案/轨迹"作为特权上下文，实际部署中可能受限于此类监督的可获得性。
- **$\alpha$ 与相似度度量仍为超参**：$\alpha=0.2$ 与 Token F1 默认值基于 Qwen3-4B SimpleMath 的经验选择，未证明在新任务/新模型上的迁移稳健性虽附录 C 显示分级度量间差异有限，但 $\alpha$ 仍是任务相关旋钮。
- **评测协议差异**：SimpleMath 使用 1,000 子集的 greedy decoding，AIME/MATH 用 $n=8$ 采样，与多数相关工作（多数采用 $n=64$）不完全可比；标准差未在主表展示。
- **格式率与能力保留**：SDS 在 1.7B 上保留的 AIME 能力（Pass@8 56.7%）仍低于纯 OPSD（66.7%），说明 SDS 的 "中间地带" 在小模型上更偏向任务侧，通用能力的极端保留并非首要目标。
