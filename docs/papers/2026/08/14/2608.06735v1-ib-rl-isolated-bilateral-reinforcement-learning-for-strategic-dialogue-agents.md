## 摘要
强化学习（RL）在改进大语言模型（LLMs）以完成具有静态、可验证奖励的任务方面取得了显著成果，例如数学推理和代码执行。在这些场景中，环境遵循固定规则，不会策略性地适应智能体。战略对话在这方面有所不同：环境是另一个会适应策略的智能体，成功取决于双方之间的交互。尽管具有这种交互特性，现有的强化学习方法通常针对固定的对话方或模拟器来训练目标智能体。我们发现，这种训练范式会鼓励策略去利用对话方特有的规律性，而非学习跨对话方泛化的策略。我们将此问题称为静态对话方不匹配（static-counterpart mismatch），并在实验中对其进行了直接量化。为解决这一问题，我们提出了隔离式双边强化学习（Isolated Bilateral Reinforcement Learning, IB-RL），其中两个角色通过联合推演共同进化，同时每个角色通过完全独立的优势函数、动作掩码和更新路径来优化自身奖励。我们在两个领域中使用冻结策略对完全独立的保留对话方进行了评估。在Vehicle TeleSales任务上，IB-RL实现了89.6%的Success@1，而最佳单边强化学习基线为84.6%。在Deal-or-NoDeal任务上，对抗DeepSeek V4 Pro时其达成了98.4%的协议率，而最佳单边基线为86.4%。这些结果表明，对两个角色进行联合训练并保持严格的逐智能体隔离，能够产生对未见对话方更有效泛化的策略。

## Abstract
Reinforcement learning (RL) has achieved strong results in improving large language models (LLMs) on tasks with stationary, verifiable rewards, such as mathematical reasoning and code execution. In these settings, the environment follows fixed rules and does not adapt strategically to the agent. Strategic dialogue differs in this respect: the environment is another agent that adapts to the policy, and success depends on the interaction between the two sides. Despite this interactive nature, current RL approaches typically train a target agent against a fixed counterpart or simulator. We find that this training paradigm encourages the policy to exploit counterpart-specific regularities rather than learn strategies that generalize across counterparts. We call this problem the static-counterpart mismatch, which we quantify directly in our experiments. To address it, we propose Isolated Bilateral Reinforcement Learning (IB-RL), in which the two roles coevolve through joint rollouts while each role optimizes its own reward through fully independent advantages, action masks, and update paths. We evaluate frozen policies against fully independent held-out counterparts in both domains. On Vehicle TeleSales, IB-RL achieves 89.6% Success@1, compared to 84.6% for the best unilateral RL baseline. On Deal-or-NoDeal, it reaches 98.4% agreement against DeepSeek V4 Pro, compared to 86.4% for the best unilateral baseline. These results indicate that jointly training both roles with strict peragent isolation produces policies that generalize more effectively to unseen counterparts.

**核心问题 —— 静态对话方不匹配（Static-Counterpart Mismatch）**：当前主流做法是**单边 RL**——固定目标对话方或模拟器来训练目标策略。由于对话方不变，策略倾向于**过拟合该特定对话方的行为规律**（exploit counterpart-specific regularities），而无法学到可跨对话方迁移的能力。其形式化定义为：

$$J_{\text{train}}(\pi_{\theta_1}) = \mathbb{E}_{\tau \sim (\pi_{\theta_1}, \pi_{\theta_2})}[R_1(\tau)]$$

$$J_{\text{deploy}}(\pi_{\theta_1}) = \mathbb{E}_{\pi'_{\theta_2} \sim \Pi_{\text{deploy}}}\big[\mathbb{E}_{\tau \sim (\pi_{\theta_1}, \pi'_{\theta_2})}[R_1(\tau)]\big]$$

$$\Delta_{\text{mismatch}} = J_{\text{train}}(\pi_{\theta_1}) - J_{\text{deploy}}(\pi_{\theta_1})$$

## 2. 方法论：Isolated Bilateral RL (IB-RL)

**核心思想**：让两个角色在**联合 rollout 中协同进化（co-evolution）**，但**严格隔离**两者的奖励信号、优势估计、动作掩码与优化器状态。

### 2.1 关键技术细节

**1) 共享轨迹，解耦梯度（Shared Trajectories, Decoupled Gradients）**

- 对每个场景 $q$ 与角色 $i$，构造自己的组 $G_{i,q}$。
- 角色 $i$ 的轨迹级优势仅在该角色自身组内归一化：

$$\hat{A}^{(i)}_g = \frac{R_i(\tau_g) - \mu_{i,q}}{\sigma_{i,q}}, \quad \mu_{i,q} = \frac{1}{|G_{i,q}|}\sum_{\tau \in G_{i,q}} R_i(\tau)$$

- 每个角色使用各自的 GRPO 目标，并通过 turn-level mask $m_i(w) \in \{0, 1\}$ 只更新自己产生的 token：

$$J_i(\theta_i) = \mathbb{E}_{\tau_g}\!\left[\sum_{w \in \tau_g} m_i(w)\,\min\!\Big(\rho_i(w)\hat{A}^{(i)}_g,\;\mathrm{clip}(\rho_i(w), 1-\epsilon, 1+\epsilon)\,\hat{A}^{(i)}_g\Big) - \beta\,\mathrm{D}_{\mathrm{KL}}(\pi_{\theta_i}\,\|\,\pi^{\text{ref}}_{\theta_i})\right]$$

其中 $\rho_i(w) = \pi_{\theta_i}(w \mid w_{1:k-1}) / \pi^{\text{old}}_{\theta_i}(w \mid w_{1:k-1})$。

**2) 协同进化的稳定化（Stabilizing Co-Evolution）**

- **对手池采样（Opponent-pool sampling）**：每个角色维护最多 $K$ 个历史 checkpoint 池 $P_i$，按概率 $p_{\text{both}}, p_{\text{agent1}}, p_{\text{agent2}}$ 采样配置 $(\pi^{\text{opp}}_1, \pi^{\text{opp}}_2)$，避免双方都永远面对最新版对手。
- **解耦角色更新调度（Decoupled role-update scheduling）**：以二元指示变量 $u_i^{(k)} \in \{0, 1\}$ 控制更新频率/学习率差异，避免双方同时大步更新导致训练崩溃。

**3) 算法伪代码（附录 B）**：标准 GRPO 双角色版本，每个迭代包含轨迹采样、per-agent 奖励与优势、独立 Adam 更新、以及 checkpoint 写入对手池。

## 3. 实验设计

### 3.1 数据集与场景

| 任务 | 数据来源 | 规模 |
|---|---|---|
| **Vehicle TeleSales**（主域） | 真实中文外呼通话经同意与脱敏 | SFT ~50K；RL 训练 3,000 模拟客户档案（28 维） |
| **Deal-or-No-Deal (DoND)** | Lewis et al. 2017 经典谈判基准 | train split；评测 1,000 个 test 场景 |

### 3.2 奖励设计

- **TeleSales**：DeepSeek V4 Pro 作为裁判，融合折扣回合分（$\lambda_{\text{turn}}=0.2$）与回合级结果（$\lambda_{\text{episode}}=0.8,\ \gamma=0.9$）。销售方偏结果，用户方偏"行为真实性 + 决策合理性"，**双方奖励目标不对齐**。
- **DoND**：纯规则化奖励——达成协议则获各自私有效用，否则零，并含无效动作惩罚，无需 LLM 评判。

### 3.3 评估协议（核心亮点）

- **保留对话方评估（held-out counterparts）**：使用与训练系统**无任何共享参数、提示或奖励逻辑**的对话方。
  - TeleSales：GPT-5.5 充当客户，配 40 维评测档案；GLM-5.2 审计动作标签；额外有 GPT-5.5 评判幻觉 + 人工盲评验证语义有效性。
  - DoND：保留对话方为 GLM-5.2 与 DeepSeek V4 Pro。
- 统计检验：二分类结果使用 logistic GEE（profile/scenario 聚类，robust SE），Holm 校正，$p<0.05$。

### 3.4 对比方法

- **单边 RL 基线**：分别以 Qwen-3.5-SFT、DeepSeek V4 Pro、Qwen-3.5-9B-SFT、3 个前沿模型池（pool-of-3）作为固定对话方训练。
- **基础模型基线**：Qwen-3.5-122B、GLM-5.2、DeepSeek V4 Pro（纯提示工程，未做 RL）。
- **前沿模型对比**：在两个任务上直接对照上述最强基线。

### 5.1 实验规模

| 类别 | 数量/规模 |
|---|---|
| 主任务 | 2 个（TeleSales + DoND） |
| 模型规模 | 2 个（4B + 9B） |
| 评估设置 | TeleSales 500 档案 × 3 次独立对话；DoND 1000 场景 |
| 统计检验 | logistic GEE + Holm 校正 |
| 消融 | 共享奖励 / 联合归一化 / 移除稳定化（对手池+错峰更新） |
| 对比基线 | 单边 RL 4 种 + 池化单边 1 种 + 前沿模型 3 种 |

### 5.2 充分性评估

- **优点**：消融分别隔离了"奖励共享"、"优势归一化"、"稳定化机制"的独立影响；DoND 上既测保留对话方又测自博弈，能直接量化 mismatch；200 段双人盲评支持了评测指标语义有效性（标注员一致率 88.0%，κ=0.76；与模拟器一致率 92.0%，κ=0.84）。
- **不足**：消融中"对手池"和"错峰更新"是**联合去除**的，因算力原因无法单独剥离；评测对手集合仍较小；不同规模、不同任务下的趋势虽一致但样本量不算大。

## 6. 主要结论与发现

1. **单边策略存在明显静态对话方不匹配**；IB-RL 大幅缩小该差距。
   - TeleSales：IB-RL 89.6% Success@1 vs. 最佳单边 84.6%（$p<0.05$）；Success@2 63.2% vs. 54.4%；Success@3 23.8% vs. 19.6%。
   - DoND：单边对训练对话方 86.4–89.7%，自博弈跌至 46.2–56.3%；IB-RL 对保留对话方 94.8–98.4%，自博弈 70.6–71.9%（均值 71.3%）。
2. **跨模型规模均显著**：9B IB-RL 在 GLM-5.2 上 92.9–94.8% vs. 最佳单边 88.4%（Holm 校正后 $p<0.01$）；4B IB-RL 平均 62.3% vs. 最佳单边 43.1%。
3. **闭源基线已被超越**：9B IB-RL 在 TeleSales 上超过 GLM-5.2（85.4%）、DeepSeek V4 Pro（83.6%）、Qwen-3.5-122B（71.8%）；DoND 上对保留 GLM-5.2 平均 93.9%，逼近 GLM-5.2 自博弈（95.2%）。
4. **隔离机制是必要的**：移除"每智能体奖励"导致策略出现合谋惯例（Succ@1 38.0%，幻觉 23.9%）；移除"逐角色优势归一化"则因基线/标准差混合而破坏更新信号（Succ@1 78.8%）。
5. **稳定化机制是必要的**：去掉对手池+错峰更新后，销售奖励在 ~25 轮后单调衰退至模板化重复行为（39 轮即终止）。
6. **池化并不替代协同进化**：在 3 个静态前沿模型池（DeepSeek V4 Pro + GLM-5.2 + Qwen-3.5-122B）上训练的单边 RL 反而跌至 64.2%，低于最弱同规模单边基线（78.8%），说明**单纯增加对手多样性而无协同进化压力并不奏效**。
7. **协同进化的两种效应并存**：
   - **配对特异协同适应**：DoND 上交叉配对自博弈高达 97.4%，体现对训练搭档的过拟合残余；
   - **可迁移能力**：对保留对话方仍保持 92.9–98.4%，说明真正学到的是泛化能力而非单纯合谋。
8. **对手语义多样性收敛**：用户策略跨 checkpoint 余弦相似度早期 ≈0.74 → 晚期 ≈0.86，说明探索了多种行为模式后稳定于一个"行为流形"，并未退化为重复模板。

## 7. 优点

- **问题刻画严谨**：用协方差分解给出 mismatch 的理论刻画（命题 A.1），明确指出单边 RL 的失败机理。
- **方法简洁、可扩展**：直接在 GRPO 之上做 per-role 隔离，无需中心化 critic；基础设施层面只动 rollout/训练层，不破坏 GRPO 的 critic-free 形式。
- **评测协议科学**：使用保留对话方 + 模拟动作标签审计 + LLM 审计 + 人工盲评四层证据链，避免了"用训练对话方自评"的循环论证。
- **统计严谨**：logistic GEE + Holm 校正，避免多基线比较的 I 类错误膨胀。
- **诊断丰富**：奖励轨迹、对手语义相似度矩阵、in-system vs. held-out 分歧曲线共同支撑"协同进化 vs. 静态过拟合"的对比。
- **跨任务、跨规模**：在两个性质差异显著的领域（销售/谈判，不对称/对称奖励）和两个模型规模上同时验证。

---

## 8. 不足与局限

- **保留对话方覆盖有限**：DoND 上主要只测 GLM-5.2 与 DeepSeek V4 Pro 两个保留方，论文本身也承认更广泛的对话方池才能加强泛化结论。
- **仅两角色/两任务/单算法**：目前只验证了两个角色、GRPO 一种策略梯度变体；多角色、其他 PPO 系算法、人在回路评估未涉及。
- **LLM 评判偏差风险**：TeleSales 使用 DeepSeek V4 Pro 作为训练奖励裁判，存在已知的 judge bias（Chen et al. 2024a）。人工审计只验证了"加 WeChat 行为"的语义有效性，**未评估裁判整体偏差**。
- **协同进化稳定性代价高**：消融中"对手池"与"错峰更新"是联合去除的，因算力原因无法独立拆解，削弱了对各组件单独贡献的归因。
- **池化基线反直觉结果**：pool-of-3 单边 RL 反而比单一对话方单边 RL 更差，作者用"梯度干扰"解释，但未做更深入归因；这一现象的普适性待进一步验证。
- **数据/合规限制**：TeleSales 使用真实外呼数据，即使经过脱敏与同意流程，仍可能存在场景偏差（如行业、地域、车型）影响外部可复现性。
- **可复现性约束**：依赖 DeepSeek V4 Pro / GLM-5.2 / GPT-5.5 等外部模型作为对话方与裁判，第三方独立复现存在接口与成本门槛。
- **未提供算力细节**：GPU 型号、训练总时长、累计 GPU-hours 均未在主文中披露，难以横向对比训练成本。
