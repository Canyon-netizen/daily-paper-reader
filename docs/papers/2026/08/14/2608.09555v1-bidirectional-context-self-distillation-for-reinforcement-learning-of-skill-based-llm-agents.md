## 摘要
外部自然语言技能为大型语言模型（LLM）智能体提供了可复用且可编辑的指导，以解决复杂任务。然而，其有效性不仅取决于技能的质量，还取决于策略能否将所提供的指导转化为恰当的动作。然而，专门用于提升这种技能利用能力的方法在很大程度上仍未得到充分探索。在实践中，基于技能的智能体通常使用以任务级奖励为中心的强化学习目标进行训练，这种目标所提供的监督有限，且难以捕捉策略在利用所提供技能方面的细微差异。我们提出了BCSD（Bidirectional Context Self-Distillation，双向上下文自蒸馏），这是一个将自蒸馏与强化学习相结合的训练框架，旨在训练LLM智能体更有效地使用外部技能。与依赖单一特权上下文的现有自蒸馏方法不同，BCSD从两种互补的技能上下文视角评估每条轨迹。其中，增强视图引入更高层次的元技能（Meta-Skill）指导，而简化视图则裁剪一般性指导以突出任务特定的技能。这两种视图的互补的token级信号被结合用于重新缩放强化学习优势函数。在ALFWorld和WebShop上的实验表明，BCSD在不同模型规模下均取得了最强的整体性能，使智能体能够更有效地利用外部技能。消融研究进一步验证了增强视图与简化上下文视图的互补性贡献。代码将发布以确保完全可复现性。

## Abstract
External natural-language skills provide large language model (LLM) agents with reusable and editable guidance for solving complex tasks. Yet their effectiveness depends not only on skill quality, but also on whether the policy can translate the provided guidance into appropriate actions. However, methods specifically designed to improve this skill-utilization ability remain largely underexplored. In practice, skill-based agents are commonly trained with reinforcement learning objectives centered on task-level rewards, which offer limited supervision and struggle to capture subtle differences in how effectively the policy uses the provided skills. We propose BCSD (Bidirectional Context Self-Distillation), a framework that combines self-distillation with reinforcement learning to train LLM agents to use external skills more effectively. Unlike prior self-distillation methods that rely on a single privileged context, BCSD evaluates each trajectory from two complementary skill-context views. The augmented view introduces higher-level Meta-Skill guidance, while the reduced view prunes general guidance to highlight task-specific skills. Their complementary token-level signals are combined to rescale the RL advantage. Experiments on ALFWorld and WebShop demonstrate that BCSD achieves the strongest overall performance across model scales, enabling agents to utilize external skills more effectively. Ablation studies further verify the complementary contributions of the augmented and reduced context views. Code will be released to ensure full reproducibility.

- **技能内化**：将技能蒸馏进模型参数，牺牲了技能的可检查性、可编辑性和可迁移性。

作者指出，即便提供了高质量的技能，策略也未必能将其转化为恰当动作（这是**技能利用能力**问题）。现有方法多采用以任务级（稀疏）奖励为中心的强化学习（如 GRPO），其监督粒度过粗，难以刻画"哪个 token 的生成体现了技能利用"。基于单特权上下文的在线策略自蒸馏（OPSD）虽能给出 token 级信号，但单一上下文引起的分布偏移、信息泄露等问题导致其监督不稳定、不可靠。因此本文聚焦一个被低估的问题：**如何训练 LLM 智能体在保留显式外部技能的前提下，提升其"使用技能"的能力？**

## 2. 方法论：BCSD 框架

### 2.1 整体思想

BCSD（Bidirectional Context Self-Distillation）将自蒸馏与 GRPO 风格强化学习结合，核心是把"单一特权上下文教师"扩展为**两个互补的上下文视角**：
- **增强视图 $C_1$**：在基础技能上下文 $C_0=(Q, G, S_c)$ 上加入高层 **Meta-Skill** $M_c$（由成功/失败轨迹提炼而来），提供"应该如何使用技能"的高层指导；
- **精简视图 $C_2$**：用外部 LLM 将通用技能 $G$ 剪枝为 $G_p$，保留任务特定技能 $S_c$ 不变，从而"去除冗余、聚焦任务"。

同一策略在 $C_0, C_1, C_2$ 三种上下文下对同一回复重新打分，得到两个 token 级对数概率差 $\Delta^{aug}, \Delta^{pru}$，二者加权融合后用于**重新缩放**（不替换）GRPO 优势。

### 2.2 关键公式

基础上下文：$$C_0 = (Q, G, S_c)$$

增强 / 精简上下文：$$C_1 = (Q, G, S_c, M_c), \qquad C_2 = (Q, G_p, S_c)$$

GRPO 群相对优势：$$A_i^{GRPO} = \frac{r_i - \mu_r}{\sigma_r + \epsilon}$$

两个 token 级 gap：$$\Delta^{aug}_{i,t} = \log \pi_\theta(y_{i,t}\mid C_1, y_{i,<t}) - \log \pi_\theta(y_{i,t}\mid C_0, y_{i,<t})$$

$$\Delta^{pru}_{i,t} = \log \pi_\theta(y_{i,t}\mid C_2, y_{i,<t}) - \log \pi_\theta(y_{i,t}\mid C_0, y_{i,<t})$$

加权融合：$$\Delta_{i,t} = \alpha \Delta^{aug}_{i,t} + (1-\alpha)\Delta^{pru}_{i,t}$$

Gap-weighted 优势重缩放（仅改变幅度，不改变方向）：$$w_{i,t} = \mathrm{clip}\!\left(\exp(\mathrm{sign}(A_i^{GRPO})\Delta_{i,t}),\,1-c,\,1+c\right)$$

$$A^{BCSD}_{i,t} = A_i^{GRPO}\big[(1-\lambda_n)+\lambda_n w_{i,t}\big]$$

其中 $\lambda_n$ 由 $\lambda_0$ 线性衰减至 0，作为"训练早期自蒸馏脚手架、后期交还环境奖励"的调度机制。

最终优化目标（带 KL 正则与 PPO 裁剪）：$$L_{BCSD}(\theta) = -\mathbb{E}_{i,t}\Big[\min\!\big(\rho_{i,t}A^{BCSD}_{i,t},\,\mathrm{clip}(\rho_{i,t},1-\epsilon,1+\epsilon)A^{BCSD}_{i,t}\big)\Big] + \beta L_{KL}$$

其中 $\rho_{i,t}(\theta) = \pi_\theta(y_{i,t}\mid C_0, y_{i,<t}) / \pi_{\theta_{old}}(y_{i,t}\mid C_0, y_{i,<t})$。

### 2.3 Meta-Skill 提取与刷新

- 初始化：用冻结的外部 LLM 对比每个任务类型 $c$ 的成功 / 失败证据集 $E^{(0)}_{c,+}, E^{(0)}_{c,-}$，生成初始 Meta-Skill $M^{(0)}_c$；
- 刷新：每经过 $N$ 步验证窗口，结合新证据定期更新 $M^{(k+1)}_c$，以跟踪策略演化的技能利用模式。Meta-Skill **仅在训练时作为教师特权上下文出现**，不进入学生上下文 $C_0$，亦不参与推理。

### 2.4 算法流程

1. 预训练前构造 $G_p$、初始化 $\{M_c^{(0)}\}$；
2. 在基础上下文 $C_0$ 下采样 $K$ 条轨迹，计算群相对优势 $A^{GRPO}_i$；
3. 在 $C_0, C_1, C_2$ 下重打分，计算 $\Delta_{i,t}$、$w_{i,t}$、$A^{BCSD}_{i,t}$；
4. 按 $L_{BCSD}$ 更新参数；
5. 每 $N$ 步用新证据刷新 Meta-Skill 并重置证据缓存。

1. **主性能**：BCSD 在 3 个模型规模上的 ALFWorld 与 WebShop 综合指标均取得最强或并列最强，例如 Qwen2.5-3B 上较最强基线 ALFWorld +5.4、WebShop 得分 +4.4 / 成功率 +9.4；

3. **Meta-Skill 刷新与 $\lambda_n$ 衰减均必要**：固定 Meta-Skill 或保留恒定 $\lambda_n$ 均会下降，尤其 WebShop；
4. **双视图并不冗余**：二者 token 级符号一致率长期维持在 47%~53%，说明它们提供差异化信号，加权融合后形成更保守的监督；
5. **技能是被"利用"而非"内化"**：移除 $S_c$ 后 BCSD 的性能下降幅度大于 Skill_GRPO\*（ALFWorld -2.3 vs -0.8，WebShop -7.8 vs -6.2），说明增益更多来自使用外部技能，而非记忆任务知识；
6. **训练动态更稳定**：BCSD 在第 60 步已显著领先基线，且全程无明显回撤。

## 7. 优点

- **视角新颖**：将"特权教师"从单一上下文扩展到增强/精简两个互补上下文，提供更可靠的 token 级监督；
- **方向保留设计**：$w_{i,t}$ 经 $\mathrm{sign}(A^{GRPO})$ 修饰后再乘回优势，**只缩放幅度、不翻转方向**，避免教师信号破坏策略梯度；
- **保留技能的可编辑性与可迁移性**：区别于 Skill-SD / SIRI / OPID 等内化路线，符合实际部署对显式技能的需求；
- **早期自蒸馏脚手架 + 后期奖励主导**的 $\lambda_n$ 衰减设计，兼顾冷启动监督与渐近最优；
- **实验维度较完整**：3 模型 × 2 基准 × 6 子任务 + 消融 + 超参 + 训练动态 + 利用归因，多角度论证；
- **算法完整可复现**：算法 1 给出了端到端伪代码，并承诺开源代码。

## 8. 不足与局限

- **算力与训练成本未披露**：读者难以评估 BCSD 三视图打分带来的额外开销是否值得其性能增益；
- **基准覆盖有限**：仅 ALFWorld 与 WebShop 两个文本环境，未在更复杂、多工具或多模态场景（如真实网页、操作系统、机器人）验证；
- **依赖外部 LLM**：Meta-Skill 提取与 $G_p$ 剪枝均依赖冻结外部 LLM，引入额外成本与稳定性风险，且其能力上界限制了 Meta-Skill 质量；
- **Meta-Skill 隐私 / 安全**：高层策略摘要可能被对抗性构造以引导智能体做出不当行为；
- **公平性争议**：所有基线在作者统一 SkillBank 设定下重跑，超参与实现细节可能未对基线最优调参，存在一定"自家框架偏向"风险；
- **对长程与稀疏奖励场景的鲁棒性**：训练仅 150 步、每步 8 条 rollout，是否能稳定扩展到极长程任务仍未知；
- **缺乏失败案例分析**：未系统讨论 BCSD 在何种类型任务上仍会失败，对局限性的认识不够充分；
- **生成式 / 创造性任务不适用**：技能高度依赖任务特定性，难以推广到开放域对话或创造性写作场景。
