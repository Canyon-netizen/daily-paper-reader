## 摘要
同策略自蒸馏（OPSD）将反馈转化为针对待优化策略所生成轨迹的稠密 token 级监督，为稀疏结果奖励的强化学习提供了有益的补充。然而，OPSD 中使用的自教师策略通常是策略在额外上下文信息条件下的停止梯度或指数移动平均副本，因此它会随学生策略及其同策略上下文分布共同演化。直接以固定的投影目标去匹配这样一个动态变化的目标，可能导致优化不稳定或分布过度集中。OPSD 的这一特性激发了本文所提出的自参考同策略自蒸馏（SR-OPSD）。在固定的学生生成上下文上，token 级的变分刻画表明有效的蒸馏目标是自教师策略与参考策略之间的几何插值。与此同时，我们使用 Rényi 散度族来推广投影几何结构。该公式将自适应目标的位置与学生向其投影的方式分离开来：插值系数控制底层目标，而 Rényi 阶数控制投影几何及其对 token 级密度比的敏感性。在科学评估、数学推理和代码生成任务中，针对多个大语言模型开展的大量实验表明，SR-OPSD 在各种设置下均能达到当前最优或具有竞争力的性能。

## Abstract
On-policy self-distillation (OPSD) converts feedback into dense token-level supervision on trajectories generated by the policy to be optimized, providing a useful complement to reinforcement learning with sparse outcome rewards. However, the self-teacher policy used in OPSD is typically a stop-gradient or exponential-moving-average copy of the policy conditioned on additional context information, and thus co-evolves with both the student policy and its on-policy context distribution. Directly matching such a moving target with a fixed projection objective can lead to unstable optimization or excessive distributional concentration. This nature of OPSD motivates the proposed \emph{Self-Referenced On-Policy Self-Distillation (SR-OPSD)}. At fixed student-generated contexts, a token-level variational characterization identifies the effective distillation target as a geometric interpolation between the self-teacher policy and a reference policy. Meanwhile, we use the Rényi divergence family to generalize the projection geometry. This formulation separates \emph{where} the adaptive target is placed from \emph{how} the student is projected toward it: the interpolation coefficient controls underlying target, while the Rényi order controls the projection geometry and its sensitivity to token-level density ratios. Extensive experiments across scientific evaluation, mathematical reasoning, and coding generation tasks with multiple large language models show that SR-OPSD achieves the state-of-the-art or competitive performance across various settings.

# SR-OPSD 论文总结

## 1. 核心问题与研究动机

**背景**：大语言模型的后训练涵盖指令微调、偏好优化与强化学习（RLHF/RLVR）。RLVR（如 GRPO）虽然能利用可验证奖励自动评估结果正确性，但仅在整条响应上赋予一个标量奖励，存在**长序列上的稀疏信用分配**问题——无法定位成功或失败究竟源于哪个中间 token 或推理步骤。

**同策略自蒸馏（OPSD）的提出**：为提供稠密的 token 级监督，OPSD 使用一个"自教师"策略 $\bar{\pi}_\theta$——即对当前策略的停止梯度（stop-gradient）或指数移动平均（EMA）副本，并在额外上下文 $h^{sf}$（如真实答案、环境反馈、反思内容、成功兄弟响应等"特权信息"）条件下进行评估。这样，OPSD 可将反馈转化为稠密 token 级监督。

**核心痛点**：在 OPSD 中，**自教师策略与学生策略及其同策略上下文分布共同演化**，三者同时变化并相互耦合。若仍以固定投影（如前向/反向 KL）去匹配一个动态目标，会引发：
- 优化不稳定；
- 分布过度集中（如反向 KL 的 mode-seeking 倾向会放大已有偏差）；
- 前向 KL 在学生采样 token 上存在 action-level 期望失配；
- 在长训练预算下出现早峰后衰减现象。

**本文立场**：现有方法（EMA 教师、对称散度、熵感知切换、正则化）只部分缓解问题。作者主张必须**分离两件事**——"自适应目标放在何处"与"学生如何向其投影"。

## 2. 方法论

### 2.1 核心思想

SR-OPSD 提出两个正交的控制维度：
- **目标位置**：通过插值系数 $\alpha\in[0,1]$ 在自教师与参考策略 $\pi_{ref}$ 之间做**几何插值**；
- **投影方式**：通过 Rényi 阶数 $\rho>0,\rho\neq 1$ 控制**投影几何**与对密度比的灵敏度。

### 2.2 关键公式

**Rényi 散度**（用于推广 KL 投影几何）：
$$D_\rho(p\|q) = \frac{1}{\rho-1}\log\sum_{a\in V} p(a)^{\rho}\,q(a)^{1-\rho}$$

**自教师更新**（EMA）：
$$\bar{\theta}_{k+1} = \beta\bar{\theta}_k + (1-\beta)\theta_{k+1}$$

**参考锚定的几何插值目标**（核心公式）：
$$\pi^\star_\alpha(a\mid h^{sf}, h^{ref}) = \frac{sg[\bar{\pi}_\theta(a\mid h^{sf})]^{\alpha}\;\pi_{ref}(a\mid h^{ref})^{1-\alpha}}{Z_\alpha(h^{sf}, h^{ref})}$$
其中 $Z_\alpha(h^{sf}, h^{ref}) = \sum_{a\in V} sg[\bar{\pi}_\theta(a\mid h^{sf})]^{\alpha}\pi_{ref}(a\mid h^{ref})^{1-\alpha}$。自然选择 $\pi_{ref} := sg[\pi_{\theta_0}]$，即优化前的冻结初始策略。

**两个理论刻画（命题 3.1、3.2）**：在固定上下文下，证明最大化变分目标等价于最小化
$$D_\rho\!\left(\pi^\star_\alpha(\cdot\mid h^{sf}, h^{ref}) \;\|\; \pi_\theta(\cdot\mid h)\right)$$
即从**插值目标到学生**的前向 Rényi 投影。

**Logit 梯度（命题 3.3）**：
$$\frac{\partial}{\partial z_\theta(a\mid h)} D_\rho\!\left(\pi^\star_\alpha \;\|\; \pi_\theta\right) = \pi_\theta(a\mid h) - \tilde{\pi}_{\alpha,\rho,\theta}(a\mid h, h^{sf}, h^{ref})$$
其中
$$\tilde{\pi}_{\alpha,\rho,\theta} \propto \pi_\theta(a\mid h)\left(\frac{\pi^\star_\alpha(a)}{\pi_\theta(a\mid h)}\right)^\rho$$
揭示 $\rho$ 对师生密度比进行**幂次温度调节**。

**SR-OPSD 目标函数**（式 (2)）：
$$\max_\theta \mathbb{E}_{x\sim D,\, y\sim \pi_{\theta_{old}}}\left[\sum_{t=1}^{L}\frac{1}{1-\rho}\log\sum_{a\in V}\exp\!\left((1-\rho)\log\pi_\theta(a\mid h_t) + \rho\alpha\log sg[\bar{\pi}_\theta(a\mid h^{sf}_t)] + \rho(1-\alpha)\log\pi_{ref}(a\mid h^{ref}_t)\right)\right]$$

**参数语义**：
- $\alpha=1$：目标退化为自教师；$\alpha=0$：退化为参考策略；
- $\rho\to 1$：投影退化为对应 KL 极限；$0<\rho<1$：幂次温度调节极端密度比。

### 2.3 算法流程（Algorithm 1）

1. 采样 prompt 与学生自生成响应；
2. 为每个 token 构造 $h_t, h^{sf}_t, h^{ref}_t$；
3. 形成冻结目标 $\pi^\star_{\alpha,k}(\cdot\mid h^{sf}_t, h^{ref}_t)$；
4. 用 AdamW 等优化器沿 $-\nabla_\theta\sum_t D_\rho(\pi^\star_{\alpha,k}\|\pi_\theta)$ 更新 $\theta_{k+1}$；
5. 用 EMA 系数 $\beta$ 更新自教师 $\bar\theta_{k+1}\leftarrow\beta\bar\theta_k+(1-\beta)\theta_{k+1}$。

## 7. 优点

- **问题刻画清晰**：明确区分"目标在哪"与"如何投影"，将 OPSD 的不稳定性归因于两者耦合，而非简单归咎于某一散度。
- **理论-实践一致**：给出 token 级变分等价（命题 3.1、3.2）与 logit 梯度（命题 3.3）的完整证明，附录 C 给出逐步推导。
- **两参数解耦**：$\alpha$（目标位置）与 $\rho$（投影几何）功能正交，可独立调优，框架可推广到现有 OPSD 方法。
- **多维度评估**：覆盖科学/数学/代码三类典型反馈形式，参数量从 0.6B 到 8B，公开代码与训练超参（Table 6、7），便于复现。
- **稳定性证据充分**：同时报告 Avg / Maj / Best 与训练曲线，缓解单指标偶然性；熵监控证明未出现分布坍缩。
- **定性补充**：附录 B 的失败模式分析增强了可解释性。

## 8. 不足与局限

- **理论边界**：所有变分刻画建立在"固定上下文 + 冻结目标分量"的**条件等价**，未建立完整"学生—自教师动态演化"下的全局收敛保证；上下文分布漂移仍是未被显式控制的误差源。
- **超参固定**：$\alpha$、$\rho$、$\beta$ 均为手工固定值，缺乏基于教师可靠性或策略漂移的自适应调度机制。
- **小模型表现**：代码生成 0.6B 上 SR-OPSD 略输 GRPO/SDPO，作者明确说明因算力昂贵未调超参，存在调优空间。
- **数学评测限制**：仅报告 200 步单次末值，未提供多随机种子方差或更细粒度学习曲线，统计充分性较弱。
- **资源披露不完整**：未给出 GPU 总数、累计 GPU·hours、数据并行规模等可复现细节，仅提"H200 与 A800"与 verl 框架。
- **评估偏差风险**：Top-K + tail bucket 的候选集近似虽在附录 A 提及通用做法，但未系统化对比其与全词汇目标在极端稀疏 token 上的差异。
- **应用限制**：依赖存在"特权上下文"（真实解、环境反馈、成功兄弟响应）的场景，纯无监督场景不适用；对极小模型（<0.6B）与超大规模（>8B）的可扩展性未验证。
- **方法论盲区**：$\alpha$ 与 $\rho$ 通过乘积 $\alpha\rho$ 在梯度中耦合，意味着两者并非完全独立——作者在命题 3.3 末尾承认这一交互，但未深入量化。
