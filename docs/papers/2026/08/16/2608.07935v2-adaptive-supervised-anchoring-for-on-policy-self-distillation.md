## 摘要
同策略自蒸馏（OPSD）通过从学生模型采样的轨迹中蒸馏冻结教师模型的指导，从而适配语言模型。然而，其效果高度取决于这些轨迹的质量。我们表明，当学生模型的rollout偏离目标轨迹时，使教师模型以偏离目标的上下文前缀为条件，会显著削弱其与任务相关的监督。受控的上下文前缀破坏实验揭示了这一失效模式，我们将其称为rollout条件化信号退化。为解决这一问题，我们提出一个统一的训练框架，将两条互补的监督路径分离。第一条路径保留rollout条件化的分布匹配，为学生模型实际访问的状态提供指导；第二条路径则在规范的真实上下文上应用监督交叉熵，从而避免在错误的rollout前缀上强行施加目标令牌所带来的不兼容性。通过词元级rollout—目标对齐来动态调整规范上下文锚定的强度：在冷启动阶段强化该锚定，并在rollout质量提升后逐步放松。跨越多个模型规模、两类任务以及通用推理基准的实验表明，与OPSD相比，所提出的方法能够改善任务习得，同时保持通用能力，从而实现更有利经验可塑性—稳定性权衡。这些发现表明，上下文质量是同策略自蒸馏中的核心瓶颈，并证明了将rollout条件化指导与规范监督相分离的价值。

## Abstract
On-policy self-distillation (OPSD) adapts a language model by distilling guidance from a frozen teacher on trajectories sampled from the student. Its effectiveness, however, depends critically on the quality of those trajectories. We show that when student rollouts drift from target trajectories, conditioning the teacher on off-target prefixes substantially weakens its task-relevant supervision. Controlled prefix-corruption experiments expose this failure mode, which we term rollout-conditioned signal degradation. To address this problem, we propose a unified training framework that separates two complementary supervision pathways. The first retains rollout-conditioned distribution matching, providing guidance on states the student actually visits. The second applies supervised cross-entropy on canonical ground-truth contexts, avoiding the incompatibility of imposing target tokens on erroneous rollout prefixes. Token-level rollout-target alignment is used to adapt the strength of the canonical-context anchor, emphasizing it during cold start and relaxing it as rollout quality improves. Experiments across multiple model scales, two task families, and general-reasoning benchmarks show that the proposed approach improves task acquisition over OPSD while preserving general capabilities, resulting in a more favorable empirical plasticity-stability trade-off. These findings identify context quality as a central bottleneck in on-policy self-distillation and demonstrate the value of separating rollout-conditioned guidance from canonical supervision.

## 1. 核心问题与研究动机

- **背景**：同策略自蒸馏（OPSD）采用"师生共享同基座模型"的设计，冻结教师凭借特权上下文（如标准解题过程 $y^*$）对学生自行采样的轨迹进行稠密 token 级监督，相比传统同策略蒸馏（OPD）无需额外白盒教师，因而成为后训练阶段习得新任务、同时减少预训练能力损失的常用方案。
- **隐含假设**：OPSD 假定教师即便在学生生成的偏轨前缀上评估，仍能保持目标对齐的 next-token 指导能力。
- **暴露的失败模式**：当任务范式/输出结构在预训练中表征薄弱时，学生容易在冷启动阶段进入偏离规范解的前缀上下文，此时即使教师知道标准答案，其条件分布也不再聚焦于目标 token，作者将这一现象命名为 **rollout-conditioned signal degradation（滚动条件化信号退化）**。
- **直接证据**：在 Qwen3-1.7B / 4B 上，对 200 道 SimpleMath 题：在标准前缀下教师目标 token 准确率分别为 78.0% / 80.4%，而换到学生冷启动 rollout 前缀后骤降至 3.0% / 6.5%，信号保留比 $\rho(\hat{y}) = \mathrm{Acc}_T(\hat{y})/\mathrm{Acc}_T(y^*)$ 仅 3.8%–8.1%。
- **症结**：监督信号在何处计算比施加多少监督更关键，OPSD 存在"滚动条件分布匹配要求学生前缀以保持 on-policy 状态覆盖"与"ground-truth 监督要求标准前缀以保持目标有效性"之间的根本张力，作者将其概括为 **监督—上下文不兼容性（supervision–context incompatibility）**。

## 2. 方法论

### 2.1 核心思想

提出 **监督蒸馏引导（Supervised Distillation Steering, SDS）**：在计算图层面**严格分离**两条监督通路——
1. **滚动条件化蒸馏通路**：在学生 rollout 前缀 $\hat{y}_{<t}$ 上对齐教师 $p_T(\cdot \mid x^{PI},\hat{y}_{<t})$ 与学生 $p_S(\cdot \mid x,\hat{y}_{<t})$；
2. **标准上下文锚定通路**：在 ground-truth 前缀 $y^*_{<t}$ 上独立做 teacher-forcing 交叉熵，使目标 token 在其语义有效上下文中被评估。

两条通路共享同一组可训练参数 $\Delta\theta$，仅在 forward pass 时通过不同前缀强制隔离。

### 2.2 关键公式

- **OPSD 基线目标**：

$$L_{\text{OPSD}} = \frac{1}{|\hat{y}|}\sum_{t=1}^{|\hat{y}|} D\big(p_T(\cdot\mid x^{PI},\hat{y}_{<t})\;\Vert\;p_S(\cdot\mid x,\hat{y}_{<t})\big)$$

- **直接拼接 ground-truth 交叉熵的"朴素"方案及其问题**：

$$L_{\text{naive CE}} = -\frac{1}{|y^*|}\sum_{t=1}^{|y^*|}\log p_S(y^*_t \mid x,\hat{y}_{<t})$$

该式在学生已偏离的前缀上评估 $y^*_t$，造成 **target–context mismatch**。

- **SDS 锚定分支（标准上下文交叉熵）**：

$$L_{\text{anchor}} = -\frac{1}{|y^*|}\sum_{t=1}^{|y^*|}\log p_S(y^*_t \mid x, y^*_{<t})$$

- **自适应锚定权重**：

$$w_{\text{anchor}} = 1 - \mathrm{sim}(\hat{y}, y^*)$$

其中 $\mathrm{sim}(\hat{y},y^*)$ 为轻量级 token 级序列相似度（梯度化指标均可，作者默认实现及消融置于附录）。

- **SDS 完整目标**：

$$L_{\text{SDS}} = \frac{1}{|\hat{y}|}\sum_{t=1}^{|\hat{y}|} D\!\left(p_T(\cdot\mid x^{PI},\hat{y}_{<t})\;\Vert\;p_S(\cdot\mid x,\hat{y}_{<t})\right) + \alpha\, w_{\text{anchor}}\!\left(-\frac{1}{|y^*|}\sum_{t=1}^{|y^*|}\log p_S(y^*_t \mid x, y^*_{<t})\right)$$

- **散度实例**：采用有界 **广义 Jensen–Shannon 散度**：

$$\mathrm{JSD}_\beta(p_T\Vert p_S) = \beta D_{\mathrm{KL}}(p_T\Vert m_\beta) + (1-\beta)D_{\mathrm{KL}}(p_S\Vert m_\beta)$$

其中 $m_\beta = \beta p_T + (1-\beta)p_S$，以避免分布严重不一致时 loss 失控。

### 2.3 算法流程

1. 对训练对 $(x, y^*)\sim\mathcal{D}$，学生用 $p_S$ 在 $x$ 上采样 rollout $\hat{y}$；
2. **滚动蒸馏分支**：用 $\hat{y}$ 作前缀计算教师 $p_T$ 与学生 $p_S$ 的 token 级 f-散度；
3. **锚定分支**：用 $y^*$ 作前缀独立前向传播计算 $L_{\text{anchor}}$（teacher-forcing 交叉熵）；
4. 计算 $w_{\text{anchor}}=1-\mathrm{sim}(\hat{y},y^*)$，对锚定项做自适应缩放；
5. 联合更新共享参数 $\Delta\theta \leftarrow \Delta\theta - \eta\nabla_\theta L_{\text{SDS}}$（教师始终冻结）。

- **上下文质量是 OPSD 的核心瓶颈**：Qwen3-4B 上教师目标 token 准确率随前缀破坏率从 80.4% 单调降至 3.8%；真实 rollout 上，"首次偏差位置 [0.15,0.23)" 的 bin 准确率仅 20.5%，而接近正确的 [0.91,1.0] bin 达 82.7%。
- **上下文隔离是必要条件**：在 OPSD 同一计算图内直接注入 ground-truth CE（Naive OPSD+CE）会使 SimpleMath 跌至 55.20%、AIME Avg@8 跌至 3.33%；仅在标准前缀上评估 ground-truth（SDS）即可恢复至 62.43% / 67.98%。
- **自适应权重是关键**：固定权重 $w=1$ 时任务精度 57.20% 但 AIME 跌至 56.25%；$w=0.5$ 时 AIME 恢复至 72.48% 但任务精度塌缩至 35.40%；只有对齐感知调度能同时兼顾。
- **内生调度优于手动两阶段**：SFT→OPSD 仅得 55.03% / 35.42%，证明硬切换引入不连续性，而 SDS 的闭环负反馈（$w_{\text{anchor}}$ 早强后弱但非零）持续协调两条通路。
- **可塑性—稳定性权衡更优**：Qwen3-4B 上 SDS 在 SimpleMath 取得 **62.43%**（OPSD 仅 23.23%，SFT 为 56.43%），同时保留 **93.2%** 的 base AIME24 Avg@8（SFT 仅 52.6%）与 95.69% 的格式合规率。
- **$\alpha$ 充当可解释旋钮**：$\alpha=0.1$ 偏能力保留（56.73% / 97.7%），$\alpha=0.5$ 偏任务习得（57.13% / 82.8%），$\alpha=0.2$ 给出最佳综合点。

## 7. 优点与亮点

- **问题定位新颖**：首次将 OPSD 失效显式归因于"前缀条件对教师信号的污染"，并通过受控 + 自然双路径诊断实验严谨论证。
- **原则化设计**：将"监督目标应在语义有效上下文中被评估"凝练为 **context-validity principle**，超越经验调参。
- **计算图级隔离**：相较 token-level masking 或部分前缀混合，强制 forward pass 隔离更彻底，杜绝污染泄漏。
- **自适应闭环调度**：用 $w_{\text{anchor}}=1-\mathrm{sim}(\hat{y},y^*)$ 替代预设阶段切换，理论动机清晰（负反馈校正）。
- **消融充分且公平**：与 Naive OPSD+CE、固定权重、Two-stage SFT→OPSD 等典型"省力方案"逐一对照，能逐项归因到 context isolation / adaptive weighting / endogenous scheduling 三个组件。
- **跨规模可复现**：在 1.7B / 4B / 8B 上趋势一致，并提供 Pareto 前沿图直观展示权衡改善。

## 8. 不足与局限

- **模型族单一**：仅评估 Qwen3，未在 Llama、Mistral、DeepSeek 等异构模型族上验证，结论的可推广性存疑。
- **任务覆盖窄**：仅 ToolAlpaca + SimpleMath 两类任务，未覆盖开放式生成、长上下文问答、代码生成等更广谱场景。
- **诊断代理有限**：受控前缀破坏以"随机替换"为主，与自然学生错误（结构化、上下文依赖）存在差距，作者亦承认该局限。
- **资源透明度不足**：未披露 GPU 型号/数量、训练时长、碳排等；仅给出相对开销 30%–40%，对大规模复现不友好。
- **超参与设计选择敏感性**：$\alpha$ 与相似度指标 $\mathrm{sim}$ 仍依赖经验选择，附录中不同相似度在乘除法上仍可见差异。
- **理论保证缺失**：仅提供经验性收敛与动态描述，未对 $w_{\text{anchor}}$ 收敛性或最优性给出形式化分析。
- **可解释性有限**：虽然能观测到自适应调度与负反馈行为，但未深入分析相似度阈值、$w_{\text{anchor}}$ 衰减速度对最终性能的影响机理。
- **应用边界**：需要 privileged context（标准答案/专家示范），与 RLHF/RLAIF 中基于结果奖励的范式不直接兼容。
