## 摘要
基于大语言模型（LLM）构建的多智能体系统（MAS）正在迅速涌现，但其异构的执行轨迹在不同方法之间缺乏统一的评估基准。仅关注结果的基准会丢弃协作过程中的信息，而以 LLM 作为评判者的评估方式则需要额外的、与模型相关的推理过程，且会因 LLM 和评分标准的不同而产生差异。我们提出了一个可泛化的评估框架，将原生 MAS 轨迹映射到一个由统一协作图构成的共享空间中，从而能够在相同的表示、参考集和指标体系下对不同方法进行评估。候选图与针对每个查询构建的参考森林进行比较。每个参考森林是基准提供的一组经过验证的成功图集合：它记录了代表性 MAS 方法完成任务的多样化方式，而非规定唯一的最优流程。作为该框架的具体实例，ForestBench 从七个公开数据集中筛选出 844 条需要协作的查询，为每条查询预先计算十个成功的目标条件参考图，并对六个代表性 MAS 框架进行评估。通过对骨干模型、参考构建方式以及扰动的对照实验，验证了评估的稳定性与适用范围。一旦基准森林构建完成，ForestBench 即可在毫秒级时间内对一条轨迹进行评分，无需进一步的 LLM 推理，为多样化 MAS 协作轨迹的比较提供了一个可复用的结构化基础。

## Abstract
Multi-agent systems (MAS) built on Large Language Models (LLMs) are proliferating rapidly, but their heterogeneous execution traces provide no common basis for evaluation across methods. Outcome-only benchmarks discard collaborations, whereas LLM-as-Judge evaluation requires additional, model-dependent inference and can vary with the LLM and rubric. We introduce a generalizable evaluation framework that maps native MAS traces into a shared space of unified collaboration graphs, enabling different methods to be evaluated under the same representation, reference set, and metric panel. Candidate graphs are compared with a query-specific reference forest. Each forest is a benchmark-provided collection of verified-success graphs: it records diverse ways in which representative MAS methods can complete the task, rather than prescribing a unique optimal process. Instantiating the framework as ForestBench, we filter $844$ collaboration-necessary queries from seven public datasets, precompute ten successful target-conditioned reference graphs per query, and evaluate six representative MAS frameworks. Controlled backbone, reference-construction, and perturbation studies test the stability and scope of evaluation. Once the benchmark forests are built, ForestBench scores a trace in milliseconds without further LLM inference, providing a reusable structural basis for comparing diverse MAS collaboration traces.

## 一、核心问题与研究动机

基于大语言模型（LLM）的多智能体系统（MAS）正以极快速度涌现，涵盖了固定流水线、动态角色分配以及自组织群体等多种协作范式。然而，新框架的出现速度已经远超对其进行评估与比较的能力，核心瓶颈在于缺乏一个**跨方法、过程级的统一评估基座**。

- **结局型基准的局限**：GSM8K、MMLU、HumanEval 等基准仅给出最终答案，丢弃了 MAS 最本质的协作过程信息（谁贡献、谁消费、谁验证、信息如何流动），无法区分协作质量。
- **LLM-as-Judge 的局限**：需要额外的、与模型和评分标准（rubric）相关的推理过程，存在重复成本、可复现性差，且评估会随 LLM 与评分规则的变化而漂移。
- **过程级评估的碎片化**：原生 MAS 轨迹与具体框架的事件模式、角色词汇、通信协议深度耦合，不同框架的轨迹无法直接对比。
- **协作多样性的忽视**：同一查询可通过辩论（debate）、规划者-专家流水线、同伴集群（swarm）等多种方式完成，若强行指定单一"最优过程"作为金标准，会不当偏袒某一协作范式。

## 二、方法论

### 2.1 整体框架

ForestBench 的核心是三层抽象：

1. **图抽象（Graph Abstraction）**：将任意 MAS 的执行轨迹映射为统一的有向无环图（DAG）。
2. **参考森林（Reference Forest）**：每个查询附带一组验证成功的参考图（多种协作范式各取若干），作为基准资产发布。
3. **指标面板（Metric Panel）**：在共享图空间上计算结构、参考对齐、信息吸收、内容冗余与成本等确定性指标，毫秒级打分，无需 LLM 推理。

### 2.2 关键公式

#### （1）协作图的形式定义

给定一个查询 $q$ 与 MAS 系统 $M$，执行得到时间序轨迹 $\tau = M(q)$，将其投影为：

$$G(\tau) = (V, E, \phi)$$

其中：
- $V$：每个原子动作（agent 消息、工具调用、决策）对应一个节点；
- $E$：每条信息传递对应一条有向边；
- $\phi$：每个节点标注其发出智能体、规范化角色 $r \in \mathcal{R}$，以及动作的文本内容。

由于每个原子动作在发出时都有唯一时间戳，且只能消费已发出的信息，因此所有边严格前向、无环，$G(\tau)$ 是良定义的 DAG。该投影是有损但稳定的：丢弃框架特定的运行时状态与精确时序交错，保留角色、动作与信息流依赖。

#### （2）参考森林

$$\mathcal{F}(q) = \{(G_k, q_k)\}_{k=1}^{K(q)}$$

其中 $G_k$ 是从代表性协作范式（多智能体辩论、Swarm、AutoGen、MetaGPT、MAS-GPT、AFlow 等）采样并验证为成功的参考图；$q_k > 0$ 是其综合权重（综合正确性、结构简洁性、token 成本）。森林代表**已被基准方验证可行的多种成功协作结构**，而非唯一最优流程。

#### （3）两图相似度

候选图 $G$ 与某棵参考树 $G'$ 的相似度：

$$\text{sim}(G, G') = \alpha\, s_{\text{node}} + \beta\, s_{\text{edge}} + \gamma\, s_{\text{topo}}$$

默认权重 $(\alpha,\beta,\gamma)=(0.4,\,0.4,\,0.2)$。

- **节点相似度**（基于角色多重集 $\mathcal{R}(\cdot)$，使用 Jaccard-like 比值）：
$$s_{\text{node}} = \frac{|\mathcal{R}(G) \cap \mathcal{R}(G')|}{|\mathcal{R}(G) \cup \mathcal{R}(G')|}$$

- **边相似度**（基于角色化边指纹多重集 $\mathcal{B}(\cdot)$）：
$$s_{\text{edge}} = \frac{|\mathcal{B}(G) \cap \mathcal{B}(G')|}{|\mathcal{B}(G) \cup \mathcal{B}(G')|}$$

- **拓扑相似度**（不奖励冗长）：
$$s_{\text{topo}} = \frac{1}{2}\!\left(\frac{\min(|V|,|V'|)}{\max(|V|,|V'|)} + \frac{\min(|E|,|E'|)}{\max(|E|,|E'|)}\right)$$

将节点与边基于规范化角色而非原始智能体 ID 进行匹配，使相似度对智能体重命名和独立动作置换保持不变。

#### （4）Forest Match（森林匹配）

将 $w_k = q_k / \max_{k'} q_{k'} \in (0,1]$ 归一化为权重，则：

$$\text{FM}(G,\mathcal{F}(q)) = \frac{\sum_{k=1}^{K(q)} w_k\, \text{sim}(G, G_k)}{\sum_{k=1}^{K(q)} w_k} \in [0,1]$$

Best Similarity 定义为 $\max_k \text{sim}(G,G_k)$。前者衡量对整片森林的对齐，后者衡量与最近一棵参考树的接近程度。

#### （5）辅助指标

- **节点有效性（Node Validity）**：非终点的可下游消费动作中，至少被一个下游动作消费的占比；
- **平均吸收度（Mean Uptake）**：基于嵌入余弦相似度是否超过阈值 $\theta_u$，衡量下游内容是否真正语义使用上游内容；
- **内容冗余度（Content Redundancy）**：归一化内容哈希后的重复比例；
- **Tokens / Efficiency**：总骨干模型 token 预算，以及拓扑效率（每智能体的图并行度）。

### 2.3 算法流程（评估新候选方法）

1. 运行候选 MAS，得到原生轨迹；
2. 用轻量适配器将原生日志解析为统一事件流（`agent_message` / `tool_call` / `decision`）；
3. 投影为协作图 $G_M(q)$，按框架别名表映射到共享角色词汇 $\mathcal{R}$；
4. 与预计算参考森林 $\mathcal{F}(q)$ 进行确定性图度量比较。

## 三、实验设计

### 3.1 基准数据集

从 7 个公开数据集筛选原始查询池 $\mathcal{Q}_0$，覆盖四大任务类型：

| 任务类型 | 数据集 |
|---|---|
| 推理（Reasoning） | GPQA、MMLU、MATH-500、GSM8K |
| 代码生成（Code Generation） | SWE-bench-Verified |
| 工具使用（Tool Use） | Terminal-Bench |
| 多跳搜索（Multi-hop Search） | WideSearch |

### 3.2 查询筛选（Trace-Suitability Pipeline, TSP）

对每条查询用一个强 LLM 在三个维度上打分：
- **深度 $d(q) \in \mathbb{Z}_{\geq 1}$**：所需最少推理步数；
- **宽度 $w(q) \in [0,1]$**：在 8 项能力（事实记忆、逻辑推理、数学、编码、搜索、创意写作、领域知识、规划）上评分的归一化 Shannon 熵；
- **可分解性 $\delta(q) \in [-2,+2]$**：是否能自然划分为独立子任务。

仅当三者同时满足阈值 $(\theta_d,\theta_w,\theta_\delta)=(5,\,0.5,\,0.5)$ 时，查询被保留：
$$d(q) \ge \theta_d,\quad w(q) \ge \theta_w,\quad \delta(q) \ge \theta_\delta$$

筛选后保留 **844 条** 查询，分布为：推理 55.9%、多跳 QA 23.7%、代码生成 15.8%、工具使用 4.6%。具体来源：SWE-bench-V 133 (15.8%)、MATH-500 249 (29.5%)、WideSearch 200 (23.7%)、GPQA 115 (13.6%)、GSM8K 60 (7.1%)、MMLU 48 (5.7%)、TermBench 39 (4.6%)。

### 3.3 参考森林构造

每条查询 $q \in \mathcal{Q}^\star$（附带验证答案 $a^\star$）从 6 个代表性 MAS 框架（Multi-agent Debate、Swarm、AutoGen、MetaGPT、MAS-GPT、AFlow）+ 单智能体 CoT-SC 锚采样，**目标条件化**生成直至重现 $a^\star$，聚类后按验证正确性、结构简洁性、token 成本赋权。每条查询保留 **10 个参考图**，总计 **8440 个**参考轨迹。

### 3.4 被评估的 MAS 框架

6 个代表性候选框架：Multi-agent Debate、Swarm、AutoGen、MetaGPT、MAS-GPT、AFlow。

每个框架每查询 3 个随机种子，6 个框架合计约 $\sim 15{,}192$ 条轨迹。

### 3.5 骨干模型

- **DeepSeek-V4-Flash**：默认候选骨干与默认参考森林骨干；
- **Claude-Sonnet-4.6、GPT-5.5、Qwen3.6-Plus**：用于跨骨干鲁棒性、诊断一致性等对照实验。

### 3.6 主要研究问题

- **RQ1 横向评估**：共享图表示能否暴露异构 MAS 间的可比较协作差异？
- **RQ2 有效性与鲁棒性**：评估对骨干、参考生成器、答案条件化的敏感度？
- **RQ3 指标行为**：图指标对受控结构变化是否可预测响应？
- **RQ4 失败诊断**：结构对齐能否揭示失败原因？

## 五、实验数量与充分性

论文实验非常充实，覆盖以下若干维度：

1. **横向对比实验**：6 个 MAS 框架 × 844 查询 × 3 随机种子（≈15,192 轨迹）下的 ForestBench 主表（Table 1），报告 Accuracy、Forest Match、Node Validity、Mean Uptake、Content Redundancy、Best Similarity、Tokens、Efficiency 共 8 项指标。
2. **跨骨干鲁棒性**：分别用 DeepSeek-V4-Flash、Claude-Sonnet-4.6、GPT-5.5 三个骨干独立构造参考森林，框架排序的 Kendall $\tau$ 与 Spearman $\rho$ 均 **=1.00**。
3. **参考生成器留出（leave-generator-out）**：依次剔除 6 个 MAS 参考生成器之一与 CoT-SC，7 种设置下 Top-3 在 **6/7** 设置下保留，Kendall $\tau$ 范围 0.60–1.00（Table 2）。
4. **答案条件化消融**：在 30 条子集上对比有/无 gold-answer 条件化构造，MAS-GPT/AutoGen/MetaGPT 保持 Top-3，Kendall $\tau=0.867$（Table 3）。
5. **结构扰动验证**：5 类扰动 × 2 强度（节点删除、边重连、角色交换、干扰插入、重复内容注入），共 10 组（Table 5）：节点删除 $p=0.5$ 使 Forest Match 下降最大 $-0.058$，重复内容注入对结构分几乎无影响但被 Content Redundancy 捕获。
6. **指标权重敏感性**：5 套非退化权重（默认、均匀、节点重、边重、拓扑重），非退化设置 Kendall $\tau \ge 0.73$，均匀/节点重/边重 $\ge 0.87$；拓扑单独权重 $\tau=0.20$（设计外用途）。
7. **TSP 阈值敏感性**：36 组 $(\theta_d, \theta_w, \theta_\delta)$ 组合，对应 222–1244 查询池，框架排序 Kendall $\tau=1.00$（36/36），Top-1 完全保留。
8. **来源层留出与按源排序**（Table 9）：leave-one-source-out 8 个数据源下 Kendall $\tau=0.87$–$1.00$，Top-1 8/8 保留；按源排名 7 个源（$\ge 20$ 轨迹）Kendall $\tau=-0.33$–$1.00$，Top-1 4/7。
9. **失败模式诊断**：300 条按框架、数据集、accuracy-Forest Match 象限分层的轨迹，3 个 LLM 评委多数投票标注结构/内容失败标签；表 4 报告共享可解析子集 $n=138$ 的多数同意率（结构 93.5%、内容 81.2%、是否被捕获 100%、首个错误位置 94.9%）。
10. **评分标准（prompt）敏感性**：同 DeepSeek 评委在 100 条轨迹上跑 3 种 rubric 变体，报告 Cohen's $\kappa$ 范围（结构 0.129–0.351、内容 0.331–0.470、是否被捕获 0.388–0.621、首个错误位置 0.537–0.616），用以警示细粒度标签的不稳定性。
11. **成本分析**：1000 条轨迹墙钟对比 ForestBench（0.7 s / 0 推理 token）vs. LLM-as-Judge（2054 s / 996k 输入 token / 78k 输出 token）。

**充分性评价**：实验在维度上**相当充分**，涵盖：跨方法、跨骨干、跨生成器、跨条件化、跨扰动、跨权重、跨阈值、跨数据源、跨评分规则的多层次鲁棒性测试；并通过 LLM 评委多数投票与 rubric 变体显式控制了"用 LLM 评判 LLM"的偏差。但仍有局限：评分标准敏感性实验揭示**细粒度 LLM 标签并不稳定**，论文因此只强调粗粒度修复方向。

## 六、主要结论与发现

1. **结局准确率单独不足以区分方法**：6 个候选框架的准确率仅相差 0.038（0.531–0.569），但 Forest Match 跨度达 0.316–0.421，揭示了显著的协作结构差异。
2. **Forest Match 是有判别力的结构信号**：它衡量候选对参考森林中多棵成功参考树的对齐，而 Best Similarity 衡量与最近一棵树的接近度；两者都不主张"更复杂的编排更好"。
3. **结构面板揭示隐藏差异**：Debate 准确率最高但 Forest Match 最低、token 接近最贵方法的两倍；AFlow 内容冗余度（0.167）约为次高者的 3 倍，源于并行求解器的重复内容；Swarm 是唯一节点有效性低于 1（0.968）的框架。
4. **领域特化**：在 SWE-bench-Verified 上，参考森林包含更多 review-and-revise 参考图，Debate 跃升为最对齐方法（0.382），与全局排名相反，提示**应结合源级分析进行域内选型**。
5. **编排增益依赖骨干**：相对单智能体 CoT 基线，平均编排增益在 DeepSeek-V4 上为 $-0.002$、GPT-5.5 上为 $-0.039$、Claude-S4.6 上为 $-0.069$——**更强骨干上加智能体并非普遍有利**。
6. **框架施加强结构先验**：跨骨干平均距离 0.171，略小于骨干内距离 0.181；三个框架的距离矩阵 Pearson 相关 0.986–0.999。
7. **稳定性证据**：跨骨干、跨生成器、跨条件化、跨权重、跨阈值的对照实验均显示框架排序在绝大多数设置下保持一致，森林作为聚合评估基础可靠。
8. **失败可分为结构 vs. 内容**：结构失败指向角色/拓扑/聚合缺失；内容失败指向验证、聚合、事实错误；Forest Match + accuracy 组合可定位修复方向。
9. **效率优势**：ForestBench 评测 1000 条轨迹约 0.7 秒、0 推理 token，比 LLM-as-Judge 快约 2900 倍；参考森林构建为一次性成本（约 2050 万 token），发布后可被所有下游用户复用。

## 七、优点（续）

- **问题定位精准**：抓住了 MAS 评估领域长期被诟病的"结局型基准丢弃协作过程、LLM-as-Judge 不稳定"的两大核心痛点，提出"图归一化 + 参考森林"这一可被广泛复用的解决思路。
- **方法论自洽且优雅**：将异构 MAS 轨迹投影为统一 DAG 的思想既简洁又具有表达力；参考森林通过"多范式成功解的聚合"巧妙回避了"金标准过程"问题，比指定单一最优流程更公平。
- **指标设计有原则**：Forest Match、Node Validity、Mean Uptake、Content Redundancy、Tokens、Efficiency 等指标**全部无需 LLM 推理**，在毫秒级完成确定性计算，可复现性强且不随时间漂移。
- **角色规范化提升公平性**：通过将节点和边匹配建立在规范化角色词汇 $\mathcal{R}$ 上而非原始智能体 ID 上，使相似度对重命名和独立动作置换不敏感，避免了"只要智能体多就对"的偏倚。
- **实验充分且系统**：涵盖了跨骨干、跨生成器、跨条件化、跨扰动、跨权重、跨阈值、跨数据源、跨评分规则的全面鲁棒性测试，并通过 LLM 多数投票与 Cohen's $\kappa$ 显式量化了 LLM 评委的不稳定性。
- **失败诊断具有实用价值**：将失败区分为"结构失败"与"内容失败"两个粗粒度维度，并通过 accuracy–Forest Match 二维象限定位修复方向，比单一 accuracy 反馈更具操作性。
- **效率优势显著**：比 LLM-as-Judge 快约 2900 倍且不消耗推理 token，参考森林一旦构建可被无限复用，分摊成本极低。
- **代码与资源承诺**：承诺发布参考森林、轨迹、骨干配置等关键资产，方便社区复现与二次研究。

## 八、缺点与局限

- **图投影的有损性**：轨迹到 DAG 的投影丢失了精确时序交错、框架内部状态、对话上下文窗口等细节；某些依赖状态机或多轮上下文累积的框架特性可能被过度简化。
- **参考森林偏差**：尽管采用了 6 个代表性框架 + CoT-SC 锚，但若某个候选框架使用了未被森林覆盖的角色词汇或动作模式，其 Forest Match 会被系统性低估，即森林本身可能存在"覆盖偏差"。
- **角色词汇有限**：$\mathcal{R}$ 虽通过别名表扩展，但本质上仍是离散且预定义的，无法捕捉新兴框架的细粒度角色语义。
- **节点与边的离散性假设**：节点基于动作、边基于信息流，对于"长篇连续推理 + 单次广播"类框架的结构差异区分度有限。
- **嵌入语义相似度的脆弱性**：Mean Uptake 依赖嵌入余弦相似度与阈值 $\theta_u$，对嵌入模型选择敏感；过高的 $\theta_u$ 会低估真实信息吸收，过低则会高估。
- **复杂度归一化的副作用**：$s_{\text{topo}}$ 用 $\min/\max$ 比值惩罚冗长，这意味着极简但错误的过程可能获得较高拓扑分；论文虽然明确不主张"越复杂越好"，但这一设计在某些场景下可能鼓励过早终止。
- **失败诊断的细粒度不稳定**：rubric 敏感性实验显示细粒度标签的 Cohen's $\kappa$ 仅 0.129–0.621，论文坦承了这一点并退回到粗粒度，但诊断精度的天花板被这一限制压低。
- **算力披露不充分**：未给出参考森林构建所用的 GPU 数量、墙钟时间等关键信息，外部研究者难以估算构建成本与决定是否自行重建。
- **数据集来源虽多但分布不均**：推理类查询占比 55.9%，SWE-bench-V 与 TermBench 相对小众且领域特定，可能影响结果在更广泛 MAS 应用场景下的泛化性。
- **骨干模型依赖**：所有指标虽不需推理 token，但参考森林与候选轨迹均由 LLM 生成，骨干本身的偏差会通过图结构传递；论文虽做了跨骨干测试，但仍是商用 API 而非开源可复现模型。
- **未讨论多轮对话与状态恢复**：投影假设边严格前向、无环，对于包含"撤销/回滚"或"状态恢复"等机制的真实系统可能产生畸变。
- **未与人类评估充分对比**：缺乏与人类专家对协作过程质量评估的对照实验，难以断言 Forest Match 等指标与人类判断的相关性强弱。
- **"Top-1 稳定性"的过度强调**：多个消融实验中 Top-1 框架稳定保留，但 Top-2/Top-3 的变化未被同等强调，部分排序内部的不稳定性可能被低估。

## 九、总体评价

ForestBench 是**MAS 评估基础设施层面的一份里程碑式工作**。它直面"过程级、跨框架、可复现、低成本"评估这一长期未被满足的需求，提出了以图归一化 + 参考森林 + 确定性指标为核心的完整解决方案。其方法论既具有理论上的优雅性，又通过全面鲁棒性实验展示了工程上的可靠性。**毫秒级确定性打分 + 一次性摊销参考森林**的范式为社区提供了一条极具吸引力的扩展路径。

论文的局限主要在于图投影的有损性、参考森林的覆盖偏差以及 LLM-as-Judge 不可避免的细粒度不稳定，但作者均通过对应实验或显式声明给予了坦诚讨论。整体而言，该工作既适合作为 MAS 过程级评估的**新基准基座**，也适合作为研究"过程结构 vs. 协作质量"关系的**实证数据来源**。

对于 MAS 框架设计者：Forest Match 与 Node Validity 等指标可直接指导编排优化方向（增加有效吸收、提升节点有效性、降低冗余）。

对于基准构建者：ForestBench 的"图归一化 + 多范式参考集 + 确定性指标"框架可被推广到其他多智能体场景（如具身智能、多机器人协作、复杂工作流引擎）的过程级评估。

对于更广泛的 NLP/AI 评估研究：ForestBench 的"避免金标准过程 + 聚合多范式成功解 + 结构性诊断"思路，可能启发对话系统、Agent 基准乃至 AI 安全评估中关于"过程级指标如何既可比又公平"的进一步研究。
