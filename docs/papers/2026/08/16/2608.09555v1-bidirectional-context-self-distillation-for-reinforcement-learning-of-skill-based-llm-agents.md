## 摘要
外部自然语言技能为大型语言模型（LLM）智能体提供了可复用且可编辑的指导，以解决复杂任务。然而，其有效性不仅取决于技能质量，还取决于策略能否将所提供的指导转化为恰当的动作。尽管如此，专门用于提升这种技能利用能力的方法在很大程度上仍未得到充分探索。在实践中，基于技能的智能体通常使用以任务级奖励为中心的强化学习目标进行训练，这种训练提供的监督有限，难以捕捉策略在多大程度上有效利用所提供的技能的细微差异。我们提出了 BCSD（双向上下文自蒸馏），一个将自蒸馏与强化学习相结合的框架，用于训练大语言模型智能体更有效地利用外部技能。与依赖单一特权上下文的先前自蒸馏方法不同，BCSD 从两种互补的技能上下文视角评估每条轨迹。增强视图引入了更高层次的元技能指导，而简化视图则裁剪通用指导以突出任务特定技能。其互补的逐词元信号被组合用于调整强化学习优势。在 ALFWorld 和 WebShop 上的实验表明，BCSD 在不同模型规模下均取得了最优的整体性能，使智能体能够更有效地利用外部技能。消融研究进一步验证了增强和简化上下文视图的互补贡献。代码将被发布以确保完全可复现性。

## Abstract
External natural-language skills provide large language model (LLM) agents with reusable and editable guidance for solving complex tasks. Yet their effectiveness depends not only on skill quality, but also on whether the policy can translate the provided guidance into appropriate actions. However, methods specifically designed to improve this skill-utilization ability remain largely underexplored. In practice, skill-based agents are commonly trained with reinforcement learning objectives centered on task-level rewards, which offer limited supervision and struggle to capture subtle differences in how effectively the policy uses the provided skills. We propose BCSD (Bidirectional Context Self-Distillation), a framework that combines self-distillation with reinforcement learning to train LLM agents to use external skills more effectively. Unlike prior self-distillation methods that rely on a single privileged context, BCSD evaluates each trajectory from two complementary skill-context views. The augmented view introduces higher-level Meta-Skill guidance, while the reduced view prunes general guidance to highlight task-specific skills. Their complementary token-level signals are combined to rescale the RL advantage. Experiments on ALFWorld and WebShop demonstrate that BCSD achieves the strongest overall performance across model scales, enabling agents to utilize external skills more effectively. Ablation studies further verify the complementary contributions of the augmented and reduced context views. Code will be released to ensure full reproducibility.

## 1. 核心问题与研究动机

- **研究背景**：外部自然语言技能（natural-language skills）为 LLM 智能体提供可复用、可编辑的程序性知识，使其在长视野任务中不必从头推理。当前"基于技能"的 LLM 智能体研究主要沿两条路径展开：
  - 路径一：**技能生成与演化**（如 SkillEvolver、SkillAudit、SkillHone），关注技能本身质量的提升，但忽略策略是否真正利用了这些技能。
  - 路径二：**技能内化**（如 Skill-SD、SDAR、SIRI），将技能蒸馏进模型参数，从而损失技能的可解释性、可编辑性与可迁移性。
- **关键问题**：如何让策略学会更好地"使用"外部技能，而非将其内化至参数？近期研究表明，提供高质量技能并不必然带来有效利用（Li et al., 2026c）。
- **现有瓶颈**：
  - 基于技能的 RL 训练常采用 GRPO 等任务级奖励，监督粒度过于粗糙，难以反映策略是否真正依据技能做出决策。
  - 近期出现的 On-Policy Self-Distillation（OPSD）虽提供 token 级信号，但依赖单一特权上下文，存在信息泄露、训练不稳定等问题，token 级信号可能受上下文风格偏移或捷径词元干扰，未必可靠。

## 2. 方法论：BCSD 框架

### 2.1 核心思想

受多教师集成（MOPD）与参考策略在 RL 中锚定作用的启发，BCSD 将"多教师集成"与"参考策略"从**参数空间**迁移到**上下文空间**，从两个互补的上下文视角评估同一轨迹并融合 token 级信号，以重塑 GRPO 优势。

### 2.2 问题设定

- 任务建模为部分可观察决策过程：第 $h$ 步智能体接收观察 $o_h$，生成动作 $a_h$，最终获得终端奖励 $R(\tau)$。
- 沿用 SkillRL 的分层 SkillBank：基础上下文 $C_0 = (Q, G, S_c)$，其中 $Q$ 为查询，$G$ 为通用技能，$S_c$ 为任务类型 $c$ 检索得到的任务特定技能。
- 对每条查询在 $C_0$ 下采样 $K$ 条轨迹 $\{\tau_i\}_{i=1}^K \sim \pi_\theta(\cdot | C_0)$，$r_i = R(\tau_i)$。
- 标准的 GRPO 优势为：

$$A_i^{GRPO} = \frac{r_i - \mu_r}{\sigma_r + \epsilon}$$

其中 $\mu_r$、$\sigma_r$ 为组内奖励的均值与标准差。

### 2.3 Meta-Skill 提取

- **定义**：Meta-Skill $M_c$ 是高层文本指导，刻画当前策略在应用 $S_c$ 时的有效与失效模式；仅在训练时作为特权信息注入教师上下文，不进入学生上下文 $C_0$，推理时也不使用。
- **提取与刷新**：每 $N$ 步根据验证表现触发刷新。在窗口 $k$ 内收集成功集 $E_{c,+}^{(k)}$ 与失败集 $E_{c,-}^{(k)}$，由冻结的外部 LLM 提炼：

$$M_c^{(0)} = \text{Extract}_{LLM}(S_c, E_{c,+}^{(0)}, E_{c,-}^{(0)})$$

$$M_c^{(k+1)} = \text{Extract}_{LLM}(S_c, M_c^{(k)}, E_{c,+}^{(k)}, E_{c,-}^{(k)})$$

刷新后清空证据缓冲。

### 2.4 双向上下文构建

- **增强视图**（augmented）：在 $C_0$ 基础上追加 Meta-Skill：

$$C_1 = (Q, G, S_c, M_c)$$

- **精简视图**（pruned）：训练前由外部 LLM 一次性裁剪通用技能 $G$，保留其核心程序性引导，记为 $G_p = \text{Prune}_{LLM}(G)$，并在训练中固定：

$$C_2 = (Q, G_p, S_c)$$

增强与精简构成 BCSD 的"双向"。

### 2.5 Gap-Weighted Advantage Rescaling

对同一条轨迹的固定响应序列 $y_i$，分别在 $C_1, C_2$ 下重新计分得 token 级对数概率差：

$$\Delta_{i,t}^{aug} = \log \pi_\theta(y_{i,t} | C_1, y_{i,<t}) - \log \pi_\theta(y_{i,t} | C_0, y_{i,<t})$$

$$\Delta_{i,t}^{pru} = \log \pi_\theta(y_{i,t} | C_2, y_{i,<t}) - \log \pi_\theta(y_{i,t} | C_0, y_{i,<t})$$

融合两路差：

$$\Delta_{i,t} = \alpha \Delta_{i,t}^{aug} + (1-\alpha) \Delta_{i,t}^{pru}$$

通过裁剪的指数权重调制优势，保持"不反转奖励决定的方向"：

$$w_{i,t} = \text{clip}\!\left(\exp\!\left(\text{sign}(A_i^{GRPO})\Delta_{i,t}\right),\; 1-c,\; 1+c\right)$$

$$A_{i,t}^{BCSD} = A_i^{GRPO}\!\left[(1-\lambda_n) + \lambda_n w_{i,t}\right]$$

其中 $\lambda_n$ 随训练从 $\lambda_0$ 线性衰减至 $0$，以在前期提供密集上下文引导、后期回归环境奖励驱动。

### 2.6 策略优化目标

沿用 GRPO 截断目标，将 $A_i^{GRPO}$ 替换为 $A_{i,t}^{BCSD}$：

$$L_{BCSD}(\theta) = -\mathbb{E}_{i,t}\!\left[\min\!\left(\rho_{i,t}(\theta)A_{i,t}^{BCSD},\;\text{clip}(\rho_{i,t}(\theta), 1-\epsilon, 1+\epsilon)A_{i,t}^{BCSD}\right) + \beta L_{KL}\right]$$

其中 $\rho_{i,t}(\theta) = \frac{\pi_\theta(y_{i,t}|C_0, y_{i,<t})}{\pi_{\theta_{old}}(y_{i,t}|C_0, y_{i,<t})}$。

### 2.7 算法流程（Algorithm 1）

1. 训练前构造 $G_p$，并用预加载轨迹初始化 $\{M_c^{(0)}\}$；
2. 每个优化步：在 $C_0$ 下采样 $K$ 条轨迹并计算 $A_i^{GRPO}$；在 $C_0, C_1, C_2$ 下重新计分；按式 (11)–(13) 计算 $\Delta_{i,t}, w_{i,t}, A_{i,t}^{BCSD}$；将去技能化轨迹存入成功/失败证据缓冲；
3. 以 $L_{BCSD}$ 更新参数；
4. 每 $N$ 步按式 (5) 刷新 Meta-Skill 并清空证据。

**充分性**：

- 多 backbone 跨规模验证，结论具有较好的泛化性；
- 不同 baseline 类型（无技能 / RL / 自蒸馏）覆盖较全；
- 消融维度（教师视图、衰减策略、Meta-Skill 更新）较系统；
- 公平性：所有自蒸馏基线共享相同的分层 SkillBank 与实验设置，作者也注明结果来自自己的复现。

**潜在不足**：

- 实验仅围绕 ALFWorld 与 WebShop 两个文本环境，缺少代码生成、工具调用、对话、机器人等场景；
- 没有针对更多模型家族（Llama、DeepSeek、GPT 系列）或多语言环境的测试；
- 训练步数较少（150 步），长程训练稳定性与收敛性未充分展示；
- 评测指标偏单一（成功率与得分），未涉及路径长度、效率、鲁棒性、跨任务迁移等维度。

## 6. 主要结论与发现

- BCSD 在三种 backbone（Qwen2.5-7B / 3B、Qwen3-1.7B）上均取得综合最优结果：
  - Qwen2.5-7B：ALFWorld 83.6、WebShop Succ. 78.1；
  - Qwen2.5-3B：分别较最强 baseline 提升 5.4 / 4.4 / 9.4 个百分点；
  - Qwen3-1.7B：ALFWorld 46.9，WebShop Score 76.8。
- 相对使用相同 SkillBank 的 Skill_GRPO*，BCSD 在两基准上仍能稳定提升 2–4 个百分点，说明其增益源自"如何用技能"而非"更多技能"。
- 消融实验表明：
  - **Meta-Skill 教师**贡献最大；缺少时 ALFWorld 从 82.0 降至 71.1，WebShop 从 66.4 降至 50.0；
  - **Pruned-Skill 教师**同样不可忽略（$75.0/57.0$ 退化），印证单一上下文视角的不可靠性；
  - **$\lambda_n$ 衰减**与 **Meta-Skill 周期性更新**均带来显著收益。
- 跨视角一致率在 47%–53% 之间，说明两个视图提供"差异而非冗余"的 token 级信号。
- 任务技能利用分析（图 6）显示，去掉 $S_c$ 后 BCSD 性能下降（ALFWorld −2.3、WebShop −7.8）大于 Skill_GRPO*（−0.8 / −6.2），证明 BCSD 的增益来自更主动地利用外部技能，而非把任务知识内化进参数。

## 7. 优点

- **保留外部技能**：与"内化路线"不同，BCSD 维持技能在训练与推理阶段的显式性，使其可编辑、可审计、可迁移；
- **双向互补视角**：首次将"上下文空间"作为多教师的载体，规避单一特权上下文的偏移与捷径风险；
- **方向保持型优势重塑**：通过对 $A_i^{GRPO}$ 的缩放而非反向修改，token 级信号不会扰乱奖励决定的更新方向；
- **早期监督 + 后期奖励的渐进过渡**：$\lambda_n$ 由 $\lambda_0$ 线性衰减到 0，使自蒸馏作为"前期脚手架"，后期回归环境奖励驱动；
- **Meta-Skill 周期性刷新**：避免静态特权信息随策略演化而过时；
- **跨 backbone 与跨 benchmark 的一致性**：在 3 个模型规模、2 个基准上均取得最优或并列最优；
- **细致消融与诊断分析**：跨视角一致率、训练动力学、技能去除实验从多角度印证方法合理性。

## 8. 不足与局限

- **实验范围**：仅在 ALFWorld、 WebShop 两个文本决策环境评测，未覆盖代码生成、具身、检索增强、对话等场景，外部有效性尚待验证；
- **训练规模**：150 步训练较短，长程训练下 Meta-Skill 刷新频率与信号可靠性是否稳定仍未知；
- **算力披露缺失**：未报告 GPU 型号/数量、训练时长、显存占用，复现成本难以估算；
- **超参依赖**：$\alpha=0.9$、$\lambda_0=0.1$ 等取值在 ALFWorld 与 WebShop 上共用，是否需要场景自适应未充分讨论；
- **Meta-Skill 依赖外部 LLM**：刷新机制中的 Extract / Prune 模型均为外部冻结 LLM，质量与偏差会直接影响上游信号，论文未对外部 LLM 的选择进行敏感性分析；
- **基线一致性**：虽然所有结果来自自我复现，但仅在 SkillRL 框架下与自身基线对比，未在更多独立框架（如 ReAct、Reflexion、AutoGen）下验证；
- **任务技能利用实验的粒度**：仅以"去掉 $S_c$ 后性能下降幅"为代理指标，可能存在任务独立性、行为相似性等混杂因素；
- **安全性与可编辑性**：作者强调外部技能可编辑、可审计，但未给出具体演示如何利用该性质进行行为干预或漏洞修复；
- **多语言与跨域迁移**：未评估在中文或多语言任务上的表现，Meta-Skill 的提炼质量是否受语言影响尚无证据。
