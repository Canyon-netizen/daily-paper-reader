## 摘要
在线策略自蒸馏（OPSD）通过自蒸馏将特权上下文内化到模型参数中，从而提升大语言模型（LLMs）的推理能力。近期的两条研究路线分别通过选择学习哪些 token 以及控制教师接收多少特权信息来改进原始的 OPSD。然而，我们发现每条路线都只优化其中一个变量而固定另一个变量，这导致了次优解。我们认为这两个变量通过学生的学习能力相互耦合：特权信息设定了教师所指定的逐 token 散度，而 token 加权则选择了学生必须吸收其中的哪些部分。我们将这两条工作路线形式化为一个统一的优化框架，在学生可吸收的总学习难度预算约束下，最大化教师与学生之间的总散度。基于此建模，我们提出了统一在线策略自蒸馏（USD），一个用于求解拉格朗日问题的轻量级在线算法。USD 揭示了一个对偶变量同时支配着这两项决策：以一个学习难度价格为尺度，它同时设定 token 选择阈值和特权信息调整的方向，使监督信号与学生不断变化的能力相匹配。通过大量实验，USD 在不同模型规模和多种推理基准上均一致地优于 OPSD 以及 token 侧和 PI 侧的基线方法。代码已开源：https://github.com/lauvlalala/USD。

## Abstract
On-policy self-distillation (OPSD) improves the reasoning abilities of LLMs by internalizing privileged context into model parameters through self-distillation.   Two recent research lines promote vanilla OPSD by choosing which tokens to learn from and by controlling how much privileged information the teacher receives, respectively.   However, we show that each line optimizes one variable while holding the other fixed, which leads to a suboptimal solution.   We argue that the two variables are coupled through the student's learning capacity: the privileged information sets the per-token divergence the teacher prescribes, while token weighting selects which of these the student must absorb.   We formalize the two lines of work into a unified optimization framework, which maximizes the aggregate teacher--student divergence, subject to a budget on the aggregate learning difficulty the student can absorb.   Under this modelling, we propose Unified On-Policy Self-Distillation (USD), a lightweight online algorithm to solve the Lagrangian.   USD reveals that a single dual variable governs both decisions: at one price for learning difficulty, it simultaneously sets the token-selection threshold and the direction of privileged-information adjustment, keeping supervision matched to the student's evolving capacity.   Through extensive experiments, USD consistently demonstrates superior performance over OPSD and token- and PI-side baselines across various model scales on various reasoning benchmarks. Code is available at https://github.com/lauvlalala/USD.

## 1. 核心问题与研究动机

**核心问题**：在线策略自蒸馏（On-Policy Self-Distillation, OPSD）已成为 LLM 推理后训练的有效范式——它不需要外部教师、RL 环境或人工标注轨迹，仅依靠同一模型本身在"特权信息（Privileged Information, PI）"（如参考解、环境反馈、真值推理链等）条件下的师生角色分工。然而现有改进路线存在结构性缺陷：

- **Token 侧方法**（如 TIP）：在固定的 PI 强度 $\beta=1$ 下重新分配 token 权重，但忽略了过强教师本身带来的不可学信号。
- **PI 侧方法**（如 PAINT）：自适应调整 PI 暴露，但保持 token 均匀加权，浪费了大量无贡献位置。
- **二者孤立优化**导致仅得到条件最优解，而非联合最优。

**关键洞察**：两个变量通过**学生学习容量**相互耦合：
- PI 强度 $\beta$ 决定教师分布本身，改变每个 token 的散度 $g_t$ 与学习难度 $d_t$；
- token 权重 $w_t$ 决定哪些监督被实际吸收，二者共享同一个"难度预算"。

降低 PI 可让原本不可学的 token 变得可学；过滤高难度 token 又反过来允许使用更强的 PI。**因此必须联合优化**。

## 2. 方法论

### 2.1 形式化两个设计轴

OPSD 的加权目标为：

$$J(w, \beta) = \frac{1}{P}\sum_t w_t \cdot D_{KL}\!\left(p_T^\beta(\cdot|x,\hat{y}_{<t}) \,\|\, p_S(\cdot|x,\hat{y}_{<t})\right)$$

其中 $w_t \in [0,1]$ 为逐 token 权重，$\beta \in [0,1]$ 控制 PI 暴露强度（$\beta=0$ 无 PI，$\beta=1$ 全暴露）。原始 OPSD 对应 $\beta=1,\ w_t\equiv 1$。

### 2.2 逐 token 散度与难度

对每个 token 位置 $t$，定义两个量：

- **散度（潜在更新幅度）**：$g_t(\beta) = D_{KL}(p_T^\beta \| p_S)_t$
- **学习难度（吸收代价）**：$d_t(\beta) = \left(\log \frac{p_T^\beta(a_t^\star)}{p_S(a_t^\star)}\right)_+$

其中 $a_t^\star = \arg\max_a p_T^\beta(a|x,\hat{y}_{<t})$ 为教师首选 token，$[\cdot]_+$ 表示正部（学生已偏好的 token 无学习负担）。

**两者都随 $\beta$ 单调递增**（在 Qwen3-1.7B 真实 rollout 上经验验证）。

### 2.3 联合约束优化：Learnability Frontier

将监督匹配建模为带预算的约束优化：

$$\max_{w\in[0,1]^T,\ \beta\in[0,1]}\ \frac{1}{N}\sum_t w_t g_t(\beta) \quad \text{s.t.}\quad \frac{1}{N}\sum_t w_t d_t(\beta) \le \varepsilon$$

其中 $\varepsilon>0$ 是学生当前阶段的可吸收难度预算。扫描 $\varepsilon$ 描绘出**可学性前沿**：

$$F(\varepsilon) = \max_{w,\beta}\left\{\frac{1}{N}\sum_t w_t g_t(\beta)\ :\ \frac{1}{N}\sum_t w_t d_t(\beta) \le \varepsilon\right\}$$

token 选择法和 PI 控制法各自仅在二维景观的一条一维切线上搜索，USD 则联合移动。

### 2.4 拉格朗日分析：单一对偶变量

引入对偶变量 $\lambda \ge 0$，拉格朗日量为：

$$L(w,\beta,\lambda) = \frac{1}{N}\sum_t w_t \underbrace{[g_t(\beta) - \lambda\, d_t(\beta)]}_{v_t(\lambda,\beta)} + \lambda\varepsilon$$

$L$ 关于 $w_t$ 是带框约束的线性函数，最优权重坍缩为**硬阈值**：

$$w_t^\star = \mathbb{1}\!\left[g_t(\beta) > \lambda\, d_t(\beta)\right]$$

当预算绑定（$\lambda>0$）且 $\beta^\star$ 在 $(0,1)$ 内时，平稳性条件给出：

$$\lambda = \frac{\sum_{t:w_t^\star=1} \partial g_t/\partial\beta}{\sum_{t:w_t^\star=1} \partial d_t/\partial\beta}$$

**核心结论**：**同一个 $\lambda$**（难度的边际价格）同时决定 token 选择阈值与 PI 调整方向——这并非设计所致，而是共享预算的结构性后果。

### 2.5 实用更新：USD 算法

由于 $\lambda$ 随训练变化、$w$ 的 0/1 指示不可微，USD 采用**在线原始-对偶算法**。对拉格朗日加熵正则 $\tau H(w)$ 得软权重：

$$w_t = \sigma\!\left(\frac{g_t(\beta) - \lambda\, d_t(\beta)}{\tau}\right)$$

三个标量按以下规则同步更新：

| 变量 | 更新规则 | 含义 |
|------|---------|------|
| $\lambda$ | $\lambda \leftarrow \max(0,\ \lambda + \eta_\lambda(\text{load}-\varepsilon))$ | 难度超预算时收紧 token 筛选 |
| $\beta$ | $\beta \leftarrow \text{clip}\!\left(\beta + \eta_\beta(\varepsilon - \text{load}),\ \beta_{\min}, 1\right)$ | 沿原始残差推向预算绑定点 |
| $w$ | 由 $\sigma\!\left(\frac{g_t-\lambda d_t}{\tau}\right)$ 闭式给出 | 软化阈值选择 |

训练损失对权重归一化以避免改变有效步长：

$$L_{\text{train}} = \frac{\sum_t w_t\, D_{KL}(p_T^\beta \| p_S)_t}{\sum_t w_t}$$

**Proposition 1** 保证：在 $\beta$ 单调性假设下，残差更新 $\beta \leftarrow \beta + \eta_\beta(\varepsilon - \text{load})$ 单调收敛到满足式 (6) 的最优 $\beta^\star$，无需对 $\beta$ 求梯度。算法每 batch 仅增加 $O(T)$ 的负载计算与两个标量更新，无额外前向传播或辅助网络。

- 单次实验使用 LoRA（rank 64）+ 300 步 + batch 32，属于轻量级训练规模；
- USD 相对 OPSD 的额外开销仅为每 batch $O(T)$ 标量计算与两个标量更新，无额外前向传播；
- 相比 GRPO（500 步、8 rollout/问题、最长 16k token），USD 采样预算显著更小（1 rollout/问题、最长 1024 token、300 步）。

| 实验类别 | 数量 / 内容 |
|---------|------------|
| 主实验 | 3 模型规模 × 3 基准 = 9 单元格，对比 6 个方法 |
| 消融 | 逐轴消融（仅 PI / 仅 token / 双轴）× 3 规模 = 12 单元格 |

| 单调性验证 | Qwen3-1.7B 实测 $g_t, d_t$ 关于 $\beta$ 的单调性 |

**评价**：实验设计较为规范，覆盖多规模、多基准、多对比方法，含消融与敏感性分析。但仍存在以下客观性局限（见 §8）。

## 6. 主要结论与发现

1. **统一框架有效**：USD 将 9 单元格平均 Avg@12 从 OPSD 的 56.4 提升到 58.7（+2.3 分），在每个规模上均稳定提升约 2 分。
2. **双轴互补**：消融显示两个轴各自独立使用均有增益，但联合使用始终最优（Qwen3-1.7B: 41.5 → 42.4 / 43.3 / 44.0；4B: 62.2 → 63.0 / 62.6 / 64.5；8B: 65.5 → 67.0 / 66.7 / 67.6）。
3. **轴重要性随规模变化**：1.7B 上 token 选择贡献更大，4B/8B 上 PI 调节贡献更大——这表明手工固定权重会失校，耦合公式（共享预算）更稳健。
4. **训练动态协同演化**：初始阶段 $\beta$ 上升、$\lambda \approx 0$；一旦 $\text{load}$ 触及预算 $\varepsilon$，$\lambda$ 激活收紧 token 选择并使 $\beta$ 回落，两者共同维持 $\text{load}$ 接近 $\varepsilon$。
5. **优于 GRPO**：在三个规模上 USD 均超 GRPO（+4.7 / +2.0 / +1.5 平均分），且采样预算显著更小。
6. **$\varepsilon$ 取中间值最优**（$\varepsilon=0.3$）：过紧会"饿死"学生，过松则约束几乎不激活、方法退化为近似均匀加权。

---

## 7. 优点

- **理论贡献扎实**：通过拉格朗日分析揭示"单一对偶变量同时控制两轴"的结构性结论，给出 Proposition 1 的单调收敛性证明。
- **方法轻量实用**：仅 2 个标量更新与 1 个 $O(T)$ 遍历，零额外前向，易于工程落地。
- **视角新颖**：将 OPSD 重新理解为"容量匹配问题"，统一了两条原本独立的研究路线。
- **实验相对充分**：含多规模、多基准、消融、超参敏感性、训练动态可视化。
- **超参稳健**：$\varepsilon, \tau, \eta_\lambda, \eta_\beta$ 等固定跨规模使用，未做规模专属调参。

---

## 8. 不足与局限

1. **基准覆盖面较窄**：仅在 3 个数学竞赛基准（AIME24/25、HMMT25）评测，未覆盖代码、Agent、通用 NLP 任务；论文自称 OPSD 在代码与 Agent 基准同样有效，但 USD 未验证。
2. **对比基线数量有限**：仅 2 个同期 OPSD 变体（TIP、PAINT），未与 Trust Region On-Policy Distillation、Entropy-Aware OPD、Prune-OPD 等近期工作直接对比。
3. **PI 暴露实现较粗糙**：PI 强度 $\beta$ 实例化为"参考解前 $\lfloor \beta L\rfloor$ 字符"，这种方式未必适用于所有 PI 类型（如环境反馈、真值推理链），泛化性受限。
4. **超参敏感性探索有限**：仅对 $\varepsilon$ 做扫描，未对 $\tau, \eta_\lambda, \eta_\beta, \beta_{\text{init}}$ 进行敏感性或稳定性分析。
5. **单调性假设依赖**：Proposition 1 建立在"$\text{load}(\beta), G(\beta)$ 关于 $\beta$ 严格递增"假设上（论文在 Qwen3-1.7B 上验证），但该假设可能因 PI 类型或模型规模不同而失效，未讨论失败情形。
6. **资源信息缺失**：未报告 GPU 型号/数量/训练时长，第三方难以复现成本评估。
7. **种子与统计显著性**：未说明是否多种子平均、未报告置信区间，单次实验的统计波动可能掩盖真实差距。
8. **方法局限**：当前框架假设每 token 的 PI 暴露是连续的；离散/结构化 PI（如多段参考解）需要重新设计。
