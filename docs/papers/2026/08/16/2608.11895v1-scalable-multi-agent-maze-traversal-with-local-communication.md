## 摘要
洞穴网络、管道系统以及类似的迷宫类环境，为在通信受限的未知场景中进行多智能体导航带来了巨大挑战。我们提出了一种分布式算法，使智能体能够协作遍历一个未知的、可能包含环路的图。智能体在指定起始节点依次进入，其任务是定位并到达一个未公开的目标节点，同时避免相互碰撞。它们通过基于主从关系与领导者切换的局部通信进行协调。在任意时刻，仅由其中一个智能体执行探索任务，该智能体运行一个单智能体迷宫求解器。我们证明了该算法是完备的，其完成时间在智能体数量上渐近等价于具有完整知识的最优策略的完成时间，并推导了其时间与空间复杂度。在多达 625 个智能体的仿真中，结果表明随着智能体数量的增加，平均燃料消耗总和呈下降趋势，并证明所提方法优于一种朴素基线——在该基线中所有智能体独立执行单智能体求解器。

## Abstract
Cave networks, pipe systems, and similar maze-like environments pose significant challenges for multi-agent navigation in unknown settings with limited communication. We propose a distributed algorithm that enables agents to collectively traverse an unknown, possibly cyclic graph. Agents enter sequentially at a designated start node and are tasked to localize and reach an undisclosed goal while avoiding collisions. They coordinate via local communication using leader-follower relationships and leader switching. At any moment in time, exploration is performed by only one of the agents, which runs a single-agent maze solver. We prove that the algorithm is complete, that its makespan is asymptotically equivalent (in the number of agents) to that of an optimal full-knowledge strategy, and derive its time and space complexity. Simulations with up to $625$ agents show a decreasing average sum-of-fuels as the number of agents increases and demonstrate that the proposed approach outperforms a naïve baseline in which all agents independently execute the single-agent solver.

## 2. 方法论

### 2.1 核心思想
- **单领导者探索 + 跟随者链**：任意时刻仅由一个"头"智能体运行单智能体迷宫求解器（如 Trémaux、BFS、随机游走）执行探索；其余活跃智能体形成以头为根的"领导者-跟随者"内向树（in-tree），通过局部通信跟随头前进。
- **避碰机制**：当移动会产生冲突时，头将"头"角色转移给占位智能体；非头智能体通过竞争上一节点的占用权，由确定性 `Selector` 算子（按预定义总序 $\leq_A$ 选最小 ID）决定唯一获胜者。
- **通信模型**：仅允许**两跳距离**且必须经由空节点的局部通信（建模视线/管道内信号传播），定义通信图 $G_{\text{com}}$。
- **三种广播消息**：状态消息（ID、是否到达目标、领导者指针）、竞争消息（是否本步要移动）、头消息（头的移动意图与下一任头）。

### 2.2 问题形式化（关键定义）

- 迷宫图 $G=(V,E)$，起始节点 $s$（叶子）、目标节点 $g$，$n$ 个智能体集合 $A=\{1,\dots,n\}$。
- 顶点点冲突：$\exists i,j\in A_{\text{active}}[k], i\neq j: v_i[k]=v_j[k]\neq g$。
- 跟随冲突：$\exists i,j\in A_{\text{active}}[k], i\neq j: v_i[k]=v_{j}[k+1]\neq g$。
- 通信可达集合：$E_{\text{com}} = \{\{i,j\}\subseteq A_{\text{active}} \mid i\neq j \wedge (v_i=v_j \vee \{v_i,v_j\}\in E \vee N^{\text{unoc}}_i \cap N^{\text{unoc}}_j \neq \emptyset)\}$。
- 有向广播覆盖集：$B_i := \bigcup_{u\in N_i} U_i[u]$，其中 $U_i[u] = \{w\in V \mid w=u \vee (u\in N^{\text{unoc}}_i \wedge \{u,w\}\in E)\}$。
- **两类评价指标**：
  - 完成时间 $\text{makespan} = \min\{k\in\mathbb{N}_0 \mid \forall a\in A: v_a[k]=g\}$；
  - 平均燃料总和 $\frac{1}{n}\sum_{i=1}^n \pi_i$（$\pi_i$ 为智能体 $i$ 走过的边数）。

### 2.3 算法流程（核心伪代码）

**Algorithm 1（主循环）**：
- 初始化（$v\leftarrow s$, $v_{\text{prev}}\leftarrow s$, $L\leftarrow \text{nil}$）。
- 每步同步感知 + 消息交换（状态/竞争/头消息）。
- **头决策**：若 $L=\text{nil}$，则运行 `SingleAgentMazeSolver()` 得 $D_{\text{solver}}$；若 $D_{\text{solver}}$ 被占，则将头转给占位者；否则沿 $\{v, D_{\text{solver}}\}$ 发送有向广播并移动。
- **跟随者决策**：调用 `ResolveConflict()` 决定目标节点 $D$ 与新领导者 $L$。
- **同步移动**：所有智能体同步移动到 $D$。
- **后置消息**：移动后沿 $\{v, v_{\text{prev}}\}$ 发送有向广播 + 状态广播。

**Algorithm 2（冲突解决 ResolveConflict）**：
- 若头在通信范围内：等待头消息；若被选为新头，则广播"不竞争"并设 $L=\text{nil}$；否则保持现状或把头设为新领导者。
- 若目标 $g$ 相邻：直接向 $g$ 移动，保持当前 $L$。
- 若领导者位于相邻节点：保持原领导者，停留。
- 否则：参与对 $v_{\text{prev}}^L$ 的竞争；通过 `Selector` 选唯一获胜者；胜者前进并保持 $L$，败者停留并把胜者设为新 $L$。

### 2.4 理论结果（核心定理）

- **引理 1**：任意时刻恰有一个头智能体；头在 $k\le k_w$ 时与单智能体求解器轨迹完全一致，$k>k_w$ 时停留在 $g$。
- **引理 2**：任何非起始节点的首次访问必由头完成；所有到达 $g$ 的智能体必经过头所访问的同一邻节点 $u$。
- **引理 3**：对任何 $v\in V\setminus\{g\}$，$v$ 上同时刻至多一个活跃智能体；冲突竞争者共享同一领导者。
- **引理 4**：任意非头智能体的领导者必处于其通信范围内。
- **引理 5**：领导者有向图 $T_L[k]$ 始终是以当前头为根的内向树。
- **定理 1（完成时间上界）**：若单智能体求解器在 $k_g-1$ 步首次到达邻目标节点，则 $n$ 个智能体在至多 $k_g + 2(n-1)$ 步内全部到达目标：
$$M_{\text{Algo}}(n) \leq k_g + 2(n-1).$$
- **定理 2（渐近最优性）**：与全知识策略的完成时间之比
$$R(n) = \frac{M_{\text{Algo}}(n)}{M_{\text{FK}}(n)}$$
满足 $R(n)=1$ 或严格递减且 $\lim_{n\to\infty} R(n)=1$；即
$$\lim_{n\to\infty}\frac{k_g+2(n-1)}{k_{\text{FK}}+2(n-1)} = 1.$$

### 2.5 复杂度

- **空间**：$O(d\cdot\min(n, d^2))$，结合具体求解器（Trémaux: $O(E + d\min(n,d^2))$；BFS: $O(V + d\min(n,d^2))$）。
- **时间**：每步 $O(\min(n,d^2))$；与 Trémaux 合计 $O((E+n)\min(n,d^2))$；与 BFS 合计 $O(((V+E)^2+n)\min(n,d^2))$；随机游走期望 $O((V^3+n)\min(n,d^2))$。

## 3. 实验设计

### 3.1 场景与数据集
- **环境**：方形网格迷宫（grid mazes），尺寸 $l\times l$，$l\in\{5,15,25,35\}$。
- **智能体规模**：$n\in\{1,5,25,125,625\}$。
- **每个组合**：20 个随机生成的迷宫，单次超时 $10^4$ 时间步。

### 3.2 Benchmark
- **求解器对比**：Trémaux 算法、BFS、均匀随机游走。
- **基线对比**：
  - **朴素基线（Naïve）**：所有智能体各自独立运行同一求解器，遇冲突按最小 ID 让行；遇目标环（target-cycle）则交换求解器实例。
  - **全知识策略（Full-Knowledge, FK）**：智能体预先知晓环境，沿最短路径依次出发。
- **评价指标**：makespan、平均 sum-of-fuels（越小越好）。

### 3.3 实验观察
- 朴素 BFS 在 $n=625$ 时 20 次全部超时；朴素 Trémaux 在 $n=625$ 时 2 次超时。
- 随机游走在 $l=25$ 与 $l=35$ 上有 10 次超时（其余两种求解器全部成功且无碰撞）。

## 6. 主要结论与发现

- **理论层面**：
  - 算法在一般图上**无碰撞**且**完备**（任意完备的单智能体求解器驱动下，所有智能体有限步内到达目标）。
  - 完成时间上界为 $k_g + 2(n-1)$，与全知识最优策略的渐近比为 1。
- **实证层面**：
  - 平均 sum-of-fuels 随 $n$ 增大而**递减**（更大群体平均代价更低）。
  - makespan 随 $n$ 增长趋于"全知识"基线水平，验证渐近最优性。
  - 在 625 智能体规模下 MAMT 全部成功，而朴素 BFS 全部超时，**显著优于朴素基线**。
  - 求解器选择影响显著：**Trémaux 优于 BFS**（因 BFS 在物理智能体上需回溯到每个访问节点，开销大）；随机游走在大型迷宫中易超时。
- **实践意义**：为管道、矿道等通信受限基础设施的自主巡检提供可扩展的分布式方案。

## 7. 优点

- **理论完备性**：首次为 MAMT 在一般图上给出严格的形式化证明（完备性、makespan 上界、渐近最优），弥补了 [1, 11] 缺乏理论保证的空白。
- **通信模型真实**：限定两跳局部通信 + 仅经空节点传递，比理想全局通信假设更贴近物理部署（管道、洞穴中的视线/射频传播）。
- **即插即用**：算法与底层单智能体求解器解耦，便于替换为 Trémaux/BFS/随机游走或其他完备求解器。
- **可扩展性**：仿真验证至 625 智能体并展现规模化收益（平均燃料递减）。
- **对比全面**：与朴素独立求解、全知识两种基线对比，超时分析揭示了朴素方案在大规模下的失效。
- **代码公开**：附 GitHub 仓库，便于复现。

## 8. 不足与局限

- **顺序探索瓶颈**：任意时刻仅一个智能体（头）真正探索，其余均处于跟随/等待状态，理论加速比为 1（与全知识串行最优同阶），**无法在并行性上突破**。
- **图结构假设**：要求 $s$ 为叶子节点；若起始点非叶子则需构造特殊环境，可能限制实际应用。
- **实验场景单一**：仅方形网格迷宫；未覆盖管道图、不规则几何、3D 洞穴等真实场景；未考虑通信延迟、丢包、感知噪声或定位误差。
- **指标局限**：以 makespan 与 sum-of-fuels 为主，未衡量通信开销、能耗、鲁棒性等实际部署关心的指标。
- **基线对比局限**：朴素基线在 625 智能体下频繁超时，但其失败原因未深入分析（如死锁、目标环策略的效率等）；未与近年 MAPF 分布式方法做直接比较。
- **超参数未消融**：`Selector` 总序、广播半径、消息重发策略等参数未做敏感性实验。
- **统计严谨性**：每组仅 20 次随机种子，未报告方差或置信区间，难以判断小规模（如 $n=1$）曲线差异是否显著。
- **可实现性**：未给出真实机器人实验或硬件在环验证（仅声明未来工作）。
