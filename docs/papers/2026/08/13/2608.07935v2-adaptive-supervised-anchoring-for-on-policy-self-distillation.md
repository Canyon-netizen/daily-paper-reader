## 摘要
在策略自蒸馏（on-policy self-distillation，OPSD）通过从学生模型采样的轨迹中蒸馏冻结教师模型的指导来适配语言模型。然而，其有效性在很大程度上取决于这些轨迹的质量。我们表明，当学生模型生成的 rollout 偏离目标轨迹时，使教师模型以这些偏离目标的前缀为条件，会显著削弱其与任务相关的监督。受控的前缀破坏实验揭示了这一失效模式，我们将其称为“rollout 条件化信号退化”。为解决这一问题，我们提出一个统一的训练框架，将两种互补的监督路径分离开来。第一条路径保留 rollout 条件化分布匹配，为学生模型实际访问的状态提供指导；第二条路径则在规范真值上下文上采用监督式交叉熵，从而避免在错误的 rollout 前缀上强制施加目标 token 所造成的不兼容性。我们利用 token 级的 rollout—目标对齐来动态调节规范上下文锚点的强度：在冷启动阶段强化该锚点，并随着 rollout 质量的提升而逐步减弱。在多个模型规模、两类任务以及通用推理基准上的实验表明，与 OPSD 相比，所提方法在保留通用能力的同时提升了任务习得能力，从而在经验上实现了更有利的可塑性—稳定性权衡。这些发现表明，上下文质量是在策略自蒸馏中的一个核心瓶颈，并证明了将 rollout 条件化指导与规范监督分离的价值。

## Abstract
On-policy self-distillation (OPSD) adapts a language model by distilling guidance from a frozen teacher on trajectories sampled from the student. Its effectiveness, however, depends critically on the quality of those trajectories. We show that when student rollouts drift from target trajectories, conditioning the teacher on off-target prefixes substantially weakens its task-relevant supervision. Controlled prefix-corruption experiments expose this failure mode, which we term rollout-conditioned signal degradation. To address this problem, we propose a unified training framework that separates two complementary supervision pathways. The first retains rollout-conditioned distribution matching, providing guidance on states the student actually visits. The second applies supervised cross-entropy on canonical ground-truth contexts, avoiding the incompatibility of imposing target tokens on erroneous rollout prefixes. Token-level rollout-target alignment is used to adapt the strength of the canonical-context anchor, emphasizing it during cold start and relaxing it as rollout quality improves. Experiments across multiple model scales, two task families, and general-reasoning benchmarks show that the proposed approach improves task acquisition over OPSD while preserving general capabilities, resulting in a more favorable empirical plasticity-stability trade-off. These findings identify context quality as a central bottleneck in on-policy self-distillation and demonstrate the value of separating rollout-conditioned guidance from canonical supervision.

## 1. 核心问题与研究动机

### 1.1 背景
在策略自蒸馏（On-Policy Self-Distillation, OPSD）是一种将"冻结的特权教师"与"同一基座模型的学生"相结合的微调范式：教师观察带标准答案的特权输入 $x^{PI} = [x; y^\star]$，而学生仅观察问题 $x$ 并产生 on-policy rollout $\hat{y} \sim p_S(\cdot|x)$。OPSD 通过最小化 token 级分布散度来对学生进行稠密监督：

$$L_{\text{OPSD}} = \frac{1}{|\hat{y}|}\sum_{t=1}^{|\hat{y}|} D\!\left(p_T(\cdot|x^{PI}, \hat{y}_{<t}) \,\|\, p_S(\cdot|x, \hat{y}_{<t})\right) \tag{1}$$

### 1.2 关键失效模式
论文识别出一种**上下文相关的监督失败现象**——**rollout 条件化信号退化**（rollout-conditioned signal degradation）：

- 在 Qwen3-4B 上，固定教师在**规范前缀**下对 SimpleMath 任务可达到 $80.4\%$ 的目标 token 准确率，但在学生**冷启动 rollout** 上骤降至 $6.5\%$（保留比仅 $8.1\%$）。
- 受控前缀破坏实验（替换比例 $\epsilon \in [0,1]$）显示，teacher 目标 token 准确率随 $\epsilon$ 单调下降，至 $\epsilon = 1$ 时仅剩 $3.8\%$。
- 自然 rollout 按"首次偏离位置"分箱后同样验证：早期偏离的 rollout 对应 $20.5\%$ teacher 准确率，近乎正确的 rollout 则对应 $82.7\%$。

### 1.3 直觉修复为何失败
两种朴素组合均不充分：

1. **Naive OPSD + CE**：将真值 token $y^\star_t$ 直接放在 rollout 前缀 $\hat{y}_{<t}$ 下计算交叉熵，会引入**目标—上下文语义失配**（在已偏离的 rollout 前缀下，真值 token 不再是合适的下一 token）。
2. **SFT → OPSD 两阶段**：人为硬划分训练阶段，依赖手工切换点，且切换后失去 rollout 条件化引导。

由此提出**上下文有效性原则**（context-validity principle）：每个监督目标应在其语义仍然成立的条件上下文中被评估。

## 2. 方法论：监督蒸馏引导（Supervised Distillation Steering, SDS）

### 2.1 核心思想
SDS 将两种监督在**前向层面分离**，使其各自处于"语义有效的条件上下文"中：

- **蒸馏分支**：在学生 rollout 上下文 $[x;\hat{y}]$ 上，对齐学生与冻结特权教师；
- **锚定分支**：在规范真值上下文 $[x;y^\star]$ 上，对学生做 teacher-forcing 交叉熵。

两条分支共享可训练参数增量 $\Delta\theta$，但条件前缀严格分离。

### 2.2 目标函数

$$L_{\text{SDS}} = \frac{1}{|\hat{y}|}\sum_{t=1}^{|\hat{y}|} D\!\left(p_T(\cdot|x^{PI},\hat{y}_{<t}) \,\|\, p_S(\cdot|x,\hat{y}_{<t})\right) + \alpha\, w_{\text{anchor}}\, L_{\text{anchor}} \tag{7}$$

其中：

$$L_{\text{anchor}} = -\frac{1}{|y^\star|}\sum_{t=1}^{|y^\star|}\log p_S\!\left(y^\star_t \,\middle|\, x, y^\star_{<t}\right) \tag{6}$$

散度 $D$ 实例化为广义 Jensen-Shannon 散度：

$$JSD_\beta(p_T\|p_S) = \beta\, D_{\text{KL}}(p_T\|m_\beta) + (1-\beta)\, D_{\text{KL}}(p_S\|m_\beta), \quad m_\beta = \beta p_T + (1-\beta)p_S \tag{8}$$

### 2.3 自适应锚定权重

$$w_{\text{anchor}} = 1 - \text{sim}(\hat{y}, y^\star)$$

其中 $\text{sim}(\cdot,\cdot)$ 为 token 级序列相似度（任意渐变相似度均可）。当学生 rollout 与真值严重偏离时，$w_{\text{anchor}}$ 自动趋近于 $1$，强化锚定；随训练推进、rollout 质量改善，$w_{\text{anchor}}$ 自动下降；且 $w_{\text{anchor}}$ 不衰减至零，而是稳定在非零水平以持续纠正后续偏差，形成负反馈闭环，避免人工设定切换点。

### 2.4 关键设计决策
- **完全上下文分离**而非部分方案（如选择性 mask、混合前缀）：因为 teacher 准确率随前缀污染率单调下降，混入 rollout 成分的上下文仍会携带退化信号。
- **超参数 $\alpha$** 作为"最大锚定强度"的可解释旋钮：$\alpha=0.1$ 偏向能力保留，$\alpha=0.5$ 偏向任务习得，$\alpha=0.2$ 在 Qwen3-4B 上取得最佳折中。

- **内生调度优于人工两阶段**：SFT → OPSD 在两项指标上均劣于 SDS。

### 6.3 机制性发现
- **"在哪里计算监督"比"施加多少监督"更关键**：SDS 与 Naive OPSD+CE 使用相同真值信号与损失函数，结果差异仅源自上下文是否有效。
- **上下文有效性应作为 on-policy / off-policy 监督组合的设计约束**，与权重、调度并列。

---

## 7. 优点与亮点

- **问题诊断严谨**：通过自然 rollout 测量 + 受控前缀破坏 + 真实 rollout 分箱三组互补实验，将"信号退化"从学生策略差中解耦出来。
- **设计原则提炼**："context-validity principle"简洁有力，且具有推广意义。
- **方法简洁实用**：仅增加一次独立学生前向传播，相对 OPSD 增加 30–40% 开销；不依赖额外路由、冻结机制或保留数据集；与 LoRA 自然兼容。
- **负反馈自适应权重**自动实现"冷启动强锚定 → 训练后期放松"的过渡，无需人工切换点，并保留非零锚定以持续纠偏。
- **多规模、多任务、可视化充分**：3 模型 × 2 任务的主表、Pareto 图、训练动力学图共同支撑论点。
- **消融结构清晰**：逐一隔离"上下文分离"、"自适应权重"、"内生调度"三个设计要素。

---

## 8. 不足与局限

- **模型族单一**：所有实验均在 Qwen3 上完成，跨族（如 Llama、DeepSeek）泛化未验证。
- **域任务覆盖窄**：仅 ToolAlpaca 与 SimpleMath 两类，未涵盖更广泛的指令遵循、代码、对话等场景。
- **受控破坏的代表性有限**：随机均匀替换 token 的合成破坏无法完全复现真实学生 rollout 中**结构化、历史依赖**的错误模式。
- **算力信息缺失**：未公开 GPU 型号/数量/训练时长，难以独立复现成本估算。
- **附录细节依赖**：相似度度量对比、跨规模能力保留、完整超参数均置于 Appendix，主文未充分展开。
- **$\alpha$ 需调参**：尽管 SDS 减少了人工切换点，但 $\alpha$ 仍是影响可塑性—稳定性权衡的关键超参数，需网格搜索。
- **未与最新 RL 后训练方法充分对比**：未与 DPO、RLHF、过程奖励模型等主流方案在同一基准上做横向比较。
