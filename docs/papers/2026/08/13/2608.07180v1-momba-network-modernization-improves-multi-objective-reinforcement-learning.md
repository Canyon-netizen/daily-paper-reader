## 摘要
深度强化学习（RL）的最新进展表明，在不改变底层算法的情况下改进神经网络架构能够显著提升样本效率与渐近性能。相比之下，多目标强化学习（MORL）旨在发现一组在相互冲突的目标之间权衡折中的策略，其研究主要聚焦于算法层面的创新，而对架构方面的探索仍然不足。由于不同权衡下的最优策略与价值函数可能差异显著，但MORL算法通常仅使用以权衡为条件的简单前馈网络来表示它们。这便引出一个问题：更具表达力的函数逼近器能否进一步提升算法性能。在本文中，我们将神经网络设计的最新进展进行整合：（i）观测与特征归一化，（ii）权重归一化，以及（iii）基于熵正则化MORL算法对分布式回报进行建模。在标准连续控制基准上的实证结果表明，这些改进在不大幅改动底层算法的前提下，显著提升了所生成的解集质量。

## Abstract
Recent advances in deep reinforcement learning (RL) have shown that improving neural network architectures can yield substantial gains in sample efficiency and asymptotic performance without altering the underlying algorithms. In contrast, work on multi-objective reinforcement learning (MORL), which aims to discover a set of policies that balance trade-offs among conflicting objectives, has predominantly focused on algorithmic innovations, leaving the area of architectures underexplored. While the optimal policies and value functions can differ significantly depending on the trade-offs, MORL algorithms commonly represent them with simple feedforward networks conditioned on the trade-off. This raises the question of whether the performance of the algorithms could be improved with more expressive function approximators. In this paper, we integrate recent advances in neural network design: (i) observation and feature normalization, (ii) weight normalization, and (iii) modeling of distributional returns with an entropy-regularized MORL algorithm. The empirical results across standard continuous control benchmarks demonstrate that these changes substantially improve the quality of the produced solution sets without requiring major changes to the underlying algorithm.

多目标强化学习（MORL）旨在发现一组能平衡多个相互冲突目标的策略（Pareto 前沿）。现有研究存在两个明显空白：

- **架构层面被忽视**：单目标深度 RL（如 SAC、DroQ、Simba、SimbaV2 等）已证明改进网络架构（归一化、分布式价值函数）能显著提升样本效率与渐近性能，但 MORL 普遍仍使用以偏好 $\omega$ 为条件的简单前馈 MLP。

传统 C51 适用于标量回报，不能直接处理向量回报 $R \in \mathbb{R}^d$。作者观察到策略优化只需标量化的 Q 值 $\omega^T Q(s,a,\omega)$，因此提出**直接学习标量化回报的分布**：

$$L_Z(\theta) = \mathbb{E}_{(s,a,r,s',\omega)\sim D} H\!\left(\hat{Z}(\omega^T r, s'),\ Z_\theta(s,a,\omega)\right)$$

策略更新仍最大化：
$$\mathbb{E}_{a\sim\pi_\phi}\!\left[\mathbb{E}[Z_\theta(s,a,\omega)]\right] + \alpha H(\pi_\phi(\cdot|s,\omega))$$

奖励按各分量最大值归一化：$\tilde{R}_i^t = v_{\max}\cdot R_i^t / G_{\max}^{i,t}$。

## 6. 主要结论与发现

- **性能显著提升**：Momba 在聚合 HV 上比次优 PGMORL 提升约 **35%**，比基础算法 CAPQL 提升约 **132%**；EUM 提升 16% 与 35%。
- **样本效率**：在 Ant 与 Humanoid 上，分别仅需 100k 和 200k 步即可达到 PGMORL 在 4.8M/12M 步的最终性能。
- **匹敌/超越 GPI-LS**：在相近 UTD 比率下，击败拥有最先进样本效率的 GPI-LS，且仅使用静态偏好采样。
- **分布式 Critic 是关键**：在控制参数规模后，MLP+CE 即可匹配或超越 Simba+MSE；Simba+CE 显著最优。参数量的增加并非性能提升的根源。
- **归一化贡献**：Shapley 值显示 ON 贡献最大（约 54.8%）、FN 约 24.8%、WN 约 20.4%，三者协同生效。
- **向量 vs 标量化分布式 Critic**：性能几乎一致，标量化版本同样适用于需要向量返回值的 Envelope 类算法。

## 7. 优点

- **思路清晰、动机充分**：首次明确指出 MORL 中架构现代化这一被忽视的研究方向。
- **最小算法改动 + 最大收益**：仅调整偏好采样频率与 Critic 损失，便带来大幅提升，强调架构层面的红利。
- **实证充分**：跨 7 任务、4 基线、10 种子的对比，并附完整消融与 Shapley 分解。
- **覆盖度好**：在多数环境中 95% SBCI 与次优方法不重叠，结论稳健。
- **方法贡献可迁移**：向量 Critic 的讨论表明可与 Envelope 类算法结合；标量化分布式 Critic 可拓展至其他线性标量化场景。
- **Pareto 前沿可视化**：定性展示了 Momba 解集的均匀性与覆盖度。

## 8. 不足与局限

- **标量化假设限制**：仅讨论线性标量化 $f_\omega(r,\omega) = \omega^T r$。非线性或学习标量化下 Bellman 误差不再成立，方法适用性受限。
- **任务覆盖偏窄**：仅限连续控制（2 目标为主，仅 Hopper-v3 为 3 目标），未覆盖离散状态/动作空间；目标维度扩展性未知。
- **算力开销更大**：SimbaV2 比传统 MLP 更复杂，参数数（~2.5M）显著高于 CAPQL（~258k），尽管实验表明性能提升并非单纯源于参数量，但墙钟时间会增加。
- **基线实现偏差**：DPMORL 性能低于原论文，作者未能完全复现；GPI-LS 因计算昂贵仅训练 200k 步，可能影响对比公平性。
- **解集多样性评估缺失**：HV/EUM 无法直接衡量多样性与均匀性，作者依赖可视化补充；不擅长检测聚集型前沿。
- **偏好采样策略简单**：使用静态均匀分布，可能进一步限制在更复杂 Pareto 形状场景下的表现。
- **未做大规模超参搜索**：承认存在通过超参调优进一步提升的可能性。
