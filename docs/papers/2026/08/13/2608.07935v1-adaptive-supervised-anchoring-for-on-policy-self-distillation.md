## 摘要
同策略自蒸馏（OPSD）通过从冻结教师模型中提炼指导信息，对学生模型在采样轨迹上的行为进行蒸馏，从而实现语言模型适配。然而，其效果高度依赖于这些轨迹的质量。我们表明，当学生模型生成的 rollout 偏离目标轨迹时，让教师模型以偏离目标的上下文前缀为条件，会显著削弱其与任务相关的监督信号。受控的前缀损坏实验揭示了这一失效模式，我们将其称为 rollout 条件化信号退化。为解决这一问题，我们提出一个统一的训练框架，将两种互补的监督路径分离开来。第一条路径保留基于 rollout 条件分布的匹配，为学生模型实际访问的状态提供指导；第二条路径则在规范的标准真值上下文上应用监督交叉熵，从而避免将目标词元强加于错误的 rollout 前缀所带来的不兼容性。该方法利用词元级 rollout—目标对齐，自适应调整标准上下文锚点的强度：在冷启动阶段强化该锚点，并随着 rollout 质量的提升而逐渐放松。在多种模型规模、两类任务以及通用推理基准上的实验表明，与 OPSD 相比，所提出的方法能够改善任务习得能力，同时保持通用能力，从而获得更有利的经验可塑性—稳定性权衡。这些发现指出，上下文质量是同策略自蒸馏中的关键瓶颈，并证明了将基于 rollout 条件化的指导与规范监督相分离的价值。

## Abstract
On-policy self-distillation (OPSD) adapts a language model by distilling guidance from a frozen teacher on trajectories sampled from the student. Its effectiveness, however, depends critically on the quality of those trajectories. We show that when student rollouts drift from target trajectories, conditioning the teacher on off-target prefixes substantially weakens its task-relevant supervision. Controlled prefix-corruption experiments expose this failure mode, which we term rollout-conditioned signal degradation. To address this problem, we propose a unified training framework that separates two complementary supervision pathways. The first retains rollout-conditioned distribution matching, providing guidance on states the student actually visits. The second applies supervised cross-entropy on canonical ground-truth contexts, avoiding the incompatibility of imposing target tokens on erroneous rollout prefixes. Token-level rollout-target alignment is used to adapt the strength of the canonical-context anchor, emphasizing it during cold start and relaxing it as rollout quality improves. Experiments across multiple model scales, two task families, and general-reasoning benchmarks show that the proposed approach improves task acquisition over OPSD while preserving general capabilities, resulting in a more favorable empirical plasticity-stability trade-off. These findings identify context quality as a central bottleneck in on-policy self-distillation and demonstrate the value of separating rollout-conditioned guidance from canonical supervision.

## 一、核心问题与研究动机

**问题背景**：同策略自蒸馏（On-Policy Self-Distillation, OPSD）通过让冻结的特权教师（teaching with privileged context，如标准答案或验证推理过程）对学生自采样轨迹进行分布匹配，从而实现任务适配。该方法在不损失通用能力方面优于 SFT，但隐含假设——特权知识在学生前缀下仍可访问——并不总是成立。

**关键发现**：当学生 rollout 偏离目标轨迹时（这在冷启动阶段尤其常见），教师在错误前缀上的目标 token 准确率急剧下降。作者将此现象命名为 **rollout-conditioned signal degradation**：

- Qwen3-4B SimpleMath：教师在规范前缀上达到 80.4% 目标 token 准确率，但在学生自然 rollout 前缀上仅 6.5%。
- 控制前缀损坏实验：将真值前缀以比例 $\epsilon \in [0,1]$ 随机替换为随机 token，准确率从 80.4% ($\epsilon=0$) 单调下降至 3.8% ($\epsilon=1$)。
- 真实 rollout 分桶：按首个错误位置分桶，目标 token 准确率从 20.5%（早期偏离）单调上升至 82.7%（近乎正确）。

**深层矛盾（supervision–context incompatibility）**：
- Rollout 条件分布匹配要求学生生成的前缀以维持 on-policy 状态覆盖；
- 真值监督要求规范前缀以维持目标语义有效性。
- 直接在错误前缀上施加交叉熵会出现 target–context mismatch；而两阶段 SFT→OPSD 切换则需要手工设定切换点。

**核心原则**：作者提出 **context-validity principle**——每个监督目标应在其语义有效的前缀下评估。

## 二、方法论

### 2.1 框架概览

SDS（Supervised Distillation Steering）将训练目标分解为两条互补路径：

$$\mathcal{L}_{\text{SDS}} = \underbrace{\frac{1}{|\hat{y}|}\sum_{t=1}^{|\hat{y}|} D\!\left(p_T(\cdot \mid x^{\text{PI}}, \hat{y}_{<t}) \,\|\, p_S(\cdot \mid x, \hat{y}_{<t})\right)}_{\text{Rollout 条件蒸馏}} + \underbrace{\alpha\, w_{\text{anchor}}\cdot \mathcal{L}_{\text{anchor}}}_{\text{规范上下文锚定}}$$

其中：
- 第一项：使用广义 Jensen–Shannon 散度 $JSD_\beta(p_T \| p_S)$，在学生 rollout 前缀 $\hat{y}_{<t}$ 上匹配教师分布，保持 on-policy 状态覆盖。
- 第二项：在独立的前向传播中，于规范前缀 $y^*_{<t}$ 上计算教师强制交叉熵：
$$\mathcal{L}_{\text{anchor}} = -\frac{1}{|y^*|}\sum_{t=1}^{|y^*|}\log p_S(y^*_t \mid x, y^*_{<t})$$

两条路径共享同一组可训练参数 $\Delta\theta$，但条件上下文严格分离。

### 2.2 自适应锚定权重

锚定权重基于 rollout 与目标之间的 token 级相似度在线计算：

$$w_{\text{anchor}} = 1 - \text{sim}(\hat{y}, y^*)$$

默认采用 **Token-level F1**（基于唯一 token 集合的精确率/召回率调和均值）。当 rollout 与目标偏离越大，$w_{\text{anchor}}$ 越大；随对齐改善而减小。这实现了闭环负反馈机制：早期 rollout 偏离严重→锚定强→教师强制监督加速收敛；后期 rollout 改善→锚定松弛→on-policy 探索主导。

### 2.3 设计理由

- **全分离而非部分分离**：如选择性 mask 或混合前缀仍保留 rollout 成分，会携带退化信号。
- **避免手工切换**：$w_{\text{anchor}}$ 随训练动态自动调整，无需预设 SFT→OPSD 切换点。
- **超参数 $\alpha$**：控制锚定项最大贡献，作为可塑性–稳定性权衡的可解释旋钮。

- **AIME 2024**（30 题，采样 8 次，Avg@8 / Pass@8 / Maj@8）
- **MATH-500**（500 题，采样 8 次）
- **ARC-Challenge**（科学推理，精度 + 格式合规率）

### 3.3 对比方法

主要基线：
- **SFT**：标准监督微调
- **GRPO**：组相对策略优化（DeepSeekMath）
- **OPSD**：原始同策略自蒸馏
- **SDS**（本文方法）

消融变体（Qwen3-4B SimpleMath）：
- Naive OPSD+CE（CE 直接施加于 rollout 前缀）
- Isolated SFT, $w=1$ / $w=0.5$（固定锚定权重）
- SFT→OPSD 两阶段手工切换
- $\alpha=0.1$ / $\alpha=0.5$（锚定强度扫描）

距离度量消融：Token F1 / Exact Match / ROUGE-L F1 / Token Edit Distance。

## 五、实验数量与充分性

**实验规模较大**，涵盖：
- **3 个模型规模** × **2 个任务** = 6 个主实验配置；

**公平性**：所有方法共用相同的 LoRA 与优化器超参数；SDS 与 OPSD 共用相同的教师（base model，LoRA disabled），从而隔离训练目标效应。

- ✅ 跨规模验证充分；消融逻辑清晰（逐项分离 context 分离 / 自适应权重 / 内生调度三个设计选择）。

## 六、主要结论与发现

1. **Rollout 条件化信号退化是真实存在的失败模式**，而非学生策略弱的副产物——控制实验与真实 rollout 分桶均证实了教师信号与前缀质量的因果关系。

2. **SDS 在任务习得上显著优于 OPSD**，尤其在 SimpleMath 上：
   - Qwen3-4B SimpleMath：SDS 62.43% vs OPSD 23.23% vs SFT 56.43%。
   - Qwen3-8B SimpleMath：SDS 56.97% vs OPSD 10.33% vs SFT 55.57%。

3. **SDS 显著优于 SFT 的通用能力保留**：
   - Qwen3-4B AIME24 Avg@8：SDS 67.98% vs SFT 38.33%；ARC-Challenge：SDS 87.75% vs SFT 66.13%。
   - Qwen3-1.7B 格式合规率：SDS 96.2% vs SFT 53.8%。

4. **可塑性–稳定性权衡最优**：在 Pareto 曲线上，SDS 占据 SFT（任务强/能力崩溃）与 OPSD（能力保留/任务弱）之间的最优位置。

5. **Naive OPSD+CE 几乎完全失败**（AIME24 仅 3.33%），证明 context 有效性是真正瓶颈，而非监督数量。

6. **自适应权重闭环机制有效**：早期 $w_{\text{anchor}}$ 接近 1，后期稳定在非零水平并随 rollout 质量波动，无须人工切换。

7. **Token F1 是稳健的默认距离度量**：与 ROUGE-L F1、Token Edit Distance 性能接近（均 62.4%），Exact Match 较差（56.5%，因乘法操作上仅 3.6%）。

## 七、优点与亮点

- **新颖的诊断框架**：通过三个递进的研究问题（信号是否有效 → 为何退化 → 朴素修补是否够）系统化揭示 OPSD 失败模式。
- **清晰的"上下文有效性"原则**：明确将"目标在哪一前缀下评估"提升为首要设计约束，并以此推导 SDS 架构。
- **内生调度优于手工调度**：闭环负反馈机制避免了 SFT→OPSD 切换点选择问题。
- **充分的消融隔离**：context 分离 / 自适应权重 / 内生调度三个组件被分别独立验证。
- **完整的训练动态分析**：图 4 显示 $w_{\text{anchor}}$、序列相似度、OPSD 损失的协同演变，附录还提供了 rollout 上下文教师准确度的训练轨迹。
- **跨规模一致性**：在 1.7B/4B/8B 三种规模上均观察到 SDS 的优势，证明方法的规模无关性。
- **距离度量鲁棒性**：对相似度函数选择不敏感（分级度量均有效，仅二进制 Exact Match 失效），降低工程调参负担。
- **附加计算开销可控**：每步仅增加一次学生前向传播，相对单次 OPSD 步骤约 30–40% 开销，且避免了独立 SFT 预训练阶段。

---

## 八、不足与局限

1. **模型家族覆盖单一**：仅在 Qwen3 系列验证，未涵盖 Llama、Mistral、DeepSeek 等其他开源家族，可能存在家族特异性偏差。

2. **任务覆盖有限**：仅数学（SimpleMath）与工具调用（ToolAlpaca）两类任务，未涵盖开放式对话、代码生成、安全对齐、长上下文推理等场景。

3. **控制实验的逼真度有限**：随机 token 替换是 tractable 近似，无法复现真实学生错误中的结构化、历史依赖模式（如在错误前提下继续推理、循环错误模式等）。

4. **算力报告不充分**：未明确报告 GPU 数量、总训练时长、碳足迹等，难以评估实际部署成本。

5. **附加前向传播开销**：尽管相对小，但相比纯 OPSD 仍增加 30–40% 步时开销；在大规模训练中可能成为瓶颈。

6. **教师-学生同源的假设**：SDS 实验采用 base model 自身作为教师（self-distillation），与 OPSD 一致；当教师为更强独立模型时，rollout-conditioned signal degradation 的程度与 SDS 收益尚需验证。

7. **α 仍需调参**：虽然 $w_{\text{anchor}}$ 实现了内生调度，但最大锚定强度 $\alpha$ 仍需人工选择（论文建议 0.2 作为平衡点），且对最终权衡敏感。

8. **下游任务格式合规问题**：即便 SDS 显著优于 SFT，在 Qwen3-1.7B 上其 AIME24 Avg@8（37.9%）仍远低于 base model（48.3%），说明对较弱模型的通用能力仍有一定侵蚀。
