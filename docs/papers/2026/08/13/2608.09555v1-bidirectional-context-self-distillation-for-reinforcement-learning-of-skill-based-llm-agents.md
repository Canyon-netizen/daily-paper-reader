## 摘要
外部自然语言技能为大型语言模型（LLM）智能体提供了可复用且可编辑的指导，以解决复杂任务。然而，其有效性不仅取决于技能质量，还取决于策略能否将所提供的指导转化为适当的动作。然而，专门用于提升这种技能利用能力的方法在很大程度上仍未得到充分探索。在实践中，基于技能的智能体通常使用以任务级奖励为中心的强化学习目标进行训练，这种方法提供的监督有限，难以捕捉策略在利用所提供的技能方面的细微差异。我们提出了BCSD（双向上下文自蒸馏），这是一个将自蒸馏与强化学习相结合的训练框架，用于训练LLM智能体更有效地利用外部技能。与先前依赖于单一特权上下文的自蒸馏方法不同，BCSD从两个互补的技能-上下文视角来评估每条轨迹。增强视图引入了更高级别的元技能（Meta-Skill）指导，而简化视图则修剪一般性指导，以突出任务特定的技能。它们互补的token级信号被结合起来重新缩放强化学习的优势函数。在ALFWorld和WebShop上的实验表明，BCSD在不同模型规模下均实现了最强的整体性能，使智能体能够更有效地利用外部技能。消融研究进一步验证了增强视图和简化视图的互补贡献。代码将被发布以确保完全可复现性。

## Abstract
External natural-language skills provide large language model (LLM) agents with reusable and editable guidance for solving complex tasks. Yet their effectiveness depends not only on skill quality, but also on whether the policy can translate the provided guidance into appropriate actions. However, methods specifically designed to improve this skill-utilization ability remain largely underexplored. In practice, skill-based agents are commonly trained with reinforcement learning objectives centered on task-level rewards, which offer limited supervision and struggle to capture subtle differences in how effectively the policy uses the provided skills. We propose BCSD (Bidirectional Context Self-Distillation), a framework that combines self-distillation with reinforcement learning to train LLM agents to use external skills more effectively. Unlike prior self-distillation methods that rely on a single privileged context, BCSD evaluates each trajectory from two complementary skill-context views. The augmented view introduces higher-level Meta-Skill guidance, while the reduced view prunes general guidance to highlight task-specific skills. Their complementary token-level signals are combined to rescale the RL advantage. Experiments on ALFWorld and WebShop demonstrate that BCSD achieves the strongest overall performance across model scales, enabling agents to utilize external skills more effectively. Ablation studies further verify the complementary contributions of the augmented and reduced context views. Code will be released to ensure full reproducibility.

## 二、方法论：BCSD（Bidirectional Context Self-Distillation）

### 2.1 整体框架

BCSD 在保留外部技能作为显式上下文的前提下，将"自蒸馏"从"参数空间"迁移到"上下文空间"——同一策略在不同上下文下充当 teacher 与 student，由此产生可比的 token 级信号，并以**加权方式重新缩放 GRPO 优势函数**。

### 2.2 关键组成

#### (1) 问题设定与基础上下文
- 任务建模为部分可观测决策过程：以基础上下文 $C_0 = (Q, G, S_c)$ 进行采样轨迹，其中 $Q$ 为查询，$G$ 为通用技能，$S_c$ 为任务特定技能。
- 采用 GRPO 计算组内相对优势：
$$A_i^{\text{GRPO}} = \frac{r_i - \mu_r}{\sigma_r + \epsilon}$$

#### (2) Meta-Skill 提取
- **定义**：Meta-Skill $M_c$ 是关于"如何运用技能 $S_c$"的高层策略相关文本指导（**仅用于 teacher 训练，不参与推理**）。
- **提取流程**：将策略在训练期间收集的成功/失败轨迹分别存入 $E_{c,+}^{(k)}$ 与 $E_{c,-}^{(k)}$，由外部冻结 LLM 对比生成：
$$M_c^{(0)} = \text{Extract}_{\text{LLM}}(S_c, E_{c,+}^{(0)}, E_{c,-}^{(0)})$$
$$M_c^{(k+1)} = \text{Extract}_{\text{LLM}}(S_c, M_c^{(k)}, E_{c,+}^{(k)}, E_{c,-}^{(k)})$$
- 每个验证窗口后进行刷新，使 Meta-Skill 与策略的当前行为对齐。

#### (3) 双向上下文构建
- **增强视图**（Augmented）：在 $C_0$ 基础上追加 Meta-Skill：
$$C_1 = (Q, G, S_c, M_c)$$
- **精简视图**（Pruned）：用外部 LLM 修剪 $G$ 中的冗余信息得到 $G_p = \text{Prune}_{\text{LLM}}(G)$，保留 $S_c$ 不变：
$$C_2 = (Q, G_p, S_c)$$

#### (4) Gap-Weighted 优势重缩放
- 对同一已实现 token 序列 $y_i$，在 $C_0, C_1, C_2$ 三种上下文下重新计算 log-prob，得到两个 token 级 gap：
$$\Delta_{i,t}^{\text{aug}} = \log \pi_\theta(y_{i,t} \mid C_1, y_{i,<t}) - \log \pi_\theta(y_{i,t} \mid C_0, y_{i,<t})$$
$$\Delta_{i,t}^{\text{pru}} = \log \pi_\theta(y_{i,t} \mid C_2, y_{i,<t}) - \log \pi_\theta(y_{i,t} \mid C_0, y_{i,<t})$$
- 加权融合：
$$\Delta_{i,t} = \alpha \Delta_{i,t}^{\text{aug}} + (1-\alpha) \Delta_{i,t}^{\text{pru}}$$
- 通过符号一致的方向与指数化构造权重：
$$w_{i,t} = \text{clip}\left(\exp\left(\text{sign}(A_i^{\text{GRPO}}) \Delta_{i,t}\right), 1-c, 1+c\right)$$
- 重缩放优势（保持原方向，仅改变幅值）：
$$A_{i,t}^{\text{BCSD}} = A_i^{\text{GRPO}} \left[(1-\lambda_n) + \lambda_n w_{i,t}\right]$$
- 其中 $\lambda_n \in [0,1]$ 随训练从 $\lambda_0$ 线性衰减为 0，控制蒸馏强度。

#### (5) 策略优化目标
- 采用标准裁剪 GRPO 损失，将 $A_i^{\text{GRPO}}$ 替换为 $A_{i,t}^{\text{BCSD}}$：
$$L_{\text{BCSD}}(\theta) = -\mathbb{E}_{i,t}\left[\min\left(\rho_{i,t}(\theta) A_{i,t}^{\text{BCSD}},\ \text{clip}(\rho_{i,t}(\theta), 1-\epsilon, 1+\epsilon) A_{i,t}^{\text{BCSD}}\right) + \beta L_{\text{KL}}\right]$$
其中 $\rho_{i,t}(\theta) = \pi_\theta(y_{i,t} \mid C_0, y_{i,<t}) / \pi_{\theta_{\text{old}}}(y_{i,t} \mid C_0, y_{i,<t})$。
- 完整流程见 Algorithm 1：每个训练步依次采样、重打分、计算 BCSD 优势、累积证据、定期刷新 Meta-Skill。

### 3.4 实现要点
- 训练 150 步，组大小 $K=8$，每 15 步评估一次。
- $\alpha=0.9$，$\lambda_0=0.1$ 线性衰减至 0，Meta-Skill 每评估窗口刷新。
- 其余设置遵循 RLSD。

## 五、实验数量与充分性

### 5.1 实验充分性
- **主实验**：2 个基准 × 3 个模型 = 6 组主实验，每组报告 6 个子任务细节 + 汇总指标。
- **消融实验**（Qwen2.5-3B）：

  - Meta-Skill 是否更新
- **超参敏感性**：
  - $\lambda_0 \in \{0.05, 0.1, 0.3, 0.5\}$ 的扫描
  - $(\alpha, 1-\alpha) \in \{(0.9,0.1), (0.5,0.5), (0.1,0.9)\}$ 的权重扫描

## 六、主要结论与发现

- **总体性能**：BCSD 在三种模型规模下均取得最强整体性能——
  - Qwen2.5-7B：ALFWorld 83.6（领先 3.1 点），WebShop 成功率 78.1（最优）。
  - Qwen2.5-3B：ALFWorld 82.0（领先 5.4 点），WebShop 成功率 66.4（领先 9.4 点）。
  - Qwen3-1.7B：ALFWorld 46.9（领先 3.9 点），WebShop 得分 76.8（最优）。
- **消融结论**：Meta-Skill 视图贡献最大（去除后 ALFWorld 性能从 82.0 降至 71.1）；Pruned-Skill 视图、$\lambda_n$ 衰减、Meta-Skill 刷新均对性能有非平凡贡献。
- **超参结论**：$\alpha=0.9$（Meta-Skill 主导）>（0.5,0.5）>（0.1,0.9），表明高层 Meta-Skill 指导是主要信号，精简视图为互补参考；$\lambda_0=0.1$ 最佳，过大过小都会降低性能。
- **训练动态**：BCSD 在约 60 步时已显著优于基线（WebShop 成功率约 45% vs. <20%），并保持稳定领先。
- **互补性分析**：两视图的 token 级方向一致性约 47%–53%，表明二者提供**实质性不同**而非冗余的信号。
- **技能利用验证**：去除任务特定技能 $S_c$ 后，BCSD 性能下降更显著（ALFWorld -2.3 / WebShop -7.8），证明其增益真正来自**外部技能利用**而非将任务知识内化进参数。

## 七、优点与亮点

- **视角新颖**：将自蒸馏从"参数空间"迁移到"上下文空间"，提出双视图互补设计，区别于单一特权 teacher 的现有 OPSD。
- **保持可解释性**：**不内化技能到参数**，保留技能的显式性、可编辑性与可迁移性，与业界对 inspectable agent 的需求一致。
- **方向不变性**：优势重缩放保持 GRPO 原方向，避免引入反向偏差，机制清晰。
- **动态刷新**：Meta-Skill 随策略演化而更新，避免静态指导过时。
- **正则化解耦**：$\lambda_n$ 线性衰减使早期密集指导过渡到后期纯奖励驱动，机理合理。
- **实验较全面**：覆盖 3 模型 × 2 基准 + 多角度消融 + 超参敏感性 + 训练动态 + 跨视图一致性 + 技能利用独立性分析。
- **可复现性承诺**：代码将开源。

## 八、不足与局限

- **算力与规模透明度不足**：未披露 GPU 型号、数量、训练时长，缺乏对计算成本的量化评估。
- **模型规模有限**：仅在 1.7B/3B/7B 规模验证，未测试 13B/70B 等更大模型或非 Qwen 家族（如 LLaMA 系列）的迁移性。
- **基准覆盖窄**：仅在 ALFWorld 与 WebShop 两个文本交互基准上验证，缺乏代码生成、工具调用、多模态等其他智能体场景的泛化证据。
- **Meta-Skill 提取依赖外部 LLM**：流程需调用冻结 LLM 生成 $M_c$ 与 $G_p$，引入额外 API 成本、提示工程敏感性，且可能存在提取质量不稳定的问题。
- **策略依赖的指导**：Meta-Skill 由当前策略的成功/失败轨迹驱动，早期策略噪声可能误导 Meta-Skill 质量，存在 early-stage 偏差风险。
- **精简视图静态**：$G_p$ 训练前一次性生成后固定，无法随技能体系演变自适应更新。
- **未与最新强基线充分对比**：仅与 RLSD/SDAR/Skill-SD 等早期 OPSD 方法对比，缺少与近期 MOPD（多 teacher）等多 teacher 方法的同条件比较。
- **仅依赖成功率等任务指标**：缺乏对技能使用粒度（如哪一步调用了哪条技能）的人工评估或细粒度诊断。
- **安全与越权风险未讨论**：BCSD 增强了策略对外部技能的响应，但未评估恶意或低质量技能带来的潜在风险。
