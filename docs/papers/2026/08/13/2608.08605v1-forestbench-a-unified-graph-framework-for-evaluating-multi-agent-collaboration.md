## 摘要
基于大语言模型（LLM）构建的多智能体系统（MAS）正快速发展，但其异构的执行轨迹在不同方法之间缺乏统一的评估基础。仅关注结果的基准测试会丢弃协作过程，而采用LLM作为评判者的评估方法则需要额外的、依赖模型的推理过程，且会因LLM和评分标准的不同而产生差异。我们提出一个可泛化的评估框架，将原生MAS轨迹映射到统一的协作图共享空间中，使不同方法能够在同一表征、同一参考集和同一指标体系下进行评估。候选图与针对查询构建的参考森林进行比较。每个森林是基准提供的一组经过验证的成功图集合：它记录了代表性MAS方法完成该任务的多样化路径，而非规定唯一的最佳过程。我们将该框架实例化为ForestBench，从七个公开数据集中筛选出844条需要协作的查询，为每个查询预计算十条成功的目标条件参考图，并对六个代表性MAS框架进行评估。通过对骨干模型、参考构建方式以及扰动的受控实验，我们验证了评估的稳定性与适用范围。一旦基准森林构建完成，ForestBench可在毫秒级内对轨迹进行评分，无需进一步的LLM推理，为比较多样化MAS协作轨迹提供了可复用的结构化基础。

## Abstract
Multi-agent systems (MAS) built on Large Language Models (LLMs) are proliferating rapidly, but their heterogeneous execution traces provide no common basis for evaluation across methods. Outcome-only benchmarks discard collaborations, whereas LLM-as-Judge evaluation requires additional, model-dependent inference and can vary with the LLM and rubric. We introduce a generalizable evaluation framework that maps native MAS traces into a shared space of unified collaboration graphs, enabling different methods to be evaluated under the same representation, reference set, and metric panel. Candidate graphs are compared with a query-specific reference forest. Each forest is a benchmark-provided collection of verified-success graphs: it records diverse ways in which representative MAS methods can complete the task, rather than prescribing a unique optimal process. Instantiating the framework as ForestBench, we filter $844$ collaboration-necessary queries from seven public datasets, precompute ten successful target-conditioned reference graphs per query, and evaluate six representative MAS frameworks. Controlled backbone, reference-construction, and perturbation studies test the stability and scope of evaluation. Once the benchmark forests are built, ForestBench scores a trace in milliseconds without further LLM inference, providing a reusable structural basis for comparing diverse MAS collaboration traces.

# ForestBench 论文总结

## 一、核心问题与研究背景

- **核心痛点**：基于 LLM 的多智能体系统（MAS）执行轨迹高度异构（不同框架采用不同的事件模式、角色词汇与通信协议），缺少统一的、过程级的横向评测基座。
- **现有方案的不足**：
  - 结果导向基准（如 GSM8K、HumanEval）将整个 MAS 执行压缩为单一最终答案，**丢弃了"协作过程"这一 MAS 的核心价值**。
  - LLM-as-Judge 需要额外、依赖模型的推理，**每次评估都有 token 与时间开销**，且评分随评判模型与评分标准波动，**不可复现**。
- **研究目标**：构建一种通用、可复现、无需 LLM 推理的 MAS 协作过程评估框架，使异构 MAS 方法在同一结构空间中公平比较。

## 二、方法论

### 2.1 核心思想

- 把每一次 MAS 执行抽象为一张**有向无环协作图** $G(\tau) = (V, E, \phi)$，节点为原子动作，边为信息流依赖，$\phi$ 标注角色与内容。
- 为每个查询 $q$ 准备一个**参考森林** $F(q) = \{(G_k, q_k)\}_{k=1}^{K(q)}$，由多个验证成功的多样化协作结构组成；候选图与该森林做结构比对。

### 2.2 关键技术

- **图抽象（Graph Abstraction）**：将 agent_message、tool_call、decision 三类事件统一投影为共享角色词汇 $R$ 下的协作 DAG；同一时刻并发但顺序不同的动作坍缩为同一偏序，保证不同框架日志可比。
- **参考森林（Reference Forest）**：避免将单一"最佳流程"作为黄金标准，记录同一查询被代表性 MAS 范式成功完成的多样化路径。
- **候选评估流程**：运行候选 MAS → 解析原生日志 → 投影为协作图 → 与 $F(q)$ 比对，全程**无 LLM 推理**。

### 2.3 评估指标

- **Forest Match（FM）**：候选图与森林中所有参考图的加权平均相似度：
$$
\mathrm{FM}(G, F(q)) = \frac{\sum_{k=1}^{K(q)} w_k \cdot \mathrm{sim}(G, G_k)}{\sum_{k=1}^{K(q)} w_k} \in [0,1]
$$
- **成对相似度**：$\mathrm{sim}(G, G') = \alpha\, s_{\text{node}} + \beta\, s_{\text{edge}} + \gamma\, s_{\text{topo}}$，默认权重 $(\alpha, \beta, \gamma) = (0.4, 0.4, 0.2)$。
- **辅助指标**：
  - **Best Similarity**：$\max_k \mathrm{sim}(G, G_k)$，衡量与最近参考树的接近度。
  - **Node Validity**：$NV(G) = |\{v \in V^- : \exists (v,u) \in E\}| / |V^-|$，衡量动作是否被下游消费。
  - **Mean Uptake**：下游内容是否语义使用上游内容，基于余弦相似度阈值。
  - **Content Redundancy**：基于归一化内容哈希的重复率。
  - **Tokens / Efficiency**：总 token 开销与拓扑并行度。

  - **工具使用**：Terminal-Bench（39）

### 3.2 对比方法

## 五、实验数量与充分性

- **主实验**：6 框架 × 4 基座 × 844 查询 × 3 种子 = 大规模轨迹集合。
- **消融/验证实验**：
  1. **参考生成器留出（leave-framework-out）**：依次剔除 6 个 MAS 框架与 CoT-SC 锚点共 7 种设置，6/7 保持 Top-3，Kendall $\tau$ 范围 0.60–1.00。

  4. **扰动实验**：节点删除、边重连、角色互换、干扰插入、重复内容注入，5 类 × 2 强度 = 10 设置；9/10 设置 Kendall $\tau = 1.0$，最坏 0.867。
  5. **权重敏感性**：5 种非退化权重下 Top-3 全保留，Kendall $\tau \geq 0.73$。
  6. **TSP 阈值扫描**：$3 \times 3 \times 4 = 36$ 种阈值组合（查询池 222–1,244 条），Kendall $\tau = 1.00$ in 36/36。
  7. **跨基座骨架分析**：相关系数 Pearson 0.986–0.999。
  8. **失败诊断**：300 条样本 × 3 个评判模型（DeepSeek-V4-Flash、GPT-5.5、Qwen3.6-Plus）多数投票；额外 100 条 × 3 评分标准变体做提示敏感性。
- **充分性评估**：实验覆盖了主对比、跨基座稳定性、参考构建敏感性、扰动鲁棒性、超参敏感性、失败诊断与效率对比，**整体比较充分**，但单次失败诊断仅 300 条，且需 LLM 辅助解读。

## 六、主要结论与发现

- **准确率区分度有限**：6 框架准确率仅相差 0.038（0.531–0.569），但 Forest Match 跨度 0.316–0.421，**结构性指标具有更强区分力**。
- **协作增益依赖基座**：相对单智能体 CoT 基线，平均增益为 DeepSeek-V4 -0.002、GPT-5.5 -0.039、Claude-S4.6 -0.069——**更强基座下"堆代理"反而是负收益**。
- **领域特化现象**：Debate 在全局 Forest Match 最低（0.316），却在 SWE-bench-Verified 上达到 0.382 排名第一，与其"评审-修订"模式契合。
- **失败可二分**：错误可分离为**结构失败**（缺失角色、固定不匹配 motif）与**内容失败**（求解/验证/聚合出错），对应不同修复方向。
- **成本优势**：ForestBench 比 LLM-as-Judge 快约 **2,900 倍**，且每条轨迹评估 **零推理 token**。
- **多模型诊断一致性**：在共享可解析子集上结构失败、内容失败、错误是否被捕获、首次出错位置多数投票一致率分别为 93.5%、81.2%、100.0%、94.9%。

## 七、优点

- **统一表征**：将异构 MAS 框架的执行轨迹映射到共享的协作 DAG 空间，实现真正的横向比较。
- **参考森林设计**：避免单一黄金流程对协调范式的偏向，承认成功路径的多样性。
- **无推理评分**：评估阶段完全确定性的图运算，毫秒级、零 token、可复现。
- **一次性构建、终身复用**：参考森林是一次性资源，新方法评估无需重建。
- **稳定性证据完整**：跨基座、跨参考生成器、跨评分权重、跨 TSP 阈值均给出 Kendall $\tau$ 等定量稳定性证据。
- **辅助诊断能力**：除全局排序外，Forest Match + 准确率 + 内容诊断可定位失败属于结构性还是内容性问题。

## 八、不足与局限

- **参考森林质量依赖**：Forest Match 是"参考相对"指标，评分质量取决于参考图集的覆盖度与代表性；若目标任务的参考范式未被覆盖，可能系统性低估。
- **TSP 仅为启发式筛选**：作者明确指出 TSP 是"用于筛选能产生可分析协作轨迹的查询"的启发机制，**并不证明每条保留查询都必须多智能体才能解**。
- **诊断仍依赖 LLM**：失败模式的细粒度标签（缺失角色、错误 motif 等）由 LLM 评判产生，且 prompt 敏感性实验中结构失败的 Cohen's $\kappa$ 仅 0.129–0.351，**细粒度标签不稳定**。
- **基座与模型时效性**：涉及 DeepSeek-V4-Flash、Claude-Sonnet-4.6、GPT-5.5、Qwen3.6-Plus 等较强/较强新型号，**通用性是否覆盖弱模型未充分验证**。
- **应用限制**：
  - 当前评估对象是已被结构化为图的轨迹，**需要每个框架维护解析适配器**，新框架接入有适配成本。
  - 图抽象是有损的（丢弃 wall-clock 交错与运行时状态），对**依赖时序细节**的过程难以区分。
  - 主要在英语任务上验证，**跨语言与跨文化任务**未涉及。
- **算力透明度不足**：未报告 GPU 型号、显存与墙钟时间，难以独立复现训练/构建成本。
- **样本规模**：开放式参考森林构造仅 30 条子集，跨基座骨架分析仅 60 条交集，可能影响小样本结论的稳健性。
