## TL;DR

这篇论文针对大语言模型智能体在强化学习中面临的稀疏奖励难题，提出了**持久一致性自蒸馏（PCSD）**方法。核心思路是通过分析教师偏好在局部邻域内的持久性来为每个 token 分配蒸馏权重，而非依赖孤立的单点差异或统一的步级权重。在不使用推理时额外技能的情况下，PCSD 在 ALFWorld 基准上全面超越了 GRPO 与 SDAR 等基线方法，在两种不同的骨干网络上分别取得了 90.6% 和 59.4% 的 Overall 成绩，并在未见过的任务划分上展现出显著的泛化优势。

## 研究背景与动机

大语言模型智能体在ALFWorld、WebShop 等复杂交互环境中展现出强大的任务规划与执行能力，但这类任务的强化学习训练长期受困于**稀疏奖励**问题。在典型的多轮对话场景中，一条包含数十个回合、数百个 token 的完整轨迹，往往只能在末端收到一个二元的结果信号——要么任务成功，要么任务失败。这种信号密度与轨迹长度之间的巨大落差，使得**信用分配（credit assignment）**成为核心难题：策略无法准确判断轨迹中间哪一步决策是真正有效的，哪一步是有害的。

为了缓解这一困境，**自蒸馏（self-distillation）**范式被引入智能体强化学习领域。具体做法是让模型的一个冻结副本充当"特权教师"，同时另一个可学习的"学生"版本参与交互。由于教师在推理时可以获得通过技能检索得到的额外上下文信息，它的输出质量通常更高。自蒸馏的核心思想是：让学生模仿教师的 token 级概率分布，从而将稀疏的轨迹级奖励信号转化为密集的 token 级监督信号。

然而，这种方法存在一个根本性的假设问题：**教师并非在每个位置上都是可靠的**。尽管教师整体上优于学生，但在某些具体位置，它给出的偏好信号可能只是采样噪声的产物，或者恰好与学生偶然探索到的正确方向相悖。如何在密集的教师监督中筛选出真正值得信赖的信号，成为提升自蒸馏效果的关键。

现有方法大体上可以分为两类，各有取舍。**Token 级方法**（如 RLSD、SDAR）基于每个位置独立的概率差异或对数比例来衡量可信度，这种做法理论上精细，但在训练早期或采样噪声较大的场景中容易受到单点波动的影响，产生误导性的梯度。**Step 级方法**（如 SOD、StepOPSD）则将整步的所有 token 聚合后再分配统一权重，虽然降低了噪声敏感性，但完全丢失了位置间的差异信息——同一步中有效与无效的 token 被等同对待。

这篇论文的核心观察是：**真正有信息量的教师偏好信号应当在局部邻域内持续出现**。一个可靠的对教师有利的决策，其优势应该在周围的 token 中也能观察到；相反，单点的尖峰更可能反映的是采样过程中的随机波动，而非教师真实的分布偏好。基于这一直觉，PCSD 从"教师偏好信号的局部持久性"出发，设计了一套完整的 token 级蒸馏权重生成机制。

## 方法

PCSD 的整体框架建立在 [[GRPO]] 之上，将其稀疏的轨迹级优势估计与 token 级的教师蒸馏信号相结合。框架中有三个关键角色：学生策略 $\pi_\theta$（参与环境交互并更新）、冻结的特权教师 $\pi_T$（同一基座检查点的副本，输入中拼接了通过关键词检索得到的技能上下文），以及最终的训练目标。

整个蒸馏权重的生成流程包含四个递进的设计层次，每一层都针对前一层的问题进行了改进。

**第一层：教师-学生采样对数概率差。** 对于轨迹中第 $k$ 个响应（turn）的第 $i$ 个 token，首先计算教师与学生在该位置的 log 概率差异：

$$\delta_{k,i} = \log \pi_T(y_{k,i} \mid h^T_{k,i}) - \log \pi_\theta(y_{k,i} \mid h^S_{k,i})$$

这个差值 $\delta_{k,i}$ 的物理含义是：给定各自的历史上下文，教师对该采样 token 的相对支持程度。$\delta_{k,i} > 0$ 意味着教师倾向于这个 token，反之则教师不看好。然而，单独的这个数值并不能说明这种偏好是"真实的"还是"偶然的"。

**第二层：持久一致性评估——指数衰减聚合。** 为了判断教师偏好是否具有持久性，PCSD 在大小为 $N$ 的前向窗口内对 $\delta$ 做指数加权聚合：

$$\bar{\delta}^{(N)}_{k,i} = \frac{\sum_{j=0}^{N-1} \alpha^{j} m_{k,i+j}\, \delta_{k,i+j}}{\sum_{j=0}^{N-1} \alpha^{j} m_{k,i+j}}$$

其中 $\alpha \in (0,1)$ 是衰减因子，越近的 token 权重越高；$m_{k,i+j}$ 是掩码（mask），处理序列末尾的有效 token 不够的情况。这本质上是在问："在接下来的几个 token 里，教师是否持续支持学生采样到的内容？"如果答案肯定，$\bar{\delta}^{(N)}_{k,i}$ 的值会保持较高；如果只是在某一点上有微弱优势但后续回落，这个聚合值会被稀释。

论文采用了 $N_{\min}=1$、$N_{\max}=8$、$\alpha=0.8$ 的配置，对应的有效样本量约为 6.41，平均位移约 2.39 个 token。

**第三层：自适应聚合机制。** 固定窗口大小无法同时兼顾精度与稳健性。当某区域的 $\delta$ 波动剧烈（高方差）时，说明此时信号不稳定，应该用更大的窗口平滑掉噪声；而当区域平稳（低方差）时，应该保留更细粒度的短窗口响应。PCSD 通过局部方差来自适应地选择窗口大小：

$$r_{k,i} = \mathrm{clip}\!\left(\frac{\sigma^2_{k,i}-\tau_{\mathrm{low}}}{\tau_{\mathrm{high}}-\tau_{\mathrm{low}}},\,0,\,1\right)$$

$$\bar{\delta}^{\mathrm{ad}}_{k,i} = (1-r_{k,i})\,\bar{\delta}^{(N_{\min})}_{k,i} + r_{k,i}\,\bar{\delta}^{(N_{\max})}_{k,i}$$

当方差低于 $\tau_{\mathrm{low}}=0.05$ 时完全采用短窗口，保持最高的 token 粒度；当方差高于 $\tau_{\mathrm{high}}=0.5$ 时完全采用长窗口，最大程度抑制噪声；中间区域线性插值。

**第四层：单边趋势调制与 sigmoid 门控。** 仅仅有持久性还不够——如果窗口内的教师支持呈下降趋势，即使当前值不低，未来也可能不再可靠。PCSD 在 $N_{\max}$ 窗口内做遮蔽感知的普通最小二乘回归，取斜率 $\mathrm{slope}_{k,i}$。仅当斜率为负（支持正在衰减）时施加惩罚：

$$\eta_{k,i} = \mathrm{clip}\!\left(1 - \gamma\cdot\mathrm{ReLU}\!\left(-\frac{\mathrm{slope}_{k,i}}{\delta_{\mathrm{scale},k}}\right),\,0,\,1\right)$$

这种单边设计是有意的：正斜率（支持在增强）不需要额外放大，因为后续的 sigmoid 门控本身就会根据 $\bar{\delta}^{\mathrm{ad}}_{k,i}$ 的绝对值给出相应的高权重。对负斜率的惩罚则确保了权重不会因为当前的高值而被错误地锁定。

最终，权重通过 sigmoid 门控产生：

$$w_{k,i} = \sigma\!\left(\beta_{\mathrm{gate}}\cdot\bar{\delta}^{\mathrm{ad}}_{k,i}\right)\cdot\eta_{k,i}$$

其中 $\beta_{\mathrm{gate}}=5.0$ 控制 sigmoid 的锐度。输出 $w_{k,i} \in [0,1]$ 是连续的，可以是 0.73 这样的中间值，也可以接近 0 或 1，而不是离散的二值选择。

**训练目标。** 得到 token 级权重后，PCSD 的蒸馏损失为：

$$\mathcal{L}_{\mathrm{PCSD}} = \frac{1}{M}\sum_{k,i} m_{k,i}\,w_{k,i}\,\delta_{k,i}$$

这里教师 log-prob 和权重 $w_{k,i}$ 都设置 stop-gradient，仅对学生 log-prob 求导，产生加权负对数似然梯度。最终目标是 GRPO 损失与 PCSD 损失的加权和：

$$\mathcal{L}_{\mathrm{total}} = \mathcal{L}_{\mathrm{GRPO}} + \lambda_{\mathrm{PCSD}}\,\mathcal{L}_{\mathrm{PCSD}}$$

默认 $\lambda_{\mathrm{PCSD}}=0.01$，即蒸馏信号作为相对较小的辅助约束存在，而非主导训练方向。

## 实验与结果

实验在 ALFWorld 和 WebShop 两个标准基准上进行，使用 Qwen2.5-3B-Instruct 和 Qwen3-1.7B-Instruct 两种规模的骨干网络。所有对比方法使用相同的训练预算、相同的教师技能配置和相同的评测协议，唯一差异在于蒸馏权重的计算方式。

在 ALFWorld 的主结果上，PCSD 取得了所有基线中的最佳 Overall 成绩。在 Qwen2.5-3B 骨干上达到 90.6%，分别超过 GRPO 15.6 分、超过 SDAR 6.2 分；在 Qwen3-1.7B 骨干上达到 59.4%，分别超过 GRPO 13.3 分、超过 SDAR 5.5 分。尤其值得注意的是，PCSD 不需要任何推理时的技能检索，这使得它与使用推理时技能的 Skill-GRPO* 相比也具有优势。在 Qwen2.5-3B 上，PCSD 90.6% 对比 Skill-GRPO* 的 87.8%，优势明显。

分任务类型来看，Heat 和 Pick2 等需要更长推理链的任务提升尤为显著，这与 PCSD 擅长处理长序列信用分配问题的设计直觉相符。在 WebShop 上，PCSD 保持竞争力，Qwen2.5-3B 达到 Score 85.0，与 SDAR 并列第一。

泛化性是更值得关注的结果。在 ALFWorld 的 valid_unseen 划分（未见过的物体位置配置）上，PCSD 的 Overall 达到 86.7%，显著超过 GRPO 的 70.9% 和 SDAR 的 72.7%，提升幅度达 15.8 分。这说明通过持久性筛选出的教师信号不仅能提升训练阶段的任务表现，还学到了更稳健的决策策略，而非过拟合于特定实例。

训练动态分析揭示了 PCSD 的行为特征。随着训练进行，教师-学生 gap 的均值从负值逐步上升（说明学生越来越接近教师的水平），同时 gate 激活率保持在 20%–28% 的水平，意味着只有五分之一到四分之一的 token 获得了 $w_{k,i} > 0.5$ 的高权重。这种"集中而非严苛"的分配模式体现了 PCSD 的设计哲学：不是对所有教师偏好不加区分地灌输，而是精准地识别并强化那些真正可靠、持久、有趋势支撑的信号。

消融实验验证了各组件的必要性。自适应窗口相比固定 $N=1$ 或 $N=4$ 的版本均有提升；去除趋势调制后性能下降，说明对衰减信号的惩罚是有效的；去除指数衰减（改为等权重平均）同样导致性能退化，证明越近的 token 越有参考价值的归纳偏置是合理的。

## 讨论与可借鉴点

PCSD 的核心贡献在于提出了**"持久性"作为教师可信度的判断标准**这一洞察。与其相信某个 token 上教师与学生的孤立差异，不如观察这种差异是否在局部邻域内持续存在。这一思路从信号处理的角度重新诠释了自蒸馏中的置信度估计问题，也为后续工作提供了新的设计方向。

从实践角度，PCSD 不依赖推理时技能的特性具有重要的工程价值。许多辅助推理的技术（如技能检索、树搜索）会增加部署时的计算开销和系统复杂度，而 PCSD 学到的策略可以直接使用，无需额外的上下文构造。这使得方法更容易融入现有的 LLM Agent 部署管线。

然而，论文也存在一些局限性。首先，方法引入了多个超参数（$N_{\min}$、$N_{\max}$、$\alpha$、$\tau_{\mathrm{low}}$、$\tau_{\mathrm{high}}$、$\gamma$、$\beta_{\mathrm{gate}}$），除了 $\lambda_{\mathrm{PCSD}}$ 外均未进行独立敏感性分析，存在这些固定值可能过拟合于当前实验配置的风险。其次，教师策略全程冻结且技能库由规则和关键词检索构建，限制了方法对动态演化环境的适应性。此外，实验仅覆盖 ALFWorld 和 WebShop 两个文本型基准，在 GUI 操作、代码生成、工具调用等更广泛场景下的效果有待验证。

对于[[强化学习]]中[[稀疏奖励]]问题的研究，PCSD 的思路提供了一个有价值的启示：信用分配不仅可以通过时序折扣或价值估计来实现，还可以通过分析教师偏好的局部结构来实现——只要这种偏好信号具有内在的一致性和可信度。这种将自蒸馏与[[强化学习]]结合的范式值得在更多任务和模型规模上探索。

## 摘要
大语言模型智能体在复杂交互任务中展现出强大的潜力，但其强化学习（RL）常常受到稀疏奖励的阻碍，因为一条较长的多轮轨迹可能仅获得单个结果级别的信号。在策略自蒸馏（OPSD）从特权教师模型提供密集的 token 级监督，但教师在每个位置上并不总是可靠的。现有方法通常依赖于孤立的 token 级差异，这可能对噪声敏感，或者分配共享的步骤级权重，这可能忽略位置上的变化。我们提出了持久一致性自蒸馏（PCSD），它从教师偏好信号的局部持久性中推导 token 级蒸馏权重。PCSD 将自适应窗口与指数衰减聚合相结合，以捕获持久的相对教师支持；应用趋势感知调制来衰减局部下降的支持；并通过 sigmoid 门控产生连续权重。最终目标与 GRPO 联合优化，将密集的教师指导与稀疏的环境反馈相结合。在不使用推理时技巧的情况下，PCSD 在两种骨干网络上均取得了所有基线中最佳的 ALFWorld Overall 成绩，分别超过 GRPO 15.6 和 13.3 分，超过 SDAR 6.2 和 5.5 分，同时在 WebShop 上保持竞争力，并在未见过的 ALFWorld 划分上比 GRPO 高出 15.8 分。

## Abstract
Large language model agents have shown strong potential in complex interactive tasks, yet their reinforcement learning (RL) is often hindered by sparse rewards, as a long multi-turn trajectory may receive only a single outcome-level signal. On-policy self-distillation (OPSD) provides dense token-level supervision from a privileged teacher, but the teacher may not be reliable at every position. Existing methods commonly rely on isolated token-level discrepancies, which can be sensitive to noise, or assign a shared step-level weight that may overlook positional variation. We propose Persistent Consistency Self-Distillation (PCSD), which derives token-level distillation weights from the local persistence of teacher-favoring signals. PCSD combines adaptive windows with exponentially decayed aggregation to capture persistent relative teacher support, applies trend-aware modulation to attenuate locally declining support, and produces continuous weights through sigmoid gating. The resulting objective is jointly optimized with GRPO, combining dense teacher guidance with sparse environmental feedback. Without inference-time skills, PCSD achieves the best ALFWorld Overall results among all baselines on both backbones, exceeding GRPO by 15.6 and 13.3 points and SDAR by 6.2 and 5.5 points, while remaining competitive on WebShop and gaining 15.8 points over GRPO on unseen ALFWorld split.

- **现有可信度加权方法的结构性矛盾**：
  - **Token 级方法**（RLSD、SDAR 等）：基于孤立差异/概率比，对采样噪声敏感；
  - **Step 级方法**（SOD、StepOPSD 等）：对整步聚合后给统一权重，掩盖了位置间可信度差异。
- **本文观察**：真正有信息量的教师偏好应当在局部邻域内持续出现，单点尖峰更可能反映采样波动而非真实分布差异。

## 二、方法论：PCSD

### 1. 整体框架

PCSD 将 GRPO 的稀疏轨迹级优势与 token 级教师蒸馏结合。设学生策略为 $\pi_\theta$，冻结教师为 $\pi_T$（同一基座检查点的冻结副本，输入拼接通过关键词检索得到的技能）。

### 2. 教师-学生采样对数概率差

对 turn $k$ 的 token $y_{k,i}$，定义：

$$\delta_{k,i} = \log \pi_T(y_{k,i} \mid h^T_{k,i}) - \log \pi_\theta(y_{k,i} \mid h^S_{k,i})$$

$\delta_{k,i}$ 越大表示教师对采样 token 的相对支持越强。

### 3. 持久一致性评估（指数衰减聚合）

在大小为 $N$ 的前向窗口内对 $\delta$ 做指数加权聚合：

$$\bar{\delta}^{(N)}_{k,i} = \frac{\sum_{j=0}^{N-1} \alpha^{j} m_{k,i+j}\, \delta_{k,i+j}}{\sum_{j=0}^{N-1} \alpha^{j} m_{k,i+j}}$$

其中 $\alpha \in (0,1)$ 为衰减因子。响应末尾窗口自动截断并按有效 token 归一化。参数上取 $N_{\min}=1$，$N_{\max}=8$，$\alpha=0.8$，对应有效样本量 $\approx 6.41$，平均位移 $\approx 2.39$ token。

### 4. 自适应聚合机制

根据 token 级 $\delta$ 在 $N_{\max}$ 窗口内的局部方差 $\sigma^2_{k,i}$ 决定短/长窗口插值比例：

$$r_{k,i} = \mathrm{clip}\!\left(\frac{\sigma^2_{k,i}-\tau_{\mathrm{low}}}{\tau_{\mathrm{high}}-\tau_{\mathrm{low}}},\,0,\,1\right)$$

$$\bar{\delta}^{\mathrm{ad}}_{k,i} = (1-r_{k,i})\,\bar{\delta}^{(N_{\min})}_{k,i} + r_{k,i}\,\bar{\delta}^{(N_{\max})}_{k,i}$$

高方差区域偏向长窗口（更平滑），低方差区域保留短窗口（更高 token 粒度）。预设 $\tau_{\mathrm{low}}=0.05$，$\tau_{\mathrm{high}}=0.5$。

### 5. 单边趋势调制

在 $N_{\max}$ 窗口内对有效位置做遮蔽感知 OLS 回归，取斜率 $\mathrm{slope}_{k,i}$。仅当斜率为负（教师支持下降）时进行衰减：

$$\eta_{k,i} = \mathrm{clip}\!\left(1 - \gamma\cdot\mathrm{ReLU}\!\left(-\frac{\mathrm{slope}_{k,i}}{\delta_{\mathrm{scale},k}}\right),\,0,\,1\right)$$

其中 $\delta_{\mathrm{scale},k}$ 为响应级平均绝对 gap。该设计是非对称的——正斜率不做额外放大，避免与 sigmoid 门控重复激励。

### 6. 连续 Sigmoid 门控

$$w_{k,i} = \sigma\!\left(\beta_{\mathrm{gate}}\cdot\bar{\delta}^{\mathrm{ad}}_{k,i}\right)\cdot\eta_{k,i}$$

其中 $\beta_{\mathrm{gate}}=5.0$ 控制 sigmoid 锐度；$w_{k,i}\in[0,1]$。结果得到连续、单 token 的蒸馏权重。

### 7. 训练目标

$$\mathcal{L}_{\mathrm{PCSD}} = \frac{1}{M}\sum_{k,i} m_{k,i}\,w_{k,i}\,\delta_{k,i}$$

教师 log-prob 与 $w_{k,i}$ 在优化时均 stop-gradient，$\mathcal{L}_{\mathrm{PCSD}}$ 对学生 log-prob 仍可微，产生加权 NLL 梯度。最终：

$$\mathcal{L}_{\mathrm{total}} = \mathcal{L}_{\mathrm{GRPO}} + \lambda_{\mathrm{PCSD}}\,\mathcal{L}_{\mathrm{PCSD}}$$

默认 $\lambda_{\mathrm{PCSD}}=0.01$。GRPO 使用 clip 后的策略比、组内归一化优势、对参考策略的 KL 惩罚；token mask 不跨越响应边界。

整体实验覆盖两个 backbone、两个 benchmark、多种基线、消融、超参与诊断分析，规模适中且层次较完整。PCSD 提出的算法依赖若干固定超参（$N_{\min}/N_{\max}/\alpha/\tau_{\mathrm{low}}/\tau_{\mathrm{high}}/\gamma/\beta_{\mathrm{gate}}/\lambda_{\mathrm{PCSD}}$），文中未对除 $\lambda_{\mathrm{PCSD}}$ 外其余做单独扫描，敏感性证据相对不足。

## 六、主要结论

- **ALFWorld Overall**：在 Qwen2.5-3B 与 Qwen3-1.7B 上分别达 **90.6% / 59.4%**，相对 GRPO 提升 **+15.6 / +13.3**，相对 SDAR 提升 **+6.2 / +5.5**；Heat / Pick2 等长链任务提升尤为显著。
- **WebShop**：Qwen2.5-3B 上 Score **85.0**，与 SDAR 并列 Acc 第一；Qwen3-1.7B 上 Score **78.9**（仅次于 Skill-GRPO*，后者使用推理时技能）。
- **不需要推理时技能**：在两种 backbone 上的 ALFWorld Overall 均优于使用推理时技能的 Skill-GRPO*。
- **泛化**：在 valid_unseen 上 Overall **86.7%**，超 GRPO 70.9%、SDAR 72.7%。
- **动态行为**：训练中平均 teacher-student gap 由负值逐步上升，同时仅 20%–28% 的 token $w_{k,i}>0.5$，说明 PCSD 选择了"集中而非严苛"的蒸馏分配。
- **加权稳健性**：PCSD 与 SDAR 在 1% 扰动下 Spearman 相近（0.985 vs 0.986），但 5%/10% 扰动下 PCSD 更优（0.934/0.887 vs 0.929/0.864）。
- **教师质量一致性**：去技能 / 打乱技能两种扰动下，PCSD $\Delta Q$–$\Delta W$ 的 Spearman 为 $0.174 / 0.052$（弱正相关），而 SDAR 为 $-0.489 / -0.208$（负相关）。

## 七、优点与亮点

- **核心洞察清晰**："教师偏好的局部持久性"作为可信度信号，可解释性较好。
- **算法设计兼顾两点精度与聚合稳健性**：自适应窗口 + 指数衰减 + 单边趋势 + sigmoid 门控形成连续 token 级权重，避免 step 级统一权重的位置信息丢失。
- **不依赖推理时技能**：相比 Skill-GRPO* 等方法，部署时无需外部技能检索，工程友好。
- **理论分析扎实**：附录给出了聚合估计的 MSE 分解、有效窗口长度 $N_{\mathrm{eff}}(N,\alpha)$、OLS 斜率方差等，便于理解参数选择。
- **诊断实验多样**：除主任务外，还对权重排序与教师质量扰动进行了针对性实验，揭示了 SDAR 出现负相关的潜在问题。
- **可与 GRPO 互补**：PCSD 损失独立于轨迹奖励，可即插即用地替换或叠加于其它 critic-free RL 方法。

## 八、不足与局限

- **超参较多且未充分扫描**：除 $\lambda_{\mathrm{PCSD}}$ 外，$N_{\min},N_{\max},\alpha,\tau_{\mathrm{low}},\tau_{\mathrm{high}},\gamma,\beta_{\mathrm{gate}}$ 均固定为单一取值，缺乏 sensitivity analysis，存在过拟合到该组合的风险。
- **冻结策略**：教师与 $\tau_{\mathrm{low}}/\tau_{\mathrm{high}}$ 等统计量全程不变，文中已指出这限制了对不断演化的轨迹统计的适应性。
- **教师特权信息来源有限**：技能库由通用规则 + 关键词检索得到，仅注入教师上下文而非学生上下文；技能构建方式与 ablation 影响若能单独报告会更有说服力。
- **Benchmark 局限**：仅 ALFWorld 与 WebShop 两个文本型任务，缺少 GUI、代码、工具调用等其它主流 agent benchmark 验证。
- **对比的"重实现"问题**：SDAR 等部分基线为作者重跑，超参对齐细节集中在附录 Table 4，公平性仍可能受实现细节影响；缺乏多随机种子报告与显著性检验。
- **诊断指标的解释边界**：作者明确说明 Spearman 正/负相关仅为权重行为分析，不构成下游性能因果证据；这一点使其相对 SDAR 的"改进"主张应保守看待。
- **泛化结论的有限性**：valid_unseen 仍属于 ALFWorld 同分布域内的布局变化，并非真正的跨任务/跨环境 OOD；缺少跨任务迁移实验。
- **收敛与效率**：未报告 wall-clock 时间、相对 GRPO 的额外计算开销（如 N 次 teacher forward 的影响），限制了对实际部署成本的评估。
