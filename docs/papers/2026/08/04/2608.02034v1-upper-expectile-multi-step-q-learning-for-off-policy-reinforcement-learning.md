## TL;DR

ENQ（Expectile n-step Q-learning）是一种面向离线策略强化学习的算法，通过将标准 n 步时序差分损失替换为作用在动作值误差上的非对称 expectile 损失，在仅新增一个超参数 $\tau$ 的情况下缓解了多步回报在离线场景下的悲观偏差问题。理论证明该算子具有 $\gamma^n$ 收缩性，且在确定性动力学下当 $\tau=1$ 时偏差在最优动作值函数处消失。在 27 个操控与导航任务上，ENQ 以单一 $\tau=0.8$ 与 LQL 整体持平，并在训练吞吐和 critic 集成扩展性上展现优势。

## 研究背景与动机

离线强化学习的核心挑战在于如何从已有的静态交互数据中学习有效策略。与在线学习不同，离线设置下智能体无法通过实时交互来纠正值函数估计的偏差，这使得多步回报的利用变得尤为棘手。

多步回报是加速值函数学习的重要技术。以 n 步回报为例，智能体不再仅依赖即时奖励和单步 bootstrap，而是将一段长度为 n 的奖励序列串联起来，再以折扣因子 $\gamma^n$ 折算到当前时刻。这种方式能显著缩短自举链长度，将 Bellman 算子的收敛压缩因子从 $\gamma$ 提升到 $\gamma^n$，从而加快奖励信号的传播效率。在长时域、稀疏奖励的场景下，这一特性尤为重要——智能体往往需要等待整个任务完成后才能获得有意义的反馈，多步回报能够将远期奖励提前带回当前决策点。

然而，多步回报在离线策略设置下存在根本性缺陷。当计算 n 步目标时，算法假设在当前状态 $s_t$ 执行动作 $a_t$ 后，会沿着日志数据中的历史动作 $a_{t+1}, a_{t+2}, \ldots, a_{t+n-1}$ 继续执行。但现实中，日志数据是由可能远逊于最优策略的行为策略产生的。于是，n 步目标实际上在评估一条"杂糅轨迹"：起点是当前要评估的 $(s_t, a_t)$ 对，而后续动作却被强制固定为次优的历史动作。这种耦合导致 n 步目标系统性地低估当前决策的价值——即使 $a_t$ 本身是最优的，如果后续动作都很差，目标值也会很低。而且随着回溯步数 n 增大，这种悲观偏差会单调累积，使得更长的回溯步反而可能损害学习效果。

现有解决方案各有局限。重要性采样（IS）和 Retrace、V-trace 等方法通过重新加权轨迹的概率比来修正离线策略偏差，但这要求能够计算日志动作在当前策略下的似然——对于基于扩散模型或流匹配技术的现代策略生成器而言，这种似然通常难以廉价获取。Long-Horizon Q-learning（LQL）通过在轨迹级别构造上下界不等式来约束 critic，但需要进行沿整条长度为 L 的轨迹的多次 critic 评估和成对约束计算，计算开销随轨迹长度线性增长。还有一些方法引入辅助价值网络来解耦偏差，但增加了网络架构和训练的复杂度。

ENQ 的核心洞察是：在一次 n 步更新中，算子天然需要两次 critic 评估——一次在起点 $(s_t, a_t)$ 处计算当前值估计，另一次在回溯终点 $(s_{t+n}, a^*)$ 处计算 bootstrap 目标。能否仅利用这两次评估本身就实现对离线策略偏差的控制，而无需引入辅助网络、似然估计或轨迹级惩罚？ENQ 正是围绕这一简洁的设计目标展开的。

## 方法

ENQ 的设计哲学可以概括为"在保持 n 步 TD 框架简洁性的同时，通过非对称损失函数注入对离线策略偏差的鲁棒性"。具体而言，标准 n 步 TD 损失将时序差分误差 $\delta = Y_{t,n} - Q(s_t, a_t)$ 的平方作为学习信号，其中 $Y_{t,n}$ 是 n 步目标值。这个平方损失对正负误差赋予对称权重——过高的估计和过低的估计会受到相同的惩罚。但在离线场景下，n 步目标 $Y_{t,n}$ 本身因耦合次优后续动作而倾向于被低估，因此对称惩罚会放大这种低估带来的负面效果。

ENQ 引入 **expectile 损失**来打破这种对称性。Expectile 是分位数（quantile）的均值类比概念：通过一个水平参数 $\tau \in (0,1)$ 定义非对称的二次损失函数。形式上，单个 critic 的 expectile 损失为：

$$\ell_\tau(u) = |\tau - \mathbf{1}(u < 0)| \cdot u^2 = \begin{cases} (1-\tau) u^2 & \text{if } u \geq 0 \\ \tau u^2 & \text{if } u < 0 \end{cases}$$

当 $\tau = 0.5$ 时，expectile 损失退化为标准对称的平方损失，此时 ENQ 即为普通 n 步 TD。当 $\tau > 0.5$ 时，正残差（目标高于估计）被赋予更大的权重 $(1-\tau)$，而负残差（目标低于估计）被赋予较小的权重 $\tau$。这意味着当 n 步目标因离线策略偏差而偏低时，算法会以较小的惩罚幅度"接受"这种低估，从而缓解悲观偏差的传播。

从语义上理解，ENQ 通过 expectile 损失在估计 n 步目标分布的一个"偏上"分位点——即目标分布的上分位而非中位数。直觉上，这种设计对应于"即使后续动作次优，也要给予当前决策一个不那么悲观的评价"的态度，因为真正次优的决策会在后续的 bootstrap 中被逐步修正。

完整的目标值定义还包含对目标 critic 的保守聚合：

$$Y_{t,n} = G_{t:t+n} + \gamma^n m_{t+n}\, \bar{Q}^{\rho}_{\bar\theta}(s_{t+n}, a^*(s_{t+n}))$$

其中 $\bar{Q}^\rho_{\bar\theta}(s,a) = \frac{1}{K}\sum_i Q_{\bar\theta,i}(s,a) - \rho\,\mathrm{std}_i\, Q_{\bar\theta,i}(s,a)$ 是对 K 个目标 critic 的集成，使用均值减去 $\rho$ 倍标准差作为保守估计。$m_{t+n}$ 是二值掩码，在遇到环境终止时屏蔽 bootstrap；$v_t$ 是折扣因子，仅保留在同一回合内的转移段。

整个 ENQ 损失为多 critic 的 expectile 损失均值：

$$L_{\mathrm{ENQ}}(\theta) = \mathbb{E}_D\!\left[ v_t \cdot \frac{1}{K}\sum_{i=1}^K \ell_\tau(\delta_i) \right]$$

其中 $\delta_i = \mathrm{sg}[Y_{t,n}] - Q_{\theta,i}(s_t, a_t)$ 是每个 critic 的时序差分误差。注意 $\mathrm{sg}[\cdot]$ 表示 stop-gradient 操作符，确保梯度仅通过在线 critic 流动。

**理论保证**是 ENQ 区别于纯粹启发式设计的核心。论文证明了三个关键结果：第一，ENQ 算子 $T^n_\tau$ 是 $\gamma^n$-压缩映射，这意味着即使在随机动力学和任意行为策略下，迭代更新也会以几何速率收敛到唯一不动点。第二，在确定性动力学下，当 $\tau=1$ 时，ENQ 的偏差在覆盖的支持集上于最优动作值函数 $Q^*$ 处消失——这说明 ENQ 在理想条件下能够精确恢复最优值。第三，在随机动力学下，偏差具有两侧界，其噪声常数与回溯步长 n 无关，这保证了算法的稳定性不会随回溯加深而恶化。值得注意的是，$\tau=1$ 的不动点自动满足 LQL 下界不等式在分离步数处的约束，这建立了 ENQ 与 LQL 之间的概念桥梁。

## 实验与结果

实验在 OGBench 和 RoboMimic 两个基准上进行，涵盖 27 个任务实例，包括 cube 操作、can 抓取、square 放置以及多个导航环境。离线-在线协议采用标准的百万步离线预训练加百万步在线微调流程。所有 ENQ 配置使用统一的超参数：$\tau=0.8$，$n=4$，未做任何任务级调参。

**整体性能对比**是首要验证目标。在 5 项 ENQ 与 LQL 的聚合对比中，ENQ 在 4 项上取得更高均值：cube-triple 动作分块版本达到 91.4% 成功率而 LQL 仅 53.3%，humanoidmaze-medium 上 ENQ 领先 14 个百分点以上，antmaze-giant 上优势同样显著。唯一落后的场景是 RoboMimic 的 FQL 策略提取方式，但差距较小。1 步 TD 和 n 步 TD 基线在多数任务上明显低于两者，验证了多步回报和偏差校正的必要性。

**训练效率**是 ENQ 的显著优势所在。在相同的转移处理量约束下（通过匹配 $B \cdot n$ 实现公平比较），ENQ 的训练吞吐量随 critic 集成规模扩大而保持较高水平。当 K=2 时加速比为 1.27 倍，K=50 时扩大到 1.77 倍。这一优势源于 ENQ 只需在起点和终点各评估一次 critic，无需 LQL 所需的轨迹级多次评估和约束计算。

**Critic 集成扩展性**的实验揭示了 ENQ 的另一个有趣特性。在 cube-triple 任务上，当使用 2 个 critic 时 ENQ 与 LQL 几乎持平（51.2% vs 52.1%），但当集成规模扩大到 10 时，ENQ 跃升至 78.0% 而 LQL 仅提升到 59.1%。这一差距主要出现在在线微调阶段，表明 ENQ 的 critic 集成能够更有效地利用多样性来校正偏差，而 LQL 的轨迹级约束可能在某种程度上抑制了 critic 的表达能力。

**消融实验**进一步验证了设计决策的有效性。Expectile 水平 $\tau$ 的扫描显示上分位（$\tau > 0.5$）在 12 个配置中的 10 个上取得最优，但最优取值与任务性质和回溯步长相关——过高的 $\tau$ 在长回溯（n=16）时表现脆弱。将 expectile 直接作用于动作值残差的策略显著优于将其路由到辅助价值网络的 n-step IQL 风格设计。在随机动力学鲁棒性测试中，向日志动作注入高斯扰动（$\sigma=0.25$）后，ENQ 保持 59.0% 成功率，而 TD-n 和 LQL 分别降至 48.4% 和仅 5.4%。通过调整 $(\tau, \rho)$ 组合至 $(\tau=0.95, \rho=0.5)$，ENQ 可进一步提升到 89.3%。

## 讨论与可借鉴点

ENQ 的贡献在于提出了一种极简但理论有据的方法来处理离线策略强化学习中多步回报的悲观偏差问题。其设计哲学——用非对称损失替代对称损失来控制偏差——在概念上与其他领域（如鲁棒优化、对抗训练）中的非对称正则化思路一脉相承，具有跨领域的启发价值。理论证明的完整性（压缩性、偏差分解、两侧界）使得 ENQ 不仅仅是一组有效的启发式技巧，而是一个有坚实数学基础的算法框架。

ENQ 也存在若干局限。首先，虽然论文声称 ENQ 仅需一次 n 步更新中固有的两次 critic 评估，但在实践中这种"简洁性"依赖于对目标 critic 的保守聚合设计——这一聚合本身包含均值和标准差的计算，在极端情况下可能仍带来计算负担。其次，$\tau=0.8$ 作为统一超参数在多数任务上有效，但在长回溯和高度随机动力学的组合场景下可能需要调高 $\tau$ 并配合保守惩罚 $\rho$ 使用，这暗示了超参数选择的潜在敏感性。第三，实验中的对比基线数字直接取自 LQL 论文而未在同一实现框架下重跑，可能存在实现细节和硬件差异对结论的潜在影响。

从实践角度，ENQ 的直接可借鉴点包括：在设计离线策略算法时，优先考虑"drop-in"式改进而非引入大量新组件，以降低工程落地的门槛；通过理论分析（如压缩性证明）来指导算法设计，可以避免纯启发式方法在边界情况下的脆弱性；在多 critic 集成的场景下，上分位损失能够更充分地利用 critic 多样性，这为其他集成学习方法提供了新的损失函数设计思路。

## 摘要
多步回报加速了离线策略强化学习中的奖励传播，但将每个决策的评估与其后续的次优记录动作耦合在一起，从而引入了随时间步长增长的悲观偏差。我们提出了分位数n步Q学习（Expectile n-step Q-learning，ENQ），它将对称的n步时序差分（TD）损失替换为作用于动作值误差上的非对称分位数损失，其中分位数水平τ是在n步TD之外唯一新增的方法特定超参数。我们证明了ENQ算子是$γ^n$-压缩映射。在确定性动力学下，当τ=1时，其偏差在覆盖的支持集内状态-动作对上于最优动作值函数$Q^*$处消失，且对应的不动点满足长时域Q学习（LQL）所使用下界不等式的分离n实例及其倍数。在随机动力学下，该算子的偏差具有两侧界，其噪声常数与时间步长无关。在27个操控与导航任务实例上，使用单一分位数水平τ=0.8和固定的回溯时间步长，ENQ在总体上与LQL具有竞争力，在我们的性能分析研究中实现了更高的训练步吞吐量，并在受控的扩展实验中对十评论家集成带来了更大的收益。

## Abstract
Multi-step returns accelerate reward propagation in off-policy reinforcement learning, but couple the evaluation of each decision to the suboptimal logged actions that follow it, inducing a pessimistic bias that grows with the horizon. We propose Expectile $n$-step Q-learning (ENQ), which replaces the symmetric $n$-step temporal-difference (TD) loss with an asymmetric expectile loss on the action-value error, with expectile level $τ$ as the only method-specific hyperparameter added beyond $n$-step TD. We prove that the ENQ operator is a $γ^{n}$-contraction. Under deterministic dynamics, at $τ=1$, its bias vanishes at the optimal action-value function $Q^*$ on covered in-support pairs, and the corresponding fixed point satisfies the separation-$n$ instance and its multiples of the lower-bound inequality used by Long-Horizon Q-learning (LQL). Under stochastic dynamics, the operator bias admits two-sided bounds with horizon-independent noise constants. Using a single expectile level $τ=0.8$ and a fixed backup horizon across 27 manipulation and navigation task instances, ENQ is competitive with LQL on aggregate, achieves higher measured training-step throughput in our profiling study, and benefits more from a ten-critic ensemble in a controlled scaling experiment.

# 论文总结：面向离线策略强化学习的上分位多步 Q 学习（ENQ）

## 一、核心问题与研究动机

在长时域、稀疏奖励的离线（off-policy）值函数学习中，**多步回报（n-step return）** 通过将一段观测奖励串联起来再 bootstrap，能显著加快奖励传播、缩短自举链长度（压缩因子从 $\gamma$ 变为 $\gamma^n$）。然而其离线代价是：**n 步目标在评估 $(s_t, a_t)$ 时，把后续 $a_{t+1:t+n-1}$ 的执行固定为日志行为策略 $\pi_\beta$**，从而把对初始决策的评价耦合到了后续的次优动作上，在异构离线数据上产生随 $n$ 单调放大的**悲观偏差**。

针对该偏差的现有处理路线各有局限：
- **重要性采样（IS）/ Retrace / V-trace** 需要动作似然，对扩散策略、流匹配策略等生成式策略难以廉价获取；
- **LQL（Long-Horizon Q-learning）** 通过轨迹级下界/上界不等式构造 hinge 惩罚，但需要沿整条长度为 $L$ 的轨迹做多次 critic 评估与两两约束。

作者追问：**能否仅用一次 n 步更新中固有的两次 critic 评估（在起点 $(s_t,a_t)$ 与 bootstrap 终点），就既保留 n 步传播、又降低离线策略偏差？**

## 二、方法论

### 1. 核心思想

ENQ（Expectile n-step Q-learning）将标准 n 步 TD 的对称平方损失替换为作用于**动作值 TD 残差**之上的非对称**期望分位（expectile）损失** $\ell_\tau$，仅新增一个超参数 $\tau$。当 $\tau=1/2$ 时退化为对称 n 步 TD；当 $\tau>1/2$ 时，对正残差赋予权重 $\tau$、对负残差赋予 $1-\tau$，从而使 critic 拟合**给定 $(s_t,a_t)$ 下、n 步目标分布的 $\tau$ 分位**——即更多追踪"好的"日志延续，对"差的"延续不敏感。

### 2. 目标与损失

对长度为 $n$ 的采样段，定义：
$$Y_{t,n} = G_{t:t+n} + \gamma^n m_{t+n}\, \bar{Q}^{\rho}_{\bar\theta}(s_{t+n}, a^*(s_{t+n}))$$
$$\bar{Q}^{\rho}_{\bar\theta}(s,a) = \frac{1}{K}\sum_i Q_{\bar\theta,i}(s,a) - \rho\,\mathrm{std}_i\, Q_{\bar\theta,i}(s,a)$$

其中 $\bar{Q}^\rho$ 是带保守惩罚 $\rho$ 的目标集成聚合；$m_{t+n}\in\{0,1\}$ 在终止状态屏蔽 bootstrap；$v_t = \prod_{k=t}^{t+n-2}(1-d_k)$ 丢弃跨回合段。

每个 critic 的残差为 $\delta_i = \mathrm{sg}[Y_{t,n}] - Q_{\theta,i}(s_t,a_t)$，整体损失：
$$L_{\mathrm{ENQ}}(\theta) = \mathbb{E}_D\!\left[ v_t \cdot \frac{1}{K}\sum_{i=1}^K \ell_\tau(\delta_i) \right]$$
$$\ell_\tau(u) = \big|\tau - \mathbf{1}(u<0)\big|\, u^2$$

算法仅需在 $(s_t,a_t)$ 评估一次在线 critic、在 $(s_{t+n},a^*)$ 评估一次目标 critic，**不需要中间 critic 评估、不需要动作似然、不需要辅助价值网络**。同时兼容单动作与 $h=4$ 的动作分块（action-chunked）critic。

### 3. 关键理论结果

- **定理 1（压缩性）**：对任意 $\tau\in(0,1]$、任意 $n\ge1$、任意动力学与行为策略，$T^n_\tau$ 是 $\gamma^n$-压缩，因此存在唯一有界不动点 $Q^n_\tau$，且按 $\gamma^n$ 几何速率收敛。
- **定理 2（确定性动力学下的偏差分解与端点校正）**：路径上 $Z^{Q^*}_n(s,a) - Q^*(s,a) = \sum_{k=1}^{n-1}\gamma^k(-\Delta^*(s_k,a_k)) + \sum_{k=0}^{n-1}\gamma^k \epsilon_k$。在确定性动力学（$\epsilon_k\equiv 0$）下：(a) $T^n_{1/2}$ 在 $Q^*$ 处偏差为 $-\mu_n(s,a)\le 0$，且 $\mu_n$ 关于 $n$ 非减；(b) 不动点 $Q^n_\tau$ 关于 $\tau$ 单调不降；(c) 在**最优覆盖**假设（行为策略对累积最优性 gap 任意小的延续赋予正概率）下，$(T^n_1 Q^*)(s,a) = Q^*(s,a)$；(d) $Q^n_\tau \le Q^*$。
- **推论 1（隐式满足 LQL 下界）**：在上述假设下，$\tau=1$ 不动点自动满足 LQL 下界不等式在分离 $n,2n,\dots$ 处的要求。
- **定理 3（随机动力学下两侧界）**：定义 $\kappa_\tau = \frac{2\tau-1}{2(1-\tau)}$，有
$$-\mu_n(s,a) \le B_\tau(s,a) \le -\mu_n(s,a) + \kappa_\tau \sigma_n(s,a)$$
且当 $\mu_n + \sigma_n > 0$ 时，给出保证 $B_\tau\le 0$ 的安全 $\tau_{\mathrm{safe}}$ 阈值；不动点误差界为
$$\|Q^n_\tau - Q^*\|_\infty \le \frac{\sup_{s,a}\mu_n(s,a) + \kappa_\tau\sqrt{V_\infty}}{1-\gamma^n}$$
其中 $V_\infty$ 与 $n$ 无关。

### 4. 与 IQL 的关键差别

与 IQL 在**状态值**上做 expectile 不同，ENQ 直接把非对称加权放在**动作值残差**上，避免引入耦合的辅助 V 网络；这一定位差异通过额外 n-step IQL 基线（Remark 2 / 消融 A3）经验验证。

## 七、优点

- **方法极简**：作为 n 步 TD 的"drop-in"替换，仅需改一行损失定义（对称平方 → 非对称 expectile）；不引入辅助网络、似然估计或轨迹级惩罚，便于在已有 n 步 pipeline 中部署。
- **理论保证齐全**：在不需要行为策略覆盖全部最优策略的强条件下，仍能在 $\tau=1$ 端点恢复覆盖支持集上的 $Q^*$，并隐式满足 LQL 下界——这是与 LQL 的概念性桥接（推论 1）。
- **两侧偏差界**：随机动力学下给出显式上界，且噪声常数 $V_\infty$ 与 $n$ 无关，提供"长 horizon 也不会让噪声项线性放大"的工程直觉。
- **吞吐与可扩展性**：critic 更新更轻、对集成更友好，$K$ 增大时加速比反而扩大。
- **实验覆盖面广**：27 任务 × 多种 actor/分块 × 4 种子 × 4 类消融，整体比较充分；尤其覆盖了 humanoidmaze-giant 这种 100M 转移的极端长程任务。

## 八、不足与局限

- **理论理想化**：分析建立在三个理想化条件上——种群 expectile、贪心 bootstrap、无限表达能力；附录 F 明示未建模函数近似、目标网络滞后、actor 近似、有限样本优化，因此压缩与偏差保证**不直接量化实际神经 critic 的估计误差**。
- **$\tau=1$ 偏差消失的强假设**：要求确定性动力学 + 行为策略对"累积次优性 gap 任意小的延续"赋予正概率（Assumption 1+2），在真实随机环境下未必成立；高 $\tau$ 在长 $n$ 时反而变脆。
- **$n$ 仍需手选**：$\tau$ 被严格控制为单一全局值，但备份步长 $n$ 仍是自由超参；论文未给出基于任务特征的 $n$ 选择准则。
- **基线非完全重跑**：TD/TD-n/LQL 数字复用既有论文，硬件、实现细节、动作分块（$h=4$ vs $h=5$）不一致，可能放大或缩小 ENQ 的表面优势。
- **安全 $\tau_{\mathrm{safe}}$ 仅是充分条件**：依赖不可观测的 $\mu_n,\sigma_n$，工程中只能通过经验扫描使用，理论到实践的桥梁较薄。
- **消融覆盖**：A3、A4 仅在 1–2 个任务上验证 expectile 放置与随机转移鲁棒性，外推到 27 任务的全局结论有风险。
- **应用边界**：方法与流匹配 / 动作分块策略紧密绑定（评测域均用 FQL 或动作分块 FQL），对离散动作、小动作空间纯 critic-only RL 的适用性未涉及。
