## 摘要
图上的博弈是一种基础模型。其应用包括反应式综合（可归结为零和双人博弈的求解），以及通过将多智能体系统建模为多人博弈来进行推理。我们研究一类称为竞价博弈的图博弈，其中为玩家分配预算，每一轮通过拍卖决定由哪位玩家移动棋子。双人竞价博弈已被广泛研究。我们首次研究多人竞价博弈。我们聚焦于离散竞价，它对玩家的预算和出价施加粒度限制。离散竞价的最初动机源于实际应用，而从技术上讲，其吸引人之处在于博弈仅有有限多个格局。我们从考虑两个玩家联盟之间的博弈入手开展研究。我们证明，在对打破竞价平局所采用机制的温和假设下，竞价博弈是确定的：从任意初始格局出发，总有一个联盟拥有必胜策略。由此，我们识别出了一类确定性的多人并发博弈子类。我们将该结果推广到平均收益博弈中值的存在性。利用确定性，我们证明在定性博弈中纯策略纳什均衡总是存在。最后，我们证明判断从给定格局出发哪个联盟获胜的复杂性，即便在可达性博弈中、即便预算以一元方式给出，也已是 PSPACE-难的。这与双人博弈形成鲜明对比，后者即使在预算以二元方式给出时已知属于 NP 与 coNP。

## Abstract
Games on graphs constitute a fundamental model. Applications include reactive synthesis, which reduces to solving a zero-sum two-player game, and reasoning about multi-agent systems by modeling them as a multi-player game. We study a class of graph games called bidding games in which the players are allocated a budget, and in each turn, an auction determines which player moves the token. Two-player bidding games have been extensively studied. We study, for the first time, multi-player bidding games. We focus on discrete bidding, which imposes granularity restrictions on the players' budgets and bids. The original motivation for discrete bidding is practical applications, and technically, it is appealing that the game has only finitely-many configurations. We initiate our study by considering a game between two coalitions of players. We show that under mild assumptions on the mechanism that is applied to break bidding ties, bidding games are determined: from every initial configuration, one of the coalitions has a winning strategy. Thus, we identify a sub-class of multi-player concurrent games that is determined. We extend the result to existence of a value in mean-payoff games. Using determinacy, we show that a pure Nash equilibrium always exists in qualitative games. Finally, we show that the complexity of deciding which coalition wins from a given configuration is PSPACE-hard already in reachability games and already for budgets given in unary. This is in stark contrast to two-player games, which are known to be in NP and coNP even for budgets given in binary.
