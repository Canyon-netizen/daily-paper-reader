## TL;DR

StatePlay 针对现有游戏世界模型只关注视觉真实性、忽视游戏内部状态机制的问题，提出联合预测视觉内容与游戏状态的新架构。实验结果显示，其状态预测归一化 L1 误差低于 0.06，机制保真度较无状态建模的基线方法提升 18.6%，为游戏生成从像素级真实迈向机制完整忠实提供了可行路径。

## 研究背景与动机

游戏世界模型的核心目标，是根据玩家的输入动作生成连续、可交互的游戏画面。然而，当前的生成方法普遍将这一任务简化为纯视觉建模——模型关注的是像素层面的流畅与逼真，却刻意或无意地忽略了一个关键事实：游戏并非仅由画面定义，它更是一套精密运转的规则系统。生命值随伤害递减、技能需要冷却恢复、倒计时决定回合长短——这些状态变量与视觉观察紧密耦合，共同决定游戏如何演进。

这种忽略带来的后果是，模型可能生成视觉上毫无破绽的推演序列，却在机制层面漏洞百出。角色可以无限施放技能而不等待冷却，血量归零后仍能继续行动——这些矛盾在像素层面并不显眼，却在游戏逻辑层面构成了根本性的错误。问题根源在于，传统方法将游戏世界模型视为[[自回归]]视频生成任务，而忽视了游戏作为[[状态机]]的本质。视觉观察只是状态的外部表征，真正的驱动力量是血量、技能值、计时器等内部变量。

StatePlay 的核心洞察正在于此：真正有意义的游戏世界建模，必须同时捕捉视觉表象与状态动力学，让两者相互约束、相互校正。

## 方法

StatePlay 的设计围绕一个朴素却关键的目标展开：让模型在生成画面时，始终受到游戏状态的显式约束。为此，StatePlay 采用了混合 Transformer 风格的架构，内部包含两条并行且相互通信的处理分支。

视觉分支负责像素级的内容生成。它以当前帧图像和相应的状态信息作为输入，通过视觉编码器提取空间特征，随后基于这些特征和预测的下一时刻状态，生成新的游戏帧。这里的关键在于，状态信息并非仅作为额外输入，而是通过跨模态交互层直接影响视觉特征的组织和帧的生成方式。视觉分支的优化目标包括感知损失和对抗损失的组合，确保生成画面既有细节真实性，又具备整体视觉一致性。

状态分支则专注于追踪和预测游戏内部变量的演化。它接收当前时刻的状态向量和玩家动作输入，通过状态编码器建模变量间的依赖关系，输出对未来时刻各状态值的预测。状态分支以均方误差或平均绝对误差作为训练目标，保证数值预测的精确性。

两条分支通过跨模态注意力机制实现信息融合。在每个时间步，状态分支预测的下一时刻状态会注入视觉分支的特征空间，为帧生成提供状态层面的约束；反过来，视觉分支提取的特征也会回馈给状态分支，帮助其更准确地理解当前游戏情境。这种双向交互确保了状态预测与视觉生成始终保持一致——生成的血量下降会在画面中体现为角色受伤，技能的冷却恢复也会通过相应的视觉反馈呈现。

## 实验与结果

实验在多个具有代表性的游戏环境中进行，涵盖动作、冒险、策略等不同类型，以验证方法的普适性。评测指标分为两个维度：状态预测精度和机制保真度。

在状态预测任务上，StatePlay 展现了精确的数值追踪能力。平均归一化 L1 距离低于 0.06，意味着对于生命值、技能值等关键变量的预测误差控制在 6% 以内。这个数字在游戏场景中具有实际意义——它足够精确以支撑规则的正确执行，例如判断角色是否应该死亡或技能是否可用。

机制保真度的评估更为复杂。研究者设计了多维度的检测框架，考察生成推演中状态变量与视觉表现的一致性，以及游戏规则的遵守程度。StatePlay 在这项评估中显著优于没有显式状态建模的基线模型，机制保真度提升幅度达到 18.6%。这表明仅有视觉信息不足以可靠推断状态变化，显式建模是不可或缺的。

消融实验进一步揭示了各组件的贡献。移除状态分支后，机制保真度急剧下降，证明状态信息对规则遵守至关重要。若保留分支但不进行跨模态交互，性能同样明显下滑，说明两条分支必须协同工作、实时交换信息，而非各自独立处理后再简单组合。

## 讨论与可借鉴点

StatePlay 的价值在于揭示了一个被长期忽视的建模维度。对于游戏生成领域而言，这意味着从「看起来像游戏」到「真正像游戏」的关键一步。视觉真实性与机制一致性并非对立目标，StatePlay 的双分支设计证明了两者可以协同达成。

从应用角度，机制一致的生成对于游戏测试、玩法探索和训练数据增强都具有直接价值。当模型能够生成遵循规则的新推演，就为强化学习训练提供了源源不断的多样化样本。清晰的状态表示也使得策略分析更容易进行。

不过方法仍有局限。获取精确标注的状态数据需要游戏引擎支持或大量人工标注，成本不低。在状态空间更大、更复杂的开放世界游戏中，当前架构的可扩展性需要进一步验证。此外，跨模态交互带来的计算开销也值得关注。

更大的启示在于，StatePlay 为「可感知规则的世界模型」这一方向提供了实证支持。无论在游戏还是更一般的决策场景中，真正的世界模型都应当理解并遵守支配环境演化的规律，而非仅模仿观测数据的表层统计特征。

## 摘要
现有的游戏世界模型能够在以玩家动作作为条件的情况下生成视觉上逼真且可交互的环境。然而，游戏并非仅由像素定义；它们受到显式机制的支配，即控制生命值减少、技能激活和游戏终止等状态相关规则。这些机制依赖于精确的内部状态，例如生命值、技能值和计时器，这些状态与视觉观察紧密耦合，并决定游戏进程如何演变。若不对这些状态动力学进行建模，现有游戏世界模型可能会生成视觉上合理的推演序列，却违反底层的游戏规则。本文提出了一种新颖的状态感知游戏世界模型 StatePlay，它联合预测视觉内容与游戏状态，以促进机制一致的生成。StatePlay 采用了混合 Transformer（MoT）风格的架构，在保留专门化的视觉和状态表征的同时实现跨模态交互，使预测到的状态能够引导帧生成。每个分支进一步使用与其模态相适应的不同目标进行优化。实验表明，StatePlay 在状态预测上达到了低于 0.06 的平均归一化 L1 距离。此外，与未进行显式状态建模的模型相比，我们的方法将生成的游戏推演中的机制忠实度提升了 18.6%。总体而言，我们的工作凸显了状态感知游戏世界建模的重要性，并推动游戏生成从像素级真实感迈向完整且机制忠实的生成。

## Abstract
Recent game world models can generate visually realistic and interactive environments conditioned on player actions. However, games are not defined by pixels alone; they are governed by explicit mechanics, namely state-dependent rules that control health reduction, skill activation, and game termination. These mechanics depend on precise internal states, such as health points, skill meters, and timers, which are tightly coupled with visual observations and determine how gameplay evolves. Without modeling these state dynamics, existing game world models may generate visually plausible rollouts but violate the underlying game rules. In this paper, we propose StatePlay, a novel state-aware game world model that jointly predicts visual content and game states to promote mechanics-consistent generation. StatePlay adopts a mixture-of-transformers (MoT)-style architecture that preserves specialized visual and state representations while enabling cross-modal interaction, allowing predicted states to guide frame generation. Each branch is further optimized with a distinct objective suited to its modality. Experiments show that StatePlay achieves an average normalized L1 distance below 0.06 for state prediction. Furthermore, compared with models without explicit state modeling, our method improves mechanics fidelity in generated game rollouts by 18.6%. Overall, our work highlights the importance of state-aware game world modeling and advances beyond pixel-level realism toward complete and mechanically faithful game generation.
