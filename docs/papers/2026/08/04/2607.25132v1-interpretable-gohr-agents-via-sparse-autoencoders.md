## TL;DR

这篇论文在隐藏规则博弈（GOHR）环境中，用稀疏自编码器（SAE）分析 Transformer 智能体的决策token嵌入，发现 SAE 的单个维度能够高度选择性地对应"所选形状""目标桶"等简单概念，甚至能还原出"先试探某条规则假设、被拒绝后再切换"这类可解释的推理策略。这说明在缺乏显式规则标签的情况下，智能体内部已经隐式地编码了规则的区分信息。

## 研究背景与动机

在构建决策智能体时，一个长期困扰研究者的核心问题是：我们能否理解智能体究竟在"想什么"？当一个系统通过大量交互学会做决策时，它的内部表征里是否真的包含人类可以解释的概念——比如"形状""桶""规则假设"——还是说它只是在进行某种连自己都无法说清的统计拟合？

过去的一些可解释性方法依赖**探测分类器**（probing classifiers）：给智能体的内部状态接一个线性层，试图预测某个概念是否存在。但这种方法有一个根本性缺陷——它只能验证我们已经猜到的概念，对于我们没猜到的隐式结构完全盲区。更糟糕的是，高探测准确率可能只是因为概念信息和模型状态在统计上相关，而非意味着模型真正"使用"了这个概念来做决策。

这篇论文的切入点是把问题推到一个更极端的设定：**隐藏规则博弈（GOHR）**。在这个环境中，智能体面对的是两条完全不同的隐藏规则——两条规则都把物体形状映射到目标桶，但映射关系完全不同。智能体从未被告知当前是哪条规则生效，只能通过与环境交互（尝试某个动作、观察接受或拒绝的反馈）来逐步推断。在正确规则被验证之前，任何假设都只是猜测。这种设定模拟了现实世界中 agent 必须从有限的反馈中学习规则的实际场景，也对可解释性提出了更高的要求：模型必须在没有任何显式规则标签的条件下，通过历史交互隐式地编码规则信息。

## 方法

作者的做法是训练[[稀疏自编码器]]来分解智能体决策时刻的 token 嵌入。SAE 的基本思想是：给定一个高维向量 $x$，用一个编码器将其投射到一个稀疏的潜在空间，再用解码器重建原始向量。目标函数通常写作：

$$\mathcal{L} = \|x - \text{decode}(\text{encode}(x))\|^2 + \lambda \|h\|_1$$

其中 $h$ 是潜在表示，$\lambda$ 是控制稀疏性的正则化系数。这种设计的直觉在于：如果智能体的嵌入空间确实离散地编码了若干概念，那么这些概念大概率不会全部同时激活——任何一个决策时刻，智能体主要关心的可能只是一两个关键概念。稀疏约束恰好鼓励了这种"一次关注一件事"的表示。

在具体实现上，编码器和解码器都是单层线性网络，中间潜伏维度设为输入维度的 8 到 16 倍（远超直觉上的"概念数量"）。这种过参数化的设计是有意为之——让 SAE 有足够的自由度把语义上不同的特征分离到不同维度，即使某些维度最终不被使用也无妨。训练数据来自智能体在两种规则下采样的决策序列，但训练目标完全是无监督的：SAE 只被要求重建嵌入向量，不接触任何规则标签或概念标注。

这里有一个关键的设计选择值得强调：如果直接用[[Transformer]]的原始输出嵌入作为输入，SAE 可能会学到大量与决策无关的表层特征（比如 token 位置、句法结构等）。作者选择聚焦于**决策 token 的嵌入**，即智能体生成最终动作选择时对应的那个向量，这样直接关联了"智能体在想什么"和"智能体做了什么"两个环节。

## 实验与结果

实验的核心验证方式是：首先让 SAE 学到一套潜在维度，然后找来一批**留出数据**（模型在训练时没见过的回合），用人类标注的概念——比如"当前选择的形状是哪种""目标桶是哪个"——给每个决策打标签。接下来考察：对于标注为"选择了形状 A"的决策，SAE 的哪些维度在此类决策上显著激活？这些维度是否在其他形状的决策上同样激活？

结果呈现出很强的选择性：当某个 SAE 维度在"选择了形状 A"的决策上有高激活时，它几乎不会在选择了其他形状的决策上激活，反之亦然。这种高度的选择性覆盖了该概念出现的大部分决策，说明 SAE 确实把"形状选择"这个概念分离到了少数几个维度上，而非把它打散在高维空间的某个方向上。

更引人注目的是对**推理策略**的还原。当智能体在一个回合中先尝试了一个"试探性"动作（比如故意选择一个在不同规则下会导向不同结果的形状），然后在收到拒绝反馈后切换到另一个选择——这种"先探后换"的模式居然也被 SAE 的单个维度捕捉到了。具体来说，存在一个维度的激活模式恰好对应"先假设某条规则、收到负面反馈后撤销"的时序特征。这意味着智能体不仅在内部编码了规则内容本身，还编码了它对规则的当前假设以及假设被推翻后的行为调整。

## 讨论与可借鉴点

当然，这项工作也有局限。首先，它验证的是一种相对简单的双规则场景——规则之间有明确的可区分维度（形状-桶映射），且规则总数只有两条。在规则更多、更复杂、规则之间存在重叠或模糊边界的情况下，SAE 是否仍能有效地将每个概念隔离到独立维度，目前尚不清楚。其次，SAE 本身的选择（比如潜伏维度倍数、稀疏性系数）需要调参，不同配置可能导致不同的概念分解结果，这引入了一定的工程敏感性。

不过，这篇论文给可解释性研究提供了一个值得借鉴的思路：与其直接问"模型的内部状态能不能预测某个概念"，不如问"模型内部是否有一个维度集合，其稀疏激活模式本身就能编码概念信息"。前者假设了人类预先知道要找什么，后者则更接近于"发现"而非"验证"。对于那些模型可能隐式学到但研究者尚未命名的策略——比如上文中"试探-反馈-切换"的模式——这种方法有潜力把它们从黑箱中打捞出来。

## 摘要
解释习得型决策系统的一个核心挑战是判断其内部表征是否包含有助于解释其行为的概念。我们报告了在隐藏规则博弈（Game of Hidden Rules, GOHR）中对一个分词化自回归 Transformer 智能体进行的可解释性实验。我们聚焦于一个紧凑的双规则任务：两条隐藏规则都将物体形状映射到目标桶，但采用不同的排列方式。策略在从这两条隐藏规则中采样的回合上进行训练，然后在固定权重条件下进行评估。系统从未获得规则标签，也不使用显式的规则分类器；任何规则信息都必须通过交互历史隐式地推断。在这种设定下，在智能体尝试一个信息性动作并观察到接受/拒绝反馈之前，正确规则是无法被识别的。在智能体决策标记嵌入上训练的稀疏自编码器（Sparse Autoencoders, SAEs）恢复了这种结构。当将留出的决策用诸如所选形状或桶等简单概念进行标注时，对某概念高度选择的 SAE 维度覆盖了该概念出现的大部分决策。单个 SAE 维度也对应于可解释的策略，例如探测某一规则假设以及在收到负面反馈后进行切换。

## Abstract
A central challenge in interpreting learned decision-making systems is to determine whether their internal representations contain concepts that help explain their behavior. We report interpretability experiments for a tokenized autoregressive Transformer agent in the Game of Hidden Rules (GOHR). We focus on a compact two-rule task in which both hidden rules map object shapes to target buckets, but with different permutations. The policy is trained on episodes sampled from these two hidden rules and then evaluated with fixed weights. It is never given a rule label and does not use an explicit rule classifier; any rule information must be inferred implicitly from interaction history. In this setting, the correct rule is not identifiable before the agent tries an informative move and observes accept/reject feedback. Sparse autoencoders (SAEs) trained on the agent's decision-token embeddings recover this structure. When held-out decisions are labeled by simple concepts such as the chosen shape or bucket, SAE dimensions that are highly selective for a concept cover most decisions where that concept is present. Individual SAE dimensions also correspond to interpretable strategies such as probing one rule hypothesis and switching after negative feedback.
