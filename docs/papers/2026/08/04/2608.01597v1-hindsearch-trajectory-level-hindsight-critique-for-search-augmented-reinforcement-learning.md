## 摘要
搜索增强的语言模型智能体通常采用二元精确匹配奖励进行训练，这会丢失失败轨迹所揭示的大部分关于其失败原因的信息。我们提出了 HindSearch，一种针对 GRPO 的事后自蒸馏方法：在每次 rollout 之后，一个冻结的评判器利用标准答案对每条失败轨迹撰写简短的批评，而这些批评为学生的搜索动作提供了辅助的同策略蒸馏信号。在使用 Qwen2.5-3B-Instruct 的标准七项基准测试套件上，HindSearch 达到了 39.4% 的平均精确匹配率，优于先前的搜索强化学习基线。移除评判器对标准答案的访问则会消除大部分增益，从而将事后信息确认为性能提升的来源。

## Abstract
Search-augmented LM agents are typically trained with a binary exact-match reward, which throws away most of what a failed trajectory tells us about why it failed. We introduce HindSearch, a hindsight self-distillation procedure for GRPO: after each rollout, a frozen judge writes a short critique of every failed trajectory using the gold answer, and the critique supplies an auxiliary on-policy distillation signal on the student's search actions. On the standard seven-benchmark suite with Qwen2.5-3B-Instruct, HindSearch reaches 39.4% average EM, outperforming prior search-RL baselines. Removing the judge's access to the gold answer erases most of the gain, isolating hindsight as the source of the improvement.

# HindSearch 论文总结

## 1. 核心问题与研究动机

- **问题**：搜索增强的语言模型（LM）智能体通常采用二元的精确匹配（EM）奖励进行端到端的强化学习（如 PPO/GRPO）训练。该奖励只告知"是否成功"，却丢弃了失败轨迹中大量关于"为什么失败"的细粒度信号（如查询内容、检索片段、应被使用却未被使用的正确查询等）。
- **结果**：导致学生策略需要从稀疏的 bandit 式信号中反推出完整的搜索策略，伴随较长的信用分配延迟与训练稳定性问题。
- **既有方案的不足**：
  - 过程奖励模型（PRM）仅对每一步做评估性打分，而非指导性修正。
  - 提示条件蒸馏方法（如 OpenClaw-RL）虽引入了自然语言提示，但提示在在线状态下生成，不能利用训练时已知的金标准答案。
- **论文定位**：利用训练时唯一能访问到的"金标答案 $a^{\star}$"，将失败轨迹转化为具有指导意义的细粒度监督信号。

## 2. 方法论

### 2.1 整体框架

- 在标准 GRPO（带二元 EM 奖励）之上，引入一个**轨迹级事后批评（TLHC）** 辅助目标：
  $$L_{\text{total}} = L_{\text{PPO}} + \lambda_{\text{OPD}} \cdot L_{\text{OPD}}, \quad \lambda_{\text{OPD}} = 0.01$$
- 在每次 rollout 后，划分为：
  $$T_{+} = \{\tau : r(\tau) = 1\}, \quad T_{-} = \{\tau : r(\tau) = 0\}$$

### 2.2 核心三步骤

1. **事后批评生成**：仅对失败轨迹 $\tau \in T_{-}$，冻结的评判器 $\pi_J$ 在看到金标 $a^{\star}$ 与完整轨迹后输出 1–2 句简短批评：
   $$h(\tau) = \pi_J(\tau, a^{\star})$$
2. **提示条件教师**：将批评广播为前缀，构造每个搜索步的条件上下文：
   $$c_t^T = \langle\text{HINT}\rangle\, h(\tau)\,\langle/\text{HINT}\rangle \oplus c_t$$
3. **同策略蒸馏（OPD）损失**：用冻结的 $\pi_{\text{ref}}$（即学生初始化，也兼任 GRPO 的 KL 锚点）在该上下文下的对数概率，监督学生的搜索动作 token：
   $$L_{\text{OPD}} = -\frac{1}{|M|} \sum_{t \in M} \text{clamp}\!\left(\ell_t^T - \ell_t^s,\; 0,\; 1\right) \cdot \ell_t^s$$
   其中 $\ell_t^s = \log \pi_\theta(a_t \mid c_t)$，$\ell_t^T = \log \pi_{\text{ref}}(a_t \mid c_t^T)$，$M$ 是失败轨迹中 $\langle\text{SEARCH}\rangle\cdots\langle/\text{SEARCH}\rangle$ 范围内的响应 token 集合。损失仅作用于搜索动作 token，最终答案 token 留给 GRPO。

### 2.3 设计要点

- **事后性 vs 过程性**：批评在 rollout 完成后再生成，是 post-hoc 视角，无需在线 PRM。
- **指导性 vs 评估性**：批评因看到 $a^{\star}$ 而成为"应该怎么做"，而非"做得好不好"。
- **损失形式**：使用 plain-clamp OPD（独立损失项），与 OpenClaw-RL 的 PPO-clipped top-K 替代目标区分开来。
- **教师选择**：$\pi_{\text{ref}}$ 与 $\pi_\theta$ 同构（均为 Qwen2.5-3B-Instruct），教师-学生差距仅由提示上下文介导，避免能力差距导致的更新失控。
- **梯度特性**：$\ell_t^T - \ell_t^s$ 经 stop-gradient，下界 0 限制梯度仅流过教师比学生更确信的 token，上界 1 抑制离群点；最终可微部分仅为 $\ell_t^s$。

### 2.4 算法伪代码（附录 A）

包含 13 步的完整训练步骤：rollout → 计算 EM 奖励与组归一化优势 → 划分 $T_{-}$ → 冻结评判器并行生成批评 → 构造 token 掩码 $M$ → 前向计算 $\ell_t^T$ 与 $\ell_t^s$ → 计算 $L_{\text{PPO}} + \lambda_{\text{OPD}} L_{\text{OPD}}$ → 优化器更新。

  - 7B 同族教师：训练在数十步内崩溃（负结果）
- **敏感度分析**：
  - 评判器规模/家族：Qwen2.5-7B 评判器 34.8（−4.6），DeepSeek-V4-Flash 评判器 39.6（+0.2）。
  - 答案泄漏讨论：域内与 zero-shot 增益相近（+5.85 vs +5.80），反驳了记忆泄漏假设。
- **负结果附录**（附录 C）：包含 5 类失败变体（逐步批评、7B 教师、token 级评判、advantage-injection OPD、$\lambda$ 衰减调度），均劣于默认配置。
- **充分性评价**：实验在数据、基线、消融、敏感度、负结果方面均较为系统；公平性通过统一主干、检索器、训练集、评估指标得到保障。

## 6. 主要结论与发现

- HindSearch 在七项基准上以 Qwen2.5-3B-Instruct 取得 **39.4% 平均 EM**，超过此前最强搜索 RL 基线 Search-R1 GRPO（33.6）**+5.8 个百分点**。
- 训练在 300 步内稳定，未出现平台或崩溃，KL 始终低于 0.43。
- 性能提升的主要来源是**事后视角**（评判器访问 $a^{\star}$），而非评判行为本身；移除 $a^{\star}$ 抹去 4.7/5.8 的增益。
- 损失形式至关重要：plain-clamp OPD 显著优于 OpenClaw-RL 的 PPO-clipped top-K 替代（差 6.7pp），同时单独的损失结构避免了与 GRPO 优势符号冲突的问题。
- OPD 信号是**泛化的搜索行为**而非记忆：域内与 zero-shot 基准的增益几乎相等。
- 评判器容量需与学生相匹配或更强：太弱（7B）则消解监督；过强（7B 教师）则产生能力差距梯度，破坏信任域。

## 7. 优点

- **问题切入精准**：直指搜索 RL 中"稀疏奖励浪费失败信息"这一公认痛点。
- **方法简洁实用**：仅在 GRPO 之上加一个辅助 OPD 损失，工程改动小，易于复现。
- **事后性与指导性结合**：批评既具备事后视角（看到 $a^{\star}$），又是指导性而非评估性的，自然语言形式表达力强。
- **搜索动作掩码设计**：OPD 损失严格限制在 $\langle\text{SEARCH}\rangle$ 范围内，答案 token 不受影响，避免答案泄漏的捷径学习。
- **双重损失解耦**：$L_{\text{PPO}}$ 与 $L_{\text{OPD}}$ 在损失空间中正交，避免优势符号与提示对数比同号时的对抗更新问题（多个负结果均由此导致崩溃）。
- **训练成本可控**：仅对失败轨迹调用评判器，整体仅 15% 的额外墙钟开销。
- **充分的负结果**：附录 C 详列多种失败变体，体现工程经验与诚实性。
- **教师同构化策略**：使用学生初始化作为教师，将"能力差距梯度"风险降到最低。

## 8. 不足与局限

- **依赖金标准答案**：方法在训练时假设每个 prompt 都带有 $a^{\star}$，对开放式或无金标场景（如开放式生成、对话）不直接适用。
- **评判器成本与可访问性**：需要 27B 规模的冻结评判模型（Qwen3.6-27B 或等效），弱评判器（7B）显著退化；跨家族迁移也并非完全无损。
- **结果泄漏风险**：尽管作者用域内/域外增益相近来反驳，但评判器批评中可能内含 $a^{\star}$ 字符串，存在潜在捷径（虽被搜索动作掩码部分限制）。
- **主干限制**：仅实验 Qwen2.5-3B-Instruct；基座模型（Qwen2.5-3B-Base）需要额外的格式习得阶段，未覆盖。
- **检索器单一**：仅在 E5-base-v2 + Wiki-18 上验证，未测试 BM25 等稀疏检索器，结果对检索设置敏感。
- **与并发工作的可比性**：ZeroSearch 等采用不同检索设置与奖励，未做头对头比较，绝对数值可能与原论文报告不一致。
- **训练时长较短**：300 步训练虽显示未饱和，但缺乏更长训练（如 1000 步）是否会过拟合或继续提升的探索。
- **批评质量敏感性**：自然语言批评的稳定性与一致性依赖于评判器提示工程，对提示措辞敏感，作者承认这是不可控因素。
