## 摘要
本文研究在具有未知智能体目标函数和与状态相关的智能体间耦合的非线性动力系统中多智能体轨迹规划的反馈纳什均衡（FBNE）求解问题。尽管动态博弈理论为这类问题提供了原则性的框架，但现有方法通常假设智能体完全理性且目标函数已知，或依赖于固定正则化，从而限制了它们在安全关键场景中捕捉有限理性以及空间变化交互强度的能力。为此，我们提出了一种具有状态相关权重的KL正则化动态博弈，该权重能够自适应地平衡最优性与行为先验。为了从演示行为中推断未知代价参数，我们开发了一种基于最大熵逆强化学习并引入物理信息正则化的上下文感知逆博弈模块，从而确保与正向博弈之间的结构一致性。我们证明了正则化局部博弈的逐次迭代良定义性（well-posedness），并表明在有界标称轨迹更新条件下，自适应权重函数保持Lipschitz连续性。协同导航与汇入场景下的数值仿真与多机器人实验验证了所提框架的有效性。

## Abstract
This paper studies feedback Nash equilibrium (FBNE) seeking for multi-agent trajectory planning in nonlinear dynamical systems with unknown agents' objectives and state-dependent inter-agent coupling. While dynamic game theory provides a principled framework for such problems, existing approaches typically assume fully rational agents with known objectives or rely on fixed regularization, limiting their ability to capture bounded rationality and spatially varying interaction intensity in safety-critical settings. To this end, we propose a KL-regularized dynamic game with a state-dependent weight that adaptively balances optimality and behavioral priors. To infer unknown cost parameters from demonstrated behaviors, we develop a context-aware inverse game module based on maximum-entropy inverse reinforcement learning with physics-informed regularization, ensuring structural consistency with the forward game. We establish per-iteration well-posedness of the regularized local game and show that the adaptive weighting function remains Lipschitz continuous under bounded nominal-trajectory updates. Numerical simulations and multi-robot experiments on cooperative navigation and merging scenarios validate the effectiveness of the proposed framework.

## 2. 方法论

### 2.1 整体框架
前向-逆耦合架构：逆向模块从专家演示推断代价参数 $\omega$；前向模块基于 KL 正则化博弈求解 FBNE 轨迹。

### 2.2 前向博弈求解器（KLGame+ Solver）

**核心思想**：在 KL 正则化代价基础上，引入**状态自适应权重** $\lambda_i(x_t)$。

**原始成本函数**：
$$J_i(\pi_i) = \mathbb{E}_\pi\left[\sum_{t=1}^{T} c_t^i(x_t, u_t, \omega_i) + \lambda_i D_{KL}\left(\pi_t^i(\cdot|x_t) \| \tilde{\pi}_t^i(\cdot|x_t)\right)\right]$$

**状态自适应权重定义**：
$$\lambda_i(x_t) = \lambda_{\min}^i + (\lambda_{\max}^i - \lambda_{\min}^i)\,\rho_i(x_t)$$

其中风险度量 $\rho_i(x_t) = \exp\left(-\frac{d_{obs}^i(x_t)^2}{2\sigma^2}\right)$，$d_{obs}^i(x_t) := \min\{dist(p_t^i, \mathcal{O}),\, \min_{j\neq i}\|p_t^i - p_t^j\|\}$。

**关键技术细节**：
- **迭代线性化**：在标称轨迹 $\eta^k = \{\hat{x}_{0:T}^k, \hat{u}_{0:T}^k\}$ 处对动力学与代价进行二次展开：
  $$\delta x_{t+1} \approx A_t \delta x_t + \sum_{j\in[N]} B_t^j \delta u_t^j$$
- **Laplace 近似**：对参考策略 $\tilde{\pi}_t^i(u_t^i|x_t)$ 进行二阶 Taylor 展开，得到局部高斯近似 $\mathcal{N}(\tilde{\mu}_t^i, \tilde{\Sigma}_t^i)$，且 $\tilde{\mu}_t^i = \hat{u}_{t}^{i,k}$，避免原 KLGame 中的内层函数优化。
- **冻结正则化**：外层迭代中固定 $\lambda_{t}^{i,k} = \lambda_i(\hat{x}_t^k)$，保证内层 Riccati 递推的 LQ 结构。
- **定理 1（FBNE 闭式解）**：高斯反馈策略 $\pi_t^{i,*}\sim\mathcal{N}(\mu_t^{i,*}, \Sigma_t^{i,*})$，其中：
  $$\mu_t^{i,*} = -P_t^i \delta x_t - \alpha_t^i$$
  $$\Sigma_t^{i,*} = \left[\frac{1}{\lambda_i}\left(R_t^{ii} + B_t^{i\top} Z_{t+1}^i B_t^i\right) + \tilde{\Sigma}_t^{i\,-1}\right]^{-1}$$
  增益 $P_t^i$、$\alpha_t^i$ 通过耦合线性系统（式 12a-12b）求解，值函数参数 $(Z_t^i, z_t^i)$ 通过后向 Riccati 递推（式 13a-13b）计算。

### 2.3 理论保证

- **命题 1（逐次迭代良定义性）**：在假设 1（线性化非奇异、$R_t^{ii}\succeq r_{\min}^i I\succ 0$、$\tilde{\Sigma}_t^i\succ 0$）下，每步 $Z_t^i\succeq 0$、$M_{t}^{i,k}\succeq m_0^i I\succ 0$、$\Sigma_t^{i,*}\succ 0$，FBNE 唯一。
- **命题 2（Lipschitz 连续性）**：$\lambda_i(\cdot)$ 关于状态是 Lipschitz 连续的，$|\lambda_i(x)-\lambda_i(x')|\le C_\lambda^i \|x-x'\|$。

### 2.4 逆博弈求解器

**最大熵 IRL 目标**：
$$P_i(\zeta|\omega_i) \approx \frac{e^{-R_{\omega_i}(\zeta)}}{\sum_{j=1}^{M} e^{-R_{\omega_i}(\tilde{\zeta}_j)}}$$

其中 $R_{\omega_i}(\zeta) = \omega_i^\top f_\zeta^i = \omega_i^\top \sum_{t=1}^{T} f_t^i(x_t, u_t)$，$\tilde{\zeta}_j$ 为从同一初始状态的 rollout 轨迹。

**场景感知神经网络架构**：
- **编码器**：GRU 编码智能体轨迹（$d_h=128$，窗口 $H=10$），MLP 编码矢量化地图（参考 VectorNet）。
- **融合模块**：交叉注意力（$n_{head}=4$，$d_k=64$）整合自车、邻车与地图表征。
- **解码器**：两层 MLP（隐藏维 64），Softplus 输出保证 $\omega_i\succ 0$。

**总损失**：
$$L_i^{total} = L_i^{MaxEnt} + \nu_{rule}\cdot L_i^{rule}$$

其中物理规则损失 $L_i^{rule} = \mathbb{E}_{\zeta\sim D}\left[\sum_{t=1}^{T}\|f_{t}^{i,rule}(x_t, u_t)\|^2\right]$ 引入碰撞避免、对车道线偏离等硬约束，确保与前向求解器结构一致。
