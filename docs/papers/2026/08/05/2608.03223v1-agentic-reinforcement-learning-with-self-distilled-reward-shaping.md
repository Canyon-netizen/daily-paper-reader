## 摘要
智能体强化学习使大语言模型（LLM）智能体能够通过交互进行学习，但稀疏的轨迹级奖励仅揭示成功与否，却无法识别哪些中间决策应获得信用。仅在训练时使用的特权技能可以通过以下方式提供更密集的监督：在以任务匹配的程序性技能为条件的同时，允许同一个冻结的策略快照对无技能轨迹中的固定token进行重新评分。然而，现有方法并未在交互步骤间联合校准教师分数，将教师置信度与实际收益相关联，并将所产生的信号整合到原生奖励到优势（reward-to-advantage）的构建中。我们提出了基于自蒸馏奖励塑形的智能体强化学习（ADRS），一个用于为多轮语言智能体构建与收益相关联的token级信用的框架。ADRS在每一步内对特权token分数进行中心化和归一化，通过基于组内置信度-收益关联的、与收益相关联的教师价值优势（TVA）门控对其进行调制，并将门控后的token信号纳入原生强化学习信用构建。这些组件共同决定了教师偏好什么、该偏好何时与收益相关、以及它如何进入原生强化学习信用路径，同时保持rollout和推理过程无技能。最后，在三个交互式基准测试上的实验表明，ADRS在长视野任务上持续提升性能，且增益在不同的强化学习骨干、减少数据设置、未见任务和延长训练中持续存在。为匿名评审，代码可在以下链接获取：https://github.com/gitrxh/ADRS-arxiv

## Abstract
Agentic reinforcement learning enables LLM agents to learn through interaction, but sparse trajectory-level rewards reveal success without identifying which intermediate decisions deserve credit. Training-only privileged skills can provide denser supervision by allowing the same frozen policy snapshot to rescore fixed tokens from skill-free trajectories while conditioned on task-matched procedural skills. Existing methods, however, do not jointly calibrate teacher scores across interaction steps, relate teacher confidence to realized returns, and integrate the resulting signal into native reward-to-advantage construction. We introduce Agentic Reinforcement Learning with Self-Distilled Reward Shaping (ADRS), a framework for constructing return-associated token-level credit for multi-turn language agents. ADRS centers and normalizes privileged token scores within each step, modulates them with a return-associated Teacher Value Advantage (TVA) gate based on within-group confidence--return association, and incorporates the gated token signal into native RL credit construction. Together, these components determine what the teacher prefers, when that preference is return-relevant, and how it enters the native reinforcement-learning credit path, while keeping rollouts and inference skill-free. Finally, experiments across three interactive benchmarks show that ADRS consistently improves performance on long-horizon tasks, with gains persisting across RL backbones, reduced-data settings, unseen tasks, and extended training. For anonymous review, our code is available at the following the link: https://github.com/gitrxh/ADRS-arxiv

**既有方案的不足**：现有 On-Policy Self-Distillation + RL（OPSD+RL）方法（如 GRPO+OPSD、Skill-SD、RLSD、SDAR）通过在训练期附加任务匹配的程序性技能提供更密集的 token 级监督，但仍存在三大未联合解决的问题：

1. **评分校准（Score Calibration）**：原始教师对数概率在不同交互步的偏移和尺度不一致，无法直接跨步比较；
2. **可靠性估计（Reliability Estimation）**：教师高置信度未必与高环境收益对齐，可能偏好"语言学上常见"而非"真正有助于任务"的决策；
3. **信用集成（Credit Integration）**：现有方法多以辅助蒸馏损失的形式注入特权信号，绕过了原生 reward-to-advantage 计算路径，可能与组内相对优势脱节。

**整体目标**：将训练期特权技能转成"回报相关（return-associated）的 token 级信用"，但 rollout 和推理阶段保持 skill-free，并嵌入到原生 GRPO/GiGPO 的信用构造管线中。

## 2. 方法论：ADRS 框架

### 2.1 总体架构

ADRS 作为一个"信用构造层（credit-construction layer）"，连接轨迹采样与 actor 优化，由三个并行/级联模块组成：

| 模块 | 回答的问题 | 对应章节 |
|---|---|---|
| M1: Within-Step Relative Privileged Scoring | 教师偏好什么？ | §4.1 |
| M2: Return-Associated TVA Reliability Gating | 该偏好何时与回报相关？ | §4.2 |
| M3: Teacher-Guided Per-Token Advantage Modulation | 如何接入原生 RL 信用？ | §4.3 |

训练流程的关键特点：**用同一个 frozen 策略快照** $\pi_{\theta_b}$ 先后在"普通上下文"和"特权技能上下文"下对**已采样好的同一批 token** 重新打分，不生成新轨迹、不引入额外教师模型。特权文本仅在 post-rollout rescoring 阶段出现。

### 2.2 关键公式

**教师与普通上下文分数**（对已采样的 token）：

$$\ell^{b}_{s,j} = \text{sg}\bigl[\log \pi_{\theta_b}(y_{s,j}\mid h_s, y_{s,<j})\bigr], \quad \ell^{T}_{s,j} = \text{sg}\bigl[\log \pi_{\theta_b}(y_{s,j}\mid \rho(x)\oplus h_s, y_{s,<j})\bigr]$$

**M1：步内中心化与归一化**：

$$b_s = \frac{1}{|\mathcal{V}_s|}\sum_{j\in\mathcal{V}_s}\ell^{T}_{s,j},\quad q_{s,j}=\ell^{T}_{s,j}-b_s,\quad \hat{q}_{s,j}=\frac{q_{s,j}}{\sigma_q+\epsilon}$$

其中 $\sigma_q = \text{Std}_{(s',j')\in\mathcal{N}(s)} q_{s',j'}$。该构造保证 $\sum_{j\in\mathcal{V}_s}\hat{q}_{s,j}=0$，即**步内零和（stepwise zero-sum）**。

**M2：TVA 门控（组内置信度–回报关联）**：

- 定义 $\mathcal{U}$ 为所选 TVA 粒度对应的单元（L2=完成轨迹，L3=GiGPO 锚步）；
- 计算单元置信度均值 $\bar{\ell}^{T}_u$，并定义软高置信权重 $\alpha_u=\sigma(\bar{\ell}^{T}_u-\bar{\ell}^{T}_{\text{batch}})$；
- 比较"高置信侧"与"低置信侧"的预 ADRS 收益差 $d_g=\mu^{+}_g-\mu^{-}_g$，再经 $\sigma$ 映射得到门控 $m_u=\text{sg}[\sigma(\tilde{\tau}\, d_{g(u)})]$。

**Proposition 1**（TVA 作为回报关联）：在数值稳定项忽略下，

$$d_g = \frac{\text{Cov}_g(\alpha, R)}{\bar{\alpha}_g(1-\bar{\alpha}_g)}$$

即 TVA 符号与"组内教师置信度与回报的协方差"一致，解释了"为什么可以用一个标量门控吸收逐对教师错误"。

**M3：教师奖励塑形与最终优势**：

$$r^{T}_{s,j} = \eta\, m_{s,j}\, \hat{q}_{s,j}, \qquad \tilde{r}_{s,j} = r^{\text{base}}_{s,j} + r^{T}_{s,j}$$

对 GRPO：先沿轨迹路径用 $\tilde{r}$ 计算 $A^{\text{traj}}_{i,k}$（组内归一化），再在 token 路径上对 $r^{T}$ 做组内白化得到 $Z^{T}_t$：

$$A^{\text{ADRS}}_{i,k,t} = A^{\text{traj}}_{i,k} + \eta Z^{T}_{i,k,t}$$

对 GiGPO：把 $\eta Z^{T}$ 加到其 episode 级优势之上，原生 step-level branch 保持不变。

**Proposition 2**（步级零和表示）：若门控与归一化在同一交互步内共享，则 $\sum_{j\in\mathcal{V}_s} r^{T}_{s,j}=0$；从而轨迹得分与基线相同、$A^{\text{traj}}$ 不被破坏，token 路径独立保留 token 级结构调整。

**Proposition 3**（轨迹保持与 token 级梯度局部等价）：在旧 log-prob 准确、clipping 未激活时：

$$\nabla_\theta J_{\text{ADRS}}\big|_{\theta_b} = \frac{1}{|\mathcal{V}|}\sum_{t\in\mathcal{V}}(A^0_t+\Delta A_t)\nabla_\theta\log\pi_\theta(y_t\mid c_t)$$

其与"加在 $A^0_t$ 上的 detached token 辅助系数 $\Delta A_t=\eta Z^{T}_t$"的更新在行为策略点处一阶相等——这是 ADRS 用 $\Delta A_{\text{new}}=\text{Adv}_{\mathcal{B}}(\tilde{r})-\text{Adv}_{\mathcal{B}}(r^{\text{base}})$ 形式而非辅助损失的核心理由。

**Actor 损失（保留原生 PPO-style clip）**：

$$\mathcal{L}_{\text{actor}}(\theta) = -\frac{1}{|\mathcal{V}|}\sum_{t\in\mathcal{V}}\min\!\bigl[\omega_t(\theta)\, A^{\text{ADRS}}_t,\ \bar{\omega}_t(\theta)\, A^{\text{ADRS}}_t\bigr]$$

## 6. 主要结论与发现

1. **新 SOTA**：以 Qwen2.5-3B 为例，ALFWorld 整体成功率 94.5%（最强基线 +10.1），Search 宏平均 45.0 EM（+0.4），WebShop 87.5 得分 / 76.6 成功率（+2.5 / +8.6）；
2. **跨模型、跨规模稳健**：在 Qwen2.5-3B/7B 与 Qwen3-1.7B 上均取得最佳 ALFWorld 成功率（94.5 / 96.1 / 62.5）；
3. **不依赖测试时技能**：所有这些增益都来自训练期特权 → 完全 skill-free rollout/inference；
4. **长程训练持续增益**：300 步下 ADRS-global+entropy/clip 在 ALFWorld 上达到 97.7 峰值，最终 96.1，比 GRPO 高 9.4；WebShop 上峰值 84.4 比 GRPO 高 5.5；
5. **数据高效与可迁移**：仅用 60% 训练数据即超过全量 GRPO（78.1 vs 75.0）；未见任务 split 平均提升 11.9；
6. **机理解释**：动作/对象 token 与风格 token 的对数概率差距比从初始化 1.6 增至 step 150 的 95.3，表明 token 级调制把更新梯度集中在真正决定动作/对象选择的 token 上。

## 7. 方法与实验设计的亮点

- **三问分解的清晰框架**：把"特权信号使用"严格拆成 calibration / reliability / integration 三个独立技术模块，配套 3 条命题刻画各自的数学含义；
- **零和结构保证轨迹方向不漂移**（Prop. 2）：$r^{T}$ 步内零和使得 teacher 信号可以"只调 token 级、不扰 trajectory 级"；
- **TVA 作为组内置信度–回报协方差**（Prop. 1）：用简单标量门控吸收逐对教师错误，无需训练额外 value/critic；
- **原生路径集成 vs 辅助损失**：通过 $\Delta A = \text{Adv}_{\mathcal{B}}(\tilde r)-\text{Adv}_{\mathcal{B}}(r^{\text{base}})$ 与 PPO clip 直接耦合，无需新增优化器；
- **可插拔性**：在同一框架下无缝切换 GRPO/GiGPO、L2/L3 TVA、全局/逐序列归一化，对超参敏感度（$\eta$、归一化方式）做了较系统的扫描；
- **机理诊断**（动作/对象/风格 token gap）提供了非平凡的可解释性证据，避免纯黑盒式报告。

## 8. 不足与局限

1. **仍需训练期特权技能**：方法的全名是 self-distilled reward shaping，但前提是任务匹配的 procedural skill 可被确定性给出（来自带 37 通用技能 + 90 任务特定技能的 provider），在缺乏这种知识源的任务上方法不可直接迁移；
2. **零回报稳定性问题**：当组内绝大多数轨迹得到 0 奖励（如 ALFWorld 早期或难例）时，TVA 协方差信号噪声大，作者虽给出 fallback（$m=0.5$、$d_g=0$），但未对"全零回报批"做专项鲁棒性分析；
3. **Search 场景收益有限**：长程过程性任务（ALFWorld、WebShop）增益显著，而短视野 Search 上几乎与 GRPO 持平，提示方法更适用于"信噪比低、决策步稀疏"的场景，定位偏窄；
4. **对比公平性**：与 SDAR 共享同一评测体系与超参搜索空间，但 ADRS 的对比是其直接前作，存在 baseline 自家优化的潜在偏差风险；与同时期更强基线（如 RAGEN、Agent Lightning、近期 RLVR 类工作）比较缺失；
5. **可复现与算力披露**：仅指明"多卡 H100"但未给具体 GPU 数、训练时长、token 量，外部难以精确复现成本；
6. **统计显著性**：主表给出单点指标与 best/final/last-3，未报告多次随机种子的均值与置信区间，超参扫描（$\eta$、normalize_mode）的方差也未量化；
7. **应用范围限制**：闭卷问答、低层推理（如数学链式思考）类任务未覆盖，且"技能检索"的可获得性限制了其在缺乏环境元数据的开放域任务上的迁移。
