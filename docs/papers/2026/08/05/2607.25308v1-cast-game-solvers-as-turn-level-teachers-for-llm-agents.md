## 摘要
训练大语言模型（LLMs）在长视野游戏中执行动作，是迈向通用决策的有前景一步，然而带有可验证奖励的强化学习（RLVR）依赖于稀疏的最终奖励，这些奖励几乎无法揭示哪些决策决定了成功。更密集的过程信号可以弥补这一缺失的回合级信用分配，但现有信号源难以同时保持低成本与高准确性。我们观察到，游戏求解器状态值的变化能够揭示某个动作是否将状态向成功推进。基于这一洞察，我们提出了CAST（Credit Assignment from Solver Teachers，来自求解器教师的信用分配），它将这些价值变化转化为求解器优势，并将其作为回合级信号注入到RLVR中。我们进一步证明，在软最优求解器的假设下，最大化求解器优势等价于来自求解器的在策略蒸馏，仅需要标量值而非教师logits。在推箱子（Sokoban）、扫雷（Minesweeper）和华容道（Rush Hour）上，CAST在域内及未见难度评估下，每款游戏均优于所有训练基线，并在ALFWorld和WebShop上取得了最高的平均零样本性能。代码已在 https://github.com/Wloner0809/CAST 开源。

## Abstract
Training large language models (LLMs) to act in long-horizon games is a promising step toward generalist decision-making, yet reinforcement learning with verifiable rewards (RLVR) relies on sparse final rewards that reveal little about which decisions determine success. Denser process signals could supply this missing turn-level credit, but existing sources are hard to keep both cheap and accurate. We observe that changes in a game solver's state value reveal whether an action advances the state toward success. Building on this insight, we propose CAST (Credit Assignment from Solver Teachers), which converts these value changes into solver advantages and injects them into RLVR as turn-level signals. We further show that, under a soft-optimal solver assumption, maximizing the solver advantage is equivalent to on-policy distillation from the solver, requiring only scalar values rather than teacher logits. Across Sokoban, Minesweeper, and Rush Hour, CAST outperforms all trained baselines on every game under both in-domain and unseen-difficulty evaluation and achieves the highest average zero-shot performance on ALFWorld and WebShop. Our code is available at https://github.com/Wloner0809/CAST.

## 1. 核心问题与研究动机

**长期博弈中的信用分配困境**：将大语言模型（LLM）训练为可在长视野游戏中行动的智能体，是迈向通用决策的重要一步。然而现有主流方法——带可验证奖励的强化学习（RLVR）——依赖稀疏的最终胜负奖励，只能告诉智能体"赢了"或"输了"，无法定位轨迹中**哪些具体回合或动作**决定了成败。这在 Sokoban、Minesweeper、Rush Hour 等需要数十乃至上百步规划的游戏中尤为突出，构成根本性的**回合级信用分配难题**。

**现有密集信号的局限**：目前的密集过程信号（如搜索扩展、过程奖励模型、跨轨迹分组如 GiGPO）普遍存在成本、监督可靠性或信号粒度之间的权衡，难以同时做到廉价、准确、密集。

**核心洞察**：既然游戏求解器（heuristic search / DP / 专用价值网络）能从任意中间状态完成对局，那么**求解器状态值的变化**就能测量"这一动作是否让状态更接近成功"。这正是 RLVR 缺失的、廉价的、回合级的密集信号。

## 2. 方法论：CAST 框架

### 2.1 求解器优势（Solver Advantage）

求解器为每个状态 $s$ 分配一个 cost-to-go $N(s)$（最短路径长度或清雷所需步数）。定义势函数 $\Phi(s) = -N(s)$，则每步的求解器优势为状态值变化：

$$A^{\pi_{\text{Solver}}}(s_t, a_t) = -1 + N(s_t) - \mathbb{E}_{s_{t+1}}[N(s_{t+1})]$$

为使"前进一步"映射为正分，平移得到**移位求解器优势**：

$$\tilde{A}^{\pi_{\text{Solver}}}(s_t, a_t) = A^{\pi_{\text{Solver}}}(s_t, a_t) + 1 = N(s_t) - \mathbb{E}_{s_{t+1}}[N(s_{t+1})]$$

其中最优动作得 $+1$，无效动作得 $0$，导致不可解死状态的动作得 $-N(s_t)$（封顶惩罚）。

### 2.2 信号整形：稳定化处理

- **asinh 压缩**：$g(x) = \operatorname{asinh}(x) = \ln(x + \sqrt{x^2+1})$。在 $|x|$ 小时近似线性，保留小步进信号；在大值时仅对数增长，压缩死状态惩罚。
- **批次级 RMS 归一化**：$h(x) = g(x) / \left(\operatorname{RMS}_B(g) + \epsilon\right)$，其中 $\operatorname{RMS}_B(g)$ 是当前 batch 内所有回合的均方根。**不减去均值**，以保留"0=无进展"的语义。

### 2.3 与 GRPO 集成

将回合级求解器优势加到 GRPO 轨迹级优势之上，并广播到 token 级别：

$$\hat{A}_{i,t} = \hat{A}^{\text{outcome}}_i + \alpha \cdot h\!\left(\tilde{A}^{\pi_{\text{Solver}}}(s_{i,t}, a_{i,t})\right)$$

其中 $\alpha = 0.1$ 为默认权重。三层粒度在此汇合：$\hat{A}^{\text{outcome}}_i$ 锚定全局胜负；$h(\tilde{A}^{\pi_{\text{Solver}}}_{i,t})$ 逐步细化；总和广播到 token。

### 2.4 理论：等价于"无 Logit 在策略蒸馏"（Logit-Free OPD）

**关键观察**（引理 C.5）：在软最优温度 $\tau > 0$ 的假设下，求解器作为最大熵 MDP 的最优策略，其 log 偏好与优势成正比：

$$A^{\pi_{\text{Solver}}}(s, a) = \tau \log \pi_{\text{Solver}}(a|s)$$

**定理 2.1**（隐式目标）：在小信号假设下，训练规则 8 的策略梯度等价于：

$$J(\theta) = \mathbb{E}_{s_0\sim\mu}\!\big[V^{\pi_\theta}_{\text{task}}(s_0)\big] - \beta\, \mathbb{E}_{s\sim d^{\pi_\theta}}\!\big[H(\pi_\theta(\cdot|s),\, \pi_{\text{Solver}}(\cdot|s))\big]$$

$$\beta = \frac{\alpha \tau}{\sqrt{2}\,(\operatorname{RMS}_B(g) + \epsilon)}$$

即隐式地**同时最大化任务回报**并**最小化到求解器的交叉熵**（OPD 目标）。由于 $A^{\pi_{\text{Solver}}} = \tau\log\pi_{\text{Solver}}$，**一个标量已编码教师对动作的偏好**，无需教师 logits 即可蒸馏。

**学生可超越教师**（推论 C.8）：解析最优策略满足：

$$\pi^*(a|s) \propto \pi_{\text{Solver}}(a|s) \cdot \exp\!\left(\frac{1}{\beta} A^{\pi_\theta}_{\text{task}}(s, a)\right)$$

求解器作为先验，任务优势作为指数修正；$\beta \to \infty$ 时退化为求解器，$\beta$ 有限时学生可偏离求解器。

附录进一步证明 $O(H\epsilon_\pi)$ 的次优性界（优于行为克隆的 $O(H^2\epsilon_\pi)$），并给出全域鲁棒化推论（C.10），说明 asinh 自然提供逐步变化的蒸馏强度 $\beta_{\text{eff}}$。

## 3. 实验设计

### 3.1 训练游戏与基准

- **Sokoban**：6×6 / 2 盒子（ID），7×7 / 3 盒子（Unseen）。
- **Minesweeper**：6×6 / 7 地雷（ID），7×7 / 10 地雷（Unseen）。
- **Rush Hour**：6×6 / 7 辆车（ID），6×6 / 9 辆车（Unseen）。
- 每关 200 个独立生成的实例，经求解器校验可解、去重。
- **零样本 OOD**：ALFWorld（具身家务，6 种任务类型，seen 验证集）与 WebShop（500 条测试指令）。

### 3.2 评测与基线

- 基础模型：Qwen3-4B-Instruct-2507（统一 back bone）。
- 训练基线：GRPO、Shao 2024；GSPO、Zheng 2025；DAPO、Yu 2026a（CAST 的 back bone）；GiGPO、Feng 2026（过程级基线）。
- 闭源参考（ReAct 提示）：Gemini-2.5-Flash/Pro、Claude Sonnet-4.5/4.6、Opus-4.5/4.6。
- 评测指标：Avg@4（即每实例 4 次独立 rollout 取平均成功率），3 个随机种子取平均。
- 评测回合预算：Sokoban/Minesweeper ID=30 步、Unseen=40 步；Rush Hour 20 步。
- 推理设置：SGLang 服务，温度 0.6，top-p 0.95，最大 16384 token/回合。

### 3.3 求解器实现

- Sokoban：基于状态 $(player, \{boxes\})$ 的 $A^\star$ 搜索，最小代价盒-目标分配作为可纳启发。
- Minesweeper：约束推理 + 全局雷概率推理，返回确定性的 reveal 步数。
- Rush Hour：预计算反向 BFS 全状态距离表，超出则回退 IDA$^\star$。

### 3.4 消融与分析

- 求解器权重 $\alpha \in \{0.01, 0.1, 0.3, 0.5\}$。
- 是否使用 asinh 压缩、是否使用批次 RMS 归一化。
- 学习求解器：用 DQN 的价值网络替代精确求解器，验证可推广性。

- **可学求解器**：在 Rush Hour 上用 DQN 替代精确求解器的对比。
- **算力开销分析**：三层粒度（环境步 / 轨迹 / 训练步）的饼图分解。
- **OOD 案例研究**：WebShop 完整轨迹对比 base 模型与 CAST（Sokoban 训练后）的行为差异。

**客观性与公平性**：

## 6. 主要结论与发现

1. **主表（表 1）**：CAST 在所有 3 个游戏、ID 与 Unseen 两个难度下均取得最佳 Avg@4。三游戏平均 ID 62.1 / Unseen 28.4，比 DAPO（44.7 / 18.7）提升 17.4 / 9.7 个百分点，超过最佳过程级基线 GiGPO（45.4 / 20.8）约 16.7 / 7.6 个百分点。Minesweeper ID 提升最显著（+14.9 vs 最佳训练基线）。
2. **样本效率**：达到 DAPO 峰值验证性能所需步数：Sokoban 120（vs 200，1.7×）、Minesweeper 200（vs 400，2.0×）、Rush Hour 140（vs 240，1.7×）。
3. **零样本 OOD 迁移（表 2）**：CAST 在 ALFWorld（37.9）和 WebShop（22.7）上均取得最高平均，整体 30.3 比次优高 5.6 个百分点；超过 ReAct 提示的基模型。
4. **消融**：$\alpha = 0.1$ 在验证和训练奖励上同时最优；过小则信号稀释，过大则压制稀疏最终目标；asinh 与 RMS 均为必需，缺一不可。
5. **可学求解器**：用 DQN 价值网络（Rush Hour）替代精确求解器后，CAST+DQN 几乎与精确求解器版本相当，验证该方法不依赖手工求解器。
6. **算力开销**：求解器查询占训练步总时长约 73 ppm，几乎可忽略。
7. **WebShop 案例**：Sokoban 训练后的模型在面对错误产品时主动重新搜索、校验颜色约束后再购买，展示了**错误恢复与约束检查**能力——可归因于推箱子训练中学到的规划纪律。

## 7. 优点

- **极致廉价的密集信号**：求解器一次状态查询仅标量 cost-to-go，无需 logit、PRM 训练或搜索扩展，开销忽略不计；论文给出了多层级量化证据。
- **漂亮的形式化连接**：定理 2.1 把"简单移位 + 整形 + 加到 GRPO 优势"这种工程直觉**严格证明**为对学生到求解器交叉熵的优化，构造了"无 Logit"蒸馏的理论桥梁。
- **稀疏目标 + 密集辅助的稳妥设计**：保留 0/1 终局奖励作为"任务真目标"，求解器信号仅作为过程辅助；避免了 reward hacking 与目标偏离。
- **方法可扩展**：当无精确求解器时，DQN 价值网络仍能提供大部分收益；附录附录 C.5.6 还基于 Performance Difference Lemma 给出 $O(H\epsilon_\pi)$ 的次优性界。
- **实验覆盖全面**：训练域 + 跨难度 + 跨域 OOD + 消融 + 样本效率 + 算力开销 + 案例研究，证据链完整。
- **干净归因**：与 DAPO 共享 back bone + 相同稀疏奖励，差异即求解器信号；超过 GiGPO 表明这是信号源本身的优越性，而非实现细节。
- **可解释性**：WebShop 案例展示了所学策略的具体行为（拒绝错误、约束校验、重新搜索），将抽象的"过程信号"化为可读的行为模式。

## 8. 不足与局限

- **应用域受限**：方法依赖**领域精确求解器**或可靠 cost-to-go 函数。论文承认在 Minesweeper 中由于部分可观测性，需手动定义近似成本 $K(s)$ 而非真正的最优 cost-to-go。**对于无高效求解器的开放世界/通用 agent 任务（如网页导航、机器人），成本如何获取、误差如何控制？** 论文未深入讨论。
- **可学求解器仅在 Rush Hour 验证**：DQN 替代实验仅在一款游戏、一个尺寸下做，未在 Sokoban、Minesweeper 上重复；价值网络与精确求解器在性能上限上的差距未充分量化。
- **算力与可复现性不透明**：未披露 GPU 型号/数量、总训练时长、训练 token 量等关键信息；闭源模型仅 1 次运行；评估细节略有差异（闭源 vs 开源温度不同）。
- **实验统计严谨性**：平均值多为 3 个种子，但闭源对比未取种子平均；未做显著性检验；Ablation 仅在 Sokoban 单游戏上完成，跨游戏泛化未充分验证。
- **OOD 提升的来源未深入分析**：ALFWorld/WebShop 提升归因于"规划纪律迁移"，但论文未做控制性分析——例如在训练集上保留/移除规划性游戏的归因实验，或在 ToT-difficulty gradient 上做迁移曲线。
- **Asinh + RMS 的理论解释略有限**：尽管附录 C.5 用小信号近似给出了 $\beta$ 闭式，但 $\alpha$、RMS 系数与训练损失尺度之间的耦合关系是经验选择；不同游戏/不同策略初始化下的鲁棒性未充分研究。
- **未与最新过程级方法对比**：如 VinePPO、Turn-PPO、Segment Policy Optimization 等近期文献未列入对比。
- **Minesweeper Unseen 表现仍较弱**（11.0），论文承认仍有空间，表明在更高难度下方法的边际收益减小；可能受限于求解器自身在更复杂局面下的精度。
- **死状态惩罚 $-N(s_t)$ 的封顶是启发式**：可能与 asinh 压缩产生交互，最坏情形未分析。
