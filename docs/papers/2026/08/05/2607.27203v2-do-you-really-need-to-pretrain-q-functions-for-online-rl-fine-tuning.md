## 摘要
预训练加微调已成为学习高性能策略的主流方法。在基于价值的强化学习（RL）中，这引出一个自然的问题：给定一个预训练策略，Q 函数是否也应该在离线数据上进行预训练？传统观点认为应该如此，但最近的研究结果表明，使用随机初始化的 Q 函数进行在线 RL 也能得到高性能且可靠的策略，无需对 Q 函数进行预训练。在本文中，我们系统地研究了当在预训练的基础策略之上进行微调时，预训练 Q 函数是否真的有帮助。我们惊讶地发现，朴素的 Q 函数预训练相比随机初始化往往几乎没有收益。我们证明这源于一个根本性的不匹配：预训练阶段学到的 Q 函数针对的是预训练策略的 Q 函数，而非在线微调最终收敛到的 Q 函数，并且即使经过离线价值最大化，这一差距仍然存在。受这一发现的启发，我们提出了基于策略集成的初始化方法（Initialization via Policy Ensemble, IPE），该方法训练多个多样化策略，并将它们汇集的 rollout 数据用于在线 RL 中 Q 函数学习的引导。在一系列具有挑战性的连续控制基准测试上，IPE 在微调性能上相比朴素的 Q 函数预训练平均取得了 1.26 倍的提升。

## Abstract
Pre-training followed by fine-tuning has become the dominant recipe for learning performant policies, and in value-based reinforcement learning (RL) this raises a natural question: given a pretrained policy, should the Q-function be pretrained on offline data too? Conventional wisdom suggests it should, but recent results show that online RL with a randomly-initialized Q-function can result in highly performant and reliable policies without needing to pretrain the Q-function. In this paper, we systematically study whether pretraining the Q-function actually helps when fine-tuning on top of a pretrained base policy. We find, surprisingly, that naive Q-function pretraining often provides little benefit over random initialization. We show this stems from a fundamental mismatch: the Q-function learned during pretraining targets the pretrained policy's Q-function, not the Q-function that online fine-tuning converges to, and this gap persists even after offline value maximization. Motivated by this finding, we propose Initialization via Policy Ensemble (IPE), a simple method that trains multiple diverse policies and uses their pooled rollouts to bootstrap the Q-function learning in online RL. Across a suite of challenging continuous control benchmarks, IPE yields an average 1.26x improvement in fine-tuning performance over naive Q-function pre-training.

## 1. 核心问题与研究动机

- **背景**：预训练 + 在线 RL 微调已成为学习高性能策略的主流范式（如 VLA 模型微调）。在基于价值的 RL 中，一个自然的问题是：**给定预训练策略 $\pi_{\text{base}}$，是否还需要在离线数据上预训练 Q 函数 $Q_\phi$？**
- **传统认知 vs 实际矛盾**：传统直觉认为预训练越多越好，因此 Q 函数也应离线预训练；但近期工作（如 EXPO-FT）表明，使用随机初始化的 Q 函数 + 在线训练即可取得高性能。
- **研究空白**：现有 offline-to-online RL 工作多要求策略与 Q 函数联合通过 offline RL 算法训练，难以直接迁移到通用预训练策略（如监督学习得到的 VLA）。
- **本文聚焦**：当**仅有一个预训练好的 base 策略与离线数据**时，系统评估 Q 函数预训练对在线 RL 微调的影响，并探索更优替代方案。
- **核心发现**：朴素 Q 函数预训练几乎无收益，甚至有时有害；根源在于 $\ Q^{\pi_{\text{base}}} \neq Q^{\pi^*_{\text{RL}}}\ $，即离线学到的 Q 函数目标与在线 RL 实际所需目标存在根本错配。

## 2. 方法论：IPE（Initialization via Policy Ensemble）

### 2.1 问题形式化
- 考虑 MDP $\mathcal{M} = \{\mathcal{S}, \mathcal{A}, \rho, r, \gamma, T\}$，目标最大化期望折扣回报。
- 已有：预训练 base 策略 $\pi_{\text{base}}$（通过监督学习得到）和离线数据集 $\mathcal{D}_{\text{offline}}$。
- Q 函数通过 TD 学习训练：

$$
\mathcal{L}(\phi) = \mathbb{E}_{(s_t,a_t,s_{t+1})\sim\mathcal{D}}\left[\left(r_t + \gamma Q_{\phi'}(s_{t+1}, \tilde{a}^*_{t+1}) - Q_\phi(s_t,a_t)\right)^2\right]
$$

- 采用 off-policy RL 算法 **EXPO**：base flow 策略 + edit policy $\pi_{\text{edit}}$，推理时取 $N$ 个采样动作的最大 Q 值：

$$
\tilde{a}^* = \arg\max_{a \in \mathcal{S}^N_{i=1}\{a_i, \tilde{a}_i\}} Q_\phi(s,a)
$$

### 2.2 核心思想
- 单个策略产生的动作分布过于狭窄（即使 expressive 也很局限），使 Q 函数在状态–动作覆盖上"塌缩"为 $Q^{\pi_{\text{base}}} \approx V^{\pi_{\text{base}}}$，丧失对动作价值的区分能力。
- 通过训练多个独立但都针对同一动作分布的策略，并汇集其 rollout，可以**在不改变数据先验的前提下显著扩大动作覆盖**，使 Q 函数能学到对替代动作的偏好，从而更接近在线 RL 所需的 $Q^{\pi^*_{\text{RL}}}$。

### 2.3 IPE 算法流程（Algorithm 1）
1. 在 $\mathcal{D}_{\text{offline}}$ 上训练一个 base 策略 $\pi_{\text{base}}$；
2. 额外训练 $N$ 个独立策略 $\{\pi_i\}_{i=1}^{N}$，监督学习目标与 $\pi_{\text{base}}$ 相同；
3. 在环境中分别 rollout $\pi_{\text{base}}$ 和 $\{\pi_i\}_{i=1}^{N}$，合并所得转移数据到 replay buffer $\mathcal{D}$；
4. 用此 buffer 引导在线 RL 微调。
- $N=0$ 时退化为普通在线 RL warm-up；实验中 $N=5$ 时效果最佳。
- **关键优势**：无需修改微调算法本身，仅替换 replay buffer 初始化方式。

  - `square (ph)`：将工具插入方形钉孔。

  - `cube-double`：多色方块取放；
  - `scene`：长程多物体交互；
  - `puzzle-4x6`：组合"熄灯"类拼图泛化。

### 3.2 对比方法
- **Naive Q-pretraining**：在 $\mathcal{D}_{\text{offline}}$ 上离线 TD 训练 Q 函数后在线微调。
- **No pretraining**（baseline）：Q 函数随机初始化，仅在线训练。
- **Offline value maximization variants**：
  - 学习 EXPO edit policy；
  - Max Q + BC 蒸馏（类似 FQL，Park et al. 2025b）；
  - Action gradient 直接更新预训练策略。
- **IPE**（N=1, 2, 3, 5）：用不同数量策略 rollout 引导 buffer。
- 评估指标：**success rate**（3 随机种子均值与方差）、**preference accuracy**（Q 函数对 $\pi_{\text{base}}$ vs $\pi^*_{\text{RL}}$ 动作的偏好准确度）、**action variance**。

### 3.3 实验设置
- 算法基础：**EXPO**（UTD=1 主实验；附录另有 UTD=20 及 RLPD 比较）。
- 共享超参：Adam 优化器、$\gamma=0.99$、critic 目标更新率 $0.005$、batch size 256、10 个 Q 函数、min Q 取 2、diffusion 去噪 10 步、actor/critic 学习率 $3\times10^{-4}$。

## 6. 主要结论与发现

- **Takeaway 1**：朴素 Q 函数预训练**几乎不加速微调**，有时还劣于随机初始化。
- **Takeaway 2**：预训练 Q 函数 $\ Q^{\pi_{\text{base}}} \neq Q^{\pi^*_{\text{RL}}}\ $；二者目标函数不同，偏好结构虽相关但不一致，且这一错位与 base 策略最优性无关（即使 base policy 近 100% 成功率仍存在）。
- **Takeaway 3**：离线值最大化（3 种变体）**不能**桥接 $Q^{\pi_{\text{base}}}$ 与 $Q^{\pi^*_{\text{RL}}}$ 的差距，必须依赖在线交互。
- **方法贡献**：IPE 通过扩大动作覆盖缓解 $Q \approx V$ 塌缩，平均带来 **1.26×（约 26%）**性能提升，超过 naive Q-pretraining；且随着策略数 $N$ 增加持续改进（$N=5$ 最优）。

## 7. 优点与亮点

- **挑战传统认知**：明确反直觉地指出"Q 函数应被预训练"的常规观点在很多情况下不成立，对社区有范式提醒意义。
- **机制解释深入**：不仅报告现象，还用 preference accuracy 指标揭示 $\ Q^{\pi_{\text{base}}}\ \text{vs}\ Q^{\pi^*_{\text{RL}}}\ $ 错配根源，诊断明确。
- **方法简洁实用**：IPE 不需改 RL 算法，仅修改 replay buffer 初始化方式，落地门槛低。
- **分析多维度**：动作多样性、Q 函数方差、性能曲线、preference score、算法扩展（UTD、RLPD）多角度交叉支撑结论。
- **正反消融完整**：包含朴素预训练 / 无预训练 / 离线值最大化 / IPE-scaling 等多个对照。

## 8. 不足与局限

- **任务规模受限**：实验均用小规模监督学习策略，未在论文重点关注的大规模 VLA 模型（如 $\pi_{0.5}$、$\pi^*_{0.6}$）上直接验证，作者承认留作未来工作。
- **算法范围**：仅验证 off-policy RL（EXPO 与 RLPD），on-policy 方法（如 PPO）下的结论未涉及。
- **数据收集开销**：IPE 需要训练并 rollout $N+1$ 个策略，相对单策略预训练引入**额外数据收集与计算成本**；作者明确指出未解决此开销问题。
- **依赖可获得 base 策略与数据**：IPE 假设已有监督预训练策略和离线数据集；对极端小数据或极弱 base policy 情形未讨论。
- **preference accuracy 度量假设**：依赖训练 10 个"成功率达 100%"的参考 critic，对不可达 100% 成功率的真实场景可能不再适用。
- **算力透明性不足**：未公开 GPU 类型、数量、训练时长，限制复现可比性。
