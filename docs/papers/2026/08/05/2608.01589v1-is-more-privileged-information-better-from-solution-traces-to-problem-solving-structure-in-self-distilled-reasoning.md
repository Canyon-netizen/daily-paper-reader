## 摘要
在策略自蒸馏（On-policy self-distillation, OPSD）通过使用以参考答案条件化的模型的特权视角来监督仅观察到问题的学生视角，从而提升推理能力。然而，教师提供的词元级目标可能依赖于在推理时不可获得的、参考答案特有的信息。我们提出了问题空间引导的 OPSD（PS-OPSD），它用基于轨迹的引导取代完整解答，这些引导描述了初始状态、目标条件、约束条件以及选定的状态转移路径。学生端的展开过程与 OPSD 目标函数保持不变。在三个数学推理基准上，覆盖从 1.7B 到 8B 的模型规模，PS-OPSD 在所比较方法中取得了最高的仅基于问题的总体准确率。受控实验进一步表明，引导的相关性与路径的一致性共同促成了这些提升，凸显出特权信息的表示形式是 OPSD 中一项重要的设计选择。

## Abstract
On-policy self-distillation (OPSD) improves reasoning by using a privileged view of a model conditioned on reference solutions to supervise a student view that observes only the question. However, the teacher-provided token-level targets may depend on reference-specific information unavailable at inference time. We propose Problem-Space-Guided OPSD (PS-OPSD), which replaces the complete solution with trajectory-grounded guidance describing the initial state, goal conditions, constraints, and a selected state-transition path. The student rollout and OPSD objective remain unchanged. Across three mathematical reasoning benchmarks and model scales ranging from 1.7B to 8B, PS-OPSD achieves the highest aggregate question-only accuracy among the compared methods. Controlled experiments further indicate that guidance relevance and path coherence contribute to these gains, highlighting the representation of privileged information as an important design choice in OPSD.

## 1. 核心问题与研究动机

**核心问题**：在策略自蒸馏（On-Policy Self-Distillation, OPSD）框架中，特权教师模型被赋予完整的参考答案作为附加条件，但这种设计面临训练-推理接口的**不对称性**问题：

- **训练时**：特权教师可访问完整参考答案 $r$，据此给出 token 级监督；
- **部署时**：学生模型只能看到问题 $q$，参考答案不可得；
- **风险**：参考答案的具体表述、计算细节、特定推理顺序与措辞可能使教师的 token 目标携带**仅在参考答案中可得、与当前实例强绑定**的依赖信号，学生在推理时无法重建这些信息，从而削弱迁移性。

论文还引入了近期研究观察到的**行为症状**：使用 OPSD 训练的模型在推理过程中可能显式提及"参考答案""答案键""提示"等不可见来源——这表明完整参考答案确实会引入不易迁移的特权信息依赖。

由此论文提出一个**先于损失函数设计的表征问题**：

$$\text{特权教师应观察怎样的信息？}$$

论文回归经典的**问题空间理论**（problem-space view，Newell & Simon 1972），结合"结构关系比表面形式更易迁移"的关系迁移理论（Gentner 1983），主张不应将参考答案作为完整 trace 暴露给教师，而应将其改写为围绕问题求解结构的关系性表征。

## 2. 方法论：PS-OPSD

### 2.1 核心思想

提出 **Problem-Space Guidance（问题空间引导）** $g_{PS}(q,r)$，用四类结构化字段替代完整解题答案：

| 字段 | 含义 |
| :--- | :--- |
| Initial State $s_0$ | 变量、实体、已知量与关系 |
| Goal Conditions $G$ | 目标值与可验证的成功条件 |
| Constraints $C$ | 域限制、全局不变量与合法性条件 |
| Selected State-Transition Path $\pi$ | 一条从参考解抽取的有序操作链 |

其中概念上的问题空间为：

$$P(q) = \langle S, s_0, O, G, C \rangle$$

但因完整枚举 $S, O$ 不可行，且一条参考解仅揭示一条现实化路径，离线提取器对每组 $(q,r)$ 序列化出：

$$g_{PS}(q,r) = \langle s_0, G, C, \pi \rangle$$

每条状态转移记录为：

$$\tau_i = \langle o_i, \text{pre}_i, \text{transform}_i, s_i \rangle$$

即：操作名 $o_i$、前置条件 $\text{pre}_i$、诱导变换 $\text{transform}_i$、结果状态 $s_i$。

### 2.2 训练流程

PS-OPSD **仅修改特权教师的上下文**，学生 rollout 与 OPSD 目标保持不变：

$$p^{OPSD}_{T,t} = p_T(\cdot \mid q, r, \hat{y}_{<t}), \quad p^{PS}_{T,t} = p_T(\cdot \mid q, g_{PS}(q,r), \hat{y}_{<t})$$

$$p_{\theta,t} = p_{\theta}(\cdot \mid q, \hat{y}_{<t})$$

学生仍以仅问题模式在策略采样 $\hat{y} \sim p_\theta(\cdot \mid q)$；教师在统一前缀处给出 token 级目标分布，并据此优化学生。提取阶段为离线完成，提取器在训练与推理时均不可用。

### 2.3 损失函数

采用 coordinate-clipped KL 形式以稳定训练。设温度 $T$ 下的 softmax 分布 $p^{(T)} = \text{softmax}(z_p/T)$，$q^{(T)} = \text{softmax}(z_q/T)$，逐词表坐标贡献定义为：

$$d_T(p,q;v) = p^{(T)}(v)\,\log\frac{p^{(T)}(v)}{q^{(T)}(v)}$$

引入裁剪阈值 $c$，得到：

$$\overline{D}_{c,T}(p \,\|\, q) = \sum_{v \in V} \min\{d_T(p,q;v),\ c\}$$

最终优化目标为：

$$\mathcal{L}_{PS\text{-}OPSD} = \mathbb{E}_{(q,r)\sim D}\,\mathbb{E}_{\hat{y}\sim p_\theta(\cdot \mid q)}\!\left[\frac{1}{|\hat y|}\sum_t \overline{D}_{c,T}\!\left(p^{PS}_{T,t}\,\|\,p_{\theta,t}\right)\right]$$

关键性质：

- 词表求和完整进行，裁剪作用于每个坐标；
- 仅优化学生参数 $\theta$，$p_T$ 与缓存的引导 $g$ 保持固定；
- 推理时无引导、无教师、无提取器，仅 $p_\theta(\cdot \mid q)$。

### 2.4 算法流程

算法 1（PS-OPSD Procedure）简要概述：
1. **离线阶段**：对 $D = \{(q_i, r_i)\}_{i=1}^N$ 预先提取并缓存 $g_i \leftarrow g_{PS}(q_i, r_i)$；
2. **训练循环**：从缓存中抽取 $(q, g)$ 小批 → 学生 on-policy 采样 $\hat y$ → 对每个前缀 $t$ 计算 $p^{PS}_{T,t}$ 与 $p_{\theta,t}$ → 计算剪裁 KL 损失 → 仅更新学生 LoRA 参数。

### 5.2 公平性评估

论文采用的"oracle envelope consistency"口径是较严格的：

- 对每种方法、每个基准，挑选**三种子中精度最高**的检查点；
- 报告均值与样本标准差；
- Avg 为该基准最优检查点的简单平均；
- $\text{Avg}$ 既不是某一检查点的单点，也不是固定检查点的均值，论文明确说明这一选择；
- 每个基准都被独立列出与对齐，避免选择性报告。

### 5.3 公平性残留问题

- AVSD 是**方法级**对比而非表征对比，与 PS-OPSD 不在同一抽象层；
- 通过 oracle envelope 报告均值，可能放大变体随机性最有利的结果；
- 表 2 指出 Flattened PS 在 HMMT25 比 PS-OPSD 高 1.39 分，提示字段结构的作用在不同基准并不一致；
- "oracle envelope"的统计显著性仍受到样本量（90 题/基准）与仅 3 个种子的限制。

总体而言，实验在体量上**较为扎实**（3 模型 × 3 基准 × 6 方法 × 3 种子 + 4 表示对照 + 行为/熵诊断），但在算力公开、统计检验、跨模型族外推方面仍有不足。

## 6. 主要结论与发现

### 6.1 主性能结论

在三档模型规模上，PS-OPSD 的 $\text{Avg}$ 分别为 **43.12 / 64.32 / 65.40**，相对最强基线每档高出 **1.54–2.04 个百分点**：

| 规模 | Base | SFT | GRPO | OPSD | AVSD | **PS-OPSD** |
| :--- | ---: | ---: | ---: | ---: | ---: | ---: |
| 1.7B Avg | 36.67 | 38.86 | 37.69 | 41.08 | 39.01 | **43.12** |
| 4B Avg | 61.76 | 61.60 | 62.38 | 61.70 | 62.78 | **64.32** |
| 8B Avg | 62.31 | 62.53 | 63.30 | 63.58 | 63.64 | **65.40** |

在 9 个规模-基准单元中，PS-OPSD 严格最高有 6 个，其余 3 个差距很小（≤0.65 分）。

### 6.2 路径结构与相关性是关键收益源

| 4B 条件 | AIME24 | AIME25 | HMMT25 | Avg |
| :--- | ---: | ---: | ---: | ---: |
| PS-OPSD | 76.57 | 70.56 | 45.83 | **64.32** |
| Flattened PS | 75.37 | 68.24 | 47.22 | 63.61 |
| Mismatched PS | 74.63 | 67.31 | 43.33 | 61.76 |
| Path-Corrupted PS | 73.06 | 68.89 | 44.63 | 62.19 |

- **Mismatched** 与 **Path-Corrupted** 都在所有基准全面低于 PS-OPSD，说明**目标相关性与全局路径连贯性**是核心；
- **Flattened** 仅次 0.71 分（HMMT25 上反而更高），说明显式字段结构是**辅助**而非决定性。

### 6.3 行为与熵诊断

- **显式 PI 调用率**：OPSD 训练集 3.0%、保留验证集 2.2%；PS-OPSD 训练集 0.5%、保留验证集 0.4%——降低 4–6 倍，提示对不可见参考的依赖显著降低；
- **正确路径 token 熵**：在最佳检查点，OPSD 与 PS-OPSD 相对 Base 的熵差均为正（分布未变尖锐），表明收益**并非**来自"让正确路径更尖锐"；
- **容量依赖**：在 1.7B 上 PS-OPSD 略低于 OPSD，在 4B/8B 上 Pass@12、Avg、HC 均高于 OPSD，表明结构化引导在小模型容量上的迁移成本与在大模型上的覆盖增益并不对称。

### 6.4 问题级覆盖与硬题子集

相对 Base：

- PS-OPSD $\Delta = +2.56$（18 升 / 7 降 / 65 不变），最大幅；
- AVSD $\Delta = +1.02$，GRPO $\Delta = +0.62$，OPSD $\Delta = -0.06$，SFT $\Delta = -0.15$；
- 在 Base-hard 子集（Base 完全答错的题）上，PS-OPSD 将 hard-accuracy 从 OPSD 的 1.69% 提升到 **4.35%**，pass 率从 8.70% 提升到 13.04%，保留率从 97.01% 提升到 98.51%。

## 7. 优点与亮点

- **问题定位明确**：将 "完整参考答案" 与 "可迁移性" 之间的张力显式化，提出以**教师上下文表征设计**取代"灌入更多上下文"，思路新颖；
- **理论锚定扎实**：援引 Newell & Simon 的问题空间理论与 Gentner 的结构映射理论，给出形式化的概念模型 $P(q) = \langle S, s_0, O, G, C \rangle$，再回退到实用形式 $g_{PS}(q,r) = \langle s_0, G, C, \pi \rangle$，避免过度承诺；
- **方法零侵入性**：学生 rollout、OPSD 损失、教师实现均不变，仅替换教师上下文，便于嵌入现有 OPSD 流水线；
- **三尺度跨模型验证**：1.7B / 4B / 8B 同族模型 + 三种子 + 三基准，比较稳定；
- **消融设计层次清楚**：Flattened / Mismatched / Path-Corrupted 三个对照变量分别对应"字段结构 / 目标相关性 / 路径连贯性"三个假说，揭示机制；
- **行为与熵双诊断**：既验证 PI 调用率下降（行为级），又验证正确路径熵变化（分布级），避免单点解释；
- **离线成本与可复用性**：提取器一次预计算+缓存，与训练解耦，便于扩展到其他数据。

## 8. 不足与局限

### 8.1 表征层面

- **仅捕获单条参考路径**：$g_{PS}$ 是从**一条**已验证参考解抽取的实例化轨迹，未覆盖完整 $S, O$；当一条参考解不典型或冗余时，引导可能误导；
- **抽象粒度依赖 LLM 提取器**：使用 Qwen3.6-35B-A3B 作为离线提取器会引入自身的语法风格、字段切分偏好与潜在错误，构成**提取器侧偏置**；
- **数学领域限定**：在文本结构不如数学清晰的推理任务（如多跳问答、代码）中，问题空间表示的可操作性需要重新验证；
- **错误恢复缺位**：论文承认未设计中间错误恢复机制，引导假设路径各步可线性推进。

## 8. 不足与局限（续）

### 8.2 实验层面（续）

- **PI 调用率与熵为"症状级"证据而非机制证据**：调用率与熵是可观测量，但未直接给出"教师条件概率 $p^{PS}_T$ 到底在哪个字段上施加了监督"或"学生表征是否真正学会了 $s_0 / G / C / \pi$ 之间的解耦"的探针测试；
- **评测仅 $K=12$**：在仅 90 题的基准上，1–2 个题目的偏差就能显著移动均值，oracle envelope 在小 $K$ 下尾部风险被放大；
- **缺少数值稳定性度量**：未报告 log-prob 收敛曲线、KL 散度的训练曲线、LoRA 适配器范数等过程性指标，外部读者难以判断训练是否平稳；
- **未做"教师能力上限"分析**：未剥离"教师是否足够强以至于需要结构化引导"这一替代假说，未在更强教师（如 235B 量级）下复核 PS-OPSD 的边际收益是否仍成立；
- **数据局限**：训练语料为数学推理子集，HMMT25 上 Flattened PS 反而高于 PS-OPSD 提示了"字段结构收益并非单调"，未做"哪些题型受益、哪些受损"的细分。

### 8.3 概念与表达层面

- **"特权教师"的语用冲突**：论文虽强调教师仅在上下文层做改动，但形式上仍沿用 OPSD 的 "privileged teacher" 框架，部分读者可能混淆"改变条件信息"与"改变教师能力"；
- **"问题空间"的形式化较浅**：$P(q) = \langle S, s_0, O, G, C \rangle$ 是符号化定义，未给出在向量空间的对应嵌入或可微近似，因此"问题空间引导"目前仍是**字符串级条件**，未触及表征层；
- **缺乏"反事实"基准**：未报告若学生训练时也直接以 $g_{PS}$ 为条件会发生什么（即把引导从"教师私有"搬到"学生共有"），从而无法区分"引导本身"与"教师私有引导"的边际贡献。

## 9. 启示与后续工作方向

### 9.1 方法论启示

- **表征设计先于损失设计**：在 OPSD/RLKD 类框架中，"教师应看什么"是相对低成本但高影响的改动点，无需重写学生 rollout 或重训教师；
- **关系性表征优于表面 trace**：将答案改写为 $\langle s_0, G, C, \pi \rangle$ 的四元结构，与人类解题教学（列已知—求什么—约束—操作链）天然对齐，具备较好的"教学可解释性"潜力；
- **离线提取—缓存—解耦**是降低工程复杂度的关键：所有昂贵 LLM 调用只在数据预处理阶段发生一次，训练循环与 OPSD 完全同构。

### 9.2 后续可探索的问题

1. **多路径 $\pi$ 聚合**：从 $K$ 条参考解或采样解中提取多条 $\pi$，在教师上下文做集合化条件，看是否能进一步降低硬题上的错误恢复失败率；
2. **可学习的字段编码器**：将 $s_0 / G / C / \pi$ 编码为独立的 embedding 前缀而非字符串，验证在向量层做"问题空间条件"是否会进一步压缩训练-推理接口 gap；
3. **跨域迁移**：将 PS 引导套到代码生成（$s_0$ = 已知 API / 输入；$G$ = 测试期望；$C$ = 类型 / 不变量；$\pi$ = 调用序列）与多跳 QA（$s_0$ = 段落实体；$G$ = 答案类型；$C$ = 一致性约束；$\pi$ = 桥接句链）；
4. **错误恢复机制**：在 $\pi$ 上引入"回退 / 替换 / 试探"等元操作元语，允许引导描述"若某步失败则尝试另一条分支"；
5. **提取器偏置审计**：用不同提取器（不同模型族 / 不同提示）提取 $g_{PS}$，观察收益是否随提取器风格变化，剥离"提取器侧风格偏置"；
6. **教师能力分层**：在不同教师规模（如 0.5B / 8B / 35B / 235B）下分别引入 PS 引导，绘制"教师容量 × 引导结构化程度"的收益图，定位结构化引导的边际效用何时饱和；
7. **与过程奖励模型（PRM）的耦合**：将 $\langle \pi_i \rangle$ 的逐步正确性作为额外过程奖励信号，探索 PRM + PS-OPSD 的协同；
8. **学生侧的"重建式"正则**：在训练时加入一项辅助损失，鼓励学生在没有 $g_{PS}$ 的情况下也能"在内部"重建四元结构，从而在推理时降低对引导的隐性依赖。

## 11. 一句话总评

PS-OPSD 以"教师应被赋予何种信息"为切入口，将完整参考答案替换为 $\langle s_0, G, C, \pi \rangle$ 的问题空间关系性表征，在 Qwen3 1.7B / 4B / 8B × AIME24/25/HMMT25 上以 3 种子取得相对最强基线 +1.5–2.0 Avg 分的稳定收益，并通过 Flattened / Mismatched / Path-Corrupted 三组消融与 PI 调用率、token 熵双诊断共同支撑了"目标相关 + 路径连贯是关键收益源、字段结构为辅助"的结论。方法改动小、理论锚定清晰、可直接嵌入现有 OPSD 流水线，是"表征设计先于损失设计"这一思路的有力范例；其主要不足在于仅捕获单条参考路径、依赖 LLM 提取器、数学领域外推未验证，以及算力与超参披露不足导致的复现性缺口。
