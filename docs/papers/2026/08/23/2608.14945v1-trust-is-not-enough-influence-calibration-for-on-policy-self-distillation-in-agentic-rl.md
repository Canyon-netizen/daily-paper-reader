## 摘要
在线策略自蒸馏（OPSD）通过一个特权自教师在策略自身轨迹上为语言智能体提供稠密的 token 级监督。现有方法主要依据教师信任度来分配这种监督，但信任度并不能揭示强调某个 token 是否支持当前策略目标。我们将此称为信任—效用失配，并提出面向自蒸馏的影响校准（ICSD）。对每个被监督的 token，ICSD 测量其重要性加权的强化学习替代贡献对教师导向输出扰动的一阶响应。批次自适应校准将这一非平稳信号转化为有界的分配权重，同时在每个动作回合内保留原有辅助损失的总量。这些分离出的权重仅影响蒸馏损失，无需额外的模型前向传播。在 ALFWorld、WebShop 和 Search-QA 上，ICSD 在 Group Relative Policy Optimization（GRPO）和 Group-in-Group Policy Optimization（GiGPO）下、在涵盖 1.5B 至 7B 的两个模型系列上，全面优于仅基于信任度的分配所对应的所有匹配聚合指标。在 7B 规模上，它在 ALFWorld 上达到 96.1% 的成功率，在 WebShop 上取得 93.1 的分数。冻结批次分析表明，ICSD 将分配给目标相悖 token 的教师支持质量占比从 60.1% 降低到 37.8%，并将面向强化学习梯度的余弦兼容性提升了 0.192。配套代码仓库已公开，地址为 https://github.com/lanqz7766/Influence-Calibration-for-On-Policy-Self-Distillation-in-Agentic-RL。

## Abstract
On-policy self-distillation (OPSD) gives language agents dense token-level supervision from a privileged self-teacher on the policy's own trajectories. Existing methods allocate this supervision mainly by teacher trust, but trust does not reveal whether emphasizing a token supports the current policy objective. We call this the trust-utility mismatch and introduce Influence Calibration for Self-Distillation (ICSD). For each supervised token, ICSD measures the first-order response of its importance-weighted RL surrogate contribution to a teacher-directed output perturbation. Batch-adaptive calibration converts this non-stationary signal into a bounded allocation weight while preserving the original auxiliary-loss mass within each action turn. These detached weights affect only the distillation loss and require no additional model pass. Across ALFWorld, WebShop, and Search-QA, ICSD improves all matched aggregate metrics over trust-only allocation under Group Relative Policy Optimization (GRPO) and Group-in-Group Policy Optimization (GiGPO), across two model families spanning 1.5B to 7B. At 7B, it reaches 96.1% ALFWorld success and a WebShop score of 93.1. Frozen-batch analyses show that ICSD reduces teacher-supported mass assigned to objective-opposed tokens from 60.1% to 37.8% and raises cosine compatibility with the RL gradient by 0.192. # 论文总结：Trust Is Not Enough — 面向智能体强化学习中在线策略自蒸馏的影响校准

## 1. 核心问题与研究动机

**在线策略自蒸馏（OPSD）** 已成为长视野语言智能体强化学习中弥合奖励稀疏性与 token 级决策之间粒度差距的关键手段。OPSD 利用特权自教师（privileged self-teacher）在学生自身 rollouts 上对每个 token 给出稠密监督信号；典型代表如 Skill-SD、SDAR、SAGE-OPD、TurnOPD 等。

然而这些方法普遍存在 **信任—效用失配（trust–utility mismatch）**：

- **信任（trust）**：衡量教师信号是否"可信"，通常依据师生分歧、不确定性、token 位置等指标；
- **效用（utility）**：衡量沿教师方向更新是否真正有助于当前 RL 目标改善。

二者是两个独立问题。在冻结的 ALFWorld 批次上，仅依赖信任度分配的 SDAR 会把 **60.1%** 的教师支持权重放在当前目标相悖的 token 上。这正是本文要解决的核心痛点。

> **论文核心主张**：信任不足以决定 token 级监督的分配方式，必须引入对当前 RL 目标的一阶影响度量。

---

## 2. 方法论：Influence Calibration for Self-Distillation (ICSD)

### 2.1 总体框架

ICSD 直接作用于已有的特权蒸馏分支，不改动 RL 替代目标。其流程为：
1. 学生策略 $\pi_\theta$ 在上下文 $x_t$ 上采样 token $a_t$；
2. 特权分支 $\pi_\theta^+$ 在额外上下文 $z_t$（如技能）下评估该 token；
3. 计算教师—学生 gap 与 token 级 RL 信号；
4. 经 ICSD 校准得到分配系数 $c_t$；
5. 系数作用于辅助蒸馏损失，不再传播梯度至特权概率。

### 2.2 关键公式

**教师—学生 gap（停梯度）**：
$$\Delta_t = \mathrm{sg}\!\left[\log \pi_\theta^+(a_t\mid x_t,z_t) - \log \pi_\theta(a_t\mid x_t)\right]$$

**基础信任权重**（继承自 SDAR）：$g_t = G_{\mathrm{trust}}(\Delta_t)\in[0,1]$，使用分裂参数为 $0.4$ 的非对称 Laplace CDF。

**教师导向输出扰动**：
$$\log \rho_t(\epsilon) = \log \rho_t + \epsilon\Delta_t,\quad \rho_t(\epsilon)=\rho_t e^{\epsilon\Delta_t}$$

**教师导向目标影响（一阶 Taylor 系数）**：
$$u_t := \left.\frac{d\,\hat A_t \rho_t(\epsilon)}{d\epsilon}\right|_{\epsilon=0} = \hat A_t\,\rho_t\,\Delta_t$$

其中 $\hat A_t$ 为 token 优势，$\rho_t = \pi_\theta(a_t\mid x_t)/\pi_{\mathrm{old}}(a_t\mid x_t)$ 为策略比。

### 2.3 批量自适应校准

绝对尺度 $u_t$ 在不同 minibatch 间不稳定，因此对每个校准组 $G$（按动作回合索引汇集）拟合中位数与两侧均值：
$$\hat\mu_G = \mathrm{median}_{j\in G} u_j,\quad \hat b_G^\pm = \mathrm{mean}_{j\in G:\, u_j\lessgtr \hat\mu_G} |u_j-\hat\mu_G|$$

并用非对称 Laplace CDF（分裂点 $\eta=0.5$，scale floor $\varepsilon$）映射到 $(0,1)$：
$$\Phi_G(u) = \begin{cases} \eta\exp\!\left(\dfrac{u-\hat\mu_G}{\hat b_G^-}\right), & u < \hat\mu_G \\[4pt] 1-(1-\eta)\exp\!\left(-\dfrac{u-\hat\mu_G}{\hat b_G^+}\right), & u \ge \hat\mu_G \end{cases}$$

设 $\tilde m_t = \Phi_G(u_t)$。

### 2.4 保守合成与回合级质量守恒

当 $\hat A_t<0$ 且 $\Delta_t<0$（双负）时，两者方向矛盾，保留基础信任权重。定义：
$$D=\{t\in B:\hat A_t<0,\ \Delta_t<0\},\quad C = B\setminus D$$

对每个动作回合 $q$，若 $\sum_{j\in C_q} g_j\tilde m_j>0$，计算缩放因子：
$$\alpha_q = \frac{\sum_{j\in C_q} g_j}{\sum_{j\in C_q} g_j\tilde m_j}$$

最终分配系数：
$$c_t = \begin{cases} g_t, & t\in D_q \\ \alpha_q\,g_t\,\tilde m_t, & t\in C_q \end{cases}$$

**关键不变性（命题 1）**：
$$\sum_{t\in q} c_t = \sum_{t\in q} g_t,\quad \forall q\in Q$$

即 ICSD 在每个动作回合内精确保持辅助损失总质量不变，仅做内部重分配。整个计算无需额外模型前向传播，仅为停梯度算术与 CDF 拟合。

## 6. 主要结论与发现

1. **全面优于信任分配**：在 ALFWorld、WebShop、Search-QA 上，ICSD 在 GRPO/GiGPO、1.5B–7B 范围内均优于 SDAR 的信任分配。
2. **7B 规模结果**：ALFWorld 成功率 94.5 → **96.1%**；WebShop Score 88.4 → **93.1**、Accuracy 78.9 → **84.4**。
3. **机制验证（冻结批次）**：
   - 分配给目标相悖 token 的教师支持质量占比由 **60.1% → 37.8%**（下降 22.3 pp，95% CI [22.1, 22.6]）；
   - 与 RL 梯度的余弦相容性提升 **+0.192**（95% CI [0.147, 0.240]），且 **16/16 批次**均提升；token 排列控制仅 +0.020，证明改进来自 **token 分配** 而非总质量。
4. **消融结论**：unsigned Fisher 幅度（91.4%）、Sign-only（92.2%）、Influence-only（93.0%）均弱于完整 ICSD（93.8%），表明 **带符号的连续影响 + 教师信任** 缺一不可。
5. **优化器无关**：GRPO 与 GiGPO 下一致生效，WebShop Accuracy 在 GRPO 下提升 +11.7 pp、GiGPO 下 +7.0 pp。
6. **敏感性**：分裂点 $\eta=0.5$、$\lambda=0.01$、非对称 Laplace 校准为最佳超参。
