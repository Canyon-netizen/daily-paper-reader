## 摘要
在线策略自蒸馏（OPSD）在策略自身轨迹上通过特权自教师为语言智能体提供密集的逐词元监督。现有方法主要通过教师信任度来分配此类监督，但信任度并不能揭示强调某个词元是否有助于当前策略目标。我们将此称为信任-效用失配，并提出自蒸馏影响校准（ICSD）。对于每个受监督的词元，ICSD衡量其重要性加权的强化学习替代贡献对教师导向输出扰动的一阶响应。批次自适应校准将该非平稳信号转化为有界的分配权重，同时保留每个动作轮次内的原始辅助损失总量。这些解耦权重仅作用于蒸馏损失，且无需额外的模型前向传播。在 ALFWorld、WebShop 和 Search-QA 上，在分组相对策略优化（GRPO）和分组内分组策略优化（GiGPO）框架下，ICSD 在覆盖 1.5B 到 7B 的两个模型系列上全面优于仅基于信任度的分配方法，所有匹配聚合指标均有提升。在 7B 模型上，其在 ALFWorld 上达到 96.1% 的成功率，WebShop 得分为 93.1。冻结批次分析表明，ICSD 将分配给目标对立词元的教师支持质量从 60.1% 降至 37.8%，并将强化学习梯度的余弦兼容性提升 0.192。配套代码仓库见 https://github.com/lanqz7766/Influence-Calibration-for-On-Policy-Self-Distillation-in-Agentic-RL。

## Abstract
On-policy self-distillation (OPSD) gives language agents dense token-level supervision from a privileged self-teacher on the policy's own trajectories. Existing methods allocate this supervision mainly by teacher trust, but trust does not reveal whether emphasizing a token supports the current policy objective. We call this the trust-utility mismatch and introduce Influence Calibration for Self-Distillation (ICSD). For each supervised token, ICSD measures the first-order response of its importance-weighted RL surrogate contribution to a teacher-directed output perturbation. Batch-adaptive calibration converts this non-stationary signal into a bounded allocation weight while preserving the original auxiliary-loss mass within each action turn. These detached weights affect only the distillation loss and require no additional model pass. Across ALFWorld, WebShop, and Search-QA, ICSD improves all matched aggregate metrics over trust-only allocation under Group Relative Policy Optimization (GRPO) and Group-in-Group Policy Optimization (GiGPO), across two model families spanning 1.5B to 7B. At 7B, it reaches 96.1% ALFWorld success and a WebShop score of 93.1. Frozen-batch analyses show that ICSD reduces teacher-supported mass assigned to objective-opposed tokens from 60.1% to 37.8% and raises cosine compatibility with the RL gradient by 0.192. A companion repository is avail- able at https://github.com/lanqz7766/Influence-Calibration-for-On-Policy-Self-Distillation-in-Agentic-RL.

## 1. 核心问题与研究动机

- **背景**：语言智能体越来越多地采用在线强化学习（on-policy RL）进行长周期交互训练，但其奖励信号极其稀疏（通常每条轨迹一次），与逐决策的密集 token 级反馈严重不匹配。
- **现有方案**：在线策略自蒸馏（OPSD, On-Policy Self-Distillation）通过特权分支（privileged branch，例如轨迹派生的技能）评估学生自身 rollout，得到 token 级密集监督。但现有方法主要依据"教师信任度"分配监督权重，例如：
  - 师生差距（gap）$Δ_t$（SDAR）
  - 不确定性 / 一致性 / 熵 / 位置偏好 / 奖励-教师一致性
- **关键缺陷（信任-效用失配, Trust–Utility Mismatch）**：信任度高 ≠ 该 token 的修正方向与当前 RL 目标一致。在冻结的 ALFWorld 批次上，仅基于信任的分配会把 **60.1%** 的教师支持质量分配到与当前策略目标对立的 token 上。
- **作者论点**：需要在保留教师信任信号的基础上，再叠加"目标端效用"信号来决定 token 级分配。

## 2. 方法论：ICSD（Influence Calibration for Self-Distillation）

### 2.1 形式化设定

- 设 $B$ 为当前 mini-batch 中有效 response token 集合。学生在位置 $t$ 采样 token $a_t$，特权分支 $\pi_\theta^+(\cdot|x_t,z_t)$ 评估该 token，$z_t$ 为轨迹派生技能等额外上下文。
- Token 级辅助蒸馏损失：
  $$\hat{\ell}^{KD}_t(\theta)=\mathrm{sg}\!\left[\log \pi_\theta^+(a_t|x_t,z_t)\right]-\log \pi_\theta(a_t|x_t)$$
- 停梯度（detached）的师生差距：
  $$\Delta_t=\mathrm{sg}\!\left[\log\pi_\theta^+(a_t|x_t,z_t)-\log\pi_\theta(a_t|x_t)\right]$$
- 总目标：
  $$\mathcal{L}(\theta)=\mathcal{L}_{\mathrm{RL}}(\theta)+\frac{\lambda}{|B|}\sum_{t\in B}\mathrm{sg}(c_t)\,\hat{\ell}^{KD}_t(\theta)$$
- 其中 $c_t\ge0$ 为解耦的分配系数；继承自 SDAR 的信任权重 $g_t=G_{\text{trust}}(\Delta_t)\in[0,1]$ 仍然保留。

### 2.2 教师导向的目标影响（Teacher-Directed Objective Influence）

- 直接在输出坐标上做教师扰动：$\rho_t(\epsilon)=\rho_t e^{\epsilon\Delta_t}$，其中 $\rho_t=\pi_\theta(a_t|x_t)/\pi_{\text{old}}(a_t|x_t)$，$\hat A_t$ 为 token 优势。
- 一阶 Taylor 系数即 **目标影响得分**：
  $$u_t=\left.\frac{d\,\hat A_t\rho_t(\epsilon)}{d\epsilon}\right|_{\epsilon=0}=\hat A_t\rho_t\Delta_t$$
- 命题：$u_t>0$ 时，沿教师方向增加采样 token 概率会提升当前 RL 替代目标；$u_t<0$ 则相反。其优势在于：只用 RL 更新已有的 $\hat A_t,\rho_t,\Delta_t$，**无需额外模型前向或 Hessian 求逆**。

### 2.3 批次自适应校准（Batch-Adaptive Calibration）

- 原始 $u_t$ 受 advantage、ratio、gap 尺度漂移和重尾影响，按动作轮次索引聚合到校准组 $G\subseteq B$。
- 对每个组 $G$ 计算：中位数 $\hat\mu_G$ 与两侧 one-sided MAD 尺度 $\hat b_G^-,\hat b_G^+$，并设定尺度下界 $\varepsilon>0$。
- 不对称 Laplace 族 CDF 形式的校准映射（分裂点 $\eta=0.5$）：
  $$\Phi_G(u)=\begin{cases}\eta\exp\!\left(\dfrac{u-\hat\mu_G}{\hat b_G^-}\right), & u<\hat\mu_G\\[4pt]1-(1-\eta)\exp\!\left(-\dfrac{u-\hat\mu_G}{\hat b_G^+}\right), & u\ge\hat\mu_G\end{cases}$$
- 校准分数 $\tilde m_t=\Phi_G(u_t)\in(0,1)$，是组内相对得分而非概率。

### 2.4 保守组合（Conservative Composition）

- 双负区（$\hat A_t<0,\;\Delta_t<0$）下：辅助损失方向与教师方向相反，$u_t>0$ 会造成误导性"支持"。定义：
  $$\mathcal{D}=\{t\in B:\hat A_t<0,\;\Delta_t<0\},\quad \mathcal{C}=B\setminus\mathcal{D}$$
- 在 $\mathcal{D}$ 中保留继承的信任权重 $c_t=g_t$；在 $\mathcal{C}$ 中按 $c_t=\alpha_q g_t\tilde m_t$ 重新分配，缩放系数：
  $$\alpha_q=\frac{\sum_{j\in C_q}g_j}{\sum_{j\in C_q}g_j\tilde m_j}$$
- 分母为 0 时退化为 $c_t=g_t$。

### 2.5 不变性与守恒（Proposition 1）

- 在 $\mathcal{C}$ 内同信任、同轮的 token 排序与 $u_t$ 一致。
- **动作轮次质量守恒**：
  $$\sum_{t\in q}c_t=\sum_{t\in q}g_t,\quad\forall q$$
- 全局层面 $\sum_{t\in B}c_t=\sum_{t\in B}g_t$，即 ICSD 不增加也不减少辅助预算。
- 校准映射对 $u$ 的正仿射变换 $u'_j=au_j+b$（$a>0$）保持不变，进一步保障跨批次跨阶段的可比性。

### 2.6 训练目标

- 最终 actor 更新仍采用 $\mathcal{L}(\theta)$，$c_t$ 与特权对数概率均被停梯度，因此辅助梯度只通过学生对数概率回传。
- 离线等价物：在理想自然梯度步 $\delta_\theta=\eta F^{-1}\Delta_t s_t$ 下，token 自贡献的一阶变化为 $\eta\kappa_t u_t+o(\eta)$，其中 $\kappa_t=s_t^\top F^{-1}s_t\ge 0$，为影响得分提供理论直觉。

## 3. 实验设计

### 3.1 数据集 / 场景与基准

- **ALFWorld**（6 个子任务：Pick / Look / Clean / Heat / Cool / Pick2）：以任务成功率衡量。
- **WebShop**：使用 Score 与 Accuracy 两个指标。
- **Search-QA**：基于 Search-R1 的七个子集（NQ、TriviaQA、PopQA、HotpotQA、2WikiMultiHopQA、MuSiQue、Bamboogle），取平均值。
- **策略优化算法**：GRPO 与 GiGPO；动作最大交互步长 ALFWorld 50、Search-QA 4、WebShop 15。

### 3.2 模型与训练协议

- 模型家族与尺寸：Qwen2.5-Instruct（1.5B / 3B / 7B），Qwen3-1.7B / Qwen3-4B。
- 完全沿用 SDAR 的数据划分、SkillBank、关键词检索与特权自教师。
- 关键超参：蒸馏系数 $\lambda=0.01$，CDF 分裂参数 $\eta=0.5$，信任 split 参数 $0.4$，尺度下界 $10^{-4}$，最小校准组大小 8；actor 学习率 $1\times10^{-6}$，ratio clip $0.2$，KL 系数 ALFWorld/WebShop 为 0.01、Search-QA 为 0.001。
- 训练步数：ALFWorld / WebShop 各 150 步，Search-QA 200 步。

### 3.3 对比方法

- **RL 基线**：GRPO、GiGPO。
- **纯辅助**：OPSD（均匀分配）。
- **信任选择型 OPSD**：SDAR（基线对比锚点）。
- **混合蒸馏**：Skill-SD、Skill-GRPO（\*号表示评估时保留技能）。
- **耦合 RL 反馈**：RLSD、EGRSD、PBSD、SG-OPD、DOPD、RG-OPD、CRAFT 等。
- **位置 / 不确定性**：TIP、Position-Weighted 等。
- 重点比较对象：在模型、数据、RL 算法、特权教师与继承信任分配完全一致的条件下，**信任基线 SDAR** vs. **ICSD**。

## 4. 资源与算力

- 在 Qwen2.5-1.5B WebShop 匹配对比中：每方法使用 **4 块 H100 GPU**。
- 计算开销：ICSD 不引入额外 forward / backward，仅增加 detached 元素运算与 CDF 拟合。
  - actor-update 阶段每 token 时延相对 SDAR **+1.7%**；
  - 折算到端到端 step 时间约 **+0.4%**（actor 更新约占 step 时间的 1/5）。
- 训练总时长未在论文中明确给出，但每任务仅 150–200 个训练步，单卡规模可见整体开销相对小。
- **未明确披露**：全局训练机时、总 GPU 小时数或显存占用。

## 6. 主要结论与发现

- **性能结果**（匹配对照下）：
  - Qwen2.5-7B / GiGPO：ALFWorld 成功率 **94.5 → 96.1**，WebShop Score/Acc **88.4/78.9 → 93.1/84.4**。
  - Qwen2.5-3B / GiGPO：ALFWorld 93.0 → 95.3，Search-QA Avg 42.6 → 43.3。
  - Qwen2.5-1.5B / GiGPO：ALFWorld 92.2 → 93.8，WebShop 88.8/71.1 → 92.2/78.1。
  - Qwen3-4B / GiGPO：ALFWorld 89.8 → 95.3。
  - Qwen3-1.7B / GiGPO：ALFWorld 75.0 → 82.8。
  - GRPO 下也有普遍提升，例如 Qwen2.5-1.5B WebShop Acc **+11.7** 点。
- **机制层面**：
  - TCM 从 **60.1% 降至 37.8%**（95% CI [22.1, 22.6]，4 批次每批均下降）。
  - 与 RL 梯度余弦兼容性平均 **+0.192**（16 批次均为正，CI [0.147, 0.240]），排列置换后只剩 +0.020，证明改进来自 token 配对而非质量大小。
  - 四象限分配转移：$\Delta_t>0,\hat A_t>0$ 区多分配 **+6.2 pp**，$\Delta_t>0,\hat A_t<0$ 区少 **−7.5 pp**，$\Delta_t<0,\hat A_t>0$ 区少 **−1.5 pp**，双负区不变。
  - 强信任强支持区获得 $2.90\times$/ $2.64\times$ 放大（ALFWorld/WebShop），强信任但对立区仅 $0.79\times$。
- **消融结论**：仅 Fisher 幅度（无符号）=91.4%，有符号无连续评分=92.2%，仅影响无信任=93.0%，组合二者（ICSD）=93.8%——**信任 × 连续有符号影响** 是有效配对。

## 7. 优点

- **问题定义精准**：明确指出"信任-效用失配"，并把 token 级蒸馏损失解释为对 *已有 RL 更新方向* 的辅助再分配，而非新目标。
- **工程友好**：分配系数 $c_t$ 完全 detached，不增加模型前向或额外存储，端到端开销 ≈0.4%。
- **理论完备**：提供 Taylor 余项界、仿射不变性证明、动作轮次守恒证明、参数空间自然梯度直觉。
- **机制可验证**：通过 TCM、梯度余弦兼容性、置换对照、四象限分配转移等多角度独立印证方法有效性，而非仅靠汇总指标。
- **通用性**：横跨 GRPO / GiGPO 两种优化器、Qwen2.5 / Qwen3 两个家族、1.5B–7B 五个配置与三类任务，迁移成本低。

## 8. 不足与局限

- **算力披露不充分**：未报告总训练机时、累计 GPU 数或显存峰值，仅在 1.5B WebShop 上做了 4×H100 的微观开销审计。
- **Teacher 能力天花板依赖**：ICSD 仍依赖 SDAR 的特权自教师与轨迹派生技能，没有解决教师自身能力上限、长序列蒸馏误差累积、以及推理模型中"先思考再行动"模式下的特权分支失效问题。
- **Search-QA 增益有限**：相对 ALFWorld / WebShop 而言增益较小，模型-任务可迁移性仍受任务结构影响。
- **近似边界**：影响得分基于未裁剪的替代目标；clip 外 token 占比仅 0.128%，但在 ratio 偏离 1 的训练阶段仍需关注。
- **消融粒度**：当前消融主要在 Qwen2.5-1.5B / GiGPO / ALFWorld 上，未在其他尺寸 / 优化器 / 任务下重复，结论的外推尚需更多证据。
- **未见与最新过程奖励 / Critic 基线的强对照**：未与 PRM、step-level reward shaping 等近期强基线进行匹配对照，难以判断在奖励侧已经做过精细化设计的方法上 ICSD 的边际收益。
- **风险**：信任权重与影响得分皆为 detached，存在训练-评估分布漂移下分数失配的可能；TCM 等机制分析仅在 4 个冻结批次上得出，样本量较小。
