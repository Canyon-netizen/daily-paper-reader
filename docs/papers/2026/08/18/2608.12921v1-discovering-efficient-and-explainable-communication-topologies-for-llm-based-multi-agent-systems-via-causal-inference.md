## 摘要
基于大语言模型（LLM）的多智能体系统（MAS）的性能在很大程度上取决于有效的通信拓扑。然而，现有的拓扑生成方法通常通过仅由任务级奖励驱动的黑盒优化来学习通信拓扑。虽然有效，但此类优化几乎无法解释为何选择特定的通信边，使得难以识别负责成功协作的关键通信子图。为了解决这一局限，我们提出了E2-Explainer，这是一个与模型无关的框架，可为任意拓扑生成器产生的通信拓扑提供可解释的解释。具体而言，我们将拓扑解释形式化为一个因果归因问题，旨在识别出由边级任务保持证据支持的紧凑通信子图。我们通过一个类Granger的目标函数来获取该证据，该目标函数衡量屏蔽每个通信通道如何改变任务结果以及最终响应的稳定性。随后，将所得的预算受限子图蒸馏为一个摊销式解释器，从而无需在部署时重复进行边级评估即可实现高效的后解释。在多个推理和编码基准上的大量实验表明，E2-Explainer能够识别出可保持成功协作的关键通信子图。这些子图还可以被直接执行以剪枝冗余的通信边，在保持具有竞争力的任务性能的同时大幅降低通信成本。

## Abstract
The performance of large language model (LLM)-based multi-agent systems (MAS) largely depends on effective communication topologies. Existing topology generation methods, however, typically learn communication topologies through black-box optimization driven solely by task-level rewards. While effective, such optimization provides little insight into why particular communication edges are selected, making it difficult to identify the critical communication subgraphs responsible for successful collaboration. To address this limitation, we propose E2-Explainer, a model-agnostic framework for providing interpretable explanations of communication topologies produced by arbitrary topology generators. Specifically, we formulate topology explanation as a causal attribution problem that identifies compact communication subgraphs supported by edge-level evidence of task preservation. We obtain this evidence with a Granger-style objective that measures how masking each communication channel changes the task outcome and the stability of the final response. The resulting budgeted subgraphs are then distilled into an amortized explainer, enabling efficient post-hoc explanation without repeated edge-level evaluations at deployment. Extensive experiments on multiple reasoning and coding benchmarks demonstrate that E2-Explainer identifies critical communication subgraphs that preserve successful collaboration. These subgraphs can also be executed directly to prune redundant communication edges, substantially reducing communication costs while maintaining competitive task performance.

## 1. 核心问题与研究动机

LLM多智能体系统（MAS）的协作性能高度依赖通信拓扑设计。现有的拓扑生成方法（如G-Designer、ARG-Designer、OFA-MAS等）多采用任务奖励驱动的黑盒优化，仅以端到端任务分数作为反馈信号，缺乏对单条通信边或局部子结构贡献的归因能力。这一局限带来两个核心问题：

- **冗余性难以揭示**：论文通过对G-Designer生成图进行随机边掩码实验（图1），发现即使随机移除50%~80%的边，大多数掩码后准确率仍接近或超过原图，说明生成拓扑中存在大量冗余通信边，但随机剪枝又难以稳定地保留有效通信。
- **缺乏因果归因**：现有方法无法识别对任务成功起决定性作用的"关键通信子图"，既不利于通信成本的优化，也不利于审计与解释。

因此，论文的核心问题是：**如何对任意拓扑生成器产生的通信图进行后验的、模型无关的因果解释，从而识别紧凑且保持任务行为的通信子图？**

## 2. 方法论

### 2.1 核心思想

将拓扑解释形式化为**因果归因问题**：借鉴Granger因果思想，对每条通信边 $e$ 进行单边干预（掩码），测量任务分数与响应稳定性的变化，从而评估边的因果贡献；再将得到的因果子图作为监督信号，蒸馏为一个摊销式（amortized）解释器 $\mathcal{F}_\theta$，使其在部署时能一次性预测预算受限的紧凑子图。

### 2.2 问题形式化

给定查询 $x$ 与拓扑生成器 $\mathcal{G}_\phi$ 生成的通信图 $G=(\mathcal{V},\mathcal{E})$，目标是寻找紧凑子图：
$$H \subseteq G, \quad H^\star_b \in \mathcal{H}_b(G), \quad Q(x, H^\star_b) \approx Q(x, G)$$

其中 $b=(\rho_E, \rho_V)$ 为预算，分别控制边和节点的剪枝比例；$Q(\cdot)$ 为任务分数。部署时学习摊销映射：
$$\mathcal{F}_\theta: (x, G, b) \mapsto \hat{H}_b \subseteq G$$

### 2.3 边级Granger式因果归因

**(a) 任务级因果贡献**：对每条活跃边 $e$，构造干预图 $G_{-e} = G \setminus \{e\}$，冻结其余组件后重新执行，定义为：
$$\Delta^{task}_e = Q(x, G) - Q(x, G_{-e})$$
$$u^{task}_e = \max(0, \Delta^{task}_e)$$

**(b) 辅助语义稳定性信号**：在稀疏任务奖励下，引入结果级语义熵作为补充。对 $M=5$ 次随机采样响应按语义等价类分组，计算：
$$\bar{H}(Y) = -\sum_{c \in \mathcal{C}(Y)} p(c)\log p(c)$$
$$u^{sem}_e = \max(0,\, \bar{H}(Y_{G_{-e}}) - \bar{H}(Y_G))$$

**(c) 统一边效用**：在图内归一化后组合两种信号（论文采用 $\alpha=0.8,\ \beta=0.2$）：
$$u_e = \mathrm{clip}_{[0,1]}\left(\alpha \cdot \tilde{u}^{task}_e + \beta \cdot \tilde{u}^{sem}_e\right)$$

由此得到边的保留排序 $\pi_G = (e_{(1)}, e_{(2)}, \ldots, e_{(|\mathcal{E}|)})$。

### 2.4 因果子图抽取与执行投影

给定预算 $b$：
- 边选择：$E^\star_b = \mathrm{TopK}(\pi_G, k_E(b))$
- 可执行投影：$H^\star_b = \mathcal{R}_{valid}(G, E^\star_b, k_V(b))$

投影 $\mathcal{R}_{valid}$ 保证：仅选择原图中的边（不引入新连接）、保留DAG性质、保留输入与聚合节点、按累计效用剔除孤立节点。

### 2.5 摊销解释器

对每个校准样本 $(x_i, G_i)$，在预算集 $\mathcal{B}$ 上构造训练集：
$$\mathcal{D}_{expl} = \{(x_i, G_i, b, H^\star_{i,b}) \mid b \in \mathcal{B}\}$$

解释器以查询嵌入 $q_x$、角色嵌入 $r_v$、结构特征 $t_v$、预算编码 $z_b$ 为输入，通过共享的MLP预测边与节点的保留概率 $\hat{A}_{b,e},\ \hat{R}_{b,v}$，优化目标为：
$$\mathcal{L} = \mathcal{L}_{edge} + \lambda_{node}\mathcal{L}_{node} + \lambda_{wd}\|\theta\|_2^2$$

其中 $\mathcal{L}_{edge}$、$\mathcal{L}_{node}$ 分别为边与节点的二元交叉熵损失。部署时直接通过 Top-K 与 $\mathcal{R}_{valid}$ 投影得到可执行子图，无需任务标签或重复边级评估。

## 6. 主要结论与发现

1. **效率-性能权衡显著改善**：E2-Explainer在4个拓扑生成器上均实现 **20.1%~25.6%** 的加权token减少，同时平均准确率提升0.44~1.09个百分点；G-Designer+E2-Explainer在保持最佳准确率（90.71）的同时减少25.1%的token。
2. **跨生成器可迁移**：仅在G-Designer上校准的解释器无需重训练即可迁移至ARG-Designer、OFA-MAS、AgentPrune三种不同范式的生成器，证明学到的是通信模式而非特定拓扑结构。
3. **跨agent规模可迁移**：在5-agent图上训练的解释器直接用于6-agent图，MMLU准确率从79.43→81.70，HumanEval从89.26→90.08，token同步降低。
4. **预算敏感性强**：纯边剪枝（$E25/50/75+N0$）token降幅小（1.7%~5.3%），引入节点剪枝后 $E25+N20$ 取得最佳权衡；$E25+N40$ 降幅最大（42.6%）但HumanEval下降6.52点，表明代码任务对激进节点剪枝敏感。
5. **手写拓扑亦有效**：在Complete/Random/Layer/Chain/Star五种手写拓扑上，30个组合中26个保持或提升准确率，token全面下降，验证了真正的模型无关性。
6. **因果信号比语义熵信号更关键**：消融中去除因果信号带来最大降幅（MMLU 79.74→75.82），但二者组合效果最佳。

## 7. 优点与亮点

- **方法论创新**：首次将通信拓扑解释形式化为Granger式因果归因问题，并区分"任务级贡献"与"响应稳定性贡献"，为黑盒优化结果提供可审计的因果解释。
- **模型无关性**：完全独立于具体拓扑生成器，仅依赖生成的候选图，适用范围广。
- **摊销设计高效**：通过离线蒸馏将昂贵的边级干预转为单次前向预测，部署开销极低。
- **可执行性**：解释结果可直接作为剪枝后的通信拓扑执行，无需额外映射。
- **实验充分**：多生成器、多数据集、多预算、消融、跨规模、手写拓扑、定性案例齐全，对照公平。
- **图1与图4的随机掩码分析**为"冗余存在但随机剪枝不可靠"的论点提供了直观、有说服力的实证支撑。

## 8. 不足与局限

- **校准成本仍存在**：离线构建监督需要每个数据集40个查询、每条边 $M=5$ 次重执行，开销不为零；论文未明确报告训练总时长。
- **干预范围有限**：仅做单边一阶条件干预，未枚举多边组合，因果贡献估计在边间强依赖时可能失真。
- **依赖任务级评估信号**：对于缺乏可靠自动评估的任务（如开放问答），语义熵与任务分数的可用性受限。
- **预算选择依赖先验**：$E25+N20$ 是通过G-Designer的预算扫描事后挑选的，迁移到其他生成器时未重新调优，可能并非每个生成器的最优预算。
- **定性案例呈独立执行**：论文明确指出原图与剪枝图的输出不是配对采样，因此"wrong→correct"等结果无法单独归因于某条边的移除，相关结论应理解为相关性而非严格因果。
- **token节省不完全对应稀疏度**：剪枝后剩余消息长度可能变化，token降幅未必与边/节点数成正比，纯边剪枝的token节省有限。
- **Backbone单一**：仅在Qwen3-8B上实验，未验证其他规模/家族LLM的迁移性。
- **应用假设**：要求底层MAS为冻结可重执行结构，且生成图能提供有效边集合，对流式、异步或动态通信机制的适用性未验证。
