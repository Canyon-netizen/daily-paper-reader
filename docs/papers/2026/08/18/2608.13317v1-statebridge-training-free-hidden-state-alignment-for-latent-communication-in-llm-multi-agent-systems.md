## 摘要
基于大语言模型的多智能体系统通常通过文本（即离散 token）进行通信。然而，文本会带来离散瓶颈：将发送方的连续隐藏状态转换为离散 token，会丢失仅凭 token 标识本身无法捕捉的信息。最近的研究提出了潜在通信作为一种替代方案，智能体直接传输隐藏表示，无需将其转换为文本。然而，现有的潜在方法要么在 Transformer 中逐层注入工作记忆，要么依赖需要训练的投影器，从而限制了可移植性。我们提出了 StateBridge，一种无需训练的潜在通信方法，通过闭式正交变换将发送方最后一层的隐藏状态对齐到接收方的输入空间。轻量级的范数校准与词表锚定确保了与预训练输入分布的兼容性。对齐后的状态以连续前缀的形式被添加到接收方智能体输入的开头。我们使用来自两个模型族的四个模型，在数学推理、代码生成和问答任务上对 StateBridge 进行了评估。StateBridge 在 26 个模型-任务对中有 22 个取得了最佳或并列最佳成绩，持续优于最强的基线方法。

## Abstract
Large language model based multi-agent systems usually communicate in text, i.e., using discrete tokens. However, text introduces a discrete bottleneck. Converting the sender's continuous hidden states into discrete tokens discards information that token identities alone cannot capture. Recent work proposes latent communication as an alternative, where agents transmit hidden representations directly without converting them to text. However, existing latent methods either inject working memory layer by layer across the transformers, or require trained projectors that limit portability. We propose StateBridge, a training-free latent communication approach that aligns the sender's final-layer hidden states to the receiver's input space via a closed-form orthogonal transformation. Lightweight norm calibration and vocabulary anchoring ensure compatibility with the pretrained input distribution. The aligned states are prepended to the input of the receiver agent as a continuous prefix. We evaluate StateBridge on math reasoning, code generation, and question answering with four models from two families. StateBridge achieves the best or tied-best score on 22 out of 26 model-task pairs, consistently outperforming the strongest baseline.

## 1. 核心问题与研究动机

基于大语言模型（LLM）的多智能体（MA）系统在数学推理、代码生成、问答等任务上需要多智能体协作（Planner → Critic → Refiner → Judger），而智能体间的通信方式会显著影响协作效果。当前主流通信媒介是**自然语言文本**，但文本通信存在固有缺陷：

- **离散瓶颈**：发送方将连续隐藏状态 $S \in \mathbb{R}^{K \times d}$ 通过采样映射为离散 token 序列 $y$，再经接收方 embedding 矩阵 $W_{\text{emb}}$ 还原为向量。该过程满足信息论上界：
$$I(S; W_{\text{emb}}[y]) \le I(S; y) \le H(y) \le K \log_2 V$$
当 $V \approx 1.5 \times 10^5$，$K=64$ 时，通道至多承载约 **1101 bits**，远小于 $K \times d$ 维连续状态所含信息量。
- **几何失配**：即便隐藏状态维度匹配，预训练 LLM 的输入层期望接收 token embedding，而末层隐藏状态位于表示空间另一区域，直接传递会导致接收方"读不懂"。

现有潜在通信方法的两条路径各有局限：
- **KV-cache 传递**（如 LatentMAS、Cache-to-Cache）：逐层注入工作记忆，但传输的是中间计算状态而非消息的紧凑表示，且跨模型家族兼容性差；
- **训练式投影器**（如 Interlat、ThoughtComm）：需要训练的投影器将其绑定到特定模型与任务，可移植性受限。

因此，关键问题变为：**能否在不训练、不修改架构的前提下，仅通过闭式对齐就解决隐藏状态到输入空间的几何失配，实现有效的潜在通信？**

## 2. 方法论

### 2.1 总体思路

StateBridge 提出 **三步闭式对齐接口**：
1. **正交 Procrustes 对齐**：将发送方末层隐藏状态旋转到接收方输入空间；
2. **范数校准（Norm Calibration）**：缩放到与 token embedding 相当的 $\ell_2$ 范数；
3. **词表锚定（Vocabulary Anchoring）**：向最近邻 token embedding 微调方向平移，保持连续性。

对齐后的状态作为**连续前缀**（continuous prefix）拼接到接收方 prompt embedding 之前。

### 2.2 消息提取

仅保留发送方生成消息末尾 $K$ 个 token 的最终层隐藏状态（$K=64$）：
$$S = (s_1, \dots, s_K)^\top \in \mathbb{R}^{K \times d}$$
对 Qwen3 等生成中间思维链的模型，丢弃 $\langle\text{think}\rangle/\langle/\text{think}\rangle$ 区间，仅保留面向接收方的消息段。

这些 token 对应的词嵌入作为参考目标：
$$R = W_{\text{emb}}[y] \in \mathbb{R}^{K \times d}$$

### 2.3 正交 Procrustes 对齐

将 $S$ 与 $R$ 视为两个点云，先**中心化**：
$$S_c = S - \mathbf{1}_K \mu_S^\top, \quad R_c = R - \mathbf{1}_K \mu_R^\top$$
其中 $\mu_S = \frac{1}{K}\sum_i s_i$，$\mu_R$ 同理。

再**白化**（加 $\lambda I$ 防奇异，$\lambda=10^{-3}$）：
$$\Sigma_S = \tfrac{1}{K}S_c^\top S_c + \lambda I, \quad \Sigma_R = \tfrac{1}{K}R_c^\top R_c + \lambda I$$
$$S_w = S_c \Sigma_S^{-1/2}, \quad R_w = R_c \Sigma_R^{-1/2}$$

最后求解**正交 Procrustes 问题**：
$$Q^* = \arg\min_{Q} \|S_w Q - R_w\|_F^2 \quad \text{s.t.} \ Q^\top Q = I$$
闭式解由 SVD 给出：$S_w^\top R_w = U D V^\top$，则 $Q^* = U V^\top$。该旋转是**等距映射**，保持白化后点云的成对距离与夹角（见 Proposition A.3）：
$$\|(S_w Q^*)_i - (S_w Q^*)_j\|_2 = \|(S_w)_i - (S_w)_j\|_2$$
$$\langle (S_w Q^*)_i, (S_w Q^*)_j \rangle = \langle (S_w)_i, (S_w)_j \rangle$$

反白化恢复参考分布的尺度与位置：
$$\tilde{S} = S_w Q^* \Sigma_R^{1/2} + \mathbf{1}_K \mu_R^\top$$

附录命题 A.1 证明：若改用岭回归 $W_{\text{ridge}} = (S^\top S + \gamma I)^{-1} S^\top R$，则 $\tilde{S} = H_\gamma R$ 被**限制在 $\text{span}(r_1,\dots,r_K)$** 内，无法表示 token embedding 张成空间之外的方向——这是 Procrustes 显著优于岭回归的几何根源。

### 2.4 范数校准与词表锚定

末层隐藏状态范数远大于 token embedding（Qwen3-4B 上约 $140\times$），需校准到词表平均范数：
$$\hat{s}_i = \tilde{s}_i \cdot \frac{\bar{n}}{\|\tilde{s}_i\|_2}, \quad \bar{n} = \frac{1}{V}\sum_v \|W_{\text{emb}}[v]\|_2$$

再做**词表锚定**：
$$v_i^* = \arg\max_{v} \frac{\hat{s}_i^\top W_{\text{emb}}[v]}{\|\hat{s}_i\|_2 \|W_{\text{emb}}[v]\|_2}$$
$$\bar{s}_i = (1-\alpha)\hat{s}_i + \alpha W_{\text{emb}}[v_i^*], \quad \alpha = 0.3$$
这一步不把消息离散化为 token，而是保持连续性同时拉近预训练见过的嵌入区域。

### 2.5 前缀注入

设接收方 prompt 嵌入为 $P \in \mathbb{R}^{N \times d}$，则
$$X = [\bar{S}; P] \in \mathbb{R}^{(K+N)\times d}$$
位置编码连续编号，前缀占据位置 $0 \sim K-1$。接收方按标准前向传播处理，无需任何架构改动。

### 2.6 计算成本

- **时间**：白化特征分解 $O(d^3)$、词表锚定搜索 $O(KVd)$、剩余步骤 $\le O(Kd^2)$。在典型配置（$T \ge 256$，$L=32$）下，对齐开销低于一次生成。
- **空间**：通过 final-layer forward hook 仅保留单层输出，提取代价 $O(Td)$，保留 $O(Kd)$，远小于 KV-cache 方法的 $O(TLd)$。

## 3. 实验设计

### 3.1 数据集

三类共 **8 个 benchmark**：

| 类别 | 数据集 | 特点 |
|------|--------|------|
| 数学推理 | GSM8K、AIME24、AIME25 | 多步数值推理、竞赛级 |
| 知识问答 | GPQA-Diamond、ARC-Challenge、MedQA | 研究生级、常识、医学执照 |
| 代码生成 | MBPP+、HumanEval+ | 严格单元测试、pass@1 |

### 3.2 模型

两个家族、四个模型：
- **Qwen3**：4B、8B、32B（Yang et al., 2025）
- **OLMo3-7B-Think**（Team OLMo et al., 2026）

### 3.3 基线

- **Single**：单智能体标准生成；
- **TextMAS**：文本顺序通信；
- **LatentMAS**：KV-cache 跨层注入（Zou et al., 2026）。

所有方法共享相同的 4 智能体流水线、超参与评估协议，仅 prompt 中通信模态描述不同。

### 3.4 评估与超参

QA 与数学用准确率，代码用 pass@1。固定 $K=64$、$\alpha=0.3$、$\lambda=10^{-3}$，温度 0.6、top-p 0.95，最大输出长度 2,048~20,000 tokens 视任务而定。

## 4. 资源与算力

文中明确说明：所有实验在 **2 块 NVIDIA A100-80G GPU** 上运行。未给出总训练/推理时长，但已说明推理时对齐开销低于一次生成，且无需 GPU 训练阶段。代码已开源（GitHub: YanwenPneg/StateBridge）。

## 5. 实验数量与充分性

- **主实验**：4 模型 × 5~8 benchmark = **26 个模型-任务对**，加上 Single/Text/Latent/SB 四列对比，相当于约 100+ 单元评测点。
- **消融实验**（Qwen3-4B，5 个 benchmark）：5 种变体（Full / 岭回归 / 随机噪声 / 无范数校准 / 无词表锚定），共 25 个数据点。
- **超参敏感性**：$K \in \{16,32,64,128\}$、$\alpha \in \{0.0,0.1,0.2,0.3,0.4,0.6\}$，合计 $4 \times 6 \times 5 = 120$ 个数据点。
- **对齐可视化**：基于 300 条 MedQA 查询的 PCA 密度图。
- **案例研究**：MedQA 上一例的可控重建实验（$K=16/64/128$）。

总体上，**实验覆盖了两个模型家族、四种模型规模、三类任务与多种消融维度**，对比公平（共享流水线与超参），结论具有较强的统计稳健性。但未报告多次随机种子平均与置信区间，且部分基准（如 AIME24/25 仅 30 题）样本量较小，存在一定波动风险。

---

## 6. 主要结论与发现

- StateBridge 在 **26 个模型-任务对中 22 个**取得最佳或并列最佳；4 个模型的平均分均优于最强基线 2.4~2.9 个百分点。
- **跨模型家族泛化性强**：OLMo3-7B-Think 上 LatentMAS 仅 55.1%，远低于 TextMAS 的 73.9%，而 StateBridge 达 76.7%，证明仅在输入层注入的接口更具通用性。
- **难任务增益更大**：AIME24（+6.6/+3.4）、GPQA（+7.0/+5.8）、MedQA（+4.0/+5.0）表明文本 handoff 在信息密集型任务上损失最严重。
- **几何保持是关键**：Procrustes → 岭回归使平均性能下降 7.5（尤其代码生成），表明保留成对几何结构比降低逐点重建误差更重要。
- **两个兼容步骤不可缺**：去掉范数校准 ↓2.9，去掉词表锚定 ↓2.2；随机噪声对照 ↓33.6，证明显著提升并非来自"任意连续前缀"。
- **案例研究**：在 K=16 时，接收方能从对齐前缀中还原出原文中不存在的医学术语（如 koilonychia），说明前缀携带了超越可见后缀 token 的语义信息。

---

## 7. 优点

- **真正的 training-free**：无任何可学习参数，仅依靠闭式线性代数运算（中心化、白化、SVD），部署成本极低。
- **架构零侵入**：在 embedding 层拼接前缀，兼容所有现有 transformer 结构，便于跨模型迁移。
- **理论支撑充分**：附录给出 Span Confinement 命题与等距性证明，从几何角度解释 Procrustes 优于岭回归。
- **算力开销低**：仅需 single-layer forward hook，对齐耗时低于一次完整生成，存储 $O(Kd)$ 远小于 KV-cache 方法。
- **实验广度好**：跨家族、跨规模、跨任务类型对比，并在多个 benchmark 上稳定领先。
- **可解释性强**：PCA 可视化与案例研究清晰展示对齐效果。

---

## 8. 不足与局限

- **同质化假设**：当前仅在所有智能体共享同一预训练 LLM 的同构 MA 系统中验证，未涉及**异构模型**间的潜在通信。
- **固定前缀长度**：$K=64$ 在所有任务上统一使用，附录证明 $K=128$ 会因全局旋转难以兼顾异质点集而性能下降，缺乏**自适应长度选择**机制。
- **GSM8K 上的退步**：在 Qwen3 系列上 StateBridge 略低于最佳基线，作者推测与连续前缀影响 exact-match 格式输出有关，提示**输出格式敏感**是该方法的隐性副作用。
- **OLMo3 上 HumanEval+ 下降 1.2**：并非全任务全胜，存在模型特定短板。
- **基准样本量差异**：AIME24/25 各仅 30 题，结果波动可能较大；论文未报告多次随机种子的置信区间。
- **架构定位局限**：仅在输入 embedding 层注入，无法像 KV-cache 那样传递完整的中间计算轨迹，可能在某些极端依赖上下文记忆的任务上不占优。
- **理论假设依赖**：白化与正交 Procrustes 假设两点云可被单一旋转对齐，若发送方/接收方表示拓扑差异过大（异构模型），闭式解可能失效。
- **未来空间**：作者明确指出尚未探索与训练式通信模块的结合、异构模型支持、自适应 K 选择等方向。
