## Abstract
Task guided agents demonstrate strong performance in a wide range of complex tasks. However, most existing task representation algorithms are tailored to specific contexts and struggle to generalize across diverse scenarios. Moreover, they typically depend on gradient signals from reinforcement learning controllers to update their weights, which can degrade both representation quality and learning efficiency. To overcome these limitations, we propose LOTUS, a temporal logic inspired universal task representation framework that can be seamlessly integrated into any RL algorithm to enhance agent performance across diverse task settings. Specifically, we design a novel task representation architecture capable of modeling relationships and extracting task semantics from LTL formulas. We further introduce a more effective update mechanism that treats the LTL encoder as a policy, thereby improving representation capacity. To enhance stability and robustness, LOTUS leverages the bisimulation metric, which provides theoretical guarantees for LTL representation, including behavioral equivalence, optimality fidelity, and trajectory robustness. Experimental results show that LOTUS outperforms most existing methods in learning efficiency, generalization capability, and representation quality. Specifically, LOTUS accelerates convergence over 20% in single-task scenarios, achieves a 15%-45% higher success rate in unseen manipulation tasks, and improves generalization performance over 25% in complex multi-task environments with increased sub-goal depth or conjunctions. ## 1. 核心问题与研究动机

论文聚焦于**强化学习（RL）中的任务表示（Task Representation）**问题。当前任务引导型智能体虽在复杂任务上表现良好，但现有任务表示算法存在两大共性缺陷：

- **场景泛化能力不足**：多数方法（LTL2Action 的 R-GCN、T2TL 的 Transformer、cDFA 的 GAT 等）只能针对单任务或多任务中的某一类进行优化，缺乏"通用"框架，难以同时在单任务与多任务、稀疏奖励与稠密奖励、离散与连续动作空间下保持竞争力。
- **训练机制不稳定**：现有 LTL 编码器的权重几乎完全依赖下游 RL 控制器通过反向传播间接更新。这种"被动式"梯度流不仅使任务表示的收敛速度慢，还会因 RL 策略震荡而损害表示质量。

此外，工业界常用的另一条路线——基于大语言模型（LLM）的任务分解——存在语义不一致、依赖 prompt 工程、复杂时序指令处理能力受限等问题。因此，论文试图回答三个核心问题：
- 如何设计一种 LTL 编码器，使其输出能同时指导单任务与多任务场景；
- 如何将编码器从 RL 梯度中"解耦"，提供更直接、更稳定的更新方式；
- 如何进一步增强表示的稳定性与鲁棒性，并提供理论保证。

## 2. 方法论

### 2.1 总体框架
LOTUS 由三个核心模块组成：**LTL→有向图转换**、**RGTN 编码器**、**TLPG 直接更新 + 双模拟度量优化**。其可作为通用插件接入任意 RL 算法。整体流程对应论文 Algorithm 1：

```
探索阶段: φ' ← prog(L(s),φ) → 构造有向图 G_{φ'} → RGTN 编码得 ψ̂ → 与状态 s 拼接 → RL 策略采样
训练阶段: 同时更新 RL 控制器（π_φ）与 LTL 编码器 Θζ（通过 TLPG + 双模拟度量）
```

### 2.2 LTL 公式到有向图
将 sc-LTL 公式 $\phi$ 表示为带四种边类型的有向图 $G_\phi=(V,E,R)$：
- **Unary**：子公式→一元算子（$\neg$、$\Diamond$ 等）；
- **Binary-left / Binary-right**：左右子公式→二元算子（$\wedge$、$\cup$）；
- **Self-loop**：每个节点的自环，用于跨时间步传递信息。

这种结构相比序列向量或自动机能更好地捕获 LTL 的层级与逻辑依赖。

### 2.3 RGTN 编码器（关系图 Transformer 网络）
RGTN 由多层 **RGTL** 堆叠，每层含三种关键子结构：

- **Multi-Relation Attention (MRA)**：按边类型分组计算注意力：

$$F_\epsilon^r = \mathrm{softmax}\!\left(\frac{Q_r K_r^\top}{\sqrt{d_k}}\right)V_r,\quad m_i^{\mathrm{rel}}=\mathrm{Concat}_\epsilon(F_\epsilon^r)$$

- **Multi-Head Attention (MHA)**：按节点聚合全局上下文：

$$m_i^{\mathrm{head}} = W_h\cdot\mathrm{Concat}_h\!\left(\mathrm{softmax}\!\left(\frac{QK^\top}{\sqrt{d_k}}\right)V\right)$$

- **Information Fusion**：通过 $W_{\mathrm{cat}}$ 将两者 concat 投影到高维空间后再相加：

$$\tilde h_i^l = W_{\mathrm{cat}}\bigl[m_i^{\mathrm{rel}}\|m_i^{\mathrm{head}}\bigr]$$

整体计算可写为：

$$\hat h^{l+1} = \sigma\!\left(W_0^l h_i^l + \sum_{j\in N(i)}\tilde h_j^l\right),\quad \hat\psi = \mathrm{LN}(\hat h^L)$$

由此单任务的子目标捕获能力（MHA+残差）与多任务的边关系建模能力（MRA+有向图）被统一到同一架构。

### 2.4 TLPG 直接更新机制
将 RGTN 建模为**任务级 MDP**（Taskable MDP $M_\Phi$）上的随机高斯策略 $\pi_\Theta^\zeta=\mathcal{N}(\hat\psi,\varrho)$，其中 LTL 公式为状态、采样得到的表示 $\hat\psi_\pi$ 为动作、prog 提供的 $r_\phi$ 与环境奖励 $r_{\mathrm{env}}$ 为奖励。编码器权重直接由策略梯度更新：

$$J_{\pi_\Theta}(\zeta)=\mathbb{E}_{\tau\sim\pi_\Theta^\zeta}\bigl[-\log\pi_\Theta^\zeta\cdot \tilde R_\phi\bigr]$$

### 2.5 双模拟度量（Bismulation Metric）优化
为消除采样噪声与稠密奖励波动对表示稳定性的影响，将原始 MDP 中的双模拟度量迁移到 Taskable MDP 上度量两公式 $\phi_i,\phi_j$ 的相似度：

$$d(\phi_i,\phi_j)=\max_{\sigma\in\Pi}\bigl[(1-c)|R(\phi_i,\sigma)-R(\phi_j,\sigma)|+c\,W_1(p_\Phi(\cdot|\phi_i,\sigma),p_\Phi(\cdot|\phi_j,\sigma))\bigr]$$

通过策略 $\pi_\Theta^\zeta$ 简化后，可直接在潜空间对齐：

$$J(\Theta)=\Bigl|\,\|\hat\psi_i^\pi-\hat\psi_j^\pi\|_1 - r_{\phi_i}^\pi + r_{\phi_j}^\pi - \gamma W_2\bigl(\hat P(\cdot|\hat\psi_i^\pi,a_i),\hat P(\cdot|\hat\psi_j^\pi,a_j)\bigr)\Bigr|_2$$

采用 2-Wasserstein 距离是因为高斯分布下存在闭式解。

### 2.6 理论保证
论文给出三个定理：
- **定理 1（行为等价）**：策略收敛到 $\pi^\*$ 时，$d(\phi_i,\phi_j)$ 是 $\pi^\*$-双模拟度量，存在最小不动点；
- **定理 2（最优性保真）**：原 MDP 与聚类潜空间上的最优值函数之差有上界：
$$V_\phi^*-V_{\Theta(\phi)}^* \le \frac{2\epsilon+2L}{(1-\gamma)(1-c)}$$
其中 $L=\sup|\|\Theta(\phi_i)-\Theta(\phi_j)\|-d(\phi_i,\phi_j)|$ 为编码误差；
- **定理 3（轨迹鲁棒）**：原轨迹 $\tau$ 与编码轨迹 $\Theta(\tau)$ 的累积奖励满足：
$$|\Phi(\tau)-\Phi(\Theta(\tau))|\le\frac{2\gamma^H(\epsilon+L)}{(1-\gamma)(1-c)}+\frac{2\epsilon(1-\gamma^H)}{(1-\gamma)(1-c)}$$
证明 $\epsilon,L$ 足够小时表示空间保留了原空间的关键信息。

- **统一架构**：RGTN 通过 MRA + MHA + Concat Fusion 的设计，将原属"单任务派"（Transformer）和"多任务派"（R-GCN/GAT）的优势整合，首次同时在两类场景上达到 SOTA。
- **解耦式训练**：TLPG 将 LTL 编码器视作独立策略并直接基于奖励更新，避免了 RL 梯度污染，是论文最有新意的设计之一。
