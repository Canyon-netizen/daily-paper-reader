## 摘要
外部自然语言技能为大型语言模型（LLM）智能体提供了可复用且可编辑的指导以解决复杂任务。然而，其有效性不仅取决于技能质量，还取决于策略能否将所提供的指导转化为恰当的动作。然而，专门用于提升这种技能利用能力的方法在很大程度上仍未得到充分探索。在实践中，基于技能的智能体通常使用以任务级奖励为中心的强化学习目标进行训练，这类目标提供的监督有限，难以捕捉策略在多大程度上有效利用所提供技能的细微差异。我们提出了 BCSD（Bidirectional Context Self-Distillation，双向上下文自蒸馏），一个将自蒸馏与强化学习相结合以训练 LLM 智能体更有效地使用外部技能的框架。与依赖于单一特权上下文的先前自蒸馏方法不同，BCSD 从两个互补的技能上下文视角评估每条轨迹。增强视图引入更高层次的元技能指导，而简化视图则对通用指导进行剪枝以突出任务特定技能。它们的互补的 token 级信号被结合用于重新调节强化学习优势函数。在 ALFWorld 和 WebShop 上的实验表明，BCSD 在不同模型规模下均取得了最强的整体性能，使智能体能够更有效地利用外部技能。消融研究进一步验证了增强与简化上下文视图的互补贡献。代码将予以发布以确保完全可复现性。

## Abstract
External natural-language skills provide large language model (LLM) agents with reusable and editable guidance for solving complex tasks. Yet their effectiveness depends not only on skill quality, but also on whether the policy can translate the provided guidance into appropriate actions. However, methods specifically designed to improve this skill-utilization ability remain largely underexplored. In practice, skill-based agents are commonly trained with reinforcement learning objectives centered on task-level rewards, which offer limited supervision and struggle to capture subtle differences in how effectively the policy uses the provided skills. We propose BCSD (Bidirectional Context Self-Distillation), a framework that combines self-distillation with reinforcement learning to train LLM agents to use external skills more effectively. Unlike prior self-distillation methods that rely on a single privileged context, BCSD evaluates each trajectory from two complementary skill-context views. The augmented view introduces higher-level Meta-Skill guidance, while the reduced view prunes general guidance to highlight task-specific skills. Their complementary token-level signals are combined to rescale the RL advantage. Experiments on ALFWorld and WebShop demonstrate that BCSD achieves the strongest overall performance across model scales, enabling agents to utilize external skills more effectively. Ablation studies further verify the complementary contributions of the augmented and reduced context views. Code will be released to ensure full reproducibility.

## 1. 核心问题与研究动机

- **核心问题**：基于自然语言技能（natural-language skills）的 LLM 智能体的有效性不仅取决于外部技能的质量，更取决于**策略能否将所提供的技能指导转化为恰当的动作**，即"技能利用能力"（skill utilization）。现有方法多聚焦于"提升技能质量"或"将技能内化进模型参数"，而对"如何更好地利用显式外部技能"这一维度缺乏系统性研究。
- **现有方法的不足**：
  - 以任务级稀疏奖励为主的 RL 训练（如 GRPO）只能为整条轨迹提供统一的优势信号，**无法识别哪些 token 真正利用了技能**，导致细粒度监督不足。
  - 现有的**在线策略自蒸馏（OPSD）**方法（如 RLSD、SDAR、Skill-SD）通常依赖**单一特权上下文**生成 token 级教师信号，容易出现信息泄漏、风格漂移与捷径 token 问题，教师信号可靠性存疑。
- **本文主张**：应保留显式技能作为外部推理时上下文，通过更可靠的 token 级监督来**增强策略的技能利用能力**，而非把技能"内化"为参数。

## 2. 方法论

### 2.1 整体框架

BCSD（Bidirectional Context Self-Distillation）将自蒸馏与强化学习相结合，核心思路是：**构造两个互补的技能上下文视角**，共同生成 token 级信号以重新调节 GRPO 优势函数。

### 2.2 基础设定

- 任务建模为部分可观察决策过程（POSDP），轨迹 $\tau=(o_1,a_1,\dots,o_H,a_H)$，获得终端奖励 $R(\tau)$。
- 采用 SkillRL 的分层 SkillBank：每个任务类型 $c$ 关联一个通用技能 $G$ 和检索到的任务特定技能 $S_c$。
- 基础上下文定义为：
$$C_0 = (Q, G, S_c)$$
- 每组 $K$ 条轨迹由策略 $\pi_\theta$ 在 $C_0$ 下采样，GRPO 计算组内相对优势：
$$A_i^{GRPO} = \frac{r_i - \mu_r}{\sigma_r + \epsilon}$$

### 2.3 Meta-Skill 提取

- **定义**：Meta-Skill $M_c$ 是对"如何利用任务特定技能 $S_c$"的高层文本指导，反映策略相关的使用经验，**仅在训练时作为教师特权上下文出现，不参与推理**。
- **初始化**：在训练前收集多个查询的成功轨迹集 $E_{c,+}^{(0)}$ 与失败轨迹集 $E_{c,-}^{(0)}$，由冻结的外部 LLM 生成：
$$M_c^{(0)} = \text{Extract}_{LLM}(S_c, E_{c,+}^{(0)}, E_{c,-}^{(0)})$$
- **刷新机制**：每个验证窗口后基于当前窗口的轨迹重新提取：
$$M_c^{(k+1)} = \text{Extract}_{LLM}(S_c, M_c^{(k)}, E_{c,+}^{(k)}, E_{c,-}^{(k)})$$

### 2.4 双向上下文构造

- **增强视图（Augmented View）**：在基础上下文上附加 Meta-Skill：
$$C_1 = (Q, G, S_c, M_c)$$
- **简化视图（Pruned View）**：用外部 LLM 对通用技能 $G$ 进行剪枝得到 $G_p$，保留任务特定技能 $S_c$：
$$G_p = \text{Prune}_{LLM}(G), \quad C_2 = (Q, G_p, S_c)$$
- $G_p$ 在训练前一次性生成后保持固定。

### 2.5 优势重调节（Advantage Rescaling）

- 在保持响应序列 $y_i$ 不变的前提下，使用同一策略在 $C_1$、$C_2$ 下重新打分，得到两个 token 级对数概率差异：
$$\Delta_{i,t}^{aug} = \log \pi_\theta(y_{i,t} \mid C_1, y_{i,<t}) - \log \pi_\theta(y_{i,t} \mid C_0, y_{i,<t})$$
$$\Delta_{i,t}^{pru} = \log \pi_\theta(y_{i,t} \mid C_2, y_{i,<t}) - \log \pi_\theta(y_{i,t} \mid C_0, y_{i,<t})$$
- 双向融合：
$$\Delta_{i,t} = \alpha \Delta_{i,t}^{aug} + (1-\alpha) \Delta_{i,t}^{pru}$$
- 通过带裁剪的指数函数将 $\Delta_{i,t}$ 映射为缩放权重：
$$w_{i,t} = \text{clip}\!\left(\exp\!\left(\text{sign}(A_i^{GRPO})\Delta_{i,t}\right),\, 1-c,\, 1+c\right)$$
- 重调节后的优势：
$$A_{i,t}^{BCSD} = A_i^{GRPO}\!\left[(1-\lambda_n) + \lambda_n w_{i,t}\right]$$
- 其中 $\lambda_n \in [0,1]$ 从 $\lambda_0$ 线性衰减到 0，**保留 GRPO 优势方向不变**。

### 2.6 策略优化目标

使用标准 PPO 风格裁剪目标，将轨迹级优势替换为 $A_{i,t}^{BCSD}$：
$$L_{BCSD}(\theta) = -\mathbb{E}_{i,t}\!\left[\min\!\left(\rho_{i,t}(\theta)A_{i,t}^{BCSD},\ \text{clip}(\rho_{i,t}(\theta), 1-\epsilon, 1+\epsilon)A_{i,t}^{BCSD}\right)\right] + \beta L_{KL}$$

其中重要性比 $\rho_{i,t}(\theta) = \frac{\pi_\theta(y_{i,t}\mid C_0,y_{i,<t})}{\pi_{\theta_{old}}(y_{i,t}\mid C_0,y_{i,<t})}$。

### 2.7 算法流程（Algorithm 1）

1. 预训练前用冻结 LLM 构造 $G_p$ 并初始化 $\{M_c^{(0)}\}$；
2. 每优化步：采样 batch $\to$ 在 $C_0$ 下采样轨迹并计算 $A^{GRPO}$ $\to$ 在 $C_1, C_2$ 下重算 log-probs $\to$ 计算 $\Delta_{i,t}, w_{i,t}, A^{BCSD}$ $\to$ 收集证据用于下一次 Meta-Skill 刷新；
3. 每 $N$ 步根据窗口轨迹刷新 Meta-Skill 并清空证据缓冲。

- **充分性评估**：覆盖了主对比、消融、超参、训练曲线、信号一致性、技能利用归因等多角度，整体较为充分。但仅在两个 benchmark 上评估，且未跨更多领域（如编程、工具调用、问答等）验证泛化性。

## 6. 主要结论与发现

- **性能领先**：在 Qwen2.5-7B、Qwen2.5-3B、Qwen3-1.7B 三个基座上，BCSD 均取得 ALFWorld 与 WebShop 上的最强综合表现。
  - Qwen2.5-7B：ALFWorld 平均成功率 83.6（+3.1），WebShop 成功率 78.1（+0.3）。
  - Qwen2.5-3B：ALFWorld +5.4、WebShop Score +4.4、WebShop 成功率 +9.4。
  - Qwen3-1.7B：ALFWorld +3.9、WebShop Score 76.8（最高）。
- **两视角互补**：去除 Meta-Skill 或 Pruned-Skill 任一视角均显著掉点；二者提供**约 50% 符号一致率**的差异化 token 信号，互补而非冗余。
- **刷新与衰减必要**：固定 Meta-Skill 或固定 $\lambda_n$ 均掉点，说明策略演化的同步刷新与早期强引导后期渐弱的调度均关键。
- **信号非冗余**：两个上下文视图的 token 级符号一致率仅 ~50%（介于 47%–53%），说明它们确实提供互补信号而非重复信号。
- **真正利用外部技能**：移除任务特定技能 $S_c$ 后，BCSD 的成功率下降幅度（ALFWorld -2.3、WebShop -7.8）大于 Skill_GRPO\*（-0.8、-6.2），说明 BCSD 的收益来源于**更好的技能利用**而非任务知识内化。
- **早期自蒸馏，后期奖励主导**：训练曲线显示 BCSD 在前 30 步后快速拉开差距，之后稳定提升，对应"早引导 + 后期奖励回归"的协同机制。

## 7. 优点与亮点

- **视角设计新颖**：把"参考策略"与"多教师融合"的思路从参数空间迁移到上下文空间，提出"增强 + 简化"双向视图，避免单一特权上下文的可靠性问题。
- **不改变优化方向**：通过 sign-preserving 的优势缩放保证更新方向与 GRPO 一致，仅调节幅度，机制简洁且风险可控。
- **保持技能显式性**：训练与推理均使用外部技能，未将技能内化进参数，保留了**可编辑性、可检查性、可迁移性**。
- **渐进式引导**：$\lambda_n$ 线性衰减机制契合"早期弱策略需强引导、后期奖励信号可靠"的训练规律。
- **实验维度丰富**：覆盖多模型规模、多任务类型、消融、超参敏感度、训练动力学、信号一致性、技能利用归因分析，论证较全面。
- **可复现性承诺**：作者声明将发布代码。

## 8. 不足与局限

- **Benchmark 覆盖有限**：仅在 ALFWorld 与 WebShop 两个文本交互环境验证，未在更具异质性的领域（如编程、检索问答、数学推理、多模态任务）评估泛化性。
- **依赖外部 LLM**：Meta-Skill 提取与 $G_p$ 剪枝均依赖冻结的外部 LLM，引入额外计算成本与潜在的外部模型偏差，未讨论所用 LLM 的具体选型与稳定性。
- **未报告算力**：训练硬件、时长、显存占用等关键资源信息缺失，影响可复现性的完整评估。
- **基线数量与多样性有限**：基线主要为 RL/OPSD 类方法，缺乏与最新技能进化（SkillEvolver、SkillClaw）或技能内化（OPID、SIRI）方法的直接对比。
- **超参搜索范围较窄**：$\lambda_0$ 与 $\alpha$ 的搜索粒度有限；未对 Meta-Skill 刷新间隔 $N$、剪枝强度、组大小 $K$ 等进行更系统的敏感度分析。
- **公平性考量**：所有基线均在作者的代码与同一 SkillBank 设置下复现，但具体奖励设计、prompt 工程细节对结果影响较大，文中未提供完整的 prompt/超参附录以保证完全公平。
- **理论分析缺失**：未对 $\Delta_{i,t}$ 的偏差-方差性质、为何两视角符号一致率约 50% 等现象提供理论解释，主要依赖经验性验证。
- **技能质量耦合风险**：若 SkillBank 中技能本身质量欠佳，BCSD 的上限仍受其约束；方法虽不依赖技能内化，但难以在技能质量较差场景下大幅超越 SkillBank 性能天花板。
