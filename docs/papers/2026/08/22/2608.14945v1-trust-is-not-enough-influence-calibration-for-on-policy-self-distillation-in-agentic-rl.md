## 摘要
在线策略自蒸馏（OPSD）通过享有特权信息的自教师，在策略自身轨迹上为语言智能体提供稠密的 token 级别监督。现有方法主要依据教师置信度来分配此类监督，但置信度并不能揭示强调某一 token 是否契合当前策略目标。我们将这一现象称为置信度-效用失配，并提出自蒸馏影响校准（ICSD）。对于每个被监督的 token，ICSD 衡量其重要性加权的强化学习替代贡献针对教师方向输出扰动的一阶响应。批次自适应校准将该非平稳信号转化为有界的分配权重，同时保留每个动作回合内原有的辅助损失总量。这些解耦权重仅作用于蒸馏损失，无需额外的模型前向计算。在 ALFWorld、WebShop 与 Search-QA 任务上，ICSD 在 Group Relative Policy Optimization（GRPO）与 Group-in-Group Policy Optimization（GiGPO）下，于两个跨越 1.5B 至 7B 参数量的模型家族上，均在所有匹配的聚合指标上优于仅依据置信度的分配方案。在 7B 模型上，其在 ALFWorld 上取得 96.1% 的成功率，并在 WebShop 上获得 93.1 的分数。冻结批次分析显示，ICSD 将分配给与目标相悖 token 的教师支持质量从 60.1% 降至 37.8%，并使其与强化学习梯度的余弦兼容性提升 0.192。配套代码仓库见 https://github.com/lanqz7766/Influence-Calibration-for-On-Policy-Self-Distillation-in-Agentic-RL。

## Abstract
On-policy self-distillation (OPSD) gives language agents dense token-level supervision from a privileged self-teacher on the policy's own trajectories. Existing methods allocate this supervision mainly by teacher trust, but trust does not reveal whether emphasizing a token supports the current policy objective. We call this the trust-utility mismatch and introduce Influence Calibration for Self-Distillation (ICSD). For each supervised token, ICSD measures the first-order response of its importance-weighted RL surrogate contribution to a teacher-directed output perturbation. Batch-adaptive calibration converts this non-stationary signal into a bounded allocation weight while preserving the original auxiliary-loss mass within each action turn. These detached weights affect only the distillation loss and require no additional model pass. Across ALFWorld, WebShop, and Search-QA, ICSD improves all matched aggregate metrics over trust-only allocation under Group Relative Policy Optimization (GRPO) and Group-in-Group Policy Optimization (GiGPO), across two model families spanning 1.5B to 7B. At 7B, it reaches 96.1% ALFWorld success and a WebShop score of 93.1. Frozen-batch analyses show that ICSD reduces teacher-supported mass assigned to objective-opposed tokens from 60.1% to 37.8% and raises cosine compatibility with the RL gradient by 0.192. A companion repository is avail- able at https://github.com/lanqz7766/Influence-Calibration-for-On-Policy-Self-Distillation-in-Agentic-RL.

**核心问题——信任-效用失配（trust–utility mismatch）**：现有 OPSD 方法（如 SDAR、SAGE-OPD、TurnOPD、Skill-SD 等）主要依据"教师-学生一致性差距""不确定性""token 位置""结果证据"等指标来衡量教师信号的"可信度（trust）"，进而分配监督权重。然而，**信任度高并不等同于该 token 的更新方向有利于当前 RL 目标**。例如，在冻结的 ALFWorld 批次上，仅依赖信任度的 SDAR 分配将 **60.1% 的教师支持质量分配到了与当前目标相悖的 token 上**，造成有效监督资源的错配。

4. **信号有效性**：局部分析仅在所部署损失能够实现所分析方向时成立，否则符号一致性并非证据。

## 二、方法论：影响校准自蒸馏（ICSD）

### 1. 总体思路

ICSD 不替换 SDAR 的信任权重，而是在继承信任信号的基础上，引入"教师方向目标影响"来重新分配每个动作回合（action turn）内的辅助损失预算，使监督权重与当前 RL 目标方向对齐。

### 2. 关键公式

**(1) 基础蒸馏损失**

学生策略 $\pi_\theta$ 在 token $t$ 处的辅助蒸馏损失为：
$$\hat{\ell}^{KD}_t(\theta) = \mathrm{sg}\!\left[\log \pi^{+}_{\theta}(a_t \mid x_t, z_t)\right] - \log \pi_\theta(a_t \mid x_t)$$

其中 $z_t$ 是教师可见但学生不可见的特权上下文，$\mathrm{sg}$ 表示 stop-gradient。教师-学生差距 $\Delta_t$ 为相应停梯度差值。

**(2) 带权蒸馏目标**

$$L(\theta) = L_{RL}(\theta) + \frac{\lambda}{|\mathcal{B}|} \sum_{t \in \mathcal{B}} \mathrm{sg}(c_t)\,\hat{\ell}^{KD}_t(\theta)$$

$c_t \geq 0$ 为解耦的分配系数；SDAR 中 $g_t = G_{\text{trust}}(\Delta_t) \in [0,1]$ 仅依赖 $\Delta_t$，故两个差距相同的 token 获得相同信任权重。

**(3) 教师方向目标影响（核心创新）**

对 token $t$，引入策略比 $\rho_t = \pi_\theta(a_t \mid x_t) / \pi_{\text{old}}(a_t \mid x_t)$ 与 token 优势 $\hat{A}_t$，定义教师方向的输出坐标扰动：
$$\rho_t(\epsilon) = \rho_t \exp(\epsilon \Delta_t)$$

则 token $t$ 对未截断替代目标 $J_t = \hat{A}_t \rho_t$ 的一阶 Taylor 系数为：
$$u_t := \left.\frac{d\, \hat{A}_t \rho_t(\epsilon)}{d\epsilon}\right|_{\epsilon=0} = \hat{A}_t \rho_t \Delta_t$$

并由 Taylor 定理给出显式余项界 $\frac{1}{2}|\hat{A}_t|\rho_t \Delta_t^2 e^{|\epsilon \Delta_t|}$，无近似。

**(4) 批次自适应校准**

每个动作回合（按 turn 索引跨轨迹汇集 token 构成校准组 $\mathcal{G}$）用中位数作位置估计，两侧一阶均值作尺度估计（最小值 $\varepsilon$）：
$$\hat{\mu}_\mathcal{G} = \mathrm{median}_{j \in \mathcal{G}} u_j,\quad \hat{b}^\pm_\mathcal{G} = \mathrm{mean}_{j \in \mathcal{G}^\pm} |u_j - \hat{\mu}_\mathcal{G}|$$

构造非对称 Laplace 族 CDF（split 参数 $\eta = 0.5$）：
$$\Phi_\mathcal{G}(u) = \begin{cases} \eta \exp\!\left(\dfrac{u - \hat{\mu}_\mathcal{G}}{\hat{b}^-_\mathcal{G}}\right), & u < \hat{\mu}_\mathcal{G} \\[6pt] 1 - (1-\eta)\exp\!\left(-\dfrac{u - \hat{\mu}_\mathcal{G}}{\hat{b}^+_\mathcal{G}}\right), & u \geq \hat{\mu}_\mathcal{G} \end{cases}$$

令 $\tilde{m}_t = \Phi_\mathcal{G}(u_t) \in (0,1)$。

**(5) 保守回退与回合级质量匹配**

若 $\hat{A}_t < 0$ 且 $\Delta_t < 0$，$u_t > 0$ 但方向与分析方向相反，保留 SDAR 系数；定义回退集 $\mathcal{D}$ 与剩余集 $\mathcal{C} = \mathcal{B} \setminus \mathcal{D}$。

对于每个动作回合 $q$，若 $\sum_{j \in C_q} g_j \tilde{m}_j > 0$，定义回合级缩放因子：
$$\alpha_q = \frac{\sum_{j \in C_q} g_j}{\sum_{j \in C_q} g_j \tilde{m}_j}$$

则最终系数为：
$$c_t = \begin{cases} g_t, & t \in \mathcal{D}_q \\ \alpha_q \, g_t \, \tilde{m}_t, & t \in \mathcal{C}_q \end{cases}$$

**(6) 不变质量分配（Proposition 1）**

当分母非零时，$c_t$ 对回合 $q$ 内满足回合级质量守恒：
$$\sum_{t \in q} c_t = \sum_{t \in q} g_t, \quad \forall q$$

并且 $\Phi_\mathcal{G}$ 对正仿射变换 $u'_j = a u_j + b$（$a>0$）不变，因此分配在训练阶段间具有可比性。

**(7) 算法流程**（见 Algorithm A1）：
- 步骤1：采样轨迹，计算 $\hat{A}_t, \rho_t$；
- 步骤2：特权教师评估，得 $\Delta_t, g_t$；
- 步骤3：计算 $u_t = \hat{A}_t \rho_t \Delta_t$；
- 步骤4：拟合 $\hat{\mu}_\mathcal{G}, \hat{b}^\pm_\mathcal{G}$，得 $\tilde{m}_t$；
- 步骤5-13：构造 $\mathcal{D}, \mathcal{C}$，逐回合计算 $\alpha_q$ 与 $c_t$；
- 步骤14：detach $\{c_t\}$ 并以分配目标更新 $\theta$。

整个过程 **不需要额外的前向或反向传播**，仅涉及解耦的逐元素运算与 CDF 拟合。

## 三、实验设计

### 1. 数据集与基准
- **ALFWorld**（文本具身智能体任务，6 类：Pick / Look / Clean / Heat / Cool / Pick2）
- **WebShop**（在线购物网页交互智能体）
- **Search-QA**（来自 Search-R1 的 7 个子集：NQ、Trivia、PopQA、HotpotQA、2WikiMultiHopQA、MuSiQue、Bamboogle）

### 2. 模型家族
- Qwen2.5-Instruct：1.5B / 3B / 7B
- Qwen3-Instruct：1.7B / 4B

### 3. RL 算法
- GRPO（Shao et al., 2024）
- GiGPO（Feng et al., 2026；$\gamma = 0.95$，单位 step 优势权重）

### 4. 对比方法
- 纯 RL 基线：GRPO、GiGPO
- Hybrid 蒸馏基线：Skill-SD、RLSD
- OPSD 变体：OPSD（Zhao et al., 2026）、SDAR（Lu et al., 2026）
- 扩展基线：Vanilla、Skill-Prompt、Skill-Prompt\*、Skill-GRPO、Skill-GRPO\*（带 \* 者在验证时保留检索到的技能）

### 5. 协议
完全对齐 SDAR：相同的 SkillBank、关键词匹配检索、特权自教师、训练/验证划分。ICSD 特定超参：信任 split = 0.4、影响 split = 0.5、尺度下限 $10^{-4}$、最小校准组 8 tokens。

## 六、主要结论与发现

1. **整体性能**：ICSD 在所有匹配的聚合指标上均优于 trust-only SDAR 分配。Qwen2.5-7B + GiGPO 下 ALFWorld 成功率 94.5%→**96.1%**，WebShop 分数 88.4→**93.1**、准确率 78.9%→**84.4%**。
2. **优化器无关性**：GRPO 与 GiGPO 下均稳定优于 SDAR，WebShop 准确率提升最显著（GRPO 下 +11.7 pts，GiGPO 下 +7.0 pts）。
3. **模型家族无关性**：Qwen3-4B 上 ALFWorld 平均从 89.8 提升至 95.3。
4. **机制验证**：TCM 从 60.1% 降至 **37.8%**（95% CI [22.1, 22.6] 降幅 22.3 pp）；与 RL 梯度的余弦兼容性平均提升 **0.192**（CI [0.147, 0.240]），排列对照仅 +0.020；正符号区域多分配 6.2 pp 质量，负符号区域少分配 7.5 pp。
5. **设计要素**：连续 signed 影响 + 教师信任的组合最强；无符号幅度不足以；硬符号过滤平于 SDAR；非对称 Laplace 校准优于 Gaussian。
6. **零额外开销**：无额外前向/反向传播，仅 0.4% 端到端时间开销。

## 七、优点

1. **概念新颖**：首次系统揭示 OPSD 中的 trust-utility 失配问题，并以"输出坐标影响"替代经典参数空间影响，绕开 Hessian 求逆的高昂代价。
2. **数学严谨**：Proposition 1 给出仿射不变性与回合级质量守恒的严格证明；Taylor 余项有显式常数；附录 A.3 详细推导了单调性与排序性质。
3. **工程友好**：完全解耦、无额外模型前向、计算开销可忽略（0.4%），易于集成到现有 SDAR 流水线。
4. **实验覆盖广**：跨 5 个模型规模、3 个基准、2 个优化器、含分配消融与超参敏感性；冻结批次机制分析从 token 分布、梯度兼容性双角度定量验证。
5. **兼容现有方法**：与 SDAR 等 trust-based 分配器正交组合，无须修改 RL 损失本身。

## 八、不足与局限

1. **基线复现不完整**：主表多行直接沿用 SDAR 论文报告的数值，仅 ICSD 与 SDAR 部分为本次训练所得，可能存在实现细节差异。
2. **机制分析时间点单一**：TCM 与余弦兼容性在 step-135 的 4 个冻结 ALFWorld 批次上统计，未验证训练全程；附录 A3 显示分配信号在 minibatch 层面波动较大。
3. **截断暴露**：分析基于未截断替代目标 $J_t = \hat{A}_t \rho_t$，而部署损失使用截断比。在 544,427 token 中，0.128% 处于截断区间外、0.069% 处于局部平坦区间；尽管占比较小（0.103% 的复合系数质量），但仍存在局部误差。
4. **回退区域保守**：当 $\hat{A}_t < 0$ 且 $\Delta_t < 0$ 时完全保留 SDAR 系数；当一符号区 ICM 主导时性能可能受限（双负区域占 0.0 pp 质量），缺乏对该区域更细粒度的处理。
5. **应用范围受限**：方法专门针对 OPSD 与 token 级辅助损失；不能直接迁移到序列级 KL 蒸馏、跨回合信用分配或非语言模态的智能体。
6. **依赖现成 trust 信号**：ICSD 需要继承 SDAR 风格的信任系数 $g_t$；若 trust 分配器完全失效或缺失，下游 ICSD 也无可靠基础。
7. **算力报告不充分**：仅给出 1.5B + WebShop + 4×H100 的匹配开销；7B 模型的具体 GPU 配置与累计训练时长未披露，影响复现成本评估。
