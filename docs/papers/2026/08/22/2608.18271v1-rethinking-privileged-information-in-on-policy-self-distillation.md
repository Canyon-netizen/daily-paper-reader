## 摘要
在线自蒸馏（OPSD）使用来自同一模型（以特权参考信息为条件）的逐 token 监督，在学生模型自身的响应上进行训练。我们研究了 OPSD 带来的性能提升究竟是因为学生模型学到了参考信息中的内容，还是仅仅反映了其对基础模型中已有推理行为的恢复。我们在科学和数学数据集上使用规模从 1.7B 到 8B 的 Qwen3 模型进行了 OPSD 实验。我们的分析框架将参考信息引入的监督与教师模型在不引入参考信息时提供的监督分离开来，并衡量二者各自与学生模型预测变化的对齐程度。正确的参考信息并未在不同的教师生成模式、模型规模和训练数据集下带来一致的性能提升。学生模型即使没有正确的参考信息也能获得改进，而在若干数学推理基准上，另一道题目的解答甚至可以优于正确解答。学生模型的预测与基础模型的思维行为之间的对齐程度，强于其与参考信息引入的监督之间的对齐程度，但由其他题目构建的对照组同样能再现这两类对齐的大部分。此外，可归因于正确参考信息的更强对齐并不必然伴随更大的性能收益。因此，仅凭性能增益和分布对齐无法判定特权参考信息在 OPSD 中究竟如何促进学生的学习。

## Abstract
On-policy self-distillation (OPSD) trains a student on its own responses using token-level supervision from the same model conditioned on privileged reference information. We investigate whether performance gains from OPSD show that the student learned the information in the reference or instead reflect recovery of reasoning behavior already present in the base model. We perform OPSD experiments on science and mathematics datasets using Qwen3 models ranging from 1.7B to 8B. Our analysis framework separates the supervision induced by the reference from the supervision provided by the teacher without the reference and measures how each aligns with changes in the student's predictions. The correct reference does not provide a consistent performance benefit across teacher generation modes, model sizes, and training datasets. Students can improve without the correct reference, and a solution from another problem can outperform the correct solution on several mathematical reasoning benchmarks. The student's predictions align more strongly with the base model's thinking behavior than with the supervision induced by the reference, but controls constructed from other problems reproduce much of both alignments. Moreover, stronger alignment attributable to the correct reference does not reliably coincide with a greater performance benefit from the reference. Performance gains and distributional alignment alone therefore cannot determine how privileged reference information contributes to student learning in OPSD.

## 1. 核心问题与研究动机

**研究背景**：在线自蒸馏（On-Policy Self-Distillation, OPSD）已成为大语言模型（LLM）后训练中的常用方法，已被 DeepSeek-V4、GLM-5、Kimi K3、Nemotron-Cascade 2、Qwen3 等主流模型采用。其核心做法是：学生模型从自身的当前策略采样轨迹，由同一个基础模型作为冻结教师，但教师在评估时能够访问特权信息（通常是参考解答），从而对学生的每一个生成位置提供逐 token 的监督信号。

**核心质疑**：OPSD 的关键假设是"特权参考信息能改善教师监督，进而将参考中的知识迁移给学生"。然而该假设面临多重挑战：
- 教师接触更多参考信息并不总有益处，反而可能改变不确定性表达或推理行为；
- 参考条件监督可能包含学生推理时根本无法使用的信息；
- 当教师工作在 thinking 模式时，其与学生的差异同时来源于上下文和生成模式两个维度；
- 仅凭最终性能无法判定学生究竟学到了参考中的知识，还是仅仅恢复了基础模型本身已具备的推理行为。

**中心问题**：OPSD 的性能提升究竟源自学生学到了参考信息的内容，还是仅反映了基础模型中已有推理行为的恢复？

## 2. 方法论：核心思想与关键技术

### 2.1 训练目标

OPSD 的训练目标为最小化教师与学生 next-token 分布之间的广义 Jensen-Shannon 散度：

$$L(\pi_S) = \mathbb{E}_{x\sim D,\; y\sim \pi_S(\cdot|x)} \left[ \sum_{t=1}^{|y|} D_{JSD}\!\left(\pi_T(\cdot|x,r,y_{<t})\;\big\|\;\pi_S(\cdot|x,y_{<t})\right) \right]$$

其中 $r$ 为参考解，$\pi_T$、$\pi_S$ 分别为冻结教师与学生，二者实例化自同一基础模型。

### 2.2 参考依赖与参考无关监督的分解

对每个 token $v\in V$，定义三种 next-token 分布（基于学生在第 $c$ 个 checkpoint 生成的固定前缀 $y^{(c)}$）：

$$T(v) = \pi_T(v|x,r,y^{(c)}_{<t}), \quad N(v) = \pi_T(v|x,y^{(c)}_{<t}), \quad S_c(v) = \pi_S^{(c)}(v|x,y^{(c)}_{<t})$$

将它们表示为 log-probability 向量后，可将教师与学生之间的总差距分解为：

$$\underbrace{\log T - \log S_c}_{D^{tot}} = \underbrace{\log T - \log N}_{D^{ref}} + \underbrace{\log N - \log S_c}_{D^{rec}}$$

- **参考方向 $D^{ref}$**：加入参考所引起的教师预测变化；
- **恢复方向 $D^{rec}$**：不带参考的教师与初始学生之间的差距，反映"恢复"基础模型已有行为的方向。

### 2.3 教师监督的组成度量

在训练步 0 测量参考方向在总教师监督上的投影系数：

$$w_{ref} = \frac{\langle D^{ref}, D^{tot}\rangle_{I_0}}{\|D^{tot}\|^2_{I_0}}$$

### 2.4 学生预测变化的刻画

固定初始学生生成的响应，定义学生在第 $c$ 个 checkpoint 的预测变化：

$$\Delta S_c = \log S_c - \log S_0$$

并定义 base model thinking 方向 $D^{think} = \log B - \log S_0$，其中 $B$ 为基础模型在 thinking 模式下的分布。

通过三个层面的指标刻画学生变化：
1. **投影系数** $\beta_D^{(c)} = \frac{\langle\Delta S_c, D\rangle_{I_0}}{\|D\|^2_{I_0}}$；
2. **余弦相似度** $\cos\theta_D^{(c)} = \frac{\langle\Delta S_c, D\rangle_{I_0}}{\|\Delta S_c\|_{I_0}\|D\|_{I_0}}$；
3. **解释方差比** $R_c^2$：$\Delta S_c$ 在 $D^{ref}$ 与 $D^{rec}$（或 $D^{ref}$ 与 $D^{think}$，针对 non-thinking 教师）的张成空间中的比例。

### 2.5 用其他题目构造对照

为剥离问题特定效应，对每条原始测量，构造对照组：将教师条件中的问题替换为另一道题目（保留学生生成的响应不变），得到 $T^*, N^*, B^*$ 及相应控制方向 $D^{*}_{ref}, D^{*}_{rec}, D^{*}_{think}$。由于 $S_0$、$S_c$、$\Delta S_c$ 不变，原始测量与对照测量之差即分离出对正确问题上下文的依赖。每组对照在三种不同题目配对下重复以检验稳健性。

- **学生模型**：Qwen3-1.7B、Qwen3-4B、Qwen3-8B，均使用 LoRA（rank 64, alpha 128），固定在 non-thinking 模式；
- **教师模式**：thinking 与 non-thinking 两个变体；
- **训练集**：NuminaMath 与 MegaScience 各取 10,000 题（去污染后）；
- **训练步数**：300 步，学习率 $5\times10^{-6}$，有效 batch size 32。

### 3.2 参考条件
对比五类参考：原始数据集解、仅答案（answer-only）、抽象提示（abstract hint）、Qwen3-8B 推理轨迹、Qwen3-32B 推理轨迹；以及错题解（mismatched reference）和无参考（no reference）条件。

### 3.3 评测基准
- **数学推理**：MATH-500（Avg@4）、AIME 2024、AIME 2025、HMMT 2025（Avg@12）；
- **科学推理**：GPQA-Diamond（Avg@12）、MMLU-Pro（Avg@1）、UGPhysics（Avg@1）；
- 评测均使用 non-thinking 模式，附录中附 thinking 模式辅助评测。

### 3.4 对比方法
在每个数据集、每个模型规模下，对比以下 OPSD 变体：
1. Non-thinking 教师 + 正确参考；
2. Non-thinking 教师 + 错题解（mismatched reference）；
3. Thinking 教师 + 正确参考；
4. Thinking 教师 + 无参考。

## 5. 实验数量与充分性

### 5.1 实验规模
- **3 个模型规模 × 2 个数据集 × 4 种 OPSD 条件** = 24 组主要训练实验；
- 8B 规模下额外进行 **5 种参考类型**对比实验（基于 4,953 题子集）；
- 每组实验生成 300 个 checkpoint 中的若干个（间隔 25 步），并在不同 benchmark 上做评估；
- 对照分析在 **3 种不同题目配对**下重复以验证稳健性；
- 配对 bootstrap 重采样 10,000 次以估计 95% 区间。

### 5.2 充分性与公平性评估
**优点**：
- 跨多个模型规模（1.7B/4B/8B）和两个领域（数学、科学）系统扫描；
- 引入严格的问题级对照实验（mismatched reference、control directions），能够剥离问题特定效应；
- 配对 bootstrap 与多次对照配对增加了统计稳健性；
- 评测指标统一（non-thinking 模式、相同 prompt、相同 batch size）以保证可比性。

**不足**：
- **每个训练条件仅运行一次**，无法估计训练随机性引起的方差；
- 仅使用 Qwen3 模型族，未涵盖其他模型家族；
- 仅覆盖数学与科学领域，未涉及代码、开放对话等场景；
- 评测基准相对集中（数学 4 个 + 科学 3 个），未能充分评估广义推理能力。

## 6. 主要结论与发现

### 6.1 性能层面
1. **正确参考不带来一致收益**：在 8B 规模下，加入参考对 thinking 教师无显著优势；4B 和 1.7B 时其效果因数据集而异；
2. **错题解可能优于正确解**：在 4B、1.7B 的所有数学竞赛基准上，错题解均优于正确解（8B 时 AIME 2025 与 HMMT 2025 也如此）；
3. 参考的实际价值取决于**教师生成模式、模型规模与训练数据集**三者的交叉作用。

### 6.2 分布对齐层面
1. 学生的预测变化与**基础模型的 thinking 行为**的对齐，**强于**与参考方向的对齐；
2. 用其他题目构造的对照组能再现这两种对齐的大部分内容，提示对齐主要不是问题特定的；
3. 控制投影系数 $w_{ref}$ 在 NuminaMath 上为 0.46、MegaScience 上为 0.39——参考确实改变了教师预测，但并未带来相应的性能优势；
4. 在五种参考类型下，正确参考方向 $D^{ref}$ 与 thinking 方向 $D^{think}$ 的余弦相似度反而**低于**错题参考构造的控制方向；
5. **更强的对齐并不对应更大的性能收益**：在 MegaScience 上，1.7B 模型的余弦差异最大，但无参考训练反而在三个科学基准上均更优。

### 6.3 综合结论
**仅凭性能增益与分布对齐无法判定特权参考信息对 OPSD 学习的实际贡献**。两种主流评估方式（benchmark 性能与分布相似度）都不能可靠地反映参考信息的真实因果作用。

---

## 7. 优点与亮点

1. **问题意识新颖且重要**：直接挑战 OPSD 文献中"特权信息一定有价值"的核心假设；
2. **方法论严谨**：通过 $D^{tot} = D^{ref} + D^{rec}$ 的正交分解将"参考带来的影响"与"教师已有的影响"在数学上明确分离；
3. **对照实验设计精巧**：使用其他题目的解（mismatched reference）与控制方向（control directions）双重对照，有效剥离问题特定效应；
4. **多尺度多数据集**：覆盖 1.7B/4B/8B 与数学/科学两域，使结论的外部效度更强；
5. **报告透明度高**：配对 bootstrap 区间、检查点选择策略、生成限制、软件版本等均有完整附录；
6. **结论审慎**：明确声明"性能与对齐本身不足以推断参考的贡献"，为后续因果性分析研究奠定了基础。

---

## 8. 不足与局限

1. **模型族单一**：仅使用 Qwen3 系列，未验证是否适用于 Llama、Mistral、DeepSeek 等其他模型族；
2. **领域受限**：仅覆盖数学与科学推理，未涉及代码生成、对话、多轮交互等场景；
3. **缺乏训练随机性估计**：每个训练条件仅运行一次，无法区分真实效应与训练噪声；
4. **未深入到 reasoning 质量层面**：评测仅基于最终答案准确率，未分析学生推理过程的正确性、完整性或风格变化；
5. **可能存在评估偏差**：仅在 non-thinking 模式下评测学生，附录中 thinking 评测范围有限；
6. **应用限制**：研究聚焦 OPSD，未直接外推到一般化的 on-policy distillation（OPD）或异师生蒸馏；
7. **统计显著性边界**：部分差异的 95% 配对区间跨越零，作者在叙述中已注意到但仍依赖点估计；
8. **未进行消融的因果干预**：未做"参考信息擦除"或"参考内容替换"之外的其他因果干预（如阻断特定 token 位置的影响），无法定位参考影响的具体路径。
