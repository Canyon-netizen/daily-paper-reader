## 摘要
同策略自蒸馏（OPSD）通过在学生模型采样的轨迹上蒸馏冻结教师模型的指导信息来适配语言模型。然而，其效果高度依赖这些轨迹的质量。我们发现，当学生模型的 rollout 偏离目标轨迹时，使教师模型以偏离目标的前缀为条件会显著削弱其任务相关监督。受控前缀损坏实验揭示了这一失效模式，我们将其称为 rollout 条件化信号退化。为解决这一问题，我们提出一个统一的训练框架，将两种互补的监督路径分离开来。第一种路径保留 rollout 条件化分布匹配，为学生模型实际访问的状态提供指导；第二种路径则在标准真值上下文上执行监督交叉熵，从而避免将目标词元强加于错误 rollout 前缀所产生的不兼容性。我们利用词元级 rollout—目标对齐来动态调整标准上下文锚点的强度：在冷启动阶段予以强化，并随着 rollout 质量提升而逐步减弱。在多种模型规模、两类任务以及通用推理基准上的实验表明，与 OPSD 相比，所提出的方法能够提升任务习得效果，同时保持通用能力，从而获得更有利的经验性可塑性—稳定性权衡。这些发现表明，上下文质量是同策略自蒸馏的核心瓶颈，并凸显了将 rollout 条件化指导与标准真值监督相分离的价值。

## Abstract
On-policy self-distillation (OPSD) adapts a language model by distilling guidance from a frozen teacher on trajectories sampled from the student. Its effectiveness, however, depends critically on the quality of those trajectories. We show that when student rollouts drift from target trajectories, conditioning the teacher on off-target prefixes substantially weakens its task-relevant supervision. Controlled prefix-corruption experiments expose this failure mode, which we term rollout-conditioned signal degradation. To address this problem, we propose a unified training framework that separates two complementary supervision pathways. The first retains rollout-conditioned distribution matching, providing guidance on states the student actually visits. The second applies supervised cross-entropy on canonical ground-truth contexts, avoiding the incompatibility of imposing target tokens on erroneous rollout prefixes. Token-level rollout-target alignment is used to adapt the strength of the canonical-context anchor, emphasizing it during cold start and relaxing it as rollout quality improves. Experiments across multiple model scales, two task families, and general-reasoning benchmarks show that the proposed approach improves task acquisition over OPSD while preserving general capabilities, resulting in a more favorable empirical plasticity-stability trade-off. These findings identify context quality as a central bottleneck in on-policy self-distillation and demonstrate the value of separating rollout-conditioned guidance from canonical supervision.

## 1. 核心问题与研究动机

- **背景**：同策略自蒸馏（OPSD）让冻结的"特权教师"在共享底座模型上对学生自身生成的 rollout 提供密集 token 级监督，被视为一种低成本、无需白盒独立教师的任务适配方案。
- **隐含假设及其脆弱性**：OPSD 假设教师在学生前缀下仍能给出任务相关的指导信号；但当任务协议（输出模式、动作空间、推理格式）在预训练中表征较弱时，学生 rollout 迅速偏离目标轨迹，使教师前缀偏离目标，导致监督信号显著退化。
- **核心问题——上下文–监督不兼容性**：
  - **Rollout 条件化蒸馏**要求保留学生生成前缀以覆盖 on-policy 状态；
  - **真值监督**要求标准（canonical）前缀以保证目标 token 的语义有效性。
  - 两者直接耦合会产生**目标–上下文失配（target–context mismatch）**，或退化为两阶段硬切换训练（人工选定切换点）。
- **作者命名的问题**：*Rollout-conditioned signal degradation*——在标准前缀下教师目标 token 准确率可达 80.4%，在自然学生 rollout 上骤降至约 5%（$\rho \approx 3.8\% \sim 8.1\%$）；随着前缀损坏率从 $\epsilon=0$ 升至 $\epsilon=1$，准确率单调下降至 3.8%。
- **整体含义**：识别并定位"上下文质量"为 OPSD 的核心瓶颈，并主张"在何处计算监督"比"施加多少监督"更关键。

## 2. 方法论

### 2.1 形式化与诊断

- **OPSD 设定**：教师策略 $p_T(\cdot|x^{PI}) \triangleq p_{\theta_0}(\cdot|x^{PI})$ 冻结且接收特权输入 $x^{PI}=[x;y^\star]$；学生策略 $p_S(\cdot|x) \triangleq p_{\theta_0+\Delta\theta}(\cdot|x)$ 在 $x$ 上 on-policy rollout $\hat{y}$ 后逐步更新。
- **OPSD 目标（按 token 平均的 f-散度）**：
$$L_{OPSD} = \frac{1}{|\hat{y}|}\sum_{t=1}^{|\hat{y}|} D(p_T^t \| p_S^t)$$
其中 $D$ 取广义 Jensen–Shannon 散度
$$JSD_\beta(p_T\|p_S) = \beta D_{KL}(p_T\|m_\beta) + (1-\beta) D_{KL}(p_S\|m_\beta),\; m_\beta = \beta p_T + (1-\beta)p_S$$
- **目标 token 准确率与信号保留率**：
$$Acc_T(c) = \mathbb{E}_{(x,y^\star),t}\!\left[\mathbf{1}\!\left[\arg\max_v p_T(v|x^{PI},c_{<t}) = y_t^\star\right]\right],\quad \rho(\hat{y}) = \frac{Acc_T(\hat{y})}{Acc_T(y^\star)}$$

### 2.2 SDS 框架：上下文分离 + 自适应锚定

- **核心思想**：把 rollout 条件化蒸馏和真值监督分别放在各自语义有效的上下文里执行，共享 $\Delta\theta$，按 rollout–target 对齐度在线调整锚定强度。
- **两条监督通路**：
  - **蒸馏分支**：在 $[x;\hat{y}]$ 上对齐 $p_T(\cdot|x^{PI},\hat{y}_{<t})$ 与 $p_S(\cdot|x,\hat{y}_{<t})$，保留 on-policy 状态覆盖；
  - **锚定分支**：在 $[x;y^\star]$ 上独立前向计算真值 teacher-forcing 交叉熵，避免目标–上下文失配：
$$L_{anchor} = -\frac{1}{|y^\star|}\sum_{t=1}^{|y^\star|} \log p_S(y_t^\star | x, y_{<t}^\star)$$
- **自适应锚定权重**：基于轻量级 rollout–target token 级相似度 $sim(\hat{y}, y^\star)$，$w_{anchor}=1-sim(\hat{y}, y^\star)$；对齐差时强化锚定，对齐好时放松。
- **SDS 完整目标**：
$$L_{SDS} = \frac{1}{|\hat{y}|}\sum_{t=1}^{|\hat{y}|} D\!\left(p_T(\cdot|x^{PI},\hat{y}_{<t}) \,\|\, p_S(\cdot|x,\hat{y}_{<t})\right) + \alpha\, w_{anchor}\!\left(-\frac{1}{|y^\star|}\sum_{t=1}^{|y^\star|} \log p_S(y_t^\star | x, y_{<t}^\star)\right)$$
- **实现要点**：teacher 用基础模型关闭 LoRA 的副本，student 是 LoRA 适配版本；真值 token ID 预编码缓存；anchor 分支带来单次额外学生前向，每步开销约单步 OPSD 的 30–40%。
- **设计原则**：作者将其概括为**上下文有效性原则**——每个监督目标应在它语义有效的上下文中被评估。

## 3. 实验设计

- **模型**：Qwen3-1.7B / Qwen3-4B / Qwen3-8B，全部基于 LoRA（rank 64，alpha 128，dropout 0.05，作用于 q,k,v,o,gate,up,down_proj）。
- **任务与数据集**：
  - **SimpleMath**：四则运算 + 链式思考 + 四位小数固定答案格式；训练 2,500 条，按运算分层 1,000 条测试子集（seed 42）。
  - **ToolAlpaca（SDFT 处理版）**：多轮结构化工具调用 ReAct 格式；训练 4,046 条，68 条工具/查询保留测试集。
- **通用能力保留基准（未参与训练）**：AIME 2024、MATH-500、ARC-Challenge；评估 Pass@8/Avg@8/Maj@8 与格式遵循率。
- **主基线**：SFT、GRPO（含二值结果奖励）、OPSD。
- **消融对照**：
  - **Naive OPSD+CE**（rollout 前缀上注入 CE，存在目标–上下文失配）；
  - **固定权重 SFT + OPSD**（$w=1$ 始终锚定 / $w=0.5$）；
  - **两阶段 SFT→OPSD**（手动切换）；
  - **$\alpha$ 调节**（0.1 / 0.2 / 0.5）；
  - **相似度度量**（Token F1 / ROUGE-L F1 / Token 编辑距离 / 精确匹配）。
- **评估协议**：SimpleMath 贪婪解码 + 精确字符串匹配；AIME/MATH-500 使用 $\boxed{}$ 抽取与 math_verify；Tool-Use 每题 12 条轨迹对比 golden。
- **训练硬件**：NVIDIA H20（143 GB），vLLM 0.11.0 部署教师/学生；框架基于 ms-swift 4.1.3 并自研 GKD 插件。

## 4. 资源与算力

- **GPU 型号与数量**：H20（143 GB）单卡为 SimpleMath 主实验平台；tool-use 1.7B 需两卡，4B/8B 单卡。
- **训练时长**：**论文未直接给出小时/天数**，仅给出 LoRA/优化器/批次等配置（AdamW、$lr=5\times10^{-5}$、batch 32、cosine schedule、bfloat16、FlashAttention-2、gradient checkpointing 等）；每方法–模型组合跑 3 个随机种子（42/43/44）。
- **额外开销**：SDS 相比 OPSD 每步约多 30–40% 计算（一次独立 anchor 前向），但省去两阶段 SFT 预热的预算和切换调参。

## 5. 实验数量与充分性

- **规模维度**：3 个模型规模 × 2 类任务（SimpleMath、Tool-Use）× 4 主方法 × 3 随机种子，主结果约 72 配置组合，并附带 5 个消融变体、$\alpha$ 敏感性扫描、4 种相似度度量、3 模型规模的 AIME 跨尺度保留评估。
- **诊断实验**：控制前缀损坏（$\epsilon \in [0,1]$，7 档）+ 200 条 SimpleMath 上的真实 rollout 按首次错误位置分桶（first-error-position bins）。
- **训练动态**：Qwen3-1.7B 与 Qwen3-8B 的对齐度、$w_{anchor}$、$L_{distill}$ 联合曲线，以及 rollout 上下文教师准确率随 step 的变化。
- **充分性与公平性评价**：
  - **优点**：3 种子平均、同一 LoRA 与优化器设置下对比、覆盖主表 + 消融 + 诊断 + 训练动态 + 度量消融；并报告了 Pareto 权衡图。
  - **不足**：所有训练均局限于 Qwen3 单家族，未见与 Llama 3、DeepSeek 或 Mistral 等系列的对比；任务仅 2 类（结构化工具调用、四则运算），未覆盖代码、长文本写作、安全对齐等典型后训练场景。

## 6. 主要结论与发现

- **任务习得（Table 1）**：在 SimpleMath 上 SDS 显著优于 OPSD，4B 模型从 23.23% 跃升至 62.43%，8B 从 10.33% 升至 56.97%；Tool-Use Pass@12 在 4B 达 72.06%，优于 OPSD(62.75%) 与 SFT(70.10%)。
- **能力保留（Table 2, 4B）**：相比 SFT 在 AIME24 Avg@8 上从 38.33% 提升至 67.98%（≈93.2% 基底保留），ARC-Challenge 从 66.13% 提升至 87.75%（≈95.2% 保留）；MATH-500 保留 >93%。
- **Pareto 优势（Fig. 3）**：SDS 位于 SFT（强任务习得但能力崩塌）与 OPSD（强保留但弱任务习得）之间，提供更优的经验性可塑性–稳定性权衡。
- **训练动态（Fig. 4/5）**：早期 $w_{anchor}$ 较大（≈1.0），随对齐改善下降并稳定于非零值，$L_{distill}$ 在快适应期先升后降，证明存在内生闭环调度而非硬切换；rollout 上下文教师准确率由 OPSD 的 ≈5% 提升到 SDS 的 46.5%（step 100，4B）。
- **消融结论（Table 3）**：
  - Naive OPSD+CE：AIME Avg@8 崩塌至 3.33%，证明**上下文有效性而非监督量**才是瓶颈；
  - 固定权重 $w=1$ / $w=0.5$ 都不能同时获得强任务与强保留；
  - 两阶段 SFT→OPSD 在两轴上均逊于 SDS；
  - $\alpha=0.2$ 为 4B SimpleMath 的最佳平衡点。
- **相似度度量**：Token F1（默认）、ROUGE-L F1、Token 编辑距离结果接近（62.4–62.43%），精确匹配退至 56.5%，验证连续相似度优于二值信号。
- **跨尺度结论（Table 13/14）**：SDS 在 1.7B/4B/8B 上均显著优于 SFT 保留推理能力，并取得与 SFT 相当或更好的 SimpleMath 任务表现。

## 7. 优点

- **问题洞察清晰**：通过控制前缀损坏与自然 rollout 分桶双诊断，量化并定位了 OPSD 的失败模式，提出"上下文有效性原则"。
- **机制简洁而通用**：仅引入一个独立 anchor 前向与一个相似度驱动的权重，未引入路由/冻结/重放数据集，结构轻、便于复现。
- **双目标协同**：闭环自适应权重替代人工切换点，避免了 SFT→OPSD 两阶段的性能断崖与超参搜索。
- **实验较系统**：3 模型 × 2 任务 × 4 主方法 × 3 种子 + 5 消融 + 4 度量 + 跨尺度保留 + 训练动态，覆盖度对一篇 15 页工作而言较为充分。
- **Pareto 视角**：以"任务习得–能力保留"二维图直观呈现可塑性–稳定性权衡，结论易于解读。
- **度量稳健**：默认 Token F1 与 ROUGE-L F1、Token 编辑距离结果几乎一致，说明核心设计对度量不敏感。

## 8. 不足与局限

- **模型家族单一**：仅在 Qwen3 系列验证，跨家族（Llama、DeepSeek、Mistral、闭源可白盒模型）泛化性未知。
- **任务覆盖窄**：仅评估结构化工具调用与四则算术两类任务，未涵盖代码生成、对话偏好、长文本写作、安全对齐、多语言等典型后训练场景。
- **诊断代理性**：随机词表替换的前缀损坏是"可处理的代理"，不能完全复现真实学生策略产生的、结构化、上下文相关的错误模式；论文亦承认这一点。
- **算力信息不全**：未公开 GPU 总数、单次训练小时数、碳排或总实验机时，外部复现与成本估算受限。
- **冷启动假设较强**：自适应权重依赖 $sim(\hat{y}, y^\star)$ 在冷启动阶段具有判别力；若 rollout 与 target 几乎不相交但语义相关，$sim$ 的可靠性可能下降。
- **超参与工程细节**：$\alpha$、LoRA 秩、相似度选择仍需调参；anchor 分支额外前向虽轻（30–40%），但仍增加显存/时序负担。
- **安全/对齐未触及**：未评估 SDS 在越狱、对齐税（alignment tax）或长上下文忠实性等指标上的表现，难以判断对实际部署的安全性影响。
