## 摘要
在策略自蒸馏（OPSD）通过从冻结的教师模型蒸馏指导来适配语言模型，指导基于从学生模型采样的轨迹。然而，其效果严重依赖于这些轨迹的质量。我们表明，当学生模型的展开偏离目标轨迹时，在偏离目标的前缀上对教师模型进行条件化会显著削弱其与任务相关的监督信号。受控的前缀损坏实验揭示了这种失败模式，我们将其称为展开条件化信号退化。为解决这一问题，我们提出了一种统一的训练框架，将两种互补的监督路径分离。第一种保留展开条件化的分布匹配，为学生实际访问的状态提供指导。第二种在规范的真值上下文上应用监督交叉熵，避免了在错误的展开前缀上强加目标词元所带来的不兼容问题。通过词元级的展开-目标对齐来自适应地调节规范上下文锚定的强度，在冷启动阶段强调该锚定，并随着展开质量的提升而逐步放松。在多个模型规模、两类任务族以及通用推理基准上的实验表明，所提方法在任务获取方面优于 OPSD，同时保留了通用能力，实现了更有利的经验可塑性-稳定性权衡。这些发现将上下文质量确定为在策略自蒸馏中的核心瓶颈，并证明了将展开条件化指导与规范监督分离的价值。

## Abstract
On-policy self-distillation (OPSD) adapts a language model by distilling guidance from a frozen teacher on trajectories sampled from the student. Its effectiveness, however, depends critically on the quality of those trajectories. We show that when student rollouts drift from target trajectories, conditioning the teacher on off-target prefixes substantially weakens its task-relevant supervision. Controlled prefix-corruption experiments expose this failure mode, which we term rollout-conditioned signal degradation. To address this problem, we propose a unified training framework that separates two complementary supervision pathways. The first retains rollout-conditioned distribution matching, providing guidance on states the student actually visits. The second applies supervised cross-entropy on canonical ground-truth contexts, avoiding the incompatibility of imposing target tokens on erroneous rollout prefixes. Token-level rollout-target alignment is used to adapt the strength of the canonical-context anchor, emphasizing it during cold start and relaxing it as rollout quality improves. Experiments across multiple model scales, two task families, and general-reasoning benchmarks show that the proposed approach improves task acquisition over OPSD while preserving general capabilities, resulting in a more favorable empirical plasticity-stability trade-off. These findings identify context quality as a central bottleneck in on-policy self-distillation and demonstrate the value of separating rollout-conditioned guidance from canonical supervision.

## 1. 核心问题与研究动机

**研究背景**：在策略自蒸馏（On-Policy Self-Distillation, OPSD）是一种新兴的 LLM 领域适配范式。它将教师与学生共享同一个基座模型，但让"特权教师"看到经过验证的标准解（如题目的解题过程），而"学生"仅看到原问题，并基于学生自己生成的轨迹做 token 级分布匹配蒸馏。相比 on-policy distillation (OPD) 需要独立的兼容词表教师，OPSD 内存与服务开销更低，且在任务习得与通用能力保留之间提供较好的折衷。

**暴露的核心问题**：OPSD 隐含假设"特权知识在学生自身前缀下依然可获取"，但这一假设十分脆弱——尤其对于输出范式、动作空间或推理协议在预训练中表征不足的任务。学生在训练早期极易进入与合法轨迹偏离的上下文，从而引发本文所称的 **rollout-conditioned signal degradation（展开条件化信号退化）**：

- **直接证据**：在 SimpleMath 上，Qwen3-4B 特权教师在 canonical（前缀为标准解）下达到 80.4% 的目标 token 准确率，但在学生自然展开（cold-start）前缀上仅 6.5%，保留比 $\rho \approx 8.1\%$。
- **受控实验**：对标准前缀按比例 $\epsilon \in [0,1]$ 做随机词替换，准确率随 $\epsilon$ 单调下降至 3.8%，与自然展开（约 5%）一致。
- **真实 rollout 分桶**：按"首个偏离位置"分桶，几乎正确的 rollout（[0.91, 1.0]）下教师准确率 82.7%，早期偏离 rollout（[0.15, 0.23]）下仅 20.5%，与受控实验一致。

**朴素补救的失败**：直接加入交叉熵监督 $\mathcal{L}_{\text{naive CE}} = -\frac{1}{|y^*|}\sum_t \log p_S(y_t^*|x,\hat{y}_{<t})$ 会出现"目标—上下文错配"——目标 token $y_t^*$ 在已偏离的前缀 $\hat{y}_{<t}$ 下语义上未必合法。实验显示 Naive OPSD+CE 在 SimpleMath 上仅 55.20%，AIME24 Avg@8 暴跌至 3.33%。而先 SFT 再 OPSD 的两阶段方案则需要人工切换点，且在切换点前后信号被硬性切分。

**核心设计原则**：本文提炼出 **context-validity principle（上下文有效性原则）**——任何监督目标都应被评估在一个使它语义仍然有效的上下文中。

## 2. 方法论：监督蒸馏引导（SDS）

### 2.1 整体思想

SDS 通过 **context-separated（上下文分离）** 的双分支训练，把两类监督信号放在各自语义合法的前缀下：

- **分支 A（rollout-conditioned distillation）**：保留 OPSD，监督在 $[x;\hat{y}]$ 上；
- **分支 B（canonical-context anchoring）**：独立的学生前向计算 $\mathcal{L}_{\text{anchor}}$，监督在 $[x;y^*]$ 上；
- **共享参数**：两分支梯度共同更新同一组 $\Delta\theta$，但前缀互不混入。

### 2.2 目标函数

完整 SDS 损失为：

$$
\mathcal{L}_{\text{SDS}} = \frac{1}{|\hat{y}|}\sum_{t=1}^{|\hat{y}|} D\!\left(p_T(\cdot|x^{PI},\hat{y}_{<t}) \,\|\, p_S(\cdot|x,\hat{y}_{<t})\right) + \alpha \cdot w_{\text{anchor}} \cdot \mathcal{L}_{\text{anchor}}
$$

其中 canonical 锚定分支定义为 teacher-forcing 交叉熵：

$$
\mathcal{L}_{\text{anchor}} = -\frac{1}{|y^*|}\sum_{t=1}^{|y^*|}\log p_S(y_t^*|x, y^*_{<t})
$$

$D$ 采用广义 Jensen-Shannon 散度（bounded，避免分布差异大时梯度爆炸）：

$$
\text{JSD}_\beta(p_T\|p_S) = \beta D_{\text{KL}}(p_T\|m_\beta) + (1-\beta)D_{\text{KL}}(p_S\|m_\beta), \quad m_\beta = \beta p_T + (1-\beta)p_S
$$

### 2.3 自适应锚定权重

权重由 rollout 与目标之间的 token 级相似度在线计算：

$$
w_{\text{anchor}} = 1 - \text{sim}(\hat{y}, y^*)
$$

- 默认采用 token-level F1（去重集合的查全/查准调和均值）；
- $\text{sim}$ 越大（rollout 越接近 target），$w_{\text{anchor}}$ 越小，自动放松锚定；
- 反之在冷启动阶段强化 canonical 锚定。
- 这避免了"先 SFT 再 OPSD"那种人工切换点，构成内生的闭环负反馈机制。

### 2.4 算法流程

1. 采样训练对 $(x,y^*)\sim\mathcal{D}$；
2. 学生生成 rollout $\hat{y}\sim p_S(\cdot|x)$；
3. **分支 A**：教师与学生分别基于 $[x;\hat{y}]$ 计算 $p_T(\cdot|x^{PI},\hat{y}_{<t})$ 与 $p_S(\cdot|x,\hat{y}_{<t})$，计算 $\text{JSD}_\beta$；
4. **分支 B**：独立前向计算 $\mathcal{L}_{\text{anchor}}$（teacher forcing 在 $[x;y^*]$）；
5. 计算 $\text{sim}(\hat{y},y^*)$，得到 $w_{\text{anchor}}=1-\text{sim}$；
6. 合并损失，对共享参数 $\Delta\theta$ 做一次梯度更新。

## 3. 实验设计

### 3.1 模型与数据集

- **基座模型**：Qwen3-1.7B / Qwen3-4B / Qwen3-8B（开源、便于自蒸馏复现）。
- **适配任务**：
  - **ToolAlpaca**（SDFT 处理版）：多轮结构化工具调用；
  - **SimpleMath**：四则小数运算（+、−、×、÷），含 2500 训练样本（每种运算 625 个），1000 测试样本（分层抽样）。
- **保留性基准**（未参与训练）：
  - AIME 2024（30 题）；
  - MATH-500（500 题）；
  - ARC-Challenge（科学推理）。

### 3.2 对比方法

- **SFT**：标准监督微调；
- **GRPO**：组相对策略优化，二元结果奖励；
- **OPSD**：带特权教师的在策略自蒸馏基线；
- **SDS（本文）**；
- 消融：Naive OPSD+CE、Fixed $w{=}0.5$、Fixed $w{=}1.0$、SFT→OPSD 两阶段、$\alpha\in\{0.1,0.5\}$；
- 距离度量消融：Token F1、Exact Match、ROUGE-L F1、Token Edit Distance。

### 3.3 实现细节

- LoRA：rank 64，$\alpha_{\text{LoRA}}{=}128$，dropout 0.05，作用于 q/k/v/o/gate/up/down；
- 优化器 AdamW（SimpleMath：lr $5\times10^{-5}$；Tool-Use：lr $1\times10^{-5}$），bf16 + FlashAttention-2 + 梯度检查点；
- 对话/rollout 通过 colocated vLLM 0.11.0 推理；
- 框架 ms-swift 4.1.3，扩展其 GKD trainer；
- 每组结果取 3 个随机种子（42/43/44）平均。

## 6. 主要结论与发现

### 6.1 任务习得

| 模型 | 方法 | SimpleMath 整体 Acc. | Tools Pass@12 |
|---|---|---|---|
| Qwen3-1.7B | Base / SFT / OPSD / **SDS** | 2.93 / 51.20 / 17.80 / **51.00** | 61.76 / 69.61 / 67.16 / 68.63 |
| Qwen3-4B | Base / SFT / OPSD / **SDS** | 3.77 / 56.43 / 23.23 / **62.43** | 61.76 / 70.10 / 62.75 / **72.06** |
| Qwen3-8B | Base / SFT / OPSD / **SDS** | 2.13 / 55.57 / 10.33 / **56.97** | 69.12 / 76.47 / 68.63 / 70.59 |

SDS 在所有规模的 SimpleMath 上均显著优于 OPSD，并在 Tools 上与 SFT 持平或更优。

### 6.2 通用能力保留（Qwen3-4B / SimpleMath 适配后）

| 方法 | AIME24 Avg@8 | MATH-500 Avg@8 | ARC-Challenge Acc. | Format |
|---|---|---|---|---|
| Base | 72.92 | 95.63 | 92.15 | 98.12 |
| SFT | 38.33 | 56.00 | 66.13 | 73.29 |
| GRPO | 61.25 | 93.75 | 90.58 | 96.63 |
| OPSD | 71.25 | 94.90 | 91.30 | 97.10 |
| **SDS** | **67.98** | **93.65** | 87.75 | 95.69 |

SDS 保留 93.2% 的基础 AIME24 Avg@8，而 SFT 仅 52.6%。

### 6.3 消融（Qwen3-4B SimpleMath）

| 变体 | 设计含义 | Control Acc. | AIME-S |
|---|---|---|---|
| SDS ($\alpha{=}0.2$) | 完整方法 | **62.43** | 67.98 |
| Naive OPSD+CE | 上下文错配 | 55.20 | 3.33 |
| Fixed $w{=}1$ | 固定权重（全 SFT） | 57.20 | 56.25 |
| Fixed $w{=}0.5$ | 固定权重（折衷） | 35.40 | 72.48 |
| SFT→OPSD | 人工调度 | 55.03 | 35.42 |

证实：context isolation、adaptive weighting、内生调度三者缺一不可；同一损失函数仅因前缀不同就产生 49 个百分点的 AIME 差距。

### 6.4 训练动态

- 早期 rollout 与 target 对齐差 → $w_{\text{anchor}}$ 大，canonical 锚定主导；
- 随着对齐提升，$w_{\text{anchor}}$ 下降至一个非零稳态，rollout-conditioned 分支获得更大影响；
- $w_{\text{anchor}}$ 不衰减到零，体现持续的负反馈纠偏；
- 不存在硬性阶段切换点。

### 6.5 距离度量

SDS 对 graded 度量（Token F1 / ROUGE-L F1 / Token Edit Distance）均稳定（约 62.4%），但 Exact Match 显著退化至 56.5%（乘法运算从 ~27% 跌至 3.6%），证实连续相似度优于二元信号。

## 7. 优点与亮点

- **明确诊断一种新的失败模式**：首次清晰命名并系统证明"rollout-conditioned signal degradation"，将 OPSD 长期被忽视的弱点显式化；
- **提出可操作的设计原则**：context-validity principle 直接转化为算法实现——"在前缀 $A$ 上施加的监督目标必须在 $A$ 下语义合法"；
- **机制简洁、可解释**：双分支 + 自适应 $w_{\text{anchor}}$ 闭环负反馈，无路由、无参数冻结、无回放数据，部署简单；
- **跨规模一致**：在 1.7B/4B/8B 三个规模、两类任务、三个外部基准上表现稳定；
- **消融设计严密**：通过同损失函数对比证明问题来自"在哪评估"而非"用什么损失"；
- **公平比较**：所有方法共享 LoRA、优化器、batch size 等超参，仅目标函数不同；
- **超参可解释**：$\alpha$ 作为 plasticity-stability 的可调旋钮，小值偏向能力保留、大值偏向任务习得；
- **开销合理**：相比两阶段管线省掉 SFT 阶段及其切换点调优，SDS 仅多一次学生前向（30–40% 增量）。

## 8. 不足与局限

- **模型家族单一**：仅在 Qwen3 一个系列上验证，作者已明确承认 SDS 在其它基座（Llama、Mistral、闭源模型等）上的泛化未验证；
- **任务域狭窄**：仅 SimpleMath（算术）与 ToolAlpaca（结构化工具调用）两类，对开放问答、代码、长文生成、Agent 任务等是否同样有效尚不清楚；
- **真实 rollout 模拟局限**：受控前缀损坏是随机均匀替换词表项的简化代理，不能完全复现自然 rollout 中结构化、历史依赖的错误模式；
- **算力披露不充分**：未报告总 GPU 小时数、wall-clock 训练时长、单步时延；
- **基础方差未呈现**：主表省略了 3 个种子的标准差，虽可在附录索取，但降低了主要结论的统计显著性感知；
- **保留性测度局限**：AIME24 仅 30 题，Pass@8/Avg@8 等指标的方差可能较大，结论稳定性受样本量影响；
- **$\alpha$ 仍为手动调参**：自适应权重是相对意义上"自适应"——但 $\alpha$ 上限仍

## 11. 适用场景与推广建议

- **强适配场景**：基座对目标任务的输出范式、动作空间或推理协议表征不足，需要"教师特权 + 学生自展开"协同的 LLM 后训练；
- **可替代**：两阶段 SFT→OPSD 中"切换点"难调、容易能力塌缩的情形；
- **可外推的修改思路**：把 anchor 分支由"标准解 teacher-forcing"换为"高质量轨迹 filtered SFT"，或替换相似度度量为 embedding-based metric，可推广到无显式 $y^*$ 的偏好学习场景；
- **谨慎使用**：任务本身已与预训练范式充分对齐（如纯英文写作），此时 OPSD 本身已较稳，SDS 的边际收益会减小。

---

## 12. 总体评价

SDS 不是泛化意义上的新算法族，而是**对 OPSD 这一具体范式的一次结构化补强**。它的真正贡献在于：

1. **把"信号来源"与"信号目标"分开**：双分支 context-separated 设计让 OPSD 不再因为 rollout 偏离而塌缩；
2. **把"调度策略"内生化**：用 $\text{sim}(\hat{y},y^*)$ 在线驱动 $w_{\text{anchor}}$，省去人工阶段切换；
3. **把"上下文有效性"提升为可操作的训练原则**：并提供了"同一损失、不同前缀就足以产生 49 个百分点差距"的强有力证据。

理论深度有限、模型与任务覆盖偏窄、$\alpha$ 仍为人工旋钮——这些是它的限制；但作为对 OPSD 长期被忽视的失败模式的首次系统刻画与可落地的修补方案，SDS 在工程价值与方法论价值上都达到了 ICML/NeurIPS/ICLR 类会议的发表门槛，并有望成为后续 on-policy self-distillation 类工作的标准比较基线。综合评价：**贡献明确、证据扎实、可复现性较好、适用范围已自承受限**。
