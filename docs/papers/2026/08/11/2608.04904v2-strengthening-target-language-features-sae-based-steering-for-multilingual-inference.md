## 摘要
多语言大语言模型在不同语言之间表现出显著的性能差异，而现有的适应方法通常需要更新参数并使用大量多语言训练数据。我们提出了一种推理时的多语言引导方法，利用预训练的稀疏自编码器来识别并强化与目标语言相关的特征。通过使用多语言平行句子，我们比较不同语言间的稀疏自编码器激活，并选择少量与每种目标语言相关的特定层特征。这些特征被解码为引导信号，在无需额外训练的情况下注入模型的隐藏状态。在 Gemma-3-12B-it 上的实验表明，该方法在 XCOPA 上平均提升了 10.9 个百分点的准确率，在 XNLI 上提升了 5.3 个百分点，在 MGSM 上提升了 1.9 个百分点。

## Abstract
Multilingual large language models exhibit substantial performance differences across languages, while existing adaptation methods often require parameter updates and considerable multilingual training data. We propose an inference-time multilingual steering method that uses pretrained sparse autoencoders to identify and strengthen target-language-related features. Using multilingual parallel sentences, we compare SAE activations across languages and select a small number of layer-specific features associated with each target language. These features are decoded into steering signals and injected into the model's hidden states without additional training. Experiments with Gemma-3-12B-it show average accuracy improvements of 10.9 percentage points on XCOPA, 5.3 points on XNLI, and 1.9 points on MGSM.

## 2. 方法论

### 2.1 核心思想
利用预训练的层专用 SAE 对 LLM 隐藏状态进行分解，通过多语言平行句比较 SAE 激活差异，定位与目标语言相关的稀疏特征，再将这些特征解码为引导向量注入隐藏状态，在推理时强化目标语言信息。

### 2.2 关键步骤

**（1）SAE 编码与解码**  
对于第 $l$ 层、token 位置 $t$ 的隐藏状态 $h_t^l \in \mathbb{R}^d$，SAE 编码器和解码器分别为：

$$z_t^l = f_l(h_t^l),\quad \hat{h}_t^l = g_l(z_t^l)$$

其中 $z_t^l \in \mathbb{R}^m$ 是稀疏特征表示，仅少量维度激活。

**（2）语言特定特征识别**  
给定目标语言 $\tau$ 与多语言平行句，对每种语言 $\lambda$ 在第 $l$ 层计算 SAE 激活均值：

$$\mu_\lambda^l = \frac{1}{N}\sum_{i=1}^{N}\left(\frac{1}{T_i^\lambda}\sum_{t=1}^{T_i^\lambda}z_{i,t}^{\lambda,l}\right)$$

定义两种参考表示：

- **多语言质心**（主方法）：$\mu_{multi}^l = \dfrac{1}{|L_{-\tau}|}\displaystyle\sum_{\lambda \in L_{-\tau}}\mu_\lambda^l$
- **英语参考**：直接使用 $\mu_{en}^l$

目标语言激活差异为：

$$\Delta_{\tau,multi}^l = \mu_\tau^l - \mu_{multi}^l,\quad \Delta_{\tau,en}^l = \mu_\tau^l - \mu_{en}^l$$

每层选取绝对差异最大的 Top-k 特征：

$$I_{\tau,r}^l = \text{TopK}(\Delta_{\tau,r}^l, k)$$

**（3）SAE 特征引导**  
构造稀疏 SAE 编码：

$$s_j^l = \begin{cases} \Delta_j^l, & j \in I^l \\ 0, & \text{otherwise} \end{cases}$$

解码为引导向量 $v^l = g_l(s^l)$，在隐藏状态上施加干预：

$$\hat{h}_q^l = h_q^l + \alpha v^l$$

其中 $\alpha$ 为引导强度系数。该干预施加于最终 prompt 位置的选定层（如 layer 47），不修改模型参数。

## 6. 主要结论与发现

- **总体性能提升**：在 Gemma-3-12B-it 上：
  - XCOPA 平均准确率从 54.5 提升至 65.8（**+11.3 分**，摘要报告 +10.9）；
  - XNLI 从 45.6 提升至 49.8（**+4.1 分**）；
  - MGSM 从 80.5 提升至 81.1（**+0.6 分**）。
- **语言层面结果**：
  - XCOPA 9 种语言全部提升，意大利语（+17.5）、印尼语（+15.5）、土耳其语（+13.8）增幅最大；
  - XNLI 9 种语言中 6 种提升，西班牙语（+11.8）、法语（+11.3）、中文（+9.0）增幅大，德语反而下降 2.5 分；
  - MGSM 增幅有限且不均匀（日语下降 0.5 分）。
- **引导强度规律**：XCOPA 增益随 $\alpha$ 上升至 $\alpha \approx 1.4$ 达到峰值后衰减；XNLI 最优 $\alpha$ 较小（$\approx 0.2$）。
- **共享系数**：固定 $\alpha = 0.6$ 时三个任务平均仍为正增益（+4.75 / +1.61 / +2.13 分），证明无需逐语言精细调参。
- **核心机制发现**：
  - 强化目标语言成分可改善下游性能，且非源于抑制英语响应（因为标签 A/B/C 与语言无关）；
  - SAE 稀疏特征比直接选取隐藏维度更有效；
  - 信号中是否包含语义信息呈任务依赖性；
  - 多语言质心与英语参考效果相近，多语言质心略稳定。

## 7. 优点与亮点

- **完全无训练**：仅在推理时注入预计算引导向量，无需更新模型参数或额外多语言训练数据。
- **稀疏化与可解释性**：通过 SAE 特征显式分离"语言成分"与"语义成分"，相比传统激活引导更具解释力。
- **轻量且可组合**：仅需每层 Top-3 特征即可显著提升，计算开销小。
- **系统性消融**：7 种策略的横向对比清晰说明了 SAE、稀疏性、参考选择、信号内容的各自作用。
- **多任务多语言验证**：覆盖常识推理、NLI、数学推理及多种高低资源语言。
- **共享系数实验**：证明方法具备一定跨语言、跨任务的鲁棒性，降低实际部署成本。

---

## 8. 不足与局限

- **依赖预训练 SAE**：方法强依赖于与目标模型兼容的高质量预训练 SAE。目前官方 SAE 仅覆盖少数模型家族，论文实验局限于 Gemma-3-12B-it + Gemma Scope 2，泛化性存疑。
- **单模型验证**：未在 Llama、Qwen、Mixtral 等其他架构上验证，结论的迁移性未知。
- **缺少统计显著性检验**：未报告多次随机种子下的均值与标准差，亦未提供显著性检验，难以判断小幅度波动（如 MGSM +0.6 分）是否稳健。
- **任务与语言覆盖不均**：MGSM 仅 4 种语言且增幅微弱；XNLI 中德语出现性能下降，未深入分析负向案例。
- **参考选择未充分探索**：仅比较多语言质心与英语，未考察其他单语言参考或更复杂的语言中心表征。
- **干预位置单一**：每层仅在最终 prompt 位置施加一次引导，未尝试多层叠加或不同 token 位置干预。
- **$\alpha$ 调参依赖验证集**：在验证集上搜索 $\alpha$ 的做法对低资源语言数据稀缺场景实用性受限。
- **公平性考量**：所有评测均在零样本、英文指令模板下进行，未使用本地化 prompt，对低资源语言可能存在结构劣势。
