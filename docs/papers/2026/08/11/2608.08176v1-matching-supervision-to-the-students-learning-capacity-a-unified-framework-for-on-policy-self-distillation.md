## 摘要
在线策略自蒸馏（OPSD）通过将特权上下文内化到模型参数中，提升大语言模型的推理能力。近期两条研究路线分别通过选择学习哪些 token 以及控制教师接收多少特权信息来改进原始 OPSD。然而，我们发现每条路线在优化其中一个变量的同时固定了另一个变量，导致次优解。我们认为这两个变量通过学生的学习能力相互耦合：特权信息设定了教师为每个 token 所规定的散度，而 token 加权则选择了学生必须吸收其中的哪些部分。我们将这两条工作路线形式化为一个统一的优化框架，在学生可吸收的总学习难度预算约束下，最大化教师—学生之间的总散度。在此建模下，我们提出了统一在线策略自蒸馏（USD），一种用于求解拉格朗日函数的轻量级在线算法。USD 揭示了一个对偶变量同时支配这两项决策：以学习难度的单一价格，它同时设定 token 选择阈值与特权信息调整方向，使监督信号始终与学生不断变化的能力相匹配。通过大量实验，USD 在不同模型规模和多种推理基准上，持续优于 OPSD 以及 token 侧和 PI 侧基线方法。代码已开源：https://github.com/lauvlalala/USD。

## Abstract
On-policy self-distillation (OPSD) improves the reasoning abilities of LLMs by internalizing privileged context into model parameters through self-distillation.   Two recent research lines promote vanilla OPSD by choosing which tokens to learn from and by controlling how much privileged information the teacher receives, respectively.   However, we show that each line optimizes one variable while holding the other fixed, which leads to a suboptimal solution.   We argue that the two variables are coupled through the student's learning capacity: the privileged information sets the per-token divergence the teacher prescribes, while token weighting selects which of these the student must absorb.   We formalize the two lines of work into a unified optimization framework, which maximizes the aggregate teacher--student divergence, subject to a budget on the aggregate learning difficulty the student can absorb.   Under this modelling, we propose Unified On-Policy Self-Distillation (USD), a lightweight online algorithm to solve the Lagrangian.   USD reveals that a single dual variable governs both decisions: at one price for learning difficulty, it simultaneously sets the token-selection threshold and the direction of privileged-information adjustment, keeping supervision matched to the student's evolving capacity.   Through extensive experiments, USD consistently demonstrates superior performance over OPSD and token- and PI-side baselines across various model scales on various reasoning benchmarks. Code is available at https://github.com/lauvlalala/USD.

## 1. 核心问题与研究动机

**背景**：On-Policy Self-Distillation（OPSD）已成为大语言模型推理后训练的主流范式，它以同一基础模型分别扮演学生与"特权教师"，仅依赖训练时可获得、推理时不可见的"特权信息"（PI，如参考解、环境反馈、真实推理链）对学生自身的 rollout 进行密集监督。OPSD 在竞赛数学、代码、Agent 等任务上效果显著，计算开销远低于强化学习（如 GRPO）。

**两类改进路线及其局限**：
- **Token 选择路线**：均匀 token 加权效率低下，研究表明约 80% 的梯度信号集中在 20% 的 token 上，且高散度位置未必可学。因此学者提出基于散度、熵、位置、可学性等信号的重加权方法。
- **PI 控制路线**：完全暴露 PI 会令教师分布偏离学生过远，难以被一步梯度吸收；同时 PI 中若包含答案，会泄漏 shortcut。学者通过自适应掩膜、暴露调度、稀疏插值等方式控制 PI 强度。

**关键洞察**：上述两条路线彼此独立——token 选择在固定教师下重分配监督，PI 控制在均匀加权下调节教师信号。但实际上两者通过**学生的学习能力**相互耦合：降低 β 会整体降低每个 token 的难度，从而引入原本不可吸收的 token；反过来，过滤高难度 token 又能腾出容量去接受更高的 β。因此优化任一变量同时固定另一变量，只能达到条件最优而非联合最优。

## 2. 方法论：USD 统一优化框架

### 2.1 两个设计轴

OPSD 的一般加权目标为：

$$J(w, \beta) = \frac{1}{\sum_t w_t} \sum_{t=1}^{|\hat y|} w_t \cdot D_{\mathrm{KL}}\!\left(p_T^\beta(\cdot|x,\hat y_{<t}) \;\|\; p_S(\cdot|x,\hat y_{<t})\right)$$

其中 $\beta \in [0,1]$ 控制 PI 暴露强度，$w_t \in [0,1]$ 为逐 token 权重；Vanilla OPSD 即 $\beta=1, w_t\equiv 1$。

每个 token 的教师信号由两个量刻画：
- **散度**（潜在更新幅度）：$g_t(\beta) = D_{\mathrm{KL}}\!\left(p_T^\beta \,\|\, p_S\right)_t$
- **学习难度**（吸收代价）：$d_t(\beta) = \left[\log\frac{p_T^\beta(a_t^\star)}{p_S(a_t^\star)}\right]_+$

二者均随 $\beta$ 严格单调递增（文中已在 Qwen3-1.7B 实测验证，见图 4）。

### 2.2 容量匹配约束优化与可学性边界

将监督匹配学生容量建模为约束优化：

$$\max_{w\in[0,1]^T,\;\beta\in[0,1]} \frac{1}{N}\sum_t w_t g_t(\beta) \quad \text{s.t.} \quad \frac{1}{N}\sum_t w_t d_t(\beta) \le \varepsilon$$

其中 $\varepsilon>0$ 是学生的批量学习容量预算。扫描 $\varepsilon$ 即得 **Learnability Frontier** $F(\varepsilon)$：每个容量等级下可达的最大平均散度，是散度–难度权衡的 Pareto 前沿。Token 选择与 PI 控制各自仅在 $F(\varepsilon)$ 上的一维切片内搜索，作者则同时沿两个维度移动以找到容量匹配点。

### 2.3 拉格朗日结构与单一对偶变量

对偶变量 $\lambda \ge 0$ 给出 Lagrangian：

$$\mathcal{L}(w,\beta,\lambda) = \frac{1}{N}\sum_t w_t\bigl[g_t(\beta) - \lambda d_t(\beta)\bigr] + \lambda\varepsilon$$

由于对 $w_t$ 为线性、最优 token 选择塌缩为硬阈值：

$$w_t^\star = \mathbb{1}\!\left[g_t(\beta) > \lambda d_t(\beta)\right]$$

当预算紧（$\lambda>0$）时，内点 $\beta^\star$ 的平稳性条件为：

$$\lambda = \frac{\sum_{t:w_t^\star=1} \partial g_t/\partial\beta}{\sum_{t:w_t^\star=1} \partial d_t/\partial\beta}$$

即 $\lambda$ 同时是 token 决策中"难度的边际价格"和 PI 调整中"散度与难度间的汇率"。

**定理 1（残差更新等价最优 PI 强度）**：在单调性假设下，$\beta \leftarrow \beta + \eta_\beta(\varepsilon-\mathrm{load}(\beta))$ 单调收敛至 $\beta^\star$（使 $\mathrm{load}(\beta^\star)=\varepsilon$），无需对 $\beta$ 求梯度。

### 2.4 USD 线上原对偶算法

因 $\lambda$ 与 $w$ 需在线联合估计、且 0/1 阈值不可微，USD 用 sigmoid 平滑与熵正则化替代硬阈值：

$$w_t = \sigma\!\left(\frac{g_t(\beta) - \lambda d_t(\beta)}{\tau}\right)$$

对偶上升与 PI 更新分别为：

$$\lambda \leftarrow \max\!\left\{0,\; \lambda + \eta_\lambda(\mathrm{load} - \varepsilon)\right\}$$

$$\beta \leftarrow \mathrm{clip}\!\left(\beta + \eta_\beta(\varepsilon - \mathrm{load}),\; \beta_{\min}, 1\right)$$

训练损失用总权重归一化：

$$\mathcal{L}_{\mathrm{train}} = \frac{\sum_t w_t\, D_{\mathrm{KL}}(p_T^\beta\|p_S)_t}{\sum_t w_t}$$

**算法 1（USD）**：每批采样学生 rollout → 用 PI 强度 $\beta$ 对教师打分 → 计算 $g_t, d_t$ → 软权重 → 归一化 KL 损失做梯度步 → 计算当前 load → 更新 $\lambda$ 与 $\beta$。每个 batch 仅一次额外 $O(T)$ 扫描 + 两个标量更新，**无需辅助网络或额外前向传播**。

- 采样：训练时温度 1.1、top-p 0.95、top-k 20、max-len 1024；评测每题 12 解、温度 1.0，每 50 步存 checkpoint。

## 6. 主要结论

1. **联合优化显著优于单轴优化**：USD 在 1.7B/4B/8B 三个规模上的 9 单元均值从 56.4 提升至 58.7（**+2.3 个点**），各单尺度均稳定 +2 左右。
2. **单一对偶变量同时支配 token 选择与 PI 调整**：训练动力学显示，当 budget 处于松弛时 $\beta$ 上升、$\lambda\approx 0$；当 load 触及预算时 $\lambda$ 激活收紧 token 筛选，同时 $\beta$ 略微回落，**二者共同稳定 load 在 $\varepsilon$ 附近**。
3. **两类改进路径互补**：表 2 显示 PI 适配在 4B/8B 略占优，token 选择在 1.7B 略占优；任何固定手调组合在某一端都会失配，而 USD 的耦合公式在所有尺度上保持最佳。
4. **预算 $\varepsilon$ 存在最优值（0.3）**：过紧（0.15–0.20）造成欠监督；过松（0.50–0.80）使约束几乎不激活，方法退化为近似均匀加权——印证了"匹配学生能力"是收益来源，而非"一味多筛"。
5. **小采样预算击败 GRPO**：在远小于 GRPO 的采样成本下，USD 在 1.7B/4B/8B 平均分别领先 +4.7 / +2.0 / +1.5 个点。

## 7. 优点

- **理论贡献清晰**：把经验性的两类工程改进凝练为带容量约束的 Lagrangian 优化，并证明残差更新等价于最优 PI 强度——给出单调收敛性保证（命题 1）。
- **算法极轻量**：仅多一次 $O(T)$ 扫描和两个标量更新；不引入辅助网络、不增加前向传播，工业友好。
- **超参跨尺度固定**：$\tau,\varepsilon,\eta_\lambda,\eta_\beta,\beta_{\mathrm{init}}$ 全规模统一，减弱了过拟合调参嫌疑。
- **机制可视化充分**：用训练轨迹图展示 $\lambda$ 与 $\beta$ 的"协商过程"，让读者直观看到监督与容量如何共演化。
- **定位明确**：强调"一种底层资源（容量预算）"和"两个表达"（token 权重与 PI 强度），为后续工作提供统一视角。

## 8. 不足与局限

- **算力与可复现性信息缺失**：未披露 GPU 型号/数量、训练墙钟时间、峰值显存；LoRA-300 步的能耗与基线公平性难以独立判断。
- **任务与家族覆盖窄**：仅 Qwen3 三档、仅数学推理、仅英文竞赛题；未在代码、Agent、多语言或非数学推理上验证。
- **消融粒度有限**：未做 $\tau$、$\eta_\lambda$、$\eta_\beta$、$\beta_{\min}$ 的敏感度扫描；LoRA rank、batch size、$\beta$ 离散化方式（字符比例）的选择也无消融。
- **潜在偏差风险**：
  - 所有方法共享同一训练数据，OpenThoughts 本身的质量和分布直接影响结果；
  - Vanilla OPSD / TIP / PAINT 均由作者复现或基于默认设置，"公平但未必最优"——基线的最佳调参可能未达；
  - 评测仅取每 benchmark "best checkpoint over checkpoints saved every 50 steps"，存在 checkpoint 选择偏差。
- **应用边界**：当前公式以"教师散度对 $\beta$ 单调"为前提，若 PI 控制方式无法保持该单调性（如离散跳跃式掩膜），残差更新可能失效。
- **缺少理论泛化界**：未给出对学生最终损失或任务性能的有限样本保证；命题 1 仅证 $\beta$ 的收敛，不直接解释下游准确率提升。
