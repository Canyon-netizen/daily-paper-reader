## 摘要
智能体强化学习使大语言模型（LLM）智能体能够通过交互进行学习，但稀疏的轨迹级奖励只能揭示成功与否，而无法识别哪些中间决策应获得信用分配。仅在训练时使用的特权技能可通过允许同一冻结策略快照对来自无技能轨迹的固定 token 进行重新评分（同时以任务匹配的流程性技能为条件），从而提供更密集的监督。然而，现有方法未能联合校准跨交互步骤的教师分数、将教师置信度与实际回报相关联，并将所得信号整合到原生奖励到优势的构建过程中。我们提出了基于自蒸馏奖励塑形的智能体强化学习（ADRS），这是一个为多轮语言智能体构建回报相关 token 级信用分配的框架。ADRS 在每个步骤内对特权 token 分数进行中心化和归一化，通过基于组内置信度—回报关联的回报相关教师价值优势（TVA）门控机制对其进行调制，并将门控后的 token 信号整合到原生强化学习信用分配路径中。这些组件共同确定了教师偏好的内容、该偏好何时与回报相关、以及它如何进入原生强化学习信用分配路径，同时保持 rollout 和推理过程无技能化。最后，在三个交互基准上的实验表明，ADRS 在长程任务上持续提升性能，且这些增益在不同的强化学习骨干网络、数据缩减设置、未见任务以及延长训练下均得以保持。鉴于匿名评审要求，我们的代码可通过以下链接获取：https://github.com/gitrxh/ADRS-arxiv

## Abstract
Agentic reinforcement learning enables LLM agents to learn through interaction, but sparse trajectory-level rewards reveal success without identifying which intermediate decisions deserve credit. Training-only privileged skills can provide denser supervision by allowing the same frozen policy snapshot to rescore fixed tokens from skill-free trajectories while conditioned on task-matched procedural skills. Existing methods, however, do not jointly calibrate teacher scores across interaction steps, relate teacher confidence to realized returns, and integrate the resulting signal into native reward-to-advantage construction. We introduce Agentic Reinforcement Learning with Self-Distilled Reward Shaping (ADRS), a framework for constructing return-associated token-level credit for multi-turn language agents. ADRS centers and normalizes privileged token scores within each step, modulates them with a return-associated Teacher Value Advantage (TVA) gate based on within-group confidence--return association, and incorporates the gated token signal into native RL credit construction. Together, these components determine what the teacher prefers, when that preference is return-relevant, and how it enters the native reinforcement-learning credit path, while keeping rollouts and inference skill-free. Finally, experiments across three interactive benchmarks show that ADRS consistently improves performance on long-horizon tasks, with gains persisting across RL backbones, reduced-data settings, unseen tasks, and extended training. For anonymous review, our code is available at the following the link: https://github.com/gitrxh/ADRS-arxiv

## 1. 核心问题与研究动机

- **场景**：多轮 LLM 智能体强化学习（Agentic RL）需要在交互环境中为每个 token 决策分配信用，但常规方法（如 GRPO、GiGPO）只使用稀疏的轨迹级终局奖励，只能判断"是否成功"，无法定位"哪些中间决策值得学习"。
- **已有路径**：引入"训练时特权技能"（procedural skills）作为教师信号，可在不改变推理时输入的前提下提供更密集的过程级监督。代表方法有 OPSD、GRPO+OPSD、Skill-SD、RLSD、SDAR 等。
- **三大未解决挑战**：
  1. **分数校准（Score Calibration）**：教师对数概率的偏移和尺度随上下文长度、交互位置、回答长度变化，跨步骤不可直接比较。
  2. **可靠性估计（Reliability Estimation）**：教师置信度高未必代表该决策与终局回报相关（可能只是语言层面的常见表达）。
  3. **信用整合（Credit Integration）**：既有方法多把特权监督作为独立的辅助蒸馏目标，绕开了 GRPO/GiGPO 原生的"奖励→优势→策略"通路。
- **研究目标**：将特权教师信号统一转化为**与回报相关联的 token 级信用**，并嵌入到原生 RL 信用路径中，同时保持 rollout 与推理完全无技能依赖。

## 2. 方法论

ADRS 由三个并行/串行模块构成，对应上述三个挑战：

### 2.1 模块一：步内相对特权打分（Within-Step Relative Privileged Scoring）

- 行为策略 $\pi_{\theta_b}$ 先采样无技能轨迹；再冻结 $\theta_b$，对**同一批采样到的 token** 在特权上下文 $\rho(x)\oplus h_s$ 下重新打分：
  $$\ell^b_{s,j}= \mathrm{sg}\!\left[\log\pi_{\theta_b}(y_{s,j}\mid h_s, y_{s,<j})\right],\quad \ell^T_{s,j}= \mathrm{sg}\!\left[\log\pi_{\theta_b}(y_{s,j}\mid \rho(x)\oplus h_s, y_{s,<j})\right]$$
- 对每步内有效 token 做**中心化 + 尺度归一化**，得到相对支持度：
  $$b_s=\frac{1}{|\mathcal V_s|}\sum_{j\in\mathcal V_s}\ell^T_{s,j},\quad q_{s,j}=\ell^T_{s,j}-b_s$$
  $$\hat q_{s,j}=\frac{q_{s,j}}{\sigma_q+\varepsilon},\qquad \sum_{j\in\mathcal V_s}\hat q_{s,j}=0$$
- 含义：移除该步整体置信度偏移，使不同交互步之间的"相对偏好"具有可比性。

### 2.2 模块二：回报相关 TVA 门控（Return-Associated TVA Gate）

- TVA 支持两级粒度：
  - **L2（完成级）**：与 GRPO 一致，比较同一 prompt 下的多条轨迹，使用**基础回报 $R_u$**。
  - **L3（步骤级）**：与 GiGPO 一致，以重复锚状态为单位，使用**从该状态起的回报-to-go**。
- 在所选粒度上计算组内置信度、软高置信度权重与两侧回报对比：
  $$\bar\ell^T_u=\frac{1}{|\mathcal V_u|}\sum_{(s,j)\in\mathcal V_u}\ell^T_{s,j},\quad \bar\ell^T_{\mathrm{batch}}=\frac{1}{|\mathcal U|}\sum_{u\in\mathcal U}\bar\ell^T_u$$
  $$\alpha_u=\sigma(\bar\ell^T_u-\bar\ell^T_{\mathrm{batch}})$$
  $$\mu^+_g=\frac{\sum_{u\in g}\alpha_u R_u}{\sum_{u\in g}\alpha_u+\varepsilon},\quad \mu^-_g=\frac{\sum_{u\in g}(1-\alpha_u)R_u}{\sum_{u\in g}(1-\alpha_u)+\varepsilon}$$
  $$d_g=\mu^+_g-\mu^-_g,\qquad m_u=\mathrm{sg}\!\left[\sigma(\tau\,\tilde d_{g(u)})\right]$$
- **命题 1（TVA 即回报关联）**：
  $$d_g=\frac{\mathrm{Cov}_g(\alpha,R)}{\bar\alpha_g(1-\bar\alpha_g)}$$
  门控符号与组内"特权置信度—回报"协方差一致；gate $=1$ 表示关闭 TVA。
- **含义**：用一个标量门控决定教师信号"在何时被信任"，避免对高置信但低回报的局部习惯化表达过度赋权。

### 2.3 模块三：教师引导的 token 级优势调制（Teacher-Guided Per-Token Advantage Modulation）

- 将门控后的 token 奖励加入基础奖励（**优势构造之前**），保持"奖励→优势→策略"单一通路：
  $$r^T_{s,j}=\eta\,m_{s,j}\,\hat q_{s,j},\qquad \tilde r_{s,j}=r^{\mathrm{base}}_{s,j}+r^T_{s,j}$$
- **轨迹路径**：使用原生骨干（GRPO/GiGPO）对 $\tilde r$ 求轨迹得分 $S_{i,k}$ 并组内归一化得到 $A^{\mathrm{traj}}_{i,k}$。
  $$A^{\mathrm{traj}}_{i,k}=\frac{S_{i,k}-\mu_{S_i}}{\sqrt{(\sigma_{S_i})^2+\varepsilon}}$$
- **Token 路径**：在 prompt 组 $g$ 内对保存的 $r^T$ 做白化：
  $$Z^T_t=\frac{r^T_t-\mu^T_g}{\sqrt{(\sigma^T_g)^2+\varepsilon}}$$
- **最终合并（仅在此处一次性合并）**：
  $$A^{\mathrm{ADRS}}_{i,k,t}=A^{\mathrm{traj}}_{i,k}+\eta Z^T_{i,k,t}$$
- **命题 2（步级零和表示）**：在步级共享门控与归一化分母时，
  $$\sum_{j\in\mathcal V_s}r^T_{s,j}=0$$
  因此步级教师信号加和为零，轨迹路径得分与基础奖励时一致；token 路径独立保留特权结构。
- **命题 3（轨迹保持 + 局部 token 梯度等价）**：在 $\theta=\theta_b$ 且裁剪未激活时，
  $$\nabla_\theta J_{\mathrm{ADRS}}\big|_{\theta_b}=\frac{1}{|\mathcal V|}\sum_{t\in\mathcal V}(A^0_t+\Delta A_t)\nabla_\theta\log\pi_\theta(y_t\mid c_t),\quad \Delta A_t=\eta Z^T_t$$
  与解耦的辅助 token 系数 $a_t=\Delta A_t$ 在一阶意义上等价，但 ADRS 不需要独立蒸馏目标。
- **策略更新**：使用标准 PPO 风格裁剪目标 + 行为策略冻结，骨干（GRPO/GiGPO）的原生熵、KL、优势结构保持不变。

## 6. 主要结论与发现

- **SOTA**：Qwen2.5-3B 上 ADRS 在三个基准同时刷新最优：ALFWorld 94.5%（+10.1 pp），Search 45.0 macro-EM（+0.4），WebShop 87.5/76.6（+2.5/+8.6）。

- **泛化**：ALFWorld 未见 split 平均提升 +11.9 pp，Cool/Pick2/Heat 提升最大（+22.8/+18.1/+12.9）。
- **长交互鲁棒**：max steps = 25/35/50 下 ADRS 持续高于 SDAR（85.2/85.2/94.5 vs 78.9/75.0/84.4）。

## 7. 优点与亮点

- **统一的三组件设计**：分数校准、可靠性门控、信用整合三者各有明确职责并耦合于单一通路（pre-advantage reward shaping），避免了"独立辅助蒸馏"常见的与原生优势目标相互干扰问题。
- **理论可解释性**：三个命题（TVA 与组内协方差同号、步级零和、行为策略点处与解耦辅助梯度一阶等价）使方法具有清晰的不变量与边界条件。
- **推理时无技能、训练时无更大教师**：仅复用冻结的同策略快照作为特权打分器，部署成本与基线 RL 持平。
- **与多种原生 RL 骨干兼容**：在 GRPO 与 GiGPO 上都能稳定增益，配套给出 L2 / L3 粒度与 L1 退化路径。
- **全面的诊断实验**：动作/对象/风格 token 级别的 gap 演化，为"特权信号真正引导了什么"提供了机制层面的证据。
- **实用化设置**：在低数据（60%）和更长交互预算（50 步）下仍保持优势，说明其对长程信用分配切实有效。
