## 摘要

## Abstract
We study online cooperative control of a multi-agent system under Byzantine attacks. Namely, an unknown, fixed subset of agents are Byzantine comprised and can stealthily overwrite its own coordinates of the team's planned joint action after observing that plan. The learner observes planned actions, public rewards, and public states, but neither the overwrite nor the executed joint action. Our objective is security: to optimize the team performance against the worst overwrites and achieve the optimal security value. We first show that the attacker's information determines the geometry. An attacker that observes the planned action induces an exact $(s,a)$-rectangular robust Markov decision process (MDP) whose rows are convex hulls of overwrite-induced public-outcome laws, whereas a blind attacker induces an $s$-rectangular model. We then identify the information-theoretic limit of security learning, showing that the security regret decomposes exactly into return regret against the response generating the data and a cumulative response gap $D_K$. Two indistinguishable horizon-one instances force $Ω(K)$ expected security regret while return regret is zero, showing that dependence on $D_K$ is unavoidable. Finally, we develop a stage-tied robust estimation-to-decisions learner and prove a regret bound of $\widetilde{\mathcal O}\!\left(H^2S\sqrt{AK}\right)+\mathbb E[D_K]$. Our studies thus provide comprehensive theoretical and algorithmic foundations of reliable multi-agent systems under Byzantine attacks.

### 2.1 核心思想
论文以**纯理论分析**为主，建立问题几何结构→识别信息论极限→设计学习算法并证明遗憾上界。具体包括三个核心贡献：

**(1) 精确公共律归约（Exact Public-Law Reduction）**

$$\Gamma_{h,s,a}^{B_\star} := \mathrm{conv}\left\{P_h^{\mathrm{phys}}(\cdot \mid s, a \oplus_{B_\star} u) : u \in A_{B_\star}\right\}$$

证明操作层面的拜占庭交互所诱导的条件公共结果律恰好是该矩形行族 $\Gamma^{B_\star} = (\Gamma_{h,s,a}^{B_\star})$ 的非预期选择器（Proposition 3.1）。

**(2) 安全遗憾分解**

定义**回报遗憾**与**响应缺口** $D_K$：
$$\mathrm{Reg}_K^{\mathrm{sec}} = \mathrm{Reg}_K + D_K$$
其中 $m_k := E_{\pi^k, q^k}\left[\sum_{h=1}^{H} R_{k,h} \mid \mathcal{F}_{k-1}\right]$ 是事实回报，$W(\pi^k)$ 为最坏回报，$d_k := m_k - W(\pi^k) \ge 0$，$D_K = \sum_{k=1}^K d_k$。

**(3) 信息论下界**

构造两个不可区分的单步实例 $\mathcal{M}_0, \mathcal{M}_1$（Theorem 4.1）：
- 相同的固定且已知的 $B_\star = \{2\}$；
- 相同的确定性覆写策略；

因此依赖 $D_K$ 是不可避免的——纯公共反馈无法一致地认证安全。

### 2.2 算法：阶段绑定的鲁棒估计到决策（Stage-Tied Robust E2D）

核心创新是引入**层绑定估计器**（Stage-Tied Estimator），将原本的 $\widetilde{\mathcal{O}}(HS^2)$ 估计预算降至 $\widetilde{\mathcal{O}}(HS)$，从而获得 $\sqrt{S}$ 的改进。

**关键步骤**：
1. **私有编码**：将奖励 $R_{k,h}$ 通过 Bernoulli 编码为 $Y_{k,h} = \mathbf{1}\{U_{k,h} \le R_{k,h}/H\}$，统计得分为 $HY_{k,h}$；
2. **层证书结构**：每阶段 $h$ 共享一个**延续向量** $\bar{v}$，对所有前驱状态统一处理；
3. **市场投注**：包含片段投注（fragment）、校准投注（calibration）、参考投注（reference）、乐观投注（optimism），通过财富更新维持后验；
4. **鲁棒 DP 决策模块**：借助 Appel-Kosoy 的 E2D 框架 [18]，使用 $\widetilde{\mathcal{O}}(H^2S\sqrt{AK})$ 的 DEC 界；
5. **安全转换**：通过 $\mathrm{Reg}_K^{\mathrm{sec}} = \mathrm{Reg}_K + D_K$ 将回报遗憾转化为安全遗憾。

**主要定理**：

- **Theorem 5.3（阶段绑定估计）**：在概率 $\ge 1-\delta$ 下：
$$\mathrm{Est}_K := \sum_{k=1}^{K} \mathrm{E}_{\pi \sim p_k} L(c_{M_k}, N^\circ, \pi) \le 144 HS \Lambda_K(\delta)$$
其中 $\Lambda_K(\delta) = \log\frac{128H^2A(K+1)^2}{\delta^2}$。

- **Theorem 5.4（安全遗憾保证）**：在假设 5.2 的近似决策神谕条件下，
$$\mathrm{E}[\mathrm{Reg}_K^{\mathrm{sec}}] \le \min\left\{HK, C_K + \mathrm{E}[D_K]\right\}$$
其中 $C_K = 114 H^2 S \sqrt{AK} \Lambda_K(K^{-2})$。当攻击者采用精确事后最坏响应时 $D_K = 0$，得 $\mathrm{E}[\mathrm{Reg}_K^{\mathrm{sec}}] \le C_K = \widetilde{\mathcal{O}}(H^2 S\sqrt{AK})$。

### 2.3 马尔可夫策略充分性

**Theorem 3.2**：在 insider 模型下，对任意 Markov 策略 $\pi$，存在一个确定性非平稳 Markov 响应达到 $W(\pi) = V_1^\pi(s_1)$；且存在一个确定性非平稳 Markov 学习策略达到 $v^\star$。
