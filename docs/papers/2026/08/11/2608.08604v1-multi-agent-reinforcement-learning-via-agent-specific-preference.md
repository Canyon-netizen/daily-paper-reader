## 摘要
多智能体强化学习（MARL）是解决复杂协作任务的强大框架，但它严重依赖于良好定义的全局奖励函数。设计这样的奖励具有挑战性，尤其是在具有异构智能体的系统中，单一标量目标可能无法捕捉到多样的行为。在本文中，我们提出了多智能体偏好集成学习（MAGPIE），通过智能体特定的偏好建模来应对这些挑战。每个智能体由专门的专家通过偏好信号进行评估，从而消除了全局评估的需要。我们从理论上证明，优化这些去中心化的偏好收敛到纳什均衡策略。为了将局部偏好整合为一致的全局目标，我们从偏好数据中构建智能体特定的奖励模型，并通过单调聚合机制将它们组合起来。我们进一步证明，优化这个聚合奖励模型等价于训练纳什均衡策略。在基准多智能体任务和顺序生产线任务上的大量实验表明，MAGPIE取得了与人工设计奖励的基线方法相当的性能，展示了其在精确奖励工程不切实际的场景中促进策略学习的潜力。

## Abstract
Multi-agent reinforcement learning (MARL) is a powerful framework for solving complex collaborative tasks, but it relies heavily on well-defined global reward functions. Designing such rewards is challenging, especially in systems with heterogeneous agents, where a single scalar objective may fail to capture diverse behaviors. In this paper, we introduce Multi-AGent Preference-Integrated lEarning (MAGPIE), which addresses these challenges through agent-specific preference modeling. Each agent is evaluated by a dedicated expert through preference signals, eliminating the need for global evaluation. We theoretically prove that optimizing these decentralized preferences converges to a Nash equilibrium policy. To integrate local preferences into a coherent global objective, we construct agent-specific reward models from preference data and combine them via a monotonic aggregation mechanism. We further prove that optimizing this aggregate reward model is equivalent to training the Nash equilibrium policy. Extensive experiments on benchmark multi-agent tasks and a sequential production line task show that MAGPIE achieves performance comparable to reward-engineered baselines, demonstrating its potential to facilitate policy learning in scenarios where precise reward engineering is impractical.

## 2. 方法论

### 2.1 整体框架
**MAGPIE（Multi-AGent Preference-Integrated lEarning）** 采用 CTDE（集中训练-分散执行）范式，包含三个核心组件：
1. **n 对 n 专家-智能体偏好机制**：每个智能体由专属"教师"评估，避免全局评估负担；
2. **智能体特定奖励模型**：通过 Bradley-Terry 模型从偏好数据学习局部奖励 $\hat{r}_i(s, A)$；
3. **单调聚合机制**：将局部奖励聚合为全局奖励 $\hat{r}(s, A)$，无缝对接标准 MARL 算法（如 QMIX、VDN、MAPPO）。

### 2.2 核心数学形式化

**Dec-POMDP 设定**：$n$ 个智能体的目标是最大化
$$\max_\theta J(\theta) = \mathbb{E}_{(A_t, s_t)} \left[ \sum_t \gamma^t r(s_t, A_t) \right]$$

**偏好定义**：对智能体 $i$，教师提供元组 $(\sigma^{(0)}, \sigma^{(1)}, p_i)$，其中 $p_i \in \{0, 0.5, 1\}$ 表示对两段长度为 $H$ 的轨迹片段的偏好。

### 2.3 理论保证

**定理 1**（Nash 均衡收敛）：在有限状态/动作空间下，若假设 1–4 成立，则算法 1（迭代局部偏好优化）当轨迹长度 $H \to \infty$ 时返回的策略 $\pi^* = (\pi_1^*, \ldots, \pi_n^*)$ 构成 Nash 均衡：
$$\mathbb{E}_{\tau \sim (\pi_i^*, \pi_{-i}^*)} \left[ \sum_{t=0}^\infty \gamma^t r(s_t, A_t) \right] \geq \mathbb{E}_{\tau \sim (\pi_i', \pi_{-i}^*)} \left[ \sum_{t=0}^\infty \gamma^t r(s_t, A_t) \right]$$

**推论 1**：当片段对足够可区分（$|R_H(\sigma^0) - R_H(\sigma^1)| \geq \delta > 0$）时，$H \geq \log \frac{\gamma \delta (1-\gamma)}{2 r_{\max}^2}$ 即可保证收敛。

**定理 2**（聚合奖励等价性）：在假设 1–7 下，若 $\hat{r}_i$ 完美对齐教师偏好，则聚合奖励 $\hat{r}(s, A) = \sum_{i=1}^n \hat{r}_i(s, A)$ 的最优策略即为真值奖励的 Nash 均衡策略。

**定理 3**（样本复杂度）：使用 Bradley-Terry 模型和交叉熵损失 $L_i^{\text{pref}}$ 学习奖励模型，当偏好数据规模 $N \to \infty$ 时，$\hat{r}_i^{\psi^*}$ 依概率一致收敛到 $r_i$（最多相差仿射变换），且有限样本误差满足：
$$\|\hat{r}_i^{\psi^*} - r_i\|_{L_2(\mu)}^2 \leq O\left( \mathcal{R}_N(\mathcal{F}) + \sqrt{\frac{\log(1/\delta)}{N}} \right)$$

**定理 4**（$\epsilon$-Nash 均衡）：聚合学习奖励 $\hat{r}$ 下的 Nash 均衡策略 $\pi^*$ 在真实偏好目标 $R_{\text{true}}(s,A) = \alpha \sum_i r_i(s,A) + n\beta$ 下构成 $\epsilon$-Nash 均衡，其中
$$\epsilon = \frac{2n \epsilon_r(N)}{1-\gamma}, \quad \epsilon_r(N) = O(1/\sqrt{N})$$

### 2.4 关键算法细节

**Bradley-Terry 偏好预测**：
$$P_\psi[\sigma^{(1)} \succ_i \sigma^{(0)}] = \frac{\exp\left( \sum_t \gamma^t \hat{r}_i^\psi(s_t^{(1)}, A_t^{(1)}) \right)}{\sum_{j \in \{0,1\}} \exp\left( \sum_t \gamma^t \hat{r}_i^\psi(s_t^{(j)}, A_t^{(j)}) \right)}$$

**总损失函数**（含正则项强化假设 7）：
$$L_i = L_i^{\text{pref}} + \lambda L_i^{\text{reg}}$$

其中正则化项：
$$L_i^{\text{reg}} = \mathbb{E}_{(\sigma^{(0)}, \sigma^{(1)}, p_i)} \left[ \max\left(0, \mathbb{I}[\sigma^{(1)} \succ_i \sigma^{(0)}] \cdot \left(\hat{R}(\sigma^{(0)}) - \hat{R}(\sigma^{(1)})\right)\right) \right]$$

### 2.5 实用技巧
- **连续偏好收集**：每 $K$ 步从新生成轨迹中收集 $M$ 对偏好，而非一次性收集；
- **经验重标记**：每次更新奖励模型后，使用最新 $\hat{r}$ 重新标记回放缓冲区中的历史转移；
- **算法 2**：MAGPIE 完整流程，与 QMIX 无缝集成。
