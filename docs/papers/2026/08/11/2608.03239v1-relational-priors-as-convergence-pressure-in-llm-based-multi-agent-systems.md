## 摘要
基于大语言模型的多智能体系统（LLM-MAS）通过角色、辩论协议和聚合规则进行设计。这些选择会产生隐式的社会期望：智能体可能被期望信任、质疑、服从同伴或与其协作。我们研究了使智能体间关系语义显式化所产生的影响。我们采用关系先验的最小有符号网络形式化，并在固定任务协议的前提下，将自然语言化的表述注入智能体的系统提示中。在公共资源治理仿真与多智能体辩论的实验中，关系先验主要充当收敛压力：关系正向性的提高倾向于使智能体更易于协调或达成一致。当效用函数奖励行为对齐时——例如在可持续资源治理与主观共识形成中——这种压力能够带来帮助。然而，它并不能可靠地提升准确性。在客观问答辩论中，更高的正向性可能增加一致性，但以正确性为条件的一致性却未必随之提升，在某些设定下甚至会出现下降。效应因模型骨干、关系类型与拓扑结构而异；显式的中立并不等同于省略关系框架。我们认为，关系先验不应作为 LLM-MAS 的默认附加组件。其更稳妥的用法应是诊断性的、面向具体任务的：与无先验基线进行比较，在涉及事实真伪的场景下监控以正确性为条件的指标，并在验证未能证明其合理性时省略关系层。

## Abstract
Large language model-based multi-agent systems (LLM-MAS) are designed through roles, debate protocols, and aggregation rules. These choices create implicit social expectations: agents may be expected to trust, challenge, defer to, or collaborate with peers. We study the effects of making inter-agent relation semantics explicit. We use a minimal signed-network formulation of relational priors and inject natural-language renderings into agent system prompts while holding the task protocol fixed. Across a commons-governance simulation and multi-agent debate, relational priors primarily act as convergence pressure: increasing relational positivity tends to make agents coordinate or agree more readily. This pressure can help when utility rewards behavioral alignment, as in sustainable resource governance and subjective consensus. It does not, however, reliably improve accuracy. In objective QA debates, higher positivity can increase agreement even when correctness-conditioned agreement does not improve and may decline in some settings. Effects vary by model backbone, relation type, and topology; explicit neutrality is not equivalent to omitting relational framing. We argue that relational priors should not be a default add-on for LLM-MAS. Their safer use is diagnostic and task-specific: compare against a no-prior baseline, monitor correctness-conditioned metrics when truth matters, and omit the relational layer when validation does not justify it.

#### 2.1 关系先验作为"协议保留型"干预

在固定的任务协议 $P$ 下，仅改变注入系统提示的关系块 $\Pi_i(r, G_R)$。第 $t$ 步时智能体输出形式化为：

$$y_i^{(t)} = \mathrm{LLM}_i\!\left(x,\; h_i^{(t)},\; \Pi_i(r, G_R)\right)$$

其中 $x$ 为任务输入，$h_i^{(t)}$ 为协议 $P$ 规定的任务历史，$r$ 为关系类型，$G_R$ 为关系网络。该干预**不改变通信图、消息可见性或聚合规则**，因此可孤立识别"提示层面的关系"效应。

#### 2.2 有符号关系网络

定义无向带符号图 $G_R = (A, E_R)$，符号函数为：

$$s : E_R \to \{-1, +1\}$$

其中 $s_{ij}=+1$ 表示对应关系类型下最大正向先验，$s_{ij}=-1$ 为最大负向先验；非边对表示省略关系。整体正向性定义为：

$$\lambda = \frac{|\{(i,j) \in E_R : s_{ij}=+1\}|}{|E_R|}$$

$\lambda=0$ 与 $\lambda=1$ 为端点边界条件；对中间值，枚举所有合法符号分配，避免依赖单一正/负边布局。

论文设计三种关系类型：
- **Attitude**（态度）：情感倾向；
- **Trust**（信任）：认知可信度；
- **Influence**（影响）：对同伴意见/建议的相互响应。

#### 2.3 显式中立与无先验对照

设置三组对照：**NO-PRIOR**（完全省略关系块）、**EXPLICIT-NEUTRAL**（每条边设 $s_{ij}=0$，明确声明中立）、$\lambda$-扫描（带符号扫描）。这用于区分"什么也不说"与"明确说中立"两种情况。

#### 2.4 提示操作化

在每个智能体的系统提示中加入标准化"关系块"，包含任务角色、关系类型简短定义以及 $G_R$ 的自然语言渲染。同一有符号图可实例化为 Attitude / Trust / Influence，仅替换关系类型词汇；并在 MMLU-Pro 的 100 题子集上做了**含义保持的改写与语句重排序**鲁棒性检验。

### 3. 实验设计

#### 3.1 任务家族与基准

**(a) GovSim（公共资源治理）**：基于 Piatti et al. (2024) 的可再生共享资源采掘仿真。每个 episode 最多 12 个月，资源崩塌阈值 $C=5$，最大库存 100，资源再生动力学：

$$h^{(t+1)} = \min\!\left(2\!\left(h^{(t)} - \sum_{i=1}^{n} r_{i,t}\right),\; 100\right)$$

每月包含同步采掘 + 自然语言讨论两阶段。覆盖**三人组（完全图）和五人组（含 chain / star / tree 拓扑）**两类设置。

**(b) 多智能体辩论**（AutoGen 式三答 + 两轮修订）：
- **主观题**：OpinionQA，报告初始不一致问题的最终一致率 CR；
- **客观题**：MMLU-Pro（1000 题）、GPQA-Diamond，报告 CR、多数投票准确率 ACC、共识正确率 CCR：

$$\mathrm{CR} = \frac{|C|}{|I|},\quad \mathrm{CCR} = \frac{|\{n\in C : c_n = y_n\}|}{|C|}$$

其中 $I$ 为初始非一致集，$C$ 为最终达成共识子集。

#### 3.2 模型与设置

- **GovSim**（同质组）：GPT-4.1-mini、GPT-4.1、Qwen-3-32B、LLaMA-3.3-70B-Instruct；temperature=0.8；每个固定条件 5 次完整运行。
- **辩论**（异质组）：GPT 组 = {GPT-4.1-nano, GPT-4.1-mini, GPT-4o-mini}；开源权重组 = {LLaMA-3.3-70B-Instruct, Qwen-3-32B, Mixtral-8x22B-Instruct-v0.1}；贪心解码。

#### 3.3 比较与指标

- **基线**：NO-PRIOR 与 EXPLICIT-NEUTRAL；
- **主要效应**：在 $\lambda$-扫描内观察同向/反向趋势；
- **GovSim 聚合指标** $S$（生存时长、存活率、总收益、平等度、过度采掘的归一化加权平均）：
$$S = w_1\tilde{m} + w_2\tilde{q} + w_3\tilde{R} + w_4\tilde{e} + w_5\tilde{o},\quad w_1=w_2=w_5=28,\; w_3=w_4=18$$
- **不确定性**：GovSim 端点采用完全运行级别 bootstrap（$5^5=3125$ 种组合取 2.5%/97.5% 分位）；辩论端点采用 10 万次配对问题级 bootstrap。

### 4. 资源与算力

论文未明确披露所用 GPU 型号、数量、训练时长或推理算力消耗。仅说明使用 API（闭源模型）与开源权重模型，temperature、解码策略与重跑次数等推理侧超参。**算力信息缺失**是该工作透明度上的一项短板。

### 5. 实验数量与充分性

- **GovSim 三人组**：4 个 backbone × 3 个关系类型 × 多个 $\lambda$ 值，每条件 5 次运行。
- **GovSim 五人组**：在 chain / star / tree 三种拓扑上重复上述设计。
- **辩论**：GPT 组 + 开源组 × OpinionQA + MMLU-Pro + GPQA-Diamond × 3 个关系类型 × 多个 $\lambda$ 值。
- **鲁棒性**：Influence 下对原始 / 改写 / 重排提示在 MMLU-Pro 前 100 题上做配对 bootstrap。

总体覆盖较广：跨 4–6 个模型、3 个关系类型、3 种稀疏拓扑、2 个任务家族、多类数据集（治理指标 + 主观 + 客观 QA）。**优势**在于多 backbone、多关系类型与多拓扑的扫描提供了较高的可推广性；**不足**在于：

1. 团队规模仅 3 或 5 人，未覆盖更大规模群体；
2. GovSim 与辩论两组实验的协议/角色异质，不能直接横向比较；
3. 同质团队在 GovSim 中消除了能力差异，但可能掩盖真实异质场景下的效应；
4. 仅测试固定、对称、共同知识的关系——非对称、私有、可学习的结构完全未涉及。

---

### 6. 主要结论与发现

1. **关系先验主要表现为收敛压力**：在 $\lambda$-扫描内，关系正向性越高，群体越倾向于协调/达成一致。
2. **GovSim**：三人组中 10/12 个"全正 vs 全负"端点对比的 95% 运行级 bootstrap CI 整体高于 0，仅 Qwen-3-32B 在 Attitude（$\Delta S=+24.7$, CI $[-13.7,+63.4]$）与 Influence（$\Delta S=-21.1$, CI $[-52.3,+15.8]$）下不显著。**但相对 NO-PRIOR 的提升并非普遍**——GPT-4.1 几乎无变化，LLaMA-3.3-70B 在某些条件下出现极大正增益。
3. **主观辩论（OpinionQA）**：$\lambda=1$ 的 CR 一致高于 $\lambda=0$，但其作用只是促进"达成共识"，并非"得到正确答案"。
4. **客观辩论（MMLU-Pro / GPQA）**：开源权重组在 MMLU-Pro 的 Influence 下，从 $\lambda=0$ 到 $\lambda=1$：CR 由 33.8% 升至 76.9%（+43.1pp, CI $[+37.8,+48.2]$），但 CCR 由 66.9% 降至 58.4%（-8.5pp, CI $[-15.8,-1.0]$），出现**共识上升、正确共识下降**的分离现象。错误共识形成率 WCF 由 11.2% 升至 32.0%（+20.8pp）。
5. **关系类型效应**：Attitude 在两个任务中都最稳定；Trust 居中；Influence 波动最大，常在辩论中相对 NO-PRIOR 出现最严重退化。
6. **拓扑效应**：五智能体 GovSim 中 chain 拓扑最不稳定，star 与 tree 较为温和（仅改变关系提示布局，不改变通信路由）。
7. **显式中立 ≠ 省略关系**：EXPLICIT-NEUTRAL 在多个 backbone / 数据集上低于或持平 NO-PRIOR，说明"中性"本身也是一种干预。

---

### 7. 优点与亮点

- **变量隔离清晰**：关系先验与任务协议正交，可精确识别"关系语义"对群体行为的纯效应。
- **协议保留型设计**：不引入新协议，仅修改提示，为评估既有 LLM-MAS 工程决策的"隐式关系代价"提供诊断工具。
- **多维扫描**：同时覆盖 backbone、关系类型、拓扑、$\lambda$ 值与任务家族，结果具有较强可推广性。
- **方法论严谨**：端点对比采用 bootstrap CI；对 Influence 提示做了含义改写与重排序的鲁棒性检验（结论方向不变）。
- **实用工程指引明确**：提出"无先验为默认 + 仅当验证集证明有效时才加关系层 + 客观任务需监控 CCR 而非 CR"的保守部署原则。

---

### 8. 不足与局限

1. **关系结构受限**：仅考察**固定、对称、共同知识**的关系，未涉及私有、非对称、可学习、随时间演化的关系；
2. **Influence 限定**：因对称性，Influence 表示**互相响应**而非**有向权威**；真实权威/从属结构未涵盖；
3. **任务覆盖有限**：仅治理博弈与三智能体辩论两类任务；未覆盖工具使用、持久记忆、人机协作、角色层级、异质能力差异等场景；
4. **算力披露缺失**：未报告 GPU 型号/数量、推理时长或 API 调用开销；
5. **同质团队偏差**：GovSim 中刻意采用同质智能体以排除能力差异干扰，但可能与现实部署不符；
6. **位置效应未充分控制**：关系语句的呈现顺序与措辞虽做部分鲁棒性检验，但仅在一种关系类型、一个数据集、一个模型组上完成，泛化性受限；
7. **聚合指标 S 的权重依赖**：GovSim 加权总分 $S$ 的权重 $w_1=w_2=w_5=28, w_3=w_4=18$ 是先验设定的，会影响结论排序；
8. **未引入反事实或反干预**：例如反向提示（明确指示"忽略以下关系块"）可进一步验证效应是否真正源于自然语言推理而非格式噪声。

---

### 综合评价

该工作以**最小的协议保留型提示干预**回答了一个被工程实践长期忽视的问题：**LLM-MAS 中那些"隐而不宣"的社会关系，究竟在多大程度上塑造了群体行为？** 论文给出清晰、可复现的实证证据：关系先验主要作为收敛压力，在主观协调任务中可作为有用的工具，但在客观准确任务中反而会放大共识与正确性的背离。研究的最大价值在于其**保守、可诊断的工程取向**——不主张把关系层作为默认组件，而建议将其作为带正确性条件指标的、按任务与 backbone 验证后再启用的可选工具。
