## 摘要
在策略自蒸馏通过在学生实际访问的状态上查询教师来提升语言模型的推理能力。近期方法通过让教师接触特权上下文来构建强大的信息不对称，但它们本质上仍依赖外部监督（例如标准答案或验证器）来构造这种优势。我们提出 CoDA（一致与分歧对齐），一个完全无监督的框架，能够完全从模型自身无标签 rollout 的潜在不确定性结构中生成可靠的特权信息。CoDA 提取两个互补信号。在正分支中，答案级的一致性识别出一种稳定的推理模式，该模式为冻结的自教师提供条件，使其在新的学生轨迹上给出密集的分布指导。然而，由于一致性并不能保证正确性，仅进行正向蒸馏有将相关错误放大为虚假共识的风险。为打破这一有害的反馈循环，CoDA 引入负分支来利用分歧：将少数轨迹视为不稳定的替代方案，并通过一种参考锚定的类 KTO 校准目标对其进行温和惩罚。这种不成对的二元反馈提供了稳健的正则化，无需假设共识即为绝对真值。在竞赛级数学基准上的实验评估表明，CoDA 显著提升了推理能力，优于自生成基线，并能有效稳定训练以抵御错误共识。

## Abstract
On-policy self-distillation improves language-model reasoning by querying a teacher on states actually visited by the student. Recent methods create a powerful information asymmetry by exposing the teacher to privileged context, yet they fundamentally rely on external supervision---such as gold solutions or verifiers---to construct this advantage. We introduce CoDA (Consensus and Disagreement Alignment), a fully unsupervised framework that creates reliable privileged information entirely from the latent uncertainty structure of a model's own unlabeled rollouts. CoDA extracts two complementary signals. In the positive branch, answer-level consensus identifies a stable reasoning mode, which conditions a frozen self-teacher to provide dense distributional guidance on fresh student trajectories. However, because agreement does not guarantee correctness, positive-only distillation risks amplifying correlated errors into a false consensus. To break this harmful feedback loop, CoDA incorporates a negative branch that exploits disagreement: minority trajectories are treated as unstable alternatives and gently penalized via a reference-anchored, KTO-style calibration objective. This unpaired binary feedback provides robust regularization without requiring the strong assumption that the consensus is the absolute ground truth. Empirical evaluations on competition-level mathematical benchmarks demonstrate that CoDA significantly improves reasoning, outperforming self-generated baselines and effectively stabilizing training against erroneous consensus.

## 1. 核心问题与研究动机

### 1.1 问题背景
长链思维（Chain-of-Thought, CoT）显著提升了语言模型的推理能力，但同时也暴露了**训练-测试失配**问题：在固定的专家轨迹上训练，推理时却必须从模型自身的不完美决策继续生成。在策略蒸馏（on-policy distillation）通过在学生实际访问的状态上查询教师来缓解这一暴露偏差（exposure bias）。其中特权自蒸馏（privileged self-distillation）通过让冻结的"自教师"接收特权上下文来构建信息不对称，进一步消除了对外部更大教师的依赖。

### 1.2 关键瓶颈
现有特权自蒸馏方法（OPSD、GATES、UniSD 等）普遍依赖**外部监督**——黄金标准答案、参考解题过程或外部验证器——来构造特权上下文。这产生了两层局限：
- **监督瓶颈**：去标签不只是去掉训练目标，而是同时去掉了教师优势的来源；
- **虚假共识风险**：当模型对某一错误解反复采样时，仅基于"答案一致"的正反馈会形成**假共识（false consensus）**，把采样误差转化为带缺陷前缀的自放大，形成有害的反馈循环。

### 1.3 研究问题
本文提出更基本的问题：**能否完全从模型自身无标签 rollout 的不确定性结构中构造可靠的特权信息？**

## 2. 方法论

### 2.1 核心思想
CODA（**Co**nsensus and **D**is**a**greement Alignment）是一个**完全无监督**框架，包含两个互补分支：
- **正分支（Consensus-Conditioned Self-Teaching）**：利用答案级一致性识别稳定推理模式，构造特权上下文指导新生成；
- **负分支（Reference-Anchored Disagreement Calibration）**：将少数派轨迹视为不稳定替代，通过参考锚定的 KTO 风格目标温和惩罚，抑制虚假共识的放大。

### 2.2 问题设定
设无标签问题集 $\mathcal{D}_x = \{x_i\}_{i=1}^N$，学生策略 $\pi_\theta$ 自回归生成补全 $y = (y_1, \dots, y_T)$：

$$P_\theta(y|x) = \prod_{t=1}^{T} \pi_\theta(y_t | x, y_{<t})$$

每个问题同时采样两组在策略数据：
- **证据集** $\mathcal{Y}_\theta(x) = \{y^{(1)}, \dots, y^{(s)}\}$：用于推断模型解空间的潜在一致性结构；
- **训练轨迹** $r \sim P_\theta(\cdot|x)$：学生独立采样的新轨迹，用于实际对齐教师与学生分布。

### 2.3 从自一致性到特权上下文
对每个规范化答案 $z$，估计经验支撑度：

$$\hat{p}_\theta(z|x) = \frac{1}{s}\sum_{j=1}^{s} \mathbb{I}[a(y^{(j)}) = z]$$

令 $c(z) = s\hat{p}_\theta(z|x)$。仅当最大答案组至少包含 2 条轨迹时，保留该 prompt，并定义模态答案集：

$$Z_{maj} = \arg\max_z c(z),\quad \max_z c(z) \geq 2$$

对应的模态池与少数派池为：

$$\mathcal{Y}_{maj} = \{y_i \mid a(y_i) \in Z_{maj}\},\quad \mathcal{Y}_{min} = \{y_i \mid a(y_i) \notin Z_{maj}\}$$

使用无标签选择器 $g$（随机/最短/最长）从 $\mathcal{Y}_{maj}$ 中选出代表轨迹 $y^+$，构造特权上下文 $c^+ = \varphi(x, y^+)$。

### 2.4 共识条件分布对齐（正分支）
学生采样新轨迹 $r \sim P_\theta(\cdot|x)$（不观测 $y^+$）。在前缀 $r_{<t}$ 下：

$$p_{\theta,t}(v) = \pi_\theta(v|x, r_{<t}),\quad q_t^+(v) = \pi_0(v|\varphi(x, y^+), r_{<t})$$

通过广义散度 $D_\alpha$ 对齐：

$$L_{con}(x) = \frac{1}{|M_r|}\sum_{t \in M_r} \min\!\big(D_\alpha(q_t^+, p_{\theta,t}),\,\tau\big)$$

其中 $\alpha \in [0,1]$ 插值前向 KL（$\alpha=0$）、广义 JS（$0<\alpha<1$）和反向 KL（$\alpha=1$）；$M_r$ 屏蔽非响应 token；$\tau$ 裁剪过大的逐 token 散度。实验中取 $\alpha=0$（前向 KL），以充分传递教师分布。

### 2.5 参考锚定分歧校准（负分支）
对少数轨迹 $y^- \in \mathcal{Y}_{min}$，定义学生-参考对数比：

$$\ell_t^-(\theta) = \log\frac{\pi_\theta(y_t^-|x, y_{<t}^-)}{\pi_0(y_t^-|x, y_{<t}^-)}$$

采用参考锚定的 KTO 风格目标：

$$L_{dis}(x) = \mathbb{E}_{y^- \sim \tilde{\mathcal{Y}}_{min},\, t \sim M_{y^-}}\big[\mathrm{softplus}(\beta\ell_t^-(\theta)) - \log 2\big]$$

通过惩罚正的对数比降低少数 token 的相对似然。**关键点**：冻结的 $\pi_0$ 锚点防止任意似然降低，仅保证少数派不被放大到高于其初始概率。结合有效答案过滤、长度截断和小系数 $\lambda$，将负分支严格视作正则化器而非"语义错误"声明。

### 2.6 联合目标与在策略更新

$$L_{CoDA}(x) = L_{con}(x) + \lambda L_{dis}(x)$$

随 $\pi_\theta$ 演化，每条证据轨迹与对齐轨迹都被重新采样；缺乏重复有效答案的 prompt 直接跳过更新，保证信号动态跟随策略改进。

- **公平性**：所有方法统一使用 LoRA、相同学习率与硬件，主对比表涵盖监督与自生成两组基线，并明确指出 SFT-Self 依赖 oracle 仅作为诊断参考，避免误导性比较；
- **消融严谨性**：提供 oracle filter 诊断揭示虚假共识的影响，但 CoDA-Full 不依赖 oracle；
- **不足**：仅在数学推理领域验证；未在通用 NLP、代码、多模态等任务上验证泛化性；评测仅用 avg@16，未报告 pass@k、置信区间或多种子方差。

## 6. 主要结论与发现

1. **无监督特权蒸馏可行**：CoDA-Full 在两个模型规模上均显著提升推理能力，无需任何外部监督。
   - Qwen3-4B：相对 base 提升 **+2.60**，相对 TTRL 提升 **+1.84**，仅落后监督 OPSD 0.25；
   - Qwen3-1.7B：相对 base 提升 **+6.38**，**超过**监督 OPSD 0.31。

2. **少数派校准是关键**：去掉负分支后 1.7B 模型平均下降 1.75 分，4B 模型下降 0.87 分；在 5/5 和 3/5 基准上观察到提升。

3. **选择器影响**：选**最短**模态轨迹作为特权上下文最优（比随机 +0.86，比最长 +0.84）；长轨迹引入冗余推理，反而损害精度。

4. **虚假共识确实发生**：未过滤的 Consensus Only 在训练后期出现明显精度坍塌，oracle filter 不提升峰值但显著改善稳定性，证明问题源于训练动力学。

5. **样本量 $s$ 的收益递减**：$s$ 从 5→10→20，精度仅从 35.05→35.26→35.41，但训练损失与收敛稳定性持续改善；论文默认 $s=10$ 作为精度-算力折中。

6. **核心结论**：模型自身的一致性与分歧结构足以构造可靠的自监督信号，免标注自蒸馏可达到甚至超越有监督方法。

## 7. 优点与亮点

- **完全无监督**：摆脱对黄金解、奖励模型、验证器的依赖，显著降低数据获取成本；
- **双信号机制设计精巧**：正分支构造信息不对称（解决"无标签还能不能蒸馏"），负分支通过参考锚定提供温和正则化（解决"一致性≠正确性"）；
- **未配对的负反馈**：相比直接构造偏好对（DPO 风格），KTO 风格的二元反馈更鲁棒，避免假设共识为绝对真值；
- **冻结参考 $\pi_0$ 锚点**：防止任意似然塌缩，将负信号严格限定为正则化器；
- **实验设计系统**：从主结果、选择器、虚假共识、样本量到训练动力学五维度展开，论证链条完整；
- **逼近甚至超越监督方法**：1.7B 上 CoDA-Full 反超 OPSD，验证了"内生信号+正则化"路线的实际竞争力。

## 8. 不足与局限

- **领域单一**：仅在数学竞赛推理上验证，未覆盖代码、开放问答、多模态等任务；泛化能力未知。
- **小模型局限**：在 1.7B 上 CoDA-Full 反而略低于 4B 上的相对增益，说明小模型内部不确定性结构较弱时，方法可能收益有限。
- **假共识无法根本解决**：负分支仅"约束"而非"纠正"错误共识；当模型系统性偏好错误解时，多数派仍可能是错的，论文未提出突破能力上限的方法。
- **算力开销大**：每 prompt 需 $s=10$ 次完整 CoT 推理生成证据集，叠加 vLLM 部署，对小团队成本仍高；论文未给出明确的 token 总量与训练时长。
- **评测单一**：仅 avg@16，未报告 pass@k、不同温度下的鲁棒性、统计显著性检验或多种子方差。
- **负分支依赖弱信号**：少数派轨迹在系统偏置下可能恰好是正确答案，温和惩罚虽 $\lambda$ 较小，仍存在压制正确答案的风险。
- **缺乏对推理行为本身的可解释分析**：未分析 CoDA 究竟改变了模型的哪些推理模式（如自我验证、回溯等），难以判断改进是源自格式规范化还是真正的推理增强。
- **OpenThoughts 数据泄漏风险未讨论**：评测基准（AIME、HMMT、AMO）若与训练 prompt 存在时间或来源重叠，可能高估真实泛化能力。
