## 摘要
外部自然语言技能为大型语言模型（LLM）智能体提供了可重用且可编辑的指导，用于解决复杂任务。然而，它们的有效性不仅取决于技能的质量，还取决于策略是否能够将所提供的指导转化为适当的动作。然而，专门设计用于提升这种技能利用能力的方法在很大程度上仍未得到充分探索。在实践中，基于技能的智能体通常使用以任务级奖励为中心的强化学习目标进行训练，这种目标提供的监督有限，难以捕捉策略如何有效使用所提供技能中的细微差异。我们提出了 BCSD（双向上下文自蒸馏），一个将自蒸馏与强化学习相结合以训练 LLM 智能体更有效利用外部技能的框架。与依赖单一特权上下文的先前自蒸馏方法不同，BCSD 从两个互补的技能上下文视角评估每条轨迹。增强视图引入了更高层次的元技能（Meta-Skill）指导，而简化视图则裁剪通用指导以突出任务特定的技能。它们互补的 token 级信号被结合用于重新缩放强化学习优势函数。在 ALFWorld 和 WebShop 上的实验表明，BCSD 在不同模型规模下均取得了最强的整体性能，使智能体能够更有效地利用外部技能。消融研究进一步验证了增强和简化上下文视图的互补贡献。代码将发布以确保完全可复现性。

## Abstract
External natural-language skills provide large language model (LLM) agents with reusable and editable guidance for solving complex tasks. Yet their effectiveness depends not only on skill quality, but also on whether the policy can translate the provided guidance into appropriate actions. However, methods specifically designed to improve this skill-utilization ability remain largely underexplored. In practice, skill-based agents are commonly trained with reinforcement learning objectives centered on task-level rewards, which offer limited supervision and struggle to capture subtle differences in how effectively the policy uses the provided skills. We propose BCSD (Bidirectional Context Self-Distillation), a framework that combines self-distillation with reinforcement learning to train LLM agents to use external skills more effectively. Unlike prior self-distillation methods that rely on a single privileged context, BCSD evaluates each trajectory from two complementary skill-context views. The augmented view introduces higher-level Meta-Skill guidance, while the reduced view prunes general guidance to highlight task-specific skills. Their complementary token-level signals are combined to rescale the RL advantage. Experiments on ALFWorld and WebShop demonstrate that BCSD achieves the strongest overall performance across model scales, enabling agents to utilize external skills more effectively. Ablation studies further verify the complementary contributions of the augmented and reduced context views. Code will be released to ensure full reproducibility.

## 1. 核心问题与研究动机

- **研究背景**：外部自然语言技能（natural-language skills）为 LLM 智能体提供了可重用、可编辑的过程性知识，使其能够在长时域任务中复用经验而无需从头求解。技能增强型智能体的研究主要沿两条路径展开：
  1. **技能演化与精炼**（如 SkillRL、SkillEvolver、SkillHone）：聚焦技能生成与迭代，但未关注智能体能否真正利用这些技能。
  2. **技能内化**（如 Skill-SD、SDAR、SIRI）：将技能蒸馏到模型参数中，但牺牲了技能的可检查性、可编辑性与可迁移性。
- **核心问题**：在保留外部技能显式上下文的前提下，如何让智能体更有效地利用所提供的技能？
- **现有方法的不足**：
  - 任务级 RL 奖励（outcome reward）稀疏且粗糙，仅在轨迹完成时给出，难以刻画智能体对技能的利用是否到位；
  - 现有 OPSD（on-policy self-distillation）方法依赖单一特权上下文构造自教师，存在信息泄漏、优化不稳定、上下文风格漂移及捷径 token 等问题，单一概率差信号难以提供可靠的 token 级信用分配。
- **本文立场**：明确"利用"（utilization）区别于"内化"（internalization），主张技能在训练与推理时均应保留为显式上下文，并提出专门的训练方法。

## 2. 方法论：BCSD 框架

### 2.1 核心思想

将单一特权上下文的自蒸馏扩展为**两个互补的上下文视图**（bidirectional context views），并将其 token 级信号融合，对 GRPO 优势进行重缩放（advantage rescaling），不改变优化方向。

### 2.2 问题设定

- 长时域智能体任务建模为部分可观测决策过程；
- 基础上下文定义为 $C_0 = (Q, G, S_c)$，其中 $Q$ 为查询，$G$ 为通用技能，$S_c$ 为任务特定技能；
- 行为策略 $\pi_\theta$ 在 $C_0$ 下采样 $K$ 条轨迹 $\{\tau_i\}_{i=1}^K$，对应奖励 $r_i = R(\tau_i)$；
- 标准 GRPO 组内相对优势为：
  $$A_i^{GRPO} = \frac{r_i - \mu_r}{\sigma_r + \epsilon}$$

### 2.3 Meta-Skill 提取与刷新

- **Meta-Skill 定义**：高层文本指导，刻画当前策略在特定技能 $S_c$ 上"应如何应用技能"，具有**策略依赖性**，仅作为训练时的特权上下文，不进入推理时的 $C_0$；
- **初始化**：在训练前用冻结的外部 LLM 对比成功/失败轨迹集 $E_{c,+}^{(0)}$、$E_{c,-}^{(0)}$：
  $$M_c^{(0)} = \text{ExtractLLM}\!\left(S_c, E_{c,+}^{(0)}, E_{c,-}^{(0)}\right)$$
- **刷新机制**：每隔 $N$ 步的验证窗口，用窗口 $k$ 内累积的证据重新生成：
  $$M_c^{(k+1)} = \text{ExtractLLM}\!\left(S_c, M_c^{(k)}, E_{c,+}^{(k)}, E_{c,-}^{(k)}\right)$$
  刷新后清空证据缓冲。

### 2.4 双向上下文构造

- **增强视图（augmented view）**：在 $C_0$ 基础上注入 Meta-Skill：
  $$C_1 = (Q, G, S_c, M_c)$$
- **剪枝视图（pruned view）**：训练前用外部 LLM 裁剪通用技能 $G$ 中冗余内容，得到 $G_p = \text{PruneLLM}(G)$，并保留任务特定技能：
  $$C_2 = (Q, G_p, S_c)$$

### 2.5 Gap-加权优势重缩放

固定已生成响应序列 $y_i$，在 $C_0$、$C_1$、$C_2$ 下用同一策略重新打分别获得两个 token 级对数概率差：

$$\Delta_{i,t}^{aug} = \log \pi_\theta(y_{i,t} \mid C_1, y_{i,<t}) - \log \pi_\theta(y_{i,t} \mid C_0, y_{i,<t})$$

$$\Delta_{i,t}^{pru} = \log \pi_\theta(y_{i,t} \mid C_2, y_{i,<t}) - \log \pi_\theta(y_{i,t} \mid C_0, y_{i,<t})$$

加权融合：

$$\Delta_{i,t} = \alpha \Delta_{i,t}^{aug} + (1-\alpha)\Delta_{i,t}^{pru}$$

裁剪权重（保留优化方向，只改变幅度）：

$$w_{i,t} = \text{clip}\!\left(\exp\!\left(\text{sign}(A_i^{GRPO})\Delta_{i,t}\right),\ 1-c,\ 1+c\right)$$

最终 token 级优势：

$$A_{i,t}^{BCSD} = A_i^{GRPO}\Big[(1-\lambda_n) + \lambda_n w_{i,t}\Big]$$

其中 $\lambda_n$ 由 $\lambda_0$ 线性衰减至 0，$c$ 为裁剪常数。

### 2.6 策略优化目标

$$\mathcal{L}_{BCSD}(\theta) = -\mathbb{E}_{i,t}\!\left[\min\!\left(\rho_{i,t}(\theta)A_{i,t}^{BCSD},\ \text{clip}(\rho_{i,t}(\theta), 1-\epsilon, 1+\epsilon)A_{i,t}^{BCSD}\right)\right] + \beta \mathcal{L}_{KL}$$

其中 $\rho_{i,t}(\theta) = \dfrac{\pi_\theta(y_{i,t}\mid C_0, y_{i,<t})}{\pi_{\theta_{old}}(y_{i,t}\mid C_0, y_{i,<t})}$。

### 2.7 完整算法（Algorithm 1）关键流程

1. 训练前构造 $G_p$ 并用预加载轨迹初始化 $\{M_c^{(0)}\}$；
2. 每个优化步：在 $C_0$ 下采样 $K$ 条轨迹并计算 GRPO 优势；在 $C_0, C_1, C_2$ 下重打分并计算 $\Delta_{i,t}$、$w_{i,t}$、$A_{i,t}^{BCSD}$；
3. 用 $\mathcal{L}_{BCSD}$ 更新参数；
4. 每 $N$ 步刷新 Meta-Skill 并清空证据缓冲。

- **消融实验**（Qwen2.5-3B）：包括"教师上下文视角"（去除 Meta-Skill 视图、去除 Pruned-Skill 视图）、"重缩放系数调度"（不衰减 $\lambda_n$）、"Meta-Skill 更新"（禁用刷新）共 4 组；
- **超参数敏感性**：$\lambda_0 \in \{0.5, 0.3, 0.1, 0.05\}$ 的 4 组消融；$(\alpha, 1-\alpha)$ 的 3 组权重组合（$0.9/0.5/0.1$）；
- **进一步分析**：WebShop 训练曲线对比（与 Skill_GRPO*、RLSD、SDAR、Skill-SD）、两个上下文视图的 token 级符号一致率曲线、General-Skill-only vs Full-Skill 的成功率差分析；
- 总体上消融维度（视图组件、刷新机制、系数调度、权重分配、token 级一致性、技能依赖性）较为完整；但**仅在 Qwen2.5-3B 上做消融**，未在 7B 或 Qwen3-1.7B 上交叉验证，主结果也存在一些"次优"项（如 7B WebShop Score 仅 0.2 落后、Qwen3 WebShop 成功率 0.8 落后），公平性需在更大规模上进一步核实。

## 6. 主要结论与发现

- BCSD 在三个模型规模、两个长时域基准上均取得最强综合性能；
- 与同样保留外部技能的 Skill_GRPO* 相比，在 ALFWorld 均值、WebShop Score、WebShop Succ. 上分别提升 3.9 / 1.7 / 2.4 个百分点，验证元技能引导的自蒸馏有助于智能体真正"学会使用技能"；
- 两个上下文视图**互为补充、不可缺一**：去除任一视图（尤其 Meta-Skill 视图）都会显著退化；
- $\lambda_0=0.1$ 的温和重缩放 + 线性衰减优于过大或过小设置；
- $(\alpha=0.9, 1-\alpha=0.1)$（以 Meta-Skill 为主）训练最稳定、最终提升最大；
- 两个教师视图的 token 级符号一致率仅约 50%（47%~53%），说明二者**提供互补而非冗余**信号；
- General-Skill-only 设置下 BCSD 的成功率下降幅度（ALFWorld -2.3、WebShop -7.8）大于 Skill_GRPO*（-0.8 / -6.2），表明 BCSD 增益更多来自"使用外部技能"而非"内化任务知识到参数"。

## 7. 优点

- **思路新颖**：将"多教师信号融合"从参数空间迁移到上下文空间，提出"双向上下文自蒸馏"，与现有单一特权上下文 OPSD 形成清晰区分；
- **保持技能显式性**：与 Skill-SD、SDAR、SIRI 等技能内化路线相比，BCSD 同时保持技能的可检查性、可编辑性与可迁移性；
- **不破坏优化方向**：通过符号保持 + 裁剪重缩放机制，使自蒸馏仅调整优势幅度，不反转奖励驱动的更新方向；
- **自适应刷新机制**：Meta-Skill 周期性基于当前策略的成败轨迹刷新，避免早期指导过时；
- **实验维度丰富**：覆盖多模型规模、多基准、多类基线、组件消融、超参敏感性、训练动力学、token 级一致性与技能依赖性分析；
- **工程化与可复现**：提供 Algorithm 1 与超参数设置，承诺开源代码。

## 8. 不足与局限

- **算力信息缺失**：未披露 GPU 型号/数量/训练时长，复现成本难以估算；
- **消融规模有限**：所有消融、敏感性实验均在 Qwen2.5-3B 上完成，7B 与 Qwen3-1.7B 上的结论稳定性未知；
- **依赖外部 LLM 质量**：Meta-Skill 提取与 $G_p$ 剪枝均依赖冻结的外部 LLM，其能力与偏差会直接影响教师信号质量；论文未分析外部 LLM 选择/提示设计对结果的敏感度；
- **Meta-Skill 刷新开销**：每个验证窗口调用外部 LLM 进行对比生成会带来额外延迟与成本，未给出量化代价；
- **仅覆盖两类基准**：ALFWorld 与 WebShop 均为文本交互环境，结论在视觉/工具调用/多模态场景下的泛化性未验证；
- **技能依赖性论证存在两面性**：作者将"去掉 $S_c$ 后下降更大"解读为"更好利用了外部技能"，但同时承认 BCSD 在绝对性能上仍较高，存在"既更依赖 $S_c$ 又更强"的因果归因不够直接的局限；
- **次优项未被深入分析**：Qwen3-1.7B 上 WebShop 成功率低于 SDAR，7B 上 WebShop Score 也非最佳，论文未对这些差异进行归因；
- **理论分析薄弱**：对 Meta-Skill 收敛性、$\lambda_n$ 衰减的理论依据，以及两个视图是否理论上独立、是否引入额外偏差缺乏形式化讨论。
