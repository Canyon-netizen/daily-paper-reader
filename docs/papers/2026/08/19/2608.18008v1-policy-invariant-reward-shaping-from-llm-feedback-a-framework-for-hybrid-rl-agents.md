## 摘要
将大语言模型与强化学习相结合日益受到关注，然而由大语言模型衍生的奖励信号在理论层面上的地位往往未被明确阐述。我们将混合的大语言模型规划器与强化学习控制器架构形式化为目标增广马尔可夫决策过程，并证明当大语言模型给出的逐状态进展评分用作有界势函数时，即使该评分并不准确，所产生的塑形项仍能保持最优策略集合不变。这一保证优于一般的大语言模型作为奖励方法所提供的保证。我们在小型马尔可夫决策过程上对四种势函数配置进行了数值验证，其中包含一种缩放至基础奖励量级二十倍的对抗性配置。

## Abstract
Combining large language models with reinforcement learning is increasingly explored, yet the theoretical status of LLM-derived reward signals is often left implicit. We formalize the hybrid LLM-planner and RL-controller architecture as a Goal-Augmented Markov Decision Process and show that when the LLM per-state progress score is used as a bounded potential function, the resulting shaping term preserves the optimal policy set even when the LLM scores are inaccurate. This guarantee is stronger than what general LLM-as-reward approaches provide. We verify the result numerically on a small MDP under four potential configurations, including an adversarial one scaled to twenty times the base reward magnitude.

## 2. 方法论

### 2.1 核心思想

将 LLM 规划器 + RL 控制器的混合架构形式化为**目标增广马尔可夫决策过程（Goal-Augmented MDP, GA-MDP）**，并证明当 LLM 的逐状态进展评分被用作 Ng, Harada, Russell (1999) 意义上的**有界势函数**时，引入的塑形项不会改变增广 MDP 的最优策略集合——即使 LLM 在任意单状态上的评分完全错误也是如此。

### 2.2 关键技术细节

**(a) 目标增广 MDP 形式化**

定义：
$$M_G = (S \times G, A, \tilde{P}, \tilde{R}, \gamma, \tilde{\rho}_0)$$
其中增广状态 $(s, g)$ 由环境状态 $s \in S$ 和当前子目标 $g \in G$ 构成。转移核为：
$$\tilde{P}((s', g') | (s, g), a) = P(s' | s, a) \cdot P^G(g' | s, g, s')$$

**(b) 基于势函数的奖励塑形**

LLM 通过评分提示输出有界标量 $s_{\text{LLM}}(s, g) \in [0, 1]$，定义势函数：
$$\Phi(s, g) = c \cdot s_{\text{LLM}}(s, g), \quad c > 0$$

塑形项为（Ng 等人的经典构造）：
$$F(s, g, s') = \gamma \Phi(s', g) - \Phi(s, g)$$

塑形后的总奖励为：
$$\tilde{R}((s, g), a, (s', g')) = R(s, a, s') + \alpha F(s, g, s')$$

**(c) 核心命题（Proposition 4.1：策略不变性）**

> 设 $M$ 为 MDP，$\Phi: S \times G \to \mathbb{R}$ 为任意有界函数，$M_G$ 为使用上述塑形项的增广 MDP。则 $M_G$ 的每一个最优策略在任意关于 $(s,g)$ 可测的子目标调度规则下，都投射回 $M$ 的一个最优策略。

**证明思路**：将 Ng 等人 1999 年 Theorem 1 应用到增广状态空间 $S \times G$。由于 $F$ 是有界势函数的伸缩差，增广回报分解为：
$$\tilde{J}(\pi) = J(\pi) - \Phi(s_0, g_0) + \lim_{T \to \infty} \gamma^T \Phi(s_T, g_T)$$

末项因 $\Phi$ 有界、$\gamma < 1$ 而趋于零。因此 $\arg\max_{\pi} \tilde{J}(\pi) = \arg\max_{\pi} J(\pi)$，最优策略集不变。

**关键意义**：LLM 评分可以在任何单状态上"任意错误"，但**只能减慢学习、不能破坏最优解**。这是 Text2Reward、Eureka 等一般性 LLM-as-reward 方法无法提供的更强保证。

### 2.3 完整推理算法（Algorithm 1）

输入：任务 $\ell$、状态 $s_0$、策略 $\pi_\theta$、LLM $p_{\text{LLM}}$、Done 预言机、势函数 $\Phi$、周期 $H$、预算 $B$。

主要流程：
1. 由 LLM 生成初始计划 $\pi^H = (g_1, \dots, g_K)$；
2. 智能体执行动作 $a_t \sim \pi_\theta(\cdot | s_t, g_t)$，观察下一状态并获得塑形奖励 $\tilde{r}_t = r_t + \gamma \Phi(s_{t+1}, g_t) - \Phi(s_t, g_t)$；
3. 若 $Done(s_{t+1}, g_k) = 1$，推进子目标指针；否则累计失败步数；
4. 当失败步数达到 $B$，触发**失败重规划**；每 $H$ 步触发**周期性重规划**。

### 2.4 实现细节

- 底层策略：PPO + GAE，子目标用 MiniLM-L6-v2（$d_g = 384$）编码后与状态编码拼接；
- 三种 Done 实现：环境事件标志、学习型 MLP、LLM 完成度提示；
- 支持 Ollama 本地部署（Qwen、Llama）和云端 API 后端。

## 3. 实验设计

### 3.1 命题 4.1 的数值验证

**场景**：3 状态、2 动作的确定性 MDP：$\{s_0, s_1, s_2\}$，$s_2$ 为终止态；"forward" 动作沿 $s_0 \to s_1 \to s_2$，仅 $s_1 \to s_2$ 转移有 $+1$ 奖励；"stay" 动作得 $-0.1$ 并回到 $s_0$。$\gamma = 0.9$，基线最优值 $V^*(s_0) = 0.9000$。

**四种势函数配置**（包括一个**对抗性配置**，单状态势函数绝对值达到基线奖励量级的 20×）：
| 配置 | 基线 $V^*(s_0)$ | 塑形后 $\tilde{V}^*(s_0)$ | 最优策略匹配 |
|---|---|---|---|
| $\Phi \equiv 0$ | 0.9000 | 0.9000 | 是 |
| $\Phi \equiv 1$ | 0.9000 | 0.7100 | 是 |
| 符号翻转 | 0.9000 | 1.4000 | 是 |
| 对抗性大值 | 0.9000 | -5.0500 | 是 |

### 3.2 规划器单独评估

**场景**：20 个 MiniGrid 任务，使用本地部署的 **Qwen-2.5:14b**（通过 Ollama）。
- 解析率（产出至少 1 个子目标）：100.0% (20/20)
- 平均真值覆盖率：54.8%
- 平均计划长度：8.00（真值平均约 3.6）
- 每计划平均多余子目标数：5.30
- 中位数每计划输出 token 数：37
- 中位数每计划墙钟：57.71 秒；20 个计划总墙钟 22.3 分钟

### 3.3 流水线端到端验证

**场景**：MiniGrid-DoorKey-6x6（CPU 规模），3 万环境步/种子，3 个种子。

**对比方法**：
- **PPO 基线**：标准 sb3 PPO，无 LLM、无子目标条件化；
- **混合框架**：以 Qwen-2.5:14b 为规划器的子目标条件 PPO，初始计划按任务字符串缓存，$H = 1000$ 周期重规划，$B = 0$（因 CPU 推理 14B 模型每步两次 LLM 调用代价过高，关塑形 $c=0$）。

### 3.4 与已有方法的对比定位

作者强调本文**不与 Text2Reward、Eureka、ELLM、GLAM 等做实证基准对比**，仅在理论上声明其方法的策略不变性保证更强。

## 6. 主要结论与发现

1. **理论结论**：当 LLM 逐状态评分作为有界势函数用于塑形时，增广 MDP 的最优策略集不变——LLM 评分错误只能减慢学习，不能改变最终固定点。
2. **数值结论**：3 状态 MDP 上 4 种势函数配置（含 20× 基础奖励的对抗性设置）均保持最优策略不变，验证了命题。
3. **规划器单独结论**：Qwen-2.5:14b 在 MiniGrid 上 100% 解析、54.8% 真值覆盖率，但倾向输出冗长的低层表述（"Turn left to face the wall"），而非紧凑的真值格式（"go to the key"）。
4. **端到端验证结论**：
   - 流水线在 CPU 上 90,000 步无异常运行；
   - 但**混合架构在 MiniGrid-DoorKey-6x6 上未超过 PPO**（成功率 9.3% vs 28.1%）；
   - **诊断出一个集成失败**：Qwen 计划的"自然语言表述"与环境事件型 Done 预言机的关键词模式不匹配（如"Move down to reach the wall" vs "pick up X"），导致 Done 从不触发、子目标指针卡死在第一步；这正是理论分析中预见到的失败模式。
5. **代码与可复现性**：开源参考实现，含 26 单元测试、YAML 配置、所有提示模板。

## 7. 优点

1. **理论贡献清晰且严格**：将经典 Ng-Harada-Russell 势函数塑形定理具体实例化为 LLM 评分的情形，证明简洁且易于复核。
2. **正确定位研究边界**：明确区分"不动点正确性"与"经验收敛性"，避免做出超出证据范围的优越性声明。
3. **架构模块化**：GA-MDP 构造清晰分离了规划器、评分器、Done 预言机、子目标调度器等组件，参考实现 1:1 对应形式化定义，便于消融与复现。
4. **诊断具体且与理论一致**：实验中观察到的 Done 预言机与 LLM 计划"词汇不匹配"失败，正是第 6 节中预见的三类失败模式之一，体现了理论与实践的相互印证。
5. **CPU 可运行、测试完备**：降低了复现门槛，26 单元测试 + 数值 sanity check 增加了可信度。

## 8. 不足与局限

1. **理论保证的边界有限**：
   - 命题只保证最优策略集**不变**，**不保证收敛速度**——差的势函数可能严重拖慢学习；
   - 证明依赖 $\Phi$ 的**严格有界性**（LLM 评分需被 clamp 到 $[0,1]$），若 LLM 产生超范围输出则保证失效；
   - 适用于 actor-critic 时，假设目标网络与训练网络看到的塑形奖励一致，依赖实现细节。
2. **实证规模严重不足**：
   - 仅在 3 状态 MDP 上验证理论；
   - 端到端实验仅 90,000 步、3 种子、1 个环境（DoorKey-6x6），远小于 PPO 在该环境通常需要的 ~5×10^5 步；
   - 为了在 CPU 上可行，**关闭了塑形项**（$c=0$），从而混合架构的核心机制在主要对比中并未被测试。
3. **基准比较缺位**：未与 Text2Reward、Eureka、ELLM 等做实证对比，也未跨多个 LLM（仅 Qwen-2.5:14b）、多个 Done 预言机实现、多个环境做消融。
4. **依赖"提示工程"**：评分提示（P2）和计划提示（P1）的具体形式影响 $\Phi$ 分布，是经验调优表面而非理论对象。
5. **混合架构优于纯 RL 的可能性未证实**：本文最实质的经验结论是"在极小规模下混合未胜出"，但无法区分这是**架构本身的问题**还是**算力不足或 Done 预言机不匹配的问题**。
6. **推广性受限**：GA-MDP 与子目标语义的细节（如 Done 预言机与计划词汇的对齐）是系统成败关键，但本文未给出系统化解决方案，仅指出"用 LLM-Done 或学习型分类器"。
7. **算力声明局限**：仅使用 CPU 完成实验，未给出 GPU 规模实验或大规模基准测试，无法回答研究者关心的"实际是否值得用"的问题。
