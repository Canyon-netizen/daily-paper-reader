多智能体推理系统通常依据一致性、置信度或自动评分来筛选影响最终答案的消息。此类过滤隐含的假设是：一条很可能正确的消息也值得保留。然而，错误的答案中可能包含有用的任务分解、约束条件或科学原理。我们借助"多样化假设审议"（Diverse Hypothesis Deliberation, DHD）这一受控测量协议来检验这一区分：该协议缓存五条独立生成的消息，并在同一下游求解器（称为整合器）上分别以各消息可用或隐藏两种条件进行重放。重放比较衡量了一条消息的轨迹价值——即让该消息可被访问是有助于还是损害后续推理。在五项数学与科学基准以及两个公开可用的模型系列（gpt-oss-120b 与 gemma-4-31B-it）上的实验表明，每一种基准—模型组合中均存在"错误但有用"的消息。在能够改变最终正确性的错误答案消息中，每种模型下都有超过四成的改变方向是有帮助的。受控重复实验表明，可重复的消息效应数量不太可能仅由重放变异性产生（p=0.0002）。针对可重复的"错误但有用"消息进行的聚焦干预研究发现，完整消息效果最佳；保留其推理过程比仅保留其答案能保留更多成功；而完整消息优势的具体来源仍有待探究。在同一问题内部，重复的轨迹价值证据所给出的保留或删除选择也优于仅凭答案正确性所作的判断。因此，答案正确性虽具参考价值，却无法决定轨迹价值。DHD 衡量了这一被忽视的属性，并生成可复用的标签，用于学习智能体在何时应当倾听其他消息。

## Abstract
Multi-agent reasoning systems often use agreement, confidence, or automated scores to decide which messages should shape a final answer. Such filtering assumes that a message likely to be correct is also worth keeping. Yet a wrong answer can contain a useful decomposition, constraint, or scientific principle. We test this distinction with Diverse Hypothesis Deliberation (DHD), a controlled measurement protocol that caches five independently generated messages and replays the same downstream solver, called the integrator, with each message available or hidden. The replay comparison measures a message's trajectory value: whether making the message available helps or harms subsequent reasoning. Across five mathematics and science benchmarks and two openly available model families, gpt-oss-120b and gemma-4-31B-it, wrong-helpful messages appear in every benchmark-model combination. Among wrong-answer messages that change final correctness, more than four in ten changes are helpful in each model. Controlled repeats show that the number of repeatable message effects is unlikely to arise from replay variation alone (p=0.0002). A focused intervention on repeatable wrong-helpful messages finds that the complete message works best, while retaining its reasoning preserves more success than retaining only its answer; the source of the complete-message advantage remains open. Within the same problem, repeated trajectory-value evidence also identifies a better keep-or-remove choice than answer correctness alone. Answer correctness is therefore informative but does not determine trajectory value. DHD measures this missing property and produces reusable labels for learning when agents should listen.

# 论文总结：错误却有用——多智能体消息中超越答案正确性的轨迹价值

## 1. 核心问题与研究动机

- **现实痛点**：现有多智能体推理系统普遍以"答案正确性"作为消息筛选依据（一致性投票、置信度、过程奖励模型等），隐含假设是"很可能正确的消息就值得保留"。
- **被忽视的反例**：一条消息即使最终答案错误，其推理过程中仍可能包含可被下游智能体复用的分解方法、约束条件或科学原理；反之，答案正确的消息也可能因附带误导性推理而干扰整合。
- **核心区分**：
  - **提案正确性（Proposal Correctness）**：本地属性，问该消息自身的答案是否正确，记为 $c_i = E(x, a_i, y)$。
  - **轨迹价值（Trajectory Value）**：上下文属性，问在固定消息池与整合器下，让该消息可访问是否能提升下游解题正确率。
- **研究意义**：将"消息是否值得保留"从单一正确性信号中解耦，为消息筛选与多智能体协作提供新的可测量属性。

## 2. 方法论：多样化假设审议（DHD）协议

### 2.1 核心思想
DHD 是一个**测量协议**，而非追求最终准确率的选优器。它在结果观测前固定候选消息池，再通过切换可见性观察每条消息对下游推理的因果贡献。

### 2.2 协议角色流程
1. **动态招募者（Recruiter）**：根据问题指派 5 个互补的、问题特异的角色，**不接触参考答案**。
2. **5 个假设者（Hypothesizer）**：各自独立根据单一角色生成一条结构化消息（推理方向 + 关键想法 + 假设 + 检查项 + 置信度 + 提议答案），互不可见、不接收评估反馈。
3. **整合器（Integrator）**：基于选定的缓存消息子集综合出一个最终答案，不进行投票、不被告知哪条答案正确。
4. **评估者（Evaluator）**：仅接收提交答案与参考答案，执行等价性判断；与推理流程完全隔离。

### 2.3 轨迹价值的重放测量
对缓存消息集 $H_K = \{h_1, \dots, h_K\}$，定义
$$
\tau_{i,K} = \Pr(Y_{H_K}=1) - \Pr(Y_{H_K \setminus \{h_i\}} = 1)
$$
其中 $Y_S = E(x, A_S, y)$ 表示整合器在消息集 $S$ 下输出答案的正确性。$\tau_{i,K}>0$ 表示消息在平均意义上提升了成功率。

### 2.4 两种互补的重放机制
- **池内留一法（In-pool LOO, $K=2,\dots,5$）**：比较完整池 $H_K$ 与 $H_K \setminus \{h_i\}$。
- **单消息重放（Single-message）**：将 $h_i$ 单独喂给整合器，与独立求解（$K=0$）比较。

每条消息的观测重放效应 $\Delta_{i,K} \in \{+1,0,-1\}$ 分别为有帮助、中性、有害。

### 2.5 概念交叉表
将提案正确性与重放效应交叉得到六格：wrong-helpful / wrong-neutral / wrong-harmful / correct-helpful / correct-neutral / correct-harmful。其中 **wrong-helpful 即"错误却有用"**。

## 6. 主要结论与发现

1. **错误却有用普遍存在**：每一个基准—模型组合（10 格）均出现 wrong-helpful 消息。
2. **改变正确性的错误消息中 >40% 有帮助**：
   - OSS：flip 率 15.0%，helpful 占 41.9%（$n=1,623$）。
   - Gemma：flip 率 7.1%，helpful 占 45.3%（$n=1,601$）。
   - 95% bootstrap 区间：OSS [39.5%, 44.3%]、Gemma [42.6%, 48.1%]。
3. **整体效应超出重放变异性**：5,000 个块内置换无数据集能匹配观测计数，$p = (0+1)/(5000+1) = 0.0002$；BH 校正后 Gemma 11 个 wrong-helpful 题目跨全部 5 个基准保留，OSS 0 个。
4. **正确性非必要也非充分**：wrong-helpful 说明正确性不是正向价值的必要条件；correct-harmful（OSS flip 率 5.7% 中 34.8% 为有害；Gemma flip 率 1.7% 中 22.5% 为有害）说明正确性也不是充分条件。
5. **完整消息 > 仅推理 > 仅答案**（针对 wrong-helpful 锚点）：
   - 完整消息：整合器成功 82%
   - 隐藏错误答案：64%
   - 隐藏推理：44%
   - 同长度中性替换：46%
   - 完全移除：26%
   - 优势主要源自推理内容，但完整消息优势的具体来源仍开放。
6. **可用候选与可整合之间存在鸿沟**：5 条消息中至少一条含正确答案的比例为 76.0%–95.4%，比 $K=5$ 准确率高 4.2–36.2 分；同一整合器对 1 条消息成功而对 5 条失败的现象在 OSS 9.8%、Gemma 6.9% 的题目中出现，反向仅 0.5% 和 0.2%。
7. **同问题机会高于仅靠正确性**：跨拟合单消息删除使准确率提升 1.68 分（OSS）和 2.61 分（Gemma），高于正确性比较器的 0.94 / 1.00 分；事后最优基线分别高出 oracle 7.1 和 5.5 分。
8. **Gemma 重复性更强**：73 个 wrong-helpful 区间分离（null 95% 范围 [13, 38]），OSS 仅 23 个（null [10, 30]）；同一消息在不同积分器下相关系数仅 $r=0.095$。

## 7. 优点

- **概念创新**：清晰分离"提案正确性"与"轨迹价值"，引入"上下文特异"而非"文本固有"的可测量属性。
- **方法严谨**：通过固定池 + 切换可见性实现准因果式测量，避免辩论、改写、过滤等生成流程混淆。
- **重复性控制**：使用置换检验、自举区间、BH/BY 多重校正，并对调用顺序、积分器更换、评估者一致性进行多维度敏感性测试。
- **机制诊断**：通过组件掩蔽（分别隐藏推理与答案）定位价值的主要承载部分；通过积分器替换揭示轨迹价值的积分器依赖性。
- **可复用资产**：发布上下文索引化的标签与提示模板，支持后续"何时该听哪条消息"的学习研究。
- **跨模型一致性**：在两个独立开发的开源模型上呈现一致方向，强化结论的外部效度。
- **完整双向案例**：附录给出 5 个基准各 1 个 wrong-helpful + 1 个 correct-harmful 的真实轨迹记录，并标注可读机制（如"复用并修正"、"复用并过滤"、错误传播、输出终止失败等）。

## 8. 不足与局限

- **轨迹价值的上下文依赖**：标签属于"消息—池—积分器"三元组，而非消息文本的内在属性；同一消息在更换积分器后方向可能改变（Pearson $r = 0.095$）。
- **LOO 的语义局限**：留一法改变提示长度与绝对位置，无法完全隔离语义内容；组件掩蔽只是初步机制探索，10 个 wrong-helpful 锚点样本量小。
- **样本非随机嵌套**：$K=2,\dots,5$ 是同一招募角色集的前缀，并非随机添加新智能体的因果效应；HK 描述的是池大小轨迹。
- **同源模型角色**：每次运行中招募者、假设者、整合器均为同一模型，无法测试异构模型组合的轨迹价值。
- **统计边界**：
  - OSS 在 BH 控制下无多重比较后保留的 wrong-helpful 题目；多数消息在 5 块预算下仍属未定区间。
  - LAB-Bench 重放变异性最高（OSS 17.5%），单题目解读需更谨慎。
- **标签评测者敏感性**：6 格复合标签的一致性低于单答案判断（71.6%–88.7%），Gemma 的复合标签对评估者更敏感。
- **应用边界**：结论基于数学与科学领域、单一正确性 ground-truth 任务；未验证交互式辩论、多模态、长上下文决策或开放式生成任务。
- **机会≠部署策略**：跨拟合收益仅衡量同问题重复证据下的决策机会，并未提供面向未见过问题的在线选择器或泛化保证。
- **完整消息优势的源头开放**：组件掩蔽仅显示"完整 > 仅推理 > 仅答案"的方向，具体推理片段的贡献仍待进一步分解。
