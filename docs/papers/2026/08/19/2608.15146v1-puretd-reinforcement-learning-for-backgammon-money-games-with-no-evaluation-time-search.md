## 摘要
我们在无评估时搜索的设定下重新审视 Tesauro 的 TD-Gammon 在双陆棋赌资博弈中的应用。棋子的走法与立方体决策（加倍立方体的使用）均通过自博弈强化学习从零开始学习，仅使用极少的手工编码逻辑，且不依赖任何专家特征。在该设定下，我们证明纯粹的自博弈强化学习足以训练出接近当前最先进水平的模型。具体而言，在带加倍赌资博弈中，我们的无搜索模型评估速度更快，并且显著强于运行单步（1 层）前瞻搜索的开源引擎 GNU Backgammon 与 Open Sage。

## Abstract
We revisit Tesauro's TD-Gammon for backgammon money games in the setting of no evaluation-time search. Both checker play and cube action (use of the doubling cube) are learned from scratch via self-play reinforcement learning (RL), with minimal hand-coded logic and no expert features. In this setting, we demonstrate that pure self-play RL suffices to train models that reach near-state-of-the-art playing strength. Specifically, for cubeful money games, our search-free model evaluates faster and is substantially stronger than the open-source engines GNU Backgammon and Open Sage running a one-move (1-ply) look-ahead search.

# PureTD 论文总结

## 1. 核心问题与研究背景

双陆棋（backgammon）计算机引擎通常由两部分组成：学习得到的位置评估器（神经网络）+ 评估时执行的 expectimax 搜索。Tesauro 的 **TD-Gammon** 作为纯自博弈强化学习（TD(λ)）的经典先驱，曾达到当时的最高水平，但后续更强的引擎（如 GNU Backgammon、eXtreme Gammon、Open Sage）普遍结合了搜索与 Janowski 解析公式等启发式方法处理**加倍立方体（doubling cube）**决策，且训练细节大多不公开。

本文核心问题是：在**完全不使用评估时搜索（0-ply）**的设定下，单纯依靠**自博弈强化学习**，能否训练出接近顶尖水平的双陆棋赌资博弈（money game）模型，并使模型端到端学习**带加倍决策的走子**？

研究的整体含义：
- 验证纯 RL（无搜索、无专家特征）的性能上限，类似"搜索无关的国际象棋"（Ruoss et al., 2024）的研究范式。
- 推动开放、可复现的双陆棋 RL 流水线。

## 2. 方法论

### 2.1 核心思想

延续 TD-Gammon 的自博弈 TD 学习思想，但做了三项关键现代化改造：
1. **ReLU 激活**取代 sigmoid。
2. **批量训练**：将自博弈数据采集与参数更新解耦，每回合采 1000 局自博弈后做一轮 mini-batch SGD（Adam 优化器）。
3. **精确 Bellman 更新**（exact backup）：对所有 21 种骰子结果取期望，对应 Hilton (2020) 的 "1-ply amplified equity"。先用 0-ply 采样目标训练至平台，再切换到 1-ply 精确目标继续训练。

### 2.2 关键公式

设伪状态 $x$（掷骰子前的局面），掷 $d \sim D$ 后到达状态 $s_{x,d}$，选择动作 $a$ 后确定性转移到伪状态 $\tilde{T}(s_{x,d}, a)$。

**采样（0-ply）目标**：

$$y_{\text{sampled}}(x) = \max_a V(\tilde{T}(s_{x,d}, a)), \quad d \sim D$$

**精确（1-ply，Exact Bellman）目标**：

$$y_{\text{exact}}(x) = \mathbb{E}_{d \sim D}\!\left[\max_a V(\tilde{T}(s_{x,d}, a))\right]$$

Bellman 最优性方程：

$$V^*(s) = \max_a \mathbb{E}_{s' \sim T(s,a)}[V^*(s')]$$

### 2.3 加倍立方体作为动作空间扩展

**主要贡献**之一：将 `offer_double` / `no_double` 加入 agent 动作空间，作为普通状态转移通过 TD 学习。

- 加倍决策无骰子随机性，采样与精确目标重合：

$$y_{\text{sampled}}(s) = y_{\text{exact}}(s) = \max_a V(\tilde{T}(s, a))$$

- 对手 `take` / `drop` 决策**贪心**地由当前评估器 $V$ 解析求解（pass 当且仅当 $2V(s_{\text{recube}}) > 1$）。
- 加入一个 `is_cube_action` 标志位（见下表，使网络能区分"轮到我决定是否加倍"与"走子"的同一棋盘状态）。

**立方体所有权与动作的 one-hot 编码表**：

| $c_{\text{centered}}$ | $c_{\text{own}}$ | $c_{\text{opp\_own}}$ | `is_cube_action` | 决策类型 |
|:---:|:---:|:---:|:---:|---|
| 1 | 0 | 0 | 0 | 走子 |
| 1 | 0 | 0 | 1 | **初始加倍**（cube centered） |
| 0 | 1 | 0 | 1 | **再加倍**（recube） |
| 0 | 0 | 1 | 1 | **不合法配置** |

此设计**修正了 Lin (2020) 的关键概念缺陷**：Lin 的方案不为 `no_double` 转移生成 TD 样本，且缺乏 `is_cube_action` 标志，导致网络在 cube-decision 与 post-no-double 两种状态共享同一值估计，无法在清晰的双倍/PASS 局面正确加倍。

### 2.4 网络架构与训练流水线

- 棋盘编码：Tesauro 的"每点四特征"+ bar/bore off 共 **196 维**，cubeful 扩展到 **200 维**（增加 3 个 cube-ownership one-hot + `is_cube_action`）。
- 视角编码：恒以"当前要走子的一方"为视角。
- 网络：MLP，cubeful 模型为 4 层 [512, 512, 256, 256]，约 **562k 参数**，输出为对当前立方体值的归一化 equity（因为金钱游戏 equity 线性正比于立方体值）。
- **渐进扩展（Progressive Expansion）**：使用 Net2Net 函数保持变换，从小到大依次扩展 `[80] → [150] → [150, 150] → [256, 256] → [512, 512] → [512, 512, 256] → [512, 512, 256, 256]`。
- **跨任务迁移**：double-match-point (DMP) → cubeless equity (`prob5`) → cubeful money，每次都重用前期权重。
- 学习率热身（warmup）：每次架构/任务切换时，前 20 轮学习率从目标值的 10% 线性升至目标值。

## 3. 实验设计

### 3.1 数据/场景
由于纯自博弈训练，**不使用任何外部数据**（不像 Open Sage 依赖 gnubg rollout 数据库）。

任务：双陆棋赌资博弈
- 无加倍（**cubeless money**）：`prob5` 模型，5 个 sigmoid 输出（win/win-gammon/win-backgammon/lose-gammon/lose-backgammon 概率），等价值 $E = 2P(\text{win}) - 1 + P(\text{win gammon}) + P(\text{win backgammon}) - P(\text{lose gammon}) - P(\text{lose backgammon})$。

### 3.2 对比基线

### 3.3 评测指标
- **Head-to-head equity (mEq/game)**：对局强度指标，1 mEq = 0.001 单位 equity，10⁷ 局。

- **决策吞吐**（decisions/s）：单线程 self-play 与 fixed-position 两个基准。

2. **Cubeful 0-ply 模型** vs. **两个强开源引擎 + 1-ply 搜索**仍显著更强：
   - vs. gnubg 1-ply：$+19.8$ mEq/game，XG++ PR 0.94 vs. 1.21。
   - vs. Open Sage 1-ply：$+17.4$ mEq/game。
3. **决策吞吐优势**：0-ply 评估速度至少是任何 1-ply 方法的 **2.5×**（最接近情形：gnubg 1-ply on Zen 3，为 $2.60\times$）。
4. **Cubeless 0-ply 模型**对 gnubg/Open Sage 在 0-ply 与 1-ply 下均显著更强（最高约 $-46.3$ mEq）。
5. **关键修正**：相对 Lin (2020) 的方案，`is_cube_action` + 对 `no_double` 转移的训练样本将 XG++ PR 从 1.70 降到 0.94（降幅 ~45%），将头对头 equity 提升 $46.4$ mEq（消融实验）。
6. **匹配深度的影响**：0 → 1 → 2-ply 持续提升双方棋力，但 PureTD 在每一深度上均优于基线（Table 6）。

## 7. 优点

- **可复现性**：完整训练与评测流水线、模型与命令以 MIT 开源，发布于 [GitHub 仓库](https://github.com/alexstrehl/backgammon-ai-engine)。
- **动作空间统一**：把加倍决策并入 RL 框架，**消除了对 Janowski 解析公式的依赖**，降低工程复杂度（这是已知让引擎开发者头疼的部分）。
- **修正了 Lin (2020) 的概念缺陷**，并通过消融明确量化了改进幅度。
- **现代化 TD-Gammon**：用 ReLU + 批训练 + 精确 Bellman 更新即可达到接近最优，验证"老方法的新威力"。
- **多视角评测**：同时报告 head-to-head 强度、离线 PR、决策吞吐，并讨论引擎层面 vs. 评估器层面的差异。
- **跨任务渐进迁移**：DMP → cubeless → cubeful 的迁移大大加速训练，相对从零开始。
- **Jacoby 规则与 cube 所有权**被显式建模，并通过清晰的算法伪代码（Algorithm 1）落地。

## 8. 不足与局限

- **未覆盖 match play**：仅评估金钱博弈；score-aware 加倍策略与更长博弈 horizon 仍是 RL 的开放挑战。
- **0-ply 评估器与端到端引擎之间的 gap**：作者明确承认此工作的目标是评估器强度而非完整系统（evaluator + search）的优化；未提供完整的搜索集成方案。
- **运行时效率未面向生产**：自实现以 PyTorch 直通，0-ply 单步 throughput 仍比 gnubg 的手写优化代码慢 5–12×。
- **未探索学习型 MCTS 规划**（如 Stochastic MuZero / AlphaZero 风格），可能进一步推高棋力。
- **Open Sage 与 Hedgehog 等近期系统的对比有限**：Hedgehog 评测口径不同（基于网络而非引擎）未能直接对齐，Open Sage 的 cubeful 评测路径也并非"代表性"路径。
- **依赖自然随机探索**：文中未使用显式探索策略（dice 之外的随机），对其他博弈场景的可移植性不明确。
- **训练细节缺失**：生产模型经数月训练迭代，逐阶段设置未保留；附录 D 给出可复现的重训方案，但与生产模型仍可能存在小幅差距（cubeful 重训版 +1.5 mEq vs. 生产）。
- **结果统计显著性**：所有报告的差异都给出了 95% 置信区间，但绝对 mEq 值相对较小（如 +19.8 mEq/game），且对偶发"失控 back game"做了 $\pm 128$ equity 截断以抑制离群值影响，可能略乐观。
- **baselines 选择**：仅对比两个最强开源引擎（gnubg、Open Sage），未对比 BGBlitz、Octopus 等更强的封闭/未发布系统。
