基于大语言模型（LLM）的多智能体系统（MAS）的性能在很大程度上取决于有效的通信拓扑。然而，现有的拓扑生成方法通常通过仅由任务级奖励驱动的黑箱优化来学习通信拓扑。虽然这种方法有效，但这种优化方式难以解释为何选择特定的通信边，使得识别负责成功协作的关键通信子图变得困难。为了解决这一局限，我们提出了 E2-Explainer，一个模型无关的框架，用于对任意拓扑生成器所产生的通信拓扑提供可解释的解释。具体而言，我们将拓扑解释建模为一个因果归因问题，旨在识别由边级任务保持证据支持的紧凑通信子图。我们采用一种格兰杰风格的目标函数来获取该证据，该目标函数衡量屏蔽每条通信信道会如何改变任务结果及最终响应的稳定性。随后，将得到的预算受限的子图提炼为一个摊销解释器，从而在部署时无需重复进行边级评估即可实现高效的事后解释。在多个推理和编程基准上的大量实验表明，E2-Explainer 能够识别出能够保持成功协作的关键通信子图。这些子图还可直接执行以剪除冗余的通信边，在保持具有竞争力的任务性能的同时大幅降低通信开销。

## Abstract
The performance of large language model (LLM)-based multi-agent systems (MAS) largely depends on effective communication topologies. Existing topology generation methods, however, typically learn communication topologies through black-box optimization driven solely by task-level rewards. While effective, such optimization provides little insight into why particular communication edges are selected, making it difficult to identify the critical communication subgraphs responsible for successful collaboration. To address this limitation, we propose E2-Explainer, a model-agnostic framework for providing interpretable explanations of communication topologies produced by arbitrary topology generators. Specifically, we formulate topology explanation as a causal attribution problem that identifies compact communication subgraphs supported by edge-level evidence of task preservation. We obtain this evidence with a Granger-style objective that measures how masking each communication channel changes the task outcome and the stability of the final response. The resulting budgeted subgraphs are then distilled into an amortized explainer, enabling efficient post-hoc explanation without repeated edge-level evaluations at deployment. Extensive experiments on multiple reasoning and coding benchmarks demonstrate that E2-Explainer identifies critical communication subgraphs that preserve successful collaboration. These subgraphs can also be executed directly to prune redundant communication edges, substantially reducing communication costs while maintaining competitive task performance.

## 2. 方法论

### 2.1 整体框架（E2-Explainer）

E2-Explainer 由两阶段组成：

1. **离线因果监督构造**：对每个候选图 $G=(V,E)$ 进行逐边干预，估计边的因果贡献，构建"图→子图"监督数据集 $\mathcal{D}_{\text{expl}}$。
2. **摊销解释器（amortized explainer）训练**：学习映射 $F_\theta:(x,G,b)\mapsto \hat{H}_b$，其中 $b=(\rho_E,\rho_V)$ 为预算（边剪除率、节点剪除率），部署时一次性预测预算化的紧凑子图。

### 2.2 边级 Granger 式因果归因

对每条活跃边 $e=(u,v)\in E$ 进行**单边去除干预**，得到干预图 $G_{-e}=G\setminus\{e\}$，重新执行冻结的 LLM-MAS。定义两个因果信号：

- **任务级因果贡献**：
$$\Delta^{\text{task}}_e = Q(x,G) - Q(x,G_{-e}), \quad u^{\text{task}}_e = \max(0,\Delta^{\text{task}}_e)$$
其中 $Q(x,G)$ 为任务得分（精确匹配、Pass@1 等），在 $M=5$ 次独立采样下取均值。

- **辅助语义熵信号**：
$$\bar{H}(Y) = -\sum_{c\in C(Y)} p(c)\log p(c)$$
$$u^{\text{sem}}_e = \max\!\bigl(0,\;\bar{H}(Y_{G_{-e}})-\bar{H}(Y_G)\bigr)$$
掩蔽后语义熵增加 ⇒ 该边对响应稳定性有贡献。

- **统一边效用**：
$$u_e = \text{clip}_{[0,1]}\!\Bigl(\alpha\cdot\tilde u^{\text{task}}_e + \beta\cdot\tilde u^{\text{sem}}_e\Bigr), \quad (\alpha,\beta)=(0.8,0.2)$$
其中 $\tilde{\cdot}$ 表示在当前图或校准批内的归一化。

### 2.3 预算化因果子图提取

给定预算 $b=(\rho_E,\rho_V)$，按保留效用降序排列得到排序 $\pi_G=(e_{(1)},\dots,e_{(|E|)})$：

$$E^\star_b = \text{TopK}(\pi_G, k_E(b))$$
$$H^\star_b = \mathcal{R}_{\text{valid}}(G,E^\star_b,k_V(b))$$

其中 $\mathcal{R}_{\text{valid}}$ 为**可执行性约束投影**：仅选原边集中的边、保留必经的输入/聚合节点、按邻接边的聚合效用优先剔除可选节点、若原图为 DAG 则自动保持无环性。

将多个预算 $b\in\mathcal{B}$ 应用上式，得到一族解释 $\mathcal{F}^\star(x,G)=\{H^\star_b:b\in\mathcal{B}\}$。

### 2.4 摊销解释器架构与训练

- **输入表示**：节点特征 $h_v = \phi_{\text{node}}([q_x\|r_v\|t_v])$，其中 $q_x$ 为查询嵌入、$r_v$ 为角色提示嵌入、$t_v$ 为结构特征（归一化入度/出度、拓扑位置）；图级摘要 $g_G=\frac{1}{|V|}\sum_v h_v$；预算嵌入 $z_b=\phi_b([\rho_E,\rho_V])$。
- **预测头**：
$$\hat A_{b,e} = \sigma\!\bigl(\phi_{\text{edge}}([h_u\|h_v\|g_G\|z_b\|s_e])\bigr)$$
$$\hat R_{b,v} = \sigma\!\bigl(\phi_{\text{retain}}([h_v\|g_G\|z_b])\bigr)$$
所有节点/边实例共享同一 MLP 编码器，参数量与图规模无关，支持跨尺度迁移。
- **训练损失**（BCE + 权重衰减）：
$$\mathcal{L} = \mathcal{L}_{\text{edge}} + \lambda_{\text{node}}\mathcal{L}_{\text{node}} + \lambda_{\text{wd}}\|\theta\|_2^2$$
- **推理解码**：$\hat E_b=\text{TopK}(\hat A_b,k_E(b))$，$\hat V_b=\text{TopK}(\hat R_b,k_V(b))$，再经 $\mathcal{R}_{\text{valid}}$ 得到最终可执行子图 $\hat H_b$。**部署时无需任务标签或重复边干预**。

## 6. 主要结论与发现

1. **冗余普遍存在**：G-Designer 与 OFA-MAS 生成的拓扑中均含大量冗余通信边，但随机剪枝难以识别"任务保持"子图。
2. **方法有效性**：E2-Explainer 在 4 类生成器上**普遍降低 20.1%–25.6% 的加权 token 开销**，同时平均精度提升 0.44–1.09 个百分点；G-Designer+E2-Explainer 取得最高平均精度 90.71%。
3. **跨生成器可迁移**：仅用 G-Designer 校准的冻结解释器，可直接迁移到 ARG-Designer、OFA-MAS、AgentPrune 三种未见生成器，验证了框架的"模型无关性"。
4. **跨规模可迁移**：在 5-Agent 上训练，在 6-Agent 上零样本测试仍能提升精度（MMLU 79.43→81.70；HumanEval 89.26→90.08）。
5. **跨手工拓扑可迁移**：在完全图、随机图、分层图、链图、星形图等 5 种手工拓扑上，30 个组合中 26 个精度持平或提升，token 全部下降。
6. **因果信号比语义熵更重要**：消融显示去除因果信号使 MMLU 精度由 79.74 降至 75.82；但语义熵作为辅助可显著提高 token 削减幅度（−23.42% → −31.50%）。
7. **预算-性能权衡**：E25+N20 是最优折中点；E25+N40 虽 token 削减达 42.63%，但 HumanEval 下降 6.52 个百分点，说明代码生成对节点级剪枝更敏感。
8. **校准源影响**：源匹配仍占优（AgentPrune 校准在 AgentPrune 目标上最佳），但混合源校准在多数情况下也能产生有竞争力结果，表明跨生成器提示信号具有共享结构。

## 7. 优点与亮点

- **理论视角新颖**：将通信拓扑解释建模为**因果归因问题**，并基于 Granger 因果思想引入边级干预信号，区别于传统 GNN 解释器的可微松弛假设。
- **双信号融合**：任务级因果贡献 + 结果级语义熵互补，缓解任务奖励稀疏问题。
- **摊销推理设计**：训练阶段一次性承担高昂的边干预开销，部署阶段仅需一次前向传播即可输出预算化子图，实用性强。
- **强可迁移性**：模型无关性通过**跨生成器、跨校准源、跨 Agent 规模、跨手工拓扑**四类迁移实验系统验证。
- **架构参数与图规模解耦**：节点/边共享 MLP 编码器，支持任意 Agent 数与边数。
- **可执行子图投影**：$\mathcal{R}_{\text{valid}}$ 保证子图可直接被原 MAS 执行，不引入新边、不破坏 DAG 性。
- **定性案例分析深入**：4 个执行轨迹细致剖析了"为何剪枝后变好/变差/不变"，比纯数值结果更具解释力。

## 8. 不足与局限

- **单一 Backbone**：所有实验均使用 Qwen3-8B，未验证在其他 LLM（如 GPT-4、Claude、Llama）下的可迁移性，限制了结论的普适性。
- **校准规模有限**：每数据集仅 40 个校准查询，对小样本噪声较敏感，可能影响因果效用估计的稳定性。
- **一阶因果干预局限**：仅做单边去除，未考虑**多边协同效应**（论文明确指出不做组合枚举），可能高估/低估某些边的真实贡献。
- **随机采样非配对**：原图与干预图采用独立随机种子采样（温度 0.2），因此定性案例中"正确→错误"或"错误→正确"的转变**不能完全归因于剪枝**，存在采样噪声。
- **任务范围偏窄**：仅覆盖英文数学、知识、代码三类推理任务，未涉及多模态、长文档理解、Agent 工具调用等更复杂场景。
- **手工拓扑基准主观**：链图、星形图等结构由作者手工设计，可能与现实部署场景的拓扑分布存在偏差。
- **未提供训练时长与碳足迹**：虽说明了 GPU 型号（4×RTX 4090），但未报告完整的离线干预开销与解释器训练总时长。
- **依赖任务反馈**：辅助信号中的任务得分仍需 ground-truth 答案或可执行测试，限制了在无监督场景的应用。
