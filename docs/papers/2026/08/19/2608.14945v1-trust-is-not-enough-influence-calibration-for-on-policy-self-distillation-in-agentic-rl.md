## 摘要
在策略自蒸馏（OPSD）利用特权自教师在策略自身轨迹上为语言智能体提供密集的 token 级监督。现有方法主要通过教师信任来分配这种监督，但信任并不能揭示强调某个 token 是否支持当前策略目标。我们将此称为信任-效用失配，并提出自蒸馏影响校准（ICSD）。对于每个被监督的 token，ICSD 衡量其重要性加权的 RL 替代目标对教师导向输出扰动的一阶响应。批量自适应校准将这一非平稳信号转化为有界的分配权重，同时保留每个动作回合内原始的辅助损失总量。这些分离的权重仅影响蒸馏损失，无需额外的模型前向传播。在 ALFWorld、WebShop 和 Search-QA 上，ICSD 在组相对策略优化（GRPO）与组内组策略优化（GiGPO）下，相较于仅依赖信任的分配方式，在跨越 1.5B 至 7B 参数规模的两个模型系列上均提升了所有匹配的聚合指标。在 7B 模型上，其在 ALFWorld 上达到 96.1% 的成功率，WebShop 得分为 93.1。冻结批次分析显示，ICSD 将分配给目标反向 token 的教师支持质量从 60.1% 降低至 37.8%，并将与 RL 梯度的余弦兼容性提升了 0.192。配套代码仓库位于 https://github.com/lanqz7766/Influence-Calibration-for-On-Policy-Self-Distillation-in-Agentic-RL。

## Abstract
On-policy self-distillation (OPSD) gives language agents dense token-level supervision from a privileged self-teacher on the policy's own trajectories. Existing methods allocate this supervision mainly by teacher trust, but trust does not reveal whether emphasizing a token supports the current policy objective. We call this the trust-utility mismatch and introduce Influence Calibration for Self-Distillation (ICSD). For each supervised token, ICSD measures the first-order response of its importance-weighted RL surrogate contribution to a teacher-directed output perturbation. Batch-adaptive calibration converts this non-stationary signal into a bounded allocation weight while preserving the original auxiliary-loss mass within each action turn. These detached weights affect only the distillation loss and require no additional model pass. Across ALFWorld, WebShop, and Search-QA, ICSD improves all matched aggregate metrics over trust-only allocation under Group Relative Policy Optimization (GRPO) and Group-in-Group Policy Optimization (GiGPO), across two model families spanning 1.5B to 7B. At 7B, it reaches 96.1% ALFWorld success and a WebShop score of 93.1. Frozen-batch analyses show that ICSD reduces teacher-supported mass assigned to objective-opposed tokens from 60.1% to 37.8% and raises cosine compatibility with the RL gradient by 0.192. A companion repository is avail- able at https://github.com/lanqz7766/Influence-Calibration-for-On-Policy-Self-Distillation-in-Agentic-RL.

## 1. 核心问题与研究动机

- **背景**：在基于在策略强化学习（On-Policy RL）训练长视野语言智能体时，外部奖励仅在整条轨迹末尾稀疏地抵达一次，粒度远粗于产生它的若干动作决策。为此，**在线策略自蒸馏（OPSD）** 通过"特权自教师"（privileged self-teacher，例如可看到轨迹衍生技能 $z_t$ 的支路）在同一 rollouts 上给当前策略提供密集的 token 级辅助监督。
- **问题揭示**：现有方法（SDAR / Skill-SD / SAGE-OPD / TurnOPD / TIP 等）几乎都**仅依据教师信任度**——例如教师–学生 log-prob 差距 $\Delta_t$、熵、位置、证据对比——来分配各 token 的蒸馏权重。然而**信任度高并不等于该 token 的更新方向契合当前 RL 优化目标**。作者将其命名为 **trust–utility mismatch**（信任–效用失配）：在冻结的 ALFWorld 批次上，信任分配将其教师支持质量的 $60.1\%$ 放在了"优势为负"的目标反向 token 上。
- **核心目标**：在不增加额外前向/反向计算、不改变 RL 主目标和辅助损失总量的前提下，按"教师导向的目标影响"对已有 trust 权重做**再分配（redistribution）**，使蒸馏梯度方向局部更兼容 RL 梯度方向。

### 2.1 形式化

- 对 minibatch 中每个合法响应 token $t\in B$，特权支路给出 stop-gradient log-prob，定义 **teacher–student 差距**  
  $$\Delta_t=\mathrm{sg}\!\left[\log\pi^+_\theta(a_t|x_t,z_t)-\log\pi_\theta(a_t|x_t)\right]$$
- **token 级辅助蒸馏损失**  
  $$\hat{\ell}^{KD}_t(\theta)=\mathrm{sg}\!\left[\log\pi^+_\theta(a_t|x_t,z_t)\right]-\log\pi_\theta(a_t|x_t)$$
- **统一分配目标**（$\lambda$ 为蒸馏系数，$c_t\ge 0$ 为 detached 权重）  
  $$L(\theta)=L_{RL}(\theta)+\frac{\lambda}{|B|}\sum_{t\in B}\mathrm{sg}(c_t)\,\hat{\ell}^{KD}_t(\theta)$$
- ICSD **保留**继承自 SDAR 的信任权重 $g_t=G_\text{trust}(\Delta_t)\in[0,1]$，仅对其做"同动作回合质量守恒"下的再分配。

### 2.2 教师导向的"目标影响"分数

记策略比 $\rho_t=\pi_\theta(a_t|x_t)/\pi_\text{old}(a_t|x_t)$，token 优势 $\hat A_t$；未裁剪替代贡献 $J_t=\hat A_t\rho_t$。对教师差距 $\Delta_t$ 做标量输出扰动：

$$\log\rho_t(\epsilon)=\log\rho_t+\epsilon\Delta_t,\quad \rho_t(\epsilon)=\rho_t\,e^{\epsilon\Delta_t}$$

取一阶 Taylor 系数定义为 **objective influence**：

$$u_t:=\left.\frac{\partial\, \hat A_t\rho_t(\epsilon)}{\partial\epsilon}\right|_{\epsilon=0}=\hat A_t\,\rho_t\,\Delta_t$$

$$J_t(\epsilon)=J_t(0)+\epsilon u_t+O(\epsilon^2)$$

（附录 A.1 给出 Lagrange 余项 $\frac12|\hat A_t|\rho_t\Delta_t^2 e^{|\epsilon\Delta_t|}$，证明一阶系数是精确的。）

### 2.3 批量自适应校准

- 按动作回合索引 $G\subseteq B$ 分组（稀疏组回退到全 minibatch 统计），用 **中位数 + 单侧均值** 拟合鲁棒位置与两端尺度：
  $$\hat\mu_G=\text{median}\,u_j,\quad \hat b^-_G=\text{mean}_{u_j<\hat\mu_G}|u_j-\hat\mu_G|,\quad \hat b^+_G=\text{mean}_{u_j\ge\hat\mu_G}|u_j-\hat\mu_G|$$
- 校准映射（带切分参数 $\eta=0.5$ 的非对称 Laplace 族 CDF）：
  $$\Phi_G(u)=\begin{cases}\eta\exp\!\left(\dfrac{u-\hat\mu_G}{\hat b^-_G}\right), & u<\hat\mu_G\\[4pt]1-(1-\eta)\exp\!\left(-\dfrac{u-\hat\mu_G}{\hat b^+_G}\right), & u\ge\hat\mu_G\end{cases}\;\Rightarrow\;\tilde m_t=\Phi_G(u_t)\in(0,1)$$
- **保形组成（保守回退）**：当 $\hat A_t<0$ 且 $\Delta_t<0$ 时，分析方向与蒸馏更新方向相反，$u_t>0$ 会"假阳"，故回退到基础信任：
  $$D=\{t\in B:\hat A_t<0,\ \Delta_t<0\},\quad C=B\setminus D$$
- **动作回合内质量守恒**：对每个回合 $q$，令 $C_q=C\cap q$，$D_q=D\cap q$。当 $\sum_{j\in C_q}g_j\tilde m_j>0$ 时
  $$\alpha_q=\frac{\sum_{j\in C_q}g_j}{\sum_{j\in C_q}g_j\tilde m_j},\qquad c_t=\begin{cases}g_t,&t\in D_q\\\alpha_q g_t\tilde m_t,&t\in C_q\end{cases}$$
- **命题 1（不变量分配）**：在非退化尺度与 $\eta\in(0,1)$ 下，$\Phi_G$ 单调；对整组分数施加正仿射变换 $u_j'=au_j+b\ (a>0)$，$\tilde m_t$、$\alpha_q$、$c_t$ 全部不变；且满足回合质量守恒 $\sum_{t\in q}c_t=\sum_{t\in q}g_t$，全局 $\sum_{t\in B}c_t=\sum_{t\in B}g_t$。同信任的 token 在 $C_q$ 内按 $u_t$ 大小排序。

### 2.4 完整算法流程（Algorithm A1）

1. 用 $\pi_\theta$ roll out，计算 $\hat A_t$、$\rho_t$ 与采样 log-prob；
2. 用 stop-gradient 特权支路计算 $\Delta_t$ 与 $g_t=G_\text{trust}(\Delta_t)$；
3. 计算 detached 影响 $u_t=\hat A_t\rho_t\Delta_t$；
4. 在校准组 $G$ 上拟合 $(\hat\mu,\hat b^-,\hat b^+)$ 并设 $\tilde m_t=\Phi_G(u_t)$，稀疏组回退到 minibatch 统计；
5. 划分 $D=\{\hat A_t<0,\Delta_t<0\}$，$C=B\setminus D$；
6. 对每个回合 $q$：若分母 $>0$，按上式算 $\alpha_q$ 并应用 $c_t$；否则令 $c_t=g_t$；
7. 分离 $\{c_t\}$ 后用目标式更新 $\theta$。

**复杂度优势**：无需任何额外模型前向/反向，所有操作仅是 detached elementwise 运算 + CDF 拟合。

- **基准与任务**：
  - **ALFWorld**（Pick / Look / Clean / Heat / Cool / Pick2 共 6 类）；
  - **WebShop**（电商网页交互）；

- **模型族**：Qwen2.5-Instruct（1.5B / 3B / 7B）与 Qwen3-Instruct（1.7B / 4B）。
- **RL 优化器**：GRPO 与 GiGPO（包含步级优势构造）。
- **基线对比**：
  - **匹配对照**：GiGPO/GRPO + SDAR（同继承 trust 分配，其余条件一致）；
  - **扩展对照**：Vanilla、Skill-Prompt\*、OPSD（Zhao 等 2026）、Skill-SD、Skill-GRPO\*、RLSD、TiP、SAGE-OPD 等。

## 6. 主要结论

- **指标层面**：所有匹配的聚合指标被 ICSD 一致提升。
  - Qwen2.5-7B + GiGPO：ALFWorld 成功率 94.5 → **96.1%**；WebShop Score / Acc 88.4 / 78.9 → **93.1 / 84.4**；
  - Qwen3-4B：ALFWorld 平均 89.8 → **95.3**；
  - 1.5B GRPO 控制组仍维持同样趋势，WebShop Acc 提升最显著（GRPO 下 +11.7 pp，GiGPO 下 +7.0 pp）。
- **分配层面**：在 teacher-supported 子集上，原本面向目标反向 token 的"trusted conflict mass（TCM）"从 **60.1% 降至 37.8%**；按 $\Delta_t$ 与 $\hat A_t$ 双维 rank，**强信任 + 强支持区域获得 ~2.9× / 2.6× 质量**，**强信任 + 目标反向区域降至 0.79×**。
- **梯度层面**：与 RL 梯度 $\nabla L_{RL}$ 的余弦相似度 **平均 +0.192**；将同一组 $c_t$ 随机置换后仅留 +0.020，证伪"由总质量驱动"的解释。
- **配置层面**：中位 CDF 切分 $\eta=0.5$、$\lambda=0.01$、非对称 Laplace 校准三选一为最佳；连续签名的影响分数同时优于"仅大小"与"仅符号"两类简化。

## 7. 优点

- **问题定位精准**：把看似常识、实则常被默认的"信任即权重"假设显式化为 trust–utility mismatch，并给出可量化的失效统计（$60.1\%$）。
- **算法轻量优雅**：仅用 RL 更新既有的 $\hat A_t,\rho_t,\Delta_t$ 计算 $u_t=\hat A_t\rho_t\Delta_t$，**不增加模型前向**，无需逆 Hessian/曲率；附录实测仅 ~0.4% 端到端开销。
- **校准稳健**：非对称 Laplace CDF 校准 + 中位数 + 双侧尺度能压住优势、ratio、teacher gap 的重尾与漂移；并证明校准在正仿射变换下不变。
- **保形性严格**：回合质量守恒 $\sum_{t\in q}c_t=\sum_{t\in q}g_t$ 使实验对照在"总蒸馏预算"维度严格公平，避免了"靠多分辅助来赢"的伪赢。
- **机制审计完备**：TCM、双维 rank redistribution、$\nabla L_{KD}$ vs $\nabla L_{RL}$ 余弦、permutation 控制四件套，从分配、几何、对照三个角度三角验证了"质量来自 token 级再分配而非总质量"。
- **泛化广**：覆盖 3 个基准、2 种 RL 算法、2 个模型族、5 个尺寸，且 ICSD 评测时**不依赖**任何特权上下文（区别于 Skill-Prompt\* / Skill-GRPO\*）。

## 8. 不足与局限

- **算力与可复现性披露不足**：仅给出 4×H100 / Qwen2.5-1.5B / WebShop 的单项开销，**3B/7B/Qwen3 系列所用 GPU 数、总训练时长、超参搜索代价均未公开**；也无多随机种子结果，难以判断尾部方差。
- **机制分析的样本规模有限

，且全为 ALFWorld 冻结 batch**：4-batch TCM + 16-batch 余弦审计都集中在 ALFWorld 与 WebShop，对 Search-QA 这类稀疏奖励、检索噪声大的场景未做同样粒度的几何检查，机制结论的"跨域一致性"仍需更大样本验证。

- **理论保证仅限一阶**：附录 A.1 用 Lagrange 余项给出 $\hat A_t\rho_t\Delta_t$ 对替代目标一阶近似误差的上界，但实际二阶项在高 $\Delta_t$（distillation 信赖极端的 token）或高 ratio 漂移处可能不可忽略；当 $|\epsilon\Delta_t|$ 较大时（如未来增大 $\lambda$ 或采用更长 horizon），应同步验证更高阶项或蒙特卡洛梯度差的影响。

- **trust-only 与"小影响"区间不可识别**：当 $|\Delta_t|$ 或 $|\hat A_t|$ 接近零时，$u_t\to 0$ 会落入 $\Phi_G$ 中位数附近的"中段"，校准几乎没有再分配能力。这意味着 ICSD 的收益主要来自**信息充分**的强信号 token，对**教师低自信**或**优势接近零**的 token 实际上保留了 trust 原值——这本身是合理保守，但也限制了其在教师自身置信度偏低场景下的适用性。

- **特权自教师的依赖未去除**：与 SDAR 同源，ICSD 仍要求存在可见 $z_t$ 的特权支路（skill 库 + 关键词检索），无法在完全无偏的纯 on-policy RL 上独立运行。对特权上下文构造成本的依赖被一并继承。

- **分配族系仍是单变量乘性形式**：ICSD 假设影响以 $u_t=\hat A_t\rho_t\Delta_t$ 的乘积形式表达，未显式建模优势-时序、ratio-方差、teacher-gap 不确定性之间的耦合（如 KL 漂移下的 ratio 偏差会同步放大 $|u_t|$）；当 policy 与 teacher 行为分布差异显著时，可能需要更复杂的局部可加性模型。

- **评测指标偏聚合**：ALFWorld 主要报"成功率"，WebShop 报 Score/Acc/Reward，Search-QA 报 F1/EM/LM-judge Acc 等聚合指标，对**任务子类型**（如 WebShop 的搜索-比较-购买路径差异、ALFWorld 的 Pick vs Cool 难度梯度、Search-QA 的多跳复杂度）的细粒度分析不足，难以判断 ICSD 的增益来自哪一类决策模式。

- **对照扩展未完全覆盖最新方法**：在表 2 的 6 类扩展对照中未纳入 Skill-SAGE-OPD、TurnOPD、TiP 等近期 token 级蒸馏方法，亦未与 trajectory-level 的 process reward / advantage shaping 等更宏观方法正面对照；与 RLSD 的对照也仅在表 2 出现，未在 Search-QA 上做全规模复算。

- **超参稳健性的边界未充分刻画**：图 5 显示在 $\eta\in\{0.3,0.5,0.7\}$、$\lambda\in\{0.005,0.01,0.05\}$ 内 ICSD 都稳定，但并未给出更极端的扫描（如 $\lambda\geq0.1$、$\eta\to 0/1$、或不同 ratio clip 阈值下）的退化曲线，因此其"稳健区间"的可外推性仍有限。

- **计算成本的低开销声明依赖特权计算未计**：1.7% 每-token actor 耗时增量仅统计 actor 更新本身，没有计入特权自教师前向（skill-bank 检索 + 关键词抽取 + stop-gradient forward）所花费的时间；若把特权支路的检索与额外 forward 计为训练成本，ICSD 的端到端开销会显著高于 0.4%。

- **缺乏失败案例分析**：未给出 ICSD 退化（如在某子任务上落后 SDAR）的反例分析，也未讨论 trust–utility mismatch 在哪些动作回合或子策略上几乎不存在（此时 ICSD 应退化为 SDAR，但实际是否如此没有验证）。

## 9. 启示与未来工作

- **从"信任"到"目标影响"的范式转变**：本文示范了 OPSD 分配不应止步于教师置信度，而应将 RL 优化目标的方向直接纳入权重设计。这一思路可自然推广到**多教师集成**、**多任务辅助损失**、**RLHF reward shaping** 等场景：把任意辅助监督项的梯度方向与主目标梯度方向做局部对齐，能在不增加总预算的前提下减少"互斥梯度"造成的"摇摆更新"。

- **校准函数族可进一步扩展**：非对称 Laplace 是当前的最简选择，未来可探索**自适应分位分段**（如基于 $G$ 内 $u_t$ 的分位切点而非中位数）、**学到的可逆校准**（如 monotone spline / neural CDF），以应对不同任务下 $u_t$ 分布形态的差异。

- **与 RL 算法协同设计**：ICSD 当前只用了 GRPO / GiGPO 的 token 级 $\hat A_t$ 与 PPO-style $\rho_t$。若与**步级 / 回合级优势**（如 Process Advantage / Tree-of-Thought 优势）、**信用分配式 advantage shaping** 相结合，影响分数 $u_t$ 可进一步精细化为"动作-回合-任务"三维影响。

- **降低对特权自教师的依赖**：可以探索在**非特权但可推断的上下文**（如从环境反馈中提炼的隐式 skill）下构造近似教师差距，或通过**自回归延迟**让当前策略在前几步充当自身教师，从而把 ICSD 推广到无显式特权的更一般 on-policy RL。

- **可解释性接口**：由于 $u_t=\hat A_t\rho_t\Delta_t$ 是可分解的，研究者可据此对**单 token 决策**给出"为什么这次更新权重大 / 小"的诊断（教师差距大？优势反向？ratio 漂移？），用于 RL policy 的可解释性分析与失败归因。

- **与曲率感知 / Fisher 信息结合**：本文仅做一阶影响估计；若未来对辅助项引入 Fisher 加权（如 SDAR 中的 magnitude 变体），可能需把 $u_t$ 替换为 Fisher-weighted gradient projection，得到"曲率对齐"意义上的影响分数，这会与 Fisher 加权 token 级蒸馏构成新的设计点。

- **更广泛基准上的可复现性报告**：未来工作应公开 **3B/7B/Qwen3 系列所用 GPU 数、单次 / 多次随机种子下的总训练时长、wall-clock 对照**，并补足 Search-QA 等稀疏检索场景下的机制审计样本，使"信任-效用失配"现象的普遍性得到更坚实的实证支撑。
