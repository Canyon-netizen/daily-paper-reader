## 摘要
持续的自改进需要一个不断扩展的、由自身生成、多样化且自适应的目标池。对于语言智能体而言，现有的训练环境池（人工策划、静态合成或冻结验证器的）随着学习者规模的扩大，目标分布始终保持固定。我们提出 SPADE（Self-Play in Adaptive Synthetic Executable Environments，自适应合成可执行环境中的自博弈），这是一个自博弈强化学习框架，其中单个 LLM 扮演两个角色：环境设计器（Environment Designer），负责以可执行代码形式编写完整的、长视野的训练环境，并配备 OpenAI Gym 风格的 reset()/step() 接口；推理智能体（Reasoning Agent），负责在其中学习行动。每个环境都是具有状态的多轮环境（包含状态转移、奖励函数与验证代码），因此同一套接口可同时覆盖推理问题与多步智能体工具使用。推理智能体的遗憾值通过其在有/无特权提示下所得奖励之间的差距来估计；在优化该遗憾信号的过程中，环境设计器学会将目标瞄准智能体能力边缘但仍可完成的环境。通过大量实验，我们发现若干对成功至关重要的组件：需将环境设计器锚定在从大规模预训练语料中采样的文档之上，并赋予其累积的环境记忆。扩展到 30B 参数模型时，SPADE 在八个保留的数学、科学、代码与推理基准上平均较最强的固定环境基线提升 +5.3，并在工具使用任务上将 BFCL-v4 多轮成绩提升 +5.7、ACEBench-Agent 提升 +13.9；在游戏任务上，相对最强基线的领先幅度随模型规模增大而扩大。通过将环境设计本身打造为可学习组件，SPADE 向开放式自改进迈出了具体的一步。

## Abstract
Continuous self-improvement requires an ever-expanding pool of self-generated, diverse, adaptive goals. For language agents, existing training environment pools (hand-curated, statically synthesized, or frozen-verifier) keep the goal distribution fixed as the learner scales. We introduce SPADE (Self-Play in Adaptive Synthetic Executable Environments), a self-play RL framework in which a single LLM plays two roles: an Environment Designer that writes complete, long-horizon training environments as executable code with an OpenAI Gym-style reset()/step() interface, and a Reasoning Agent that learns to act in them. Each is a stateful, multi-turn environment (state transitions, reward functions, and verification code), so one interface spans reasoning problems and multi-step agentic tool use. The Reasoning Agent's regret is estimated using the gap between its reward with and without privileged hints; in optimizing this regret signal the Environment Designer learns to target environments at the edge of the agent's capabilities while keeping them feasible. Through extensive experimentation, we find several components critical to success: grounding the Environment Designer on documents sampled from a large pretraining corpus, and giving it an accumulated environment memory. Scaling to 30B-parameter models, SPADE improves over the strongest fixed-environment baseline by +5.3 on average across eight held-out math, science, code, and reasoning benchmarks, and lifts the tool-use setting by +5.7 on BFCL-v4 multi-turn and +13.9 on ACEBench-Agent; on the games setting, the margin over the strongest baseline grows with model scale. By making environment design itself a learnable component, SPADE takes a concrete step toward open-ended self-improvement.

## 1. 核心问题与研究动机

- **持续自改进的瓶颈**：随着语言智能体在长视野推理、工具使用、网页与计算机操作上的能力提升，从"经验中学习"成为主要驱动力。人类高质量文本是有限资源（Villalbos et al., 2024），进一步智能体进展的瓶颈正逐步转向**训练环境的供给**——即带可验证奖励的交互式任务。
- **现有路径的局限**：
  - 人工策划的环境池（AgentRL、RLVE 等）扩展速度受限于人力；
  - 静态合成的环境生成器（AWM、ScaleEnv、EvoCUA 等）虽然规模大，但生成器固定，模型很快会耗尽其覆盖空间；
  - 自博弈方法（AZR、R-Zero、SPIRAL、SPICE 等）通常只生成"任务"（带稀疏终止奖励的题目），而非完整的多轮 MDP（状态转移 + 奖励函数 + 验证代码），且易受"信息对称"限制坍缩到已有知识。
- **核心问题**：是否存在一种机制能让训练环境分布随智能体能力的提升而**自适应地演化**，而不是停留在固定池或固定生成器？

## 2. 方法论

### 2.1 整体框架：双角色自博弈

- 同一个 LLM 策略 $\pi_\theta$ 通过**角色化系统提示**承担两个角色：
  - **环境设计器 (Environment Designer, ED)**：$\pi_\theta(\cdot \mid \text{role}=D)$，输出可执行 Python 环境 $e \in \mathcal{E}$（实现 OpenAI Gym 风格 `reset()/step()` 接口）以及一条"特权提示" $h$；
  - **推理智能体 (Reasoning Agent, RA)**：$\pi_\theta(\cdot \mid \text{role}=A)$，通过多轮交互解决环境中的任务。
- 两个角色**共享参数 $\theta$**，每轮自我对弈后通过 GRPO 联合更新。

### 2.2 基于提示的遗憾奖励 (Hint-Based Regret)

- 对每个生成的环境 $e$，分别采样 $G$ 次带提示的轨迹 $\{y'_i\}$ 与不带提示的轨迹 $\{y_i\}$，定义 ED 奖励：
$$r_D(e) = \bar{r}_A(e\mid h) - \bar{r}_A(e) = \frac{1}{G}\sum_{i=1}^{G} r_A(y'_i\mid e, h) - \frac{1}{G}\sum_{i=1}^{G} r_A(y_i\mid e)$$
- 三种情形：
  - 高遗憾 → 环境处于"学习前沿"（需提示才解得出）；
  - 低遗憾 + 高分 → 智能体已掌握；
  - 低遗憾 + 低分 → 环境不可解。
- 实际部署时该遗憾信号与"难度锚"（要求 RA 胜率落入带状区间 $[0.4, 0.6]$）混合（权重 0.6:0.4），并将遗憾值下限截断为 0 以避免欺骗。

### 2.3 算法流程（Algorithm 1）

- 每一轮迭代：
  1. ED 采样域提示 $p_d$ 与语料文档，生成环境 $e_b$ 与提示 $h_b$，验证语法可执行性；
  2. RA 不带提示与带提示各采样 $G$ 次轨迹，分别计算 $\bar{r}_A(e_b)$ 与 $\bar{r}_A(e_b\mid h_b)$；
  3. 计算 ED 奖励 $r_D(e_b)$ 与 RA 奖励 $r_A(y_i\mid e_b)$；
  4. 按角色做组内/技能内优势归一化，使用 GRPO 截断策略梯度更新共享 $\theta$。
- 关键稳定化技巧：ED 更新延迟 $k$ 步，并采用**截断重要性采样**进行离策略修正；非对称 PPO 截断 $(\varepsilon_{low}, \varepsilon_{high}) = (0.20, 0.28)$。

### 2.4 环境设计的三要素

- **代码即环境 (Code-as-Environment)**：每个环境是一个 Python 类，含隐状态、状态转移 $T(s'|s,a)$、奖励 $R(s,a)$ 与可验证终止。同一接口统一了单轮推理与多轮工具使用。
- **语料锚定 (Corpus Grounding)**：每轮从大规模预训练语料（游戏场景下从 DCLM + MegaScience 抽取 15k 数学/科学文档；工具使用场景下从 Nemotron 代码语料抽取 15k 文档）中采样一段作为生成种子，避免"信息对称"导致坍缩。
- **环境记忆 (Environment Memory)**：维护一个 200 条记录的环形缓冲，存放历史 $(e, r_D, \text{skill})$，避免 ED 重复生成 RA 已掌握或不可解的环境。

### 2.5 理论分析（附录 B）

- 在"声音生成 / 充分提示 / 提示行为可内化"三个假设下，**任何纯纳什均衡**都满足：
$$u_D(D^\circ, \pi^\circ) = 0, \quad R_{\pi^\circ}(e) = R^\star(e),\ R^h_{\pi^\circ}(e) = R_{\pi^\circ}(e), \ \forall e \in \mathcal{M}$$
- 即在均衡处，RA 在所有合法环境上达到无提示最优，ED 的期望遗憾归零。

## 7. 优点与亮点

- **范式层面**：将"环境生成器"由外部冻结的资产变成**与 RA 同一 LLM 的可学习角色**，并使用同一套 GRPO 训练循环联合优化，是 UED 思路在 LLM 后训练中的自然延伸。
- **方法层面**：
  - 提示式遗憾奖励 $r_D(e)=\bar{r}_A(e\mid h)-\bar{r}_A(e)$ 实现轻量化的 minimax regret 估计，**无需单独训练对抗网络**；
  - 代码即环境（带隐状态、状态转移、奖励、可执行验证）将单轮推理与多轮工具使用统一到同一接口，避免了"任务-环境"鸿沟；
  - 语料锚定 + 环境记忆的双输入机制解决了"信息对称坍缩"与"重复生成已掌握任务"两个长期痛点；
  - ED 更新延迟 + 截断重要性采样提供了稳定的双角色联合训练。
- **实验层面**：
  - 三档 backbone 完整评测 + 跨族系验证（Nemotron）；
  - 跨 4 类能力的 8 个 OOD 基准；
  - 长达 73 页的附录提供了提示样例、环境样例、奖励曲线、生成样例的全文源代码，便于复现与诊断。

## 8. 不足与局限

- **可生成复杂度受限于基座**：ED 无法产出超出基座模型本身表达能力的更复杂环境，生成复杂度随模型规模与生成预算扩张而封顶（"invisible leash"，Chae et al., 2025）。
- **优化器由人类设计**：两角色仍由固定的人类编写 RL 算法（GRPO）驱动，**未修改自身学习规则**。
- **理论未达最优性证明**：提示式遗憾受 PAIRED 启发但**未被证明生成最优课程**；评估仍以固定任务成绩衡量，未直接度量开放式推理成长。
- **小模型信号噪声**：4B 与 8B 上 ED 遗憾估计频繁出现负值，表明有限样本下经验差距并非最优遗憾的一致估计。
- **对比公平性**：工具使用对比中多系统源自不同论文、不同用户模拟器与 BFCL 快照，跨行均值仅作参考。
- **稳定性与系统开销**：双角色联合训练需多组稳定化技巧（延迟更新、重要性采样、难度锚、混合奖励），调参与计算开销大于普通 RLVR；大规模训练算力 / 墙钟时间未在文中披露。
