## 摘要
我们在不使用评估时搜索的设定下，重新审视 Tesauro 的 TD-Gammon 在双陆棋赌资游戏问题上的应用。无论是棋子走法还是方块动作（即加倍立方体的使用），都通过自对弈强化学习（RL）从零开始学习，仅依赖极少量人工编写的逻辑，不使用任何专家特征。在此设定下，我们证明了纯自对弈强化学习足以训练出棋力接近当前最优水平的模型。具体而言，在含加倍权的赌资游戏中，我们的无搜索模型评估速度更快，并且其棋力显著强于执行一步（1 层）前瞻搜索的开源引擎 GNU Backgammon 和 Open Sage。

## Abstract
We revisit Tesauro's TD-Gammon for backgammon money games in the setting of no evaluation-time search. Both checker play and cube action (use of the doubling cube) are learned from scratch via self-play reinforcement learning (RL), with minimal hand-coded logic and no expert features. In this setting, we demonstrate that pure self-play RL suffices to train models that reach near-state-of-the-art playing strength. Specifically, for cubeful money games, our search-free model evaluates faster and is substantially stronger than the open-source engines GNU Backgammon and Open Sage running a one-move (1-ply) look-ahead search.

## 一、核心问题与研究动机

双陆棋（Backgammon）计算机引擎的传统范式由两部分组成：(1) 一个学习得到的位置评估器（通常是神经网络，输出局面的 equity）；(2) 一个 expectimax 搜索，在决策时对评估器的打分沿 $n$ 步博弈树取期望。几乎所有现代强引擎（如 eXtreme Gammon、GNU Backgammon）都依赖以下设计：

- **训练无公开文档**，细节封闭；
- 使用**无加倍立方（cubeless）评估器**，cube 动作由后处理的 Janowski 解析公式近似；
- 端到端强棋力依赖**搜索 + 手工特征 + 大量工程**。

本文回到 Tesauro 的 TD-Gammon 原始范式：仅靠**纯自博弈时序差分（TD）强化学习**，不使用评估时搜索、不使用专家特征，端到端学习同时包含棋子走法与加倍立方决策的统一网络。论文要回答的核心问题是：**在 0-ply（无前瞻）设定下，纯自博弈 RL 能否训练出接近当前最优（SOTA）的双陆棋引擎？** 研究动机既是历史性致敬（TD-Gammon 范式复兴），也是工程意义（去除搜索即可部署到低延迟或资源受限环境）。

## 二、方法论

### 2.1 核心思想

将双陆棋建模为两人零和 MDP，固定参考方为 maximizer，对手 minimizer。Bellman 最优性方程为：

$$V^*(s) = \max_a \mathbb{E}_{s' \sim T(s,a)}\big[\,V^*(s')\,\big]$$

为了消除骰子随机性的方差，引入"伪状态"（pseudo-state）$x$（掷骰子之前的局面）。掷骰子 $d \sim \mathcal{D}$ 后得到状态 $s_{x,d}$，agent 选择走法 $a$，进入确定性的下一伪状态 $\tilde{T}(s_{x,d}, a)$。则最优值函数满足：

$$V^*(x) = \mathbb{E}_{d\sim\mathcal{D}}\!\left[\,\max_a\, V^*\!\big(\tilde{T}(s_{x,d},a)\big)\,\right]$$

### 2.2 训练目标：0-ply 与 1-ply

- **采样（0-ply）目标**：单次掷骰子后取贪心续局值

$$y_{\text{sampled}}(x) = \max_a\, V\!\big(\tilde{T}(s_{x,d},a)\big),\quad d\sim\mathcal{D}$$

- **精确 Bellman（1-ply）目标**：对全部 21 种骰子结果取平均

$$y_{\text{exact}}(x) = \mathbb{E}_{d\sim\mathcal{D}}\!\left[\,\max_a\, V\!\big(\tilde{T}(s_{x,d},a)\big)\,\right]$$

训练流水线先用采样目标（约快 5×）到第一个 plateau，再切换到精确 Bellman 目标到第二个 plateau。

### 2.3 加倍立方作为动作空间扩展

将 cube-offer 决策（`no_double` vs `offer_double`）纳入 agent 的动作空间，不掷骰子，状态转移确定性，因此采样与精确目标一致：

$$y_{\text{sampled}}(s) = y_{\text{exact}}(s) = \max_a\, V\!\big(\tilde{T}(s,a)\big)$$

被加方（take/pass）由当前网络贪心决定。**关键修正**（相对于 Lin 2020）：加入 `is_cube_action` 标志以区分 cube 决策状态与不加倍后续的 checker-play 状态，并对每次 cube-offer（含 `no_double`）生成 TD 更新样本。Lin 的方法缺少这两点，会导致明确 double/pass 局面下不加分。

### 2.4 网络架构与训练流程

- **Cubeful money 模型**：MLP，200 输入 → 隐藏层 $[512,512,256,256]$ → 线性输出（每单位 cube 值的 equity），共约 562k 参数，ReLU 激活。
- **Cubeless money 模型（prob5）**：196 输入 → $[512,512,256,128]$ → 5 个独立 sigmoid 概率头（win, win_gammon, win_backgammon, lose_gammon, lose_backgammon），共 528k 参数。
- **Board encoding**：Tesauro 风格每点 4 特征 + bar/born-off，加上 cube 三位 one-hot 与 `is_cube_action` 标志，共 200 维。
- **流水线**：每轮 $N=1000$ 局自博弈 → 收集所有访问状态的回归目标 → 一轮 Adam 小批量 SGD。批训练替代原始 TD-Gammon 的在线 SGD。
- **渐进式扩张与跨任务迁移**：宽度/深度逐级增长，使用 Net2Net function-preserving 变换保留先前权重；DMP 网络 warm-start cubeless 模型，后者再 warm-start cubeful 模型（扩展输入层 196→200）。每次任务切换后做 20 轮学习率 warmup（从约 10% 目标值线性升到目标值）。

## 六、主要结论与发现

1. **Pure self-play RL 足以训练 0-ply 接近 SOTA 的评估器**：cubeful 0-ply PureTD XG++ PR 为 $0.94\,[0.89,0.99]$，优于 1-ply 的 gnubg（$1.21\,[1.15,1.27]$）和 Open Sage（$1.28\,[1.20,1.39]$）。
2. **头对头优势显著**：对 gnubg 1-ply 取得 $+19.8$ mEq/game，对 Open Sage 1-ply 取得 $+17.4$ mEq/game（$10^7$ 局，cubeful money）。
3. **算力代价更低**：在 Zen 5 上 PureTD 0-ply 决策速度是 gnubg 1-ply 的 4.6×，比 Open Sage 1-ply 快两个数量级；综合（对局数 × 决策速率）至少快 2.5×。
4. **搜索仍有助益**：PureTD 0-ply/1-ply/2-ply 的 XG++ PR 分别为 $0.94 \to 0.46 \to 0.29$，随深度持续下降，且在各匹配深度上仍优于两基线。
5. **Cube 决策是关键差异**：Lin 风格变体 XG++ PR 从 $0.94$ 退化到 $1.70$，其中 Cube-PR 从 $0.60$ 退化到 $2.13$，验证了 `is_cube_action` 与 no-double 训练样本的必要性。
6. **网络容量与搜索协同**：更大网络（562k 参数）虽然单次评估慢于 gnubg 的专用裁剪网络，但避免了搜索开销，仍取得更优的代价-强度权衡。

## 七、优点与亮点

- **范式回归的价值**：在 AlphaZero/MuZero 主导的时代，重新证实 Tesauro 原始 TD 学习在双陆棋上的能力天花板远未到达，且完全不需要 MCTS。
- **端到端 cubeful 学习**：把 cube-offer 视为普通动作，首次给出与 gnubg/Open Sage 等成熟开源引擎直接对弈并胜出的 cubeful 端到端 RL 模型。
- **完整开源可复现**：代码、模型、复现命令均以 MIT 协议发布；自 2026 年 3 月起部分结果就持续公开。
- **训练流水线工程细致**：Net2Net 渐进扩张、跨任务 warm-start、学习率 warmup、采样与精确 Bellman 两阶段切换，都是实用且经过消融验证的选择。
- **公平对比口径**：明确区分带裁剪与不带裁剪的强度差异，量化移动过滤对结果的微小影响；置信区间与 bootstrap 设置透明。
- **跨任务迁移加速训练**：DMP → cubeless equity → cubeful money 的链式 warm-start 被证明显著快于从零学习。

## 八、不足与局限

1. **缺乏 match play 评估**：方法与实验均仅覆盖 money games，未触及分制比赛中分数感知型 cube 策略与更长决策视野的问题。
2. **未系统评估搜索对模型的影响**：主要强调 0-ply 评估器强度，仅在 4.4 节简单展示搜索的增益，没有给出完整带搜索的引擎端到端对比。
3. **未与最强闭源/私有引擎直接对弈**：BGBlitz、Octopus、Hedgehog 商业模型 Colossus、XG 等都未参与 head-to-head，仅用 XG++ PR 作为外部分析代理。
4. **0-ply 模型并非完整引擎**：未将搜索与评估器组合优化，最大化的是评估器本身强度而非引擎整体 strength；论文也承认这是 genuine limitation。
5. **截断统计量**：cubeful 对局 equity 在 ±128 处截断；论文承认极少数失控后局面可能掩盖某些复杂后场局面下的真实差距。
6. **Open Sage cubeful 对比受限**：因 Open Sage 当前未提供高效的 cubeful money 与自博弈 API，cubeful 表中只对比了 gnubg，且 cubeful 决策速率测量不具代表性（其 cubeful API 每次调用会重载评估器）。
7. **未探索更深层学习模型规划**：未触及 AlphaZero/Stochastic MuZero 风格的学得模型 + MCTS 规划，未给出学习模型 + 学习的 cube 决策的端到端组合。
8. **生产模型细节缺失**：由于训练跨月进行，部分逐阶段超参与时间表未保留，仅以附录 D 的可复现替代训练替代，承认两者之间存在轻微统计漂移。
9. **算力门槛仍存在**：虽然单工作站可训练，但 2 亿局自博弈 + 65 小时墙钟 + 高端 GPU 对个人研究者而言并不低廉。
10. **对手池单一**：评估对手只有两个开源引擎，未给出对人类玩家、不同棋风 backgammon bots、或自博弈内部方差的多样性测试。

（完）
