## 摘要
在线策略自蒸馏（OPSD）为语言智能体提供来自特权自教师的密集 token 级监督信号，这些监督作用于策略自身生成的轨迹上。现有方法主要依据教师信任度来分配此类监督，但信任度并不能揭示强调某个 token 是否服务于当前策略目标。我们将此现象称为"信任–效用失配"，并提出自蒸馏影响校准（ICSD）。对于每个受监督的 token，ICSD 测量其重要性加权 RL 替代目标贡献对教师方向输出扰动的一阶响应。批自适应校准将这一非平稳信号转化为有界的分配权重，同时在每个动作轮次内保持原有辅助损失的总量。这些解耦权重仅作用于蒸馏损失，无需额外的模型前向计算。在 ALFWorld、WebShop 和 Search-QA 上，ICSD 在组相对策略优化（GRPO）与组中组策略优化（GiGPO）框架下，相对仅基于信任度的分配方法，在涵盖 1.5B 到 7B 的两类模型系列上均提升了所有匹配的聚合指标。在 7B 模型上，其 ALFWorld 成功率可达 96.1%，WebShop 得分为 93.1。冻结批次分析显示，ICSD 将分配给与目标相悖 token 的教师支持质量占比从 60.1% 降至 37.8%，并将相对于 RL 梯度的余弦兼容性提升 0.192。配套代码仓库见 https://github.com/lanqz7766/Influence-Calibration-for-On-Policy-Self-Distillation-in-Agentic-RL。

## Abstract
On-policy self-distillation (OPSD) gives language agents dense token-level supervision from a privileged self-teacher on the policy's own trajectories. Existing methods allocate this supervision mainly by teacher trust, but trust does not reveal whether emphasizing a token supports the current policy objective. We call this the trust-utility mismatch and introduce Influence Calibration for Self-Distillation (ICSD). For each supervised token, ICSD measures the first-order response of its importance-weighted RL surrogate contribution to a teacher-directed output perturbation. Batch-adaptive calibration converts this non-stationary signal into a bounded allocation weight while preserving the original auxiliary-loss mass within each action turn. These detached weights affect only the distillation loss and require no additional model pass. Across ALFWorld, WebShop, and Search-QA, ICSD improves all matched aggregate metrics over trust-only allocation under Group Relative Policy Optimization (GRPO) and Group-in-Group Policy Optimization (GiGPO), across two model families spanning 1.5B to 7B. At 7B, it reaches 96.1% ALFWorld success and a WebShop score of 93.1. Frozen-batch analyses show that ICSD reduces teacher-supported mass assigned to objective-opposed tokens from 60.1% to 37.8% and raises cosine compatibility with the RL gradient by 0.192. A companion repository is avail- able at https://github.com/lanqz7766/Influence-Calibration-for-On-Policy-Self-Distillation-in-Agentic-RL.

## 一、核心问题与研究动机

- **背景**：语言智能体在长程交互任务中日益采用在线策略强化学习（on-policy RL），但奖励信号在轨迹级高度稀疏（一次整条轨迹一次回报），与逐 token 的决策粒度严重错配。
- **现有解决方案**：以 OPSD（on-policy self-distillation）为代表的稠密辅助蒸馏方法通过特权自教师（privileged self-teacher）在策略自身 rollout 上提供 token 级监督，从而将稀疏回报转化为密集信号。
- **核心痛点 — 信任–效用失配（trust–utility mismatch）**：
  - 现有 OPSD 分配规则（如 SDAR）主要依据"教师信任度"——即教师–学生差距（gap）、不确定性、token 位置等——决定监督权重。
  - 但**信任度并不等于效用**：两个 token 可能被教师同等信任，但一个落在当前 RL 优势函数（advantage）支持的动作轮次，另一个落在被惩罚的轮次，简单的信任加权错配了目标方向。
  - 在冻结 ALFWorld 批次上的统计显示：trust-only 分配将 **60.1%** 的教师支持质量放在了与目标相悖的 token 上。
- **三个落地的技术挑战**：
  1. 影响估计：经典影响函数需要在参数空间内做 Hessian 逆求解与逐 item 梯度，对 billion 规模模型不可行。
  2. 分布校准：优势、概率比、教师差距具有漂移量纲与重尾，固定阈值不具跨 batch 可比性。
  3. 信号有效性：局部信号仅在所部署的损失能实现所分析的方向时才有效。

## 二、方法论

### 2.1 OPSD 辅助损失基线

学生策略 $\pi_\theta$ 在状态 $x_t$ 采样 token $a_t$，特权分支 $\pi^+_\theta(\cdot|x_t, z_t)$ 拥有额外上下文 $z_t$（如轨迹派生 skill）；教师对数概率在当前 actor 更新中被 stop-gradient。token 级蒸馏损失为：

$$\hat{\ell}^{\text{KD}}_t(\theta) = \mathrm{sg}\!\left[\log\pi^+_\theta(a_t|x_t, z_t)\right] - \log\pi_\theta(a_t|x_t)$$

教师–学生差距 $\Delta_t = \mathrm{sg}\!\left[\log\pi^+_\theta(a_t|x_t, z_t) - \log\pi_\theta(a_t|x_t)\right]$。

整体目标：

$$L(\theta) = L_{\text{RL}}(\theta) + \lambda \frac{1}{|B|}\sum_{t\in B}\mathrm{sg}(c_t)\,\hat{\ell}^{\text{KD}}_t(\theta)$$

其中 $c_t\ge 0$ 为 detached 分配系数。SDAR 取 $g_t = G_{\text{trust}}(\Delta_t)$ 作为信任权重，依赖且仅依赖 $\Delta_t$。

### 2.2 教师方向的目标影响（Teacher-Directed Objective Influence）

避免昂贵的参数空间影响计算，转而对**输出坐标**做 teacher 方向扰动：

$$\log\rho_t(\epsilon) = \log\rho_t + \epsilon\Delta_t,\quad \rho_t(\epsilon) = \rho_t\exp(\epsilon\Delta_t)$$

token $t$ 对未裁剪最大化替代贡献 $J_t = \hat{A}_t\rho_t$ 的一阶 Taylor 项为：

$$u_t := \left.\frac{d\,\hat{A}_t\rho_t(\epsilon)}{d\epsilon}\right|_{\epsilon=0} = \hat{A}_t\rho_t\Delta_t$$

正值 $u_t$ 表示提升采样 token 概率将提高局部 surrogate 贡献，符号直接反映教师方向是否与当前 RL 目标一致。

### 2.3 批自适应校准（Batch-Adaptive Calibration）

为消除量纲漂移与重尾，对每个动作轮次组 $G$（跨轨迹同动作索引的 token 池，过小则回退至全 batch），用中位数与单侧均值做鲁棒位置–尺度估计：

$$\hat{\mu}_G = \mathrm{median}_{j\in G}\,u_j,\quad \hat{b}^{-}_G = \mathrm{mean}_{j\in G,\,u_j<\hat{\mu}_G}|u_j-\hat{\mu}_G|,\quad \hat{b}^{+}_G = \mathrm{mean}_{j\in G,\,u_j\ge\hat{\mu}_G}|u_j-\hat{\mu}_G|$$

两侧尺度做 $\varepsilon$ 下限保护后，得到**非对称 Laplace 族 CDF** 校准映射：

$$\Phi_G(u) = \begin{cases} \eta\exp\!\left((u-\hat{\mu}_G)/\hat{b}^{-}_G\right), & u<\hat{\mu}_G\\[4pt] 1-(1-\eta)\exp\!\left(-(u-\hat{\mu}_G)/\hat{b}^{+}_G\right), & u\ge\hat{\mu}_G \end{cases}$$

其中 $\eta=0.5$，$\tilde{m}_t = \Phi_G(u_t)\in(0,1)$。该校准具备**正仿射不变性**：对所有 token 施加 $u'_j=au_j+b$（$a>0$）时，$\tilde{m}'_t=\tilde{m}_t$，$\alpha'_q=\alpha_q$，$c'_t=c_t$。

### 2.4 保守组合（Conservative Composition）

当 $\hat{A}_t<0$ 且 $\Delta_t<0$（双负）时，所部署的辅助更新方向与分析的扰动方向相反，二者乘积使 $u_t$ 仍为正，造成"虚假支持"假象。定义保守回退集：

$$D=\{t\in B:\hat{A}_t<0,\ \Delta_t<0\},\quad C=B\setminus D$$

- 对 $t\in D$：保留基线信任系数 $c_t = g_t$。
- 对 $t\in C$，在动作轮次 $q$ 内做**精确质量匹配（mass matching）**：

$$\alpha_q = \frac{\sum_{j\in C_q}g_j}{\sum_{j\in C_q}g_j \tilde{m}_j},\quad c_t = \alpha_q g_t \tilde{m}_t,\ t\in C_q$$

若分母近零，则整轮次 $c_t=g_t$。

由此得到**轮次级不变量** $\sum_{t\in q}c_t = \sum_{t\in q}g_t$，全局 $\sum_{t\in B}c_t = \sum_{t\in B}g_t$，即 ICSD **不增加也不减少任何辅助预算**，仅做同一总量内的重分配。

### 2.5 算法流程（每 minibatch）

1. Rollout $\pi_\theta$，计算 $\hat{A}_t$、$\rho_t$。
2. stop-gradient 特权分支评估得到 $\Delta_t$ 与 $g_t = G_{\text{trust}}(\Delta_t)$。
3. 计算 detached 影响 $u_t = \hat{A}_t\rho_t\Delta_t$。
4. 拟合 $(\hat{\mu},\hat{b}^-,\hat{b}^+)$，得到 $\tilde{m}_t = \Phi_G(u_t)$。
5. 形成回退集 $D$ 与活跃集 $C$。
6. 对每个动作轮次 $q$ 计算 $\alpha_q$ 并赋值 $c_t$。
7. 解耦 $\{c_t\}$，执行 actor 更新。

$c_t$ 与 $\log\pi^+_\theta$ 均被 stop-gradient；辅助梯度只经过学生对数概率流回，**无需任何额外的前向或反向计算**。

## 三、实验设计

### 3.1 数据集 / Benchmark

- **ALFWorld**：6 类交互任务（Pick、Look、Clean、Heat、Cool、Pick2），成功率。
- **WebShop**：得分（Score）与准确率（Acc.）。
- **Search-QA**：Search-R1 的 7 个子集（NQ、TriviaQA、PopQA、HotpotQA、2WikiMultiHopQA、Musique、Bamboogle）。
- 使用 SDAR 的任务划分与评估指标（Lu et al., 2026）。

### 3.2 模型与算法

- 模型族：Qwen2.5-Instruct 1.5B / 3B / 7B；Qwen3-1.7B、Qwen3-4B。
- 策略优化器：GRPO 与 GiGPO 两种。
- 公平对比：在同一模型、数据、RL 算法、privileged teacher 与 SDAR 基线的前提下，仅替换 token 级分配规则为 ICSD（matched comparison）。

### 3.3 对比方法

- No-RL 基线：Vanilla、Skill-Prompt\*（测试时仍带 retrieval）。
- Hybrid 蒸馏基线：Skill-SD、RLSD。
- 纯 OPSD 类：OPSD、SDAR。
- Skill/RL 结合：Skill-GRPO、Skill-GRPO\*。
- 内部消融变体：Fisher magnitude（无符号控制）、Sign-only（仅硬符号）、Influence-only（仅影响无信任）。

## 四、资源与算力

- 文中仅在**实现细节附录 C.2**中给出了少量算力信息：
  - 在 Qwen2.5-1.5B WebShop 上，使用 **4×H100 GPU** 做 matched 对比。
  - ICSD 的 per-token actor 更新耗时相对 trust-only SDAR 增加 **1.7%**；因 actor 更新约占总步时的 1/5，归一化端到端 overhead 约 **0.4%**。

## 六、主要结论与发现

- **统一提升**：在 3 个基准、2 个 RL 算法、5 个模型配置、6 种分配变体下，ICSD 在所有匹配的聚合指标上均优于 trust-only 的 SDAR。
- **量级结果**：Qwen2.5-7B GiGPO+ICSD → ALFWorld 96.1%（vs 94.5%）、Search-QA 49.1%、WebShop 93.1 / 84.4%（vs 88.4 / 78.9%）。
- **机制层面的客观重分配**：teacher-supported、objective-opposed token 的质量占比 TCM 由 SDAR 的 **60.1% → ICSD 的 37.8%**（22.3 个百分点的下降，95% 动作轮次 bootstrap CI [22.1, 22.6]），并在 4 个 batch 中全部呈下降。
- **梯度兼容性**：冻结 batch 上 $\cos(\nabla L_{\text{KD}},\nabla L_{\text{RL}})$ 提升 **0.192**（CI [0.147, 0.240]），随机置换同样权重仅带来 0.020 提升，说明增益源自 token 配对而非总量。
- **优化器无关**：GRPO 与 GiGPO 下均获益，WebShop 准确率差距最大：GRPO +11.7pp，GiGPO +7.0pp。
- **跨模型族一致**：Qwen3-4B 上 ICSD 仍较 SDAR 在 ALFWorld 平均成功率上获 +5.5pp（89.8 → 95.3）。
- **算法开销极低**：相对 trust-only 仅有 0.4% 的端到端额外耗时，无新增前向。

## 七、优点

- **问题洞察清晰**：把"trust"与"utility"区分开，揭示了 OPSD 中被长期忽视的错配根源，并以具体数字（60.1% TCM）量化其严重性。
- **方法轻量优雅**：影响信号 $u_t=\hat{A}_t\rho_t\Delta_t$ 仅复用 RL 更新已有的量，完全回避 Hessian 求解；非对称 Laplace CDF 校准给出正仿射不变性，使分配在 batch/阶段间可比；精确轮次质量匹配保证辅助预算不变。
- **保守性设计**：对双负（$\hat{A}_t<0,\Delta_t<0$）信号回退到基线信任权重，避免局部符号错位带来的假支持。
- **匹配式实验**：matched comparison 把变量隔离到分配规则这一唯一维度，使差异归因明确。
- **机制可解释**：TCM 指标 + 梯度余弦兼容 + 置换对照三件套，从分配与几何两端验证收益来源。
- **跨模型/算法/任务可泛化**：Qwen2.5 全尺寸与 Qwen3 两族、GRPO 与 GiGPO、文本与搜索场景一致有效。
- **可插拔**：仅替换 $c_t$，不改变 RL surrogate，对已有 OPSD 代码库友好。

## 八、不足与局限

- **机制分析样本有限**：TCM 与梯度余弦分析仅在 4–16 个 batch 上估计，未给出 Search-QA、WebShop 等场景下的同类证据；缺少跨随机种子的统计不确定性。
- **算力信息不充分**：仅 Qwen2.5-1.5B WebShop 报告 4×H100；更大模型与更多基准的训练时长、总算力、能耗未披露，难以复现成本估算。
- **理论假设较强**：附录 B 的自然梯度解释依赖"token 分数在 Fisher 度量下互相独立、unclipped surrogate 局部激活"等理想化假设，并未证明这些假设在训练动态下成立。
- **clip 近似误差**：附录 C.2 显示 token 损失被裁剪时，$u_t$ 使用 unclipped surrogate 定义；虽然实证比例 <0.13%，但论文未提供在线校正方案。
- **未探索更广场景**：仅在 on-policy、单一 privileged self-teacher 设计下验证；未涵盖 off-policy、多教师、异构 skill source 等更复杂自蒸馏设定。
- **超参网格粗糙**：CDF 分割点、$\lambda$ 与回退阈值的扫描范围较窄（$\eta\in\{0.3,0.5,0.7\}$），未对最小校准组大小、尺度 floor $\varepsilon$ 做敏感性测试。
- **基线对齐偏差风险**：部分基线（如 Skill-GRPO\*）在测试时仍持有 privileged 上下文，与 ICSD 的"测试时零成本"设定不在同一条公平线上，需读者自行甄别。
- **长程任务的边界**：尽管 GiGPO 解决的是 step-aware 信用分配，但 ICSD 仍未对超长 horizon（如需要数十步工具调用）的轨迹级别效用做独立验证。
