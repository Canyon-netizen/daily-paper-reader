## 摘要
智能体强化学习使大语言模型智能体能够通过交互进行学习，但稀疏的轨迹级奖励只能揭示成功与否，却无法识别哪些中间决策值得归因。仅在训练阶段使用的特权技能可以通过让同一冻结策略快照对来自无技能轨迹的固定 token 进行重新评分（同时以任务匹配的程序性技能为条件），从而提供更密集的监督信号。然而，现有方法并未联合校准跨交互步骤的教师评分、将教师置信度与实际回报相关联，并将由此产生的信号整合到原生奖励到优势的构建中。我们提出了基于自蒸馏奖励塑形的智能体强化学习（ADRS），这是一个为多轮语言智能体构建与回报关联的 token 级信用分配框架。ADRS 在每个步骤内对特权 token 分数进行中心化和归一化处理，通过基于组内置信度–回报关联的、与回报相关的教师价值优势（TVA）门控机制对其进行调制，并将门控后的 token 信号整合到原生强化学习信用构建中。这些组件共同决定了教师偏好什么、该偏好何时与回报相关、以及它如何进入原生强化学习信用路径，同时保持 rollout 和推理过程无技能依赖。最后，在三个交互式基准测试上的实验表明，ADRS 在长视野任务上持续提升性能，且这些增益在不同强化学习骨干、减少数据设置、未见任务和延长训练情况下均得以保持。为匿名评审，代码可通过以下链接获取：https://github.com/gitrxh/ADRS-arxiv

## Abstract
Agentic reinforcement learning enables LLM agents to learn through interaction, but sparse trajectory-level rewards reveal success without identifying which intermediate decisions deserve credit. Training-only privileged skills can provide denser supervision by allowing the same frozen policy snapshot to rescore fixed tokens from skill-free trajectories while conditioned on task-matched procedural skills. Existing methods, however, do not jointly calibrate teacher scores across interaction steps, relate teacher confidence to realized returns, and integrate the resulting signal into native reward-to-advantage construction. We introduce Agentic Reinforcement Learning with Self-Distilled Reward Shaping (ADRS), a framework for constructing return-associated token-level credit for multi-turn language agents. ADRS centers and normalizes privileged token scores within each step, modulates them with a return-associated Teacher Value Advantage (TVA) gate based on within-group confidence--return association, and incorporates the gated token signal into native RL credit construction. Together, these components determine what the teacher prefers, when that preference is return-relevant, and how it enters the native reinforcement-learning credit path, while keeping rollouts and inference skill-free. Finally, experiments across three interactive benchmarks show that ADRS consistently improves performance on long-horizon tasks, with gains persisting across RL backbones, reduced-data settings, unseen tasks, and extended training. ## 1. 核心问题与研究动机

**问题背景**：在多轮语言智能体强化学习（Agentic RL）中，环境反馈通常仅为极其稀疏的轨迹级（trajectory-level）奖励——仅告知一段交互是否最终成功，而无法定位序列中**哪些中间决策**应当被归因。这一"信用分配难题"（temporal credit assignment）在 GRPO、GiGPO 等无价值网络、组相对的组内归一化方法下尤为突出，因为其优势估计仅依赖标量回报，无法区分 token 级贡献。

**现有方法的缺口**：研究人员尝试引入"特权技能"（task-matched procedural skills）作为训练阶段附加的密集监督信号。同一冻结的策略快照可以在技能上下文下对已经被采样的 token 重新打分，从而构造蒸馏信号。代表性方法包括 OPSD、GRPO+OPSD、Skill-SD、RLSD 与 SDAR 等。但这些工作存在三个相互割裂的问题：

1. **分数校准**：原始教师 log-prob 在不同交互步骤间偏移与尺度差异显著，无法跨步骤直接比较；
2. **可靠性估计**：教师高置信度未必对应更高回报，仅是"语言学熟悉度"；
3. **信用整合**：多数方法将特权监督作为额外辅助蒸馏损失置于原生 RL 信用路径**之外**，可能错配 token 更新与组相对优势。

**研究目标**：把训练阶段特权指导转化为与回报相关的 token 级信用分配，且**保持 rollout 与推理阶段完全无技能依赖**（skill-free）。

## 2. 方法论

ADRS 是一个处于轨迹采样与 actor 优化之间的"信用构造层"，由三个串联模块组成。

### 2.1 模块 1：步骤内相对特权打分（Within-Step Relative Privileged Scoring）

对每个已采样交互步骤 $s$，使用同一冻结参数 $\theta_b$ 计算普通上下文得分与特权技能上下文得分：
$$\ell^b_{s,j} = \text{sg}\!\left[\log \pi_{\theta_b}(y_{s,j}\mid h_s,y_{s,<j})\right],\quad \ell^T_{s,j} = \text{sg}\!\left[\log \pi_{\theta_b}(y_{s,j}\mid \rho(x)\oplus h_s,y_{s,<j})\right]$$

随后计算步骤内均值 $b_s$、中心化偏差 $q_{s,j}=\ell^T_{s,j}-b_s$，并除以同一步骤内的标准差 $\sigma_q$：
$$\hat q_{s,j}=\frac{q_{s,j}}{\sigma_q+\epsilon},\quad \sum_{j\in\mathcal V_s}\hat q_{s,j}=0$$

> 关键性质：$\hat q_{s,j}$ 是该步骤内部的**有符号、零和**的相对支持信号，$\hat q_{s,j}>0$ 表示该 token 获得特权评分高于本步骤平均。

### 2.2 模块 2：回报关联 TVA 可靠性门控

TVA（Teacher Value Advantage）在"组"层级对比特权置信度与回报。设组 $\mathcal U$ 的单位为轨迹（L2=GRPO 风格）或锚定步骤（L3=GiGPO 风格），计算：
$$\bar\ell^T_u=\frac{1}{|\mathcal V_u|}\sum_{(s,j)\in\mathcal V_u}\ell^T_{s,j},\quad \bar\ell^T_{\text{batch}}=\frac{1}{|\mathcal U|}\sum_{u\in\mathcal U}\bar\ell^T_u,\quad \alpha_u=\sigma(\bar\ell^T_u-\bar\ell^T_{\text{batch}})$$

定义高/低置信度侧的回报均值差：
$$d_g=\mu^+_g-\mu^-_g,\quad m_u=\text{sg}\!\left[\sigma(\tilde\tau\cdot d_{g(u)})\right]$$

> **命题 1（TVA 即回报关联）**：忽略数值稳定项 $\epsilon$，有 $d_g=\mathrm{Cov}_g(\alpha,R)/\bar\alpha_g(1-\bar\alpha_g)$，即 TVA 符号与组内"特权置信度–回报"经验协方差一致。

### 2.3 模块 3：教师引导的 per-token 优势调制（预优势奖励塑形）

构造教师 token 奖励与塑形奖励：
$$r^T_{s,j}=\eta\, m_{s,j}\,\hat q_{s,j},\quad \tilde r_{s,j}=r^{\text{base}}_{s,j}+r^T_{s,j}$$

随后形成两条互补路径：

- **轨迹路径**：$\tilde r$ 走原生 $A_{\text{traj}}=\text{Adv}_\mathcal{B(\tilde r)}$，由于步骤内 $\sum_j r^T_{s,j}=0$，轨迹优势方向与基线一致；
- **token 路径**：对 $r^T$ 按 prompt 组内做白化 $Z^T_t$，叠加到优势：

$$A^{\text{ADRS}}_{i,k,t}=A^{\text{traj}}_{i,k}+\eta Z^T_{i,k,t}$$

并以 PPO 风格裁剪目标进行更新：
$$\mathcal L_{\text{actor}}(\theta)=-\frac{1}{|\mathcal V|}\sum_{t\in\mathcal V}\min\!\left[\bar\omega_t(\theta)A^{\text{ADRS}}_t,\hat\omega_t(\theta)A^{\text{ADRS}}_t\right]$$

> **命题 2（步骤级零和表示）**：当门控与归一化分母在同一交互步共享时，$\sum_{j\in\mathcal V_s}r^T_{s,j}=0$，且该奖励可写为 $r^T_{s,j_r}=\Phi_{s,r+1}-\Phi_{s,r}$ 的链式差分形式。
> **命题 3（轨迹守恒与局部 token-梯度等价）**：在 $\theta_b$ 点、当裁剪未激活时，ADRS 更新与 $\Delta A_t=\eta Z^T_t$ 的辅助系数产生的局部策略梯度一致。

## 7. 优点

- **问题切分清晰**：将"特权信号引入 RL"分解为分数校准、可靠性估计、信用整合三个可独立量化的子问题；

- **保持 skill-free rollout/inference**：将训练特权压缩为 token 级奖励增量后回归到单一 RL 目标，对部署无副作用；
- **原生兼容 GRPO/GiGPO**：通过奖励塑形而非额外损失与多种无价值网络 backbone 直接组合；
- **实验充分且覆盖广**：跨 3 模型、3 基准、3 骨干、5 数据比例、3 交互上限、跨训练预算的密集验证，并提供 300 步轨迹可视化；
- **诊断性证据**：教师–学生 log-prob gap 分离动作/对象/风格 token，为 token 级信用分配的有效性提供机制层面证据；
- **代码公开**：`https://github.com/gitrxh/ADRS-arxiv` 便于复现。

## 8. 不足与局限

1. **算力披露不全**：仅写"multiple H100"，无 GPU 数量、单卡小时数、总训练时长与碳足迹估计，难以评估真实成本；
2. **Skill Provider 设计选择**：技能来自固定训练 split（成功/失败记忆各 223/196/200 条），依赖启发式的"环境级指南 + 任务匹配文件"，未做技能检索错误的鲁棒性消融；若 provider 错配技能，上下文门控机制是否仍稳健未深入分析；
3. **跨任务 / 跨域迁移有限**：仅在 ALFWorld 提供了 unseen split 结果；Search、WebShop 均未在未见任务上验证 token 级信号是否仍有效；
4. **Search 类提升边际**：步 150 最高仅 +0.4 宏平均 EM，说明在 4 步短视野的检索类任务上 token 级监督信息有限；
5. **附表出现的 Look 类负增益**：在 ALFWorld unseen split 上 Look 下降 4.4 个百分点，未给出失败模式分析；
6. **依赖参考策略与 KL/熵正则**：与 SDAR 共享相同的额外正则项，这些项对 token 级信号有效性的贡献未独立消融；
7. **理论等价的局部性**：命题 3 仅在 $\theta_b$ 点、未裁剪时成立，远离该点时 PPO 裁剪会破坏梯度等价，且未涵盖完整 PPO 多 epoch 更新情形；
8. **生态对比风险**：未与未列出但近期出现的同类方法（如 KDRL、Rebellious Student、CRAFT 等仅在相关工作提及）做直接对照，存在选择性报告偏差风险；
9. **隐私与安全约束缺失**：在 web/检索等开放环境中，特权技能若由不可信来源提供会带来提示注入风险，论文未讨论威胁模型与防御措施。
