## 摘要
通信受限的分布式多智能体系统中的协同任务调度具有挑战性，因为每个智能体必须在满足复杂实际约束的同时，基于部分且动态的观测做出决策。现有启发式方法依赖于手工设计的投标规则和重复共识，而许多基于学习的方法则假设全局观测可用，且缺乏基于显式通信的协调机制。为解决上述不足，本文提出了一种面向分布式多机器人任务分配（MRTA）的神经调度框架，包含多解码器图注意力模型（MDGAM）策略模型和无评论家的群组相对多智能体策略梯度（GRMAPG）训练算法。MDGAM采用扩展的图注意力机制联合更新节点和边特征，并利用多个解码器生成任务选择决策和通信消息。GRMAPG通过等价任务规划实例构建群组相对优势，以替代传统多智能体强化学习（MARL）算法中使用的评论家网络，从而降低训练难度并提升收敛性能。在不同问题规模和通信范围下的实验表明，所提方法在任务完成性能上优于现有启发式和基于学习的方法，消融实验、复杂度分析和泛化测试进一步验证了所提创新点的有效性。

## Abstract
Cooperative task scheduling in communication-constrained distributed multi-agent systems is challenging because each agent must make decisions from partial and dynamic observations while satisfying complex practical constraints. Existing heuristics rely on handcrafted bidding rules and repeated consensus, whereas many learning-based methods assume global observations and lack explicit communication-based coordination. To address these limitations, this paper proposes a neural scheduling framework for distributed multi-robot task allocation (MRTA), consisting of a multi-decoder graph attention model (MDGAM) policy model and a critic-free group relative multi-agent policy gradient (GRMAPG) training algorithm. MDGAM uses an extended graph attention mechanism to jointly update node and edge features, and employs multiple decoders to generate task-selection decisions and communication messages. GRMAPG constructs group-relative advantages from equivalent task-planning instances to replace the critic network used in conventional MARL algorithms, thereby reducing training difficulty and improving convergence performance. Experiments under different problem scales and communication ranges show that the proposed method improves task-completion performance over existing heuristic and learning-based methods, while ablation, complexity, and generalization tests further validate the proposed innovations.

- **启发式方法**（如 CBBA、PI-maxAss、EEPI）依赖手工投标规则，需重复共识/重规划，通信与计算开销大。

## 二、方法论

### 2.1 问题建模：Dec-POMDP

将分布式任务规划过程建模为去中心化部分可观测马尔可夫决策过程 $(\mathcal{S}, \{A_m\}, P, R, \{O_m\}, O, \gamma)$。集中式目标为：

$$\max_{\{\sigma_m\}_{m \in \mathcal{R}}} \sum_{m=1}^{M} |\sigma_m|$$

约束包括时间窗、能力、冲突避免、返回时间等。在分布式执行下，联合轨迹概率可分解为：

$$P_\theta(\sigma|g) = \prod_{m=1}^{M} \prod_{i=1}^{|\sigma_m|} P_\theta(a_m^i = \sigma_{m,i} | o_m^i)$$

决策采用**事件触发、异步进行**：智能体完成任务后才触发下一次决策，决策时收集当前通信连通分量内所有可达智能体的状态与已存消息。

### 2.2 MDGAM 策略模型

**架构**为编码器–多解码器结构：

**(a) 扩展图注意力机制**：包含三种串行的注意力操作
- 节点–节点注意力（Node-Node Attention）：$\hat{h}_i^\ell = \mathrm{MHA}(h_i^{\ell-1}, [h_1^{\ell-1}, \ldots, h_{N'}^{\ell-1}])$
- 边–节点注意力（Edge-Node Attention）：方向感知的位置编码 $\mathrm{PE}(\hat{h}_i^\ell, \hat{h}_j^\ell) = [\mathrm{Concat}(\hat{h}_i^\ell, -1), \mathrm{Concat}(\hat{h}_j^\ell, 1)]$ 用于区分有向边起点与终点
- 节点–边注意力（Node-Edge Attention）：$h_i^\ell = \mathrm{MHA}(\hat{h}_i^\ell, [e_{i,1}^\ell, \ldots, e_{i,N'}^\ell])$

实现节点与边表示的**双向信息交换**。

**(b) 编码器**：$L = 4$ 层，每层包含上述注意力模块 + 前馈模块（FF）+ 残差连接 + LayerNorm。初始嵌入维度 $d_m = 128$，多头数 8，每头维度 $d_q = d_k = d_v = 16$，FF 隐藏维度 $d_{ff} = 256$。

**(c) 多解码器**：
- **任务解码器**：$K_1 = 1$ 层，通过单头注意力打分，输出选择概率分布
$$u_j = \begin{cases} \alpha \cdot \tanh\left(\frac{q_c^T k_j}{\sqrt{d_m}}\right), & \text{若节点 } j \text{ 可行} \\ -\infty, & \text{否则} \end{cases}$$
训练时采样，测试时贪心。
- **通信解码器**：$K_2 = 1$ 层，输出连续消息向量 $c_m^i = W_{com} c^{K_2} + b_{com}$，维度 $d_{com} = 128$，供后续邻居决策使用。

### 2.3 GRMAPG 训练算法（无评论家）

**核心思想**：通过等价变换构造实例群组，以组内其他成员的奖励构造 leave-one-out 基线，避免训练评论家网络。

对每个实例 $g$ 构造群组 $G(g) = \{g^1, g^2, \ldots, g^K\}$（如坐标旋转、能力交换、时间参数缩放等对称变换），每个成员生成轨迹 $\sigma^k$，获得奖励 $R^k$：

$$b_k = \frac{1}{K-1} \sum_{j \neq k} R_j, \quad \hat{A}_k = R_k - b_k$$

由于 $b_k$ 与当前轨迹 $\sigma^k$ 条件独立（stop-gradient 处理），梯度估计保持无偏：

$$\nabla_\theta L(\theta|g) = \frac{1}{K} \sum_{k=1}^{K} \hat{A}_k \nabla_\theta \log P_\theta(\sigma^k | g^k)$$

**优势**：直接优化终局任务完成奖励；省去评论家网络，可训练参数减少；避免手工分解逐步奖励。
