## 摘要
我们提出了一种结构化大语言模型（LLM）架构，用于在具有私有目标视图的协作建造任务中实现零样本人机协调。在去中心化部分可观测马尔可夫决策过程（Dec-POMDP）框架的指导下，该架构将决策过程分解为：(i) 动作条件化的心智理论（ToM）推理；(ii) 分层规划；(iii) 对话解读；(iv) 动作验证；(v) 基于反馈的重新规划。我们将所提方法与一个不含 ToM 推理的消融版本以及一个在大量目标对上离线训练的多智能体强化学习策略进行了对比。在以人为参与者的实验中，所提方法相比两个基线方法均需要更少的交互步骤，并在交互后获得了更高的信任评分。这些结果表明，系统性地分解团队决策问题、将 LLM 作为原本难以处理的推理与规划计算的可处理替代手段，以及保留对物理可行性的传统验证，能够同时改善任务协作与人类体验。

## Abstract
We present a structured large-language-model (LLM) architecture for zero-shot human--robot coordination in a cooperative construction task with private goal views. Guided by a Dec-POMDP formulation, the architecture decomposes decision-making into (i) action-conditioned Theory-of-Mind (ToM) inference, (ii) hierarchical planning, (iii) conversation interpretation, (iv) action verification, and (v) feedback-based replanning. We compare the proposed method with an ablation without ToM inference and a multi-agent reinforcement-learning policy trained offline over many goal pairs. In human-participant experiments, the proposed method required fewer interaction steps and yielded higher post-interaction trust ratings than both baselines. These results suggest that systematically decomposing the team decision problem, using LLMs as tractable surrogates for otherwise intractable inference and planning computations, and retaining conventional verification for physical feasibility can improve both task coordination and the human experience.

## 一、核心问题与研究动机

在混合人机团队中，**自主系统往往以"团队成员"而非"孤立决策者"的身份运作**。人与机器人各自持有私有的目标、观测或偏好，信息呈现高度非对称。要实现有效协作，机器人必须：

- 从交互历史中推断对方的隐藏目标；
- 在必要时进行通信；
- 随新证据出现修订计划；
- 同时严格满足几何、动力学与资源约束。

理论上的标准框架是 **去中心化部分可观测马尔可夫决策过程（Dec-POMDP）**，但精确推理与规划在小规模问题之外便计算难解。LLM 的兴起提供了新机遇：以 LLM 作为难解推断/规划的**可处理代理（tractable surrogate）**，并保留传统验证模块保障物理可行性。

本文将该问题具象化为 **La Boca 协作建造任务**：人与机器人各自拥有目标结构的一个二维投影视图，需协作搭建同时满足两视图的三维结构，且为**零样本**协作（不依赖针对特定搭档的预训练）。

## 二、方法论：结构化 LLM 协调架构

### 2.1 Dec-POMDP 形式化

状态、观测与策略形式化为：

$$S_t = (x_t, g^H, g^R, \rho_t) \in \mathcal{S}$$

$$\mathcal{I}_t^H = (\mathcal{C}_t, g^H),\quad \mathcal{I}_t^R = (\mathcal{C}_t, g^R)$$

$$u_t^i = (a_t^i, m_t^i) \in \mathcal{U}^i,\quad u_t^i \sim \pi_t^i(\cdot \mid \mathcal{I}_t^i)$$

团队目标：

$$\max_{\pi^H,\pi^R} \mathbb{E}_\pi\!\left[\sum_{t=0}^{T-1} r_t(S_t, u_t^H, u_t^R) + r_T(S_T)\right]$$

物理可行性约束：

- 棋子可用：$p \in R_t$；
- 占据格在域内且不重叠：$\mathrm{Occ}(p,c,o) \subseteq \mathcal{W},\ O_t(q)=\varnothing$；
- 支撑约束：$\forall (x,y,z)\in \mathrm{Occ}(p,c,o),\ z>1$，都有 $(x,y,z-1)\in \mathrm{Occ}(p,c,o)\cup\{q\in \mathcal{W}:O_t(q)\neq\varnothing\}$。

机器人侧需维护对人类目标的近似信念：

$$b_t^H(g) = \Pr(g^H = g \mid \mathcal{C}_t, g^R)$$

并按贝叶斯规则更新：

$$b_{t+1}^H(g) = \frac{q_t^H(e_t^H \mid g, \mathcal{C}_t, g^R)\, b_t^H(g)}{\sum_{\bar g \in \mathcal{G}^H} q_t^H(e_t^H \mid \bar g, \mathcal{C}_t, g^R)\, b_t^H(\bar g)} \quad (1)$$

这要求一个目标条件化的人类响应模型 $q_t^H$。

### 2.2 整体架构（五个相互耦合的模块）

1. **层次化 LLM 任务规划器**（High-Level + Low-Level Planner）
2. **基于 LLM 的心智理论（ToM）推理模块**
3. **对话模块**（含语音识别、意图抽取、回复生成与 TTS）
4. **基于规则的物理可行性验证器**
5. **基于反馈的重规划器（Feedback-Based Replanner）**

显式的世界状态表示与结构化交互记录（含历史动作、子目标、验证反馈、对话抽取信息）作为模块间的共享上下文。

### 2.3 层次化规划

$$z_t = \mathrm{LLM}_{\text{high}}(\mathcal{K}_t),\quad \hat a_t^R = \mathrm{LLM}_{\text{low}}(\mathcal{K}_t, z_t)$$

- **High-Level**：输出 `intent`（当前步骤目标）、`subgoal`（自然语言描述的中间状态）、`rationale`（解释）；
- **Low-Level**：将子目标翻译为具体的 `(操作, 棋子, 锚格, 朝向)` 候选动作；
- 子目标作为持久目标，可在动作反复重规划时保留。

### 2.4 规则验证器

$$V(x_t, \hat a_t^R) = \begin{cases} (\text{valid}, \varnothing), & \hat a_t^R \in A_{\text{feas}}(x_t) \\ (\text{invalid}, e_t), & \text{otherwise} \end{cases}$$

检查项：棋子可用性、边界、格占用、结构支撑、操作合法性。验证只判断**物理可执行性**，不判断策略优劣。

### 2.5 反馈重规划

验证失败时，重规划器接收上下文 + 当前子目标 + 被拒动作 + 失败解释，修订操作/棋子/位置/朝向；再送验证。形成"生成—验证—修订"闭环，避免将物理不可执行动作下发到环境。

### 2.6 ToM 模块（动作条件化的逆规划）

对每个候选人类目标 $g \in \mathcal{G}^H$：

$$\hat a_t^H(g) = \mathrm{LLM}_{\text{act}}(x_t^H, g, h_t)$$

$$b_{q,t}^H(g) = \mathrm{LLM}_{\text{compare}}(h_t^H, \hat a_{0:t}^H(g))$$

比较**预测行为**与**实际观测行为**，输出兼容度以实例化式 (1) 中的 $q_t^H$，从而得到更新后的人类目标信念。

### 2.7 对话模块

- 麦克风录入 → `gpt-4o-mini-transcribe` 转写；
- `gpt-4.1-nano` 抽取意图并判断是否含显式装配建议，若是则转为 `(操作, 棋子, 坐标)` 的结构化表示；
- 机器人回复 → TTS；
- 支持澄清请求、动作解释、子目标沟通、协商与替代方案讨论。

## 六、主要结论与发现

1. **交互步数**：LLM+ToM（5.2） < LLM 消融（6.4） < RL（10.2，包含未完成轨迹）；
2. **任务完成**：LLM 类条件下全部 5 名被试均成功；RL 条件下仅 1 人完成，其余 4 人因行为难理解/不可信而中途终止；
3. **信任评分**：
   - 前测均分 68.6；
   - LLM+ToM 后测 84.9，LLM 后测 81.1，RL 后测降至 57.1；
4. **ToM 推理**：经两轮更新后，真实目标信念概率随步数上升，ToM 模块对意图追踪有效；
5. **方法论层面**：将 Dec-POMDP 系统化分解为五个功能模块，并以 LLM 替代难解推断/规划、保留规则验证，是兼顾**效率**与**可信度**的有效设计选择。

---

## 七、优点

- **理论与架构耦合紧密**：以 Dec-POMDP 为先验导出模块需求，再以 LLM 模块实现，形成"决策理论→架构→实现"的清晰链路；
- **五模块解耦且互补**：ToM 解决"对方在想什么"、层次规划解决"分步推理"、对话解决"自然语言落地"、验证解决"物理安全"、重规划解决"近似错误恢复"；
- **层次化规划 + 验证-重规划闭环**：避免 LLM 必须一次性给出完美物理动作，可渐进修正；
- **零样本能力**：不依赖特定搭档或任务对的训练，部署灵活；
- **多维度评估**：包含任务效率、人因信任（标准化量表）、ToM 信念演化三类指标；
- **消融 + 外部基线齐全**：含 ToM 消融与离线 RL 双基线对比；
- **双向语音交互**：在 LLM 推理架构上叠加真实 ASR/TTS 流水线，更贴近真实 HRI 场景。

## 八、不足与局限

1. **被试规模极小**（$n=5$），且为同质群体（研究生），缺乏统计检验，结论为**探索性**而非定论；
2. **目标对与场景多样性不足**：每个被试仅 1 个目标对，任务局限于 4×4×4 网格 + 9 个固定棋子；未测试更大规模或更复杂结构；
3. **ToM 评估粒度粗**：每 2 步更新一次，5 步内仅记录 3 个信念点，难以刻画精细推理轨迹；
4. **RL 基线对比不公**：训练阶段使用了中心化 critic 看到对方视图与目标，而执行中信息非对称；且 RL 轨迹混入"主动终止"的非完成回合，使均值解读需谨慎；
5. **LLM/RL 异构组合几乎全部失败**（LLM/RL 成功率 0%），提示 LLM 与 RL 策略的**互操作性**问题，但论文未深入分析；
6. **依赖 LLM 推理可靠性与提示工程**：未给出 prompt 细节、错误模式分析或失败案例，方法可复现性受影响；
7. **算力与训练成本未披露**：GPT-5.4 nano 选择背后的成本/延迟权衡、RL 训练时长、prompt token 消耗等均缺数据；
8. **物理可行性 ≠ 行为可解释**：即便动作合法，RL 仍被评价为"难理解/不可信"，说明**意图可读性**比单纯正确执行更影响人机信任，但论文未提供可读性分析或可解释性增强方案；
9. **未讨论安全与失败恢复**：人类中途终止 RL 条件时机器人如何应对、是否存在不可恢复错误状态，均未涉及；
10. **缺乏长期/跨任务泛化测试**：未评估同一被试多次重复、或更换任务后的表现稳定性。
