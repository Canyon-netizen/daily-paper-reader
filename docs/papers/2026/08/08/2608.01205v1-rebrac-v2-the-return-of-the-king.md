## Abstract
Recent offline reinforcement learning methods increasingly rely on expressive generative policies and specialized value-guidance mechanisms. We ask whether comparable progress can instead come from systematically modernizing a conventional behavior-regularized actor-critic while preserving its algorithmic simplicity. We introduce ReBRAC-v2, which directly trains an exact-likelihood normalizing flow as the RL actor, combines likelihood, MSE, and MAE behavior regularization, and integrates a classification-based residual critic, staged optimization, and multi-sample test-time action selection. Rather than tuning this recipe separately for every task, we develop a single shared configuration via roughly 600 Bayesian proposals on six challenging OGBench tasks, freeze all structural and optimization choices, and adapt only two behavior-regularization coefficients over a 16-point grid. Across ten common state-based OGBench categories, ReBRAC-v2 averages 74.8 compared to 52.3 for the next-best aggregate result and ranks first in eight categories. The same recipe, without structural changes, obtains the strongest averages in our comparisons on D4RL AntMaze (90.2) and Adroit (33.6). Fixed-recipe ablations show the largest sensitivity to the selected mixed cloning objective, staged training, sufficient flow capacity, and multi-sample inference, while showing that several smaller choices depend on the values of other hyperparameters. These results show that disciplined, transferable engineering can achieve state-of-the-art aggregate performance without abandoning a minimalist offline RL foundation.

## 二、方法论

### 2.1 整体框架
ReBRAC-v2 沿用 ReBRAC 的 Bellman 学习 + 行为正则化 actor-critic 结构，关键创新在于对 actor、critic、优化调度与推理流程的系统升级。

### 2.2 端到端精确似然归一化流 Actor

- **结构**：14 个 RealNVP 风格仿射耦合块 + PLU 维度混合（来自可逆 1×1 卷积）+ uniform base + 最终 $\tanh$ 变换。
- **特性**：通过可逆性同时获得**精确似然**与**单次采样**；同一组参数直接接收 critic 梯度与似然正则化梯度，无需分离迭代流匹配策略或蒸馏代理。
- **精确条件似然**：
$$\log \pi_\phi(a\mid s) = \log p_0\!\left(f_\phi^{-1}(a;s)\right) - \log \det \frac{\partial f_\phi(z;s)}{\partial z}$$

### 2.3 混合行为正则化目标

Actor 总损失：
$$L_{\text{actor}}(\phi) = -\lambda\,\mathbb{E}_{s\sim D}\!\left[Q_{\min}(s,\tilde{a})\right] + \mathbb{E}_{(s,a)\sim D}\!\left[L_{\text{BC}}(\phi;s,a)\right]$$

其中 $\lambda = \left(\mathbb{E}|Q_{\min}| + 10^{-6}\right)^{-1}$ 用于归一化 value 尺度。

混合 BC 项同时包含**精确似然**与**辅助 MSE + MAE 距离**：
$$L_{\text{BC}}(\phi;s,a) = -\alpha_{\text{NF}}\log \pi_\phi(a\mid s) + \alpha_{\text{aux}}\,\frac{1}{d_A}\!\left(\|\tilde{a}-a\|_2^2 + \|\tilde{a}-a\|_1\right)$$

- **NLL** 训练完整条件密度；
- **MSE** 强调大幅偏差；
- **MAE** 对非零残差保留恒定幅度修正。

### 2.4 分类式残差 Critic 集成

- **集成规模**：4 个 critic，采用**均值聚合**作为 Bellman 目标：
$$y = r + \gamma(1-d)\,\frac{1}{M}\sum_{m=1}^{M}\bar{Q}_m(s', a'), \quad M=4$$
- **参数化**：201 个 HL-Gauss 分类分箱预测 + 交叉熵损失；critic 目标**移除**了行为正则化项 ($\alpha_Q=0$)，精简接口。
- **结构**：5 层残差主干 + 独立的 value 头与 next-state 预测头；GSP 激活 $\sigma(x)=\text{GELU}(x)\bigl(1+0.5\,\text{sinc}(x)\bigr)$；辅助损失 $L_{\text{dyn}}=\|g_\psi(h_\theta(s,a))-s'\|_2^2$ 贯穿全程。
- **Q_min 分离**：训练用均值 Bellman 目标，策略改进与评估用 $\min_m Q_{\theta_m}$。

### 2.5 分阶段优化（总预算 100 万步）

1. **BC warm-up**：仅更新 actor，10 万步，使用 $L_{\text{BC}}$；
2. **Critic warm-up**：冻结 actor，仅更新 critic，20 万步；
3. **Joint RL**：交替更新 critic 与延迟 actor（actor 每 2 个 critic 步更新一次），70 万步。

Actor EMA（$\tau_{\text{EMA}}=0.005$）**仅用于评估**；critic 目标网络使用 current actor。

### 2.6 多采样测试时动作优化

推理时冻结网络参数，从 EMA actor 采样 $K=32$ 个候选动作，每个进行 $J=2$ 步 Q 梯度优化：
$$a_k^{(j+1)} = \Pi_A\!\left(a_k^{(j)} + \eta\,\frac{\nabla_a Q_{\min}(s,a)\big|_{a=a_k^{(j)}}}{\|\nabla_a Q_{\min}(s,a)\big|_{a=a_k^{(j)}}\|_2 + \epsilon}\right)$$

最终执行 $\arg\max_{a\in\{a_k^{(J)}\}_{k=1}^{K}} Q_{\min}(s,a)$；$\Pi_A$ 裁剪到合法动作范围。

- **Kron**（Kronecker-factored PSGD）为最终选择；
- 同时搜索了 AdamW 与 Adan；权重衰减、梯度噪声、dropout 在 actor 与 critic 上分别调优。

- **OGBench**：10 类平均 **74.8**（次优 DriftQL 为 52.3），8 类排名第一；
- **D4RL AntMaze**：**90.2**（最强均值），6 数据集中 3 项第一，与 FAC 在 Large Diverse 持平；
- **D4RL Adroit**：**33.6**（最强均值），在 Pen Human/Cloned、Door Cloned、Relocate Cloned 上大幅领先；
- 在 HumanoidMaze Large（72.2 vs GFP 14.9）、Puzzle 4×4（52.2 vs GFP 30.5）等长视野/组合任务上提升尤为显著；
- 在 30 任务 NF-RLBC 子集上：ReBRAC-v2 90.1 vs NF-RLBC 61.2 vs FAC 74.2。

### 6.2 消融核心结论（6 任务平均）
| 替换项 | 平均降幅 |
|---|---|
| min target aggregation | −93.5% |
| w/o 辅助 BC (MSE+MAE) | −88.4% |
| AdamW 替代 Kron | −65.2% |
| 仅有 MAE 辅助 | −22.9% |
| 仅有 MSE 辅助 | −18.8% |
| w/o NF 似然 BC | −15.3% |
| w/o 两阶段 warm-up | −13.9% |
| w/o critic warm-up | −9.6% |

**最敏感因素**：混合克隆目标（似然 + MSE + MAE）、分阶段训练、足够的流容量（≥8 层）、多采样推理。

**较小效应**：集成规模（4 vs 2，−4.7%）、激活函数（GSP vs ReLU，−3.5%）、残差连接（−5.1%）、正则化整体（合并后仅 −1.0%）等。

### 6.3 Flow 容量与推理
- 深度 < 8 时性能急剧下降，8–18 层趋于平稳；
- 采样数从 1 → 8 平均提升 14.1%，32 时相近，64 略降；
- Q 精炼：单样本下提升 7.6%；与采样叠加效应非单调且任务依赖。

### 6.4 失败案例
- **Cube Double**：8.3，低于原 ReBRAC（12.2）甚至远低于 GFP（40.1），且为开发任务之一，**无确切解释**，作者将其归因于"待研究的 critic 设计问题"。

## 七、优点

- **极简接口**：仅暴露 4×4 = 16 个配置、2 个正则化系数的适配界面，远少于 GFP（25/4/6 + 多重结构选择）、FAC（12/6/24 + 密度阈值）、DriftQL（64/10/20 + 核函数）；
- **架构上不引入额外机制**：仍是单一 actor + 单一 critic ensemble，**没有第二个策略、没有流匹配蒸馏代理**；
- **精确似然 vs. 迭代流匹配**：避免数值积分和蒸馏损失，提供精确对数似然；
- **扎实的工程整合**：混合克隆目标 + 分类式残差 critic + 分阶段训练 + 多采样推理形成有机耦合；
- **详尽的消融与协议透明**：明确分离"开发"与"适配"，公开贝叶斯搜索域、选定超参、所有任务的均值与标准差；
- **可复现性强**：固定最终 checkpoint 评估、公开代码、明确 commit 与种子策略；
- **跨基准迁移**：单一共享方案在 OGBench（4 类未参与开发）、D4RL AntMaze、Adroit 均达 SOTA。

## 八、不足与局限

- **后选择偏差**：开发集使用 1 种子、6 任务、共 ~600 贝叶斯提案，存在选择过拟合风险；
- **环境返回值辅助的模型选择**：系数调优依赖环境奖励（即便策略优化仍是纯离线）；
- **Cube Double 失败无解**：作者明确承认"无确切解释"，仅指出 critic 设计为待研究方向；
- **单种子开发 vs. 多种子**：6 任务的 1-种子开发分数本身方差较大，可能放大固定方案消融的"敏感性"信号；

## 八、不足与局限（续）

- **未涉及像素观测、offline-to-online 调优、多模态/混合质量数据、长视频演示、真实世界机器人数据等场景**，所有结论局限于基于状态的 gym/mujoco 风格模拟环境；
- **依赖大规模贝叶斯开发**：~576 提案、~3,456 单任务运行需要相当算力，普通研究者难以负担，方法的"易用性"在算力受限场景下未必成立；
- **缺乏理论分析**：作者未对 critic warm-up、混合 BC 项、分阶段调度的收敛性或稳定性提供形式化解释，所有结论均依赖经验证据；
- **固定方案迁移假设过强**：作者声称单一共享方案可跨基准迁移，但仍需在每个类别/数据集重新调整 $(\alpha_{\text{NF}}, \alpha_{\text{aux}})$，且调整依赖环境奖励，"真正零适配"并未实现；
- **EMA 仅用于评估的潜在不一致**：训练用 current actor 提供 Q 目标、评估用 EMA actor，可能导致训练-评估分布不匹配，尽管作者在表 10 中给出鲁棒性证据；
- **消融粒度有限**：单因子替换未联合重新搜索超参，部分效应可能被高估或低估；
- **资源声明不完整**：正文未给出总墙钟时间、GPU 数量或碳排放等可量化的资源消耗指标。

## 九、总结与启示

- **研究范式层面**：ReBRAC-v2 展示了"工程化系统整合"在离线 RL 中仍具强大生命力——通过对 actor-critic 五大子系统（生成式 actor、critic、目标函数、训练调度、推理流程）的协同调优，可在不引入流匹配蒸馏、双策略或复杂引导模块的前提下达到 SOTA。
- **方法论层面**：
  1. **精确似然归一化流**比迭代流匹配更适合与 critic 端到端耦合；
  2. **混合克隆目标（似然 + MSE + MAE）**比单一 NLL 更稳健；
  3. **均值集成 + min 取动作**在均值化目标下显著优于 min 集成；
  4. **分阶段训练（BC → Critic → Joint）**仍是工程上稳定 RL 训练的关键；
  5. **测试时多采样 + Q 精炼**为生成式 actor 提供了"低成本"的最后性能提升。
- **实践启示**：对离线 RL 研究者而言，"少即多"——精心设计的极简接口（4×4 系数网格）相比结构繁复的混合方案反而更具可复现性与可迁移性。
- **争议点**：作者对生成式方法额外机制的批评（如流匹配蒸馏），部分被自身使用的"多采样 + Q 精炼"以另一种形式"补偿"——本质上仍依赖 critic 引导下的额外推理时计算，但避免了训练阶段的额外网络。
- **后续研究方向**：作者明确指出的开放问题包括 Cube Double 失败的 critic 设计根源、像素观测下的扩展、与 model-based RL 的结合，以及如何降低对大规模贝叶斯搜索的依赖。
