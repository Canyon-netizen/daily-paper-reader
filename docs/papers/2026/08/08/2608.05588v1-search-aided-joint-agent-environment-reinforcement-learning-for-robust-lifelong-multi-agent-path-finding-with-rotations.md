## 摘要
终生多智能体路径规划（LMAPF）要求为持续接收新目标的智能体反复规划无碰撞路径，每当智能体到达当前目标后即会被赋予新目标。尽管已有许多基于学习的LMAPF规划器被提出，但其中大多数依赖于过度简化的运动学假设，可能忽略对现实应用性能至关重要的运动约束。在本文中，我们研究了一种源自众多实际自动化仓储系统的更现实的LMAPF模型，称为LMAPF-R2，其包含鲁棒安全性约束和原地旋转约束。这些约束大幅增加了协调难度，尤其是在高密度受限空间中。为应对这些挑战，我们提出了搜索辅助联合强化学习（SJRL）。我们首先使用因果PIBT（一种基于搜索的单步规划器）来增强神经策略，以解决智能体之间的碰撞并传播其意图。随后，我们引入一种统一的强化学习框架，联合优化智能体策略与环境策略，其中环境策略学习图边权重，通过反向Dijkstra搜索提供全局移动引导。实验表明，在多个高密度地图上，SJRL相较于强大的基于搜索的规划器因果PIBT取得了显著提升。我们进一步在一个具有挑战性的混合现实仓储环境中验证了SJRL，该环境包含8台物理机器人和248个虚拟机器人。

## Abstract
Lifelong Multi-Agent Path Finding (LMAPF) requires repeatedly planning collision-free paths for agents that continuously receive new goals upon reaching their current ones. While many learning-based planners have been proposed for LMAPF, most rely on oversimplified kinematic assumptions that may overlook motion constraints critical to real-world performance. In this work, we study a more realistic LMAPF model derived from many real-world automated warehouse systems, termed LMAPF-R2, which incorporates robust safety constraints and in-place rotation constraints. These constraints substantially increase coordination difficulty, particularly in highly constrained spaces. To address these challenges, we propose Search-Aided Joint Reinforcement Learning (SJRL). We first augment neural policies with Causal PIBT, a single-step search-based planner that resolves agents' collisions and propagates their intentions. We then introduce a unified RL formulation that jointly optimizes agent and environment policies, where the environment policy learns graph edge costs to provide global movement guidance via backward Dijkstra search. Experiments demonstrate that SJRL achieves significant improvements over the strong search-based planner, Causal-PIBT, across multiple high-density maps. We further validate SJRL in a challenging mixed-reality warehouse environment with 8 physical robots and 248 virtual robots.

## 1. 核心问题与研究动机

- **问题背景**：终生多智能体路径规划（LMAPF）要求在共享图上为多智能体持续规划无碰撞路径，目标为最大化系统吞吐量（单位时间步到达目标的平均次数），广泛应用于自动化仓储（如 Amazon、Ocado）等场景。
- **现有方法的建模缺陷**：从 PRIMAL、PRIMAL_2 到 SILLM、MAPF-GPT、HMAGAT 等先进学习型 LMAPF 规划器，几乎全部采用"标准模型"——智能体在一个离散时间步内可直接移动到相邻顶点。该假设过度简化，忽略了真实机器人系统所需的关键运动学约束，导致**规划与执行之间的建模鸿沟**。
- **本文提出的 LMAPF-R2 模型**：在 4 邻居网格图上加入两类约束：
  - **鲁棒安全约束（R1）**：禁止"跟随冲突"（即后车在前车离开的下一刻立即进入其顶点），等价于 $k=1$ 的 $k$-robust MAPF；
  - **原地旋转约束（R2）**：每个智能体有方向 $\text{orientation}\in\{\text{East, South, West, North}\}$，到达相邻顶点需 1–3 个时间步（旋转 + 等待）。
- **新增的协调难度**：鲁棒约束要求智能体占用更多顶点作为安全缓冲，旋转约束使到达邻接顶点需要更多时间步，两者共同导致环境更拥挤、更易出现死锁与活锁，对学习型规划器尤其具有挑战性。

## 2. 方法论

### 2.1 核心思想
SJRL 基于两个关键设计原则：
1. **搜索与学习的优势互补**：用单步搜索式规划器（Causal PIBT 变体）解决神经策略输出的碰撞并传播意图；
2. **联合优化智能体与环境策略**：智能体策略负责局部反应式协调，环境策略学习图边代价，通过反向 Dijkstra 生成全局启发式引导。

### 2.2 MDP 建模
- **环境策略**：在 $t=0$ 时刻采样边代价 $\{c_e\}_{e\in E}$，并对所有"顶点-方向"状态对做反向 Dijkstra，得到最小代价距离 $h(s,g)$；
- **智能体策略**：在自由（IDLE）状态时采样下一顶点作为**子目标** $sg$，随后变为忙碌（BUSY）状态，贪心地朝子目标执行旋转、等待或前进动作；
- **奖励设计**：
  - 智能体每步动作 $-1$；
  - 到达决策点时获得进度奖励 $\mathrm{dist}(s_{\text{prev}},g)-\mathrm{dist}(s_{\text{curr}},g)$；
  - 团队奖励为 $5\times5$ 邻域内所有智能体平均奖励；
  - 环境策略的奖励为所有智能体奖励之和。

### 2.3 智能体策略学习
- 继承 SILLM 的 CNN + 通信模块 + MLP 架构，输入包含障碍物、优先级（高/低/无三值）、繁忙/空闲状态、**四通道方向启发式特征图**；
- **新增两条跳跃连接（skip connections）**：将候选下一顶点的启发式距离直接拼接到 CNN 输出与通信模块输出后，强化环境策略对智能体决策的影响；
- **策略层级化**：神经策略预测下一顶点作为子目标，而非原始动作。这显著缓解了长走廊中多智能体随机探索的对齐困难；
- **同步 Causal PIBT 作为碰撞屏蔽**：
  - 仅 IDLE 智能体参与联合决策，BUSY 智能体的当前顶点与子目标均视为障碍；
  - 禁止循环移动（避免执行时的死锁）；
  - 通过深度优先搜索 + 优先级继承形成"链式推挤" $a_1\to a_2\to\cdots\to a_k$，将 $a_1$ 的意图沿链传播；
  - 仅在最终贪心动作选择阶段严格执行鲁棒约束，以最大化意图传播效果；
  - 训练与推理均使用，PPO 直接优化（无需修正策略梯度）；
- 伪代码见原文 Algorithm 1 与 Algorithm 2。

### 2.4 环境策略学习
- 一个 5 层 $3\times 3$ CNN（padding=1），输入为障碍物二值图 + 已有规划器（Causal PIBT 或 warm-up 智能体策略）模拟产生的顶点访问频率与边遍历频率；
- 每条边输出高斯分布的均值与方差（共 10 个通道，对应 5 条出边的 cost 与 wait），无效边被 mask；
- 使用 $\arctan$ + 线性变换将 cost 映射到 $[1,10]$，可通过偏置初始化均值（例如 0 偏置对应 5.5）；
- 推理时直接用均值，无需采样；
- 将每条边视为共享同一奖励的"虚拟智能体"，用 MAPPO 训练。

### 2.5 联合训练流程
- **预热阶段**：以均匀边代价 $c_e=5.5$ 训练智能体策略 16 轮，每轮 64 次仿真，避免早期随机探索的高方差干扰环境策略；
- **联合训练阶段**：智能体与环境策略同步训练 128 轮，每轮 128 次仿真；
- 推理时环境策略只需为每张地图**预计算一次**边代价与启发式距离，时间复杂度可控。

- **物理-虚拟混合验证**（Table 2）：在 8 台真机 + 248 虚拟机器人的混合现实仓储中，SJRL 吞吐 $1.01\pm0.07$，优于 SERL（$0.84$）、SARL（$0.87$）和 NORL（$0.72$）。

## 7. 优点

- **率先系统性研究 LMAPF-R2 设定**，呼吁学习型 LMAPF 研究在建模层面也要追赶搜索式方法的现实性；
- **搜索与学习的紧耦合**：Causal PIBT 同时在训练与推理中作为碰撞屏蔽，并被形式化为环境的一部分，使 PPO 不需做梯度修正；
- **意图传播机制巧妙**：通过优先级继承 + DFS，把高层意图沿链式推挤扩散，显著改善长走廊中的多智能体探索；
- **联合 RL 框架新颖**：将每条边视作共享同一回报的"虚拟智能体"，统一了智能体与环境的训练目标；
- **跳跃连接设计有针对性**：直接把启发式信息注入决策层，强化环境策略对智能体行为的引导；
- **从仿真到真机**：在混合现实仓储中验证了方法落地可行性；
- **代码与配置公开**（论文声称随源代码发布）。

## 8. 不足与局限

- **建模差异导致对比不完全公平**：SoTA 方法仍用标准模型 + ADG 执行层适配，而非真正的 LMAPF-R2 模型，作者坦承将其适配至 LMAPF-R2 需要"非平凡修改"且可能带来性能下降，因此将 IL 方法的 LMAPF-R2 适配列为未来工作；
- **依赖专家先验**：在窄巷道地图上，Causal PIBT、SARL、SJRL 均显著受益于专家设计的边代价初始化；SJRL 从零训练未能追上带专家初始化的版本，说明 PPO 的局部优化可能陷入次优局部极值，作者明确指出需要"更有效的联合学习优化范式"；
- **跨地图泛化未验证**：与 SILLM、MAGAT+ 等一样，按地图训练与评估，未报告跨地图或跨布局的迁移性能；
- **固定地图上的边代价**：环境策略对每张地图需离线预计算一次，未探索在线更新（如周期性地随流量变化更新），作者将其留给未来工作；
- **通信与表征改进空间**：SJRL 直接沿用 SILLM 的通信模块，作者承认对 LMAPF-R2 及更复杂运动学下的通信机制研究尚未深入；
- **真机规模有限**：物理实验仅 8 台真机 + 248 虚拟机器人，结论的统计强度受限于真机数量；
- **算力披露不完整**：未给出总算力消耗、训练样本总数、收敛曲线等可复现细节；
- **行为多样性**：策略层级化（预测子目标）虽利于探索，但也可能限制策略在更复杂长视野任务中的灵活性。
