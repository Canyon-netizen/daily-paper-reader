## 摘要
大语言模型智能体在复杂交互任务中展现出了强大的潜力，但其强化学习（RL）常受到稀疏奖励的制约，因为一条多轮轨迹可能仅获得单一的结果级信号。在策略自蒸馏（OPSD）通过特权教师模型提供稠密的 token 级监督，但教师模型在每个位置上未必都可靠。现有方法通常依赖孤立的 token 级差异，可能对噪声敏感，或者分配一个共享的 step 级权重，可能忽略位置间的差异性。我们提出了持续一致性自蒸馏（PCSD），通过教师偏好信号的局部持续性来推导 token 级的蒸馏权重。PCSD 将自适应窗口与指数衰减聚合相结合，以捕捉教师持续的相对支持，并应用趋势感知调制来衰减局部下降的支持，最后通过 sigmoid 门控生成连续权重。该目标函数与 GRPO 联合优化，将稠密的教师引导与稀疏的环境反馈相结合。在无需推理时技能的情况下，PCSD 在两种骨干网络上均取得了 ALFWorld Overall 上所有基线方法中的最优结果，相较 GRPO 分别提升 15.6 和 13.3 分，相较 SDAR 分别提升 6.2 和 5.5 分，同时在 WebShop 上保持竞争力，并在未见过的 ALFWorld 划分上相较 GRPO 提升 15.8 分。

## Abstract
Large language model agents have shown strong potential in complex interactive tasks, yet their reinforcement learning (RL) is often hindered by sparse rewards, as a long multi-turn trajectory may receive only a single outcome-level signal. On-policy self-distillation (OPSD) provides dense token-level supervision from a privileged teacher, but the teacher may not be reliable at every position. Existing methods commonly rely on isolated token-level discrepancies, which can be sensitive to noise, or assign a shared step-level weight that may overlook positional variation. We propose Persistent Consistency Self-Distillation (PCSD), which derives token-level distillation weights from the local persistence of teacher-favoring signals. PCSD combines adaptive windows with exponentially decayed aggregation to capture persistent relative teacher support, applies trend-aware modulation to attenuate locally declining support, and produces continuous weights through sigmoid gating. The resulting objective is jointly optimized with GRPO, combining dense teacher guidance with sparse environmental feedback. Without inference-time skills, PCSD achieves the best ALFWorld Overall results among all baselines on both backbones, exceeding GRPO by 15.6 and 13.3 points and SDAR by 6.2 and 5.5 points, while remaining competitive on WebShop and gaining 15.8 points over GRPO on unseen ALFWorld split.

### 1.1 研究背景
- 大语言模型（LLM）智能体在多轮交互式任务（如具身操作、网页浏览、电商购物）中展现出强大能力，但其强化学习（RL）面临**稀疏奖励**的根本性挑战：一条跨越数十轮、数百 token 的轨迹通常只能获得一个最终结果级（success/failure）信号。
- **GRPO** 等无评论家方法利用分组相对奖励改善可扩展性，但本质仍是轨迹级粗粒度监督，难以准确归因中间动作或 token 的贡献。

### 1.2 现有方法及其局限
- **在策略自蒸馏（OPSD）** 使用特权教师（frozen privileged-context teacher，本质为同一基座检查点的冻结副本，仅额外注入检索到的技能）为策略采样轨迹提供稠密 token 级监督，缓解稀疏性问题。
- 但特权教师并非在每个 token 位置都可靠（检索噪声、上下文歧义等），无差别蒸馏会传播错误偏好。
- 现有可信度感知蒸馏存在两种范式之间的**根本权衡**：
  - **Token 级方法**（RLSD、SDAR 等）：基于孤立 token 差异或概率比估计可靠性，对采样波动敏感——单点大差异可能源于瞬时噪声而非真实优势。
  - **Step 级方法**（SOD、StepOPSD 等）：对整步内所有 token 分配共享权重，鲁棒但粗粒度，无法刻画位置间的可信度差异。

### 1.3 核心洞察
- 有信息量的教师优势应当**在局部邻域内持续存在**；而孤立尖峰更可能反映采样噪声或偶发波动。
- 因此应同时利用**点差异**与**邻域支持的持续性**，兼顾 token 级精度与局部聚合的鲁棒性。

## 2. 方法论

### 2.1 总体框架
PCSD 在 GRPO 基础上引入**辅助的自蒸馏目标**，通过三个互补机制将 token 级教师–学生 log 概率差转化为**连续 token 级蒸馏权重**，再与 GRPO 目标联合优化。

### 2.2 预备：教师–学生对数概率差
对第 $k$ 轮响应中第 $i$ 个 token，定义：

$$\delta_{k,i} = \log \pi_T(y_{k,i} \mid h^T_{k,i}) - \log \pi_\theta(y_{k,i} \mid h^S_{k,i})$$

其中 $h^S_{k,i}$ 为学生可见上下文，$h^T_{k,i}$ 额外注入任务相关技能。$\delta_{k,i}$ 越大表示教师对被采样 token 的**相对支持**越强。

### 2.3 持续一致性估计（持久性评估）
对位置 $i$ 在大小为 $N$ 的前向窗口内做**指数衰减加权聚合**：

$$\bar{\delta}^{(N)}_{k,i} = \frac{\sum_{j=0}^{N-1} \alpha^{j} m_{k,i+j}\, \delta_{k,i+j}}{\sum_{j=0}^{N-1} \alpha^{j} m_{k,i+j}}$$

其中 $\alpha \in (0,1)$ 为衰减因子，$m_{k,i}$ 为响应掩码。位置越近权重越大，但局部邻域信息仍被纳入。响应末尾的窗口自然截断，只对有效 token 归一化。

### 2.4 自适应聚合机制
单一固定窗口难以应对异质差异模式。设局部均值与方差为：

$$\mu^{(N_{\max})}_{k,i} = \frac{\sum_j m_{k,i+j}\, \delta_{k,i+j}}{\sum_j m_{k,i+j}},\quad \sigma^2_{k,i} = \frac{\sum_j m_{k,i+j}(\delta_{k,i+j} - \mu^{(N_{\max})}_{k,i})^2}{\sum_j m_{k,i+j}}$$

将方差映射为**归一化插值系数**：

$$r_{k,i} = \mathrm{clip}\!\left(\frac{\sigma^2_{k,i} - \tau_{\text{low}}}{\tau_{\text{high}} - \tau_{\text{low}}},\ 0,\ 1\right)$$

据此在短窗口 $N_{\min}$ 与长窗口 $N_{\max}$ 间做**连续插值**：

$$\bar{\delta}^{\text{ad}}_{k,i} = (1 - r_{k,i})\, \bar{\delta}^{(N_{\min})}_{k,i} + r_{k,i}\, \bar{\delta}^{(N_{\max})}_{k,i}$$

- 方差低于 $\tau_{\text{low}}$：退化为短窗口估计，保留 token 级细节；
- 方差高于 $\tau_{\text{high}}$：退化为长窗口估计，加强平滑；
- 中间区域连续插值，避免硬切换。

### 2.5 趋势调制与连续门控
指数衰减对**附近位置加权更重**，但当前高 gap 紧接快速衰减时仍可能主导局部估计。为此引入**单向趋势调制**：

$$s_{k,i} = \frac{\sum_j m_{k,i+j}(j - \bar{j}_{k,i})\,\delta_{k,i+j}}{\sum_j m_{k,i+j}(j - \bar{j}_{k,i})^2 + \epsilon_{\text{slope}}}$$

并按响应级平均绝对 gap 归一化：

$$\delta_{\text{scale},k} = \frac{\sum_i m_{k,i}|\delta_{k,i}|}{\sum_i m_{k,i}} + \epsilon_{\text{scale}}$$

趋势因子仅对**负斜率**（教师支持下降）施加衰减：

$$\eta_{k,i} = \mathrm{clip}\!\left(1 - \gamma\cdot \mathrm{ReLU}\!\left(\frac{-s_{k,i}}{\delta_{\text{scale},k}}\right),\ 0,\ 1\right)$$

最终 token 级蒸馏权重通过 **sigmoid 门控**生成：

$$w_{k,i} = \sigma\!\left(\beta_{\text{gate}} \cdot \bar{\delta}^{\text{ad}}_{k,i}\right) \cdot \eta_{k,i}$$

- $\sigma(\cdot)$ 将持续一致性估计单调映射到 $[0,1]$ 的权重；
- $\eta_{k,i}$ 对局部下降支持做有界衰减，不放大；
- $\beta_{\text{gate}}$ 控制门控锐度。

### 2.6 训练目标
设 $M = \sum_{k,i} m_{k,i}$ 为总有效 token 数，PCSD 蒸馏损失为：

$$\mathcal{L}_{\text{PCSD}} = \frac{1}{M}\sum_{k,i} m_{k,i}\, w_{k,i}\, \delta_{k,i}$$

教师 log 概率与 $w_{k,i}$ 在优化时**分离**（detached），因此该损失在学生采样 token 上产生**加权负对数似然梯度**。最终目标与 GRPO 联合优化：

$$\mathcal{L}_{\text{total}} = \mathcal{L}_{\text{GRPO}} + \lambda_{\text{PCSD}}\mathcal{L}_{\text{PCSD}}$$

其中 $\mathcal{L}_{\text{GRPO}}$ 使用组内归一化优势 $\hat{A}_g = (R_g - \mu_R)/(\sigma_R + \epsilon)$、截断策略比与相对参考策略的 KL 正则。

## 3. 实验设计

### 3.1 基准测试
- **ALFWorld**（文本具身 AI，6 类任务）：Pick、Look、Clean、Heat、Cool、Pick2，采用 GiGPO 数据划分（valid_seen / valid_unseen）。
- **WebShop**（电商代理）：1,000 训练任务，128 固定验证实例。

### 3.2 评估指标
- ALFWorld：分类别成功率与 Overall 成功率（$\text{SR} = 100 \cdot \frac{1}{N}\sum_n \text{won}_n$）。
- WebShop：归一化 Score（产品–规格匹配度）与严格 Acc（$q_n=1$ 比例）。

### 3.3 对比基线
- 无技能：**Vanilla、GRPO**；
- 推理时技能：*\* 标记的 **Skill-Prompt**、**Skill-GRPO\***；
- 自蒸馏：**OPSD、GRPO+OPSD、RLSD、SDAR**；
- 训练时检索技能（KM 策略）：**Skill-SD** 等。

### 3.4 实现细节
- 骨干网络：**Qwen2.5-3B-Instruct** 与 **Qwen3-1.7B-Instruct**；
- 训练：AdamW，学习率 $1\times10^{-6}$，梯度裁剪阈值 1.0，**150 个更新步**；
- ALFWorld 批大小：16 任务 × 8 rollout = 128；最大 prompt 长度 2,048；
- WebShop 同样 16×8 rollout，最大 prompt 长度 4,096；
- PCSD 超参：$N_{\min}=1$，$N_{\max}=8$，$\alpha=0.8$，$\tau_{\text{low}}=0.05$，$\tau_{\text{high}}=0.5$，$\gamma=0.3$，$\beta_{\text{gate}}=5.0$，$\lambda_{\text{PCSD}}=0.01$。

### 5.2 客观性与公平性

- SDAR 依据原文方法在共享设定下重新实现；
- 同一骨干下所有方法超参与硬件一致；
- PCSD 在两骨干 + 两基准上均报告完整类别分解，避免聚合指标掩盖差异。

## 6. 主要结论与发现

### 6.1 主结果
- ALFWorld Overall 上 PCSD 在两骨干均达到**最优**：Qwen2.5-3B 为 **90.6%**（超 GRPO +15.6、超 SDAR +6.2）；Qwen3-1.7B 为 **59.4%**（超 GRPO +13.3、超 SDAR +5.5）；
- WebShop：Qwen2.5-3B 上 PCSD Score **85.0**（最高），两骨干 Acc 与 SDAR 并列最高；Qwen3-1.7B Score **78.9** 居第二；
- **未见泛化**：ALFWorld valid_unseen Overall PCSD **86.7%**，显著高于 GRPO 70.9% 与 SDAR 72.7%。

### 6.2 训练动态
- 教师–学生 gap 均值随训练逐步上升（从约 $-0.20$ 至 $-0.07$），表明学生 token 越来越受教师支持；
- 20%–28% 的有效 token 满足 $w_{k,i}>0.5$，蒸馏是**聚焦而非硬选择**的。

### 6.3 消融
- 任一组件缺失（固定窗口、去趋势调制、去指数衰减）均导致 Overall 性能下降，验证三者互补；
- $\lambda_{\text{PCSD}}$ 呈非单调：$0.01$ 最佳，过大（0.05）削弱 GRPO 主导，过小（0.005）监督不足，无蒸馏（0）仅 75.0%。

### 6.4 诊断分析
- **权重鲁棒性**：在 1%/5%/10% 隔离 gap 扰动下，PCSD 的 token 权重排序 Spearman 相关性均不低于 SDAR，扰动越大优势越明显（10% 时 0.887 vs 0.864）；
- **教师质量对齐**：在去技能与 shuffled 技能两种扰动下，PCSD 的 $\Delta Q$–$\Delta W$ 相关性为弱非负（$\rho=0.174$、$0.052$），而 SDAR 呈负相关（$\rho=-0.489$、$-0.208$），表明 PCSD 避免了归一化加权引入的负向耦合。

## 7. 优点

- **问题刻画精准**：明确指出 token 级与 step 级蒸馏的精度–鲁棒性权衡，并以"持续性"作为统一信号，概念清晰；
- **机制设计完整且互补**：指数衰减聚合提供局部平滑，自适应窗口根据方差连续插值，单向趋势调制仅衰减不放大，sigmoid 门控输出连续权重——三者在功能上互不重叠；
- **教师构造严谨**：特权教师冻结、与参考策略分离、技能仅来自任务级先验且不接触验证集，确保评估反映学生内化能力而非推理时依赖；
- **实验充分且公平**：2 骨干 × 2 基准 × 多基线（含重实现 SDAR），消融+敏感性+动态+诊断多角度验证，配对控制变量清晰；
- **泛化性强**：无需推理时技能即可在 unseen split 大幅超越基线，实用价值高；
- **理论分析补充**：附录给出 bias–variance 分解、有效样本量 $N_{\text{eff}}\approx6.41$、加权位移 $\approx2.39$，对方法行为给出可解释的量化刻画。

## 8. 不足与局限

- **基准覆盖有限**：仅在 ALFWorld 与 WebShop 两个文本代理环境验证，未涵盖代码生成、GUI 操作、检索增强生成等其它长程 agentic 任务，结论的跨域泛化尚需更多证据；
- **基线范围**：未与最新的更复杂方法（如 SEED、MAD-OPD、OPID、TCOD 等）逐一对比，论文在 Related Work 中提及但未纳入实验；
- **超参固定**：所有 PCSD 超参在两骨干两基准上**保持不变**（无任务级调优），虽然展示出鲁棒性，但也意味着可能未达最佳；
- **自适应范围受限**：自适应窗口仅在 $N_{\min}=1$ 与 $N_{\max}=8$ 间插值，对极长/极短响应或技能显著相关的极端场景可能不充分；

## 8. 不足与局限（续）

- **缺乏收敛性保证**：附录的 bias–variance 分析为局部估计器性质，并未给出 PCSD 目标在 GRPO 联合优化下的整体收敛性证明；权重 $w_{k,i}$ 与策略分布通过梯度耦合，存在反馈环路，理论分析较为困难；
- **门控激活率偏低**：仅 20%–28% 的 token 获得 $w_{k,i}>0.5$，大量 token 实际受到弱监督，蒸馏信号的利用率仍有提升空间；
- **教师特权信息仅限技能检索**：特权教师仅通过注入技能获得额外上下文，未涵盖真实环境反馈、状态价值等更丰富信号，与"特权教师"在经典 RL 文献中的设定存在差距；
- **诊断指标的统计强度有限**：$\Delta Q$–$\Delta W$ 相关性基于文档级（query-level）样本量，弱相关（$\rho\approx 0.05$–$0.17$）是否具有统计显著性、是否随样本量提升而稳定，仍需更大规模验证；
- **复现门槛**：涉及 8×A100、千级 token 长度轨迹、150 步 RL 训练以及特权教师前向，完整复现需较多算力与工程实现细节（如技能检索库构造、专家轨迹格式、prompt 模板等），论文未公开全部代码细节；
- **缺少人类或更大模型评估**：所有结果均为自动成功率/Score 指标，未提供人工评估或 GPT-4 等级评分作为补充。

## 9. 理论分析要点

- **Bias–Variance 分解**：将 $\bar{\delta}^{(N)}_{k,i}$ 视为对潜在"教师优势信号" $d_i$ 的局部估计，得到
$$\mathbb{E}[(\bar{\delta}^{(N)}_{k,i}-d_i)^2] = \underbrace{B^2(N,i)}_{\text{近似偏差}} + \underbrace{V(N,i)}_{\text{采样方差}}$$
  指数衰减聚合在不显著增大偏差的前提下降低了方差，体现"局部聚合即正则"的直觉。
- **有效样本量**：在不同任务上实测 $N_{\text{eff}}\approx 6.41$，说明约 6 个相邻 token 即可支撑一次稳定估计，过大的窗口反而引入不必要的偏差。
- **加权位移**：相对原始 $\delta_{k,i}$ 的加权位移约为 2.39 个 token，远小于典型 step 长度，证明窗口化不会破坏 token 级精度。
- **理论局限性**：上述分析建立在教师信号在窗口内近似平稳的假设之上；自适应窗口虽缓解该假设，但未给出对非平稳信号的最坏情况界。

## 10. 结论与未来工作

### 10.1 论文结论
- 提出 **PCSD（Persistent Consistency Self-Distillation）**，通过**局部邻域持续性**统一 token 级与 step 级蒸馏的精度–鲁棒性权衡；
- 引入**自适应窗口聚合 + 单向趋势调制 + sigmoid 门控**三机制，将教师–学生 log 概率差转化为连续、聚焦的 token 级蒸馏权重；
- 在 ALFWorld、WebShop 上使用 Qwen2.5-3B / Qwen3-1.7B 两骨干全面超越 OPSD、RLSD、SDAR 等基线，并在 unseen split 上展现强泛化；
- 诊断实验表明 PCSD 权重对扰动更鲁棒、与教师质量保持弱正相关，避免了 SDAR 式归一化加权带来的负向耦合。

### 10.2 未来工作方向
- 将持续一致性信号推广到**多模态 agent**（含图像、GUI 操作）以及**代码生成**等更长程任务；
- 探索**特权教师的更丰富定义**（如引入真实环境反馈、过程奖励模型、检索增强文档）以提升教师信号质量；
- 研究**权重 $w_{k,i}$ 与策略梯度之间的去耦机制**，避免反馈环路并提供收敛性保证；
- 将 PCSD 与**过程奖励模型（PRM）**或**评论家**结合，进一步提升稀疏奖励环境下的样本效率；
- 在更大规模 LLM（7B/13B+）与更多基准上验证方法的可扩展性。

## 11. 总体评价

PCSD 针对 LLM 智能体 RL 中的稀疏奖励与自蒸馏可靠性问题，提出了一种**概念清晰、机制互补、工程可落地**的持续一致性加权方案。其核心贡献——以"局部持续性"作为教师可靠性的代理信号——既具直觉合理性，又通过自适应窗口、趋势调制、sigmoid 门控实现了细致的工程化。实验在两骨干、两基准上系统验证了有效性、泛化性与鲁棒性，诊断分析也直接回应了"权重是否合理"这一关键质疑。

主要局限在于基准与基线覆盖仍不够广、理论分析停留在局部估计器层面、且对教师特权信息的定义相对狭窄。整体而言，PCSD 为 agentic RL 中的自蒸馏提供了一个**值得借鉴的加权范式**，并为后续研究（更丰富教师、更长程任务、收敛性分析）留下了明确空间。
