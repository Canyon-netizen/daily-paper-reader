## 摘要
智能体强化学习使大语言模型（LLM）智能体能够通过交互进行学习，但稀疏的轨迹级奖励仅揭示了成功与否，而无法识别哪些中间决策应获得信用。仅在训练阶段使用的特权技能可以提供更密集的监督：冻结的同一策略快照在以任务匹配的流程性技能为条件的前提下，对无技能轨迹中的固定token进行重新评分。然而，现有方法无法同时完成以下三件事：在交互步骤间联合校准教师分数、将教师置信度与实际收益相关联，并将所得信号整合到原生奖励到优势的构建中。我们提出了基于自蒸馏奖励塑形的智能体强化学习（ADRS），这是一个面向多轮语言智能体构建与收益关联的token级信用的框架。ADRS在每个步骤内对特权token分数进行中心化和归一化，通过基于组内置信度-收益关联的、与收益关联的教师价值优势（TVA）门控对其进行调节，并将经门控的token信号融入原生强化学习信用构建中。这些组件共同决定了教师偏好什么、该偏好何时与收益相关，以及它如何进入原生强化学习信用路径，同时保持 rollout 和推理过程无技能依赖。最后，在三个交互式基准上的实验表明，ADRS 在长视野任务上持续提升性能，其增益在不同的 RL 骨干、减少数据场景、未知任务以及延长训练中均得以保持。为匿名评审，代码已在以下链接公开：https://github.com/gitrxh/ADRS-arxiv

## Abstract
Agentic reinforcement learning enables LLM agents to learn through interaction, but sparse trajectory-level rewards reveal success without identifying which intermediate decisions deserve credit. Training-only privileged skills can provide denser supervision by allowing the same frozen policy snapshot to rescore fixed tokens from skill-free trajectories while conditioned on task-matched procedural skills. Existing methods, however, do not jointly calibrate teacher scores across interaction steps, relate teacher confidence to realized returns, and integrate the resulting signal into native reward-to-advantage construction. We introduce Agentic Reinforcement Learning with Self-Distilled Reward Shaping (ADRS), a framework for constructing return-associated token-level credit for multi-turn language agents. ADRS centers and normalizes privileged token scores within each step, modulates them with a return-associated Teacher Value Advantage (TVA) gate based on within-group confidence--return association, and incorporates the gated token signal into native RL credit construction. Together, these components determine what the teacher prefers, when that preference is return-relevant, and how it enters the native reinforcement-learning credit path, while keeping rollouts and inference skill-free. Finally, experiments across three interactive benchmarks show that ADRS consistently improves performance on long-horizon tasks, with gains persisting across RL backbones, reduced-data settings, unseen tasks, and extended training. For anonymous review, our code is available at the following the link: https://github.com/gitrxh/ADRS-arxiv

  2. **可靠性估计（Reliability Estimation）**：高教师置信度未必反映对任务有用的指导；可能偏爱语言上熟悉但与实际收益无关的决策。

## 2. 方法论：ADRS 框架

ADRS 是一个**信用构建层**，位于轨迹采集与策略更新之间，由三个并行/耦合的模块组成，分别回答"教师偏好什么"、"何时与收益相关"、"如何进入原生信用通路"。

### 2.1 流程概览

- 行为策略 $\pi_{\theta_b}$ 在**无技能**条件下采样 $K$ 条轨迹，并接收环境反馈。
- 同一冻结快照在**特权技能上下文** $\rho(x) \oplus h_s$ 下，对已固定 token 进行重评分。
- 三模块输出整合后进入原生 GRPO/GiGPO 优势估计，再执行 PPO 风格裁剪更新。

### 2.2 模块 1：步内相对特权评分（Within-Step Relative Privileged Scoring）

- 冻结行为策略 $\theta_b$ 计算同一 token 在普通上下文与特权上下文下的对数概率：
$$\ell^b_{s,j} = \mathrm{sg}\!\left[\log \pi_{\theta_b}(y_{s,j}\mid h_s, y_{s,<j})\right], \quad \ell^T_{s,j} = \mathrm{sg}\!\left[\log \pi_{\theta_b}(y_{s,j}\mid \rho(x)\oplus h_s, y_{s,<j})\right]$$
- 步内中心化与归一化：
$$b_s = \frac{1}{|\mathcal{V}_s|}\sum_{j\in\mathcal{V}_s} \ell^T_{s,j}, \quad q_{s,j} = \ell^T_{s,j} - b_s$$
$$\sigma_q = \mathrm{Std}_{(s',j')\in\mathcal{N}(s)}(q_{s',j'}), \quad \hat{q}_{s,j} = \frac{q_{s,j}}{\sigma_q + \epsilon}$$
- 关键性质：在步内求和为零（$\sum_{j\in\mathcal{V}_s}\hat{q}_{s,j}=0$），消除步间整体置信度漂移。

### 2.3 模块 2：与收益关联的 TVA 门控（Return-Associated TVA Reliability Gate）

- **L2（完成级）**：与 GRPO 对齐，以同 prompt 的完整轨迹作为比较单元；**L3（步级）**：与 GiGPO 对齐，以重复锚点状态作为单元。运行时选择一种粒度。
- 单元置信度与软高置信度权重：
$$\bar{\ell}^T_u = \frac{1}{|\mathcal{V}_u|}\sum_{(s,j)\in\mathcal{V}_u}\ell^T_{s,j}, \quad \bar{\ell}^T_{\mathrm{batch}} = \frac{1}{|\mathcal{U}|}\sum_{u\in\mathcal{U}}\bar{\ell}^T_u, \quad \alpha_u = \sigma\!\left(\bar{\ell}^T_u - \bar{\ell}^T_{\mathrm{batch}}\right)$$
- 高/低置信度侧的收益对比：
$$\mu^+_g = \frac{\sum_{u\in g}\alpha_u R_u}{\sum_{u\in g}\alpha_u + \epsilon}, \quad \mu^-_g = \frac{\sum_{u\in g}(1-\alpha_u)R_u}{\sum_{u\in g}(1-\alpha_u) + \epsilon}, \quad d_g = \mu^+_g - \mu^-_g$$
- 门控：$m_u = \mathrm{sg}\!\left[\sigma(\tau \tilde{d}_g^{(u)})\right]$，对组内 token 广播。
- **命题 1**（门控即收益关联）：$d_g$ 的符号与组内 $(\alpha, R)$ 的经验协方差一致，即 $d_g = \dfrac{\mathrm{Cov}_g(\alpha, R)}{\bar{\alpha}_g(1-\bar{\alpha}_g)}$。

### 2.4 模块 3：教师引导的逐 token 优势调制（Teacher-Guided Per-Token Advantage Modulation）

- 教师 token 奖励与塑形奖励：
$$r^T_{s,j} = \eta\, m_{s,j}\, \hat{q}_{s,j}, \quad \tilde{r}_{s,j} = r^{\mathrm{base}}_{s,j} + r^T_{s,j}$$
- **轨迹路径**：在步内 $r^T$ 求和为零的前提下，$\tilde{r}$ 的轨迹得分等于基础奖励的轨迹得分；GRPO/GiGPO 据此得到 $A^{\mathrm{traj}}_{i,k}$，保留环境定义的方向。
- **token 路径**：在 prompt 组 $g$ 内对 $r^T$ 做白化：
$$\mu^T_g = \mathrm{Mean}_{v\in\mathcal{V}_g}(r^T_v), \quad (\sigma^T_g)^2 = \mathrm{Var}_{v\in\mathcal{V}_g}(r^T_v), \quad Z^T_t = \frac{r^T_t - \mu^T_g}{\sqrt{(\sigma^T_g)^2 + \epsilon}}$$
- **单次合并**（pre-advantage shaping）：
$$A^{\mathrm{ADRS}}_{i,k,t} = A^{\mathrm{traj}}_{i,k} + \eta Z^T_{i,k,t}$$
- 策略目标（PPO 风格裁剪）：
$$\mathcal{L}_{\mathrm{actor}}(\theta) = -\frac{1}{|\mathcal{V}|}\sum_{t\in\mathcal{V}} \min\!\left[\omega_t(\theta)\, A^{\mathrm{ADRS}}_t,\ \bar{\omega}_t(\theta)\, A^{\mathrm{ADRS}}_t\right]$$
其中 $\omega_t(\theta) = \exp(\log\pi_\theta(y_t|c_t) - \ell^b_t)$，$\bar{\omega}_t$ 为裁剪版本。
- **命题 2**（逐步零和表示）：在步内共享门控下，$\sum_{j\in\mathcal{V}_s} r^T_{s,j}=0$，可写为采样链上的势差形式 $r^T_{s,j_r} = \Phi_{s,r+1} - \Phi_{s,r}$，且 $\Phi_{s,1}=\Phi_{s,n_s+1}=0$。
- **命题 3**（轨迹保持与局部 token 梯度等价）：轨迹得分在 $r^{\mathrm{base}}$ 下不变；$\eta=0$ 时退化为原生算法；在行为策略点且裁剪不激活时，ADRS 的逐 token 局部梯度与 $a_t = \Delta A_t$ 的辅助目标梯度相同。

- **跨模型与规模一致**：Qwen2.5-7B 上 ALFWorld 达 96.1%（+7.8），Qwen3-1.7B 上 ALFWorld 62.5%、Search 42.9%、WebShop 77.7/65.6（+8.6 / +0.7 / +7.0）。
- **长训练稳定**：ALFWorld 上 ADRS-global+entropy/clip 达 97.7% peak / 96.1% final；GiGPO 骨干下 ADRS+TVA 在 300 步 final/last-3 为 94.5%/94.3%。WebShop 上 ADRS-per-seq 达 84.4% peak。
- **GiGPO 上仍有效**：中心化 ADRS 将 GiGPO 从 82.8% 提升至 87.5%，+TVA 后达 89.8%；在 300 步 last-3 上再 +2.4。
- **数据效率**：使用 60% 训练数据即超过全量 GRPO（75.0%），80% 与 100% 进一步提升至 80.5% / 94.5%。
- **未见任务迁移**：ALFWorld unseen split 上 6 类中 5 类正增益，平均 +11.9，其中 Cool +22.8、Pick2 +18.1、Heat +12.9。
- **最大步长鲁棒**：在 25/35/50 步预算下，ADRS 相比 SDAR 提升 +6.3 / +10.2 / +10.1。
- **机制证据**：Action–Object 诊断显示在 step 150 处 action 间隙 $-0.858$、object 间隙 $+0.459$、style 间隙仅 $0.0085$，action-to-other 比率从初始化 1.6 升至 95.3，说明 token 级调制集中于任务相关决策。
- **优化动态**：ALFWorld 上 ADRS 到达 70% 成功率约需 70 步，而 SDAR 约需 130 步（约 1.9× 加速）。

## 7. 优点

- **概念上的三重统一**：将"教师偏好"、"何时与收益相关"、"如何进入原生信用通路"系统化，命题 1/2/3 给出统计/代数/局部梯度三重刻画。
- **保持 rollout 与推理无技能**：特权技能仅用于 post-rollout 重评分，无需在部署阶段提供技能提示。
- **原生 RL 兼容性**：单次合并在 token 级的 $\eta Z^T$ 调制不替换组内优势构造，与 GRPO/GiGPO 的轨迹/步级分支直接兼容；$\eta=0$ 时严格退化为原生算法。
- **零和结构保护轨迹方向**：步内 $\sum r^T=0$ 保持 GRPO 轨迹得分不变，理论证明 + 经验验证（动作/对象/风格 token 间隙随训练显著分化）。
- **跨骨干/数据/任务/视野一致增益**：实验设计相对系统，证明增益并非来自特定超参或环境。
- **训练动态与机制诊断**：固定轨迹的 token 间隙分析为"长视野收益来自 token 级信用重分配"提供直接证据。

## 8. 不足与局限

- **算力披露不全**：未给出具体 GPU 数量、训练时长、能耗，难以评估方法的实际部署成本。
- **对特权技能质量的依赖**：ADRS 假设存在"任务匹配"的流程性技能 $\rho(x)$；若技能来源质量差、与任务不匹配，TVA 门控虽会下调权重，但理论上的"逐步零和"在门控非常数时不严格成立（论文明确该结构仅在 step-shared 门控下成立），可能引入教师偏差。

## 8. 不足与局限（续）

- **稀疏设置下未充分覆盖**：论文主要聚焦于具备 1–50 步交互的中等视野任务，并未在**超稀疏、超长视野**（如百步以上的具身导航）或多回合对话任务上验证 ADRS 的稳定性；当轨迹内有效决策极少时，步内中心化可能因有效 token 集合太小而出现归一化不稳定。
- **技能依赖的循环性**：流程性技能 $\rho(x)$ 的生成质量直接影响教师信号。若技能来自更强模型或人工标注，则方法本质上是**特权蒸馏**而非纯 RL；论文未给出当技能来源与策略同源或弱于策略时的退化曲线。
- **计算开销**：每步 token 需要在特权上下文中**两次前向**（普通 + 特权）以计算 $\ell^b$ 与 $\ell^T$，相比 GRPO 翻倍；TVA 门控还需单元级统计与收益聚合，整体 rollout-后处理时间显著增加。
- **白化与门控的方差敏感性**：$\sigma^T_g$ 在 prompt 组内方差较小时会放大噪声；GateNorm 虽缓解，但论文未给出在方差极小情形下的截断策略。
- **未与其他信用分配方法联合**：未与 hindsight credit assignment、counterfactual baseline、或基于 value function 的方法（如 GiGPO-L2 变体中的 L2 单元优势）做正交组合实验。
- **搜索 QA 的子集协议差异**：Search-R1 协议下各数据集的检索语料与工具接口存在版本差异，与同期其他工作（如 ReSearch、ZeroSearch）对比时需对齐。

## 9. 启示与展望

- **对 RL-based 智能体的方法论启示**：在缺乏稠密奖励时，**特权自蒸馏不必作为独立目标**，而应通过势差/白化结构并入原生优势通路，避免与组内相对优势竞争；步内零和是保证轨迹方向不被偏移的最小约束。
- **对技能设计的启示**：技能的作用窗口是**训练期**而非推理期，因此可优先考虑**生成成本低、任务对齐度高**的技能源，无需担心部署时的额外提示开销。
- **可拓展方向**：
  - 将 TVA 门控从二元软门控推广到**连续可靠度估计**（如基于教师自一致性的不确定性）；
  - 探索**多教师**（不同技能模板）下的稳健组合；
  - 与**过程奖励模型（PRM）**或**基于价值的 critic** 正交结合，形成 token-step-trajectory 三级信用；
  - 在**多智能体**或**工具调用密集型**场景中验证 ADRS 的适配性；
  - 将 $\eta Z^T$ 调制推广到**策略外**（off-policy）的信用构建。

## 10. 总体评价

ADRS 提出了一种**保持推理无技能、将训练期特权信号并入原生 RL 信用通路**的通用方法，以"步内零和 + TVA 门控 + 逐 token 白化调制"三重机制解决了特权自蒸馏中长期存在的**分数校准、可靠性估计、信用整合**三大问题。理论层面，命题 1（门控即收益关联）、命题 2（逐步零和势差表示）与命题 3（轨迹保持 + 局部梯度等价）共同保证了方法在 GRPO/GiGPO 上的严格兼容性；实验层面，跨 3 个模型 × 3 个基准（具身、网页、搜索）× 11 个对比方法的系统验证表明，ADRS 在固定 150 步、扩展 300 步、最大步长、数据效率、未见任务、骨干选择等维度均稳定优于现有特权蒸馏与组内相对 RL 基线。Action–Object token 间隙的机制诊断进一步为"长视野收益来自 token 级信用重分配"提供了直接证据。主要局限在于算力披露不全、对特权技能质量的依赖、超参逐环境调优，以及在超稀疏/超长视野任务上的验证空白。整体而言，ADRS 是当前 LLM 智能体 RL 中**特权自蒸馏与原生信用分配耦合**方向的代表性工作，对后续过程级监督与组内相对优势的统一具有方法论参考价值。
