## Abstract
Cooperative task scheduling in communication-constrained distributed multi-agent systems is challenging because each agent must make decisions from partial and dynamic observations while satisfying complex practical constraints. Existing heuristics rely on handcrafted bidding rules and repeated consensus, whereas many learning-based methods assume global observations and lack explicit communication-based coordination. To address these limitations, this paper proposes a neural scheduling framework for distributed multi-robot task allocation (MRTA), consisting of a multi-decoder graph attention model (MDGAM) policy model and a critic-free group relative multi-agent policy gradient (GRMAPG) training algorithm. MDGAM uses an extended graph attention mechanism to jointly update node and edge features, and employs multiple decoders to generate task-selection decisions and communication messages. GRMAPG constructs group-relative advantages from equivalent task-planning instances to replace the critic network used in conventional MARL algorithms, thereby reducing training difficulty and improving convergence performance. Experiments under different problem scales and communication ranges show that the proposed method improves task-completion performance over existing heuristic and learning-based methods, while ablation, complexity, and generalization tests further validate the proposed innovations.

- **任务时间窗约束** $t_n \le t^{arr}_{m,i} \le \bar{t}_n$（到达时间需落在开放窗口内）；
- **任务类型能力约束** $\kappa_{\sigma_{m,i}} \in K_m$（任务必须由具备对应能力的智能体完成）；
- **冲突避免约束** $\sigma_m \cap \sigma_{m'} = \emptyset$；
- **返回时间约束** $t^{dep}_{m,|\sigma_m|} + d(\sigma_{m,|\sigma_m|}, p^0_m)/v_m \le T_r$；
- **有限通信半径** $r$：仅距离不超过 $r$ 的智能体可直接通信，导致时变且可能出现多个不相连分量的通信拓扑。

整体优化目标为最大化总完成任务数：

$$\max_{\{\sigma_m\}_{m \in R}} \sum_{m=1}^{M} |\sigma_m| \quad \text{s.t. } \text{(3b)}-\text{(3e)}$$

作者将分布式决策过程建模为 **Dec-POMDP**，定义为元组 $(S, \{A_m\}, P, R, \{O_m\}, O, \gamma)$，决策事件由事件触发而非同步时钟驱动，呈现**异步、事件驱动**特性。作者指出，已有方法的两类局限：(1) 启发式方法如 CBBA、PI-maxAss、EEPI、GPI 依赖**手工投标/性能影响函数**，且需要反复 replanning，开销显著；(2) 学习方法如 MAPDP、DL-DRL、CAM 多假设**全局观测**或不显式建模通信拓扑，难以直接适用于通信受限且拓扑分量的场景。

## 2. 方法论

### 2.1 整体框架

提出**神经调度框架**，由两部分组成：

1. **MDGAM（Multi-Decoder Graph Attention Model）**：策略模型，负责将图结构局部观测编码为节点/边嵌入，并联合产出任务选择决策与通信消息。
2. **GRMAPG（Group Relative Multi-Agent Policy Gradient）**：无 critic 的训练算法，直接优化终局奖励（任务完成数）。

### 2.2 扩展图注意力机制（Extended Graph Attention）

基本算子仍是 MHA：

$$\text{MHA}(X,Y,Z) = W^O \cdot \text{Concat}(H_1, \ldots, H_h), \quad H_i = \text{Attention}(X^TW^Q_i, Y^TW^K_i, Z^TW^V_i)$$
$$\text{Attention}(Q,K,V) = \text{softmax}\!\left(\frac{QK^T}{\sqrt{d_k}}\right)V$$

针对**节点-边联合表征**需求，作者设计了三个注意力子步骤（$\ell$ 层）：
- **Node-Node Attention**：聚合所有可观测节点信息：
  $$\hat{h}^\ell_i = \text{MHA}\!\big(h^{\ell-1}_i, [h^{\ell-1}_1, \ldots, h^{\ell-1}_{N'}]\big)$$
- **Edge-Node Attention**：用入射节点更新边表征，引入**方向感知位置编码** $PE(\hat{h}^\ell_i, \hat{h}^\ell_j) = [\text{Concat}(\hat{h}^\ell_i, -1), \text{Concat}(\hat{h}^\ell_j, 1)]$：
  $$\tilde{e}^\ell_{i,j} = \text{MHA}\!\big(e^{\ell-1}_{i,j}, PE(\hat{h}^\ell_i, \hat{h}^\ell_j)\big) + e^{\ell-1}_{i,j}$$
- **Node-Edge Attention**：将更新过的边信息回传至节点：
  $$\tilde{h}^\ell_i = \text{MHA}\!\big(\hat{h}^\ell_i, [\tilde{e}^\ell_{i,1}, \ldots, \tilde{e}^\ell_{i,N'}]\big) + \hat{h}^\ell_i$$

每个 Encoder 层均含 **残差连接**与**层归一化**，共堆叠 $L$ 层，输出 $\{h^L_i\}$。该机制使 MDGAM 能同时精细化**节点状态**与**非对称成对关系**（如时间窗匹配、通信链路）。

### 2.3 解码器（多输出）

- **任务解码器**（Task Decoder，$K_1$ 层）：以当前决策上下文 $h^0_c$（由当前 agent 编码初始化）为查询，输出候选节点选择概率：

$$u_j = \begin{cases} \alpha \cdot \tanh\!\left(\dfrac{q_c^T k_j}{\sqrt{d_m}}\right), & \text{节点 } j \text{ 可行} \\ -\infty, & \text{否则} \end{cases}$$
$$P_\theta(a^i_m = j \mid o^i_m) = \text{softmax}_j(u_1, \ldots, u_{N'})$$

- **通信解码器**（Communication Decoder，$K_2$ 层）：结构类似但输出**连续消息向量** $c^i_m = W_{com}\, c^{K_2} + b_{com}$，供后续可达 agent 在构造局部观测时使用。

### 2.4 GRMAPG 训练算法

针对终局奖励延迟问题，作者设计**无 critic** 的策略梯度优化器。核心思路：对原始实例 $g$ 通过**等价变换**（坐标旋转、任务类型与能力配对交换、时空参数同步缩放、采样对称性等）构造群 $G(g) = \{g^1, \ldots, g^K\}$，由同一策略 $P_\theta$ 分别求解并得到各成员终局奖励 $R_k$。

构建 **leave-one-out 基线**与**组相对优势**：

$$b_k = \frac{1}{K-1}\sum_{j=1, j\ne k}^{K} R_j, \quad \hat{A}_k = R_k - b_k$$

梯度估计器为：

$$\nabla_\theta L(\theta \mid g) = \frac{1}{K}\sum_{k=1}^{K} \hat{A}_k \nabla_\theta \log P_\theta(\sigma_k \mid g_k)$$

作者证明，因 $b_k$ 与 $\sigma_k$ 条件独立（其他群成员轨迹 $\sigma_{-k}$ 独立采样且取 stop-gradient），引入基线不改变期望梯度，是**无偏估计**。算法 1 给出了完整的 Batch 训练流程。优化目标对照式 (7) 为：

$$\max_\theta \mathbb{E}_{g \sim P(g),\, \sigma \sim P_\theta(\sigma \mid g)} [R(\sigma, g)]$$

相比 MAPPO/MAA2C 等 actor-critic 方法，GRMAPG **无需辅助 critic 网络**，避免了分步奖励设计困难与价值估计偏差，并减少了可训练参数。

**公平性方面**：所有学习基线的模型规模、超参与本文尽量保持一致；MAPPO/MAA2C 与 GRMAPG 共用相同的实例分布、batch、epoch、learning rate，并通过 $K=4$ 的群构造做数据增广；为 actor-critic 提供与本文 actor 同结构的**注意力中心化 critic**。从这一角度看，训练算法消融的对比是公平的；但 PI 类方法的运行环境（CPU）与本文（GPU）存在**硬件差异**，文中已说明。

## 6. 主要结论

- **主性能**：所提方法在全部 9 组设置上均取得最高平均完成任务数。在 $r=0.4$ 下相对 PI-maxAss 提升 2.24% / 4.13% / 5.94%（小/中/大规模），相对 CAM 提升 2.86% / 3.74% / 5.06%；即使在严格通信 $r=0.2$ 下仍保持最优；
- **复杂度**：在大规模设置下，推理约 1.9 秒/实例，比 PI-maxAss 快约 **95 倍**，比 EEPI 快约 **5.7 倍**；通信消息数从 5272/3905 降至 2149（vs PI-maxAss/EEPI）；
- **消融**：
  - MDGAM 优于 AM、GCN 及其无通信解码器的变体，证实边感知机制 + 多解码器设计的有效性；
  - GRMAPG 在收敛速度与最终性能上同时优于 MAPPO 和 MAA2C；
- **泛化**：对任务数变化最鲁棒（最大性能差 ≤ 0.7%）；当 agent 数差异 ≤ 2 时性能下降 < 1%；通信半径从极端（0.2/0.6）迁移至中间值出现较明显退化，但中间范围训练的模型可兼容更广设置。

## 7. 优点

- **架构层面**：把"任务决策"与"通信消息"统一在一个多解码器图注意力模型中，且通过 **Node-Node / Edge-Node / Node-Edge** 三个注意力步骤实现节点-边双向信息交换，使策略对**非对称、非欧氏关系**（如时间窗差、方向通信链路）敏感；
- **训练层面**：GRMAPG 利用**问题对称性 + 解对称性**作为隐式监督信号，避免了 actor-critic 训练中对 step-wise 奖励设计与价值近似的依赖，参数更少、收敛更稳；
- **系统层面**：通信消息维度可调、兼容异构 agent、能直接处理通信图不相连分量，与真实部署契合；
- **评测层面**：覆盖 (规模 × 通信范围) 的交叉扫描 + 消融 + 复杂度 + 泛化热力图，并提供公开代码，便于复现；
- **实证强度**：在大规模 (150, 10) 下同时在性能、运行时间、通信开销三个维度上明显领先 PI 类算法。

## 8. 不足与局限

- **通信建模抽象**：仅在**拓扑层**建模通信限制（通信半径决定可达性），未考虑带宽、延迟、丢包、能耗等**低层网络效应**；
- **奖励稀疏**：奖励是 episode 末端的总完成任务数，GRMAPG 通过群相对优势缓解了稀疏性，但训练仍依赖大规模采样；
- **价值估计的可信度**：训练算法消融中虽使用相同的 critic 结构，但未给出 critic 价值估计的 MSE/拟合误差等诊断指标，难以判断 actor-critic 性能劣势来源于 critic 偏差还是策略更新方式本身；
- **超参/搜索透明度**：群大小 $K=4$、对称变换类型（旋转、配对交换、缩放等）的具体组合未给出消融，缺乏对"群大小 ↔ 性能/方差 ↔ 训练时间"的敏感性分析；
- **任务与场景固定**：所有实验均为**离线规划、规模在 [50, 150]**、任务类型 $C=2$、agent 数最多 10；未涉及论文末提到的更动态场景（在线任务到达、不确定执行时长、自适应带宽/能量约束）以及更大规模、更多任务类型的实验；
- **基线对比硬件差异**：PI 类方法在 CPU 上运行，本文在 GPU 上推理，运行时间对比虽有意义但**非完全公平**，可通过标准化 FLOPs 或 wall-clock with same hardware 进一步增强说服力；
- **推理方式单一**：测试阶段仅用**单次贪心解码**，未探讨 beam search、rollout baseline 或 RL 引导的 refinement 在不影响实时性的前提下能否进一步提升；
- **开源代码以匿名链接**（anonymous.4open.science）发布，长期可访问性与版本管理存在不确定性；
- **公平性的潜在偏差**：PI-maxAss 被设计为"大多数设置中最强启发式基线"，但与 CBBA/EEPI 相比本文重新设计了其在动态拓扑下的触发逻辑，作者实现的 PI 类方法本身可能存在参数调试不充分的风险，进而**系统性地高估相对收益**。
