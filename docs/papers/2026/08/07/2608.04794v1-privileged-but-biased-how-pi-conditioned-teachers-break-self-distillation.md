## 摘要
自蒸馏（Self-Distillation, SD）已成为一种计算高效的方案，可替代带可验证奖励的强化学习：自教师以关于答案的特权信息（Privileged Information, PI）（例如参考解）为条件，向从未见过这些信息的学生提供密集的逐token监督。然而，已报告的增益几乎完全来自狭窄的低难度设置，这留下了一个基本问题：作为唯一目标、且不设奖励项，自蒸馏究竟能否教会任何东西？我们在简单设置中复现了SDPO所报告的增益，然后将完全相同的设置应用于困难任务，结果发现其并不能奏效。在问答、数学、编程和多轮智能体工具使用等任务上，跨越不同推理模式、模型规模和PI形式，并在SDPO与OPSD两种方案下，逐token损失持续下降，而验证准确率却未见提升、甚至通常出现下降。我们通过一条从损失指向其所产生模型的因果链来解释这一失败。该因果链始于PI偏差：在见过某个特定参考解之后，教师的逐token目标会被拉向该轨迹，而不是一般意义上的正确性，我们用PI偏差分数（PI Bias Score）量化了这一效应。由于学生被训练在各处匹配这一目标，其目标函数几乎对rollout是否正确变得视而不见，并且其所分配的损失主要落在低信息量的token上——如停用词、标点符号、不确定性标记——而非决定答案的那些token；在正确的rollout内部，探索性token承受了最高的分歧，因此该损失惩罚了推理所必需的犹豫。其结果是产生了一个更平淡、更缺乏决断力的学生，其推理能力并未得到提升：作为唯一目标，自蒸馏所优化的是一种与任务成功脱钩的信号。

## Abstract
Self-distillation (SD) has emerged as a compute-efficient alternative to reinforcement learning with verifiable rewards: a self-teacher, conditioned on privileged information (PI) about the answer such as a reference solution, supplies dense per-token supervision to a student that never sees it. Reported gains, however, come almost exclusively from narrow, low-difficulty settings, leaving open a basic question: as a lone objective, with no reward term, does SD teach anything? We reproduce SDPO's reported gains in its easy setting, then apply the identical setup to difficult tasks and find that it does not. Across question answering, mathematics, coding, and multi-turn agentic tool use, across reasoning modes, model sizes, and forms of PI, and under both the SDPO and OPSD recipes, the per-token loss falls steadily while validation accuracy does not improve and typically degrades. We explain this failure through a single causal chain from the loss to the model it produces. The chain begins with PI bias: having seen one particular reference solution, the teacher's per-token target is pulled toward that trajectory rather than toward correctness in general, an effect we quantify with a PI Bias Score. Trained to match this target everywhere, the student's objective becomes nearly blind to whether a rollout is correct, and the loss it assigns falls mostly on low-information tokens like stopwords, punctuation, uncertainty markers, rather than those that determine the answer; within correct rollouts the exploratory tokens incur the highest divergence, so it penalizes the hesitation that reasoning requires. The result is a flatter, less decisive student that is no better at reasoning: as a lone objective, SD optimizes a signal decoupled from task success.

# 论文总结：享有特权却存在偏差——PI 条件教师如何破坏自蒸馏

## 1. 核心问题与研究动机

自蒸馏（Self-Distillation, SD）近期被作为带可验证奖励的强化学习（RLVR）的**计算高效替代方案**而备受关注。其核心思路是：让一个**自教师**（即被训练的模型本身）在"特权信息"（Privileged Information, PI，如参考解、提示或执行反馈）条件下，为从未见过这些信息的学生提供**逐 token 的稠密监督**，从而无需外部教师或奖励函数。

然而 SDPO 和 OPSD 等方法所报告的增益几乎全部来自**短小、低难度的任务**（如多项选择知识问答）。一个基本问题悬而未决：

> **作为唯一训练目标（不附加任何奖励项）的自蒸馏，究竟是否真的在"教"模型任何东西？**

本文的核心论断是：在困难推理任务上，作为唯一目标的 SD **无法优化任务正确性**，其所优化的信号与任务成败**脱钩**。

## 2. 方法论

### 2.1 自蒸馏目标函数（Eq. 1）

学生策略 $\pi_\theta$ 在仅含 prompt $x$ 的条件下自回归生成 $\hat{y}$；自教师为同一模型 $\pi_{\theta'}$，额外以 PI $r$ 为条件。训练最小化沿学生 rollout 的逐 token 散度：

$$
L_{\text{SD}}(\theta) = \mathbb{E}_{(x,r)} \mathbb{E}_{\hat{y}\sim \mathrm{sg}(p_S)} \left[ \frac{1}{|\hat{y}|} \sum_{t=1}^{|\hat{y}|} D\!\left(\mathrm{sg}(p_T(\cdot\mid x,r,\hat{y}_{<t})) \,\|\, p_S(\cdot\mid x,\hat{y}_{<t})\right) \right]
$$

其中 $\mathrm{sg}$ 表示 stop-gradient，$D$ 取 Jensen-Shannon 散度（与 SDPO 一致）。两个设计选择共同驱动后续所有失败：

- **稠密性**：每个 token 都分到目标，使停用词、标点、风格词与内容 token 同等重要；
- **PI 条件性**：当 $r = y^\star$（整段参考解）时，目标锁定到**一条具体解**的措辞与顺序。

### 2.2 PI 偏差分数（PI Bias Score, Eq. 2）

针对前缀 $(x, y_{<t})$ 和目标序列 $w = (w_1,\ldots,w_K)$，定义教师与学生对 $w$ 的平均对数概率之差：

$$
PS_t(w) = s_t^T(w) - s_t^S(w) = \frac{1}{K}\sum_{k=1}^{K} \log \frac{p_T(w_k\mid x,y^\star, y_{<t})}{p_S(w_k\mid x,y_{<t})}
$$

四个目标对照：$PS_\star$（in-context 解 $y^\star$）、$PS'$（同题另一正确解）、$PS^-$（错误解）、$PS^\sim$（无关题解）。若教师编码正确性，应有 $PS_\star \approx PS'$；若编码轨迹，则 $PS_\star \gg PS' \approx PS^\sim > PS^-$。

### 2.3 训练稳定化

为应对困难任务上的不稳定，作者引入：极小教师 EMA 速率 $\alpha = 0.001$（SDPO 为 0.01，Kim 等为 0.05），以及较激进的逐 token 散度裁剪 $\tau = 0.001$。

## 6. 主要结论与发现

- **整体失败模式**：作为唯一目标，SD 在困难任务上**损失稳定下降而验证准确率停滞甚至退化**；在 agentic 域 think 模式下平均下降 **3.51 分**，BFCL Miss.Func 单项下降 7.0 分；在 OPSD 配方下一般 QA 与数学 think 模式分别再降 1.96 与 4.28 分。
- **五条因果链**（均在 Qwen3-8B 上同组运行中测得）：

  1. **教师锁定单一轨迹而非正确性**：PI Bias Score 在 in-context 解上达 **0.52**，对同题另一正确解仅 **≤ 0.02**；
  2. **损失对正确性失明**：正确与错误 rollout 的逐 token 损失均约 $3.5\times 10^{-4}$，KL 均约 0.03，几乎完全重叠；且师生 log-prob 差在正确 rollout 上反而更高（约 0.7 vs 0.45）；
  3. **损失集中在低信息 token**：停用词、不确定性标记、标点、空白合计吸收 **55.4%** 的损失，而数字、算符、内容词占比很小；
  4. **惩罚探索**：在正确 rollout 内，离参考路径位置的 KL 约 **0.31**，约为 on-path 的 **4 倍**（错误 rollout 内差距扩大至约 5 倍），导致模型缩短思考、提前承诺；
  5. **学生被"摊平"而非锐化**：师生 LP gap 由 ≈3.1 收敛到 ≈0，但 ±1 std 带不收窄，学生熵上升，perplexity 上升——这是"对消"而非真正"匹配"。

- **鲁棒性结论**：短轨迹与长轨迹表现同等差；简单子集与困难子集均下降；Qwen3-32B 也未改善；PI 形态实验显示**过强 PI 锁定轨迹、过弱 PI 什么也不教**，两端都失败。
- **理论与经验呼应**：本文将 RLSD 的 $L_\text{OPSD} = L^\star + I(Y_t;R\mid X,Y_{<t})$ 界与 Kim 等的"风格吞噬"现象，用同一组运行统一为一条可测量因果链。

## 7. 优点

- **可复现性**：先在 SDPO 原域（SciKnowEval）复现其报告增益，再迁移到困难任务，使"代码与实现"作为失败原因被排除，论证严谨；
- **PI Bias Score 设计巧妙**：仅需前向传播即可量化教师对特定解的偏好，**比条件互信息更易操作**，并提供训练前的 PI 筛选工具；
- **五环节因果链**：从 PI → 损失 → token 分布 → 探索 → 学生形态，每环节均有直接测量，且能在 PI 形态干预下"动"起来，形成因果而非纯相关；
- **跨域跨模式跨规模的一致性**：think / instruct、8B / 32B、4 个推理域、2 种配方下结论同向，结论的外部有效性较强；
- **实践指引**：建议**监控验证准确率**而非训练损失；PI Bias Score 的 $PS_\star - PS'$ 大小可作为训练前的"信号质量探针"。

## 8. 不足与局限

- **观察性研究**：作者明确指出本文不提出新方法，仅刻画现有目标的失败机制；缺乏"教师目标集 = 全部正确解"等可修复设定的干预实验；
- **模型族单一**：仅在 Qwen3 系列（8B / 32B）上验证，未跨架构（如 DeepSeek、LLaMA）做泛化检验；
- **统计噪声**：每个基准 4 次 rollout 平均，**部分 per-domain 差异与运行间方差相比偏小**；某些子项正向但被负向均值掩盖（如 coding instruct 在 MBPP+ 上 +12.6，但被 HumanEval+ −3.8 等抵消）；
- **PI Bias Score 的目标选择敏感性**：分数依赖于 $y'$、$y^-$、$\tilde{y}$ 的具体抽样与回望长度 $K=2000$ 的设定，作者承认其补充而非替代条件互信息估计；
- **弱 PI 形态的构造偏差**：提示与技能卡均由另一模型生成，"弱 PI 表现差"中可能掺杂了**生成质量**而非 PI 强度的混淆；
- **未覆盖保留奖励的混合设置**：RLSD 等"奖励主导 + SD 辅助"的工作不在本文实验范围，因此本文不直接判定那些方法是否同样失败；
- **应用边界**：本文结论限于"PI 条件 + 逐 token 稠密目标作为唯一训练信号"这一特定目标族；并非声称 SD 在所有形式下均无效。
