## 摘要
大语言模型智能体通常通过具有稀疏轨迹级奖励的强化学习进行训练，而这类奖励对单个词元应被多大程度地更新所提供的指导有限。在策略自蒸馏（OPSD）通过在特权回放视图下对生成的词元重新打分来获得密集的词元级监督，从而缓解了这一问题。然而，我们发现了一个混淆问题：由此得到的支持信号可能既反映了回放视图所包含的特权信息，也反映了由回放脚手架所引起的分数变化，从而难以将支持信号专门归因于该信息。当未来环境观察充当特权信息时，这一问题尤为突出，因为回放这些观察需要重建一个扩展的脚手架，而该脚手架本身就会扰动词元分数。为了解决这一混淆，我们提出了观察校准自蒸馏（OCSD），它通过对比两个结构上匹配的回放视图——完整视图与观察消融视图（仅在实际未来观察是否存在这一点上有所不同），推导出观察残差，从而扣除由回放脚手架共享的分数变化。然后，OCSD 将该残差应用于在高不确定性步骤上调制词元级 GRPO 更新，同时保留轨迹级的更新方向。在 ALFWorld、WebShop 和 Search-QA 上跨三种 Qwen3 模型规模的实验表明，OCSD 始终优于强基线。诊断分析进一步确认，校准后的残差与局部环境反馈具有更好的一致性。我们的代码已公开发布于 https://github.com/yiy1x/OCSD。

## Abstract
Large language model agents are commonly trained through reinforcement learning with sparse trajectory-level rewards, which offer limited guidance on how strongly individual tokens should be updated. On-Policy Self-Distillation (OPSD) addresses this by re-scoring generated tokens under a privileged replay view to obtain dense, token-level supervision. However, we identify a confounding issue: the resulting support may reflect both the privileged information contained in the replay view and score shifts induced by the replay scaffold, making it difficult to attribute the support specifically to that information. This issue is especially pronounced when future environment observations serve as privileged information, since replaying them requires reconstructing an extended scaffold that itself perturbs token scores. To resolve this confounding, we propose Observation-Calibrated Self-Distillation (OCSD), which contrasts two structurally matched replay views, Full and Observation-Ablated, differing only in whether the actual future observation is present, to derive an observation residual that discounts score changes shared by the replay scaffold. OCSD then applies this residual to modulate token-level GRPO updates at high-uncertainty steps, while preserving the trajectory-level update direction. Experiments on ALFWorld, WebShop, and Search-QA across three Qwen3 model scales show that OCSD consistently outperforms strong baselines. Diagnostic analyses further confirm that the calibrated residual aligns better with local environment feedback. Our code is publicly available at https://github.com/yiy1x/OCSD.

## 1. 核心问题与研究动机

- **背景**：大语言模型（LLM）智能体常采用 GRPO 等强化学习方法进行训练，但 GRPO 仅依据稀疏的轨迹级奖励对所有 token 施加同一优势，对单个 token 应被多大程度更新缺乏细粒度指导。
- **现有方法的局限**：On-Policy Self-Distillation（OPSD）通过在特权回放视图（privileged replay view）下对已生成 token 重新打分来获得密集 token 级监督。但本文指出 OPSD 存在一个**归因混淆（attribution confound）**问题：
  - 当特权信息为未来环境观察时，回放这些观察需要重建一个扩展的脚手架（replay scaffold，包括未来动作 schema、格式等）；
  - 该脚手架本身就会扰动 token 分数，因此 Full 视图的支持信号既包含来自真实未来观察的偏好，也包含脚手架共享带来的分数变化，难以将支持信号单独归因于未来观察本身。
- **关键动机图示**：论文以 ALFWorld 为例展示，Full 视图与去除真实观察后的 Observation-Ablated 视图对"I / should / from"等通用词的支持几乎相同，但对"take / mug / shelf"等与环境反馈相关的实体词差异显著，说明 Full 视图支持混淆了两类贡献。

## 2. 方法论

### 2.1 核心思想

构建两个**结构匹配**的回放视图——Full 视图与 Observation-Ablated 视图（两者仅在是否包含真实未来观察这一点上不同），通过对比二者对同一 token 的打分差，提取出**观察残差（observation residual）**，用于校准 token 级 GRPO 更新强度，同时保留轨迹级更新方向。

### 2.2 关键技术细节

**特权回放评分定义**：对第 $i$ 条轨迹、第 $k$ 步、token $y_{i,k,t}$，定义 Full 支持与 Ablated 支持：

$$\delta^{F}_{i,k,t} = \log \pi_{F}(y_{i,k,t}\mid h_{i,k,t}, E^{F}_{i,k}) - \log \pi_{S}(y_{i,k,t}\mid h_{i,k,t})$$

$$\delta^{A}_{i,k,t} = \log \pi_{A}(y_{i,k,t}\mid h_{i,k,t}, E^{A}_{i,k}) - \log \pi_{S}(y_{i,k,t}\mid h_{i,k,t})$$

**观察残差（Observation Residual）**：由于 Student 视图项在差值中抵消：

$$e_{i,k,t} = \delta^{F}_{i,k,t} - \delta^{A}_{i,k,t} = \log \pi_{F}(y_{i,k,t}\mid h_{i,k,t}, E^{F}_{i,k}) - \log \pi_{A}(y_{i,k,t}\mid h_{i,k,t}, E^{A}_{i,k})$$

**有界校准信号**：通过 tanh 映射到 $[-1, 1]$：

$$q_{i,k,t} = \tanh\!\left(\frac{e_{i,k,t}}{2}\right)$$

**NLL 引导的步骤选择**：对每条轨迹，按步骤内平均 token NLL 进行排序，选取 top-$\rho$ 比例的高不确定性步骤：

$$u_{i,k} = -\frac{1}{T_{i,k}}\sum_{t=1}^{T_{i,k}} \log \pi_{\theta_{\text{old}}}(y_{i,k,t}\mid h_{i,k,t})$$

$$S_{i} = \text{TopIndices}_{\lceil \rho K_{i}\rceil}\big(\{u_{i,k}\}_{k=1}^{K_{i}}\big)$$

**符号保留式 GRPO 集成**：仅在被选中步骤上，残差用于调制 token 级优势幅度，未选中步骤保留原轨迹级优势：

$$\hat{A}^{\text{OCSD}}_{i,k,t} = \begin{cases} \hat{A}_{i}\big(1 + \beta\,\mathrm{sgn}(\hat{A}_{i})\,q_{i,k,t}\big), & k \in S_{i} \\ \hat{A}_{i}, & k \notin S_{i} \end{cases}$$

**最终优化目标**（带 clip 和 KL 正则）：

$$J_{\text{OCSD}}(\theta) = \mathbb{E}_{i,k,t}\Big[\min\big(r_{i,k,t}(\theta)\,\hat{A}^{\text{OCSD}}_{i,k,t},\ \text{clip}(r_{i,k,t}(\theta),1-\epsilon,1+\epsilon)\,\hat{A}^{\text{OCSD}}_{i,k,t}\big) - \beta_{\text{KL}}\,\mathbb{D}_{\text{KL}}(\pi_{\theta}\Vert\pi_{\text{ref}})_{i,k,t}\Big]$$

其中 $r_{i,k,t}(\theta)=\pi_{\theta}(y_{i,k,t}\mid h_{i,k,t})/\pi_{\theta_{\text{old}}}(y_{i,k,t}\mid h_{i,k,t})$。

### 2.3 回放证据构造

- **Full 证据** $E^{F}_{i,k}$：包含两步未来观察 $o_{k+1}, o_{k+2}$ 与中间动作 $a_{k+1}$ 的自然化 schema（保留粗粒度意图与句法结构，但将具体实体、位置、查询等替换为语义角色表达，如"take an item from a receptacle"）。
- **Ablated 证据** $E^{A}_{i,k}$：保留相同的字段顺序、回放格式与未来动作脚手架，仅将每个未来观察字段替换为固定短语 "Observation: not provided"。

### 2.4 算法流程（Algorithm 1）

1. 设置 $\theta_{\text{old}}\leftarrow\theta$，对任务批量进行 on-policy rollout 并计算组相对优势 $\hat{A}_{i}$；
2. 计算每步平均 NLL，按 $\rho$ 选择高不确定性步骤；
3. 对每个被选步骤构造 Full / Ablated 证据，重新打分同前缀 token；
4. 计算 $\delta^{F}, \delta^{A}, e_{i,k,t}, q_{i,k,t}$ 并按式 (11) 构造 $\hat{A}^{\text{OCSD}}$；
5. 按 $J_{\text{OCSD}}$ 更新策略参数。
