## Abstract
Reinforcement learning with verifiable rewards (RLVR) is effective for training large language model agents. However, terminal rewards provide only coarse trajectory-level supervision, leaving successful behaviors, recurring mistakes, and incidental choices entangled in the same outcome signal. Existing agentic self-distillation methods enrich sparse supervision with natural-language skills, but skills retrieved externally or extracted from a single trajectory by stronger models may mismatch current experience, exceed the policy's capability, or remain path-specific. We propose Group-Reflective Self-Distillation (GRSD), which derives capability-aligned and outcome-discriminative guidance from the policy's own verified rollouts. For each prompt, the policy reflects on each verified trajectory in an on-policy group, and a stop-gradient snapshot contrasts the resulting reflections from successful and failed rollouts to construct group-level privileged guidance. Conditioned on this guidance, a self-teacher refines turn-level credit assignment by modulating outcome-based advantages while preserving the verifier-determined learning direction. Experiments across multiple agentic environments and model scales demonstrate that GRSD consistently outperforms competitive baselines and generalizes more effectively to unseen tasks.

## 1. 核心问题与研究动机

- **研究背景**：带可验证奖励的强化学习（RLVR，如 GRPO）已成为训练 LLM 智能体执行多轮工具调用任务的主流范式。其核心思想是利用 verifier 给出的终局奖励直接优化智能体策略，无需训练 critic。
- **核心痛点**：终局奖励是 **轨迹级（trajectory-level）** 监督，粒度过粗。成功行为、反复出现的错误与偶然选择全部纠缠在同一个 reward 信号中，无法区分"哪一步决策真正贡献了成功/失败"，导致信用分配效率低下。
- **现有自蒸馏方法的局限**：
  - 基于外部技能库的检索方法（如 Skill-SD、SDAR）所选技能可能与当前 prompt/状态不匹配；
  - 基于更强外部模型对单条轨迹的事后反思（如 OPID）易超出当前策略的能力边界；
  - 单轨迹技能未对比同一 prompt 下多条成功/失败 rollout，易陷入"路径特定细节"而非真正的成败差异模式。
- **关键问题**：(1) 如何从策略自身的同策略经验中得出 **能力对齐（capability-aligned）** 的指导？(2) 如何 **对比同一 prompt 下的多条 rollout** 以提取真正区别成败的行为模式？

## 2. 方法论

### 2.1 总体框架：两阶段构造 + 自蒸馏

GRSD 将稀疏轨迹级监督细化为 **轮次级（turn-level）信用**，核心由两部分组成：

- **Stage A — 策略原生自反思（Policy-Native Self-Reflection）**：对每条已验证轨迹 $\tau_i$，使用 rollout 策略本身（而非更强外部模型）按指令 $p_{\text{ref}}$ 生成结构化反思 $s_i$，识别成败关键轮次并给出具体的"应做/应避免"行为。
- **Stage B — 分组级指导构造（Group-Level Guidance Construction）**：用 **stop-gradient 策略快照** $\bar\theta = \mathrm{sg}(\theta_{\text{old}})$ 对比成功反思集 $S_x^+$ 与失败反思集 $S_x^-$，合成紧凑的 DO/AVOID 指导 $z_x$。

### 2.2 关键公式

**GRPO 轨迹级优势**（组内归一化）：

$$A_i = \mathrm{Norm}_G(R_i) = \frac{R_i - \bar{R}}{\sqrt{\frac{1}{G}\sum_{j=1}^G (R_j - \bar{R})^2 + \epsilon_{\text{adv}}}}$$

**反思奖励（外部 judge 打分 $r_i^{\text{ref}} \in \{0,1,2,3\}$）**：

$$A_i^{\text{ref}} = \mathrm{Norm}_G(r_i^{\text{ref}})$$

**教师-学生似然差（指导对轮次 $t$ 的影响）**：

$$\Delta_{i,t} = \frac{1}{L_{i,t}} \sum_{k=1}^{L_{i,t}} \left[ \log \pi_{\bar\theta}(y_{i,t,k} \mid y_{i,t,<k}, c_{i,t}^{\text{tea}}) - \log \pi_{\bar\theta}(y_{i,t,k} \mid y_{i,t,<k}, c_{i,t}^{\text{stu}}) \right]$$

其中 $c_{i,t}^{\text{stu}} = C(x, H_{i,t})$，$c_{i,t}^{\text{tea}} = C(x, z_x, H_{i,t})$。

**方向对齐的调制分数**（用符号对齐与奖励方向、归一化、裁剪）：

$$q_{i,t} = \mathrm{sign}(A_i) \cdot \Delta_{i,t}, \quad \tilde{q}_{i,t} = \mathrm{clip}\left(\frac{\exp(q_{i,t})-1}{\frac{1}{|T_x|}\sum_{(j,t')\in T_x} |\exp(q_{j,t'})-1| + \epsilon_{\text{gap}}}, -\bar{G}, \bar{G}\right)$$

**轮次级调制优势**（保留 verifier 方向，仅做有界缩放）：

$$\tilde{A}_{i,t} = A_i(1 + \lambda \tilde{q}_{i,t} m_x), \quad \lambda \bar{G} < 1$$

其中 $m_x = \mathbb{1}[|S_x^+|>0 \wedge |S_x^-|>0]$ 为"混合结果组"掩码；当组内缺乏同时存在的成功/失败轨迹时退化为 $A_i$，即恢复标准 GRPO。

**总体目标**（任务损失 + 反思损失 + KL 正则）：

$$L(\theta) = L_{\text{task}}(\theta) + \alpha L_{\text{ref}}(\theta) + \beta L_{\text{KL}}$$

其中 $L_{\text{task}}$ 是用 $\tilde{A}_{i,t}$ 替换 $A_i$ 的 clipped GRPO surrogate，$L_{\text{ref}}$ 独立训练反思 token。

### 2.3 理论性质（附录严格证明）

- **Proposition 1**：在条件独立噪声假设下，分组对比 $\hat{d}_x = \overline{S_x^+} - \overline{S_x^-}$ 是 $\mu_1^x - \mu_0^x$ 的无偏估计，且 MSE 为 $\mathrm{tr}(\Sigma_1^x/n_+ + \Sigma_0^x/n_-)$，证明聚合可减少轨迹特定方差。
- **Proposition 2**（有界调制）：当 $\delta = \lambda \bar{G} < 1$ 时，$w_{i,t} = 1 + \lambda m_x \tilde{q}_{i,t} \in [1-\delta, 1+\delta]$，且 $\mathrm{sign}(\tilde{A}_{i,t}) = \mathrm{sign}(A_i)$——指导只能缩放、不能反转验证器方向。
- **Proposition 3**：GRSD 任务 surrogate 严格等价于 **detached 正权重再缩放** 的 clipped GRPO surrogate（$\phi_\varepsilon(\rho, wA) = w \phi_\varepsilon(\rho, A)$），并给出每 token 梯度扰动上界 $\|g_{i,t,k}^{\text{GRSD}} - g_{i,t,k}^{\text{GRPO}}\| \le \delta \|g_{i,t,k}^{\text{GRPO}}\|$。

### 2.4 推理时无开销

指导 $z_x$ 仅用于构造训练信号，**推理时只使用普通 prompt**，不增加任何部署成本。

- **有效组依赖**：仅当 $|S_x^+|>0 \wedge |S_x^-|>0$ 时才启用调制；训练早期若策略过弱/过强导致全组同质化，将退化为普通 GRPO。
- **单家族 LLM 验证**：仅在 Qwen 系列（1.7B/3B/7B）评估，未在 LLaMA、DeepSeek 等其他家族或更大规模（13B+）上验证，泛化性结论需谨慎外推。
- **理论假设较强**：Proposition 1 假设条件独立且无公共 prompt 引起的相关性，自然语言反思显然违反该假设，作者也明确承认这一"理想化表征"的范围局限。
- **指导质量无监督保证**：$\Delta_{i,t}$ 是 **后视性（hindsight-conditioned）** 的兼容性信号，而非因果轮次信用估计，作者明确指出"不保证语义正确、单调改进或收敛"。
- **连续奖励下方向不一致**：当 verifier 返回连续奖励时，$\mathrm{sign}(A_i)$ 与 outcome label $b_i$ 不再必然一致，可能削弱指导的语义清晰度。
- **环境覆盖有限**：尽管涉及具身、QA、网页三类任务，但均为相对受限的学术 benchmark，未在更开放、真实、长程（如 Software Engineering、Computer Use）环境中验证。
- **prompt 与超参敏感**：反思 $p_{\text{ref}}$ 与指导 $p_{\text{guide}}$ 的设计依赖 prompt engineering，论文未给出系统性的 prompt 敏感性研究。
