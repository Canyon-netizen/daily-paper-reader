## 摘要
智能体强化学习使大语言模型（LLM）智能体能够通过与环境交互进行学习，但稀疏的轨迹级奖励仅揭示成败，而无法识别哪些中间决策应获得信用。仅在训练阶段使用的特权技能可提供更密集的监督，其做法是：保持策略快照冻结不变，在以任务匹配的流程性技能为条件下，对来自无技能轨迹的固定token重新打分。然而，现有方法未能同时完成以下三项工作：在各交互步骤间联合校准教师打分；将教师置信度与实际回报相关联；并将所得信号整合到原生的"奖励—优势"构建中。我们提出了基于自蒸馏奖励塑形的智能体强化学习（ADRS），这是一个面向多轮语言智能体、用于构建与回报相关联的token级信用的框架。ADRS在每个步骤内对特权token分数进行中心化与归一化处理，再通过基于组内置信度—回报关联的、与回报相关联的教师价值优势（TVA）门控对其进行调制，最后将门控后的token信号融入原生的强化学习信用构建过程。上述各组件共同回答了三个问题：教师偏好什么、何时该偏好与回报相关，以及该偏好如何进入原生强化学习的信用通路——同时保持轨迹生成（rollout）与推理过程均不依赖任何技能。最后，在三个交互基准上的实验表明，ADRS在长程任务上稳定提升性能，且相关增益在不同RL骨干网络、低数据设置、未见任务以及更长训练周期下均得以保持。为配合匿名评审，代码已在以下链接公开：https://github.com/gitrxh/ADRS-arxiv

## Abstract
Agentic reinforcement learning enables LLM agents to learn through interaction, but sparse trajectory-level rewards reveal success without identifying which intermediate decisions deserve credit. Training-only privileged skills can provide denser supervision by allowing the same frozen policy snapshot to rescore fixed tokens from skill-free trajectories while conditioned on task-matched procedural skills. Existing methods, however, do not jointly calibrate teacher scores across interaction steps, relate teacher confidence to realized returns, and integrate the resulting signal into native reward-to-advantage construction. We introduce Agentic Reinforcement Learning with Self-Distilled Reward Shaping (ADRS), a framework for constructing return-associated token-level credit for multi-turn language agents. ADRS centers and normalizes privileged token scores within each step, modulates them with a return-associated Teacher Value Advantage (TVA) gate based on within-group confidence--return association, and incorporates the gated token signal into native RL credit construction. Together, these components determine what the teacher prefers, when that preference is return-relevant, and how it enters the native reinforcement-learning credit path, while keeping rollouts and inference skill-free. Finally, experiments across three interactive benchmarks show that ADRS consistently improves performance on long-horizon tasks, with gains persisting across RL backbones, reduced-data settings, unseen tasks, and extended training. For anonymous review, our code is available at the following the link: https://github.com/gitrxh/ADRS-arxiv

# ADRS 论文详细总结

## 一、核心问题与研究动机

智能体强化学习（Agentic RL）通过让 LLM 智能体与环境交互进行学习，但通常只能获得稀疏的轨迹级（trajectory-level）奖励——即仅在任务完成时返回成败信号，无法识别中间哪些查询或动作值得获得"信用"。这给 token 级的时序信用分配带来了极大困难，即使是无评论家（critic-free）的组相对方法（如 GRPO、GiGPO）也难以克服。

引入自然语言技能可以提供更稠密的指导，描述子目标、动作规则和常见失败模式。但现有方法（OPSD、Skill-SD、RLSD、SDAR 等）通常将特权监督作为独立的辅助蒸馏目标，无法同时解决三个关键挑战：
- **分数校准（Score Calibration）**：教师 log-probability 因上下文长度、交互位置等产生偏移，不同交互步骤之间不可直接比较。
- **可靠性估计（Reliability Estimation）**：教师高置信度未必反映与回报真正相关的决策，可能只是语言层面的熟悉度。
- **信用整合（Credit Integration）**：独立的辅助目标绕过了 GRPO/GiGPO 的原生"奖励—优势—策略"通路，可能与组相对优势对齐不良。

## 二、方法论

### 2.1 整体思路

ADRS 是一个**自蒸馏奖励塑形（Self-Distilled Reward Shaping）**框架，将仅在训练阶段使用的任务匹配流程性技能转化为与回报相关联的 token 级训练奖励。学生在无技能环境下采样轨迹，由同一冻结策略快照在附加技能上下文中对固定 token 重新打分，然后：
- **模块 1**（What 教师偏好什么）：对每个步骤内教师 token 分数进行**中心化和标准化**；
- **模块 2**（When 何时偏好与回报相关）：基于组内"置信度—回报"关联的 **TVA（Teacher Value Advantage）门控**进行调制；
- **模块 3**（How 如何进入原生 RL 通路）：将门控后的 token 信号注入原生奖励—优势—策略路径，**不再使用独立的辅助目标**。

推理和轨迹采集阶段均不使用技能。

### 2.2 关键公式

**步骤内中心化和归一化分数**：

$$b_s = \frac{1}{|\mathcal{V}_s|}\sum_{j \in \mathcal{V}_s} \ell^T_{s,j}, \quad q_{s,j} = \ell^T_{s,j} - b_s, \quad \hat{q}_{s,j} = \frac{q_{s,j}}{\sigma_q + \epsilon}$$

其中 $\ell^T_{s,j}$ 为冻结快照 $\pi_{\theta_b}$ 在特权上下文下的 token log-probability，$b_s$ 是该步骤均值，$\sigma_q$ 为归一化范围标准差，$\epsilon > 0$ 保证数值稳定。

**TVA 单元置信度**：

$$\bar{\ell}^T_u = \frac{1}{|\mathcal{V}_u|}\sum_{(s,j)\in \mathcal{V}_u} \ell^T_{s,j}, \quad \bar{\ell}^T_{\text{batch}} = \frac{1}{|\mathcal{U}|}\sum_{u \in \mathcal{U}} \bar{\ell}^T_u$$

$$\alpha_u = \sigma(\bar{\ell}^T_u - \bar{\ell}^T_{\text{batch}})$$

其中 $u$ 为选定的 TVA 单元（L2 为完成级/L3 为步骤级）。

**组内回报对比与门控**：

$$\mu^+_g = \frac{\sum_{u \in g} \alpha_u R_u}{\sum_{u \in g}\alpha_u + \epsilon}, \quad \mu^-_g = \frac{\sum_{u \in g}(1-\alpha_u) R_u}{\sum_{u \in g}(1-\alpha_u) + \epsilon}, \quad d_g = \mu^+_g - \mu^-_g$$

$$m_u = \text{sg}[\sigma(\tau \tilde{d}_{g(u)})]$$

**教师奖励与塑形后的 token 奖励**：

$$r^T_{s,j} = \eta m_{s,j} \hat{q}_{s,j}, \quad \tilde{r}_{s,j} = r^{\text{base}}_{s,j} + r^T_{s,j}$$

**最终 token 级优势**：

$$A^{\text{ADRS}}_{i,k,t} = A^{\text{traj}}_{i,k} + \eta Z^T_{i,k,t}$$

其中 $Z^T_t$ 为组内白化后的教师奖励调制项 $\displaystyle Z^T_t = \frac{r^T_t - \mu^T_g}{\sqrt{(\sigma^T_g)^2 + \epsilon}}$。

### 2.3 理论性质

- **命题 1**：$\displaystyle d_g = \frac{\text{Cov}_g(\alpha, R)}{\bar{\alpha}_g(1-\bar{\alpha}_g)}$，故 TVA 门控正负号与组内经验协方差符号一致。
- **命题 2（逐步零和表示）**：当门控和归一化分母在同一交互步骤共享时，$\sum_{j \in \mathcal{V}_s} r^T_{s,j} = 0$，存在势函数 $\Phi$ 使得 $r^T_{s,j_r} = \Phi_{s,r+1} - \Phi_{s,r}$。因此轨迹和路径保留了环境回报方向。
- **命题 3**：在行为策略点无剪裁条件下，ADRS 的 token 级梯度等价于一个附加额外 token 辅助系数的原生策略梯度。

### 2.4 算法流程（每次迭代）

1. 行为策略 $\pi_{\theta_b}$ 在无技能上下文下采样 $K$ 条轨迹，记录有效 token 掩码、环境反馈及基础奖励；
2. 冻结 $\theta_b$，分别计算普通分数 $\ell_b$ 和技能条件下分数 $\ell^T$；
3. 计算步骤中心化与归一化分数 $\hat{q}$；
4. 若启用 TVA，按式 (4)–(4.2) 计算门控 $m$；否则设 $m = 1$；
5. 形成并保存教师奖励 $r^T = \eta m \hat{q}$，塑形奖励 $\tilde{r} = r^{\text{base}} + r^T$；
6. 轨迹路径：通过原生骨干（GRPO/GiGPO）计算 $A^{\text{traj}}$；
7. token 路径：白化 $r^T$ 得到 $Z^T$；
8. 合并 $A^{\text{ADRS}} = A^{\text{traj}} + \eta Z^T$，detach 合并系数；
9. 以原生 PPO/clip 目标优化，更新策略。

- **新 SOTA**：在 Qwen2.5-3B 上，ADRS 在 ALFWorld（94.5%）、Search（45.0%）、WebShop（87.5 / 76.6）三个基准上均取得新高，相对最强基线分别提升 +10.1、+0.4、+2.5/+8.6 分；

- **测试时无技能**：所有 ADRS 评估不使用特权技能，性能来自训练阶段注入的信用而非测试时增强；
- **长期训练可保持**：300 步下 ADRS-global+entropy/clip 配置峰值达 97.7%、终值 96.1%，GRPO 仅 92.2% / 86.7%；

- **类别泛化**：在 unseen split 的六个类别中，五类得到提升（Cool +22.8、Pick2 +18.1、Heat +12.9、Clean +7.9、Pick +5.0），仅 Look 下降 4.4；
- **Action–Object 诊断**：150 步时动作—风格比达 95.3，显示 token 级优势调制将更新对比集中于决定可执行动作与对象选择的 token 上，而非均匀扩散到全响应。

## 七、优点

1. **问题分解清晰**：把特权教师信号使用拆解为"分数校准 / 可靠性估计 / 信用整合"三个正交问题，并各自有对应模块，给出完整的工程与理论基础；
2. **理论支撑**：三项命题分别证明 TVA 与组内协方差对应、步骤级零和结构、与采样—token 辅助目标在策略点的一阶梯度等价；
3. **集成干净**：将教师信号作为"前置奖励塑形"注入原生 RL 通路（pre-advantage），避免引入额外的辅助损失，结构上只保留单一 RL 目标；
4. **推理时纯净**：完全在 skill-free 状态下评估，避免类似 Skill-Prompt/Skill-GRPO* 可能带来的对比偏差；
5. **兼容性好**：同时适配 GRPO 和 GiGPO 两种骨干，且可结合其原生 step-level 信用；
6. **实验完整**：3 模型 × 3 基准 + 消融 + 数据效率 + 泛化 + 长期训练 + 诊断 + 超参扫描；
7. **多细粒度门控**：L2 / L3 / L1（fallback）覆盖轨迹级、步骤级、token 级不同组结构。

## 八、不足与局限

1. **Search-QA 增益不明显**：在 Qwen2.5-3B 上相对最强基线仅 +0.4 分，Qwen3-1.7B 上仅 +0.7 分；在某些设置下 step-150 上甚至低于 GRPO（−0.1），任务异质性下表现波动大；
2. **依赖任务匹配技能供应者**：需要一个确定性的特权技能供应方 $\rho(x)$，其在不同环境和任务族下需要专门配置；论文使用 37 通用 + 90 任务特定技能与 619 源记忆，迁移到新任务族需要重新设计；
3. **门控统计有效性**：TVA 公式在组规模过小或回报方差过低时退化为 $m = 0.5$，限制了对极小批次或弱反馈任务的适应性；
4. **超参数敏感性**：附录显示 $\eta = 0.005$ 时训练早期峰值 38.3% 后迅速跌到 9.6%，且不同环境对全局 vs 逐序列归一化的偏好不一致（ALFWorld / Search 偏全局，WebShop 偏逐序列）；
5. **训练开销与算力信息不足**：未给出 GPU 数量、训练时长、单次迭代的额外前向开销，难以评估相比基线的实际训练成本；
6. **backbone 依赖**：整体性能受策略规模影响，Qwen3-1.7B 上绝对值（62.5%）远低于 7B 模型（96.1%），对小模型友好度有限；
7. **理论命题的局限**：命题 3 仅在"行为策略点 + 采样—token 路径不参与

剪裁"的条件下成立，忽略了 clip 机制、KL 惩罚、tempering 等常见工程化组件，理论与实际实现存在差距；
8. **技能完备性假设**：方法假设"教师知道如何做"，但没有讨论技能本身质量不足或与回报真实因果错位时（如 $\rho$ 给出次优指引）ADRS 的退化行为；
9. **诊断指标有限**：Action–Object 诊断仅在固定成功轨迹上进行，未覆盖失败轨迹或训练中后期；token 级优势调制是否真的导致"动作—对象对比更锐利"还需要更系统的因果分析；
10. **公平性比较的细微问题**：基线 OPSD/SDAR 等使用相同技能，但 ADRS 的设计目标本身就规避了独立辅助损失的缺陷，所以"基线偏弱"也可能部分由"它们未对齐原生 RL 通路"导致，难以完全归结为 ADRS 的内在优势。

## 九、个人评价与启示

ADRS 的核心贡献在于把"特权教师信号"从独立的辅助蒸馏损失重新定位为**前置奖励塑形**，通过**中心化—归一化—门控—白化—注入**这一条清晰的工程链，让技能信息沿着原生"奖励—优势—策略"通路流动。这套设计有较强的普适性：任何拥有"特权但只训练用"指导的 RL 场景（代码生成、机器人控制、工具使用等）都可借鉴其分模块思想。

其方法论特别值得借鉴之处有三点：
- **以门控代替硬过滤**：TVA 单元把"教师置信度—回报"关联作为软门控，比 OPSD 等的硬丢弃更鲁棒；
- **以步骤内归一化解决分数偏移**：简单但有效地消解了不同上下文长度下的 log-prob 不可比问题；
- **以势函数构造保证零和结构**：命题 2 给出的逐步零和性质，从理论上保证了塑形信号不会破坏原始回报的方向性。

未来可能的研究方向包括：
1. **技能自生成**：摆脱对外部 $\rho$ 的依赖，让 LLM 在探索过程中自动归纳可重用的子目标模板；
2. **跨任务技能迁移**：当前技能与具体任务族强绑定，若能在任务族之间共享抽象技能（如"先观察再行动"），可大幅降低部署成本；
3. **更细粒度的 TVA**：探索 trajectory-attribution（如 SHAP / integrated gradients）作为门控信号，与回报形成更直接的归因；
4. **与过程奖励模型（PRM）结合**：ADRS 的 token 级调制与 PRM 的步骤级打分有天然的互补空间，二者融合可能进一步提升信用分配质量；
5. **理论到工程的桥接**：将命题 3 推广到含 clip、KL、tempering 的完整 GRPO 目标，给出更严格的收敛性与偏差分析。

总体而言，ADRS 在 agentic RL 场景下提出了一种**简洁、可解释、可集成**的特权监督利用范式，把"奖励塑形"这一经典 RL 思想与 LLM 智能体的稀疏回报、token 级训练有效结合。其在 ALFWorld、WebShop 上的显著且稳定提升，及其对 GRPO / GiGPO 两种骨干的兼容性，使其具备较高的工程落地价值。Search-QA 上增益有限、计算开销信息不充分等问题也提示后续工作需要在更广任务域与更细训练成本评估上进一步验证。
