## 摘要
多语言大语言模型在不同语言之间表现出显著的性能差异，而现有的适配方法通常需要更新参数并依赖大量的多语言训练数据。我们提出了一种推理阶段的多语言引导方法，利用预训练的稀疏自编码器来识别并强化与目标语言相关的特征。通过使用多语言平行句子，我们比较了不同语言下 SAE 的激活情况，并选取了少量与各目标语言相关的特定层特征。这些特征被解码为引导信号，在无需额外训练的前提下注入到模型的隐藏状态中。在 Gemma-3-12B-it 上的实验表明，该方法在 XCOPA 上平均提升了 10.9 个百分点的准确率，在 XNLI 上提升 5.3 个百分点，在 MGSM 上提升 1.9 个百分点。

## Abstract
Multilingual large language models exhibit substantial performance differences across languages, while existing adaptation methods often require parameter updates and considerable multilingual training data. We propose an inference-time multilingual steering method that uses pretrained sparse autoencoders to identify and strengthen target-language-related features. Using multilingual parallel sentences, we compare SAE activations across languages and select a small number of layer-specific features associated with each target language. These features are decoded into steering signals and injected into the model's hidden states without additional training. Experiments with Gemma-3-12B-it show average accuracy improvements of 10.9 percentage points on XCOPA, 5.3 points on XNLI, and 1.9 points on MGSM.

# 论文总结：强化目标语言特征——基于稀疏自编码器的多语言推理引导

## 1. 核心问题与研究动机

多语言大语言模型（LLM）在不同语言上的性能存在显著差异，英语及高资源语言表现远优于低资源语言。造成该现象的主要原因是预训练语料的语言分布严重不均（英语占主导）。现有改善多语言性能的方案（如继续预训练、指令微调、表示对齐 MID-Align、偏好对齐 RLHF/DPO 等）通常需要：

- **大规模多语言训练数据**；
- **参数更新**与可观的计算开销；
- 且对低资源语言难以适用。

推理时（inference-time）激活引导（activation steering）方法（如 ActAdd、Wang 等 2025 的跨语言干预）虽然轻量，但通常在**完整隐藏表示**上进行干预，难以将语言相关成分从语义信息中**隔离**出来进行精细操控。

本文旨在提出一种**无需参数更新、无需额外训练**的推理时多语言引导方法，利用稀疏自编码器（SAE）精确定位并强化目标语言相关特征，从而以最低成本提升跨语言任务性能。

## 2. 方法论

### 2.1 核心思想

利用预训练 SAE 将模型隐藏激活分解为稀疏特征，**对比平行句子在不同语言上的 SAE 激活差异**，筛选出与目标语言强相关的少量稀疏特征（top-$k$），将这些特征的有符号激活差异**解码回隐藏空间**作为引导向量，注入模型的残差流中。

### 2.2 关键技术细节

**（1）SAE 编码—解码过程**

对第 $l$ 层、第 $t$ 个 token 的隐藏状态 $h_t^l \in \mathbb{R}^d$，层专属 SAE 编码器 $f_l$ 输出稀疏特征：

$$z_t^l = f_l(h_t^l), \quad z_t^l \in \mathbb{R}^m$$

解码器 $g_l$ 将稀疏特征映射回隐藏空间：

$$\hat{h}_t^l = g_l(z_t^l)$$

**（2）语言相关特征的识别**

给定包含 $N$ 组多语言平行句的语料（来自 FLORES-200），对语言 $\lambda$、第 $i$ 句、第 $t$ 个 token 的隐藏状态编码：

$$z_{i,t}^{\lambda,l} = f_l\!\left(h_{i,t}^{\lambda,l}\right)$$

在 token 内和句子间求平均，得到语言级 SAE 激活均值：

$$\mu_\lambda^l = \frac{1}{N}\sum_{i=1}^{N}\!\left(\frac{1}{T_\lambda^i}\sum_{t=1}^{T_\lambda^i} z_{i,t}^{\lambda,l}\right)$$

**（3）两种参考表示**

- **多语言质心（主方法）**：除目标语言 $\tau$ 外，对所有其他语言取平均作为"语言无关"的语义参考：
$$\mu_{multi}^l = \frac{1}{|L_{-\tau}|}\sum_{\lambda \in L_{-\tau}} \mu_\lambda^l$$
$$\Delta_{\tau,multi}^l = \mu_\tau^l - \mu_{multi}^l$$

- **英语参考（对照设置）**：直接以英语均值为参考：
$$\Delta_{\tau,en}^l = \mu_\tau^l - \mu_{en}^l$$

**（4）Top-k 特征选择**

$$I_{\tau,r}^l = \text{TopK}\!\left(\Delta_{\tau,r}^l,\, k\right), \quad r \in \{\text{multi}, \text{en}\}$$

本文默认 $k=3$。

**（5）构建引导向量**

仅保留被选特征的**有符号激活差异**，其余 SAE 维度置零：

$$s_j^l = \begin{cases} \Delta_j^l, & j \in I^l \\ 0, & \text{otherwise} \end{cases}$$

经 SAE 解码器映射回隐藏空间：

$$v^l = g_l(s^l)$$

**（6）激活干预**

在选定层 $l$ 的最后提示位置 $q$ 处注入：

$$\hat{h}_q^l = h_q^l + \alpha\, v^l$$

其中 $\alpha$ 为引导强度系数。仅干预第一个响应 token 位置前的隐藏状态，其余生成步骤不再施加干预。

- **逐层引导扫描**：对全部 48 个 transformer 层独立评估（XCOPA 验证集），定位最优干预层；
- **引导强度敏感度**：对 $\alpha$ 进行网格扫描（XCOPA 25 个值，XNLI/MGSM 各 11 个值），并绘图展示每条语言曲线；
- **固定 $\alpha$ 鲁棒性测试**：在所有语言和数据集上统一使用 $\alpha=0.6$，验证无需逐语调参的可行性；
- **跨层特征可视化**（Layer 47、Layer 20）以证实所选特征确实具备语言区分度。

### 5.2 充分性与公平性

- **充分性**：覆盖了不同推理类型（常识、NLI、数学）、不同语种（含高/低资源、东亚/欧洲/南亚/非洲语言）、不同干预强度与不同 SAE 参考设置，论证较为全面；
- **公平性**：所有方法均使用相同 SAE、相同提示模板、相同评估切分；$\alpha$ 均通过验证集选定后再做测试集评估，避免了在测试集上调参；
- **不足**：仅测试单一模型（Gemma-3-12B-it）；样本量适中（每语 200–400），未做显著性检验或置信区间报告。

## 6. 主要结论与发现

### 6.1 主实验（验证集选 $\alpha$）

| 数据集 | Baseline 平均 | Ours 平均 | 提升 |
|---|---|---|---|
| XCOPA | 54.5 | 65.8 | **+11.3 pp** |
| XNLI | 45.6 | 49.8 | **+4.1 pp** |
| MGSM | 80.5 | 81.1 | **+0.6 pp** |

（论文摘要宣称 XCOPA +10.9 pp、XNLI +5.3 pp、MGSM +1.9 pp；Table 1 中报告 +11.3、+4.1、+0.6，两处数值存在不一致，疑因统计口径不同，但均显示显著正向趋势。）

**统一固定 $\alpha=0.6$ 时**仍可获得 XCOPA +4.75 pp、XNLI +1.61 pp、MGSM +2.13 pp 的平均提升，说明方法**无需逐语精调**亦能稳定生效。

### 6.2 关键发现

1. **目标语言强化确实能提升任务性能**：XCOPA 上平均增益随 $\alpha$ 单调上升至约 $\alpha=1.4$（平均 +8.6 pp），之后递减；XNLI 在较小 $\alpha\approx0.2$ 即饱和；MGSM 区间更窄；
2. **语义信息并非必需**：语言-only 与 full-representation 两种 SAE 变体表现互有胜负，语义/上下文信息的有无对效果的影响是任务依赖的；
3. **多语言质心与英语参考表现相近**：参考选择的影响小于"是否保留语义信息"的影响；
4. **简单缩放与隐藏空间 top-$k$ 都不奏效**：Hidden-state scaling 几乎等于基线（54.3 vs 54.5），Hidden Top-k 仅 +1.5 pp，说明**SAE 的稀疏分解对隔离有效语言信号至关重要**；
5. **最佳干预层位于第 47 层**（紧随模型输出之前），第 6 层增益接近（13.9 pp），表明中后期层均承载较强的语言可分性。

## 7. 优点

- **轻量化**：完全推理时、无需训练、无参数更新，适合资源受限或低资源语言场景；
- **可解释性强**：基于 SAE 的稀疏特征使干预对象可定位、可解释；
- **方法通用**：不依赖英语为中心的表示假设（多语言质心同样有效）；
- **实验设计全面**：含层扫描、强度扫描、固定 $\alpha$ 测试、多组消融基线；
- **即插即用**：仅在残差流最后提示位置注入一次向量，不破坏模型主体结构；
- **开源代码**：提供 GitHub 仓库便于复现。

---

## 8. 不足与局限

1. **模型覆盖有限**：仅在 Gemma-3-12B-it（搭配 Gemma Scope 2 SAE）上验证；其他模型族（如 LLaMA、Qwen、DeepSeek 等）尚无可直接使用的 SAE，需自行训练，迁移性未知；
2. **干预层与超参的敏感性**：依赖验证集选 $\alpha$ 和干预层（第 47 层），不同任务最佳值差异较大（MGSM 几乎不增益），实际部署时仍需调参；
3. **增益分布不均**：XNLI 上德语下降 2.5 pp，MGSM 上日语下降 0.5 pp；表明方法**对某些语言可能带来副作用**，未做失败案例深入分析；
4. **未做统计显著性检验**：报告单点准确率，无置信区间或多随机种子评估，结果波动幅度未量化；
5. **依赖高质量平行语料**：特征识别需 FLORES-200 类对齐语料，对于无平行资源的极端低资源语言不可直接应用；
6. **数据集数量与规模受限**：XCOPA/XNLI 每语 400 例、MGSM 仅 200 例，可能不能完全反映真实性能；
7. **未涉及长文本、对话或开放式生成任务**：评估集中在判别式与短答案任务，对开放式多语言生成的有效性未经验证；
8. **SAE 训练成本被忽略**：作者将 SAE 当作"现成工具"，但实际训练 SAE 本身需大量算力与数据，文中未讨论这一上游成本。
