带可验证奖励的强化学习（RLVR）在训练大语言模型智能体方面效果显著。然而，终端奖励仅提供粗粒度的轨迹级监督，导致成功行为、反复出现的错误与偶然性选择在同一结果信号中纠缠不清。现有的智能体自蒸馏方法借助自然语言技能来丰富稀疏监督，但外部检索的技能或由更强模型从单一轨迹中提取的技能，可能与当前经验不匹配、超出策略自身能力范围，或仅具有路径特异性。我们提出群体反思自蒸馏（GRSD），从策略自身已验证的采样轨迹中提取能力对齐且具有结果区分性的指导信号。对于每个提示，策略对同策略组中每条已验证轨迹进行反思，并通过停止梯度快照对比成功与失败轨迹所产生的反思，进而构建群体级的特权指导信号。在该指导信号的条件下，自教师通过调节基于结果的优势来细化轮次级信用分配，同时保留由验证器所确定的学习方向。在多种智能体环境和不同模型规模上的实验表明，GRSD 始终优于具有竞争力的基线方法，并能更有效地泛化到未见过的任务。

## Abstract
Reinforcement learning with verifiable rewards (RLVR) is effective for training large language model agents. However, terminal rewards provide only coarse trajectory-level supervision, leaving successful behaviors, recurring mistakes, and incidental choices entangled in the same outcome signal. Existing agentic self-distillation methods enrich sparse supervision with natural-language skills, but skills retrieved externally or extracted from a single trajectory by stronger models may mismatch current experience, exceed the policy's capability, or remain path-specific. We propose Group-Reflective Self-Distillation (GRSD), which derives capability-aligned and outcome-discriminative guidance from the policy's own verified rollouts. For each prompt, the policy reflects on each verified trajectory in an on-policy group, and a stop-gradient snapshot contrasts the resulting reflections from successful and failed rollouts to construct group-level privileged guidance. Conditioned on this guidance, a self-teacher refines turn-level credit assignment by modulating outcome-based advantages while preserving the verifier-determined learning direction. Experiments across multiple agentic environments and model scales demonstrate that GRSD consistently outperforms competitive baselines and generalizes more effectively to unseen tasks.

# GRSD：面向智能体强化学习的群体反思自蒸馏——论文总结

## 一、核心问题与研究动机

带可验证奖励的强化学习（RLVR）已成为训练大语言模型智能体的主流范式（如 GRPO），但其依赖的终端奖励仅提供粗粒度的轨迹级监督信号。在多轮交互场景下，单个轨迹中成功行为、反复出现的错误与偶然选择被同一成功/失败标签纠缠，导致：
- 信用分配粒度过粗，无法识别对最终结果起决定性作用的关键回合；
- 现有自蒸馏方法（如 Skill-SD、SDAR）的技能来源存在两类局限：① 外部检索技能可能与当前提示或交互状态不匹配；② 由更强模型从单条轨迹中提取的技能可能超出当前策略能力边界，且缺乏跨成功/失败轨迹的对比，易陷入路径特异性。

论文提出两个关键挑战：① 如何使策略从自身同策略经验中提取能力对齐的指导；② 如何对比同提示下的多条采样轨迹，识别决定成败的关键行为。

## 二、方法论：核心思想与关键技术细节

### 2.1 整体框架

**GRSD（Group-Reflective Self-Distillation）** 由两阶段构造特权指导信号，并基于该指导信号实现回合级信用再分配，全程推理阶段不使用特权信息。

### 2.2 阶段 A：策略本征自反思（Policy-Native Self-Reflection）

每条已完成轨迹 $\tau_i$ 经验证器奖励 $R_i$ 与二元结果标签 $b_i \in \{0,1\}$ 标注后，由同策略快照 $\pi_{\theta_{\text{old}}}$ 按反思指令 $p_{\text{ref}}$ 生成轨迹级技能：

$$s_i \sim \pi_{\theta_{\text{old}}}(\cdot \mid x, \tau_i, b_i, p_{\text{ref}})$$

外部固定裁判 $J$ 给出 0–3 分的反思质量评分 $r_i^{\text{ref}}$，组内归一化得到反思优势 $A_i^{\text{ref}} = \text{Norm}_G(r_i^{\text{ref}})$，用于训练反思能力本身（prompt 与任务目标解耦）。

### 2.3 阶段 B：群体级指导构造（Group-Level Guidance Construction）

对同一提示 $x$，按结果标签分组：

$$S_x^+ = \{s_i \mid b_i = 1\}, \quad S_x^- = \{s_i \mid b_i = 0\}$$

停止梯度快照 $\pi_{\bar{\theta}}$（$\bar{\theta} = \text{sg}(\theta_{\text{old}})$）按指导合成指令 $p_{\text{guide}}$ 对比两个技能集合，生成紧凑的 DO/AVOID 指导信号：

$$z_x \sim \pi_{\bar{\theta}}(\cdot \mid x, S_x^+, S_x^-, p_{\text{guide}})$$

该构造仅作特权文本上下文，无梯度回流。仅在混合结果组（同时存在成功与失败轨迹）激活，标记 $m_x = 1$；否则回退至标准 GRPO。

### 2.4 回合级自蒸馏（Turn-Level Self-Distillation）

为回合 $t$ 构造纯学生上下文与指导增强教师上下文：

$$c_{i,t}^{\text{stu}} = C(x, H_{i,t}), \quad c_{i,t}^{\text{tea}} = C(x, z_x, H_{i,t})$$

冻结快照在两上下文下对采样动作的对数似然差 $\Delta_{i,t} = \frac{1}{L_{i,t}}\sum_{k=1}^{L_{i,t}} \bigl[\log \pi_{\bar{\theta}}(y_{i,t,k} \mid c_{i,t}^{\text{tea}}) - \log \pi_{\bar{\theta}}(y_{i,t,k} \mid c_{i,t}^{\text{stu}})\bigr]$ 经符号对齐 $q_{i,t} = \text{sign}(A_i)\Delta_{i,t}$、指数化、组内归一化与截断得到调制分数 $\hat{q}_{i,t}$，进而调制轨迹级优势：

$$\hat{A}_{i,t} = A_i\,(1 + \lambda \hat{q}_{i,t}\,m_x)$$

要求 $\lambda \bar{G} < 1$ 保证调制不翻转符号，验证器决定更新方向、引导分支调节强度。

### 2.5 总体目标

$$\mathcal{L}(\theta) = \mathcal{L}_{\text{task}}(\theta) + \beta \mathcal{L}_{\text{KL}}(\theta; \pi_{\text{ref}}) + \alpha \mathcal{L}_{\text{ref}}(\theta)$$

任务损失采用裁剪 GRPO 代理但优势替换为 $\hat{A}_{i,t}$；反思损失只监督反思 token 序列 $s_i$。理论分析给出三个命题：① 群体对比的方差缩减（Proposition 1）；② 有界正调制 $\hat{A}_{i,t}$ 与 $A_i$ 同号且相对扰动不超过 $\delta = \lambda \bar{G}$（Proposition 2）；③ 调制等价于对裁剪 GRPO 代理的正向再加权（Proposition 3）。

1. **聚合性能领先**：跨 3 个骨干取平均，GRSD 在 ALFWorld 上比 GRPO 提升 **+5.5%**，SearchQA 提升 **+2.7%**，WebShop Score/Succ 分别提升 **+4.8% / +7.2%**；

4. **泛化能力**：ALFWorld Unseen 上平均成功率 83.6%，较 GRPO/SDAR 高 **+8.2% / +6.0%**，在 Pick2、Cool 任务上增益尤为突出；
5. **消融结论**：群组聚合、失败反思、回合级调制均不可缺，策略本征反思优于外部模型反思；
6. **超参结论**：中等 $\alpha=0.01$ 与 $\lambda=0.5$ 最优，过小监督不足，过大则挤压任务目标。

## 七、优点与亮点

- **方法论创新**：首次将“策略本征反思 + 同提示成功/失败对比”引入智能体 RL，不依赖外部技能库或更强模型，避免能力错配与路径特异；
- **理论严谨**：三个命题共同证明 GRSD 是对裁剪 GRPO 的有界正再加权，保持验证器方向的信用分配单调性；
- **训练-推理解耦**：所有指导信号仅用于训练期调制，**推理时不增加任何开销**，可与现有 GRPO 流程无缝替换；
- **可扩展性**：在 1.7B / 3B / 7B 不同规模上一致验证，主体框架与骨干无关；
- **实验透明度高**：算法伪代码、提示模板、超参表、墙钟时间、专家样例均完整披露，方便复现；
- **训练成本可控**：相比 GRPO 仅多 17%，相对 SDAR 由于指导更紧凑反而缩短教师前向传播。

## 八、不足与局限

- **算力 / 训练规模**：仅 8×H100 单节点、240–600 步更新，未报告更长程（如 7B 模型上千步）训练是否仍保持优势；
- **混合组依赖**：依赖同提示 rollout 组中同时存在成功与失败轨迹，当策略已收敛到全成功时指导将自动失效，文中虽设 fallback 回 GRPO，但该情形下的渐近行为缺乏讨论；
- **裁判依赖**：反思能力训练依赖外部 DeepSeek-V4-Flash 裁判（评分 0–3），该裁判的可靠性直接影响反思优势信号，但论文未做裁判消融；
- **任务覆盖**：环境仅 3 类（ALFWorld、SearchQA、WebShop），对更复杂的工具调用链、软件工程类长程任务（如 SWE-Bench、CodeAct）等缺乏验证；

- **潜在偏差风险**：反思评判员对某些风格可能存在隐性偏好；判分截断到 0–3 整数尺度可能造成反思优势信号量化粗糙；
- **环境步骤限制**：ALFWorld 最多 50 步、WebShop 15 步，对极长程任务的可扩展性尚待检验。
