## Abstract
We present PRIMAL3, an ultra-large-scale learning-based framework for multi-agent pathfinding (MAPF) that integrates reinforcement learning, topology-aware communication, LaCAM3-guided training, and PIBT-based action refinement. PRIMAL3 targets failures at topologically critical states, where agents must coordinate decisively around bottlenecks, dead ends, and persistent conflicts. Each agent is represented using features derived from cut vertices, dead-end regions, shortest-path distances, and blocking estimates. Two complementary graphs capture agent interactions: a same-direction following graph propagates multihop context along compatible paths, while a different-direction conflict graph differentiates agents competing for shared space through masked attention and relative features. During training, we propose to let policy entropy identify uncertain agents, for which LaCAM3 provides confidence-triggered action interventions and label-smoothed imitation targets. During execution, a priority-aware PIBT module refines the proposed joint actions using persistent, learned, and distance-aware priorities together with policy-aware fallback preferences while maintaining collision-free execution. The resulting framework combines learned exploration with structured expert guidance without requiring LaCAM3 at inference. Experiments demonstrate that PRIMAL3 substantially outperforms state-of-the-art learning-based baselines and scales to ultra-large instances with up to city-level 100,000 agents. Real-world experiments further demonstrate the feasibility of deploying PRIMAL3 on physical robotic systems and ablation studies validate the individual contributions the components we proposed. ### 2.5 推理期：优先级感知 PIBT 精炼

PIBT 模块使用**复合优先级**：

$$\rho_i(t) = w_{age}\cdot \tau_i(t) + w_{prio}\cdot s^{prio}_{\theta,i}(o^i_t)$$

其中 $\tau_i(t)$ 为等待时长（persistent priority），$s^{prio}_{\theta,i}$ 为学习得到的优先级头，辅以**距离感知优先级**与**策略感知回退偏好**。当策略给出动作 $u$ 时，按下式选择 PIBT 实际执行动作：

$$p_i(u) = [\bar{p}_i(u)]^+,\quad p'_i(u) = \frac{p_i(u)}{\sum_{u'\in U} \bar{p}_i(u')},\quad \hat{u}^{i}_t = \arg\max_u p_i(u)$$

其中 $[x]^+ = \max(x, 0)$，并配合回退到停留动作以维持无碰撞执行。

## 三、实验设计

### 3.1 数据集与场景

- **地图**：以 $32 \times 32$ 栅格地图为主要基准（含随机障碍、瓶颈、死胡同）。
- **智能体规模**：$N \in \{1000, 2000, 3000, 4000, 5000, 7500, 10000\}$ 的标准基准，以及扩展至 **$N=100{,}000$ 的城市级**超大规模实例。
- **场景类型**：随机地图、空旷地图及含死胡同/瓶颈的困难地图。

### 3.2 Baseline

主要对比对象包括：

- **PRIMAL / PRIMAL2**：同系列前代方法；
- **MAPF-GPT、RHCR**：其他大规模学习方法；
- **LaCAM3 / LaCAM**：作为 oracle / 教师方法的对比。

### 3.3 评估指标

- **成功率（SR）**：$\epsilon_{SR_N} = (1-\epsilon)^N$；
- **平均流速（throughput）**；
- **单步推理时延**；
- **缩放性曲线**：经验关系 $\lambda_N = -\ln SR_N \approx 1.46\times 10^{-4} N$，$R^2=0.966$。

## 五、实验数量与充分性

论文报告的实验较为系统化，主要包括：

1. **可扩展性曲线**：在 $N=1000\sim 10000$ 上做密集采样；
2. **超大规模实验**：$N=100{,}000$ 的城市级实例，验证方法的极限能力；
3. **消融实验**：分别验证
   - 双图通信中两个图各自的贡献（$\gamma_{conf},\gamma_{foll}$ 消融，提到 $\gamma_{foll}=0$ 时性能下降 60.5%，$\gamma_{conf}=0$ 时下降 48.0%）；

   - PIBT 精炼模块的有效性；

整体实验**较为充分**，覆盖了规模、组件、消融、真实部署四个维度；但基准对比基线数量相对有限，主要集中在"学习型方法"赛道，缺少与 ECBS、PP 等搜索式方法在相同大规模下的公平对比。

## 六、主要结论

- PRIMAL3 在 $N=1000\sim 10000$ 区间内显著超越现有学习型方法，成功率指标 $\lambda_N$ 与 $N$ 的经验关系为 $\lambda_N = 1.46\times 10^{-4} N$，呈现良好的**线性可扩展性**；
- 框架首次将基于学习的 MAPF 拓展到 **$N=100{,}000$ 的城市级规模**；
- **推理期无需调用 LaCAM3**，通过"训练时专家引导 + 推理时 PIBT 精炼"的解耦设计获得了实用部署性；
- 真实机器人实验证明了**仿真到真机的迁移可行**；
- 消融实验证实双图通信、熵触发的 LaCAM3 干预、PIBT 优先级精炼三者均为关键组件。

---

## 七、优点

- **训练-推理解耦**的设计巧妙：避免推理期对重型搜索的依赖，使部署成本大幅下降；
- **双图拓扑感知通信**显式区分同向跟随与异向冲突，比单一全连接图更契合 MAPF 的几何结构；
- **熵触发干预**机制具有自适应性质，仅在"必要时刻"调用 LaCAM3，兼顾学习效率和专家知识；
- **PIBT 优先级融合**引入"等待时长 + 学习优先级 + 距离"等多源信号，缓解了纯学习型策略在死锁处的脆弱性；
- 引入 **$10^5$ 智能体规模**，将学习型 MAPF 推向新的基准。

## 八、不足与局限

- **算力资源披露缺失**：GPU 型号/数量、训练时长、LaCAM3 调用频次均未明确，难以复现；
- **baseline 不够全面**：缺少与 ECBS、PP、LaCAM 等搜索式/混合式方法在 $10^4\sim 10^5$ 规模上的**直接公平对比**，无法判断"学习型方法在何种密度下真正优于搜索式方法"；
- **奖励函数 $\mathbf{A}^{conf},\mathbf{A}^{foll}$ 设计依赖专家先验**，其权重 $\gamma_{conf},\gamma_{foll}$ 在不同地图尺寸下的最优取值仍需人工调参（论文给出 $32\times32$ 的推荐 $(0.9,0.5)$，但泛化性证据有限）；
- **熵阈值 $\eta=0.464$ 为经验值**，对不同地图拓扑的敏感性未做系统分析；
- **真实机器人实验规模仍较小**，与 $10^5$ 仿真实验之间存在"规模鸿沟"，实际部署性能仍待大规模真机验证；
- 论文聚焦**离线集中式 MAPF**，对部分可观、异步执行、动态障碍等更现实约束未深入讨论。
