## 摘要
大语言模型（LLMs）近期在推理、规划和工具使用方面展现出强大能力，推动了新型自主智能体的出现。然而，基于LLM的智能体在需要精确动作优化和环境交互的长周期序贯决策任务中表现欠佳。强化学习（RL）虽然在序贯控制方面效果显著，但往往缺乏复杂场景所需的高层次抽象与任务分解能力。本文提出了一种大语言模型增强的强化学习智能体，将LLM驱动的规划与基于RL的动作优化相融合。所提出的架构利用LLM生成子目标、结构化计划和上下文引导，而RL智能体则通过与环境交互来优化底层动作。在序贯决策任务上的实验表明，相较于仅使用RL和仅使用LLM的基线方法，所提方法在样本效率、成功率和动作轨迹一致性方面均有提升。这种混合范式为构建更强大的自主系统指明了前景广阔的方向。

## Abstract
Large Language Models (LLMs) have recently shown strong capabilities in reasoning, planning, and tool-use, enabling new forms of autonomous agents. However, LLM-based agents struggle with long-horizon sequential decision tasks that require precise action optimization and environment interaction. Reinforcement Learning (RL), while effective for sequential control, often lacks the high-level abstraction and task decomposition abilities needed for complex scenarios. This paper introduces an LLM-Augmented Reinforcement Learning Agent that integrates LLM-driven planning with RL-based action optimization. The proposed architecture leverages the LLM to generate subgoals, structured plans, and contextual guidance, while the RL agent refines low-level actions through interaction with the environment. Experiments on sequential decision tasks demonstrate improved sample efficiency, higher success rates, and more coherent action trajectories compared to RL-only and LLM-only baselines. This hybrid paradigm highlights a promising direction for building more capable autonomous systems.

## 2. 方法论

### 2.1 整体架构（模块化设计）

系统由四大组件构成：
1. **LLM 高层规划器**：生成子目标 $g_t$ 与结构化动作序列。
2. **RL 核心**：基于环境状态执行低层动作优化。
3. **记忆模块**：存储轨迹、计划与反馈，支持策略更新与计划修正。
4. **环境**：提供状态转移与奖励信号。

### 2.2 LLM 驱动的高层规划

- **提示工程（Prompting）**：LLM 接收当前状态 $s_t$ 与任务文本描述，输出三部分内容：
  - 子目标 $g_t$
  - 高层动作序列
  - 上下文推理（contextual reasoning）
- **动作分解（Action Decomposition）**：将复杂任务拆解为可执行单元，例如「导航至目标 → 避障 → 收集物体」。
- **任务抽象（Task Abstraction）**：将环境细节抽象为符号表示，支撑长视野规划。

### 2.3 RL 策略优化

- **目标函数**（标准 RL 设定）：
$$
J(\pi) = \mathbb{E}_\pi \left[ \sum_{t=0}^{T} \gamma^t r_t \right]
$$
- **策略条件化**：策略同时接收环境状态 $s_t$ 与 LLM 生成的子目标 $g_t$，即 $\pi(a_t \mid s_t, g_t)$。
- **LLM 引导的奖励塑形（Reward Shaping）**：将 LLM 的语义反馈转化为辅助奖励，例如：
  - 「你接近目标」→ 正向塑形（positive shaping）
  - 「你偏离计划」→ 负向塑形（negative shaping）
- **改进探索**：LLM 子目标降低随机探索需求，使探索更加目的化。

### 2.4 交互循环

定义如下七步迭代过程：
1. 环境提供状态 $s_t$
2. LLM 生成子目标 $g_t$ 与高层计划 $\pi^H$
3. RL 策略选择低层动作 $a_t$
4. 环境返回下一状态 $s_{t+1}$ 与奖励 $r_t$
5. 记忆模块存储轨迹
6. RL 更新策略
7. LLM 必要时修正计划

## 6. 主要结论与发现

- **混合 LLM+RL 架构在所有三个环境中均取得最优性能**：
  - Gridworld 成功率 93%（vs. RL-Only 72%、LLM-Only 65%）

- **消融发现**：
  - 移除子目标导致性能下降约 17%，为最关键模块。
  - 移除奖励塑形下降约 12%。
  - 随机子目标造成最严重的性能崩溃（–39%），验证结构化 LLM 引导的必要性。
- **定性发现**：混合智能体的轨迹更连贯、目的性更强（例如在 pick-and-place 任务中 8 步到达钥匙，而 RL-Only 需 ~40 步）。
