## Abstract
On-policy (Self-)Distillation (OPD / OPSD) has shown strong potential for post-training large language models (LLMs). However, existing methods still rely heavily on external supervision, including ground-truth signals, environmental feedback, or guidance from larger models, and therefore fall short of genuine "self"-distillation. In this study, we show that on-policy self-distillation can be achieved using only a model's own generations via internal consistency. We propose Unsupervised On-Policy Self-Distillation (U-OPSD). U-OPSD first samples multiple rollouts and constructs a pseudo-solution by majority vote under a self-consistency threshold. It then conditions a teacher distribution on the shortest pseudo-solution and distills it into prefixes of the model's longest incorrect completion, allowing the model to correct itself precisely where it is confidently wrong. Across diverse benchmarks, base models, and training settings, U-OPSD consistently improves over the base models and matches or surpasses supervised methods with ground truth (GT), such as OPSD and GRPO. On AIME24, AIME25, HMMT25, MATH500, and AMC23, U-OPSD improves over the base model by 8.5% and 10.7% on Qwen3 non-thinking mode at the 4B and 8B scales, respectively, and outperforms OPSD by an average of 3.2% and 2.3%. In thinking mode, U-OPSD remains on par with OPSD, outperforming it by 0.9% at 4B and matching it at 8B, while surpassing GRPO by 0.7% and 1.1%, respectively.

## 1. 核心问题与研究动机

- **既有方法的局限性**：当前主流的 LLM 后训练范式——监督微调（SFT）、RLVR/GRPO、知识蒸馏、同策略蒸馏（OPD）、同策略自蒸馏（OPSD）——均在不同程度上依赖**外部监督**（真实标签、环境反馈、更强教师模型、in-context 示例或特权观测）。
- **"自"蒸馏名不副实**：以 OPSD 为例，虽然教师与学生共享同一组参数，但使教师更强的"特权上下文"（如真实解题过程 $y^\star$）仍来自外部；学生并未真正从自身生成中学习。
- **核心提问**：能否完全摆脱外部监督，仅利用模型自身的多次采样与内部一致性，构造出一个不依赖真实标签的"特权教师"，实现**真正的同策略自蒸馏**？
- **应用动机**：摆脱对昂贵、稀缺、不可靠的人类标注的依赖，使 LLM 后训练可扩展到海量无标注数据。

## 2. 方法论：U-OPSD

### 2.1 核心思想

利用"模型多条独立 rollout 之间的多数共识"作为伪标签：在达成自一致性阈值的题目上，将**最短的共识 rollout**当作"伪解题过程 $y^+$"，并将其作为教师分布的特权上下文；对**不一致的 rollout $y^-$**执行**前缀级 token 级蒸馏**，从而在模型"自信地犯错"的位置精准注入纠错信号。

### 2.2 三步流程

- **(1) Sample**：对每个无标注 prompt $x \sim \mathcal{U}$，独立采样 $G$ 条 rollout $y^{(1)}, \ldots, y^{(G)} \sim \bar{\pi}(\cdot|x)$，其中 $\bar{\pi} \triangleq \pi_{\text{sg}[\theta]}$ 是带 stop-gradient 的当前策略副本。每条 rollout 通过大括号匹配扫描器解析最后 `\boxed{...}` 中的最终答案 $a^{(g)} = \mathrm{Ans}(y^{(g)})$，并做规范化（分数形式、末尾小数转分数等）。
- **(2) Vote**：在有效答案中做多数投票得到伪答案
  $$\tilde{a}(x) = \arg\max_a \sum_{g=1}^{G} \mathbb{1}[a^{(g)} = a]$$
  并计算自一致性分数
  $$c(x) = \frac{1}{G} \sum_{g=1}^{G} \mathbb{1}[a^{(g)} = \tilde{a}(x)]$$
  仅当 $c(x) \geq \tau$（默认 $\tau = 1/2$）时该 prompt 才参与训练；否则丢弃。rollout 被划分为共识集 $Y_x^+$ 与分歧集 $Y_x^-$；无效（无法解析）rollout 同时排除在两集合之外。
- **(3) Distill**：选择 $y^+ \in \arg\min_{y \in Y_x^+} |y|$（默认最短共识 rollout）作为教师参考，将教师分布 $\bar{\pi}(\cdot|x, y^+, y_{<n}^-)$ 蒸馏到学生 $\pi_\theta(\cdot|x, y_{<n}^-)$ 上，作用于所有分歧轨迹的每个 token 前缀。

### 2.3 目标函数

U-OPSD 的整体损失为：

$$L_{U-OPSD}(\theta) = \mathbb{E}_{x \sim \mathcal{U}} \mathbb{E}_{\{y^{(g)}\}_{g=1}^G \sim \bar{\pi}(\cdot|x)} \left[ \mathbb{1}[Y_x^- \neq \emptyset] \frac{1}{|Y_x^-|} \sum_{y^- \in Y_x^-} \frac{1}{|y^-|} \sum_{n=1}^{|y^-|} D_\beta \left( \bar{\pi}(\cdot | x, y^+, y_{<n}^-) \| \pi_\theta(\cdot | x, y_{<n}^-) \right) \right]$$

与 OPSD 的核心区别仅在于把真实解 $y^\star$ 替换为伪解 $y^+$，并把蒸馏目标限定为不一致 rollout：

$$L_{OPSD}(\theta) = \mathbb{E}_{(x,y^\star) \sim S} \mathbb{E}_{y \sim \bar{\pi}(\cdot|x)} \sum_{t=1}^{|y|} D_\beta \left( \bar{\pi}(\cdot | x, y^\star, y_{<t}) \| \pi_\theta(\cdot | x, y_{<t}) \right)$$

默认采用 **前向 KL 散度**（即 $\beta=0$ 的 Jensen-Shannon 散度极限），结合 per-token 点式裁剪以稳定训练；教师固定为初始策略（即 LoRA 适配器关闭下的基础权重）。

### 2.4 算法伪代码要点

```
Require: prompt x; student πθ; detached teacher π̄; rollouts G; threshold τ
1: sample y^(1), ..., y^(G) ~ π̄(·|x)
2: a^(g) ← Ans(y^(g))    # ∅ if unparsable
3: ã(x) ← plurality of {a^(g) : a^(g) ≠ ∅};  c(x) ← (1/G) Σ 1[a^(g) = ã(x)]
4: Y+_x ← {y^(g) : a^(g) = ã(x)};  Y-_x ← {y^(g) : a^(g) ∉ {ã(x), ∅}}
5: if c(x) < τ or Y-_x = ∅: return   # 不可信投票或无纠错目标
6: select y+ ∈ Y+_x (default: shortest), B-_x ⊆ Y-_x (default: one uniform)
7: minimize (1/|B-_x|) Σ_{y-∈B-_x} (1/|y-|) Σ_t D_β( π̄(·|x,y+,y-_<t) ‖ πθ(·|x,y-_<t) )
```

### 2.5 与相关方法关系

- **vs. OPSD**：去掉对真实解题过程 $y^\star$ 的依赖；其余 OPSD 训练配方（教师冻结、前向 KL、点式裁剪、LoRA rank=64）原样保留。
- **vs. GRPO/TTRL/RENT/Intuitor**：这些方法把共识信号压缩为**标量奖励**，而 U-OPSD 用共识构造**特权教师分布**并执行**密集 token 级**蒸馏，监督粒度更细。
- **vs. 多数投票自训练**：U-OPSD 不是在 teacher-forced 前缀下模仿 $y^+$，而是把 $y^+$ 当作条件去纠错学生自己的不一致轨迹。

- **跨模式/跨规模泛化**：在 4B、8B、30B-A3B 以及非思考/思考/Instruct 三种模式下均观察到一致增益，证明方法对架构与训练模式不敏感。

## 8. 局限性与未来方向

- **伪标签噪声**：在非思考、低自一致率场景下，伪标签正确率仅 50–70%，仍有相当比例"伪共识但实际错误"被当作教师参考，可能系统性放大错误路径；作者坦言这是"known limitation"。
- **多次采样开销**：$G=8$ 条 rollout + 4096 token completion 使单次训练时长约为 OPSD 的 2.5 倍；规模化部署需权衡算力成本。
- **可解析答案假设**：方法依赖 `\boxed{...}` 解析器，无法直接迁移到开放问答、代码生成、对话等非封闭答案任务；作者建议未来扩展到**结构性答案抽取**或**LLM-as-judge 验证**。
- **域外泛化未知**：实验仅在数学推理域验证；常识、代码、长文档推理上的有效性仍是开放问题。
- **缺乏多种子误差棒**：作者明确指出全部主表为单种子结果，多种子显著性检验尚未完成。
- **安全性/对齐影响**：训练完全依赖模型自身信号，可能放大已有偏差；论文未做 safety/biased-bench 评测。
- **未来工作**：作者列出（i）把伪标签构造与 verifier-free RL 结合；（ii）探索更长训练窗口下的固定 vs EMA 教师；（iii）把 U-OPSD 与课程学习/数据筛选结合以提升伪标签质量；（iv）扩展到多模态、多轮任务。

## 9. 复现性与代码

- 代码仓库：文中给出 GitHub 链接（`github.com/.../U-OPSD`），包含基于 OpenRLHF/vLLM 的训练与评测流水线。

**一句话总结**：U-OPSD 通过"多条 rollout 多数共识选最短作伪解题过程 + 对不一致 rollout 做前缀级前向 KL 蒸馏"的范式，首次实现了**完全无外部监督**的 LLM 同策略自蒸馏，并在多模型、多模式下稳定超越需要真实解的监督 OPSD，为无标注数据下的 LLM 后训练开辟了新路径。
