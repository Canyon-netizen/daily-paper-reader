## 摘要
基于大语言模型的多智能体系统近期在复杂的长时序任务中展现出强大潜力。然而，现有方法主要依赖粗粒度的提示词级差异化，且未针对多样化子任务进行参数自适应，导致智能体之间的异质性不足、专门化能力有限，从而在需求复杂的任务上形成性能瓶颈。为解决此问题，我们提出了面向任务的多智能体系统与角色-子任务专家混合（MoRSE），在任务结构层面与参数层面同时通过（角色, 子任务）条件化的专门化来区分各智能体。为了在任务结构层面使智能体的职责显式化，我们将面向任务的多智能体系统形式化为一个依赖感知的子任务有向无环图，并为每个智能体分配特定的（角色, 子任务），在协作智能体之间引入任务级专门化。此外，为应对多样化的角色与子任务参数自适应需求，我们提出了一个动态的（角色, 子任务）LoRA 专家混合模块，并配备基于原型的子任务语义路由器，在共享的大语言模型基座上以低成本方式增强智能体的参数级专门化。为在稀疏任务奖励下稳定地协同优化专家与路由器，我们进一步提出了一种带双层信用分配的分层组相对策略优化方法，将专家更新与路由决策所引入的跨路由方差隔离开来，从而将专家质量与路由质量解耦。在三种基座模型上的代码生成基准实验表明了我们方法的有效性，整体任务性能与逐步性能均得到提升，且训练所得的专门化能力可泛化至未见的任务类别和领域。

## Abstract
Large language model-based multi-agent systems have recently shown strong potential for complex, long-horizon tasks. However, existing methods mainly rely on coarse prompt-level differentiation without parameter adaptation for diverse subtasks, resulting in insufficient inter-agent heterogeneity and limited specialized capability that bottleneck performance on tasks with complex requirements. To address this, we introduce a Task-Oriented Multi-Agent System with Mixture of Role-Subtask Experts (MoRSE) that distinguishes agents with (role, subtask)-conditional specialization at both the task structure and parameter levels. To make agents' responsibility explicit at the task structure level, we formulate a task-oriented multi-agent system that decomposes each task into a dependency-aware Directed Acyclic Graph of subtasks and assigns each agent a specific (role, subtask), introducing task-level specialization across collaborating agents. Additionally, to address the diverse role and subtask parameter adaptation demands, we propose a dynamic Mixture of (role, subtask) LoRA Experts module with a prototype-based semantic router for subtasks, augmenting agents with parameter-level specialization on a shared LLM substrate cost-effectively. Then, to co-optimize experts and router stably under sparse task rewards, we further propose a hierarchical group-relative policy optimization with two-layer credit assignment that isolates expert updates from the cross-route variance introduced by routing decisions, disentangling expert quality from routing quality. Experiments on code-generation benchmarks across three backbones demonstrate the effectiveness of our approach, with improvements in both whole-task and step-wise performance, and the gains from trained specialization generalize across held-out task categories and domains.

## 1. 核心问题与研究动机

现有基于 LLM 的多智能体系统（MAS）主要依赖**粗粒度的提示词级角色区分**，而没有针对多样化子任务进行参数自适应，导致两个层面的不足：

- **任务结构层异质性不足**：在冻结基座模型上仅靠提示词分配角色，智能体输出趋于冗余（如图1所示，MacNet 中输出相似度中位数从 prompt 到 output 上移 +0.14）。
- **参数层异质性不足**：即使引入角色级 LoRA 适配（MoRAgent、AT-GRPO、MARTI 等），同一复杂任务内部多种子任务的差异需求也无法被一个共享基座满足。

**研究目标**：在任务结构与参数两个层级同时实现 `(role, subtask)` 条件化专门化，提升复杂长链路任务（代码生成）上的整体与逐步性能。

## 2. 方法论

MoRSE 由三个紧密耦合的模块组成：

### 2.1 任务导向多智能体系统（ToMAS）

将任务实例 $T$ 分解为依赖感知的 DAG $G=(V,E)$，每个节点 $v_i$ 携带角色 $r_i$ 和子任务描述 $s_i$。按拓扑序执行：

$$\text{Merger:}\ C_i \sim p(\cdot \mid r=\text{merge},\, T,\, \{y_j\}_{j\in \text{Pa}(i)};\,\theta_i^{r})$$

$$\text{Executor:}\ y_i \sim p(\cdot \mid r=\text{execute},\, T,\, s_i,\, C_i;\,\theta_i^{r})$$

每个 DAG 节点配套**规则化验证器**，输出逐步奖励 $u_i \in [0,1]$，并阻断不合格产物传播以防止误差累积。

### 2.2 角色-子任务 LoRA 专家混合（MoLE）

在冻结基座 $\theta_0$ 上挂载两组 LoRA 专家：

- **角色专家池** $\Phi_r$：每个角色 $r$ 对应一个专家 $e(r)\in\Phi_r$；
- **子任务专家池** $\Phi_s$：共享 $K_s$ 个专家，通过原型路由器选 top-K。

每次调用的有效参数：

$$\theta_i = \theta_0 + \Delta\theta_i,\qquad W_\ell^{(i)} = W_\ell + \sum_{k\in E_i} w_k\cdot \alpha\rho\, B_{\ell,k} A_{\ell,k}$$

其中激活集 $E_i = \{e(r_i)\}\cup E_{s,i}$，$w_k = 1/|E_i|$。

**原型语义路由器**：

$$z_k = \frac{h_\eta(s_i)^\top p_k}{\|h_\eta(s_i)\|_2\|p_k\|_2},\quad \pi_\psi(k\mid s_i) = \mathrm{softmax}(z)_k$$

训练时 top-K 随机采样，推理时贪心选取。

### 2.3 分层 GRPO 双层信用分配（HGRPO）

对每个节点采样 $B$ 条路由 × $M$ 个候选，得到 step 奖励 $u_i^{(b,m)}$，构造两层优势：

$$A^{(b,m)}_{\text{within}} = \frac{u_i^{(b,m)}-\mu^{(b)}}{\sigma^{(b)}+\epsilon},\qquad A^{(b)}_{\text{cross}} = \frac{\mu^{(b)}-\bar{\mu}}{\sigma_C+\epsilon}$$

对应双层损失：

$$L_{\text{LoRA}} = -\sum_{b,m} A^{(b,m)}_{\text{within}}\cdot \log p\!\left(y_i^{(b,m)}\mid T,r_i,s_i,C_i;\,E_i^{(b)}\right)$$

$$L_{\text{router}} = -\alpha_\pi\sum_b A^{(b)}_{\text{cross}}\cdot \log \pi_\psi(E_{s,i}^{(b)}\mid s_i)$$

**核心结论（Proposition 3.1）**：HGRPO 与标准 GRPO 共享期望梯度，但在有限组大小时 LoRA 专家梯度方差严格更小：

$$\mathrm{Var}[g_{\text{LoRA}}^{\text{HGRPO}}] = \mathrm{Var}[g_{\text{LoRA}}^{\text{single}}] - \sigma_C^2\cdot \mathbb{E}\!\left[\|\nabla_\Phi\log p\|^2\right]$$

其中 $\sigma_C^2 = \mathrm{Var}_b[\mu^{(b)}]$ 为跨路由方差。该形式在归一化版本（Corollary G.1）下以 $\mathbb{E}_b\!\left[\dfrac{(\mu^{(b)}-\bar\mu)^2}{(\sigma^{(b)}+\epsilon)^2}\right]$ 重加权保留。

## 6. 主要结论与发现

1. **结构层有效**：未训练的 MoRSE base 在 All set 上已超越所有多智能体基线（Qwen3-4B 上 SRDD Exec 77.00% vs. MacNet 61.81%）。
2. **参数层叠加有效**：训练后的 MoRSE 在 Test 集的所有指标上均取得最佳（Qwen3-4B SRDD Exec 86.25%，Llama-3.1-8B Exec 87.34%）。
3. **OOD 泛化**：在 8 类别留出的 SRDD 上，MoRSE 较 MoRSE base 提升 Exec +6.25%（Qwen3-4B）、+7.5%（Llama-3.1-8B），并优于标准固定 LoRA 微调。
4. **HGRPO 必要性**：C vs. D 消融显示无分层信用时 MoLE 训练脆弱（甚至低于 MoRSE base），标准 GRPO 在 epoch 7–8 损失崩溃至 ≈ −11.5，HGRPO 全程稳定在 ±0.05。
5. **路由器未塌缩**：top-2 路由的熵为 1.009 nats（远高于固定对的 ln 2 = 0.693），呈"通用专家 + 切换第二槽"的结构。
6. **基座越强，训练增益越小**：Gemma-4-31B 上 LoRA 可训练参数占比仅 0.048%（Qwen3-4B 为 0.170%），增量更小。

## 7. 优点

- **双层异质性建模**：首次同时显式建模任务结构层 DAG 和参数层 `(role, subtask)` 因子化专家；
- **理论保证**：HGRPO 的方差缩减具有严格的命题与证明（Prop 3.1 + Cor G.1），与 GRPO 共享期望梯度；
- **覆盖极限定理（Thm L.2）**：证明单一 rank-$\rho$ 共享 LoRA 在角色-子任务子空间发散时存在严格覆盖上界 $\bar p(V_s)\leq (1+\sqrt{1-\Delta})/2$，为多专家必要性提供理论支撑；
- **预算对齐实验设计严谨**：在激活参数、全部参数、采样与优化预算三层面同时匹配对照；
- **评测独立性**：用与训练奖励、评测嵌入模型族系不同的 LLM 做执行验证复核，缓解了指标泄露风险；
- **训练/推理高效**：top-2 路由 + 共享基座，推理成本接近单模型。
