## 摘要
智能体强化学习使大语言模型（LLM）智能体能够通过与环境交互进行学习，但稀疏的轨迹级奖励仅揭示最终是否成功，而无法识别哪些中间决策应获得信用。仅在训练阶段使用的特权技能可通过允许同一份冻结的策略快照对来自无技能轨迹的固定词元进行重新打分，同时以任务匹配的程序化技能为条件，从而提供更密集的监督。然而，现有方法未能同时完成三件事：跨交互步骤校准教师分数、将教师置信度与实际收益相关联，以及将所得信号融入原生奖励-优势函数的构建之中。我们提出了基于自蒸馏奖励塑形的智能体强化学习（ADRS），一个面向多轮语言智能体的、用于构建与收益关联的词元级信用的框架。ADRS 在每个步骤内对特权词元分数进行中心化和归一化处理，利用基于组内置信度-收益关联的、与收益相关联的教师价值优势（TVA）门控对其进行调制，并将门控后的词元信号融入原生强化学习信用构建中。这些组件共同回答了三个问题：教师偏好什么、该偏好何时与收益相关，以及它如何进入原生强化学习的信用通路，同时保持轨迹采样与推理过程不依赖技能。最后，在三个交互式基准上的实验表明，ADRS 在长视野任务上持续提升性能，且该增益在不同强化学习骨干、缩减数据设置、未知任务以及延长训练的情况下均能保持。为便于匿名评审，代码已发布于以下链接：https://github.com/gitrxh/ADRS-arxiv

## Abstract
Agentic reinforcement learning enables LLM agents to learn through interaction, but sparse trajectory-level rewards reveal success without identifying which intermediate decisions deserve credit. Training-only privileged skills can provide denser supervision by allowing the same frozen policy snapshot to rescore fixed tokens from skill-free trajectories while conditioned on task-matched procedural skills. Existing methods, however, do not jointly calibrate teacher scores across interaction steps, relate teacher confidence to realized returns, and integrate the resulting signal into native reward-to-advantage construction. We introduce Agentic Reinforcement Learning with Self-Distilled Reward Shaping (ADRS), a framework for constructing return-associated token-level credit for multi-turn language agents. ADRS centers and normalizes privileged token scores within each step, modulates them with a return-associated Teacher Value Advantage (TVA) gate based on within-group confidence--return association, and incorporates the gated token signal into native RL credit construction. Together, these components determine what the teacher prefers, when that preference is return-relevant, and how it enters the native reinforcement-learning credit path, while keeping rollouts and inference skill-free. Finally, experiments across three interactive benchmarks show that ADRS consistently improves performance on long-horizon tasks, with gains persisting across RL backbones, reduced-data settings, unseen tasks, and extended training. For anonymous review, our code is available at the following the link: https://github.com/gitrxh/ADRS-arxiv

# ADRS 论文总结：基于自蒸馏奖励塑形的智能体强化学习

## 一、核心问题与研究动机

在多轮语言智能体强化学习（agentic RL）中，训练信号通常仅为**稀疏的轨迹级回报**（trajectory-level reward），仅在任务终止时给出成功/失败反馈。这导致**时间信用分配**（temporal credit assignment）极为困难：现有无价值网络方法（如 GRPO、GiGPO）虽能在组内归一化最终回报，却无法识别中间哪些查询或动作值得正/负信用。

利用自然语言技能（procedural skills）提供子目标、动作规则与失败模式等密集监督是常见思路，但其使用面临三大技术挑战：

1. **分数校准（Score Calibration）**：原始教师对数概率 $\ell^T_{s,j}$ 受上下文长度、交互位置和回答组成影响，其偏移和量纲在不同交互步骤间**不可直接比较**——同一偏移在步骤 A 中表示强支持，在步骤 B 中可能仅为弱偏好。
2. **可靠性估计（Reliability Estimation）**：教师高置信度未必意味着高可靠性——高 token 似然可能仅反映语言熟悉度，而与最终实际收益 $R(\tau)$ 脱钩。
3. **信用整合（Credit Integration）**：将特权监督作为**独立辅助蒸馏目标**会绕开骨干自身的 reward-to-advantage 计算路径，导致 token 级更新与 GRPO/GiGPO 的组相对优势错位。

## 二、方法论：ADRS 框架

ADRS 通过三个耦合模块将"训练专用"的程序化技能转化为**回报关联的 token 级信用**，且 rollout 与推理阶段始终**不依赖技能**。

### 2.1 模块 1：步骤内相对特权打分（Within-Step Relative Privileged Scoring）

对由行为策略 $\pi_{\theta_b}$ 采样的固定 token，在**冻结快照** $\theta_b$ 下分别计算普通上下文与特权上下文（拼接 $\rho(x)\oplus h_s$）的对数概率 $\ell^b_{s,j}$、$\ell^T_{s,j}$（均 stop-gradient）。在每个交互步骤 $s$ 内进行**中心化与尺度归一化**：

$$b_s = \frac{1}{|\mathcal{V}_s|}\sum_{j \in \mathcal{V}_s} \ell^T_{s,j}, \quad q_{s,j} = \ell^T_{s,j} - b_s, \quad \hat{q}_{s,j} = \frac{q_{s,j}}{\sigma_q + \epsilon}$$

其中 $\sigma_q$ 为步骤 $s$ 内 $q$ 值的标准差。步骤共享分母保证：

$$\sum_{j \in \mathcal{V}_s} \hat{q}_{s,j} = 0$$

正 $\hat{q}_{s,j}$ 表明该采样 token 在步骤内获得高于平均的特权支持。该处理同时剥离了交互位置相关的整体置信度偏移，并对评分离散度的变化保持鲁棒。

### 2.2 模块 2：回报关联 TVA 可靠性门控（Return-Associated TVA Gate）

为判断教师信号是否与回报一致，ADRS 在选定的对比组内估计一个标量门控 $m_u$。提供两种粒度（一次训练只选其一）：

- **完成级 TVA（L2）**：与 GRPO 对齐，按同一 prompt 采样的轨迹为组，使用 pre-ADRS 完成回报。
- **步骤级 TVA（L3）**：与 GiGPO 对齐，以重复锚点状态定义可比交互步骤，使用自该状态起的 return-to-go。

组内单元置信度与软高置信度权重为：

$$\bar{\ell}^T_u = \frac{1}{|\mathcal{V}_u|}\sum_{(s,j) \in \mathcal{V}_u} \ell^T_{s,j}, \quad \alpha_u = \sigma\!\left(\bar{\ell}^T_u - \bar{\ell}^T_{\text{batch}}\right)$$

门控基于高/低置信度侧的回报对比：

$$\mu^+_g = \frac{\sum_{u\in g}\alpha_u R_u}{\sum_{u\in g}\alpha_u + \epsilon}, \quad \mu^-_g = \frac{\sum_{u\in g}(1-\alpha_u)R_u}{\sum_{u\in g}(1-\alpha_u)+\epsilon}, \quad d_g = \mu^+_g - \mu^-_g$$

经可选正尺度归一化后，门控为：

$$m_u = \text{sg}\!\left[\sigma\!\left(\tau \tilde{d}_{g(u)}\right)\right]$$

**Proposition 1（TVA 作为回报关联）**：忽略数值 $\epsilon$，在任意非退化组内有

$$d_g = \frac{\text{Cov}_g(\alpha, R)}{\bar{\alpha}_g(1-\bar{\alpha}_g)}$$

因此 TVA 符号与组内特权置信度-回报的**经验协方差**一致。组规模过小时取 $m=0.5$，关闭 TVA 则固定 $m=1$。

### 2.3 模块 3：教师引导的 token 级优势调制（Per-Token Advantage Modulation）

教师 token 奖励与塑形 token 奖励定义为：

$$r^T_{s,j} = \eta\, m_{s,j}\,\hat{q}_{s,j}, \qquad \tilde{r}_{s,j} = r^{\text{base}}_{s,j} + r^T_{s,j}$$

其中 $\eta \geq 0$ 控制教师信号幅度。ADRS 采用**双通路**整合：

- **轨迹通路**：将 $\tilde{r}$ 送入骨干原生信用构造得 $\text{Adv}_{\mathcal{B}}(\tilde{r})$，从而保留环境定义的完成方向。
- **token 通路**：在 prompt 组 $g$ 内对保存的 $r^T$ 做白化：

$$Z^T_t = \frac{r^T_t - \mu^T_g}{\sqrt{(\sigma^T_g)^2 + \epsilon}}$$

最终 token 级优势为：

$$A^{\text{ADRS}}_{i,k,t} = A^{\text{traj}}_{i,k} + \eta Z^T_{i,k,t}$$

对 GiGPO，$Z^T$ 加到 episode 级优势，原生 step 级分支保持不变。actor 仍使用标准 PPO 裁剪目标：

$$\mathcal{L}_{\text{actor}}(\theta) = -\frac{1}{|\mathcal{V}|}\sum_{t \in \mathcal{V}} \min\!\left[\omega_t(\theta) A^{\text{ADRS}}_t, \bar{\omega}_t(\theta) A^{\text{ADRS}}_t\right]$$

**Proposition 2（步骤零和表示）**：若归一化分母与门控在步骤 $s$ 内共享，则 $\sum_{j \in \mathcal{V}_s} r^T_{s,j}=0$，且对任意 token 排序 $r^T_{s,j_r} = \Phi_{s,r+1} - \Phi_{s,r}$，$\Phi_{s,1}=\Phi_{s,n_s+1}=0$。该零和恒等式意味着轨迹求和不改变回报排序。

**Proposition 3（轨迹保持与局部 token 梯度等价）**：在 step-shared 门控下 GRPO 轨迹得分不变。在行为策略点 $\theta_b$ 且裁剪未激活时：

$$\nabla_\theta J_{\text{ADRS}}\big|_{\theta_b} = \frac{1}{|\mathcal{V}|}\sum_{t\in\mathcal{V}} (A^0_t + \Delta A_t)\nabla_\theta \log\pi_\theta(y_t|c_t)$$

其中 $A^0_t = A^{\text{traj}}_{i,k}$、$\Delta A_t = \eta Z^T_t$。令辅助系数 $a_t = \Delta A_t$，则与一类分离的采样 token 辅助目标在 $\theta_b$ 处**一阶局部等价**（PPO 裁剪与偏离 $\theta_b$ 时不再严格相等）。

## 七、设计取舍与理论保证

论文通过 **Proposition 1–3** 给出三层理论保证：

- **Proposition 1** 将 TVA 重写为组内特权置信度-回报协方差，使门控可解释为"教师信号与稀疏回报同向性的统计度量"，避免人工阈值。
- **Proposition 2** 给出步骤级零和表示：$\sum_{j\in\mathcal{V}_s} r^T_{s,j}=0$，意味着轨迹求和不改变回报排序，从而骨干原生信用路径不受破坏。
- **Proposition 3** 证明在行为策略点 $\theta_b$ 且未触发 PPO 裁剪时，ADRS 的 token 级优势调制与"对采样 token 加权"的分离辅助目标**一阶局部等价**，但 ADRS 通过调制原生优势保持了与 GRPO/GiGPO 的相对优势计算兼容。

这些理论结果在论文中既支撑了"为什么不需要额外蒸馏损失"，也支撑了"为什么仍能与组相对优势共存"——这是相对 OPSD / RLSD / SDAR 等把教师信号当作独立 KL 蒸馏目标的特权自蒸馏方法的关键差异。

## 八、局限与未来方向

论文明确承认以下几点局限：

1. **技能依赖**：特权监督仍需预先编写 $\rho(x)$ 的程序化技能。论文未涉及自动技能发现、LLM 自身抽取或弱监督生成。
2. **教师模式恒定**：冻结快照 $\theta_b$ 在训练早期有效，但随骨干更新，原教师分布会逐渐与当前策略脱节；论文未提出动态教师刷新或 EMA 教师机制。
3. **任务范围**：评测集中于文本游戏、网页交互、搜索 QA 三类，对真实 API 调用、工具链、多模态 agent 的适用性尚未验证。
4. **理论界限**：Proposition 3 仅在 $\theta_b$ 邻域、裁剪未触发下成立，对长程训练中偏离 $\theta_b$ 时的等价性无法保证；作者建议未来工作中结合 PPO 信赖域给出更紧的误差界。
5. **算力报告缺失**：未给出 GPU 数量、总训练时长、单次实验 GPU 小时数等复现关键信息；附录只列出学习率、PPO epoch、batch 大小等共享超参。

未来工作可探索的方向包括：动态教师更新（如 $\theta_T$ 与 $\theta_b$ 的 EMA）、技能自动发现、ADRS 与过程奖励模型（PRM）的耦合，以及把特权信号扩展到多模态 agentic RL。

## 九、总体评价

ADRS 的核心贡献在于**将"训练时的特权自蒸馏"重新表述为"对原生 token 级优势的回报关联调制"**，从而避开了"独立蒸馏目标 → 偏离 GRPO/GiGPO 组相对优势"的常见陷阱。三模块设计（步骤内相对打分 + 回报关联 TVA 门控 + 轨迹/token 双通路调制）逻辑清晰且各自有理论支撑，实验在三个模型、三个基准、一系列训练时长与数据规模上系统验证了增益。

从学术角度看，论文的**理论部分（Proposition 1–3）**是亮点——它把"如何用特权信号而又不破坏原生信用"这一长期 open question 形式化为零和恒等式与一阶局部等价性，并辅以门控机制保证统计有效性。**实验部分**虽覆盖了主流骨干与 RL 后端，但缺乏与最新特权自蒸馏方法（TCOD、HDPO、TIP 等）的全面 head-to-head，且算力报告的缺失会影响完整复现。

整体而言，ADRS 是 2025 年 agentic RL 领域中"特权监督"与"组相对优势"融合的一个**有力且方法论清晰的方案**，对希望使用自然语言技能但又不愿引入额外蒸馏损失的实践者具有较高的可借鉴价值。
