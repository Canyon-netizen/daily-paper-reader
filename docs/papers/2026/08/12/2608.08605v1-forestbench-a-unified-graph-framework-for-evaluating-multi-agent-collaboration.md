## 摘要
基于大语言模型（LLM）构建的多智能体系统（MAS）正快速发展，但其异构的执行轨迹缺乏跨方法评估的统一基础。仅关注结果的基准测试会丢弃协作过程，而以 LLM 作为裁判的评估方式则需要额外的、依赖于模型的推理过程，且会因 LLM 和评分标准的不同而产生差异。我们提出了一种可泛化的评估框架，将原生 MAS 轨迹映射到统一的协作图共享空间中，从而使不同方法能够在相同的表示、参考集和指标体系下进行评估。候选图与针对每个查询构建的参考森林进行比较。每个森林是基准测试提供的一组经过验证的成功图：它记录了代表性 MAS 方法完成任务的多样化方式，而非规定唯一的最佳流程。作为该框架的实例化，ForestBench 从七个公开数据集中筛选出 844 个需要协作的查询，为每个查询预计算十个成功的目标条件参考图，并评估六个代表性 MAS 框架。受控的基座模型、参考构建和扰动研究检验了评估的稳定性和适用范围。一旦基准森林构建完成，ForestBench 即可在毫秒级时间内对轨迹进行评分，无需进一步的 LLM 推理，为比较多样化的 MAS 协作轨迹提供了可复用的结构化基础。

## Abstract
Multi-agent systems (MAS) built on Large Language Models (LLMs) are proliferating rapidly, but their heterogeneous execution traces provide no common basis for evaluation across methods. Outcome-only benchmarks discard collaborations, whereas LLM-as-Judge evaluation requires additional, model-dependent inference and can vary with the LLM and rubric. We introduce a generalizable evaluation framework that maps native MAS traces into a shared space of unified collaboration graphs, enabling different methods to be evaluated under the same representation, reference set, and metric panel. Candidate graphs are compared with a query-specific reference forest. Each forest is a benchmark-provided collection of verified-success graphs: it records diverse ways in which representative MAS methods can complete the task, rather than prescribing a unique optimal process. Instantiating the framework as ForestBench, we filter $844$ collaboration-necessary queries from seven public datasets, precompute ten successful target-conditioned reference graphs per query, and evaluate six representative MAS frameworks. Controlled backbone, reference-construction, and perturbation studies test the stability and scope of evaluation. Once the benchmark forests are built, ForestBench scores a trace in milliseconds without further LLM inference, providing a reusable structural basis for comparing diverse MAS collaboration traces.

  - **过程导向评估**存在两大问题：① 原生轨迹与框架特定的事件模式、角色词汇、通信协议强绑定；② LLM-as-Judge 需要额外的、依赖模型与评分标准的推理，**成本高、可复现性差**。
- **核心诉求**：缺乏一个**通用的过程级表征**，能在同一参考集与指标下对异构 MAS 方法进行**横向、可复现**的比较。

## 2. 方法论：核心思想与技术细节

### 2.1 整体框架（"森林"隐喻）

将每个 MAS 任务的执行轨迹投影为统一的**有向无环协作图**，与一个**查询特定的参考森林**进行结构化对比。森林由多条"经验证的成功"协作图组成，承认同一任务可由辩论、流水线、对等群等多种成功路径完成。

### 2.2 图抽象（Graph Abstraction）

- 对于一次 MAS 执行轨迹 $\tau = \mathcal{M}(q)$，投影得到：
  $$G(\tau) = (V, E, \phi)$$
  其中：
  - $V$：每个原子动作（消息、工具调用、决策）一个节点；
  - $E$：每条信息传递的有向边；
  - $\phi$：节点标注（发出代理、规范角色 $r \in \mathcal{R}$、文本内容）。
- **有向无环性**：每个动作有唯一时间戳，边严格指向前方，无环。
- **故意有损**：丢弃框架特定运行时状态与精确时间交错，**保留角色、动作、信息流依赖**，从而对异构框架具有结构可评估性。

### 2.3 参考森林（Reference Forest）

- 对查询 $q$ 定义：
  $$F(q) = \{(\mathcal{G}_k, q_k)\}_{k=1}^{K(q)}$$
  其中每个 $\mathcal{G}_k$ 来自代表性协作范式的成功轨迹，并通过目标条件化生成。
- 每条参考图附权重 $q_k$，综合**正确性、结构简洁性、token 成本**。
- 森林是基准测试**发布资产**，下游评估无需重建。

### 2.4 评估指标

**（1）成对图相似度**
$$\text{sim}(G, G') = \alpha\, s_{\text{node}} + \beta\, s_{\text{edge}} + \gamma\, s_{\text{topo}}$$
默认权重 $(\alpha, \beta, \gamma) = (0.4, 0.4, 0.2)$。

- $s_{\text{node}}$：基于规范角色的 Jaccard 相似度（多重集）：
$$s_{\text{node}} = \frac{|R(G) \cap R(G')|}{|R(G) \cup R(G')|}$$
- $s_{\text{edge}}$：基于角色类型边指纹的 Jaccard：
$$s_{\text{edge}} = \frac{|B(G) \cap B(G')|}{|B(G) \cup B(G')|}$$
- $s_{\text{topo}}$：惩罚冗余的规模比较：
$$s_{\text{topo}} = \frac{1}{2}\left(\frac{\min(|V|,|V'|)}{\max(|V|,|V'|)} + \frac{\min(|E|,|E'|)}{\max(|E|,|E'|)}\right)$$

**（2）Forest Match（核心指标）**
$$\text{FM}(G, F(q)) = \frac{\sum_{k=1}^{K(q)} w_k \cdot \text{sim}(G, \mathcal{G}_k)}{\sum_{k=1}^{K(q)} w_k} \in [0,1]$$

其中 $w_k = q_k / \max_{k'} q_{k'}$ 为归一化权重。

**（3）辅助指标**
- **Best Similarity**：$\max_k \text{sim}(G, \mathcal{G}_k)$
- **Node Validity**：被下游消费的非终止节点比例
$$\text{NV}(G) = \frac{|\{v \in V^- : \exists (v,u) \in E\}|}{|V^-|}$$
- **Mean Uptake**：基于嵌入余弦相似度的下游语义利用度
$$\text{Uptake}(G) = \frac{1}{|E|} \sum_{(u,v) \in E} \mathbb{1}[\cos(\text{emb}(x_u), \text{emb}(x_v)) > \theta_u]$$
- **Content Redundancy**：归一化内容哈希去重后的重复率
- **Tokens / Efficiency**：总 token 预算与图并行度/活跃代理比

所有指标均为 $G(\tau)$ 的确定性函数，**无需 LLM 推理，毫秒级输出**。

### 2.5 查询筛选（Trace-Suitability Pipeline, TSP）

- 通过强筛选 LLM 对每个查询打分：
  - 深度 $d(q) \geq \theta_d = 5$
  - 宽度 $w(q) \geq \theta_w = 0.5$（基于 8 类能力的归一化 Shannon 熵）
  - 可分解性 $\delta(q) \geq \theta_\delta = 0.5$
- 三个阈值同时满足才保留。

  - 在线评估对比（1,000 条轨迹）：
    - ForestBench：≈ 0.7 秒，**0 推理 token**
    - LLM-as-Judge：≈ 34 分钟，~996k 输入 token + ~78k 输出 token
  - **加速比约 2,900×**，零推理 token/千条。

## 5. 实验数量与充分性

### 5.1 实验规模

- **6 框架 × 3 随机种子 × 844 查询 ≈ 15,192 条候选轨迹**
- 多项受控实验（节 5.3–5.5 + 附录 A–E）

### 5.2 实验维度

- **基座对比**：3 个不同基座构建参考森林，框架排序 Kendall $\tau$ = Spearman $\rho$ = 1.00。
- **生成器剔除（leave-one-generator-out）**：7 种剔除设置，6/7 保留 Top-3。
- **目标条件化 vs. 开放式**：30 查询子集，Kendall $\tau$ = 0.867，Top-3 完全保留。
- **来源剔除（leave-one-source-out）**：8/8 保留 Top-1。
- **结构扰动**：5 种扰动（节点删除、边重连、角色交换、干扰插入、内容复制）× 2 强度（$p \in \{0.3, 0.5\}$），9/10 设置 Kendall $\tau$ = 1.00。
- **权重敏感性**：5 种权重方案，非退化方案 Kendall $\tau \geq 0.73$，均匀/节点重/边重方案 $\tau \geq 0.87$；仅拓扑权重方案（移除角色与边语义）$\tau = 0.20$，符合作者预期。
- **TSP 阈值扫描**：36 种阈值组合，框架排序 Kendall $\tau = 1.00$。
- **失败诊断**：300 条失败轨迹，多评委投票（DeepSeek-V4-Flash、GPT-5.5、Qwen3.6-Plus）；通过共享 parse-clean 子集（$n=138$）报告 93.5% 结构失败、81.2% 内容失败共识。
- **评估成本对比**：1,000 条轨迹实测。

### 5.3 公平性

- 评估阶段对共享框架源采用 **Leave-One-Out (LOO)** 处理，避免"自比自"。
- 生成器剔除测试严格于评估时 LOO，移除整个贡献者的参考轨迹。
- 多基座、多权重、多阈值的交叉验证使结论不易归因于某一超参选择。

## 6. 主要结论与发现

- **准确率难分方法**：6 框架准确率仅差 0.038（0.531–0.569），而 Forest Match 范围 0.316–0.421，**结构信号更敏锐**。
- **指标面板互补**：Debate 准确率最高但 Forest Match 最低、token 最高、Best Similarity 最低（0.284），表明无单一标量足以刻画协作。
- **领域特化**：Debate 在 SWE-bench-Verified 上 Forest Match 升至 0.382（局部最优），验证"全局排名应与领域分析结合"。
- **不同失败机制**：失败可分为**结构失败**（缺角色、错误拓扑、流水线截断）与**内容失败**（错误分解、幻觉、聚合选错），对应不同修复方向。
- **基座效应**：平均编排增益 $\Delta_{\text{acc}}$：DeepSeek-V4 = −0.002、GPT-5.5 = −0.039、Claude-S4.6 = −0.069——**更强基座下加 agent 不一定增益**。
- **成本优势**：评估比 LLM-as-Judge 快约 2,900 倍，零推理 token。
- **森林而非单树**：森林替换单一模板匹配，保留多种成功结构并支持复现。

## 7. 优点

- **统一表征**：图抽象屏蔽框架特定的事件模式、角色名、通信协议，实现真正的横向比较。
- **无需 LLM 推理**：评估为确定性函数，可毫秒级、可复现、无 token 成本。
- **多视角指标面板**：Forest Match（参考森林对齐）、Best Similarity（最近邻）、Node Validity、Mean Uptake、Content Redundancy、Tokens、Efficiency 形成互补画像。
- **鲁棒性证据充分**：基座、生成器、阈值、权重、扰动 5 类敏感性研究均显示主结论稳定。
- **失败诊断价值**：通过 accuracy–Forest Match 象限 + LLM 解释层（仅作诊断，非评分），把失败分为结构/内容两类，具可操作性。
- **资产化发布**：参考森林作为基准组件一次构建、永久复用，扩展到新数据集成本一次、零次评估。
- **公平性机制**：评估时 LOO、剔除生成器、剔除来源等多重防偏。

## 8. 不足与局限

- **参考森林覆盖度依赖**：森林由 6 个 MAS 框架 + 单代理锚点生成，无法枚举所有有效协作路径；新颖范式若不在参考集内，可能被系统性低估。
- **目标条件化偏差**：主构造使用已知 gold answer 引导生成，虽对参考集稳定性有益，但**非真实任务场景**的开放性条件会产生排名漂移（$\tau = 0.867$，中间位次互换）。
- **领域异质性**：单源排名在不同数据集上波动（Kendall $\tau$ 范围 −0.33 至 1.00），单一全局排名可能误导领域选择。
- **诊断层对 prompt 敏感**：细粒度失败标签的 Cohen's $\kappa$ 仅 0.129–0.351（结构失败），故只能给粗粒度"修复方向"而非精确诊断。
- **TSP 是启发式**：仅保证所选题更可能产生非平凡协作结构，**不证明每条都必须多 agent**，单代理强基座也可能解出。
- **角色映射与别名表**：依赖 per-framework alias table，跨框架角色语义对齐仍可能出现偏差（论文亦指出此为"应作透明处理"而非"普遍质量标签"）。
- **算力与可复现细节未披露**：未报告 GPU 类型/数量、墙钟时延的硬件分布，仅给出 token 与秒级汇总。
- **拓扑权重方案不稳健**：去掉角色与边语义后 Kendall $\tau$ 仅 0.20，说明该指标设计**不能与角色/通信语义解耦**，迁移到极简协作表示时存在退化风险。
- **领域覆盖偏推理**：55.9% 推理 + 23.7% 多跳搜索占主导，工具使用仅 4.6%（39 题），对纯工具/交互场景的代表性有限。
