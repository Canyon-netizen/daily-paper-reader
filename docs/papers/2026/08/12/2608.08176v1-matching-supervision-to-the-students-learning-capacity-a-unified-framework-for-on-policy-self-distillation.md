## 摘要
在线策略自蒸馏（OPSD）通过自蒸馏将特权上下文内化到模型参数中，从而提升大语言模型（LLMs）的推理能力。最近的两条研究路线分别通过选择学习哪些 token 以及控制教师所接收的特权信息量来改进原始的 OPSD。然而，我们发现每条路线在固定另一个变量的同时仅优化一个变量，这会导致次优解。我们认为这两个变量通过学生的学习能力紧密耦合：特权信息设定了教师所指定的逐 token 散度，而 token 加权则决定了学生必须吸收其中哪些散度。我们将这两条研究路线形式化为一个统一的优化框架，在学生可吸收的总体学习难度预算约束下，最大化教师与学生之间的总体散度。基于该建模，我们提出了统一在线策略自蒸馏（USD），一种用于求解拉格朗日函数的轻量级在线算法。USD 揭示了单一对偶变量同时支配着两个决策：以学习难度的统一价格为参数，它同时设定 token 选择阈值与特权信息的调整方向，使监督信号与学生不断变化的能力保持匹配。通过大量实验，USD 在不同模型规模和多种推理基准上，相较于 OPSD 以及 token 侧和 PI 侧的基线方法，始终展现出更优越的性能。代码已开源于 https://github.com/lauvlalala/USD。

## Abstract
On-policy self-distillation (OPSD) improves the reasoning abilities of LLMs by internalizing privileged context into model parameters through self-distillation.   Two recent research lines promote vanilla OPSD by choosing which tokens to learn from and by controlling how much privileged information the teacher receives, respectively.   However, we show that each line optimizes one variable while holding the other fixed, which leads to a suboptimal solution.   We argue that the two variables are coupled through the student's learning capacity: the privileged information sets the per-token divergence the teacher prescribes, while token weighting selects which of these the student must absorb.   We formalize the two lines of work into a unified optimization framework, which maximizes the aggregate teacher--student divergence, subject to a budget on the aggregate learning difficulty the student can absorb.   Under this modelling, we propose Unified On-Policy Self-Distillation (USD), a lightweight online algorithm to solve the Lagrangian.   USD reveals that a single dual variable governs both decisions: at one price for learning difficulty, it simultaneously sets the token-selection threshold and the direction of privileged-information adjustment, keeping supervision matched to the student's evolving capacity.   Through extensive experiments, USD consistently demonstrates superior performance over OPSD and token- and PI-side baselines across various model scales on various reasoning benchmarks. Code is available at https://github.com/lauvlalala/USD.

## 1. 核心问题与研究动机

**背景**：在策略自蒸馏（On-Policy Self-Distillation, OPSD）已成为大语言模型（LLM）推理后训练的重要范式。该方法在单一基础模型上同时承担学生（生成 rollout）与教师（借助特权信息 Privileged Information, PI 给出逐 token 监督）两个角色，既无需精选推理轨迹（SFT），也无需环境交互（RL）或更强的外部教师（cross-model distillation）。

**两大已有缺陷**：
- **Token 层**：原始 OPSD 对所有 token 采用均匀加权，但监督信号集中于少量关键位置（前 20% 贡献约 80% 的梯度），且大量高散度 token 对应的修正不可学（teacher mass 落在 student support 之外）。
- **PI 层**：完全暴露特权上下文会把教师分布推得离学生过远，单步梯度难以闭合，且可能将显式答案泄露到监督信号中。

**已有两条改进路线各自孤立**：
- **Token 选择方法**（TIP 等）：固定 PI 强度 $\beta$，按某种 score 重新加权 token；
- **PI 控制方法**（PAINT 等）：固定均匀 token 权重，按策略调节 PI 暴露量。

**本文核心论点**：两个变量通过"学生学习能力"耦合——PI 决定了教师给出的逐 token 散度 $g_t(\beta)$，token 加权决定学生吸收其中哪些；任一变量在另一变量固定下的最优解仅是条件最优，整体上是次优的。

## 2. 方法论

### 2.1 两个设计轴

设学生 $p_S$ 生成 rollout $\hat{y}$，教师 $p_T^\beta$ 在特权信息强度 $\beta\in[0,1]$ 下给出 token 级分布，加权目标为：

$$J(w,\beta)=\frac{1}{P}\sum_t w_t \cdot D_{KL}\!\left(p_T^\beta(\cdot|x,\hat{y}_{<t})\,\|\,p_S(\cdot|x,\hat{y}_{<t})\right)$$

- $\beta$ 轴：控制**生成什么样的监督信号**（改变教师分布本身）；
- $w$ 轴：控制**在何处施加多大强度的监督**（不改变教师，只分配 loss）。

### 2.2 两个关键量

- **散度**：$g_t(\beta)=D_{KL}\!\left(p_T^\beta\,\|\,p_S\right)_t$，代表该位置教师修正的潜在更新幅度；
- **学习难度**：$d_t(\beta)=\left[\log\frac{p_T^\beta(a_t^\star)}{p_S(a_t^\star)}\right]_+$，即学生对教师首选 token 的"惊讶度"。

### 2.3 统一优化框架（受容量约束的散度最大化）

$$\max_{w\in[0,1]^T,\;\beta\in[0,1]}\;\frac{1}{N}\sum_t w_t g_t(\beta)\quad\text{s.t.}\quad \frac{1}{N}\sum_t w_t d_t(\beta)\le \varepsilon$$

$\varepsilon>0$ 是**学生单 batch 可吸收的难度预算**。扫描 $\varepsilon$ 即可绘出 **Learnability Frontier** $F(\varepsilon)$——每个容量水平下能达到的最大散度。单轴方法（固定 $\beta$ 或固定 $w$）仅在二维设计空间中沿一条切片搜索，本文同时优化两个轴。

### 2.4 拉格朗日对偶分析

构造拉格朗日量：

$$L(w,\beta,\lambda)=\frac{1}{N}\sum_t w_t\!\left[g_t(\beta)-\lambda d_t(\beta)\right]+\lambda\varepsilon$$

由于 $L$ 在 $w_t$ 上线性，box 约束下最优权重退化为**硬阈值**：

$$w_t^\star=\mathbb{1}\!\left[g_t(\beta)>\lambda d_t(\beta)\right]$$

即 token 是否被纳入，取决于其"净价值" $v_t=g_t-\lambda d_t$ 的符号。$\lambda$ 即**难度的边际价格**。

在约束绑定（$\lambda>0$）且内点最优 $\beta^\star\in(0,1)$ 时，平稳性条件给出：

$$\lambda=\frac{\sum_{t:w_t^\star=1}\partial g_t/\partial\beta}{\sum_{t:w_t^\star=1}\partial d_t/\partial\beta}$$

**核心结论**：同一个 $\lambda$ 同时决定 (a) token 选择阈值与 (b) PI 调整方向——这并非设计上的巧合，而是共享预算约束的结构性后果。

### 2.5 残差更新避免对 $\beta$ 求导

由于 $\beta$ 通过非可微操作作用于教师上下文，无法直接计算 $\partial g_t/\partial\beta$。在单调性假设（$g_t$ 与 $d_t$ 关于 $\beta$ 严格递增，已在 Qwen3-1.7B 的真实 rollout 上验证）下，沿原始残差更新即可单调收敛到 $\beta^\star$：

$$\beta\leftarrow\beta+\eta_\beta(\varepsilon-\text{load})$$

其中 $\text{load}=\frac{1}{N}\sum_t w_t d_t(\beta)$。

### 2.6 USD 算法（轻量在线原-对偶）

| 步骤 | 操作 |
|------|------|
| 1. 学生 rollout | $\hat{y}\sim p_S(\cdot|x)$ |
| 2. 教师打分 | 在 $\beta$ 下获得 $p_T^\beta$ |
| 3. 逐 token 散度/难度 | $g_t, d_t$ 计算 |
| 4. **软权重**（可微） | $w_t=\sigma\!\left(\dfrac{g_t(\beta)-\lambda d_t(\beta)}{\tau}\right)$ |
| 5. 训练损失 | $L_{\text{train}}=\dfrac{\sum_t w_t D_{KL}(p_T^\beta\|p_S)_t}{\sum_t w_t}$（仅做归一化，不改变有效步长） |
| 6. 学生梯度更新 | 仅更新 LoRA（rank 64, $\alpha=128$） |
| 7. **对偶上升** | $\lambda\leftarrow\max(0,\lambda+\eta_\lambda(\text{load}-\varepsilon))$ |
| 8. **PI 调整** | $\beta\leftarrow\text{clip}(\beta+\eta_\beta(\varepsilon-\text{load}),\beta_{\min},1)$ |

每次 batch 的额外开销仅为一次 $O(T)$ 扫描 + 两个标量更新，无辅助网络、无额外前向。

**闭环机制**：load 超预算 → $\lambda$ 上升 → 软权重收紧 + $\beta$ 下降 → 教师变温和 → load 回落；load 有余 → $\lambda$ 归零 → 权重近似均匀 + $\beta$ 上升 → 教师变锐。两者在同一预算上协同演化。

| PI 侧 | PAINT | 重叠自适应后缀掩码 + 稀疏 teacher-student logit 插值，固定均匀 token 权重 |
| **本文** | **USD** | **联合优化** |

所有方法共享相同基础模型与训练数据；除 GRPO（500 步）外均训练 300 步。

---

## 4. 资源与算力

论文**未明确披露**具体的 GPU 型号、数量、训练时长或总计算预算。仅给出训练超参：
- LoRA rank 64, $\alpha=128$，AdamW 学习率 $5\times 10^{-6}$，有效 batch size 32，梯度范数裁剪 0.1；
- USD 自身超参（跨规模固定）：$\tau=0.1,\;\varepsilon=0.3,\;\eta_\lambda=0.1,\;\beta_{\text{init}}=0.8,\;\eta_\beta=0.03,\;\beta_{\min}=0.1$，逐 token KL 裁剪 0.05；
- 采样：温度 1.1、top-p 0.95、top-k 20、最大长度 1024 token；评测温度 1.0，每题 12 个解；
- USD 每 batch 仅多一次 $O(T)$ 扫描 + 两个标量更新，相较 vanilla OPSD 几乎无额外计算开销。

## 5. 实验数量与充分性

- **主结果**：3 个模型规模 × 3 个 benchmark = 9 个 cell，全方法覆盖；
- **消融**：每规模上 4 种配置（vanilla / +PI only / +Token only / +Both），共 12 组；
- **敏感性**：在 Qwen3-1.7B 上对容量预算 $\varepsilon\in\{0.15,0.20,0.30,0.40,0.50,0.80\}$ 做了 6 组扫描；
- **训练动态**：在 Qwen3-1.7B 上绘出 load、$\lambda$、$\beta$ 三者的曲线（图 5）；
- **单调性假设实证**：在真实 Qwen3-1.7B rollout 上验证 $g_t(\beta)$ 与 $d_t(\beta)$ 关于 $\beta$ 严格递增（图 4）。

**充分性评价**：
- 优点：跨规模、跨 benchmark、与同期 SOTA 方法直接对比、含消融、含敏感性、含训练动力学，分析层次较为完整；
- 不足：(1) 仅覆盖数学推理 3 个竞赛基准，**未涉及代码、Agentic、通用 NLP 等任务**；(2) 仅用 Qwen3 系列模型，**未验证其他家族（如 LLaMA、DeepSeek）的可迁移性**；(3) 与 GRPO 的对比虽给出采样开销对比（USD 1 rollout × 1024 token vs GRPO 8 rollout × 16k token），但**未在固定算力预算下做 head-to-head**；(4) 评测样本数（AIME 30 题 ×12 采样）较小，**置信区间与统计显著性未报告**。

## 6. 主要结论与发现

1. **耦合性**：token 加权与 PI 强度通过共享的"学习难度预算"严格耦合，单轴优化在二维平面上仅能触及条件最优；
2. **统一解的存在性**：单一对偶变量 $\lambda$ 同时确定 token 选择阈值与 PI 调整方向，构成 Pareto 前沿上容量匹配点；
3. **效果提升**：在 9 个 (模型, benchmark) cell 的均值上，USD 将 vanilla OPSD 的 56.4% 提升到 58.7%（+2.3），三个规模上分别约 +2 点；同步优于 TIP、PAINT，并超过 GRPO（+4.7 / +2.0 / +1.5 per-scale），且采样预算远小；
4. **互补性**：消融中单轴增益在规模间不稳定（1.7B 偏 token 侧、4B/8B 偏 PI 侧），但联合变体在所有规模都最优；
5. **动态行为**：训练初期 $\beta$ 上升、$\lambda\approx 0$；当 load 触达 $\varepsilon$ 后，$\lambda$ 激活收紧 token 选择，$\beta$ 同步回落，两者协同维持 load 在 $\varepsilon$ 附近；
6. **敏感性**：$\varepsilon=0.3$ 表现最佳，过紧会"饿死"学生，过松则退化为近均匀加权；
7. **理论保证**：在单调性假设下，残差更新单调收敛到 KKT 条件刻画的最优 PI 强度 $\beta^\star$（Proposition 1）。

---

## 7. 优点

- **理论清晰**：把工程上的"直觉"（监督应匹配学生能力）转化为带对偶变量的紧致优化问题，并给出 KKT 等价条件与收敛证明；
- **设计极简**：USD 不引入任何额外网络或前向，仅两个标量更新 + 一个 $O(T)$ 扫描，工程开销几乎为零；
- **框架统一**：以同一 $\lambda$ 同时驱动两类已有工作（TIP、PAINT），证明二者并非相互替代而是同一预算下的两种表达；
- **可解释性强**：训练动力学可直接读出"难度预算是否被吃满"，便于诊断与调参；
- **跨规模一致**：在 1.7B–8B 三档均稳定取得 +2 点的均值提升；
- **不依赖外部信号**：$\lambda$ 与 $\beta$ 的更新完全基于 batch 内统计，无需预先设定 schedule；
- **开源**：代码已发布。

---

## 8. 不足与局限

- **任务覆盖窄**：仅在数学竞赛（AIME/HMMT）上验证，未覆盖代码生成、Agentic、对话、通用 NLP 等任务；
- **模型家族单一**：仅用 Qwen3，对 LLaMA、DeepSeek、Mistral 等系列的迁移性未知；
- **统计显著性缺失**：AIME/HMMT 单基准样本量小，**未报告置信区间、p 值或多次随机种子方差**，结论的稳健性难以严格评估；
- **公平性争议**：与 GRPO 的对比中 GRPO 使用更多步数（500 vs 300）和 8×16k token 采样，但**未在固定总 token 预算下做严格 ablation**，可能存在 compute-normalized 比较偏差；
- **超参脆弱性**：$\varepsilon=0.3$ 在 1.7B 上最优，但论文未在 4B/8B 上扫描 $\varepsilon$，**默认同一 $\varepsilon$ 跨规模是否真正最优存疑**；
- **单调性假设依赖**：Proposition 1 严格依赖 load 与 divergence 关于 $\beta$ 严格递增的假设；若 PI 内容包含答案泄露或语义冲突，该单调性可能破裂，但**未给出违反时的退化分析**；
- **潜在偏差风险**：
  - 训练数据来自 OpenThoughts，与评测基准（AIME/HMMT）可能存在分布重叠；
  - $\beta$ 以"参考解答前 $\lfloor\beta L\rfloor$ 字符"作为连续 PI 强度的实现方式，这种离散化是否在所有任务上都合理未讨论；
  - LoRA 微调下 $\lambda$ 的可微等价形式（sigmoid 软化硬阈值）与理论硬阈值之间存在 gap，论文未分析该 gap 的影响；
- **实际部署限制**：单 batch 容量预算 $\varepsilon$ 的设定需要先验知识（论文取 0.3 是经验值），**缺乏自动调节机制**，对新任务或新模型不够鲁棒。
