## 摘要
多阶段随机模型预测控制（MPC）通过在场景树上进行优化来处理不确定性，场景树是由采样预测构建的未来结果的有限分支近似。为构建此类树，传统方法侧重于匹配底层概率分布——例如通过基于 Wasserstein 的场景削减——但分布精度的提升并不一定能带来更好的控制性能。我们提出一种面向控制的方法，直接从场景树构建对下游决策的影响中学习其构建方式。在固定树拓扑的前提下，我们将树的构建形式化为将采样场景按序分配到叶节点的过程。该分配由一个作用于场景集合的基于注意力机制的策略参数化，并通过强化学习进行训练，以闭环控制利润作为目标。训练过程通过一个利用已实现未来轨迹的非对称评论家加以稳定。我们在风险厌恶的电池套利问题上对所提方法进行了评估。在多种预测集合规模下，学习到的构建方法始终获得最高利润，优于经典的前向与后向削减方法以及确定性等价（单条预测轨迹）控制。学习到的策略在困难实例上也表现出更强的鲁棒性，始终展现更好的尾部风险特征。对生成树的分析表明，我们的方法构建出紧凑的、具有选择性分支结构的树，能够捕捉高影响事件，同时使大多数轨迹近乎确定性。这些发现强调了场景树的价值关键取决于其所支撑的决策，并提供了一种仅基于闭环控制优化信号即可训练场景树构建器的有效框架。

## Abstract
Multistage stochastic model predictive control (MPC) handles uncertainty by optimizing over a scenario tree, a finite branching approximation of future outcomes constructed from sampled forecasts. To build such a tree, conventional methods focus on matching the underlying probability distribution---e.g., via Wasserstein-based scenario reduction---but improved distributional accuracy does not necessarily yield better control performance. We propose a control-oriented approach that learns scenario tree construction directly from its impact on downstream decisions. Fixing the tree topology, we formulate tree construction as a sequential assignment of sampled scenarios to leaves. This assignment is parameterized by an attention-based policy over the scenario set and trained using reinforcement learning, with closed-loop control profit as the objective. Training is stabilized by an asymmetric critic that leverages realized future trajectories. We evaluate the method on a risk-averse battery arbitrage problem. Across a range of forecast set sizes, the learned construction consistently achieves the highest profit, outperforming classical forward and backward reduction methods and certainty-equivalent (single-trajectory forecast) control. The learned policy also exhibits greater robustness on challenging instances, consistently demonstrating better tail-risk characteristics. Analysis of the resulting trees indicates that our method constructs compact, selectively branching structures that capture high-impact events while keeping most trajectories nearly deterministic. These findings highlight that the value of a scenario tree depends critically on the decisions it supports, and provide an effective framework to train scenario tree constructors merely based on the closed-loop control optimization signal.

### 2.1 问题形式化

- **控制任务**：电池能量套利（charging/discharging against uncertain prices），采用线性规划形式的最优调度，包含充放电功率限制、能量容量约束与充放电效率。
- **风险厌恶**：采用多个置信水平 $\beta_k$ 下的条件风险价值（CVaR）作为风险度量，最终优化目标为

$$
\max_{\mathbf{u}, \boldsymbol{\alpha}} \; -\Bigl(C(\mathbf{u}) + \sum_{k} \lambda_k \,\mathrm{CVaR}_{\beta_k}(\mathbf{u}, \alpha_k)\Bigr)
$$

其中 $C(\mathbf{u})$ 为树上的期望调度成本。

- **决策格式**：所有方法使用相同的 MPC 框架，差异仅在于树的构造方式。

### 2.2 树构建：序列分配

- **固定拓扑**：预设一棵有 $L=6$ 片叶的空模板（root + 分支路径），拓扑结构固定。
- **分组序列分配**：将 $S$ 条采样情景按与均值的欧氏距离降序排列后分为 $K = \lceil S/G\rceil$ 组（$G$ 为每组大小），逐组分配。
- **隐式剪枝**：分配零情景的叶子与分支被自动剪除，因此策略可自主决定实际使用的分支数。
- **状态编码**：每个情景由一个 token 表示

$$
\mathbf{x}^{(i,k)}_t = [\hat{s}_t,\; \hat{\boldsymbol{\xi}}^{(i)},\; p^{(i)},\; \mathbf{b}^{(i,k)},\; m^{(i,k)}]
$$

包含系统状态、价格轨迹、概率、已分配叶子的 one-hot 编码、当前组指示。

### 2.3 网络架构

- **Actor 与 Critic**：均采用基于交叉注意力的集合编码器（参考 Set Transformer），但参数独立。
- **上下文-查询机制**：所有 $S$ 个 token 经共享投影后形成上下文集 $\mathcal{C}^{(k)}$；查询集由一个可学习的全局 token $\mathbf{q}_{\mathrm{CLS}}$ 与当前组 $\mathcal{G}^{(k)}_t$ 中情景的嵌入组成，经 $N$ 层多头交叉注意力更新。
- **计算复杂度**：$O(G \cdot S)$，避免完全成对交互的 $O(S^2)$。
- **策略输出**：actor 对当前组中每个情景独立输出叶子分布

$$
\pi_\theta(a^{(i,k)}_t = \ell \mid \mathcal{T}^{(k)}_t) = \mathrm{softmax}\bigl(\mathrm{MLP}(\mathbf{q}^{(i,k)}_t)\bigr)_\ell
$$

- **非对称 Critic**：训练时可访问"特权未来信息"（已实现轨迹）以降低价值估计方差，部署时仅使用 actor。

### 2.4 PPO 训练

- **奖励**：完整 receding-horizon rollout 中每步获得的实际套利利润 $r_t$，所有参与构造同一棵树的分组决策共享该利润。
- **目标**：使用 $H$ 步无折扣回报 $G_j = \sum_{h=0}^{H-1} r_{t_j+h}$ 与优势函数 $A_j = G_j - V_\phi(\mathcal{T}^{(k_j)}_{t_j})$。
- **损失**：标准 PPO 截断替代目标 + 熵正则项 + Huber 损失的价值回归。
- **训练稳定性**：小回放缓冲、梯度范数截断、基于 KL 散度的内循环早停。

## 3. 实验设计

### 3.1 数据/场景

- **合成电价环境**：采用 latent 状态 $z_t$ 演化方程

$$
z_{t+1} = z_t + \theta(\mu_t - z_t) + \sigma \varepsilon_t + J_t
$$

综合了均值回归、24 小时日内周期、罕见大幅冲击（重尾）三大要素。观测价格通过对 $z_t$ 的非线性变换得到。

- **训练/评估数据**：分别生成 200 条独立轨迹（每条 $T=120$ 步），测试集与训练集同分布但完全独立。
- **预测情景**：每个控制步生成 $S$ 条未来 $H=6$ 步的预测轨迹（均匀概率 $1/S$）。

### 3.2 对比方法

| 方法 | 说明 |
|---|---|
| **Oracle** | 使用已实现价格的完美预见上限 |
| **RL Agent（本文）** | 学习到的注意力策略，6 片叶固定拓扑 |
| **Deterministic** | $S$ 条轨迹的逐元素均值（确定性等价控制） |
| **Random** | 同一 6 片叶拓扑上的随机分配 |
| **Forward** | 前向选择场景削减，6 片叶预算 |
| **Backward** | 后向削减场景削减，6 片叶预算 |

评估场景规模 $S \in \{10, 25, 50, 100, 150, 200, 300\}$。

### 3.3 评估指标

- **利润**：累计套利利润的均值与标准差；
- **Gap closed**：相对于确定性等价与 Oracle 之间距离的恢复比例；
- **尾部风险**：CVaR 5% 与 CVaR 10%；
- **树规模**：实际使用的叶数 $|{\cal L}|$ 与节点数 $|{\cal N}|$；
- **计算成本**：每步构建时间与求解时间；
- **Win rate**：在 200 条测试 profile 上的逐条胜率。

## 4. 资源与算力

## 5. 实验数量与充分性

- **规模维度**：7 个预测集合规模 $\times$ 6 种方法（含 Oracle）= 42 组主结果；
- **风险维度**：CVaR 5% 与 CVaR 10% 两层尾部评估；
- **逐条分析**：对所有 $S$ 与所有基线给出 win rate 与每条 profile 散点图；
- **结构维度**：分析树的实际叶数与求解时间；
- **公平性**：所有方法使用相同的 MPC 程序（Eq. (9)）、相同的预测生成过程、相同的评估协议；RL 与 Random 在同一拓扑上对比（隔离拓扑与分配的贡献），与 Forward/Backward 在相同叶预算下对比；
- **单一任务**：仅在电池套利一项任务上验证。

总体而言，**对比维度较为完整**，但**任务与场景的多样性不足**（仅一个线性套利任务、一个合成数据生成过程），未在更广泛的控制问题与真实数据上验证。

## 6. 主要结论与发现

1. **小样本下优势最显著**：$S=10$ 时 RL Agent 的 gap closed 比次优基线高约 8%，$S=200$ 时仍高约 2%。
2. **大样本下的收敛行为**：所有方法（除 Forward 选择外）在 $S\gtrsim 150$ 时趋于同一利润上限（约 1640），原因是该线性问题下确定性等价控制随均值估计收敛而逼近最优。
3. **尾部风险持续优越**：CVaR 10% 在所有 $S$ 下均为最优；CVaR 5% 仅在 $S=100$ 与 $S=300$ 上略低于 Forward；最差 profile 利润在整个扫描范围内保持正值，而确定性控制在多个 $S$ 下出现负值。
4. **结构性发现**：策略平均仅填充约 1.7–2.4 片叶（接近单一轨迹），呈现"近确定性 + 选择性分支"的紧凑结构，与确定性等价控制互补。
5. **计算可扩展性**：当 $S\gtrsim 150$ 时，后向削减的构建时间超过 RL Agent；$S=300$ 时后向削减构建时间约为 RL Agent 的 3–4 倍。
6. **小样本高效性**：RL Agent 在 $S=200$ 时的均值（1645）已匹配后向削减在 $S=300$ 时的最优均值（1644），即以少约 1/3 的情景达到同等性能。

## 7. 方法与实验设计的优点

- **端到端控制导向训练信号**：直接以闭环套利利润作为奖励，避免了分布度量与决策质量之间的脱节。
- **序列分配框架 + 隐式剪枝**：策略可自主决定"何时分支、分多少"，无需预设分支规则。
- **非对称 Critic 设计**：训练时利用已实现轨迹降低方差，部署时不引入未来信息泄露，兼顾训练效率与现实一致性。
- **注意力集合编码器**：天然处理无序情景集，具备排列等变性，计算开销为 $O(G\cdot S)$。
- **公平对比设计**：通过共享拓扑（vs Random）与共享叶预算（vs Forward/Backward）将分配策略与拓扑的贡献分离。
- **多维度评估**：不仅看均值利润，还报告 CVaR、win rate、树规模、计算时间，给出控制性能与计算成本的可读权衡。

## 8. 不足与局限

- **任务单一**：仅在电池能量套利这一**线性**任务上验证；在 Jensen 不等式约束下非凸/非线性控制问题中，确定性等价控制未必随 $S$ 收敛，因此 RL 的相对优势可能更大但本文未验证。
- **预测正确设定**：实验中预测分布与真实动态同分布，是确定性等价控制与距离型削减最有利的场景；真实场景中预测常有偏差，反而可能为本文方法提供更多补偿空间，但本文未在此情形下实验。
- **预测规模受限**：仅评估至 $S=300$，更大规模的扩展性依赖未来工作（论文已指出 induced-set 或线性注意力可降低渐近二次复杂度）。
- **算力信息缺失**：未报告 GPU 型号、训练时长、收敛曲线等算力相关细节，难以复现与横向对比。
- **缺乏消融**：未明确给出 actor/critic 架构（如注意力层数 $N$）、分组大小 $G$、熵系数、PPO 超参等关键组件的消融研究。
- **训练与推理拓扑固化**：训练固定在 $S=10$，对更大 $S$ 的迁移虽显示出较好效果，但未分析这种 zero-shot 迁移在极端稀疏或极端稠密情况下的失效边界。
- **真实数据缺失**：合成电价过程可控但与实际市场行为仍有差距，方法在真实日前/日内市场中的有效性有待验证。
- **无理论保证**：与基于 Wasserstein 距离的削减方法所具备的稳定性界相比，本文方法虽具实证优势，但缺乏对控制性能差距的理论分析。
