## 摘要
外部自然语言技能为大型语言模型（LLM）智能体提供了可重用且可编辑的指导，以解决复杂任务。然而，它们的有效性不仅取决于技能的质量，还取决于策略能否将所提供的指导转化为适当的动作。专门用于提升这种技能利用能力的方法在很大程度上仍未得到充分探索。在实践中，基于技能的智能体通常使用以任务级奖励为中心的强化学习目标进行训练，这种目标所提供的监督有限，难以捕捉策略在多大程度上有效地利用了所提供的技能。我们提出了BCSD（双向上下文自蒸馏，Bidirectional Context Self-Distillation），一个结合自蒸馏与强化学习的框架，用于训练LLM智能体更有效地使用外部技能。与依赖单一特权上下文的现有自蒸馏方法不同，BCSD从两个互补的技能上下文视角评估每条轨迹。其中，增强视图引入了更高层级的元技能指导，而简化视图则裁剪通用指导以突出任务特定的技能。这两种互补的token级信号被组合起来用于重新缩放强化学习优势。在ALFWorld和WebShop上的实验表明，BCSD在不同模型规模下均取得了最强的整体性能，使智能体能够更有效地利用外部技能。消融研究进一步验证了增强视图与简化视图的互补贡献。代码将公开发布以确保完全可复现性。

## Abstract
External natural-language skills provide large language model (LLM) agents with reusable and editable guidance for solving complex tasks. Yet their effectiveness depends not only on skill quality, but also on whether the policy can translate the provided guidance into appropriate actions. However, methods specifically designed to improve this skill-utilization ability remain largely underexplored. In practice, skill-based agents are commonly trained with reinforcement learning objectives centered on task-level rewards, which offer limited supervision and struggle to capture subtle differences in how effectively the policy uses the provided skills. We propose BCSD (Bidirectional Context Self-Distillation), a framework that combines self-distillation with reinforcement learning to train LLM agents to use external skills more effectively. Unlike prior self-distillation methods that rely on a single privileged context, BCSD evaluates each trajectory from two complementary skill-context views. The augmented view introduces higher-level Meta-Skill guidance, while the reduced view prunes general guidance to highlight task-specific skills. Their complementary token-level signals are combined to rescale the RL advantage. Experiments on ALFWorld and WebShop demonstrate that BCSD achieves the strongest overall performance across model scales, enabling agents to utilize external skills more effectively. Ablation studies further verify the complementary contributions of the augmented and reduced context views. Code will be released to ensure full reproducibility.

## 1. 核心问题与研究动机

- **核心问题**：在基于外部自然语言技能（external natural-language skills）的 LLM 智能体中，"是否拥有高质量技能"与"能否真正用好技能"是两个独立维度。现有方法或聚焦于提升技能本身的质量，或将技能内化（internalization）进模型参数；但对**技能利用质量（skill utilization）**的专门训练方法仍属空白。
- **现有局限**：
  - 任务级稀疏奖励（outcome reward）对智能体是否真正"读懂了技能"难以提供细粒度监督。
  - On-Policy Self-Distillation（OPSD）等近期方法依赖于**单一特权上下文**生成的 token 级教师信号，但已有研究指出该信号存在信息泄露、风格偏移和 shortcut token 等不稳定问题。
- **本文切入点**：提出一个新视角——既不改进技能本身，也不将技能塞入参数，而是让策略**学会更好地利用外部技能**，并通过**上下文空间的双向互补**获得更可靠的 token 级监督。

## 2. 方法论

### 2.1 核心思想

BCSD 将**多教师整合**与**参考策略锚定**这两类已有思想从"参数空间"迁移到"上下文空间"：同一策略在不同上下文下作为"自己教自己"的自教师（self-teacher），其 token 级概率差可直接比对与融合。

### 2.2 上下文构造（三种上下文）

- **基础上下文**：$C_0 = (Q, G, S_c)$，其中 $G$ 为通用技能（General Skill），$S_c$ 为检索出的任务特定技能。
- **增强上下文**：$C_1 = (Q, G, S_c, M_c)$，加入高层级的**元技能** $M_c$，刻画当前策略"应该如何使用技能"。
- **精简上下文**：$C_2 = (Q, G_p, S_c)$，由冻结的外部 LLM 预先对 $G$ 做冗余裁剪得到 $G_p$，保留 $S_c$，作为"该任务技能是否被遵循"的聚焦参考。

### 2.3 元技能的提取与刷新

- 定义：元技能 $M_c$ 是对当前策略**成功/失败利用方式**的高层文本总结，仅作为特权上下文用于教师，**不进入学生上下文 $C_0$**，也不在推理时使用。
- 初始化：用预加载轨迹的成功集 $E_{c,+}^{(0)}$ 与失败集 $E_{c,-}^{(0)}$，通过冻结 LLM 对比提取：
$$M_c^{(0)} = \text{ExtractLLM}\!\left(S_c, E_{c,+}^{(0)}, E_{c,-}^{(0)}\right)$$
- 刷新：在每个验证窗口结束时，用新收集的成功/失败证据重新提取：
$$M_c^{(k+1)} = \text{ExtractLLM}\!\left(S_c, M_c^{(k)}, E_{c,+}^{(k)}, E_{c,-}^{(k)}\right)$$

### 2.4 双向上下文自蒸馏与优势重缩放

对同一条在 $C_0$ 下采样得到的轨迹 $\tau_i$，保留其响应序列 $y_i$ 不变，分别在 $C_1, C_2$ 下重新打分，得到两个 token 级对数概率差：

$$
\Delta_{i,t}^{aug} = \log \pi_\theta(y_{i,t} \mid C_1, y_{i,<t}) - \log \pi_\theta(y_{i,t} \mid C_0, y_{i,<t})
$$

$$
\Delta_{i,t}^{pru} = \log \pi_\theta(y_{i,t} \mid C_2, y_{i,<t}) - \log \pi_\theta(y_{i,t} \mid C_0, y_{i,<t})
$$

按权重融合：

$$
\Delta_{i,t} = \alpha \, \Delta_{i,t}^{aug} + (1-\alpha)\, \Delta_{i,t}^{pru}
$$

构建一个**仅调节幅度、不改变方向**的 token 级权重：

$$
w_{i,t} = \text{clip}\!\left(\exp\!\left(\text{sign}(A_i^{GRPO}) \cdot \Delta_{i,t}\right),\, 1-c,\, 1+c\right)
$$

对标准 GRPO 优势 $A_i^{GRPO} = \frac{r_i - \mu_r}{\sigma_r + \epsilon}$ 做 token 级重缩放：

$$
A_{i,t}^{BCSD} = A_i^{GRPO} \cdot \left[(1-\lambda_n) + \lambda_n w_{i,t}\right]
$$

其中 $\lambda_n \in [0,1]$ 在训练中由 $\lambda_0$ **线性衰减至 0**，早期提供稠密引导，后期让奖励信号主导。

### 2.5 策略优化目标

采用带 KL 约束的截断目标：

$$
\mathcal{L}_{BCSD}(\theta) = -\mathbb{E}_{i,t}\!\left[\min\!\left(\rho_{i,t}(\theta) A_{i,t}^{BCSD},\, \text{clip}(\rho_{i,t}(\theta), 1-\epsilon, 1+\epsilon)\, A_{i,t}^{BCSD}\right)\right] + \beta\, \mathcal{L}_{KL}
$$

其中重要性比 $\rho_{i,t}(\theta) = \frac{\pi_\theta(y_{i,t}\mid C_0,y_{i,<t})}{\pi_{\theta_{old}}(y_{i,t}\mid C_0,y_{i,<t})}$，**仅在 $C_0$ 下计算**，确保训练与推理一致。

### 2.6 算法流程（Algorithm 1）

1. 训练前用外部 LLM 构造 $G_p$ 并初始化 $\{M_c^{(0)}\}$；
2. 每步采样 $B$ 个 query，在 $C_0$ 下采样 $K$ 条轨迹，计算 GRPO 优势；
3. 在 $C_0, C_1, C_2$ 三个上下文下对 realized tokens 重新打分；
4. 计算 $\Delta_{i,t}, w_{i,t}, A_{i,t}^{BCSD}$ 并更新参数；
5. 每 $N$ 步用新证据刷新元技能并清空证据缓冲。

## 6. 主要结论与发现

- **总体结论**：BCSD 在三个模型规模、两个基准上均取得最强聚合性能，平均提升 3~5 个百分点；在 Qwen2.5-7B-ALFWorld 达到 83.6% 成功率，Qwen2.5-7B-WebShop 成功率 78.1%。
- **组件贡献**：增强视角与精简视角**互为补充**，缺一不可；移除任一会带来明显退化（WebShop 尤为显著：从 66.4 跌至 50/57）。
- **机制发现**：
  - 元技能需**周期性刷新**——固定元技能反映的是早期策略的能力模式，会随训练失效。
  - 早期 $\lambda_n$ 应大、后期应衰减——避免后期对特权上下文的过度依赖。
  - **$\alpha=0.9$**（以 Meta-Skill 为主、精简技能为辅）最优；$\alpha=0.5$ 时两视角冲突导致训练不稳定。
  - 两视角的 token 级符号一致率约 **50% 左右**，说明两者提供**正交而非冗余**的信号。
- **核心解读**：BCSD 的提升**主要来自更好地利用 $S_c$**，而非把任务知识内化进参数——移除 $S_c$ 后 BCSD 的成功率下降幅度（ALFWorld -2.3 / WebShop -7.8）显著大于 Skill_GRPO\*（-0.8 / -6.2），证明策略确实"学会了读技能"。

## 7. 优点

- **问题定义新颖**：把"技能利用质量"与"技能质量""技能内化"清晰区分，正面回答了"如何用好外部技能"这一空白问题。
- **方法简洁且可插拔**：BCSD 不引入额外损失项，而是通过**优势重缩放**融合多视角信号，结构干净，易与 GRPO 系列 RL 算法对接。
- **双向互补视角的设计优雅**：增强与精简分别对应"如何用技能""是否真在用技能"，自然形成正交监督。
- **元技能刷新机制闭环**：成功/失败证据由训练轨迹本身产生，无需额外标注；外部 LLM 用于对比抽象，符合"自改进"思路。
- **诊断实验有说服力**：移除 $S_c$ 的诊断设计直击"是真利用还是假内化"这一核心问题；交叉视角一致率分析从机制层面验证了两视角的非冗余性。
- **覆盖面较广**：跨 3 个模型规模、2 个基准、6 类 ALFWorld 子任务逐一报告，避免了"单点取胜"的误导。

## 8. 不足与局限

- **基准与生态有限**：
  - 仅有 ALFWorld、WebShop 两个文本类基准，缺乏多模态、具身、长流程工具调用等更复杂环境。
  - 模型仅限 Qwen 系列（3B/7B/1.7B），未在 Llama、GPT 等其他家族上验证，泛化性存疑。
- **可复现性披露缺失**：未说明 GPU 型号/数量、训练时长、外部 LLM 类型与 token 消耗；Meta-Skill 提取与刷新涉及外部 LLM，prompt 与随机性未被控制，可能引入**评估偏差风险**。
- **超参与工程细节未充分展开**：
  - $G_p$ 仅在训练前裁剪一次，固定不变——并未裁剪 $S_c$ 或动态更新，可能不是最优。
  - 元技能刷新间隔 $N$、裁剪比例、$\alpha$ 的最优区间仅在 Qwen2.5-3B 上验证，未做跨规模复测。
  - $c$（clipping 上界）的取值与影响未讨论。
- **公平性细节**：基线虽在同一 SkillBank 下复现，但 RLSD、Skill-SD、SDAR 等的特权上下文与 BCSD 的元技能性质不同（前者多为答案，后者为高层策略），公平性边界仍有争议。
- **理论分析薄弱**：仅以经验性"视角独立 ⇒ 互补"为主，缺乏对双向视角信号方差/偏差、token 级缩放稳定性等的理论刻画。
- **应用面限制**：方法对"显式自然语言技能 + 检索式 SkillBank"假设较强，对隐式、技能压缩或工具型技能体系的扩展未验证。
- **统计显著性缺失**：未报告多次随机种子的均值与方差，结论的稳健性有待进一步验证。
