基于可验证奖励的强化学习（RLVR）在训练大语言模型智能体方面十分有效。然而，终局奖励仅提供粗粒度的轨迹级监督，使得成功行为、反复出现的错误以及偶发性选择纠缠在同一种结果信号中。现有的智能体自蒸馏方法通过自然语言技能来丰富稀疏的监督信号，但这些技能要么从外部检索得到，要么由更强的模型从单条轨迹中提取，可能与当前经验不匹配、超出策略能力范围，或者仅适用于特定路径。我们提出组反思自蒸馏（GRSD），它从策略自身经过验证的采样轨迹中获取与能力对齐且对结果具有判别力的指导。具体而言，对于每个提示，策略对在线组中每条已验证的轨迹进行反思，并通过一个停止梯度快照来对比成功与失败采样所产生的反思，从而构建组级别的特权指导。以此指导为条件，自教师通过调节基于结果的奖励优势来细化轮次级的信用分配，同时保留由验证器所确定的学习方向。在多种智能体环境和模型规模上的实验表明，GRSD 始终优于有竞争力的基线方法，并在未见任务上展现出更强的泛化能力。

## Abstract
Reinforcement learning with verifiable rewards (RLVR) is effective for training large language model agents. However, terminal rewards provide only coarse trajectory-level supervision, leaving successful behaviors, recurring mistakes, and incidental choices entangled in the same outcome signal. Existing agentic self-distillation methods enrich sparse supervision with natural-language skills, but skills retrieved externally or extracted from a single trajectory by stronger models may mismatch current experience, exceed the policy's capability, or remain path-specific. We propose Group-Reflective Self-Distillation (GRSD), which derives capability-aligned and outcome-discriminative guidance from the policy's own verified rollouts. For each prompt, the policy reflects on each verified trajectory in an on-policy group, and a stop-gradient snapshot contrasts the resulting reflections from successful and failed rollouts to construct group-level privileged guidance. Conditioned on this guidance, a self-teacher refines turn-level credit assignment by modulating outcome-based advantages while preserving the verifier-determined learning direction. Experiments across multiple agentic environments and model scales demonstrate that GRSD consistently outperforms competitive baselines and generalizes more effectively to unseen tasks.

# 论文总结：面向智能体强化学习的组反思自蒸馏（GRSD）

## 1. 核心问题与研究动机

在基于可验证奖励的强化学习（RLVR）训练大语言模型智能体时，**终局奖励（terminal reward）仅提供粗粒度的轨迹级监督信号**。这一稀疏信号将以下三种本质上不同的成分纠缠在一起：

- **成功行为**：真正促成任务完成的关键决策；
- **反复出现的错误**：导致失败的失败模式；
- **偶发性选择**：与结果无因果关联的中性选择。

现有的"智能体自蒸馏"方法（如 Skill-SD、SDAR、OPID 等）通过向策略注入自然语言"技能"（skill）来稠化监督信号，但存在三类瓶颈：

1. **检索式技能（如 Skill-SD、SDAR）**：从离线技能库检索得到，可能与当前提示、交互历史或环境状态失配；
2. **外部强模型抽取式技能（如 OPID）**：由远强于当前策略的外部分析器从已完成轨迹中提取，可能**超出当前策略的能力边界**，导致策略无法内化；
3. **单轨迹抽取式技能**：独立地从每条轨迹抽取，未在同提示下的多条成功/失败轨迹之间进行对比，容易捕获**路径特异性细节**而非真正区分成败的行为模式。

由此引出两个核心研究问题：

- **Q1**：如何从策略**自身**的在线经验中提炼与自身能力对齐（capability-aligned）的指导信号？
- **Q2**：如何在同提示下的多轨迹间进行**成功-失败对比**，识别对结果真正关键的行为？

## 2. 方法论

### 2.1 整体框架

GRSD 是一个**两阶段构造 + 轮级自蒸馏**的闭环框架：

- **Stage A（策略原生反思）**：用策略自身对每条已验证轨迹生成反思，得到"轨迹级技能"$s_i$；
- **Stage B（组级指导构建）**：用一个停止梯度（stop-gradient）的策略快照 $\bar\pi_{\bar\theta}$ 对比同提示下成功集合 $S_x^+$ 与失败集合 $S_x^-$ 的反思，合成紧凑的 DO/AVOID 指导 $z_x$；
- **轮级自蒸馏**：将 $z_x$ 作为特权上下文（privileged context）注入自教师，对每个轮次的 advantage 进行调制，**保留验证器决定的方向**，仅调整幅度。

### 2.2 关键公式

**(1) 轨迹级 GRPO advantage**

设对每个 prompt 采样 $G$ 条 rollout $\{\tau_i\}_{i=1}^G$，验证器给出奖励 $R_i$ 与二值结果标签 $b_i \in \{0,1\}$，组内归一化优势为：

$$A_i = \mathrm{Norm}_G(R_i) = \frac{R_i - \bar R}{\sqrt{\tfrac{1}{G}\sum_{j=1}^G(R_j-\bar R)^2 + \epsilon_{\mathrm{adv}}}}$$

**(2) Stage A：策略原生反思**

$$s_i \sim \pi_{\theta_{\mathrm{old}}}(\cdot \mid x, \tau_i, b_i, p_{\mathrm{ref}})$$

其中 $p_{\mathrm{ref}}$ 是反思指令 prompt，$s_i$ 含 3 条要点。固定外部评判器 $J$ 给每条反思打分 $r_i^{\mathrm{ref}} = J(s_i, \tau_i, b_i) \in \{0,1,2,3\}$，由此计算反思 advantage $A_i^{\mathrm{ref}} = \mathrm{Norm}_G(r_i^{\mathrm{ref}})$。

**(3) Stage B：组级指导合成**

按结果标签划分：

$$S_x^+ = \{s_i \mid b_i=1\}, \quad S_x^- = \{s_i \mid b_i=0\}$$

用停止梯度快照 $\bar\theta = \mathrm{sg}(\theta_{\mathrm{old}})$ 合成：

$$z_x \sim \pi_{\bar\theta}(\cdot \mid x, S_x^+, S_x^-, p_{\mathrm{guide}})$$

仅当混合结果掩码 $m_x = \mathbb{1}[|S_x^+|>0 \wedge |S_x^-|>0] = 1$ 时才激活指导构造。

**(4) 轮级教师-学生似然差**

对第 $i$ 条轨迹的第 $t$ 轮，构造学生上下文与教师上下文：

$$c^{\mathrm{stu}}_{i,t} = C(x, H_{i,t}), \quad c^{\mathrm{tea}}_{i,t} = C(x, z_x, H_{i,t})$$

冻结策略在两种上下文下对**同一已采样动作**的似然差为：

$$\Delta_{i,t} = \frac{1}{L_{i,t}}\sum_{k=1}^{L_{i,t}}\Big[\log \pi_{\bar\theta}(y_{i,t,k}\mid y_{i,t,<k}, c^{\mathrm{tea}}_{i,t}) - \log \pi_{\bar\theta}(y_{i,t,k}\mid y_{i,t,<k}, c^{\mathrm{stu}}_{i,t})\Big]$$

对齐到验证器方向：

$$q_{i,t} = \mathrm{sign}(A_i)\cdot \Delta_{i,t}$$

**(5) 有界调制分数**

$$u_{i,t} = \exp(q_{i,t}) - 1, \quad D_x = \frac{1}{|T_x|}\sum_{(j,t')\in T_x}|u_{j,t'}| + \epsilon_{\mathrm{gap}}$$

$$\hat q_{i,t} = \mathrm{clip}\!\left(\frac{u_{i,t}}{D_x},\; -\bar G,\; \bar G\right)$$

**(6) 轮级调制 advantage**

$$\hat A_{i,t} = A_i\!\left(1 + \lambda\, m_x\, \hat q_{i,t}\right), \quad \text{约束}\;\lambda\bar G < 1$$

约束保证调制**不会反转 $A_i$ 的符号**——验证器决定方向，指导只调整幅度。

**(7) 总优化目标**

$$\mathcal{L}(\theta) = \mathcal{L}_{\mathrm{task}}(\theta) + \alpha\, \mathcal{L}_{\mathrm{ref}}(\theta)$$

其中 $\mathcal{L}_{\mathrm{task}}$ 是用 $\hat A_{i,t}$ 替换 $A_i$ 的 PPO-clipped GRPO 损失，$\mathcal{L}_{\mathrm{ref}}$ 是反思 token 上的独立 GRPO 损失，二者监督**互不相交的 token 集合**。

### 2.3 理论性质（附录）

论文给出三条命题保证优化机制的稳健性：

- **Proposition 1**（方差缩减）：在条件独立表示假设下，组级对比估计 $\hat d_x$ 的均方误差为 $\mathrm{tr}(\Sigma_1^x/n_+ + \Sigma_0^x/n_-)$，聚合多轨迹可减少路径特异性噪声；
- **Proposition 2**（有界正调制）：若 $\delta = \lambda \bar G < 1$，则 $w_{i,t}\in[1-\delta, 1+\delta]$，且 $\mathrm{sign}(\hat A_{i,t}) = \mathrm{sign}(A_i)$；
- **Proposition 3**（正重加权等价性）：$\phi_\varepsilon(\rho, wA) = w\,\phi_\varepsilon(\rho, A)$，故 GRSD 任务损失**精确等于**一个带 detached 正权重的 clipped GRPO 替代损失。

## 6. 主要结论与发现

1. **整体最优**：跨 3 个骨干 × 3 个环境，GRSD 一致取得最强聚合性能——相对 GRPO 在 ALFWorld +5.5%、SearchQA +2.7%、WebShop Score +4.8%/Success +7.2%；
2. **优于技能自蒸馏**：相对 Skill-SD/SDAR 中较强者，ALFWorld 成功率 +4.2%、WebShop Success +5.5%（跨骨干平均）；
3. **更强的未见过任务泛化**：在 ALFWorld Unseen 上 GRSD 83.6%，超 GRPO 8.2%、超 SDAR 6.0%；在 Pick2/Cool 上提升尤为显著（+23.5/+14.3% vs GRPO）；
4. **持续的晚期增益**：所有 baseline 在训练后半段趋于平台期，GRSD 仍持续上升；
5. **更小的 teacher-student gap**：相对 Skill-SD/SDAR，GRSD 的特权上下文对策略原生似然的扰动更小，表明指导**更兼容**；
6. **反思学习有效**：Stage A 反射奖励随训练显著上升，且有效组（同时含成功与失败）比例持续保持非平凡水平，确保 Stage B 始终有对比证据可用。

## 7. 优点

- **"能力对齐"视角**：用策略自身而非外部强模型生成反思，天然规避技能-能力失配问题；
- **组级成功-失败对比**：相比单轨迹抽取，合成指导更具结果判别力且抑制路径特异性；
- **保持验证器方向**：通过 $\lambda\bar G<1$ 约束，调制只能调整幅度不能反转符号，机制清晰且可证；
- **无推理开销**：所有额外计算仅在训练时发生，推理时仅使用 plain prompt；
- **理论保证**：附录给出三条命题，有界正调制 + GRPO 替代损失的精确正重加权分解；
- **训练成本可控**：相对 GRPO 仅 +17%，相比 SDAR 多出的成本由"更短 teacher forward"部分抵消；
- **组件正交**：任务 loss / 反思 loss 监督 disjoint token 集合，Stage B 完全 stop-gradient，职责清晰；
- **prompt 与示例透明**：附录公开全部模板与一个完整 8-rollout 组的反思-合成对照样例，可复现性强。

## 8. 不足与局限

- **依赖外部评判器**：Stage A 反射奖励由 DeepSeek-V4-Flash 打分，引入对外部模型的依赖，可能引入评判偏差，且**训练和推理的策略-评判器分布不完全一致**；
- **$m_x$ 激活比例受限**：当某 prompt 组内全部成功或全部失败时，$m_x=0$ 退化为 GRPO，限制了指导机制的覆盖率（论文图 7(b) 显示 valid-group 比例仅维持在"intermediate range"）；
- **方差缩减假设的局限**：Proposition 1 假设反思噪声条件独立，论文自己也指出在共享 prompt/参数/解码行为下条件独立性可能不成立；
- **$\Delta_{i,t}$ 是后视信号（hindsight signal）**：$z_x$ 依赖完整轨迹，可能引入非因果的"事后合理化"偏差，附录明确表示该方法**不保证 credit assignment 的因果正确性**；
- **环境与基线覆盖**：仅在 3 类环境上验证，未涉及代码生成、多模态、长程开放世界游戏等；基线集中在已有自蒸馏/RLVR 方法，未与 Process Reward Model（PRM）、MCTS 式反思等更强方法直接对比；
- **OOD 评测规模有限**：Search-based QA 的 5 个 OOD 子集虽数量较大，但都基于 Wikipedia 检索，未覆盖真实工具调用栈异质分布；
- **训练步数差异**：ALFWorld Qwen3-1.7B 跑 600 步，其余仅 240 步，可能放大或缩小不同骨干间的相对优势；
- **失败模式未深入分析**：对 GRSD 在哪些子任务上仍弱于 Skill-SD/SDAR（Table 1 个别单元格未取得最优）缺少定性归因；
