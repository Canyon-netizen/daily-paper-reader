# Idea: 检索增强生成（RAG）系统优化

## 概述
优化检索增强生成系统的端到端性能，包括检索、排序和生成三个环节。

## 详细描述
RAG 是当前 LLM 应用的主流架构，但系统优化空间很大：
- 检索器：Dense vs Sparse、跨语言检索
- 排序器：学习式排序 vs 规则排序
- 生成器：如何更好地利用检索到的上下文
- 幻觉问题的根本解决思路
