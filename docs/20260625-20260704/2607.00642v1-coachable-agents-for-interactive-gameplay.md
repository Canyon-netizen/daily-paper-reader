## 摘要
强化学习已被证明是构建先进人工智能与机器人系统中的宝贵工具，其应用涵盖了从游戏对战到机器人技术再到基础模型等诸多领域。通过试错，这些人工智能系统通常会学习一种近乎最优的行为来解决其任务。然而，在许多用例中，人们希望能够对任务的解决方式施加某种程度的控制，且最好能够实时进行。我们将这些对核心任务的修改称为风格（styles）。我们将通用价值函数逼近器（UVFAs）与精心挑选的训练场景、学习算法以及数据增强相结合，构建了一个用于在复杂领域中指导智能体展现特定风格的框架。我们在 AAA 级电子游戏《地平线：西之绝境》和《Gran Turismo》中，以及在一个开源的人形机器人测试领域中展示了该框架的应用。尽管这些领域性质各异——赛车、风格化的游戏战斗以及人形机器人步行——但每个智能体都对其风格指令展现出高度的一致性，同时仍然能够完成其所在领域的主要任务。重要的是，本文所概述的技术允许终端用户在运行时选择最终行为，从而使其能够灵活地控制最终执行的表现。

## Abstract
Reinforcement learning has proven to be a valuable tool in the creation of advanced AI and robotic systems, contributing to everything from game playing to robotics to foundation models. Through trial-and-error, these AI systems typically learn one, near-optimal behavior to solve their tasks. However, there are many use cases in which one would like to assert some level of control, preferably in real time, over how the task is solved. We refer to these modifications of a core task as styles. We combine universal value function approximators (UVFAs) with carefully selected training scenarios, learning algorithms, and data augmentation to create a framework for coaching agents that exhibit styles in complex domains. We demonstrate the framework's application in the AAA video games Horizon Forbidden West and Gran Turismo, and in an open-source humanoid test domain. Despite the different nature of the domains -- car racing, stylized game combat, and humanoid walking -- each agent shows strong coherence to the style requests while still satisfying the main task in its domain. Importantly, the techniques outlined in this paper allow an end user to choose the final behavior at run time, giving them flexible control over the final executed performance.

# 面向交互式游戏的可指导智能体——论文总结

## 1. 核心问题与研究背景

- **问题定义**：传统强化学习（RL）智能体通常通过试错学习**一种**接近最优的行为来完成单一任务，缺乏对"如何完成任务"这一层面的运行时控制能力。而游戏设计、机器人交互中存在大量"风格可控"的需求。
- **研究动机**：以清理机器人为例，用户可能根据婴儿睡眠或客人来访的情境，分别偏好"安静打扫"或"快速打扫"。这两种风格并非不同**任务**，而是同一任务下的多种**执行方式**，并且常常存在一个连续光谱。
- **与相关工作的区别**：
  - 与多任务学习（multi-task）、多目标 RL（multi-objective）、目标条件 RL（goal-conditioned learning）不同——这些方法将"快速"与"安静"看作两个独立任务，反而掩盖了它们的共性。
  - 与既有可配置智能体工作（如 de Woillemont 等）相比，论文将该思路**首次规模化**到 AAA 级 3D 游戏等高维实时控制领域，并提出完整的训练算法体系。

## 2. 方法论

### 2.1 核心思想：风格条件化 UVFA（Style-Conditioned UVFA）

延续 UVFA（Schaul et al.）将价值函数条件化于"目标状态"的思路，论文将奖励拆分为任务奖励与风格奖励：

$$r(s, a; \theta) = r_{\text{task}}(s, a) + r_{\text{style}}(s, a, \theta)$$

其中 $\theta$ 为多维风格向量（含权重、阈值、设定值等），并对策略与价值网络同时进行风格条件化：$\pi(a|\tilde{s})$、$Q(\tilde{s}, a)$，其中 $\tilde{s} := (s, f(\theta))$。

### 2.2 关键技术细节

- **风格采样分布 $p_{\Theta}$**：风格参数在每个 episode 开始时采样并在该 episode 内固定，避免跨步的信用分配问题：
$$J(\phi) = \mathbb{E}_{s_0 \sim \rho,\ \theta \sim p_{\Theta},\ \tau \sim \pi_\phi}\left[ G_\theta \right],\quad G_\theta=\sum_{t=0}^{T-1}\gamma^t\left[r_{\text{task}}(s_t,a_t)+r_{\text{style}}(s_t,a_t;\theta_t)\right]$$

- **三种领域分别采用不同 RL 算法**（同一离策略 Actor-Critic 框架基础上）：
  - **Humanoid（DMC）**：标准 SAC + tanh-Gaussian 策略。
  - **Gran Turismo 7**：QR-SAC（分位数回归 SAC，使用分布式 critic，先更新策略再更新 critic）。
  - **Horizon Forbidden West**：新算法 **Cat-RAC（Categorical Regularized Actor-Critic）**——
    - 用通用正则化器 $R(a|s, f(\theta))$ 替代熵项，按动作子空间分别施加"离散用精确分类熵 + 连续用 $n=10^3$ 样本的经验负对数密度"；
    - 离散策略头部采用**基于后悔匹配的梯度**修正（受 CFR+ 启发），以避免 Gumbel-Softmax 在大动作空间下的数值不稳定性；
    - 价值函数用 255 bins 的**离散分类分布** + HL-Gauss TD(0) 目标编码；
    - 仍采用"先策略后 critic"的更新顺序以稳定目标分布。

- **数据组织与增强**：
  - **任务模拟（Task Impersonation）**：将每个采样 transition 同时在 $n+1$ 个重采样的风格向量下重新打标签（本文取 $n=4$），扩大风格空间覆盖且不增加 replay 容量；
  - **分层采样（Stratified Sampling）**：在 GT 中用 multi-tables，在 HFW 中用 event tables，保证 mini-batch 对场景/风格的均衡覆盖；
  - **场景训练（Scenario Training）**：在所有领域使用，随机化初始状态、敌人、位置等以提高泛化。

- **风格奖励设计原则**：
  - 风格奖励幅值需归一化/有界化以保证价值函数对 $\theta$ 的平滑依赖；
  - $\theta$ 内部分组件可独立开关、连续变化，支持组合式偏好（如"用腐蚀爆破枪 + 火焰元素"）；
  - $w_i > 0$ 鼓励、$w_i < 0$ 反对、$w_i = 0$ 中立，可在运行时融合而无需重训。

## 6. 主要结论

- 在 GT7 中，$\theta$ 取值可让 GT Sophy 在"省胎/省油"与"圈速"之间连续权衡，使换胎/加油窗口最多延后约 60%，代价仅 2-3 秒/圈；亦可学得漂移（Figure 2）与通过纵向/横向距离阈值调节攻击性（Figure 6）。
- 在 HFW 中，被请求的风格与对应伤害/事件类型呈现明显主对角线强相关（图 3a），且能在战斗中实时切换风格；5 个种子针对元素风格发展出不同武器偏好，符合设计者"多武器平衡"的目标；OOD 敌人仍能赢得大多数战斗；
- Pareto 曲线显示，用户可通过调节风格权重直接在"风格得分-胜率"前沿上选取工作点，无需重训；
- 在 Humanoid 中，连续步长可与三种离散臂部姿态实时组合，并通过开源代码复现；
- 总体结论：**风格条件化 UVFA + 合适的学习算法 + 场景训练/数据增强** 足以在"看似完全不同"的高维实时控制领域中编码一个可表现一族行为的策略。

## 7. 优点

- **统一框架**：单一策略即可表达一族行为，无需为每个风格训练独立网络，显著降低训练成本；
- **运行时可控**：训练完成后用户可在系统运行时实时调制行为，符合"无重训调优"的目标；
- **算法层面的创新**：Cat-RAC 将 SAC 推广到混合离散/连续动作空间，并用 regret-matching 解决了 Gumbel-Softmax 在大动作空间下的数值脆弱性；
- **数据效率**：任务模拟（多 UVFA 重标签）+ 分层采样（event/multi tables）兼顾覆盖与训练稳定性；
- **多领域、可复现**：开源 Humanoid 完整代码；与传统 RL 仅追求单一最优行为相比，框架对游戏设计、QA、可访问性（accessibility）以及未来家用机器人都具有直接应用价值。

## 8. 不足与局限

- **风格奖励工程量大**：风格必须由人工精细设计（18 种风格，每种都对应一组状态-动作-事件奖励），缺乏自动发现或自动编码；
- **OOD 表现下降**：HFW 在面对"两只最难敌人同场"的极限 OOD 时胜率明显下滑；部分风格（如纯近战、Boltblaster/Sunscourge）在 Thunderjaw、Slaughterspine 上胜率不足 50%；
- **奖励权重失衡风险**：在 HFW 中，部分种子因为部件拆除奖励过高，导致策略在弱敌人处追逐"最佳射击角度"而超时（Table 3 中的 Burrower/Scrounger/Scrapper 出现大量 20 分钟超时），说明风格与任务奖励尺度的精细平衡仍是难题；
- **部分可观性**：HFW 中一些投射物等实体缺乏引擎侧的简洁表示，部分可观察性问题尚未完全消除；
- **可解释性方法的局限**：作者明确指出 SHAP/Saliency "不构成因果证据"，仅作为一致性的间接支持；
- **伦理与商业层面**：风格奖励将"设计者偏好"内嵌于智能体，可能放大对某种武器/玩法/打法的偏好，需要后续工作关注公平性与多样性；
- **领域泛化未充分验证**：Humanoid 仅展示仿真，未涉及 sim-to-real 的迁移；Gran Turismo 部分风格（如漂移）仅在特定车型/赛道上展示，跨车型/赛道的鲁棒性尚需更系统评估。
