## 摘要
自蒸馏智能体强化学习通过 token 级蒸馏损失来增广轨迹级奖励，其教师模型为同一策略在特权上下文条件下的输出。当前主流方案以单一标量——教师与学生的对数概率差——作为该损失的门控信号。该信号存在双重局限：它是回顾性的，仅对已实现的回滚进行打分，从不评估反事实回滚；并且它对符号不敏感，从不提示教师偏好的动作是否会对轨迹造成损害。我们提出 CRAFT，一种由三大支柱组成的信用分配方案，用以同时解决上述两个局限。支柱一，即反事实 Token 重要性，复用 GRPO 已然采样的 G-1 个兄弟回滚，并按对数概率差对其进行重要性加权，从而构建一个自归一化的估计量，度量在每一步上对教师偏好动作进行上权重所带来的优势函数组级反事实变化；这以近乎零的额外计算代价得到带符号的逐 token 信用。支柱二是一个非对称控制器，它沿门控活动的指数移动平均，蒸馏权重升高时参考 KL 权重相应降低，反之亦然。支柱三对 KL 惩罚进行逐 token 极化，根据信用符号在寻峰模式与覆盖模式更新之间切换。每个支柱都配有独立的开关；当禁用时，损失与梯度在 IEEE-754 算术下与基线逐字节相同，因此任何测得的增益都归因于算法层面的改变，而非实现漂移。我们证明了该估计量的一致性与方差界，给出了结构层面与位精确层面的可复现性保证，并在三个智能体环境、四种模型规模、五种端到端方法上评估了 CRAFT，外加两个以表格形式列出的既有工作基线。其中一项对照方法为自适应 CRINGE，它与 CRAFT 共享支柱二的设计，从而可单独隔离出反事实机制的贡献。

## Abstract
Self-distilled agentic reinforcement learning augments trajectory-level reward with a token-level distillation loss, using as its teacher the same policy conditioned on privileged context. The prevailing recipe gates this loss by a single scalar, the teacher-student log-probability gap. This signal is doubly limited: it is retrospective, scoring only the realised rollout and never the counterfactual ones, and it is sign-blind, never signalling when a teacher-preferred action would have harmed the trajectory. We introduce CRAFT, a three-pillar credit-assignment scheme that addresses both limitations. Pillar 1, Counterfactual Token Importance, reuses the G-1 sibling rollouts that GRPO already samples and importance-weights them by the log-probability gap to form a self-normalised estimate of the group-level counterfactual change in advantage from up-weighting teacher-preferred actions at each step; this yields a signed per-token credit at near-zero extra compute. Pillar 2 is an asymmetric controller that raises the distillation weight as it lowers the reference-KL weight along an exponential moving average of gate activity, and conversely. Pillar 3 polarises the KL penalty token by token, switching between a mode-seeking and a mode-covering update according to the sign of the credit. Each pillar has an independent switch that, when disabled, renders the loss and gradient byte-identical to the baseline in IEEE-754 arithmetic, so any measured gain is attributable to algorithmic change rather than implementation drift. We prove the estimator's consistency and a variance bound, give structural and bit-exact reproducibility guarantees, and evaluate CRAFT across three agentic environments, four model scales, and five end-to-end methods, plus two tabulated prior-work baselines. Among these is Adaptive-CRINGE, a comparator sharing Pillar 2 with CRAFT, isolating the counterfactual contribution.

## 一、核心问题与研究动机

### 1.1 背景
自蒸馏智能体强化学习（Self-Distilled Agentic RL, SDAR）在轨迹级奖励之上引入 token 级蒸馏损失：将同一策略 $\pi_\theta$ 在特权上下文 $s^+_t$（技能标注、验证器提示、检索轨迹等）下的输出作为"教师" $\pi_T$，用教师—学生的对数概率差 $\Delta_t = \log \pi_T(y_t \mid s^+_t) - \log \pi_\theta(y_t \mid s_t)$ 作为门控信号：

$$L_{\text{SDAR}} = \text{Agg}\big[\sigma(\beta\Delta_t)\cdot (\log \pi_T - \log \pi_\theta)\big]$$

### 1.2 现存双重局限
- **回顾性（Retrospective）**：$\Delta_t$ 仅对**已发生**的回滚打分，无法刻画"若第 $t$ 步采用教师动作，序列优势将如何变化"这一反事实信息，尽管 GRPO 已然为每个 prompt 采样了 $G$ 条平行回滚。
- **符号盲（Sign-blind）**：门 $\sigma(\beta\Delta_t)$ 关于 $\Delta_t$ 单调，即使在教师偏好的动作会**损害**轨迹的位置，仍给出弱正权重；门控信号永远不会告诉策略"教师的动作更差，不要跟随它"。

### 1.3 论文立场
正确的逐 token 信用应是"若在第 $t$ 步从教师采样，序列优势的反事实变化量"。GRPO 已采样的 $G-1$ 个兄弟回滚天然提供了几乎免费的样本池，可构造自归一化重要性采样（SNIS）估计量，无需额外采样。

## 二、方法论：CRAFT 三支柱信用分配

整体损失保持 $L_{\text{GRPO}}$ 与教师前向不变，仅在三处叠加新项：

$$L_{\text{CRAFT}}(\theta) = L_{\text{PG}}(\theta) + \mu^{(t)} L_{\text{KL-pol}}(\theta) + \lambda^{(t)} L_{\text{CTI}}(\theta)$$

三个支柱各自配有独立的**主开关**，关闭后损失与梯度与基线在 IEEE-754 下逐字节相同（保证 P7）。

### 2.1 支柱一：反事实 Token 重要性（CTI）

**理想化逐轨迹目标**：

$$\text{CTI}^{(i)}_t = \mathbb{E}_{y'_t \sim \pi_T(\cdot \mid s^{+,(i)}_t)}\big[A(\tau^{(i)}_{<t}, y'_t, \tau^{(i)}_{>t})\big] - A^{(i)}$$

**组级可估计量**（避免对单轨迹重采样）：

$$\overline{\text{CTI}}^{(i)}_t = \frac{\mathbb{E}_{\mu_t}[\varrho A]}{\mathbb{E}_{\mu_t}[\varrho]} - A^{(i)}, \quad \varrho := \frac{\pi_T(y_t \mid s^+_t)}{\pi_\theta(y_t \mid s_t)}$$

**自归一化重要性采样估计量**（$\tau=1$，$w^{(j)}_t \propto e^{\Delta^{(j)}_t}$）：

$$\widehat{\text{CTI}}^{(i)}_t = \sum_{j \neq i} w^{(j)}_t A^{(j)} - A^{(i)}$$

**带符号信用**（中心化非对称 sigmoid，$c_t \in (-1,1)$）：

$$c_t = \big(2\sigma(\beta_+ \widehat{\text{CTI}}_t) - 1\big)\mathbb{1}[\widehat{\text{CTI}}_t > 0] - \big(2\sigma(\beta_-|\widehat{\text{CTI}}_t|) - 1\big)\mathbb{1}[\widehat{\text{CTI}}_t < 0]$$

**CTI 损失**（REINFORCE 形式，信用 $c_t$ 停止梯度）：

$$L_{\text{CTI}}(\theta) = -\text{Agg}\big[c_t \cdot \log \pi_\theta(y_t \mid s_t)\big]$$

**边际算力**：仅需一次 `torch.no_grad()` 下的组级 softmax 与加权求和，复杂度 $O(BTG)$，相比基线开销可忽略。

### 2.2 支柱二：相位感知非对称控制器

定义门活动比率 $\rho_{\text{gate}}(t)$ 为当前 mini-batch 中满足 $|c_t|>\theta_g$ 的 token 占比。控制器维护 EMA：

$$\rho^{\text{EMA}}_{\text{gate}}(t+1) = \alpha \rho^{\text{EMA}}_{\text{gate}}(t) + (1-\alpha)\rho_{\text{gate}}(t)$$

并沿 EMA 反向联动两个系数：

$$\lambda(t) = \lambda_{\min} + (\lambda_{\max}-\lambda_{\min})\,\rho^{\text{EMA}}_{\text{gate}}(t)$$
$$\mu(t) = \mu_{\min} + (\mu_{\max}-\mu_{\min})\big(1-\rho^{\text{EMA}}_{\text{gate}}(t)\big)$$

效果：训练早期 $\rho_{\text{gate}}$ 高→$\lambda$ 上升吸收教师信号、$\mu$ 下降放松参考 KL；后期反向。前 $n_{\text{warmup}}$ 步保持中位状态防抖。

### 2.3 支柱三：方向极化 KL

根据 $c_t$ 符号按 token 切换三种 KL 形式（阈值 $\theta_{\text{KL}}\ge 0$）：

| 区域 | 分支 | 形式 | 效果 |
|---|---|---|---|
| $c_t > \theta_{\text{KL}}$ | rev | $\log \pi_\theta - \log \pi_{\text{ref}}$ | mode-seeking（吸收） |
| $c_t < -\theta_{\text{KL}}$ | fwd | $-(\log \pi_\theta - \log \pi_{\text{ref}})$ | mode-covering（推开） |
| $|c_t|\le\theta_{\text{KL}}$ | std | 标准 $k_3$ 惩罚 | 中性带 |

注：fwd 分支并非 $KL(\pi_{\text{ref}}\|\pi_\theta)$ 的无偏估计（IS 替代在 $\pi_\theta$ 极小时方差无界），论文将其作为**策略更新规则**而非散度估计器。

### 2.4 关键结构性命题（P1–P7）
- **P1**：在 $\tau=1$ 下，$\widehat{\text{CTI}}^{(i)}_t$ 是组级目标的一致估计量（$G\to\infty$ 时依概率收敛，$O(1/G)$ 偏差）。
- **P2**：$\text{Var}(\widehat{\text{CTI}}^{(i)}_t) \le R^2_{\max}\bar\rho_t^2/(G-1)$，$\bar\rho_t$ 为 Horvitz–Thompson 帽。
- **P3**：锐化门控 $\beta_\pm\to\infty$ 且退化到单回滚回退 $\widehat{\text{CTI}}\leftarrow A^{(i)}\Delta^{(i)}_t$ 时，$L_{\text{CTI}}$ 逐 token 收敛到 $L_{\text{SDAR}}$（正优势 token）或其符号翻转版（负优势 token）。
- **P4**：控制器 EMA 以速率 $\alpha$ 几何收敛至 $\bar\rho$。
- **P5**：rev/fwd 分支梯度方向与 $\text{sign}(c_t)$ 一致，per-token KL 上界为 $|\log\pi_\theta-\log\pi_{\text{ref}}|$。
- **P6**：$L_{\text{PG}}$ 不变，附加项在 (A1)–(A3) 下有限、与 PPO 裁剪兼容。
- **P7**：所有开关关闭时 $L_{\text{CRAFT}}=L_{\text{baseline}}$ 字节相同（`torch.equal` 验证）。

### 8.3 理论层面
- **L4**：支柱一中 SNIS 估计量的偏差上界 $O(1/G)$（P1）仅给出量级，未给出在 $\beta_\pm$ 有限、$G=8$ 时的具体偏差数值
- **P2 方差界**依赖 $R^2_{\max}$ 与 Horvitz–Thompson 帽，实际方差可能受 $\pi_\theta$ 接近零时的重要性权重爆炸影响
- **fwd KL 更新规则**：L5 已指出非散度估计器，论文未给出其与真正 $KL(\pi_{\text{ref}}\|\pi_\theta)$ 优化轨迹的差距界

### 8.4 可复现性层面
- **代码发布**：论文承诺开源 87 条 CI 测试与训练脚本，但 9 个新超参数的默认值跨环境是否需重新调优未明示
- **特权上下文依赖**：CRAFT 与 SDAR 同样依赖 $s^+_t$（技能标注、验证器提示、检索轨迹），实际部署中此类"教师特权"的获取成本与噪声敏感性未单独讨论
- **随机种子**：未明确报告每个 cell 的种子数量与置信区间

## 九、可复现性与工程严谨度

### 9.1 强项
- **位精确回退**：P7 锚定所有附加项关闭后与基线 `torch.equal` 一致，彻底排除"实现 bug 伪装成增益"的可能
- **完整 CI 测试栈**：87 条回归测试（8 条位精确 + 24 条数学正确性 + 55 条工程契约），CPU 上约 4 秒即可跑完，可作为下游使用者的金标准
- **伪代码清晰**：三个支柱各有独立伪代码块（Algorithm 1–3），可一一对应实现
- **结构性命题配套测试**：每个 Prop 至少配一条单元测试或端到端验证

### 9.2 风险点
- 9 个超参数中 $\beta_\pm$、$\tau$、$\theta_g$ 对结果敏感度较高（A4、A5 扫描），新环境接入时需重做小规模网格
- Adaptive-CRINGE 作为对照是论文提出的内部变体，第三方无既有代码可参照，复现需自行实现 CRINGE 负信用项

## 十、与 SOTA 的相对位置

| 维度 | CRAFT 表现 |
|---|---|
| 主指标（4×3=12 cell） | 12/12 最优 |
| OOD 鲁棒性 | 显著优于 SDAR 与 Adaptive-CRINGE |
| 训练成本 | 与 SDAR 持平（无额外采样） |
| 部署成本 | 需额外维护 $\rho_{\text{gate}}$ EMA 与方向 KL 路由 |
| 调优成本 | 9 个新超参数，默认值固定但需小规模验证 |

相较于 SDAR，CRAFT 在保持零边际采样成本的前提下，将"单门控回顾性重加权"升级为"反事实 + 极化 KL + 自适应控制器"三位一体机制，并在 P7 锚定下做到归因干净。

## 十一、面向实践者的建议

- **优先接入 GRPO 类 backbone**：需 $G\ge 2$ 的组回滚，PPO 单条轨迹版需先做适配
- **先关后开**：建议按 P1 → P1+P2 → P1+P3 顺序逐步打开，每加一根支柱做小规模 ablation
- **关注 $\rho_{\text{gate}}$ EMA**：训练中监控该曲线，若长期贴近 0 或 1 提示 $\beta_\pm$ 需调整
- **跨环境迁移**：E7 已显示 OOD 增益空间，建议在新环境先用 A4/A5 做局部扫描

## 十二、整体评价

CRAFT 是一篇**机制清晰、归因严谨、工程扎实**的自蒸馏 RL 改进工作。其核心贡献——将 SDAR 的"回顾性符号盲"门控替换为基于兄弟回滚的 SNIS 反事实估计量——在 12 个主网格 cell 上获得一致正向增益（最大 +5.5，最小 +1.6），并通过 Adaptive-CRINGE 对照与 A6/A7 反向实验给出了可证伪的因果证据。P7 字节相同性保证将"实现偏差"质疑降到最低，87 条 CI 测试显著降低第三方接入门槛。

主要遗憾在于：(1) 消融实验仅在单模型上做，规模化稳健性证据偏弱；(2) 极化 KL 独立增益小，理论动机（受前向 KL 启发但非其估计器）的解释仍待加强；(3) OOD 仅同域留出，未触及真正跨域迁移；(4) 训练预算与算力披露不完整，复现成本估算困难。

总体而言，CRAFT 在"自蒸馏 + GRPO"这一赛道提供了**目前最干净的可证伪改进**，对于追求机制可解释性与可复现性的研究者与工程团队均具较高参考价值；对于追求绝对 SOTA 数字的工业部署，建议先在小规模 cell 上复现 E1 与 E7，再决定是否全面替换 SDAR。
