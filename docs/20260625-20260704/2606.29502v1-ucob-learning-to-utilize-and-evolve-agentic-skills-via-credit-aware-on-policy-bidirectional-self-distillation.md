## 摘要
技能记忆可以通过将过去经验作为文本指导进行重用来提升智能体强化学习，但检索到的技能并非神谕：它们可能在某个状态下有所帮助，又在另一个状态下误导同一策略。这使得常见的特权教师假设变得脆弱，即假设以技能为条件的提示可以被当作无技能提示的固定教师。我们提出了 UCOB，一个通过信用感知在线策略双向自蒸馏来学习利用与演化智能体技能的框架。UCOB 将以技能为条件的提示与无技能提示视为同一模型的两种在线策略上下文视图，在同一任务与锚定状态下比较它们的剩余回报，并将回报更高的视图作为局部教师。这一局部信用信号将有用的技能条件化行为内化、纠正误导性的技能使用，并指导任务/状态层面的技能记忆更新、效用感知的检索以及反思式自训练。在包括 ALFWorld、WebShop 和 Search-QA 在内的智能体任务上的实验表明，UCOB 在不同模型规模下均优于无技能强化学习、技能记忆基线以及自蒸馏方法，在 ALFWorld 和 WebShop 上相比当前最优基线分别取得了高达 23.5 和 18.0 分的提升。消融实验与进一步的分析验证了其核心机制与效率。

## Abstract
Skill memories can improve agentic reinforcement learning by reusing past experience as textual guidance, but retrieved skills are not oracular: they may help in one state while misleading the same policy in another. This makes the common privileged-teacher assumption fragile, namely that a skill-conditioned prompt can be treated as a fixed teacher for the no-skill prompt. We introduce UCOB, a framework for learning to utilize and evolve agentic skills via credit-aware on-policy bidirectional self-distillation. UCOB treats skill-conditioned and no-skill prompts as two on-policy context views of the same model, compares their return-to-go within the same task and anchor state, and uses the higher-return view as the local teacher. This local credit signal internalizes useful skill-conditioned behavior, corrects misleading skill usage, and guides task/state skill memory updates, utility-aware retrieval, and reflection self-training. Experiments on agentic tasks, including ALFWorld, WebShop, and Search-QA, show that UCOB outperforms skill-free RL, skill-memory baselines, and self-distillation methods across model scales, with up to 23.5 and 18.0 point gains over SOTA baselines on ALFWorld and WebShop. Ablations and analyses further validate its core mechanisms and efficiency.

# UCOB 论文总结

## 1. 研究动机与核心问题

在智能体强化学习（agentic RL）的长视野交互任务中，传统方法依赖稀疏的终局奖励反馈，导致样本效率低、探索困难。近年来，**技能记忆（skill memory）** 作为一种将过往经验转化为可复用文本指导的机制，能够改善智能体的探索与泛化能力（代表性工作包括 Reflexion、Voyager、SkillRL、D2Skill、Skill1 等）。

然而，论文指出这些方法普遍隐含一个**脆弱假设**：将"有技能条件化（skill-conditioned）提示"作为"无技能（no-skill）提示"的特权教师（privileged teacher）。但检索到的技能并非神谕（not oracular），它们可能：
- 与当前状态不相关、过时或过于通用；
- 在某些状态下显著帮助智能体，却在另一些状态误导同一策略；
- 智能体无法把有用的技能在当下观察中有效接地（ground）。

这种**教师质量的局部异质性**使得固定方向的技能到无技能蒸馏变得不可靠。论文通过三组诊断实验（Section 2）系统验证了这一观察：在 SDAR 设置下，带技能评估（eval w/ skills）并不一致优于不带技能评估；将技能条件化分支也纳入在线 rollout（dual-rollout）虽然缩小了暴露失配（exposure mismatch），仍然无法消除教师歧义（teacher ambiguity）；按 anchor state 分组对比两视角回报，发现符号混合的局部价值差（value gap），说明"哪一视角应作教师"必须**基于同状态回报证据**逐状态决定。

## 2. 方法论：UCOB 框架

### 2.1 核心思想

UCOB（**U**tilize and evolve agentic skills via **C**redit-aware **O**n-policy **B**idirectional self-distillation）将"有技能提示 $P_+(s_t)$"与"无技能提示 $P_0(s_t)$"视为**同一在线模型的两种上下文视角**，而非固定的师生关系。核心机制是把跨视角对比产生的**局部信用**同时用于：
1. **策略蒸馏方向的选择**（CBSD）；
2. **任务级与状态级技能记忆的更新、检索、写回**；
3. **反思式技能写手（reflection-based skill writer）的自训练**。

### 2.2 关键技术细节

#### 2.2.1 双粒度技能记忆与 UCB 检索

UCOB 维护两个独立的技能池：任务级（task-level）描述可复用策略，状态级（state-level）基于同锚定状态高低回报对比生成局部决策规则。每个技能 $m$ 包含文本原则、适用条件、检索键 $k_m$、效用分数 $U(m)$、使用计数 $n_m$。检索分数采用 UCB：

$$R_p(m;s_t) = \alpha \cdot \mathrm{sim}(q_p(s_t), k_m) + (1-\alpha)\left(U(m) + \eta\sqrt{\frac{\log(N_p+1)}{n_m+1}}\right)$$

其中 $p \in \{\text{task}, \text{state}\}$，$q_p$ 为对应池的检索查询，$N_p$ 为池总使用次数。

#### 2.2.2 混合技能/无技能在线 Rollout

对每个任务组，UCOB 对**当前在线策略** $\pi_\theta$ 同时采样：一半轨迹使用 $P_+$，另一半使用 $P_0$；两分支都获得环境交互奖励与 RL 更新，**没有预先固定的教师**。

#### 2.2.3 锚定状态分组（Anchor-State Grouping）

沿用 GiGPO（Feng et al., 2025）的机制，在同一任务 $u$ 内把到达相同 anchor 状态 $\tilde{s}$ 的记录归入同一组 $C(u, \tilde{s})$，构造可比对记录：

$$\rho_{i,t} = \langle s_{i,t},\ c_{i,t},\ P_{c_{i,t}}(s_{i,t}),\ P_{\bar{c}_{i,t}}(s_{i,t}),\ y_{i,t},\ G_{i,t} \rangle$$

其中 $c_{i,t} \in \{+,0\}$ 为采样分支，$\bar{c}_{i,t}$ 为对侧分支，$G_{i,t} = \sum_{\ell \ge 0} \gamma^\ell r_{i,t+\ell}$ 为回报。

#### 2.2.4 CBSD：信用感知的双向自蒸馏

对每个 anchor-state 组，先选最高回报记录 $\rho^\star$，其分支记为 $c^\star$，响应记为 $y^\star$；对所有对侧分支记录 $\rho_{\mathrm{opp}}$（满足 $G_{\rho^\star}-G_{\rho_{\mathrm{opp}}>\epsilon_{CBSD}$）形成候选对 $e=(\rho^\star,\rho_{\mathrm{opp}})$。**若 $c^\star=+$，技能视图教导无技能视图；若 $c^\star=0$，无技能视图反向纠正技能视图。** 教师方向完全由同状态回报决定。

对每个被接受的对 $e$，在共享前缀 $y^\star_{<j}$ 上评估两视角分布，对参考视角取 Top-$K_{tok}$ token 支持集 $S_{e,j}$，在该集合上做 KL 重整化：

$$q_{e,j}(v) = \mathrm{sg}\!\left[\frac{\pi_\theta(v\mid h^{\mathrm{ref}}_{e,j})}{\sum_{z\in S_{e,j}}\pi_\theta(z\mid h^{\mathrm{ref}}_{e,j})}\right],\quad p_{e,j}(v) = \frac{\pi_\theta(v\mid h^{\mathrm{tgt}}_{e,j})}{\sum_{z\in S_{e,j}}\pi_\theta(z\mid h^{\mathrm{tgt}}_{e,j})}$$

token 级匹配损失为 $D^{topK}_{e,j} = \mathrm{KL}(q_{e,j}\Vert p_{e,j})$。结合 SDAR 风格的置信门（confidence gate）抑制不可靠位置：

$$g_{e,j} = \sigma\!\left(\beta_{\mathrm{gate}}\left(\log\pi_\theta(y^\star_j\mid h^{\mathrm{ref}}_{e,j}) - \log\pi_\theta(y^\star_j\mid h^{\mathrm{tgt}}_{e,j})\right)\right)$$

gap 加权 $w_e = \mathrm{clip}(\Delta_e/\tau_{CBSD},\ 0,\ w_{\max})$，得到 CBSD 损失：

$$L_{CBSD} = \frac{1}{Z_{CBSD}}\sum_{e\in P_{CBSD}}\sum_j \chi_{e,j}\,D^{topK}_{e,j},\quad \chi_{e,j}=m_{e,j}\,w_e\,g_{e,j}$$

#### 2.2.5 技能记忆演化与写手自训练

- **写技能**：任务级技能通过 rollout 组反思生成；状态级技能基于同一 anchor state 内**高 vs 低回报对比**生成（区别于 D2Skill 的轨迹级总结）。
- **效用更新**：以任务组无技能成功率 $b_u$ 为基线，使用技能的 rollout 成功率提升 $\delta_m$ 作 EMA 更新：

$$U(m) \leftarrow (1-\beta_U)U(m) + \beta_U\,\delta_m$$

- **写手自训练**：利用反思响应 $(x_m, z_m)$ 与池归一化效用优势 $A^{\mathrm{refl}}_m = (U(m)-\mu_{\mathrm{pool}})/\max(\sigma_{\mathrm{pool}},\,\epsilon_{\mathrm{refl}})$，做 PPO 风格 clip 损失：

$$L_{\mathrm{refl}} = -\frac{1}{Z_{\mathrm{refl}}}\sum_{m,j}\ell^{\mathrm{refl}}_{m,j}\,\min\!\left(\rho^{\mathrm{refl}}_{m,j}A^{\mathrm{refl}}_m,\ \mathrm{clip}(\rho^{\mathrm{refl}}_{m,j},1-\epsilon,1+\epsilon)A^{\mathrm{refl}}_m\right)$$

#### 2.2.6 总体训练目标

$$L = L_{RL} + \lambda_{CBSD}\,L_{CBSD} + \lambda_{\mathrm{refl}}\,L_{\mathrm{refl}} + \beta_{KL}\,L_{KL}$$

其中 $L_{RL}$ 为 GiGPO 风格的 group advantage RL 损失，$L_{KL}$ 为参考策略正则。

### 2.3 理论视角（附录 C）

**命题 1（CBSD 一阶局部改进方向）**：固定旧策略 $\pi$ 与上下文 $x=(u,\tilde s)$，记 $\mu_c(x)=\mathbb{E}_{y\sim p_c(\cdot|x)}Q^\pi(x,y)$，$\Delta(x)=\mu_+(x)-\mu_0(x)$。设 $h,\ell$ 为高低分支（$\delta_x>0$），理想插值 $p^\eta_\ell=(1-\eta)p_\ell+\eta p_h$，则：

$$\mathbb{E}_{p^\eta_\ell}A^\pi(x,y) - \mathbb{E}_{p_\ell}A^\pi(x,y) = \eta\delta_x$$

在 trust-region 控制下 $J(\pi_\eta)-J(\pi) \ge \frac{d_\pi(x)}{1-\gamma}\eta\delta_x - C\eta^2$。当 $\Delta(x)<0$ 时固定技能→无技能方向会**局部退化**（命题 4），而 CBSD 反向蒸馏保持更新符号为正。Corollary 1 在"高回报分支更接近局部最优响应"的条件下给出 KL 收缩率 $\eta\zeta_x$。

## 6. 主要结论与发现

1. **整体性能**：UCOB 在 ALFWorld 与 WebShop 上对三种 backbone 均取得最佳/次佳整体成功率，对 Skill1 在 Qwen3-1.7B 上分别提升 **+23.5 / +18.0 分**，对 SDAR 提升 **+35.2 / +21.1 分**；7B、3B 上相对最强先验也有 0.8–3.1 分的稳定提升。
2. **Search-QA**：UCOB 在三种 backbone 上

均取得最佳 Accuracy，平均较 Skill1 提升 **+4.8 ~ +8.2 分**，较 SDAR 提升 **+7.6 ~ +10.3 分**，显示技能蒸馏的双向策略在多跳检索-推理任务上同样有效。

2. **CBSD 关键性**：固定教师方向（force-directed）和仅保留 gap 门但强制技能→无技能（gap-gated）都明显退化，验证"教师方向必须由同状态回报证据决定"是 UCOB 性能增益的核心来源，而非单纯的 top-K 蒸馏或双向训练。

3. **混合 rollout 的作用**：去掉 mixed rollouts（仅用技能视角做 rollout）会导致性能显著下降，说明在 SDAR 设定下仅靠 dual-rollout 缩小暴露失配是不够的，CBSD 在此基础上进一步消除教师歧义才是关键。

4. **状态级技能与反思自训练**：state skills、reflection self-training、anchor-state grouping 三项去掉后均出现可观测的性能损失；反思自训练使用 GPT-5.4 作为外部后端时与自训练后端性能接近，但自训练版额外节省推理成本。

5. **机制可解释性**（图 8）：
   - CBSD 路由中"无技能→技能"方向比例在训练中后期上升至接近 50%，说明确实存在大量状态是基础视角更优；
   - 技能库规模随训练增长但效用均值与 Useful-Skill Ratio 保持稳定，记忆演化机制避免了低质量技能堆积；
   - 反思优势的幅度随训练逐步下降，反映技能池质量提升后边际增益趋于饱和。

6. **两视角评估曲线**（图 9）：UCOB 训练后期 eval w/ skills 与 w/o skills 的成功率均高于 Dual-SDAR 且差距更小，说明 UCOB 真正学到"在需要时用技能、不需要时不被技能误导"的弹性利用能力，而非仅靠技能增益掩盖基础策略缺陷。

7. **成本对比**（图 10）：在 Qwen3-1.7B 上 UCOB 达到与 SDAR 相同成功率所需的训练时间更短，per-step breakdown 显示额外开销主要来自 CBSD 的双向前向与 top-K 集合重算，可控且随批量增大摊薄。

8. **案例分析**（图 11）：在 ALFWorld 的具体 episode 中，CBSD 在某些状态选择技能→无技能教师，在另一些状态反向纠正技能视角，与论文核心论断"教师方向必须逐状态决定"在定性层面一致。

## 7. 局限与潜在不足

- **模型规模**：实验覆盖 1.7B / 3B / 7B，但消融、机制分析与成本曲线几乎全部基于 Qwen3-1.7B，更大模型上的组件贡献是否同构未充分验证。
- **基准多样性**：仅三个 agentic / QA 基准（ALFWorld、WebShop、Search-QA），未覆盖代码生成、操作系统类（OSWorld）、游戏类（Crafter / Minecraft）等更广任务域。
- **技能记忆上限**：技能池规模随训练单调增长，但未引入遗忘或剪枝机制；长时程训练下检索与效用更新的稳定性仍需更长 horizon 实验验证。
- **理论保证强度**：附录 C 的命题以"高回报分支更接近局部最优响应"为前提假设（Assumption 1），该假设在实际 LLM 策略下的成立程度未给出定量刻画。
- **统计显著性**：主表未报告多次随机种子下的均值与标准差，也未做显著性检验；部分基线数字复用原作者报告值，存在实现差异风险。
- **超参敏感性**：$\lambda_{CBSD}$、UCB 系数 $\alpha$、$\eta$、top-$K_{tok}$ 等关键超参仅做有限离散扫描，未做 grid 或敏感度曲线分析。

## 8. 总结性评价

UCOB 针对 agentic RL 中"技能到无技能"固定教师蒸馏这一普遍但脆弱的范式，提出**信用感知的双向自蒸馏（CBSD）+ 双向混合 rollout + 双粒度技能记忆演化 + 反思写手自训练**的系统性方案。其核心思想——将技能/无技能提示视为同一在线模型的两种上下文视角、并以同状态回报决定蒸馏方向——具有清晰的方法论动机与理论支撑，并在三个主流 agentic 基准、三个不同规模 backbone 上取得一致提升。论文的优势在于：（1）动机由三组诊断实验自然推出；（2）方法覆盖技能记忆的检索、更新、生成全生命周期；（3）实验含主表、消融、机制可视化、成本分析与案例，证据链完整。主要短板在于更大模型上的消融、统计稳健性、长程训练下的记忆稳定性，以及对"高回报分支即局部最优"假设的实证支撑仍有补足空间。总体而言，UCOB 是对 skill-conditioned agentic RL 中教师质量异质性问题的明确、有力且可复现的一次推进。
