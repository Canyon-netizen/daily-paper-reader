## 摘要
在没有真实世界交互反馈或人工标注监督的情况下对大型语言模型（LLM）进行后训练仍然具有挑战性，尤其是在专家标注成本高昂的专业领域。最近的无标注自演化方法通过将模型自身输出用作监督信号来解决这一问题：通过额外上下文构建教师模型，并通过多数投票聚合多次rollout的预测以生成伪标签。然而，这些方法并非没有缺点：基于SFT和GRPO的变体存在域外性能下降问题，而基于奖励的on-policy强化学习则会扩大校准误差。本文提出了神经元在线策略自蒸馏（Neuron-OPSD），这是一个以数据为中心的无标注自蒸馏框架，利用内部神经元激活来指导训练数据选择和教师上下文构建。随后，模型通过从教师分布进行在线策略蒸馏来训练，在任何阶段都不需要真实标签。在专业领域基准测试中，Neuron-OPSD在提升域内任务性能的同时，保持了跨域泛化能力，并缓解了相对于先前无标注基线的校准崩溃问题。该框架特别适用于在线交互或外部监督成本高昂或不可行的场景，且在概念上不同于依赖记录的有奖励标签轨迹的离线强化学习方法。

## Abstract
Post-training large language models (LLMs) without real-world interaction feedback or human-labeled supervision remains challenging, particularly in specialized domains where expert annotations are costly to obtain. Recent annotation-free self-evolution methods address this by using the model's own outputs as supervision signals, constructing a teacher via additional context and aggregating predictions across multiple rollouts through majority voting to produce pseudo-labels. However, these approaches are not without drawbacks: SFT- and GRPO-based variants suffer out-of-domain performance degradation, while reward-based on-policy RL inflates calibration error. In this paper, we propose Neuron On-Policy Self-Distillation (Neuron-OPSD), a data-centric framework for annotation-free self-distillation that leverages internal neuron activations to guide both training-data selection and teacher context construction. The model is then trained via on-policy distillation from the teacher distribution, requiring no ground-truth labels at any stage. Across specialized-domain benchmarks, Neuron-OPSD improves in-domain task performance while preserving cross-domain generalization and mitigating calibration collapse over prior annotation-free baselines. This framework is particularly relevant to settings where online interaction or external supervision is costly or infeasible, and is conceptually distinct from offline RL approaches that rely on logged, reward-labeled trajectories.

# 面向无标注 LLM 自蒸馏的神经元感知数据选择 — 论文总结

## 1. 核心问题与研究动机

在缺乏真实交互反馈与人工标注的专业领域（如教育、法律、STEM 等）对 LLM 进行后训练仍然困难。现有无标注自演化方法的核心问题：

- **SFT 类方法**（如 LMSI）：在自生成响应/推理链上微调，容易引发**灾难性遗忘**和**域外性能下降**。
- **GRPO 类方法**（如 TTRL、Intuitor）：将多次 rollout 通过多数投票压缩为标量奖励后优化，会面临**组内奖励方差消失导致的梯度消失**、**熵坍缩**，并且**标量奖励只能提供轨迹级监督**，无法指引具体推理环节。
- **奖励式 on-policy RL**：会放大模型的**校准误差**（calibration error），即置信度与正确性错配。

本文的核心洞察：当没有外部更强教师或奖励信号时，必须依赖**模型自身内部信号**来挑选可靠训练样本并构造有信息量的教师上下文，否则自蒸馏只会强化已有幻觉与错配。

## 2. 方法论

### 2.1 整体框架：Neuron-OPSD

Neuron-OPSD 包含**数据选择 + 上下文构造 + 自演化训练**三个阶段，全程不使用真实标签。

### 2.2 内部神经元激活提取

对于样本 $x$，先用冻结 LLM 在 zero-shot 下生成 rollout。对每个生成 token $\hat{y}$，对每层 $l$、神经元 $i$ 计算"早期反嵌入贡献分数"：

$$S^{\hat{y},i}_{l} = k^{i}_{l} \cdot (w^{\text{out},i}_{l} \cdot e_{\hat{y}}), \quad k_l = \sigma(h_l W^{\text{in}}_l)$$

对每个生成 token 取所有层中分数前 K=5000 的神经元并集，得到样本的激活集 $N(x)$。

### 2.3 数据选择：神经元共识（Neuron Consensus）

将样本可靠性代理定义为激活神经元数量：

$$s(x) = |N(x)|$$

$s(x)$ 越小表示神经元激活越稀疏、共识越强、与正确性正相关（论文在 SciKnowEval 上 Pearson $r = -0.369,\ p<10^{-6}$）。Neuron-OPSD 选择**前 20% 最低激活**的样本作为训练集 $\mathcal{S}$。

### 2.4 教师上下文构造：神经元重叠（Neuron Overlap）

用 Jaccard 距离度量两个样本在神经元激活上的相似度：

$$J(x_i, x_j) = 1 - \frac{|N(x_i) \cap N(x_j)|}{|N(x_i) \cup N(x_j)|}$$

为每个查询 $x_q$ 在域内池中检索 K=10 个最近邻作为 few-shot 上下文 $C_K(x_q)$。这些示例与查询共享相似神经元回路，能诱导教师产生更尖锐的预测分布。

### 2.5 自演化训练：On-Policy Distillation (OPD)

- 学生：zero-shot 策略 $\pi^{\text{stu}}_\theta(\cdot|x,y_{<t}) := \pi_\theta(\cdot|x,y_{<t})$
- 教师：EMA 更新 $\bar\theta$ + 神经元检索上下文 $C_K(x)$ ：

$$\pi^{\text{tea}}_{\bar\theta}(\cdot|C_K(x),x,y_{<t}) := \pi_{\bar\theta}(\cdot|C_K(x),x,y_{<t}), \quad \bar\theta \leftarrow (1-\tau)\bar\theta + \tau\theta$$

- 优化目标为**逐 token 反向 KL 散度**：

$$\mathcal{L}_{\text{OPD}} = \mathbb{E}_{x\sim\mathcal{S},\,y_{<t}\sim\pi^{\text{stu}}_\theta}\!\left[\sum_{t=1}^{T} D_{\text{KL}}\!\left(\pi^{\text{stu}}_\theta(\cdot|x,y_{<t}) \,\Big\|\, \pi^{\text{tea}}_{\bar\theta}(\cdot|C_K(x),x,y_{<t})\right)\right]$$

反向 KL 使学生**逼近教师分布**（mode-seeking），从而在不丢教师不确定性信息的前提下进行 token 级蒸馏。算法见原文 Algorithm 1。

## 6. 主要结论与发现

1. **神经元共识与正确性强相关**：SciKnowEval 上 Pearson $r = -0.369$，四个子域均显著（图 2、图 3）。激活越稀疏 → 共识越强 → 模型更可能正确。
2. **共识选择非充分条件**：Top-20% 与 Bottom-20% 在 OPD 下表现接近，说明激活计数虽具信息量，但**单独作为选择规则不够**，存在"可靠但学习价值低 vs 不确定但有改进空间"的权衡。
3. **神经元重叠检索有条件地优于随机**：在域内推理多样性高的域（Chem：Jaccard 平均距离 0.870）效果明显；在推理同质化的域（Bio/Mat：≈0.63）退化为接近随机。
4. **域内增益来自教师–学生 token 级分布差**：Mat ($\Delta H = -0.017$)、Phys ($\Delta H = -0.010$) 两个教师明显锐化的域对应最大 in-domain 增益 (+2.27、+2.93)；Bio、Chem $|\Delta H|<0.003$，几乎无增益。
5. **跨域与校准更稳健**：相比 LMSI 跨域 Avg 下降 3.97、Intuitor 跨域 ECE 增加 0.030，Neuron-OPSD 跨域 Avg 提升 0.70、跨域 ECE 仅 -0.001。
6. **Edu-Feedback 上最显著**：N-OPSD EDU 行在 Edu 上 +7.24 Avg、ECE -0.056，是所有 N-OPSD 行中精度增益最大、校准最优的配置。

## 7. 优点

- **首次将神经元激活同时用于数据选择与教师上下文构造**，形成统一的"内部信号驱动的数据工程"范式。
- **全程无标注**：从样本筛选、上下文构建到 OPD 训练，零真实标签依赖。
- **token 级蒸馏避免奖励坍缩**：反 KL + 软教师分布保留了不确定性，缓解标量奖励 RL 的 calibration collapse 问题。
- **可解释性强**：通过 $\Delta H$、Maj−Avg、神经元 Jaccard 距离等可观测指标定位失效域，可指导后续改进。
- **机制清晰**：与 He et al. (2026) 的"自监督锐化先验"理论相吻合——改进发生于教师提供的 token 级分布差距足够且高共识样本未过度饱和时。

## 8. 不足与局限

1. **域内增益不均衡**：Bio、Chem 上几乎无 in-domain 增益，受限于教师 token 级不锐化，方法对域的"分布差距"敏感。
