# Phase 1 — Orientation（0-3 个月）

> **你现在的画像:** 入门小白（`audienceProfile: 'novice'`）
> **本阶段目标:** 不焦虑、不被淹没、能跟上一两篇综述。

---

## 1. 你这 3 个月最大的敌人

不是"读不懂"——而是**读不完**。

每天 arXiv 新增 200+ 论文,就算只看你方向也有 30+。新人最常犯的错是**订阅全量**,然后被淹没,产生"我是不是不适合读 PhD"的错觉。

**本阶段唯一指标:** 1 周精读完 1 篇综述 + 2 篇经典 + 0 篇追新。

---

## 2. 你的第一个库:配置指南

进 `/libraries/`,新建库时填这些字段：

| 字段 | 推荐值 | 为什么 |
|------|--------|--------|
| 名称 | `我的 ML 入门` 或你方向的名字 | 一眼认出来 |
| 描述 | `novice 画像,只收综述 + 经典 + 奠基性论文` | 让未来的你记得为什么建 |
| 读者画像 | **入门小白** | defaultThreshold=0.55,对新人友好 |
| 关键词 | `survey` / `review` / `tutorial` / 经典方法名 | LLM 会按这些匹配 |
| 排除关键词 | `benchmark` / `empirical` / 你不关心的子方向 | 避免边角论文混进来 |
| 默认阈值 | 用画像默认值 0.55,**别手动调** | 你现在还没能力判断一篇是否"够格" |

**关键动作:** 在库里加 3-5 篇 anchor paper。
- 找法:进 `/concepts/` 找你方向的根概念 → 看概念页里"反向链接"里被引最多的那几篇。
- 标记 anchor = 你认定的"必读论文"。新论文打分时,和 anchor 越像分越高。

---

## 3. 1 周读 1 篇综述的具体步骤

1. 在库里点 **"🔍 拉取 arXiv 候选"**,筛综述类
2. 选一篇引用数 ≥ 100 的综述 → 点进论文详情页
3. 读 3 个 section:
   - **Abstract**(论文自己的 1 段)
   - **TL;DR**(本站点 LLM 生成的 1 句话)
   - **核心贡献 / Main contributions**(原文 §1 末尾)
4. **不读 Methods** — 你现在读不懂,读了也记不住
5. **读 Related Work**(原文 §2)— 这是综述最值钱的 section
6. 看到反复出现的名字 → 写进你的 idea 库(进 `/ideas/`)
7. 读完后,回你的库,把这篇 mark as `included` + 写 1 句话的 note

---

## 4. 你的第一个 idea 库

进 `/ideas/` → "新建想法"。

**头 5 条 idea 不要"造 idea",要"抄 idea"**：
- 第 1 条:刚才综述里你最感兴趣的 1 个方向,标题写它的英文名 + 中文副标
- 第 2 条:综述里出现频率最高的 3 个术语,标题写"`术语A` vs `术语B`"
- 第 3-5 条:综述 Related Work 里点名的 3 个奠基论文,标题写"读 `<论文名>` 笔记"

为什么要"抄"？因为 PhD 头 3 个月最值钱的不是创意,是**知道前人做了什么**。

---

## 5. 不要做的事（重要）

- ❌ **不要订阅每天 arXiv** — 你现在消化不了
- ❌ **不要硬啃 Top venue 单论文** — 先读综述
- ❌ **不要上来就 LLM 自动 ingest 全量** — novice 画像虽然宽松,但还是会塞一堆你读不下去的
- ❌ **不要追求"读完"** — 读 100 篇 paper 不如深读 5 篇 + 复现 1 篇
- ❌ **不要相信"我也能想到这个 idea"** — 99% 的情况是综述里已经有人想过了
- ❌ **不要花超过 2 周挑一个方向** — 先选一个能 talk 10 分钟的方向,3 个月后再 pivot

---

## 6. 1 个月后该有的产出

- [ ] 1 个 `novice` 画像的库,≥10 篇论文
- [ ] ≥5 条 idea(3 条是"读 X 笔记",2 条是"方向探索")
- [ ] 1 篇综述的 1 页 PDF 笔记(可以放进 `/writing/`,type=`note`)
- [ ] ≥1 个 anchor paper 的完整精读(读 Methods + 实验 + Limitations)

---

## 7. 切换到 Phase 2 的信号

出现以下任意 3 条,你就该进 Phase 2 了：

- [ ] 你能在 5 分钟内给同实验室的硕士讲清楚你方向的 3 个核心问题
- [ ] 你读新论文时,不再每句都查术语
- [ ] 你能用 1 段话说清楚"这个方法的 limitation 是什么"
- [ ] 你的库里 ≥15 篇,而且**有重复 / 互相引用的子集**(说明你开始形成 map)
- [ ] 你能在 10 分钟内分辨一篇论文是"综述 / 方法 / 实验 / 复现"哪种
